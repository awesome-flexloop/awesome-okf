## F-001 项目基本信息

- 项目名称：Code Your Own LLM
- 副标题：动手训练你自己的大语言模型
- 当前状态：⚠️ Alpha内测版，尚不完整且可能存在错误
- 来源：README.md:3-5, 25

## F-002 项目定位与起源

- 项目是基于 [nanochat](https://github.com/karpathy/nanochat) 的深度扩展项目
- 定位为"全栈式参考指南"，用最简洁的代码端到端定义大语言模型的每一个细节
- 代码风格：极致扁平化结构、零层级嵌套、极简项目依赖
- 五个覆盖维度：原理解读、工程实现、实践指导、优化分析、可视化展示
- 来源：README.md:21-23

## F-006 AGENTS.md 性质

- AGENTS.md 实际内容为"第零章 格式模板和规范指南"
- 是适用于本项目所有 `.md` 文档的格式模板
- 推荐在 Typora 中以 GitHub 主题预览
- 来源：AGENTS.md:1-5

## F-007 文档结构规范

- 采用三级标题体系，禁止出现孤立的三级标题
- 章节标题（`#`）后需添加无标题序言概括核心内容
- 每个一级标题段落前后需要空行
- 段落长度需合理，不宜过长或过短
- 来源：AGENTS.md:10-16

## F-008 内容写作规范

- 主要语言为中文，英文作为辅助语言
- 英文部分使用反引号限定（如 `transformer`）
- 中英文混排时英文与两侧中文间留一个空格（标点侧除外）
- 首行缩进使用 `&emsp;` 实现
- 叙述主体统一使用"我们"
- 强调文字使用 `<strong> </strong>` 包裹
- 引用标记使用 `<sup> </sup>` 包裹
- 来源：AGENTS.md:35-41

## F-009 图像规范

- 图像格式：png 或 gif
- 图中文字：中文用宋体，英文用 Times New Roman
- 每个图像必须包含 caption（位于图像下方居中）
- 图像编号格式：`x.y`（x为章节号，y从1开始递增）
- 正文中必须包含对应图像引用
- 来源：AGENTS.md:45-54

## F-010 表格规范

- 每个表格必须包含 caption（位于表格上方居中）
- 表格编号格式：`x.y`（x为章节号，y从1开始递增）
- 正文中必须包含对应表格引用
- 来源：AGENTS.md:58-73

## F-011 代码规范

- 代码块使用三重反引号，开头标注语言标识符（python/bash/json等）
- 代码风格遵循 Google Python Style Guide
- 函数必须包含 docstring（描述、Args、Returns、Raises）
- 所有函数参数和返回值需包含类型注解（Type Hints）
- 类需包含文档字符串说明用途和属性
- 行内代码使用单个反引号包裹
- 命令行代码统一使用 bash 作为语言标识符
- 代码块长度一般不超过 50 行，超长代码只展示关键部分或放 code/ 目录
- 来源：AGENTS.md:76-237

## F-012 公式规范

- 使用 LaTeX 语法编写
- 行内公式用单 `$` 包裹，独立公式用 `$$` 包裹
- 重要公式添加编号，格式 `(x.y)`
- 公式排版：变量斜体、函数名正体、向量矩阵粗体、集合花体/空心体
- 规定了六类常用数学符号：数字和数组、集合和索引、线性代数运算、微积分、概率和信息论、常用函数
- 来源：AGENTS.md:241-442

## F-013 参考文献规范

- 参考文献遵循 APA Style
- 一般链接引用直接使用 markdown 语法
- 出版物/论文正式引用需添加引用标记及参考文献列表
- 来源：AGENTS.md:446-450
