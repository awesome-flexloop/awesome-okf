# 第一章 NLP 基础概念

## 信源信息

- **文件路径**：`docs/chapter1/第一章 NLP基础概念.md`
- **GitHub**：https://github.com/datawhalechina/happy-llm/blob/main/docs/chapter1/第一章%20NLP基础概念.md

## 内容概要

本章为非 NLP 背景读者提供基础知识，涵盖：

- **什么是 NLP**：自然语言处理的定义与研究范畴
- **发展历程**：符号主义阶段 → 统计学习阶段 → 深度学习阶段 → 预训练模型阶段 → 大模型阶段
- **任务分类**：自然语言理解（NLU）与自然语言生成（NLG），包括分类、NER、问答、翻译、摘要等
- **文本表示演进**：向量空间模型（VSM）→ 语言模型 → Word2Vec → ELMo → BERT/GPT

## 对应概念

本章为全书基础，不直接对应独立概念文档，但为 [Transformer 架构](../concepts/transformer-architecture.md) 和 [预训练语言模型](../concepts/pretrained-language-model.md) 提供背景知识。
