# NLP 基础与发展历程

## 核心理解

自然语言处理（Natural Language Processing, NLP）是人工智能的重要分支，赋予计算机**理解、解释、生成人类语言**的能力，并基于这些能力对文本数据进行决策。NLP 旨在弥合人类交流的模糊性、情境性与计算机精确指令系统之间的鸿沟。

## NLU 与 NLG

NLP 工程实践可概括为两类能力：

- **自然语言理解（NLU）**：输入语言，输出结构化信息——意图识别、实体提取、情感分析。例如从"帮我订明天去上海的机票"解析出意图和关键实体。
- **自然语言生成（NLG）**：输入结构化信息，输出语言——将数据转化为人类可读文本。现代大语言模型以"预测下一个 token"为统一训练目标，在同一模型内同时覆盖理解与生成。

## 技术四层次

NLP 技术体系是层层递进的金字塔：

| 层次 | 任务 | 示例 |
|------|------|------|
| **词法分析** | 分词、词性标注 | "南京市/长江大桥" |
| **句法分析** | 语法结构、语法树 | "我爱北京天安门"主谓宾 |
| **语义分析** | 词义消歧、关系抽取 | "苹果"指水果还是公司 |
| **语用分析** | 语境理解、意图推断 | "房间里真冷"=请求关窗 |

## 发展四阶段

### 1. 萌芽期（1950s）

- 1950 年图灵发表《计算机器与智能》，提出**图灵测试**。
- 1954 年 IBM-Georgetown 俄英机器翻译演示（250 词条、6 条规则），曾乐观预测"三到五年实用"。

### 2. 规则时代（1960s-1980s）

- 由语言学家主导，以**逻辑规则描述语言**，乔姆斯基形式语言理论影响深远。
- 代表系统：ELIZA（1966，关键词匹配模拟心理治疗）、SHRDLU（1970，积木世界指令理解）。
- 瓶颈：规则难以穷尽，系统脆弱，无法处理规则外情况。

### 3. 统计时代（1990s-2000s）

- 范式转变：**让计算机从数据中学习规律**，将语言现象转化为概率计算。
- 核心技术：N-gram 模型、隐马尔可夫模型（HMM）、条件随机场（CRF）。
- 标志性成果：2006 年 Google 翻译上线（统计机器翻译）。

### 4. 深度学习与 LLM 时代（2010s-至今）

| 年份 | 里程碑 | 意义 |
|------|--------|------|
| 2013 | Word2Vec | 词的稠密向量表示，分布式语义 |
| 2014 | Attention | 神经机器翻译中的注意力机制 |
| 2017 | Transformer | 自注意力为核心，并行计算，大模型架构基础 |
| 2018 | BERT | 掩码语言模型，预训练-微调范式普及 |
| 2020 | GPT-3 | 大规模参数带来少样本/零样本泛化，LLM 时代到来 |
| 2022 | ChatGPT | 指令微调+RLHF 对齐，引爆全球 AI 浪潮 |

## NLP 主要任务

涵盖文本分类、情感分析、命名实体识别（NER）、关系抽取、机器翻译、文本摘要、问答系统、对话系统等。现代大语言模型以统一的生成式框架覆盖了上述大部分任务。

## 环境准备

教程要求 Python 3.10+，基于 PyTorch 深度学习框架，需掌握 Python 基础语法、PyTorch 基本使用、深度学习基础（反向传播、模型训练）和基本数学（线性代数、概率论、梯度下降）。
