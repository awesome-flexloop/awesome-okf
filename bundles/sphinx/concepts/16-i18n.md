# 国际化与本地化

Sphinx提供了完整的国际化（i18n）支持，基于GNU gettext标准。你可以将Sphinx文档翻译成多种语言，而不需要修改源文件。

## 核心概念

- **POT文件**（Portable Object Template）：翻译模板文件，包含所有需要翻译的字符串
- **PO文件**（Portable Object）：特定语言的翻译文件
- **MO文件**（Machine Object）：PO文件编译后的二进制文件，Sphinx运行时使用
- **消息ID（msgid）**：原始文本字符串
- **消息字符串（msgstr）**：翻译后的字符串

## 配置

```python
# conf.py
language = 'zh_CN'           # 文档语言
locale_dirs = ['locales/']   # 翻译目录（相对于conf.py）
gettext_compact = False      # 是否将所有文档的翻译合并到一个POT文件
gettext_uuid = False         # 是否在POT文件中生成UUID
gettext_location = True      # 是否在POT中包含源位置信息
gettext_auto_build = True    # 是否自动编译MO文件
figure_language_filename = '{root}.{language}{ext}'  # 语言特定图片的命名模式
gettext_allow_fuzzy_translations = False  # 是否允许模糊翻译
translation_progress_classes = False  # 是否在HTML中添加翻译进度CSS类
```

### 支持的语言

Sphinx通过Babel库支持多种语言，常用的语言代码：

| 代码 | 语言 |
|------|------|
| `en` | 英语（默认） |
| `zh_CN` | 简体中文 |
| `zh_TW` | 繁体中文 |
| `ja` | 日语 |
| `ko` | 韩语 |
| `fr` | 法语 |
| `de` | 德语 |
| `es` | 西班牙语 |
| `pt_BR` | 巴西葡萄牙语 |
| `ru` | 俄语 |

## 翻译工作流

### 步骤1：生成POT模板

```bash
sphinx-build -b gettext docs docs/locales/gettext
```

这会在`docs/locales/gettext/`目录下生成`.pot`文件。每个文档对应一个`.pot`文件（如果`gettext_compact=False`），或所有文本合并到一个`sphinx.pot`文件中（如果`gettext_compact=True`）。

### 步骤2：初始化PO文件

```bash
# 使用sphinx-intl（推荐工具）
pip install sphinx-intl
sphinx-intl update -p docs/locales/gettext -l zh_CN -l ja
```

这会创建`docs/locales/zh_CN/LC_MESSAGES/*.po`文件。

手动创建也可以：
```bash
msginit -i docs/locales/gettext/sphinx.pot -o docs/locales/zh_CN/LC_MESSAGES/sphinx.po -l zh_CN
```

### 步骤3：翻译PO文件

编辑`.po`文件，填写msgstr：

```po
msgid "Welcome to My Project"
msgstr "欢迎使用我的项目"

msgid "Installation"
msgstr "安装"

msgid "See also:"
msgstr "参见："
```

可以使用Poedit、Lokalize等图形化工具编辑PO文件。

### 步骤4：编译MO文件

```bash
sphinx-intl build
# 或
msgfmt -o docs/locales/zh_CN/LC_MESSAGES/sphinx.mo docs/locales/zh_CN/LC_MESSAGES/sphinx.po
```

Sphinx设置`gettext_auto_build=True`时会自动编译PO文件为MO文件。

### 步骤5：构建翻译后的文档

```bash
sphinx-build -b html -D language=zh_CN docs docs/_build/html/zh_CN
```

或在conf.py中设置`language = 'zh_CN'`。

## 可翻译内容

Sphinx自动提取以下内容用于翻译：

| 内容类型 | 是否提取 | 说明 |
|---------|---------|------|
| 段落文本 | ✅ | 所有普通段落 |
| 章节标题 | ✅ | section标题 |
| 指令内容 | ✅ | note/warning/code-block标题等 |
| 指令选项 | ⚠️ | 部分选项（如`:caption:`） |
| 目录树标题 | ✅ | toctree的caption选项 |
| 角色内文本 | ✅ | 如 `:ref:\`Link text <label>\`` 中的Link text |
| 索引项 | ✅ | index指令中的文本 |
| 代码块内容 | ❌ | 代码不翻译 |
| 字面量 | ❌ | 行内代码不翻译 |
| 配置值 | ⚠️ | project/author/copyright等配置项需要手动翻译 |

### 翻译配置项

conf.py中的配置项可以通过条件设置：

```python
project = 'My Project'
copyright = '2026, Author'
author = 'Author'

if tags.has('i18n') or language == 'zh_CN':
    project = '我的项目'
    copyright = '2026, 作者'
    author = '作者'
```

## 多语言构建

### 多语言目录结构

```
docs/
├── conf.py
├── index.rst
├── locales/
│   ├── gettext/          # POT模板（gettext builder输出）
│   │   └── sphinx.pot
│   ├── zh_CN/
│   │   └── LC_MESSAGES/
│   │       ├── sphinx.po
│   │       └── sphinx.mo
│   └── ja/
│       └── LC_MESSAGES/
│           ├── sphinx.po
│           └── sphinx.mo
└── _static/
    └── logo.zh_CN.png    # 语言特定图片
```

### 语言特定资源

使用`figure_language_filename`模式，可以为不同语言提供不同的图片：

```python
# conf.py
figure_language_filename = '{root}.{language}{ext}'
# 默认图片：screenshot.png
# 中文图片：screenshot.zh_CN.png
```

## 翻译上下文（msgctxt）

Sphinx在某些情况下使用msgctxt（消息上下文）来区分相同文本的不同含义：

```po
# 例如"Search"作为按钮和作为标题
msgctxt "button"
msgid "Search"
msgstr "搜索"

msgctxt "title"
msgid "Search"
msgstr "搜索文档"
```

## 智能引号

Sphinx内置智能引号转换功能，自动将直引号转换为排版引号 [F-063]：

```python
smartquotes = True  # 默认启用
smartquotes_action = 'qDe'  # q=引号, D=长破折号, e=省略号
smartquotes_excludes = {
    'languages': ['ja', 'zh_CN', 'zh_TW'],  # 中日韩不转换
    'builders': ['man', 'text'],            # 纯文本builder不转换
}
```

中文、日文等CJK语言默认不启用智能引号，因为它们使用不同的引号字符。
