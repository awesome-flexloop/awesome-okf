## 产品定位

WorkBuddy 定位为在线 AI 助手 Web 应用（腾讯龙虾）（F-052），标语为 "WorkBuddy, 我帮你"（F-053）。当前处于公测阶段（F-060）。

## 两大场景

### 日常办公

覆盖以下能力（F-054）：

- 幻灯片
- 视频
- 深度研究
- 文档
- 数据分析
- 可视化
- 金融
- 产品
- 设计
- 邮件

### 代码开发

覆盖以下能力（F-055）：

- 日常开发
- 网站
- Agent 应用
- Skill 开发
- CI/CD
- 文档

## 交互方式

WorkBuddy 采用对话式交互（F-056）：

- `@` 引用对话文件
- `/` 调用技能与指令

右侧面板提供三部分内容（F-057）：

| 面板区域 | 内容 |
|----------|------|
| 概览 | 任务整体情况 |
| 产物（Artifacts） | 生成的交付物 |
| 引用来源追踪 | 信息来源溯源 |

## 其他特性

- 支持代码仓库关联（F-058）
- 支持全屏模式（F-058）

## 顶部导航

WorkBuddy 顶部导航包含以下入口（F-059）：

- IDE
- 插件
- CLI
- 文档
- 定价
- 博客
- API 文档
- 活动

该导航结构表明 WorkBuddy 与 CodeBuddy IDE/插件/CLI 属于同一产品生态体系。
