# Concepts

本目录包含 CodeBuddy 产品矩阵的 6 个概念文档，按"产品矩阵篇"与"核心能力篇"组织。

## 产品矩阵篇

- [00 - 产品矩阵总览](/concepts/00-product-matrix.md) — IDE/插件/CLI 三态一体与 NPC、WorkBuddy、Security 三大延伸产品的定位与关系
- [01 - CodeBuddy IDE](/concepts/01-ide.md) — 基于 VSCode 架构的产设研一体 AI 桌面端，自然语言驱动全流程开发
- [02 - CLI](/concepts/02-cli.md) — 终端原生 AI 编程工具，全仓代码感知、MCP 双端、分层记忆与 Sub-agents
- [03 - NPC 云端 AI 员工](/concepts/03-npc.md) — 基于 CodeBuddy 的云端自主 Agent，目标驱动从需求到 PR 全流程
- [04 - WorkBuddy 在线助手](/concepts/04-workbuddy.md) — 覆盖办公与开发双场景的对话式在线 AI 助手
- [05 - Security 安全审计](/concepts/05-security.md) — 六步安全闭环、对抗性 AI 审查与 PoC 动态验证

## 阅读建议

1. **新用户**：从 00-product-matrix 了解全貌，再按需深入具体产品
2. **开发者**：01-ide → 02-cli → 03-npc，掌握从本地到云端的完整研发链路
3. **安全工程师**：05-security 重点阅读六步闭环与对抗性审查机制
4. **办公用户**：04-workbuddy 了解在线助手能力
