# constants.py：枚举常量全量参考

## 信源概述

| 信源 | 类型 | 行数 | 职责 |
|------|------|------|------|
| `zmq/constants.py` | Python 枚举定义 | ~717行 | 所有 ZeroMQ 常量的 IntEnum/IntFlag 定义及模块级展开 |

`constants.py` 是 pyzmq 常量的唯一权威定义处。它使用 Python 标准库的 `IntEnum` 和 `IntFlag` 定义了十个枚举类别，在枚举定义之后通过 `# AUTOGENERATED_BELOW_HERE` 标记把所有枚举成员展开为模块级常量，以支持 `from zmq.constants import *` 和旧式 `zmq.POLLIN` 直接访问。

## 枚举类别一览

| 枚举类 | 基类 | 用途 |
|--------|------|------|
| `Errno` | IntEnum | ZeroMQ 错误码 |
| `ContextOption` | IntEnum | Context 级选项（如 IO_THREADS） |
| `SocketType` | IntEnum | 套接字类型（PUB/SUB/REQ/REP 等） |
| `SocketOption` | IntEnum | 套接字选项，成员携带 `_opt_type` 元数据 |
| `MessageOption` | IntEnum | 消息相关选项 |
| `Flag` | IntFlag | 发送/接收标志（NOBLOCK/SNDMORE） |
| `PollEvent` | IntFlag | 轮询事件位掩码（POLLIN/POLLOUT/POLLERR） |
| `DeviceType` | IntEnum | 设备类型（QUEUE/FORWARDER/STREAMER） |
| `SecurityMechanism` | IntEnum | 安全机制（NULL/PLAIN/CURVE/GSSAPI） |
| `Event` | IntFlag | 套接字监控事件类型 |

## SocketOption 的 _opt_type 机制

### F-090：SocketOption 成员携带 _opt_type

**信源**：`zmq/constants.py:138-151`

`SocketOption` 的 `__new__` 方法签名为：

```python
def __new__(cls, value, opt_type=_OptType.int):
    obj = int.__new__(cls, value)
    obj._opt_type = opt_type
    return obj
```

每个 `SocketOption` 枚举成员除了整数值外，还携带一个 `_opt_type` 属性，取值来自 `_OptType` 枚举：

| _OptType | C 指针类型 | 适用选项示例 |
|----------|-----------|-------------|
| `int` | `int*` | SUBSCRIBE、LINGER、SNDHWM、RCVHWM、TYPE 等 |
| `int64` | `int64_t*` | AFFINITY、RATE、RECOVERY_IVL、SNDBUF、RCVBUF 等 |
| `bytes` | `char*` | IDENTITY、SUBSCRIBE（二进制前缀）、PLAIN_USERNAME、PLAIN_PASSWORD、CURVE_SERVERKEY、CURVE_PUBLICKEY、CURVE_SECRETKEY 等 |
| `fd` | `SOCKET`（Windows）/`int`（POSIX） | FD |

后端（Cython 或 CFFI）在调用 `zmq_setsockopt`/`zmq_getsockopt` 时，根据 `_opt_type` 选择正确的 C 指针类型进行参数封送。CFFI 后端的 `Socket.set()` 方法通过 `SocketOption(option)._opt_type` 判断类型并调用 `initialize_opt_pointer` 构造对应 C 指针（F-081）。

## 主要枚举值速查

### SocketType

| 常量 | 值 | 说明 |
|------|----|------|
| PAIR | 0 | 一对一双向通信 |
| PUB | 1 | 发布端（扇出） |
| SUB | 2 | 订阅端（扇入） |
| REQ | 3 | 请求端（严格请求-应答） |
| REP | 4 | 应答端 |
| DEALER | 5 | 异步请求端（ROUTER-DEALER 模式） |
| ROUTER | 6 | 异步应答端（按路由标识分发） |
| PULL | 7 | 管道上游（公平排队接收） |
| PUSH | 8 | 管道下游（循环分发发送） |
| XPUB | 9 | 扩展发布端（暴露订阅消息） |
| XSUB | 10 | 扩展订阅端（可编程订阅） |
| STREAM | 11 | 原生 TCP 流 |

### Flag（发送/接收标志）

| 常量 | 值 | 说明 |
|------|----|------|
| NOBLOCK | 1 (DONTWAIT) | 非阻塞模式，EAGAIN 时立即返回 |
| SNDMORE | 2 | 标记后续还有更多消息帧（multipart） |

### PollEvent（轮询事件）

| 常量 | 值 | 说明 |
|------|----|------|
| POLLIN | 1 | 可读事件 |
| POLLOUT | 2 | 可写事件 |
| POLLERR | 4 | 错误事件 |

`Poller.register(socket, flags=POLLIN|POLLOUT)` 的 flags 参数即使用此 IntFlag 组合。

### ContextOption

| 常量 | 值 | 说明 |
|------|----|------|
| IO_THREADS | 1 | I/O 线程数 |
| MAX_SOCKETS | 2 | 最大套接字数 |
| IPV6 | 42 | 启用 IPv6 |
| BLOCKY | 100 | 阻塞模式（内部） |

### SecurityMechanism

| 常量 | 值 | 说明 |
|------|----|------|
| NULL | 0 | 无认证 |
| PLAIN | 1 | 用户名/密码明文认证 |
| CURVE | 2 | CURVE 椭圆曲线加密认证 |
| GSSAPI | 3 | GSSAPI/Kerberos 认证 |

### DeviceType

| 常量 | 值 | 说明 |
|------|----|------|
| QUEUE | 1 | 请求-应答队列设备 |
| FORWARDER | 2 | 发布-订阅转发设备 |
| STREAMER | 3 | 管道流设备 |

### Errno（关键错误码）

| 常量 | 值 | 对应异常 |
|------|----|---------|
| EAGAIN | 11 | `Again` — 非阻塞操作无法立即完成 |
| EINTR | 4 | `InterruptedSystemCall` — 系统调用被信号中断 |
| ETERM | 156384715 | `ContextTerminated` — Context 已终止 |
| ENOTSUP | 156384741 | `ZMQError` — 操作不被支持 |
| EFSM | 156384765 | `ZMQError` — 套接字状态机不允许此操作 |
| EADDRINUSE | 98（POSIX）/ 10048（Windows） | `ZMQError` — 地址已被占用 |

### Event（监控事件，IntFlag）

Event 枚举定义了套接字监控事件的位掩码值，包括：

| 事件类别 | 典型事件 |
|---------|---------|
| 连接事件 | EVENT_CONNECTED、EVENT_CONNECT_DELAYED、EVENT_CONNECT_RETRIED |
| 监听事件 | EVENT_LISTENING、EVENT_BIND_FAILED |
| 接受事件 | EVENT_ACCEPTED、EVENT_ACCEPT_FAILED |
| 关闭事件 | EVENT_CLOSED、EVENT_CLOSE_FAILED、EVENT_DISCONNECTED |
| 全部事件 | EVENT_ALL（所有事件位的组合） |

`Socket.get_monitor_socket(events=None, addr=None)` 的 `events` 参数默认为 `EVENT_ALL`（F-041）。

### MessageOption

`MessageOption` 定义了消息帧（zmq_msg_t）级别的选项，主要用于 Frame 属性访问，包括 MORE（是否有后续帧）、SHARED（消息是否共享）等。

## F-091：AUTOGENERATED 模块级常量展开

**信源**：`zmq/constants.py:449-717`

在所有枚举类定义之后，`constants.py` 使用 `# AUTOGENERATED_BELOW_HERE` 标记，将每个枚举成员展开为模块级同名常量：

```python
# AUTOGENERATED_BELOW_HERE

# 从 Errno 展开
EAGAIN = Errno.EAGAIN
EINTR = Errno.EINTR
ETERM = Errno.ETERM
# ...

# 从 SocketType 展开
PUB = SocketType.PUB
SUB = SocketType.SUB
REQ = SocketType.REQ
REP = SocketType.REP
ROUTER = SocketType.ROUTER
# ...

# 从 PollEvent 展开
POLLIN = PollEvent.POLLIN
POLLOUT = PollEvent.POLLOUT
POLLERR = PollEvent.POLLERR

# 从 Flag 展开
NOBLOCK = Flag.NOBLOCK
SNDMORE = Flag.SNDMORE
DONTWAIT = Flag.DONTWAIT  # NOBLOCK 的别名
# ...
```

这一展开有三重作用：

1. **`from zmq.constants import *` 支持**：`__all__` 列出所有展开的常量名，使 `from zmq import *` 可直接使用 `zmq.PUB`、`zmq.POLLIN` 等。
2. **向后兼容**：旧版 pyzmq 用户习惯直接用 `zmq.POLLIN` 整数值，而非 `zmq.PollEvent.POLLIN`。
3. **属性动态查找**：`AttributeSetter.__setattr__` 将属性名大写后从 `zmq.constants` 模块命名空间查常量（F-059），模块级展开使这一查找可以直接命中。

## 与 attrsettr 的协作

`AttributeSetter` mixin（见 [attrsettr-options.md](attrsettr-options.md)）的 `__setattr__` 方法在遇到非实例/非类属性时，将 key 大写后从 `zmq.constants` 查枚举常量。由于模块级展开，`socket.linger = 1000` 中的 `linger` 大写为 `LINGER`，可在 constants 模块中直接找到 `SocketOption.LINGER`，进而委托给 `self._set_attr_opt('LINGER', SocketOption.LINGER, 1000)`。
