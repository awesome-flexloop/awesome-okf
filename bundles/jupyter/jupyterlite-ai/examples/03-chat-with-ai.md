# AI 对话技巧

掌握高效的对话方式，让 JupyterLite AI 成为你数据分析和编程的得力助手。

## 聊天面板功能

### 界面布局

- **消息区域**：显示对话历史，支持 Markdown 渲染和代码高亮
- **输入框**：底部输入区域，支持多行文本（Shift+Enter 换行）
- **发送按钮**：发送消息，或直接按 Enter
- **停止按钮**：AI 回复过程中可中断生成
- **清空对话**：清除当前对话历史（不影响 Notebook 内容）
- **设置按钮**：打开配置面板

### 消息操作

- **复制代码**：鼠标悬停在代码块上显示复制按钮
- **插入到 Notebook**：将 AI 生成的代码插入到当前 Notebook 单元格
- **重新生成**：重新生成 AI 的上一条回复
- **编辑消息**：编辑自己发送过的消息重新提交

## 对话上下文

AI 能看到的上下文包括：
1. **对话历史**：当前会话的所有消息
2. **Notebook 内容**：当前打开的 Notebook 的单元格内容（AI 可主动读取）
3. **系统提示词**：Persona 定义的角色设定
4. **工具结果**：工具调用返回的结果

### 上下文窗口限制

AI 模型有上下文窗口长度限制。对话过长时，早期消息会被截断或总结。

## 高效提示词技巧

### 1. 明确表达需求

| ❌ 模糊 | ✅ 明确 |
|---------|---------|
| "帮我写代码" | "帮我写一个 Python 函数，输入是 pandas DataFrame，输出是按日期分组的销售总额统计" |
| "数据分析" | "对我 Notebook 中的 df 数据框进行探索性分析，包括缺失值统计、数值分布和相关性分析" |

### 2. 提供必要上下文

```
我正在分析一个电商数据集，数据框名为 sales，包含列：order_date, product, quantity, price, customer_id。
请帮我计算每月的 GMV 并画一个趋势图。
```

### 3. 分步请求

对于复杂任务，分步进行效果更好：

1. 先请 AI 理解数据："请先读取并总结我当前 Notebook 中的数据"
2. 再提出分析需求："基于这些数据，帮我分析..."
3. 最后细化结果："把图表改成分组柱状图，加上标题和图例"

### 4. 指定输出格式

```
请用以下格式输出：
1. 问题分析（简短说明思路）
2. 代码实现
3. 结果解释
```

## 常用对话模式

### 代码生成

```
写一个 Python 函数，接收一个文件路径，读取 CSV 文件，返回：
- 数据基本信息（行列数、列名、数据类型）
- 缺失值统计
- 数值列的描述性统计
使用 pandas 实现，代码要有注释。
```

### 代码解释

```
请解释我当前 Notebook 中第 3 个单元格的代码在做什么？
```

### 调试帮助

```
运行第 5 个单元格时出现了 ValueError，错误信息是：[粘贴错误信息]
请帮我分析原因并修复。
```

### 数据探索

```
请帮我探索 Notebook 中的数据集：
1. 先读取数据概览
2. 检查数据质量
3. 对关键列做分布分析
4. 给出下一步分析建议
每一步都生成代码并插入到 Notebook 中运行。
```

### 学习辅导

```
我是 Python 初学者，请帮我理解什么是列表推导式，用简单例子说明，然后给我一个练习题。
```

## 多轮对话策略

1. **及时纠正**：AI 理解有误时立即指出
2. **追加要求**："在刚才的代码基础上，再加一个错误处理"
3. **引用前文**："就像你上一步做的那样，但应用到另一个列上"
4. **总结提炼**："请总结一下我们刚才做的分析步骤和结论"

## 注意事项

- AI 生成的代码应审查后再运行，尤其是涉及数据修改的操作
- AI 可能会"幻觉"不存在的 API 或函数，遇到不确定的请查阅官方文档
- 对话中的 Notebook 操作需要审批（execute_command 工具）
- 定期清空不需要的对话历史，避免上下文溢出
