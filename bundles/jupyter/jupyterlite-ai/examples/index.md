## 前置条件

- **JupyterLab** 4.x 或 **Notebook** 7.x，或 **JupyterLite** 0.6.x+
- **Python** 3.10+
- 至少一个 AI 模型提供商的 API Key
- 现代浏览器（Chrome/Firefox/Edge/Safari 最新版）

## 学习路径建议

1. **新手**：按顺序阅读快速入门 → 核心功能
2. **有经验开发者**：直接阅读高级功能和开发者示例
3. **JupyterLite 用户**：重点阅读 01-quick-start 和 08-jupyterlite-deployment
