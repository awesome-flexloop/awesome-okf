# 成员指南信源

**原始文件路径**：`docs/team/member-guide.md`

**内容摘要**：

成员指南为 Council 成员提供资源和行为指导，帮助成员成为高效、愉快的团队参与者。

## 团队资源
- **Team Compass 仓库**：团队相关信息（开发提示、会议信息、里程碑、路线图等）
- **Team Compass Issues**：讨论与团队相关的具体可操作事项

## 沟通渠道政策
1. **GitHub Issues**：特定仓库的变更讨论（功能请求、Bug 报告）
2. **Discourse 论坛**：通用讨论、支持问题、灵感交流
3. **Zulip**：讨论和支持问题
4. **邮件列表**（jupyterlab-council）：成员资格、非公开问题等

## 成员具体职责（5项）
1. **Watch 仓库**：关注 team-compass 和 council 仓库的通知
2. **了解会议动态**：通过置顶 Issue 获取会议记录
3. **投票**：参与至少 2/3 的投票，GitHub 会自动 ping
4. **请假通知**：长期不在时告知团队（公开或私下）
5. **促进开放包容讨论**：在公开空间交流、为离线重要对话做汇报、创建 Issue 时提供充分上下文、鼓励反馈、耐心等待审批合入

## PR 合并指南（5条原则）
1. **运用最佳判断**：团队信任成员的判断力
2. **确保代码质量**：组织良好、文档齐全、遵循语言最佳实践
3. **确保有测试**：新功能和 Bug 修复都应附带测试
4. **留足讨论时间**：开放社区需要时间让他人审阅和讨论，复杂议题多给几天
5. **不要害怕合并**：大多数变更可以直接合入，不要让指南成为负担
