# README 文档信源

**原始文件路径**：`README.md`（仓库根目录）

**内容摘要**：

README 是 frontends-team-compass 仓库的入口文档，包含以下核心信息：

1. **仓库定位**：Jupyter Frontends 团队交互、同步和会议记录的仓库，服务于 JupyterLab 生态系统
2. **周会信息**：
   - Frontends 团队周会：每周三太平洋时间 9:00 AM，Jupyter Zoom 房间
   - Triage 周会：每周二太平洋时间 9:00 AM，同一 Zoom 房间
   - 会议记录在 Hackmd.io 上撰写，以评论形式添加到本仓库的 GitHub Issue 中
3. **行为准则**：遵循 Project Jupyter 官方 Code of Conduct
4. **扩展贡献流程**（4步）：
   - 第一步：考虑贡献到 jupyterlab-contrib 组织
   - 第二步：在本仓库提 Issue 描述扩展并链接现有代码，须回应子项目准入标准的每一点
   - 第三步：社区评审至少一周，核心维护者审查代码、评估维护者社区参与度、可能建议归入 jupyterlab-contrib
   - 第四步：如被接受，遵循 Jupyter 官方并入指南；维护者获得 npm 包管理员权限（8步 npm 邀请流程）

**关键事实锚点**：
- F-001: 仓库定位为团队交互/同步/会议记录
- F-002: Frontends周会时间（周三 9AM PT）
- F-003: Triage周会时间（周二 9AM PT）
- F-004: 会议记录归档方式（HackMD → GitHub Issue comment）
- F-005: CoC 遵循 Jupyter 官方行为准则
- F-006: 扩展贡献4步流程
