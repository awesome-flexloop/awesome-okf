# 通过编程式API执行shell命令

本示例演示如何在JupyterLite扩展中使用`@jupyterlite/terminal:execute-shell`命令执行shell命令并捕获输出。

## 基本用法：执行单条命令

最简单的用法是执行一条命令并获取结果：

```typescript
import { JupyterFrontEnd } from '@jupyterlab/application';

async function runCommand(app: JupyterFrontEnd) {
  const result = await app.commands.execute(
    '@jupyterlite/terminal:execute-shell',
    {
      code: 'ls /drive'
    }
  );
  
  console.log('Success:', result.success);
  console.log('Output:', result.output);
  console.log('Exit code:', result.exitCode);
  console.log('Duration:', result.duration, 'ms');
}
```

### 返回值示例

成功执行`ls /drive`后的返回值：

```javascript
{
  success: true,
  status: "ok",
  output: "greeting.txt\nmonths.txt\n",
  exitCode: 0,
  shellName: "headless-1",
  duration: 123,
  message: "Command executed successfully in 123ms"
}
```

命令执行失败（如文件不存在）：

```javascript
{
  success: false,
  status: "error",
  output: "cat: /drive/nonexistent.txt: No such file or directory\n",
  exitCode: 1,
  shellName: "headless-2",
  duration: 50,
  message: "Command failed with exit code 1 after 50ms"
}
```

超时：

```javascript
{
  success: false,
  status: "timeout",
  output: "(partial output if any)",
  exitCode: null,
  shellName: "headless-3",
  duration: 30000,
  message: "Command timed out after 30000ms"
}
```

## 在JupyterLab插件中使用

完整的插件示例：

```typescript
import {
  JupyterFrontEnd,
  JupyterFrontEndPlugin
} from '@jupyterlab/application';
import { ICommandPalette } from '@jupyterlab/apputils';

const plugin: JupyterFrontEndPlugin<void> = {
  id: 'my-extension:shell-demo',
  autoStart: true,
  requires: [ICommandPalette],
  activate: (app: JupyterFrontEnd, palette: ICommandPalette) => {
    
    // 注册一个命令：列出/drive文件
    const command = 'my-extension:list-files';
    app.commands.addCommand(command, {
      label: 'List Drive Files',
      caption: 'Execute ls /drive via terminal',
      execute: async () => {
        try {
          const result = await app.commands.execute(
            '@jupyterlite/terminal:execute-shell',
            {
              code: 'ls -la /drive'
            }
          );
          
          if (result.success) {
            alert(`Files:\n${result.output}`);
          } else {
            alert(`Command failed: ${result.message}`);
          }
        } catch (err) {
          alert(`Error: ${(err as Error).message}`);
        }
      }
    });
    
    palette.addItem({ command, category: 'My Extension' });
  }
};

export default plugin;
```

## 指定工作目录

```typescript
const result = await app.commands.execute(
  '@jupyterlite/terminal:execute-shell',
  {
    code: 'ls',  // 列出当前目录
    cwd: '/drive'  // 在/drive目录下执行
  }
);
// result.output 包含/drive下的文件列表
```

## 自定义超时

默认超时30秒，可以通过timeout参数调整：

```typescript
// 快速命令，短超时
const fastResult = await app.commands.execute(
  '@jupyterlite/terminal:execute-shell',
  {
    code: 'echo hello',
    timeout: 5000  // 5秒超时
  }
);

// 长时命令，长超时
const longResult = await app.commands.execute(
  '@jupyterlite/terminal:execute-shell',
  {
    code: 'some-long-running-command',
    timeout: 120000  // 2分钟超时
  }
);
```

timeout必须是正有限数值，否则会throw错误。

## 执行多条命令（一次性shell）

使用分号`;`顺序执行多条命令（一次性shell模式，命令完成后shell自动关闭）：

```typescript
const result = await app.commands.execute(
  '@jupyterlite/terminal:execute-shell',
  {
    code: 'cd /drive; ls -la; echo "---"; cat months.txt | grep J'
  }
);
// output包含所有命令的输出
// 注意：每条命令的输出会按顺序拼接
```

## 执行管道命令

```typescript
const result = await app.commands.execute(
  '@jupyterlite/terminal:execute-shell',
  {
    code: 'cat /drive/months.txt | grep ember | wc -l'
  }
);
// result.output 可能包含匹配行数（取决于cockle是否支持wc）
```

## 写入文件

```typescript
const result = await app.commands.execute(
  '@jupyterlite/terminal:execute-shell',
  {
    code: 'echo "Generated by extension" > /drive/output.txt'
  }
);
if (result.success) {
  console.log('File written successfully');
}
```

## 错误处理

```typescript
try {
  const result = await app.commands.execute(
    '@jupyterlite/terminal:execute-shell',
    { code: 'invalid-command' }
  );
  
  if (result.status === 'timeout') {
    console.warn('Command timed out, shell may need to be restarted');
  } else if (result.status === 'error') {
    console.error(`Command failed with exit code ${result.exitCode}`);
    console.error('Stderr/stdout:', result.output);
  }
} catch (err) {
  // 参数校验错误、shell不可用等
  console.error('Failed to execute command:', (err as Error).message);
}
```

可能的错误：
- `"code must be a non-empty string"`：code参数为空或非字符串
- `"timeout must be a positive finite number"`：timeout参数无效
- `"No headless shell found with name 'X'"`：指定的shellName不存在
- `"Shell is busy..."`：同一shell正在执行其他命令
- `"Shell timed out and cannot be reused..."`：shell已超时，需重新创建

## 执行结果处理模式

### 模式1：简单输出显示

```typescript
const result = await app.commands.execute(
  '@jupyterlite/terminal:execute-shell',
  { code: 'ls /drive' }
);
// 直接显示result.output
```

### 模式2：检查文件是否存在

```typescript
const result = await app.commands.execute(
  '@jupyterlite/terminal:execute-shell',
  { code: 'test -f /drive/data.csv && echo EXISTS || echo MISSING' }
);
const exists = result.output.trim() === 'EXISTS';
```

### 模式3：解析结构化输出

```typescript
const result = await app.commands.execute(
  '@jupyterlite/terminal:execute-shell',
  { code: 'ls -1 /drive' }  // -1: 单列输出
);
const files = result.output.trim().split('\n').filter(Boolean);
console.log('Files in /drive:', files);
```

## 注意事项

1. **输出清理**：execute-shell自动去除命令回显和PS1提示符，但shell的错误输出也在output中（cockle将stderr合并到stdout）
2. **换行符**：输出中统一使用`\n`换行
3. **编码**：输出为UTF-8字符串
4. **性能**：创建一次性shell有WASM加载开销（通常数百ms），频繁执行建议使用复用shell模式
5. **超时后处理**：超时返回后建议shutdown该shell（如果是复用模式），因为超时shell不可继续使用
