# 常设委员会与工作组信源

**原始文件路径**：
- `docs/standing_committees_and_working_groups.md` - 委员会和工作组总览
- `docs/list_of_standing_committees_and_working_groups.md` - 当前列表

**内容摘要**：

**共同点**：
- 都有明确定义的 Council，使用 Jupyter 决策指南做决策
- 遵循章程中规定的 Council 任命流程
- 由 EC 管理、向 EC 报告、对 EC 负责
- 有定义范围和目的的章程（charter）
- 在章程范围内自主决策
- 尽可能开放透明地运作
- 维护公开的 GitHub 仓库（成员列表、章程、公开会议等）

**常设委员会（Standing Committees）特性**：
- 永久性，由 EC+SSC 联合投票创建和解散
- 章程变更需 EC+SSC 联合批准
- 始终在 SSC 有代表
- EC 负责确保常设委员会始终有适当资源

**当前常设委员会**：
- Diversity, Equity, and Inclusion (DEI) - 多元公平包容
- Code of Conduct Incident Response - 行为准则事件响应
- Conflict of Interest - 利益冲突
- Community Advisory Panel - 社区顾问小组

**工作组（Working Groups）特性**：
- 由 EC 单独决定创建和解散
- 章程变更由 EC 批准
- 默认无 SSC 代表
- EC 可提名工作组获 SSC 代表权，经 SSC 批准后获得

**当前工作组**：
- Trademark and Branding - 商标与品牌
- Jupyter Community Building - 社区建设
- Jupyter Media Strategy - 媒体策略
- Jupyter Documentation - 文档

**关键事实锚点**：F-015, F-016, F-017, F-018
