## 行为准则的目标

Jupyter 行为准则（Code of Conduct，简称 CoC）的目标是：
- **保证参与者的人身安全**
- **鼓励包容性、尊重性和协作性的社会互动**
- **营造有利于所有人的产出环境**

行为准则适用于 Project Jupyter 管理的所有空间，包括 GitHub 仓库、邮件列表、会议、Discord、Stack Overflow 等。

## 期望行为

1. **热情有礼、包容友善**
2. **考虑周到**：你的工作会被他人使用，你也会依赖他人的工作
3. **尊重不同观点和经验**：分歧不是无礼行为的借口
4. **协作优先**：在开源中，合作优于个人成就
5. **提问意识**：不知道不丢人，及时提问避免更大问题
6. **谨慎用词**：做尊重、包容的社区成员，避免贬损/歧视/骚扰言论和行为
7. **务实优先**：如果其他人不同意，请优雅处理——我们以"务实优先"（rough consensus and running code）为准则
8. **注意文化差异**：避免刻板假设，不同文化对"直率"的理解不同
9. **注意时间和格式**：在线异步沟通（issues/PR/邮件）中尤其注意措辞

## 不可接受行为

- **骚扰**：包括冒犯性言论、故意恐吓、跟踪、偷拍/录音骚扰、持续打扰、不适当身体接触、不受欢迎的性关注
- **排斥性语言**：不接受使他人感到不属于社区或不安全的语言
- 尤其不得使用带有性暗示的绰号或性暗示评论
- 未经允许发布他人的身份信息（如真实姓名）
- 以歧视性、贬损性或侮辱性方式威胁或辱骂他人
- 在社区活动中使用性图像/性关注
- 在社区空间中因他人的身份（包括但不限于性别、性别表达、性取向、残障、外貌、体型、公民身份、国籍、种族、年龄、宗教）而区别对待
- 提倡或鼓励上述任何行为

## 举报渠道

如遇到行为准则问题或需要报告事件：

| 渠道 | 说明 |
|------|------|
| **邮箱** | [conduct@jupyter.org](mailto:conduct@jupyter.org)（发送至 CoC 委员会） |
| **表单** | [Google Form 在线举报](https://docs.google.com/forms/d/e/1FAIpQLSfYImV4jZgKq98M1s8l0fGz1w5B2DqE1w1Kk7tVp8xQ4w9n5w/viewform) |
| **团队成员** | 联系任何 Jupyter 社区团队成员 |
| **具体活动** | 在特定活动中遵循该活动的行为准则报告流程 |

所有报告将由 CoC 事件响应常设委员会（Code of Conduct Incident Response Standing Committee）处理，绝对保密。

## 事件响应机制

CoC 委员会拥有和管理事件响应流程，对具体事件做出裁决。具体的执行手册见 [Enforcement Manual](https://jupyter.org/governance/conduct/enforcement.html)。

### 申诉机制

如果对 CoC 委员会的裁决不满，可以向 **EC（执行委员会）** 申诉。EC 是 CoC 事件的**最终申诉机构**。

### 紧急措施

在事件处理期间，CoC 委员会和 EC 可采取临时措施，如暂时禁止违规者参与社区空间，以保护社区成员安全。

## 维护与改进

行为准则是一份**活文档**——它通过开源协作维护，欢迎通过 PR 提交改进建议。与 Jupyter 软件一样，治理文档也受益于社区的贡献。

## 反常识要点

- **"务实优先"不等于无礼**：Jupyter 重视"rough consensus and running code"的务实文化，但这绝不是无礼或攻击性行为的借口。行为准则明确指出分歧不是不尊重的理由。
- **CoC 是常设委员会不是志愿者小组**：与很多项目将行为准则执行交给"热心志愿者"不同，Jupyter 将 CoC 事件响应设为**常设委员会**（Standing Committee），与 SSC 拥有代表权，拥有正式的章程和执行手册。
- **EC 是最终申诉机构**：CoC 委员会的裁决不是终局的，EC 作为全维度治理者拥有最终申诉裁决权。这形成了权力制衡。
- **在线沟通有特殊提醒**：行为准则特别强调在线异步沟通（issues、PR、邮件）中的措辞注意，因为缺乏面对面沟通的语境和肢体语言线索，容易产生误解。
