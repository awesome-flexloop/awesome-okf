## 学习路径建议

按照从基础到进阶的顺序学习：

1. **第一步：基础使用示例**。如果你是 jupyterlab-git 的新用户，请从基础使用示例开始。它将带你完成从安装到第一次提交、推送的完整流程，帮助你熟悉 Git 面板的布局和基本操作。
2. **第二步：分支管理与合并工作流**。掌握基础操作后，学习分支管理是进行团队协作开发的关键。功能分支模式是最常用的 Git 工作流，理解分支创建、合并和冲突解决是必备技能。
3. **第三步：Diff查看与Stash使用**。Diff 和 Stash 是提升日常开发效率的重要工具。Diff 帮助你精确了解每次变更的内容，Stash 让你在多任务切换时游刃有余。
