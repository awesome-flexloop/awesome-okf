# 信源判读方法：如何判读舞动与戏剧治疗网络资料

舞动治疗与戏剧治疗的中文网络资料多为二手乃至三手转述，历史人物的生卒年、机构年份与资质名称是讹传高发区。本篇给出五条判读原则与四步流程，并用本束登记过程中实际发生的修正案例作演示——所有案例都对应 [facts.md](../facts.md) 中的真实登记记录。

## 为什么该领域讹传高发

- **转述链长**：英文一手材料 → 英文科普 → 中文科普 → 再转述，每一环都可能引入改动；
- **人物年表最脆弱**：先驱人物已离世多年，网络互相转载，日期讹误会"滚雪球"固化；
- **两套职业体系易混**：ADTA 与 NADTA 名字相近、历史相邻，资质名称常被张冠李戴。

## 五条判读原则

1. **组织官网优先**：职业定义、资质、组织史以 [adta.org](https://adta.org/) 与 [nadta.org](https://nadta.org/what-is-drama-therapy/) 现行页面为准；转述与官网冲突时，先怀疑转述。
2. **档案与学术期刊优先于商业网站**：如哈佛 Countway 图书馆的 Moreno 档案、Dance Research Journal 上的研究，信源质量高于一般科普页。
3. **双源规则**：关键年表事实须有两个**独立**信源；只获一个时，标（单源待核），不得写成定论。
4. **双说并列不裁决**：无法决断的分歧，把两说并列呈现并注明各自出处，而不是静默择一。
5. **无据不书**：流传甚广但未获双源的说法，宁可不写入事实登记——这不等于断言其为假，而是如实声明信源状态。

## 讹传修正实录

### 案例一：Whitehouse 卒年——2001 说与 1979 说

- **流传**：部分网络资料（含中文材料）将 Mary Starks Whitehouse 的卒年记为 **2001**。
- **本束处理**：按 GoodTherapy 词条与 Stromsted 两篇文献等**双源**登记为 **1911-1979**——她自 1950 年代起在加州开展该工作直至 1979 年去世（facts DD-04）。
- **教训**：生卒年是最高发讹传点；2001 与 1979 相差 22 年，直接影响"学生继承其工作"（Janet Adler、Joan Chodorow）的叙事时间轴。凡见与通行记载冲突的卒年，须回查信源而非沿用。

### 案例二：Moreno 自发性剧场开幕日——1921-04-01 说不予登记

- **流传**：该剧场开幕日常被记为 **1921-04-01**。
- **本束处理**：本次登记未获双源，**不予登记**（facts DD-07）——正文只写"1920 年代创立"。
- **教训**：精确到日的日期最有"看起来可靠"的迷惑性；无法双源核验时，宁可粗化到年代，也不收录无法担保的精度。

### 案例三：NADTA 更名年份——不登记

- **流传**：多家资料给出 National Association for Drama Therapy 更名为 NADTA 的具体年份。
- **本束处理**：1979 年设立有官网自述（incorporated in 1979）支撑；**更名年份未获双源，不予登记**（facts DD-09）。
- **教训**：同一组织名称的"设立"与"更名"是两个独立事实，不能因前者已核实就顺带认定后者。

### 案例四：NYU 戏剧治疗项目创立年份——1982/1984 两说并列

- **流传**：Landy 个人官网记 NYU 项目 **1984 年**创立；心理学期刊文献记 **1982 年** NYU 与另一院校同时出现两个戏剧治疗硕士项目。
- **本束处理**：两说并列登记、不裁决（facts DD-11），并要求引用者注明口径。
- **教训**：当分歧双方都是可查信源时，"裁决"本身就是制造讹传；并列披露才是可审计的做法。

### 案例五：Evan 与 Espenak 生卒——单源待核

- **本束处理**：Blanche Evan（1909-1982）与 Liljan Espenak（1905-1988）的生卒年均只获单一信源，全部标注（单源待核）（facts DD-05、DD-06）；Espenak "1961 年纽约结构化课程"之说同标（facts DD-06）。
- **教训**：凡是只有一处出处的日期，引用时保留标注，第二信源出现前不升级为定论。

## 常见红旗清单

读到以下任一情形时，应显著降低对材料的信任并回查一手信源：

- 职业定义不注出处或 URL；
- 生卒年与通行记载冲突却无任何说明；
- 精确到日的机构日期查不到双源；
- 资质名称混用（如把 R-DMT/BC-DMT 写成 NADTA 旗下，或反之）；
- 出现疗效承诺、包治类营销话术；
- 把文献学习材料当成治疗建议来推销。

## 判读流程四步

1. **定位断言类型**：先分清眼前的句子属于哪一类——职业定义／人物年表／机构沿革／资质体系／技术描述——不同类型对应不同的一手信源层级；
2. **找一手信源**：定义与资质回官网，人物与机构回档案与期刊，著作信息回出版方页面；
3. **双源比对，记录分歧**：两个独立信源一致的，可按已核引用；有分歧的，按并列口径记录分歧双方；
4. **按保留度分级引用**：输出时明确标注四级保留度——已核（双源）／单源待核／双说并列／未登记——并让读者能看到标注。

## 使用边界

本篇是文献判读方法论，不评价任何疗法的有效性，不替代对任何执业者资质的正式核验；涉及心理健康的实际需求，请咨询执业专业人员。
