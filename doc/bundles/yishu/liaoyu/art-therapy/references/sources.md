# 信源登记

## 一、信源分级口径

本束事实（AT-01–AT-18）共引用约 30 个信源，按其性质与权威性分为三级。级别刻画的是**信源性质**，不等于该信源在具体条目上的可靠性——拍卖行著录对生卒年的记载可能与档案一致，教学演示也可能全部承袭同一上游；级别只决定核查时的优先次序与采信权重。

- **A 级：组织官网与学术档案**。专业协会官网、大学档案馆与图书馆目录、学术基金会、国会图书馆等机构对自身馆藏/立场的原始记载，以及权威学术出版平台的官方页面（出版社期刊页、全文数据库）。
- **B 级：学术期刊文章、讣告与综述**。同行评议期刊上的研究文章、综述与正式讣告，包括经由学术平台分发的版本；1947 年书评等历史出版物按内容性质归入此级（其网络转载载体另按 C 级看待）。
- **C 级：交叉参考与教学材料**。百科条目及其镜像、科普/执业辅导网站、术语表、教学演示文稿（Prezi 等）、拍卖行著录、博客与课程讲义转载。此类信源用于交叉印证与线索发现，不单独支撑事实登记。

## 三、双源核对记录说明

1. **覆盖范围**：AT-01–AT-18 共 18 条事实中，17 条具备 ≥2 个独立信源；唯一例外为 AT-09（见下节披露）。
2. **多源条目**：AT-02（4 源）、AT-03（3 源）、AT-05（4 源）、AT-06（3 源）、AT-08（3 源）、AT-12（3 源）、AT-13（3 源）、AT-17（4 源）等条目具备三源以上交叉。
3. **独立性判定**：跨系统双源为基本要求（如档案 × 期刊、官网 × 期刊论文）；对教学演示文稿（Prezi 系列）作了同源甄别——AT-09 的多份演示互承同一上游（Gantt 1992），故整体计为单源。本束的分级与独立性判定方法亦用于 [网络资料可信度判读](../examples/02-source-appraisal.md) 的示范。
4. **异说登记**：以下分歧已双源并列、登记不裁决——Hill 术语首用 1942/1945（AT-02）、Walden School 1914/1915（AT-03）、《Schizophrenic Art》1950/1953（AT-05）、Kramer 卒日 2014-02-21/22（AT-06）、Ulman 编辑任期两种表述（AT-11）、《Bulletin》更名 1970/1979（AT-12）、Buck HTP 首发 1948/1949 与页码著录分歧（AT-17）。

## 四、单源待核披露
