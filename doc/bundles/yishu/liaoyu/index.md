# 🎨 艺术疗愈

本组收录艺术疗愈领域的知识包，按“总览 + 五分支 + 中国脉络”组织共六束。全组遵循统一编纂纪律：历史事实双信源核对（讹传修正显式留痕）、原文引用分层（公共领域古籍全文引、受版权保护著作仅结论性引用+书目）、循证证据以 WHO 2019 scoping review 与 Cochrane 系统综述为锚点并诚实标注证据质量；每个束根首页均含免责声明——本教程为艺术疗愈文献学习资料，非医疗或心理治疗建议。

术语速览：art therapy（美术治疗，临床职业）→ music therapy / dance-movement therapy / drama therapy（同属 creative arts therapies 伞式术语下的临床分支）→ expressive arts therapy（跨模态治疗模型）→ arts in health / 艺术疗愈（广义健康促进）；详见总览束定义辨析篇。
