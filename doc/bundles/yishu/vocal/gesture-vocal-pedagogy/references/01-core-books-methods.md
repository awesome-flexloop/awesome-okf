# 核心著作、机构与教材课标信源

本篇登记支撑手势辅助声乐/视唱教学体系源流与实践轨的信源：一手原著、体系考证文献、官方机构、教材与课程标准。可信度分级：**权威原著/权威档案**（作者本人著作、档案馆与官方机构一手材料）＞**学术/党媒/权威机构**（学术期刊论文、高校与研究机构官网）＞**行业媒体/教学站点**＞**百科/自媒体**（仅作线索，需交叉验证）。
