# 🎤 声乐教学

本分组收录声乐演唱与教学法知识包。面向零基础歌唱爱好者、流行/美声方向初学者与声乐教师，把口传心授、术语神秘化的声乐训练整理为有信源、有步骤、有剂量、可照做的中文教程。当前知识包以"美通为用、咽音为体"为主线：咽音八步骤解决发声机能（呼吸、喉位、共鸣、换声），美通解决风格表达（混声、咬字、通道、审美）；另有手势辅助教程把听不见的声音参数（音高、气息、共鸣、节拍）转译为看得见的身体动作，与发声机能教程形成"手势管转译、机能管发声"的交叉分工。
