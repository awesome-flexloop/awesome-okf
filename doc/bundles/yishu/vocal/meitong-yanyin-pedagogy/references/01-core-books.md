# 核心著作与教材信源

本篇登记本束教学内容直接依托的正式出版物。可信度分级：**权威原著**（作者本人著作、出版社版权页/书目数据可核）＞**学术/党媒/权威机构**＞**行业媒体**＞**百科/自媒体**（仅作线索）。以下图书均属第一级。

## 五、选型建议

- **零基础自学主线**：林俊卿《八个步骤》（机能）+ 本束 [每日清单](../examples/01-daily-practice-routine.md)；
- **美通/流行表达**：潘乃宪《声乐实用指导》修订本 + 《圆你歌星梦》（有示范）；
- **学院派体系化**：金铁霖《声乐教学艺术》（教学法）+ 邹本初《歌唱学》（美声功底）；
- **购书优先级**：正式出版物（人音社/上海音乐/上海三联）＞ 正规电子书＞网络转录讲义；凡“咽音速成”“美通创始人亲授”类无书号资料，按 [概念02](../concepts/02-three-styles-and-meitong.md) 术语辨析对待。
