# 红歌曲谱库搭建指南

曲谱库的最小可用单位不是"一份谱"，而是每份谱附带的**权利状态向量**：词/曲作者及卒年 → 保护期是否届满 → 使用场景是否落入法定许可 → 署名与版本来源（原理见 [09 篇第一节](../concepts/09-score-library-copyright-and-lesson-design.md)）。本指南给出目录结构、信源清单、保护期计算、登记卡模板与自查清单，可直接复制到教研组共享盘落地。

## 一、三维标签目录结构

三个标签维度：

- **时代**：革命时期（1919—1949）／建设时期（1949—1978）／改革与新时代（1978 年至今），分期依据 F-003，课堂四代曲目层见 [01 篇](../concepts/01-red-song-definition-and-eras.md)；
- **年级**：低段（1—2 年级）／中段（3—5 年级）／高段（6—9 年级），学段划分见 F-033、F-034；
- **体裁**：进行曲／分节歌／颂歌／合唱，体裁速览见 [02 篇](../concepts/02-notation-basics.md) 与 F-058。

可复制目录树：

```text
red-song-score-library/
├── README.md                              # 库说明与版权红线，每学期复查一次
├── 01-revolutionary-1919-1949/            # 革命时期（F-003 第一阶段）
│   ├── grade-3-5/
│   │   ├── march/                         # 进行曲体裁
│   │   │   └── yiyongjun-jinxingqu.registration.md
│   │   └── verse-song/                    # 分节歌体裁
│   ├── grade-6-9/
│   │   └── chorus/
│   │       └── baowei-huanghe.registration.md
├── 02-construction-1949-1978/             # 建设时期
│   ├── grade-3-5/
│   │   └── ode/                           # 颂歌体裁
│   └── grade-6-9/
│       └── march/
│           └── gechang-zugu.registration.md   # 只存登记卡，不放谱文件
├── 03-reform-new-era-1978-present/        # 改革与新时代
│   ├── grade-6-9/
│   │   ├── lyric/                         # 抒情歌曲
│   │   └── chorus/
├── _public-domain/                        # 保护期届满曲目（仍须署名、不得删改）
└── _templates/
    └── registration-template.md           # 入库登记表模板（见本指南第六节）
```

目录规则：

1. **保护期内曲目不存谱文件、不存歌词文本**，只存登记卡（`.registration.md`），谱源栏写"教材 XX 版第 X 页投影"式正版指引；
2. 保护期届满曲目方可在 `_public-domain/` 存谱文件，且必须保留署名；
3. 文件名一律拼音 kebab-case，曲目中文名与作者信息写在登记卡内；
4. 每学期开学由库负责人按 [09 篇来源决策树](../concepts/09-score-library-copyright-and-lesson-design.md) 全库复查一次授权状态。

## 二、资源信源清单

| 平台/渠道 | 授权类型 | 适用场景 | URL 或获取方式 |
|---|---|---|---|
| 人民音乐出版社人音版教材及配套教师用书、音视频资源 | 教科书法定许可（由出版方按规定付酬，F-063） | 课堂谱面投影、教唱、欣赏 | 学校统一采购正版教材；配套资源以教材版权页与教师用书标注的官方平台为准，不录第三方网盘链接（教材双版本见 F-038） |
| 人民教育出版社教材体系（第十二套义务教育教科书·艺术·音乐） | 教科书法定许可（F-063） | 教材选用与备课参考 | https://www.pep.com.cn/ （教材简介见 F-035） |
| 学校/公共图书馆馆藏乐谱与音像资料 | 馆藏合法获取、馆内借阅使用 | 备课比对版本、文献查证 | 各校图书馆馆藏目录；国家图书馆目录 https://www.nlc.cn/ |
| IMSLP 国际乐谱库 | 公版乐谱（仅收录权利状态明确、保护期届满的作品） | 西方古典与公版作品查阅；**红歌基本不适用**——中国近现代红歌多在保护期内，IMSLP 不收录，也不应从其他渠道转录替代 | https://imslp.org/ |
| 正规音频平台（QQ 音乐、网易云音乐等）的官方发布录音 | 平台已获授权的录音制品 | 课堂欣赏、教师范唱参考；不使用用户上传的翻录伴奏 | https://y.qq.com/ ；https://music.163.com/ |
| 法律法规与付酬标准官方文本 | 权威发布 | 保护期与法定许可边界自查 | 著作权法全文 http://www.npc.gov.cn/c2/c30834/202011/t20201119_308796.html ；付酬办法国务院公报 https://www.gov.cn/gongbao/content/2014/content_2561303.htm |

IMSLP 适用边界一句话：它解决"公版谱从哪来"，红歌教学主要解决"正版教材怎么用"——两个问题不混用渠道。

## 三、保护期计算表

计算规则（F-062）：自然人作品保护期为作者终生及其死亡后五十年，**截止于作者死亡后第五十年的 12 月 31 日**；合作作品按**最后死亡的作者**计；署名权、修改权、保护作品完整权等人身权保护期不受限制（F-061）。

## 四、教科书法定许可边界（300 / 5 / 不含教参）

- 为实施义务教育编写出版教科书，可不经著作权人许可汇编已发表的短小音乐作品，但**应当按规定支付报酬、指明作者姓名与作品名称**，且不得侵犯其他权利（F-063）；
- 付酬标准：教科书汇编音乐作品**每首 300 元**（由出版方履行，F-064）；
- "短小"边界：九年制义务教育教科书中**单篇不超过 5 页面或时长不超过 5 分钟**的单声部音乐作品（多声部乘以相应倍数，F-064）；
- **教科书不包括教学参考书和教学辅导材料**——教师自编讲义、课件、学案、练习册不享受法定许可（F-064）。

## 五、课堂之外的场景授权提示

同一份谱，换个场景法律状态就变。活动报批时对照：

| 使用场景 | 保护期内曲目 | 依据 |
|---|---|---|
| 课堂教学（正版教材谱面＋官方音频） | 可以，教材汇编走法定许可 | F-063 |
| 自编讲义/课件转录歌词曲谱 | 不可以（法定许可不含教参辅导材料） | F-064 |
| 校园艺术节公开演出 | 须获授权或走正版演出授权渠道 | [09 篇第八节](../concepts/09-score-library-copyright-and-lesson-design.md) |
| 演出录音录像、校园电视台播放 | 须获授权 | 同上 |
| 公众号/短视频/视频号发布 | 须获授权，不用来路不明伴奏 | 同上 |
| 改编编曲（加二声部、换伴奏） | 须获授权（改编权）；国歌不得改编 | F-068 |

提示：不存在"非盈利就不侵权"的例外，法定许可不覆盖演出、录播与网络传播。

## 六、入库曲目登记表模板

每首曲目一张登记卡，复制下表存为 `.registration.md`：

| 字段 | 填写说明 | 填写示例（《歌唱祖国》） |
|---|---|---|
| 曲目 | 全名 | 《歌唱祖国》 |
| 词作者/卒年 | 不可考写"待考" | 王莘（词曲合一）/ 2007 年卒（F-023） |
| 曲作者/卒年 | 同上 | 同上 |
| 权利状态 | 保护期截止日＋推算依据 | 保护期至 2057-12-31（F-067；规则 F-062） |
| 谱源 | 只写正版指引，不附谱文件 | 人音版《艺术·音乐》第 __ 册第 __ 页，课堂投影 |
| 音频源 | 官方录音名称与平台 | 教材配套官方音频 |
| 授权凭证 | 分场景标注授权状态 | 课堂教学：法定许可覆盖；演出/录播/网络：未授权，使用前须申请 |
| 登记人/日期 | 责任到人 | ____ / 2026-__-__ |

空白模板字段顺序：曲目 → 词作者/卒年 → 曲作者/卒年 → 权利状态 → 谱源 → 音频源 → 授权凭证 → 登记人/日期。

## 七、每学期版权自查清单

- [ ] 库内无保护期内曲目的谱文件与歌词文本，只有登记卡；
- [ ] 每张登记卡四字段齐全（作者卒年／保护期截止日／场景授权状态／版本来源，[09 篇第五节](../concepts/09-score-library-copyright-and-lesson-design.md)）；
- [ ] 保护期届满曲目（如《义勇军进行曲》，F-065）仍保留署名、未删改；国歌一律使用标准曲谱与官方录音（F-068）；
- [ ] 全库无教材整页扫描/拍照外传的指引；
- [ ] 本学期演出、录播、网络发布计划已在活动审批中单列授权项；
- [ ] 单源待核史实曲目（F-024、F-027、F-028）登记卡已标注"一说"，课堂表述同步。

## 常见问题速答

- **问：网上随手能搜到谱，为什么还要建库？**
  搜到不等于可用。曲谱库管的不是"找得到"，而是"每一份谱的权利状态说得清"（[09 篇第一节](../concepts/09-score-library-copyright-and-lesson-design.md)）；获取成本趋近于零，核查成本不可压缩。
- **问：保护期届满的歌可以自由改编吗？**
  不可以随意删改。财产权届满但署名权、修改权、保护作品完整权永久（F-061）；国歌另有不得篡改词曲的法定要求（F-068）。
- **问：库建在共享文档里给全组用，最要注意什么？**
  保护期内曲目不传谱、只传登记卡；库负责人每学期按来源决策树复查一次授权状态。

## 小结

- 目录按时代／年级／体裁三维标签，保护期内曲目只存登记卡、不存谱；
- 信源优先级：正版教材 ＞ 图书馆馆藏 ＞ 公版库（IMSLP 仅适用公版）＞ 音频平台官方录音；
- 保护期 = 作者终生 + 死后 50 年、截止第五十年 12 月 31 日，合作作品取最晚死亡者；
- 法定许可记三个数：每首 300 元、5 页面或 5 分钟、不含教参；演出、录播、网络传播一律先授权。
