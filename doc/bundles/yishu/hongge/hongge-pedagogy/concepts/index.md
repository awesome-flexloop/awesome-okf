# 概念文档

本目录是「红歌教学教程（曲谱库·赏析·歌谱·手势声乐）」的概念层，共 10 篇。建议按 00→01→02→03→04→05→06→07→08→09 的顺序学习：先读入门地图与红歌界定，再学曲谱基础与赏析框架，随后按革命时期、建设与改革时期、新时代三期做曲目赏析示范，最后落到手势应用、声乐合唱与曲谱版权教案。07、08 篇的技术细节分别链向声乐域两个兄弟束，可按需跳转。
