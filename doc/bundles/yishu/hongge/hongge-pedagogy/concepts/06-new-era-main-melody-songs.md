# 新时代主旋律曲目赏析示范

## 学习目标

- 能说出三首第四代（新时代）曲目的创作/传播背景与档案编号，对《不忘初心》使用"一说"表述；
- 能向学生讲清新时代主旋律歌曲为什么不能用进行曲喊唱法唱，流行抒情风格的可听特征是什么；
- 能设计"进行曲 vs 新时代抒情"的对比听辨活动，并指导合唱编曲避开风格错配；
- 明确本批曲目全部在保护期内，课件不转录、演出录播需授权。

> 用法说明：本篇是六步框架（[03 篇](03-six-step-appreciation.md)）的第四代曲目示范，分期依据见 [01 篇](01-red-song-definition-and-eras.md)。四栏精简：**背景 | 曲式旋律特征（听辨任务） | 演唱处理 | 教学要点**。

## 版权前置说明

三首曲目均为 2014 年以后创作、传播的新作（F-028、F-029、F-030），词/曲作者均在世或逝世未逾五十年，**全部在著作权保护期内**。课件、讲义、公众号、短视频均不得转录歌词与旋律谱，不得擅自改编；课堂使用教材正版谱面与官方音频，校园演出与录播需取得授权（决策树见 [09 篇](09-score-library-copyright-and-lesson-design.md)）。

## 一、《不忘初心》

| 栏 | 内容 |
|----|------|
| 背景 | **一说（本束仅检索到百科词条单源，待核，F-028）**：朱海作词、舒楠作曲，创作于 2016 年，歌名取自"不忘初心、牢记使命"，是新时代主旋律歌曲代表作之一。课堂讲述用"一说/通行记载为"，创作细节以权威出版物与官方发布为准。 |
| 曲式旋律特征 | 听辨任务：主歌的音区是不是像"耳边说话"？副歌"不忘初心"句第一次出现时，旋律是级进上去还是大跳上去？全曲最长的一句有几拍不换气——跟唱时先标气口再唱。 |
| 演唱处理 | 流行抒情唱法：主歌允许气声与弱声起句，副歌靠气息支撑拉开线条而不是靠喊；混声过渡要平滑（机能原理见声乐兄弟束 [美通唱法技术原理](../../../vocal/meitong-yanyin-pedagogy/concepts/03-meitong-technique.md)）。 |
| 教学要点 | 与第一代进行曲做 A/B 对比听辨（见第四节）；待核条目不写入定论性讲义。 |

## 二、《共筑中国梦》

| 栏 | 内容 |
|----|------|
| 背景 | 入选 2014 年中宣部等部门组织的"中国梦"主题新创作歌曲展播曲目，由中国文学艺术界联合会"中国梦"主题歌曲专题页面收录推介（F-030）。这是三首中**有权威机构专题页面收录**的一首，背景讲述可直接引用 F-030。 |
| 曲式旋律特征 | 听辨任务：副歌的节奏与主歌相比，是更铿锵还是更舒展？它在三首新时代曲目中，进行曲气质保留得最多还是最少？ |
| 演唱处理 | 介于颂歌与流行抒情之间：副歌保持集体性的明亮音色，但仍以连贯线条为基础；咬字清晰但不硬，避免退回喊唱。 |
| 教学要点 | 可作"新时代也有多种风格"的证据：第四代不等于一律柔声，风格由作品决定（洞察六）。 |

## 三、《灯火里的中国》

| 栏 | 内容 |
|----|------|
| 背景 | 田地作词、舒楠作曲，2021 年中央广播电视总台春节联欢晚会上首唱，以都市万家灯火意象描绘新时代中国图景，是新世纪红色/主旋律歌曲的新作代表（F-029）。 |
| 曲式旋律特征 | 听辨任务：闭上眼睛听，音乐描绘的是"广场队列"还是"万家窗灯"？作曲家靠什么（速度、力度、音区、配器）让你产生这个意象？旋律里长音多还是短促音多？ |
| 演唱处理 | 三首中流行抒情气质最纯粹：弱声、气声、长线条，电视舞台传播场景决定了它不需要大音量穿透——麦克风承担扩声，声音可以收着唱（与群众集会现场齐唱的传播场景对比，见下节）。 |
| 教学要点 | 意象听辨是审美感知素养（F-031）的好素材：让学生画出自己听到的"灯火"画面，再回听验证。 |

## 四、核心课点：新时代风格为什么不能喊

### 4.1 风格由创作范式与传播场景决定

第一代进行曲为队列行进而写，要求强节奏、直声高位置、咬字铿锵；新时代抒情主旋律歌曲为舞台与电视传播而写，旋律线条长、气口口语化、审美上接近流行抒情唱法（[insights.md](../insights.md) 洞察六）。《灯火里的中国》的都市万家灯火意象（F-029）靠舒展旋律与细腻力度刻画，用《义勇军进行曲》式的喊唱法唱会直接破坏意象；反过来用流行气声唱《保卫黄河》则消解战斗性——**唱法应当服从作品，而非作品迁就唱法**。

### 4.2 可操作的风格对比听辨

设计 A/B 对比活动（选用 [04 篇](04-revolutionary-era-songs.md) 第一代曲目与本篇三首各一句）：

| 听辨维度 | 进行曲（第一代） | 新时代抒情（第四代） |
|----------|------------------|----------------------|
| 音量与音色 | 明亮、靠前、直声，集体穿透 | 允许气声、弱声、混声，麦克风扩声 |
| 乐句 | 方整、短促有力 | 长线条、气口口语化 |
| 咬字 | 铿锵，声母弹性强 | 清晰但自然，语气像诉说 |
| 速度力度 | 稳健、强弱分明 | 弹性、层次细腻 |
| 身体反应 | 想踏步 | 想随旋律挥手/轻摇 |

### 4.3 编曲与合唱提示

- 给新时代曲目配军鼓式行进伴奏是典型错配（洞察六）：编曲慎用进行曲打击乐，可用铺底和声、钢琴/弦乐伴奏；
- 合唱编排上，副歌可用二声部烘托但保持线条连贯，轮唱式的"此起彼伏"战斗效果不适用；
- 学生常见问题是"唱红歌就要用力"：教师明确示范同一句歌词的喊唱版与抒情版对比，让学生先听出差别再模仿；气息与混声的机能训练不在本篇展开，按 [08 篇](08-vocal-foundations-and-chorus.md) 的交叉链接到声乐兄弟束学习。

## 五、气声与弱声：课堂怎么带（不展开机能原理）

新时代曲目主歌常用弱声、气声起句（F-028、F-029 的可听特征），学生一唱就"放不出来"或"虚到没音"。课堂提示三条：

1. **先有气息再谈音色**：起句前先做一次从容的腹式吸气（呼吸的课堂要求与热身见 [08 篇](08-vocal-foundations-and-chorus.md)；机能原理链美通兄弟束 [生理基础](../../../vocal/meitong-yanyin-pedagogy/concepts/01-singing-physiology.md)）。弱声不是漏气，气声也要有气息支撑——让学生手叉腰，吸气时腰腹有扩张感再唱。
2. **用"说悄悄话"找感觉**：让学生先用耳语的音量把主歌念一遍，保持咬字清晰，再把同样的位置"加上一点声音"唱出来；声音小但字音不散，就是流行抒情主歌要的质感。
3. **副歌不靠喊靠拉开**：副歌到达时要求"声音变宽不变炸"：气息稳住、口腔打开、音高上去而音量只加一档；混声过渡不顺时不要硬顶，降调或降音量先唱顺（换声与混声的技术细节链 [美通唱法技术原理](../../../vocal/meitong-yanyin-pedagogy/concepts/03-meitong-technique.md)）。

## 六、编曲与演唱错配自查清单

排新时代曲目前逐项自查：

- [ ] 伴奏是否用了军鼓/行进打击乐？（《灯火里的中国》类抒情曲属错配，洞察六）
- [ ] 主歌是否被唱成了齐步走的重音？（应口语化、强弱随语气）
- [ ] 副歌是否全员硬喊到最高音？（应以气息支撑拉开，必要时降调）
- [ ] 轮唱/此起彼伏处理是否被用在抒情长线条上？（轮唱适合战斗性曲目如《保卫黄河》，见 [04 篇](04-revolutionary-era-songs.md)）
- [ ] 演出用的伴奏与谱子是否来源正版、授权状态是否确认（F-028、F-029、F-030 全部在保护期内，规则见 [09 篇](09-score-library-copyright-and-lesson-design.md)）？

## 七、学段安排建议

- **小学高段（5—7 年级）**：可唱《共筑中国梦》副歌片段（集体性最强、最接近学生熟悉的颂歌咬字，F-030）；主歌弱声处理暂不要求，以唱齐、唱得连贯为目标。
- **初中（8—9 年级）**：三首均可进赏析课，《灯火里的中国》做意象听辨与绘画输出（F-029、F-031），《不忘初心》做"进行曲 vs 抒情"A/B 对比（F-028 待核背景用"一说"）。
- **合唱队/校园歌手**：可排独唱加合唱副歌版本，重点练主歌弱声与副歌混声；演出授权按 [09 篇](09-score-library-copyright-and-lesson-design.md) 决策树办理。

## 常见问题速答

- **问：学生说这些歌"不像红歌"，怎么回应？**
  正好用四代分层回答（[01 篇](01-red-song-definition-and-eras.md)）：红歌从救亡进行曲长到新时代抒情歌，风格随时代生长；判据不是"像不像老歌"，而是题材与精神内核。让学生用第 4.2 节的五维表自己听出：身体反应从"想踏步"变成"想挥手"，音乐变了、传统没断。
- **问：气声会不会把学生嗓子唱坏？**
  有气息支撑的弱声不伤嗓，伤嗓的是漏气的虚唱与硬顶高音。热身与呼吸要求见 [08 篇](08-vocal-foundations-and-chorus.md)，嗓音异常（嘶哑、疼痛）处理链兄弟束 [嗓音保健](../../../vocal/meitong-yanyin-pedagogy/concepts/08-voice-health.md)；初中生变声期尤其避免强唱高音。
- **问：《不忘初心》到底是哪年写的？教材和网上说法不一样。**
  本束 facts 中该条为单源待核（F-028），课堂一律用"一说为 2016 年"表述；考试与讲义不考年份细节，以所用教材和权威发布为准。可考的是可听特征：主歌弱声、副歌拉开的流行抒情处理。
- **问：新时代曲目能不能也做轮唱？**
  一般不做。轮唱的艺术效果是声部此起彼伏的战斗与劳动意象（《保卫黄河》为典型，F-016）；新时代抒情曲目的长线条与口语气口叠进轮唱会互相糊掉。多声部需求用副歌二声部烘托（[08 篇](08-vocal-foundations-and-chorus.md)）。
- **问：三首里课时有限，优先教哪首？**
  教唱优先《共筑中国梦》副歌（集体性最强、咬字接近学生熟悉的颂歌，F-030）；赏析优先《灯火里的中国》（意象鲜明、绘画任务单好设计，F-029）。《不忘初心》背景单源待核（F-028），课堂以听作品为主、背景用"一说"带过，不做讲述重点。

## 八、意象听辨活动：《灯火里的中国》绘画任务单

《灯火里的中国》2021 年央视春晚首唱、以都市万家灯火为意象（F-029），适合把审美感知素养（F-031）做成跨学科输出：

1. **初听（完整一遍）**：不说话、不看谱，学生闭眼听，只在纸上用一条线画出旋律的"高低走势"；
2. **二听（主歌段）**：任务——音乐像"广场上的队伍"还是"窗子里的灯火"？听到长音就画一盏灯，听到弱声就画小点、强声画大点；
3. **三听（副歌段）**：任务——力度比主歌开了多少？画面从"一点灯火"变成什么？补完画；
4. **展示与回听**：抽 2—3 名学生展示画，全班回听对应段落验证"画的和听到的一致吗"；
5. **收束**：教师只点一句——作曲家靠速度、力度、音区、配器让声音有了画面（第 4.2 节五维表），这就是审美感知。

材料合规：音频用官方发布版本，课件不转录歌词旋律（保护期内，本篇版权前置说明）；画作学生自留或班级展示，不随演唱视频公开发布。

## 九、课时安排与跨代串联备课

三首曲目不必平均用力，按课型两种排法：

- **赏析课 1 课时**：三首各放"主歌 + 副歌"一段，用第 4.2 节五维表与 [04 篇](04-revolutionary-era-songs.md) 进行曲片段做 A/B 对比，收束到"唱法服从作品"（洞察六）；《不忘初心》背景一律"一说"（F-028）；
- **教唱课 2 课时**：第 1 课时教《共筑中国梦》副歌（集体性最强、最接近学生熟悉的颂歌咬字，F-030）；第 2 课时教《灯火里的中国》主歌弱声处理，配第八节意象绘画任务单；
- **跨代串联**：与 [05 篇](05-construction-reform-era-songs.md)《走进新时代》（1997，F-027）连成"1997→2014→2021"时间线听赏，让学生听到第三代到第四代是风格延续而非突变——第一人称口吻、长线条乐句一以贯之，流行抒情浓度逐代增加；
- **合唱队/校园歌手**：以"独唱领唱主歌 + 合唱副歌"版本为主，领唱用气声弱声、合唱副歌拉开但不喊（音色三档见 [08 篇](08-vocal-foundations-and-chorus.md) 第四节）；演出授权按 [09 篇](09-score-library-copyright-and-lesson-design.md) 决策树办理；
- **评价收口**：输出任务用意象绘画或对比听辨文字（审美感知 F-031），不考待核年份；教材"实践与创造"类栏目可作评价载体（F-038）。

## 小结

- 三首档案：《不忘初心》2016 年（F-028，单源待核用"一说"）；《共筑中国梦》2014 年"中国梦"主题展播曲目（F-030，权威机构收录）；《灯火里的中国》2021 年央视春晚首唱、万家灯火意象（F-029）；
- 第四代风格要点：流行抒情唱法、气声弱声、长线条、电视舞台传播场景；与进行曲喊唱在音量音色、乐句、咬字、力度、身体反应五个维度可听辨对比；
- 编曲慎用军鼓行进伴奏，合唱副歌求连贯不求铿锵；机能技术链声乐兄弟束（呼吸支撑、混声平滑过渡）；
- 三首均在保护期内，课件不转录、演出版权规则见 [09 篇](09-score-library-copyright-and-lesson-design.md)。
