# 🎤 艺术

本域存放艺术相关的知识包，分两组收录：艺术疗愈组（总览、美术治疗、音乐治疗、舞动与戏剧治疗、表达性艺术治疗、中国艺术疗愈六束——定义辨析、双信源史实核对、WHO/Cochrane 循证锚定、中西对读）与声乐教学组（美通唱法与咽音体系：林俊卿咽音练声八步骤（呼吸/喉位/共鸣/换声）、美通唱法（美声功底×通俗表达）、嗓音科学、常见毛病纠正、嗓音保健、教学法与每日练声清单）。
