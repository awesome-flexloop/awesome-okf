# 示例文档（Examples）

本目录包含 sphinxext-opengraph 的实用配置示例，从基础到高级覆盖常见使用场景。

## 示例列表

- [基础配置示例](basic-setup.md) — 从零开始配置sphinxext-opengraph的最小可用示例，包含安装、conf.py配置和构建验证
- [社交卡片完整配置示例](social-cards-example.md) — 配置自动生成社交媒体预览PNG卡片，包括自定义图片、颜色、字体和卡片禁用
- [页面级定制示例](per-page-customization.md) — 使用RST field lists为特定页面自定义OGP标签，包括自定义标题/描述/图片、添加视频标签等
- [高级配置示例](advanced-config.md) — 版本化文档canonical URL、Twitter Cards、Article元数据、多语言站点等高级配置
