# 架构洞察（Architecture Insights）

> 基于事实清单（facts.md）得出，每条洞察遵循四元组结构（陈述/证据/反常识/行动）

---

## 洞察 1：读《庄子》必须先分"三层文本"，否则会误把注释当原文

| 四元组 | 内容 |
|--------|------|
| **陈述** | 今本《庄子》33 篇并非同一人、同一时代、同一可靠性层级的文本，而是"内篇（庄子自著）+ 外杂篇（后学）+ 历代注疏（注家）"三层叠加的产物。 |
| **证据** | F-023（内篇一般认为庄子自著）、F-030（外杂篇多后学所作）、F-014（郭象删定 33 篇）、F-036（郭象注为通行起点）。 |
| **反常识** | 多数人"读庄子"实际上是"读郭象注的庄子"或"读陈鼓应注译的庄子"，把注家的玄学化/学术化解说当成了庄子本文。 |
| **行动** | bundle 单独设"作者分层"概念（02-authorship），内篇全文（03）与注家立场（07）分离，读原文时先屏蔽注疏。 |

## 洞察 2：郭象删定 33 篇本既是"抢救"也是"塑造"，今本《庄子》是玄学化的产物

| 四元组 | 内容 |
|--------|------|
| **陈述** | 今通行 33 篇本由郭象删定，从 52 篇本逸去 19 篇，宋代以后独行，今人所读"庄子"的面貌由郭象这一刀决定。 |
| **证据** | F-012（《汉书·艺文志》52 篇）、F-014（郭象删定 33 篇）、F-015（逸去 19 篇）、F-018（宋以后郭象本独行）。 |
| **反常识** | 读者常默认"流传下来的就是原本"，但郭象删去的"依托附益"内容恰在删定时被判定为"非原文"；王叔岷辑佚 176 条（F-046）说明"失文"真实存在。 |
| **行动** | 概念 01-text-versions 明确"33 篇是郭象定本"而非"汉时原貌"；references/core-texts 列出可回查的多底本。 |

## 洞察 3："最权威原文"在无出土全本现实下，靠"传世本系统 + 数字底本双源核对"逼近，异文登记而非裁决

| 四元组 | 内容 |
|--------|------|
| **陈述** | 与《老子》有帛书、郭店简、北大汉简等出土本不同，《庄子》至今无出土全本，权威原文只能依赖传世注本系统与数字化底本的多方比勘。 |
| **证据** | F-020（ctext 以续古逸丛书本为据）、F-045（ctext 提供多种底本）、F-012（《汉书》52 篇本已不存）。 |
| **反常识** | 要求"最权威最真实原文"时不存在唯一权威本；"最真实"只能靠异文显式标注（"某本作某"）诚实呈现差异，而非斩钉截铁给唯一答案。 |
| **行动** | 内篇全文（03）关键异文处显式标注；facts.md 登记编号事实与信源 URL（F-054~F-056）；不强做无法裁决的校勘选择。 |

## 洞察 4：庄子的"道"是境界与修辞而非宇宙论命题，注家传统常在本文上叠床架屋

| 四元组 | 内容 |
|--------|------|
| **陈述** | 庄子的核心文本（逍遥、齐物、心斋、坐忘）多用寓言、反诘、吊诡表达，本质是破除执着的"境界引导"，而非给出一套可论证的本体论体系；郭象注（玄学化）、成玄英疏（重玄学）却常将其系统化为形而上学。 |
| **证据** | F-050（逍遥游主旨是精神境界）、F-053（得意忘言）、F-036/F-037（郭象注、成玄英疏的哲学发挥）。 |
| **反常识** | 很多人把"庄子哲学"等同于郭象《注》里的"独化""玄冥"等概念，但这些是魏晋玄学的范畴，未必是庄子本文所固有。 |
| **行动** | 概念 05-core-concepts 与 07-commentaries 严格区分"本文语义"与"注家引申"；核心句解读至少呈现 2 种注家立场并标注出处。 |
