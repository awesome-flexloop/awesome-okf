# 交叉引用

本文件登记与《庄子》内篇阅读教程相关的其他知识包与外部在线资源。庄子与老子并称"老庄"，同属先秦道家，《庄子》与《老子》《周易》合称"三玄"（F-009）；司马迁称庄子"其学无所不窥，然其要本归于老子之言"（F-011）。故读《庄子》常需回看《老子》诸知识包。
