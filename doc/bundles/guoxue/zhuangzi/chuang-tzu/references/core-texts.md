# 权威底本清单

与《老子》有帛书、郭店简、北大汉简等出土本不同，《庄子》至今无出土全本，权威原文只能依赖传世注本系统与数字化底本的多方比勘（见 [架构洞察](../insights.md) 洞察 3）。本清单登记可回查《庄子》原文的底本，每条附可信 URL（优先取自 [事实清单](../facts.md) F-020 / F-045）。

## 传世底本系统

### 郭象注 33 篇本（今通行本起点）

| 项 | 内容 |
|----|------|
| 性质 | 今通行《庄子》的面貌由郭象删定 52 篇本为 33 篇（内篇七、外篇十五、杂篇十一），宋以后独行于世（F-014 / F-015 / F-018） |
| 定位 | 读《庄子》绕不开的通行底本，也是历代注本共同的文本基础（F-036） |
| 可信出处 | 中华文库《莊子》全文：https://www.zhonghuashu.com/wiki/%E8%8E%8A%E5%AD%90 |

ctext.org 的《庄子》数字底本以《續古逸叢書》本《南華真經》为据录入（F-020），并同时提供多种影印底本资源（F-045）：

|------|---------|------|---------|

| 《四部叢刊初編》本《南華真經》 | 影印底本 | ctext.org 提供的底本资源之一（F-045） | https://ctext.org/zhuangzi |
