# 注本分级表

《庄子》的历代注本不只是"解释"，更是层层叠加的"再塑造"——郭象注的玄学化、成玄英疏的重玄学化，常被误当作庄子本文（见 [架构洞察](../insights.md) 洞察 1 / 洞察 4）。读注本前须先分清"本文语义"与"注家引申"。本表按入门 / 进阶 / 研究三级登记注本，逐家标注立场与可信出处（F-036~F-044）。

## 选用策略

1. **入门**：只用陈鼓应《庄子今注今译》，先不读古注，避免被旧注束缚
2. **进阶**：读郭象注 + 成玄英疏，理解传世通行本的阐释主线；对照王先谦《集解》的简注
3. **研究**：以郭庆藩《集释》为核心考据底本，按需查阅王夫之《解》的哲理解读、陆德明《音义》的异文、焦竑《翼》的历代辑录
