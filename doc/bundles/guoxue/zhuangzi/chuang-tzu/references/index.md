## 信源使用说明

- 概念文档通过 frontmatter 的 `sources` 字段引用本目录信源；正文引用格式使用 bundle-relative 根路径（如 `/references/core-texts.md`）
- 各信源文档内的 URL 均出自 [事实清单](../facts.md) 或知名公开古籍站点（ctext.org、中华文库等），不收录未经核实的外部链接
- 「权威底本」指可回查《庄子》原文的传世影印本与数字化底本；「注本」指历代注疏、集释与今人注译
