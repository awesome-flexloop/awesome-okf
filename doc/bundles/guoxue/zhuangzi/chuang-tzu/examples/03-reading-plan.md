# 庄子通读计划

本计划覆盖郭象注三十三篇本**全部三十三篇**：内篇七篇以 [内篇原文](/concepts/03-neipian-full-text.md)（概念 03）为主线，外篇十五、杂篇十一（外杂合计二十六篇）续以概念 [08](/concepts/08-waipian-full-text-1.md)→[09](/concepts/09-waipian-full-text-2.md)→[10](/concepts/10-zapian-full-text-1.md)→[11](/concepts/11-zapian-full-text-2.md) 全文通读。内篇以《逍遥游》《齐物论》《养生主》三篇为精读重点（有示例 01、02 可作范本），按内篇七篇次序（F-021）推进；外篇按 F-027 篇目、杂篇按 F-028 篇目接续，全部依同一底本（郭象注本系统 + ctext.org《续古逸丛书》数字底本，F-020）逐字核对。注本分级与阅读法均锚定 [事实清单](/facts.md) 与 [架构洞察](/insights.md)。

> **边界声明**：本篇是**通读向导**（篇目、次序、分层提示、注本搭配），不是三十三篇的逐字总录——白文原文一律以概念 03、08、09、10、11 的双源核对稿为准。

## 一、为什么以内篇为主

- 内篇七篇篇目均为三字、以主旨标题，一般认为**庄子本人所作**，代表庄子核心思想（F-021、F-022、F-023）。
- 内篇七篇占全书四分之一，被视作全书精华（F-024）。
- 外篇 15、杂篇 11 多为门人后学所作，不能与内篇等量齐观（F-030，另见 [作者分层](/concepts/02-authorship.md)）。

**通读主线**：先精读内篇原文（概念 03），再以示例 [01《逍遥游》精读](01-xiaoyaoyou-reading.md)、[02《齐物论》精读](02-qiwulun-reading.md) 为范本，把精读法迁移到其余篇目；内篇三阶段完成后，按阶段四、阶段五接续通读外篇（概念 08→09）与杂篇（概念 10→11）。

## 二、注本分级选用

据事实清单的注家记载（F-036～F-045），按阅读阶段分级选用注本：

|------|------|------|------|
| 入门 | 陈鼓应《庄子今注今译》 | 白话译注，先过文义关 | F-044 |
| 进阶 | 王先谦《庄子集解》 | 字词训诂，简明得体 | F-040 |
| 进阶 | 郭庆藩《庄子集释》 | 汇集众说，清代集大成（王孝鱼点校） | F-039 |
| 研究 | 郭象注 + 成玄英疏 | 玄学 / 重玄学传统源头，看"本文如何被系统化" | F-036、F-037 |
| 研究 | 陆德明《庄子音义》 | 音义训读 | F-038 |

> 选用原则（源自 [架构洞察](/insights.md) 洞察 4）：把郭象注、成玄英疏当"注家引申"而非"本文"读；先用王先谦《集解》过训诂关、用陈鼓应《今注今译》过文义关，最后再回到郭象 / 成玄英看玄学如何叠床架屋。

## 三、五阶段通读计划（内篇三阶段 + 外杂两阶段）

### 阶段一：入门通读（以概念 03 原文 + 白话译注）

目标：读完内篇原文，建立整体印象。

|------|------|--------------------|-----------|

| 第 2 篇 | 齐物论 | 消除世间万物分别（F-050） | 吾丧我、道枢、梦蝶 |
| 第 3 篇 | 养生主 | 养"神"、顺其自然（F-051） | 庖丁解牛（F-025） |
| 第 4 篇 | 人间世 | 处世之道（F-051） | 处世与自处 |
| 第 5 篇 | 德充符 | —（F-021 只列篇名，主旨以本文为本，不先入为主） | 德充于内 |
| 第 6 篇 | 大宗师 | 道的本质、特征及道与人的关系（F-052） | 道与真人 |
| 第 7 篇 | 应帝王 | 帝王顺其自然、效法于道（F-052） | 浑沌之死（F-056） |

行动：逐篇读概念 03 原文，配陈鼓应《今注今译》（F-044）定文义；第 1～3 篇精读，第 4～7 篇通读。

### 阶段二：逐篇精读（加训诂 + 本文/注家分离）

目标：逐篇过训诂关，养成"本文语义"与"注家引申"分开读的习惯。

- 每篇先读原文，屏蔽注疏（洞察 1、洞察 4）。
- 再用王先谦《集解》（F-040）厘清字词、句读；关键异文如《逍遥游》"抟/搏"（F-055）、《应帝王》"浑沌"（F-056），以及《养生主》"奏刀"拟声字的异文（F-054），按 [事实清单](/facts.md) 登记而非强行裁决（洞察 3）。
- 拿示例 [01《逍遥游》精读](01-xiaoyaoyou-reading.md) 当范本，把"逐段本文语义 + 多注本对照"复制到《齐物论》《养生主》。

### 阶段三：注本贯通（对照研究）

目标：理解"注家传统"如何塑造了今人眼中的庄子。

- 对照郭象注、成玄英疏（F-036、F-037），观察玄学 / 重玄学如何把"境界"系统化为形而上学（洞察 4）。
- 回查 ctext.org《莊子》多底本（续古逸丛书本、四部丛刊本、四库本等，F-020、F-045），体会"无出土全本下靠双源比对逼近原文"的治学现实（洞察 3）。
- 记住"定本意识"：今本 33 篇是郭象删定本、非汉时原貌（F-012、F-014、F-018；洞察 2）。

## 四、可复用阅读法（提炼）

以下四法可迁移到其他古籍（尤其无出土全本的传世经典），每条按「触发场景 → 核心步骤 → 反模式 → 迁移示例」四要素登记，对应 [架构洞察](/insights.md) 的 G3 萃取要求。

### 法 1：三层文本分辨法

- **触发场景**：拿到任意一部冠名"某子/某人"的古籍，或读到一段被注释包裹的原文时。
- **核心步骤**：先问"我读的是作者本文、后学增益、还是注家引申？"——内篇=庄子自著（F-023）、外杂篇=后学（F-030）、注疏=注家层，逐层定位后再读（洞察 1，对应 [作者分层](/concepts/02-authorship.md)）。
- **反模式**：把《庄子》33 篇笼统当"庄子一个人的思想"，或把郭象注里的"独化""玄冥"当成庄子原文固有概念。
- **迁移示例**：《论语》"孔子曰"与弟子辑录之分、《老子》各章年代分层，均可用同一"本文 / 增益 / 注家"三层判读。

### 法 2：本文 / 注家分离法

- **触发场景**：初读某书一上来就被历代注疏淹没、越读越绕时。
- **核心步骤**：第一遍屏蔽注疏只读白文，第二遍再带注家读，第三遍专门看注家"加了什么"（洞察 4）。
- **反模式**：读"庄子"实读"陈鼓应 / 郭象的庄子"，把现代译注的学术化或玄学化发挥当成本文语义。
- **迁移示例**：读《周易》先把卦爻辞与《十翼》分开、读《老子》先把本文与王弼注分开，皆同一法。

### 法 3：双源核对 + 异文登记法

- **触发场景**：关键句要"最真实原文"、需逐字核定时。
- **核心步骤**：关键句找至少两个独立底本（如郭象本系统 + ctext.org 数字底本）逐字比对；异文显式标注"某本作某"而非拍板唯一答案（洞察 3，F-054～F-065）。
- **反模式**：无出土全本仍强作唯一"定本"、把个人校勘偏好当权威文本；或一句话只抄一个网络来源不加核对。
- **迁移示例**：《淮南子》《列子》等无出土全本或出土不全的传世子书，均可照此法"双源逐字比勘 + 异文登记"。

### 法 4：定本意识

- **触发场景**：准备通读一部古籍、判断"我读的是不是原貌"之前。
- **核心步骤**：先查"流传到手的本子是谁定的、删了什么、改了什么"，再谈"读原文"（洞察 2，F-012、F-014、F-015、F-018）。
- **反模式**：默认"流传下来的就是原本"，忽略郭象删定（52 篇→33 篇、逸去 19 篇）这类关键塑型事件（F-014、F-015）。
- **迁移示例**：任何经后人编定 / 删定的典籍，都先做"定本溯源"，再判断所读文本的可靠性。

> 这四条共同落在一条边界上：**把"庄子本文"当境界引导（F-050～F-052），不当作一套可论证的形而上学命题。**凡遇到把庄子读成"体系"的注本，都要回到这条边界上核查（洞察 4）。

## 五、落地清单

1. 阶段一：读概念 03 内篇原文 + 陈鼓应《今注今译》，一周一篇，按内篇次序推进。
2. 阶段二：用王先谦《集解》重读《逍遥游》《齐物论》，对读示例 01、02。
3. 阶段三：通读内篇七篇，任一关键句做双源核对和异文登记。
4. 阶段四：按概念 08→09 通读外篇十五篇；《秋水》《知北游》精读，异文对照 F-057～F-059。
5. 阶段五：按概念 10→11 通读杂篇十一篇；先读《天下》《外物》《寓言》，疑伪四篇（F-031～F-033）最后读并对照作者分层，异文对照 F-060～F-065。
6. 全程守住"通读向导"边界：篇目与次第以本计划为纲，白文以概念 03/08/09/10/11 双源核对稿为准。
