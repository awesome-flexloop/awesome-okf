# 佛家核心经典（Buddhism）知识包

本目录收录佛家核心经典汉译本的 OKF 知识包。与《阴符经》《老子》等本土经典不同，汉传佛经的「原文」本身已是梵文/巴利文原典的汉语译本（梵本大多散佚），因此各知识包以「译本系统标注（译者/年代）+《大正藏》底本 + 关键段落逐字核对 + 多重注家立场」保证权威性与真实性。

## 知识包列表

| 知识包 | 定位 | 说明 |
|--------|------|------|
| [heart-sutra/](heart-sutra/index.md) | 《般若波罗蜜多心经》（玄奘译，260 字） | 般若系核心短经，全文精读与「空」解读 |
| [diamond-sutra/](diamond-sutra/index.md) | 《金刚般若波罗蜜经》（鸠摩罗什译） | 般若系核心长经，「无住生心」与三十二分结构 |
| [platform-sutra/](platform-sutra/index.md) | 《六祖坛经》（敦煌本/宗宝本） | 唯一称「经」的中国祖师著作，禅宗顿悟法门 |
| [amitabha-sutra/](amitabha-sutra/index.md) | 《佛说阿弥陀经》（鸠摩罗什译） | 净土宗核心，称名往生法门 |
| [lotus-sutra/](lotus-sutra/index.md) | 《妙法莲华经》选读（鸠摩罗什译） | 大部经导读，「会三归一」与法华诸喻选读 |

## 阅读路径建议

- 般若系入门：先读 [《心经》](heart-sutra/index.md)（260 字，最短），再读 [《金刚经》](diamond-sutra/index.md)（完整对话式展开）。
- 禅宗脉络：从 [《金刚经》](diamond-sutra/index.md) 的「应无所住而生其心」切入，过渡到 [《六祖坛经》](platform-sutra/index.md)。
- 净土地门：读 [《阿弥陀经》](amitabha-sutra/index.md)，理解「信愿行」与称名法门。
- 大部经通览：读 [《法华经》选读](lotus-sutra/index.md)，把握「会三归一」与法华诸喻。
