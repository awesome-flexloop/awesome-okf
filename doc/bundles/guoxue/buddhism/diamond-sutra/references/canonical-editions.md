# 底本信源

## 一、一级文献（底本）

《金刚经》有「六译」之说，其中被《大正新修大藏经》收录的通行译本如下：

| 译者 | 译本名 | 《大正藏》编号 |
|------|--------|---------------|
| 鸠摩罗什 | 《金刚般若波罗蜜经》 | T08 No.235（本 bundle 底本） |
| 菩提流支 | 《金刚般若波罗蜜经》 | T08 No.236 |
| 真谛 | 《金刚般若波罗蜜经》 | T08 No.237 |
| 达摩笈多 | 《金刚能断般若波罗蜜经》 | T08 No.238 |
| 玄奘 | 《大般若经》第九会〈能断金刚分〉（卷五七七） | No.220(9) |
| 义净 | 《佛说能断金刚般若波罗蜜多经》 | T08 No.239 |

> 说明：玄奘译本（《能断金刚般若波罗蜜多经》）是《大般若波罗蜜多经》第九会，非 T08 独立单行本；T08 No.238 为达摩笈多（Dharmagupta，隋）译，非失译。

## 三、核对说明

本 bundle 关键段落以 CBETA《大正藏》T08 No.235 为底本逐字核对；「品名」为梁昭明太子分章，未计入经文。著名偈颂（「一切有为法，如梦幻泡影，如露亦如电」）依罗什本作六喻，玄奘本作九喻（星、翳、灯、幻、露、泡、梦、电、云），属译本差异。
