# 架构洞察（Architecture Insights）

## 洞察 1：《金刚经》的权威在于「译文稳定 + 分章可辨」而非「唯一原典」

| 四元组 | 内容 |
|--------|------|
| **陈述** | 汉传《金刚经》无法宣称存在单一「原始原文」——梵本多本并存、罗什译文千年稳定传承、三十二分是后人分层装置。其权威来自「译者/年代可考 + 《大正藏》卷次可核 + 品名与原文可区分」这一可复现链条。 |
| **证据** | F-007（三十二分为萧统所分）、F-009（五译本并存）、F-011（罗什本最流行）、F-002（T08 No.235） |
| **反常识** | 一般人以「三十二分品名」当作经文本身的目录，但那是梁代萧统的分章，属「阅读装置」而非「原文结构」；混淆二者会误把后人的分段标题当作经典原文。 |
| **行动** | bundle 以「标注译者与《大正藏》编号 + 明确三十二分非原文 + 名句逐字标注出处分品」替代「宣称唯一原文」 |

## 洞察 2：「金刚三句义」是一个可迁移的破执公式

| 四元组 | 内容 |
|--------|------|
| **陈述** | 「A，即非 A，是名 A」（如「佛说般若波罗蜜，即非般若波罗蜜，是名般若波罗蜜」）不是文字游戏，而是一套「立名 → 破名 → 假名」的破执公式：先破除对「A」概念的实体化执着，再保留其假名功能。 |
| **证据** | F-029（三段句式）、F-019（凡所有相皆是虚妄）、F-018（四相即非菩萨） |
| **反常识** | 「即非」不等于虚无主义否定，而是中道——既不执着于「有」（实体），也不落入「无」（断灭），故下一分即设「无断无灭」。 |
| **行动** | 用「三段论破执法」模式（见下）作为一切名相（法、菩萨、福德）的统一破执方法 |

## 洞察 3：「无住」是《金刚经》与《心经》相较最独特的落脚点

| 四元组 | 内容 |
|--------|------|
| **陈述** | 《心经》以「空」破执、落脚于「无所得」；《金刚经》则以「无住」贯穿布施、生心、说法，落脚于「应无所住而生其心」——把般若空性落到「心如何安住」的修行论。 |
| **证据** | F-021（应无所住而生其心）、F-020（应无所住行于布施）、F-016（云何降伏其心）、F-030（惠能闻此悟入） |
| **反常识** | 「无所住」看似消极，实则是「不住色声香味触法」而积极「生清净心」——不是什么都不做，而是不粘着地做。 |
| **行动** | 与《心经》bundle 交叉互链，突出「空性（理）」与「无住（行）」的般若系双翼 |

## 洞察 4：同一名句在不同注家体系中呈现不同理论面向

| 四元组 | 内容 |
|--------|------|
| **陈述** | 「凡所有相皆是虚妄」「应无所住而生其心」等名句，在中观（性空）、唯识（遣遍计执）、禅宗（明心见性）三系注疏中被导向不同理论面向；「最真实解读」并非唯一答案，而需呈现立场差异。 |
| **证据** | F-019、F-021 搭配历代注家（吉藏/窥基/憨山/印顺）的不同释读 |
| **反常识** | 读者易把「某一宗派的解读」当作「经典本义」，但经典本义本身开放，权威性在「如实呈现多立场」而非「独占唯一正解」。 |
| **行动** | 在 [历代注家立场](concepts/05-commentaries.md) 中并列诸家，不做唯一结论 |

## 阅读模式（可复用）

### 模式一：三段论破执法

| 要素 | 内容 |
|------|------|
| **触发场景** | 阅读佛经见到「A，即非 A，是名 A」句式，或想破除对某概念的实体化执着 |
| **核心步骤** | 1）列出被讨论的名相 A（如「法」「菩萨」「波罗蜜」）→ 2）问「A 的实指是什么」→ 3）确认「即非 A」（破实体、破自性）→ 4）确认「是名 A」（假名安立，仍可用）→ 5）回到当下修行的落脚（如「无住」「无得」） |
| **反模式** | 把「即非 A」读作「A 不存在」的断灭见；把三段式当作诡辩而不落实于修行 |
| **迁移示例** | 用于《心经》「色即是空，空即是色」、中观「缘起性空」、日常破除「成功/失败」的执着 |

### 模式二：四相自检法

| 要素 | 内容 |
|------|------|
| **触发场景** | 发现自己「以为有一个固定的自我/他人/群体/永恒主体」时 |
| **核心步骤** | 1）识别当下执取的是哪一相（我相＝自我实体；人相＝他人实体；众生相＝众生实体；寿者相＝永恒持续主体）→ 2）以「即非菩萨」反问该执取是否与觉者相应 → 3）回到「无我」观察诸法因缘 |
| **反模式** | 只做口头上的「无我」而不对照具体执取；把四相当作四类「人有」而非四类「心执」 |
| **迁移示例** | 用于日常冲突（看见「我相/人相」的对立）、团队协作（「众生相」的刻板印象）、对死亡与寿者的恐惧 |
