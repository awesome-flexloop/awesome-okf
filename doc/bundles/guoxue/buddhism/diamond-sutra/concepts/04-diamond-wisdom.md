# 金刚三段论式

## 一、句式原型

《金刚经》第十三品「如法受持分」：

> 佛说般若波罗蜜，即非般若波罗蜜，是名般若波罗蜜。

此为「A，即非 A，是名 A」三段：

| 段 | 作用 |
|----|------|
| A（说般若波罗蜜） | 立名：语言上的安立 |
| 即非 A | 破名：破除对 A 自性实体的执着 |
| 是名 A | 假名：保留 A 作为假名、方便之用 |

## 二、中道义

「即非」不是断灭式否定（「A 不存在」），而是**遣除执着**；「是名」不是重新执有，而是**假名安立**。整体构成「离二边、行中道」的破执公式。

- 若偏「有」：执着法、菩萨、福德为实体 → 落入善相。
- 若偏「无」：以为一切空无 → 落入断灭（故第二十七分专设「无断无灭分」对治）。
