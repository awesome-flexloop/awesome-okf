# 《坛经》阅读与修行建议

## 一、三阶段进阶

| 阶段 | 目标 | 做法 |
|------|------|------|
| 1. 入门 | 熟悉宗宝本 | 读「行由品」「般若品」，重点诵得法偈与「菩提自性本来清净」 |
| 2. 明义 | 理解义理 | 依 [自性清净](../concepts/02-self-nature-originally-pure.md) → [顿悟](../concepts/03-sudden-enlightenment.md) → [三无](../concepts/04-three-no.md) 顺序读 |
| 3. 版本对照 | 辨析异文 | 以宗宝本为底，对照敦煌本得法偈等关键处 |

## 二、诵持要点

- 「菩提自性，本来清净，但用此心，直了成佛」宜常诵。
- 诵得法偈时留意「本来无一物」与「佛性常清净」的版本之别。
