# 架构洞察（Architecture Insights）

## 洞察 1：《坛经》的「真实」在于版本异文而非单一通行本

| 四元组 | 内容 |
|--------|------|
| **陈述** | 《坛经》无「唯一定本」——敦煌本与宗宝本在得法偈（「本来无一物」vs「佛性常清净」）等处存在实质文字差异，反映禅宗思想随时代流变。其「权威」来自如实呈现版本谱系与异文，而非以单一通行本冒充定本。 |
| **证据** | F-014（得法偈异文）、F-007（四版本系统）、F-009（敦煌本较早）、F-008（宗宝本通行） |
| **反常识** | 通行「本来无一物」常被当作惠能原偈，但更早的敦煌本作「佛性常清净」——「最真实」不等于「最熟悉」的通行本。 |
| **行动** | bundle 以「版本对照 + 异文标注」替代「单一原文宣称」；在 [版本系统](concepts/01-editions-dunhuang-zongbao.md) 与 [得法偈精读](examples/01-verses-and-koan-reading.md) 中并列两本 |

## 洞察 2：顿渐之辨的分水岭是「心性起点」而非「方法多少」

| 四元组 | 内容 |
|--------|------|
| **陈述** | 神秀「时时勤拂拭」（渐修）与惠能「本来无一物」（顿悟）的对立，本质是对「自性是否本自清净」的起点判断：若本来清净则直了成佛（顿）；若需除染则渐次修证（渐）。 |
| **证据** | F-012/F-013（两偈）、F-020（自性清净 vs 渐修）、F-015/F-023（顿教立场） |
| **反常识** | 「顿悟」不是否认修持，而是把修持重新定位为「直了见性」——顿悟不废修行，只是不安置次第。 |
| **行动** | 以「顿渐之辨起点论」贯穿 [顿悟法门](concepts/03-sudden-enlightenment.md)，避免把禅宗顿悟误解为「不修」 |

## 洞察 3：「唯一称经的中国祖师著作」标志禅宗中国化的里程碑

| 四元组 | 内容 |
|--------|------|
| **陈述** | 印度传来者为「经」，中国祖师著者通例不称「经」；《坛经》独称「经」，标志禅宗「即心即佛」「教外别传」对中国佛教「经」之权威的重构——祖师言教与佛说同尊。 |
| **证据** | F-001（唯一称经）、F-024（不立文字教外别传）、F-025（即心即佛） |
| **反常识** | 一般以「经」必为佛说，《坛经》以祖师说而称「经」，是禅宗对经典权威的革命性重定义。 |
| **行动** | 在 [禅宗史立场](concepts/05-history-and-stance.md) 中阐明「经」字背后的宗派意图 |

## 洞察 4：风幡公案把「心动」确立为禅宗心性论的入口

| 四元组 | 内容 |
|--------|------|
| **陈述** | 「不是风动，不是幡动，仁者心动」的公案，把外界动静之争转向「识心」，「心动」成为禅宗心性论的关键切入点——心为万法枢机。 |
| **证据** | F-017（风幡之议）、F-028（公案强调心性）、F-016（但用此心直了成佛） |
| **反常识** | 公案字面似唯心论，实则指向「识取自心、见性成佛」的修行指向，非否认外境之客观存在。 |
| **行动** | 以「公案解析法」（见下）解读风幡与得法偈，避免字面误解 |

## 阅读模式（可复用）

### 模式一：版本对照阅读法

| 要素 | 内容 |
|------|------|
| **触发场景** | 阅读《坛经》等存在多种版本系统的中国古籍，需分辨「通行本」与「早期本」 |
| **核心步骤** | 1）确定所读版本（如宗宝本）→ 2）找出早期本（敦煌本）→ 3）逐字比对关键处（得法偈）→ 4）判定异文是传抄讹误还是思想流变 → 5）在 facts 中登记异文 |
| **反模式** | 只读通行本却宣称「这是原文」；把版本差异当作「真假问题」而非「流变问题」 |
| **迁移示例** | 用于《老子》帛书本/王弼本、佛经诸译本、敦煌写本文献的对照 |

### 模式二：偈颂公案解析法

| 要素 | 内容 |
|------|------|
| **触发场景** | 阅读禅宗偈颂或公案，想从字面进入义理 |
| **核心步骤** | 1）先确认字面与版本异文 → 2）拆解意象（菩提树、明镜台、尘埃的比喻）→ 3）还原对话语境（谁在竞争衣钵/法义）→ 4）提炼心性论指向（渐/顿的起点）→ 5）落到「自省」而非「字面辩驳」 |
| **反模式** | 把公案当逻辑谜题猜谜；脱离版本谈「唯一标准解读」 |
| **迁移示例** | 用于解读「看山是山」三段公案、《无门关》公案、及一切禅门机锋 |
