# 遮遣系列

## 一、「无……」的次第

从「是故空中无色」起，《心经》逐层遮遣，对象由粗到细：

| 经文 | 遮遣对象 |
|------|---------|
| 无受想行识 | 五蕴 |
| 无眼耳鼻舌身意，无色声香味触法 | 十二处 |
| 无眼界，乃至无意识界 | 十八界 |
| 无无明，亦无无明尽，乃至无老死，亦无老死尽 | 十二因缘及其还灭 |
| 无苦集灭道 | 四谛 |
| 无智亦无得 | 能证之智与所证之果 |

## 二、遮遣的用意

「无 A」非断言「A 不存在」，而是遮遣对 A 的**实体化执着**（自性见）。凡夫执五蕴为我、执三世流转、执四谛为实法、执有「智」与「得」，故以「无」层层对治。

## 三、遮遣之后

遮遣一切执着后，经文不落断灭，反而归结为积极肯定——「以无所得故……究竟涅槃」「三世诸佛……得阿耨多罗三藐三菩提」，并赞般若波罗蜜多为「大神咒」「大明咒」。故遮遣是「破执」而非「虚无」，详见 [空性中道](03-emptiness.md)。
