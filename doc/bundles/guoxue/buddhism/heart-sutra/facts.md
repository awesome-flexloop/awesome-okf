## 核心名句

| 编号 | 事实内容 |
|------|---------|
| F-024 | 「照见五蕴皆空，度一切苦厄」为《心经》总纲句 |
| F-025 | 「色不异空，空不异色；色即是空，空即是色」为玄奘本通行译文 |
| F-026 | 「受想行识，亦复如是」表色空不二同样适用于受、想、行、识四蕴 |

| F-030 | 「无无明，亦无无明尽，乃至无老死，亦无老死尽」遮遣十二因缘及其还灭 |
| F-031 | 「无苦集灭道」遮遣四谛 |
| F-032 | 「无智亦无得」遮遣能证之智与所证之果 |
