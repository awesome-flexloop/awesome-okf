# 般若波罗蜜多心经阅读教程

本知识包（bundle）是《般若波罗蜜多心经》（简称《心经》，玄奘译，通行 260 字）的权威原文与解读指南。《心经》是全大藏经中最短的般若经典之一，其「原文」本身是梵本的汉译本，因此本 bundle 以「译本系统标注（译者/年代）+《大正藏》底本 + 260 字全文分段精读 + 多重注家立场」保证权威性与真实性。

> 关键提醒：通行玄奘本 260 字是「略本」，无序分（如是我闻）与流通分（欢喜奉行）；历代另有法成、法月、智慧轮、施护等「广本」含序分与流通分。阅读时应区分「略本/广本」与「译本差异」。
