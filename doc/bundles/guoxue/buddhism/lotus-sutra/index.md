# 妙法莲华经选读教程

本知识包（bundle）是《妙法莲华经》（简称《法华经》，鸠摩罗什译，通行七卷二十八品）的大部经选读指南。与《心经》《金刚经》等短经可全文照录不同，《法华经》二十八品约六万九千余字，故本 bundle 采用「大部经选读」模式：以「结构总览 + 核心品选读 + 关键偈颂 + 选读计划」替代全文逐字照录，并以「译本系统标注 + 《大正藏》底本 + 品次可核 + 多重注家立场」保证权威性与真实性。

> 关键提醒：通行二十八品中的《提婆达多品》与《普门品》重颂偈，皆为后人在罗什原译（七卷二十七品）基础上补入；阅读时应区分「原译」与「后人补入」，详见 [译本系统与二十八品结构](concepts/01-translation-and-structure.md)。
