# 架构洞察（Architecture Insights）

## 洞察 1：大部经的权威不在「唯一原文」，而在「译本分判 + 品次可核」

| 四元组 | 内容 |
|--------|------|
| **陈述** | 《法华经》约七万字，梵本多系（尼泊尔/克什米尔/新疆）与三汉译本并存，无法宣称单一「原始原文」。其权威来自「译本系统（三译可互勘）+《大正藏》卷次可核 + 二十八品品次可辨 + 后人补入内容可标注」这一可复现链条。 |
| **证据** | F-009（三译本并存）、F-007（提婆达多品/普门品偈为后人补入）、F-013（梵本四十余种）、F-002（T09 No.262） |
| **反常识** | 一般读者以「通行二十八品」当作罗什原译原貌，但《提婆达多品》与《普门品》重颂偈是后人补入，「原译」实为二十七品；混淆「原译」与「补入」会误判经文形成史。 |
| **行动** | bundle 以「三译本异同 + 品次标注 + 补入内容显式标注」替代「宣称唯一原文」 |

## 洞察 2：「会三归一」是一套结构化的「废权显实」操作，而非平等口号

| 四元组 | 内容 |
|--------|------|
| **陈述** | 「三乘会归一佛乘」并非否定三乘的修行价值，而是把三乘（声闻/缘觉/菩萨）重新定位为「权」（方便），把一佛乘定位为「实」（真实）；其操作是「开权显实」——先开三乘之权，再显一乘之实，令一切众生皆能成佛。 |
| **证据** | F-016（会三归一）、F-022（唯有一乘法，无二亦无三，除佛方便说）、F-023（余二则非真）、F-021（一大事因缘） |
| **反常识** | 「无二亦无三」易被误读为抹平教法差异，实则「除佛方便说」一句保留了权教的工具价值——三乘是过渡的方便，不是要被否定，而是要被「显实」地统摄。 |
| **行动** | 用「权实二分法」模式（见下）统摄一切「究竟/方便」类教义辨析 |

## 洞察 3：法华诸喻是大部经的「故事函数库」，是选读的最优抓手

| 四元组 | 内容 |
|--------|------|
| **陈述** | 《法华经》教义的抽象命题（一乘真实、佛性本有、二乘可成佛）大多通过「喻」来传达。「法华七喻」构成一个「故事函数库」：每个喻把某一抽象义理映射到具体场景，读者可绕过品次与长文，以「喻」为单位快速把握核心。 |
| **证据** | F-019（法华七喻）、F-020（火宅喻）、F-025（穷子喻）、F-026（化城喻）、F-027（衣珠喻） |
| **反常识** | 「七喻」之名是后人的归纳，并非经中自带的清单；且七喻分布在前后不同品，若不按品次而按「喻」摘读，易失去上下文。选读应「先认喻、再回品」。 |
| **行动** | 在 examples 中以「喻」为核心编写[核心品选读](examples/01-key-chapters-reading.md)，并提供「先认喻、再回品」的选读路径 |

## 洞察 4：「迹门/本门」二分是把《法华》读成立体经教的顶层框架

| 四元组 | 内容 |
|--------|------|
| **陈述** | 天台智者以「前十四品为迹门、后十四品为本门」把二十八品读成一套立体结构：迹门以「开三显一」说一乘之因（二乘亦能成佛），本门以「久远实成」显一乘之果（释迦久已成佛、寿命无量）。「迹」如水月，「本」如天上月。 |
| **证据** | F-018（迹门本门二分）、F-017（久远实成）、F-016（开权显实） |
| **反常识** | 读者易把《法华经》当作平铺的二十八品叙事，忽略「从本垂迹→开迹显本」的两层结构；不把握此框架，则《如来寿量品》的「久远实成」容易被读成神话而非义理核心。 |
| **行动** | 以「迹门/本门」为轴编写[译本与结构](concepts/01-translation-and-structure.md)与[核心品导引](concepts/04-key-chapters.md) |

## 选读模式（可复用）

### 模式一：大部经「结构总览 → 核心品精读 → 选读计划」三段选读法

| 要素 | 内容 |
|------|------|
| **触发场景** | 面对一部数万字的大部经（如《法华》《华严》《楞严》），无法全文精读，又想把握要旨 |
| **核心步骤** | 1）先读「结构总览」（译本系统 + 品目一览 + 迹门/本门等大分科）建立地图 → 2）锁定「核心品」（如法华的方便品、譬喻品、如来寿量品、普门品）做节选精读 → 3）以一两个关键词（如「会三归一」「法华七喻」）为轴做横向串联 → 4）制定「选读计划」分阶段推进，而非一次通读 |
| **反模式** | 无结构地从头通读到尾；把「选读」降格为「只读名句」而丢品次语境；把后人补入内容当作原译 |
| **迁移示例** | 用于《华严经》（以「入法界品」为精读核）、《楞严经》（以「七处征心」为精读核）等大部经的选读 |

### 模式二：「先认喻、再回品」的譬喻选读法

| 要素 | 内容 |
|------|------|
| **触发场景** | 大部经以大量譬喻传达抽象义理，读者想以故事为单位快速把握而不失原典脉络 |
| **核心步骤** | 1）列出该经的著名譬喻及所在品 → 2）逐喻提取「喻体（故事）— 喻义（义理）— 品次（出处）」三元组 → 3）先读喻体记住故事，再回原品核对喻义与上下文 → 4）把多个喻按义理主题（如「二乘可成佛」「佛性本有」）归类串联 |
| **反模式** | 只记故事不扣义理；脱离品次孤立引用而断章取义；把后人归纳的「七喻」当作经文自带目录 |
| **迁移示例** | 用于《百喻经》（寓言集）、《涅槃经》（贫女宝藏等喻）以及一切以「喻」说法的经论 |

### 模式三：权实二分法

| 要素 | 内容 |
|------|------|
| **触发场景** | 阅读中遇到「究竟/方便」「真实/权巧」类教义辨析，或想理解某法门为何被「统摄」而非「否定」 |
| **核心步骤** | 1）辨认文本中「权」（方便，阶段性工具）与「实」（真实，究竟目标）两层面 → 2）确认「权」的合法性来源（方便说）而非其虚假 → 3）确认「开权显实」的统摄方向（由权入实）→ 4）避免把「显实」读成「废权」 |
| **反模式** | 把「无二亦无三」读作抹平一切教法；把方便法门等同虚伪而被否定 |
| **迁移示例** | 用于辨析《金刚经》「是名」假名与法华「三乘方便」、天台判教「五时八教」、日常中「手段与目的」的关系 |
