# 注本分级

## 注疏分级

| 级别 | 注疏 | 说明 |
|------|------|------|
| 一级（宗派亲释） | 智顗《法华玄义》《法华文句》 | 天台正宗，明「迹门/本门」「五时八教」 |
| 一级（印度论释） | 世亲《妙法莲华经优波提舍》（即《法华经论》） | 印度最早《法华》论，菩提流支、昙林译 |
| 二级（古德疏解） | 吉藏《法华玄论》《法华义疏》、窥基《法华玄赞》 | 三论宗/唯识宗各自立场 |
| 三级（天台阶梯） | 湛然《法华玄义释签》《法华文句记》 | 读懂智顗的进阶阶梯 |
| 三级（近现代/会通） | 智旭《法华会义》、憨山德清《法华经通义》 | 禅净/诸家会通视角 |

## 选用原则

- 明「迹门/本门」：首选智顗（《玄义》《文句》），配湛然释签作阶梯。
- 释「会三归一」：可对照吉藏（中观）、窥基（唯识）。
- 明「一切众生皆能成佛」：可参竺道生、湛然「无情有性」说。
