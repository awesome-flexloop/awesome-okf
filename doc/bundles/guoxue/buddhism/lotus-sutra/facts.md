# 事实清单（Facts Inventory）

## 经典基本信息

| 编号 | 事实内容 |
|------|---------|
| F-001 | 《妙法莲华经》，梵名 Saddharma-puṇḍarīka-sūtra，简称《法华经》，属大乘经 |
| F-002 | 鸠摩罗什译《妙法莲华经》通行本为七卷二十八品，收《大正新修大藏经》第九册，编号 T09 No.262 |
| F-003 | 鸠摩罗什于后秦弘始八年（406 年）在长安译出《妙法莲华经》 |
| F-004 | 鸠摩罗什（344-413），龟兹人，中国佛教四大译经家之一 |
| F-005 | 「妙法」译自梵语 Saddharma，意「正妙之法」；「莲华」译自 puṇḍarīka（白莲华），喻佛法出淤泥而不染、至上清净 |
| F-006 | 通行本《法华经》约六万九千余字，二十八品由「长行」（散文）与「重颂」（偈语）两部分组成 |
| F-007 | 罗什译本原为七卷二十七品，《普门品》原无重诵偈；后人补入南齐法献所得《提婆达多品》、阇那崛多译《普门品偈》与玄奘译《药王菩萨咒》，构成现行七卷二十八品 |
| F-008 | 《法华经》被尊为「经中之王」，是天台宗的根本经典 |

## 译本系统与流传

| 编号 | 事实内容 |
|------|---------|
| F-009 | 现存汉译本三种：竺法护《正法华经》（十卷二十七品）、鸠摩罗什《妙法莲华经》（七卷二十八品）、阇那崛多与达摩笈多《添品妙法莲华经》（七卷二十七品） |
| F-010 | 竺法护《正法华经》译于西晋太康七年（286 年），是现存三本中最早者，收 T09 No.263 |
| F-011 | 《添品妙法莲华经》译于隋仁寿元年（601 年），收 T09 No.264；因补罗什译本所阙（如药草喻品之半、提婆达多品、普门品偈等）故名「添品」 |
| F-012 | 据《开元释教录》，本经先有「六译」之说，现存唯上述三种译本 |
| F-013 | 梵文《法华经》写本现存四十余种，大致分为尼泊尔、克什米尔（基尔基特）、新疆三种体系 |
| F-014 | 第二十五品《观世音菩萨普门品》单行流通称《观音经》 |
| F-015 | 天台宗以《无量义经》为开经、《妙法莲华经》为正经、《观普贤菩萨行法经》为结经，合称「法华三部经」 |

## 核心义理与名句

| 编号 | 事实内容 |
|------|---------|
| F-016 | 核心思想为「开权显实、会三归一」：声闻、缘觉、菩萨三乘皆为方便，会归究竟一佛乘 |
| F-017 | 「久远实成」思想出于《如来寿量品第十六》：释迦成佛以来，寿命无量，非今生菩提树下始成 |
| F-018 | 天台智者大师判本经前十四品为「迹门」（从本垂迹），后十四品为「本门」（开迹显本） |
| F-019 | 「法华七喻」为后人归纳：火宅喻、穷子喻、药草喻、化城喻、衣珠喻、髻珠喻、医子喻 |
| F-020 | 「三界无安，犹如火宅，众苦充满，甚可怖畏」出自《譬喻品第三》 |
| F-021 | 「诸佛世尊，唯以一大事因缘故，出现于世」出自《方便品第二》 |
| F-022 | 「十方佛土中，唯有一乘法，无二亦无三，除佛方便说」出自《方便品第二》 |
| F-023 | 「唯此一事实，余二则非真」出自《方便品第二》 |
| F-024 | 《见宝塔品第十一》说多宝佛塔从地涌出，多宝佛分半座与释迦，二佛并坐 |
| F-025 | 《信解品第四》以「穷子喻」说声闻但受小法，不知自有佛性大业 |
| F-026 | 《化城喻品第七》以「化城」喻二乘涅槃为方便所化，非究竟处 |
| F-027 | 《五百弟子受记品第八》以「衣珠喻」（系珠喻）说众生本具佛性而不自知 |
