# 核心品精读导引

《法华经》二十八品不必平均用力，以下八品为精读重点（其余品作结构通览）。详细节选与偈颂见 [核心品选读与关键偈颂](../examples/01-key-chapters-reading.md)。

| 品 | 品名 | 精读要点 |
|----|------|---------|
| 2 | 方便品 | 全经纲领：「开示悟入」「一大事因缘」「唯有一乘法，无二亦无三」 |
| 3 | 譬喻品 | 火宅喻 + 三车，火宅/大白牛车喻「会三归一」 |
| 4 | 信解品 | 穷子喻，声闻弟子自陈「回小向大」的理解 |
| 10 | 法师品 | 弘经持诵的功德，闻经受持即入佛道 |
| 11 | 见宝塔品 | 多宝塔涌出、二佛并坐、虚空会，证《法华》真实 |
| 15 | 从地涌出品 | 本门开场，地下涌出无量菩萨，引出「久远实成」之问 |
| 16 | 如来寿量品 | 「久远实成」核心：释迦成佛无量劫、寿命无量、医子喻 |
| 25 | 观世音菩萨普门品 | 称名救苦、三十三应化身，单行称《观音经》 |

## 精读串联建议

1. 立纲领：先读《方便品》的「一大事因缘」「唯一佛乘」；
2. 看方法：再读《譬喻品》《信解品》的两个喻，看「会三归一」如何以故事展开；
3. 入果地：读《从地涌出品》《如来寿量品》，进入「本门」的「久远实成」；
4. 落修行：以《普门品》观世音称名救苦作日用修行入口。
