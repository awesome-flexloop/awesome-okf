# 历代注家立场

《法华经》注疏极多（历代达数十种），代表注家与立场如下：

| 注家 | 时代 | 立场/代表作 | 释经要领 |
|------|------|-----------|---------|
| 世亲（婆薮盘豆） | 印（约四五世纪） | 《妙法莲华经优波提舍》（菩提流支、昙林译，即《法华经论》） | 印度最早的《法华》论释，开「论」释经先河 |
| 竺道生 | 刘宋 | 《法华经疏》二卷 | 最早流传的《法华》注疏之一，主「一阐提亦能成佛」 |
| 法云 | 梁 | 《法华经义记》八卷 | 光宅法云，梁代《法华》义学代表 |
| 智顗 | 隋 | 《法华玄义》《法华文句》（法华三大部） | 天台判教「五时八教」，立「迹门/本门」，教观双美 |
| 吉藏 | 隋 | 《法华玄论》《法华义疏》 | 三论宗（中观）立场释「会三归一」 |
| 窥基 | 唐 | 《法华玄赞》 | 法相唯识立场释《法华》 |
| 湛然（荆溪） | 唐 | 《法华玄义释签》《法华文句记》 | 中兴天台，阐「无情有性」 |
| 智旭 | 明 | 《法华会义》 | 天台与唯识、禅、净会通 |

## 立场的差异价值

同一「会三归一」在不同注家体系中呈现不同面向：

- 天台系（智顗、湛然）：重在「一心三观、开权显实」的圆教判释；
- 三论/中观系（吉藏）：重在以「缘起性空」释「方便」与「真实」；
- 唯识系（窥基）：重在以「三乘分别—一乘真实」对比三性与种性。

「最真实解读」并非独占正解，而是**如实现呈多立场**（见 [架构洞察](../insights.md)）。
