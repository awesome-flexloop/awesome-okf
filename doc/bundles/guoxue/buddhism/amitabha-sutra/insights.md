# 架构洞察（Architecture Insights）

## 洞察 1：《阿弥陀经》的权威在「译本稳定 + 行门简明」而非深奥义理

| 四元组 | 内容 |
|--------|------|
| **陈述** | 与《金刚经》重「无住生心」的义理思辨不同，《阿弥陀经》以「执持名号、一心不乱、临终往生」为简明行门，其权威来自罗什译文的千年稳定流传 + 净土宗「三经」经系定位，而非玄谈。 |
| **证据** | F-002（T12 No.366）、F-028（罗什本流传最广）、F-004（净土三经）、F-014（执持名号） |
| **反常识** | 「最真实」不等于「最艰深」——一部以「简单行法」为核心的经典，其真实性恰在其「人人可持」的普世性。 |
| **行动** | bundle 以「译本标注 + 经文逐字 + 行门框架」呈现，不堆砌玄学 |

## 洞察 2：称名念佛把「修行」从自力难行转向他力易行

| 四元组 | 内容 |
|--------|------|
| **陈述** | 「执持名号」将成佛的主动权从「自力证果」转向「信愿持名、仰仗佛力接引」，是佛教修行论从「难行道」向「易行道」的重大转向。 |
| **证据** | F-014（执持名号）、F-016（临终接引）、F-018（少善根亦可往生）、F-020（信愿行） |
| **反常识** | 「易行」不是「不修」，而是把「行」集中为「称名」这一极简而普被的形式，故经末强调「难信之法」。 |
| **行动** | 以「信愿行」三资粮为框架解释称名法门，避免简化为主观臆断 |

## 洞察 3：「一心不乱」是「修」与「信」的交汇与后世诤论焦点

| 四元组 | 内容 |
|--------|------|
| **陈述** | 「一心不乱」究竟指「事一心/理一心」的功夫深浅，还是「信愿不退」的信念坚定，是净土宗与各宗长期诤论之点；不同注家给出不同解释。 |
| **证据** | F-015（一心不乱）、F-023（蕅益要解）、F-024（莲池疏钞） |
| **反常识** | 「一心不乱」常被误读为禅定功夫的标准，但净土宗多从「信愿」而非「禅定」来解。 |
| **行动** | 在 [执持名号与一心不乱](concepts/03-name-recitation.md) 中并列诸家解读，不做唯一裁定 |

## 洞察 4：依正庄严是「信仰语言」而非「地理描述」

| 四元组 | 内容 |
|--------|------|
| **陈述** | 「七重栏楯、七宝池、八功德水」等描述是净土信仰的「愿力呈现」，属宗教语言（依正庄严），不应以现代地理/物理标准作字面执实。 |
| **证据** | F-011（七重栏楯）、F-012（七宝池八功德水）、F-013（依正庄严）、F-010（无有众苦但受诸乐） |
| **反常识** | 读者易把「极乐世界」当作宇宙中可定位的物理星体，但经文的着力点是「信愿的状态」而非「坐标」。 |
| **行动** | 在 [依正庄严](concepts/02-sukhavati.md) 中划定「信仰语言」边界 |

## 阅读模式（可复用）

### 模式一：译本对照阅读法

| 要素 | 内容 |
|------|------|
| **触发场景** | 阅读汉译佛经，需分辨「原文」与「译风」、罗什本与玄奘本的差异 |
| **核心步骤** | 1）确定底本（T12 No.366 罗什本）→ 2）找异译本（玄奘《称赞净土佛摄受经》）→ 3）比对关键名句（执持名号/一心不乱）→ 4）判定差异属译风还是义理 → 5）登记 facts |
| **反模式** | 只读单一译本却宣称「这是原文」 |
| **迁移示例** | 用于《无量寿经》诸译本、《金刚经》罗什/玄奘本对照 |

### 模式二：三资粮自检法

| 要素 | 内容 |
|------|------|
| **触发场景** | 学习净土法门，或检验自己对「信愿行」的落实 |
| **核心步骤** | 1）信：是否信极乐净土与阿弥陀佛愿力 → 2）愿：是否发起往生之愿 → 3）行：是否落实称名等行门 → 4）三者是否构成闭环而非偏废 |
| **反模式** | 只有「行」（称名）却无信愿，或只有信愿却无行门 |
| **迁移示例** | 迁移到一切「信念-意愿-行动」一致性的自我检验 |
