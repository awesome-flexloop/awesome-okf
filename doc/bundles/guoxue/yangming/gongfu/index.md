# 王阳明修养工夫论与现代实践教程

王阳明（1472—1529）心学的落点不在书本知解，而在可日用的修养工夫。钱德洪述其教法三变："居贵阳时首于学者为知行合一之说；自滁阳后多教学者静坐；江右以来始举'致良知'三字，直指本体"（facts F1）。本知识包（bundle）以"工夫"为纲，系统整理阳明论立志、静坐、事上磨练、省察克治的核心语录，全部古文引文经两个以上独立信源逐字核对、异文登记不改字（facts F6–F35），并提供一份分层标注的 30 天现代实践手册。本束特点有三：

1. **头脑—工夫—效验三层结构**——头脑是立志与致良知（"志不立，天下无可成之事""吾教人'致良知'在'格物'上用功，却是有根本的学问"），工夫是静坐、事上磨练、省察克治、知行合一，效验是"静亦定，动亦定"与临终"此心光明"的自评尺度（facts F4、F7、F16、F17、F34）；
2. **教法转向如实呈现**——早年贵阳、滁州时期教人静坐收放心，晚年自道"久之渐有喜静厌动、流入枯槁之病……故迩来只说'致良知'"，事上磨练成为正鹄；静坐是"因病而药"的方便，非究竟法门（facts F5、F13、F14、F20、F21）；
3. **古典原意与现代实践严格分层**——概念页只陈述双源核对的古典文本；[30 天实践手册](examples/01-modern-practice-30days.md)开篇即声明"现代实践设计，非古文原意"，每个现代动作均回标古典依据（F 编号），现代话术不伪装成阳明原话。

## 🚀 快速开始

如果你之前从未接触过阳明心学：

1. 先读[工夫论总纲](concepts/00-overview.md)，建立"头脑—工夫—效验"三层框架
2. 读[立志](concepts/01-lizhi.md)，写下你自己的立志句（手册第 0 步有模板）
3. 打开[30 天实践手册](examples/01-modern-practice-30days.md)，从第 1 天开始打卡

如果你已有中国哲学或心学基础：

1. 从[事上磨练](concepts/03-shishang-molian.md)入手，核对"人须在事上磨"的卷次录者（卷上陆澄录，非卷下）与"磨炼/磨链"异文
2. 读[静坐澄心](concepts/02-jingzuo.md)与[省察克治](concepts/04-xingcha-kezhi.md)，辨明静坐的方便性质与"人欲=过度之私"的诠释分层
3. 对照[信源登记](references/sources.md)复核全部双源核对记录
