# 《传习录》阅读教程

《传习录》，书名取《论语·学而》曾子"吾日三省吾身……传不习乎"之义（facts F1），是明代思想家王守仁（号阳明，1472—1529）讲学语录与论学书信的合集，被钱穆列为"有关修养人人所必读"之书（facts F5）。全书分三卷：卷上为徐爱、陆澄、薛侃所录语录（条 1–129），卷中为答顾东桥书等论学书信并右南大吉录（条 130–200），卷下为陈九川、黄直、黄修易、黄省曾、黄以方等所录语录（条 201–342），另有《传习录拾遗》51 条（facts F13–F17）。本知识包（bundle）是面向普通读者与研究者的《传习录》系统中文阅读教程，特点有三：

1. **三卷分层、编号双轨**——卷上/卷下语录体、卷中书信体、《大学问》属《全书》续编而非本书，三层文本显式分判；条目定位同时给出陈荣捷编号与录者分篇，分卷异说（右南大吉录卷中/卷下）、分篇异说（黄直/黄以方/钱德洪所录）并列登记不裁决（facts F14–F19、F36）；
2. **11 组原文双源核对**——亲民、心即理、知行合一、知而不行、致良知、四句教、岩中花树、事上磨练、拔本塞源、训蒙大意、《大学问》11 组选读均经两个以上独立信源（维基文库/中华文库 × 古诗文网/5000yan/汉典古籍/学术页）逐字比对，异文（四句教"是"字系、"即/既"、"云滃/云蟬"、"词章/辞章/问章"、"衰痿/衰萎"、"磨/磨鍊"）登记不改字（facts F21–F37）；
3. **版本链清晰、义理为纲**——从正德十三年（1518）薛侃赣州初刻，到南大吉绍兴增刻、钱德洪《传习续录》，再到隆庆六年（1572）谢廷杰《王文成公全书》三卷定型，版本链 50 余年有据可查（facts F6–F11）；阅读计划以"心即理—知行合一—致良知—万物一体"义理主线组织。

## 🚀 快速开始

如果你之前从未读过《传习录》：

1. 先读[全书概览](concepts/00-overview.md)，了解书名出处、三卷体例与王守仁生平
2. 读[三卷结构与编号](concepts/02-volumes-structure.md)，记住三卷分野与陈荣捷编号用法
3. 打开[三轨阅读计划](examples/01-reading-plan.md)，按零基础轨从卷上徐爱录开始通读
4. 随读对照[选读原文](concepts/04-selected-readings.md)第一至四组（亲民、心即理、知行合一、知而不行）

如果你已有中国哲学或心学基础：

1. 从[核心命题地图](concepts/03-core-entries-map.md)开始，抓"心即理—知行合一—致良知—万物一体"义理主干
2. 读[成书与版本](concepts/01-compilation-versions.md)，理清初刻、增刻、《传习续录》与隆庆定型的版本链
3. 对照[选读原文](concepts/04-selected-readings.md)第五至十一组（致良知、四句教、岩中花树、事上磨练、拔本塞源、训蒙大意、大学问）核对异文
4. 参考[信源登记](references/sources.md)，以陈荣捷《详注集评》或邓艾民《注疏》为研读底本
