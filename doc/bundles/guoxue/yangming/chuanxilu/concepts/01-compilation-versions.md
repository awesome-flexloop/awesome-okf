# 成书与版本

《传习录》非一时一人成书，从正德十三年（1518）初刻到隆庆六年（1572）三卷"定本"入《王文成公全书》，版本链历时 50 余年（董平称"历时 50 多年"、ctext 作"五十五年"，两数并登记），最终定稿人钱德洪（facts F6–F11）。

## 卷中书信的编辑：钱德洪序

卷中卷首钱德洪序记述南大吉刻本与卷中编次（fact F8）：

> 昔南元善刻《博习录》于越，凡二册。下册摘录先师手书，凡八篇……《答徐成之》二书……故今不复录……答文蔚之第二书，故增录之。

据此可知：南大吉（字元善）绍兴刻本分二册，下册摘录阳明手书八篇；《答徐成之》二书当时未予收录；《答聂文蔚》第二书为后来增录。今本卷中书信段次（答顾东桥书、启周道通书、答陆原静书、又、答欧阳崇一、答罗整庵少宰书、答聂文蔚、答聂文蔚二）即此编次系统（facts F8、F14）。

## 底本选择原则

1. **原文正字**以隆庆本《王文成公全书》系统（维基文库、中华文库所据）为主录；
2. **条号定位**用陈荣捷编号（342 条＋拾遗 51 条），同时注卷次与录者篇名，双轨标注（facts F13–F17）；
3. **异文登记**：各本异文（四句教"是"字系、"即/既"、"磨/磨鍊"、"云滃/云蟬"、"词章/辞章"等）登记不改字，OCR 讹字标注为讹；
4. **层级声明**：《大学问》属《全书》卷二十六续编，《朱子晚年定论》为隆庆本附录，均不与三卷本文混引（facts F12、F36）。

## 年代异说登记（不裁决）

- 南大吉绍兴刻本：董平作嘉靖三年（1524）；陈荣捷《传习录略史》有"嘉靖五年"碎片说——并列（fact F7）；
- 初刻年份：董平正文作"正德十三年（1517）"，正德十三年实为公元 1518 年——原文照录、加注记（fact F6）；
- 定本历时：董平"历时 50 多年"；ctext"历时五十五年"——并列（fact F11）。
