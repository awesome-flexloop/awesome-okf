# 王阳明心学·思想源流与后学分化束（束5）

本束是王阳明心学知识包的**谱系束**，回答三个问题：阳明心学从哪里来（远源与朱王分化）、阳明之后怎样分化（天泉证道与王门七派）、走出中国后怎样变形（东亚传播与近代复兴）。全束以黄宗羲《明儒学案》的分派框架为骨架，以 F 编号事实登记为证据层，特点有三：

1. **关键引文双源核对**——"宇宙便是吾心，吾心即是宇宙"、"有泰州、龙溪而风行天下，亦因泰州、龙溪而渐失其传"、"姚江之学，惟江右为得其传"、"以明心见性之空言，代修己治人之实学"、王夫之"销行以归知"等关键原文均经两个以上独立信源核对，异文（陆九渊卒年 1192/1193、大盐平八郎生年 1793/1794、西乡隆盛生年 1826/1828、格竹系年两说等）登记不改字（facts F5、F12、F30、F31）；
2. **争议并列不裁决**——《朱子晚年定论》性质（调停策略/考据失误两说）、"阳明学为明治维新精神动力"说（倡导说/现代学界质疑说）、"阳明学"名称源流（和制汉语说/中国本土说/折中说三说）、天泉证道真伪悬案，均并列 ≥2 说、各自给信源（facts F16、F18、F32、F33）；
3. **师承-命题-分化三维并录**——后学分派不只录师承关系，同时录各派核心命题（四无/四有、归寂、百姓日用即道、止修）与分化节点，并旁注判词的立场性（如黄宗羲"惟江右为得其传"出自江右正统观，须与泰州、龙溪文献对读）。

## 🚀 快速开始

如果你之前只听说过"知行合一""致良知"：

1. 先读[谱系总图](concepts/00-overview.md)，建立孟→陆→王→后学→东亚的整体地图
2. 读[思想远源](concepts/01-sources-mengzi-luxiang.md)，理解阳明心学不是凭空而起
3. 打开[三级书单与进学路径](examples/01-study-path.md)，从《传习录》白文通读开始

如果你已有中国哲学基础：

1. 从[朱王之辨](concepts/02-zhu-wang-divergence.md)入手，对照心即理与性即理的分野
2. 读[后学分派](concepts/03-disciples-schools.md)，抓四派命题差异
3. 读[明清反思与近代复兴](concepts/04-critique-revival.md)与[东亚传播](concepts/05-east-asia-modern.md)，注意所有争议处均为并列表述
4. 对照[信源登记](references/sources.md)选用中华书局点校本《明儒学案》作研读底本
