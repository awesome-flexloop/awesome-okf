## 二、地理迁移简表（文字地图）

```
余姚（瑞云楼，1472 生）
  → 1482 随父祖赴北京（11 岁，"读书学圣贤"之问）
  → 1488 南昌（洪都）成婚
  → 1506 北京下诏狱 → 谪赴贵州
  → 1508 龙场驿（今贵阳修文县；龙冈书院，悟道）
  → 1509 贵阳（贵阳书院，知行合一）
  → 1510 江西庐陵（知县）
  → 北京 → 1513 滁州（太仆寺少卿，静坐教法）→ 南京（鸿胪寺卿）
  → 1517 赣州（南赣巡抚衙门；十家牌法/乡约/社学）
  → 1519 丰城闻变 → 吉安起义 → 南昌 → 鄱阳湖樵舍擒濠
  → 1521 南昌（揭致良知）→ 1522 绍兴越城（丁忧讲学六年；天泉桥在此）
  → 1527 出征：绍兴 → 严滩（富春江上）→ 广西（思田、八寨断藤峡）
  → 1528 东归 → 1529-01-09 南安府青龙铺（今大余县）舟中卒
  → 归葬绍兴山阴洪溪（今兰亭仙霞山）
```

地理线要点（fact F36）：**浙江（余姚—绍兴）是出生与归葬地，贵州（龙场—贵阳）是悟道地，江西（赣州—南昌—南安）是事功与卒地，广西是最后征程。** 今日可游学的核心遗址带：浙江余姚瑞云楼、绍兴阳明故里/天泉桥/兰亭墓、贵州修文龙冈书院/阳明洞、江西赣州（通天岩、崇义）、南昌、庐山开先寺纪功碑摩崖、大余青龙铺。

## 四、两种实操读法

### 读法 A：按地游学（空间线）

1. **浙江线**：余姚瑞云楼（出生）→ 绍兴阳明故里、天泉桥（证道）、兰亭仙霞山阳明墓（归葬）——主题：成学与晚年；
2. **贵州线**：修文龙场阳明洞/龙冈书院遗址 → 贵阳文明书院——主题：悟道与知行合一，配读 [02 龙场悟道](../concepts/02-longchang-awakening.md)；
3. **江西线**：赣州通天岩/崇义（南赣治理）→ 南昌（宁王府旧址、揭致良知）→ 庐山开先寺纪功碑摩崖 → 大余青龙铺（卒地）——主题：事功与归宿，配读 [03 文治武功](../concepts/03-shigong.md)、[04 晚年归宿](../concepts/04-tianquan-and-final.md)。

每到一地，先读本表对应行，再读对应概念篇，最后核 [../facts.md](../facts.md) 该段 F 编号。

### 读法 B：按年读《传习录》（时间线）

《传习录》上卷主要为徐爱、薛侃等所录早期语录，中卷为书信（含《答顾东桥书》等论知行合一、致良知），下卷为钱德洪、王畿等所录晚年语录（含天泉证道、严滩问答）。建议：

| 阅读顺序 | 配读生平段落 |
|----------|--------------|
| 《传习录》上卷开头（徐爱录，论知行合一、心即理） | 龙场—贵阳段（1508—1509，F15、F17） |
| 中卷书信（《答顾东桥书》等，知行合一展开） | 南京—南赣段（1513—1518） |
| 中卷《答聂文蔚》及致良知诸说 | 南昌揭教前后（1521，F29） |
| 下卷黄以方录（严滩问答）、钱德洪录（天泉证道） | 晚年（1527，F32、F33） |

### 读法 C（备查）：异说对照读

凡年表中标注"异说/异文"处（杖数、格竹年龄、平濠天数、致良知系年、四句教"是/之"、遗言文本、卒时辰时/午时、隆庆 1567/1568），读时并排打开 [../facts.md](../facts.md) 对应 F 条与 [../references/sources.md](../references/sources.md) 双源核对表，先看各说出处，再看本束取舍口径——本束一律"并列登记、不改字不裁决"。
