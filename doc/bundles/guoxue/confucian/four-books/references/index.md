# 信源参考索引

本目录登记"儒家四书"知识包所依据的文献信源，供概念文档与示例文档溯源引用。信源按三层分档：经文层（原文权威信源）、注疏层（历代注疏）、现代解读层（现代译注与研究）。

| 信源文件 | 内容 | 对应文档层 |
|---------|------|----------|
| [canonical-sources.md](canonical-sources.md) | 原文权威信源：ctext.org《論語》《孟子》《禮記》、zh.wikisource 对应页面、中华书局整理本、定州汉墓竹简《论语》等出土文献（含 URL 表与用途说明） | 经文层 |
| [commentaries.md](commentaries.md) | 历代注疏：何晏《论语集解》、赵岐《孟子章句》、朱熹《四书章句集注》、刘宝楠《论语正义》、焦循《孟子正义》、王阳明《传习录》等（含立场标注表与推荐使用场景） | 注疏层 |
| [modern-studies.md](modern-studies.md) | 现代译注与研究：杨伯峻《论语译注》《孟子译注》、钱穆《论语新解》、李泽厚《论语今读》、海外儒学研究概况（标注取向差异） | 现代解读层 |
| [cross-refs.md](cross-refs.md) | 交叉引用：帛书老子阅读教程、laozi-lineage 老子传本谱系、psi 理论体系，及 confucian 组增量规划 | 元数据/导航 |

## 信源使用说明

- 全部信源 URL 均出自[四书事实清单](../facts.md)（F-001~F-067）及原文底料登记，无虚构链接；未登记信源的条目在各文档中显式标注"未登记"
- 原文采录以 ctext.org 与 zh.wikisource.org 双源一致为标准（F-067）
- 概念文档的事实性陈述均标注 F-xxx 编号，对应 facts.md 登记条目
- 三层文本属性严格区分：经文层/注疏层/现代解读层不混淆（见[四书知识包架构洞察](../insights.md)洞察4）
- 关联的 laozi 域知识包（帛书阅读教程、传本谱系）经 cross-refs.md 互联，与本包构成经典阅读方法论互补
