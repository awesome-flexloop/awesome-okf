## 洞察1：四书是朱熹设计的"入门课程包"，而非自古固有的经典单元

| 四元组 | 内容 |
|--------|------|
| **陈述** | 四书不是先秦既有的经典组合，而是二程表彰、朱熹结集的一次面向学习的"课程设计"：把两部《礼记》单篇（《大学》《中庸》）与两部子书（《论语》《孟子》）升格为经，并明确规定阅读次序——这条次序本身就是一套教学进阶逻辑。 |
| **证据** | F-013（《大学》原为《礼记》第四十二篇）、F-014（《中庸》原为《礼记》第三十一篇）、F-018（二程表彰四书雏形）、F-019（朱熹绍熙元年前后漳州合刻四书）、F-020（《四书章句集注》十九卷结构）、F-023（朱熹定读四书之序：大学定规模→论语立根本→孟子观发越→中庸求微妙）、F-024（元代科举定朱注为标准） |
| **反常识** | 一般以为"四书自古就是儒家核心经典"，实际上四书作为整体只有约八百年历史（以 1190 年漳州合刻计），远晚于十三经格局定型；《孟子》在开成石经（837）中尚未入选（F-004），其经学地位是宋代理学运动升格的结果；四书的"经典性"很大程度由科举制度固化（F-024、F-025），1905 年废科举后它仍作为经典读本流传（F-026），说明结集本身具有超越科举的阅读价值。 |
| **行动** | 以"朱熹设计的入门课程"视角读四书：遵循朱熹次序（先《大学》定规模→《论语》立根本→《孟子》观发越→《中庸》求微妙）理解一条由纲领到义理的进阶路径，而非四本并列随意翻阅；同时意识到这是理学立场的选目——汉唐经学系统的入门路径（五经）与之不同，见 [concepts/00-classics-system.md](concepts/00-classics-system.md)。 |

## 洞察2：历代注疏的正确使用方式是"按阶段与问题选用"而非"依次通读"

| 四元组 | 内容 |
|--------|------|
| **陈述** | 四书积累了两千年注疏层积（何晏集解→皇侃义疏→邢昺疏→朱熹集注→刘宝楠/焦循正义→现代译注），各代注疏服务于不同问题；正确用法是按阅读阶段与问题类型检索选用，而非从汉到清依次通读。 |
| **证据** | F-037（何晏《论语集解》现存最早完整注本）、F-039（皇侃《论语义疏》逐条引诸家）、F-040（邢昺《论语注疏》入十三经注疏）、F-043（朱熹注四书体例分"章句"与"集注"）、F-044（集注汇集二程张载及程门之说）、F-046（刘宝楠《论语正义》）、F-047（焦循《孟子正义》三十卷）、F-049/F-050（杨伯峻译注）、F-052（钱穆《论语新解》）、F-053（中华书局点校本） |
| **反常识** | 一般以为"读古注越多越扎实"，实际上各代注疏功能互补而非层层递进：何晏集解保存汉魏古义、朱熹集注构建理学体系、清人正义做训诂考据、杨伯峻译注面向现代入门。不同注家立场互斥（如王阳明反对朱熹分经补传，F-045），无问题意识的全读只会陷入"公说公有理"的混乱；清人正义动辄数十卷，通读既不可能也不必要。 |
| **行动** | 三阶段选用：入门用一种现代译注（杨伯峻，F-049/F-050）建立文义；进阶读朱熹集注（F-053 点校本）理解义理体系；研究具体章句训诂时再查刘宝楠/焦循正义；王阳明《传习录》作为心学对照立场按专题选读——同一阶段并行不超过 2 家，选用决策树见 [examples/03-reading-plan.md](examples/03-reading-plan.md)。 |

## 洞察3：汉宋注疏分歧没有消失，而是转入了现代译注的取向差异——选译注即选立场

| 四元组 | 内容 |
|--------|------|
| **陈述** | 汉学（训诂求古义）与宋学（义理建体系）对同一文本给出系统性不同的解释；现代译注是这两种路径的当代延续——不存在"零立场"的译注，选择译注实质是选择解释立场。 |
| **证据** | F-011（十三经注疏本《论语》用何晏集解、邢昺疏）、F-043（朱熹章句/集注体例）、F-021（朱熹自言补"格物致知"传）、F-045（王阳明主《大学》古本、反朱熹分经补传）、F-048（戴震《孟子字义疏证》以训诂方法疏证"理""性"诸概念）、F-049/F-050（杨伯峻译注）、F-052（钱穆《论语新解》以朱注为本、兼采众说） |
| **反常识** | 一般以为现代白话译注是"客观中立"的翻译，实际上钱穆《论语新解》明言以朱注为本（F-052），偏宋学义理一系；杨伯峻译注更重训诂语法与历史语境，近汉学路径一系——汉宋分歧并未终结，而是转化为译注取向的分歧。把任一本译注当作"标准答案"，等于暗中接受了一种注疏立场。 |
| **行动** | 关键章句（"克己复礼""格物致知""浩然之气"）至少对照两种立场的解读再下判断；选译注前先读其自序/凡例确认立场取向；把朱熹分经补传与阳明主古本之争（F-021 vs F-045）理解为文本开放性的入口，而非需要消除的障碍——立场标注表见 [references/commentaries.md](references/commentaries.md)。 |

## 洞察4：四书文本是三层叠压（经文/注疏/现代解读），大量"耳熟能详的道理"属注疏层而非经文层

| 四元组 | 内容 |
|--------|------|
| **陈述** | 四书文本实际由三层叠压而成：经文层（先秦文本）、注疏层（汉唐宋清注家构建的解释传统）、现代解读层（当代学者的翻译与重构）；阅读的核心纪律是三层不混淆——引用与讲述时显式标注文本层归属。 |
| **证据** | F-021（朱熹补"格物致知"传一章——补传文字为朱熹自写）、F-022（朱熹分《中庸》为三十三章——分章结构为朱熹所为）、F-045（阳明恢复古本之争）、F-042（旧题孙奭《孟子注疏》朱熹与清儒已疑非孙奭作）、F-034（赵岐判《孟子》外书四篇为伪托）、F-058/F-061/F-062（定州汉简本与今本的系统异文） |
| **反常识** | 一般以为"读四书就是读孔孟原话""朱熹的注释等于经文的一部分"，实际上"格物致知"传文是朱熹补写（F-021），《大学》《中庸》的分章格局是朱熹重构（F-022），今本《论语》文字与定州汉简本存在通假与分章异文（F-061/F-062）——连经文层本身也是历史建构与科举定本固化的产物。三层不分的阅读会把朱熹的理学解读误认为孔子原意。 |
| **行动** | 引用与讲述时显式标注文本层（"《大学》经一章曰…" vs "朱熹补传曰…" vs "杨伯峻译曰…"）；本 bundle 概念文档在每处关键解读标注注家与出处；把"辨认当前读的是哪一层"当作经典阅读素养的核心训练，分层示范见 [examples/01-analects-close-reading.md](examples/01-analects-close-reading.md)。 |

## 洞察5：儒家经典同样需要版本意识——与道家 bundle（think/laozi/）构成方法论互补

| 四元组 | 内容 |
|--------|------|
| **陈述** | 本 bundle 与 think/laozi/ 既有 bundle 构成经典阅读方法论的互补对：laozi-lineage 覆盖版本学/文献学（研究者侧），boshu-reading 覆盖异文对照阅读（读者侧），four-books 覆盖注疏分层与多注家并读（读者侧）——三者共享"双源核对""分层呈现"方法论，应用于不同问题域。 |
| **证据** | F-067（双源一致采录标准）、F-066（原文底料登记文件）、F-063/F-064/F-065（ctext.org 与 zh.wikisource.org 信源结构）、F-058（定州简本释文约为今本之半）、F-061/F-062（简本异文）、F-034（《孟子》外书真伪）、F-045（《大学》古本/改本之争） |
| **反常识** | 一般以为儒家经典"文本稳定、无需版本意识"（与出土本层累流动的《老子》相对），实际上《论语》有定州汉简本的系统异文（F-058/F-061/F-062），《孟子》有外书真伪问题（F-034），《大学》有古本与朱熹改本之争（F-045）——四书文本的"稳定"是科举定本（F-024/F-025）与通行整理本（F-053）人为固化的表象，版本核对对四书同样必要。 |
| **行动** | 已读 laozi bundle 的读者可直接迁移"双源核对"与"异文并列登记"方法；未读者通过本 bundle 的 examples/ 习得同一方法；两域 bundle 经 [references/cross-refs.md](references/cross-refs.md) 互联不重复——laozi 讲"版本怎么流传"，four-books 讲"注疏怎么分层使用"。 |

## 可复用经典阅读模式（G3）

### 模式一：双源核对阅读法

| 要素 | 内容 |
|------|------|
| **触发场景** | 需要引用或讲授任何古籍原文时（尤其要写入文档、教程、引用语料）；两个来源文字出现不一致；涉及异文敏感章句（如《论语》"攻乎异端"，今本与定州简本作"功"，F-062）。 |
| **核心步骤** | ① 选定两个相互独立的权威信源（如 ctext.org 底本页 + zh.wikisource 对应页，F-063/F-065）；② 逐字比对目标段落，登记一致/不一致状态；③ 异文处不作裁决，并列登记"某本作某"+ 信源 URL（F-062 模式）；④ 单源文本显式标注"单源"，禁止合并改动（F-067 标准）；⑤ 核对底料单独登记存档（F-066 模式）。 |
| **反模式** | 只查一个来源就引用；发现异文后凭语感"择优"拼合出一个混合文本；用二手转引（白话译文、公众号文章、教材选本）充当原文；核对完成后丢弃核对记录，导致无法复审。 |
| **迁移示例** | 从四书迁移到《老子》（帛书本/传世本双源对照，见 think/laozi/boshu-reading）；迁移到任何有多个数字化底本的古籍；亦可迁移到非古籍场景——两个官方镜像比对关键配置文档、两版规范对照引用条文。 |

### 模式二：注家分层选用法

| 要素 | 内容 |
|------|------|
| **触发场景** | 阅读注疏传统深厚的经典（四书、五经、《老子》《庄子》）；面对多家互相冲突的解释不知何从；需要引用"解读"而非仅原文；为他人推荐注本或设计阅读路径时。 |
| **核心步骤** | ① 先分层：区分经文层/注疏层/现代解读层，明确当前要解决的是文义问题（训诂）还是义理问题（体系）；② 按阶段选注：入门用 1 种现代译注建立文义（杨伯峻，F-049/F-050），进阶用 1 种体系性古注理解义理（朱熹集注，F-053），专题研究再查考据注（刘宝楠/焦循正义，F-046/F-047）；③ 关键章句强制并读 ≥2 种立场（如朱熹 vs 阳明、汉注 vs 宋注）并标注各家出处；④ 为所用注本记录立场标签（汉学/宋学/心学/考据/现代），形成个人注家索引，见 [references/commentaries.md](references/commentaries.md) 立场标注表。 |
| **反模式** | 试图从古至今通读全部注疏（"读更多注本≠理解更深"）；把任一家注疏（尤其影响最深的一家，如朱熹集注）当作经文本身，导致三层混淆；终身只用一种译注并视其为标准答案；引用解读时不标注注家与出处，使立场伪装成客观。 |
| **迁移示例** | 从四书迁移到《老子》（王弼玄学注/河上公道教注/陈鼓应今注，按阶段选用）；迁移到佛典（各宗判教疏释差异）；亦可迁移到技术领域——官方规范（"经"）、各权威实现文档（"注"）、社区教程（"现代解读"）的三层区分与按问题选用。 |
