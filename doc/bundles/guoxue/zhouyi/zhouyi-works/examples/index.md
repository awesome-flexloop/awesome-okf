# 精读示例索引

本目录提供两类**经传合读**的示范文档，作为从 [text/](../text/index.md) 原文区进入 [commentaries/](../commentaries/index.md) 解读区的桥梁：先给出权威原文（经、传全录或摘引），再并置注家立场，让读者看到"同一句经文，不同立场的读法差异"，而不由本文档代替读者作单一裁决。

- 原文文字以阮元校刻《十三经注疏》本《周易正义》为底本，经 ctext.org（武英殿本）逐字核对，详见 [references/authoritative-editions.md](../references/authoritative-editions.md)。
- 注家立场标签与书目分级见 [references/sources-cross-ref.md](../references/sources-cross-ref.md)，事实断言以 [facts.md](../facts.md) 的 F 编号溯源。
