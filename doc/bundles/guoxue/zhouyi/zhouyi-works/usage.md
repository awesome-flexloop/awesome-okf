# 阅读指南

本知识包聚焦**《周易》经传的原文与解读本体**：今本六十四卦经文以阮刻《十三经注疏·周易正义》为底本（ctext.org 与维基文库双源逐字核对），《系辞》《说卦》《序卦》《杂卦》全录，出土四大文本系统（马王堆帛书、上博楚简、阜阳汉简、王家台秦简《归藏》）分层著录异文；解读三线并收——出土校注、历代注本、现代注本，凡有分歧并列呈现，不做单一仲裁。本文说明如何按需查阅。

## 三级阅读路径

1. **入门（建立经传全貌）**：概念 [名实与经传结构](concepts/01-zhouyi-overview.md) → [核心概念](concepts/03-core-concepts.md) → 精读 [乾坤二卦](examples/qian-kun-jingdu.md)（经传对照最完整的主案例）；注本取黄寿祺、张善文《周易译注》全译打底，立场标签见 [注本分级](references/sources-cross-ref.md)。
2. **进阶（经传合读与义理）**：精读 [代表卦选讲](examples/key-gua-jingdu.md)（泰否、谦、既济/未济、复）→ 传文 [系辞传](text/zhuan-xici.md)、[说卦传](text/zhuan-shuogua.md) → 概念 [十翼结构与归属](concepts/04-shiyi-ten-wings.md) 厘清传文分工；注本取朱熹《周易本义》（占筮本义派）或程颐《伊川易传》（义理派）一路深入。
3. **研究（文本校勘与学术史）**：概念 [文本系统与古三易](concepts/02-text-systems.md)、[历代易学谱系](concepts/05-yixue-lineage.md) → [出土文献异文选录](text/unearthed-variants.md) ＋ [权威底本与电子双源](references/authoritative-editions.md) → [权威解读](commentaries/index.md) 三线并收 ＋ [争议与不确定性](commentaries/controversies.md)；注本按下方决策树的象数路径或古史辨/出土路径进入汉易与出土文献研究。

## 注本选用决策树

- **入门通读**：黄寿祺、张善文《周易译注》（`huang-zhang-yizhu`，全译、门槛低）→ 朱熹《周易本义》（`zhu-zhuxi-benyi`，回到占筮本义的简明古注）。
- **义理路径**：程颐《伊川易传》（`cheng-yichuan`）→ 孔颖达《周易正义》/ 王弼、韩康伯注（`kong-zhengyi`/`wangbi-hankangbo`）→ 金景芳、吕绍刚《周易全解》（`jin-lv-quanjie`）。
- **象数路径**：李鼎祚《周易集解》（`li-dingzuo-jijie`，汉易集解）→ 刘大钧《周易概论》（`liu-dajun-gailun`）→ 惠栋《周易述》/ 张惠言《周易虞氏义》（`hui-dong-shushi`/`zhang-huiyan-yushi`）。
- **古史辨/出土路径**：高亨《周易古经今注》＋《周易大传今注》（`gao-gujing`/`gao-dazhuan`，离传解经）→ 李镜池《周易通义》（`li-jingchi-tongyi`）→ 廖名春新论（`liao-mingchun-xinlun`）/ 李零《死生有命 富贵在天》（`li-ling-ziran`）与出土整理本。
- **学术史定位**：朱伯崑《易学哲学史》（`zhu-boxuan-zhexueshi`，通史）＋ 概念 [历代易学谱系](concepts/05-yixue-lineage.md)。

完整书目、成书信息与立场标签见 [注本分级与交叉引用](references/sources-cross-ref.md)。

## 信源溯源方法

- 正文事实性论断以脚注 `[^source-id]` 溯源，ID 对应 [信源登记簿](references/index.md) 的信源清单；每条信源含可核查 `resource`（出版社·年份）。
- 经文与所录传文以阮刻本为文字基准，经 `ctext-zhouyi` 与 `wikisource-zhouyi` 双源逐字核对，核对方法见 [权威底本与电子双源](references/authoritative-editions.md)。
- 出土释文一律溯源自正式出版整理本，残损处显式标注，不编造；电子文本（C 级）仅用于逐字核对与线索，不单独支撑事实结论。

## 使用注意

- 经文上下篇（text/jing-shang.md、text/jing-xia.md）**待补**：六十四卦卦爻辞全本尚未转录；乾、坤二卦经文随 [乾坤二卦精读](examples/qian-kun-jingdu.md) 完整收录，其余各卦卦爻辞可经 ctext.org 与维基文库逐卦查阅（入口见 [经传原文区](text/index.md)）。
- 《彖传》《象传》《文言传》不在原文区整篇全录：乾坤部分随 [乾坤二卦精读](examples/qian-kun-jingdu.md) 经传合读完整收录，其余各卦经双源电子文本逐卦查阅（分页指引见 [text/index.md](text/index.md)）。
- 出土文献部分为**分层著录＋选录**（非全本转录），帛书卦序、楚简残字等异文以 [出土文献异文选录](text/unearthed-variants.md) 为准，残毁处标注，不编造释文。
- 注家立场在解读文档中**并置**呈现，本包不做单一仲裁；成书年代、十翼归属、卦序、性质之争见 [争议与不确定性](commentaries/controversies.md)。
- 字形与爻题体例（规范汉字、"无咎"用"无"、初九/六二自下而上等）见 [text/index.md](text/index.md) 的底本与体例说明。
