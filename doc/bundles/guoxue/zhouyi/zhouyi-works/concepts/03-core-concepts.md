# 核心概念

## 阴阳

阴阳是《周易》最基本的符号与哲学范畴。爻以阴阳立名：阳爻称"九"、阴爻称"六"[^facts-004]。就符号言，阳爻以一道直线（—）为象，阴爻以两短横（--）为象。

《易传》把阴阳提升为贯通天人的法则。《系辞传》以"一阴一阳之谓道"概括，直接赋予阴阳以本原性的哲学地位。需注意《易传》的阴阳哲学与战国阴阳家（如邹衍）的阴阳五行学说属于不同流派，《易传》阴阳观与阴阳家的关系详见 `think/yinyangjia` 的专题，此处仅说明《易传》立场。

## 八卦

八卦为最基本的经卦，各以三爻组成，即：乾、坤、震、巽、坎、离、艮、兑。其象义系统见《说卦传》——"乾健坤顺、震动巽入、坎险离丽、艮止兑说"[^facts-112]，并载有各类取象（天、地、雷、风、水、火、山、泽等）与八卦方位（"天地定位"章、"帝出乎震"章）[^facts-112]。

八卦方位与次序在易学史上衍生出先天（伏羲）图、后天（文王）图两套体系（详见 [历代易学谱系](05-yixue-lineage.md) 的宋易图书一节），二者说解不同，本文档不执一端。

## 六十四卦

八卦两两相重即得六十四卦（六十四别卦），每卦六爻。经文六十四卦合计三百八十四爻，乾另附"用九"、坤另附"用六"[^facts-002]。六十四卦分上下两篇：上经三十卦、下经三十四卦[^facts-003]。

卦序关系古有两类说明：

- **《序卦传》**：按通行本卦序解说六十四卦前后相次之义[^facts-113]。
- **《杂卦传》**：以错杂方式两两对举卦义[^facts-113]。

此外通行本卦序有"两两相耦、非覆即变"的现象结构（每两卦一正一倒或相反），此属文本观察，非单一学派断言。

## 卦爻辞体例

经文由卦辞与爻辞构成：卦辞总论一卦之大义，爻辞按六爻位逐一论断吉凶。卦辞所断对象传统上以"彖"称之（"彖"本指断卦之辞），《彖传》即释此；爻辞则按六位断一爻之吉凶[^facts-110]。

爻题体例：自下而上为初、二、三、四、五、上；阳爻题"九"、阴爻题"六"[^facts-004]。经文文字的具体校读以今本（阮刻）与出土各系统的异文对照为准，见 [文本系统与古三易](02-text-systems.md)。

## 象数

"象"指卦象、爻象（卦画的象征系统），"数"指与卦画相配的筮数（四象、六十四卦之数、大衍之数等）。象数之学以卦象爻位解释经传、推衍天道人事，是汉代易学的主干[^facts-114]。

象数与义理两派的关系：汉代以象数为主（孟喜、京房、郑玄、荀爽、虞翻，见 [历代易学谱系](05-yixue-lineage.md)），魏晋王弼起转向义理、扫落汉象数。后世"象数、义理、图书、占筮"诸家分立，本 bundle 在 [历代易学谱系](05-yixue-lineage.md) 中分层并置。

## 时位

"时"与"位"是《易》学分析卦爻的两大概念：

- **时（卦时）**：一卦所处之时势，六爻共处一"时"，用以论一卦之总境。
- **位（爻位）**：爻所处之位，含地位的尊卑、中正与否（如二、五为中，三、四为多惧之地），爻位与爻象相合可断吉凶。

"卦时"与"爻位"结合是汉以降象数派与义理派共通的分析框架，其具体条例在各家注本中或有出入，本文档只述其一般义。

## 占筮与大衍之数

《周易》本为卜筮之书，占筮是用蓍草揲数取卦以断吉凶的活动。《系辞传》载明占筮的基本数理框架：

> 大衍之数五十，其用四十有九[^facts-111]

其操作程序为分二、挂一、揲四、归奇[^facts-111]，经三变而成一爻，十八变而成一卦。"大衍之数五十"一章的帛书异文情况见 [文本系统与古三易](02-text-systems.md)[^facts-028]。

对《周易》性质有"卜筮之书"与"义理之书/哲学之书"的立场分歧：

- 朱熹主"《易》本卜筮之书"，强调占筮本义[^facts-096]（其编排亦恢复经传分列古本）。
- 义理派与经学家侧重于经传的哲学义涵，视占筮为历史背景而非核心。
- 现代学者或从"古史辨"视卦爻辞为上古筮辞与史料（如高亨[^sources-gao]），或以方术史为背景重建其读法（如李零）。

本文档并置上述立场，不执单一是非。
