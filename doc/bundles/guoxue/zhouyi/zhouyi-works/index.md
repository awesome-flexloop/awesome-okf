# 周易著作（权威原文与三线解读）

本知识包（bundle）聚焦**《周易》经传的原文与解读本体**：经文以阮刻《十三经注疏·周易正义》为底本提供六十四卦全本，经 [ctext.org](https://ctext.org/book-of-changes/zh) 与 [维基文库](https://zh.wikisource.org/wiki/周易) 双源逐字核对；十翼选录《系辞》《说卦》《序卦》《杂卦》全文，《彖》《象》《文言》随乾坤精读完整呈现；出土文献（马王堆帛书、上博楚简、阜阳汉简、王家台秦简《归藏》）以存佚分层方式著录并选录关键异文；解读三线并收——出土校注（文本层）、历代注本（义理/象数层）、现代注本（综合层），凡有分歧并列呈现，不做单一仲裁。

与既有 bundle 互补：`think/confucius/works` 处理"孔子与六经关系"（含韦编三绝、十翼归属），`think/yinyangjia` 处理邹衍阴阳家辑佚；本 bundle 侧重《周易》「原文 + 解读」本身。

## 原文与解读策略

- **经文基准**：阮元校刻《十三经注疏》本《周易正义》（魏·王弼、晋·韩康伯注，唐·孔颖达等疏），经文部分与 ctext.org、维基文库双源逐字核对。
- **传文范围**：《系辞》上下、《说卦》《序卦》《杂卦》全录；《彖》《象》《文言》随乾坤精读全录，余卦传文给出权威电子信源指引。
- **出土文献**：只著录与选录——四大文本系统的存佚范围、卦序差异与关键异文，释文片段全部溯源正式整理本，残损处显式标注，不编造。
- **解读三线**：出土校注（文本层）→ 历代注本（义理/象数层）→ 现代注本（综合层），分歧显式化。
