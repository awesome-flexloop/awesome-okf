## 一、经传结构与名实事实

| 编号 | 事实内容 |
|------|---------|
| F-001 | 《周易》文本分"经"与"传"两部分；"经"指六十四卦卦辞与爻辞，"传"指解释经文的十篇文献（十翼） |
| F-002 | 经文共六十四卦，每卦六爻，合计三百八十四爻；乾卦另附"用九"一条，坤卦另附"用六"一条 |
| F-003 | 六十四卦分上下两篇：上经三十卦（乾、坤、屯、蒙、需、訟、師、比、小畜、履、泰、否、同人、大有、謙、豫、隨、蠱、臨、觀、噬嗑、賁、剝、復、无妄、大畜、頤、大過、坎、離），下经三十四卦（咸、恆、遯、大壯、晉、明夷、家人、睽、蹇、解、損、益、夬、姤、萃、升、困、井、革、鼎、震、艮、漸、歸妹、豐、旅、巽、兌、渙、節、中孚、小過、既濟、未濟） |
| F-004 | 爻题自下而上排列，依次为初、二、三、四、五、上；阳爻题"九"、阴爻题"六"，如"初九""六二""上九""上六" |
| F-005 | 十翼为七种十篇：《彖传》上、《彖传》下、《象传》上、《象传》下（大象释卦、小象释爻）、《系辞传》上、《系辞传》下、《文言传》、《说卦传》、《序卦传》、《杂卦传》 |
| F-006 | 《汉书·艺文志》六艺略著录"《易经》十二篇，施、孟、梁丘三家"，并载"《易》道深矣，人更三圣，世历三古"之说 |
| F-007 | "人更三圣"传统说以伏羲画八卦、周文王重卦并作卦辞、周公作爻辞、孔子作十翼为基本框架 |
| F-008 | 通行本经文以三国魏王弼、晋韩康伯注、唐孔颖达等疏《周易正义》系统流传，阮元校刻《十三经注疏》本为清代以后通行底本 |
| F-009 | ctext.org（中国哲学书电子化计划）收录《周易》全文，标注底本为《武英殿十三经注疏》本《周易正义》，并列《阮元校刻十三经注疏》本等影印资源；网址 https://ctext.org/book-of-changes/zh |
| F-010 | 维基文库收录《周易》经传全文，按卦与传分页面；网址 https://zh.wikisource.org/wiki/周易 |
| F-011 | 《周礼·春官·大卜》载"掌三易之法：一曰《连山》，二曰《归藏》，三曰《周易》"，并称"其经卦皆八，其别皆六十有四" |
| F-012 | 古三易中今仅《周易》完整传世；《连山》无存，《归藏》有清人辑本与王家台秦简出土文本（见 F-060 以下） |
| F-013 | 北宋欧阳修《易童子问》首次系统质疑《系辞传》《文言传》等非孔子一人所作，提出"众说淆乱"之辨 |
| F-014 | 张政烺《试释周初青铜器铭文中的易卦》（《考古学报》1980年第4期）将商周甲骨、青铜器上的"奇字"论证为"数字卦"，即以五六七八九等数字记录占筮所得卦象 |
| F-015 | 清华大学藏战国竹简有《筮法》《别卦》等易筮类文献（《清华大学藏战国竹简（肆）》，中西书局2013年），属占筮方法资料，不属《周易》经传本文 |

## 二、马王堆帛书《周易》事实

| 编号 | 事实内容 |
|------|---------|
| F-020 | 马王堆帛书《周易》于1973年在湖南长沙马王堆三号汉墓出土，墓葬下葬于汉文帝前元十二年（前168年） |
| F-021 | 帛书《周易》抄写于西汉文帝初年，字体为汉隶 |
| F-022 | 帛书经文篇题作《六十四卦》，共93行、约4900余字，首尾基本完整 |
| F-023 | 帛书卦名多用通假字，如"乾"作"键"、"坤"作"川"、"艮"作"根"、"兑"作"夺" |
| F-024 | 帛书《六十四卦》卦序与通行本不同，按六爻卦变（八宫体系）排列，学者称"帛书卦序" |
| F-025 | 帛书《周易》传文共六种：《二三子问》《系辞》《易之义》（又称《衷》）《要》《缪和》《昭力》 |
| F-026 | 《二三子问》共36行、约2500字，以"二三子问"与"孔子曰"问答体说《易》 |
| F-027 | 帛书《系辞》共47行、约3000字，不分上下篇，内容包含今本《说卦传》前三章 |
| F-028 | 今本《系辞上传》"大衍之数五十"一章不见于帛书《系辞》 |
| F-029 | 《易之义》（《衷》）约45行、3000余字；《要》篇篇末有题记"《要》，千六百卌八" |
| F-030 | 帛书《周易》经文释文首次公布于《文物》1984年第3期，同期载于豪亮《帛书〈周易〉》、张政烺《帛书〈六十四卦〉跋》 |

## 七、历代注本事实

| 编号 | 事实内容 |
|------|---------|
| F-090 | 王弼（226—249）著《周易注》，主扫象数、阐义理，开魏晋玄学解《易》风气；其注未及《系辞》以下传文 |
| F-091 | 韩康伯（332—380）续注《系辞传》《说卦传》《序卦传》《杂卦传》，与王弼注合为通行注本系统 |
| F-092 | 唐孔颖达（574—648）等奉敕撰《周易正义》（一名《周易注疏》），以王弼、韩康伯注为底本作疏，为唐代科举官学标准本 |
| F-093 | 清阮元（1764—1849）主持校刻《十三经注疏》（嘉庆年间南昌府学本），《周易正义》列为第一种；中华书局1980年影印阮刻本为现代通行影印本 |
| F-094 | 唐李鼎祚撰《周易集解》，博采汉魏至唐三十五家《易》说（以荀爽、虞翻、郑玄等汉儒为主），为保存汉代象数易学最主要的文献 |
| F-095 | 北宋程颐（1033—1107）著《伊川易传》（《周易程氏传》），成书于绍圣间谪居涪陵时，为义理派《易》学代表作 |
| F-096 | 南宋朱熹（1130—1200）著《周易本义》（成书于淳熙年间），强调"《易》本卜筮之书"，恢复经传分列的古本编排 |
| F-097 | 清李光地（1642—1718）等奉敕编纂《周易折中》，康熙五十四年（1715年）成书，以程颐《伊川易传》、朱熹《周易本义》为主，兼采历代诸家 |
| F-098 | 清代朴学复兴汉易，代表著作有惠栋《周易述》、张惠言《周易虞氏义》（专研虞翻象数之学） |

## 九、文本制度与学术史事实

| 编号 | 事实内容 |
|------|---------|
| F-110 | 《周易》经文卦辞称"彖曰"所释对象（"彖"本指断卦之辞），爻辞按六位断一爻之吉凶 |
| F-111 | 《系辞传》载"大衍之数五十，其用四十有九"，记述揲蓍占筮的分二、挂一、揲四、归奇程序 |

| F-113 | 《序卦传》按通行本卦序解说六十四卦前后相次之义；《杂卦传》以错杂方式两两对举卦义 |
| F-114 | 汉代象数易学代表人物有孟喜、京房（卦气说、纳甲、八宫卦序）、郑玄（爻辰）、荀爽、虞翻（卦变、之正） |
| F-115 | 宋代图书易学以陈抟、邵雍为代表，传先天图、后天图、河图洛书之说；程颐主义理、朱熹兼收图书与占筮 |
| F-116 | 1973年马王堆帛书、1977年阜阳汉简、1993年王家台秦简、1994年上博楚简等出土文献构成《周易》文本研究的"出土系统"，与传世"今本系统"相对 |
