## 三、选用建议（详见 [usage.md](../usage.md)）

- **入门通读**：`huang-zhang-yizhu`（全译，门槛低）→ `zhu-zhuxi-benyi`（回到占筮本义的简明古注）。
- **义理路径**：`cheng-yichuan` → `kong-zhengyi`/`wangbi-hankangbo` → `jin-lv-quanjie`。
- **象数路径**：`li-dingzuo-jijie`（汉易集解）→ `liu-dajun-gailun` → `hui-dong-shushi`/`zhang-huiyan-yushi`。
- **古史辨/出土路径**：`gao-gujing`＋`gao-dazhuan` → `li-jingchi-tongyi` → `liao-boshu-lunji`/`li-ling-ziran` 与出土整理本。
- **学术史定位**：`zhu-boxuan-zhexueshi`（通史）＋本 bundle [concepts/05-yixue-lineage.md](../concepts/05-yixue-lineage.md)。

## 五、信源可靠性分级

- **A 级（一手/底本）**：`ruan-ke-shisanjing`、`wuying-dian`、出土整理本 `zhang-jiaodu`/`shangbo-3`/`han-fuyang`/`wang-wangjiatai`/`qiu-jicheng`、历代原注本 `wangbi-hankangbo`/`li-dingzuo-jijie`/`cheng-yichuan`/`zhu-zhuxi-benyi`/`li-guangdi-zhezhong`。
- **B 级（权威现代整理/研究）**：`beida-zhengli`、`gao-gujing`/`gao-dazhuan`、`huang-zhang-yizhu`、`zhu-boxuan-zhexueshi`、`liao-boshu-lunji` 等。
- **C 级（电子/网络，仅核对或线索）**：`ctext-zhouyi`、`wikisource-zhouyi`、`chen-chutu-xingtai`、`sun-peiyang-guaxu`。电子文本用于逐字核对，网络论文用于数据互勘，均不单独支撑事实结论。
