# 周易（Zhouyi）知识包

本目录收录与《周易》相关的 OKF 知识包。《周易》本为占筮之书，经孔子与儒家后学作《易传》（十翼）阐发义理，汉以后列为"群经之首"，是儒家经学、道家思想与阴阳数术之学的共同文本源头。本组知识包以「经文全本 + 十翼选读 + 出土文献异文 + 三线注本」为组织基调，原文以阮刻《十三经注疏·周易正义》为底本并经双源电子文本核对，分歧并列不仲裁。
