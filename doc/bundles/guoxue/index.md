# 📜 国学

本域按广义国学收录中国传统学术整体的知识包：经史子集四部、中国化佛学（汉传佛教经典）与中国传统算学。覆盖儒家（四书与孔子著作）、道家（老庄与道家全谱系）、墨家、法家、阴阳家、纵横家（鬼谷子）、周易与河图洛书图书学、黄帝经典、佛家核心经典、王阳明心学与中国算经阅读教程。

**收录边界**：中国传统学术整体归入本域；西方数学经典归 [科学](../kexue/index.md) 域；中医典籍归 [医学与养生](../yixue/index.md) 域；现代学科著作（性学、社会学等）归 [社会科学](../sheke/index.md) 域。
