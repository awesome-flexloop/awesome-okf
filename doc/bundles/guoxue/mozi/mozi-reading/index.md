# 墨子（Mozi）研读教程

本知识包（bundle）提供《墨子》最权威真实原文与中文解读。《墨子》原七十一篇，今存五十三篇，是墨家学派的思想总集，涵盖"兼爱、非攻、尚贤、尚同、节用、节葬、非乐、非命、天志、明鬼"十论核心主张、墨经中的逻辑与科学（光学、力学、几何学）、城守兵学，以及大量语录与历史轶事。

本 bundle 坚持"文本分层诚实呈现"：正文严格以中国哲学书电子化计划（ctext）《墨子》全文与孙诒让《墨子间诂》双源核对，凡存疑、脱文、讹误处均如实标注，不臆测不改写，把"原文是什么"与"我们如何解读"明确分开。
