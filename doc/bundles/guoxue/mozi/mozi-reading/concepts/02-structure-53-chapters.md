## 二、十论与《非儒》（存 23 + 存 1）

「十论」即尚贤、尚同、兼爱、非攻、节用、节葬、天志、明鬼、非乐、非命（F-030），原各分上中下三篇，合 30 篇；因亡佚 7 篇现存 23 篇，上中下文字大致「其旨固无大殊」（F-031）。存篇提要如下：

| 篇名 | 卷次 | 一句话提要 |
|------|------|-----------|
| 尚贤上／中／下 | 卷二 | 任人唯贤、崇尚贤才（F-034）。 |
| 尚同上／中／下 | 卷三 | 追求上同于天、统一天下意志（F-035）。 |
| 兼爱上／中／下 | 卷四 | 「兼相爱、交相利」，爱人若爱其身，无亲疏差等（F-036）。 |
| 非攻上／中／下 | 卷五 | 反对为私利发动的不义战争，主张「救守」防御（F-037）。 |
| 节用上／中 | 卷六 | 节约用度，反对奢侈浪费（F-038）。 |
| 节葬下 | 卷六 | 反对厚葬久丧（F-039）。 |
| 天志上／中／下 | 卷七 | 以天为最高意志与行为准则（F-040）。 |
| 明鬼下 | 卷八 | 主张鬼神存在、能赏善罚暴（F-041）。 |
| 非乐上 | 卷八 | 反对繁复礼乐（F-042）。 |
| 非命上／中／下 | 卷九 | 反对命定论，强调人为努力（F-043）。 |
| 非儒下 | 卷九 | 批评儒者之篇；具体条文 facts 未收录，待考（《非儒》属第二组，F-026）。 |

> 文本分层提示：十论「上中下」三篇对应墨家三派传本（相里氏／相夫氏／邓陵氏，据《韩非子·显学》F-044），非墨子一人三写；详见 [十论核心思想](03-ten-doctrines.md)。

## 三、墨经六篇（6 篇，均存）

| 篇名 | 卷次 | 一句话提要 |
|------|------|-----------|
| 经上、经下 | 卷十 | 「经」文，与《经说》相配，广义墨经之一（F-047）。 |
| 经说上、经说下 | 卷十 | 「说」文，解说经文（鲁胜「引说就经」「各附其章」，F-022）。 |
| 大取、小取 | 卷十一 | 广义墨经中论「取」之篇（F-047）。 |

墨经六篇着重墨家认识论与逻辑思想，兼含几何、光学、力学等自然科学内容，多认为反映后期墨家思想（F-048）——此属**后期墨家层**，非墨子自著（详见 [墨经逻辑与科学](04-mohist-canons.md)）。
