# 📜《史记》人物（Shiji Figures）知识包总纲

本分组补「经史子集」中**史部人物列传**的缺口：以《史记》列传为文本母体，以《汉书》异史与《资治通鉴》编年为对读层，逐人整理为可核查、可迁移的人物研读知识包。首束为西汉汲黯——一个在「黄老无为」向「儒术独尊 + 文法吏治」转型期坚持旧治理范式与直谏伦理的样本。

## 判读口径（贯穿全分组）

1. **原文双源核对**——入库古文均经至少两个独立数字化文本（ctext.org、古诗文网、24histories、识典古籍等）逐字核对；底本注明。
2. **异史并置**——《史记》与《汉书》《资治通鉴》同记一事而文异者，逐条登记，不擅改、不静默统一。
3. **史评分离**——「太史公曰」「赞曰」属史家评论层，与叙事层分栏呈现；今人评价再单列一层。
4. **形象层累标记**——地方纪念、廉洁教育、网络转述中的新增细节，标注「不见于正史」，不与原文混同。
5. **年代分级**——原文有明确纪年者标「原文」；由制度/人物关系推得者标「推算」；仅见于地方叙事者标「地方口径」。
