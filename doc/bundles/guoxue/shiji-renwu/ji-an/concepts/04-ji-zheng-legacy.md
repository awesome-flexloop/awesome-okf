# 合传与流变——郑当时、太史公与「卧治」形象

## 一、合传不是拼盘：为什么汲黯要和郑当时同传

《史记》卷一百二十题为《汲郑列传》，先写汲黯，次写郑当时，末以「太史公曰」收束。三人（含太史公）构成一个完整的意义结构：

```
汲黯：面折、抗礼、逆势直言 ——「刚」的一面
郑当时：推士、廉平、趋和承意 ——「柔」的一面
太史公曰：翟公署门、宾客聚散 ——「交道」的史论
```

合传的共同点，司马迁在传末点明：

> 「郑庄、汲黯始列为九卿，廉，内行修洁。此两人中废，家贫，宾客益落。及居郡，卒后家无余赀财。」（F37）

四个共同标签：**九卿、廉、中废、家贫**。再加上「宾客益落」，合传的主题就从「两个好官」转为「势利之交的可验性」——这才是《汲郑列传》的真正题眼。

## 二、郑当时：汲黯的镜像

| 维度 | 汲黯 | 郑当时 |
|------|------|--------|
| 性格 | 性倨、面折、不能容人之过（F11） | 以任侠自喜，慕长者如恐不见（F33） |
| 待人之道 | 合己者善待，不合者不能忍见（F11） | 客至无贵贱无留门者；未尝名吏，若恐伤之（F35） |
| 朝堂风格 | 面触、非毁、逆势直言（F17、F18） | 「常趋和承意，不敢甚引当否」（F36） |
| 举荐 | 未见系统推士记载 | 推毂士及官属丞史，常引以为贤于己（F35） |
| 共同点 | 廉、内行修洁、中废、家贫、卒后无余财（F37） | 同左 |

郑当时的家世也有一段硬骨：其先郑君事项籍，高祖令故项籍臣「名籍」，郑君独不奉诏，被逐，死于孝文时（F32）。这段「不奉诏」的家族记忆，与汲黯的「不拜」「面折」形成隐约呼应。

郑当时的仕途：太子舍人→鲁中尉→济南太守→江都相→右内史（九卿）→詹事→大农令；晚节因宾客为大农僦人多逋负，被司马安发其事，赎为庶人，后为汝南太守，数岁以官卒（F34、F36）。

> 一个刚而折，一个柔而推；一个当面顶撞，一个背后补台。太史公把两人并列，不是为了说「刚好柔坏」或「柔好刚坏」，而是说：**两种做人都逃不过「势去客散」的同一结局**。

## 三、太史公曰：翟公署门与「交情」三句

传末引下邽翟公故事：

> 始翟公为廷尉，宾客阗门；及废，门外可设雀罗。翟公复为廷尉，宾客欲往，翟公乃大署其门曰：「一死一生，乃知交情。一贫一富，乃知交态。一贵一贱，交情乃见。」（F38）

太史公接一句：「汲、郑亦云，悲夫！」（F38）

这段史论的力量在于**用两个人的一生验证一句门榜**：

- 「一死一生」——汲黯、郑当时都经历过「中废」与「复用」，宾客随之聚散；
- 「一贫一富」——两人都廉，家无余财，宾客益落；
- 「一贵一贱」——都从九卿落到郡守、庶人，交态立见。

因此，读《汲郑列传》若只读汲黯的直谏故事，会漏掉半篇文章；太史公真正要写的，是**权力—交情—人格的三元关系**。

## 四、汉书赞语：四个人的四种德性

《汉书·张冯汲郑传》赞曰：

> 「张释之之守法，冯唐之论将，汲黯之正直，郑当时之推士，不如是，亦何以成名哉！」（F39）

班固把汲黯的核心德性定为「正直」，把郑当时定为「推士」。这与《史记》的「廉—中废—宾客」主题不同：**《史记》写命运，《汉书》写德性**。两书对读，能看到同一组人物在不同史学旨趣下的不同剪裁。

## 五、后世流变：从「直臣」到「卧治」符号

### 5.1 正史层（可作史实）

- 汲黯以黄老之术治东海、淮阳，东海大治、淮阳政清（F9、F28）；
- 淮阳之任，武帝曰「卧而治之」（F26）；
- 卒后家无余财，弟、子、表亲皆至高位（F31、F37）；
- 葬地：地方纪念文章称葬于今河南郸城汲冢镇（F42）。

### 5.2 编年与学术层（可作解释）

- 《资治通鉴》把淮阳之任系于元狩五年（前 118），并作「十岁而卒」（F25、F29）；
- 现代研究把汲黯定位为「黄老之术到儒术独尊转变过程中的典型人物」：治政用黄老、为臣守儒家大义，武帝对其「既欣赏又疏远」（F41）。

### 5.3 地方纪念层（只能作流变证据）

周口地方纪念文章增加了大量正史未载的细节：

| 细节 | 正史有无 | 性质 |
|------|----------|------|
| 河内火灾系于建元六年（前 135） | 《史记》无纪年 | 地方系年 |
| 「宁可获罪于天，不可愧对苍生」 | 不见于《史记》《汉书》 | 后世拟语 |
| 题诗「太守府门朝南开，无理有钱莫进来」 | 不见于正史 | 廉洁教育叙事 |
| 悬印梁上、卧榻听讼、开木窗通街巷 | 不见于正史 | 形象化演绎 |
| 微服出访、惩办贪官、处决私铸要犯 | 不见于正史 | 清官模板 |
| 卒于元鼎五年（前 112） | 由「七岁而卒」推算 | 推算口径 |
| 「在淮阳十年」 | 与《史记》「七岁」冲突 | 地方口径 |

> **判读规则**：这些细节不是「假的」，而是**后世记忆的产物**。它们证明汲黯形象在地方文化中已被重构为「清官—廉吏—爱民者」符号；但引用时必须标注「不见于正史」，不能倒推为汉代史实。

### 5.4 网络转述层（需最谨慎）

常见问题有三类：

1. 把「社稷之臣」的评价挪到矫制发粟之后（原文是庄助答问后武帝语，F15）；
2. 把「上默然，不许」改写成「武帝最终改变做法」（《史记》原文为「不许」，F24）；
3. 把「七岁而卒」直接写成「前 112 年卒」，不交代《汉书》《通鉴》的「十岁」异说（F29）。

## 六、典故小词典

| 典故 | 出处原文 | 今义 |
|------|----------|------|
| 后来者居上 | 「陛下用群臣如积薪耳，后来者居上」（F22） | 后起者超越前人；原含有功旧臣的不平 |
| 门可罗雀 | 翟公「门外可设雀罗」（F38） | 失势后宾客稀少 |

| 社稷之臣 | 武帝「古有社稷之臣，至如黯，近之矣」（F15） | 关系国家安危的重臣 |

| 刀笔吏不可为公卿 | 汲黯斥张汤（F17） | 对以文牍苛细取宠者的批评 |

## 七、评价的边界：三个不要

1. **不要把汲黯写成「反儒」**：他反对的是「怀诈饰智以阿人主取容」的儒生做派，不是儒家义理本身；现代研究甚至认为他「为臣之道恪守儒家大义」（F41）。
2. **不要把他写成「完美清官」**：《史记》明写「褊心」「不能容人之过」「士亦以此不附」（F11、F22）。
3. **不要把他写成「无为即躺平」**：「卧治」前有「择丞史」、后有「政清」，是一套有验收标准的治理方法（详见 [黄老治术](02-huanglao-governance.md)）。
