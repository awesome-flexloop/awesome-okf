# 生平与仕宦年表

## 一、先给结论：一条「中央—地方—中央—地方」的钟摆线

汲黯的仕途不是直线上升，而是四次进入权力中心、三次被推离：

```
太子洗马（东宫旧臣）→ 谒者（皇帝近使）→ 荥阳令（耻为令，病归）
→ 中大夫（近臣）→ 东海太守（外放）→ 主爵都尉（九卿）
→ 右内史（京畿要职）→ 免官隐田园 → 淮阳太守（外放终老）
```

每一次「离开中心」都与直谏有关，每一次「回到中心」都靠治理绩效与旧臣资望。理解这条钟摆线，比记住单个年份更重要。

## 四、三个结构性观察

### 4.1 三次「离开中心」，理由各不同

1. **东海之放**：由中大夫外放太守，直接原因是「数切谏，不得久留内」（F8）——近臣位置容不下高频异议。
2. **右内史之调**：表面是「非素重臣不能任」的重用，实由公孙弘建言；《史记》明写「弘、汤深心疾黯……欲诛之以事」（F18、F19）——这是**用难题岗位消化异己**。
3. **淮阳之任**：免官隐居数年后被重新起用，武帝明说「顾淮阳吏民不相得，吾徒得君之重」（F26）——这是**危机驱动的复用**，不是政治平反。

### 4.2 每次外放都留下治理绩效

东海「岁余大治」，淮阳「政清」（F9、F28）。这说明汲黯的治术是**可移植的**：不依赖特定辖区、不依赖皇帝宠信，靠的是择人授权与抓大放小。反过来，这也解释了他为何反复被外放却始终不被弃置——朝廷需要他的治理能力，但不需要他的朝堂声音。

### 4.3 「不得久居位」是常态，不是意外

《史记》在性格段末句直接写：「亦以数直谏，不得久居位。」（F11）年表里每一次职位变动，几乎都能在这句话下找到解释。读年表时若只记「某年某官」，会漏掉这条贯穿性的结构。

## 五、年表使用说明

- 引用年份时，优先写「元狩五年（前 118）」这类双标注，并注明是《资治通鉴》系年；《史记》本传多数事件无绝对纪年。
- 看到「建元六年（前 135）河内火灾」时，要知道这是地方纪念文章的系年，正史只记事件不记年（F5、F6）。
- 看到「元狩二年（前 121）浑邪王降」时，可引《汉书·武帝纪》系年，但《史记》本传本身不系年（F23）。
- 卒年引用必须带口径：「《史记》七岁而卒（约前 112）」或「《汉书》《通鉴》十岁而卒（约前 109）」，不要写成一个无来源的确定年份。
