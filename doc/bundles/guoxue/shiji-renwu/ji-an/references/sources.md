## 四、引用规则

1. **原文引用**：以 R1 为主，R2/R3 逐字核对；《汉书》异文用 R4/R5。引用格式示例：「《史记》卷一百二十《汲郑列传》：『……』（F9）」。
2. **年代引用**：本传无年的事件，不得径写公历年份；确需年代时注明「《资治通鉴》系元狩五年（前 118）」或「地方口径系建元六年（前 135）」。
3. **二手叙事**：R7/R8/R12 的细节，一律加「地方纪念叙事」「不见于正史」标注，禁止与 A 级材料混排。
4. **学术观点**：R9 作「现代研究认为」引用，不写成「史实如此」。
5. **异文处理**：同一事有字句差异时，正文取一源并出注，另源列入[异文对勘](textual-variants.md)，不静默统一。

## 五、已知限制

- 《史记》本传多数事件无绝对纪年，年表中的「推算」项依赖制度与人物任期，存在误差区间。
- 汲黯生年无载，任何「享年」表述都只能是推算。
- ctext.org 的单节接口存在反爬限制，引用时以主页面 URL 为准，不引用被拦截节点的内容。
- 地方纪念文章的系年（如建元六年河内火、元狩二年浑邪王降）与正史事件可对应，但年份本身不见于本传，使用时须标级别。
