# 史记/汉书/资治通鉴异文对勘

> 对勘底本：《史记》以 R1（ctext 武英殿本）为主，R2/R3 核对；《汉书》以 R4（古诗文网）为主，R5（国学大师）核对；《资治通鉴》用 R6（含胡三省注）。
> **原则**：异文登记不改字；正文取一源并出注；不据异文擅改原文；避讳解释只作参考，不作校改依据。

## 二、逐条说明

### V1 七世 / 十世

- 《史记》：「至黯七世，世为卿大夫。」
- 《汉书》：「至黯十世，世为卿大夫。」
- **说明**：两书对汲氏世代数记载不同。可能来源：班固另有所本，或传抄致误。无更强证据时，**引用哪本书就写哪本书的数字**，不合并为「七/十世」的模糊表述；确需综述时写「《史记》七世，《汉书》十世」。

### V2 以庄见惮 / 以严见惮

- 《史记》作「庄」，《汉书》作「严」。
- **避讳解释**：东汉明帝名刘庄，传统上有学者以避讳解释《汉书》多改「庄」为「严」（如庄助→严助）。但《汉书》传本避讳并不彻底——同篇郑当时「字庄」仍保留——因此避讳只能作**解释之一**，不能据此把《史记》的「庄」校改为「严」，反之亦然。
- **写作取舍**：引《史记》原文用「庄」，引《汉书》原文用「严」，各自保留。

### V3 河南 / 河内

- 《史记》：「臣过河南，河南贫人伤水旱万余家……持节发河南仓粟以振贫民。」
- 《汉书》：「臣过河内，河内贫人伤水旱万余家……持节发河内仓粟以振贫民。」
- **说明**：两郡相邻（河南郡治洛阳，河内郡治怀县），同属司隶。事件框架完全一致，仅地名不同。可能为班固改写或传抄之误。
- **写作取舍**：叙述事件时说「途经河南/河内一带」，引用原文时按所据书注明；不裁定哪一郡为准。地方纪念文章多采「河南」。

### V4 庄助 / 严助

- 《史记》「庄助」，《汉书》「严助」。
- **说明**：与 V2 同一避讳系统；《汉书》另有《严助传》（本姓庄）。引用时按书保留。

### V5 傅柏/傅伯、袁盎/爰盎

- 《史记》「傅柏、袁盎」，《汉书》「傅伯、爰盎」。
- **说明**：「袁/爰」为同姓异写（袁盎又作爰盎），「柏/伯」为同音异写。不影响语义。
- **写作取舍**：正文统一用「袁盎」（通行写法），引文按原书。

### V6 刘弃 / 刘弃疾

- 《史记》「宗正刘弃」，《汉书》「宗正刘弃疾」。
- **说明**：人名脱字或异名。汉代宗正刘弃疾见《汉书·王子侯表》系统，通常认为《史记》脱「疾」字。此为**他校**推断，不作正文改字。
- **写作取舍**：正文写「宗正刘弃（《汉书》作刘弃疾）」。

### V7 发蒙振落 / 发蒙

- 《史记》：「如发蒙振落耳。」《汉书》：「如发蒙耳。」
- **说明**：语义相同（揭开覆盖物、摇落枯叶，喻极易），《史记》多「振落」二字，语势更强。
- **写作取舍**：引《史记》用四字，引《汉书》用二字；解释时说明二者同义。

### V8 七岁 / 十岁（最关键）

- 《史记》：「令黯以诸侯相秩居淮阳。七岁而卒。」
- 《汉书》：「令黯以诸侯相秩居淮阳。居淮阳十岁而卒。」
- 《资治通鉴》元狩五年条：「使黯以诸侯相秩居淮阳，十岁而卒。」胡三省注未对「十岁」提出异议。
- **史源关系**：《通鉴》此处从《汉书》。因此形成「《史记》七岁」vs「《汉书》—《通鉴》十岁」两个系统。
- **年代后果**：以元狩五年（前 118）赴任起算，七岁→约前 112（元鼎五年）；十岁→约前 109（元封二年）。
- **写作取舍**：本束正文并列两说，不裁决；引用卒年必须带史源（详见 [年表](../concepts/01-life-chronology.md) F29、F30）。

### V9 「其先」/「其行」（数字文本讹字）

- 通行本《汉书》作「其先有宠于古之卫君也」，颜师古注引文颖曰「六国时卫弱但称君也」；部分在线文本作「其行有宠」。
- **说明**：「行」当为「先」之形近讹字（数字识别或录入错误），不是版本异文。
- **写作取舍**：按「其先」理解与引用；遇到「其行」文本，标注为讹字而非异文。

### V10 不许 / 弗许

- 《史记》「上默然，不许」，《汉书》「上弗许」。
- **说明**：同义。关键是两书都作**否决**，与地方纪念文章「最终改变了这个荒唐的做法」不同（见 [决策案例集](../examples/02-decision-casebook.md) 结果异说登记）。
- **写作取舍**：正文写「武帝不许」，地方说法只作流变层。

## 三、异文处理四原则

1. **底本先行**：先确定引哪本书、哪个底本，再谈异文；不把不同底本混成一句。
2. **不擅改**：异文不改字，出注说明；数字文本的明显讹字（如 V9）标「讹」，不与版本异文混同。
3. **他校慎断**：用他书、类书、注疏作旁证时，只作推断，不直接改正文（如 V6）。
4. **异说并列**：涉及年代、数量、结局的实质分歧（如 V8、V10），并列呈现并说明后果，不替读者裁决。

## 四、对写作的影响

- **年表**：卒年必须写「七岁/十岁」两说；不能只写「前 112」。
- **治术篇**：河南/河内的差异不影响「矫制发粟」的决策结构，可放心讨论方法。
- **直谏篇**：「不许」是硬事实，不能写成「武帝被说服」。
- **流变篇**：避讳、异文、地方叙事三层要分开，避免把校勘问题误当人物评价问题。
