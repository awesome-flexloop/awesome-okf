# 决策案例集——矫制、受降与卧治

> 本页把汲黯的三组事件还原为「决策题」，而不是道德故事。每案五栏：情境、约束、选项、决策与结果、现代映射。最后一节给出合法性边界与决策校验清单。
>
> **重要提醒**：现代映射是类比，不是建议照搬。尤其是「矫制」——在汉代也是重罪，汲黯靠「自请归节伏罪」与武帝「贤而释之」才过关（F7），不可当作通用操作模板。

## 案例一：河南矫制发粟

### 情境

武帝派汲黯往视河内火灾。途经河南，见水旱饥民万余家，「或父子相食」（F6、F7）。

### 约束

| 约束 | 内容 |
|------|------|
| 授权边界 | 使命是「视火」，不是赈灾；开仓需诏令 |
| 时间压力 | 饥荒正在发生，「父子相食」不可等待往返请旨 |
| 法律后果 | 未经诏令发仓＝「矫制」，可治重罪 |
| 信息不对称 | 朝廷未必知道河南灾情程度 |

### 选项

| 选项 | 收益 | 风险 |
|------|------|------|
| A. 只报火灾，回朝再奏河南灾情 | 程序合规 | 灾民继续死亡，错过窗口 |
| B. 持节发仓，回朝请罪 | 立即救灾 | 矫制罪，可能丢官甚至丧命 |
| C. 就地募捐/劝富户出粟 | 不触法 | 杯水车薪，执行力不足 |

### 决策与结果

汲黯选 B：「臣谨以便宜，持节发河南仓粟以振贫民。臣请归节，伏矫制之罪。」结果：「上贤而释之，迁为荥阳令。」（F7、F8）

**关键动作**：先救灾，后请罪；把「程序违规」的责任完全个人化，不推给下属、不辩解。

### 现代映射

- 紧急状态下的「先处置、后补程序」，需要同时准备**责任承担方案**；
- 若组织没有「事后追认/容错」机制，B 选项会把个人变成制度漏洞的替罪羊；
- 可迁移的不是「擅自行动」，而是**「处置—留痕—请责」三件套**。

### 校验问题

1. 是否真的存在不可等待的时间窗口？
2. 是否有更低风险的替代方案（C）被认真评估？
3. 是否准备好承担程序后果，而不是只准备了好结果？

## 案例二：浑邪王受降与五百贾人案

### 情境

元狩二年（前 121，地方口径系年），匈奴浑邪王率众来降。汉发车二万乘迎送，县官无钱，向民贳马；民匿马，武帝怒，欲斩长安令。随后，长安贾人与降众市易，五百余人坐「阑出财物于边关」当死（F23、F24）。

### 约束

| 约束 | 内容 |
|------|------|
| 财政约束 | 迎降耗费巨大，官府无钱，只能向民借马 |
| 安全叙事 | 边关法禁、防间谍、防物资外流是硬政策 |
| 政治压力 | 武帝正以「招怀四夷」为功，反对声容易被定为「沮事」 |
| 人命规模 | 五百余人一案，刑罚规模远超个案 |

### 选项

| 选项 | 收益 | 风险 |
|------|------|------|
| A. 支持斩长安令、严办五百贾人 | 迎合上意、维护法禁 | 民怨、冤滥、治理合法性受损 |
| B. 先争长安令，再争五百贾人 | 保住具体人命 | 连续顶撞，政治风险高 |
| C. 只私下劝谏，不公开反对 | 降低冲突 | 政策不变，人命仍失 |

### 决策与结果

汲黯选 B，分两步：

1. 争长安令：「长安令无罪，独斩黯，民乃肯出马。」并反问「何至令天下骚动，罢弊中国而以事夷狄之人乎！」→「上默然」（F23）。
2. 争五百贾人：以「庇其叶而伤其枝」为喻，主张以胡人赐从军死事者家，而非以微文杀无知者 →「上默然，不许」，随后「黯坐小法，会赦免官」（F24）。

**结果异说登记**：

| 史源 | 结果表述 |
|------|----------|
| 《史记·汲郑列传》 | 「上默然，不许……后数月，黯坐小法，会赦免官」（F24） |
| 《汉书·张冯汲郑传》 | 「上弗许……后数月，黯坐小法，会赦，免官」（R4、F40） |
| 河南省纪委监察委文章（R8） | 「汉武帝听后沉默不语，最终改变了这个荒唐的做法」（F42） |

> 前两史源一致作「不许」，地方文章作「改变做法」。二者冲突，本束并列登记，**不采用「武帝被说服」的说法**作为史实。

### 现代映射

- 在「安全/合规」高压叙事下，替具体的人争取程序正义，需要**把宏大叙事换算成具体代价**（「以微文杀无知者五百余人」）；
- 提出替代方案（以胡人赐死者家）比单纯反对更容易被听进去；
- 异议的代价往往延迟结算（「后数月」才免官），不要用「当场没出事」判断安全。

### 校验问题

1. 反对的是政策目标，还是政策的执行方式？
2. 是否给出了可执行的替代方案？
3. 是否区分了「上默然」的默认与「不许」的否决？

## 案例三：淮阳卧治

### 情境

元狩五年（前 118），更铸五铢钱，民多盗铸，楚地尤甚。淮阳为楚地之郊，吏民不相得。武帝召拜汲黯为淮阳太守（F25、F26）。

### 约束

| 约束 | 内容 |
|------|------|
| 身体约束 | 汲黯「常有狗马病，力不能任郡事」（F26） |
| 政治约束 | 刚从免官隐居中被起用，无讨价还价空间 |
| 治理难题 | 「淮阳吏民不相得」——官民关系紧张，非普通郡 |
| 货币危机 | 盗铸涉及经济秩序，需强硬手段与地方配合 |

### 选项

| 选项 | 收益 | 风险 |
|------|------|------|
| A. 辞不受印 | 避免力不胜任 | 诏数强予，最终仍须赴任；损君臣关系 |
| B. 请求留京为中郎 | 留在权力中心 | 武帝不许，明确要「君之重」 |
| C. 受任，以黄老术「卧而治之」 | 用威重+授权稳定局面 | 若所择非人，失控风险高 |

### 决策与结果

汲黯先泣辞、请求留京（A/B），不许；然后受诏赴任，按「居郡如故治」行事，结果「淮阳政清」（F26、F28）。任上还警告李息提防张汤，张汤败后武帝「以黯言抵息罪」，并「令黯以诸侯相秩居淮阳」（F27、F28）。

**决策结构**：

```
辞让（表达力不胜任与恋阙）→ 受命（服从）→ 复制东海治术（择人授权）
→ 结果验收（政清）→ 制度回报（诸侯相秩）
```

### 现代映射

- 「辞让」不是拒绝，而是**风险预告与资源谈判**；武帝的回应「吾徒得君之重」明确了资源（威重）与授权；
- 空降难治之地，先复制已验证的方法（东海经验），不急于推新政；
- 「卧治」的前提是团队与威重，不是身体缺席（详见 [黄老治术](../concepts/02-huanglao-governance.md)）。

### 校验问题

1. 是否明确了自己被需要的到底是「能力」还是「威重」？
2. 是否有可复制的既有方法，而不是到任后重新试错？
3. 结果验收标准是什么（「政清」如何量化）？

## 合法性边界：三个不能学

| 不能学 | 原因 | 正确做法 |
|--------|------|----------|
| 把「矫制」当常规操作 | 汉代矫制是重罪；汲黯靠自请归节才获释（F7） | 紧急处置必须配套追认机制与责任承担 |
| 把「面折」当沟通模板 | 汲黯「士亦以此不附」，同僚关系受损（F11） | 区分「议题冲突」与「人际攻击」，尽量给替代方案 |
| 把「卧治」当不作为 | 「卧」之前有「择丞史」，之后有「政清」（F9、F28） | 先建团队与验收标准，再谈授权 |

## 决策校验清单（五问）

1. **时间窗**：这件事能不能等到程序走完？不能等，才进入「先处置」讨论。
2. **授权边界**：我越的是哪一条线？越线后的责任由谁承担？
3. **替代方案**：除了反对，我是否给出可执行的他案？
4. **对象区分**：我面对的是「决策」还是「人」？批评决策，不攻击人格。
5. **后果准备**：最坏结果（免官、处分、关系破裂）我是否接受？
