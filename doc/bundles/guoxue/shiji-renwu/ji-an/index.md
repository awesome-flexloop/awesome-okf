# 汲黯研读教程

汲黯，字长孺，濮阳（今河南濮阳一带）人，西汉景帝、武帝两朝名臣。其家「至黯七世，世为卿大夫」，以父任为太子洗马，武帝即位后为谒者；曾持节发河南仓粟赈灾而自请「矫制」之罪，出任东海太守以黄老清静之术「岁余，东海大治」，入朝为主爵都尉、右内史，位列九卿；因面折廷争、反对征伐与苛法，屡遭外放，最终以淮阳太守终老（facts F1、F7、F9、F10、F25、F29）。《史记》以他与郑当时合传，太史公借「翟公署门」发「一死一生，乃知交情」之叹；《汉书》赞其「正直」（facts F38、F39）。本知识包是面向普通读者与研究者的汲黯系统中文教程，特点有四：

1. **三层信源、异史对读**——以《史记·汲郑列传》为母本，《汉书·张冯汲郑传》与《资治通鉴》卷二十为对读层，地方纪念文章只作「流变层」证据；同一事在三种史源中的异文逐条登记（facts F40，详见 [异文对勘](references/textual-variants.md)）。
2. **治术与人格分开讲**——东海「责大指、不苛小、不拘文法」与淮阳「卧而治之」是治理技术；面折田蚡、斥张汤、谏浑邪王是职位伦理。两者常被混为「性格直」，本束分篇拆解（[黄老治术](concepts/02-huanglao-governance.md)、[直谏与朝廷](concepts/03-zhijian-and-court.md)）。
3. **年代分级、不造精确**——原文有明确纪年者标「原文」，由制度与人物关系推得者标「推算」，仅见于地方叙事者标「地方口径」；生年史无明文，卒年有「七岁而卒」与「十岁而卒」两说，并列不裁决（facts F29、F30）。
4. **形象层累可核查**——后世「题诗退贿」「悬印梁上」「卧榻听讼」「微服出访」等细节不见于《史记》《汉书》，本束标注为地方纪念叙事，不与正史混同（facts F42，详见 [合传与流变](concepts/04-ji-zheng-legacy.md)）。

## 🚀 快速开始

如果你第一次读汲黯：

1. 先读[全书概览](concepts/00-overview.md)，记住「黄老能吏 + 直谏之臣 + 廉吏」三重身份
2. 读[生平年表](concepts/01-life-chronology.md)，建立「景帝太子洗马→武帝谒者→东海→九卿→淮阳」的仕宦骨架
3. 打开[阅读地图](examples/01-reading-map.md)，按原文段落顺序读一遍《汲郑列传》汲黯部分

如果你已有汉代史基础：

1. 从[黄老治术](concepts/02-huanglao-governance.md)入手，比较汲黯与曹参、盖公一系的「无为」实践差异
2. 读[直谏与朝廷](concepts/03-zhijian-and-court.md)，把每一次面折对应到具体制度冲突（太后外戚、儒术、文法吏、征伐）
3. 用[异文对勘](references/textual-variants.md)检查你手边版本的字句，再读[合传与流变](concepts/04-ji-zheng-legacy.md)
