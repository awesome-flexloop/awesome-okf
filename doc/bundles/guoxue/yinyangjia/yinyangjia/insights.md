# 阴阳家知识包·架构洞察（Architecture Insights）

> 基于事实清单（facts.md，F-001～F-064）得出，每条洞察遵循四元组结构（陈述/证据/反常识/行动）。

## 洞察 1：文本存佚悖论——著录 369 篇全部亡佚的学派，其核心学说却直接塑造秦汉政治正当性叙事

| 四元组 | 内容 |
|--------|------|
| **陈述** | 阴阳家是先秦诸子中"文本存量与历史影响力倒挂"最极端的学派：《汉书·艺文志》著录二十一家三百六十九篇全部亡佚，邹衍个人著录 105 篇今存直接佚文学界估计仅约 20 条（论文转述值，马国翰辑本影印原文未核对，存疑，见 F-035/U-05）；但五德终始说经《吕氏春秋·应同》载体与秦汉政令（始皇水德改制、公孙臣土德上书、太初改历）进入帝国正当性叙事的最高层，传播路径绕开了学派自身文本的存续。 |
| **证据** | F-001（二十一家三百六十九篇著录）、F-034（邹衍 105 篇全部亡佚）、F-035（直接佚文约 20 条）、F-027/F-028（《应同》五德推移为学说遗留载体）、F-051（始皇"推终始五德之传……方今水德之始……数以六为纪"）、F-052（封禅书"邹子之徒论著终始五德之运，及秦帝而齐人奏之"）、F-054（公孙臣以终始五德上书言汉得土德）、F-056（董仲舒"始推阴阳，为儒者宗"）。 |
| **反常识** | 挑战"文本亡佚＝思想边缘化"的默认假设。一个自身文本几乎清零的学派，其学说框架（五德转移、符应、改制）反而成为秦汉政治合法化的通用语法；思想的存续依赖政治实践与敌对/中立载体（政令、史书、辩论记录、批判文本），而非学派文献的传承。 |
| **行动** | 知识包以"存佚总览"而非"经典全文"开篇，开宗明义给出 369 篇 vs 约 20 条的存佚对账；将《史记·秦始皇本纪》《历书》《汉书·五行志》等秦汉政治文本列为学说传播的一级材料，与《应同》、辑佚佚文并列呈现，而非仅作背景附注。 |

## 洞察 2：归属判定三层法（A 确证佚文 / B 争议归属 / C 受影响传世文献）是引用亡佚学派文本的前置门槛

| 四元组 | 内容 |
|--------|------|
| **陈述** | 阴阳家文献的任何一句"原文"引用都必须先过归属判定关：A 层（辑本注明原始引书且经双源逐字核对，如《别录》"谈天""雕龙"条、《文选》李善注"五德从所不胜"条）、B 层（归属有争议，如仅标"邹子曰"的佚文存在邹衍/邹奭/后学混入可能）、C 层（受影响传世文献，如《管子·四时》《礼记·月令》《淮南子·天文训》体现阴阳五行思想但非阴阳家著作）——三层一旦混用，即生产出虚构的"邹衍原文"。 |
| **证据** | F-020/F-021/F-031（A 层样例：辑本＋原始引书＋双源核对）、F-036（B 层：类书引"邹子"不区分邹衍邹奭；"五德从所不胜"有邹衍/后学综述之争）、F-038（《论衡·谈天》为转述、不作逐字佚文）、F-040/F-041（《盐铁论》为汉代辩论记录、间接材料）、F-042～F-048（C 层：管子三篇、月令、淮南子两训的归属层级）、F-050（《荀子·非十二子》"五行"系于子思孟轲、篇中无邹衍）。 |
| **反常识** | 挑战"引书名即可信"与"内容对得上即是原文"两个默认假设。《管子·四时》"阴阳者，天地之大理也"文字再"阴阳家"，它也是《管子》文本而非邹衍佚文；《论衡》对大九州说的复述再详尽，也是王充的转述文字；甚至《史记》"乃深观阴阳消息而作怪迂之变"也只是司马迁的叙述语（F-036）。C 层材料的思想价值不因非"原文"而减损，但引用时若冒称 A 层即属虚构。 |
| **行动** | bundle 每条引文显式打 A/B/C 标签（spec 已规定 SHALL 级要求）；concepts 层为三层法专设"传世文献中的阴阳家材料"文档；凡仅标"邹子曰"的佚文一律入 B 层并列出归属分歧双方依据，不作单一署名。 |

## 洞察 3：解读立场光谱——同一批材料在现代研究中可得出从"疑古消解"到"方法论重估"的相反结论

| 四元组 | 内容 |
|--------|------|
| **陈述** | 对阴阳家同一批材料，现代研究呈现完整的光谱：顾颉刚（承梁启超）将五行说起源后置于战国后期、视五德终始说为帝制运动时代鲁文化与齐文化混合的产物（"只在说明如何才可有真命天子出来"）；冯友兰从中读出"科学的起源"；吕思勉认为邹衍"先验细物，推而大之，其法固不误也"、五德终始"犹儒家之通三统"；白奚则以稷下学宫为框架提出阴阳家成立于战国晚期、系阴阳家与五行家合流的复合模型——立场的分布跨越"负资产—科学萌芽—方法论先驱—学派合成物"全域。 |
| **证据** | F-058（顾颉刚原语）、F-059（梁启超"诸大哲皆未尝齿及"）、F-060（冯友兰"术数……往往是科学的起源"）、F-061（吕思勉"其法固不误也""实犹儒家之通三统"）、F-062（白奚"阴阳家应是阴阳五行家的简称……阴阳家与五行家结合互补的产物"；该条证据层级较低——讲座口述新闻稿＋豆瓣读书用户录入，纸本未核对，见 U-18）。 |
| **反常识** | 挑战"存在唯一权威解读"的默认假设。证据链（战国以前文献中阴阳五行痕迹稀薄）既可支持"后起建构"的疑古结论，也可支持"思想方法论先驱"的正面重估——分岐不在材料而在评价框架；且光谱两端共享同一批事实（F-007/F-008 司马谈评述、F-027《应同》文本），说明"材料一致"不保证"结论收敛"。 |
| **行动** | 解读章节（五德终始说解读）并列呈现各家观点并逐条标注文献出处与证据层级，不设"正确答案"；对证据层级较低的转述（如梁启超结论句经顾颉刚转引，F-059/U-12）显式标注转引链条，供读者自行核验。 |

## 洞察 4：信源可达性现实——最权威的数字信源在实战中大面积不可用，多信源冗余是采集的生存策略而非锦上添花

| 四元组 | 内容 |
|--------|------|
| **陈述** | 本次采集中最权威的数字信源 ctext.org 大面积间歇性不可用（《汉书·艺文志》页正文截断，史记、论衡等页被人机验证拦截），维基文库三个关键篇页亦未返回内容；实际完成的逐字核对主要依靠"维基文库＋汉程网＋汉典古籍＋古诗文网＋泉学网"的组合冗余，部分条目降级为"检索摘要＋学术论文转引交叉核对"。 |
| **证据** | F-064（ctext 间歇性不可用全况）、F-045（《月令》以古诗文网＋可可诗词网核对）、F-037（《论衡》以古诗文网＋ctext 检索缓存核对）、F-039（《盐铁论》以泉学网＋诗词汇核对）、U-01～U-04/U-17（各"未能核对"标注）、F-032/F-033（马辑本、叶辑本影印原文不可得，以学术论文转述登记）。 |
| **反常识** | 挑战"权威信源＝可用信源"与"单一权威源依赖"的默认采集策略。权威性排序（ctext ＞专业古籍站＞商业古籍网）与可用性排序在实战中并不同构；一次采集任务的可信度上限由"可达信源的冗余度"而非"名义上引用了哪个权威源"决定。 |
| **行动** | 采集阶段执行多信源冗余策略：每条关键引文至少两个独立可达源，首选"数字图书馆（维基文库）＋带注本专业站（汉程网）"组合；主源不可达时显式降级并登记证据层级；所有"未能核对"项保留在 facts.md 未能核对项清单（U-01～U-18）中，不做静默吞没。 |
