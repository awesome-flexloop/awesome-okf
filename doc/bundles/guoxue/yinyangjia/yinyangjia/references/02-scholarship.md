## 三、使用建议（入门 → 进阶 → 研究级）

1. **入门**：先读冯友兰《中国哲学简史》第十二章（通史定位、网络可得、观点平正），再读吕思勉《先秦学术概论》第九章（对阴阳家与数术之关系、邹衍方法论的评价最简明）。
2. **进阶**：读顾颉刚《五德终始说下的政治和历史》专文——疑古路径代表作，读时注意其证据链（商代甲骨、东西周文籍、早期诸子书中无五行痕迹）与结论（五行说起源后置）之间的推理强度。
3. **研究级**：梁启超《阴阳五行说之来历》须查原刊（《饮冰室合集》或《古史辨》第五册下编，网络所见均系转引）；白奚《稷下学研究》须查纸本（讲座口述与豆瓣摘录的证据层级有限）；齐思和《中国史探研》相关篇目无网络全文，须图书馆调阅——三者均不可只凭二手转述立论。
4. **纪律**：凡引用上表观点，须如本表一样标注证据层级（原文直引/二手转引）与出处；引用顾颉刚、吕思勉大段文字时注意其单源风险（Q-05），条件允许时回查纸本或第二信源。
