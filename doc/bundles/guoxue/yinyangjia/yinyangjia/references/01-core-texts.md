## 六、CTEXT 拦截情况与本包多信源策略

**实测拦截情况（F-064/U-01～U-04/U-17）**：本次采集期间 ctext.org 间歇性不可用——《汉书·艺文志》页一次成功访问但正文截断于六艺略·诗部分；对 han-shu/yi-wen-zhi、shiji/74、shiji/130、shiji/6、lun-heng/tan-tian、yan-tie-lun/lun-zou、guanzi 三篇、xunzi/fei-shi-er-zi、li-ji/yue-ling 等页多次访问（含简体 zhs 与繁体 zh 页面）返回人机验证页面（CAPTCHA）或超时。维基文库《吕氏春秋·应同》《论衡·谈天》《盐铁论·论邹》具体篇页亦未返回有效内容。各 ctext URL 仍列于各条信源栏供后续人工复核（stale_after 2027-08-30 复核窗口）。

**多信源策略（洞察 4 的落地）**：

1. **权威性 ≠ 可用性**：权威性排序（ctext ＞ 专业古籍站 ＞ 商业古籍网）与实战可用性排序并不同构；一次采集的可信度上限由"可达信源的冗余度"决定，而非名义上引用了哪个权威源。
2. **双源组合首选**：书志与史传类采用"维基文库（数字图书馆）＋ 汉程网（带注本专业站）"组合逐字核对（F-001/F-006/F-007/F-010 等均双源一致）。
3. **降级显式登记**：主源不可达时显式降级（如《论衡》以古诗文网＋ctext 检索缓存交叉核对 F-037；《管子》三篇以先前抓取文本为准并逐条注明 U-17），并在上表"风险"列保留标注，不做静默吞没。
4. **单源条目风险前置（Q-05 处置）**：凡单源核对或低稳定性信源（汉典古籍《别录》辑文、而若书屋《历书》、点藏网《坠形训》、中华文库《楚元王传》等），上表已显式标注风险等级并给出替代信源建议——复核时若 URL 失效，按替代建议补源而非放弃该事实。
