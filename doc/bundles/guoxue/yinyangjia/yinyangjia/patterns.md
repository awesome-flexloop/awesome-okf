# 阴阳家文献·可复用阅读模式（Reusable Reading Patterns）

> 从本次阴阳家文献采集（facts.md F-001～F-064）萃取的可复用阅读模式。每个模式含触发场景、核心步骤、反模式（均为本次采集的实际教训）、检验标准与跨领域迁移示例。

---

## 模式 1：亡佚三层阅读法（A/B/C 分层）

**模式名**：亡佚三层阅读法

**触发场景**：

- 适用：研究对象为原著已亡佚、仅存辑佚残篇与后世转述的学派/作者（阴阳家、邹衍为典型）；需要判断某段号称"原文"的文字可信度；需要为知识库/教程组织亡佚学派的文献材料。
- 不适用：原著完整传世的典籍（如《庄子》有郭象定本通行，只需做版本分层而非存佚分层）；出土文献研究（简帛本自有出土层位框架，无需 A/B/C 归属判定）。

**核心步骤**：

1. **书志定位**：从正史艺文志/经籍志著录确立"原规模"基线（家数、篇数）——阴阳家案例为《汉书·艺文志》"右阴阳二十一家，三百六十九篇"（F-001），邹衍个人 105 篇（F-034）。
2. **A 层提取**：收集确证佚文——辑佚书所录、注明原始引书出处、经至少两个独立信源逐字核对的文字（如《别录》"谈天""雕龙"条经《全汉文》与《史记》集解互核，F-020/F-021；《文选》李善注"五德从所不胜"条，F-031）。
3. **B 层隔离**：归属有争议的材料单独存放并列双方依据——"邹子曰"未明指邹衍者可能是邹奭或后学（F-036）；学说载体（如《吕氏春秋·应同》）存在"邹衍原文孑遗 vs 学派综述"之争（F-028/F-036）。
4. **C 层标注**：受影响传世文献如实标注"体现某派思想，非某派著作"——《管子·四时/五行/幼官》（F-042～F-044）、《礼记·月令》（F-045）、《淮南子·天文训/坠形训》（F-047/F-048）。
5. **存佚对账**：明示著录数与辑存数的落差（369 篇 vs 约 20 条直接佚文，F-001/F-035），杜绝"以 C 层材料冒充原著规模"的隐性夸大。
6. **转述单列**：后世转述与评论（《论衡·谈天》《盐铁论·论邹》、司马迁叙述语）单列为间接材料，不入 A 层（F-038/F-041）。

**反模式**（均为本次采集过程中实际遇到/规避的教训）：

1. **将受影响文献当原文**：把《管子·四时》"阴阳者，天地之大理也"直接当邹衍佚文引用——C 层冒充 A 层是亡佚文献引用中最常见的虚构形式。
2. **将转述当佚文**：《论衡·谈天》《盐铁论·论邹》文字再详尽也是王充、桓宽的文字；顾颉刚等学者仅以之为间接证据（F-038）。
3. **凭记忆写古籍原文**：跳过逐字核对凭印象书写引文，必然引入讹字与版本混淆（本次异文登记表 Y-01～Y-23 中"钜/巨""祥/详""毙/弊""蚓/螾""徙/徒"等均为实际撞见的版本差异或录文讹误，凭记忆必错；其中 Y-13/Y-21 系对抗审查抽查发现的原录文误字，已照信源页改正）。
4. **将争议归属材料径直署名**：仅标"邹子曰"的佚文径直署名邹衍，吞没邹衍/邹奭/后学的归属分歧（F-036）。

**检验标准**：

- 每条引文可回溯至具体辑本＋原始引书＋数字信源 URL；
- B/C 层材料在任何表述中未被呈现为 A 层（对抗审查抽查断言即可验证）；
- 存佚数字对得上账：著录篇数、亡佚数、辑存条数三者的口径区分明确（原著篇数 ≠ 辑得条数，F-035）。

**跨领域迁移示例（软件文档考古）**：

某开源项目已停止维护且官网下线（＝原著亡佚），研究其"原始设计"时同样适用三层法：A 层＝官方存档中可溯源的 README/release notes/design docs（有版本库 hash 或存档快照佐证）；B 层＝第三方技术博客中归属不明的"作者说过"（可能是核心开发者、贡献者或社区转述）；C 层＝受该项目影响的后续项目代码与文档（体现其设计思想、非其原始文本）。引用该项目"设计原意"时，三层混用同样会生产虚构的"项目原文"。

## 模式 2：辑佚溯源链阅读法

**模式名**：辑佚溯源链阅读法

**触发场景**：

- 适用：使用或核查任何一条二手引文/佚文——从引文反推其证据链完整性；数字人文采集任务中评估某条"古籍原文"的可信度；撰写引用亡佚文献的学术文本。
- 不适用：直接阅读完整传世本的一手文本（无辑佚环节，溯源链退化为"底本→数字信源"两步）；出土文献（其证据链是"出土物→释文→整理本"，环节不同）。

**核心步骤**：

1. **锚定佚文**：从今人所引的一句话出发（如"五德从所不胜，虞土、夏木、殷金、周火也"）。
2. **上溯辑本**：查明这句话出自哪个辑本——马国翰《玉函山房辑佚书》辑《邹子》一卷（F-030）；辑者的学术判断（如马氏判定《应同》五德段为邹衍遗文）本身是链条上的一个证据层。
3. **上溯原始引书**：查明辑本又从何处辑来——《文选》卷六魏都赋李善注（F-031）；唐宋类书与古注（《艺文类聚》《太平御览》《史记》三家注）是阴阳家佚文的主产地（F-030）。
4. **落到数字信源**：核对当前可访问的 URL 并逐字比对（ctext.org/维基文库/专业古籍站）；主源不可达时启用多信源冗余（维基文库＋汉程网组合，或古诗文网＋ctext 检索缓存交叉核对，F-037/F-064）。
5. **登记异文与断点**：链条上任一环缺失（如马辑本影印原文不可得，F-032）即显式标注"未能核对"；辑本与古注引文的异文（如"其书言天事"vs"尽言天事"，Y-09）照录备考，不作裁决。

**反模式**（均为本次采集过程中实际遇到/规避的教训）：

1. **单一信源依赖**：只依赖 ctext.org 一个"最权威"源——本次其被人机验证大面积拦截（F-064），若无多信源冗余整个采集链即告断裂；"权威性"不等于"可用性"。
2. **跳过辑本直接从类书引用**：从《太平御览》《艺文类聚》直接引"邹子曰"而绕过辑本层，丢失辑者的版本判断与出处系联，也丢失辑本与引书间的异文信息（Y-09/Y-10）。
3. **溯源链断点静默吞掉**：马辑本影印不可得（U-05）、叶德辉辑本无逐字页面（U-07）时，不标注"未能核对"而照常转述收条数量——佚文以讹传讹即始于此；正确做法是"以学术论文转述为准，标注存疑"（F-032）。
4. **凭记忆写古籍原文**：不经过四层链条的任何一层逐字核对，直接书写"记得的"引文。
5. **网页缺字径直补字不声明**：信源网页显示缺字符时（如汉典古籍"奭"字缺显，Y-11），不声明缺字来源径直补正——正确做法是据他源补字并加〔〕标示，或将缺字以〔缺字〕照录（F-023）。

**检验标准**：

- 每条佚文可画出完整四层链：佚文 → 辑本 → 原始引书 → 数字信源 URL；
- 链条上每一处断点均有显式"未能核对/存疑"标注，无静默吞没；
- 关键异文（某本作某）登记在案且不武断裁决，保持"登记而非裁决"（spec 开放问题条款同此精神）；
- 引文的每个环节均可被独立复核（对抗审查随机抽查即可执行）。

**跨领域迁移示例（已下线开源项目研究）**：

核查一条"该项目作者说过 X"的断言：X 的转载（佚文）→ 哪个汇总帖/综述文章收录（辑本）→ 原始邮件列表存档/issue/commit message（原始引书）→ Wayback Machine 快照或 Git 镜像（数字信源）。四层链条任何一环断裂（原帖删除、存档缺失）都应降低该断言的可信度评级并显式标注，而非照引不误——与古籍辑佚"断点即存疑"的纪律完全同构。
