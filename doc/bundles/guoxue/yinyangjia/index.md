# 阴阳家（Yinyangjia）知识包

本目录收录与先秦阴阳家学派相关的 OKF 知识包。阴阳家为《汉书·艺文志》九流十家之一，以邹衍（"谈天衍"）为代表人物，核心学说为五德终始与大九州；其著录文献（二十一家三百六十九篇）全部亡佚，今存者仅为辑佚残篇与传世文献中的相关材料，故本组知识包以"存佚分层 + 辑佚溯源"为组织基调。
