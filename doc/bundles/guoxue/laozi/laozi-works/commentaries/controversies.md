# 争议与不确定性

本解读文档显式记录《老子》研究中的重大断代、释文、诠释分歧。对存在争议的问题，本知识包不单方面下确定性断言，而以「多立场呈现 + 依据标注」的方式处理。

## 1. 「大器晚成」与「大器免成」之争

- **文本事实**：帛书乙本作「大器免成」，传世本作「大器晚成」[^gao-ming-jiaozhu]。
- **立场甲（主「免成」为古）**：高明等据帛书认为「免」为本字，「晚」为后起改字。「大器免成」与上文「大音希声」「大象无形」义脉连贯——皆言至极者不显其成。
- **立场乙（主「晚成」可通）**：部分学者认为「晚成」在传世本义脉自洽，且「免」「晚」或为音近通假，未必能定孰为「本字」。
- **本包处理**：两说并存，异文对照见[关键异文对照](../text/key-variants.md)，不作为定论。

## 2. 郭店楚简本性质之争

- **文本事实**：郭店本无「绝仁弃义」，对应处作「绝伪弃虑」[^liao-mingchun-guodian]。
- **争议点**：郭店本为「早期无激烈反儒思想的原本」，抑或「有选择节抄、略去反儒句的传本」？
- **立场甲**：主张郭店本反映《老子》早期面貌，反儒言语为后人所增。
- **立场乙**：主张郭店本系节抄，抄者有意过滤反儒句，不能据此断定原本无「绝仁弃义」。
- **本包处理**：两说并存，仅陈述「郭店本无此句」这一文本事实，不断言其性质。

## 3. 「道」与「无」的哲学诠释分歧

- **争议点**：老子「道」究竟是有实体的本体，还是「无」本身？「道」是否等同于「无」？
- **立场甲（玄学义理，王弼一系）**：以「无」为本，「道」即「无」的别名[^gao-ming-jiaozhu]。
- **立场乙（哲学史，陈鼓应等）**：「道」为实存之体，「无」「有」是描述「道」的一对范畴，非「道」本身。
- **立场丙（古文献，李零等）**：「道」是处世智慧，非神秘本体，「无」「有」是经验概括。
- **本包处理**：三立场并存于[现代学者注本解读](modern-commentaries.md)，本处仅汇总分歧。

## 4. 帛书甲本抄写年代的弹性

- **文本事实**：帛书甲本不避「邦」讳，学界据避讳推定抄于刘邦称帝前。
- **不确定性**：避讳推定依赖「抄写必避当朝讳」的前提，该前提并非绝对，故甲本年代的精确下限存在弹性。

## 本包处理原则

1. 有争议处**并列多立场**，标注各自依据。
2. **文本事实陈述**（某本作某字）优先于**性质判断**（某本更古/更真）。
3. 释文不确定处标注「□」「存疑」，不臆补。
