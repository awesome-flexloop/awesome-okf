# 出土文献校注解读

本解读文档汇聚出土文献整理者与校勘学者的立场，聚焦「文本层」问题：原文应如何校读、释文应如何判断。

## 高明《帛书老子校注》

高明以帛书甲乙本为底本，参校33种传世版本，是帛书校勘的集大成之作[^gao-ming-jiaozhu]。其核心立场：

1. **以帛纠传**：帛书本早于传世本，故遇文字歧异时，应重视帛书本的古貌。
2. **避讳字还原**：「恒」「邦」等避讳改字应还原，以恢复先秦本貌。
3. **通假字训读**：帛书中大量通假字（「胃」通「谓」等）应依训诂破读。

> 示例：传世本「大器晚成」，高明据帛书乙本「大器免成」指出「免」为本字，「晚」为后起误字或改字[^gao-ming-jiaozhu]。

## 裘锡圭《长沙马王堆汉墓简帛集成》

裘锡圭主编的集成本吸收数十年简帛研究新成果，对帛书《老子》的拼缀与释文有修订[^qiu-xigui-jicheng]：

1. **拼缀修订**：利用红外摄影等手段重新拼合残片，修正旧释。
2. **释文精校**：吸收战国秦汉文字研究新成果，多处释文较1980年本更精确。
3. **立场审慎**：对难以确定的释读，明确标注存疑，不做武断裁定。

## 北大简整理组

北京大学出土文献研究所整理《老子》时，采取以下立场[^beida-hanjian-2]：

1. **保存原貌**：释文忠实竹简文字，通假字保留原字并括注。
2. **篇题确认**：据竹简篇题确认西汉《老子》分「上经（德）」「下经（道）」。
3. **校勘对照**：与帛书本、传世本系统对校，厘清文本演变链。

## 三家校勘共同结论

| 结论 | 依据 |
|------|------|
| 早期《老子》德经在前 | 帛书甲乙本、北大汉简本一致 |
| 「恒」「邦」为古字 | 避讳改字可考 |
| 文本流动无唯一原版 | 各系统异文系统存在 |
