# 关键异文对照

本页对《老子》出土本与传世本之间的核心异文作逐条对照，每条标注版本来源并链接至相应解读与争议。

## 异文对照表

### 1. 「恒」与「常」

| 版本 | 文句 |
|------|------|
| 帛书甲/乙本 | 道可道也，非**恒**道也 |
| 北大汉简本 | 道可道，非**恒**道也 |
| 传世本（王弼） | 道可道，非**常**道 |

- **性质**：避汉文帝刘恒讳，「恒」改「常」[^gao-ming-jiaozhu]。
- **义理影响**：「恒道」强调道的永恒不变性，「常道」的「常」亦含恒常义，但用字差异是训诂的重要线索。

### 2. 「邦」与「国」

| 版本 | 文句 |
|------|------|
| 帛书甲本 | 大**邦**以下小邦（不避讳） |
| 帛书乙本 | 大**国**以下小国（避「邦」讳） |
| 传世本 | 大**国**以下小国 |

- **性质**：避汉高祖刘邦讳，「邦」改「国」[^gao-ming-jiaozhu]。

### 3. 「大器晚成」与「大器免成」

| 版本 | 文句 |
|------|------|
| 帛书乙本 | 大器**免**成 |
| 传世本（王弼） | 大器**晚**成 |

- **性质**：义理重大异文。「免成」义为「大象无形」般的不求完成，「晚成」义为「后来方成」。详见解读与争议。

### 4. 「绝仁弃义」有无

| 版本 | 文句 |
|------|------|
| 郭店楚简本 | 无「绝仁弃义」，作「绝伪弃虑」 |
| 传世本 | 绝仁弃义，民复孝慈 |

- **性质**：郭店本无激烈反儒之句[^liao-mingchun-guodian]，是研究《老子》早期思想面貌的关键证据。
