# 核心哲学概念

《老子》哲学以「道」为最高范畴，衍生「德」「无为」「自然」等核心概念。本概念文档以出土文献为准提取原义，并与传世本对照。

## 道

「道」是《老子》的核心概念，开篇即言「道可道，非恒道」（帛书本；传世本作「非常道」，「恒」避汉文帝讳改「常」）[^chen-guying-jinzhu]。

「道」的内涵可归纳为三层：

1. **本体义**：宇宙万物的本原与根据，先于天地而存在（「道生一，一生二，二生三，三生万物」）。
2. **法则义**：万物运行的总规律（「反者道之动」）。
3. **实践义**：人应遵循的行为准则（「人法地，地法天，天法道，道法自然」）。

「道」不可言说、不可名状，故老子用「无」「有」这对范畴逼近其描述。

## 德

「德」是「道」在万物与人身上的具体体现：

- 帛书本以「上德不德，是以有德」开篇（德经首章），可见「德」在老子体系中占据开篇地位[^lou-yulie-wangbi]。
- 「道」生万物，「德」畜养万物（「道生之，德畜之」），故「德」即万物得之于「道」者。
- 传世本「道德经」之名，正取自「道」「德」二范畴，早期篇序「德经在前」亦说明「德」并非次要概念。

## 无为

「无为」是老子政治哲学与修养论的核心主张：

- 「无为」非「不作为」，而是「不妄为」——不违背「自然」的强制性作为。
- 帛书本「无为而无不为」的说法（对应传世本第48章），表明「无为」的最终指向是「无不为」。
- 郭店楚简本亦有「无为」相关文句，足证此概念先秦已有。

## 自然

「自然」是「道」「无为」的最终根据：

- 「道法自然」——「自然」并非在「道」之上，而是「道」自身「自然而然」的状态。
- 「自然」为本然、自在、不假外力之义，非今之「自然界」。
- 「自然」概念是理解「无为」的钥匙：因万物本然如此，故圣人「辅万物之自然而不敢为」。

## 概念关系

```
道（本体/法则）
 ├── 生
德（得之于道，畜养万物）
 ├── 循
自然（本然状态，最终根据）
 └── 致
无为（不妄为，政治与修养准则）
```
