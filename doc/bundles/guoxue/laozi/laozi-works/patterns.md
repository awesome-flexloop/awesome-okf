# 可复用模式（Patterns）

> 从本次知识沉淀中萃取的可复用方法模式，每条含触发场景、核心步骤、反模式、迁移验证四个要素（G3 质量门）

---

## 模式1：出土文献层级校读法

| 要素 | 内容 |
|------|------|
| **触发场景** | 需要以出土文献为准整理古典文本原文，且存在多个出土系统与传世本的文字差异时。 |
| **核心步骤** | ① 列出全部出土系统与传世本的时间序列；② 选保存最完整者作底本（如帛书乙本）；③ 其余系统与传世本作校勘参照（如甲本避讳更古、郭店本最早但节选）；④ 异文逐条对照，标注避讳/通假/义理差异性质；⑤ 分歧显式化为「争议」，不做单一断言。 |
| **反模式** | ❌ 以「更古老」直接等同于「更正确」，据某单个出土本强行「纠改」传世本；❌ 逐字转录全部残简而不标注残毁处，臆测补字；❌ 把节选本（如郭店本）当作全本对待。 |
| **迁移验证** | 本模式已用于《老子》帛书/楚简/汉简三系统；可迁移至《周易》《论语》等有出土本与传世本差异的先秦典籍整理。 |

## 模式2：多注本立场对照法

| 要素 | 内容 |
|------|------|
| **触发场景** | 需要整理某经典的历代与现当代注本解读，且注家立场差异显著时。 |
| **核心步骤** | ① 按「文本校勘 / 义理诠释 / 综合研究」三层划分注家；② 每层选取代表性注家（非穷举）；③ 对核心范畴（如「道」）逐家提取其立场与依据；④ 用对照表显式呈现差异；⑤ 分歧点单独成「争议」文档并标注依据。 |
| **反模式** | ❌ 穷举所有注家导致文档臃肿且主次不分；❌ 择一注家立场为「标准答案」，遮蔽诠释多元性；❌ 把现代注本的哲学预设误当作经典本义。 |
| **迁移验证** | 本模式已用于《老子》四家历代注本与三位现代学者；可迁移至《庄子》《孟子》等注释传统丰富的经典。 |

## 模式3：脚注信源溯源法（逐声明归因）

| 要素 | 内容 |
|------|------|
| **触发场景** | 知识包需保证每条事实性论断可回溯到权威信源，避免无据转述时。 |
| **核心步骤** | ① 统一信源 ID 清单，集中在 `references/` 登记；② 正文以脚注 `[^source-id]` 标注论断来源；③ 信源含可核查 `resource`（出版社·年份 / URL）；④ 同一信源在全包使用同一 ID。 |
| **反模式** | ❌ 正文论断无脚注、无法回溯；❌ 同一信源在不同文档用不同 ID，造成登记混乱；❌ 信源只写书名不写版本/年份，无法核查。 |
| **迁移验证** | 本模式已在 laozi-works 与既有 boshu-reading/okf-spec bundle 中应用；可迁移至任何需严格溯源的知识包。 |

## 模式关系

```
模式1（层级校读法）→ 产出可靠原文 → 供模式3溯源
模式2（立场对照法）→ 产出可靠解读 → 供模式3溯源
模式3（脚注溯源法）→ 贯穿全包，保证可核查
```
