# 架构洞察（Architecture Insights）

> 基于事实清单（facts.md）和资料分析得出，每条洞察遵循四元组结构（陈述/证据/反常识/行动）

---

## 洞察1：帛书本的阅读价值在于"实践入口"而非"版本正确"

| 四元组 | 内容 |
|--------|------|
| **陈述** | 帛书本相对于传世本的核心价值不是"更正确"或"更古老"的版本学意义，而是提供了"德经在前"的实践入口——从"上德不德"的境界描述开始阅读，与"道可道"的本体论入口形成互补。 |
| **证据** | F-042（帛书德前道后）、F-043（约300处异文）、韩非子《解老》先德后道的顺序 |
| **反常识** | 一般人以为读帛书本就是读"更原始的正确版本"，但实际上《老子》文本在战国至汉魏间是流动的，不存在唯一"原版"。帛书本真正的独特贡献是提供了另一种阅读顺序和实践哲学入口。 |
| **行动** | bundle设计不做"以帛纠传"的版本批判，而是做"两种读法"的互补指南——读者可以从道经或德经开始，体验不同的哲学入口 |

## 洞察2：134种注本的正确使用方式是"按问题检索"而非"依次通读"

| 四元组 | 内容 |
|--------|------|
| **陈述** | 本地收藏147个注本文件，但初学者最容易犯的错误是要么全不读古注，要么试图从汉到民国全部读完。正确的方法是按阅读阶段和问题类型选用：入门用现代注本（1-2种），进阶用王弼+河上公，专题按兴趣选1-2家。 |
| **证据** | F-005（147个注本文件）、F-021~F-031（核心注本覆盖） |
| **反常识** | "读更多注本≠理解更深"。焦竑《老子翼》引用了历代大量注说，但它是检索工具书而非通读材料；高明《帛书老子校注》是案头查阅书，不需要从头到尾读。不同注家立场不同（玄学、道教、儒家、佛教、校勘），全读反而会陷入"公说公有理"的混乱。 |
| **行动** | bundle中按阶段（入门→进阶→专题）给出注本选用指南，明确标注每种注本的立场和适用场景 |

## 洞察3：避讳字和通假字是理解差异的关键线索而非阅读障碍

| 四元组 | 内容 |
|--------|------|
| **陈述** | 帛书本中"邦/国""恒/常"等避讳字和大量通假字（"胃"通"谓"、"免"通"晚"等），初看是阅读障碍，实则是判断抄本年代、理解文本演变的关键线索。 |
| **证据** | F-041（甲本不避邦字讳）、F-010（释文存在） |
| **反常识** | 一般读者把"邦→国""恒→常"当作简单的"古代避讳常识"一笔带过，但这些改字不仅改变了语义（"恒道"的永恒性vs"常道"的常规性），还标志着文本从先秦到汉代的哲学转向——从"恒"的绝对本体到"常"的经验规律。 |
| **行动** | bundle中专门讲解避讳字和通假字的规律，重点分析"邦/国""恒/常"两组避讳的哲学影响，其他通假字列表备查 |

## 洞察4：现有laozi-lineage bundle覆盖学术侧，本bundle应覆盖阅读侧

| 四元组 | 内容 |
|--------|------|
| **陈述** | 已有的laozi-lineage bundle（位于SpecWeave/bundles/）侧重版本学、文献学、考古学，面向研究者；新bundle应面向普通读者，解决"怎么开始读""读哪个版本""遇到异文怎么办""注本怎么选"等实践问题。 |
| **证据** | F-045（laozi-lineage含8传本、2考古、4异文、2方法论）、F-002~F-007（223文件分类） |
| **反常识** | 一般认为"先有版本知识才能读古书"，但实际上普通读者完全可以先读现代人注本建立理解，再回头补充版本知识。学术准备不是阅读的前置条件，而是深度阅读后的自然需求。 |
| **行动** | 两个bundle通过cross-reference互联但不重复——laozi-lineage讲"版本怎么流传"，boshu-reading讲"拿到帛书怎么读" |
