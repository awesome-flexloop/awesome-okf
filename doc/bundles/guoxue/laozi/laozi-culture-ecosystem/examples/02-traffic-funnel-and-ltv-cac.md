# 流量漏斗与 LTV/CAC 算例

> **重要声明**：以下数字、情景与参数均为**教学假设**，用于演示机制如何工作，**不构成任何投资、经营、政策或财税建议**，也不代表任何真实平台、项目或企业的数据。全部数字均为教学算例。

## 一、基础设定

教学情景：某文化内容方在线上投放，用户沿「曝光 → 点击 → 线索 → 成交 → 复购」的漏斗逐段流失，需要判断获客投入能否被用户的存续期贡献覆盖。

流量指单位时间内到达某一内容、页面或渠道的访问或互动次数（F-023）；转化漏斗各阶段转化率相乘构成总体转化率（F-025）；获客成本 CAC 等于统计期内获取支出除以同期新增用户数（F-026）；LTV 由客单价、复购频次与毛利率估算（F-027）。

显式假设：

| 参数 | 符号 | 取值 | 说明 |
|---|---|---|---|
| 月曝光量 | I | 100,000 次 | 教学假设（F-023） |
| 点击率 | CTR | 5% | 曝光 → 点击 |
| 点击 → 线索转化率 | r1 | 8% | 留资 / 进群 |
| 线索 → 成交转化率 | r2 | 25% | 首购 |
| 客单价 | AOV | 300 元 | 教学假设 |
| 毛利率 | m | 40% | 首购与复购同率 |
| 年复购次数 | f | 2 次/年 | 复购间隔 6 个月 |
| 平均存续年限 | n | 2 年 | 教学假设 |
| 月营销支出 | M | 15,000 元 | 投放 |
| 月渠道费 | Ch | 5,000 元 | 渠道维护 |
| 贴现率 | r | 10%/年 | 用于折现口径对照 |

补充口径：品牌与广告可作为质量信号，影响前端点击率与线索转化率（F-032）；作为对照，事实清单另给出两组教学算例——CAC 算例（F-029：支出 10,000 元、新增 200 人 → 50 元/人）与 LTV 算例（F-030：客单价 100、年复购 2、毛利率 40%、存续 2 年 → 约 160 元），本章数字与之同为教学假设。

## 二、逐步计算

**第 1 步 · 漏斗各阶段人数**

- 点击 = 100,000 × 5% = 5,000
- 线索 = 5,000 × 8% = 400
- 成交（新客）= 400 × 25% = **100 人/月**
- 总体转化率 = 5% × 8% × 25% = **0.1%**（各阶段相乘，F-025）

**第 2 步 · CAC**

- CAC = (15,000 + 5,000) ÷ 100 = **200 元/人**（F-026）

**第 3 步 · LTV**

- 单客首单毛利 = 300 × 40% = 120 元
- 年毛利 = 120 × 2 = 240 元
- LTV = 240 × 2 = **480 元**（F-027）

**第 4 步 · LTV/CAC**

- 480 ÷ 200 = **2.4**（F-031）

**第 5 步 · 首月现金对照**

- 月首单毛利 = 120 × 100 = 12,000 元
- 月支出 = 15,000 + 5,000 = 20,000 元
- 月首单现金 = 12,000 − 20,000 = **−8,000 元**

**第 6 步 · 存续期口径对照**

- 100 位新客存续期总毛利 = 480 × 100 = 48,000 元
- 减获客成本 = 200 × 100 = 20,000 元
- 存续期净贡献 = **28,000 元**

## 三、结果

| 指标 | 结果 |
|---|---|
| 月成交（新客） | 100 人 |
| CAC | 200 元/人 |
| LTV | 480 元/人 |
| **LTV/CAC** | **2.4** |
| 首月首单现金 | −8,000 元 |
| 存续期净贡献（100 客） | 28,000 元 |
| 折现后 LTV（r = 10%） | ≈ 447.5 元 |
| 折现后 LTV/CAC | ≈ 2.24 |
| CAC 回收期 | 约 6 个月（第 2 次购买时点） |

**回收期推导**：单客累计毛利在第 1 次购买（t = 0）为 120 元，不足 CAC 200 元；第 2 次购买（t = 6 个月，复购间隔 = 12 ÷ 2）累计 240 元 ≥ 200 元 → 回收期约 **6 个月**。

**折现 LTV 推导**（每次购买毛利 120 元，r = 10%，t = 0 / 0.5 / 1.0 / 1.5 年）：

- 120 + 120/1.10^0.5 + 120/1.10 + 120/1.10^1.5 ≈ 120 + 114.4 + 109.1 + 104.0 ≈ **447.5 元**

关键结论：**首月现金为负、LTV/CAC > 1**，二者并不矛盾——前者是现金口径的时间分布（F-015），后者是存续期口径的净贡献（F-031）。回流能否维持闭环，取决于回流量与回流速度两个变量（F-016），而 LTV/CAC 的数值会随口径（是否折现、是否含运营成本）变化。

## 四、敏感性 / 边界情形

**情形 A · 存续年限由 2 年降至 1 年**

- LTV = 300 × 40% × 2 × 1 = 240 元
- LTV/CAC = 240 ÷ 200 = **1.2**

机制方向：留存与存续年限直接压缩 LTV，比值趋近 1（F-028）。

**情形 B · 点击率由 5% 降至 3%**

- 点击 = 3,000；成交 = 3,000 × 8% × 25% = 60 人
- CAC = 20,000 ÷ 60 ≈ **333.3 元/人**
- LTV/CAC = 480 ÷ 333.3 ≈ **1.44**

机制方向：漏斗前端一点下滑，会沿乘法链条放大到成交人数与 CAC（F-025）。

**边界情形 · LTV/CAC = 1 与 < 1**

- 比值 = 1：单位用户的存续期净贡献恰好抵消获客成本（不计运营成本）；
- 比值 < 1：单位用户净贡献为负，规模扩张不能自行覆盖获客投入（F-031）。

比值大小与口径绑定：是否折现、是否摊入运营成本，都会改变结论，比较不同方案时须先统一口径。

## 五、常见误读

| 误读 | 纠正 | 依据 |
|---|---|---|
| 「LTV/CAC 越大越该加投放」 | 比值高也可能来自 LTV 口径宽松或留存假设乐观，须先核对口径与假设 | F-031 |
| 「LTV 是已经赚到的钱」 | LTV 是存续期的**期望**贡献，依赖留存与复购假设 | F-027、F-028 |
| 「首月亏钱就是模式不成立」 | 首月负现金流是时间结构问题，须看回收期与存续期口径 | F-015、F-016 |
| 「漏斗某一环提升 10% 只多 10%」 | 各阶段相乘，单环提升对总量是乘数效应 | F-025 |
| 「流量峰值高就是健康」 | 场域的可自我维持取决于现金流规模、速度与信息反映度，峰值不等于可持续 | F-017 |

## 六、小结

本算例把「曝光 → 点击 → 线索 → 成交 → 复购」的漏斗逐段拆开，算出 CAC（200 元）、LTV（480 元）、比值（2.4）与回收期（约 6 个月）。要点是：**现金口径与存续期口径回答的是两个不同问题**——前者看时间分布（F-015），后者看净贡献（F-031）；而闭环的可持续性还须看回流速度（F-016）。LTV/CAC 的边界（趋近 1 或低于 1）提示获客投入能否被存续期贡献覆盖。
