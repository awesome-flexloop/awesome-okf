# 算例索引

本目录提供 4 篇教学材料：3 篇可复算的现金流算例（渠道分成与场地费、流量漏斗与 LTV/CAC、利他现金流时间结构）与 1 篇闭环四维对照卡（自查工具）。算例用于训练「现金如何在生态圈中分配与回流」的因果直觉，对照卡用于逐条判定闭环是否成立。

## 文档列表

| 序号 | 文档 | 一句话说明 | 适用读者 |
|------|------|-----------|---------|
| 01 | [渠道分成与场地费现金流算例](./01-channel-split-and-venue-cash-flow.md) | 在「渠道点位 + 分成比例」下分步推演生态圈与渠道方的现金分配，并演示渠道价差如何被竞争抹平 | 想理解分成口径、场地费与渠道价差衰减的读者 |
| 02 | [流量漏斗与 LTV/CAC 算例](./02-traffic-funnel-and-ltv-cac.md) | 拆解曝光 → 点击 → 线索 → 成交 → 复购的漏斗，算出 CAC、LTV、比值与回收期 | 想弄清获客成本与用户价值口径的读者 |
| 03 | [利他现金流「先予后取」时间结构算例](./03-altruistic-cash-flow-give-first.md) | 对比「高毛利快收」与「低毛利慢回流」两条现金流序列，演示回流速度对闭环的影响 | 想训练现金流时序直觉、理解让渡周期的读者 |
| 04 | [生态圈闭环四维对照卡与自查清单](./04-ecosystem-loop-scorecard.md) | 现金 / 信息 / 信任 / 规则四维逐条对照，附可直接勾选的自查清单 | 想快速体检一个生态圈闭环是否成立的读者 |

## 推荐阅读顺序

1. **先练直觉**：[01 渠道分成与场地费](./01-channel-split-and-venue-cash-flow.md) → [02 流量漏斗与 LTV/CAC](./02-traffic-funnel-and-ltv-cac.md)，建立「现金净额」与「口径差异」的基本感；
2. **再看时间结构**：[03 利他现金流「先予后取」](./03-altruistic-cash-flow-give-first.md)，理解回流速度与前置周期如何决定成败；
3. **最后做体检**：[04 闭环四维对照卡](./04-ecosystem-loop-scorecard.md)，用清单逐条核对。

若只想解决单一问题，可直接跳到对应篇目；建议先读理论轨 [02 流量变现](../concepts/02-traffic-monetization.md)、[03 渠道变现](../concepts/03-channel-monetization.md)、[04 利他现金流](../concepts/04-altruistic-cash-flow.md)，再动手计算。
