## 二、文化生态圈与现金流总论

| 编号 | 事实内容 | 信源 |
|------|---------|------|
| F-013 | 罗闻全（2004）以生态系统类比市场：参与者的策略在竞争中被模仿或淘汰，环境变化又产生新机会，二者共同演化（适应性市场假说）。本主题所称"文化生态圈"沿用这一生态类比，指以同一文化主题为核心、由内容生产、传播、社群、交易、服务等参与者围绕共同资源与规则相互作用并共同演化的系统。 | S33 |
| F-014 | 生态圈的要素可归纳为五类：参与者（生产者、传播者、消费者、服务者）、资源（内容、注意力、信任、渠道）、规则（定价、分成、准入、合规）、交换关系（流量、商品、服务、现金的流向）与演化过程（规模与效率随时间变化）。 | S33、S36 |
| F-015 | 现金流（cash flow）指一定期间内现金与现金等价物的流入与流出；在经营语境中，收入与支出按时间排列形成现金流序列，其规模与时间分布共同决定资金周转状况。 | S36 |
| F-016 | 现金流闭环指系统内产生的现金流入能够回流至系统的再投入环节（内容生产、渠道维护、用户服务），形成"投入—产出—再投入"的循环；闭环的观察指标为回流量与回流速度。 | S36 |
| F-017 | 场域在本主题中指交易与交换关系集中发生的制度空间，包含参与者、规则、价格信号与信任关系；"现金流有效场域"指上述空间内现金流的规模、速度与信息反映程度达到可自我维持的状态。 | S10、S22 |
| F-018 | 本主题以三条现金流为骨架：①流量变现——将注意力转化为现金；②渠道变现——将渠道与点位（场地、代理、分销关系）转化为现金；③利他现金流——以先行让利换取持续现金回流。三者分别对应注意力与信息市场、分销与中间层结构、信号与信任机制。 | S8、S15、S36 |
| F-019 | 注意力在信息供给远大于需求的环境下具有稀缺属性；注意力的总量受人均可用时间约束，其分配由供给方的可见性与需求方的选择共同决定。 | S36 |
| F-020 | 分工受市场范围限制（斯密 1776）：市场越大、交换越便利，专业化分工越深；本主题的"多形态商业圈"可视为文化生态圈内部把内容生产、分销、服务等环节分化的结果。 | S7 |
| F-021 | 价格具有双重功能：传递稀缺信息与提供行为激励（哈耶克 1945）；在文化生态圈中，定价既是收益分配的载体，也是参与者决策的信号。 | S10 |
| F-022 | 市场是买者与卖者相互作用、交换商品与服务的制度化安排，可表现为集市、交易所或线上撮合系统；它同时是一般均衡与局部均衡分析的对象（瓦尔拉斯 1874；马歇尔 1890）。 | S7、S8、S9、S36 |

## 三、流量变现机制

| 编号 | 事实内容 | 信源 |
|------|---------|------|
| F-023 | 流量指单位时间内到达某一内容、页面或渠道的访问或互动次数；常见口径包括曝光量、点击量、独立访客数与活跃用户数。 | S36 |
| F-024 | 注意力总量受用户可用时间约束，内容供给的增长不改变人均可用时间总量；在这一约束下，注意力的分配呈竞争状态。 | S36 |
| F-025 | 转化漏斗（funnel）指用户从触点到达、互动、留资到成交的分阶段流失结构；各阶段转化率相乘构成总体转化率。 | S36 |
| F-026 | 获客成本（CAC）指为获取一位新用户所付出的全部营销与渠道费用，等于统计期内的获取支出除以同期新增用户数。 | S36 |
| F-027 | 用户生命周期价值（LTV）指一位用户在与平台的关系存续期间为平台带来的净贡献总和，通常由客单价、复购频次与毛利率估算。 | S36 |
| F-028 | 留存率指某一时点的新增用户在后续某时点仍然活跃的比例；留存曲线描述留存率随时间的衰减。 | S36 |
| F-029 | 商业算例：某统计期内获取支出为 10000 元、新增用户 200 人，则 CAC 为 50 元/人（教学算例，非真实经营数据）。 | S36 |
| F-030 | 商业算例：客单价 100 元、年复购 2 次、毛利率 40%、平均存续 2 年的用户，其 LTV 约为 160 元（教学算例，非真实经营数据）。 | S36 |
| F-031 | 商业分析中常用的判据为 LTV 与 CAC 的比值；比值大于 1 表示单位用户的净贡献为正，比值随口径（是否计入运营成本、是否折现）变化。 | S36 |
| F-032 | 广告与品牌可作为质量信号：在信息不对称条件下，卖方通过广告投入与品牌声誉向买方传递质量信息，降低买方的不确定性（斯彭斯 1973 信号传递）。 | S15 |

## 四、渠道变现机制

| 编号 | 事实内容 | 信源 |
|------|---------|------|
| F-033 | 渠道指商品或服务从供给方向需求方转移所经过的中间环节，包括实体渠道（门店、场地、集市）与线上渠道（平台、社群、私域）。 | S36 |
| F-034 | 渠道分层指同一商品经由一级、二级等多层中间环节到达终端；每层抽取的价差称为分成或抽成，分成比例以成交额或毛利为基数。 | S36 |
| F-035 | 一价定律（law of one price）：在无摩擦、可自由交易的市场中，同一资产（或等价资产）应有同一价格，价格偏离会被套利纠正（马歇尔 1890）。【P0】 | S8、S36 |
| F-036 | 渠道价差指同一标的在不同渠道的报价差异；差异的表现来源包括信息成本、交易成本、渠道层级与服务内容的差别。 | S8、S36 |
| F-037 | 渠道点位（场地、展位、货架）具有排他性与稀缺性；场地费、进场费、货架费是渠道方对点位占用收取的费用。 | S13、S36 |
| F-038 | 代理与分销的常见法律形态包括经销（买断转售）、代销（受托代售）与居间（撮合收费）；三种形态在库存风险、定价权与结算时点上不同。 | S36 |
| F-039 | 渠道冲突指同一供给方的不同渠道在价格、客户与库存上的竞争关系；常见表现包括串货、跨渠道比价与终端价格失控。 | S36 |
| F-040 | 交易成本（搜寻、缔约、履约、监督成本）与渠道层级的数量相关：交易成本较高时中间层存在空间，较低时供给方与需求方可以更直接地交易（科斯 1960 的制度与交易成本视角）。 | S12 |
| F-041 | 中间层的信息与信誉功能：当终端买方难以核验商品质量时，具备信誉的中间层以自身声誉作担保承担质量甄别功能（与阿克洛夫 1970 逆向选择问题相对）。 | S14 |
| F-042 | 渠道竞争的收敛取向：竞争者发现可获利的渠道价差后，更多供给与资金进入该渠道，价差收窄（与格罗斯曼—斯蒂格利茨 1980 关于竞争抹平超额收益的表述一致）。 | S17 |

## 五、利他现金流机制

| 编号 | 事实内容 | 信源 |
|------|---------|------|
| F-043 | 利他现金流指供给方先行让渡部分价值（免费内容、试用、补贴、无偿服务）以换取后续现金回流的机制；其时间结构为"先予后取"。 | S15 |
| F-044 | 信号传递（斯彭斯 1973）：信息优势方以高成本、难伪造的行动自证质量；免费或低价提供高质量内容可作为一种能力与诚意的信号。【P0】 | S15 |
| F-045 | 信号的有效性条件：信号成本对低质量方高于对高质量方（差异成本），否则信号可被模仿而失去区分力。 | S15 |
| F-046 | 逆向选择（阿克洛夫 1970）：信息不对称条件下，买方按平均质量出价使优质供给退出、劣质供给留下（柠檬市场）；声誉制度是对该问题的常见回应。【P0】 | S14 |
| F-047 | 信任与声誉是两个概念：信任是交易一方对另一方行为的主观预期，声誉是关于该方过往行为的公共记录；声誉的积累依赖重复交易与可观察的历史。 | S14、S16 |
| F-048 | 消费者剩余（马歇尔 1890）：买方愿意支付的最高价格与实际支付价格之差；用户剩余让渡指供给方主动扩大买方的剩余，以换取重复交易与推荐。 | S8 |
| F-049 | 重复关系中的合作条件：当交易关系持续且双方可观察对方行为时，短期让利可以在后续交易中回收；关系终止的可能性越低，合作越容易维持。 | S16 |
| F-050 | 复利指收益按周期并入本金后继续产生收益的累积方式；在利润率固定且收益全部再投入的算例中，资金规模随时间呈指数增长（教学算例，非收益承诺）。 | S27、S36 |
| F-051 | 飞轮效应指系统中多个环节互为输入与输出、形成正反馈循环；市场本身被视为参与者行为与价格相互反馈的系统（罗闻全 2004 的反馈回路表述）。 | S33 |
| F-052 | 利他现金流的可持续性判据：让渡成本可由后续现金回流覆盖，且回流的现值不低于让渡成本的现值（净现值为正）；该判据为财务分析口径，不构成任何收益承诺。 | S36 |

## 六、现金流有效场域与市场机制

| 编号 | 事实内容 | 信源 |
|------|---------|------|
| F-053 | 价格发现指市场通过交易把分散信息聚合进价格的过程；价格是无数买卖决策合成的结果（哈耶克 1945 的知识分散与价格传递信息）。【P0】 | S10 |
| F-054 | 私有信息通过交易逐步被价格吸收：掌握私有信息的交易者通过下单把信息传递进市场，私有信息逐步转化为公共信息。 | S10、S22 |
| F-055 | 套利指在同一或相关标的上同时买卖以锁定价差的交易；一价定律的偏离构成套利的对象。 | S17、S36 |
| F-056 | 无套利假设：若不存在无风险套利机会，价格之间须满足特定关系；该假设不需要关于投资者偏好的信息，只检验价格之间的自洽性（夏普 1964 年前后 CAPM 体系）。 | S23 |
| F-057 | 竞争抹平超额收益：可获利机会被更多资金进入后价差收窄，超额收益衰减；发现者获得的超额收益对应其承担的信息成本与风险（格罗斯曼—斯蒂格利茨 1980）。 | S17 |
| F-058 | 格罗斯曼—斯蒂格利茨悖论（1980）：若价格已反映全部信息，则无人有成本搜集信息的动机；若无人搜集信息，价格又无法反映这些信息；两种情形不能同时成立，完全信息有效的市场不能存在。【P0】 | S17 |
| F-059 | 均衡只能是部分有效：价格须足够有信息量以补偿信息采集者，又不能完全揭示信息，使信息生产具有回报；效率的表现形式为有程度、有边界、因市场而异。 | S17 |
| F-060 | 信息不对称指交易一方掌握另一方不知道的关键信息；其后果之一是逆向选择，即在签约前按平均质量定价使优质供给退出。 | S14 |
| F-061 | 外部性（庇古 1920）：经济活动对未直接参与交易的第三方产生的影响；负外部性对应过度生产，正外部性对应供给不足。【P0】 | S11 |
| F-062 | 公共品（萨缪尔森 1954）具有非排他性与非竞争性，对应搭便车问题与私人供给不足；文化通识内容的传播具有近似公共品的属性。【P0】 | S13 |

## 七、效率边界：EMH/AMH 与行为金融

| 编号 | 事实内容 | 信源 |
|------|---------|------|
| F-063 | 有效市场假说（EMH）由尤金·法玛 1970 年在《有效资本市场：理论与实证研究综述》中正式提出；其含义为价格完全反映所有可得信息，机制基础是套利与竞争把信息压进价格。【P0】 | S22 |
| F-064 | EMH 三种形态：弱式——价格反映历史价格与成交量信息（技术分析无法持续获利）；半强式——价格反映所有公开信息（基本面分析难以持续跑赢，检验方式为事件研究）；强式——价格反映包括内幕信息在内的所有信息。【P0】 | S22、S24 |
| F-065 | 三种形态呈嵌套关系：强式包含半强式，半强式包含弱式；反之不成立。 | S22 |
| F-066 | 联合假设问题：检验 EMH 必须先设定一个定价模型；当价格偏离模型时，无法区分"市场无效"与"模型错误"，EMH 不能单独被检验。 | S22 |
| F-067 | 随机游走：巴舍利耶 1900 年博士论文《投机理论》首次以随机过程（布朗运动）描述资产价格；肯德尔 1953 年对英国股价指数序列的实证发现股价序列近似随机、无可预测模式。【P0】 | S18、S19 |
| F-068 | 萨缪尔森 1965 年给出证明：在竞争性市场中，若价格充分反映可得信息，则价格变动不可预测；"信息有效"与"可预测的获利机会"在逻辑上不能同时成立。【P0】 | S20 |
| F-069 | 理性预期（穆斯 1961）：个体的主观预期平均而言与真实经济模型一致，不会系统性犯错；该假设不要求人人理性，只要求错误不构成可反复利用的获利机会。【P0】 | S21 |
| F-070 | 规模与价值异象（法玛与弗伦奇 1993）：小市值股票与高账面市值比（价值股）长期取得超额收益，构成三因子模型（市场、规模、价值）的基础；对该收益的解释存在风险补偿与定价错误两种（法玛与席勒于 2013 年同获诺贝尔经济学奖，观点对立）。【P0】 | S25、S29、S36 |
| F-071 | 动量异象（杰加迪什与蒂特曼 1993）：过去 3–12 个月表现好的股票在随后数月倾向继续跑赢，为最难用风险补偿解释的异象之一；哈维、刘、朱 2016 年提出数据挖掘与多重检验警戒，主张新因子的 t 值门槛应远高于 2。【P0】 | S26、S35 |
| F-072 | CAPM（夏普 1964 年前后）给出风险与预期收益的均衡关系：承担更多系统性风险对应更高的预期收益；CAPM 本身受大量质疑，其动摇会连带影响"用 CAPM 检验 EMH"的结论。 | S23、S27 |
| F-073 | 主动与被动对照证据（SPIVA 报告，标普道琼斯指数公司，按年发布）：以约 15 年长周期计，约九成美国大盘主动基金未跑赢 S&P 500，且业绩持续性弱。【P0】 | S34 |
| F-074 | 行为金融与适应性市场：前景理论（卡尼曼与特沃斯基 1979）提出损失厌恶（损失痛苦约为等额收益快乐的 2–2.5 倍）、参照点依赖与概率权重扭曲；席勒 1981 年实证发现股价波动幅度超出基本面所能解释的程度，《非理性繁荣》（2000）分析情绪周期并提出 CAPE；塞勒 2017 年因心理账户、禀赋效应与"助推"研究获诺贝尔经济学奖；有限套利（施莱弗与维什尼 1997）指出错误定价可能先变得更错、套利者受资金与卖空约束；罗闻全 2004 年提出适应性市场假说（AMH），将效率表述为随竞争与参与者演化的动态状态。【P0】 | S28、S29、S30、S31、S32、S33 |
