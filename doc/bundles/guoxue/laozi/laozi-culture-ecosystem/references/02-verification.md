## 二、口径留痕

### 1. 老子章序口径

- **通行本口径**：81 章，《道经》第 1–37 章、《德经》第 38–81 章（F-006）。
- **帛书口径**：不分 81 章，以分章符（黑点）标示段落，《德经》在前、《道经》在后（F-003）；德经对应通行本第 38–81 章，道经对应通行本第 1–37 章。
- **本包规则**：凡引用章号一律标注「通行本章号」；帛书篇序单独说明，不与通行本章号混称。北大汉简本另有「上经/下经」篇题与 44/33 章的分章（F-005），单独登记。

### 2. 异文并列不混称原则

- 凡涉及异文（邦/国、恒/常、有静/不争、大器免成/晚成、弗/不、也字有无），**以帛书用字为准、传世用字并列标注**，写作「帛书作 X（传世本作 Y）」的形式。
- **不将任一读法写成定论**：涉及学界仍有争议者（如「大器免成」之「免」训「无/不」与通「晚」两说），一律并置两侧（F-011）。
- 避讳改字（邦/国、恒/常）与实词异文（大器免成/晚成）**分列说明**：前者为制度性改字，后者牵引义理分野，两者性质不同，不作同类归并。

### 3. 教学算例标注

- 凡出现收益率、转化率、CAC、LTV、分成比例、复利累积等数字，一律标注「教学算例」，并在 [facts.md](../facts.md) 的 F-029、F-030、F-050 及声明条 F-084 中明确其非真实经营数据。
- 教学算例仅用于说明机制（如 CAC 的算法、LTV 与 CAC 比值的口径、复利的累积方式），**不代表任何真实平台费率、行情数据、机构业绩或个人经营收支**。

## 三、放弃核验清单

以下内容**本包不做核验或不作为事实主张**，列明以免误用：

| 项目 | 处理方式 | 原因 |
|---|---|---|
| 任何真实平台的费率、抽成比例与分成规则 | 不收录 | 时效敏感、随平台政策调整，且构成具体平台指向 |
| 任何实时流量数据、行情数据、指数点位 | 不收录 | 不可核验、时效性强、构成数据引用风险 |
| 任何具体机构、个人的经营数据与收支明细 | 不收录 | 属个体私域数据，不可公开核验 |
| 任何具体商业项目、产品的收益表现 | 不收录 | 构成产品推荐与收益暗示 |
| 任何对「文化生态圈能否盈利」的量化预测 | 不判定 | 属预测而非事实，且依赖个体执行与外部环境 |
| 具体法律法规条文与最新数字 | 只给原则 | 会调整，须以监管部门官网最新发布为准（F-077、F-078） |
| 各学派的「最优」商业模式处方 | 不判定 | 涉及价值判断与场景差异，超出通识范围 |
| 帛书本个别残损字的补释字形 | 只录整理本释文 | 字形考释各家有异，以整理本与校注本图版为准（F-011） |

## 四、核验边界声明

1. **文本边界**：本包帛书文句取自出土整理本与校注本的通行转写（S1–S6）；帛书甲、乙本多有残损，个别字词在不同整理本间或有出入，本包不新增未经核验的释读，涉及争议处并置两侧。
2. **机制边界**：本包市场机制事实与 [efficient-markets](../../../../sheke/markets/efficient-markets/facts.md) 同口径登记；凡理论、假说（EMH、CAPM、理性预期、各因子异象）均按「谁提出、何年提出、原文主张什么、争议在哪」客观登记，**不把假说写成定律**。
3. **数值边界**：全部数值型事实（F-029、F-030、F-050）为教学算例，非真实数据；本包不提供任何真实费率、行情或业绩数字。
4. **时效边界**：信源记于 2026-10-31，`stale_after` 为 2028-10-31；诺贝尔奖记录、SPIVA 报告与监管规则均按年更新，引用前须回官方来源复核最新发布。
5. **用途边界**：本包为通识教育材料，不构成投资建议、经营建议、法律意见或财税建议，亦不构成任何收益承诺（F-083、F-084）。
