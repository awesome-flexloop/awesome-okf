## 三、核验方式

- **帛书与出土文献**：以出土整理本与校注本的图版、释文与校勘记为准（S1–S6），异文用字逐条回原书核校；本包沿用本地知识包 [`laozi-lineage`](../../laozi-lineage/index.md) 与 [`boshu-reading`](../../boshu-reading/index.md) 的既有核验结论，未新增未经核验的释读。
- **诺贝尔奖记录**：nobelprize.org 检索 Akerlof / Spence / Stiglitz（2001）、Kahneman（2002）、Fama / Shiller / Hansen（2013）、Thaler（2017）。
- **学术论文**：以期刊卷期页码为准，可在 JSTOR、各期刊官网或 Google Scholar 检索原文标题核验；引用时标注卷期。
- **行业统计**：SPIVA 报告可在标普道琼斯指数公司官网按年下载，注意区分不同市场与不同统计期。
- **教科书叙述**：供需模型、外部性、公共品、逆向选择、现金流与获客成本等属标准教科书内容，以主流经济学教材交叉核对。
- 详细核验记录见 [02-verification.md](02-verification.md)。

## 四、使用建议

1. **文本先于机制**：先读 S1–S6 建立帛书文本基线（篇序、避讳、异文），再读 S7–S36 建立「市场如何运转」的坐标系。
2. **理论、证据分开读**：EMH、CAPM、理性预期是**描述市场的理论模型**，不是操作指令；SPIVA、异象是**证据**，两者不可混为一谈。
3. **异文并列、不混称**：凡异文一律并列呈现（如「大器免成」/「大器晚成」），以帛书用字为准、传世用字并列标注，不将任一读法写成定论。
4. **争议必须两面并读**：法玛（S22）与席勒（S29、S30）的观点在同一年获诺奖（2013），任何只引用一方的读法都是选择性引用。
5. **警惕以经典为名的营销**：经典著作与学术结论被大量「荐股」「代客理财」「包赚项目」内容引用背书；凡承诺收益、催促付费、拉群荐股的，均不属于本知识体系（见 [facts.md](../facts.md)）。
