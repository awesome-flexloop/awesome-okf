# 《九章算术》的结构与体例

## 成书与作者

《九章算术》不是一人一时之作，而是战国至汉代官私算术长期积累、经多人删补定型的问题集。刘徽《九章算术注·序》（263 年）追述其源于"九数"，经西汉张苍、耿寿昌等删补（F-022、F-023）；现代研究（据 r-qian-history、r-guoxuedashi）一般认为其定本约成于东汉初年（公元 1 世纪）。书中 246 道题目（F-024）至今仍是研究汉代数学最系统的文本。

| | **合计** | **246** | |

九章的分类逻辑不是按数学理论分支，而是按**国家治理的实际事务**：田亩、粮政、分配、工程、赋役（F-025~F-031）。这决定了中算"问题—算法"的组织形态。

## 问—答—术体例

每题由三部分组成：

- **问**：具体题目，含数据。如方田章首题："今有田广十五步，从十六步。问为田几何？"
- **答**：具体答案。"答曰：一亩。"（古制 240 平方步为一亩。）
- **术**：算法程序。分两类：一类是针对一类问题的**通用术文**（如方田章"合分术"、方程章"方程术"），一类是本题专用的计算步骤。术文只给程序与依据的比率关系，不作演绎证明——证明由注文承担。

## 注的传统：刘徽与李淳风

《九章》的理论高度主要体现在注中：

- **刘徽注**（263 年）：对每条术文给出原理论证，创割圆术、极限分割、出入相补、齐同原理，并自撰《重差》一卷（后独立为《海岛算经》）。详见 [05-liuhui-commentary.md](05-liuhui-commentary.md)。
- **李淳风等注**（656 年）：奉敕为算学馆教材作注，引祖暅球积说等，与刘注并行传世（F-002）。

今传本经文、刘注、李注合刻，读《九章》必须读注，否则只见算法不见道理。

## 原文选读（方田·合分术）

> **合分术曰**：母互乘子，并以为实；母相乘为法，实如法而一。不满法者，以法命之。其母同者，直相从之。
>
> ——《九章算术·方田》，底本《四部丛刊初编》本（s-ctext-jiuzhang，res 77423）

**逐句解读**：两个分数 $\frac{a}{b}$ 与 $\frac{c}{d}$ 相加，"母互乘子"即 $ad$ 与 $bc$，"并以为实"得分子 $ad+bc$；"母相乘为法"得分母 $bd$；"实如法而一"即相除。也就是：

$$
\frac{a}{b}+\frac{c}{d}=\frac{ad+bc}{bd}
$$

"不满法者，以法命之"指余数小于分母时以分数表示；分母相同时直接分子相加。这是世界数学史上最早的系统分数运算法则之一。
