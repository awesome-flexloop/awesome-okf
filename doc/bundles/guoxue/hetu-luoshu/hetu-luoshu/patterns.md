# 河图洛书·可复用阅读模式（Reusable Reading Patterns）

> 从本次河图洛书调研（facts.md F-001～F-053）萃取的可复用阅读模式。每个模式含触发场景、核心步骤、反模式（均为本次调研实际撞见/规避的教训）、检验标准与跨领域迁移示例。

---

## 模式 1：层累符号史阅读法（名实三层剥离）

**模式名**：层累符号史阅读法——对一个被使用了上千年的符号名，按时代切开它的所指层，让"名字史"与"实体史"分离。

**触发场景**：

- **适用**：研究对象是一个跨时代高频出现、所指疑似漂移的文化符号（河图洛书、太极、八卦、阴阳、五行、风水、龙、经络、命门……）；遇到"X 其实是 Y"式翻案文章需要裁决；要为这类符号写教程或知识库；面对"考古发现证实了 X"的报道。
- **不适用**：所指稳定的专名（如具体人名、地名、单一著作）；纯自然科学对象（对象史与概念史合一）；当代新造术语（尚无层累，直接查定义即可）。

**核心步骤**：

1. **锚定符号名，建立文献年表**：穷尽收集各时代提及该符号的文献，每条只记三件事——时代、原文怎么说、它把符号当成什么（器物？祥瑞？图？数字？原理？）。本包案例：《子罕》《顾命》《洪范》《系辞》《礼运》《明堂》六条先秦记载（F-001～F-011）。
2. **找"第一次实体描写"**：在年表中定位第一次出现**具体图像/结构/配置描写**的文献——没有图式描写的时代，符号就只停在名物层。胡渭的做法是查"古经及注疏有无列图于前者"（F-037），判决结果是"有之自朱子《本义》始"。
3. **拆零件，各自溯源**：把图式拆成可独立存在的零件（洛书=三阶幻方、河图=五行生成数、先天图=二进制卦序），每个零件单独做年表。幻方零件可追到《明堂》数序（F-010）、西汉占盘实物（F-049）；生成数零件可追到《汉书·五行志》（F-019）。
4. **断"命名合流"年代**：查明零件与符号名**何时合名**——幻方与"洛书"合名在 12 世纪（F-046 英文文献独立佐证），唐代九宫坛（F-040）还用九宫本名。合流之前，零件与名字是两条平行线。
5. **辨定型方式与竞争方案**：记录图式定型期的竞争方案与裁决者——刘牧"九为河图"vs 朱熹/蔡元定"十为河图"（F-020/F-022/F-023），定本因科举与《本义》流通而胜出；谱系叙事（朱震表 F-026）同时要做来源审查（F-027/F-028）。
6. **争议并列、推测标注**：后世解释冲突时（如凌家滩玉版 F-052 vs F-053），同页并列双方依据与证据层级；凡"X 就是 Y"的解释性结论一律以"某某认为"引出，与可逐字核对的原文分层。
7. **输出三层表**：把全部材料归入**名物层**（符号作为器物/祥瑞记载）／**图式层**（图像与配置的定型与流通）／**附会层**（术数民俗演绎），每层标注年代、代表文献、证据类型。

**反模式**（本次调研实际撞见的教训）：

1. **以名定实**：看到先秦书里有"河图"二字，就把宋代黑白点图读进去——F-002 的"河图在东序"是一件陈宝玉器，不是挂图。名字相同是层累史的起点而非证据。
2. **以真零件担保假起源**：幻方八条线皆 15 是可验算的真数学，但这不支持"伏羲受河图画八卦"的起源叙事（F-017 刘歆模式、F-038 胡渭判决）——内容正确性与历史起源是两个独立问题。
3. **辨伪扩大化**：因图式不古就宣布"河图洛书全是骗局"——胡渭否定的是"专以图书为作易之由"，幻方、生成数、卦序的数学内容与图书学的哲学史地位都不因此消灭（F-038/F-043）。
4. **考古实物直接连线传说**：把凌家滩玉版称作"五千年前的洛书/八卦实物"——硬证据是纹饰与年代（F-051），"原始八卦"是 1989 年学者的解释性假说且同年有严肃异议（F-052/F-053），中间五千年无文字链路。
5. **因果倒转叙事**：传播"莱布尼茨受《易经》启发发明二进制"——二进制 1679 年成稿、卦图 1703 年才送达（F-047），当事人自述"我若没有早发明二进制算术，我也不能明白六十四卦"。遇到跨文化"谁启发谁"的故事，先排时间线。

**检验标准**：

- 任意一句"X 是……"的陈述，都能回答：哪个时代的文献？属于名物/图式/附会哪一层？证据几级（原文双源/单源/转引/假说）？
- 图式能被拆成零件，且每个零件有独立于符号名的年代证据；
- "命名合流"有明确断代文献，合流前的零件与名字不混称；
- 争议双方的依据都能列出，推测与事实在排版上即可区分；
- 三条学习路径上的读者（新人/研究者/猎奇者）拿到三层表后不会互相误用对方层级的材料。

**跨领域迁移示例**：

- **中医史**："命门""三焦"等概念同样经历名物（《内经》部位/官能）→图式（后世命门学说、太极命门图）→附会（民间功法）三层；用本方法可裁决"命门到底是什么器官"式争论——它在不同层指不同对象。
- **技术思想史**："云原生""中台""AI Agent"等术语在十年内即可完成层累：同一术语先后指具体工具、架构范式、营销标签；写技术史或做选型时，按文献年表切层（谁第一次给出具体定义？零件——容器/编排/服务网格——各自何时成熟？何时与术语合流？），可有效识别"借旧名装新货"与"借真名担保伪起源"。
- **法律/制度符号**："宪法""法治"等词在不同政体中的所指漂移，同样适用名实剥离。

## 模式 2：可验算性分级法（三种真值状态，三种信任方式）

**模式名**：可验算性分级法——把一个知识传统中的命题按真值状态分三级，各级用不同的验证方式，拒绝跨级担保。

**触发场景**：

- **适用**：阅读一个混合了数学/技术内容、哲学义理与术数民俗的复合传统（易学、中医、风水、养生、古代天文历法）；评估"古人智慧"类内容的可信度；为这类传统写科普或教程需要划界。
- **不适用**：单一类型文本（纯数学论文直接验算、纯哲学文本直接论证分析）；伦理与价值命题（本就不适用可验算标准，但需明确声明而非混级）。

**核心步骤**：

1. **逐命题打标签**：把传统中的命题分三级——**A 可验算**（给出明确输入与操作，结果可复算/复现，如幻方八条线皆 15、2⁶=64）；**B 义理**（自洽的哲学/概念系统，如"无极而太极→阴阳→五行→万物"的生成论，可用文本分析、版本考订、哲学论证处理）；**C 附会**（不可证伪的操作与应验宣称，如占卜排盘、风水改运）。
2. **A 级做最小实验**：对每条可验算命题设计纸笔/工具最小实验（本包示例 02 的四个实验），亲自跑一遍；跑不通的降级处理。
3. **B 级做版本与辩论史**：义理命题查版本异文（Y-01 太极图说公案）、关键争论（朱陆太极之辩 F-044）、学派谱系；评价标准是论证质量与历史影响，不是"对错"。
4. **C 级只做思想史处理**：附会内容作为社会史/心态史对象研究（谁在何时为何需要它），不提供操作教程、不讨论"灵不灵"。
5. **禁止跨级担保**：A 级为真不提升 B 级起源叙事的真值（洞察 2），更不及于 C 级；B 级影响大不赋予 C 级可操作性。

**反模式**：

1. **用义理回答数学问题**：以"天人合一"解释幻方为何纵横十五——加法不需要宇宙论，且这种解释会反向稀释数学的硬度。
2. **用实验要求义理**：试图"验算"太极生成论——B 级命题没有可复算的输入输出，用错工具只会得到"不科学"的廉价判决或"深不可测"的廉价崇拜。
3. **把附会当义理尊重**：把排盘操作包装成"哲学"回避证伪——C 级与 B 级的分界就在"是否声称可操作并产生具体应验"。
4. **因 C 级可疑而否定 A 级**：因风水附会而否定幻方数学——同一传统内证据硬度可差三个数量级（洞察 3），泼洗澡水不能连孩子。

**检验标准**：

- 传统中的每条核心命题都有 A/B/C 标签且读者可复核标签理由；
- A 级命题至少有一个读者可独立完成的最小实验；
- C 级内容在教程中零操作步骤（本包 AC-4）；
- 不存在"A 级为真→起源叙事为真→C 级可信"的连锁表述。

**跨领域迁移示例**：

- **营养学/养生内容**：营养素生化机制（A 可验算）、整体健康哲学（B 义理）、食疗排毒仪式（C 附会）三级混杂，分级法可直接套用。
- **工程方法论**：可基准测试的架构指标（A）、设计哲学与原则（B）、 cargo-cult 仪式（C，如不理解前提的照搬流程）——评审技术方案时先分级再讨论。
