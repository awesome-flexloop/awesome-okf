## 二、四训结构与内容

| 编号 | 事实内容 | 信源 ID |
|------|---------|---------|
| F-005 | 《了凡四训》分四篇：立命之学、改过之法、积善之方、谦德之效。信源：`source-shuge-liaofan` | `source-shuge-liaofan` |
| F-006 | 第一篇《立命之学》：记述了凡早年被孔先生算定命运，后遇云谷禅师点化，悟"命由我造，福自己求"之理。信源：`source-ctext-liaofan` | `source-ctext-liaofan` |
| F-007 | 第二篇《改过之法》：论述改过须具羞耻心、敬畏心、笃行心三心，改过有从事上、理上、心上三层。信源：`source-baogao-liaofan` | `source-baogao-liaofan` |
| F-008 | 第三篇《积善之方》：辨析善之真假、是非、端曲、阴阳、偏正，提出十种善行与积善准则。信源：`source-shuge-liaofan` | `source-shuge-liaofan` |
| F-009 | 第四篇《谦德之效》：论述谦虚之德可获福报，以了凡自身谦德改运之经历为证。信源：`source-ctext-liaofan` | `source-ctext-liaofan` |
| F-010 | 《谦德之效》引《易经》"天道亏盈而益谦，地道变盈而流谦，鬼神害盈而福谦，人道恶盈而好谦"，为全书收束之论。信源：`source-ctext-liaofan` | `source-ctext-liaofan` |

## 三、核心命题原文摘录

| 编号 | 事实内容 | 信源 ID |
|------|---------|---------|
| F-011 | 《立命之学》："命由我造，福自己求。" ——此句为全书核心命题。信源：`source-shuge-liaofan` | `source-shuge-liaofan` |
| F-012 | 《立命之学》："从前种种，譬如昨日死；从后种种，譬如今日生。" ——改命之立志语。信源：`source-ctext-liaofan` | `source-ctext-liaofan` |
| F-013 | 《改过之法》："大抵最上乘者，须从心上改。" ——心上改为改过最高境界。信源：`source-baogao-liaofan` | `source-baogao-liaofan` |
| F-014 | 《积善之方》："善有真、有假；有端、有曲；有阴、有阳；有是、有非；有偏、有正；有半、有满；有大、有小；有难、有易。" ——五善十类辨析。信源：`source-shuge-liaofan` | `source-shuge-liaofan` |
| F-015 | 《谦德之效》收束全书，以谦德改运之亲身经历印证善恶因果不虚。信源：`source-ctext-liaofan` | `source-ctext-liaofan` |
