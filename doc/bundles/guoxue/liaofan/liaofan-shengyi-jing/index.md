# 了凡生意经（智然解读）

本知识包（bundle）收录**智然老师**于2013年在北京颐年山庄主讲的"了凡生意经——企业家研修班"课程实录，由喜马拉雅平台整理发布。全书五讲，以《了凡四训》四篇原文为经典层底本，结合现代企业经营实践进行阐释，属**阐释层**。
