## 二、核心阐释概念

| 编号 | 事实内容 | 信源 ID |
|------|---------|---------|
| F-060 | 六想方法：智然从《了凡四训·立命之学》延伸出的自我训练工具，想了凡先生当年如何被算定、遇云谷禅师、改命后的经历、如何记功过格、如何行善、晚年如何成圣。信源：同上 | `source-ximalaya-82159945` |
| F-061 | 六思方法：智然将原文叙事转化为行为层自我追问——思自己为何被算定、思自己为何无子、思自己功名有限之因、思自己性格缺陷、思改命之道、思立命之法。信源：同上 | `source-ximalaya-82159945` |
| F-062 | 十案例"家族账本"模板：智然将《积善之方》十个历史案例整理为现代企业积善参考对照表。信源：同上 | `source-ximalaya-82159945` |
| F-063 | 利他即高能量：智然阐释"利他即利己"，利他行为积累企业能量，是企业文化建设的根基。信源：同上 | `source-ximalaya-82159945` |
| F-064 | 根深方能业茂：孝悌是根，企业成就是枝叶；无根之木，虽盛必枯。信源：同上 | `source-ximalaya-82159945` |
| F-065 | 转念即转运：念头一转命马上就变，强调心念对企业经营方向的决定性作用。信源：同上 | `source-ximalaya-82159945` |
| F-066 | 三重维度：智然提出企业经营要兼顾员工成长、客户价值与社会责任三重维度，超越单纯利润追求。信源：同上 | `source-ximalaya-82159945` |
| F-067 | 正念生正气，正气养正念：企业领导者的正念是企业正气的源头，正气积累形成良性企业文化循环。信源：同上 | `source-ximalaya-82159945` |
| F-068 | 改过三心三法深度阐释：智然对《改过之法》中的三心（耻心、畏心、勇心）与三法（事上改、理上改、心上改）进行逐条阐释。信源：同上 | `source-ximalaya-82159945` |
| F-069 | 过错深重七种表现：智然列出过错深重的七种具体表现（详见《了凡生意经·改过之法》第五讲）。信源：同上 | `source-ximalaya-82159945` |
