## 零、十案例的整体结构

《积善之方》开篇即言："善有十，内则有五，外则有五。"袁了凡用十个真实案例来验证这个分类体系。

| 类别 | 编号 | 人物 | 核心善行类型 |
|------|------|------|-------------|
| 内善（阴德/内修） | ① | 杨荣（杨少师荣） | 救人于危难 |
| 内善 | ② | 杨自惩 | 执法公正+仁爱囚犯 |
| 内善 | ③ | 谢迁（谢都事） | 保全无辜性命 |
| 内善 | ④ | 莆田林氏 | 长期不间断施惠 |
| 内善 | ⑤ | 冯琦父 | 救人性命（雪中救人） |
| 外善（阳善/外修） | ⑥ | 应大猷 | 解他人之困+自我修行 |
| 外善 | ⑦ | 徐凤竹父 | 带头行善+公益基建 |
| 外善 | ⑧ | 屠康僖 | 司法纠错+制度建议 |
| 外善 | ⑨ | 包凭 | 修寺供像+化解纷争 |
| 外善 | ⑩ | 支立父 | 司法公正+拒绝诱惑 |

## 一、十案例逐条详述

### 案例①：杨荣（杨少师荣）—— 救人即不取财

**【人物背景】**
建宁人，世代以摆渡为生。

**【原文精读】**
> 世以济渡为生，久雨溪涨，横流冲毁民居，溺死者顺流而下，他舟皆捞取货物，独少师曾祖及祖，惟救人，而货物一无所取，乡人嗤其愚。
> 逮少师父生，家渐裕，有神人化为道者，语之曰："汝祖父有阴功，子孙当贵显，宜葬某地。"遂依其所指而窆之，即今白兔坟也。后生少师，弱冠登第，位至三公，加曾祖，祖，父，如其官。子孙贵盛，至今尚多贤者。

**【施善行为拆解】**
| 要素 | 内容 |
|------|------|
| 情境 | 暴雨成灾，洪水泛滥，居民被冲毁，溺水者顺流而下 |
| 常人反应 | 其他船民趁乱捞取落水者的财物 |
| 杨氏反应 | 只救人，不取分文货物 |
| 当时评价 | "乡人嗤其愚"——周围人嘲笑他们愚蠢 |

**【余庆结果】**
| 代际 | 结果 |
|------|------|
| 曾祖父/祖父 | 行善时未获回报，反遭嘲笑 |
| 父亲 | 家道渐裕（开始好转） |
| 杨荣本人 | 弱冠登第，位至三公（最高官阶） |
| 曾祖/祖/父追封 | 均获追赠三公之位 |
| 后代 | 子孙贵盛，至今尚多贤者 |

**【案例特征归类】**
- 善行类型：**救人于危难**（人命关天的紧急救助）
- 善的性质：**阴德**（无人知晓，只求救人）
- 关键品质：**在众人逐利时坚守道义**（逆势而为）
- 余庆速度：**三代显贵**（祖父行善→父亲家裕→自己三公）

### 案例②：杨自惩—— 执法公正+仁爱囚犯

**【人物背景】**
鄞人，初为县吏。

**【原文精读】**
> 初为县吏，存心仁厚，守法公平。时县宰严肃，偶挞一囚，血流满前，而怒犹未息，杨跪而宽解之。宰曰："怎奈此人越法悖理，不由人不怒。"自惩叩首曰："上失其道，民散久矣，如得其情，哀矜勿喜；喜且不可，而况怒乎？"宰为之霁颜。
> 家甚贫，馈遗一无所取，遇囚人乏粮，常多方以济之。一日，有新囚数人待哺，家又缺米；给囚则家人无食；自顾则囚人堪悯；与其妇商之。妇曰："囚从何来？"曰："自杭而来。沿路忍饥，菜色可掬。"因撤己之米，煮粥以食囚。后生二子，长曰守陈，次曰守址，为南北吏部侍郎；长孙为刑部侍郎；次孙为四川廉宪，又俱为名臣；今楚亭，德政，亦其裔也。

**【施善行为拆解】**
| 要素 | 内容 |
|------|------|
| 善行一 | 劝谏严酷县宰：引用《诗经》"如得其情，哀矜勿喜"，平息县宰怒火 |
| 善行二 | 长期接济囚犯：囚犯没饭吃，自己家也缺米，仍多方济助 |
| 善行三 | 与妻子商量：遇到两难（给囚则家人无食），与妻子共同决策 |
| 妻子的角色 | 妻子问囚犯来源，得知"沿路忍饥，菜色可掬"后，同意撤己之米煮粥 |

**【余庆结果】**
| 代际 | 结果 |
|------|------|
| 儿子 | 长子守陈=南京吏部侍郎；次子守址=北京吏部侍郎 |
| 孙子 | 长孙=刑部侍郎；次孙=四川廉宪 |
| 曾孙 | 楚亭，有德政，亦为名臣 |

**【案例特征归类】**
- 善行类型：**执法公正+司法仁爱**（在权力系统中保持良知）
- 善的性质：**阳善**（公开场合劝谏，为众人所知）
- 关键品质：**在权力面前不退缩**（县宰发怒时敢于跪谏）
- 余庆速度：**四代名臣**（杨自惩→二子侍郎→孙辈监察御史→曾孙德政）
- 特别之处：**夫妻同心行善**（妻子也参与决策）

### 案例③：谢迁（谢都事）—— 保全万人性命

**【人物背景】**
正统年间，鄞县张都宪楷南征邓茂七之乱，后委布政司谢都事（谢迁之父）搜杀东路贼党。

**【原文精读】**
> 谢求贼中党附册籍，凡不附贼者，密授以白布小旗，约兵至日，插旗门首，戒军兵无妄杀，全活万人；后谢之子迁，中状元，为宰辅；孙丕，复中探花。

**【施善行为拆解】**
| 要素 | 内容 |
|------|------|
| 背景 | 农民起义（邓茂七），朝廷派兵镇压，局势混乱 |
| 善行 | 秘密调查"附贼者"名册，将未参与者名单保密 |
| 具体措施 | 给无辜者发放白布小旗，约定官军到时就插在门口，防止乱杀 |
| 保护对象 | "全活万人"——数万人免于一死 |

**【余庆结果】**
| 代际 | 结果 |
|------|------|
| 儿子谢迁 | 状元及第，官至宰相（宰辅） |
| 孙子谢丕 | 探花及第 |

**【案例特征归类】**
- 善行类型：**在战争/混乱中保护无辜**（大规模人道主义行动）
- 善的性质：**阴功**（秘密进行，无人知晓其用心）
- 关键品质：**在体制内保持良知**（身为官员却保护被镇压者）
- 余庆规模：**万人救命→状元宰相**（量级对比悬殊）
- 特殊价值：这是十案例中**拯救人数最多**的一个（万人级别）

### 案例④：莆田林氏—— 三年如一日的坚持

**【人物背景】**
莆田林氏，先世有老母好善。

**【原文精读】**
> 常作粉团施人，求取即与之，无倦色；一仙化为道人，每旦索食六七团。母日日与之，终三年如一日，乃知其诚也。因谓之曰："吾食汝三年粉团，何以报汝？府后有一地，葬之，子孙官爵，有一升麻子之数。"其子依所点葬之，初世即有九人登第，累代簪缨甚盛，福建有无林不开榜之谣。

**【施善行为拆解】**
| 要素 | 内容 |
|------|------|
| 日常善行 | 每天做粉团施舍给路人，有求即给，毫无厌倦之色 |
| 考验 | 道人每日来讨六七团，持续三年，天天如此 |
| 关键品质 | "终三年如一日"——不是偶尔行善，而是长期坚持 |
| 考验的本质 | 仙人伪装试探：看她能否在无人监督、反复索求的情况下仍然坚持 |

**【余庆结果】**
| 代际 | 结果 |
|------|------|
| 儿子 | 依仙指葬地 |
| 初世 | 九人登第（一科中有九人中进士） |
| 累代 | 簪缨甚盛（世代为官） |
| 民间评价 | "福建有无林不开榜"——福建科举榜单如果没有林家名字，就不算完整 |

**【案例特征归类】**
- 善行类型：**长期不间断的小善**（日复一日的施舍）
- 善的性质：**阴德**（日常小事，不为外人所知）
- 关键品质：**坚持与耐心**（三年如一日，无倦色）
- 余庆速度：**一代爆发**（儿子葬后即九人登第）
- 特别之处：**善行的持续性比强度更重要**（仙人考验的就是这个）

### 案例⑤：冯琦父—— 雪中救人一命

**【人物背景】**
冯琢庵太史之父，为邑庠生（秀才）。

**【原文精读】**
> 隆冬早起赴学，路遇一人，倒卧雪中，扪之，半僵矣。遂解己绵裘衣之，且扶归救苏。梦神告之曰："汝救人一命，出至诚心，吾遣韩琦为汝子。"及生琢庵，遂名琦。

**【施善行为拆解】**
| 要素 | 内容 |
|------|------|
| 情境 | 隆冬时节，早起上学（或上班），路上发现有人倒在雪地里 |
| 初步判断 | "扪之，半僵矣"——触摸此人，已经半僵硬（接近死亡） |
| 具体行动 | 解下自己的棉袍给对方穿，扶回家中救醒 |
| 善的性质 | 陌生人，无任何回报预期，纯出至诚心 |

**【余庆结果】**
| 代际 | 结果 |
|------|------|
| 做梦 | 神告之："吾遣韩琦为汝子" |
| 生子 | 生下一子，取名"琦"（即后来的冯琢庵） |
| 后代成就 | 冯琦官至太史（翰林院官员），名震天下 |

**【案例特征归类】**
- 善行类型：**救人性命**（最直接的生命救助）
- 善的性质：**阴德**（救助陌生人，不求回报）
- 关键品质：**至诚心**（神明确说"出至诚心"）
- 余庆的隐喻：**韩琦是北宋名相**——神说"我派韩琦来做你的儿子"，暗示后代将有宰相之才
- 特别之处：这是十案例中**因果链条最清晰**的一个（救人→做梦→生子命名→后代显贵）

### 案例⑥：应大猷—— 解他人之困+自我修行

**【人物背景】**
台州应尚书，壮年习业于山中。

**【原文精读】**
> 夜鬼啸集，往往惊人，公不惧也；一夕闻鬼云："某妇以夫久客不归，翁姑逼其嫁人。明夜当缢死于此，吾得代矣。"公潜卖田，得银四两。即伪作其夫之书，寄银还家；其父母见书，以手迹不类，疑之。既而曰："书可假，银不可假，想儿无恙。"妇遂不嫁。其子后归，夫妇相保如初。公又闻鬼语曰："我当得代，奈此秀才坏吾事。"旁一鬼曰："尔何不祸之？"曰："上帝以此人心好，命作阴德尚书矣，吾何得而祸之？"
> 应公因此益自努励，善日加修，德日加厚；遇岁饥，辄捐谷以赈之；遇亲戚有急，辄委曲维持；遇有横逆，辄反躬自责，怡然顺受；子孙登科第者，今累累也。

**【施善行为拆解】**
| 要素 | 内容 |
|------|------|
| 背景 | 在山上读书，夜间常有鬼啸，但并不害怕 |
| 事件 | 听鬼说：某妇因夫久出不归，公婆逼其改嫁，次日将要自缢，鬼要借她的命"得代" |
| 具体行动 | 暗中卖田，得银四两；伪造其夫书信，寄银回家 |
| 关键细节 | 公婆见信怀疑字迹不像，但"书可假，银不可假"——想到儿子还活着，就不再逼嫁 |
| 鬼的反应 | 鬼抱怨被秀才坏了好事，另一鬼说：上帝因为他心好，命他做阴德尚书，我们怎么能害他？ |

**【后续行为】**
| 善行 | 内容 |
|------|------|
| 遇岁饥 | 捐谷赈灾 |
| 遇亲戚有急 | 委曲维持（尽力周旋帮助） |
| 遇横逆（无理取闹/欺辱） | 反躬自责，怡然顺受 |

**【余庆结果】**
- 子孙登科第者，今累累也（后代中进士举人多不胜数）

**【案例特征归类】**
- 善行类型：**解他人之困+对抗邪祟**（从人道主义到超自然层面）
- 善的性质：**阴德**（暗中卖田，不让人知晓）
- 关键品质：**不畏鬼神**（鬼啸不惊，反而保护欲被害者）
- 余庆规模：**累累登科**（后代多人中举）
- 特别之处：
  1. 十案例中**唯一与鬼/神直接对话**的案例
  2. 展示了"善"的完整闭环：救人→鬼神敬畏→自我修行→余庆后代
  3. 应对逆境的三层修养：捐谷（物质）+ 维持（关系）+ 自责（心态）

### 案例⑦：徐凤竹父—— 带头行善+公益基建

**【人物背景】**
常熟徐凤竹栻，其父素富。

**【原文精读】**
> 其父素富，偶遇年荒，先捐租以为同邑之倡，又分谷以赈贫乏，夜闻鬼唱于门曰："千不诓，万不诓；徐家秀才，做到了举人郎。"相续而呼，连夜不断。是岁，凤竹果举于乡，其父因而益积德，孳孳不怠，修桥修路，斋僧接众，凡有利益，无不尽心。后又闻鬼唱于门曰："千不诓，万不诓；徐家举人，直做到都堂。"凤竹官终两浙巡抚。

**【施善行为拆解】**
| 要素 | 内容 |
|------|------|
| 第一步 | 遇年荒，先捐租，为同邑之倡（带头示范） |
| 第二步 | 分谷以赈贫乏（直接救济） |
| 鬼的预言 | "徐家秀才，做到了举人郎"（连续叫喊） |
| 第一重结果 | 是岁，凤竹果举于乡（当年中举） |
| 后续善行 | 修桥修路，斋僧接众，凡有利益，无不尽心 |
| 第二重预言 | "徐家举人，直做到都堂" |
| 最终结果 | 凤竹官终两浙巡抚（巡抚即都堂级） |

**【余庆结果】**
| 阶段 | 结果 |
|------|------|
| 中举 | 当年即中举人 |
| 官场 | 官至两浙巡抚（从二品，相当于省长） |

**【案例特征归类】**
- 善行类型：**带头行善+公益基建**（从个人救济到公共建设）
- 善的性质：**阳善**（公开行为，为乡里所知）
- 关键品质：**带头作用**（"为先捐租以为同邑之倡"）
- 余庆速度：**当年见效**（当年中举）
- 特别之处：
  1. 十案例中**鬼两次预言**的案例（秀才→举人→都堂，层层递进）
  2. 善行的扩展路径：捐租→赈贫→修桥→修路→斋僧→接众（从点到面）
  3. 展现了"善的复利效应"：第一次行善成功后，更加积极（"益积德，孳孳不怠"）

### 案例⑧：屠康僖—— 司法纠错+制度建议

**【人物背景】**
嘉兴屠康僖公，初为刑部主事。

**【原文精读】**
> 初为刑部主事，宿狱中，细询诸囚情状，得无辜者若干人，公不自以为功，密疏其事，以白堂官。后朝审，堂官摘其语，以讯诸囚，无不服者，释冤抑十余人。一时辇下咸颂尚书之明。公复禀曰："辇毂之下，尚多冤民，四海之广，兆民之众，岂无枉者？宜五年差一减刑官，核实而平反之。"尚书为奏，允其议。时公亦差减刑之列，梦一神告之曰："汝命无子，今减刑之议，深合天心，上帝赐汝三子，皆衣紫腰金。"是夕夫人有娠，后生应埙，应坤，应埈，皆显官。

**【施善行为拆解】**
| 要素 | 内容 |
|------|------|
| 善行一 | 宿狱中，详细询问囚犯案情，发现若干无辜者 |
| 善行二 | 不自居功，秘密上疏给上级（堂官） |
| 结果 | 朝审时，堂官引用他的记录审问，无人不服，释放冤抑十余人 |
| 善行三（制度建议） | 提出"五年差一减刑官"的制度建议，核实平反全国冤案 |
| 结果 | 尚书奏请皇帝，批准实施 |

**【余庆结果】**
| 代际 | 结果 |
|------|------|
| 梦境 | 神告："汝命无子，今减刑之议，深合天心，上帝赐汝三子" |
| 当晚 | 夫人有娠 |
| 后代 | 生三子：应埙、应坤、应埈，皆为显官 |

**【案例特征归类】**
- 善行类型：**司法纠错+制度改良**（从个案到系统的善）
- 善的性质：**阴德+阳善**（暗中平反是阴德，制度建议是阳善）
- 关键品质：**不自居功**（"公不自以为功"）+ **制度思维**（从个案到五年一任减刑官）
- 余庆结果：**无子→三子皆显官**（直接从"无"到"有"的逆转）
- 特别之处：
  1. 十案例中**最具制度创新意义**的一个
  2. 展示了"善"可以从个人层面扩展到制度层面
  3. 屠康僖自己后来也被选派为减刑官，亲自践行自己提出的制度

### 案例⑨：包凭—— 修寺供像+化解纷争

**【人物背景】**
嘉兴包凭，字信之，其父为池阳太守，生七子，凭最少。赘平湖袁氏（入赘到袁家），与袁了凡父亲往来甚厚。博学高才，累举不第（多次科举不中），留心二氏之学（佛道）。

**【原文精读】**
> 一日东游泖湖，偶至一村寺中，见观音像，淋漓露立，即解橐中十金，授主僧，令修屋宇，僧告以功大银少，不能竣事；复取松布四疋，检箧中衣七件与之，内纻褶，系新置，其仆请已之。凭曰："但得圣像无恙，吾虽裸裎何伤？"僧垂泪曰："舍银及衣布，犹非难事，只此一点诚心，是我们用功之所无也。"
> 亭北有淤沙田数亩，常有争讼者，平居日劝和解之，因识曰："此田不赛，讼不息也。"俾各出财若干，雇舟载土，高筑堤防，凡数尺，田遂为永业。又尝见路旁室屋倾颓，犹存佛像，遂倾赀修之，曰："使塑像得所，即我成身时也。"闻者莫不感服。

**【施善行为拆解】**
| 要素 | 内容 |
|------|------|
| 善行一 | 见观音像在露天淋雨，取出随身十金请僧修庙 |
| 善行二 | 僧说功大银少，他又拿出四匹松布、七件衣服（包括新买的纻褶） |
| 仆人的反应 | 劝他不要这样做（"已之"） |
| 包凭的回答 | "但得圣像无恙，吾虽裸裎何伤？"（只要圣像不受损，我光着身子有什么关系？） |
| 僧的反应 | 垂泪："舍银及衣布犹非难事，只此一点诚心，是我们用功之所无也" |
| 善行三 | 化解沙田纠纷：劝说争讼双方，出资雇舟载土，高筑堤防，使田地成为永久产业 |
| 善行四 | 见路旁倾颓房屋中尚有佛像，倾资修缮 |
| 包凭的态度 | "使塑像得所，即我成身时也"（让佛像有安身之处，就是我成佛的时候） |

**【余庆结果】**
- 原文未明确记载包凭本人的后代成就，但提到"闻者莫不感服"
- 包凭与袁了凡父亲往来甚厚，其善行成为《了凡四训》的佐证案例

**【案例特征归类】**
- 善行类型：**宗教奉献+公益调解**（对神明的敬意+对世俗纠纷的化解）
- 善的性质：**阴德+阳善**（修庙是阴德，调解纠纷是阳善）
- 关键品质：**极致的诚意**（不惜所有，甚至不顾自己冷暖）
- 特别之处：
  1. 十案例中**最有宗教色彩**的一个
  2. 展示了"善"可以跨越宗教边界（修佛像也是善）
  3. 包凭本人科举不顺（累举不第），但善行感动了袁了凡，成为书中重要的佐证

### 案例⑩：支立之父—— 司法公正+拒绝美色

**【人物背景】**
嘉善支立之父，为刑房吏。

**【原文精读】**
> 为刑房吏，有囚无辜陷重辟，意哀之，欲求其生。囚语其妻曰："支公嘉意，愧无以报。明日延之下乡，汝以身事之。彼或肯用意，则我可生也。"其妻泣而听命。及至，妻自出劝酒，具告以夫意。支不听，卒为尽力平反之。囚出，妻果孕。后子隆，举于乡，官至山西参议。

**【施善行为拆解】**
| 要素 | 内容 |
|------|------|
| 背景 | 有囚犯无辜被判重刑，支父怜悯，想为他求生机 |
| 囚犯的计策 | 让妻子次日带酒菜去乡下招待支父，以身相许作为交换条件 |
| 囚妻的执行 | 哭泣着听从丈夫安排，亲自劝酒，告知丈夫的本意 |
| 支父的反应 | "支不听"——拒绝了这个提议 |
| 最终结果 | 仍然尽力为囚犯平反（不靠美色交换，靠正当途径） |
| 囚妻的结果 | 囚犯出狱后，囚妻果然怀孕（暗示支父的品格赢得了尊重） |

**【余庆结果】**
| 代际 | 结果 |
|------|------|
| 儿子支隆 | 举于乡，官至山西参议 |

**【案例特征归类】**
- 善行类型：**司法公正+抵御诱惑**（在巨大诱惑面前坚守原则）
- 善的性质：**阴德**（拒绝美色是不为人知的考验）
- 关键品质：**在诱惑面前不动摇**（囚妻主动献身，他不仅拒绝，还继续公正执法）
- 余庆结果：**儿子中举+官至参议**
- 特别之处：
  1. 十案例中**考验最激烈**的一个（美色诱惑 vs 司法公正）
  2. 展示了"真正的善不需要交易"（他不靠美色换公正，而是坚持正当途径）
  3. 囚妻的"泣而听命"反衬出支父的品格——她本可以成功诱惑他，但他守住了

## 二、十案例的跨案例模式提取

### 2.1 善行类型分布

| 类型 | 案例 | 数量 |
|------|------|------|
| 救人性命 | ①杨荣、⑤冯琦父 | 2 |
| 司法公正 | ②杨自惩、⑧屠康僖、⑩支立父 | 3 |
| 保护无辜 | ③谢迁、⑥应大猷 | 2 |
| 长期施惠 | ④莆田林氏 | 1 |
| 带头公益 | ⑦徐凤竹父 | 1 |
| 宗教奉献 | ⑨包凭 | 1 |

**结论**：十案例中，**司法公正类最多**（3例），其次救人/保护无辜（各2例）。这与《积善之方》强调"阴德"的主旨一致——司法领域最容易积累阴功。

### 2.2 阴德 vs 阳善分布

| 性质 | 案例 | 特点 |
|------|------|------|
| 纯阴德 | ①、④、⑤、⑥、⑧、⑨、⑩ | 不让人知晓，不求回报 |
| 阳善为主 | ②、③、⑦ | 公开行为，为人所知 |

**结论**：袁了凡更推崇阴德（7/10），认为阴德的福报更深远。

### 2.3 余庆速度的规律

| 速度 | 案例 | 说明 |
|------|------|------|
| 当年见效 | ⑦徐凤竹父 | 当年中举 |
| 一代爆发 | ④莆田林氏、⑧屠康僖 | 葬后即发/无子变三子 |
| 二代显贵 | ①杨荣、②杨自惩 | 祖父行善→父辈家裕→自己显贵 |
| 三代累积 | ③谢迁、⑥应大猷 | 数代簪缨 |

**结论**：善行越大、越无私，余庆速度越快。屠康僖的"减刑制度建议"（最大善）→ 当晚就有娠（最快反应）。

### 2.4 十案例的核心共性

1. **都不求人知晓**：七个案例明确是阴德，三个阳善也是"不自以为功"
2. **都经过实际考验**：不是口头善，而是付出真金白银/冒风险/抵诱惑
3. **余庆都是"超预期"**：救一人→三公；无子→三子；秀才→都堂
4. **都有连续性**：不是一次行善，而是持续行善（三年如一日、孳孳不怠）
5. **都改变了命运轨迹**：从平民→三公，从无子→三代名臣，从困窘→显贵
