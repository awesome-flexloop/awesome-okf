## 一、三概念核心速览

### 1. 事上花开，心上花不开

| 维度 | 说明 |
|------|------|
| **出处** | 智然《了凡生意经》现代阐释（非袁了凡原文） |
| **含义** | 外在行为可以积极投入、开花结果，但内心不执著于结果 |
| **经典依据** | 《金刚经》"应无所住而生其心"；《菜根谭》"事事留个有余不尽的意思，便造物不能忌我" |
| **操作化** | 做事时全力以赴 → 做完后放手 → 不被结果绑架情绪 |

### 2. 惜福

| 维度 | 说明 |
|------|------|
| **出处** | 《了凡四训》原文多处长篇论证 |
| **核心比喻** | 福报如存款，过度消耗则枯竭；袁了凡自述少年挥霍，晚年贫病交加 |
| **关键原文** | "吾为进士，不做三公，可得二十五年；为京卿，不做总督，可得十八年"——早知命数，惜福即延寿 |
| **操作化** | 吃七分饱、穿旧衣、用简朴——不是苦行，而是主动降低消耗速率 |

### 3. 留余播种

| 维度 | 说明 |
|------|------|
| **出处** | 智然《了凡生意经》现代阐释，呼应《周易》"谦，尊而光，卑而不可逾" |
| **核心比喻** | 农民秋收不留种则来年无收；人也需留余才能再生 |
| **关键原文** | "积善之家，必有余庆"——余庆就是"留余"在家族层面的体现 |
| **操作化** | 赚到钱分一部分给他人/公益 → 建立"种子账户" → 等待因缘成熟时发芽 |

## 二、六想 + 六思：从认知到行为的完整体系

### 六想（认知层）—— 详见 [06-liuxiang-modern-practice.md]

> 原文：命当荣显→常作落寞想；时当顺利→常作拂逆想；眼前足食→常作贫窭想；人相爱敬→常作恐惧想；家世望重→常作卑下想；学问颇优→常作浅陋想。

| 想 | 机制 | 一句话口诀 |
|----|------|-----------|
| 荣显→落寞 | 反脆弱训练 | 得意时想失去，不飘 |
| 顺利→拂逆 | 压力接种 | 顺境时想阻碍，不麻痹 |
| 足食→贫窭 | 消费脱敏 | 富裕时想匮乏，不执着 |
| 爱敬→恐惧 | 关系警觉 | 被捧时想转折，不盲目 |
| 望重→卑下 | 去中心化 | 高位时想平凡，不自大 |
| 优→浅陋 | 认知谦逊 | 能力强时想无知，不停止学习 |

**每日晨检（3分钟）**：洗漱时过一遍六想，问自己"今天哪个场景需要对冲？"

### 六思（行为层）—— 详见 [07-liusi-behavior-layer.md]

> 原文：远思扬祖宗之德，近思盖父母之愆；上思报国之恩，下思造家之福；外思济人之急，内思闲己之邪。务要日日知非，日日改过。

| 思 | 方向 | 一句话口诀 | 核心行动 |
|----|------|-----------|---------|
| 远思扬祖宗之德 | 向上追溯 | 我做的事配得上祖先吗？ | 决策前想家族声誉 |
| 近思盖父母之愆 | 向下修复 | 我在弥补父母的遗憾吗？ | 主动维护父母尊严 |
| 上思报国之恩 | 向社回馈 | 我为社会做了什么？ | 纳税+志愿服务 |
| 下思造家之福 | 向后代传承 | 我给后代留下什么？ | 培养品格而非只留钱 |
| 外思济人之急 | 向外伸手 | 谁能得到我的帮助？ | 3秒响应机制 |
| 内思闲己之邪 | 向内净化 | 我今天有邪念吗？克制了吗？ | 晚间三省 |

**改过三层**：改事（治标）→ 改心（治本）→ 改命（终极）

**每日改过流程**：
```
早晨（1分钟）→ 选一条六思重点践行
白天（随时）→ 记录发现的"非"
晚间（3分钟）→ 问：犯了什么错？根源是什么？明天怎么改？
周末（15分钟）→ 分类统计高频问题，制定专项计划
```

### 十案例五大共性

1. **不求人知**：7/10 明确为阴德，其余也"不自以为功"
2. **真金白银**：无一只是口头善，都付出了实际代价
3. **超预期回报**：救一人→三公；无子→三子；秀才→都堂
4. **持续性**：不是一次性善举，而是长期坚持（三年如一日、孳孳不怠）
5. **改变命运轨迹**：从平民→三公，从困窘→显贵

### 阴德 vs 阳善

| 性质 | 案例 | 袁了凡态度 |
|------|------|-----------|
| **阴德**（不让人知） | ①③④⑤⑥⑧⑨⑩ | 更推崇，福报更深 |
| **阳善**（为人所知） | ②⑦ | 有效，但不如阴德深远 |

## 四、核心操作指南（可直接执行）

### 每日三问（1分钟）
1. 今天我的哪个行为配得上祖先？（扬祖宗之德）
2. 今天谁需要我的帮助？我伸手了吗？（济人之急）
3. 今天我发现了自己的什么"非"？明天如何改？（日日知非）

### 每周行动（1小时）
- 做一件"利他不利己"的事（志愿服务/捐赠/技能帮助）
- 审查本周消费：多少是"想要"而非"需要"？（足食→贫窭）
- 给父母打个电话，不问需求，只问候（盖父母之愆）

### 每月检视
- 六想六思自查：哪一条我做得最好？哪一条最差？
- 家庭关系审计：我在维护谁的尊严？我在修复什么？
- 余庆账户：本月我为"种子账户"存入了什么？
