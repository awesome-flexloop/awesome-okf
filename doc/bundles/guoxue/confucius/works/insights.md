## 洞察1：「述而不作」不是谦虚，而是读懂孔子全部著作的总钥匙

| 四元组 | 内容 |
|--------|------|
| **陈述** | 孔子自称「述而不作」，这并非客套，而是锁定了他对六经的真实关系——「传述整理」而非「原创著作」。孔子亲撰仅有（传统说的）《春秋》一部，《诗》《书》《礼》《乐》《易》是整理传授，《论语》更是门人辑录。读孔子著作，必须先辨别每部书的归属层级，否则会把「整理」「传授」「辑录」误读为「创作」。 |
| **证据** | F-002（述而不作原文）、F-004（范文澜概括孔子整理六经三准绳）、F-007（孔子编诗书礼乐、晚年加易与春秋）、F-014/F-016（《春秋》相传孔子修/作）、F-026/F-028（删诗说存疑）、F-052（门人辑录论语）、F-045/F-048/F-049（十翼归属存疑） |
| **反常识** | 俗说「孔子著六经」「孔子作十翼」「孔子删诗三千」，把孔子塑造成「作者」；实际上这些说法或出自汉儒尊孔、或出自纬书附会，均被后出证据削弱：《论语》孔子自称「诗三百」与季札观乐表明《诗》已先定型（F-027/F-028）；欧阳修早疑《系辞》《文言》非孔子作（F-048）；《论语》明确是门人辑录（F-052）。孔子真实的历史角色更接近「整理者、传授者、课程编纂者」，而非「六经的作者」。 |
| **行动** | 拿到任何一部先秦经典，先问「它和孔子是哪种关系」——亲作/整理/传授/辑录/存疑，再谈义理。这个「归属辨析」动作，比直接读注释更能定位文本的时代与可信层级，见 [concepts/08-guishu-bianwei.md](concepts/08-guishu-bianwei.md) 的归属矩阵。 |

## 洞察2：读孔子必须区分「其言」与「其行被记录」，《论语》是最近信源却非孔子手写

| 四元组 | 内容 |
|--------|------|
| **陈述** | 研究孔子最直接、量最大的材料是《论语》，但它恰恰不是孔子亲笔——是弟子及再传弟子「辑而论纂」的语录汇编（F-052）。这意味着读《论语》时面对的孔子言行，都经过了记录者的选择、整理与文字转写，存在「孔子所说」与「被记录下的孔子所说」两层。 |
| **证据** | F-052（汉书艺文志「门人相与辑而论纂」）、F-050/F-051（今本二十篇四百九十二章、非一人一时编定）、F-053（汉代鲁齐古三种传本）、F-057~F-060（定州简本与今本异文、分章出入）、F-063（《坊记》引论语义） |
| **反常识** | 一般人读《论语》默认「每句话都是孔子原话」；实际上今本《论语》经历了鲁齐古三本合校、张禹《张侯论》合并、郑玄定本、定州简本所显示的战国传抄异文（F-054/F-055/F-060），连「是哪一章、哪个字」都在历史中变动过。《论语》的可贵不在「逐字是孔子原话」，而在它是「距孔子最近、最成体系的行为实录」。 |
| **行动** | 引用《论语》时区分引文性质：作为「孔子思想的直接记录」读其义，而非作为「孔子亲笔文本」抠字；关键章句对照定州简本异文（F-060）与诸家注（F-056）理解文字演变。示范见 [examples/02-lunyu-xuandu.md](examples/02-lunyu-xuandu.md)。 |

## 洞察3：六经文本都经过「层累」，读经典须有版本批判思维，而非默认「传世本即古本」

| 四元组 | 内容 |
|--------|------|
| **陈述** | 与孔子相关的每一部经典，传世本都不是先秦原貌：《尚书》有今古文与伪造问题、《诗经》有删诗之疑与三家诗毛诗之别、《易传》有十翼归属之疑、《论语》有定州简本异文、《春秋》有经传之分。它们都经历了注疏层累、今古文分派、出土文献校正三层改造，「传世本即古本」是一个需要警惕的默认假设。 |
| **证据** | F-031~F-033/F-035（尚书今古文与伪古文、清华简证实伪造）、F-026~F-029（删诗说与四家诗）、F-044~F-049（易传人更三圣说渐被否定）、F-057~F-060（定州简本异文）、F-009~F-011（今古文次序与立场分歧）、F-061/F-062（郭店上博缁衣同源异本） |
| **反常识** | 一般以为「儒家经典文本自古以来稳定可靠」；实际上今天所读《尚书》掺入了东晋伪造的二十五篇（F-033），《易传》的「十翼」作者至今无定论（F-045~F-049），《论语》今本与最早实物定州简本只有约一半字数对得上（F-059）。经典文本的「稳定性」大半是后代注疏与科举定本（如《十三经注疏》、朱熹《四书章句集注》）人为固化的表象。 |
| **行动** | 阅读时对每一处关键异文做「版本来源确认」：明确所据是传世本还是出土本、是今文还是古文、有无异文争议；异文不仲裁、并列登记。这构成【模式一·版本对照阅读法】的操作要点，见本文「可复用阅读模式」。 |

## 洞察4：「六经」本身是孔子设计的教材体系，次序之争背后是两种儒学的分歧

| 四元组 | 内容 |
|--------|------|
| **陈述** | 「六经」不是自古既有的固定组合，而是孔子晚年整理出的课程教本；仅六经的次序，今文与古文两家就给出不同排列（诗书礼乐易春秋 vs 易书诗礼乐春秋），这排序差异不是技术问题，而是「孔子是否作经」这一根本立场的投影。 |
| **证据** | F-007（孔子编诗书礼乐、晚年加易与春秋）、F-008（六艺二义）、F-009/F-010（今古文两种次序）、F-011（今文尊孔子为素王、古文以孔子为先师）、F-012（乐经亡佚、西汉立五经） |
| **反常识** | 一般读者只知「四书五经」而不知「六经」本身是孔子的课程设计、不知今古文两家对孔子地位的定性对立（素王 vs 先师）；把「孔子作六经」视为常识，恰恰是今文经学的立场被后世固化的结果，遮蔽了古文经学「六经是史」的另一传统。 |
| **行动** | 读六经时同时意识到「儒家读本」与「先秦史料」两种读法的张力：前者沿今文「经」的路径寻义理，后者沿古文「史」的路径考史实。两套次序、两种立场可作为读经的坐标轴，见 [concepts/07-banben-yuanliu.md](concepts/07-banben-yuanliu.md)。 |

## 可复用经典阅读模式（G3）

### 模式一：归属辨析法（先辨「谁的著作」，再谈义理）

| 要素 | 内容 |
|------|------|
| **触发场景** | 阅读任何被冠以某位古人名义的经典（尤其中华典籍），要把「作者是谁、怎么形成的」作为阅读第一步；面对「某某作某经」的通行说法；为他人讲解或选书、判断文本可信度时。 |
| **核心步骤** | ① 先列出该书的归属候选层级：亲作/整理/传授/辑录/存疑，逐一无预设地核对证据（F-002/F-052/F-048 模式）；② 区分「传统说」与「现代辨伪/考古证据」，两者并列呈现（如春秋亲作说 F-014/F-016 vs 删诗说存疑 F-028）；③ 记录后出处证据编号或信源 URL，使归属判断可追溯；④ 只有在归属清楚之后，才进入义理解读，避免把「后世附会」当「作者本义」。 |
| **反模式** | 直接接受「孔子著六经」「某某作某书」的俗说而不考证；把纬书、汉儒尊孔之辞当作史实（F-047 十翼为孔子作）；对出土文献证据（F-035/F-058）视而不见，固守传世定本；把「后人整理」模糊成「作者创作」。 |
| **迁移示例** | 从孔子六经迁移到《老子》（帛书本/郭店本/传世本的作者与成书之争，见 think/laozi/boshu-reading）；迁移到《墨子》《庄子》等诸子书的「学派集体创作」判定；亦可迁移到现代文档——区分「原作者」「整理者」「转述者」三层，判断一份规范或代码注释的可信来源。 |

### 模式二：版本对照阅读法（多底本并读 → 差异定位 → 差异归因）

| 要素 | 内容 |
|------|------|
| **触发场景** | 阅读存在多个传本或出土本的经典；需要引用原文并追求「最真实」；传世本与出土本（简帛）存在异文时；需要判定某条引文的文字是否有争议。 |
| **核心步骤** | ① 确定至少两个相互独立的底本来源（如传世本 + 出土简本；或 ctext.org + 权威点校本，F-050/F-060 模式）；② 逐字比对目标段落，登记一致/不一致；③ 定位差异后做归因：通假、避讳改字、隶定转写、篇次分章、后人增删（F-060 五类）；④ 差异处不仲裁，并列登记「某本作某」+ 信源（F-062 同源异本模式）；⑤ 将核对底料单独存档，便于复审。 |
| **反模式** | 只读一个传世本并默认为古本原貌；发现异文后凭语感「择优」拼出混合文本；用白话译文或二手转引充当原文；归因时无证据臆断「抄手笔误」。 |
| **迁移示例** | 从《论语》定州简本异文迁移到《老子》帛书/郭店/传世本对照（think/laozi/boshu-reading）；迁移到任何有多数字化底本的古籍；迁移到非古籍场景——两个官方镜像或两个版本之间比对关键条文、代码变更的源出处核验。 |

### 模式三：注家分层选用法（经文层 / 注疏层 / 现代解读层不混淆）

| 要素 | 内容 |
|------|------|
| **触发场景** | 阅读注疏传统深厚的经典（六经、四书）；面对多家互相冲突的解释；需要引用「解读」而非原文；为他人设计阅读路径或推荐注本。 |
| **核心步骤** | ① 先分层：经文层（先秦文本）/注疏层（汉唐清注家）/现代解读层（当代译注与研究），明确当前问题是「文义训诂」还是「义理体系」；② 按阶段选注：入门用一种现代译注（杨伯峻等）建立文义，进阶用一种体系性古注（郑玄/孔颖达/朱熹）理解义理，专题研究再查考据注（清人正义）；③ 关键章句强制并读 ≥2 种立场（今文 vs 古文、汉注 vs 宋注、赵岐 vs 朱熹）并标注出处（F-011/F-056）；④ 为所用注本记录立场标签（今文/古文/汉学/宋学/心学/考据/现代），形成个人注家索引。 |
| **反模式** | 从汉到清通读全部注疏；把影响最深的一家注（如朱熹）当作经文本身；终身只用一种译注并视为标准答案；引用解读不标注家与出处，使立场伪装成客观。 |
| **迁移示例** | 从六经迁移到四书（见 think/confucian/four-books，赵岐《孟子章句》与朱熹《集注》的分层）；迁移到佛典（各宗判教疏释差异）；亦可迁移到技术领域——官方规范（「经」）、权威实现文档（「注」）、社区教程（「现代解读」）三层区分与按问题选用。 |
