# 全书概览

## 书名沿革

《太平经》有两个名称，对应两个层面（facts F1、F2）：

| 名称 | 层面 | 说明 |
|------|------|------|
| 《太平清领书》 | 史书记载名 | 《后汉书·襄楷传》载宫崇所上神书"皆缥白素、朱介、青首、朱目，号《太平清领书》" |
| 《太平经》 | 道教通行名 | 唐李贤注："神书，即今道家《太平经》也"；道教奉为经典 |

另有先出同名别本：汉成帝时甘忠可诈造《天官历》《包元太平经》十二卷，与百七十卷《太平经》非一书（fact F12）。

## 十部一百七十卷结构

全书分甲、乙、丙、丁、戊、己、庚、辛、壬、癸十部，每部一十七卷，共一百七十卷（fact F4）。据王明《太平经合校》目录（fact F20）：

| 部 | 卷次 | 代表篇目 | 今存状况 |
|----|------|----------|----------|
| 甲部 | 卷一至十七 | 后圣帝君定法本起 | 全佚（合校本据钞补） |
| 乙部 | 卷十八至三十四 | 合阴阳顺道法、守一明法、解承负诀 | 全佚（合校本据钞补） |
| 丙部 | 卷三十五至五十一 | 分别贫富法、五事解承负法、三合相通诀 | 残存 |
| 丁部 | 卷五十二至六十八 | 六罪十治诀、戒六子诀 | 残存 |
| 戊部 | 卷六十九至八十五 | 学者得失诀、真道九首 | 残存 |
| 己部 | 卷八十六至一百二 | 来善集三道文书、拘校三古文法 | 残存 |
| 庚部 | 卷一百三至一百十九 | 天乐得善人文付火君、禁烧山林诀 | 残存 |
| 辛部 | 卷一百二十至一百三十六 | （全佚） | 全佚 |
| 壬部 | 卷一百三十七至一百五十三 | （全佚） | 全佚 |
| 癸部 | 卷一百五十四至一百七十 | 神人真人圣人贤人自占可行是与非法 | 全佚（合校本据钞补） |

> 甲、乙、辛、壬、癸五部完全遗失，其余几部各亡佚若干卷，残卷多标"阙题"（facts F17、F20）。

## 定位：道教第一部经典

三种定位陈述并置（facts F14–F16）：

- **经典史定位**：早期太平道奉为主要经典，被视为道教第一部（系统性）经典；
- **思想史定位**：以"太平"为理想，主兴国广嗣、养生、符箓方术与社会政治理想（调研基座 [G]）；
- **政治史关联**："后张角颇有其书焉"——与黄巾太平道有文献关联，但经文本义为"兴国广嗣"的治国之书，非起义纲领。

## 全书自我定位

襄楷上疏概括（fact F3）：

> 专以奉天地、顺五行为本，亦有兴国广嗣之术，其文易晓，参同经典。

范晔概括（fact F2）："其言以阴阳五行为家，而多巫觋杂语。"
