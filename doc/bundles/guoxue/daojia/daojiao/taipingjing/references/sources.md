## 五、选用策略

1. **研读**：王明《太平经合校》（中华书局）——唯一校补附存兼备的通行辑校本。
2. **检索**：北大历史系 FTP 合校本全文 + 纽读道藏本白文对照。
3. **核对**：任何引文至少两个独立信源核对后方可引用；残卷（标"阙题"处）不据《太平经钞》径补而不注。
4. **避坑**：神授传说（老君授干吉、帛和授素书等）属托名层，不与"东汉累积成形"的文本层结论混同；"于吉/干吉"用字差异属版本层异文。
