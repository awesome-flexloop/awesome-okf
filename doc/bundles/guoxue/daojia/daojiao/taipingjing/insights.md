# Insights — 《太平经》洞察与模式（I/E 阶段 · G2/G3）

## 洞察（G2 四元组：现象/根因/影响/建议）

### I1 神授谱系是托名层，须与"东汉累积成形"的文本层结论分判
- 现象：《太平经》托"天师"（老君）授干吉——《神仙传》天仙授书、《仙苑编珠》帛和授素书、《太平经复文序》后圣帝君传授谱系诸说并存；而王明考定"不是一时一人所作"，学界主流定为东汉长期累积成形（facts F7–F11）。
- 根因：早期道教经典以神授谱系确立权威，宗教叙事与文献考据分属两个层面；历代著录（《抱朴子》五十卷与一百七十卷并存）显示传本本身即有多源。
- 影响：把神授传说当史实会虚构作者与成书年代；完全否认传说层又丢失道教自身的经典叙事与传授史材料。
- 建议：统一采用"托名层（神授干吉传说，诸说并列）+ 文本层（东汉累积成形）"双层表述；神授诸说作为道教传授史材料登记，不作史实裁决。

### I2 残本须"残本优先、教义为纲"阅读，不可逐卷平推
- 现象：原一百七十卷，道藏本仅存五十七卷，甲乙辛壬癸五部全佚，残卷多标"阙题"；王明《合校》以《太平经钞》及 27 种引书校补附存才恢复轮廓（facts F17–F20）。
- 根因：辑校本中经本、钞本、引书补苴混排，读者若不辨"经文本/钞补文"层级，会把节录与佚文当作完整经文。
- 影响：逐卷平推会在阙题与方术篇中受挫；不辨层级则引用出处失真（把《太平经钞》节文标为《太平经》某卷）。
- 建议：阅读计划只排残存五部（丙丁戊己庚）；引用注明卷次篇名与"经本/钞本"来源；方术篇观其大略。

### I3 承负说是《太平经》对善恶报应论的独创发展，须与佛教因果、《想尔注》报应分判
- 现象：承负说"承者为前，负者为后"，善恶报应流及后代，且及于国家政治（帝王大臣人民皆有承负）；《太平经》另有"善者自兴，恶者自病"的现世报应，与《老子想尔注》"道设生以赏善，设死以威恶"同调（facts F23、F24、F29、F30）。
- 根因：承负说在《周易》"积善余庆，积恶余殃"基础上发展，回答"行善得祸、行恶得福"的经验反例——祸福是先人行为的代际结算，与佛教个人因果轮回不同源。
- 影响：把承负混同佛教因果会误读其代际结算结构；忽视其与《想尔注》的同调关系则割裂早期道教报应论的整体图景。
- 建议：教程中承负单列为《太平经》独创教义，注明与《易传》的承继、与《想尔注》的互证、与佛教因果的区别三条关系线。

### I4 《太平经》在线信源少且层级参差，原文核对须声明信源层级
- 现象：ctext.org 无《太平经》正文收录（仅 datawiki 条目）；可用在线信源为王明《合校》电子全文（北大历史系 FTP、纽读）、道藏本转录站（纽读）、标点简体转录站（全学网）；部分名句（如"善者自兴，恶者自病"）仅能取得转引双源（facts 信源表、F29）。
- 根因：《太平经》文本残佚、用字古僻、篇幅庞大，数字化整理滞后于诸子类典籍；各转录站底本不一（道藏本/合校本/钞本）。
- 影响：单一转录站抄录会把转录噪声（"徧/遍""於/于"等古今字之外还有讹字）当原文；把转引当全文核对会高估核对强度。
- 建议：优先用合校本电子全文 + 道藏本转录站双源核对；转引类引文如实标注"转引双源"层级；异文（含古今字）登记不改字。

## 可复用模式（E · G3）

### P1 神授型经典的托名/文本双层判读框架
- 触发场景：整理道教神授谱系经典（太平经、黄庭经、清静经等）知识时。
- 核心步骤：①托名层登记神授诸说（各说并列，注明出处书）；②文本层登记累积成形/成书年代诸说（学界主流与异说并列）；③两层之间显式声明"传说非史实"分判；④神授谱系作为传授史材料保留，不删。
- 反模式：把神授传说写入"作者"字段；用宗教叙事替代成书年代考据；因"迷信"而删除传授谱系材料。
- 迁移示例：本 bundle concepts/01-origin-transmission 按双层组织，神授三说并列。

### P2 残本辑佚书的"底本—补苴"分级引用法
- 触发场景：引用辑佚/残本古籍（太平经、列子辑佚、慎子辑本等）原文时。
- 核心步骤：①先查通行辑校本的凡例（校/补/附/存的标识方式）；②引用注明卷次篇名与文本层级（经本/钞补/佚文附存）；③阙题处不妄补；④异文登记不改字。
- 反模式：把辑校本补苴文当作原经全文引用；不注层级导致出处失真。
- 迁移示例：本 bundle 02-versions 底本原则与 04-selected-passages 各组均注卷次篇名。

### P3 双源逐字核读法（《太平经》版）
- 触发场景：任何需要给出《太平经》原文片段的写作/整理任务。
- 核心步骤：①优先选王明《合校》电子全文（北大历史系 FTP/纽读）为底本；②另选一个独立转录站（全学网/纽读道藏本）逐字比对；③登记古今字与异文（"徧/遍""於/于""小小失之/小小过失"）不改字；④仅能取得转引的引文如实标注信源层级；⑤核对结果登记于 facts 与 log。
- 反模式：单一转录站直接抄录；把转引当全文核对；静默统一古今字。
- 迁移示例：本 bundle 4 组选读段落核对记录见 [log.md](log.md)，结果登记于 [facts.md](facts.md) F22–F28。
