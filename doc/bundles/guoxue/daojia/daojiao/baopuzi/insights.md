# Insights — 《抱朴子内篇》洞察与模式（I/E 阶段 · G2/G3）

## 洞察（G2 四元组：现象/根因/影响/建议）

### I1 作者明确的经典可跳过托名分层，直入义理与方术
- 现象：道教经典段内多数经典（参同契、太平经、黄庭经、清静经）皆有托名层需分判；唯《抱朴子内篇》作者明确——葛洪自序存、《晋书》有传、成书年代有自述"至建武中乃定"（facts F9、F13）。
- 根因：《抱朴子》是子书体例的自著之作，非宗教神授谱系产物；葛洪本人兼具士人与方士双重身份，主动署名立言。
- 影响：教程若套用托名分层框架反而制造虚假争议；但卒年等细节（81 岁说与 61 岁说）仍需并列呈现，不因作者明确而放松信源核对。
- 建议：作者明确文本以"生平—师承—著述"三节组织作者篇；细节争议（卒年）并列两说并标注判据（F10）。

### I2 名句出处必须回原典核对，网络常误标篇名
- 现象："我命在我不在天"网络常误标出自《论仙》，实出卷十六《黄白》引《龟甲文》"我命在我不在天，还丹成金亿万年"（facts F23–F24）。
- 根因：名句脱离语境传播时只记书名不记篇名；《论仙》是讨论神仙有无的名篇，望文生义被附会为出处。
- 影响：误标出处使读者回原典检索落空，并掩盖该句在"黄白术"（炼丹成金）语境中的本义——夺造化之工的实践宣言。
- 建议：凡引名句必注卷次与篇名，并在教程中显式登记常见误标（facts F24 五源一致更正）。

### I3 方术文本须分级阅读，不宜逐卷平推
- 现象：二十卷内容异质度极高——卷一至卷十偏义理（畅玄、论仙、对俗、至理、微旨等），卷四金丹、卷十一仙药、卷十六黄白为方术实录，卷十七登涉为入山方术百科，卷十九遐览为道书目录（facts F1、F14–F25）。
- 根因：葛洪"鸠集久视之方"的集大成性质决定全书是义理论证与方术资料的复合体，各卷功能不同。
- 影响：零基础读者逐卷平推会在金丹、仙药的丹方药名中受挫弃读；研究型读者若只读义理篇则错过遐览的目录学价值。
- 建议：按"义理→方术→杂应→目录"四段组织阅读计划（examples/01-reading-plan），方术卷以"观其大略"为度。

### I4 版本选择以整理本为研读底本，影印本为对勘参照
- 现象：传世本系统多元——道藏本、明刻本、平津馆丛书本、四库本、四部丛刊本并行；ctext 电子文本以四部丛刊初编本为底本（facts F3–F5）。
- 根因：《抱朴子》向无古注本行世，清代孙星衍平津馆校刊本始有系统校勘，王明《校释》以平津馆本为底本集大成（F5）。
- 影响：直接读道藏本或四库本无校勘支撑，易为讹字所困；只读电子文本则失去异文判断依据。
- 建议：研读以王明《抱朴子内篇校释》（中华书局增订本）为底本，在线核对以 ctext 为第一检索入口，版本源流见 concepts/02-text-versions。

## 可复用模式（E · G3）

### P1 作者明确文本的"生平—师承—著述"三节法
- 触发场景：整理自著型古籍（作者有自序、正史有传）的知识包时。
- 核心步骤：①生平以正史传与自序互证，生卒年争议并列；②师承谱系单列（思想来源可追溯）；③著述清单以自叙篇为纲、史志著录为辅；④不设托名分层章节，但保留细节争议登记。
- 反模式：对自著文本套用托名分层；因作者明确而省略信源核对。
- 迁移示例：本 bundle concepts/01-author-ge-hong 按三节组织，卒年两说并列（facts F10）。

### P2 名句出处回核法
- 触发场景：任何以"名句"为卖点的古籍教程/引用。
- 核心步骤：①名句先在全书电子文本检索定位卷次篇名；②至少两个独立信源确认引文与出处；③登记网络常见误标并显式更正；④引文保留语境句（如"龟甲文曰"的引书标记）。
- 反模式：凭印象标注出处；只记书名不记篇名；删去引书标记使引文归属模糊。
- 迁移示例：facts F23–F24 对"我命在我不在天"执行四步，更正《论仙》误标。
