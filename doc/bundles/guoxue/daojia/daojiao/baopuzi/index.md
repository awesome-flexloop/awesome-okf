# 《抱朴子内篇》阅读教程

《抱朴子内篇》二十卷，东晋葛洪（283—363）自号"抱朴子"自著，论神仙方术、炼丹、养生，集汉晋道教方术之大成，主"我命在我不在天"（facts F1、F6、F18–F19）。本知识包（bundle）是面向普通读者与研究者的《抱朴子内篇》系统中文阅读教程，特点有三：

1. **作者明确、非托名**——葛洪自序存、《晋书》有传，是道教经典段内唯一作者明确且文本大体完整之作，无需托名分层，直入义理与方术（facts F9–F10）；
2. **关键原文双源核对**——《畅玄》开篇、《论仙》开篇、《金丹》要旨、《仙药》品级与"服金者寿如金"、《黄白》"我命在我不在天"共 6 条原文经 ctext.org 与至少一个其他权威信源逐字比对（facts F12–F18）；
3. **名句出处正本清源**——"我命在我不在天"实出卷十六《黄白》引《龟甲文》，网络常误标《论仙》，本包显式更正（facts F18–F19）。
