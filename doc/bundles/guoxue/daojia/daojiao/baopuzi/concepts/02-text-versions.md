# 文本与版本谱系

## 传本性质

《抱朴子内篇》今传本为**传世本系统**（道藏本、明刻本系统），**无出土本**（facts F4）。这与段内其他道教经典（如托名诸经）不同——文本大体完整，无辑佚问题。

## 主要版本系统

| 版本 | 性质 | 说明 |
|------|------|------|
| 《正统道藏》本 | 道藏本 | 明《正统道藏》收录，道教经典段内通行藏本 |
| 明刻本系统 | 明刻本 | 明代多种刻本流传 |
| 清孙星衍平津馆校刊本 | 清校刊本 | 清代系统校勘之始，《平津馆丛书》本 |
| 《四部丛刊初编》本 | 影印本 | ctext.org 电子文本底本（facts F3） |
| 《钦定四库全书》本 | 四库本 | 清四库系统 |
| 《摛藻堂四库全书荟要》本 | 荟要本 | 四库荟要系统 |

> ctext.org《抱朴子》电子文本底本为《四部丛刊初编》本《抱朴子内外篇》，站内并列平津馆本、四库本、荟要本等版本入口（facts F3）。

## 权威研读底本：王明《抱朴子内篇校释》

- 中华书局 1980 年 1 月初版，1985 年 3 月出版增订本，收入《新编诸子集成》第 1 辑，20 卷（facts F5）。
- 以清孙星衍平津馆校刊本为底本，与其他 10 余种书籍参校；或采用前人校语标明出处，或断以己意迳作校语（facts F5）。
- 《抱朴子》向无注本行世，此书先校后释，注解简明扼要；汇校与注释均属首次，已有集大成性质（facts F5）。
- 附录一：清严可均辑《抱朴子·内篇佚文》、葛洪撰《抱朴子·内篇序》、《抱朴子外篇自叙》、《晋书·葛洪传》（facts F6）。
- 附录二：孙星衍《新校正抱朴子内篇序》、《抱朴子内篇目录》、方维甸《校刊抱朴子内篇序》、《葛洪撰述书目表》（facts F6）。

## 版本选用策略

| 用途 | 推荐版本 |
|------|----------|
| 研读底本 | 王明《抱朴子内篇校释》（中华书局增订本） |
| 在线检索 | ctext.org（四部丛刊初编本为底本，可切换平津馆/四库本对照） |
| 对勘参照 | 道藏本、平津馆本（校勘记参照） |

> 判读要点：直接读道藏本或四库本无校勘支撑，易为讹字所困；只读电子文本则失去异文判断依据。故以王明《校释》为研读底本，ctext 为第一检索入口（insights I4）。
