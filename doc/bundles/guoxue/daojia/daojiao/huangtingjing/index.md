# 《黄庭经》阅读教程

《黄庭经》是《黄庭内景经》（《太上黄庭内景玉经》）与《黄庭外景经》（《太上黄庭外景玉经》）的合称，另有出现较晚的《黄庭中景经》（facts F1）。内景三十六章、外景分上中下三部，均为七言韵语；托西王母／太上老君等传，晋魏华存（魏夫人）为内景经传说传人（调研基座 [G]）。外景经至迟公元 255 年已定型，内景约成于魏晋，二经先后与作者为学界争议点（facts F7–F13）。本知识包（bundle）是面向普通读者与研究者的《黄庭经》系统中文阅读教程，特点有三：

1. **托名层/文本层双层分判**——魏夫人传授传说（《真诰》、务成子注叙、景林真人授秘藏草稿诸说）并列登记为托名层，"外景早于内景、均成魏晋之际"为文本层，两层显式分判、不作史实裁决（facts F4–F13）；
2. **关键原文双源核对**——内景上清章、上有章、口为章与外景上部经开篇四组选读段落经至少两个独立信源逐字比对，异文（"老君/太上/老子闲居""阖两靡/合两扉""元炁/元气"）登记不改字（facts F21–F24）；
3. **外景先行、存神为纲**——阅读计划按"外景先行、内景继之"安排（欧阳修所见王羲之写本即外景），以"存神守一—三丹田—身神名讳"三条义理主线选章。

## 🚀 快速开始

如果你之前从未读过《黄庭经》：

1. 先读[全书概览](concepts/00-overview.md)了解书名沿革与内外景结构
2. 读[成书与神授传说](concepts/01-origin-transmission.md)，分清魏夫人传说与魏晋成书两个层面
