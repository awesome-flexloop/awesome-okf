# 四周阅读计划

《黄庭经》内景三十六章、外景三部，均为七言韵语；内景身神名讳密集，零基础读者不宜从内景硬读，建议按"外景先行、存神为纲"原则分四周选读（facts F2、F18）。底本内景用道藏本白文（中华文库底本）、外景用务成子注本系统（fact F16）。

## 总原则

1. **外景先行**：外景文约义赅（98 句 686 字），先读外景建立"黄庭—关元—幽阙—命门"身中地图，再入内景；
2. **存神为纲**：以"三丹田—身神名讳—五脏神"三条义理主线选章，不按三十六章次序硬读；
3. **先读史源**：第一周先读陈撄宁《黄庭经讲义》弁言与《太平广记·魏夫人传》记载，建立魏夫人与传授的历史坐标；
4. **名讳章略读**：八景神、二十四真等名讳密集处以"观其大略"为度。
