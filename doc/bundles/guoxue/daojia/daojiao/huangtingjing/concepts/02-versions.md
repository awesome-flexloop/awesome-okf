# 版本系统

## 传本概况

《黄庭经》仅传世本，无出土本（调研基座 [G]）：

| 传本系统 | 说明 |
|------|------|
| 道藏本 | 明《正统道藏》洞玄部本文类收《黄庭内景玉经》；中华文库底本即此，参校《道藏辑要》本与清董德宁《太上黄庭经发微》本（fact F14） |
| 务成子注本 | 唐务成子注《黄庭外景经》三卷，注叙载扶桑大帝君命旸谷神仙王传魏夫人谱系，为外景经重要注本（facts F6、F16） |
| 梁丘子注本 | 唐玄宗时隐士白履忠（号梁丘子）注，收入《云笈七签》卷十一、十二与《修真十书》，为今所见最早注本（fact F15） |
| 王羲之写本（石本） | 传王羲之书小楷《黄庭经》（所写为外景经），欧阳修曾亲见王氏写本（石本）；智永、欧阳询、虞世南、褚遂良、赵孟頫等均有临本传世，亦有真伪之辨（fact F17） |

## 历代重要注本

| 注本 | 时代·作者 | 说明 |
|------|----------|------|
| 梁丘子注本 | 唐·白履忠（号梁丘子） | 今所见最早注本，收《云笈七签》《修真十书》（fact F15） |
| 务成子注本 | 唐·务成子 | 外景经三卷注本，注叙载传授谱系（fact F16） |
| 胡愔、欧阳修、刘处玄、蒋慎修诸注 | 唐宋金 | 历代注本甚多（fact F16） |
| 《黄庭经发微》 | 清·董德宁 | 较晓畅易懂（fact F16） |
| 《黄庭经讲义》 | 近代·陈撄宁 | 分类诠释，解难释晦（fact F16） |

> 研究著作：王明《黄庭经考》（内景外景先后、魏夫人注述说）；陈国符《道藏源流考》（中华书局新修订版）（调研基座 [G]）。

## 底本选择原则

1. **原文正字**以内景《正统道藏》洞玄部本文类（中华文库底本）、外景务成子注本系统为准；
2. **异文登记**：各本异文（"老君/老子闲居""阖两靡/合两扉""元炁/元气""玉宸/玉晨""太和官/太和宫""戊己/戌已"等）登记不改字；
3. **层级声明**：注文与经文分判——梁丘子注、务成子注均为注本系统，引用时注明经/注层级；书法写本（王羲之系统）与道藏本用字差异属异文层级，不据以改经。
