# 版本系统

## 传本概况

《周易参同契》仅传世本，无出土本（调研基座 [G]）：

| 传本系统 | 说明 |
|------|------|
| 道藏本 | 明《正统道藏》太玄部收注本若干种（第 621–629 册），注家四十余家（fact F16） |
| 彭晓分章本系统 | 五代后蜀彭晓《周易参同契分章通真义》三卷，以四篇统分三卷为九十章，为今通行本所本（fact F15） |
| 《古文参同契》 | 明代以后出现之别本，以四言句为魏伯阳之经、五言句为徐从事之传，真伪存疑，登记备览（fact F14） |

## 底本选择原则

1. **原文正字**以彭晓分章本系统（道藏本系统）为准；
2. **异文登记**：各注本系统异文（"橐籥/橐钥/槖籥""离己/离巳""戊己/戊巳""干立未可持/干立末可持"等）登记不改字；
3. **层级声明**：注文与经文分判——俞琰已指出"经注相杂"问题，引用时注明经/注层级；错简与后人增窜处不妄改。
