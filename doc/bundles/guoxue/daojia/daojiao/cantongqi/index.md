# 《周易参同契》阅读教程

《周易参同契》简称《参同契》，三卷约六千字，题东汉魏伯阳撰，是道教最早系统论述炼丹术的著作，后世尊为"万古丹经王"（facts F1–F4）。全书托易象而论炼丹，参同"大易""黄老""炉火"三家之理而会归于一（facts F18）。作者与成书年代争议大：或题魏伯阳独撰，或题魏伯阳、徐从事、淳于叔通三人相续而成；今本为五代彭晓分章本系统，文本层有错简与后人增窜之说（facts F5–F17）。本知识包（bundle）是面向普通读者与研究者的《周易参同契》系统中文阅读教程，特点有三：

1. **托名层/文本层双层分判**——魏伯阳独撰说与三人合著说并列登记为托名层（《神仙传》、彭晓序、刘知古引玄光先生诸说），"东汉末成书、今本为彭晓分章本"为文本层，两层显式分判、不作史实裁决（facts F5–F14）；
2. **关键原文双源核对**——大易总叙章、乾坤设位章、"日月为易"句、自序隐名四组选读段落经至少两个独立信源比对，异文（"橐籥/橐□""离己/离巳""戊己/戊巳"）登记不改字（facts F19–F22）；
3. **注本为先、义理为纲**——阅读计划以彭晓分章本为底本、以"三道由一"义理主线选章，不逐章硬读隐语。
