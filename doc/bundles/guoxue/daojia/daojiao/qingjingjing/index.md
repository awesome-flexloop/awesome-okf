# 《太上老君说常清静经》阅读教程

《太上老君说常清静经》简称《清静经》，又名《太上老君说常清静妙经》《太上老君说常清静真经》《常清静经》，一卷约 391 字，是道教论述"清静"修心的短经，被《玄门日诵早晚功课经》置于众经之首、每日持诵（facts F1、F18）。经文托太上老君所说，经后附仙人葛翁（葛玄）、左玄真人、正一真人三段赞语，称此经西王母口口相传、至三国葛玄书录成文（facts F3–F4）。成书年代学界争议大：或信老君亲说，或定魏晋稍后，或定隋唐／唐以前（任继愈主唐代说）（fact F5）。本知识包（bundle）是面向普通读者与研究者的《清静经》系统中文阅读教程，特点有三：

1. **托名层/文本层双层分判**——老君说经与葛玄书录传说（经后赞语、杜光庭注本补叙）并列登记为托名层，"成书三说（老君亲说/魏晋稍后/隋唐或唐以前）"为文本层，两层显式分判、不作史实裁决（facts F3–F6）；
2. **全文三段双源核对**——经文上段（道体论）、中段（澄心遣欲）、下段（妄心苦海）与葛玄赞语四组选读段落经至少两个独立信源逐字比对，异文（"名谓/名为""欲/慾""不名道德/不明道德""葛玄/葛翁"）登记不改字（facts F14–F17）；
3. **功课经导向、义理为纲**——阅读计划以"道体—遣欲—三观—真静"四条义理主线组织，先读经文白文（全文仅 391 字），再入杜光庭注本。
