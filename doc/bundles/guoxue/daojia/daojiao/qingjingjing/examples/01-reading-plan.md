# 四周阅读计划

《清静经》全文仅约 391 字，是道教最短而最常被持诵的经典之一，零基础读者可以白文直入，建议按"功课经导向、义理为纲"原则分四周研读（facts F2、F18）。底本用《正统道藏》白文（中华文库底本），注本用杜光庭注（fact F6）。

## 总原则

1. **白文先行**：全文仅 391 字，第一周先通读白文成诵，不急于看注；
2. **义理为纲**：以"道体—遣欲—三观—真静"四条义理主线分段，不按字句顺序硬解；
3. **功课经导向**：此经为《玄门日诵早晚功课经》众经之首，诵读本身即是修持法，可每日持诵一遍；
4. **注本后入**：第二周起以杜光庭注破读，宋元诸注选读。

## 进阶建议

- 通读一遍后，对照《道德经》第十六章（"致虚极，守静笃"）与第四十五章（"清静为天下正"）回读，体会经义与老子的承继关系；
- 对照道藏白文与各站转录本异文（如"名谓/名为""不名道德/不明道德""葛玄/葛翁"），体会版本系统差异；
