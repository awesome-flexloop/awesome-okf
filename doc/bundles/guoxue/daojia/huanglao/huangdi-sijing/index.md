# 《黄帝四经》（马王堆帛书）知识包

《黄帝四经》是 1973 年长沙马王堆三号汉墓出土帛书《老子》乙本卷前的四篇古佚书——《经法》《十六经》（或作《十大经》）《称》《道原》，共一百七十五行、一万一千一百六十四字（facts F1、F5）。全书无传世本，唯此出土本；"黄帝"为托名层，实为战国黄老学派作品，作者佚名（F7、F16、F17）。它是理解战国黄老之学"道生法"纲领与汉初文景之治思想渊源的枢纽文献，权威性评级 A（出土文献＋权威整理本）。

本知识包（bundle）是面向普通读者与研究者的《黄帝四经》系统中文阅读教程，特点有三：

1. **关键原文经多信源双源核对**——《经法·道法》开篇"道生法"段与《道原》开篇共 13 条原文逐条比对（V1–V13），帛书古字转写差异（殹／也、恆無／恆先、迵／迥等）全部登记，不隐不改；
2. **托名层/文本层诚实区分**——书名托名黄帝，定名《黄帝四经》与《黄帝书》两说并载，《十六经》亦作《十大经》，不作单一裁决；
3. **出土文献只作成书下限硬约束**——帛书抄于汉文帝前元十二年（前 168 年）下葬之前，证明成书不晚于此，但不作为全书定型的充分证据。
