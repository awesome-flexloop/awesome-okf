# 核心概念

四篇佚书以「道生法」为纲，道法结合、兼采刑名阴阳（分组页判读口径）。本页按三大支柱——**道生法、刑名、阴阳刑德**——组织核心概念，全部引文登记于 [facts.md](../facts.md)，原文核对见[选篇原文](04-selected-passages.md)。

## 一、道生法：法的形上根据

《经法·道法》开篇即全书纲领（F17）[R3][R7][R8][R9]：

> 道生法。法者，引得失以绳，而明曲直者也。故执道者，生法而弗敢犯也，法立而弗敢废也。故能自引以绳，然后见知天下而不惑矣。

要点：

1. **法源于道**——法不是君主意志的产物，而是"道"所生；"法"的功能是"引得失以绳，而明曲直"，即作为衡量是非得失的准绳（F17）。
2. **执道者受法约束**——"生法而弗敢犯""法立而弗敢废"：立法者（执道者）自身不得犯法、废法（F17）。
3. **与老庄的差异**——黄老希望通过源自于"道"的法来治理社会、约束行为；法律作为国家确认的行为规范具有最高效力，任何人不能违犯。这与老庄对法的批判和不信任形成重大区别，而与法治有相通之处（F18）[R9]。老子"法令滋彰，盗贼多有"（《老子》第 57 章）的立场，在黄老这里被"道生法"的立法论所补充和发展（F18 信源语境）[R9]。
4. **法的公正性**——《经法·大分》："诛禁当罪，而不私其利，故令行天下而莫敢不听"（F23）[R9]。

## 二、刑名（形名）：名实相应的治术

《经法·道法》论刑名（F20）[R3]：

> 见知之道，唯虚无有；虚无有，秋毫成之，必有形名；形名立，则黑白之分已。故执道者之观于天下也，无执也，无处也，无为也，无私也。是故天下有事，无不自为形名声号矣。形名已立，声号已建，则无所逃迹匿正矣。

要点：

1. **形名即名实**——事物（形）与其名称（名）相应，"形名立，则黑白之分已"：名分既定，是非黑白自然分明（F20）。
2. **以虚无为本**——"见知之道，唯虚无有"：执道者以虚静无为的态度观天下，"无执、无处、无为、无私"（F20）。
3. **名自正**——"天下有事，无不自为形名声号"：形名声号由事物自显，而非由上强加；名形已定，则"无所逃迹匿正"（F20、F21 信源语境）。
4. **恒常秩序**——"天地有恒常，万民有恒事，贵贱有恒位，畜臣有恒道，使民有恒度"；"使民之恒度，去私而立公"（F21）[R3]。

## 三、阴阳刑德：文武并用的治道

《黄帝四经》强调"文武并用，刑德兼行"的思想，建立"以法为符，皆断于法"的法治社会，提出在法治条件下实行"无为而治"的主张（F19，任务调研基座）[R6]。

相关已登记内容：

- 《十六经·观》含宇宙生成模式"一—天地—阴阳—四时—刚柔—万物"——阴阳刑德的治术以宇宙论为根据（F24）[R6]；
- 帛书同出文献中另有《刑德》甲乙丙三篇（马王堆帛书整体目录），可见"刑德"为当时黄老系统的通行范畴（F6 信源语境）[R2]；
- 《十六经·前道》："道有原而无端，用者实，弗用者雚"（陈鼓应读"雚"为"款"或"窾"）（F22）[R10]。

## 四、总纲：以道驭法，清静无为而治

三大支柱合为总纲——**主以道驭法、清静无为而治**（任务调研基座）：

- 道为法的形上根据（道生法）；
- 法以形名为操作机制（刑名）；
- 治以刑德为两手（阴阳刑德）；
- 归宿是"无为而治"——非无所作为，而是"定好规矩，照着走，不折腾"（F26）[R12]。

《道原》篇末"抱道执度，天下可一也"（F25）即此总纲的浓缩：抱持大道、执守法度，天下可归于一统。

## 五、与《老子》的差异对照

| 维度 | 《老子》 | 四篇佚书（黄老） |
|------|---------|-----------------|
| 对法的态度 | "法令滋彰，盗贼多有"（批判） | "道生法"（立法论，法源于道）（F18） |
| 无为 | 不赏而民劝、不罚而民畏 | 法治条件下的无为而治（F19） |
| 治术 | 绝圣弃智 | 形名声号、去私立公（F20、F21） |
| 政治参与 | 批判现实 | 实际参与政治，"唯余一人，兼有天下"（F18 信源语境） |

（对照框架据 R9 [R9]；《老子》引文为陈霞文所引。）
