# 核心概念：形名、道法、名分三要素

《尹文子》的义理主干可归纳为三要素：**形名**（正名与名法分类）、**道法**（道法术势递降链）、**名分**（定分止争与圣法之治）（facts F18–F25）。

## 一、形名要素：名以正形

《尹文子》以形名为全书枢纽，开篇即立总纲：

- 大道上："大道无形，称器有名。名也者，正形者也。形正由名，则名不可差，故仲尼云：'必也正名乎！名不正，则言不顺也。'"（fact F18）
- 形名互检："有形者，必有名；有名者，未必有形……形以定名，名以定事，事以检名，察其所以然，则形名之与事物，无所隐其理矣"（fact F18）。

名法分类（名三科、法四呈）：

> 一曰命物之名，方圆白黑是也；二曰毁誉之名，善恶贵贱是也；三曰况谓之名，贤愚爱憎是也。一曰不变之法，君臣上下是也；二曰齐俗之法，能鄙同异是也；三曰治众之法，庆赏刑罚是也；四曰平准之法，律度权量是也。（fact F20）

"命物之名"对应感官属性，"毁誉之名"对应价值判断，"况谓之名"对应比拟称谓；四法从伦理秩序（不变）到度量标准（平准）逐层落实——这是先秦名学最系统的分类之一。

## 二、道法要素：道法术势递降链

《尹文子》承黄老"道→法"路线，给出完整的治理工具递降与回返链条：

> 道不足以治，则用法；法不足以治，则用术；术不足以治，则用权；权不足以治，则用势。势用，则反权；权用，则反术；术用，则反法；法用，则反道；道用，则无为而自治。（fact F19）

- 递降：道→法→术→权→势，治理工具逐级具体化；
- 回返：势→权→术→法→道，"道用，则无为而自治"为终极归宿；
- 术势之秘："术者，人君之所密用，群下不可妄窥。势者，制法之利器，群下不可妄为"，而术可秘、势可专的前提是"先正名分，使不相侵杂"（fact F19）。

此链与刘向别录"自道以至名，自名以至法；以名为根，以法为柄"（fact 见 R8）互为表里，是"出入黄老申韩"定位的最直接文本。

## 三、名分要素：定分止争

- 大道上："名定，则物不竞；分明，则私不行。物不竞，非无心，由名定，故无所措其心；私不行，非无欲，由分明，故无所措其欲"（fact F21）——定分不是消灭心欲，而是使心欲无所措；
- 道治与法治的层次："道行于世，则贫贱者不怨，富贵者不骄，愚弱者不慑，智勇者不陵，定于分也。法行于世，则贫贱者不敢怨富贵……此法之不及道也"（fact F21）——道治"定于分"高于法治"不敢怨"；
- 圣法之治（大道下）：彭蒙答宋子"圣人之治"与"圣法之治"之别——"圣人者，自己出也。圣法者，自理出也……故圣人之治，独治者也；圣法之治，则无不治矣"（fact F24）——以"理"的客观性超越"己"的主观性，是稷下黄老"法治优于人治"的经典表述。

## 四、政治应用：八术与六征

大道下将形名落实到治术：

- **八术**："仁、义、礼、乐，名、法、刑、赏，凡此八者，五帝三王治世之术也"，八者各有正反两用（"仁者，所以博施于物，亦所以生偏私"），"用得其道则天下治，失其道则天下乱"（fact F22）；
- **六征**："凡国之存亡有六征：有衰国、有亡国、有昌国、有强国、有治国、有乱国"，以制度结构（"内无专宠，外无近习，支庶繁字，长幼不乱"）而非道德标签判国运（fact F23）；
- **名实寓言组**：庄里丈人名子"盗""殴"、郑人周人"璞"名之辨、宣王好射（三石实而九石名）、黄公好谦（国色实而丑恶名）——以寓言演"违名得实""因名失实"（fact F25）。

## 五、与黄老系统的关联

《尹文子》与稷下黄老学派直接关联：

- 人物系统：大道下载田子（田骈）、宋子（宋钘）、彭蒙问答，与《庄子·天下》宋钘尹文一派、仲长氏序"同学于公孙龙"互证（facts F7、F9、F24）；
- 思想系统：道法术势链与帛书《黄帝四经》"道生法"结构同调；李学勤以帛书《黄帝书》释顾实之疑（fact F16）；
- 学派定位：胡家聪断其为"道法刑名思想融为一体的稷下道家黄老学说"（fact F14）。
