# 版本与注本：仲长氏序本系统

《尹文子》仅存传世本，无出土本（调研基座 [G]）；今通行本皆出自**魏仲长氏条次撰定本**系统（facts F3、F26、F27）。

## 著录沿革

| 时代 | 著录 | 说明 |
|------|------|------|
| 战国 | 《世本》"齐有尹文子，著书五篇"（郑樵《通志》引） | 原本五篇（fact 见 R8） |
| 汉 | 《汉书·艺文志》名家类"《尹文子》一篇" | 刘向别录"凡二卷，仅五千言"（facts F1、R8） |
| 魏 | 仲长氏序"条次撰定为上下篇" | 黄初末缪袭（熙伯）示书（fact F3） |
| 隋 | 《隋书·经籍志》名家类二卷 | 注"尹文，周之处士，游齐稷下"（fact F2） |
| 唐宋 | 《新唐志》《宋志》一卷；《文献通考》二卷 | 四库提要断今本一卷为"后人所合并"（facts F2、F4） |

## 仲长氏序本

- 序文自述："余黄初本始到京师，缪熙伯以此书见示，意甚玩之。而多说误，聊试条次，撰定为上下篇，亦未能究其详也"（fact F3，R3）。
- 四库提要考："序中所称熙伯，盖缪袭之字。其山阳仲长氏，不知为谁。李淑邯郸书目以为仲长统，然统卒于建安之末，与所云黄初末者不合"（fact F11，R2/R4）。
- 序文引《庄子·天下》尹文之学与刘向"学本黄老，大较刑名家"之说，为托名层的关键文献（fact F9，R3）。
