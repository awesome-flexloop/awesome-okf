# 《尹文子》阅读教程

《尹文子》题战国尹文撰，《汉书·艺文志》名家类著录一篇（facts F1）。今传本前有魏黄初末山阳仲长氏序，称"条次撰定为上下篇"（fact F3）。全书分大道上、大道下两篇（fact F4）。四库提要定位"其书本名家者流，大旨指陈治道，欲自处于虚静，而万事万物则一一综核其实，故其言出入于黄老申韩之间"（fact F5）。本知识包（bundle）是面向普通读者与研究者的《尹文子》系统中文阅读教程，特点有三：

1. **真伪之辩两说并列**——罗根泽《诸子考索·尹文子探源》魏晋伪托说与胡家聪《尹文子与稷下黄老学派》先秦古书说并载，四库提要折中立场单列，不作单一裁决（facts F10–F16）；
2. **关键原文双源核对**——大道上、大道下核心段落以维基文库本 × ctext 四部丛刊初编本逐字核对，异文登记不改字；
3. **道→名→法脉络定位**——"自道以至名，自名以至法"（周氏涉笔语，四库提要引）作为理解其思想坐标的入口，与稷下黄老学派关联。

## 🚀 快速开始

如果你之前从未读过《尹文子》：

1. 先读[全书概览](concepts/00-overview.md)了解书名与两篇结构
2. 读[真伪之辩](concepts/01-authenticity-debate.md)，理解这本书为何真伪争议千年未决
3. 打开[三周阅读计划](examples/01-reading-plan.md)，按第 1 周计划先读大道上形名论

如果你已读过个别名段（如"大道无形，称器有名"）：

1. 从[核心概念](concepts/03-core-concepts.md)开始，抓全书形名/道法/名分三要素主干
2. 读[版本与注本](concepts/02-versions.md)，了解仲长氏序本与四部丛刊本系统
3. 跟着[选篇导读](concepts/04-selected-chapters.md)补读大道下政治篇
