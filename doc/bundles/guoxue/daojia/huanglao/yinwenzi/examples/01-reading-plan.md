# 三周阅读计划

《尹文子》全书仅大道上、大道下两篇（约六千余字），篇幅短小但义理密度高且真伪问题特殊，零基础读者建议按"真伪之辩先行"原则分三周通读（insights I1）。底本用厉时熙《尹文子简注》（fact F29）；在线对照用维基文库本 × ctext 四部丛刊本（facts R1/R5）。

## 总原则

1. **真伪之辩先行**：第 1 周先读真伪文献（四库提要、罗根泽探源、胡家聪稷下论），建立判读框架再入文本——这是本书区别于一般先秦子的阅读起点；
2. **形名为入路**：第 1 周后半读大道上开篇正名段与名三科法四呈段，从形名总纲入手（文从字顺，易建立信心）；
3. **道法为纲**：第 2 周读道法术势链与名分论，抓"自道以至名，自名以至法"的义理主干；
4. **政治收束**：第 3 周读大道下八术、六征、圣法之治与名实寓言，回查真伪之辩验证理解。

## 进阶建议

- 通读一遍后，补读大道上"天下万事不可备能"段与大道下"凡人富则不羡爵禄"段，体会形名落实到经济治理的维度；
- 对照维基文库本与 ctext 四部丛刊本异文（fact F30），体会校勘记与古今字差异；
- 以厉时熙《尹文子简注》逐段精读，关注其注释（fact F29）；
- 延伸阅读《庄子·天下》宋钘尹文段与马王堆帛书《黄帝四经》，完成稷下黄老系统的对照阅读（facts F7、F16）。
