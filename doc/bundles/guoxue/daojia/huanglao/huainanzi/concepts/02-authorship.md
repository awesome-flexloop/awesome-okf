# 作者与成书

《淮南子》是**集体编撰**之书，署名须分层陈述（insights I1、P3）。

## 三层判读

### 主持层：淮南王刘安

- 刘安（前 179—前 122），汉高祖刘邦之孙，淮南厉王刘长之子，袭封淮南王（fact F8）。
- 《汉书·淮南衡山济北王传》载其"招致宾客方术之士数千人"（fact F3）。
- 刘安为著书活动的组织者与主持者，非唯一执笔者。

### 编撰层：门下宾客集体

- 《汉志》著录"《淮南内》二十一篇。王安。"，著录撰者为刘安本人；宾客共撰之说出自高诱《叙》（facts F10、F25）。
- 实际执笔为宾客群体，各篇非出一手——这是理解全书思想内部差异的默认框架。

### 文本层：各篇思想差异

- 全书以道家"道"论为本，兼综儒、墨、名、法、阴阳（fact F12）；
- 篇与篇之间的思想侧重不一（道论、政治、兵略、天文、养生），以"集体编撰、非出一手"解释，不强行统一为一人一时之作。

## 成书年代

- 书成于西汉武帝初年，约前 139 年献于朝廷（fact F9，调研基座 [G]）。
- 大体非托名：《汉志》著录《淮南内》二十一篇、撰者"王安"，与今传本篇数相合（fact F10）。

## 刘安名下其他著作

《汉志》另著录刘安名下多种（fact F11）：《淮南道训》二篇、《淮南外》三十三篇、《淮南王赋》八十二篇等。今传者以《淮南内》二十一篇（即《淮南子》）为最完整。
