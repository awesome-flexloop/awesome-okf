# 《淮南子》阅读教程

《淮南子》又名《淮南鸿烈》，《汉志》录为《淮南内》二十一篇，题淮南王刘安主持、门下宾客集体编撰，成于西汉武帝初年（约前 139）（facts F1、F3、F7、F9）。全书以道家"道"论为本，兼综儒、墨、名、法、阴阳，主"无为而无不为"（facts F12、F13）。本知识包（bundle）是面向普通读者与研究者的《淮南子》系统中文阅读教程，特点有三：

1. **关键原文双源核对**——《原道训》开篇（ctext × 维基文库）与《要略》序（维基文库 × 四库电子本）逐字核对，异文登记不改字；
2. **集体编撰署名分层**——主持层（刘安）/编撰层（宾客）/文本层（各篇非出一手）三层陈述，不题"刘安著"；
3. **《要略》总序先行**——以居末的总序为阅读起点，建立二十一篇全书地图。

## 🚀 快速开始

如果你之前从未读过《淮南子》：

1. 先读[全书概览](concepts/00-overview.md)了解书名沿革与二十一篇结构
2. 打开[四周阅读计划](examples/reading-plan.md)，按第 1 周计划先读《要略》总序
3. 通读《要略》后，再看[选篇导读](concepts/04-selected-chapters.md)按层选读

如果你已读过个别名篇（如《原道训》《人间训》）：

1. 从[核心概念](concepts/03-core-concepts.md)开始，抓全书义理主干
2. 读[作者与成书](concepts/02-authorship.md)，理解集体编撰性质
3. 参考[版本与注本](concepts/01-versions.md)选择权威整理本
4. 跟着[四周阅读计划](examples/reading-plan.md)补齐未读篇目
