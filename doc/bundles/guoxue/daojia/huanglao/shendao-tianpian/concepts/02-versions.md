# 版本与辑本：群书治要七篇与玉函山房辑田子

《慎子》今存为辑本，《田子》全佚仅存辑佚条目（调研基座 [G]）；慎子以**守山阁丛书本（钱熙祚校）**为通行权威辑本，田子以**玉函山房辑佚书本**为辑佚底本（facts F29、F31、F32）。

## 著录沿革

| 时代 | 著录 | 说明 |
|------|------|------|
| 战国 | 《史记》"慎到著十二论" | 徐广注"今《慎子》刘向所定，有四十一篇"（fact F12） |
| 汉 | 《汉书·艺文志》法家类"慎子四十二篇"、道家类"田子二十五篇" | 班固注"名到，先申、韩，申、韩称之""名骈，齐人，游稷下，号天口骈"（facts F1、F2） |
| 唐 | 《群书治要》节录慎子七篇 | 今本七篇之所出（fact F11） |
| 宋 | 《通志·艺文略》"旧有十卷四十二篇，今亡九卷三十七篇" | 郑樵所见已止五篇（fact F4） |
| 隋唐以后 | 《隋志》《新唐志》不著录《田子》 | "佚已久"（fact F5） |
| 清 | 钱熙祚校辑守山阁本（七篇+逸文）、马国翰辑《田子》一卷 | 今通行辑本定型（facts F11、F31） |

## 田子辑本

- **马国翰《玉函山房辑佚书》辑《田子》一卷**：从《吕氏春秋》辑得佚说三篇，其一与《淮南子》所引互有详略异同，参订校补，并附考为卷（fact F31，R13/R14）；
- 《田子》佚文另见《古佚书辑本目录》（调研基座 [G]）；
- 本教程田骈佚文直接以《吕氏春秋》执一、士容篇（ctext 四部丛刊初编本）为原文信源，佚文出处书与转引层级逐条标注（facts F26、F27、F28）。

## 校勘与辑佚

- 钱熙祚跋两条声明："知今本又经后人删节，非其原书"；旧本逸文"盖杂取《鬻子》《墨子》《韩非子》《战国策》诸书，以流传既久，姑过而存之"（facts F12、F13）；
- 守山阁本逸文内保留归属标注："匠人成棺"条注"《鬻子》有此文"、"小人食于力"条注"《墨子》有此文"、"古之全大体者"条注"《韩非子》有此文"（fact F13）。

## 权威整理本

- **钱熙祚校《慎子》（守山阁丛书本）**为通行权威辑本（调研基座 [G]，fact F32）；
- 今人新注：**张觉《慎子 太白阴经》**（中华经典名著全本全注全译丛书，中华书局）（fact F32，R11）。

本教程原文引用以维基文库守山阁丛书本（钱熙祚校定）用字为正字，校记"原刻某，依《治要》补/改"如实呈现；异文登记于 [facts.md](../facts.md) F33，不改字；深入研究以张觉三全本与守山阁本校记为底本依据。

## 底本选择原则

1. 在线引用优先选底本标注明确者（ctext 标注守山阁丛书本；吕氏春秋标注四部丛刊初编本）；
2. 双源核对至少取两个独立信源（慎子取维基文库守山阁本 × 国学导航本，第三方印证古诗文网；田骈佚文取 ctext 吕氏春秋 × 冯友兰试稿引文）；
3. 异文处登记不改字；版本层异文（守山阁本×慎懋赏本）与引文层变体（韩非子难势引文）分类登记；
4. 逸文条目只选归属明确者，自注"某书有此文"诸条标注存疑归属，不入选篇导读。
