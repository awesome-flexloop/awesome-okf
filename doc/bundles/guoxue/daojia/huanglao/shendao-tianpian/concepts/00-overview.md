# 全书概览

慎到、田骈均为战国齐稷下先生，同属彭蒙、田骈、慎到一系的黄老学派；《慎子》残存七篇辑本，《田子》全佚仅存数条佚文（facts F6、F7、F11、F5）。

## 书名与作者

- 慎到：战国赵人（《史记·孟子荀卿列传》），齐宣王时稷下学士，"皆赐列第，为上大夫，不治而议论"（fact F6）。《史记》称其"学黄老道德之术，因发明序其指意""著十二论"（fact F3）。
- 田骈：齐人，又称陈骈，号"天口骈"；《庄子·天下》篇释文载"田骈名广"（facts F7）。《史记》称田骈、接子"皆有所论焉"（fact F3）。
- 著录：《汉书·艺文志》法家类"慎子四十二篇"（注"名到，先申、韩，申、韩称之"），道家类"田子二十五篇"（注"名骈，齐人，游稷下，号天口骈"）（facts F1、F2）。
- 托名层：二子为稷下先生的传统形象建立在《史记》《庄子·天下》《荀子·非十二子》《战国策》诸书之上；今传文本则是辑佚本与佚文（见下文篇卷结构）。

## 篇卷结构

《慎子》今存七篇辑本（清钱熙祚校辑，出自《群书治要》节录，fact F11）：

| 篇 | 内容主旨 |
|----|---------|
| 威德 | 势位论——腾蛇游雾、立天子以为天下、立公弃私 |
| 因循 | 因人之情——用人之自为，不用人之为我 |
| 民杂 | 兼畜下者——臣事事而君无事，君逸乐而臣任劳 |
| 知忠 | 忠不足以救乱世——治国在贤使任职，不在忠 |
| 德立 | 立天子不使诸侯疑——定分止争，害在有与不在独 |
| 君人 | 任法而弗躬——事断于法，去私塞怨 |
| 君臣 | 据法倚数——官不私亲，法不遗爱，唯法所在 |

另有逸文一卷（钱熙祚辑，含他书混入条目标注，fact F13）。

《田子》全佚，今存佚文数条，出自《吕氏春秋》（执一、士容）与《战国策》（齐策）（facts F5、F26、F27、F28）：

- **执一段**：田骈以道术说齐王，"无政而可以得政""变化应来而皆有章，因性任物而莫不宜当"；
- **士容段**：田骈论士，"火烛一隅，则室偏无光""好得恶予，国虽大不为王"；
- **齐策段**：齐人讥田骈"设为不宦，赀养千钟"。

## 思想定位

- 《庄子·天下》学旨纲维："齐万物以为首""慎到弃知去己而缘不得已，泠汰于物以为道理"；豪杰笑之"非生人之行而至死人之理"（fact F9）。
- 《荀子·非十二子》批评："尚法而无法……是慎到、田骈也"；《解蔽》"慎子蔽于法而不知贤"（fact F10）。
- 四库提要："道德之为刑名，此其转关，所以申韩多称之也"；吕思勉："其学实合道法为一家"（fact F15）。
- 本教程采用"稷下黄老、道法转关"的定位：学统层以庄子、荀子叙述并列，文本层以辑本与佚文为材料（见 [03-core-concepts.md](03-core-concepts.md)）。

## 历史评价

- 《史记》：慎到、田骈"皆学黄老道德之术，因发明序其指意"（fact F3）。
- 《庄子·天下》结语："彭蒙田骈慎到不知道。虽然，概乎皆尝有闻者也"（fact F9）。
- 《荀子·非十二子》："其持之有故，其言之成理，足以欺惑愚众"（fact F10）。
