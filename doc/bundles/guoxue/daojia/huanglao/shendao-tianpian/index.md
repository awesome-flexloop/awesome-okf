# 《慎到·田骈辑佚》阅读教程

慎到、田骈均为战国齐稷下先生，同属彭蒙、田骈、慎到一系的黄老学派（facts F6、F7、F9）。《汉书·艺文志》法家类著录"《慎子》四十二篇"，道家类著录"《田子》二十五篇"（facts F1、F2）。《慎子》大部亡佚，今存《群书治要》节录七篇（威德、因循、民杂、知忠、德立、君人、君臣），清钱熙祚校辑入守山阁丛书，附逸文一卷（fact F11）；《田子》全佚，仅存《吕氏春秋》《战国策》所引数条佚文（facts F5、F26、F29）。本知识包（bundle）是面向普通读者与研究者的慎到、田骈辑佚系统中文阅读教程，特点有三：

1. **学旨纲维与辑佚框架先行**——《庄子·天下》"齐万物以为首""慎到弃知去己""田骈贵齐"的叙述是理解二家学旨的原始依据（调研基座 [G]），《荀子·非十二子》"尚法而无法"的批评并列，不作单一裁决（facts F9、F10）；
2. **关键原文双源核对**——慎子七篇以维基文库守山阁丛书本 × 国学导航本逐字核对，田骈佚文以 ctext 四部丛刊本《吕氏春秋》× 冯友兰《中国哲学史新编试稿》引文核对，韩非子、吕氏春秋引文异文登记不改字；
3. **三层材料分判**——学统层（庄子、荀子叙述）、文本层（辑本本身）、引文层（他书引文）分开陈述，上博楚竹书《慎子曰恭俭》作为出土旁证单列（fact F16）。

## 🚀 快速开始

如果你之前从未读过慎到、田骈的材料：

1. 先读[全书概览](concepts/00-overview.md)了解二子生平与辑佚格局
2. 读[辑佚与真伪考辨](concepts/01-authenticity-debate.md)，理解"辑本"与"原书"的区别
3. 打开[三周阅读计划](examples/01-reading-plan.md)，按第 1 周计划先读《庄子·天下》彭蒙田骈慎到段

如果你已读过个别名段（如"腾蛇游雾，飞龙乘云"或"一兔走街，百人追之"）：

1. 从[核心概念](concepts/03-core-concepts.md)开始，抓势/因/法/齐万物四要素主干
2. 读[版本与辑本](concepts/02-versions.md)，了解群书治要本与守山阁本系统
3. 跟着[选篇导读](concepts/04-selected-chapters.md)补读田骈佚文
