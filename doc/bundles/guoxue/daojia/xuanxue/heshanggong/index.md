# 河上公《老子章句》阅读教程

《老子道德经河上公章句》（简称《河上公章句》）题河上公撰，分《老子》为八十一章并冠以章题（如"体道第一""养身第二"），是现存成书较早、影响较大的《老子》注本（facts F1、F2、F27）。河上公授汉文帝《老子章句》之说为托名传说（《史记》仅载战国末"河上丈人"而未言作注），成书年代有西汉说、东汉说、两汉之际说、魏晋以后说诸家并列，学界多定于两汉（facts F5–F16）。全书以"治身治国之要"为旨归，是汉代黄老学以无为治国、清净养生观点解《老》的代表（facts F22、F23）。本知识包（bundle）是面向普通读者与研究者的《河上公章句》系统中文阅读教程，特点有三：

1. **托名层与文本层分离**——河上公传说（托名层）与成书年代诸说（文本层）分层登记、并列不裁决；
2. **版本判读先行**——王卡点校本（中华书局）为权威底本，道藏本、影宋本、敦煌唐写本三大版本系统各有异文，引用前须知底本；
3. **关键章句双源核对**——体道第一、养身第二、成象第六等 8 处注文经维基文库 × 道藏本系统信源逐字核对，异文登记不改字。

如果你之前从未读过《河上公章句》：

1. 先读[全书概览](concepts/00-overview.md)了解书名沿革与八十一章结构
2. 读[托名与成书年代](concepts/01-authorship-dating.md)，理解"河上公"为托名、成书年代诸说并列
