# Insights — 郭象《庄子注》洞察与模式（I/E 阶段 · G2/G3）

## 洞察（G2 四元组：现象/根因/影响/建议）

### I1 注案署名须分"文献记载层/学术判定层"两层陈述
- 现象：郭象与向秀注的关系，《晋书·向秀传》载郭象"述而广之"，《晋书·郭象传》与《世说新语·文学》载郭象"窃以为己注"；《经典释文·序录》载向秀注二十卷二十六篇、郭象注三十三卷三十三篇，二家卷数篇数不同，陆德明时向、郭二注并存；今人研究又有窃注说、郭象自著说、述而广之说三种意见并列（facts F11–F16）。
- 根因：早期史传与笔记对同一事件的记载本就分歧，卷数篇数差异又使"点定文句"与"全窃"两说各有可据之处；现代学者据《经典释文》所引向注残文校郭本，结论仍分三派。
- 影响：直断"郭象窃向秀注"会把《晋书·郭象传》一说当定论；直断"郭象独立自注"又与《晋书·向秀传》及四库提要的校勘结论冲突。
- 建议：统一采用"郭象注（其与向秀注的关系，述而广之说与窃注说并载）"表述；两说（三说）分层登记、并列不裁决；涉及著作权论断时注明所持学说与代表学者。

### I2 郭注引用须先判版本系统
- 现象：郭象注今传形态有郭庆藩《庄子集释》本（含成玄英疏、陆德明释文与清人校勘）、四库全书本《庄子注》十卷、《南华真经注疏》本、《庄子义疏》本等；各本注文存在详略异文（如罔两问景注"卒于无待而独化之理明矣"与"故责其所待而寻其所由，则寻责无极而至于无待，而独化之理明矣"）；四库提要且疑《让王》《渔父》《盗跖》《说剑》四篇注文有脱佚（facts F23–F25、F27）。
- 根因：郭注自晋至唐经陆德明、成玄英层累作音义与疏，宋以后又入四库系统，各本转录底本不同；杂篇注文简略引发脱佚之疑。
- 影响：不判版本直接抄录，会把某一系统的详略形态当作郭注原貌；以集释本校记之字径改他本，会混入清人校勘。
- 建议：引用前声明底本（日常用郭庆藩《庄子集释》点校本，校勘加四库本与注疏本）；异文登记不改字；杂篇注文简略处注明四库提要之疑。

### I3 "独化—玄冥—性分"是郭注的第一读法
- 现象：郭注核心术语有明确文本锚点——天籁注"块然而自生耳"、罔两问景注"物各自造而无所待焉"立"独化"；"玄冥者，所以名无而非无也"与"卓尔独化，至于玄冥之境"立"玄冥"；逍遥游篇题注"各当其分，逍遥一也"与"物各有性，性各有极"立"性分"；郭象《庄子序》"神器独化于玄冥之境"总括全书（facts F8、F17–F19、F32–F33）。
- 根因：郭象注以术语体系解庄，"独化"为本体论、"性分"为物性论、"玄冥"为境界论，三者互训；郭序自述其旨，可与注文互证。
- 影响：只按文学读《庄子》会漏掉郭注的哲学建构；只按概念史读又会脱离注文的具体文本位置。
- 建议：通读时以三术语为默认框架，逐篇标记注文落在独化、性分还是玄冥；以郭序回验注文，术语出处一律标篇名与事实编号。

### I4 网络通行注本存在版本混拼，注文引用须双源核对
- 现象：本次核对发现集释本与四库本在逍遥游篇题注（"场／则"录文差异）、鲲鹏注（末句"耳"字有无）等处存在异文；《庄子义疏》本郭注与集释本在罔两问景注处有详略之别；研究文献转引之"神人即圣人"注与尧许由章注未及原文逐字核对（facts F28–F31、F27、F35）。
- 根因：在线文本各据不同版本系统转录（集释本、四库本、注疏本底本不同），且标点为转录者所加；研究文献转引存在压缩与改写。
- 影响：单一信源抄录会把某一系统的异文当作定本；转引注文不经原文核对可能引入讹误。
- 建议：入库注文至少经两个独立信源（国学导航集释本 + 汉典古籍/点藏网/识点古籍）逐字核对；异文处登记不改字；转引条目标注"转引存疑，待补核"。

## 可复用模式（E · G3）

### P1 注案公案判读框架
- 触发场景：整理存在著作权争议的注本（郭象/向秀《庄子注》、王弼《周易注》诸说等）知识时。
- 核心步骤：①拆文献记载层（各史传笔记原文、卷数篇数著录差异）；②拆学术判定层（古今诸说并列，各说代表学者与论据）；③两层分开陈述，不以一说裁剪他说。
- 反模式：把某一史传记载当定论；用单一判定掩盖诸说分歧。
- 迁移示例：concepts/01-life-era 按两层组织。

### P2 双源逐字核读法（郭象《庄子注》版）
- 触发场景：任何需要给出郭象《庄子注》原文/注文片段的写作/整理任务。
- 核心步骤：①声明底本（郭庆藩《庄子集释》点校本优先）；②选至少 2 个独立在线信源（国学导航集释本 + 汉典古籍/点藏网四库本/识点古籍注疏本）；③分别抄录目标段落；④逐字比对并登记异文（位置/各本作某）；⑤异文处加注不改字；⑥转引条目标注存疑待核。
- 反模式：单一百科/文库直接抄录；以清人校记之字径改注文；静默统一异文。
- 迁移示例：本 bundle 双源核对记录见 [log.md](log.md)，核对结果登记于 [facts.md](facts.md) F26–F35。

### P3 观念术语溯源读法
- 触发场景：通读以术语体系解经的注本（郭注、王弼注、成玄英疏等）。
- 核心步骤：①先立术语表（独化/玄冥/性分/名教即自然/寄言出意）；②逐篇标记注文落点并系于术语；③以注者自序（郭象《庄子序》）与目录学要旨回验标记结果。
- 反模式：只按篇章顺序读注文；术语不系原文位置。
- 迁移示例：concepts/03-interpretive-method 与 examples/01-reading-plan 按此组织。
