# 版本系统

郭象《庄子注》今传形态有多个版本系统，阅读与引用须先判版本（insights I2、P2）。

## 权威底本：郭庆藩《庄子集释》

| 项目 | 内容 |
|------|------|
| 书名 | 《庄子集释》 |
| 编者 | 清郭庆藩 |
| 点校者 | 王孝鱼 |
| 出版 | 中华书局·新编诸子集成，1961 年第 1 版／2016 年（ISBN 9787101116694） |
| 内容 | 收郭象注、成玄英疏、陆德明释文及清人校勘 |

（fact F23，调研基座 [G]）原文正字与校勘以此本为首选。

## 主要版本系统

### 一、集释本系统（含注疏）

- 郭庆藩《庄子集释》以郭注为经、成疏为纬，附陆德明释文与清人校勘，是今日通行整理本（fact F23）。
- 唐成玄英《南华真经注疏》以郭象注为基础作疏，成玄英《庄子序》："依子玄所注三十篇，辄为疏解，总三十卷。"（fact F24）

### 二、四库本系统

- 《四库全书》子部道家类收《庄子注》十卷（晋郭象注）（fact F25）。
- 四库提要称《让王》篇惟注三条、《渔父》篇惟注一条、《盗跖》篇惟注三十八字、《说剑》篇惟注七字，"似不应简略至此，疑有所脱佚"（fact F25）。
- 四库本与集释本存在录文差异（如逍遥游篇题注"场／则"、鲲鹏注末句"耳"字有无），异文登记不改字（facts F28、F29）。

### 三、注疏本与义疏本系统

- 识点古籍《南华真经注疏》（郭象注、成玄英疏）与《庄子义疏》为另外两个可资对勘的系统；《庄子义疏》本郭注在罔两问景注处与集释本有详略之别（fact F27）。

### 四、郭象《庄子序》

- 郭象《庄子序》："上知造化无物，下知有物之自造也"，又曰"是以神器独化于玄冥之境而源流深长也"（fact F8），为郭注自述宗旨之文，可与注文互证。

## 版本选择建议

| 用途 | 推荐版本 |
|------|---------|
| 日常阅读与引用正字 | 郭庆藩《庄子集释》（中华书局点校本） |
| 校勘与异文研究 | 集释本校记 + 四库本 + 注疏本/义疏本 |
| 郭注与成疏合读 | 《南华真经注疏》 |
| 郭注宗旨总纲 | 郭象《庄子序》 |

## 与向秀注的关系

陆德明《经典释文·序录》时向、郭二注并存（向秀注二十卷二十六篇，郭象注三十三卷三十三篇）（fact F14）；今传主流为郭注三十三篇本，五十二篇本不传（facts F6、F7）。向郭注案详见[生平与时代](01-life-era.md)。
