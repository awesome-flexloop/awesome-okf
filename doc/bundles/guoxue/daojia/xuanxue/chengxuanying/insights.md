# Insights — 《南华真经注疏》洞察与模式（I/E 阶段 · G2/G3）

## 洞察（G2 四元组：现象/根因/影响/建议）

### I1 成玄英生平须分"生平层/文本层"两层陈述，生卒年并列不裁决
- 现象：成玄英生卒年诸说并列（百科 608—669、郑燦山约 601—690、ctext 仅记活动期 631—655）；《新唐书》注仅载"贞观五年召至京师，永徽中流郁州"；疏序所述庄子生平（"师长桑公子，受号南华仙人"）含传说成分（facts F5–F8）。
- 根因：唐初道士史料记载匮乏，生平只能依据有限文献梳理；注疏序文中的圣贤叙事属宗教托名传统而非信史。
- 影响：以单一断代裁剪思想史，会把推测的生卒年当作定论；把疏序中的庄子传说当作史实，会误导《庄子》成书年代的判断。
- 建议：统一表述"唐初道士成玄英（约活动于贞观、永徽年间）"；生卒年诸说并列登记不裁决；疏序中的庄子生平标注"成玄英所述"。

### I2 注疏引用须先判版本系统与底本
- 现象：《南华真经注疏》有道藏本（三十五卷）、成疏自序"总三十卷"、两《唐志》"《疏》十二卷"、《文献通考》三十三卷诸说；曹础基黄兰发点校本以《古逸丛书》覆宋本为底本，道藏本、《庄子集释》本各有分卷差异（facts F2、F3、F15–F17）。
- 根因：注疏合刊为宋以后人所編集，卷第为后人所析；各系统经翻刻、辑录产生分化。
- 影响：不判版本直接抄录，会把某一系统的卷数或用字当作全书原貌；以道藏本卷次定位《庄子集释》本必然错位。
- 建议：引用前声明底本（日常用曹础基黄兰发点校本，校勘加道藏本与《庄子集释》本）；卷数诸说并列登记；异文登记不改字。

### I3 "双遣—重玄"是成疏的第一读法
- 现象：成疏以"遣之又遣"释"玄之又玄"：先遣有无双执（一玄），再遣其遣（重玄）；《齐物论》疏遣是非、《大宗师》疏立"三绝"（绝有、绝无、绝非有非无），"境智两忘、能所双遣"取资佛教中观（facts F18–F23）。
- 根因：唐初重玄学以《老子》"玄之又玄"为理论基点，吸收佛教中观学双遣双非方法，对老庄哲学进行本体论提升；成玄英为集大成者。
- 影响：只按郭象玄学读会漏掉成疏的重玄义理层；只按佛教中观读会忽略成疏的道教立场与"自然独化"底色。
- 建议：通读时以"双遣—重玄"为默认框架，逐篇标记疏文落在遣有无、遣是非还是三绝重玄；郭注与成疏对读，区分玄学层与重玄层。

### I4 网络通行注疏本存在转录讹误与版本混拼，疏文引用须双源核对
- 现象：本次核对发现诗词汇本存在大量转录讹字（"元"代"無"、"束"代"東"、"淇"代"冥"、"子泰"代"子綦"）；与识典古籍本在"咯焉／嗒焉"等处存在异文；重玄总论在不同信源间有"以遣双执／以造双执""行者／学者"等异文（facts F30、F34、F35）。
- 根因：在线文本各据不同版本系统转录，且转录层引入形近讹字；研究文献引文亦各据不同底本。
- 影响：单一信源抄录会把转录讹字当作原文；把某一系统的异文当作定本。
- 建议：入库疏文至少经两个独立信源（诗词汇本 + 道藏本系统信源或研究文献引文）逐字核对；讹字与异文登记不改字；正字以曹础基黄兰发点校本为准。

## 可复用模式（E · G3）

### P1 注疏合编书判读框架
- 触发场景：整理注疏合编古籍（《南华真经注疏》《十三经注疏》等）知识时。
- 核心步骤：①拆注层与疏层（注者、疏者各为一家之学）；②拆生平层与文本层（作者生平诸说并列、文本卷数诸说并列）；③两层分开陈述，不以生平断代裁剪文本，不以卷数定本掩盖诸说。
- 反模式：混称注疏不辨层次；用单一卷数或单一断代掩盖诸说分歧。
- 迁移示例：concepts/01-life-era 与 concepts/02-versions 按两层组织。

### P2 双源逐字核读法（《南华真经注疏》版）
- 触发场景：任何需要给出《南华真经注疏》原文/注文/疏文片段的写作/整理任务。
- 核心步骤：①声明底本（曹础基黄兰发点校本优先）；②选至少 2 个独立在线信源（诗词汇本 + 道藏本系统信源如古诗网/点藏网，或研究文献引文）；③分别抄录目标段落；④逐字比对并登记异文与转录讹字；⑤异文处登记不改字；⑥卷次只在所据系统内使用。
- 反模式：单一文库直接抄录；把转录讹字（"元"代"無"类）当作原文；静默统一异文。
- 迁移示例：本 bundle 双源核对记录见 [log.md](log.md)，核对结果登记于 [facts.md](facts.md) F30–F40。

### P3 重玄双遣注文标记读法
- 触发场景：通读重玄型注疏（成玄英疏、李荣注、杜光庭义等）。
- 核心步骤：①通读时逐篇标记疏文落点（遣有无／遣是非／三绝重玄／境智两忘）；②汇总"遣之又遣"类句式作为旨要证据；③以疏序总纲（"述重玄之妙旨"）回验标记结果；④与郭注对读，区分玄学层与重玄层。
- 反模式：只按郭象玄学单读成疏；忽略"双遣""三绝"句式。
- 迁移示例：concepts/03-interpretive-method 与 examples/01-reading-plan 按此组织。
