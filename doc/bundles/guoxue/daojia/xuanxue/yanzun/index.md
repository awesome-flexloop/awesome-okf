# 严遵《老子指归》阅读教程

《老子指归》又名《道德真经指归》《道德指归论》，题西汉严遵（字君平）撰、唐人谷神子（冯廓）注，是现存最早的《老子》注本之一（facts F1、F22）。作者严君平卖卜于成都市，"闭肆下帘而授《老子》"，"依老子、严周之指著书十余万言"，扬雄少时从其游学，《法言·问明》称"蜀庄沈冥……不作苟见，不治苟得"（facts F7、F8）。今传本残缺：道藏本十三卷仅存《德经》七卷（卷七至卷十三），六卷本（《道德指归论》）又缺第十三卷；卷数著录有十四、十一、十三卷诸说，真伪有《四库提要》"赝托"说与张岱年等肯定说两说并载（facts F12–F16）。全书分《老子》为七十二章（上经四十、下经三十二），以"道德—神明—太和—天地"的生成序列与"无心""自然""无为"诸范畴阐发《老子》，被视为两汉宇宙生成论向魏晋玄学本体论过渡的先声（facts F13、F18–F22）。本知识包（bundle）是面向普通读者与研究者的《老子指归》系统中文阅读教程，特点有三：

1. **残缺书的版本判读先行**——道藏本（七卷存德经）与六卷本（《道德指归论》）两大系统、卷数诸说与真伪两说分层并列，引用前须知底本；
2. **佚文意识**——道经部分亡佚，道经佚文散见唐宋注疏，读今存七卷须知其非全书；
3. **关键段落双源核对**——《汉书》本传、《法言》"蜀庄"段、上德不德章与圣人无常心章指归等 5 处原文经道藏本系统 × 津逮本系统 × 史传电子本逐字核对，异文登记不改字。

## 🚀 快速开始

如果你之前从未读过《老子指归》：

1. 先读[全书概览](concepts/00-overview.md)了解书名沿革与七十二章结构
2. 读[严君平其人](concepts/01-yanzun-life.md)，理解作者生平与扬雄之评
3. 读[传本残缺与卷数诸说](concepts/02-versions-transmission.md)，建立"今存七卷非全书"的残缺书意识
4. 打开[四周阅读计划](examples/01-reading-plan.md)，按第 1 周计划先读《说二经目》与上德不德章

如果你已熟悉王弼注本《老子》：

1. 从[核心概念](concepts/03-core-concepts.md)开始，抓"无心""自然"义理主干
2. 读[选读段落](concepts/04-selected-passages.md)，对读严遵指归与王弼注
3. 参考[传本残缺与卷数诸说](concepts/02-versions-transmission.md)选择底本（日常用王德有点校本）
4. 跟着[四周阅读计划](examples/01-reading-plan.md)通读德经七卷
