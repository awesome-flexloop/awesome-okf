# 《老子指归》全书概览

## 一、书名与体例

《老子指归》又名《道德真经指归》《道德指归论》，为《老子》注本，题汉严遵（字君平）撰、唐人谷神子（冯廓）注（facts F1）。书名之异反映两大传本系统：道藏本、怡兰堂本题《道德真经指归》，秘册汇函、津逮秘书、学津讨原本题《道德指归论》（facts F4、F5）。

"指归"者，指明旨归。全书体例为每章先引《老子》经文，后附严遵"指归"阐发；谷神子注则在经句下作小注。道藏本系统保留经文全文，六卷本系统仅取每篇开头数字作篇题、删去经文（facts F5）。

## 二、七十二章结构：德前道后

全书分《老子》为**七十二章**：上经（德经）四十章、下经（道经）三十二章，无标目（facts F13）。此分章与河上公本、王弼本之八十一章不同，与帛书本《老子》德前道后之序相合（facts F13）。

《说二经目》自述其分章依据："昔者老子之作也，变化所由，道德为母，效经列首，天地为象，上经配天，下经配地。阴道八，阳道九，以阴行阳，故七十有二首。"（facts F27）即以阴阳之数（阴八阳九，八九七十二）编排行列，上经四十、下经三十二亦由五行八、四行八推得（facts F13、F27）。

## 三、现存残缺状况

今传本**残缺**：道藏本十三卷原缺卷一至六，仅存《德经》七卷（卷七至卷十三）；六卷本较道藏本又缺第十三卷，仅存三十四篇（facts F4、F5）。宋以后所见《指归》著录均为十三卷，道经部分已佚（facts F14）。

道经佚文散见于唐宋《老子》注疏——强思齐《玄德纂疏》、陈碧虚《藏室纂微篇》、李霖《取善集》、刘惟永《集义》并引《指归》道经佚文；蒙文通、王德有、樊波成先后辑集（facts F14）。

> **残缺书阅读提示**：今存七卷为德经部分，非全书。读《指归》须知道经三十二章已佚，仅能从辑佚佚文管窥其貌。

## 五、一句话定位

《老子指归》是现存最早的《老子》注本之一，以"道德—神明—太和—天地"的生成序列与"无心""自然""无为"诸范畴阐发《老子》，被视为两汉宇宙生成论向魏晋玄学本体论过渡的先声（facts F18–F22）。
