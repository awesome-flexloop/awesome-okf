# 四周阅读计划

王弼注以《老子道德经注》为主干，《周易注》《周易略例》为延伸，零基础读者建议按"版本判读先行"原则分四周通读（insights I2、P2）。底本用楼宇烈《老子道德经注校释》（中华书局）（fact F10）。

## 总原则

1. **版本判读先行**：第一周先明王弼本系统与底本选择，再读正文；
2. **《老》注为纲**：第二周读《老子》注要章，抓"以无为本"；
3. **《易》注为用**：第三周读《周易注》《周易略例》，看"得意忘言"的展开；
4. **对读收束**：第四周与河上公注对读，回查版本与诠释差异。

## 每日读法提示

1. 先读经文白文，再读注文，标记注文落在"本末"还是"言意"（insights P3）；
2. 注文引用前核对底本，异文处查 [../facts.md](../facts.md) F16–F24；
3. 《老》《易》互证：读四十章注时并读复卦注，读三十八章注时并读明象。
