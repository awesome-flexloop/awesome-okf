# Insights — 王弼《老子道德经注》《周易注》洞察与模式（I/E 阶段 · G2/G3）

## 洞察（G2 四元组：现象/根因/影响/建议）

### I1 自著注与托名注的知识包组织方式不同
- 现象：王弼（226—249）为信史注家，《三国志》附传可考，注为自著；与河上公等托名注本不同，无托名层/成书诸说分层问题（facts F1–F4）。
- 根因：自著注的生平与文本一体，年代可由史传直接锁定；托名注则需把传说与成书年代诸说分层登记。
- 影响：对自著注套用托名分层框架会制造不存在的"诸说并列"；反之对托名注直接采信署名会误定年代。
- 建议：自著注知识包以"生平与文本层合一"组织，史传引文直接登记；托名分层框架仅用于托名注。

### I2 王弼注引用须先判版本系统
- 现象：王弼本《老子》为传世本系统之一，与河上本、帛书本、竹简本分系；今本王弼本分章与早期传本亦有差异（洪颐烜所记空一格本）；《周易注》为《周易正义》所据，后世与韩康伯注合行（facts F8、F9）。
- 根因：王弼本经唐宋翻刻、辑录产生分化；《周易注》在合行过程中与韩注混编。
- 影响：不判版本直接引用，会把某一系统的分章或用字当作王弼原貌；引《周易注》时可能误把韩康伯注系于王弼。
- 建议：引用前声明底本（日常用楼宇烈校释本）；《老子》注与《周易》注分别注明版本系统；合行本中区分王注与韩注。

### I3 「崇本息末」「得意忘言」是王弼注的第一读法
- 现象：三十八章注"守母以存其子，崇本以举其末"、《周易略例·明象》"得意在忘象，得象在忘言"、复卦注"寂然至无，是其本矣"，三处注文构成"以无为本"的本末—言意双线（facts F12–F14）。
- 根因：王弼以「无」为本体，注文在《老》《易》两经间互训；本末论与言意论是同一本体论的两面。
- 影响：只按《老子》读会漏掉《周易注》的本体论展开；只按象数读《易》会漏掉"得意忘象"的诠释方法。
- 建议：通读时以"本末—言意"双线为默认框架；《老》注抓"崇本息末"，《易》注抓"得意忘象"，两线对读。

### I4 网络通行注本存在版本混拼，注文引用须双源核对
- 现象：本次核对发现中华文库本与五千言本在十一章注（"以实统众"／"以寡统众"）、道德经网与五千言在三十八章注（"德其母"／"则得其母"、"秘有患忧"／"必有患忧"）、四十章注（"贵以贱为本"／"贵以贱为奉"）等处存在异文（facts F18、F19、F21）。
- 根因：在线文本各据不同版本系统转录，标点为转录者所加；断句差异（如"所以"下属与否）会改变句意。
- 影响：单一信源抄录会把某一系统的异文当作定本；断句差异会造成理解分歧。
- 建议：入库注文至少经两个独立信源逐字核对；异文处登记不改字；正字以楼宇烈校释本为准。

## 可复用模式（E · G3）

### P1 自著注判读框架
- 触发场景：整理信史注家（王弼、郭象、成玄英等）注本知识时。
- 核心步骤：①史传引文直接登记生平；②著作清单与版本系统分开陈述；③不套用托名分层框架。
- 反模式：对自著注虚构"成书诸说"；把后世合行本的混编内容系于原作者。
- 迁移示例：concepts/01-life-era 按"生平与文本层合一"组织。

### P2 双源逐字核读法（王弼注版）
- 触发场景：任何需要给出王弼《老子注》《周易注》原文/注文片段的写作/整理任务。
- 核心步骤：①声明底本（楼宇烈校释本优先）；②选至少 2 个独立在线信源（中华文库 + 道德经网/五千言，或汉典古籍 + 维基文库）；③分别抄录目标段落；④逐字比对并登记异文（位置/各本作某）；⑤异文处加注不改字；⑥断句差异单独登记。
- 反模式：单一百科/文库直接抄录；静默统一异文；忽略断句差异。
- 迁移示例：本 bundle 双源核对记录见 [log.md](log.md)，核对结果登记于 [facts.md](facts.md) F16–F24。

### P3 本末—言意双线注文标记读法
- 触发场景：通读王弼《老子注》《周易注》《周易略例》时。
- 核心步骤：①通读时逐章标记注文落在"本末"（崇本息末/以无为本）还是"言意"（得意忘象/忘言）；②汇总对举句式（"守母以存其子，崇本以举其末"）作为旨要证据；③以《周易略例·明象》回验《老子注》的本体论。
- 反模式：只按单一维度（本末或言意）选读注文；忽略《老》《易》互训。
- 迁移示例：concepts/03-interpretive-method 与 examples/01-reading-plan 按此组织。
