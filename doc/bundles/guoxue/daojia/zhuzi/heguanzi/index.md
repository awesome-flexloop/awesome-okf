# 《鹖冠子》阅读教程

《鹖冠子》题楚人鹖冠子（楚之隐士，居深山，以鹖为冠）著，《汉书·艺文志》道家类著录一篇，今传本为宋陆佃注本三卷十九篇（facts F1、F6、F30）。全书以黄老道德为本，兼法家刑名与兵家言，四库提要定位"其说虽杂刑名，而大旨本原于道德"（facts F21、F22）。本知识包（bundle）是面向普通读者与研究者的《鹖冠子》系统中文阅读教程，特点有三：

1. **真伪之辩两说并列**——柳宗元《辩鹖冠子》判伪说与韩愈《读鹖冠子》推崇、四库提要翻案、出土文献再评价诸说并载，不作单一裁决（facts F12–F20）；
2. **关键原文双源核对**——《博选》《天则》《环流》《泰鸿》四篇核心段落以 ctext（四部丛刊本）× 维基文库（四库全书本/标点本）逐字核对，异文登记不改字；
3. **黄老系统定位**——与马王堆帛书《黄帝四经》的文本关联（《泰鸿》与《经法》等 18 处意同语同）作为理解其思想坐标的入口。

## 🚀 快速开始

如果你之前从未读过《鹖冠子》：

1. 先读[全书概览](concepts/00-overview.md)了解书名与十九篇结构
2. 读[真伪之辩](concepts/01-authenticity-debate.md)，理解这本书为何曾被弃置千年又被重新认定
3. 打开[三周阅读计划](examples/01-reading-plan.md)，按第 1 周计划先读《博选》《天则》

如果你已读过个别名篇（如《世兵》《学问》）：

1. 从[核心概念](concepts/03-core-concepts.md)开始，抓全书道法/刑名/兵家三要素主干
2. 读[版本与注本](concepts/02-versions.md)，了解陆佃注本系统与权威整理本
3. 跟着[选篇导读](concepts/04-selected-chapters.md)补读《环流》《泰鸿》等道论篇
