# 版本与注本：陆佃注本系统

《鹖冠子》仅存传世本，今通行本皆出自**宋陆佃注本**系统（facts F30–F33）。

## 著录沿革

| 时代 | 著录 | 说明 |
|------|------|------|
| 汉 | 《汉书·艺文志》道家类"《鹖冠子》一篇" | 注"楚人，居深山，以鹖为冠"（fact F1） |
| 隋 | 《隋书·经籍志》三卷 | 篇卷较汉志有附益（fact F2、F4） |
| 唐 | 韩愈所见十六篇本；《旧唐志》《新唐志》三卷 | 韩愈《读鹖冠子》称"十有九篇"，方崧卿注本或作"十六"（fact F2、F15） |
| 宋 | 陆佃注本十九篇 | 今通行本祖本（fact F30） |
| 清 | 《四库全书》本三卷（陆佃解） | 子部著录，卷首有四库提要（fact F31） |

四库馆臣案："惟其书汉志称一篇，隋志始为三卷，或汉以来有所附益，则未可知耳"（fact F4）——篇卷差异本身即提示文本有层累。

## 陆佃注本

- 陆佃（北宋）为《鹖冠子》作解，凡十九篇，自序称"其道踳驳，著书初本黄老，而末流迪于刑名"（facts F21、F30）。
- 陆佃序又谓韩愈但称十六篇，"未睹其全"；四库提要推测今本韩集作十九篇"殆后来反据此书以改韩集"（fact F30，R6）。
- 陆佃注在宋代已不甚显：惟陈振孙《书录解题》载其名，《文献通考》不著录；晁公武《读书志》但称有八卷本（前三卷全同《墨子》，后两卷多引汉以后事），公武削去前后五卷得十九篇，似未见陆注（R6 提要）。
- 今存明覆宋刊本：《四部丛刊初编》据景江阴缪氏艺风堂藏明覆宋刊本影印（fact F30，R9）。

## 权威整理本

- **黄怀信《鹖冠子汇校集注》**（中华书局，2004）[G]；
- **黄怀信《鹖冠子校注》**（中华书局，2014，新编诸子集成续编）[G]。

本教程原文引用以通行本（陆佃注本系统）用字为正字，异文登记于 [facts.md](../facts.md) F35，不改字；深入研究以黄怀信校注为底本依据。

## 底本选择原则

1. 在线引用优先选底本标注明确者（ctext 标注四部丛刊初编本）；
2. 双源核对至少取两个独立信源（本教程取 ctext × 维基文库四库本/标点本）；
3. 异文处登记不改字，版本层差异（四库本脱文、四部丛刊本异字）如实呈现。
