# 全书概览

《鹖冠子》是战国末期黄老系统的道家著作，兼法家刑名与兵家言（facts F1、F21、F22）。

## 书名与作者

- 书名即作者之号。"鹖"为鸟名（今名褐马鸡，《说文解字》"鹖，似雉"），性勇悍好斗；"鹖冠"即以鹖鸟羽毛为冠（fact F5）。
- 《汉书·艺文志》道家类著录"《鹖冠子》一篇"，注曰"楚人，居深山，以鹖为冠"（fact F1）。
- 托名层：传统题楚人鹖冠子，为楚之隐士；《艺文类聚》引袁淑《真隐传》"隐居深山，衣敝履空，以鹖为冠"（facts F6、F7）。
- 书中多载"庞子问鹖冠子"，庞子即战国末年赵将庞煖；旧题鹖冠子为庞煖之师（fact F8）。

## 篇卷结构

今传本三卷十九篇（宋陆佃注本系统）（fact F3）：

| 卷 | 篇目 |
|----|------|
| 卷上 | 博选第一、著希第二、夜行第三、天则第四、环流第五、道端第六、近迭第七 |
| 卷中 | 度万第八、王鈇第九、泰鸿第十、泰录第十一 |
| 卷下 | 世兵第十二、备知第十三、兵政第十四、学问第十五、世贤第十六、天权第十七、能天第十八、武灵王第十九 |

篇目内容大致可分三组：

- **道论组**：《夜行》《环流》《泰鸿》《泰录》《天权》《能天》——宇宙生成、气化流行、太一神明；
- **政治刑名组**：《博选》《著希》《天则》《道端》《度万》《王鈇》《备知》《世贤》——选贤、法度、君臣之术；
- **兵学组**：《近迭》《世兵》《兵政》《武灵王》——先兵之义、兵势、不战而胜。

## 思想定位

- 陆佃序："其道踳驳，著书初本黄老，而末流迪于刑名"（fact F21）。
- 四库提要："其说虽杂刑名，而大旨本原于道德，其文亦博辨宏肆"（fact F22）。
- 本教程采用"道家为本、兼法家刑名与兵家"的定位，与《黄帝四经》同属黄老系统（见 [03-core-concepts.md](03-core-concepts.md)）。

## 历史评价

- 刘勰《文心雕龙》："鹖冠绵绵，亟发深言"（fact F34）。
- 韩愈《读鹖冠子》称其"施于国家，功德岂少"；柳宗元《辩鹖冠子》则判为伪书——两说详见 [01-authenticity-debate.md](01-authenticity-debate.md)。
- 吕思勉品评为"子部瑰宝"（fact F34）。
