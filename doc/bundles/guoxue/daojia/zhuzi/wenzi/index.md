# 《文子》阅读教程

《文子》唐天宝元年诏号《通玄真经》，《汉书·艺文志》道家类著录九篇，班固原注「老子弟子，与孔子并时，而称周平王问，似依托者也」；今传本十二篇（facts F1、F2、F4）。全书以老子之言为教，主圣人无为而治、兼采礼法，上承老子下启黄老（facts F36–F38）。本知识包（bundle）是面向普通读者与研究者的《文子》系统中文阅读教程，特点有三：

1. **伪书翻案学术史并载**——唐柳宗元判「驳书」以来千余年伪书说，与 1973 年定州八角廊汉墓竹简出土后「先秦古籍但今本有窜乱」的翻案主流说并列陈述，另存「今本现况晚于《淮南子》」一说，不作单一裁决（facts F12–F23）；
2. **关键原文双源核对**——《道原》《精诚》《自然》《道德》四篇关键段落经 ctext.org 与维基文库逐字比对，异文登记不改字（facts F28–F35）；
3. **托名层诸说分层**——文子其人有老子弟子、子夏弟子、计然（辛钘）诸说，李暹合计然文子为一人之说与《四库提要》驳论并载（facts F6–F11）。

## 🚀 快速开始

如果你之前从未读过《文子》：

1. 先读[全书概览](concepts/00-overview.md)了解书名沿革与九篇/十二篇著录之变
2. 读[八角廊竹简与翻案](concepts/01-bamboo-slip-discovery.md)，理解这本书「千年伪书一朝翻案」的学术史位置
3. 打开[四周阅读计划](examples/01-reading-plan.md)，按第 1 周计划从《道原》篇开始

如果你已知道「文子」其名或读过个别段落：

1. 从[核心概念](concepts/03-core-concepts.md)开始，抓全书义理主干
2. 读[版本与注本](concepts/02-versions.md)，理解今本与竹简本、《淮南子》的复杂关系
3. 跟着[选篇导读](concepts/04-selected-chapters.md)对照双源核对原文精读四篇
