# Insights — 《文子》洞察与模式（I/E 阶段 · G2/G3）

## 洞察（G2 四元组：现象/根因/影响/建议）

### I1 出土文献可推翻千年定谳，但翻案结论须分层限定
- 现象：《文子》自唐柳宗元判「驳书」后千余年间多被视为伪书；1973 年定州八角廊汉墓竹简出土后，「先秦古籍」说成为主流（facts F12、F15、F20）。
- 根因：传世文献辨伪只能依据文本内部证据（文风、重出、年代矛盾）；出土文献提供了抄写年代的硬下限（五凤二年，前 56 年），直接证明其书至迟西汉已流传（fact F17）。
- 影响：翻案若不加限定，会把「古本不伪」误读为「今本全部可信」；今本中与《淮南子》相重的八成五文字仍属窜乱嫌疑部分（facts F22、F23）。
- 建议：翻案表述统一限定为「先秦古籍但今本有窜乱」；引用今本段落时区分与《淮南子》相重/不相重两类。

### I2 古本与今本须分层陈述，竹简本不能径改今本
- 现象：竹简《文子》仅存 277 枚 2790 字，问答体作「平王曰……文子曰」；今本十二篇作「文子问……老子曰」，体例相反（facts F15、F19）。
- 根因：竹简本残损严重且可能为节录，今本在流传中经过改题问答主客、增窜《淮南子》文字等多重改造。
- 影响：以竹简本释文径改今本会制造「伪古本」；以今本面貌反推竹简本会低估文本变动幅度。
- 建议：教程中竹简本与今本各作一层陈述；涉及体例差异（问答主客、篇题）处显式对照，不作静默统一。

### I3 托名诸说须并置而非择一
- 现象：文子其人有老子弟子（《汉志》）、子夏弟子（刘向《别录》）、计然辛钘（李暹注、杜道坚序）诸说；《四库提要》又驳李暹合计然文子为一人之非（facts F6–F10）。
- 根因：汉代以前人物记载多依托传闻；「计然」与「文子」的合并始于北魏李暹注，此前两书两人界限分明（《意林》并列两书）。
- 影响：直题「辛钘著」会采纳一家晚出之说为定论；完全否认托名层又与《汉志》著录体例冲突。
- 建议：统一采用「传统题老子弟子文子（一说计然，姓辛）」表述，诸说并列于托名层表格，注明各说出处与时代。

### I4 网络通行本存在系统性转录差异，原文引用须双源核对
- 现象：本次核对发现 ctext 本与维基文库本多处异文：「表之不盈一握／卷之不盈一握」「大常之道／天常之道」「尊精积稽／尊精积稸」「故有道则知／故有道则和」（facts F28、F32）。
- 根因：《文子》传本系统复杂（道藏本、四库本、守山阁本等），数字化转录各据不同底本；「稸/稽」「和/知」等异文部分可追溯至竹简本（竹简作「和」）。
- 影响：单一信源抄录会把某一传本的异文当作原文；与竹简本相合的异文（如「和」）可能被误判为讹字。
- 建议：入库原文至少经两个独立信源逐字核对；异文处登记不改字；与竹简释文相合的异文优先标注（可能存古）。

## 可复用模式（E · G3）

### P1 出土文献翻案判读法
- 触发场景：整理曾被判伪、后有出土文献介入的古籍（《文子》《鹖冠子》《六韬》等）。
- 核心步骤：①陈述判伪定谳（定谳者、时代、理由）；②陈述出土证据（出土时间地点、数量、年代下限）；③陈述翻案后主流说（限定表述：先秦古籍但今本有窜乱）；④并列未翻案部分（今本与出土本不符处、与同时代书相重处）。
- 反模式：翻案不加限定（「出土即全部可信」）；无视出土证据继续判伪。
- 迁移示例：本 bundle concepts/01-bamboo-slip-discovery 按此四步组织。

### P2 双源逐字核读法（《文子》版）
- 触发场景：任何需要给出《文子》原文片段的写作/整理任务。
- 核心步骤：①选至少 2 个独立信源（ctext.org 道藏本系统 + 维基文库白文）；②分别抄录目标段落；③逐字比对并登记异文（位置/各本作某）；④与竹简释文相合的异文标注「可能存古」；⑤异文处加注不改字。
- 反模式：单一百科/诗词站直接抄录；把与竹简本相合的异文当讹字径改。
- 迁移示例：本 bundle 双源核对记录见 [log.md](log.md)，核对结果登记于 [facts.md](facts.md) F28–F35。

### P3 托名文本三层判读框架
- 触发场景：整理托名争议古籍（《文子》《列子》《关尹子》等）知识时。
- 核心步骤：①拆托名层（书名所托之人，诸说并列注明出处时代）；②拆文本层（文本真伪学术史，出土文献介入前后分段陈述）；③拆思想层（全书义理主干，独立于真伪裁决）。
- 反模式：以托名裁决替代文本裁决；以文本裁决否定思想价值。
- 迁移示例：concepts/00-overview（托名层）与 concepts/01-bamboo-slip-discovery（文本层）按此分层组织。
