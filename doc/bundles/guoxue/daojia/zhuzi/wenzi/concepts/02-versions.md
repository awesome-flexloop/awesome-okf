# 版本与注本

## 注本系统

《文子》注本自北魏至元有四个系统（fact F24）：

| 注本 | 注者 | 卷数 | 状态 |
|------|------|------|------|
| 《文子注》 | 李暹（北魏） | — | 不传（据《读书志》所引） |
| 《通玄真经注》 | 徐灵府（默希子，唐） | 十二卷 | 存，《正统道藏》洞神部玉诀类 |
| 《通玄真经注》 | 朱弁（宋） | 七卷（一作十二卷） | 存，缺《自然》《下德》《上仁》《上义》《上礼》五篇 |
| 《通玄真经缵义》 | 杜道坚（元） | 十二卷 | 存，《正统道藏》洞神部玉诀类 |

> 杜道坚《缵义》自注：「《文子》十二篇，凡一百八十八章，道坚随义析之，增八十一章，章别其旨，题曰《缵义》」（fact F25）。
