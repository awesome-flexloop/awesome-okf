# 《关尹子》阅读教程

《关尹子》题周关令尹喜撰，《汉书·艺文志》道家类著录九篇，刘向《列仙传》作《关令子》；《隋志》《唐志》皆不著录，其佚已久（facts F1、F2）。南宋徐蒇（子礼）始得本于永嘉孙定家，前有刘向校定序，后有葛洪序（fact F3）。宋徽宗尊号《文始真经》（fact F5）。全书分一宇、二柱、三极、四符、五鉴、六匕、七釜、八筹、九药九篇（fact F6）。本知识包（bundle）是面向普通读者与研究者的《关尹子》系统中文阅读教程，特点有三：

1. **真伪之辩两说并列**——宋濂《诸子辨》疑孙定伪为说与四库提要"其书虽出于依讬，而核其词旨，固远出《天隐》《无能》诸子上，不可废也"两说并载，不作单一裁决（facts F10–F14）；
2. **关键原文双源核对**——《一宇》《三极》《四符》《五鉴》核心段落以维基文库本 × 四库全书本（经 cnkgraph 影印转写）逐字核对，玄/元避讳字与形近讹字登记不改字；
3. **托名层/文本层分判**——书名托关令尹喜（托名层）与文本层"唐宋方士解文章者所为"（四库提要语）分开陈述，不以依托否定其思想史价值。

## 🚀 快速开始

如果你之前从未读过《关尹子》：

1. 先读[全书概览](concepts/00-overview.md)了解书名与九篇结构
2. 读[真伪之辩](concepts/01-authenticity-debate.md)，理解这本书为何被定为"依托"却仍"不可废"
3. 打开[三周阅读计划](examples/01-reading-plan.md)，按第 1 周计划先读《一宇》《三极》

如果你已读过个别名篇（如《一宇》"一道能作万物"）：

1. 从[核心概念](concepts/03-core-concepts.md)开始，抓全书道/心性/精神魂魄/梦觉四要素主干
2. 读[版本与注本](concepts/02-versions.md)，了解南宋重出本与四库本系统
3. 跟着[选篇导读](concepts/04-selected-chapters.md)补读《四符》《五鉴》等心性篇
