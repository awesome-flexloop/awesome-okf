# 版本与注本：南宋重出本系统

《关尹子》仅存传世本，今通行本皆出自**南宋徐蒇所得永嘉孙定家本**系统（前有刘向序、后有葛洪序）（facts F3、F21）。

## 著录沿革

| 时代 | 著录 | 说明 |
|------|------|------|
| 汉 | 《汉书·艺文志》道家类"《关尹子》九篇"；刘向《列仙传》作《关令子》 | 旧本著录（fact F1） |
| 隋 | 《隋书·经籍志》不著录 | 其佚已久（fact F2） |
| 唐 | 《旧唐志》《新唐志》皆不著录 | 同上（fact F2） |
| 宋 | 南宋徐蒇得本于永嘉孙定家；宋徽宗尊号《文始真经》 | 今本祖本重出（facts F3、F5） |
| 清 | 《四库全书》子部道家类著录一卷 | 卷首有四库提要（fact F22） |

四库提要案："考汉志有《关尹子》九篇……而《隋志》《唐志》皆不著录，则其佚久矣。南宋时徐蒇子礼始得本于永嘉孙定家"（fact F3）——著录链的中断（汉有→隋唐无→南宋重出）本身即是依托文本的层累证据。

## 南宋重出本

- 徐蒇（字子礼）于永嘉孙定家得本，前有刘向校定序，后有葛洪序（fact F3）。
- 刘向序叙传授链："盖公授曹相国参，曹相国薨，书葬；至孝武皇帝时，有方士来，以七篇上……淮南王安好道聚书，有此不出；臣向父德，因治淮南王事得之"——四库提要评"其说颇诞"，疑假借淮南鸿宝秘书事附会（fact F4）。
- 葛洪序叙篇题释义："宇者道也，柱者建天地也，极者尊圣人也，符者精神魂魄也，鉴者心也，匕者食也，釜者化也，筹者物也，药者杂治也"，自署"洪亲受之，咸和二年五月朔，丹阳葛洪稚川序"（fact F6，R2）。

## 注本

- 俞琰《席上腐谈》称旧有陈抱一注；元大德中有杜道坚注，名曰《阐玄》——四库提要称"今皆未见"（fact F24）。
- 调研基座：今本无公认权威整理本（fact F25，[G]）。
