# 《列子》阅读教程

《列子》，唐天宝元年（742 年）诏号《冲虚真经》，宋景德四年（1007 年）加至德二字曰《冲虚至德真经》；全书八篇，传统题战国列御寇（列子）撰，汉刘向定为八章（facts F1、F4、F16、F17）。本知识包（bundle）是面向普通读者与研究者的《列子》系统中文阅读教程，特点有三：

1. **署名双层陈述**——托名层（列御寇战国郑人，《汉志》"列子八篇"、《吕氏春秋》"子列子贵虚"）与文本层（魏晋伪托/辑缀说 + 含先秦材料说 ≥2 学说并列不裁决）分开叙述，不做单一判定（insights I1）；
2. **辨伪史两说并载**——自唐柳宗元《辨列子》发疑，至宋朱熹、明宋濂、清姚际恒，至近代马叙伦《列子伪书考》二十证、杨伯峻《列子著述年代考》汉语史辨伪为"主伪说"，另一面则有吕思勉等"含先秦材料说"，以及严灵峰《列子辩诬》、马达《列子真伪考辨》等主"非伪"，两派均列陈述，不裁决；
3. **原文双源逐字核对**——选读寓言（愚公移山、杞人忧天、两小儿辩日）均经 ctext.org × 维基文库 × 古诗文网 双源逐字比对，异文登记不改字。

## 🚀 快速开始

如果你之前从未读过《列子》：

1. 先读[全书概览](concepts/00-overview.md)了解八篇结构与道藏封号
2. 打开[作者与辨伪史](concepts/01-authorship-authenticity.md)建立两层署名框架
3. 跟着[三周阅读计划](examples/01-reading-plan.md)第 1 周先读《天瑞》与《汤问》寓言
4. 读[选篇导读](concepts/04-selected-chapters.md)按兴趣深入

如果你已读过个别寓言（如愚公移山、杞人忧天）：

1. 从[核心概念](concepts/03-core-concepts.md)抓"贵虚""生死观""安命"义理主干
2. 读[版本与注本](concepts/02-versions.md)，用杨伯峻《列子集释》作底本
3. 回读[作者与辨伪史](concepts/01-authorship-authenticity.md)了解为何两说并存
4. 参考[三周阅读计划](examples/01-reading-plan.md)补齐未读篇目

## 🎯 Bundle 定位

| 维度 | 本 bundle（liezi） | 典型网络资料 |
