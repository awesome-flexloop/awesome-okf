# 版本与注本

## 传世本链：张湛注本系统

《列子》**仅有传世本（晋张湛注本系统），无出土本**（fact F26，[G]）。与有出土简帛本的《老子》《庄子》《文子》不同，《列子》的文本层断链长达 300 余年，只能通过张湛序与《隋书·经籍志》等目录学材料勾勒传本：

| 阶段 | 事件 | 依据 |
|------|------|------|
| 永嘉之乱（4 世纪初） | 张湛家存残卷三卷：《杨朱》《说符》《目录》 | 张湛《列子序》（fact F27） |
| 东晋（约 4 世纪中） | 自正舆（刘舆？）、王弼女婿赵季子等处搜辑残卷六卷，"参校有无，始得全备"，定八篇注本 | 张湛《列子序》（fact F27） |
| 《隋书·经籍志》 | 著录"《列子》郑之隐人列御寇撰，东晋光禄勋张湛注" | 正史目录（fact F28） |
| 唐 | 殷敬顺撰《列子释文》一卷；天宝元年诏号《冲虚真经》 | fact F29、F1 |
| 宋 | 陈景元（碧虚子）补《列子释文》遗；景德四年加"至德"曰《冲虚至德真经》；道藏本入藏 | fact F29、F1 |
| 清 | 任大椿《列子释文考异》 | fact F29 |

### 张湛事略（据《列子集释》附录一张湛事迹辑略 [R5]）

张湛字处度，高平人（今山东金乡一带）。东晋官至中书侍郎、光禄勋。除注《列子》外，又注《庄子·让王》《文子》，撰《养生要集》十卷（佚）。其注《列子》融儒释道三家，又以玄学解经，是东晋玄学晚期的代表注本。

### 张湛《列子序》要点（fact F27）

> 湛闻之先父曰：吾先君与刘正舆、傅颖根皆王氏（王宏、王弼、王粲）之甥也，并舅氏（王宏）所集善本。遭永嘉之乱，颖根（傅敷）南逃时在车中漏失其本，仅存《杨朱》《说符》《目录》三卷。后正舆、辅嗣女婿赵季子家各得六卷，参校有无，始得全备。

这段叙录一方面解释了"永嘉散佚 → 残卷拼合"的传本链，另一方面也是主伪派（梁启超等）质疑"张湛自注自造"的文本切入点。
