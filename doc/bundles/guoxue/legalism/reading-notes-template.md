# 法家知识包阅读笔记模板

本模板与法家知识包共同体例对接：每一栏都对应知识包的一项质量承诺（事实编号可回溯、异文并列、归属分层、多元解读）。填写笔记的过程即执行这套体例的过程。使用时复制所需章节到自己的笔记文件，删除不用的部分。

## 使用说明

| 场景 | 使用章节 |
|---|---|
| 逐篇精读（《更法》《五蠹》等传世篇目） | 一至七节（完整流程） |
| 概念研读（农战一体、法不阿贵等） | 二、三、五节 |
| 辑佚篇目（《申子》佚文、《慎子》残篇） | 一至七节 + 第八节（辑佚专版） |
| 快速摘录（浏览式阅读） | 仅三、四节 |
