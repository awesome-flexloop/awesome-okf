# 法家知识包阅读指南

本指南面向首次进入法家域的读者，回答四个问题：读之前要知道什么、四包各是什么定位、按什么顺序读、以及如何核验读到的原文。域内四个知识包（管子、商君书、韩非子、早期法家辑佚）各自独立成篇，但共享同一套事实登记与异文体例——理解这套体例是有效阅读的前提。

## 一、阅读前提：三个必须先接受的体例

1. **成书性质显式分层**。法家文献多为学派结集而非个人专著：《管子》托名管仲、实为稷下学派文献总集；《商君书》非商鞅手著、为商鞅学派结集；《韩非子》主体为韩非亲著但经汉代刘向编定；《申子》《慎子》则已严重散佚、今存辑佚残篇。各包首页均显式标注这一层次——把托名当史实、把结集当手著，是读法家文献最常见的错误。
2. **异文并列、不作裁决**。全部原文经多源实抓核对，凡各底本文字有出入处（如《商君书·开塞》"刑者/利者"之异、《韩非子·有度》"辟/避"之异），均显式登记为编号事实并并列呈现。引用原文时须注明所据底本，不要把某一源的文字当成唯一"正确"文本。
3. **事实编号可回溯**。每个引文后附事实编号（F-GZ / F-SJS / F-HF / F-EL 前缀），通过编号可回溯信源登记中的原始 URL 复核。怀疑任何一句引文时，第一步是查编号、对信源，而不是查百度。

## 二、四包定位与依赖关系

| 知识包 | 思想史位置 | 核心问题 | 阅读难度 |
|---|---|---|---|
| [管子](guan-tzu/index.md) | 齐国稷下学派，法家兼儒道阴阳 | 经济伦理与国家调控（仓廪礼节论、轻重之术） | 中 |
| [商君书](shang-jun-shu/index.md) | 秦国道术，耕战体系的制度设计 | 富国强兵如何重构社会（农战、壹刑、弱民） | 中高 |
| [韩非子](han-fei-tzu/index.md) | 法家集大成，法·术·势总汇 | 君主制的技术性治理（参验、刑名、说难） | 高 |
| [早期法家辑佚](early-legalists/index.md) | 集大成之前的源流（李悝→申不害·慎到·商鞅） | 术与势的原始形态、法家从何而来 | 高（辑佚体例） |

依赖关系上，四包彼此独立、均可单独进入；但**源流→集大成**的历史叙事线（李悝→申商→韩非）以《韩非子·定法》"皆帝王之具也"为总纲，因此先读韩非子包的[法·术·势三纲](han-fei-tzu/concepts/fa-shu-shi.md)再回溯早期法家辑佚包，源流谱系会更有落点。

## 三、推荐阅读路径

### 路径 A：思想史顺序（源流→集大成，适合系统研读）

```
1. 早期法家辑佚包《法家源流》概念 —— 建立谱系图：李悝→申不害(术)·慎到(势)·商鞅(法)→韩非
2. 管子包《仓廪礼节论》+《牧民》精读 —— 理解法家思想中"经济基础"一脉的温和形态
3. 商君书包《历史进化观》+《开塞》精读 —— 进入激进变法一脉（不法古不修今、刑九赏一）
4. 韩非子包 法·术·势三纲 → 《五蠹》精读 —— 抵达集大成的体系总汇
5. 早期法家辑佚包 申不害之术 + 慎到之势精读 —— 回望集大成之前的两源
```

### 路径 B：从精读入手（适合以文本为中心的读者）

```
1. 商君书包《更法》精读 —— 全书第一篇，论战体，对话与论证结构清晰，是最好的入门文本
2. 韩非子包《五蠹》精读 —— 理论密度最高，串联历史进化论、显学批判、文化政策
3. 管子包《牧民》精读 —— 仓廪四维开篇，对照商韩的激进方案
4. 韩非子包《说难》《孤愤》精读 —— 法术之士的处境与游说方法论
5. 早期法家辑佚包《申子·大体》《慎子·威德》细读 —— 辑佚文本的特殊读法（见下节）
```

## 四、辑佚文本的特殊读法

早期法家辑佚包与其他三包体例不同，阅读时须多注意三点：

1. **佚文不是完本**。《申子》今仅存《大体》一篇（经《群书治要》保存），《慎子》四十二篇残存七篇。辑佚文本只能支持"某命题见于某书引"的判断，不能支持"申不害思想体系全貌"的重构——任何超出佚文范围的体系化叙述都是后人的建构。
2. **每条佚文都有出处链**。佚文后括注的《艺文类聚》《意林》《太平御览》等，是辑佚的来源类书。判断一条佚文可信度时，看出处链：类书越早、越接近原书时代，可信度越高。
3. **两源标记**：事实登记用 ✅（实抓）与 🔎（检索验证）区分核验状态，引用前先确认标记。

## 五、信源复核方法

各包引文的复核路径统一：

```
引文后的事实编号（如 F-SJS-033）
  → 主仓 .trae/specs/create-legalism-okf-wiki/ 下对应 facts 文件
  → 该条登记的信源 URL（ctext.org / 古诗文网 / 中华典藏 / moocky 等）
  → 对照原文，核验异文标注
```

工作底本参考：商君书用蒋礼鸿《商君书锥指》（中华书局《新编诸子集成》），管子用黎翔凤《管子校注》，韩非子用陈奇猷《韩非子新校注》，慎子用许富宏《慎子》（中华书局）。西学脉络可循 Yuri Pines（商君书译注）与 Herrlee Creel（申不害研究）两条线，见各包 references 分区。

## 六、阅读节奏建议

- **概念文档**（concepts/）每篇 10-20 分钟，建议按各包"学习路径"节的顺序通读一遍，不追求一次消化全部细节。
- **精读文档**（examples/）每篇 30-60 分钟，需要对照原文逐段读，异文处停留做笔记。
- **信源文档**（references/）不必通读，作为研读时的核查工具按需取用。
- 全域完整研读（四包全部概念+精读）约需 10-15 次专注阅读会话；若只走路径 B 的五篇精读加对应概念，3-5 次即可建立骨架。
