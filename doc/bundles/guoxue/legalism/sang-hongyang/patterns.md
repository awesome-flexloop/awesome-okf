# 桑弘羊知识包·可复用模式

> 三个模式均满足可迁移性要求：有明确触发场景、可复现步骤、对等反模式、至少一个跨领域迁移验证。

## 模式一：制度文本三源对读法

### 触发场景

- 研究一项历史制度，手上有多种材料，但类型不同（编年史、专门志、论辩集、奏议）；
- 发现同一件事在不同材料里说法不一，不确定该信哪一个；
- 需要判断某句引文能否作为论据。

### 核心步骤

1. **列出材料类型表**：给每种材料标注"性质—成书年代—可靠性—擅长回答的问题"。例如《史记·平准书》擅长制度与数字，《汉书》纪传擅长编年与人事，《盐铁论》擅长论辩与思想。
2. **锁定同一议题**：只比同一件具体事（如"桑弘羊任什么官"），不做整段泛比。
3. **逐字并列**：把各材料的原句并排抄录，标出篇目与版本。
4. **给差异分类**：用字差异／句读差异／叙事次序差异／覆盖范围差异／性质差异。
5. **按类型定引用**：事实引史书，思想引论辩集，制度细节引奏议；差异登记在案，不强行统一。

### 反模式

| 反模式 | 表现 | 后果 |
|--------|------|------|
| 单源定论 | 只引一种材料就下结论 | 忽略异文与叙述立场 |
| 以文代史 | 用对话体证明制度细节 | 把文学修辞当事实 |
| 强行统一 | 把异文改成"通顺"的版本 | 掩盖史料层累，失去研究线索 |
| 泛比不锁题 | 整段对读，不聚焦具体问题 | 越读越乱，无法得出结论 |

### 迁移验证

**场景**：研究唐代两税法。

- 材料类型：两税法诏令（制度文本）、两《唐书》食货志（专门志）、《通典》（政书）、韩愈等文人议论（论辩）。
- 应用：先锁"两税何时定名""户税与地税如何合并"等具体议题，再逐字并列；文人议论只用于思想史，不用于制度细节。
- 结论：该方法在任何"多类型史料并存"的制度史研究中通用，不依赖汉代背景。

## 模式二：政策评价四步法

### 触发场景

- 一项政策引发长期争议，双方各执一词；
- 需要写评价性文章，但不想沦为立场宣示；
- 需要在"效果"与"价值"之间划清界限。

### 核心步骤

1. **事实层**：这项政策具体怎么运作？机构、流程、对象、成本。（只描述，不评价）
2. **效果层**：原典/数据记录了哪些可观察后果？分正面、负面、未证实三类。
3. **激励层**：制度让谁受益、让谁受损、让谁改变行为？（如告缗使储蓄转向消费，F-SHY-048）
4. **价值层**：在安全、民生、伦理等坐标上如何排序？（此步必须由评价者自认，不能用史料代替）

### 关键纪律

- **前三步可证，第四步不可证**：把两者混在一起，就会用价值判断冒充事实判断。
- **区分"税"与"负担"**："民不益赋"（F-SHY-039）只说明税目未增，不说明价格未涨、隐性负担未增。
- **区分"设计目标"与"执行结果"**：设计目标写在奏议里，执行结果写在纪传里。

### 反模式

| 反模式 | 表现 | 后果 |
|--------|------|------|
| 以道德代分析 | "与民争利"四字包打天下 | 无法解释制度为何长期存在 |
| 以成败论人 | 因谋反被诛而否定全部制度 | 忽略五铢钱等长期有效部分 |
| 以现代范畴套古代 | 直接称"宏观调控""国企" | 遮蔽汉代制度的具体条件 |
| 跳过激励层 | 只谈效果好坏，不谈行为改变 | 错过最重要的长期后果 |

### 迁移验证

**场景**：评价当代某项平台监管政策。

- 事实层：规则条文、执行机构、处罚手段；
- 效果层：可查的投诉率、价格变化、市场集中度；
- 激励层：平台、商家、消费者各自的行为调整；
- 价值层：创新、公平、安全如何排序。
- 结论：四步法同样适用；且"跳过激励层"是最常见的失误，与桑弘羊研究中的失误同构。

## 模式三：执行偏差三信号识别

### 触发场景

- 一项政策设计良好，但执行后出现"变味"；
- 需要判断问题出在个人道德还是制度结构；
- 监管者同时是被监管行业的经营者。

### 核心步骤

1. **查质量信号**：产品或服务是否出现"苦恶"类抱怨？（F-SHY-029 铁器苦恶）
2. **查强制信号**：是否出现"强令买卖""留难"等记载？（F-SHY-029、F-SHY-037）
3. **查人员信号**：监管者是否来自被监管行业、与被监管者同源？（F-SHY-027 "多贾人"）
4. **判断结构**：三信号中两个以上出现，优先诊断为**角色冲突**，而非个人腐败。
5. **对症下药**：分离监管权与经营权；改变考核指标；建立外部复核。

### 反模式

| 反模式 | 表现 | 后果 |
|--------|------|------|
| 道德化归因 | 把结构问题说成"贪官污吏" | 换人之后问题重现 |
| 只看口号 | 以"便民""抑商"等目标论证成效 | 忽略执行后果 |
| 忽视人员同源 | 不问监管者从哪来 | 错过最关键的制度线索 |

### 迁移验证

**场景**：分析某行业"裁判员兼运动员"问题（如平台自营与平台治理）。

- 质量信号：自营商品与第三方商品的投诉率差异；
- 强制信号：是否出现强制搭售、流量倾斜；
- 人员信号：监管团队是否来自被监管业务线。
- 结论：三信号法可跨时代使用；桑弘羊案例的价值在于它提供了**最早的完整记录**——质量、强制、人员三项信号同时出现，且被当时人写入史书。

## 三个模式的关系

| 模式 | 解决的问题 | 使用阶段 |
|------|-----------|---------|
| 三源对读法 | 材料可信吗？ | 研究起点 |
| 四步评价法 | 如何评价？ | 研究终点 |
| 三信号识别 | 为什么变味？ | 中间诊断 |

三者构成一条完整链路：**先确认材料（模式一）→ 再诊断执行（模式三）→ 最后评价（模式二）**。跳过任何一步，结论都会失真。
