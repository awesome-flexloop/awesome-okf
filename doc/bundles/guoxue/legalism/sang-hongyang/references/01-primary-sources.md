## 版本与转写说明

### 简体转写

本包所有引文均取自上述数字底本的**简体输出**。维基文库与 ctext.org 默认提供简体转换，因此：

- 原文中的异体字、通假字在转写中可能已被规范化；
- 繁简一对一以外的字（如"筦／管""斡／筦"）以页面实际显示为准；
- 引用时若需繁体原貌，应回查繁体版页面或纸本。

### 底本层级

- **ctext.org**：《盐铁论》以《四部丛刊初编》本为底本，页面同时列出《钦定四库全书》本、《龙溪精舍丛书》本、《摛藻堂四库全书荟要》本、《乾隆御览四库全书荟要》本等影像，可用于核对。
- **维基文库**：《史记》《汉书》为公有领域文本的数字化录入，未附校勘记。
- 两者都是**阅读本级**的底本，不是**校勘本级**的定本。

### 缺失与风险

| 风险 | 表现 | 处置 |
|------|------|------|
| 缺字 | 个别页面以方框或拼音代替生僻字 | 引用时加说明，不臆补 |
| 繁简误转 | 同名异字被合并（如"嬢／缗"） | 异文表中并列保留 |
| 页面变更 | 数字库链接内容可能修订或失效 | 引用时记录篇目与卷次，不只记 URL |
| 句读差异 | 无标点或标点不同导致语义变化 | 关键句注明所据版本（如 Y-SHY-07） |

## 引用规范

### 三条硬规则

1. **篇目优先于 URL**：引用格式写"《史记·卷三十·平准书》"，URL 只作辅助。链接失效时，篇目仍可定位。
2. **逐字为准，不改字**：引文与底本不一致时，宁可在括号内注明"底本作某"，也不直接改字。
3. **性质匹配**：制度细节引史书（甲、乙），论辩思想引《盐铁论》（丙），两者不可互换。

### 推荐引用格式

```
《史记·卷三十·平准书》："……"（信源：https://zh.wikisource.org/wiki/史記/卷030）
```

### 进一步核对建议

本包的数字底本足以支撑通读与教学，但若用于学术写作，建议进一步核对：

- 中华书局点校本《史记》《汉书》（看校勘记与标点）；
- 《盐铁论》的整理本（看篇目分章、异文校记）；
- 相关职官志（如《汉书·百官公卿表》）以确认官名沿革（本包未展开，见 U-SHY-03）。

## 本包未使用的材料

以下材料与桑弘羊相关但本包**未纳入事实清单**，原因如列：

| 材料 | 相关性 | 未用原因 |
|------|--------|---------|
| 《汉书·百官公卿表》 | 可确认大司农、御史大夫的任免年份 | 未实抓核对，避免二手转述 |
| 《汉书·武帝纪》 | 可确认榷酒酤、算缗令的诏令年份 | 未实抓核对 |
| 《资治通鉴》相关卷 | 编年整合，便于通读 | 二手编纂，不作第一信源 |
| 后世论说（王安石、司马光等） | 接受史 | 未逐条核对原文，不引 |

这些缺口不影响本包的核心结论，但读者若要做年表级研究，应补齐上述材料。
