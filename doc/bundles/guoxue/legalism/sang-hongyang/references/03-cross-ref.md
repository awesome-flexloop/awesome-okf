# 交叉引用：组内对照与跨域连接

## 组内对照（法家组）

桑弘羊与先秦法家共享功利主义与制度工具论，但没有"法术势"式的理论体系。对照阅读可以看清"法家"这个标签的边界。

| 知识包 | 对照点 | 建议读法 |
|--------|--------|---------|
| [韩非子](../../han-fei-tzu/index.md) | 法·术·势三纲 vs 桑弘羊的商业财政 | 先读韩非的"帝王之具"，再问：盐铁均输属于"法"还是"术"？答案可能都不是 |
| [商君书](../../shang-jun-shu/index.md) | 农战、壹赏壹刑 vs 盐铁官营 | 商鞅抑商是抑制私商，桑弘羊"抑商"是取代私商；目标同、手段异 |
| [管子](../../guan-tzu/index.md) | 轻重之术、官山海 vs 均输平准 | 读《管子》轻重诸篇，注意"官山海"与桑弘羊政策的异同；直接承袭关系属推断 |
| [早期法家辑佚](../../early-legalists/index.md) | 法家源流谱系 | 用于定位桑弘羊在"法家"叙事中的位置；本包不主张把他列入先秦法家谱系 |
| [法家阅读指南](../../reading-guide.md) | 阅读前提与路径 | 先读指南，再进入各包 |
