# 桑弘羊（Sang Hongyang）

桑弘羊（约前152—前80）是汉武帝后期至昭帝初年的财政主官。他主持盐铁官营、均输平准、五铢钱与算缗告缗，把汉帝国的财政从"食租衣税"推向"经营天下货物"；他也在始元六年的盐铁会议上成为贤良文学集中攻击的对象，最终于元凤元年以谋反罪被诛。

原典对他没有独立传记。他的形象由三类材料拼合：**《史记·平准书》的制度叙述**、**《汉书》纪志传的编年与人事**、**《盐铁论》的论辩文学**。三者的证据力不同，混用即失真——这是本包反复强调的第一条纪律。

## 一句话概括

桑弘羊的核心问题不是"要不要干预经济"，而是：**当战争与大一统的支出超过常规税基时，国家应该加税、借钱，还是自己下场做生意？** 他选择了第三条路，并由此留下一个延续两千年的评价难题。

## 使用方式

本包事实编号前缀为 **F-SHY**，共 76 条，全部登记在[事实清单](facts.md)，每条附信源 URL。引用本包任何原文时，请通过对应编号回溯 ctext.org 或维基文库复核。

1. **先分层**：史书叙述、论辩文学、编纂立场，三者不可混用。
2. **再看异文**：凡两源有出入处，均以异文编号（Y-SHY-01 至 Y-SHY-09）并列呈现，不作隐性裁断。
