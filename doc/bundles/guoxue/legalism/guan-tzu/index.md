# 管子（Guanzi）

《管子》托名春秋管仲，实为战国至秦汉间陆续写成、经西汉刘向校定的齐国稷下学派文献总集。今本 86 篇目、实存 76 篇，分《经言》《外言》《内言》《短语》《区言》《杂篇》《管子解》《轻重》八类，兼具法家、道家、儒家、名家、阴阳家、农家、兵家学说成分，以"仓廪实—知礼节"的经济伦理命题与《轻重》诸篇的国家经济调控术著称于先秦诸子。
