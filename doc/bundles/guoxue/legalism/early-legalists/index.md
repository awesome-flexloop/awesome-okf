# 早期法家辑佚（Early Legalists）

本知识包聚焦韩非集大成之前的早期法家文献世界：李悝著《法经》（《晋书·刑法志》，F-EL-028）开其端，申不害主"术"、慎到主"势"、商鞅主"法"分立其脉，至韩非"皆帝王之具也"（F-EL-008）总汇其流。与《商君书》《韩非子》均有传世完本不同，早期法家的两大文献《申子》《慎子》均已严重散佚，本包以辑佚文献为核心对象，故名"早期法家辑佚"。

## 文献散佚概况

### 《申子》：二篇—六篇—一篇的递减链

- 《史记·老子韩非列传》记申不害"著书二篇，号曰申子"（F-EL-003）。
- 《汉书·艺文志》著录《申子》六篇（F-EL-001、F-EL-005）。
- 《隋书·经籍志》已不著录，原书大部散佚（F-EL-005）。
- 今存《大体》一篇，经《群书治要》卷三十六引《申子·大体》保存（F-EL-009），另存严可均《全上古三代文》卷四所辑零散佚文（F-EL-007）。

### 《慎子》：四十二篇—残存七篇

- 《汉书·艺文志》著录《慎子》四十二篇，注"名到，先申、韩，申、韩称之"（F-EL-001、F-EL-012）。
- 《吕氏春秋·慎势》高诱注作"法书四十一篇"，与汉志"四十二"构成异文（F-EL-024）。
- 今残存七篇：《威德》《因循》《民杂》《知忠》《德立》《君人》《君臣》，另有《逸文》辑录，通行底本为守山阁丛书本（F-EL-012，ctext 底本即此本）。

## 法家源流谱系

```
李悝（著《法经》，《晋书·刑法志》F-EL-028）
  → 申不害·主术（"申不害言术"，《韩非子·定法》F-EL-026）
  → 慎到·主势（"先申、韩，申、韩称之"，汉志 F-EL-001）
  → 商鞅·主法（"公孙鞅为法"，《韩非子·定法》F-EL-026）
  → 韩非·集大成（"此不可一无，皆帝王之具也"，F-EL-008）
```

谱系两端的文献状态恰成对照：起点李悝《李子》三十二篇（汉志法家类首列，F-EL-028）今无传本，其《法经》赖《晋书·刑法志》转述；终点韩非《韩子》五十五篇（F-EL-001）大体完存（另见本库韩非子知识包）。中间的申、慎两家则处于"残存"状态——这正是本包以辑佚方法处理的领域。
