# 商君书概念总目

《商君书》概念体系围绕"富国强兵"单极目标展开：以历史进化观破除法古心理，以农战一体确立国力来源，以壹赏壹刑壹教垄断激励渠道，以弱民强国论处理国家与社会的张力，以法治工具论落实执行保障。本分区收录五个核心概念，每个概念文档独立成篇，事实依据可回溯至信源事实登记（F-SJS 编号）。

## 概念间关系

- 历史进化观为全部体系提供正当性前提：时代已变，制度必须重构，旧礼不足法。
- 农战一体确立国家汲取的两个单一渠道（粮食与兵员），壹赏壹刑壹教将全部激励与惩罚对准这两个渠道。
- 弱民强国论处理农战体系的社会代价：民强（有独立资源与组织能力）则脱离国家渠道，民弱则只能循农战之途求利。
- 法治工具论回答执行问题：国皆有法而无使法必行之法，故须以刑去刑、以赏禁赏。
