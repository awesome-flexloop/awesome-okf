# awesome-deepseek-agent

**awesome-deepseek-agent** 是 DeepSeek 官方维护的精选资源列表，收录了将 DeepSeek 大语言模型（DeepSeek-V4-Pro、DeepSeek-V4-Flash 等）集成到 22 个主流 AI Agent 和编程助手工具的完整接入指南。每份指南包含安装、配置、首次运行步骤，几分钟即可在你喜爱的工具中用上 DeepSeek。

- **类型**：文档型资源合集（Awesome List），非代码库
- **语言**：中英文双语
- **工具数量**：22 个
- **适用模型**：DeepSeek-V4-Pro、DeepSeek-V4-Flash

## 收录工具概览

### IDE 插件（3 个）
- **Cline** — VS Code 自主编程 Agent
- **GitHub Copilot** — VS Code/JetBrains AI 结对编程
- **Kilo Code** — CLI+编辑器双模式编程助手

### 终端 CLI 工具（12 个）
- Claude Code、Codex、Crush、Deep Code、DeepSeek-TUI、GitHub Copilot CLI、Langcli、OpenCode、Pi、Qwen Code、Reasonix、Oh My Pi

### 桌面/聊天客户端（2 个）
- **Cherry Studio** — 开源跨平台桌面 AI 客户端（300+助手、MCP、知识库）
- **WorkBuddy/CodeBuddy** — OpenAI 兼容配置客户端

### AI Agent 框架与平台（5 个）
- **AstrBot** — 多平台聊天 Agent（QQ/微信/飞书）
- **Hermes** — Nous Research 自我进化 Agent
- **LobeHub** — Agent 团队运营平台
- **nanobot** — 轻量 AI 智能体
- **OpenClaw** — 飞书/微信个人助手

## 快速开始

1. 访问 [DeepSeek 开放平台](https://platform.deepseek.com/) 注册并获取 API Key
2. 从下方列表选择你使用的工具
3. 按对应指南配置 API endpoint（`https://api.deepseek.com`）和 API Key
