# 03 用途与展望

> Tushare + AI 办公平台的金融数据查询场景、用例示例与未来展望。

> ⚠️ 本文档中的用例描述基于博文声称的集成状态。由于核心声明（官方预置连接器）未获 P0 核验证实，以下用例代表的是"如果集成完成后可实现的场景"或"通过手动 MCP 配置可实现的场景"，而非已验证的开箱即用体验。

## 核心理念

博文提出的核心价值主张（F-020📝）：

> 有了 AI 办公平台，我们不再需要编程就可以调取 Tushare 数据进行分析，只要会问问题、会调试问题，就可以得到想要的结果。

这代表了金融数据消费的一种范式转变：

```
传统方式：Python编程 → Tushare SDK → Pandas处理 → 可视化
AI方式：自然语言提问 → AI调用MCP → 自动分析 → 图文报告
```

## 用例示例

博文给出的查询示例（F-021, F-022）：

### 示例1：板块资金流向

> "获取近5日涨幅最大的板块并分析资金流向"

预期效果：AI 调用 Tushare 数据接口，返回图文并茂的报告，包含板块涨幅排名和资金流向分析。

### 示例2：指数走势对比

> "上证指数、沪深300今年以来的走势对比"

预期效果：获取两个指数的日线数据，生成走势对比图表。

### 示例3：个股行情

> "贵州茅台最近20个交易日的日线行情"

预期效果：返回贵州茅台（600519.SH）最近20日的 OHLCV 数据。

### 示例4：龙虎榜

> "今天龙虎榜有哪些机构席位买入"

预期效果：返回当日龙虎榜数据，筛选机构席位买入记录。

### 示例5：融资融券

> "两融余额变化、融资净买入行业分布"

预期效果：返回两融市场总量数据和行业分布。

### 示例6：涨停板

> "今日涨停板名单、连板高度"

预期效果：返回当日涨停股票列表和连板天数统计。

## 数据可行性分析

上述用例在 Tushare 数据层面**均可行**（F-022✅）：

| 用例 | Tushare 接口 | 积分要求 |
|------|-------------|----------|
| 板块涨幅 | `moneyflow_ind` 等 | 较高（2000+） |
| 指数走势 | `index_daily` | 基础（120+） |
| 个股行情 | `daily` | 基础（120+） |
| 龙虎榜 | `top_list` / `top_inst` | 中等 |
| 两融数据 | `margin` / `margin_detail` | 中等 |
| 涨停板 | `limit_list_d` | 较高 |

> 注意：部分高级接口（如资金流）需 2000+ 积分，免费用户可能无法访问全部数据。

## 趋势判断

### AI + 金融数据的三个层次

1. **数据接口层**（当前）：Tushare 提供 Python SDK / MCP / Skill 三种接入方式
2. **AI 编排层**（发展中）：AI 办公平台通过自然语言编排数据查询
3. **智能分析层**（未来）：AI 自动完成数据获取→分析→报告→决策建议

### MCP 在金融数据领域的意义

Tushare 提供 MCP Server 的意义在于：
- 标准化：任何支持 MCP 的 AI 工具都可接入
- 低代码：自然语言替代 Python 编程
- 可组合：金融数据可与其他 MCP 工具（搜索、绘图、文档）组合使用

但"官方预置"与"手动配置"的用户体验差距巨大——前者是开箱即用，后者需要技术能力。博文声称的"官方预置"若属实，将显著降低使用门槛。
