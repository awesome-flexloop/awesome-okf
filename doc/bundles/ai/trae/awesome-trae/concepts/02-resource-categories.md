# 资源分类体系详解

awesome-trae 将 TRAE 生态资源分为 8 个一级分类，每个分类下设有 3-4 个子类，形成结构化的资源导航体系。

## 一、Official Resources（官方资源）

收录 TRAE 官方维护的核心入口：

| 资源 | 链接 | 说明 |
|------|------|------|
| TRAE 官网 | trae.ai | 产品主页 |
| 官方文档 | docs.trae.ai | 使用文档和 API 参考 |
| TRAE Blog | trae.ai/blog | 官方博客和更新公告 |
| TRAE Discord | discord.gg/trae | 官方 Discord 社区 |

官方资源分类不接受社区 PR 提交，由维护者直接管理。

## 二、Projects & Demos（项目与演示）

基于 TRAE 构建的实际项目，分 4 个子类：

- **Web Applications**：Web 应用和网站项目
- **Tools & Utilities**：实用工具和效率应用
- **Games & Interactive**：游戏和交互式体验
- **AI Applications**：AI 驱动的应用程序

> ⚠️ **事实记录**：当前所有子类条目均为占位示例，等待社区贡献。更丰富的项目展示请参见 [trae-demos](../../trae-demos/index.md) 仓库。

## 三、Custom Agents（自定义智能体）

TRAE 自定义 Agent 配置，分 4 个子类：

- **Code Generation**：代码生成类 Agent
- **Documentation Assistants**：文档辅助类 Agent
- **Testing Helpers**：测试辅助类 Agent
- **Workflow Agents**：工作流自动化 Agent

> ⚠️ **事实记录**：当前所有子类条目均为占位示例。完整的 Agent 配置集合请参见 [trae-agents](../../trae-agents/index.md) 仓库。

## 四、Tools & Extensions（工具与扩展）

TRAE 相关工具和 IDE 扩展，分 4 个子类：

- **IDE Extensions**：IDE 插件和扩展
- **Productivity Tools**：生产力工具
- **Integration Plugins**：第三方服务集成插件
- **Development Utilities**：开发辅助工具

> ⚠️ **事实记录**：当前所有子类条目均为占位示例。

## 五、Tutorials & Guides（教程与指南）

学习 TRAE 的教程和指南，分 4 个子类：

- **Getting Started**：入门教程和快速上手指南
- **Advanced Tutorials**：进阶教程和深度指南
- **Best Practices**：最佳实践和经验总结
- **Tips & Tricks**：技巧和窍门

> ⚠️ **事实记录**：当前所有子类链接均为占位 URL。

## 六、Templates & Boilerplates（模板与脚手架）

项目模板和启动脚手架，分 3 个子类：

- **Web App Starters**：Web 应用启动模板
- **API Templates**：API 项目模板
- **Configuration Files**：配置文件模板

> ⚠️ **事实记录**：当前所有子类条目均为占位示例。

## 七、Learning Resources（学习资源）

TRAE 相关的学习资料，分 4 个子类：

- **Video Courses**：视频教程和课程
- **Documentation Hubs**：文档中心和知识库
- **Books & E-books**：书籍和电子书
- **Podcasts & Interviews**：播客和访谈

> ⚠️ **事实记录**：当前所有子类条目均为占位示例。

## 八、Community（社区）

TRAE 社区入口：

| 社区 | 链接 | 说明 |
|------|------|------|
| TRAE Discord | discord.gg/trae | 实时聊天社区 |
| GitHub Discussions | 本仓库 Discussions | 异步讨论论坛 |
| Reddit r/trae | reddit.com/r/trae | Reddit 子版块（标注"if available"） |
| Twitter @trae | @trae | 官方社交媒体 |

## 分类设计逻辑

8 大分类按照用户从"接触 TRAE"到"深度使用"的路径排列：

1. 先看 **Official Resources** 了解产品
2. 再看 **Projects & Demos** 了解能做什么
3. 然后通过 **Agents/Tools** 增强能力
4. 借助 **Tutorials/Templates/Learning** 学习使用
5. 最后进入 **Community** 参与交流
