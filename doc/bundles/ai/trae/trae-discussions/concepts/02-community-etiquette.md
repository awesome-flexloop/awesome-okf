# 社区礼仪与有效提问指南

## 4 条社区行为准则

trae-discussions 定义了 4 条核心社区指南，所有参与者都应遵守：

### 1. Be Respectful（尊重他人）

社区是多元化的，参与者技术水平、背景和观点各不相同：

- **欢迎新人**：对新手友好，耐心回答基础问题，不嘲讽"这都不会"
- **建设性反馈**：批评应对事不对人，提供改进建议而非单纯否定
- **无攻击言论**：禁止人身攻击、歧视性语言、恶意挑衅
- **友善待人**：记住屏幕另一边也是真实的人

### 2. Stay On Topic（保持主题）

- **使用适当分类**：发帖时选择最匹配的分类（参见[讨论分类与使用指南](01-discussion-categories.md)）
- **讨论相关内容**：帖子内容与分类主题一致，不在 Q&A 下发无关广告
- **链接相关讨论**：如果已有类似讨论，在帖子中链接引用而非重复开帖
- **避免劫持话题**：不在他人帖子下讨论无关的子话题，开新帖讨论

### 3. Search First（先搜索）

- **发帖前搜索**：使用 Discussions 搜索功能检查是否已有相同问题或讨论
- **避免重复**：相同问题不重复发帖，可以在已有帖子下追加信息
- **引用现有帖子**：如果发现相关讨论，在你的帖子中链接到它们
- **查看置顶帖**：发新帖前先看是否有公告或置顶帖包含答案

### 4. Quality Content（质量内容）

- **清晰标题**：标题简明扼要地描述问题或主题
- **提供背景**：说明你的使用场景、尝试过什么、期望什么结果
- **正确格式**：代码使用代码块、列表使用列表格式、善用分段
- **信息完整**：提问时提供足够信息，避免"有人知道吗？"这类无信息含量的帖子

## 中英文双语规范

TRAE 社区是国际化社区：

- **可以使用中文或英文发帖**：没有强制语言要求
- **标题语言与内容一致**：用中文写标题就用中文写内容
- **中英文帖子都受欢迎**：社区维护者和成员会尽力用你使用的语言回应
- **行为准则文件双语提供**：CODE_OF_CONDUCT.md（英文）和 CODE_OF_CONDUCT.zh-CN.md（中文）

## 有效提问指南

在 Q&A 分类提问时，遵循以下模板提高获得高质量回答的概率：

### 提问模板结构

```
**标题**：[问题简述] （如："如何在 TRAE 中配置自定义 MCP 服务器？"）

**环境信息**：
- TRAE 版本：xxx
- 操作系统：Windows 11 / macOS 14 / Ubuntu 22.04
- 相关配置：（如涉及 MCP/Agent 配置）

**问题描述**：
清晰描述你遇到的问题，包括：
- 你想做什么？
- 实际发生了什么？
- 你期望发生什么？

**复现步骤**：
1. 第一步...
2. 第二步...
3. 出现错误/问题

**已尝试的解决方案**：
- 尝试了什么？结果如何？
- 搜索过哪些关键词？找到了什么？

**截图/错误信息**：
（粘贴相关截图或完整错误信息）
```

### 提问 Do's 和 Don'ts

| ✅ 应该做 | ❌ 不应该做 |
|----------|------------|
| 标题简洁描述问题 | 标题写"求助"、"急"、"有人吗" |
| 提供环境信息 | 只说"用不了"、"报错了" |
| 描述复现步骤 | 让别人猜你做了什么 |
| 说明已尝试的方案 | 完全没搜索就提问 |
| 粘贴完整错误信息 | 只说"报错了"不贴错误内容 |
| 一个帖子问一个问题 | 一个帖子问 N 个不相关问题 |

## 知识分享指南

在 Knowledge Sharing 分类分享内容时：

- **提供具体步骤或代码**：让读者可以复现
- **说明背景和场景**：这个技巧/经验在什么情况下适用
- **分步骤讲解**：长内容分步骤、加小标题
- **欢迎讨论**：分享帖也欢迎提问和补充

## 协作配对指南

在 Collaboration 分类寻找合作者时：

- **说明项目是什么**：清晰描述项目目标和当前进度
- **说明需要什么**：前端/后端/设计/文档？什么技能水平？
- **说明时间投入**：是业余项目还是全职投入？预计多长时间？
- **说明联系方式**：如何联系你进一步讨论
