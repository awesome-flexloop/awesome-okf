## 讨论平台定位

- F-005: 项目定位为"参考点"（reference point），功能是引导社区成员到合适的讨论平台，本身不承载讨论内容。来源：README.md
- F-006: 指定 GitHub Discussions 为唯一社区互动平台，主入口链接为 `https://github.com/orgs/trae-community/discussions`（组织级 Discussions）。来源：README.md

## 讨论分类

- F-007: 定义 5 个讨论分类：📚 General（欢迎介绍/社区公告/离题对话）、💡 Ideas & Suggestions（功能请求/改进建议/社区倡议）、❓ Q&A（帮助支持/操作问题/故障排除）、📖 Knowledge Sharing（最佳实践/案例研究/提示技巧）、🤝 Collaboration（项目配对/寻找贡献者/团队组建）。来源：README.md

## 参与指南与行为规范

- F-008: 参与步骤为 4 步：访问 GitHub Discussions → 点击顶部 "Discussions" → 浏览或创建新讨论 → 评论/反应/贡献。来源：README.md
- F-009: 社区指南 4 条：Be Respectful（尊重他人/欢迎新人/建设性反馈）、Stay On Topic（相关讨论/使用适当分类/链接相关讨论）、Search First（发帖前搜索/避免重复/引用现有帖子）、Quality Content（清晰标题/提供背景/正确格式）。来源：README.md
