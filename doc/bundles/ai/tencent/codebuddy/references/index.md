## 信源使用说明

- **IDE 官网**（ide.md）：记录产品定位、全流程链路、平台支持与架构基础。
- **IDE 文档**（docs-intro.md）：记录三种形态、四阶段流程、内置生态、插件兼容矩阵与高级功能清单。
- **CLI 官网**（cli.md）：记录终端工具的安装要求、代码感知、MCP、分层记忆与 Sub-agents。
- **NPC 官网**（npc.md）：记录云端 AI 员工的目标驱动、自主上下文、全流程 PR 与协同能力。
- **WorkBuddy 官网**（workbuddy.md）：记录在线助手的办公与开发两大场景、对话交互与产物面板。
- **Security 官网**（security.md）：记录六步安全闭环、对抗性审查、PoC 验证与 CVE 战绩。
