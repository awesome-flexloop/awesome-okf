## 设计定位

基础篇是 Vibe Vibe 四大板块的入口，面向完全零基础学习者。`docs/Basic/index.md` 开宗明义：

> "这套基础篇已经按新版主线完成重写：围绕'个人主页 + 数字分身'这一个连续案例，带你从第一次生成，到本地修改、界面优化、内容补全、数字分身校准，再到正式上线。"

它明确声明自己**不是传统教材**：

> "这不是一本'先学语法、再学框架、最后再做项目'的传统教材。它更像一条可以直接走通的路线。"

基础篇默认读者是**独立 vibe coder**——不假设身边有前端、后端、测试同事，学习者需要自己承担需求描述、结果审查、方向决策三重角色。

## 主线案例：个人主页 + 数字分身

基础篇 v2 用一个连续案例贯穿全程，而非每章换一个独立示例：

| 部分 | 负责什么 | 为什么适合基础版 |
|------|---------|----------------|
| 个人主页 | 展示你是谁、做过什么、别人如何联系你 | 结果直观，容易建立成就感 |
| 数字分身 | 代替你回答别人最常问的问题 | 天然适合引入 AI，对话结果容易验证 |
| 正式发布 | 把作品变成稳定链接分享给别人 | 完成第一次"从想法到上线"的闭环 |

这个案例选择体现了 Vibe Coding 的教学逻辑：结果可见（网页能打开）、反馈即时（数字分身能对话）、门槛低（个人主页不需要复杂业务逻辑）、但又完整覆盖了从生成到部署的全流程。

## 七个交付里程碑

基础篇 v2 按 7 个章节（编号 0-6）组织，每章明确"解决什么问题"和"核心交付"：

| 章节 | 目录 | 解决的问题 | 核心交付 |
|------|------|-----------|---------|
| 第 0 章：开始前 | `00-preface/` | 知道自己要学什么、怎么学、卡住怎么办 | 一张清晰的学习地图 |
| 第 1 章：第一个版本 | `01-awakening/` | 先做出第一个能预览、能聊天的版本 | v1 原型 |
| 第 2 章：带回工作台 | `02-mindset/` | 把项目带回本地，获得长期掌控力 | 本地可运行、可修改的项目 |
| 第 3 章：第一印象 | `03-technique/` | 让首页更像作品而不是默认模板 | 视觉统一的首页 |
| 第 4 章：内容完整 | `04-practice-0-to-1/` | 让内容更完整，也让代码更可回退 | 更完整的主页 + 最小 Git 闭环 |
| 第 5 章：数字分身 | `05-advanced/` | 让数字分身更像你，学会基础排错 | 更稳定、更像你的数字分身 |
| 第 6 章：正式上线 | `06-launch/` | 把作品正式上线并收集真实反馈 | 公网可访问的稳定链接 |

每章目录下含一个 `index.md`（章节首页）和若干编号小节文件，例如第 1 章含 `1.1-coder-to-commander.md`（从码农到指挥官）、`1.2-breaking-myths.md`（破除迷信）、`1.3-tools-guide.md`（工具选型）、`1.4-vibe-vs-spec.md`（Vibe Coding 与 Spec Coding）。

## 教学设计原则

基础篇在 `docs/Basic/index.md` 中给出了四条推荐学习方式：

1. **先动手，再回看**：容易焦虑的话，先做出东西会更有信心
2. **每章都要亲手操作**：这不是只靠阅读就能掌握的教程
3. **遇到问题先问 AI**：不要求学习者先自己硬扛半小时
4. **不用一次看完附录**：附录是"遇到再查"，不是"提前全背"

这些原则体现了 Vibe Coding 教学法的核心：**做中学**（learning by making），而非**学完再做**（learn then make）。知识点被打散到对应里程碑中，在"需要时"才出现。

## 与旧版结构的对比

仓库保留了 `docs/Basic-old/` 目录，记录了基础篇重构前的结构。新旧对比如下：

| 维度 | 旧版（Basic-old） | 新版（Basic v2） |
|------|-------------------|-----------------|
| 组织方式 | 按知识点分章（觉醒/心法/技法/实战/精进） | 按交付里程碑组织（7 章） |
| 案例 | 多个分散示例（背单词软件等） | 单一连续案例（个人主页+数字分身） |
| 章节数 | 5 章 + 大量子节 + 附录 | 7 章（0-6）+ 附录 + 结语 + 预告 |
| 子目录深度 | 深（如 `02-mindset/2.5-soul-questions/2.5.4-why-you.md`） | 浅（如 `02-mindset/2.1-thinking-upgrade.md`） |
| 附录 | A-E 共 5 个（Prompt 速查、错误表、术语表、工具对比、idea 清单） | 保留附录但精简 |

旧版第 2 章"心法"有 8 个子节加 appendix，新版精简为 4 个文件（2.1-2.4）。这反映了从"知识全面覆盖"到"最小可行路径"的教学思路转变。

## 基础篇技术栈

基础篇不要求学习者预先掌握任何技术栈，而是在做项目的过程中接触：

- **前端基础**：HTML/CSS/JavaScript（在第 1 章生成原型时自然接触）
- **AI 工具**：ChatGPT/Claude/Cursor 等（第 1 章工具选型）
- **Git 版本控制**：最小 Git 闭环（第 4 章）
- **静态部署**：把网页发到互联网（第 6 章）
- **安全意识**：API Key 管理、代码风险（第 5 章）

进阶篇才引入完整的现代全栈技术栈（Next.js 16 + React + TypeScript + Tailwind + shadcn/ui + Drizzle + PostgreSQL）。

## 入口指引

`docs/Basic/index.md` 为不同状态的学习者提供两个入口：

- **想先搞清楚自己是否适合这条路线**：从[第 0 章：开始前](/Basic/00-preface/)开始
- **已经迫不及待想做出第一个版本**：看完第 0 章后直接进入[第 1 章：第一个版本](/Basic/01-awakening/)
