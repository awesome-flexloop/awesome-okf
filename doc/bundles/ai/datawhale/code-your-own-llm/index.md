# Code Your Own LLM

**动手训练你自己的大语言模型**

Code Your Own LLM 是 Datawhale 出品的全栈式大语言模型参考指南，基于 Andrej Karpathy 的 [nanochat](https://github.com/karpathy/nanochat) 深度扩展。项目以最简洁的代码、扁平化结构和极简依赖，帮助学习者端到端理解大语言模型从原理到工程的每一个细节。

> ⚠️ 项目当前处于 **Alpha 内测版**，部分章节在建中，内容可能存在错误。

## 快速上手

1. 访问 [在线阅读地址](https://datawhalechina.github.io/code-your-own-llm/) 开始学习
2. 从已完成的章节入手：引言、环境配置、数据、模型架构、有监督微调、强化学习
3. 准备 Python 3.10+ 环境
4. 阅读 AGENTS.md（第零章）了解文档规范

## 项目特点

- **全栈覆盖**：从数据采集到红队测试，12 章覆盖 LLM 完整生命周期
- **代码极简**：无复杂封装、零层级嵌套，每行代码都可追溯原理
- **五维诠释**：原理解读、工程实现、实践指导、优化分析、可视化展示
- **规范严格**：出版级 Markdown 写作规范，Google Python Style Guide 代码风格
