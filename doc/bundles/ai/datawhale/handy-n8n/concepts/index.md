# 核心概念

本目录包含 handy-n8n 教程的 5 个核心概念，按学习路径排列：从入门定位到工作流设计，从数据处理到 AI 集成，再到高级实战。

## 入门与基础

* [n8n 入门与核心概念](getting-started.md) — n8n 定义（nodemation）、四大特点、与 dify/coze 定位对比、四种部署方式、平台界面与数据结构。对应 C01-C02 及 C03 平台介绍。
* [工作流设计](workflow-design.md) — 触发器节点（Manual/Schedule/Webhook/Chat）、核心节点（数据处理/控制流/HTTP）、工作流导入执行、节点连接与分支。对应 C03。

## 数据与代码

* [数据处理与转换](data-processing.md) — 对象数组数据结构（json/binary）、Expressions 表达式、Code 节点（JS/Python）、内置变量与外部库、数据拆分合并。对应 C03。

## AI 与扩展

* [AI 与 API 集成](ai-api-integration.md) — 集群节点（Chain/Agent）、Memory 记忆、RAG 向量检索、Tools 工具、MCP 协议、HTTP Request 通用连接。对应 C04。
* [高级实战](advanced-practice.md) — 子工作流、Error Trigger 错误处理、社区节点、TypeScript 自定义节点开发、GitHub 实战案例。对应 C04-C06。
