# 根 README.md 引用

Deep Agents 项目的产品级入口文档。

## 核心内容

- **项目定位**："batteries-included agent harness"——开箱即用的有主见的 Agent 框架
- **四大原则**：Opinionated、Extensible、Model-agnostic、Production-ready
- **核心特性**：子 Agent、文件系统、上下文管理、Shell 访问、持久化记忆、人在回路、技能、工具/MCP
- **快速开始**：`uv add deepagents`，使用 `create_deep_agent()` 构建 Agent
- **FAQ**：与 LangGraph/LangChain 的区别（三层栈）、开放权重/本地模型支持、生产可用性、选型指南
- **生态资源**：示例、文档、API 参考、社区论坛、LangChain Academy
- **安全模型**："trust the LLM"，在工具/沙箱层面强制边界
- **致谢**：灵感来自 Claude Code
