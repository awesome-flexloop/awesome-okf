# 🔬 自然科学

本域存放自然科学基础学科的经典著作知识包，采用"经典原文选读 + 现代科学解读"的教程范式：精选公共领域原著的关键段落，辅以逐段注释、自撰今译与现代科学视角的对照解读，并为零基础读者规划阅读路径。

与 [💭 思想与理论](../think/index.md) 域侧重哲学思想不同，本域面向实证自然科学元典，关注概念、实验与理论如何在历史中演进。
