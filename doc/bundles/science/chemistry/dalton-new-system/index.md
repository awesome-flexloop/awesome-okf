# 道尔顿《化学哲学新体系》阅读教程

本知识包（bundle）是约翰·道尔顿（John Dalton, 1766–1844）《化学哲学新体系》（*A New System of Chemical Philosophy*，1808–1827）的阅读指南，面向具备中学化学基础、希望回到近代化学起点阅读原典的读者。内容侧重"怎么读"：如何从气体研究的问题链进入原子论，如何读 1808 年的原子量表与化合规则，如何看待道尔顿的著名错误（水作 HO、氧原子量定为 7），以及原子如何从"有用的假说"变成"被证实的实在"。

本束在化学史序列中承上启下：上承[拉瓦锡《化学基础论》阅读教程](../lavoisier-treatise/index.md)的元素分析与定量化学传统，下启[门捷列夫周期律阅读教程](../mendeleev-periodic-law/index.md)以原子量排序元素的体系化工作。

## 🚀 快速开始

如果你只读过中学化学、从未接触科学原典：

1. 先读[为什么读《化学哲学新体系》](concepts/00-why-read.md)，明确阅读目标
2. 顺着[从气体研究到原子论](concepts/01-from-gases-to-atoms.md)走完"气象观测→分压→溶解度→原子重量"的问题链
3. 打开[核心段落选读](concepts/04-key-passages.md)，对照今译读 3–4 段原文
4. 最后读[影响、证实与遗产](concepts/05-legacy.md)，看原子论如何在百年后被实验证实

如果你已具备大学普通化学基础：

1. 直读[原子量与最大简单性规则](concepts/03-atomic-weights.md)，重点看道尔顿如何在没有分子式证据时"补全"数据
2. 跟着[倍比定律段落逐句精读](examples/01-multiple-proportions-reading.md)用现代原子量复算 1808 年表格
3. 读[影响、证实与遗产](concepts/05-legacy.md)中盖-吕萨克、阿伏伽德罗与道尔顿的三方分歧
4. 按[原典阅读路线](examples/02-reading-route.md)进入 Internet Archive 上的原书扫描本

> 阅读经典文本的通用方法论（版本选择、短引规范、今译与注释的配合），可参照[帛书《老子》阅读教程](../../../think/laozi/boshu-reading/index.md)的读法框架。

## 🎯 Bundle 定位

| 维度 | 拉瓦锡《化学基础论》（前驱束） | 道尔顿《新体系》（本束） | 门捷列夫周期律（后继束） |
|------|------------------------------|------------------------|------------------------|
| 核心问题 | 什么是元素？燃烧中质量如何守恒？ | 元素由什么构成？原子能否称量？ | 元素之间有无体系性关系？ |
| 关键工具 | 天平、定量分析、元素表（33 种） | 相对原子量表、化合规则、倍比定律 | 按原子量排序的周期表 |
| 历史位置 | 近代化学的"独立宣言"（1789） | 近代原子论的定量奠基（1808） | 原子量体系化的完成（1869） |
| 适合读法 | 看概念框架如何替换燃素说 | 看假说与数据如何互相牵引 | 看分类法如何预测未知元素 |

三个束通过正文互链串联，建议按"拉瓦锡→道尔顿→门捷列夫"的顺序阅读。
