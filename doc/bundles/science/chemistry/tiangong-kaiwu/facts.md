## 作者与成书

| 编号 | 事实内容 |
|------|---------|
| F-001 | 《天工开物》作者宋应星，字长庚，江西奉新人，生于明万历十五年（1587），卒年无确考，约在清初康熙初年[^1]。 |
| F-002 | 宋应星于万历四十三年（1615）江西乡试中举，名列第三；此后多次赴京会试未中，转而讲求经世实学[^1]。 |
| F-003 | 宋应星于崇祯七年（1634）任江西分宜县教谕，《天工开物》在分宜教谕任内写成[^1]。 |
| F-004 | 《天工开物》初刊于明崇祯十年（1637），由友人涂绍煃（字伯聚）捐资刊刻，该本世称"涂本"[^1]。 |
| F-005 | 宋应星后任福建汀州府推官、南直隶亳州知州；入清后不仕，为明遗民[^1]。 |
| F-006 | 书名"天工"取自《尚书》"天工人其代之"，"开物"取自《周易·系辞》"开物成务"，合指人代天工、开发万物[^2]。 |
| F-007 | 全书十八卷，分上、中、下三部：上卷六、中卷七、下卷五；正文约五万余字，初刻本附插图一百二十余幅（常作 123 幅）[^2]。 |
| F-008 | 十八卷依次为：乃粒、乃服、彰施、粹精、作咸、甘嗜、陶埏、冶铸、舟车、锤锻、燔石、膏液、杀青、五金、佳兵、丹青、曲糵、珠玉[^2]。 |
| F-009 | 全书以农食民生之卷《乃粒》开篇、以珍宝之卷《珠玉》殿后，编排上体现"贵五谷而贱金玉"的取向[^2]。 |
| F-010 | 与化学工艺关系较密的卷篇有《作咸》《陶埏》《冶铸》《锤锻》《燔石》《五金》《丹青》《佳兵》等[^3]。 |

## 版本流传与海外影响

| 编号 | 事实内容 |
|------|---------|
| F-011 | 《天工开物》在清代未收入《四库全书》，国内传本稀少，清代中后期几近绝迹[^1]。 |
| F-012 | 本书在日本江户时代流传并被翻刻、研究；1771 年日本大阪菅生堂刊行和刻本，世称"菅本"[^1]。 |
| F-013 | 20 世纪初，丁文江、陶湘等学者据日本流传本整理回流；1929 年陶湘涉园刊本（"陶本"）行世，本书在国内重新通行[^1]。 |
| F-014 | 现代通行整理与译注本有钟广言《天工开物译注》（广东人民出版社）、潘吉星《天工开物校注及研究》（巴蜀书社）等[^4]。 |
| F-015 | 19 世纪法国汉学家儒莲（Stanislas Julien）曾节译本书部分内容介绍至欧洲[^2]。 |
| F-016 | 英国李约瑟（Joseph Needham）《中国科学技术史》（Science and Civilisation in China）多处引用本书；本书常被称为"中国 17 世纪的工艺百科全书"[^2]。 |

## 《五金》卷与金属冶炼

| 编号 | 事实内容 |
|------|---------|
| F-017 | 《五金》卷记述金、银、铜、铁、锡等金属的开采与冶炼，并在"附：倭铅"条专记金属锌的冶炼[^5]。 |
| F-018 | "倭铅"为明代对金属锌的称呼；《五金》载其原料为炉甘石（菱锌矿，主要成分为碳酸锌 ZnCO₃），产地以山西太行山一带为盛，荆州、衡州次之[^5]。 |
| F-019 | 《五金·倭铅》记炼锌工序：炉甘石十斤装入泥罐，泥封后渐次砑干、勿使见火拆裂，逐层以煤炭饼垫盛，罐底铺薪发火煅红，冷定后毁罐取出，"每十耗去其二，即倭铅也"[^5]。 |
| F-020 | 《五金·倭铅》载倭铅"无铜收伏，入火即成烟飞去"，并释名曰"以其似铅而性猛，故名之曰倭"，描述了锌高温易挥发的性质[^5]。 |
| F-021 | 《五金》记黄铜冶炼：先世以炉甘石点化红铜，"后人因炉甘石烟洪飞损，改用倭铅"；"每红铜六斤，入倭铅四斤，先后入罐熔化，冷定取出，即成黄铜"[^6]。 |
| F-022 | 《冶铸·钱》记铸钱铜料配比："每十斤，红铜居六七，倭铅（京中名水锡）居三四，此等分大略"，并记"倭铅每见烈火必耗四分之一"[^7]。 |
| F-023 | 《五金》《锤锻》记铁分生铁、熟铁："出炉未炒则生，既炒则熟"，"生熟相和，炼成则钢"，以含碳高低与生熟搭配区分生铁、熟铁与钢[^3]。 |
| F-024 | 《五金·黄金》记黄金成色的比色鉴别："其高下色，分七青、八黄、九紫、十赤，登试金石上，立见分明"[^5]。 |
| F-025 | 《五金·黄金》记黄金延展性，打金箔"每金七厘造方寸金一千片"；又以同体积铜、银、金的增重关系比较，给出比重经验数据[^5]。 |

## 《丹青》卷：朱砂、水银与墨

| 编号 | 事实内容 |
|------|---------|
| F-026 | 《丹青》卷分"朱""墨"两部；"朱"条开篇即言"凡朱砂、水银、银朱，原同一物"，以精粗老嫩分别名目[^8]。 |
| F-027 | 《丹青·朱》记升炼水银：次朱砂水和搓成条装入釜中，上盖一釜、釜旁以盐泥固济，以铁制曲溜管将釜中气体导入盛水罐中冷凝，"共煅五个时辰，其中砂末尽化成汞"[^8]。 |
| F-028 | 《丹青·朱》记以水银回升银朱：水银一斤入石亭脂（硫黄所制）二斤，同研炒作青砂头，密封罐内加热；"每升水银一斤，得朱十四两、次朱三两五钱，出数藉硫质而生"（明代一斤为十六两）[^8]。 |
| F-029 | 《丹青·墨》记制墨以烧烟凝质而成，取松烟者居十分之九，取桐油、清油、猪油烟者居十分之一；贵重墨推徽郡所造[^8]。 |

## 《作咸》卷：制盐

| 编号 | 事实内容 |
|------|---------|
| F-030 | 《作咸》卷记述食盐制取，分列海盐、池盐、井盐及土盐、崖盐（岩盐）等类[^2]。 |
| F-031 | 《作咸》记四川井盐以卓筒井凿井取卤，并载利用"井火"（天然气）煎煮卤水成盐[^2]。 |

## 《燔石》卷：煤炭、石灰、矾、硫、砒

| 编号 | 事实内容 |
|------|---------|
| F-032 | 《燔石》卷记述石灰、蛎灰、煤炭、矾石、硫黄、砒石等非金属矿物的烧制与应用[^9]。 |
| F-033 | 《燔石·石灰》记"凡石灰经火焚炼为用，成质之后，入水永劫不坏"；以煤饼与石灰石层叠、铺薪灼火燔烧，成品最佳者称"矿灰"；石灰用于固舟缝、砌墙石、垩墙壁、筑三和土等[^9]。 |
| F-034 | 《燔石·煤炭》记煤分三种：明煤（大块如斗，燕、齐、秦、晋所产）、碎煤（吴、楚所产，又分火焰高的"饭炭"供炊烹、火焰平的"铁炭"供冶锻）、末煤（细如面，名"自来风"，以泥、水调成饼入炉）[^9]。 |
| F-035 | 《燔石·煤炭》记采煤安全法：初见煤层时"毒气灼人"，将凿去中节的巨竹尖端插入炭中引毒烟上透，人在其下拾取；井内支板以防压崩[^9]。 |
| F-036 | 《燔石》记矾类烧炼：白矾与皂（青）矾、红矾、黄矾、胆矾等，取煤炭外矿石（俗名"铜炭"）入炉，以煤饼包裹烧炼而得；白矾用于染色固结、造纸及药用[^9]。 |
| F-037 | 《燔石》记硫黄取自含硫石卵（气甚薰者名"臭煤"），与烧矾同炉取硫；同卷并记砒石烧炼[^9]。 |

## 现代化学对应与考古印证

| 编号 | 事实内容 |
|------|---------|
| F-038 | 现代化学对书中物质的对应：炉甘石主要成分为 ZnCO₃；朱砂、银朱为硫化汞 HgS；白矾为十二水合硫酸铝钾 KAl(SO₄)₂·12H₂O；皂矾（绿矾）为七水合硫酸亚铁 FeSO₄·7H₂O；胆矾为五水合硫酸铜 CuSO₄·5H₂O；砒霜为三氧化二砷 As₂O₃；石灰石为 CaCO₃，石灰为生石灰 CaO[^3]。 |
| F-039 | 锌的碳热还原过程：碳酸锌高温先分解为氧化锌与二氧化碳（ZnCO₃ → ZnO + CO₂），氧化锌再被碳还原（ZnO + C → Zn + CO）；氧化锌还原温度约 900℃ 以上，金属锌沸点约 907℃，两者接近，还原所得为气态锌，须设冷凝回收装置[^10]。 |
| F-040 | 重庆忠县临江二队明代炼锌遗址于 2013 年发掘，出土保存较完好的明代冶锌炉、反应罐、冷凝盖、锌锭等；冶金考古所见"密封蒸馏—冷凝收锌"工艺与《五金·倭铅》文字记载相互印证[^10]。 |
| F-041 | 学界普遍认为《天工开物》是世界上最早系统记载金属锌冶炼工艺的文献之一；欧洲大规模蒸馏炼锌一般以 18 世纪英国布里斯托尔为标志（William Champion 于 1738 年取得蒸馏炼锌专利）[^10]。 |
| F-042 | 《丹青·朱》"出数藉硫质而生"一条，记录水银加硫制银朱后产物增重、增重部分来自硫质，属于化合反应中质量增加的定量观察；按明制一斤十六两折算，一斤水银得头朱十四两、次朱三两五钱[^8]。 |
