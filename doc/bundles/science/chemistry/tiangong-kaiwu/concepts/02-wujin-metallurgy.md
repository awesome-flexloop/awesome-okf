# 《五金》卷——金属冶炼的工艺实录

> ⚠️ **安全提示**：本卷涉及铅及铅制品（卷末附胡粉、黄丹等条），铅化合物有毒；本束为文献阅读教程，**严禁模仿任何冶炼、熔炼操作**。

《五金》为下五卷之首，记述金、银、铜、铁、锡等金属的开采与冶炼，并在"附：倭铅"条专记金属锌的冶炼[^1]。在线原文见 [references/original-sources.md](../references/original-sources.md) O-07（该卷依次为黄金、银、铜、附倭铅、铁、锡、铅、胡粉、黄丹）。逐句精读演示见 [../examples/01-wujin-passage-reading.md](../examples/01-wujin-passage-reading.md)。

## 倭铅：世界上最早的锌冶炼文字记载之一

### 原料：炉甘石

"倭铅"是明代对金属锌的称呼[^2]。其冶炼原料为炉甘石——即菱锌矿，主要成分为碳酸锌 ZnCO₃，产地以山西太行山一带为盛，荆州、衡州次之[^2]。

### 工序：泥罐密封煅炼

《五金·附倭铅》所记工序为：炉甘石十斤装入泥罐，泥封后渐次砑干、勿使见火拆裂，逐层以煤炭饼垫盛，罐底铺薪发火煅红，冷定后毁罐取出，"每十耗去其二，即倭铅也"[^3]——十斤炉甘石损耗二成，剩下的就是锌。原文选读与逐句注释见 [04-key-passages.md](04-key-passages.md) 第一段。

### 物性观察：入火成烟

原文并载倭铅"无铜收伏，入火即成烟飞去"，释名则说"以其似铅而性猛，故名之曰倭"[^4]。这两句话概括了锌最要紧的工艺性质：高温下极易挥发，若不加以"收伏"就会跑光。

### 现代化学原理

用今天的化学语言还原这段工艺：

```
第一步（分解）：ZnCO₃ ──高温──▶ ZnO + CO₂↑
第二步（还原）：ZnO + C  ──高温──▶ Zn（蒸气）+ CO↑
```

工艺的关键困难在于温度窗口：氧化锌被碳还原的温度约 900℃ 以上，而金属锌的沸点约 907℃，两者非常接近——还原一发生，得到的立即是锌蒸气而不是液态锌。因此必须设置冷凝回收装置，这正是"无铜收伏，入火即成烟飞去"这句话对应的现代解释[^5]。密封的泥罐由此构成一个简易蒸馏罐：罐内上部温度相对较低，锌蒸气在此冷凝为金属锌，避免了挥发损失。

### 考古互证：忠县临江二队遗址

文字记载并非孤证。2013 年重庆忠县临江二队明代炼锌遗址经考古发掘，出土保存较完好的明代冶锌炉、反应罐、冷凝盖、锌锭等遗物；冶金考古揭示的"密封蒸馏—冷凝收锌"工艺，与《五金·附倭铅》的文字记载相互印证[^6]。三家权威媒体的独立报道（中新网/中国文化报、光明日报、人民网/重庆日报）内容一致[^7]。

### 世界地位

学界普遍认为《天工开物》是世界上最早系统记载金属锌冶炼工艺的文献之一；欧洲的大规模蒸馏炼锌一般以 18 世纪英国布里斯托尔为标志（William Champion 于 1738 年取得蒸馏炼锌专利）[^8]——比本书初刊晚了一百年。审慎起见，本束采用"世界最早记载之一"的表述（关于"最早冶锌国家"的争议见 [../references/modern-scholarship.md](../references/modern-scholarship.md) 交叉验证节）。

## 黄铜与铸钱：从"点化"到"配料"

《五金》记黄铜冶炼的演变：先世以炉甘石直接点化红铜，"后人因炉甘石烟洪飞损，改用倭铅"；配比为"每红铜六斤，入倭铅四斤，先后入罐熔化，冷定取出，即成黄铜"[^9]。

现代解读有两条线索：

1. **合金**：黄铜即铜锌合金。红铜六斤对倭铅四斤，即约 60:40 的铜锌比，落在现代工业黄铜常见的配比区间内。
2. **工艺路线的进步**：从"炉甘石点化"（矿石与铜共熔，碳酸锌分解后部分锌随烟散失，即"烟洪飞损"）改为"先炼出金属锌、再按斤两配料"，是把不确定性从反应内部移到称量台上的进步——配料化使合金成分变得可控可重复。

《冶铸·钱》条另记铸钱铜料配比："每十斤，红铜居六七，倭铅（京中名水锡）居三四，此等分大略"，并记"倭铅每见烈火必耗四分之一"[^10]——熔铸钱币时锌要烧损约四分之一，再次印证锌易挥发的物性；而原文把损耗率写得如此具体，正是经验定量意识的体现。

## 生铁、熟铁与钢

《五金》《锤锻》记铁分生铁、熟铁："出炉未炒则生，既炒则熟"，"生熟相和，炼成则钢"[^11]。现代解读：三者是同一金属按含碳量高低排列的连续谱——生铁含碳高而脆，熟铁含碳低而软；"炒"是让生铁在空气中氧化脱碳，"生熟相和"则是把不同含碳物料配合冶炼，相当于古老的碳量调控。原文没有"含碳量"概念，但用"生/熟"二字把连续谱的两端和中间态都抓住了。

## 黄金：比色与物性

- **比色鉴别**：《五金·黄金》记"其高下色，分七青、八黄、九紫、十赤，登试金石上，立见分明"[^12]——以试金石划痕的颜色判断成色，对应现代"金银铜合金中银、铜含量影响金色泽"的原理；
- **物性记录**：记黄金延展性极佳（可打金箔），又以同体积铜、银、金的增重关系比较，给出比重方面的经验数据[^13]。

## 现代解读小结

《五金》卷的物质—工艺对应（详见 [05-modern-chemistry-lens.md](05-modern-chemistry-lens.md)）：炉甘石即 ZnCO₃，倭铅即 Zn；冶炼即"分解 + 碳热还原 + 冷凝"三步。它代表本卷的价值上限：不仅记下了做什么，还记下了损耗率与物性边界，并经考古证实可信。局限同样明显：全书没有元素与成分分析的概念框架，"倭铅"之名仍停留在性状类比（详见 [03-chemical-crafts.md](03-chemical-crafts.md) 与 05 篇的对照讨论）。
