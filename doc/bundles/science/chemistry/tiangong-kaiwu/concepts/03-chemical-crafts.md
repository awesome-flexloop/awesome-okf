# 《丹青》《作咸》《燔石》——非金属工艺三卷

> ⚠️ **安全警示**：《丹青》涉及汞（水银）及其化合物，《燔石》涉及砒石（砒霜，As₂O₃）——均为剧毒物质。本束仅作文献与历史分析，**严禁模仿任何升炼、烧制、接触操作**。

《五金》之外，本束重点阅读的非金属工艺卷有三：《丹青》（颜料与墨）、《作咸》（食盐）、《燔石》（烧石成用）。三卷在线原文分别为 [references/original-sources.md](../references/original-sources.md) 的 O-08、O-03、O-06。

## 《丹青》：朱与墨

### 朱：朱砂、水银、银朱"原同一物"

《丹青》分"朱""墨"两部。"朱"条开篇即言"凡朱砂、水银、银朱，原同一物"，以精粗老嫩分别名目[^1]。用现代化学说：三者都是硫化汞（HgS）体系中的物质，天然矿石称朱砂，人工制品称银朱，单质汞（水银）则是它们的转化枢纽[^2]。

**升炼水银**：次朱砂水和搓成条装入釜中，上盖一釜、釜旁以盐泥固济，以铁制曲溜管将釜中气体导入盛水罐中冷凝，"共煅五个时辰，其中砂末尽化成汞"[^3]。这是一个完整的"加热分解—气体导出—水中冷凝"装置：朱砂（HgS）在空气中受热分解析出汞蒸气，经曲溜管导入水罐冷凝成液态汞。简化表示为：

```
HgS + O₂ ──加热──▶ Hg（蒸气）+ SO₂↑　（汞蒸气经曲溜管入水冷凝）
```

装置设计的现代要点：汞沸点约 357℃，远低于焙烧温度，汞蒸气若不导出冷凝就会全部散失——曲溜管与水罐正承担了"导出 + 冷凝"两个功能，与《五金》炼锌"收伏"锌蒸气是同一工艺思想（对照 [02-wujin-metallurgy.md](02-wujin-metallurgy.md)）。

**回升银朱**：水银一斤入石亭脂（硫黄所制）二斤，同研炒作青砂头，密封罐内加热；"每升水银一斤，得朱十四两、次朱三两五钱，出数藉硫质而生"（明代一斤为十六两）[^4]。这即是汞与硫化合为硫化汞：

```
Hg + S ──研合/微热、密封加热──▶ HgS
```

值得注意的是"出数藉硫质而生"这句定量观察：产物（十四两头朱加三两五钱次朱，合计十七两五钱）比投入的水银（十六两）重了，作者明确把增重归因于硫[^5]。这是化合反应中质量增加的一条朴素而准确的记录。原文选读见 [04-key-passages.md](04-key-passages.md) 第三段。

### 墨：松烟与油烟

《丹青·墨》记制墨以"烧烟凝质"而成：取松烟者居十分之九，取桐油、清油、猪油烟者居十分之一；贵重墨推徽郡所造[^6]。现代解读：墨的主要成分是不完全燃烧所得的碳质微粒（烟炱），松烟与油烟只是碳的不同来源与形态，"烧烟—凝聚—和胶成型"是典型的物理—化学联合工艺。

## 《作咸》：食盐

《作咸》卷记述食盐制取，分列海盐、池盐、井盐及土盐、崖盐（岩盐）等类[^7]。食盐即氯化钠，四类盐的差别不在成分，而在卤水来源与浓缩结晶方式：海盐晒或煎海水，池盐借风日蒸发湖池卤水，井盐凿井取地下卤水，崖盐则直接采咸石。

《作咸》记四川井盐以卓筒井凿井取卤，并载利用"井火"（天然气）煎煮卤水成盐[^8]——以地下自产的天然气为燃料蒸发卤水，是能源与工艺就地配套的巧妙案例，也是天然气应用于工业的早期记录。

## 《燔石》：烧石成用

《燔石》卷记述石灰、蛎灰、煤炭、矾石、硫黄、砒石等非金属矿物的烧制与应用[^9]。"燔石"二字即"烧石头"——本卷几乎全是高温化学。

### 石灰

《燔石·石灰》记"凡石灰经火焚炼为用，成质之后，入水永劫不坏"；以煤饼与石灰石层叠、铺薪灼火燔烧，成品最佳者称"矿灰"；石灰用于固舟缝、砌墙石、垩墙壁、筑三和土等[^10]。现代化学对位：石灰石（碳酸钙）高温分解为生石灰（氧化钙）并放出二氧化碳——

```
CaCO₃ ──高温──▶ CaO + CO₂↑
```

"入水永劫不坏"描述的是产物（氧化钙及其后与水反应所得的氢氧化钙、再与空气中二氧化碳回到碳酸钙）化学性质稳定的宏观经验。

### 煤炭

《燔石·煤炭》记煤分三种：明煤（大块如斗，燕、齐、秦、晋所产）、碎煤（吴、楚所产，又分火焰高的"饭炭"供炊烹、火焰平的"铁炭"供冶锻）、末煤（细如面，名"自来风"，以泥、水调成饼入炉）[^11]。

分类维度值得注意：明煤、碎煤、末煤按块度分，饭炭、铁炭却按火焰高低（对应燃烧特性与用途）分——这已是在按**用途与燃烧性能**给燃料分类，与现代按煤质（挥发分、发热特性）选煤的思路相通。

同节并记采煤安全法：初见煤层时"毒气灼人"，将凿去中节的巨竹尖端插入炭中引毒烟上透，人在其下拾取；井内支板以防压崩[^12]——竹管引流是对付井下有害气体的原始排气措施，配以支护，是成套的矿业安全经验。

### 矾类

《燔石》记矾类烧炼：白矾与皂（青）矾、红矾、黄矾、胆矾等，取煤炭外矿石（俗名"铜炭"）入炉，以煤饼包裹烧炼而得；白矾用于染色固结、造纸及药用[^13]。现代对位（见 [facts.md](../facts.md) F-038）：白矾为十二水合硫酸铝钾 KAl(SO₄)₂·12H₂O，皂矾（绿矾）为七水合硫酸亚铁 FeSO₄·7H₂O，胆矾为五水合硫酸铜 CuSO₄·5H₂O——同卷所记诸"矾"实为一族硫酸盐，由不同金属硫酸盐结晶水合物得名。

### 硫黄与砒石

《燔石》记硫黄取自含硫石卵（气甚薰者名"臭煤"），与烧矾同炉取硫；同卷并记砒石烧炼[^14]。砒石烧炼所得砒霜即三氧化二砷 As₂O₃，剧毒[^15]——再次强调：本卷一切操作仅作文本阅读，严禁模仿。

## 三卷合观

三卷合看，晚明的"经验化学"覆盖了分解（石灰、朱砂）、还原（炼锌、烧炭）、化合（银朱）、结晶（盐与矾）与燃料利用（煤、天然气）等今日化学的基本操作类型；只是这些内容分散于不同卷次、按生产部门而非学科组织（见 [insights.md](../insights.md) 洞察 3）。把分散的线索串起来的工作，见 [05-modern-chemistry-lens.md](05-modern-chemistry-lens.md)。
