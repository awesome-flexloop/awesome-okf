# 宋应星与晚明——《天工开物》的成书语境

读懂一部工艺百科，先要认识写它的人：一位在科举道路上屡屡受挫、转而把目光投向百工技艺的晚明士人。

## 生平速览

| 时间 | 事迹 |
|------|------|
| 1587 年（万历十五年） | 生于江西奉新，字长庚[^1] |
| 1615 年（万历四十三年） | 江西乡试中举，名列第三[^2] |
| 此后多次 | 赴京会试未中，转而讲求经世实学[^2] |
| 1634 年（崇祯七年） | 任江西分宜县教谕[^3] |
| 1637 年（崇祯十年） | 《天工开物》在分宜教谕任内写成并刊行[^3][^4] |
| 其后 | 任福建汀州府推官、南直隶亳州知州；入清后不仕，为明遗民[^5] |

两点阅读提示：

1. **卒年无确考**：宋应星卒年史无明文，约在清初康熙初年[^1]。百科类页面或作"约 1666 年""约 1661 年"，均为推测，本束不采用具体卒年[^6]。
2. **"举人而非进士"**：他终其一生未中进士，最高功名是乡试第三名——这恰是理解本书立场的关键：一位未能进入中央官学系统的士人，把写作重心放在了"国之生人所需"的生产知识上。

## 从科举到实学

1615 年的乡试捷报之后，是接连的会试失利[^2]。正是在这个阶段，宋应星的兴趣从制义时文转向农工技艺。晚明商品经济繁荣、手工业技术积累深厚，士人中亦有讲求实学的风气；宋应星后来在《天工开物》自序中流露的态度——重视"民用"而轻视珍玩——与这条个人轨迹一致（编排上"贵五谷而贱金玉"，见 [00-why-read.md](00-why-read.md)）[^7]。

## 分宜教谕任上成书

1634 年出任分宜县教谕，是本书的成书契机：教谕是县学的学官，事务不繁，使他有余暇整理历年见闻与调查所得，《天工开物》即在分宜教谕任内写成[^3]。

初刊于崇祯十年（1637），由友人涂绍煃（字伯聚）捐资刊刻，这个初刻本世称"涂本"[^4]。一部讲"百姓日用量产之学"的书，靠友人私人出资才得以刊行——出版史的这个细节，本身就说明了当时士林对这类知识的冷热温差。

## 书名与全书结构

- **书名**："天工"取自《尚书》"天工人其代之"，"开物"取自《周易·系辞》"开物成务"，合指人代天工、开发万物[^8]。
- **结构**：全书十八卷，分上、中、下三部（上卷六、中卷七、下卷五），正文约五万余字，初刻本附插图一百二十余幅（常作 123 幅）[^9]。
- **十八卷次第**：乃粒、乃服、彰施、粹精、作咸、甘嗜、陶埏、冶铸、舟车、锤锻、燔石、膏液、杀青、五金、佳兵、丹青、曲糵、珠玉[^10]。其中与化学工艺关系较密者为《作咸》《陶埏》《冶铸》《锤锻》《燔石》《五金》《丹青》《佳兵》等卷[^11]。

## 版本流传：从国内中绝到日本回流

这本书的传世之路颇富戏剧性，分四段：

1. **清代国内中绝**：《天工开物》未收入《四库全书》，清代国内传本稀少，中后期几近绝迹[^12]。
2. **日本流传与翻刻**：本书在江户时代日本流传并被翻刻、研究；1771 年大阪菅生堂刊行和刻本，世称"菅本"[^13]。
3. **20 世纪回流**：丁文江、陶湘等学者据日本流传本整理，1929 年陶湘涉园刊本（"陶本"）行世，本书在国内重新通行[^14]。
4. **现代整理**：通行整理与译注本有钟广言《天工开物译注》（广东人民出版社）、潘吉星《天工开物校注及研究》（巴蜀书社）等[^15]。

## 国际影响

- 19 世纪法国汉学家儒莲（Stanislas Julien）曾节译本书部分内容介绍至欧洲[^16]；
- 李约瑟《中国科学技术史》多处引用本书，本书因此常被称为"中国 17 世纪的工艺百科全书"[^17]。
