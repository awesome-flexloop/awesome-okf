# 核心段落选读——倭铅、黄铜与银朱

本篇从《天工开物》中选取三段最能代表其化学工艺价值的原文[^1]：

1. **倭铅冶炼段**（《五金·附倭铅》）——世界上最早的锌冶炼系统记载之一；
2. **黄铜配比段**（《五金》）——合金配料从矿石点化走向金属配比的转折记录；
3. **银朱定量段**（《丹青·朱》）——化合增重的朴素定量观察。

每段按"原文 → 注释 → 今译 → 现代解读"四步呈现。引文保留原文用字，每段不超过 80 字；今译均为自撰并明确标注，只用于帮助理解句意，不代替专业注译本。逐句精读的完整流程演示见 [../examples/01-wujin-passage-reading.md](../examples/01-wujin-passage-reading.md)。

> ⚠️ **安全提示**：本篇涉及锌冶炼、汞化合物与硫黄操作，古代工况无任何防护，**严禁模仿文中任何加热、煅烧、研磨操作**。

## 一、倭铅冶炼段：《五金·附倭铅》

### 原文

> 每炉甘石十斤，装载入一泥罐内，封裹泥固，以渐砑干，勿使见火拆裂。然后逐层用煤炭饼垫盛，其底铺薪，发火煅红，罐中炉甘石熔化成团。冷定毁罐取出，每十耗去其二，即倭铅也。[^2]

### 注释

- **炉甘石**：菱锌矿，主要成分为碳酸锌 ZnCO₃，炼锌原料；产地以山西太行山一带为盛，荆州、衡州次之[^3]。
- **泥罐**：泥质反应罐，既是耐热容器，又以封裹构成内部隔氧、外部保温的环境。
- **封裹泥固，以渐砑干**：用泥密封裹紧，再逐渐压碾阴干；**砑**（yà），碾压、磨光。"勿使见火拆裂"是工艺经验——湿罐骤热会炸裂。
- **煤炭饼**：煤压成的饼，既作燃料又是还原剂（碳源），"逐层垫盛"使料与煤接触充分。
- **煅红**：加热至红热高温。
- **冷定毁罐取出**：冷却后打破罐子取料——与考古出土反应罐所见"破罐取锌"流程一致[^4]。
- **每十耗去其二**：十斤料损耗二成；**倭铅**：明代对金属锌的称呼[^3]。

### 今译

> 〔今译〕每十斤炉甘石装入泥罐，用泥封裹牢固，逐渐压碾阴干，不要让它见火时开裂。然后逐层用煤炭饼垫隔，罐底铺柴引火，烧到通红，罐中炉甘石熔化成团。冷却后打破罐子取出，每十斤损耗掉二斤，剩下的就是倭铅（锌）。

### 现代解读

这段工序对应锌的碳热还原冶炼，化学骨架为两步：

```
分解：ZnCO₃ ──高温──▶ ZnO + CO₂↑
还原：ZnO + C  ──高温──▶ Zn（蒸气）+ CO↑
```

关键困难在温度窗口：氧化锌的碳还原温度约 900℃ 以上，而锌的沸点约 907℃，两者几乎重合——还原一经发生，锌立即以蒸气形式出现[^5]。原文"收伏"之难（"无铜收伏，入火即成烟飞去"，见 [02-wujin-metallurgy.md](02-wujin-metallurgy.md)）与密封泥罐的设置，正是对这一物理约束的工程回应：锌蒸气在罐内相对低温处冷凝，"每十耗去其二"记录的则是挥发与还原不完全造成的真实损耗。

这段记载的可信度有考古支撑：2013 年重庆忠县临江二队明代炼锌遗址出土冶锌炉、反应罐、冷凝盖与锌锭，"密封蒸馏—冷凝收锌"工艺与文字互证[^4]；学界普遍视本书为世界上最早系统记载锌冶炼工艺的文献之一，欧洲同类工艺要到 18 世纪才有专利记载[^6]。

## 二、黄铜配比段：《五金》

### 原文

> 后人因炉甘石烟洪飞损，改用倭铅。
>
> 每红铜六斤，入倭铅四斤，先后入罐熔化，冷定取出，即成黄铜。[^7]

### 注释

- **炉甘石点化**：早期工艺直接把炉甘石矿石与红铜同熔炼铜，锌由矿石在炉内还原而来。
- **烟洪飞损**：锌随烟气大量飞散损耗——矿石共熔时锌的收得率低，直接对应锌高温易挥发的物性[^3]。
- **改用倭铅**：改用先炼好的金属锌配料。
- **红铜**：纯铜；**黄铜**：铜锌合金。
- **先后入罐**：加料有先后次序，暗含对锌易烧损的照顾（后入者受热时间短）。

### 今译

> 〔今译〕后人因为用炉甘石直接点化红铜时锌随烟大量飞散损耗，改用倭铅（金属锌）。
>
> 每六斤红铜，配入四斤倭铅，先后放入罐中熔化，冷却后取出，就得到黄铜。

### 现代解读

黄铜即铜锌合金。"红铜六斤对倭铅四斤"即约 60:40 的铜锌比，与现代工业黄铜的常见配比区间相当；铸钱条所记"红铜居六七、倭铅居三四"的大略配比（见 [02-wujin-metallurgy.md](02-wujin-metallurgy.md)）也落在同一量级[^8]。

工艺史上这段话的价值在"改用"二字：从**矿石共熔**（锌源在炉内临时还原，收得率不可控）转为**金属配料**（先炼出锌，再按斤两配比），是把合金成分从"碰运气"变成"可称量、可重复"的关键一步。而"烟洪飞损"四字，恰是对锌挥发损失（重熔时"每见烈火必耗四分之一"[^8]）的直观描述——定量意识与物性观察在这里汇合。

## 三、银朱定量段：《丹青·朱》

### 原文

> 每升水银一斤，得朱十四两、次朱三两五钱，出数藉硫质而生。[^9]

### 注释

- **升**：升华炼制；此处指由水银升炼银朱。
- **水银**：汞，常温唯一液态金属，受热易挥发。
- **朱／次朱**：头等（上等）与次等的银朱，即人工硫化汞 HgS；与天然朱砂同为一物，精粗老嫩有别[^10]。
- **石亭脂**：硫黄所制的药剂原料，此处为硫的来源（配比见水银一斤对石亭脂二斤）[^11]。
- **出数藉硫质而生**：产出的分量是凭借硫质而生成的——明确把产物超出水银的部分归因于硫。
- **斤两**：明代一斤为十六两[^11]。

### 今译

> 〔今译〕每升华水银一斤，得到头等朱十四两、次等朱三两五钱；多出来的分量，是凭借硫质而生成的。

### 现代解读

这段是汞硫直接化合的记录：

```
Hg + S ──研合/微热、密封加热──▶ HgS
```

按明制十六两一斤折算：投入水银十六两，产出头朱十四两加次朱三两五钱，合计十七两五钱——比水银本身重出一两五钱；"出数藉硫质而生"正是对这份**化合增重**的归因[^12]。在现代化学里，汞与硫化合为硫化汞是典型的化合反应，产物质量等于两者之和；一条 1637 年的工艺记录能把"增重"与"硫"两个要素分别抓住，已是非常朴素的定量观察（详见 [05-modern-chemistry-lens.md](05-modern-chemistry-lens.md) 对其意义与限度的讨论）。与上一段升炼水银（HgS 分解出 Hg）对照读，可见同一物质体系的正反两个方向[^13]。

## 选读小结

三段选文对应本书化学工艺的三种记录形态：**工序实录**（倭铅段，含损耗率）、**配比规程**（黄铜段，含沿革与理由）、**定量观察**（银朱段，含归因）。读其余卷篇时，可沿用同一套四步法：先抄原文、再注名物、自撰今译、最后做现代对位——完整演示见 [../examples/01-wujin-passage-reading.md](../examples/01-wujin-passage-reading.md)。
