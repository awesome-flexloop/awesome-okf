## 作者与成书

| 编号 | 事实内容 |
|------|---------|
| F-001 | 《周易参同契》传统题署作者为魏伯阳，成书时代系于东汉（公元 2 世纪）；Golden Elixir 网站称其为"the main Chinese alchemical scripture"（中国炼丹术的主要经典），并述传统说法：魏伯阳读《龙虎经》（*Longhu jing*）后撰成此书。（M-1） |
| F-002 | 经文末章"自敘啟後章第三十五"自称"會稽鄙夫，幽谷朽生，挾懷朴素，不樂權榮……晏然閑居，乃撰斯文"，不著姓名；在 ctext 全文中检索"魏伯陽""徐從事""淳于"等人名，主文本均无命中。（O-1） |
| F-003 | 黄震《黄氏日抄》称此书"為上虞人魏伯陽所作"；陈振孙《直斋书录解题》载朱熹评其书"詞韻皆為古體，奧祕難懂"。（O-2） |
| F-004 | 魏伯阳生平的主要传记材料见于题葛洪（283—343）《神仙传》，其最早完整收录见《太平广记》（978 年成书）；传称魏伯阳为"吴"人（约当今江苏及安徽、浙江部分地区），出身高门。（M-3） |
| F-005 | 《神仙传》本传记述：魏伯阳携三弟子入山炼丹，以炼成之丹试犬，犬食之而死，伯阳自服亦死，一弟子随之服丹，余二弟子离去；伯阳、该弟子与犬后皆复苏。（M-3） |
| F-006 | 朱熹《周易参同契考异》卷末跋语自署"空同道士鄒訢"；ctext 页面释文据《礼记》郑玄注与《集韵》反切说明"訢"与"熹"音同（皆"虛其切"），朱熹以此化名托身道士作注。（O-2） |

## 文本结构与体例

| 编号 | 事实内容 |
|------|---------|
| F-007 | 传世《参同契》分上、中、下三篇；五代后蜀彭晓《周易参同契分章通真义》将全文分为 35 章，ctext 所收即此分章本，首章为"大易總敘章第一"，末章为"自敘啟後章第三十五"。（O-1、O-3） |
| F-008 | 35 章章名中可见"龍虎兩弦章第九""奼女黃芽章第二十六""鼎器妙用章第三十三""補塞遺脫章第三十四"等；ctext 用字作"奼女"（后世通行本作"姹女"）。（O-1） |
| F-009 | 经文以韵文为主体，四言、五言相间，多用骈偶句式；炼丹药物与设备多以隐语指代，如铅汞、龙虎、姹女、黄芽、偃月炉等。（O-1、M-2） |
| F-010 | 自叙章自述撰述内容："歌敘大易，三聖遺言……引內養性，黃老自然，含德之厚，歸根返元……配以伏食，雄雌設陳"，并自称"羅列三條，枝莖相連。同出異名，皆由一門"，篇末点题"命參同契，微覽其端"。（O-1） |
| F-011 | 自叙章有"挺除武都，八石棄捐"之语；经文另有"搗治羌石膽，雲母及礬磁。硫磺燒豫章……雜性不同類，安肯同體居。千舉必萬敗"等句，属本书药物取舍主张的文本内证。（O-1） |
| F-012 | Pregadio 指出：开篇"乾坤者，易之門戶"化用《易·系辞》"乾坤其易之門戶邪"；"橐籥"意象出自《道德经》第五章，"三十辐共一轂"意象出自《道德经》第十一章。（M-4） |

## 易理框架

| 编号 | 事实内容 |
|------|---------|
| F-013 | 大易总叙章开篇："乾坤者，易之門戶，眾卦之父母。坎離匡廓，運轂正軸，牝牡四卦，以為橐籥。"（O-1） |
| F-014 | Pregadio 解说本书宇宙论骨架：坎卦 ☵ 中含实爻（true yang）、离卦 ☲ 中含虚爻（true yin），坎离为乾坤之用；全书炼丹话语围绕铅与汞展开（"revolves around Lead and Mercury"）。（M-2） |
| F-015 | 经文以卦象配昼夜一日之程："朔旦屯直事，至暮蒙當受，晝夜各一卦用之依次序"，即屯、蒙二卦分主朔旦昼夕。（O-1） |
| F-016 | 经文以卦体内外配一年四时："春夏據內體，從子到辰巳，秋冬當外用，自午訖戌亥"。（O-1） |
| F-017 | 偃月炉段以月相卦象配药物与火候："上弦兌數八，下弦艮亦八，兩弦合其精，乾坤體乃成。二八應一斤，易道正不傾。"（O-1） |
| F-018 | 传统注家以纳甲法（月相盈亏配八卦与天干）、卦气说（六十四卦配节气、日辰）解说本书火候制度；Pregadio 将第一篇第 1—17 节归为宇宙论部分。（M-4、M-2） |

## 炼丹内容：药物、设备与火候

| 编号 | 事实内容 |
|------|---------|
| F-019 | 奼女黃芽章第二十六："河上奼女，靈而最神，得火則飛，不見埃塵，鬼隱龍匿，莫知所存。將欲制之，黃芽為根。"（O-1） |
| F-020 | 经文记铅化合物受热变化："胡粉投火中，色壞還為鉛。冰雪得溫湯，解釋成太玄。金以砂為主，秉和於水銀。"（O-1） |
| F-021 | 偃月炉段："偃月法爐鼎，白虎為熬樞；汞日為流珠，青龍與之俱。舉東以合西，魂魄自相拘。"（O-1） |
| F-022 | 水火情性章第十五："名者以定情，字者以性言。金來歸性初，乃得稱還丹。"同章又云："古記題龍虎，黃帝美金華。淮南煉秋石，玉陽加黃芽。"（O-1） |
| F-023 | 经文以四象、五行配五脏与药物："丹砂木精，得金乃并，金水合處，木火為侶。四者混沌，列為龍虎，龍陽數奇，虎陰數偶。肝青為父，肺白為母，腎黑為子，離赤為女，脾黃為祖"。（O-1） |
| F-024 | 鼎器妙用章（鼎器歌部分）记炉鼎形制尺寸与火候节奏："圓三五，寸一分，口四八，兩寸唇，長尺二，厚薄均。腹齊三，坐垂溫。陰在上，陽下奔。首尾武，中間文。始七十，終三旬，三百六，善調均。陰火白，黃芽鉛。"（O-1） |
| F-025 | 朱熹《考异》以版本校勘为本：汇集各本异同、保留异文，书名"考異"（一作"考義"）；《年谱》记庆元三年（1197）蔡元定将赴道州，与朱熹夜宿寒泉精舍共论《周易参同契》。（O-2） |

## 注本与诠释史

| 编号 | 事实内容 |
|------|---------|
| F-026 | 彭晓《周易参同契分章通真义》为五代后蜀时期注本，是现存最早的系统分章注本之一，其 35 章分法为后世通行结构。（O-3） |
| F-027 | 朱熹为南宋理学代表人物，其《参同契》注本托名"空同道士邹䜣"；ctext 页面释文说明朱熹托名道士一事，并指出研究丹法本非儒者本务。（O-2） |
| F-028 | 后世重要注本有元代陈致虚《周易参同契分章注》、清代朱元育《参同契阐幽》等；注本史上长期并存外丹（炉火黄白之术）与内丹（身内修养之术）两种诠释取向。（M-1、M-5） |
| F-029 | Golden Elixir 网站称《参同契》以隐语包含了后世道教内丹（Neidan）教义的核心阐述（"hides the exposition of the teaching that gave origin to Taoist Internal Alchemy"）。（M-1） |
| F-030 | 龍虎兩弦章第九有"古記題龍虎"语，与传统所谓魏伯阳参据《龙虎经》撰书的说法相呼应。（O-1、M-1） |

## 现代化学与毒理背景

| 编号 | 事实内容 |
|------|---------|
| F-031 | 现代化学中，丹砂（朱砂，HgS）在空气中焙烧析出汞：HgS + O₂ → Hg + SO₂；汞与硫经研磨或缓慢加热可化合为硫化汞：Hg + S → HgS。（现代化学通识，参 M-6） |
| F-032 | PMC 开放获取综述（*Frontiers in Pharmacology*，2022）称汞在中国传统医学中的使用已有约 3500 年；该页面中 "HgS" 出现 21 次、"cinnabar"（丹砂）出现 11 次。（M-6） |
| F-033 | 该综述记述：古人将丹砂（HgS）置于空气中焙烧以制取汞；生成的汞易挥发、难以收集，操作者可发生汞中毒；古人在实践中积累经验，采用密闭方法制取汞。（M-6） |
| F-034 | "河上奼女……得火則飛"的物性描写，与金属汞常温呈液态、受热易挥发的性质相符；"黃芽為根"的"制之"之法，历代注家有铅华（铅的氧化物）与硫黄两解，硫黄与汞化合生成 HgS，可固定挥发的汞。（O-1、M-6） |
| F-035 | 胡粉为古代常用白色颜料与药物，化学成分为碱式碳酸铅；"胡粉投火中，色壞還為鉛"所记为铅化合物受热分解、还原而复归为铅的变化。（O-1，现代化学通识） |
| F-036 | 本书以"還丹"名其丹药理想："金來歸性初，乃得稱還丹"；该想象与丹砂—汞—丹砂的转化循环相对应，经文中未见化学反应式层面的定量记述。（O-1、M-2） |
