# 炉火段逐句精读——鼎器歌六步法

## 精读对象

"鼎器妙用章第三十三"中的三言韵语（后世称"鼎器歌"），是全书设备与火候信息最密集的段落（ctext 彭晓分章本，繁体原文，54 字）：[^1]

> 圓三五，寸一分，口四八，兩寸唇，長尺二，厚薄均。腹齊三，坐垂溫。陰在上，陽下奔。首尾武，中間文。始七十，終三旬，三百六，善調均。陰火白，黃芽鉛。

本篇演示对这一段的完整精读流程。与 [../concepts/04-key-passages.md](../concepts/04-key-passages.md) 的"四步概览"不同，这里逐句落实，可作为阅读其他炉火、火候段落的模板。

> 安全提示：本段涉及炉鼎与铅汞药物，仅作文本分析，**严禁据以仿制器具、加热矿物或服食任何产物**。

## 第一步：断句与通读

鼎器歌是三言一句的韵语，共十八组，每句三字、一逗到底。通读三遍：

1. 第一遍认字：圓、唇、齊（齐）、旬、均；
2. 第二遍分板块：前六句（"圓三五"至"厚薄均"）讲**形制尺寸**，"腹齊三，坐垂溫。陰在上，陽下奔"讲**安置与火势**，"首尾武"至"善調均"讲**火候节奏与日数**，末句"陰火白，黃芽鉛"讲**火色与药物**；
3. 第三遍抓反复出现的母题：数字（三、五、四八、尺二、七十、三旬、三百六）与阴阳文武。

## 第二步：逐句注释

| 原文 | 注释 |
|------|------|
| 圓三五，寸一分 | 鼎腹圆围三寸五分（一说圆径与围度之数），壁厚一分。记容器规格。 |
| 口四八，兩寸唇 | 口径四寸八分，口沿厚（宽）两寸。"唇"指鼎口边沿。 |
| 長尺二，厚薄均 | 鼎身高一尺二寸，器壁厚薄均匀——受热均匀的工艺要求。 |
| 腹齊三，坐垂溫 | 腹宽（深）三寸；安置后以垂火温养（"坐"为安坐安置，"垂溫"为下沉式缓火温养）。 |
| 陰在上，陽下奔 | 阴（鼎器/冷凝之处）在上，阳（火）在下奔腾上炎。即下加热、上冷凝的位势。 |
| 首尾武，中間文 | 烧炼首尾用**武火**（猛火、升温），中间用**文火**（温养、保温）。 |
| 始七十，終三旬 | 起首七十日、终末三十日（一旬十日，三旬即三十日）。 |
| 三百六，善調均 | 全程合三百六十日之数，要善于调匀火候。 |
| 陰火白，黃芽鉛 | 温养的阴火色白（文火之色）；黄芽与铅相应（药物配属，参 [../concepts/03-alchemy-content.md](../concepts/03-alchemy-content.md)）。 |

## 第三步：自撰今译

> （鼎）圆围三寸五分、壁厚一分，口径四寸八分、口沿两寸，身高一尺二寸、厚薄均匀；腹宽三寸，安坐后以垂火温养。阴气在上、阳气自下奔腾。烧炼首尾用武火，中间用文火；起首七十日、终末三十日，合三百六十日之数，善于调匀。温养之火色白，黄芽与铅相应。

（今译为自撰，仅供理解；韵文节奏与隐语双关仍以原文为准。）

## 第四步：现代解读

**设备工艺**：这是一只带口沿、有腹深的密闭反应容器，下置热源。"陰在上，陽下奔"准确描述了升华装置的位势——下部加热使药物气化，上部温度较低使蒸气凝结：焙烧丹砂所得汞蒸气正是靠这种上凝结构收集的；古人并且知道须**密闭制取**才能收集易挥发的汞。[^2] "厚薄均""坐垂溫"则反映对受热均匀、避免局部过热的工艺自觉。

**火候曲线**："首尾武，中間文"翻译成现代语言就是一条温度曲线——升温期（武火）→ 恒温温养期（文火）→ 收尾期（武火），与现代热处理、晶体生长"升温—保温—降温"的三段式同构。"始七十，終三旬，三百六"是把这条曲线标定在日数上的时间参数；它与屯蒙值日、上弦兑八等卦象时间表属于同一套火候编码系统（见 [../concepts/02-theoretical-framework.md](../concepts/02-theoretical-framework.md)）。[^3]

## 第五步：双镜头判读

**工艺镜头（事实层）**：本段保留了可核验的工艺信息——反应器有明确的尺寸与均匀性要求，加热分上下位势，火力分武/文两档且按周期排布。这些与汞、硫升华化合的实际操作需要相符。

**象征镜头（框架层）**：数字同时服务于易学象征——"三五""四八""三百六"等与易数、历法（周天三百六十度、一年日数）相配，"陰在上，陽下奔"也是坎离交媾卦理的重述。经文没有称量、没有产物鉴定，"三百六"更像理想周期而非实测工期。[^4] 因此不能把鼎器歌当作汉代工程图纸直读；它是**工艺参数与象征数字的合体韵文**。

**信仰镜头（目的层）**：这套设备与规程的最终目的是炼成"还丹"服食求仙——该目标不被现代科学支持，且铅汞有剧毒（详见 [../concepts/05-modern-chemistry-lens.md](../concepts/05-modern-chemistry-lens.md)）。

## 第六步：思考题（可自答或讨论）

1. "首尾武，中間文"如果画成温度—时间曲线，是什么形状？它与屯蒙值日、上弦兑八编码的是不是同一个变量？（提示：都是时间—温度。）
2. "陰在上，陽下奔"与焙烧 HgS 收集汞蒸气的装置有什么对应关系？为什么密闭如此关键？（提示：HgS + O₂ → Hg + SO₂，汞蒸气无色易散且致中毒，参 F-031、F-033。）
3. 鼎器歌的数字（三五、四八、三百六）哪些可能接近工艺参数，哪些明显是象征数字？判断依据是什么？
4. 同样讲"设备 + 火候"，葛洪《抱朴子·金丹》以丹方日数为主（见 [../../baopuzi/index.md](../../baopuzi/index.md)），《参同契》以卦象月相为主——两种编码方式各适合什么传授场景？

## 精读模板复用

阅读《参同契》其他炉火段（如偃月炉段、姹女黄芽段）时，可沿用六步法：

1. **断句通读**（三言/四言/五言韵语先分板块）；
2. **逐句注释**（器物名、药物隐语、火候日数，参 [../concepts/03-alchemy-content.md](../concepts/03-alchemy-content.md) 隐语表）；
3. **自撰今译**（标注"今译"，不照抄版权注本）；
4. **现代解读**（对位设备、反应、温度曲线，方程式参 [../concepts/05-modern-chemistry-lens.md](../concepts/05-modern-chemistry-lens.md)）；
5. **双镜头判读**（工艺层是否成立 / 象征层在编排什么 / 信仰层外推了什么）；
6. **提出一个"如果……会怎样"的问题**。
