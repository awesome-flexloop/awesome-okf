## 精读对象

《抱朴子·内篇·金丹》中比较草木药与丹药的一段（ctext 四部丛刊底本，繁体原文）：

> 凡草木燒之即燼，而丹砂燒之成水銀，積變又還成丹砂，其去凡草木亦遠矣。故能令人長生。

同篇相邻段落还记有当时人的疑问："或不知水銀出於丹砂，告之終不肯信，云丹砂本赤物，從何得成此白物。又云丹砂是石耳，今燒諸石皆成灰，而丹砂何獨得爾。"葛洪的回答大意是：这正是丹砂为神物之处——"此丹砂之為神也"。

本篇演示对这一段的完整精读流程，可作为阅读其他丹法段落的模板。

## 第一步：断句与通读

繁体原文无标点，先按句意断句（简体镜像有标点本，见 [references/original-sources.md](../references/original-sources.md)）：

> 凡草木 / 燒之即燼，/ 而丹砂 / 燒之成水銀，/ 積變 / 又還成丹砂，/ 其去凡草木 / 亦遠矣。/ 故能令人長生。

通读三遍：第一遍认字（燼、砂、銀），第二遍找主语（草木、丹砂），第三遍抓比较结构（"而"字转折，草木 vs 丹砂）。

## 第二步：逐句注释

| 原文 | 注释 |
|------|------|
| 凡草木燒之即燼 | 凡：大凡；燼（jìn）：烧成灰烬。草木为有机物，燃烧后灰烬很少，主要产物（CO₂、水蒸气）逸散。 |
| 而丹砂燒之成水銀 | 而：可是，表转折。丹砂：硫化汞 HgS 矿物，红色。水銀：金属汞 Hg，常温液态、银白色。 |
| 積變又還成丹砂 | 積變：累积多次变化。還（huán）：回复、还原。水银再与硫黄合炼，又变回红色丹砂。 |
| 其去凡草木亦遠矣 | 去：距离、相差。它（丹砂）比普通草木高明得太远了。 |
| 故能令人長生 | 故：因此，表推论。葛洪的结论：服食丹砂能让人长生。 |

## 第三步：自撰今译

> 大凡草木之类，一烧就成了灰烬；可是丹砂烧炼后能变成水银，再经过累积变化又能变回丹砂，它比普通草木高出太多了。（葛洪据此推论）服食它便能令人长生不死。

（今译为自撰，仅供理解；古文语感仍以原文为准。）

## 第四步：现代化学解读

**反应一：焙烧（丹砂 → 水银）**

```
HgS + O₂  ──加热──▶  Hg↑ + SO₂↑
```

- 硫化汞在空气中焙烧，生成汞蒸气与二氧化硫；汞蒸气导入冷却容器冷凝，即得液态水银。
- 古代操作要点：丹釜密封、设置冷凝收集装置——汞蒸气若不收集则散失且中毒。这正是炼丹家"六一泥"封固与上下釜（"丹釜""丹鼎"）结构的用途。

**反应二：还复（水银 → 丹砂）**

```
Hg + S  ──研磨──▶  黑色 HgS  ──密闭升华──▶  红色 HgS 结晶
```

- 水银与硫黄研磨先得黑色硫化汞（黑色变体），置于密闭器中升华（加热使气化再凝结），转变为红色结晶——外观与天然丹砂一致。
- "積變又還成丹砂"的"积变"二字准确描述了需要研磨、升华等多步操作才能完成的回复过程。

**观察质量评估**：

| 葛洪的观察 | 现代判定 |
|-----------|---------|
| 草木烧之即烬 | 正确（有机物燃烧产物逸散） |
| 丹砂烧之成水银 | 正确（HgS 焙烧得汞） |
| 积变又还成丹砂 | 正确（汞硫再化合，升华转红） |
| 故能令人长生 | 不成立（类比外推；且汞有剧毒） |

## 第五步：双镜头判读

**现象镜头（事实）**：这是 4 世纪对硫化汞—汞互变循环的明确、完整记录，包括反应物、产物、外观变化（赤→白→赤）与往复方向。同类记录在世界化学史上属于较早的系统表述。

**信仰镜头（解释）**：葛洪的推理链是——草木烧后成灰（速朽）→ 丹砂烧后能循环复生（不朽）→ 服食丹砂可把"不朽"转移给人体（"假求于外物以自坚固"）。这个推理的破绽在：

1. 物质在化学反应中循环，与人体衰老是两类不同过程，不能类比转移；
2. 丹砂循环依赖人的反复操作（焙烧、收集、研磨、升华），并非自动"长生"；
3. 汞及汞盐进入人体后不表现为"坚固"，而表现为神经与肾脏毒性。

历史反证：唐代太宗、宪宗、穆宗、武宗、宣宗至少五帝服丹身亡（详见 [05-modern-chemistry-lens.md](../concepts/05-modern-chemistry-lens.md)）。

## 第六步：思考题（可自答或讨论）

1. 葛洪记录的时人疑问——"丹砂本赤物，从何得成此白物"——属于什么性质的问题？（提示：这是关于颜色与物质同一性的经验疑问，葛洪以"神"作答；现代化学以元素与化合作答。）
2. "积变又还"中的"还"字，与后世"还丹""还原"等词有何关系？
3. 如果把这段文字的最后一句"故能令人长生"删去，它与一条实验记录还有多远距离？还缺什么？（提示：缺定量比例、条件参数、产物收集与称量。）
4. 同样准确的观察，为什么《肘后备急方》的青蒿条在 20 世纪结出青蒿素，而丹砂循环没有结出近代化学？（提示：目标框架的可检验性，见 [insights.md](../insights.md) 洞察 3。）

## 精读模板复用

阅读《金丹》《黄白》其他丹方段落时，可沿用六步法：

1. 断句通读（用简体标点本辅助）；
2. 逐句注释（矿物名、操作名、火候时日）；
3. 自撰今译；
4. 写出对应现代反应（参考 [05-modern-chemistry-lens.md](../concepts/05-modern-chemistry-lens.md) 各物质体系）；
5. 双镜头判读（现象是否成立 / 信仰外推是什么）；
6. 提出一个"如果……会怎样"的问题。
