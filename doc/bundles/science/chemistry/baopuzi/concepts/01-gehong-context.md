## 葛洪生平年表

葛洪，字稚川，自号抱朴子，丹阳句容（今江苏句容）人。关于其生年，通行说法为西晋太康四年（283），中国哲学书电子化计划标注为 300—343 年，卒年另有 363 年之说。[^ctext] 以下年表据白寿彝主编《中国通史》第五卷"葛洪、陶弘景"章整理。[^scholarship]

| 时间 | 事件 |
|------|------|
| 283 年（太康四年） | 生于丹阳句容没落官宦之家。祖父葛系仕三国吴，历任吏部尚书等要职；父葛悌入晋后官至邵陵太守。 |
| 约 296 年（十三岁） | 父卒，家道中落；自述饥寒困瘁、躬执耕穑，"伐薪卖之，以给纸笔"，纸张正反面反复抄用。 |
| 少年时期 | 十六岁前后读《孝经》《论语》《诗经》《易经》等儒家经典；后以儒学知名，却"才非政事"，无意仕途。 |
| 约 301—302 年（十八九岁） | 入庐江马迹山，拜从祖葛玄弟子郑隐（郑思远）为师，研习道书与炼丹术。郑隐门下弟子五十余人，葛洪独受金丹经法。 |
| 303 年（太安二年，二十一岁） | 应吴兴太守顾秘之邀任将兵都尉，参与镇压石冰部义军，功迁伏波将军；事平后投戈释甲，赴洛阳搜求异书。 |
| 306 年（光熙元年，二十四岁） | 嵇含表为广州参军，先行至广州，嵇含中途遇害，遂留广州多年；其间拜南海太守鲍靓（鲍太玄）为师，娶鲍靓之女鲍姑（名潜光，最早见于记载的女针灸医家）为妻。 |
| 约三十岁后 | 携家归乡里，潜心著述十余年，作品多达数百卷。 |
| 约 317 年（建武元年，三十五岁） | 完成《抱朴子内篇》二十卷、《外篇》五十卷；同期有《神仙传》十卷、《玉函方》一百卷、《肘后备急方》三卷等。 |
| 咸和年间（326—334，约五十岁） | 闻扶南（今越南、柬埔寨南部一带）出产丹砂，上书求为勾漏（今广西北流）令；后止于罗浮山炼丹。 |
| 343 年（一说 363 年） | 卒于罗浮山。 |

## 丹经传承谱系

《金丹》篇自述其丹法来源，这是中国炼丹史上少见的清晰师承记录：

> 昔左元放于天柱山中精思，而神人授之金丹仙经……余从祖仙公，又从元放受之。凡受《太清丹经》三卷及《九鼎丹经》一卷、《金液丹经》一卷。余师郑君者，则余从祖仙公之弟子也……乃于马迹山中立坛盟受之。

谱系为：**左慈（元放）→ 葛玄（从祖，葛仙公）→ 郑隐（郑君）→ 葛洪**。葛洪特别强调"江东先无此书"，丹经以立坛盟授、口诀不书的方式秘传，这解释了《内篇》为何反复慨叹"不得明师口诀，诚不可轻作"。

## 内外篇结构与分工

《抱朴子》分内、外两篇，葛洪在《抱朴子内篇序》中自述："今为此书，粗举长生之理……名曰内篇，凡二十卷，与外篇各起次第也。"《四库全书总目提要》概括为："外篇言时政得失、人事臧否……内篇则论神仙吐纳、符箓之事。"

### 外篇五十卷（经世人事）

外篇用儒家子书论辩文体，谈君道、臣节、用刑、审举、交际、行品、百家等时政人事问题，文体近《论衡》《潜夫论》。阅读内篇时了解外篇的存在，才能理解葛洪"儒道双修"的完整立场：他不是在野方士，而是以子书作者自期的士大夫。

## 历史语境：两晋之际的道教转型

葛洪生活的时代，道教正在经历深刻转型：

1. **民间道教的遗产**：汉末太平道、五斗米道以符水治病、教团组织动员民众，与农民起义关联，受到政权警惕。
2. **士族化改造**：两晋之际，士大夫阶层介入道教，试图将其改造为有经典、有师承、有仪轨、不涉造反的"神仙道教"。葛洪《内篇》是这一改造的代表性文本——他强调金丹需"入名山、斋百日、绝人事"，把成仙变成精英式的、烧炼外丹的技术路径，与民间符水治病拉开距离。
3. **南渡与江南传统**：葛洪家族本为江东士族，丹经传承（左慈渡江→葛玄→郑隐）本身就是汉末乱后北方方术南传的缩影；罗浮山、勾漏、马迹山等南方名山构成其炼丹地理。
4. **儒道会通**：《内篇·明本》提出"道者儒之本也，儒者道之末也"，以道为本而不弃儒；外篇论时政，内篇论长生，一人之手完成两种文体。研究界（如侯星如 2024 年论文）视之为"将民间道教转化为士族神仙道教"的努力。[^scholarship]

## 葛洪的写作目的

综合《内篇》文本与自序，可归纳为四点：

1. **整理与保存**：他"考览养性之书，鸠集久视之方，曾所披涉篇卷以千计"，痛惜流俗道士"各有数十卷书亦未能悉解"，故把金丹大法系统钞录。
2. **论证与辩护**：以论辩文体证明"神仙实有，长生可致"，回应"世人少所识，多所怪"的讥笑。
3. **传授与择人**：反复强调非"明师口诀"不可轻作，书为"识者"传，"不可与言者不令见"。
4. **医道并重**：《杂应》明言"古之初为道者，莫不兼修医术，以救近祸"，他本人著《肘后备急方》，把救急治病视为修道的组成部分。

## 阅读提示

- 读《内篇》前先知道葛洪的双重身份：炼丹理论家与医药学家。后者留下的《肘后备急方》以"青蒿绞汁"条启示了青蒿素的发现（详见 [00-why-read.md](00-why-read.md) 与 [references/modern-scholarship.md](../references/modern-scholarship.md)）。
- 《内篇》的论辩策略常以"物质可变"类比"人可成仙"：黄丹胡粉化铅所作、骡为驴马所生、水精碗合五种灰铸成——这些例子本身是准确的工艺观察，结论却是信仰跳跃。阅读时注意区分。
- 道家思想背景可上溯《老子》，参读 [帛书《老子》阅读教程](../../../../think/laozi/boshu-reading/index.md)。
