# 波义耳《怀疑的化学家》阅读教程

罗伯特·波义耳的《怀疑的化学家》（*The Sceptical Chymist*，伦敦，1661）是化学走向近代的标志性著作。全书以花园对话体写成：Carneades（波义耳的化身）当着仲裁者 Eleutherius 的面，用实验证据逐一检验亚里士多德派的四元素说（土、气、火、水）与帕拉塞尔苏斯派的三要素说（盐、硫、汞），并在第六部分给出近代著名的元素定义，随即宣布当时没有任何已知物质符合这一定义。本知识包提供公版原文选读（每段英文 ≤40 词）、自撰今译、词句注释与化学史解读，帮助读者直接读懂这本 17 世纪经典。
