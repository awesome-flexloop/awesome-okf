## B. 燃素说与 18 世纪气体化学

| 编号 | 事实内容 |
|---|---|
| F-008 | 燃素说（phlogiston theory）由德国化学家格奥尔格·恩斯特·施塔尔（Georg Ernst Stahl，1660–1734）在约翰·约阿希姆·贝歇尔（J. J. Becher）工作基础上系统化，主张可燃物含有"燃素"，燃烧、煅烧与呼吸是燃素逸出的过程。 |
| F-009 | 金属煅烧后所得灰渣（calx）重量大于原金属；按燃素逸出的解释煅烧应减重，重量变化方向与理论预期相反。 |
| F-010 | 18 世纪中叶气体化学积累一批成果：约瑟夫·布莱克（Joseph Black）研究"固定空气"（二氧化碳），亨利·卡文迪什（Henry Cavendish）研究"可燃空气"（氢气）。 |
| F-011 | 约瑟夫·普利斯特里（Joseph Priestley，1733–1804）于 1774 年 8 月 1 日加热红色汞灰（氧化汞）收集到一种气体，蜡烛在其中燃烧火焰明显更旺；他按燃素说框架将其命名为"脱燃素空气"（dephlogisticated air）。 |
| F-012 | 1774 年 10 月普利斯特里随谢尔本勋爵访问巴黎，在拉瓦锡家宴上介绍该实验，拉瓦锡夫人在场协助语言沟通。 |
| F-013 | 瑞典药剂师卡尔·威廉·舍勒（Carl Wilhelm Scheele，1742–1786）约在 1771–1772 年制得同种气体，命名为"火气"（Feuerluft），其实验笔记存世；相关著作 1777 年出版。 |
| F-014 | 约 1774 年末舍勒曾致信拉瓦锡，描述该气体的制备方法。 |
| F-015 | 普利斯特里 1794 年移居美国宾夕法尼亚州，1804 年去世，终生未接受氧化学说。 |
| F-016 | 普利斯特里一生发表书籍与小册子逾 200 种，主题涵盖神学、政治、教育学、语言学与自然科学。 |

## C. 拉瓦锡的氧化学说研究

| 编号 | 事实内容 |
|---|---|
| F-017 | 1772 年拉瓦锡确立研究纲领：系统考察空气在燃烧、煅烧、呼吸等化学与生理过程中的参与；他记录到燃烧与煅烧物体吸收空气且重量增加。 |
| F-018 | 1774 年 4 月巴黎化学家皮埃尔·巴扬（Pierre Bayen）发现红色汞灰可不加木炭、仅靠强热还原为金属汞。 |
| F-019 | 拉瓦锡 1775 年 5 月发表论文，称该气体为"纯粹的、完整未分解的空气"；普利斯特里公开指出这一判断有误，拉瓦锡随后改称其为"空气中最纯净的部分"。 |
| F-020 | 1777 年拉瓦锡发表《燃烧通论》（Mémoire sur la combustion en général，载《科学院报告》第 592–600 页），系统提出燃烧的氧化学说。 |
| F-021 | 1779 年拉瓦锡确认该气体为一切酸的组成部分，在论文修订中创造 oxygène 一词，构词取希腊文"酸之生成者"之意。 |
| F-022 | 拉瓦锡批判燃素说的循环论证：该说一面称可燃物含火素故能燃烧，一面又以燃烧为其含火素的证据，他指出这是"以燃烧解释燃烧"。 |
| F-023 | 汞煅烧实验（《化学基础论》第一部分）：曲颈瓶容积约 36 立方英寸，内盛 4 盎司纯汞，瓶颈通入汞槽上的钟罩；汞保持近沸点连续加热约 12 天。 |
| F-024 | 该实验中空气体积由约 50 立方英寸减至 42–43 立方英寸，减少约六分之一；汞面生成红色微粒共 45 格令（grains）。 |
| F-025 | 将 45 格令红色物质置于小曲颈瓶中强热，收集到 41.5 格令液态汞与 7–8 立方英寸弹性流体；该流体支持呼吸与燃烧的能力明显强于普通空气。 |
| F-026 | 水的分解实验（第一部分）：100 格令水分解后，85 格令氧与铁结合，15 格令为可燃气体（氢）；现代化学值约为氧占 88.9%、氢占 11.1%。 |
| F-027 | hydrogène 一词释义为"水之生成原则"（the generative principle of water），构词取自希腊文 hydōr（水）与表"生成"的希腊文词根。 |
| F-028 | 1783 年 6 月拉瓦锡在科学院公开进行水的合成与分解实验，以定量方式确认水由氧与氢两种物质组成。 |

## D. 《化学基础论》文本与结构

| 编号 | 事实内容 |
|---|---|
| F-029 | 法文原版《Traité élémentaire de chimie》1789 年出版于巴黎，书商为 Cuchet（rue & hôtel Serpente），扉页标 M. DCC. LXXXIX，获科学院与皇家医学会特权许可，分两卷。 |
| F-030 | 英译本 Elements of Chemistry, in a New Systematic Order, Containing All the Modern Discoveries 由罗伯特·克尔（Robert Kerr，1755–1813）翻译，1790 年于爱丁堡由 William Creech 出版，扉页注明"含十三幅铜版插图"（ILLUSTRATED WITH THIRTEEN COPPERPLATES）。 |
| F-031 | 全书分三部分：第一部分论气态流体的形成与分解、简单物体的燃烧、酸的形成及动植物物质的分解；第二部分论酸与可盐化碱基的结合、中性盐组成与亲和力学说；第三部分论化学仪器与操作、实验室建设、符号使用与酒类发酵。 |
| F-032 | "简单物质表"（TABLE OF SIMPLE SUBSTANCES）位于第二部分开篇，共列 33 项，分四类。 |
| F-033 | 第一类"自然界三界共有、可视为物体元素的简单物质"共 5 项：光（Light）、热质（Caloric）、氧（Oxygen）、氮（Azote）、氢（Hydrogen）。 |
| F-034 | 第二类"非金属可氧化可酸化简单物质"共 6 项：硫、磷、炭（charcoal）、盐酸根（muriatic radical）、氟酸根（fluoric radical）、硼酸根（boracic radical）；后三项在表中标注"仍属未知"（Still unknown）。 |
| F-035 | 第三类"可氧化可酸化金属简单物质"共 17 项：锑、砷、铋、钴、铜、金、铁、铅、锰、汞、辉钼矿（molybdena）、镍、铂（platina）、银、锡、钨（tungstein）、锌。 |
| F-036 | 第四类"可盐化土质简单物质"共 5 项：石灰（lime）、镁土（magnesia）、重土（barytes）、黏土（argill）、硅土（silex）。 |
| F-037 | 以现代化学回看，33 项中光与热质不属物质元素，五种土质后被证明为化合物（以氧化物为主），表中约 23 项对应现代意义上的化学元素。 |
| F-038 | 表中附新旧名称对照：氧旧称脱燃素空气／纯火空气／生命空气，氮旧称燃素化空气／瘴气（mephitis），氢旧称可燃空气，热质旧称热／火／火流体。 |
| F-039 | 序言（Discours préliminaire）给出元素定义：元素或"物体之原则"指"分析所能达到的最后一点"；凡能借分解将物体还原所得的物质皆须承认为元素；在实验与观察证明其为复合物之前，不应假定它们复合。 |
| F-040 | 序言引用孔狄亚克（Condillac）《逻辑》等著作中的格言："我们只借语言思考……推理的技艺不过是排列良好的语言。" |
| F-041 | 序言记载：1787 年，德莫沃（de Morveau）、贝托莱（Berthollet）、德富克鲁瓦（de Fourcroy）与拉瓦锡四人合作完成《化学命名法》（Méthode de nomenclature chimique）。 |
| F-042 | 质量守恒论述见于第三部分"论酒类发酵"章，克尔英译文为 "in all the operations of art and nature, nothing is created; an equal quantity of matter exists both before and after the experiment"；法文原文为 "rien ne se crée, ni dans les opérations de l'art, ni dans celles de la nature"。 |
| F-043 | 同章提出化学"等式"思想：实验中须假定被检验物体之原则与分析所得产物之间存在"真正的相等或等式"（une véritable égalité ou équation）；法文版以等式表达发酵：le moût de raisin = acide carbonique + alkool（葡萄汁＝碳酸＋酒精）；克尔英译本将该等式改写为散文表述。 |
| F-044 | 书中燃烧定义（第三部分第八章引第一部分）：燃烧是可燃物体对氧气的分解；构成氧气基的氧被燃烧体吸收并与之化合，热质与光则被释放。 |
| F-045 | 第二部分论及亲和力（affinity）时，拉瓦锡声明亲和力数据尚不完备，书中未给出亲和力表。 |
| F-046 | 克尔译本附有译者注，包括对 carbone 与 charcoal 用词区分的说明、列氏温标数值后附华氏括注等处理。 |
