# 架构洞察

> 本文件为 seven-concepts I 阶段产物。每条洞察采用四元组结构：**陈述 / 证据 / 反常识 / 行动**；证据回溯 [facts.md](facts.md) 事实编号。

## 核心洞察

| # | 陈述 | 证据 | 反常识 | 行动 |
|---|---|---|---|---|
| I-1 | 化学革命的引擎不是某种新气体，而是"全反应物—全产物称量 + 质量平衡"的方法纪律。普利斯特里与舍勒都制出了氧气，拉瓦锡的独占性贡献是把天平贯穿反应全程。 | F-011、F-013、F-017、F-023、F-024、F-025、F-026、F-042、F-043 | 习惯说法把革命归功于"发现氧气"；但最早制得者是舍勒（约 1771）、最早发表者是普利斯特里（1775），两人都终生抱持燃素说。发现物质不等于理解物质。 | 读每个实验时先停笔列出"反应物清单 / 产物清单 / 两边重量"，再读拉瓦锡的结论；把本书当作质量平衡习题集来读。参见 [03 质量守恒与定量方法](concepts/03-conservation-of-mass.md)。 |
| I-2 | 元素表是"分析技术的临时边界"，不是世界的本体清单。拉瓦锡把元素定义绑定在分解操作的极限上，光与热质入表正是这一方法论的自然后果。 | F-032、F-033、F-034、F-035、F-036、F-037、F-039 | 现代读者常把第一张元素表当"正确率约 23/33 的早期周期表"来嘲笑；拉瓦锡本人明确警告：在实验证明其复合之前不应假定表中物质复合。错误项与正确项出自同一条方法论规则。 | 读表时做"三列批注"：拉瓦锡名 / 现代名 / 后来被分解或取消的年份与理由；理解"分析极限"随仪器（电解、光谱）推进而移动。参见 [04 命名法与元素表](concepts/04-nomenclature-and-elements.md)。 |
| I-3 | 新化学的扩散在相当程度上是语言工程的胜利：1787 命名法让化合物名称自带组成信息，使燃素说在词汇层面失去栖身之所。 | F-038、F-040、F-041、F-047 | 通常以为科学革命靠一锤定音的判决性实验；本书序言却把孔狄亚克的语言哲学置于卷首，拉瓦锡自陈"以为自己只在做命名法，实则在创造一门语言"。 | 阅读中维护"旧名 → 新名（1787）→ 现代名"三列对照表；用后缀规则（-ic/-ous、-ate/-ite 对应的酸与盐）反推化合物组成，把命名法当化学语法来学。参见 [04 命名法与元素表](concepts/04-nomenclature-and-elements.md)。 |
| I-4 | 革命框架内部保留了旧时代组件：拉瓦锡驱逐了"可燃物里的火"（燃素），又把热实体化为可称量的流体"热质"（caloric）列入元素表首位。 | F-033、F-044、F-037 | 推翻燃素说的人同时主张热是一种物质元素；"火是物质"的直觉换了形式留在新体系里，直到 19 世纪热功当量工作才被清除。革命不意味着与传统的全盘断裂。 | 阅读时标记 caloric（热质）出现的每一处，试用现代能量语言改写句子；对比燃素与热质的功能对称性，理解"概念替换"与"概念废除"的区别。参见 [02 氧化学说](concepts/02-oxygen-theory.md)。 |

## 知识地图

```text
拉瓦锡《化学基础论》阅读教程
├── 语境：18 世纪的化学与燃素说危机
│   ├── 燃素说（Stahl/Becher）及其重量悖论
│   ├── 气体化学：Black 固定空气 / Cavendish 可燃空气 / Priestley 脱燃素空气 / Scheele 火气
│   └── 拉瓦锡生平：科学院（1768）→ 包税会 → 阿森纳尔实验室（1776）→ 断头台（1794）
├── 核心理论
│   ├── 氧化学说：燃烧＝氧化合（非燃素逸出）；煅烧、呼吸同构
│   ├── 质量守恒与质量平衡法："nothing is created" 与化学"等式"
│   ├── 元素的操作定义与 33 项简单物质表（四类）
│   └── 1787 命名法：语言即推理工具（Condillac）
├── 文本结构（1789 巴黎 Cuchet / 1790 爱丁堡 Kerr 译本）
│   ├── 序言：语言哲学 + 元素定义 + 命名法由来
│   ├── 第一部分：气体 · 汞煅烧 12 天 · 水的组成（85/15）· 酸
│   ├── 第二部分：盐 · 简单物质表 · 亲和力（刻意留白）
│   └── 第三部分：仪器与操作 · 发酵章（守恒名言 + 第一个化学方程式）
└── 遗产与局限
    ├── 化学方程式思想、定量生理学（呼吸＝缓慢燃烧）
    ├── 热质说残留、光与五种土质的错误项
    └── 史学：化学革命的"断裂 vs 连续"之辨（Rocke 等）
```

## 学习路径推荐

- **90 分钟速览**：序言元素定义 → 第二部分开篇 33 项元素表 → 第三部分发酵章守恒名言与方程式。配套 [05 关键段落精读](concepts/05-key-passages.md)。
- **一日精读**：速览内容 + 第一部分汞煅烧实验（12 天）与水的组成章 + [01 燃烧段落逐句精读](examples/01-combustion-passage-reading.md)。配套概念 [01](concepts/01-chemical-revolution.md)、[02](concepts/02-oxygen-theory.md)、[03](concepts/03-conservation-of-mass.md)。
- **三周通读**：按 [三档阅读路线](examples/02-reading-route.md) 读完全书三部分，配合波义耳《怀疑的化学家》（前驱）与道尔顿《化学哲学新体系》（后继）两个兄弟知识包做思想史对照。
