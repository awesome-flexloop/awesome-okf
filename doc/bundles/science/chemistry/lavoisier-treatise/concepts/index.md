## 阅读顺序建议

- **概念主线**：01 → 02 → 03 → 04（危机 → 理论 → 方法 → 体系），00 与 05 可随时插入。
- **原文主线**：05 配合 [示例一：燃烧段落逐句精读](../examples/01-combustion-passage-reading.md) 使用。
- **思想史主线**：01 读完后参读前驱 [波义耳《怀疑的化学家》](../../boyle-sceptical-chymist/index.md)；04 读完后参读后继 [道尔顿《化学哲学新体系》](../../dalton-new-system/index.md)。
