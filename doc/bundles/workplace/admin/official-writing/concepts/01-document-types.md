# 十五种法定公文总览与易混辨析

## 是什么

法定公文是《党政机关公文处理工作条例》（中办发〔2012〕14号）第八条明确规定的 **15 种正式文种**：决议、决定、命令（令）、公报、公告、通告、意见、通知、通报、报告、请示、批复、议案、函、纪要。每一种文种都有法定的适用范围，选错文种不是“措辞问题”，而是行文关系错误。

企业虽然不是党政机关，但内部正式行文（通知、通报、报告、请示、函、纪要）普遍借用这套文种体系；写对文种是行政、人事、秘书岗位的基本功。

## 为什么：文种是行文关系的表达，不是标题装饰

文种的本质是回答两个问题：**我和受文方是什么关系？我要对方做什么？**

- 关系是“上级对下级”还是“下级对上级”，决定行文方向（下行/上行/平行）；
- 目的是“让对方知晓”“让对方执行”还是“请对方批准”，决定具体文种。

同样写“请批准”：对上级用**请示**（期复，必须等批复），对不相隶属单位用**函**（商洽请求批准），答复下级的请准则用**批复**——内容相似，文种完全不同。

## 怎么做：15 文种速查表

| 文种 | 适用范围（压缩自条例第八条） | 行文方向 | 企业场景类比 |
|---|---|---|---|
| 决议 | 会议讨论通过的重大决策事项 | 下行（会议产出） | 股东会/董事会决议 |
| 决定 | 重要事项决策部署、奖惩、撤销下级不当决定 | 下行 | 重大组织调整、奖惩决定 |
| 命令（令） | 公布行政法规规章、重大强制措施、授衔嘉奖 | 下行 | 企业一般不用 |
| 公报 | 公布重要决定或重大事项 | 公开 | 企业一般不用（上市公告相近） |
| 公告 | 向国内外宣布重要事项或法定事项 | 公开 | 注销/清算等法定公告 |
| 通告 | 一定范围内应遵守或周知的事项 | 下行/公开 | 园区封路、停电梯通告 |
| 意见 | 对重要问题提出见解和处理办法 | 方向灵活 | 改进方案指导意见 |
| **通知** | 发布传达要求执行/周知事项，批转转发公文 | 下行为主 | 会议通知、放假通知、制度发布 |
| 通报 | 表彰先进、批评错误、传达重要精神情况 | 下行 | 表彰通报、违纪通报 |
| **报告** | 向上级汇报工作、反映情况、答复询问 | 上行 | 工作总结报告、专项报告 |
| **请示** | 向上级请求指示、批准 | 上行（期复） | 预算申请、采购申请 |
| 批复 | 答复下级请示事项 | 下行 | 对部门申请的正式答复 |
| 议案 | 政府向同级人大提请审议事项 | 特定 | 企业一般不用 |
| **函** | 不相隶属机关间商洽、问答、请求批准 | 平行 | 对外商洽、询价、催款函 |
| **纪要** | 记载会议主要情况和议定事项 | 内部周知 | 办公会纪要、项目例会纪要 |

加粗的 6 种（通知、报告、请示、函、纪要、通报）覆盖企业行政人事岗位 90% 以上的正式行文场景，优先掌握。

### 选择路径（动笔前 30 秒自检）

1. 这件事是不是 15 种法定公文事项？不是 → 事务文书（计划、总结、邮件等，见 [职场常用文书](03-workplace-documents.md)）。
2. 是 → 我和受文方什么关系？向上 / 向下 / 平级不相隶属。
3. 我要对方做什么？知晓 → 通知/通告/公告；执行 → 通知/决定；批准 → 请示（向上）/函（平级）；答复 → 批复/报告；记载会议结论 → 纪要。

完整决策图见 [洞察分析：文种选择决策图](../insights.md)。

### 五组易混文种辨析

**1. 决议 vs 决定**：决议必须经**会议讨论并表决通过**，程序色彩强；决定可由领导机关**直接作出**，用于部署、奖惩、撤销。记忆点：“决议走会议，决定可直接”。

**2. 公告 vs 通告**：公告面向**国内外**，宣布重要或法定事项，范围最广；通告面向**一定范围**，内容带“应当遵守”的约束力（如交通管制、施工停水）。记忆点：“公告广而告之，通告通告相关人”。

**3. 请示 vs 报告**（最高频硬伤）：请示是**事前**请求批准，**一文一事**，上级**必须批复**；报告是**事中/事后**汇报情况，可一文多事，上级**可以不回复**。条例明确禁止在报告中夹带请示事项。对照范例见 [报告与请示对比示例](../examples/02-report-vs-request.md)。

**4. 通知 vs 通报**：通知重在**布置执行**（要你做什么）；通报重在**教育传达**（表彰、批评、传达精神）。处分决定用“决定/通报”，布置开会用“通知”。

**5. 函 vs 请示**：都可能是“请求批准”，区别在关系——有隶属关系、向上级用**请示**；不相隶属（兄弟单位、外部公司、政府对口部门）用**函**。向无隶属关系的主管部门请求批准事项也用函（如向园区管委会申请用房）。

另注意：**纪要 ≠ 会议记录**（记录求全、纪要要决），辨析见 [职场常用文书](03-workplace-documents.md)。

## 常见坑与边界

- **“请示报告”连用**：标题写成《关于××的请示报告》属于文种混用，要么请示、要么报告。
- **报告里夹带“请领导批准”**：违反“不得在报告等非请示性公文中夹带请示事项”（F-025），可能不被批复而耽误事项。
- **请示一文多事**：一份请示申请预算又申请招人又申请出差，上级无法整体批复，应一文一事分别行文。
- **对外部公司用“通知”**：双方不相隶属，应用“函”；对客户/供应商发“通知”属于关系错位。
- **该用纪要写了记录**：纪要只记议定事项与责任分工，把领导原话全文照抄是会议记录，不是纪要。
- 边界：15 种是党政机关法定文种；企业内部制度可自行规定文书形式，借用文种时保持“关系—目的”逻辑一致即可，不必照搬份号、密级等机关格式要素（见 [公文格式18要素](02-format-elements.md)）。
