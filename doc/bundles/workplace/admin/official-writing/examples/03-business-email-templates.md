# 商务邮件模板（可直接改写）

> 说明：商务邮件属于事务文书，无法定格式，但通行结构稳定（F-036）。本篇给出结构公式、主题行写法和四封高频场景模板，公司名与人名均为虚拟。正式度要求更高的对外事项（如法律函件、正式商洽）应用“函”的形式，参见 [十五种法定公文总览](../concepts/01-document-types.md)。

## 一、结构公式

```text
主题：【事项标签】+ 具体事由 + 行动/期限
称呼：××经理/××老师/××总：（对方职务不明用“您好”）
正文：第一段——我是谁、为什么事、希望对方做什么（结论先行）
　　　第二段——背景与必要细节（分条列项，一事一邮件）
　　　第三段——明确的行动要求与时限
祝颂：顺颂商祺 / 祝好 / 谢谢
署名：姓名 | 职务 | 公司 | 电话 | 邮箱
```

主题行示例：`【询价】三楼办公区改造工程，请于9月20日前报价`、`【请示】四季度招聘预算申请（请9月10日前批复）`。

## 二、模板一：对外询价洽商（平行/对外）

```text
主题：【询价】××公司办公区改造项目，邀请报价（9月20日前）

××装饰公司 王经理：

您好！我是××科技有限公司行政部李××。我司拟对三楼办公区进行改造，
现邀请贵司参与报价，有关事项如下：

一、项目概况：三楼北区约320平方米，新增开放工位24个、讨论间2间，
　　含基础装修与家具配套。
二、报价要求：请按附件需求清单分别列明工程费、家具费、税费及工期，
　　报价文件请加盖公章。
三、时间安排：请于9月20日（星期六）17:00前将报价发送至本邮箱；
　　现场勘察可与我联系预约。

附件：办公区改造需求清单

如对需求有疑问，欢迎随时联系（电话010-××××××××）。
顺颂商祺！

李×× | 行政专员 | ××科技有限公司
电话：010-×××××××× | 邮箱：li.xx@example.com
```

## 三、模板二：内部资源申请（上行，邮件版“请示”）

```text
主题：【申请】请批准租用10月12日外部培训场地（预算4800元）

张总：

您好。为保障新员工入职培训（10月12日，约60人），公司内部会议室
容量不足，行政部拟租用××酒店会议室半天，费用4800元（含投影与茶歇，
两家比价见附件）。

拟请您批准：
1. 场地租用立项；
2. 费用4800元从培训预算列支。

妥否，请批示。附件为报价对比与场地照片。谢谢！

李×× | 行政部
分机8012
```

**要点**：内部邮件申请同样遵循“一文一事、明确请求、附件支撑、结尾期复”，实质就是邮件版请示。

## 四、模板三：礼貌催办（平行/对外）

```text
主题：【跟进】办公家具报价确认（烦请9月25日前回复）

王经理：

您好！9月18日发送的办公家具询价清单（邮件附下），不知贵司评估
进展如何？因我方需在9月底前完成比价上报，烦请于9月25日（星期四）
前反馈报价或告知预计时间。

如需求清单需要进一步说明，我随时配合。感谢支持！

李×× | ××科技有限公司行政部
电话：010-××××××××
```

**要点**：催办邮件不指责、只重申事实与时限；主题保留原事项便于检索；语气用“烦请/感谢支持”。

## 五、模板四：求职自荐（对外个人）

```text
主题：应聘行政主管——李××（5年行政经验）

××公司人力资源部：

您好！我从贵司官网看到行政主管岗位招聘信息，结合5年行政统筹经验
（负责过300人规模公司的采购、会议与办公环境管理），认为与岗位要求
匹配，现投递简历。

核心经历简述：
1. 建立供应商比价机制，年采购成本降低约12%；
2. 统筹公司级会议与活动年均40场次以上；
3. 持有企业人力资源管理师三级证书。

附件为我的简历，期待有机会面谈。感谢阅读！

此致
敬礼

李××
电话：138-××××-×××× | 邮箱：li.xx@example.com
```

## 六、常见错误对照

| 错误 | 后果 | 改正 |
|---|---|---|
| 主题只写“您好”“请查收” | 收件人无法判断优先级，检索困难 | 主题含事项标签+事由+期限 |
| 一封邮件谈三件事 | 对方无法逐条处理与回复 | 一事一邮件 |
| 正文大段背景、请求在最后 | 重要事项被淹没 | 结论先行，第一句说请求 |
| 无署名或署名无联系方式 | 对方想电话沟通却找不到人 | 签名档含职务、公司、电话 |
| 催办邮件带情绪（“怎么还没回复”） | 损害合作关系 | 重申事实与时限，语气礼貌 |
| 全部收件人放“收件人”栏 | 回复全员刷屏，责任不清 | 主责任人放收件人，知情方放抄送 |
