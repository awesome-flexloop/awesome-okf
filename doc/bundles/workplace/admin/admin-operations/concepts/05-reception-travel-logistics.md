# 接待、差旅与后勤保障

## 是什么

这是行政「对外窗口」与「对内保障」两类工作的合集（F-007、F-008、F-009）：接待和差旅是低频高规格的「项目制」工作，后勤是高频琐碎的「运营制」工作。两类工作的共同能力底座是**供应商管理**与**应急预案**。

## 一、接待管理（F-007）

商务接待（客户、供应商、合作伙伴）与政企接待（政府部门、考察团）的标准流程：

1. **接任务**：搞清五要素——来访单位与人数、带队人职务、来访目的、时间、接待规格（由领导确定）；
2. **做方案**：行程表（精确到分钟：接站、会谈、参观、用餐、住宿、送站）、责任人分工、预算；
3. **落地预订**：车辆（公司车/网约车/商务车租赁）、酒店（协议价）、餐厅（包间、菜单、忌口）、会议室布置；
4. **现场执行**：提前 30 分钟到位迎接；引导路线；座次安排（乘车、会谈、餐桌座次有惯例，拿不准提前请示）；拍照留档；
5. **收尾**：费用结算、发票、接待小结；重要客户回访由业务部门衔接。

政企接待额外注意：守纪律——按公司差旅与接待标准执行，不超标、不铺张；通知与报备流程走全。

## 二、差旅管理（F-008）

- **预订**：机票酒店统一渠道（OTA 企业版/差旅平台/协议酒店，F-020），既控价又免员工垫资；
- **标准**：公司差旅制度规定各级别交通工具舱位、酒店价格上限、餐补交通补标准；行政是标准执行者，超标部分按制度审批；
- **行程保障**：出差行程变动（改签、延误）提供 7×24 协助口径；紧急出差有快速预订通道；
- **报销衔接**：行程单、发票、审批单三单匹配后交财务。

## 三、后勤保障（F-009）

后勤是「办公环境正常运行」的一揽子事务，管理思路是**供应商分类 + 报修闭环**：

| 事项 | 供应商/对接方 | 管理动作 |
|------|--------------|---------|
| 办公场地 | 房东/物业 | 租赁合同到期提醒、租金物业费缴纳、续租谈判提前启动 |
| 网络电话 | 运营商 | 故障报修时限约定、备用网络（4G/5G 路由） |
| 水电 | 物业/公用事业 | 费用缴纳、跑冒滴漏巡查 |
| 保洁 | 保洁公司/阿姨 | 服务标准与频次、检查评分 |
| 绿植 | 绿植租摆公司 | 租摆比购买省心（含养护更换），月度检查 |
| 车辆 | 公车/网约车企业版/租赁 | 油卡 ETC、用车登记、违章处理；公车保险年检台账 |
| 宿舍/公寓 | 房东/公寓运营商 | 入住退宿登记、押金、安全检查 |
| 门禁钥匙 | 自制+锁匠/门禁厂商 | 钥匙登记、离职回收（与 HR 离职清单联动）、门禁权限表 |

**报修闭环**：统一入口（行政微信/群/OA 报修单）→ 响应时限约定（如水电急修 2 小时、一般维修 24 小时）→ 维修后报修人确认 → 月度统计高频问题（同一下水管三个月修五次 → 换管道）。

## 常见坑与边界

- **接待方案不落地**：行程表排得漂亮但没确认司机、没留餐厅电话——接待拼的是每个环节都有 B 计划（航班延误备车、会议室冲突备场）。
- **座次礼仪出错**：重要场合座次是政治，拿不准就提前请示领导秘书，别自己发挥。
- **后勤全靠临时找人**：没有供应商库，坏了再网上搜电话，价格响应双失控；平时建好分类供应商台账（名称、联系人、价格、响应时限）。
- **差旅标准因人而异**：标准执行不一致最容易引发内部不公投诉，制度面前一视同仁，超标走审批留痕。
- **忽视安全责任**：宿舍消防、食堂/团餐食品安全、车辆安全都有实体责任，供应商合同要约定安全责任，现场定期检查。
