# 固定资产盘点表与用印登记表模板

> 说明：以下模板为原创通用表格，可直接复制到 Excel/在线表格使用。行政台账的核心是「实时更新 + 定期盘点 + 责任到人」。

## 一、固定资产台账（一物一行）

| 资产编号 | 资产名称 | 规格型号 | 购置日期 | 金额（元） | 供应商 | 存放地点 | 使用人 | 状态 | 备注 |
|---------|---------|---------|---------|-----------|--------|---------|--------|------|------|
| GD-2026-001 | 笔记本电脑 | XX 品牌 i7/16G | 2026-03-10 | 5800 | XX 公司 | 研发部 | 张三 | 在用 | 工号 A1023 |
| GD-2026-002 | 打印机 | A3 彩色激光 | 2026-01-15 | 4200 | XX 办公 | 打印区 | 公用 | 在用 | |

填写要点：编号规则统一（GD-年份-序号）；资产到岗即贴标即录账；状态字段固定为「在用/闲置/维修/报废」。

| 资产编号 | 名称 | 使用人（台账） | 存放地点（台账） | 实盘情况 | 盘盈/盘亏 | 差异原因 | 处理意见 |
|---------|------|--------------|----------------|---------|----------|---------|---------|
| | | | | □ 账实相符 □ 找不到 □ 损坏 | | | |
| 盘点人签字：____ | 监盘人签字：____ | 日期：____ | 审批：____ | | | | |

盘点流程：账面导出 → 实地逐项核对（见物就贴/扫码）→ 差异逐项查因（借用未登记/报废未销账/丢失）→ 盘盈盘亏报批 → 台账更新。

## 四、用印登记表（核心风控表）

| 日期 | 文件名称 | 用印类型（公章/合同章/财务章/其他） | 份数 | 对方单位 | 用印事由 | 经办人（签字） | 审批人（签字） | 备注 |
|------|---------|----------------------------------|------|---------|---------|--------------|--------------|------|
| 2026-09-01 | XX 服务合同 | 合同专用章 | 2 | XX 科技有限公司 | 服务采购签订 | | | 合同编号 HT-2026-015 |

铁律：**无审批不盖章、不盖空白件、章不外带（特批且保管人陪同除外）**。审批单与合同文件随登记表归档。
