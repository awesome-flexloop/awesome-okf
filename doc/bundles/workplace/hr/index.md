# 👔 人力资源（HR）

本分组收录人力资源岗位系统进修的知识包，按“先定位、再建体系、后守底线”的学习顺序组织：职业地图解决“往哪发展、考什么证”，六大模块与三支柱解决“HR 工作的知识体系是什么”，劳动法律合规解决“哪些动作有法定标准与法律风险”。法规数字（试用期、经济补偿、加班费、社保费率、仲裁时效等）逐条挂全国人大、人社部、国务院官方信源。

## 阅读路径

- **入行/转行**：先读 [hr-profession-map](hr-profession-map/index.md) 明确通道与证书，再以 [hr-six-modules](hr-six-modules/index.md) 建立知识体系，遇到具体法规问题查 [labor-law-compliance](labor-law-compliance/index.md)。
- **在岗提升**：直接从 [hr-six-modules](hr-six-modules/index.md) 的模块卡片查漏补缺，配合 examples 清单模板用于日常工作。
- **风险排查**：处理入离职、加班、工伤、争议前，必读 [labor-law-compliance](labor-law-compliance/index.md) 对应概念卡与合规自检清单。
- **行政联动**：入离职行政手续与办公物资配合，交叉阅读行政组 [行政管理实务](../admin/admin-operations/index.md) 与 [公文写作](../admin/official-writing/index.md)。
