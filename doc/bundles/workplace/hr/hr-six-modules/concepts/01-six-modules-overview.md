# 人力资源管理六大模块总览

## 是什么

六大模块是中国人力资源管理职业教育中通行的职能地图：**人力资源规划、招聘与配置、培训与开发、绩效管理、薪酬福利管理、劳动关系管理**（F-001）。它回答「HR 这门职业到底管哪些事」，是进修时的目录框架——先知道全景，再逐个深入。

六大模块按「选、育、用、留」组织成人才管理闭环（F-002）：

| 模块 | 一句话定位 | 对应闭环 | 关键产出物 |
|------|-----------|---------|-----------|
| 人力资源规划 | 算清楚要多少人、什么结构、花多少钱 | 前置 | 定编定岗表、人力预算、制度汇编、继任计划 |
| 招聘与配置 | 把合适的人在合适的时间放到合适的岗 | 选 | JD、面试评估表、录用通知、配置方案 |
| 培训与开发 | 让员工能力跟上岗位与业务需要 | 育 | 培训计划、课程体系、培训记录与评估 |
| 绩效管理 | 对齐目标、评价贡献、驱动改进 | 用 | 绩效方案、目标表、考核结果、面谈记录 |
| 薪酬福利管理 | 用钱与福利认可贡献、控制人力成本 | 留 | 薪酬结构、调薪方案、工资表、社保福利台账 |
| 劳动关系管理 | 维系合法、稳定、可预期的雇佣关系 | 留 | 劳动合同、员工手册、奖惩制度、争议处理记录 |

## 为什么这样分：模块之间的咬合关系

六个模块不是六个孤岛，而是一条因果链：

- **规划定盘子**：定编与预算决定招聘量（F-003）；
- **招聘补缺口**：进来的人决定培训需求（F-004）；
- **培训补能力**：能力差距通过绩效暴露（F-005）；
- **绩效评贡献**：考核结果驱动薪酬调整与培训改进（F-006）；
- **薪酬做兑现**：薪酬福利与劳动关系管理共同决定员工「留不留」（F-007、F-008）。

任何一个模块的制度设计都要考虑对其他模块的传导。例如：绩效方案如果只打分不应用，就退化为形式；薪酬如果不与绩效挂钩，激励就断链；招聘标准如果脱离岗位分析（规划），招进来的人必然用不好。

## 怎么做：学习者按模块建立自己的「产出物库」

进修六大模块最有效的方法不是背定义，而是为每个模块收集/制作可复用产出物：

1. **规划**：一份定编表模板 + 一份人力预算表；
2. **招聘**：一套 JD 模板 + 结构化面试问题库（见 [examples/03](../examples/03-jd-interview-templates.md)）；
3. **培训**：一份年度培训计划模板 + 新员工培训清单；
4. **绩效**：一份目标设定表 + 绩效面谈提纲（见 [examples/02](../examples/02-performance-cycle.md)）；
5. **薪酬**：一张薪酬结构图 + 工资核算流程（社保费率等合规数字见同组 [劳动法律合规实务](../../labor-law-compliance/index.md)）；
6. **劳动关系**：劳动合同签订/续订/解除检查清单（见同组合规束）。

## 常见坑与边界

- **把知识地图当组织架构**：模块是学习框架，不是岗位说明书。中小企业一个人全包六个模块，大企业设招聘经理、薪酬经理等专岗，还有企业按三支柱分工（见 [02 三支柱](02-three-pillars.md)）。
- **重「术」轻「法」**：六大模块里凡是涉及钱、合同、工时、社保的动作，都有法律红线。管理方法可以学先进，法规底线不可突破——法规错误代价是赔偿与仲裁。
- **模块割裂**：只管招聘不管入职融入、只做考核不做反馈、只发工资不做成本分析，都是模块没有咬合的表现。
