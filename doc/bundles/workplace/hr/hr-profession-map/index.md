# HR 职业地图与进修路径知识包

本知识包面向想要系统进修、提升职业能力的行政人事从业者，回答三个问题：行政人事岗位的版图是什么样、证书该怎么考、能力该按什么路线提升。内容覆盖企业人力资源管理师退出国家职业资格目录后的证书制度现状（人社厅发〔2020〕80号、社会化职业技能等级认定、osta 联网查询）、经济师人力资源职称独立序列、HR/行政岗位层级与三支柱分工，以及可直接照做的分阶段进修清单与报考防骗指南。

> 阅读提示：本包政策事实以人社部、中国人事考试网等官方信源为准（截至 2026-09）；岗位设置类内容来自公开招聘信息的市场实践汇总，标注为市场实践而非法规。证书与补贴政策属地差异大，报考前以属地人社部门公告为准。

## 知识包立场

| 维度 | 本知识包的处理方式 |
|------|------------------|
| 内容性质 | 面向职业进修的岗位地图、政策现状与学习路线指南 |
| 事实与观点 | 政策与证书事实入 [facts.md](facts.md)（官方信源）；岗位版图类内容标注为市场实践；解释性判断入 [insights.md](insights.md) |
| 时效处理 | 政策类事实标注发文号与时点，设置 stale_after；属地差异明确提示以当地公告为准 |
| 防骗立场 | 不推荐任何培训机构；提供官方渠道核验方法，对「包过/挂靠/换证」话术明确警示 |
| 信源原则 | 只登记人社部、中国政府网、中国人事考试网、osta 等官方渠道与公开招聘平台信息 |
