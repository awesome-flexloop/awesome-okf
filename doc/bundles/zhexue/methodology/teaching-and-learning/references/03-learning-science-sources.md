# 学习科学信源：机构级循证策略

> 本束 [学习科学循证策略](../concepts/04-evidence-based-learning.md) 与 [学习理论谱系](../concepts/02-learning-theory-spectrum.md) 的机构级信源登记。均为公开可访问页面/文档。

## 循证学习策略

| 策略 | 信源 | 关键证据 |
|------|------|---------|
| 检索练习/测试效应 | Manchester FSE Teaching Academy[^manchester] | 练习者显著优于重读/高亮/摘录者 |
| 间隔/睡眠巩固 | 北师大认知神经科学与学习国家重点实验室[^bnu-brain] | 休息与睡眠增强学习、减少遗忘；间隔检索优于连续练习 |
| 交错/样例 | Manchester[^manchester] | spacing/interleaving/worked-example 四效应 |
| 主动学习 | NTU Singapore[^ntu] | think-pair-share、同伴互教、问题式学习 |
| 认知负荷 | 中国教育新闻网"脑友好"教学[^brain-friendly] | 内在/外在/关联负荷三分；支架；双重编码 |

## 信源性质说明

- 全部为机构级公开信源（高校教学中心/国家重点实验室/教育部系统媒体）。
- 循证策略的效应量表述保持原信源口径，本束不叠加未经验证的量化结论。
