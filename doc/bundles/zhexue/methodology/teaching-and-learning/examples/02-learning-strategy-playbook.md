# 学习策略实操手册

> 用途：学习者（或教者指导学生）把学习科学循证策略落到日常执行。策略依据见本束 [学习科学循证策略](../concepts/04-evidence-based-learning.md)。

## 策略一：检索练习（测试效应）——把"读"换成"考自己"

**执行步骤**：
1. 学完一个单元后，合上材料，写下/说出你能回忆的一切（自由回忆 5 分钟）。
2. 对照材料找出遗漏与错误，只重读遗漏处。
3. 用闪卡（Anki/手写卡）做主动回忆：正面问题→想答案→翻面核对。
4. 自测频率：当天、次日、一周后各一次（配合间隔策略）。

**何时用**：任何需要长期保留的知识。**何时不用**：首次接触全新领域时（先建立图式再检索）。

## 策略二：间隔与交错——把"突击"换成"分散+混合"

**执行步骤**：
1. 把 3 小时学习拆成 3 个 1 小时，跨天分布（睡眠巩固记忆）。
2. 复习时混合题型/主题（如数学混合刷题、外语混合话题），不按章节顺序。
3. 用日历排定"间隔复习日程"而非"考前突击日"。

**何时用**：备考、技能训练、长期学习。**何时不用**：需要快速熟悉单一流程时（集中样例更高效）。

## 策略三：费曼讲解（以教促学）——把"懂"换成"讲得出"

**执行步骤**（对应本库 [费曼学习法+AI](../../feynman-ai-learning/index.md)）：
1. 选一个概念，用最简单的话向"初中生"讲解（可对 AI 讲，让 AI 扮演初学者）。
2. 讲卡壳处 = 理解盲区，标记之。
3. 回到材料补盲区，再讲一遍，直到无卡壳。
4. 用生活类比重述，检验是否真正理解本质。

**何时用**：概念性、原理性知识的内化。**何时不用**：纯程序性技能（直接练）。

## 策略四：认知负荷管理——把"硬扛"换成"拆解"

**执行步骤**：
1. 复杂任务先拆成可控步骤（支架式分解）。
2. 消除学习材料中的冗余干扰（外在负荷）。
3. 图文结合（双重编码），用概念图组织关系。
4. 每次只聚焦一个核心子任务（避免关联负荷超载）。

**何时用**：内容复杂、容易过载时。**何时不用**：简单任务，拆解反而浪费时间。

## 每日学习自检清单

- [ ] 今天有"输出"环节吗（自测/讲解/做题）？——不只是阅读
- [ ] 今天的学习是分散的还是突击的？
- [ ] 我在哪里"卡壳"了？卡壳是否被标记并回补？
- [ ] 我能用自己的话解释今天学的核心概念吗？
