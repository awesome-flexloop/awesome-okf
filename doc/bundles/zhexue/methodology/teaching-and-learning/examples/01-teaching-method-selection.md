# 教学法选型对照表

> 用途：教者在设计一堂课/一门课时，按"目标 → 学习者 → 场景"三步选择教学法，并预设失效条件。依据见本束 [教学法流派与实践](../concepts/03-teaching-methods.md)。

## 步骤一：确定学习目标层级

| 目标层级 | 典型问题 | 倾向方法 |
|---------|---------|---------|
| 记忆/识别 | "学生需要知道基本概念" | 讲授 + 检索练习 |
| 理解/解释 | "学生要能用自己的话解释" | 苏格拉底式 + 费曼互教 |
| 应用/操作 | "学生要会做" | 样例 + 练习 + 支架式 |
| 分析/评价 | "学生要能批判与判断" | 苏格拉底式 + 项目式 |
| 创造/迁移 | "学生要能解决新问题" | 项目式 + 探究式 + 翻转课堂 |

## 步骤二：评估学习者状态

| 学习者状态 | 影响 | 调整 |
|-----------|------|------|
| 前备知识薄弱 | 认知负荷高 | 先讲授/样例建立图式，再讨论 |
| 自主性弱 | 需要外部结构 | 支架式、明确步骤、频繁反馈 |
| 自主性强 | 可放权 | 项目式、探究式、翻转课堂 |
| 动机低 | 外驱压制内在动机 | 检查自主/胜任/归属三需求（SDT） |

## 步骤三：按场景约束收敛

| 场景约束 | 排除项 | 保留项 |
|---------|--------|--------|
| 大班（50+） | 苏格拉底式深度对话 | 讲授 + think-pair-share + 检索练习 |
| 小班（<20） | 纯讲授浪费互动 | 苏格拉底式 + 支架式 + 协作 |
| 无课前自学条件 | 翻转课堂（前提塌陷） | 课堂内讲授+练习闭环 |
| 跨学科真实问题 | 单科讲授 | 项目式学习 |

## 失效条件自查（每法必答）

- [ ] 讲授式：是否有检索/输出环节？还是只"讲完了"？
- [ ] 苏格拉底式：学生是否已有讨论所需的概念储备？
- [ ] 支架式：支架何时撤除？是否造成依赖？
- [ ] 项目式：学习目标是否明确？评估是否跟进产出？
- [ ] 翻转课堂：课前自学是否被验证？课堂是否真的用于互动？

> **红线**：选型改变的是"教的形式"，真正起效的是"学的机制"（输出、检索、建构、迁移）是否被激活。形式相同而机制未变，等于没换。
