# 教与学

> 教与学不是两个对立的活动，而是围绕"学习者自身结构改变"这一唯一事件的两个角色——**学是这个事件本身，教是使这个事件更可能、更高效发生的条件工程**。

## 概述

本知识包对"教与学"做系统性综述：它们是什么（中西定义谱系）、怎么做（教学法与学习科学循证策略）、本质是什么（第一性原理三重命题）、区别与联系（教学相长）、真问题真目标真需求（动机与价值层）、以及 AI 时代的变革。内容横跨中国教学论传统（《学记》《论语》、叶圣陶）与西方教育哲学/学习科学（杜威、皮亚杰、维果茨基、认知负荷理论、检索练习），归属方法论分组，与 [费曼学习法+AI](../feynman-ai-learning/index.md) 构成"学的方法论 → 教与学本质"的知识闭环。

**架构类型**: 多源综合综述（概念+实操+信源三层，含可复现实操材料）

## 关键洞察

1. **学的不可代理性**：学习者的改变只能发生在自身结构上，无人可代——一切"教"的设计最终要回到"让学习者自己的建构发生"。
2. **教是条件工程**：教无法直接产生结果，只能创设条件；教的评价标准是"学是否发生"，而非"讲得是否好"。
3. **教学相长是机制不是口号**：《学记》"学然后知不足，教然后知困"被费曼学习法与检索练习效应现代科学化——输出驱动输入，教与学在这一点上合流。
