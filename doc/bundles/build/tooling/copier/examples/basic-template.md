# 基础模板创建与使用

本示例从零开始创建一个 Copier 模板，并用它生成一个 Python 项目。覆盖模板目录结构、copier.yml 配置、Jinja2 模板文件编写、命令行生成项目的完整流程。[^copier-src]

## 1. 创建模板目录结构

创建以下目录结构：

```
python-template/
├── copier.yml
├── README.md.jinja
├── pyproject.toml.jinja
├── .gitignore.jinja
└── {{package_name}}/
    ├── __init__.py.jinja
    └── main.py.jinja
```

注意目录名 `\{{package_name}}/` 使用了 Jinja2 变量语法，会根据用户输入动态渲染。

## 2. 编写 copier.yml

```yaml
# copier.yml
_templates_suffix: ".jinja"
_min_copier_version: "9.0.0"
_message_after_copy: |
  ✅ 项目 {{ project_name }} 创建成功！
  下一步：
    cd {{ project_name }}
    pip install -e .
    git init && git add . && git commit -m "Initial commit"

project_name:
  type: str
  help: "项目名称（kebab-case）"
  default: "my-python-project"

package_name:
  type: str
  help: "Python 包名（snake_case，自动从 project_name 推导）"
  default: "{{ project_name|replace('-', '_') }}"

project_description:
  type: str
  help: "项目简短描述"
  default: "A Python project generated by Copier"

author_name:
  type: str
  help: "作者姓名"

author_email:
  type: str
  help: "作者邮箱"

python_version:
  type: str
  help: "Python 版本"
  default: "3.12"
  choices:
    - "3.10"
    - "3.11"
    - "3.12"
    - "3.13"

use_docker:
  type: bool
  help: "是否包含 Dockerfile？"
  default: false
```

## 3. 编写模板文件

**README.md.jinja**：
```jinja
# {{ project_name }}

{{ project_description }}

## 安装

```bash
pip install -e .
```

## 使用

```python
import {{ package_name }}
{{ package_name }}.main()
```

## 开发

```bash
pip install -e '.[dev]'
pytest
```
{% if use_docker %}
## Docker

```bash
docker build -t {{ project_name }} .
docker run --rm {{ project_name }}
```
{% endif %}

## 作者

\{{ author_name }} <\{{ author_email }}>
```

**pyproject.toml.jinja**：
```jinja
[build-system]
requires = ["setuptools>=68.0", "wheel"]
build-backend = "setuptools.build_meta"

[project]
name = "{{ project_name }}"
version = "0.1.0"
description = "{{ project_description }}"
requires-python = ">={{ python_version }}"
authors = [
    { name = "{{ author_name }}", email = "{{ author_email }}" }
]

[project.scripts]
{{ package_name }} = "{{ package_name }}.main:main"

[tool.setuptools.packages.find]
include = ["{{ package_name }}*"]
```

**.gitignore.jinja**：
```
__pycache__/
*.py[cod]
*.egg-info/
dist/
build/
.eggs/
*.egg
.env
.venv/
.pytest_cache/
```

**\{{package_name}}/__init__.py.jinja**：
```jinja
"""{{ project_description }}"""

__version__ = "0.1.0"
```

**\{{package_name}}/main.py.jinja**：
```jinja
"""Main entry point for {{ project_name }}."""


def main():
    """Run the main application."""
    print("Hello from {{ project_name }}!")


if __name__ == "__main__":
    main()
```

## 4. 生成项目

### 交互式生成

```bash
copier copy ./python-template ./my-demo-project
```

Copier 会依次询问每个问题：

```
🎤 项目名称（kebab-case）
   my-python-project

🎤 Python 包名（snake_case，自动从 project_name 推导）
   my_python_project

🎤 项目简短描述
   A demo project

🎤 作者姓名
   Zhang San

🎤 作者邮箱
   zhang@example.com

🎤 Python 版本
   3.12

🎤 是否包含 Dockerfile？ (y/N)
   No

✅ 项目 my-python-project 创建成功！
```

### 非交互式生成（CI/CD 友好）

```bash
copier copy --defaults --overwrite \
  -d project_name=demo-app \
  -d author_name="Bot" \
  -d author_email="bot@example.com" \
  ./python-template ./demo-app
```

## 5. 查看生成结果

生成后的项目结构：

```
my-demo-project/
├── .copier-answers.yml
├── .gitignore
├── README.md
├── pyproject.toml
└── my_python_project/
    ├── __init__.py
    └── main.py
```

检查生成的文件内容（以 pyproject.toml 为例）：
```toml
[build-system]
requires = ["setuptools>=68.0", "wheel"]
build-backend = "setuptools.build_meta"

[project]
name = "my-python-project"
version = "0.1.0"
description = "A demo project"
requires-python = ">=3.12"
authors = [
    { name = "Zhang San", email = "zhang@example.com" }
]

[project.scripts]
my_python_project = "my_python_project.main:main"

[tool.setuptools.packages.find]
include = ["my_python_project*"]
```

### answers 文件

`.copier-answers.yml` 记录了所有答案，用于后续更新：

```yaml
_commit: v0.0.0
_src_path: /path/to/python-template
project_name: my-python-project
package_name: my_python_project
project_description: A demo project
author_name: Zhang San
author_email: zhang@example.com
python_version: "3.12"
use_docker: false
```

## 6. 使用远程模板

模板存放在 Git 仓库后，可以直接通过 URL 使用：

```bash
# GitHub 快捷方式
copier copy gh:yourname/python-template my-project

# 指定版本标签
copier copy -r v1.0.0 gh:yourname/python-template my-project
```
