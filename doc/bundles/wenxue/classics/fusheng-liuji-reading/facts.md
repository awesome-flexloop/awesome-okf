## 作者与生平

| 编号 | 事实内容 |
|------|----------|
| F-001 | 《浮生六记》作者沈复，字三白，号梅逸，清代苏州府长洲县人。 |
| F-002 | 沈复约生于乾隆二十八年（1763年）。 |
| F-003 | 沈复卒年无确载，学界并存卒于道光五年（1825年）之后与卒于道光十二年（1832年）之后等异说。 |
| F-004 | 沈复一生未应科举，以游幕（充当官府幕僚）、卖画、经商为生。 |
| F-005 | 沈复之妻陈芸为其表姐，年长沈复十个月。 |
| F-006 | 陈芸因血疾于嘉庆八年（1803年）病逝，时年约四十一岁。 |
| F-007 | 沈复与陈芸育有一子一女，子名逢森，女名青君。 |
| F-008 | 《坎坷记愁》卷记载沈复一生遭遇多次贫困、病痛与亲人离世。 |
| F-009 | 嘉庆十三年（1808年），沈复随册封琉球国王正使齐鲲、副使费锡章出使琉球。 |

## 成书与书名

| 编号 | 事实内容 |
|------|----------|
| F-010 | 《浮生六记》书名出自李白《春夜宴桃李园序》"浮生若梦，为欢几何"。 |
| F-011 | 学界一般认为《浮生六记》成书于嘉庆十三年（1808年）前后。 |
| F-012 | 沈复自述《浮生六记》共有六记，现存四记，后二记《中山记历》《养生记道》佚失。 |
| F-013 | 《浮生六记》现存四卷为《闺房记乐》《闲情记趣》《坎坷记愁》《浪游记快》。 |

## 版本流传

| 编号 | 事实内容 |

| F-018 | 1923至1924年，俞平伯校点本《浮生六记》由朴社出版，成为通行定本。 |
| F-019 | 俞平伯在校点本序中称《浮生六记》为"纯美的水晶"。 |

## 伪书公案

| 编号 | 事实内容 |
|------|----------|
| F-020 | 1935年8月，上海世界书局《美化文学名著丛刊》刊行王文濡（字均卿，1867-1935）整理的"足本"《浮生六记》，补入题名《中山记历》《养生记逍》二卷。 |
| F-021 | 1978年，吴幅员比勘李鼎元《使琉球记》后指出"足本"补卷与史实不合，为作伪之证。 |
| F-022 | 1980年，杨仲揆著文论证"足本"补卷系伪作。 |
| F-023 | 1980年，郑逸梅忆述王文濡曾请其代拟补卷文字。 |
| F-024 | 1989年，王瑜孙撰文披露补卷作者为黄楚香，作伪报酬为二百大洋。 |
| F-025 | 蔡根祥考证补卷作伪时间约在1932年前后，并指出《养生记逍》部分文字抄自向恺然太极拳文章。 |
| F-026 | "足本"补卷存在时间矛盾：卷五所记嘉庆五年（1800年）出使琉球事与卷四所记同年同月同日之事相互冲突。 |
| F-027 | 林语堂早年即从补卷使用新名词及提及太极拳等方面提出疑伪。 |
| F-028 | 陈寅恪提出"伪材料"论，认为伪材料经适当处理亦可成为研究史料。 |

## 佚文发现

| 编号 | 事实内容 |
|------|----------|
| F-029 | 2005年秋，收藏家彭令在南京地摊购得清代钱泳手稿《记事珠》。 |
| F-030 | 钱泳《记事珠》手稿内含《册封琉球国记略》一篇，约6200字，内容与出使琉球相关。 |
| F-031 | 学界疑《册封琉球国记略》摘抄自沈复《浮生六记》佚卷《中山记历》（一说原拟名《海国记》）。 |

| F-033 | 学界对钱泳抄本是否确为沈复卷五原文仍存争议，苗怀明持审慎态度。 |

## 内容事实

| 编号 | 事实内容 |
|------|----------|
| F-040 | 《闲情记趣》开篇"余忆童稚时，能张目对日，明察秋毫"，后节选入中学语文教材，题作《童趣》。 |
| F-041 | 《闲情记趣》中有"夏蚊成雷，私拟作群鹤舞空"句。 |
| F-042 | 《闺房记乐》记载陈芸婚前为沈复藏暖粥的片段，常被称引为名段。 |
| F-043 | 《闺房记乐》记载七夕之夜二人镌"愿生生世世为夫妇"图章二方（朱文、白文各一）。 |
| F-044 | 《闺房记乐》记载陈芸论李白、杜甫诗，称李诗宛如姑射仙子。 |
| F-045 | 《坎坷记愁》记载陈芸去世后回煞之夜沈复守候痛哭的片段。 |
| F-046 | 《浪游记快》为现存四卷中篇幅最大的一卷，记载沈复的游历见闻。 |
