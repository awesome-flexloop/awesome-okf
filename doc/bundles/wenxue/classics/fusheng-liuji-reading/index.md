# 《浮生六记》阅读教程

本知识包（bundle）是面向普通读者的《浮生六记》阅读指南，基于公开信源（中华书局三全本前言、陈毓罴《浮生六记研究》、光明日报《真伪之间》等）整理，涵盖作者生平、六记结构、文本流传与伪书公案。与学术研究专著互补，本bundle侧重"怎么读"而非"版本怎么考"，同时给对版本考据感兴趣的读者一条可深入的路径。

## 🚀 快速开始

如果你是零基础读者（从未读过《浮生六记》）：

1. 先读[为什么要读《浮生六记》](concepts/00-why-read.md)了解阅读价值
2. 打开[阅读计划与进度安排](examples/02-reading-plan.md)，按计划开始读正文（建议从《闺房记乐》入手）
3. 读完第一遍后，回看[六记结构与佚失二记](concepts/02-six-records-structure.md)与[芸娘](concepts/03-yun-niang.md)

如果你已读过或想深入了解：

1. 从[文本流传与版本史](concepts/04-textual-history.md)开始，理解版本脉络
2. 读[芸娘：被赞美与被书写的主体](concepts/03-yun-niang.md)，对照两种读法
3. 跟着[名段精读示例](examples/01-close-reading.md)重读经典段落
4. 参考[闲情雅趣与生活美学](concepts/06-life-aesthetics.md)拓展理解

如果你对版本考据感兴趣：

1. 读[伪书公案与辨伪方法](concepts/05-forgery-case.md)，掌握五重证据链
2. 跟着[佚失二记与钱泳抄本考](examples/03-lost-records.md)梳理争议
3. 深入[信源参考](references/index.md)各信源，自行比对判断
