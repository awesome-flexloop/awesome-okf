# 💊 道医（Daoyi）知识包

本分组收录与"道医"（道家、道教传统与中国传统医学交汇的医学文化）相关的 OKF 知识包。所谓道医，不是独立于中医的另一套医学体系，而是"道—理—术"三层连续体：以《道德经》之道为哲学本体，以《黄帝内经》之理为医学理论，以医术与养生方术为实践层面（详见束内概念文档）。

本分组知识包以**权威原文 + 可核验信源**为原则：每部经典配已实际访问核验的在线全文链接（识典、维基文库、ctext 等）与权威纸本点校本指南；托名、扶乩、辑佚类文献两说并陈；不收录未经证实的说法。

- `daozang-yangsheng/`：道藏养生文献专题（《云笈七签》《道枢》《修真十书》导引服气类）

## 内容边界提示

本分组所有内容为**文化与文献研究**，不构成医疗、诊断、用药或练功指导；古籍中方药、针灸、导引、内丹等内容均属历史文献，未经现代医学验证，切勿据以自行施治或练习。
