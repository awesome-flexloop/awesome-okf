# 道医经典阅读教程

本知识包（bundle）是面向中文读者的**道医经典权威阅读指南**。"道医"不是独立于中医的另一套医学，而是道家、道教传统与中国传统医学两千余年交汇形成的文化—实践连续体：葛洪、陶弘景、孙思邈这些道门中人同时也是医学史关键人物；《素问》《灵枢》以道论医，《云笈七签》以道藏收医方；马王堆、张家山、天回出土的方技文献显示医学与神仙、导引、房中本为一家。

本束采用**广义道医**框架，覆盖六层文献：①中医元典的道家根源；②道门医家著述；③道藏医书与养生文献；④内丹与身神传统；⑤出土方技；⑥医道会通流派与现代学术。所有在线全文链接均经实际访问核验，所有纸本指南均给出版社、年份与 ISBN；托名、扶乩、辑佚类争议文献两说并陈。

## 🎯 内容边界与非医疗声明

> **本知识包为文化与文献研究内容，不构成医疗、诊断、用药、针灸或练功（导引、调息、内丹、静功）指导。**
>
> 古籍中所载方药、灸法、服食、辟谷、房中等内容均属历史文献，反映特定时代的知识与信仰，**未经现代医学验证，部分内容（如外丹服食、符咒疗法）已知具有健康风险**。任何健康问题请咨询具备资质的现代医疗机构与执业医师。陈撄宁《静功疗养法》等近现代疗养文献同样按历史文献处理，不代表现代医疗建议。
>
> 本束对符、咒、斋、禁等外周圆内容仅作学术描述，不提供操作方法。
