# 架构洞察（Architecture Insights）

> 基于事实清单（facts.md，116 条）与三路公开信源调研得出，每条洞察遵循四元组结构（陈述/证据/反常识/行动），证据栏引用 facts.md 事实编号。

## 洞察1：道医不是独立医学体系，而是"道—理—术"三层连续体

| 四元组 | 内容 |
|--------|------|
| **陈述** | 古文献中并无"道医"名目，相近说法是"道士医师"（AX-015）；现代学术界定的道教医学，是道教信仰与中国传统医学交汇形成的文化—实践连续体，可用三层结构描述：道（《道德经》本体论）—理（《黄帝内经》医理）—术（医术与养生方术）（AX-016）。吉元昭治三圆模型给出技术构成：中心圆为汤液、本草、针灸（与传统医学共享），中间圆为导引、调息、内丹、辟谷、内视、房中，外周圆为符、占、签、咒、斋、禁、祭祀（AX-014）。 |
| **证据** | AX-015（词源考：古无"道医"提法）、AX-016（道—理—术三层）、AX-014（三圆模型）、AX-013（盖建民"宗教医学"界定）、AX-012（丁贻庄1985定义）、AX-007（胡孚琛"道教医药学"）、CAN-004~CAN-009（医经元典为共享层） |
| **反常识** | 流行文化把道医想象成独立于中医的"另一套医学"（画符念咒、秘传丹方），但三圆模型显示中心圆技术与传统医学完全重合，差异集中在中间圆与外周圆；概念史上也是先有"道士医师"之称（AX-015），现代"道医"概念迟至1985年才由丁贻庄给出学术定义（AX-012）。 |
| **行动** | 教程按"六层文献"而非"道医 vs 中医对立"组织；阅读从共享医经层入门，再进入道藏养生与内丹专属层；外周圆技术（符咒斋禁）只作历史文化描述，不作任何实践指导，束根设非医疗声明。 |

## 洞察2：医道同源有制度与文本物证，不止是口号

| 四元组 | 内容 |
|--------|------|
| **陈述** | 医学与道教的交融在制度、文本、人物三个层面都有可核验物证：制度上，国家医政长期设宗教性医学科目——唐太医署咒禁科、元明太医院十三科含祝由科，至隆庆五年（1571）裁撤（AX-023）；文本上，隋官修《诸病源候论》不载方药而附"养生方导引法"，其导引内容与《抱朴子》《养性延命录》《云笈七签》同源（CAN-011、CAN-012），正统道藏长期收载医书约二十部，含《葛仙翁肘后备急方》《孙真人备急千金要方》（AX-021）；人物上，葛洪明言"古之初为道者，莫不兼修医术"（DAO-001）。 |
| **证据** | AX-023（祝由科沿革）、CAN-011、CAN-012（诸病源候论导引法互文）、AX-021（道藏收医书约二十部）、DAO-001、DAO-005（养性延命录入云笈七签卷32）、AX-009（《中国道教科学技术史》设"医·道同源"章）、AX-022（"十道九医"与《道医集成》分期） |
| **反常识** | "十道九医"常被当作浪漫传说，但制度物证（祝由科在国家医院存在数百年）与文本物证（官修医书直接收录道门导引法）表明医道交融曾是制度性事实；反过来，祝由科被裁撤（1571）也说明这套制度性交融在晚明已终结，不能据此把符咒疗法投射到现代医疗语境。 |
| **行动** | 概念页 01 用"制度—文本—人物"三条证据链讲医道同源；祝由、符咒内容严格限定为历史描述，所有涉医、涉术页面统一配非医疗提示。 |

## 洞察3：道医文献服从"层累造成"律，断代有硬方法

| 四元组 | 内容 |
|--------|------|
| **陈述** | 道医相关文献大量存在三种非常态文本形态：托名（《中藏经》托华佗、《太上老君养生诀》托"华佗授吴普"）、扶乩降著（《医道还元》1894年托名吕祖）、辑佚复原（《神农本草经》原书早佚，今传本为辑佚本）。断代有三类可操作硬方法：避讳字（"山药"避宋英宗赵曙讳，1064年以后）、著录首见（《中藏经》首见《宋史·艺文志》）、传本链追踪（《辅行诀》1918年购卷→1966年原卷毁→14种抄本传世）。 |
| **证据** | FRG-001（中藏经避讳字与著录）、FRG-002、FRG-003（辅行诀传本链与两说）、FRG-004（医道还元扶乩）、FRG-005（华佗神医秘传近代伪书）、CAN-007（神农本草经辑佚本性质）、DAO-006（太上老君养生诀托名）、FLW-002（扁鹊心书清刊已发现掺后人内容） |
| **反常识** | 书名题署"华佗""陶弘景""吕祖"不等于成书年代；但判为"伪书"也不等于内容无价值——《辅行诀》主流学术意见是"非近代伪，但不可能早到梁代"（FRG-003），其方药体系仍被专门研究。真伪是传本谱系问题，不是真假二分；"托名"在上古是著述方式，"扶乩降著"在清代是宗教写作方式，都需放回各自语境断代。 |
| **行动** | 设概念页 08（辨伪方法论）与信源页 references/04（辨伪登记表），五部争议书两说并陈并给阅读建议；每部经典介绍固定先给"成书年代/最早著录/传本形态"三要素，再谈内容。 |

## 洞察4：信源必须分级，在线平台与纸本点校本各有可靠层级

| 四元组 | 内容 |
|--------|------|
| **陈述** | 在线古籍平台可靠性层级为：识典（精校+白话译文）＞维基文库（白文本，标注校勘进度）＞ctext 主库＞diancang 典藏（FRG-007、SRC-001~004）。各平台有已核实的具体缺陷：ctext《本草纲目》res=161524 为 OCR 乱码不可用（CAN-017、SRC-003）；维基文库《伤寒论》页面自述方部未校（CAN-008、SRC-002）；diancang《云笈七签》为120/121卷系统，与道藏122卷本有卷次差异（DAO-011、SRC-004）；zysj.com.cn 遭博彩 SEO 污染，全站禁用（FRG-006）。纸本以人民卫生出版社"中医古籍整理丛书"与中华书局"道教典籍选刊"两套点校本为一级信源（CAN-022、DAO-024、SRC-009）。 |
| **证据** | FRG-006（污染站禁用）、FRG-007（平台优先级）、SRC-001~SRC-009（平台特征与纸本两套）、CAN-017（ctext 本草纲目乱码）、CAN-008（维基伤寒论未校）、DAO-011（diancang 卷次差异）、DAO-015（伍柳仙宗无在线权威全文，只能纸本） |
| **反常识** | "能搜到全文"不等于"文本可信"。在线全文最常见的风险不是缺字，而是无声改字——OCR 错字、卷次错配、底本不明，读者无从察觉。权威点校本的价值不在难读，而在校勘记交代了文本依据；反过来，道藏白文本（涵芬楼/三家本影印）虽"最原真"，却无标点无校记，不适合入门。 |
| **行动** | references/01 做"典籍×平台"矩阵并逐格标注缺陷与底本；概念页引用原文优先给识典/维基链接并注明底本性质；凡在线文本有已知缺陷或缺在线权威全文的（如《伍柳仙宗》），明确引导到纸本点校本。 |

## 洞察5：临床结构"先医药后符咒"，养生范式外丹让位于内丹

| 四元组 | 内容 |
|--------|------|
| **陈述** | 临床结构上，盖建民指出道教医学"融生理治疗、心理治疗、精神信仰治疗于一炉"，处置次序为"先医药，后符咒"（AX-005）；林富士道士医术四类（医者之术、养生之术、巫者之术、道教自创仪式疗法）中，医药始终是基础层（AX-010）。养生范式上，胡孚琛概括唐代以后内丹取代外丹、并转向重视肾脏（AX-007）：文献序列为《抱朴子》兼重修仙服食与外丹→《周易参同契》《悟真篇》立内丹经典→宋以后《性命圭旨》《伍柳仙宗》集内丹大成；医家侧同期兴起命门/肾命学说（张景岳"命门为水火之宅"、赵献可《医贯》命门论，FLW-004、FLW-005）。 |
| **证据** | AX-005（先医药后符咒）、AX-010（医术四类）、AX-007（内丹取代外丹、重肾脏）、AX-014（三圆层级）、DAO-001（抱朴子兼修医术）、DAO-012、DAO-013（参同契、悟真篇）、DAO-014、DAO-015（性命圭旨、伍柳仙宗）、FLW-004、FLW-005、FLW-007（景岳、献可、钦安的肾命/坎离话语） |
| **反常识** | 大众以为道医以画符念咒为主，文献次序恰恰相反——葛洪《肘后备急方》是实用救急方书，《抱朴子内篇》才兼论金丹；符咒在外周圆而非中心圆（AX-014）。另一层反常识：内丹经的铅汞、坎离、炉火话语高度隐喻，不能按外丹化学或人体解剖直读，否则会把修炼文本误读为药物学或生理学。 |
| **行动** | 概念页 03、05 按"医药基础层→养生中间层→信仰外周层"顺序叙述；丹经段落显式标注隐喻性质；全部方药、气功、内丹内容配非医疗声明，现代疗养文献（陈撄宁《静功疗养法》）标注"历史文献，非现代医疗指导"。 |

## 洞察6：阅读路径按"读者三档 × 文献六层"双维映射，最权威不等于最难入口

| 四元组 | 内容 |
|--------|------|
| **陈述** | 文献六层（中医元典道家根源／道门医家／道藏医书养生内丹／出土方技／医道流派／现代学术）与读者三档（零基础／中医基础／研究型）不是一一对应：零基础读者应从现代学术概论（盖建民《道教医学》，AX-001）与元典选读（《素问》《千金要方》识典精校本）进入，而非直接读道藏白文本或丹经；研究型读者才需要道藏目录（三家本36册／中华道藏49册，AX-018、AX-020）与出土整理本（EXC-003、EXC-006、EXC-010、EXC-012）。 |
| **证据** | AX-001~003（盖建民专著与分期）、AX-018~020（中华道藏、三家本、涵芬楼本）、CAN-004~006（元典在线精校本）、CAN-022（人卫点校本）、DAO-024（中华书局道教典籍选刊）、EXC-003/006/010/012（出土整理本）、FRG-007（平台分级） |
| **反常识** | "最权威＝从最难的原典开始"是错的。道藏影印本无标点无校记，零基础直接读《云笈七签》122卷或《悟真篇》丹诗，必然误入隐喻迷宫或卷次迷宫；权威读法是阶梯式的：今人精校带译文（识典）→权威点校本（人卫／中华书局）→影印道藏与出土整理本。 |
| **行动** | examples/02 提供三档分周路径（零基础8周／中医基础6周／研究型专题书单）；references/01 矩阵中每部经典同时给"入门入口（识典精校+译文）"与"深度纸本"两格；examples/03 给现代学术地图与读法。 |
