# 三档阅读路径

阅读设计的核心原则（见 [insights 洞察6](../insights.md)）：**最权威的不等于最适合入门的**。道藏影印本无标点无校记，零基础直接读丹经必然误入隐喻迷宫。正确顺序是阶梯式：今人精校带译文（识典）→权威点校本（人卫/中华书局）→影印道藏与出土整理本。

## 路径一：零基础 8 周

目标：建立"道医是什么"的整体框架，读完 5 种核心文献的选段。每周约 3-4 小时。

| 周次 | 内容 | 材料与链接 | 产出 |
|------|------|-----------|------|
| 第1周 | 框架建立 | 概念文档 [00](../concepts/00-what-is-daoyi.md)、[01](../concepts/01-history-yidao-tongyuan.md)；盖建民《道教医学》前两章（见 [references/03](../references/03-modern-scholarship.md)） | 能用三圆模型说清道医构成 |
| 第2-3周 | 《素问》选读 | 《上古天真论》《四气调神大论》两篇，识典 SBCK072 精校+译文：https://www.shidianguji.com/book/SBCK072 | 读通"法于阴阳""治未病"两段原文 |
| 第4周 | 《千金要方》选读 | 《大医精诚》《食治》选段，识典 DZ1163（道藏93卷本）或 SK1426（四库30卷本） | 理解大医精诚医德规范 |
| 第5周 | 《抱朴子》选读 | 《杂应》篇"兼修医术"段，识典 DZ1185 精校+译文 | 对照葛洪医家/丹道两面 |
| 第6周 | 《云笈七签》选读 | 卷32《养性延命录》导引按摩篇，识典 DZ1032 | 了解道藏养生文献形态 |
| 第7周 | 现代道家疗养文献 | 陈撄宁《静功疗养法》全文：http://www.homeinmists.com/Sitting_Quiet_Treatment.htm （历史文献，非医疗指导） | 理解近现代道家疗养语境 |
| 第8周 | 辨伪与信源意识 | 概念文档 [08](../concepts/08-authenticity-and-sources.md) + [references/04](../references/04-authenticity-register.md) | 掌握断代三法与平台分级 |

配合材料：[精选原文10段](01-classic-passages.md)随时对照。

## 路径二：中医基础 6 周

目标：在中医常识之上补全"道医"维度，重点读元典原校与道藏医书。每周约 5-6 小时。

| 周次 | 主题 | 材料 |
|------|------|------|
| 第1周 | 元典重读：道家根源 | 概念 [02](../concepts/02-classics-daolist-roots.md)；《素问》郭霭春校注本（人卫）上古天真、四气调神、运气七篇选读；《难经》凌耀星校注 |
| 第2周 | 道门医家 | 概念 [03](../concepts/03-daoist-physicians.md)；《千金要方》李景荣校释本大医精诚/食治/养性；《肘后》维基文库本选读 |
| 第3周 | 道藏医书 | 概念 [04](../concepts/04-daozang-medical.md)；《云笈七签》李永晟点校本卷32-36、卷56-62；《养性延命录》ctext res=73338；与《诸病源候论》丁光迪校注本导引法对勘 |
| 第4周 | 内丹传统 | 概念 [05](../concepts/05-neidan-medical.md)；《黄庭经》识典 DZ0331；《悟真篇》王沐浅解（中华书局）；注意丹经隐喻读法 |
| 第5周 | 出土方技 | 概念 [06](../concepts/06-excavated-fangji.md)；《长沙马王堆汉墓简帛集成》或马继兴《马王堆古医书考释》选读；《天回医简》图版 |
| 第6周 | 医道流派 | 概念 [07](../concepts/07-yidao-schools.md)；《景岳全书》李继明整理本传忠录选读、《医贯》郭君双整理本玄元肤论、《四圣心源》diancang 本 |

## 路径三：研究型专题书单

目标：直接进入学术研究。材料以纸本为主（见 [references/02](../references/02-print-editions.md)、[references/03](../references/03-modern-scholarship.md)）。

1. **学术框架**：盖建民《道教医学》（2001）+《道教医学精义》（2014）；胡孚琛《道学通论》（2009修订版）；姜生、汤伟侠《中国道教科学技术史》第一、二卷；吉元昭治《道教与不老长寿医学》（1992中译本）。
2. **道藏目录与原典**：三家本《正统道藏》（1988，36册）或《中华道藏》（2004，49册）；重点《云笈七签》（李永晟点校）、《抱朴子内篇》（王明校释）、《修真十书》《道枢》。
3. **出土文献**：裘锡圭主编《长沙马王堆汉墓简帛集成》（2014）、《张家山汉墓竹简》（2001）、《天回医简》（2022）、马继兴《敦煌古医籍考释》（1988）/《敦煌医药文献辑校》（1998）、沈澍农《敦煌吐鲁番医药文献新辑校》（2016）。
4. **辨伪专题**：钱超尘编《辅行诀五脏用药法要传承集》、田永衍2015年论文（《南京中医药大学学报社科版》）、FRG 登记五种争议书（[references/04](../references/04-authenticity-register.md)）。
5. **专题论文入口**：李贵海《道医学初探》（《世界宗教文化》2019年第5期）；柳长华等天回医简论文（《文物》2017年第12期，DOI:10.13619/j.cnki.cn11-1532/k.2017.12.007）。
