# 《黄帝内经》阅读教程

本知识包（bundle）是《黄帝内经》（《素问》81 篇＋《灵枢》81 篇）的阅读教程，目标是"最权威、最真实的原文与解读"：

- **原文逐字核对**：精读原文以 ctext.org 四部叢刊景印本（《重廣補註黃帝內經素問》《靈樞經》）为底本繁体照录，简体页互校；异文双录不擅改（如"热因热用/热因寒用"、十九条"心/火"公案）
- **三层解读分开**：白文层（文本自身结构）／古注层（王冰、张介宾、李中梓、丹波父子等）／现代层（院校教材概述，自撰不复制受版权保护的白话译文）
- **诚实的边界**：每篇均含"可以怎么用／不可以怎么用"。本包是文献与思想史教程，**不是医书，不构成任何医疗建议**

## ⚠️ 首要声明

《黄帝内经》是公元前至汉代成书、唐代定型的古典医学文献。本包全部内容用于文化、哲学与文献学习。**任何健康、疾病、针刺、用药、养生实践问题，请咨询执业医师**；不得据本包内容自行诊断、用药、施针、艾灸或调整饮食治疗。
