# 🌿 医学与养生

本域存放医学与养生相关的知识包，覆盖中医典籍体系（中医经典分组：典籍谱系总览、难经、伤寒杂病论、神农本草经、黄帝外经）、《黄帝内经》（素问·灵枢）阅读教程、东亚医学经典（《医心方》）、道家道教医学传统（道医）、从《黄帝内经》到《老老恒言》的养生经典阅读教程，以及中国古代性文化（房中）典籍的医家性医学与养生传统研究。

域内知识包坚持"托名层/文本层/辑复层"分层呈现的文献学立场：原文忠实于权威底本、成书学说并列不武断、辑复性质显式标注。

> ⚠️ **医学免责声明**：本域全部内容为古籍文献学习资料，非医疗建议；任何健康问题请咨询执业医师。

**收录边界**：中医与养生传统归本域；现代性学著作归 [社会科学](../sheke/index.md) 域；《黄帝阴符经》等道藏思想典籍归 [国学](../guoxue/index.md) 域。
