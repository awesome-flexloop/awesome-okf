# 🌿 中医经典与理论

本域存放中医（Traditional Chinese Medicine）典籍体系相关知识包，覆盖四大经典的原文精读（双信源逐字核对）、版本与成书考证、历代注家谱系、整个中医典籍谱系的总览与方法论，以及《黄帝外经》（今本《外经微言》）专题研读。域内知识包坚持"托名层/文本层/辑复层"分层呈现的文献学立场：原文忠实于权威底本、成书学说并列不武断、辑复性质显式标注。

> ⚠️ **医学免责声明**：本域全部内容为古籍文献学习资料，非医疗建议；任何健康问题请咨询执业医师。
