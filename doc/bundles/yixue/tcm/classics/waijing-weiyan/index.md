# 《外经微言》（黄帝外经）阅读教程

> ⚠️ **医学免责声明**：本知识包是**古籍文献学习与研究资料**，不是医疗建议，不构成任何诊断、治疗或养生处方指引。书中方药、针刺、房中方术（如红铅）等内容反映明清以前的医学与方术观念，现代医学与伦理多有不取；任何健康问题请咨询执业医师，切勿据古籍自行施治或服食。

> 📚 **文献学提示**：《汉书·艺文志》著录的《黄帝外经》三十七卷早已亡佚；今存《外经微言》九卷八十一篇为清代抄本，题"岐伯天师传，山阴陈士铎述"。名实关系请先读[概念 00：名实之辨](concepts/00-what-is-huangdi-waijing.md)。

本知识包（bundle）是《外经微言》（坊间多以《黄帝外经》之名印行）的阅读指南，以公共领域原文的**双信源逐字核对**为底，配合字词注解、白话大意、学术解读四板块精读 13 篇核心篇章，其余 68 篇提供一句提要与全文链接。成书、托名、真伪问题分层如实呈现，真伪两派证据并列不裁决。

## 🚀 分读者快速开始

**第一次接触中医经典**：
1. 读[概念 00 名实之辨](concepts/00-what-is-huangdi-waijing.md)与[概念 04 结构导览](concepts/04-structure-guide.md)，建立地图
2. 打开[通读路径](examples/reading-path.md)，按第一周计划从卷一开始
3. 边读边对照[卷一精读（上）](examples/juan1-yangsheng-a.md)的注解与白话

**有《黄帝内经》或中医基础**：
1. 快速过概念 00–03（文献学背景）
2. 直入[命门三章精读](examples/mingmen-three-chapters.md)与[概念 06 命门水火](concepts/06-mingmen-fire-water.md)
3. 再回看[概念 05 颠倒之术](concepts/05-diandao-shunni.md)理解思维方式
4. 按 [81 篇全目](references/catalog-81.md)挑卷六至卷九专题

**文献/版本研究者**：
1. 概念 00–03 + references 全部
2. [通读路径](examples/reading-path.md)中的双源核读法演示
3. 以 1984 年中医古籍出版社影印本或《陈士铎医学全书》纸本复核 facts.md 中 WJ-TEX-28 的 8 条存疑校记
