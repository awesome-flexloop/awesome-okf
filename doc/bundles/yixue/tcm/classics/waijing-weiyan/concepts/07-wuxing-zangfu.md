# 五行脏腑与运气伤寒：卷二至卷九的理论展开

> 本篇是卷二至卷九的论题地图。命门三章之外，本书理论含量最大的部分是：五行生克的六种变局、脏腑学说的两处新说（脏六腑七、奇恒可脏），以及卷六以降成体系的运气、伤寒、辨证论述。完整篇次与一句提要见 [81 篇分卷全目](../references/catalog-81.md)。

## 一、五行生克：六种变局

卷五《五行生克篇》（第 38 篇）不满足于"木生火、火生土……"的平面相生序，专论生克关系的六种变局（WJ-RES-19）：

| 变局 | 含义 |
|------|------|
| **生中克** | 相生之中暗藏相克（如母旺子弱，生之反以害之） |
| **克中生** | 相克之中暗藏相生（如金克木，木经斧削方成器） |
| **生不全生** | 相生之力未必全额到位（有能生之位、无能生之气） |
| **克不全克** | 相克之力未必全然得施 |
| **生畏克** | 欲生而畏其所克牵掣 |
| **克畏生** | 欲克而畏其所生救援 |

这是卷一"五行順生不生，逆死不死"（WJ-RES-03，见 [05 颠倒顺逆](05-diandao-shunni.md)）在五行理论中的展开：生克不是机械循环，而是随脏腑虚实变化的力量关系。卷五《水不克火篇》（第 40 篇）是其应用例——饮水不解火热，外水不能制人身无形相火，治当大补先天真水（catalog-81 第 40 篇提要）。

## 二、脏腑学说：两处新说

### 脏六腑七（WJ-RES-13、WJ-RES-22）

通行中医理论为"五脏六腑"，本书卷二《臟腑闡微篇》（第 16 篇）提出"脏六腑七"：

- **胞胎可名为脏**：胞胎处心肾之交，能藏先天精气，具脏"藏而不泻"之性；
- **包络当称腑**：包络（心包络）为相火，有名无形、代心火宣化，具腑"传化物"之性，独与三焦为表里（《包絡配腑篇》第 18 篇，WJ-RES-22）。

此说重新清点脏腑名额，目的是给命门—包络—三焦这组"相火系统"在脏腑框架中腾出位置。

### 奇恒可脏（WJ-RES-23）

卷三《奇恆篇》（第 22 篇）论脑、髓、骨、脉、胆、女子胞六者能藏肾精，**可名为脏**，与《素问·五脏别论》"奇恒之腑"论题直接相接而更进一步——《素问》名之为"腑"（形态似腑），本书因其"藏精"功能主张可名为脏。修真养精、气结圣胎之说由此切入，是医理与道家修养论的接合部。

### 脏腑分论十三篇（WJ-RES-14）

卷三卷四以肺金、肝木、肾水、心火、脾土、胃土、包络火、三焦火、胆木、膀胱水、大肠金、小肠火、胆腑命名诸篇，逐脏逐腑论气化宜忌（第 19、24–35 篇）。其共同特点：

- 每篇都把该脏腑放在**与命门水火的关系**中定位（如脾土赖命门相火而生、膀胱恃心肾二火化水）；
- 治法多取"隔脏施治"与"水火互济"，如肺金受刑赖肾水相救、心火宜滋肾水以济——与卷一逆向思维一脉相承。

## 三、经脉与奇经

卷二（第 10–18 篇）论生育与经脉：十二经脉循行终始、顺逆（惟足少阴肾经独以逆为顺）、经气标本所在不可妄刺、任督二脉同起会阴为生死道路、阴阳二跷起止（WJ-RES-01，详见 catalog-81 卷二提要）。此卷与《灵枢》经脉诸篇论题相接。

## 四、卷六卷七：五运六气与诊疗

卷六卷七以 18 篇篇幅展开运气诊疗说（WJ-RES-16），主要论题：

- **诊法**：《診原篇》主"诊脉不若诊原"，切腧穴以气之清浊浮沉别阴阳生死，法约易识；《精氣引血篇》论九窍出血治宜补气摄血，不可清火；
- **天人相应**：《天人一氣篇》《地氣合人篇》《三才并論篇》论人气随天气转移、九州配九窍、五运六气当合天地人三才并论；
- **运气专门**：《五運六氣離合篇》《六氣分門篇》《六氣獨勝篇》《三合篇》《四時六氣異同篇》《司天在泉分合篇》《從化篇》——五运不可分门、六气可分门论症，暑为君火、火为相火，君相二火当分；
- **暑火营卫**：《暑火二氣篇》辨暑病与火病之异，《營衛交重篇》论营出中焦、卫出下焦，不可重卫轻营；《五臟互根篇》论阴中有阳、阳中有阴。

## 五、卷八：伤寒八风，自成体系

卷八九篇论外感病（WJ-RES-15）：八风命名与太乙占法（《八風命名篇》《太乙篇》）、风邪寒邪入路之分（《親陽親陰篇》——风为阳邪从风府入自上而下、寒为阴邪从脐入自下而上）、传经不传经（《異傳篇》《傷寒知變篇》）、伤寒六种之辨（《傷寒同異篇》——中风中暑中热中寒中湿中疫皆异，惟冬月感寒传经为正伤寒）、风寒殊异、阴寒格阳（热药从治）、春温似疫。

与张仲景《伤寒论》论题相接而自成体系——本书的特点是把外感病放在"八风—运气—脏腑虚实"框架中讨论，反复强调"脏虚乃中""治脏为本、治风为标"（《八風固本篇》在卷七末）。

## 六、卷九：辨证治则，终篇养生

卷九九篇论辨证治则（WJ-RES-20）：补泻阴阳（新病可泻、久病宜补）、**善養篇**（调阴阳在人不在时，见 [善养篇精读](../examples/shanyang.md)）、亡阳亡阴（阳亡本于阴先亡，皆本肾中水火虚）、昼夜轻重（阳病昼重、阴病夜重）、解阳解阴（十二经气王之时）、真假疑似（寒热虚实各有真假，真火假火可试以外水）、从逆窥源（气逆之源在肾水不足）、移寒移热、寒热舒肝（五脏郁气自病亦作寒热，舒肝木之郁则诸郁尽舒）。

卷九以辨证始、以养生终（善养篇在卷九第二），与卷一养生总纲首尾呼应，完成"养生—理论—外感—辨证—养生"的闭环。
