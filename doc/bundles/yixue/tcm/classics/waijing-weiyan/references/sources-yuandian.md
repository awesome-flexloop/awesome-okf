# 原典信源：全文电子文本与底本影印

> 本文件登记《外经微言》原文的一级信源。原典为公共领域（Public Domain）清代文献，原文可照录；现代点校/语译部分版权归各出版社，不转录。

## 一、现存底本与影印本

| 项 | 内容 |
|---|---|
| 现存最早实物 | 清代精抄本（专家鉴定），1980 年整理古医籍时发现，现藏**天津市卫生职工医学院图书馆** |
| 抄本形态 | 前无序、后无跋，封皮残缺，印章模糊难辨；卷首题"**岐伯天师传，山阴陈士铎号远公又号朱华子述**" |
| 书末朱题 | "**嘉庆二十年静乐堂书**"（1815），笔体与正文稍异，整理者疑或后人所加 |
| 最早影印本 | **1984 年 4 月中医古籍出版社**据清抄本原书法体影印，一版一印，32 开 340 页，**印数 5500 册**，标注"限国内发行" |
| 书目著录 | 多种图书目录未见记载；**嘉庆八年（1803）《山阴县志》**著录陈士铎著作含《外经微言》，并载其"邑诸生，治病多奇中，医药不受人谢，年八十余卒" |
| 现代排印本 | 1999 年柳长华主编《陈士铎医学全书》（中国中医药出版社）收《外经微言》为第一部；另有 2016 年中国医药科技出版社排印本等 |

## 三、原文引用规范（本知识包内部约定）

1. 精读原文以**维基文库为工作底本**逐段照录，篇末"陈士铎曰/陈远公曰"按语属原文组成部分，一并完整收录。
2. 维基页面中夹有近人"凌波按"及无署名现代口语夹批共 7 处（卷一 6 处、命门真火篇末 1 处），**非原文，一律剔除**，不计入原文。
3. 双源实义异文在各篇"异文校记"中以"底本（维基文库）作『A』，古书网清抄本作『B』"格式标注；繁简字、异体字（如回/迴）差异不出校。
4. 各电子本共同传抄疑误（8 条，见 [命门三章精读](../examples/mingmen-three-chapters.md)）标注"**存疑，待纸本裁定**"，不擅改原文。
5. 篇名以维基卷子页标题与寻岐黄目录互证后的 81 篇全目为准（见 [catalog-81](catalog-81.md)）；维基总目 4 处讹脱（六氣分門篇脱"篇"字、四時六氣異同篇脱"四時"、傷寒同異篇误作"异同"、亡陽亡陰篇误作"亡阴亡阳"）已在全目中订正。
6. 现代排印本（如 1984 影印本、《陈士铎医学全书》点校本）为纸本裁定依据，本包不转录其点校语译。
