# 四大经典通读计划：四阶段、注本选用与顺序建议

> 本计划是文献学习路径，不是医学训练路径——读经典不能替代系统中医教育与执业训练；健康问题请咨询执业医师。

## 计划总则

- **适用对象**：以文献阅读与研究为目的的自学者；有考试或临床研修目标的读者请按 [概念 04：书目分级](../concepts/04-graded-bibliography.md)对齐官方书单（教材体系 OV-039 / 研修大纲 OV-038）。
- **周期弹性**：四阶段无固定周数，以"完成每阶段的退出检查"为准。
- **方法配套**：每开一部经先过 [五问法](../concepts/03-pseudepigrapha-dating.md)；引用原文时执行 [双源核对](dual-source-verification-demo.md)。

## 四阶段总览

| 阶段 | 内容 | 退出检查 | 对应谱系层 |
|---|---|---|---|
| 0 地图与提问 | 本束概念 00/01/03 + 任一部经典的通识导读 | 能画出三层谱系图；对四经各答出五问 | 总览 |
| 1 理论入门 | 《内经》选篇精读 + 《难经》选难对照 | 精读篇目完成双源核对与笔记 | 经典层·医经 |
| 2 临床进入 | 《伤寒论》通读 → 《金匮要略》选篇 | 建立方证笔记框架；辨析"条文的整理定型史" | 经典层·经方 |
| 3 药物补维 | 《本经》序录 + 代表药条；回望《伤寒》方与《本经》药的对应 | 能说明"引用的是某辑本" | 经典层·本草 |

## 阶段 0：地图与提问（1—2 周）

**做什么**：读[概念 00 谱系分层](../concepts/00-genealogy-layering.md)、[概念 01 四大经典](../concepts/01-four-classics-guide.md)、[概念 03 五问法](../concepts/03-pseudepigrapha-dating.md)；另选一部通识导读（如中华书局《〈黄帝内经〉通识》，OV-040）建立感性认识。

**为什么先读地图**：四经存在托名、层累、辑复问题，先知道"书是什么"能避免把整理者文字当原作者文字（INS-001）；同时避免把"四大经典"边界当知识边界（INS-003）。

## 阶段 1：理论入门——《内经》选篇（约 2—3 个月）

**选篇**：建议从《素问》早期理论篇章入手。本轮调研双源核对完成的 9 篇可作为起步池：《上古天真论》《四气调神大论》（前半）、《阴阳应象大论》（节选）、《灵兰秘典论》、《异法方宜论》、《脉要精微论》（节选），以及《灵枢》的《九针十二原》（节选）、《本神》（节选）、《天年》（节选）（NGJ-034）。

**读本选用**：

| 需求 | 选用 | 依据 |
|---|---|---|
| 原文电子全文 | ctext.org《黄帝内经》（底本：四部丛刊本系统） | OV-026 |
| 原文纸本 | 《中医临床必读丛书》经典著作类《黄帝内经素问》《灵枢经》（白文本+导读） | OV-033 |
| 注译入门 | 中华书局姚春鹏译注本等原文译注形态 | OV-040 |
| 深入研究 | 11 部重点古籍整理工程之《黄帝内经》校注本/语译本 | OV-034 |

**方法要点**：每周精读 1—2 篇；引用原文前按 [双源核对演示](dual-source-verification-demo.md)流程对读（ctext 四部丛刊本 + 通行整理本两个版本系统）。《难经》可选若干"难"与《内经》对应条文对照读，体会"问难解经"体例（OV-009）。

## 阶段 2：临床进入——《伤寒论》→《金匮要略》（约 3—4 个月）

**顺序理由**（本束建议）：《伤寒论》六经辨证体系相对完整、条文体例统一，适合先建立"辨证论治"的临证思维框架；《金匮要略》按病篇组织，适合在其后按病专题选读。两书同源于《伤寒杂病论》（OV-010），先后读可自然衔接。

**读本选用**：白文本用《中医临床必读丛书》经典著作类《伤寒论》《金匮要略》（OV-033）；电子信源 ctext.org《伤寒论》页面明确标注"底本：《四部丛刊初编》本《注解伤寒论》"（OV-027）；研究级用 11 部整理工程之《伤寒论》《金匮要略》校注本（OV-034）。

**方法要点**：

- 开卷先过五问——特别注意：今本文字经西晋王叔和整理、北宋校正医书局校订定型，条文编号为现代校注者所加（SH-008/009/019）。
- 建立"方证笔记"：一条条文 = 证候 + 方药 + 出自哪个整理系统的文本。
- 方药剂量仅为文献记录，不作任何实际应用（束根免责声明）。

## 阶段 3：药物补维——《神农本草经》序录与代表药（约 1—2 个月）

**做什么**：先读序录（三品分类总纲），再选上品代表药若干条精读；回望《伤寒》诸方所用药物在《本经》中的记载。

**读本选用与关键认知**：《本经》现行本全部为辑复本（OV-011）——**选用读本时必须意识到"读的是某辑本"**：卢复、孙星衍、顾观光、森立之等辑本在药条归属、药序、条目数上互有差异（INS-004），引用一律标注"某辑本作某"。11 部整理工程中有《神农本草经》辑佚成果（OV-034），电子全文可参维基文库（OV-028）。

## 顺序建议的弹性说明

- **备考读者**：考试体系"四大经典"为《内经》《伤寒论》《金匮要略》+ 温病学（OV-004）——阶段 2 后应插入温病学内容（可从《温病条辨》《温热经纬》入手，均见人卫必读丛书经典著作类，OV-033；《温病条辨》全文见维基文库，OV-028）。
- **文献兴趣读者**：可在任一阶段并行读 [waijing-weiyan](../../waijing-weiyan/index.md) 束（单书精读的完整样例）。
- **进阶到学说层**：完成四阶段后，按[概念 00 谱系分层](../concepts/00-genealogy-layering.md)进入金元四大家与温病学派（各家学说层）。

## 通读三原则

1. **先问后读**：每部经开卷前过五问（[概念 03](../concepts/03-pseudepigrapha-dating.md)）。
2. **双源入库**：任何要引用/记录的原文，先双源核对（[演示](dual-source-verification-demo.md)）。
3. **形态匹配**：读本形态随水平切换——诵读/通识 → 译注 → 白文本 → 校注/影印（[概念 04](../concepts/04-graded-bibliography.md)），不跳级也不停级。
