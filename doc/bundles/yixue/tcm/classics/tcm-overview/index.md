# 中医典籍总览——谱系、导读与阅读方法

> ⚠️ **医学免责声明**：本知识包内容为古籍文献学习资料，非医疗建议；任何健康问题请咨询执业医师。文中方药剂量仅为文献记录。

> 📚 **文献学提示**："四大经典"并非自古固定的组合——该词正式提出于 1955 年教学计划，首提书目与今通行组合不同，至今多种组合并存（见[概念 01：四大经典导读](concepts/01-four-classics-guide.md)）。读中医典籍，先把"书是什么"与"怎么读"分开处理。

本知识包（bundle）是中医典籍体系的**总览束**：回答"中医有哪些书、经典层如何构成、各层关系如何、按什么顺序读、用什么方法读"五个体系性问题。与单书精读束（如 [waijing-weiyan](../waijing-weiyan/index.md)、[huangdi-neijing](../../../huangdi-neijing/neijing-reading/index.md)）不同，本束不逐篇精读某一本书，而是提供整个谱系的地图、进门的文献学常识与可迁移的阅读方法。

## 🚀 分读者快速开始

**第一次接触中医经典**：
1. 读[概念 00 谱系分层](concepts/00-genealogy-layering.md)建立全书地图
2. 读[概念 03 五问法](concepts/03-pseudepigrapha-dating.md)学会"先问再读"
3. 按[四大经典通读计划](examples/four-classics-reading-plan.md)阶段 0–1 进入《内经》选篇

**有中医基础 / 备考读者**：
1. 快速过[概念 01 四大经典](concepts/01-four-classics-guide.md)的组合争议部分（考试体系与通行说法的差异点）
2. 按通读计划阶段 2–3 进入《伤寒》《金匮》《本经》
3. 用[概念 04 书目分级](concepts/04-graded-bibliography.md)对齐教材与研修书目

**文献 / 版本研究者**：
1. 精读[概念 02 版本学](concepts/02-philology-basics.md)与[概念 05 阅读方法论](concepts/05-reading-methodology.md)
2. 对照[双源核对演示](examples/dual-source-verification-demo.md)复走七步流程
3. 以[权威信源总登记](references/authoritative-sources.md)为入口进入底本与数据库层
