# 版本系统考——宋本/成注本/康平本/桂林古本并列

> ⚠️ 本知识包内容为古籍文献学习资料，非医疗建议；任何健康问题请咨询执业医师。文中方药剂量仅为文献记录，不构成用药指导。

## 为什么"选本子"是个真问题

现存《伤寒论》主要版本系统有四：宋本（赵开美 1599 年摹刻）、成注本（金·成无己《注解伤寒论》）、康平本（日本 1060 年抄本）、桂林古本（清末传抄本）（SH-012）。四系文字互有出入——差异不只是个别字词，还涉及条文有无、分条层次乃至整篇存佚。读哪一个本子，就隐性接受了哪一系的文字立场（INS-002）。

## 四大版本系统对照

| 系统 | 形成时间与关键人物 | 特征 |
|------|--------------------|------|
| 宋本 | 明万历二十七年（1599 年）赵开美据北宋校正医书局刻本摹刻（《仲景全书》本） | 今日通行"宋本"影印与排印本多以此为底本；赵刻原印本稀少，中国国家图书馆、上海图书馆、中国中医科学院图书馆及日本均有收藏（SH-013） |
| 成注本 | 金皇统四年（1144 年）成无己撰《注解伤寒论》 | 现存最早的《伤寒论》全文注本；正文文字与赵开美本存在多处差异（如第 263 条少"为"字）（SH-014） |
| 康平本 | 日本康平三年（1060 年）丹波雅忠抄录之本，1937 年日本大塚敬节等影印公布 | 正文以书写形式区分原文与注文的层次（追文、嵌注、旁注），与宋本分条结构不同，且无"辨脉法""平脉法""伤寒例"诸篇（SH-015） |
| 桂林古本 | 题名《伤寒杂病论》，相传为张仲景四十六世孙张绍祖家传"第十三稿"，经左盛德授予罗哲初，1934 年罗氏手抄，1939 年于桂林刊行 | 内容较宋本多出温病等篇，条文总数与方剂数均多于宋本 398 条体系；学界对其真伪观点不一（SH-016、SH-020） |

另有一部**《金匮玉函经》**：北宋校正医书局 1066 年刊行，为《伤寒论》同源异构传本（SH-010），常作对勘之用（详见[概念 01](01-textual-history.md)）。

## 差异实例：版本对勘长什么样

- **第 263 条（少阳病提纲）**：宋本作"少阳之为病，口苦，咽干，目眩也"；成注本此条作"少阳病"，无"为"字——此为宋本与成注本显著差异之一（SH-014）。
- **第 219 条（三阳合病）**：成无己本"口不仁"下有"而"字（作"口不仁而面垢"）；《脉经》"口"字下有"中"字；《千金翼方》"面垢"作"语言向经"；康平本"三阳合病"作嵌注，层次与宋本不同（SH-034）。
- **篇目层面**：康平本无"辨脉法""平脉法""伤寒例"诸篇（SH-015）——这些篇目是宋本系统"二十二篇"的组成部分但不计入 398 条编号体系（SH-023）。桂林古本则多出温病等篇（SH-016）。

这类异文在本包精读文档中一律显式标注"某本作某"，义理级异文并列不裁决；完整登记见[权威底本与信源](../references/sources-editions.md)。

## 现代通行校注本

刘渡舟主编《伤寒论校注》（人民卫生出版社 1991 年）以赵开美摹刻宋本为底本；钱超尘、郝万山等整理本亦通行于高校教学（SH-017）。今日高校与临床教学中的"《伤寒论》第 N 条"引文体系，基本建立在宋本系统的现代校注本之上（另见[概念 03](03-six-channels-framework.md) 关于编号体系的事实）。

## 立场：并列不裁决

四大系统没有哪一个可以单独宣称"即仲景原书"：宋本定型最迟（经王叔和、宋臣两层整理校订）却是千年流传主脉；成注本最早成注而文字有改；康平本存古层次信息却缺宋本数篇；桂林古本内容最多而真伪存争议（SH-008~016）。本知识包的处理方式是**四系并列登记、差异显式标注、义理级两读不裁决**（INS-002 的行动条款），供读者按需选本：

- 初学者：从以宋本为底本的现代校注本入门（SH-017）。
- 进阶者：以成注本对照宋本，留意文字差异（如第 263、219 条）。
- 研究者：康平本的层次区分（追文/嵌注/旁注）与桂林古本的真伪讨论，见[注本分级表](../references/commentary-grades.md)研究级一档。
