# 六经辨证阅读路线图——六经→条文→方证导航

> ⚠️ 本知识包内容为古籍文献学习资料，非医疗建议；任何健康问题请咨询执业医师。文中方药剂量仅为文献记录，不构成用药指导。

## 这张图怎么用

《伤寒论》的阅读难点不在单条文字，而在"条文群"的组织：398 条分属十篇（SH-036，编号为现代校注者所加，SH-019），每篇之下方证交错。本路线图按"**六经（篇）→ 条文号范围 → 代表方证 → 精读入口**"四级导航，配合[398 条索引](../references/catalog-398.md)使用：先在此图定位某经某方证，再按索引找全该方证的全部条文。

## 三阳篇：由表入里

### 太阳病（第 1—178 条，三篇 178 条，全书近半）

- **提纲**：第 1 条"太阳之为病，脉浮，头项强痛而恶寒"（C、W、J）。
- **两纲**：第 2 条"名为中风"（表虚→桂枝汤类）与第 3 条"名为伤寒"（表实→麻黄汤类）。
- **代表方证**：桂枝汤类（12、13、20、25）、麻黄汤类（35、55）、大/小青龙汤（38、40）、五苓散（71）、栀子豉汤（76）、小柴胡汤（96、97）、桃核承气汤（106）、大陷胸汤（135）、十枣汤（152）、泻心汤类（154）。
- **精读入口**：[太阳病篇核心条文逐条精读](taiyang-passages.md)（23 条全覆盖）。
- **阅读要点**：太阳篇是全书的"方法训练场"——先表后里（106、152）、同脉异治（25 与 26）、方证边界（16 桂枝禁例、38 大青龙禁例）等原则都在此立例。

### 阳明病（第 179—262 条，84 条）

- **提纲**：第 180 条"阳明之为病，胃家实是也"（C、W、J）。
- **代表方证**：白虎汤（219）、白虎加人参汤（26，在太阳上篇）、调胃承气汤（207、248）、小承气汤（213）、大承气汤（215、253）、茵陈蒿汤（236）。
- **阅读要点**：热证（白虎）与腑实（承气）两大方向；承气三方的层次（调胃→小→大）是"程度分级"用药的典型。第 219 条多本异文、第 236 条茵陈蒿汤诸本异文（见[权威底本与信源](../references/sources-editions.md)）提示此篇版本对勘材料丰富。

### 少阳病（第 263—272 条，10 条）

- **提纲**：第 263 条"少阳之为病，口苦，咽干，目眩也"（C、W、J；异文：成注本此条作"少阳病"，无"为"字）。
- **代表方证**：小柴胡汤主证虽在太阳中篇（96、97），少阳本篇立禁例与运用（267 坏病、265 不可发汗）；热入血室见于太阳下篇 143—145 条。
- **阅读要点**：少阳篇条文最少而禁例最多（不可吐下 264、不可发汗 265）——枢机之病，汗吐下皆禁，"和解"之义由此而显。

## 三阴篇：由阳入阴

### 太阴病（第 273—280 条，8 条）

- **提纲**：第 273 条"太阴之为病，腹满而吐，食不下，自利益甚，时腹自痛"（C、W、J）。
- **代表方证**：四逆辈（277"自利不渴者，属太阴，以其脏有寒故也，当温之"）、桂枝加芍药汤/桂枝加大黄汤（279）。
- **阅读要点**：三阴中最轻浅一层，"当温之，宜服四逆辈"（辈字示方剂范围而非一方）；第 280 条太阴用药法度（"设当行大黄芍药者，宜减之"）示护胃气之慎。

### 少阴病（第 281—325 条，45 条）

- **提纲**：第 281 条"少阴之为病，脉微细，但欲寐也"（C、W、J）。
- **代表方证**：麻黄附子细辛汤/甘草汤（301、302）、黄连阿胶汤（303）、附子汤（304）、真武汤（316）、通脉四逆汤（317）、四逆汤急温（323）、急下三证（320—322）。
- **阅读要点**：少阴是生死关头——寒化（四逆辈）与热化（黄连阿胶）两路并行，"急温之"（323）与"急下之"（320—322）并举，示病势急骤时当机立断。真武汤在第 82 条（太阳中篇）与第 316 条两见，是跨经方证的典型。

### 厥阴病（第 326—381 条，56 条）

- **提纲**：第 326 条"厥阴之为病，消渴，气上撞心，心中疼热，饥而不欲食，食则吐蛔，下之利不止"（C、W、J）。
- **代表方证**：乌梅丸（338）、白虎汤（350）、当归四逆汤（351）、四逆汤类（353、354）、麻黄升麻汤（357）、白头翁汤（371、373）、吴茱萸汤（378）。
- **阅读要点**：厥阴篇最难读——提纲证、厥热胜复（331—336）、厥证总纲（337"凡厥者，阴阳气不相顺接，便为厥"）、寒热错杂诸方杂陈。建议先立"厥证总纲"再分寒热两头读。

## 两篇附录性篇章

- **辨霍乱病脉证并治（第 382—391 条，10 条）**：霍乱提纲（382、383）、四逆辈（384、386—389）、五苓散/理中丸（387"热多欲饮水者，五苓散主之；寒多不用水者，理中丸主之"）、通脉四逆加猪胆汁汤（390）。
- **辨阴阳易差后劳复病脉证并治（第 392—398 条，7 条）**：阴阳易烧裈散（392）、枳实栀子豉汤（393）、竹叶石膏汤（397）、差后微烦损谷则愈（398）——大病瘥后调理之专篇。

## 推荐阅读顺序

```
第一遍（立骨架）：太阳上（1—30）→ 六经提纲六条（1/180/263/273/281/326）→ 本路线图通读
第二遍（读主脉）：太阳中（31—127，配合 taiyang-passages.md 精读）→ 阳明（179—262）→ 少阴（281—325）
第三遍（补两翼）：太阳下（128—178）→ 太阴/厥阴 → 少阳 → 霍乱/差后劳复
研究延伸：金匮要略首篇（见 concepts/04-jingui-structure.md）→ 注家分级选本（references/commentary-grades.md）
```
