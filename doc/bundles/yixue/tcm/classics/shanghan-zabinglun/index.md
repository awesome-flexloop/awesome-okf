# 《伤寒杂病论》（伤寒论·金匮要略）阅读教程

> ⚠️ **医学免责声明**：本知识包内容为古籍文献学习资料，非医疗建议；任何健康问题请咨询执业医师。文中方药剂量仅为文献记录，不构成用药指导。

> 📚 **文献学提示**：东汉张仲景所撰《伤寒杂病论》原书十六卷早已散佚；今本《伤寒论》文字经西晋王叔和整理、北宋校正医书局校订而定型，《金匮要略》则由北宋林亿等自馆阁残卷编成。今通行"第 1—398 条"之条文编号为现代校注者所加，宋本、成注本原书无编号。名实与流变请先读[概念 00：什么是伤寒杂病论](concepts/00-what-is-shanghan.md)与[概念 01：成书流变](concepts/01-textual-history.md)。

本知识包（bundle）是《伤寒杂病论》两大传世分支——《伤寒论》与《金匮要略》——的阅读指南，以公共领域原文的**双信源逐字核对**为底（中国哲学书电子化计划 ctext + 维基文库宋本转录，辅以中医宝典等），共精读登记 71 条核心条文（伤寒论 65 条 + 金匮要略第一篇 6 条），涉及方证 40 个。成书流变、版本系统、真伪问题分层如实呈现，四大版本系统并列不作单一"真本"裁决，义理级异文并列不裁决。

## 🚀 分读者快速开始

**第一次接触中医经典**：
1. 读[概念 00 什么是伤寒杂病论](concepts/00-what-is-shanghan.md)与[概念 03 六经辨证框架](concepts/03-six-channels-framework.md)，建立"书是什么、骨架是什么"的地图
2. 打开[六经辨证阅读路线图](examples/six-channels-reading-map.md)，按"太阳→阳明→少阳→三阴"顺序入门
3. 边读边对照[太阳病篇逐条精读](examples/taiyang-passages.md)的注释与注家对照

**有中医基础**：
1. 快速过概念 00–02（文献学背景），重点读[概念 02 版本系统考](concepts/02-version-systems.md)
2. 直入[概念 05 核心方证解读](concepts/05-core-formulas.md)与[太阳病篇逐条精读](examples/taiyang-passages.md)
3. 按 [398 条索引](references/catalog-398.md)挑阳明、少阴等经专题延伸

**文献/版本研究者**：
1. 概念 00–02 + references 全部三篇
2. 重点核对 [sources-editions.md](references/sources-editions.md) 的异文登记摘要（8 处）与四大版本系统差异
3. 桂林古本真伪、康平本层次结构等存而不决的问题按"并列登记"体例复核
