# 《难经》核心概念解读

本篇按"论脉 → 生命本体 → 经络 → 脏腑杂论 → 诊法 → 腧穴与治法"的顺序，将《难经》可原文验证的核心理论贡献逐条登记。引文格式一律作"《难经》第 N 难作某"，原文均出自双源核对底稿（维基文库本为底本、国学导航本为主对校本、古诗文网为第三参证）。

## 一、脉学体系：独取寸口

《难经》第一难作："寸口者，脉之大会，手太阴之脉动也"，又谓寸口为"五脏六腑之所终始"，确立**独取寸口**诊脉法。配套的度量体系亦在第一难："人一呼脉行三寸，一吸脉行三寸，呼吸定息，脉行六寸。人一日一夜，凡一万三千五百息，脉行五十度，周于身"——以呼吸计时、以五十度为周期，为寸口诊法提供生理学论证（逐句精读见 [第一难精读](../examples/first-nan-cunkou.md)）。

中医宝典词条（国家中医药管理局名词术语规范推广项目审核认证）总结：书中首创独取寸口及寸关尺及浮中沉三部九候的切脉方法、脉证相参的辨证观。此外：

- **损至之辨**（十四难）：至脉一呼再至曰平、三至曰离经、四至曰夺精、五至曰死、六至曰命绝；损脉反之。治损五法："损其肺者益其气，损其心者调其荣卫……损其肾者益其精"。
- **是动/所生病**（二十二难）："是动者，气也；所生病者，血也"——以气血释经脉病候。

## 二、生命本体：肾间动气、命门、三焦

**肾间动气**（八难）：《难经》第八难称之为"五脏六腑之本，十二经脉之根，呼吸之门，三焦之原，一名守邪之神"，并断言"气者，人之根本也，根绝则茎叶枯矣"。

**命门**（三十六难）："其左者为肾，右者为命门。命门者，诸神精之所舍，原气之所系也"，"故男子以藏精，女子以系胞"。

> ⚠️ 义理级两读（必须并列）：此难末句**维基文库本作"故知肾有二也"，国学导航本与古诗文网作"故知肾有一也"**——一字之差直接关系"肾有几个"的理论表述：作"二也"则左肾右命门合为二，作"一也"则命门之外肾惟其一。两读均为传本实况，本束并列登记不裁决。

**三焦**（三十八难）：三焦"有原气之别焉，主持诸气，有名而无形"。此处同样有异文：**维基文库本作"谓二焦也"，国学导航本与古诗文网作"谓三焦也"**。

中医宝典词条总结：《难经》在藏象学说方面突出肾的重要性，建立了"肾（命门）—元气—三焦"为轴心的整体生命观——八难（动气）、三十六难（命门）、三十八难（三焦）、六十六难（原穴）四条文本互为支撑。

## 三、经络：奇经八脉

第二十七难总列奇经八脉之名：**阳维、阴维、阳跷、阴跷、冲、督、任、带**，并以沟渠溢满为喻解释其"不拘于经"。中医宝典词条载："奇经八脉"这一名称在现存古籍中是《难经》最先提出的。第二十八难载八脉起止循行，如督脉"起于下极之俞，并于脊里，上至风府，入属于脑"（异文：维基文库本作"上至风腑"）。第二十九难载八脉病候。

## 四、脏腑杂论：七冲门、八会、五积

- **七冲门**（四十四难）：唇为飞门、齿为户门、会厌为吸门、胃为贲门、太仓下口为幽门、大肠小肠会为阑门、下极为魄门——消化道七道关门的解剖命名沿用至今。
- **八会**（四十五难）：腑会太仓、脏会季胁、筋会阳陵泉、髓会绝骨、血会鬲俞、骨会大杼、脉会太渊、气会三焦——八类组织的会穴纲领。
- **五脏之积**（五十六难）：肝积肥气、心积伏梁、脾积痞气、肺积息贲、肾积奔豚，各配得病时日（如"肥气以季夏戊己日得之"）与传变机理（"肺病传于肝，肝当传脾，脾季夏适王，王者不受邪……故留结为积"）。
- **伤寒有五**（五十八难）："有中风，有伤寒，有湿温，有热病，有温病"，并分列五者脉象——广义伤寒的分类框架。

## 五、诊法界说：神圣工巧

第六十一难提出诊法界说："望而知之谓之神，闻而知之谓之圣，问而知之谓之工，切脉而知之谓之巧"，并将四诊各自的认识路径具体化（望五色、闻五音、问五味、诊寸口视虚实）。

## 六、腧穴与治法

- **十二经原穴**（六十六难）：肺太渊、心大陵、肝太冲、脾太白、肾太溪、少阴兑骨、胆丘墟、胃冲阳、三焦阳池、膀胱京骨、大肠合谷、小肠腕骨；理论根据在"脐下肾间动气者，人之生命也，十二经之根本也，故名曰原"。异文：心之原维基文库本作"大陵"（底本原作"太"，据《灵枢·九针十二原》改）、国学导航本作"太陵"。
- **五输穴主病**（六十八难）："井主心下满，荥主身热，俞主体重节痛，经主喘咳寒热，合主逆气而泄"。
- **补母泻子**（六十九难）："虚者补其母，实者泻其子"。
- **泻南补北**（七十五难）："东方实，西方虚，泻南方，补北方"，以五行相平立论（"子能令母实，母能令子虚"）。
- **治未病**（七十七难）："上工治未病，中工治已病"，以"见肝之病，则知肝当传之与脾，故先实其脾气"为例。
- **实实虚虚之戒**（八十一难）：以"无实实虚虚，损不足而益有余"总诫针害，与第十二难内外之绝之戒呼应。
