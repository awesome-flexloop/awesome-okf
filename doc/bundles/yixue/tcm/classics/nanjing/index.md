# 《难经》（黄帝八十一难经）阅读教程

> ⚠️ **医学免责声明**：本知识包内容为古籍文献学习资料，非医疗建议；任何健康问题请咨询执业医师。文中方药剂量仅为文献记录。

> 📚 **文献学提示**：《难经》原名《黄帝八十一难经》，旧题秦越人（扁鹊）撰，但《史记·扁鹊仓公列传》不载此事，《汉书·艺文志》亦未著录此书；成书年代五说并存。托名与成书问题请先读[概念 00：什么是难经](concepts/00-what-is-nanjing.md)。

本知识包（bundle）是《难经》的阅读指南，以公共领域原文的**双信源逐字核对**为底（维基文库本为底本、国学导航本为主对校本、古诗文网为第三参证）：6 篇概念文档覆盖文献考辨、81 难结构、与《内经》的关系、核心理论、注家谱系与影响史；2 篇精读示例演示逐句读法与对照读法；2 篇信源文档登记底本系统与注本分级。托名、成书、异文诸问题并列登记，不作裁决。

## 🚀 分读者快速开始

**第一次接触中医经典**：
1. 读[概念 00](concepts/00-what-is-nanjing.md)与[概念 01](concepts/01-structure-81.md)，先建立"这是一部什么书、81 难都有什么"的地图
2. 打开[第一难精读](examples/first-nan-cunkou.md)，按六句拆解学会"问曰/然曰"的读法
3. 遇到"《难经》与《内经》什么关系"的疑问时，读[概念 02](concepts/02-relation-to-neijing.md)与[对照阅读法](examples/nanjing-neijing-parallel.md)

**有《黄帝内经》或中医基础**：
1. 快速过概念 00–02（文献学背景）
2. 直入[概念 03 核心概念](concepts/03-core-concepts.md)，重点看命门/三焦/奇经八脉与异文两读
3. 按[注本分级表](references/commentary-grades.md)选进阶本细读

**文献/版本研究者**：
1. 概念 00–02 + 信源参考全部
2. 重点复核 [sources-editions](references/sources-editions.md) 的异文登记摘要（含义理级两读 NJ-073）
3. 以《难经集注》系统（日传本源流）与吕杨注辑校复核

## 🎯 Bundle 定位

| 维度 | 本 bundle（nanjing） | 姊妹束（waijing-weiyan） |
|------|--------------------|--------------------------|
| 对象 | 《难经》八十一难（托名秦越人，汉唐间定型） | 《外经微言》九卷八十一篇（陈士铎述，清抄本系统） |
| 核心问题 | 脉学独取寸口、命门三焦、与内经关系、注家谱系 | 名实考辨、命门水火、颠倒之术、真伪两派 |
| 读法特色 | 逐句精读 + 难经内经对照 + 81 难全录存目 | 双源核读法 + 13 篇精读 + 68 篇存目 |
