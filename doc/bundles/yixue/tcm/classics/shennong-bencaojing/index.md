# 《神农本草经》阅读教程

> ⚠️ **医学免责声明**：本知识包内容为古籍文献学习资料，非医疗建议；古籍所载药物功效与毒性记载为历史文献记录，现代用药请遵执业医师与药典指导。

> 📚 **文献学提示**：《神农本草经》原书早佚，"神农"为托名，今传全书皆为后世辑复本（明卢复 1616、清孙星衍 1799、清顾观光 1844、日本森立之 1854 等系统并列）。**引用任何《本经》文字都必须注明所据辑本**——"水银属上品还是中品"这类问题的答案，取决于读的是哪个辑本。请先读[概念 00：什么是神农本草经](concepts/00-what-is-bencaojing.md)。

本知识包（bundle）是《神农本草经》（又名《神农本草》，简称《本草经》《本经》）的阅读指南，以**维基文库本（辑复系统通行文本）× 清孙星衍、孙冯翼辑本（1799）的双信源逐条核对**为底：序录全文逐句精读、三品理论与 365 之数、辑本系统与六类系统差异、11 味代表药选读，另附 365 药三品归属完整存目。辑本间异文一律并列登记、不作裁决。

## 🚀 分读者快速开始

**第一次接触中医经典**：
1. 读[概念 00：什么是神农本草经](concepts/00-what-is-bencaojing.md)与[概念 02：三品分类理论](concepts/02-three-grades.md)，建立"这是一部辑复本"的阅读坐标
2. 打开[序录逐句精读](examples/preface-close-reading.md)，从三品总纲句开始逐句读
3. 对照[概念 04：代表药选读](concepts/04-representative-herbs.md)，读几味上品、中品、下品药

**有本草学或中医基础**：
1. 快速过概念 00/01（文献学背景与辑本系统）
2. 直入[三品对照阅读法](examples/three-grades-comparison.md)，理解水银、雄黄三品归属两读
3. 查 [365 药三品归属表](references/modern-research.md) 定位具体药味的品级

**文献/版本研究者**：
1. 概念 01 + [信源参考](references/index.md)两篇
2. [序录逐句精读](examples/preface-close-reading.md)的异文登记（X-1～X-10）
3. 以纸本复核电子转录差异（如同一孙辑本不同电子转录间"石胆"条目出入，见调研事实 BC-019）
