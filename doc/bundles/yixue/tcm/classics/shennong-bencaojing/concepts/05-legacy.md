# 影响与本草学传统：一部被层累保存的经典

## 传承链：原书亡而系统存

原书早佚，但《本经》以"经文被层层转抄、分层保存"的方式延续了两千年：

| 阶段 | 载体 | 对《本经》的处理 |
|---|---|---|
| 汉魏之际 | 《名医别录》 | 在"神农旧条"上增补新内容 |
| 梁（494 年） | 陶弘景《本草经集注》 | 将本经与别录两层以朱墨分书 |
| 唐宋 | 唐宋官修本草 | 继承集注的分层传统 |
| 宋 | 《证类本草》（大观本） | 以黑白字再现经文/增补的边界 |
| 明 | 李时珍《本草纲目》 | 再整理（孙星衍评其"割裂旧文"） |
| 明清以降 | 卢复、孙星衍、顾观光、森立之等辑本 | 从大观本白字中反向辑出《本经》 |

朱墨（黑白）分书是关键机制。孙星衍自序引嘉补注序："所谓神农本经者，以朱字。名医因神农旧条而有增补者，以墨字间於朱字。"——千余年间，历代本草家像地质分层一样保存着"神农层"与"增补层"，清人才能据此辑复。没有这一保存机制，就没有今日任何一部《神农本草经》。

## 注疏传统

《本经》有自成谱系的注疏传统：

| 注本 | 年代 | 注家 |
|---|---|---|
| 《名医别录》 | 汉魏之际 | （托名诸名医） |
| 《本草经集注》 | 494 年 | 梁·陶弘景 |
| 《神农本草经疏》 | 1625 | 明·缪希雍 |
| 《本草崇原》 | 1663 | 清·张志聪 |
| 《神农本草经百种录》 | 1736 | 清·徐大椿 |
| 《本经疏证》 | 1837 | 清·邹澍 |
| 《神农本草经校点》 | 1981 | 今人·尚志钧 |

孙星衍辑本以"《名医》曰"附经文之后、"《吴普》曰"存诸家旧说、"案"语下断，本身即是这一注疏传统的辑复式延续：**读孙辑本的版面结构，就是在同时读"经—注—案"三层**（见[概念 01](01-reconstruction-systems.md)）。

## 《吴普本草》：一个平行的早期见证

孙星衍自序据《魏志》华佗传、《隋书》经籍志指出"吴普本草，梁有六卷"；引嘉本草云"普修神农本草，成四百四十一种"；并断言"是普书宋时已佚"。孙辑药条所附《吴普》引文中"神农∶甘；黄帝∶苦，有毒；扁鹊∶苦；李氏∶大寒"式的诸家并列（如丹沙条），保存了《本经》定型前的多源药性说——这是今日可见的最早"注疏层"之一，比别录、集注更接近诸家旧说的原始形态。

## 现代生命

- **现代研究评价**：现代解题概括本书"创立了药有'四气''五味'的理论，和药分上、中、下'三品'的分类方法"，"创立了药物之间'七情合和'理论和组方配伍的'君臣佐使'原则，总结了丸、散、汤、酒、膏等基本剂型"。
- **出版仍在继续**：上海科技教育出版社 2026 年 1 月新排印孙星衍、孙冯翼辑本（李桂英编译，ISBN 978-7-5428-8556-2/R·529）——两百年前的辑本至今仍在进入书市（见[现代研究与辑本选用建议](../references/modern-research.md)）。
- **经典地位**：在现代中医"四大经典"组合中，《本经》自 1955 年首提书目起即占一席——需知这一"经典群"本身是现代教育建制的产物，其成员名单至今未定，本知识包不把它当作天然知识边界。

## 阅读提示

读《本经》的后续本草（集注→证类→纲目），看到的是"一个不断被注释、被增补、被重排的知识系统"；读清人辑本，看到的是"从层累中反向剥离原层的努力"。两种读法互为镜像——理解了这层关系，才能理解为什么"《本经》原文"必须永远带引号、标辑本。
