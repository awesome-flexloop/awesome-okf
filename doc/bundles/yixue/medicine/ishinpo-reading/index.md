# 《医心方》阅读教程

![平安时代书库中堆积的汉文卷子本与油灯暖光](/_static/bundles/yixue/medicine/ishinpo-reading/images/hero-heian-scroll-library.png)

*AI 生成意境图，非历史图像，仅作阅读氛围辅助*

本知识包（bundle）是面向普通读者的《医心方》阅读指南，基于 Web 公开信源调研整理。《医心方》为日本平安时代丹波康赖于永观二年（984）撰进的三十卷医方类书，是日本现存最古医书，征引中国隋唐以前医籍两百余种、万余条，其中大量典籍在中国本土早已亡佚（《素女经》《洞玄子》《小品方》《养生要集》等），被誉为"六朝·隋唐医学之宝库"。本包侧重文献学视角：成书结构、辑佚价值、版本流传、研究史与选读方法。与[养生经典阅读教程](../../yangsheng/yangsheng-classics-reading/index.md)、[性学经典阅读教程](../../../sheke/sexology/classics-reading/index.md)互为姊妹篇——三者共享"先立地图、再入原典"的读法，本包聚焦《医心方》作为佚书渊薮的独特地位。
