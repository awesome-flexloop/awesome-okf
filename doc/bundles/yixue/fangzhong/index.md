# 🛏️ 房中（Fangzhong）知识包

本分组收录与"房中"（中国古代性文化、房中术典籍）相关的 OKF 知识包。房中是《汉书·艺文志·方技略》所分方技四家（医经、经方、房中、神仙）之一，《汉志》小序以"乐而有节，则和平寿考；及迷者弗顾，以生疾而陨性命"确立其节欲框架；房中八家原书后世全部亡佚，今见文献主要靠出土简帛（马王堆）、域外医书引文（日本《医心方》卷二十八）与清末辑佚（《双梅景闇丛书》）保存。

本分组知识包以**权威原文 + 可核验信源 + 学术与文献学定位**为原则：所有在线链接经实际访问或平台编号核验，所有纸本指南给出版社、年份与 ISBN；托名、辑佚、断代争议两说并陈；**不收录露骨描写，不提供任何实践操作指导**。

## 内容边界提示

本分组所有内容为**学术史、文献学与社会史研究**，研究对象为公版古籍与公开出版物。古籍中"还精补脑""采阴益阳"等主张均属历史文献，**不构成现代医学、养生或任何实践指导，本束不作功效背书**；明清艳情小说、春宫版画仅作文献学史与社会史材料列目，不录正文、不收图像。
