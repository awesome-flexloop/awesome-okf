# 信源核验案例集——五个真实陷阱的处理过程

本案例集记录本次调研中实际遇到的五个核验问题，演示 [08 辨伪方法与信源分级](../concepts/08-authenticity-and-sources.md) 的实战用法。

## 案例 1：NDL《双梅景闇叢書》——原刻还是日译本？

**场景**：日本国立国会图书馆数字馆藏提供《双梅景闇叢書》全文在线（pid/12678185），看起来是"光绪原刻数字化"。

**疑点**：条目显示出版年为昭和五十八年（1983），东京公論社，译者伊吹浄，214 页——与叶德辉 1903-1911 长沙郋园刊本的年代、形态均不符。

**核验路径**：

1. 比对 NDL 书目标注（叢書名："中国古典文学" 第 1；体裁：翻訳書）；
2. 与《郋园先生全书》影印本著录核对原刻形态。

**结论与处理**（FRG-116）：该资源是 1983 年伊吹净**日文译本**，非叶氏原刻。本束 references 中保留该 URL 但明确标注"日译本"，引用原刻须查《郋园先生全书》或丛书影印本。

**方法论**：数字馆藏 ≠ 原刻；必须核对出版者、年代、体裁（翻译/原文）三项。

## 案例 2：识典《医心方》OCR——"素女"变"素久"

**场景**：识典古籍《医心方》卷二十八页面（影写本图像 OCR）文字可读，检索"素女"命中数极少。

**疑点**：作为引《素女经》数十次的卷次，"素女"不可能如此稀少。

**核验路径**：

1. 对照同页影印图像与排印文本（中华文库《醫心方/卷二十八》）；
2. 发现 OCR 将"素女"误作"素久"、俗字与片假名混入。

**结论与处理**（FRG-117）：识典影写本 OCR 列为 C 级信源——只作线索与定位（页码、篇目），**不引用、不转写**其文字；引用原文用中华文库排印本或人卫影印安政本核对。

**方法论**：图像 OCR 的错字在俗字、异体字、双栏混排时高发；专名（人名、书名）是抽查重点。

## 案例 3：网络"素女经九法/二十四式"

**场景**：多个养生类网站与短视频流行"《素女经》九法/二十四式"名目与详图。

**疑点**：《医心方》卷二十八有"九法第十二""卅法第十三"，为《素女经》《洞玄子》佚文中的仿生名目；而"二十四式"不见于任何目录、辑本或研究文献。

**核验路径**：

1. 查《隋志》《两唐志》《抱朴子·遐览》著录——无"二十四式"；
2. 查叶德辉辑本与高文铸述略引文具存的篇目——九法、卅法可溯，二十四式无出处；
3. 比对网络文本措辞——现代白话、夹杂当代保健术语。

**结论与处理**（FRG-113）：九法、卅法为辑本中确实存在的篇目（本束不录其内容）；"二十四式"系当代演绎或编造，不具文献价值。在 [08 辨伪](../concepts/08-authenticity-and-sources.md) 中作为低权威读物典型案例登记。

**方法论**：名目存在 ≠ 内容可信；凡古籍名物先查著录链与辑本，查不到的"古书内容"一律存疑。

## 案例 4：《洞玄子》成书年代——唐？隋唐？

**场景**：《洞玄子》不见任何史志著录，其成书年代有"唐代""隋唐间"两种说法。

**核验路径**：

1. 高文铸《〈医心方〉房中养生文献述略》据引文与文体分析，推断成书于唐代的可能性极大；
2. 叶德辉校刻《大乐赋》时发现白行简（唐）赋中引《洞玄子》语，为隋唐存在该书提供旁证（WENXUE-086）；
3. 但均无直接著录证据把年代定死。

**结论与处理**（FRG-110）：两说并陈——"成书于唐代的可能性极大（高文铸）；叶德辉据《大乐赋》引文主隋唐说"，措辞用"可能性极大""盖"，不写死具体年代。

**方法论**：著录链缺环时，旁证（类书引用、同时代文学互文）只能给出概率结论；两说并陈是纪律，不是骑墙。

## 案例 5：《汉志》房中卷数——191 卷还是 186 卷？

**场景**：《汉志》八家著录逐家相加：26+36+23+20+25+24+20+17 = 191 卷；但小序总结作"房中八家，百八十六卷"（186 卷）。

**疑点**：同篇之内 5 卷差异。

**核验路径**：

1. 逐家书卷数复核无误；
2. 查校勘学史——异文来源（传写致误或小序概括本有出入）无定论。

**结论与处理**（CAT-004）：facts 中并记两个数字并标"异文待考"，概念页 [01 目录学史](../concepts/01-catalog-history.md) 同时呈现。不擅自取舍、不"修正"原文。

**方法论**：古籍内部数字冲突是常态；能定则定（有版本依据），不能定则标待考——两种记录都保留，这正是文献学"忠实"的要求。

## 五个案例的共性纪律

1. 凡数字资源先核对版本信息（出版者/年代/体裁）；
2. OCR 文本只作线索，专名必抽查；
3. 名目先查著录链，无出处不引用；
4. 断代证据不足时两说并陈；
5. 原文异文不擅改，标待考。
