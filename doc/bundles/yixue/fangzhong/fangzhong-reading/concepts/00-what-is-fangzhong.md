# 房中是什么——界定、异称与学术定位

## 目录学界定：方技四家之一

"房中"是《汉书·艺文志·方技略》的正式类目名。班固（32-92）据刘歆《七略》删要而成的《汉志》，将方技分为四家：**医经、经方、房中、神仙**（CAT-001）。房中类著录八家、合计 191 卷（小序作"百八十六卷"，差异待考，见 [01 目录学史](01-catalog-history.md)）。

《汉志》房中小序给出的官方定性是（CAT-003）：

> 房中者，情性之极，至道之际，是以圣王制外乐以禁内情，而为之节文……乐而有节，则和平寿考。及迷者弗顾，以生疾而陨性命。

也就是说，在汉代国家知识体系中，房中既不是诲淫之书，也不是神仙秘术，而是一门以**"节"为纲**的养生方技：承认情欲为人性之极，但以节度为健康与长寿的条件。这个"乐而有节"的框架被后世医家房中论述继承为基本基调（CAT-013）。

## 历代异称

房中类文献在历代有多种异称（CAT-016）：

| 异称 | 语境 |
|------|------|
| 阴道 | 《汉志》书名多用，如《容成阴道》《尧舜阴道》——以"阴阳交接之道"为名 |
| 养阳 | 如《黄帝三王养阳方》，方技书名 |
| 接阴之道 | 马王堆《十问》等出土文献用语 |
| 玄素之术 | 玄女、素女的合称，葛洪《抱朴子·极言》"黄帝论道养性，则资玄素二女"（CAT-009） |
| 黄赤之道 / 男女合气 | 早期天师道仪式性合气术的教内称呼（DAOJIAO-070） |
| 御女之术 | 六朝隋唐道医文献用语 |
| 房内 | 日本《医心方》卷二十八篇名，沿用唐人的"房内"称谓（JIYI-034） |

## 内容构成：四条线索

综合出土文献、辑佚文献与医道记载，房中传统包含四条可区分的线索：

1. **节欲养生论**：以"节"为纲的性与健康论述——《汉志》小序、《素问》、孙思邈《千金要方·房中补益》、李鹏飞《三元延寿参赞书》"四不可"为代表（详见 [04 医家性医学](04-medical-tradition.md)）。
2. **求嗣种子术**：求子、养胎、胎教与种子方药——马王堆《胎产书》（EXC-022）开其端，明代万全《广嗣纪要》、张介宾《景岳全书·妇人规·子嗣类》集大成。
3. **交接节度与养生技术**：交接的时机、节律、仿生姿态与"八益七损"等名目——马王堆《合阴阳》《天下至道谈》（EXC-020、EXC-021）与《医心方》卷二十八所引《素女经》《玉房秘诀》《洞玄子》为代表（详见 [03 《医心方》与辑佚链](03-yixin-fang-and-jiyi.md)）。
4. **道教内丹化阐释**：房中话语在道教中经历仪式化（黄书合气）、被改革废除（寇谦之，DAOJIAO-071）、再被内丹隐喻吸收（清修/双修解释之争）三个阶段（详见 [05 道教房中](05-daoist-fangzhong.md)、[06 内丹清修与双修](06-neidan-qingxiu-shuangxiu.md)）。

## 现代学术定位

房中研究在现代学术中分布于四个学科视角：

- **医学史 / 中医文献学**：马继兴《马王堆古医书考释》、高文铸《〈医心方〉房中养生文献述略》、刘鹏关于房中与中医肾—髓—脑理论关联的研究（YIXUE-065）；
- **宗教史 / 道教史**：葛洪房中观、天师道合气术、内丹双修派——陈国符《道藏源流考》、胡孚琛《道学通论》、林富士《略論早期道教與房中術的關係》（DAOJIAO-082、078、083）；
- **社会史 / 文化史**：高罗佩《中国古代房内考》开创、江晓原《性张力下的中国人》修正、刘达临《中国古代性文化》通史（XUESHU-093、098、100）；
- **海外汉学**：Douglas Wile《Art of the Bedchamber》（SUNY 1992）、Joseph Needham《SCC》Vol.5 Part 5（1983）、马伯乐（Henri Maspero）道教养生研究、Donald Harper 马王堆房中书论文（XUESHU-101、102，DAOJIAO-084，EXC-027）。
