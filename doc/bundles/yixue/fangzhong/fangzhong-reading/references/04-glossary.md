# 术语表

| 术语 | 简释 |
|------|------|
| 方技 | 《汉志》所载古代医学技术类知识的总称，分医经、经方、房中、神仙四家 |
| 房中 | 方技四家之一；以性与养生、求嗣为内容的文献与方技门类，以"乐而有节"为基本框架 |
| 阴道 / 接阴 | 房中文献早期异称，如《容成阴道》；马王堆帛书称"接阴之道" |
| 玄素 | 玄女、素女的合称，房中术的代称（"资玄素二女"） |
| 天癸 | 《素问》概念，指主宰生殖能力成熟与衰竭的物质/节律；女子二七至、七七竭，丈夫二八盛、八八尽 |
| 八益七损 | 马王堆《天下至道谈》所载交接节度名目；八益（治气、致沫等）为有益做法，七损（闭、泄等）为有害做法 |
| 仿生十节 | 马王堆《合阴阳》以动物动作命名的交接姿态名目（虎游、蝉附等） |
| 节宣之和 | 葛洪用语：既不纵欲（任情肆意）也不禁欲（都绝阴阳），以节度为养生原则 |
| 四不可 | 李鹏飞《三元延寿参赞书》纲领：欲不可纵、不可早、不可强、不可绝 |
| 还精补脑 | 古籍中的房中养生主张（葛洪列为房中家"大要"）；本束仅作历史主张登记，不作功效背书 |
| 托名 | 古书假托古人/神仙为作者的惯例；房中书托名黄帝、素女、彭祖等，作者署名不可信 |
| 辑佚 | 从类书、注疏、域外文献的引文中汇辑已佚古书文本的工作；叶德辉辑本、孙星衍辑《素女方》是典型 |
| 辑本 | 辑佚所得文本；今见《素女经》《玉房秘诀》《洞玄子》通行文本全部是辑本，非原书 |
| 著录链 | 一部古书在历代目录/类书中的著录与引用记录，用于断代（如《素女经》见《抱朴子·遐览》与《隋志》） |
| 黄书合气 | 早期天师道（三张）仪式性男女合气术，又称黄赤之道、男女合气；寇谦之 423 年改革明令废除 |
| 三张 | 天师道早期领袖张陵、张衡、张鲁；"三张伪法"为寇谦之改革对象 |
| 内丹 | 道教修炼技术，以身体为鼎炉、精气神为药物；隋唐后兴起，取代外丹主流地位 |
| 清修 | 内丹一派，主张独修自身精气神，丹经中阴阳男女之象读为自身内景 |
| 阴阳双修 | 内丹一派（彼家丹法/龙虎丹法），主张男女同修；翁葆光注《悟真篇》主此说，东派陆西星、西派李西月承之 |
| 三家四派 | 胡孚琛丹法分类：文始派（虚无丹法）、少阳派（清净丹法）、阴阳派（彼家丹法/龙虎丹法） |
| 南宗两系 | 张伯端之后：石泰—薛道光—陈楠—白玉蟾清修系；刘永年—翁葆光阴阳系 |
| 东派 / 西派 | 内丹阴阳派两支：明代陆西星（东派，《方壶外史》）；清代李西月（西派，《道窍谈》，"清静立基，阴阳双修"） |
| 半井家本 | 《医心方》古抄本系统，1560 年下赐半井家，1984 年认定日本国宝，藏东京国立博物馆 |
| 仁和寺本 | 《医心方》京都仁和寺藏抄本，最重要校勘本 |
| 安政本 | 1859 年（安政六年）多纪元坚等以半井家本为底本影写刊行的《医心方》刊本；现代人卫影印本之底本 |
| 郋园 | 叶德辉号；其辑刊《双梅景闇丛书》称郋园刊本，收入《郋园先生全书》 |
| 性张力 | 江晓原概念：礼教性规范与社会实际情欲生活之间的结构性张力 |
