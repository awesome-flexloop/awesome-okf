# 知识目录

[知识目录](https://cloud.google.com/products/knowledge-catalog)（前身为 Dataplex）是一个 AI 驱动的数据目录和元数据管理平台。它为您的所有数据（结构化和非结构化）提供动态知识图谱，为 AI 智能体提供语义和业务上下文。

本仓库包含演示知识目录功能的工具、智能体和示例，以及构建上下文管理、数据丰富和检索解决方案的资源。
