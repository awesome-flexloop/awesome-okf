# 实战示例

ManimGL 实战示例，共 4 篇，从基础图形到交互进阶。

* [基础图形绘制](basic-shapes.md) — 学习创建圆形、方形、三角形、线条、箭头等基础几何图形，掌握颜色填充、描边设置和位置排列方法，通过 Create 动画逐个显示图形。
* [简单动画实战](simple-animation.md) — 掌握 Create/FadeIn/FadeOut/Transform/ReplacementTransform 等常用动画，对比不同 rate_func 缓动效果，学习 animate 语法糖链式调用和 lag_ratio 延迟动画。
* [相机运动](camera-movement.md) — 学习操控 self.frame 实现镜头推拉摇移：平移(shift)、缩放(scale)、旋转(rotate)、跟随移动对象、2D/3D 视角切换，复现 3Blue1Brown 视频中流畅的镜头语言。
* [更新器与交互](updaters-interaction.md) — 掌握 add_updater 基本用法、always/f_always 持续更新、ValueTracker 数值驱动、鼠标位置追踪，实现响应式动画和简单的可交互场景。
