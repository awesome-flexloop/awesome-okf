# ManimGL 缓动函数（Rate Functions）参考

本文档登记 `manimlib/utils/rate_functions.py` 中定义的所有内置缓动函数（F-132 ~ F-146）。缓动函数（Rate Function）控制动画过程中参数 alpha（∈ [0,1]）随时间的变化曲线，决定动画的加速、减速、回弹等视觉效果。

## 基础缓动函数

### 1. linear（线性）

| 属性 | 值 |
|------|-----|
| 函数签名 | `linear(t: float) -> float` |
| 数学特征 | `f(t) = t`，恒等映射 |
| 事实依据 | F-132 |

**曲线形态**：严格的直线，斜率恒定为1，无加速无减速。

**典型使用场景**：
- 需要恒定速度的机械运动
- 与其他非线性组合的基础构建块
- 精确控制动画进度的场景

---

### 2. smooth（平滑，默认）

| 属性 | 值 |
|------|-----|
| 函数签名 | `smooth(t: float) -> float` |
| 数学特征 | `f(t) = t³(10s² + 5st + t²)`，其中 `s = 1-t`；等价于三次贝塞尔曲线 `[0,0,0,1,1,1]` |
| 事实依据 | F-133 |

**曲线形态**：S形曲线，在 t=0 和 t=1 处一二阶导数均为0，两端静止、中间加速后减速，起始和结束非常平滑自然。

**典型使用场景**：
- **默认缓动函数**（Animation 类 rate_func 参数默认值）
- 大多数普通变换动画（移动、缩放、旋转）
- 需要自然流畅观感的场景

---

### 3. rush_into（急入）

| 属性 | 值 |
|------|-----|
| 函数签名 | `rush_into(t)` |
| 数学特征 | `f(t) = 2 * smooth(0.5 * t)` |
| 事实依据 | F-134 |

**曲线形态**：前半段加速明显，后半段趋于平滑。动画开始时快速冲入，结尾时速度放缓。

**典型使用场景**：
- 物体快速进入画面
- 强调"突然出现"的效果
- 撞击、切入类动画

---

### 4. rush_from（急出）

| 属性 | 值 |
|------|-----|
| 函数签名 | `rush_from(t)` |
| 数学特征 | `f(t) = 2 * smooth(0.5 * (t + 1)) - 1` |
| 事实依据 | F-135 |

**曲线形态**：前半段缓慢启动，后半段加速冲出。动画开始平稳，结束时快速离去。

**典型使用场景**：
- 物体快速离开画面
- 强调"突然消失"的效果
- 退场、飞离类动画

---

### 5. slow_into（缓入，圆形）

| 属性 | 值 |
|------|-----|
| 函数签名 | `slow_into(t)` |
| 数学特征 | `f(t) = sqrt(1 - (1-t)²)`，四分之一圆弧 |
| 事实依据 | F-136 |

**曲线形态**：圆形曲线，起始时速度较快，随后逐渐减速至停止，轨迹沿第一象限四分之一圆弧。

**典型使用场景**：
- 物体接近目标时自然减速
- 停靠、落位类动画
- 需要"软着陆"效果的运动

---

### 6. double_smooth（双平滑）

| 属性 | 值 |
|------|-----|
| 函数签名 | `double_smooth(t)` |
| 数学特征 | t<0.5 时 `0.5*smooth(2t)`；t≥0.5 时 `0.5*(1+smooth(2t-1))` |
| 事实依据 | F-137 |

**曲线形态**：由两段 smooth 曲线拼接而成，中段（t=0.5附近）有一段近似线性的匀速区间，两端仍然保持平滑。比普通 smooth 中段更"平直"。

**典型使用场景**：
- 长距离移动中需要一段匀速过程
- 希望减少普通 smooth 的"停顿感"
- 节奏更均匀的连续运动

---

### 7. there_and_back（去而复返）

| 属性 | 值 |
|------|-----|
| 函数签名 | `there_and_back(t)` |
| 数学特征 | t<0.5 时 `smooth(2t)`；t≥0.5 时 `smooth(2(1-t))` |
| 事实依据 | F-138 |

**曲线形态**：对称的钟形曲线，从0上升到1（t=0.5时），再平滑回到0。形成"去程-回程"的完整往返。

**典型使用场景**：
- 指示性动画（指向某物然后返回）
- 强调、提示类动画
- 脉冲、呼吸效果的基础

---

### 8. there_and_back_with_pause（去而复返带暂停）

| 属性 | 值 |
|------|-----|
| 函数签名 | `there_and_back_with_pause(t, pause_ratio=1/3)` |
| 数学特征 | 三段式：去程 smooth → 中间 pause_ratio 区间保持值1 → 回程 smooth |
| 事实依据 | F-139 |

**曲线形态**：类似 there_and_back，但在峰值处有一段暂停平台，默认暂停占总时长的1/3。物体到达目标后"停留"一会再返回。

**典型使用场景**：
- 需要观众看清目标状态的提示动画
- 指认、强调并停留
- 展示-返回类交互

---

### 9. running_start（起跑）

| 属性 | 值 |
|------|-----|
| 函数签名 | `running_start(t, pull_factor=-0.5)` |
| 数学特征 | `f(t) = bezier([0, 0, pull_factor, pull_factor, 1, 1, 1])(t)` |
| 事实依据 | F-140 |

**曲线形态**：起始阶段有一段"后退-蓄力"再向前冲的效果（pull_factor 为负时），类似运动员起跑前的预备动作。曲线先略低于0再快速上升。

**典型使用场景**：
- 弹性、有冲劲的启动
- 卡通风格的运动
- 需要表现"蓄力"感的动画

---

### 10. overshoot（过冲）

| 属性 | 值 |
|------|-----|
| 函数签名 | `overshoot(t, pull_factor=1.5)` |
| 数学特征 | `f(t) = bezier([0, 0, pull_factor, pull_factor, 1, 1])(t)` |
| 事实依据 | F-141 |

**曲线形态**：曲线先超过目标值1（达到 pull_factor，默认1.5），然后回落到1。形成"冲过了头再回来"的弹性效果。

**典型使用场景**：
- 弹性到达、弹簧效果
- 活泼的 UI 动画
- 强调到位感的变换

---

### 11. wiggle（摆动）

| 属性 | 值 |
|------|-----|
| 函数签名 | `wiggle(t, wiggles=2)` |
| 数学特征 | `f(t) = there_and_back(t) * sin(wiggles * π * t)` |
| 事实依据 | F-143 |

**曲线形态**：在 there_and_back 的包络下叠加正弦振荡，默认摆动2次。物体来回摆动的同时幅度先增后减。

**典型使用场景**：
- 摇头、摆手等否定/不确定动画
- 振动、摇晃效果
- 引起注意的抖动提示

---

### 12. lingering（滞留）

| 属性 | 值 |
|------|-----|
| 函数签名 | `lingering(t)` |
| 数学特征 | `f(t) = squish_rate_func(lambda t: t, 0, 0.8)(t)`，即0~0.8区间线性，0.8之后保持1 |
| 事实依据 | F-145 |

**曲线形态**：前期80%时间线性推进到1，最后20%时间停留在1不动。动画较快完成然后"卡住"在最终状态。

**典型使用场景**：
- 快速到位后保持
- 提前完成的等待感
- 需要早停的动画序列

---

### 13. exponential_decay（指数衰减趋近）

| 属性 | 值 |
|------|-----|
| 函数签名 | `exponential_decay(t, half_life=0.1)` |
| 数学特征 | `f(t) = 1 - exp(-t / half_life)` |
| 事实依据 | F-146 |

**曲线形态**：指数上升曲线，开始时快速逼近1，随后越来越慢地趋近，永远不会真正到达（理论上渐近）。半衰期 half_life=0.1 意味着 t=0.1 时达到约0.63，t=0.3时已接近0.95。

**典型使用场景**：
- 物理阻尼、充电效应
- 渐近式的聚焦/模糊
- 自然衰减类效果

## 高阶缓动函数（Higher-Order Functions）

以下函数接受其他缓动函数作为参数，返回修饰后的新缓动函数。

### 14. not_quite_there（未达终点）

| 属性 | 值 |
|------|-----|
| 函数签名 | `not_quite_there(func=smooth, proportion=0.7)` |
| 数学特征 | 返回 `proportion * func(t)`，即目标值乘以比例系数（默认0.7） |
| 事实依据 | F-142 |

**效果描述**：动画不会完全到达终点，只到达 proportion 指定的比例位置。默认只到70%就停止。

**典型使用场景**：
- 部分动画、半途停顿
- 下拉、展开的预览效果
- 链式动画的中间步骤

**用法示例**：
```python
# 只执行到70%的平滑动画
play(..., rate_func=not_quite_there(smooth))
# 只执行到50%的线性动画
play(..., rate_func=not_quite_there(linear, proportion=0.5))
```

---

### 15. squish_rate_func（区间压缩）

| 属性 | 值 |
|------|-----|
| 函数签名 | `squish_rate_func(func, a=0.4, b=0.6)` |
| 数学特征 | t<a 时返回 func(0)；t>b 时返回 func(1)；中间映射到 func((t-a)/(b-a)) |
| 事实依据 | F-144 |

**效果描述**：将原缓动函数的有效区间从 [0,1] 压缩到 [a,b]，之前保持起始值，之后保持结束值。默认在40%~60%时间段内完成动画，其余时间静止。

**典型使用场景**：
- 动画时序编排（多个动画在不同时间段触发）
- 延迟启动、提前结束
- 精确控制动画发生的时间窗口

**用法示例**：
```python
# 前50%时间等待，后50%时间完成smooth动画
play(..., rate_func=squish_rate_func(smooth, 0.5, 1.0))
# 前20%快速完成，后80%保持
play(..., rate_func=squish_rate_func(rush_into, 0, 0.2))
```

## 函数关系速览

```
linear ───────────────────────────────────── 恒等直线
smooth ───────────────────────────────────── 默认S曲线（两端零导数）
├─ rush_into ─────────────────────────────── 2*smooth(0.5t)
├─ rush_from ─────────────────────────────── 2*smooth(0.5(t+1))-1
├─ double_smooth ─────────────────────────── 两段smooth拼接
├─ there_and_back ────────────────────────── smooth(2t) → smooth(2(1-t))
│  └─ there_and_back_with_pause ──────────── 加中间暂停平台
│     └─ wiggle ──────────────────────────── 叠加正弦振荡
├─ running_start ─────────────────────────── 贝塞尔曲线（负pull_factor）
├─ overshoot ─────────────────────────────── 贝塞尔曲线（正pull_factor）
├─ lingering ─────────────────────────────── squish_rate_func(linear,0,0.8)
└─ not_quite_there ───────────────────────── 比例缩放高阶函数
slow_into ────────────────────────────────── 圆形缓入 sqrt(1-(1-t)²)
exponential_decay ───────────────────────── 指数趋近 1-exp(-t/half_life)
squish_rate_func ─────────────────────────── 区间压缩高阶函数
```
