# 公文写作四原则与常见语病

## 是什么

公文写作的质量标准可以归纳为四条原则：**准确、规范、简明、实效**。它们对应条例对公文内容“情况属实、观点明确、表述准确、文字精练”的要求，也是企业文书审核的实用尺子。

## 为什么

正式文书的读者带着明确目的阅读：要知道“发生了什么、要我做什么、什么时候做完”。任何不准确（数字错、人名错）、不规范（文种错、格式缺）、不简明（套话淹没重点）、不实效（没有行动要求和时限）的文字，都会转化为执行成本——返工、误读、推诿、错过时限。

## 怎么做：四原则与操作方法

### 原则一：准确——事实与数字零容错

- 人名、职务、单位名称、日期、金额、比例必须与原始凭据一致；引用法规写全称和文号。
- 请示一文一事（F-025）；报告中不夹带请示事项。
- 写完后对每一个数字、每一个专有名词回查来源。

### 原则二：规范——文种、格式、用语各就各位

- 文种按 [15文种总览](01-document-types.md) 选择；标题 = 机关 + 事由 + 文种。
- 格式按 [18要素](02-format-elements.md) 的企业简化清单核对。
- 用语得体：上行文用“拟、请、恳请、妥否请批示”；下行文用“决定、要求、务必、不得”；平行文用“商请、烦请、为盼”。

### 原则三：简明——一页能说完不写两页

- 结论先行：第一段写明目的和核心事项，背景放后面。
- 分条列项：执行要求用“一、二、三”或“1. 2. 3.”，每条只讲一件事。
- 删除套话：“为进一步加强……全面贯彻……高度重视”等开头若与事项无关，一律删。

### 原则四：实效——对象意识与闭环

- 动笔前回答三问：**谁读？要他做什么？什么时候做完？**
- 通知类文书必须有：时限、责任人、联系方式；请示类必须有：明确请求事项（批准什么）。
- 行文闭环：请示要跟踪批复、通知要确认收悉、纪要要跟催议定事项（与收文办理“催办、答复”程序对应）。

### 公文语言特点

- 多用祈使句和陈述句，不用感叹句、反问句；
- 第三人称客观表述，不用“我觉得、大概、可能吧”；
- 用确定词语：“应当、不得、于×日前”，不用“尽快、适当、有关部门”等模糊表述（规章制度中尤其重要）；
- 不使用网络用语、表情符号、口语缩略。

## 常见坑：高频语病清单

| 类型 | 错误示例 | 正确写法 |
|---|---|---|
| 文种混用 | 《关于采购电脑的请示报告》 | 《关于采购办公电脑的请示》（一文一事） |
| 标题缺要素 | 《通知》 | 《××公司关于国庆节放假安排的通知》 |
| 日期不规范 | “9.3 即日生效” | “2026年9月3日”“自2026年9月10日起施行” |
| 时限模糊 | “请尽快报送” | “请于9月8日17:00前报送行政部” |
| 责任不清 | “由相关部门落实” | “由人力资源部牵头，各部门配合” |
| 数字打架 | 正文“预算15万”，附件“18万” | 全文数字一处来源，发出前核对 |
| 报告夹带请示 | 工作总结末尾“另请领导批准新增编制” | 编制事项单独行文请示 |
| 结尾误用 | 请示结尾“特此报告” | 请示用“妥否，请批示”；报告用“特此报告” |
| 邮件无主题 | 主题“您好” | “【请示】三季度招聘预算申请（请9月10日前批复）” |

## 常见坑与边界

- 四原则适用于正式行文与重要事务文书；即时通讯、头脑风暴草稿不必套用，避免沟通僵化。
- “简明”不等于省略关键信息——责任、时限、依据永远不能为短而删。
- 边界：本原则为教学归纳（F-034、F-037），党政机关公文的完整审核标准以条例第五章“公文拟制”及各机关办文规定为准。
