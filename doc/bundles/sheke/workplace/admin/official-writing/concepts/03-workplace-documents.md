# 职场常用文书：事务文书、专用书信与商务邮件

## 是什么

行政人事岗位日常写作中，真正属于 15 种法定公文的只是少数；大量产出是**事务文书**（计划、总结、简报、规章制度、会议记录）、**专用书信**（介绍信、证明信、邀请函、感谢信）和**商务邮件/即时通讯**。它们不属于法定公文（F-034），没有强制格式，但普遍参照公文的格式与语言规范。

## 为什么：先分清“法定”与“事务”，才不会用错力气

- 法定公文重**效力**：文种、格式、用印都有规定，错了影响文件效力。
- 事务文书重**实用**：把事说清、把责任落实、能归档检索即可，格式可简化。
- 新手常见偏差是把事务文书当公文“摆架子”（空话套话凑篇幅），或把正式行文当邮件“太随意”（申请预算只发一条微信）。判断标准：**这件事需不需要追责、归档、对外证明？** 需要就按正式行文，不需要就用事务文书或邮件。

## 怎么做：三类文书的写法要点

### 一、事务文书（企业内部最高频）

| 文书 | 核心结构 | 常见坑 |
|---|---|---|
| 工作计划 | 目标（可量化）→ 重点任务（分条）→ 时间节点 → 责任人 → 资源需求 | 只有口号没有指标；任务无责任人 |
| 工作总结 | 完成情况（数据对照目标）→ 亮点做法 → 问题与原因 → 下步打算 | 流水账；只写“做了什么”不写“做成了什么” |
| 工作简报 | 标题 → 导语（一段说清何事何果）→ 主体（分条/分段）→ 结尾 | 写成新闻稿；篇幅过长 |
| 规章制度 | 目的依据 → 适用范围 → 具体条款（该做/不该做）→ 奖惩 → 生效日期 | 条款模糊（“适当”“及时”无定义）；无生效日期 |
| 会议记录 | 时间地点、主持人、参会人、议题、发言要点、决定事项 | 求全照抄；无决议事项栏 |

### 二、会议记录 vs 纪要（重点辨析）

| 维度 | 会议记录 | 纪要 |
|---|---|---|
| 性质 | 事务文书（内部档案） | 法定文种（15种之一） |
| 内容 | 谁讲了什么，求全 | 会议主要情况和**议定事项**，要决 |
| 写法 | 按发言顺序记 | 按议题归纳：议题—结论—责任人—时限 |
| 发出 | 一般不外发，存档备查 | 可正式印发，作为执行依据 |

操作要点：开会时做**记录**（素材），会后整理成**纪要**（产出）。纪要模板见 [通知与纪要范例](../examples/01-notice-minutes-samples.md)，会议全流程见 [会议管理](../../admin-operations/concepts/03-meeting-management.md)。

### 三、专用书信与商务邮件

- **介绍信/证明信**：用于对外证明身份或事项，必须写明被介绍人姓名、身份、事由、有效期，加盖公章；证明信内容只写已核实事实，不写评价。
- **邀请函/感谢信**：结构为“事由—时间地点—邀请/感谢内容—联系方式”，语气敬重但不夸张。
- **商务邮件**：五段结构——主题（事由+行动/期限）、称呼、正文（一事一邮件、结论先行、分条列项）、祝颂语（对外可用“顺颂商祺”）、署名（姓名、职务、单位、电话）。可直接套用的模板见 [商务邮件模板](../examples/03-business-email-templates.md)。

### 企业“借用”法定文种场景表（F-037）

| 企业场景 | 借用文种 | 行文方向 |
|---|---|---|
| 布置工作、发布制度、告知会议/放假 | 通知 | 向下/周知 |
| 表彰优秀、批评违纪、传达事故教训 | 通报 | 向下 |
| 向公司/上级汇报工作、答复询问 | 报告 | 向上 |
| 申请预算、编制、采购、用印授权 | 请示 | 向上（一文一事、期复） |
| 对客户/供应商/兄弟单位商洽、询价、催办 | 函 | 平行/对外 |
| 记载会议决定、布置执行 | 纪要 | 内部 |
| 人事任免、重大处分、组织调整 | 决定 | 向下 |

人事岗位高频正式行文（录用通知、解除劳动合同通知等）还需符合劳动法规，见 [劳动合同生命周期](../../../hr/labor-law-compliance/concepts/01-labor-contract-lifecycle.md)。

## 常见坑与边界

- **用微信/口头替代正式行文**：预算申请、请假审批、辞退通知等需要留痕的事项，仅有聊天记录在争议中举证力弱。
- **总结只写过程不写结果**：“召开了5次会议”不等于“推动了什么结果”，总结要对照目标写数据。
- **邮件一封多事**：一封邮件同时谈合同、催款、约时间，对方无法逐条处理；一事一邮件，主题可检索。
- **证明信滥用**：为员工出具收入证明时虚高金额，可能承担法律责任；只证明可核实的事实。
- 边界：本条所述为企业通行实践（【市场实践】【教学归纳】），不具有法规强制力；党政机关办文仍以条例为准。
