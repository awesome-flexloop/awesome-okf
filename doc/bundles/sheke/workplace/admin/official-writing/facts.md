## 一、法规基准

| 编号 | 事实内容 | 信源 |
|---|---|---|
| F-001 | 【P0】《党政机关公文处理工作条例》由中共中央办公厅、国务院办公厅于2012年4月16日印发（中办发〔2012〕14号），自2012年7月1日起施行。 | S1 |
| F-002 | 【P0】条例第八条：公文种类主要有15种——决议、决定、命令（令）、公报、公告、通告、意见、通知、通报、报告、请示、批复、议案、函、纪要。 | S1（第八条） |
| F-003 | 决议：适用于会议讨论通过的重大决策事项。 | S1（第八条） |
| F-004 | 决定：适用于对重要事项作出决策和部署、奖惩有关单位和人员、变更或者撤销下级机关不适当的决定事项。 | S1（第八条） |
| F-005 | 命令（令）：适用于公布行政法规和规章、宣布施行重大强制性措施、批准授予和晋升衔级、嘉奖有关单位和人员。 | S1（第八条） |
| F-006 | 公报：适用于公布重要决定或者重大事项。 | S1（第八条） |
| F-007 | 公告：适用于向国内外宣布重要事项或者法定事项。 | S1（第八条） |
| F-008 | 通告：适用于在一定范围内公布应当遵守或者周知的事项。 | S1（第八条） |
| F-009 | 意见：适用于对重要问题提出见解和处理办法。 | S1（第八条） |
| F-010 | 【P0】通知：适用于发布、传达要求下级机关执行和有关单位周知或者执行的事项，批转、转发公文。 | S1（第八条） |
| F-011 | 通报：适用于表彰先进、批评错误、传达重要精神和告知重要情况。 | S1（第八条） |
| F-012 | 【P0】报告：适用于向上级机关汇报工作、反映情况，回复上级机关的询问。 | S1（第八条） |
| F-013 | 【P0】请示：适用于向上级机关请求指示、批准。 | S1（第八条） |
| F-014 | 批复：适用于答复下级机关请示事项。 | S1（第八条） |
| F-015 | 议案：适用于各级人民政府按照法律程序向同级人民代表大会或者人民代表大会常务委员会提请审议事项。 | S1（第八条） |
| F-016 | 函：适用于不相隶属机关之间商洽工作、询问和答复问题、请求批准和答复审批事项。 | S1（第八条） |
| F-017 | 纪要：适用于记载会议主要情况和议定事项。 | S1（第八条） |

## 二、格式要素

| 编号 | 事实内容 | 信源 |
|---|---|---|
| F-018 | 【P0】条例第九条：公文一般由18个要素组成——份号、密级和保密期限、紧急程度、发文机关标志、发文字号、签发人、标题、主送机关、正文、附件说明、发文机关署名、成文日期、印章、附注、附件、抄送机关、印发机关和印发日期、页码。 | S1（第九条） |
| F-019 | 【P0】标题由发文机关名称、事由和文种组成（第九条第七项）。 | S1（第九条） |
| F-020 | 发文字号由发文机关代字、年份、发文顺序号组成，如“中办发〔2012〕14号”；联合行文时使用主办机关的发文字号。 | S1（第九条第五项） |
| F-021 | 成文日期署会议通过或者发文机关负责人签发的日期；联合行文时，署最后签发机关负责人签发的日期。 | S1（第九条第十二项） |
| F-022 | 紧急程度是公文送达和办理的时限要求。根据紧急程度，紧急公文应当分别标注“特急”“加急”。 | S1（第九条第三项） |
| F-023 | 附注是公文印发传达范围等需要说明的事项，如“（此件公开发布）”。 | S1（第九条第十四项） |

## 三、行文规则

| 编号 | 事实内容 | 信源 |
|---|---|---|
| F-024 | 【教学归纳】行文关系根据隶属关系和职权范围确定，按方向分为：上行文（向上级机关行文，如请示、报告）、下行文（向下级机关行文，如通知、通报、批复、决定）、平行文（不相隶属机关之间行文，主要为函）。 | S1（第四章）【教学归纳】 |
| F-025 | 【P0】请示应当一文一事；不得在报告等非请示性公文中夹带请示事项。 | S1（第十五条） |
| F-026 | 向上级机关行文，原则上主送一个上级机关，根据需要同时抄送相关上级机关和同级机关，不抄送下级机关。 | S1（第十五条） |
| F-027 | 同级党政机关、党政机关与其他同级机关必要时可以联合行文；属于党委、政府各自职权范围内的工作，不得联合行文。 | S1（第十七条） |
| F-028 | 党委、政府的部门依据职权可以相互行文；部门内设机构除办公厅（室）外不得对外正式行文。 | S1（第十七条） |

## 五、职场文书市场实践

| 编号 | 事实内容 | 信源 |
|---|---|---|
| F-034 | 【教学归纳】法定公文仅15种。企业日常高频写作的工作计划、工作总结、工作简报、规章制度、会议记录、介绍信、证明信、商务邮件等属于事务文书或专用文书，不属于法定公文，不受条例文种强制约束，但普遍参照条例的格式与语言规范。 | S1【教学归纳】 |
| F-035 | 【市场实践】企业行政、文员、秘书类岗位 JD 普遍将“公文写作能力”“会议纪要撰写”“通知与函件起草”列为硬性要求；中小企业行政岗常同时承担法定文种拟制（通知、通报、请示、报告、函）与事务文书撰写。 | S2 |
| F-036 | 【市场实践】商务邮件通行结构为：主题（事由加行动要求）、称呼、正文（一事一邮件、结论先行）、祝颂语、署名（姓名、职务、单位、联系方式）；对外洽商常用“烦请、恳请、为盼、顺颂商祺”等敬语。 | S2【教学归纳】 |
| F-037 | 【教学归纳】企业内部“借用”法定文种时的对应关系：向下布置或告知事项用通知，表彰先进或批评错误用通报，向上汇报工作用报告，向上请求批准用请示，平级或对外商洽用函，记载会议议定事项用纪要。 | S1【教学归纳】 |
