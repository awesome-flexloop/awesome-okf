# 报告 vs 请示对比与对照范例

> 说明：报告与请示是职场上行文中最容易混用的两个文种。条例明确规定“请示应当一文一事；不得在报告等非请示性公文中夹带请示事项”（F-025）。本篇给出六维对比、两则对照范例和行文前自检清单。公司名、人名、金额均为虚拟。

## 一、六维对比表

| 维度 | 报告 | 请示 |
|---|---|---|
| 目的 | 汇报工作、反映情况、答复上级询问（F-012） | 请求上级指示、批准（F-013） |
| 行文时机 | 事中、事后（也有例行定期报告） | **事前**（必须先获批准再行动） |
| 上级是否回复 | 可以不批复（阅知性） | **必须批复**（期复性） |
| 事项数量 | 可一文多事（综合报告） | **一文一事** |
| 结尾用语 | “特此报告”“以上报告，请审阅” | “妥否，请批示”“以上请示，请批复” |
| 禁止事项 | 不得夹带请示事项（F-025） | 不得多头主送（原则主送一个上级，F-026） |

记忆口诀：**“事前要批准用请示，事后说情况用报告；请示等批复，报告供阅知。”**

## 二、报告范例（节选）

> **××公司行政部关于2026年第三季度行政工作的报告**

公司领导：

　　现将行政部2026年第三季度主要工作情况报告如下：

　　一、重点工作完成情况

　　（一）会议与接待保障。三季度组织公司级会议12场次、接待外部来访7批次，均按流程完成场地、设备、餐饮保障，满意度回访平均4.8分（满分5分）。

　　（二）采购与资产管理。完成办公物资集中采购3批次，采购金额8.2万元，较预算节约9%；完成三季度固定资产盘点，盘盈盘亏率为0。

　　（三）办公环境与安全。完成消防设施年检，组织疏散演练1次；协调物业修复空调、门禁等报修42单，平均响应时间缩短至4小时。

　　二、存在的问题

　　（一）供应商比价机制执行不均，零星采购中仍有2笔未取得三家报价；

　　（二）会议室资源紧张，周三、周四高峰时段冲突率约15%。

　　三、四季度工作打算

　　（一）10月底前出台零星采购补充规定，堵塞比价漏洞；

　　（二）推行会议室线上预约与超时释放机制，预计冲突率降至5%以下。

　　特此报告。

　　　　　　　　　　　　　　　　××公司行政部
　　　　　　　　　　　　　　　　2026年10月9日

**点评**：全文汇报情况，无请求批准事项；结尾用“特此报告”；数据对照目标，问题有原因、打算有措施。

## 三、请示范例（节选）

> **××公司行政部关于三楼办公区改造立项及预算的请示**

公司领导：

　　为解决研发团队扩编后的工位不足问题（现缺工位约20个），行政部拟对三楼北区进行改造，新增开放工位24个、讨论间2间。经初步比价，工程及家具总费用约15万元（明细见附件），拟从本年度行政专项预算中列支。

　　妥否，请批示。

　　附件：三楼办公区改造方案及报价对比表

　　　　　　　　　　　　　　　　××公司行政部
　　　　　　　　　　　　　　　　2026年9月18日

**点评**：一文一事（只请示改造立项与预算）；事前行文；有明确请求事项（批准立项、批准15万元预算）；附件支撑决策；结尾用“妥否，请批示”。

## 四、常见错误改写

| 错误写法 | 问题 | 正确处理 |
|---|---|---|
| 《关于三季度工作的请示报告》 | 文种混用 | 汇报用“报告”，申请事项另发“请示” |
| 工作总结末尾“另请批准招聘编制3人” | 报告夹带请示 | 编制事项单独行文《关于新增招聘编制的请示》 |
| 一份请示同时申请预算、招人、出差 | 一文多事 | 拆分为三份请示，分别批复 |
| 请示同时主送总经理和董事会 | 多头主送 | 原则主送一个上级，必要时抄送 |
| 先采购后补请示 | 事后请示失去意义 | 事前请示，紧急事项先口头报告并及时补文 |

## 五、行文前自检清单

- [ ] 我是在**事前**请求批准/指示吗？是 → 请示；只是汇报情况 → 报告
- [ ] 请示是否只有**一件**请求事项？
- [ ] 是否只主送**一个**上级机关/领导？
- [ ] 请示结尾是否为“妥否，请批示/请批复”？报告结尾是否无请求语句？
- [ ] 标题是否为“机关+事由+文种”，且文种只有一个？
- [ ] 请示附件是否足以支撑上级决策（方案、报价、依据）？
