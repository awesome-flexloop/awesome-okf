# 会议保障全流程清单

> 说明：本清单为原创通用 SOP。「★」标记为重要外部会议（客户/政企/董事会）必须项；内部常规会议可简化。

## T-3 天（会议确定时）

- [ ] ★ 明确五要素：时间/时长/地点/人数/主题，与召集人书面确认
- [ ] 会议室预约并锁档（重要会议前后各留 30 分钟）
- [ ] ★ 参会人员名单与职务（排座次用）、外部单位联系人
- [ ] 视频会议需求确认（远端参会人数、平台、试连时间）
- [ ] ★ 接待需求：车辆、停车、餐饮、住宿、横幅/指引牌

## T-1 天

- [ ] 议程与材料定稿，打印份数 = 参会人数 + 2（装订）
- [ ] ★ 桌签（名牌）制作，座次图排定并与领导秘书确认
- [ ] 设备清单核对：投影/大屏、投屏线（含备用转接头）、麦克风、激光笔
- [ ] ★ 视频会议远端试连一次
- [ ] 茶水安排（茶/水/咖啡）、★ 茶歇或餐饮预订
- [ ] ★ 通知保安/前台访客名单与来访时间

## T-0 会议当天（提前 30 分钟到场）

- [ ] 开门、开空调灯光（温度 24–26℃）
- [ ] 设备实测：投影画面、声音、麦克风、激光笔
- [ ] 材料按座位摆放、桌签就位
- [ ] 茶水沏好、纸巾/文具齐备
- [ ] ★ 门口/大堂迎接引导，访客登记
- [ ] 签到表/签到方式就绪

## 会中

- [ ] 引导入座、会议准时开始
- [ ] 添茶水（20–30 分钟一次）
- [ ] 会场外/后排待命，30 秒响应临时需求（打印、文具、叫车、设备）
- [ ] 设备故障切备用方案（备用转接头/纸质材料/备用会议室）
- [ ] ★ 拍照留档（注意涉密会议不拍）

## 会后 30 分钟内

- [ ] 设备关闭、材料清场（★ 涉密材料回收）、桌椅归位
- [ ] 垃圾清理、茶杯回收、空调灯光关闭
- [ ] 会议室预约释放/状态复位

## T+1（会后 24 小时内）

- [ ] 纪要发出：结论 + 待办事项（责任人 + 完成时限），见 [公文写作束纪要写法](../../official-writing/concepts/01-document-types.md)
- [ ] 待办事项进入督办台账并跟踪
- [ ] 费用结算（茶歇/餐饮/场地/车辆）、发票归档
- [ ] ★ 接待小结/费用明细报领导

## 应急预案（提前想好）

| 突发情况 | 备用方案 |
|---------|---------|
| 投影/大屏故障 | 备用转接头 → 备用会议室 → 纸质材料先开会 |
| 视频连不上 | 电话接入 + 会后材料补发；提前一天试连是根本预防 |
| 临时加人 | 材料多备 2 份、折叠椅就近 |
| 客人早到/晚到 | 接待室等候区 + 茶水；行程表标注可压缩环节 |
| 会议室冲突 | 预约锁档即预防；备用小会议室预占 1 间 |
