# 事实清单（Facts Inventory）

> 采集时间：2026-09-01
> 说明：本清单登记行政岗位实务工作内容。与 HR 合规束不同，行政管理**没有全国统一的「行政法」知识体系**，其「事实」主要是市场通行的职责划分与工作方法，证据形态为公开招聘信息中的岗位描述。以下事实除特别说明外，均标注【市场实践】，来自 2026 年公开招聘平台行政/行政人事岗位 JD 汇总（S1、S2），不支撑任何法规断言；涉及法规的动作（消防、印章、合同、社保）在文中明确指向法规信源。解释性判断见 [insights.md](insights.md)。

## 一、十二大职能域（市场 JD 高频职责归纳）

| 编号 | 事实内容 | 信源 |
|------|---------|------|
| F-001 | 办公物资管理是行政 JD 最高频职责之一，完整链路为：需求收集 → 采购（比价/供应商）→ 入库登记 → 领用签字 → 台账维护 → 定期盘点，低值易耗品与固定资产分类管理。【市场实践】 | S1、S2 |
| F-002 | 固定资产管理覆盖全生命周期：采购验收、编号贴标、领用登记、调拨、维修、盘点（通常每半年或每年一次）、报废处置；台账字段通常含资产名称、编号、规格、购置日期、金额、使用人、存放地点、状态。【市场实践】 | S1 |
| F-003 | 会议管理是行政核心日常，全流程包括：会议预约（会议室/时间冲突协调）、会前准备（议程、材料、座次、设备调试、茶水）、会中服务（签到、记录支持、设备保障）、会后收尾（纪要跟进、会议室复原、费用结算）。【市场实践】 | S1、S2 |
| F-004 | 公文与函件管理包括：收发登记（来文来函签收登记）、传阅（按领导批示流转）、督办（办理期限跟踪）、归档；快递收发登记也是常见职责。【市场实践】 | S1 |
| F-005 | 印章管理通行做法：公章/合同章/财务章/法人章分人保管或集中保管，用印须经审批流程并登记（用印日期、文件名称、份数、经办人、审批人），印章原则上不外带，确需外带须审批并由保管人陪同。【市场实践】 | S1、S2 |
| F-006 | 档案与合同管理：员工档案、合同文本、公司证照分类归档；营业执照的变更、年报公示（年检）、资质证书申报与维护是行政或行政人事岗的常见职责。【市场实践】 | S1 |
| F-007 | 接待工作分商务接待（客户、供应商、合作伙伴）与政企接待（政府部门、考察团），内容包括行程安排、车辆调度、餐饮住宿预订、接待物料、座次礼仪、费用报销。【市场实践】 | S1、S2 |
| F-008 | 差旅管理：机票酒店预订、出差行程协调、差旅标准执行与报销单据审核；部分公司使用差旅平台（OTA 企业版/差旅管理公司）统一结算。【市场实践】 | S1 |
| F-009 | 后勤保障面广且杂：办公场地租赁对接与物业协调、网络与电话、水电、办公环境保洁、绿植租摆、车辆管理（公车/网约车/油卡 ETC）、员工宿舍或公寓管理、办公钥匙门禁。【市场实践】 | S1、S2 |
| F-010 | 行政预算与成本管控：编制年度行政费用预算（办公费、租赁费、物业费、差旅费、接待费、活动费等），按月跟踪执行，采购比价与供应商管理是成本控制的主要抓手。【市场实践】 | S1 |
| F-011 | 安全、消防与保密：办公区域安全巡查、消防设施检查与消防演练组织、监控与门禁管理、保密制度执行（涉密文件、访客管理）；消防安全另有法定要求（见概念卡中的法规提示）。【市场实践】 | S1、S2 |
| F-012 | 政府项目与资质事务：高新技术企业认定、专精特新（小巨人）申报、各类补贴政策跟踪申报等，常由行政牵头或配合财务/技术部门完成。【市场实践】 | S1 |
| F-013 | 企业文化活动：年会、团建、节日活动、生日会、员工关怀活动的策划与执行；办公环境文化布置（文化墙、宣传栏）。【市场实践】 | S1、S2 |
| F-014 | 入离职行政手续：与 HR 衔接办理入职（工位、设备、门禁、工牌）与离职（资产回收、权限注销）行政部分——该职能与 HR 入离职流程交叉，见 [HR 六大模块束](../../hr/hr-six-modules/examples/01-onboarding-offboarding-checklist.md)。【市场实践】 | S1 |

## 二、工作方法与协作边界

| 编号 | 事实内容 | 信源 |
|------|---------|------|
| F-015 | 行政岗位 JD 中高频出现的通用要求包括：服务意识、沟通协调能力、细致有责任心、抗压能力、熟练使用 Office（Excel/PPT）；行政人事复合岗同时要求熟悉劳动法规与社保流程。【市场实践】 | S1、S2 |
| F-016 | 企业规模决定行政形态：小微企业通常 1 名行政人事全包；中型企业设行政主管+行政专员分工；大型企业设行政部并细分前台、后勤、采购、车队、行政 BP 等岗位，部分设 EHS（环境健康安全）专岗。【市场实践】 | S1 |
| F-017 | 行政工作的成果大量以「台账、表单、清单」为载体：物资台账、资产台账、用印登记、会议记录、合同台账、钥匙/门禁登记等；表单化程度是行政成熟度的直观指标。【市场实践】 | S1 |
| F-018 | 行政采购与费用报销通常受财务制度约束：预算内审批、定点供应商、大额采购比价/招标、发票合规；行政是费用制度的执行者而非审批者。【市场实践】 | S1 |
| F-019 | 消防安全在行政工作中带有法定属性：机关、团体、企业、事业单位依法履行消防安全职责（《消防法》第 16 条等），包括配置消防设施器材、组织防火检查与消防演练；行政部门通常是内部消防安全责任的日常牵头部门。【法规提示，详见概念卡】 | S3 |
| F-020 | 行政岗在数据化工具上的常见实践：OA 系统（用印、采购、报修流程线上化）、固定资产管理系统、共享文档/表单工具、费用报销系统；线上化是解决「行政琐事不可见」问题的主要路径。【市场实践】 | S1、S2 |

## 放弃的未核验事实（不作为本知识包断言）

1. **行政岗位薪资水平**：随城市、行业、企业规模差异大，不采作事实。
2. **行政服务商（绿植、保洁、差旅平台）的品牌与报价推荐**：属地化且商业性强，不做推荐。
3. **印章管理的具体法规条文细节**：企业印章管理的法规要求分散在多部法规与地方规定中，本包仅登记市场通行的用印实务红线（审批、登记、不外带），不展开法条。
4. **固定资产的会计折旧年限与税务处理**：属财务会计范畴（企业会计准则与税法），本包只登记行政台账管理方法。
5. **高企/专精特新申报的具体条件与补贴金额**：政策逐年调整、属地差异大，本包只登记「行政可能牵头/参与资质申报」这一职责事实，申报条件以科技/工信部门当年申报指南为准。
6. **消防法具体条款号的逐条引用**：F-019 仅作法定提示，具体职责清单以《消防法》现行文本与属地消防救援机构要求为准。
7. **任何「最佳行政制度」模板的效力断言**：examples 中的清单模板为原创通用框架，需结合企业实际调整。
