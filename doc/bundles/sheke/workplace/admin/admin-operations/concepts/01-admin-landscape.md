# 行政管理职能全景

## 是什么

行政管理是保障办公体系正常运转的支撑职能。根据公开招聘 JD 的市场实证（F-001 至 F-014），行政工作可归纳为十二大职能域：

| 职能域 | 核心动作 | 载体/产出 |
|--------|---------|----------|
| ① 办公物资 | 采购、入库、领用、盘点 | 物资台账、领用单 |
| ② 固定资产 | 全生命周期台账、盘点、报废 | 资产台账、盘点表 |
| ③ 会议会务 | 预约、会前会中会后保障 | 会议预约表、签到、纪要跟进 |
| ④ 公文函件 | 收发登记、传阅、督办、归档 | 收发文登记簿 |
| ⑤ 印章管理 | 用印审批、登记、保管 | 用印登记表 |
| ⑥ 档案证照 | 合同/员工档案归档、营业执照变更年报、资质申报 | 档案柜/电子库、证照台账 |
| ⑦ 接待 | 商务/政企接待、行程、餐饮住宿 | 接待方案、费用单 |
| ⑧ 差旅 | 机酒预订、行程协调、标准执行 | 差旅预订、报销审核 |
| ⑨ 后勤保障 | 物业、网络、水电、保洁、绿植、车辆、公寓、门禁 | 供应商台账、报修记录 |
| ⑩ 预算成本 | 年度行政预算、月度跟踪、比价采购 | 预算表、比价单 |
| ⑪ 安全消防保密 | 巡查、消防设施检查与演练、访客保密 | 巡查记录、演练记录 |
| ⑫ 文化活动与资质事务 | 年会团建、文化墙、高企/补贴申报 | 活动方案、申报材料 |
| （交叉）入离职行政 | 工位设备门禁的开通与回收 | 与 HR 入离职清单联动 |

## 为什么：行政是「公司运转的操作系统」

行政工作的成果不直接出现在利润表上，但它决定了组织运行的摩擦力——物资断供、会议设备故障、印章乱用、证照过期、消防隐患，每一件都能让业务停摆或给公司带来实体风险。行政的三个本质特征：

1. **高频低额、容错率低**：单笔金额小，但出错频次高、影响面大（证照过期、用印违规是实体法律风险）。
2. **服务属性强**：内部客户是全体员工，响应速度与态度直接可感。
3. **结果不可见、问题很可见**：做得好是「一切正常」，做不好立刻被看见——这要求行政主动把隐性工作显性化（台账、报表、SOP）。

## 协作边界：行政与 HR、财务、IT

| 事项 | 主责 | 行政的位置 |
|------|------|-----------|
| 入离职手续（合同/社保/薪酬） | HR | 行政配合工位、设备、门禁、工牌（F-014） |
| 采购付款与报销审核 | 财务 | 行政执行采购与验收入库，财务管钱与发票合规（F-018） |
| 办公账号与信息系统 | IT | 行政管门禁钥匙等物理准入，IT 管系统账号 |
| 消防安全 | 行政牵头日常 | 法定职责在单位（F-019），行政是内部牵头部门 |
| 公文与制度发文 | 行政/文秘 | 写作规范见 [公文写作与职场文书](../../official-writing/index.md) |

## 怎么做：不同规模企业的行政形态（F-016）

- **小微企业（几十人内）**：1 名行政人事全包 12 个职能域 + HR 基础事务，核心打法是 SOP 化与模板化（本包 examples 直接可用）。
- **中型企业（百人至数百人）**：行政主管 + 1–2 名行政专员，前台/后勤/采购初步分工；开始上 OA 流程（用印、采购、报修线上化，F-020）。
- **大型企业（千人以上/多场地）**：行政部细分前台、后勤、采购、车队、行政 BP；安全消防独立为 EHS 专岗；行政预算独立核算。

对个人进修的启示：行政专业纵深有三条路——**行政运营管理**（预算、供应商、场地、流程数字化）、**文秘与公文**（写作、会议、督办，向总助/办主任发展）、**行政人事复合**（打通 HR 模块，向综合管理发展）。

## 常见坑与边界

- **把行政做成「救火队」**：没有台账和计划，所有需求都是紧急需求——解法是周期性工作年历化（年检、盘点、预算、消防演练都是固定时点）。
- **重服务轻风控**：只图「大家方便」，印章随手盖、资产不登记、访客不登记——方便的代价是风险敞口。
- **行政与财务职责混淆**：行政直接谈价付款、不经采购审批，是内控漏洞；行政管事、财务管钱的分离原则不能破。
- **忽视法定红线**：消防不是「后勤小事」（F-019）；劳动合同、社保不是行政可以「灵活处理」的事（见 [劳动合规束](../../../hr/labor-law-compliance/index.md)）。
