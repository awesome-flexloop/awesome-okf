# 采购、办公物资与固定资产管理

## 是什么

这是行政最日常的职能域（F-001、F-002），管理两类对象：

- **办公物资（低值易耗品）**：文具、打印耗材、饮用水、清洁用品、纸杯纸巾等——单价低、消耗快、按领用管理；
- **固定资产**：电脑、打印机、办公家具、投影仪、空调等——单价高、使用周期长、按「人/地点」跟踪到报废。

两者都走「计划 → 采购 → 入库 → 领用 → 盘点」链路，但管控颗粒度不同。

## 为什么：钱物对应是内控底线

物资资产管理的本质是回答三个问题：**东西在哪、谁在用、还剩多少**。答不上来的直接后果：重复采购（预算浪费）、资产流失（离职带走、损坏无记录）、账实不符（审计/税务风险）。行政在这件事上的专业度，就体现在台账是否实时、盘点是否闭环。

## 怎么做

### 采购流程（与财务分工，F-018）

1. **需求**：部门提需求（口头/表单/OA 流程），行政判断是库存领用还是新采购；
2. **比价**：定点供应商询价，超过企业规定金额（如 2000 元/5000 元，按财务制度）至少三家比价；大额走采购或招标流程；
3. **审批**：预算内按审批权限签字；预算外先追加预算；
4. **验收**：货到核对数量、规格、质量，验收人签字（**行政不能既采购又独自验收**，大额采购应有使用部门共同验收）；
5. **入库/报销**：登记入库后再领用；发票合规（品名、税号）交财务。

### 办公物资台账（流水账思路）

- 物资台账：品名、规格、单价、入库数量、出库数量、结存、最低库存线；
- 领用登记：日期、品名、数量、领用人签字；
- **最低库存预警**：高频物资设安全库存线（如 A4 纸低于 5 箱即补），避免断供。

### 固定资产全生命周期（F-002）

1. **验收编号**：到货验收后立即贴资产编号标签（一物一码），录入台账；
2. **台账字段**：资产编号、名称、规格型号、购置日期、金额、供应商、使用人、存放地点、状态（在用/闲置/维修/报废）；
3. **领用/调拨**：使用人签字确认；跨部门调拨更新台账；
4. **定期盘点**：每半年或每年全盘一次，账实核对，盘盈盘亏查明原因并报批（盘点表模板见 [examples/02](../examples/02-asset-inventory-seal-templates.md)）；
5. **报废处置**：达到使用年限或损坏的，填报废申请、审批后处置（变卖收入入公司账，不得私自处理）；
6. **离职联动**：离职资产回收是 HR 离职清单的行政环节，见 [入离职清单](../../../hr/hr-six-modules/examples/01-onboarding-offboarding-checklist.md)。

## 常见坑与边界

- **采购不验收**：货没到/货不对板就签字报销，供应商纠纷时公司被动。
- **资产不贴标**：电脑家具无编号，盘点时只能靠人认，离职交接必乱。
- **「以领代耗」**：物资领出即算消耗，没有结存管理，浪费无法发现。
- **供应商一家独大**：长期只找一家不询价，价格虚高；至少保持 2–3 家备选并年度比价。
- **会计折旧归财务**：资产的折旧年限、税务处理是财务范畴，行政台账管实物与使用状态，两侧定期对账（见 [facts.md 放弃核验清单](../facts.md)）。
