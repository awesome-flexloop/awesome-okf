# 行政预算、安全消防与文化活动

## 是什么

这三类工作回答行政的三个进阶问题：钱怎么管（预算）、风险怎么防（安全消防保密）、氛围怎么建（文化活动），外加一项常落在行政头上的专项：资质补贴申报（F-012）。这是行政从「打杂」走向「管理」的分水岭。

## 一、行政预算与成本管控（F-010）

行政费用预算的主要科目：房租物业、水电费、办公物资、快递、差旅、接待、绿植保洁、车辆、活动费、维修费、证照资质费。

**编制方法（年度）**：

1. **固定费用先锁**：房租、物业、网络、绿植保洁等有合同的，按合同金额直接列入；
2. **变动费用看历史**：办公物资、快递、差旅按上年实际发生额 × 人员增长系数 + 节约目标；
3. **专项费用单列**：年会、搬家、大型装修、资质申报等一次性项目单独立项；
4. **汇总与平衡**：行政总费用 ÷ 人数 = 人均行政成本，与历史和行业感知对比，报领导审批。

**执行方法（月度）**：

- 按月做「预算 vs 实际」对比表，超支科目找原因（如快递费翻倍 → 比价换供应商）；
- 成本管控三板斧：**集中采购比价、固定供应商年度议价、费用标准制度化**（差旅标准、接待标准、物资领用标准）；
- 预算模板见 [examples/03](../examples/03-annual-budget-framework.md)。

## 二、安全消防与保密（F-011、F-019）

消防安全带有**法定属性**：机关团体企业事业单位依法履行消防安全职责（《消防法》），行政通常是内部日常牵头部门。实务动作：

- **设施**：灭火器（压力、有效期月检）、消防栓、应急照明、疏散指示、烟感，按物业/消防要求配置并定期检查记录；
- **通道**：疏散通道和安全出口保持畅通（不堆杂物、不上锁）；
- **演练**：每年至少组织 1–2 次消防演练（含疏散路线、集合点、点名）；
- **日常**：下班断电巡查、违规电器检查（热得快、小太阳）、充电管理；
- **档案**：检查记录、演练记录留存——这是尽到管理义务的证据。

保密与访客：涉密文件柜管理、访客登记与陪同、会议室使用后材料清场、离职权限注销（与 IT/HR 联动）。

## 三、企业文化活动（F-013）

- **常规节奏**：生日会（月）、节日活动（妇女节、端午、中秋等）、团建（季）、年会（年）；
- **策划四要素**：预算、参与感（活动形式让多数人愿意参加）、执行清单（场地/物料/流程/摄影）、复盘（参与率与满意度反馈）；
- **文化环境**：文化墙、宣传栏、荣誉展示区更新维护；
- 活动费同样走预算与审批，发票合规。

## 四、资质与补贴申报（F-012）

高新技术企业认定、专精特新（小巨人）、稳岗补贴、社保补贴、人才政策等，行政常承担「政策跟踪 + 材料组织 + 跨部门协调」角色（技术材料由研发/财务提供）。要点：关注属地科技、工信、人社部门申报通知（窗口期短），建资质台账（已获资质、有效期、可申报项目日历）。**具体条件与金额以当年官方申报指南为准**（见 [facts.md 放弃核验清单](../facts.md)）。

## 常见坑与边界

- **预算年初编完就不管**：预算的价值在月度对比与纠偏，不在那张表本身。
- **消防演练摆拍**：演练没有疏散路线预演和点名，真出事时员工不知道往哪跑。
- **活动自嗨**：行政觉得热闹，员工觉得占用休息时间——活动设计提前征求员工意见，参与率是硬指标。
- **申报错过窗口期**：补贴政策有明确申报期，过期不候；资质日历要提前 3–6 个月预警。
- **行政≠安全员的法定责任主体**：单位是消防安全责任人，行政是牵头执行部门；重大消防问题必须书面上报领导，留痕免责。
