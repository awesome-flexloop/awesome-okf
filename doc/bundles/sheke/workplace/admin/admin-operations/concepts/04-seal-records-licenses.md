# 印章、档案与证照管理

## 是什么

这是行政职能域里**风险等级最高**的一块（F-004、F-005、F-006）：管的是公司「意思表示」的物理载体——印章代表公司对外作出承诺，档案是公司经营与劳动关系的证据，证照是公司合法经营的资格凭证。三者共同特点：平时不出事，出事就是大事。

## 一、印章管理：先审批，后用印

企业常见印章：公章（对外效力最高）、合同专用章、财务专用章、发票专用章、法定代表人名章、人事专用章等。市场通行红线（F-005）：

1. **审批前置**：任何用印先有用印审批单（文件名称、份数、用途、经办人、审批人按权限签字），不得「先盖后补」；
2. **逐次登记**：用印登记表记录日期、文件名称、份数、对方单位、经办人、审批人（模板见 [examples/02](../examples/02-asset-inventory-seal-templates.md)）；
3. **章不出门**：印章原则上不外带；确需外出用印（如现场签合同），须专项审批并由印章保管人陪同，用印后即时归还登记；
4. **分人保管、人走章收**：印章保管人离职必须交接并登记；不得由同一人保管全部印章且独自完成审批（不相容职务分离）；
5. **不盖空白**：严禁在空白纸张、空白合同、空白介绍信上盖章。

> 风险提示：私自盖章或违规用印对外仍可能构成表见代理（公司可能仍需对外担责，再向责任人追偿）——内部登记制度是事后追责与风险切割的证据。

## 二、档案管理：分类、归档、可查

| 档案类型 | 内容 | 管理要点 |
|---------|------|---------|
| 合同档案 | 业务合同、租赁合同、供应商合同 | 编号、原件归档、到期提醒（与法务/财务共享台账） |
| 人事档案 | 员工入离职材料、合同、考核记录 | 与 HR 共担，**劳动争议举证材料至少保存至离职后 2 年以上**（见 [合规束](../../../hr/labor-law-compliance/concepts/06-labor-dispute-resolution.md)） |
| 文书档案 | 收发公文、会议纪要、规章制度、报告请示 | 按年度分类归档（写作规范见 [公文写作束](../../official-writing/index.md)） |
| 证照档案 | 营业执照、资质证书、商标专利 | 见下文 |

归档三原则：**原件优先、分类编号、借阅登记**。电子档同步扫描备份，纸质档防潮防火防盗。

## 三、证照管理：别让公司「无证经营」

- **营业执照**：正本/副本保管、企业年报公示（每年通过国家企业信用信息公示系统报送，逾期列入经营异常名录）、登记事项变更（地址、法人、注册资本、经营范围）及时办理；
- **资质证书**：行业许可证、高新证书、ISO 体系证书等，台账登记有效期，**到期前 3–6 个月启动续期**；高企认定、专精特新等申报常由行政牵头或配合（F-012，申报条件以当年官方指南为准）；
- **证照外借**：原件外借（投标、开户、办事）登记借还，复印件对外使用标注「仅用于 XX 用途、再次复印无效」。

## 常见坑与边界

- **用印登记流于形式**：登记簿空白或事后补填，一旦发生纠纷无法自证。
- **证照过期无提醒**：资质过期直接影响投标与经营；年报逾期列入异常名录影响企业信用。
- **档案堆放无台账**：合同到期无人知道、劳动争议找不到合同文本（二倍工资风险，见 [合规束](../../../hr/labor-law-compliance/concepts/01-labor-contract-lifecycle.md)）。
- **微信传章图片**：印章扫描件管理与实体章同等级别，滥用图片盖章等于失控。
- **行政越权签合同**：合同审批、法务审核、用印是三个环节，行政管流程不管交易条款。
