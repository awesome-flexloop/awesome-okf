# 🏢 职场与管理

本域存放职场技能与管理实践相关的知识包，面向行政、人事、秘书等岗位的系统进修：人力资源方向覆盖职业地图与进修路径、六大模块与三支柱体系、劳动法律合规；行政办公方向覆盖行政管理实务全景与公文写作、职场文书。法规类内容逐条挂全国人大、人社部、国务院等官方信源，实践类内容附可直接复制的清单、模板与算例。
