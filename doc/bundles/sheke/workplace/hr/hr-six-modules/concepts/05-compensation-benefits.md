# 薪酬福利结构

## 是什么

薪酬福利管理是「用经济手段认可贡献、同时控制人力成本」的模块（F-007）。一套典型薪酬由以下部分构成：

| 构成 | 说明 | 变动性 |
|------|------|--------|
| 基本工资（固定工资） | 按岗位与职级确定，保障基本生活 | 固定，随出勤调整 |
| 绩效工资/奖金 | 与绩效周期结果挂钩 | 浮动 |
| 津贴补贴 | 岗位津贴、餐补、交通补、通讯补等 | 半固定 |
| 法定福利 | 五险（养老/医疗/失业/工伤/生育）一金（住房公积金） | 法定强制 |
| 企业福利 | 补充医疗、体检、年假外福利、节日福利、团建 | 弹性 |
| 长期激励 | 股权、期权、利润分享（多见于成长型/上市公司） | 长期 |

## 为什么：薪酬是模块耦合度最高的系统

- 薪酬向下连着**法规底线**：最低工资、社保公积金费率与基数、加班费倍率、试用期工资、经济补偿基数，全部有法定标准（见 [劳动法律合规实务](../../labor-law-compliance/index.md)）。
- 薪酬向上连着**绩效系统**：绩效工资占比、调薪矩阵、奖金分配规则如果不与绩效结果挂钩，激励就失效（见 [04 培训开发与绩效管理](04-training-performance.md)）。
- 薪酬向外连着**市场行情**：定薪低于市场分位会招不到、留不住；过高则人力成本失控。薪酬调研与带宽设计是 COE 的核心专业活。

## 怎么做

**1. 定薪**：新人定薪参考三因素——岗位职级带宽、市场水平、候选人现状薪资与期望；关键动作是**薪酬带宽**（每个职级设最低/中位/最高值），避免同岗不同薪无序扩张。

**2. 调薪**：常见两类——年度普调（随预算与市场）与绩效调薪（按考核结果差异化）；晋升调薪随职级带宽变动。调薪要有预算总盘与规则，否则年年靠谈判。

**3. 月度薪酬核算**：出勤工资、加班费（工作日 150%/休息日 200%/法定节假日 300%）、病假事假扣款、社保公积金个人部分代扣、个税代扣。月计薪天数 21.75 天是标准换算基数（计算示例见合规束 [examples/02](../../labor-law-compliance/examples/02-compensation-calculation.md)）。

**4. 福利设计**：法定福利不可省（社保公积金是强制义务）；企业福利按预算做差异化（年轻员工重体检/餐补，有家庭员工重补充医疗/子女福利）。

**5. 薪酬沟通**：薪酬保密制度普遍存在，但「保密」不等于「不解释」——员工要理解自己的薪酬由什么决定、怎样能涨；HR 要能讲清薪酬结构与调薪规则。

## 常见坑与边界

- **社保按最低基数缴或不缴**：属于明确违法，员工投诉或离职仲裁时单位要补缴并承担滞纳金；「员工自愿放弃社保」的承诺无法律效力（费率与基数规则见合规束）。
- **加班费玩文字游戏**：用「包薪制」「综合工时未经审批」规避加班费，仲裁中基本不被支持。
- **薪酬结构随意改**：降低固定工资比例、单方调整薪酬结构属于变更劳动合同，须协商一致并书面确认。
- **只发钱不管理预期**：调薪没有规则感，员工把每一次调薪视为谈判而非制度结果，内部公平感崩坏。
- **人力成本无预算**：薪酬总额不做预算与人均效能监控，人力成本随招聘无序膨胀——这是薪酬模块与人力资源规划模块的咬合点。
