# 入离职办理清单

> 说明：本清单为原创通用 SOP，可直接复制到企业内部表格使用。涉及合同期限、试用期、社保时限等法律要求，以 [劳动法律合规实务](../../labor-law-compliance/index.md) 的法规要点与属地政策为准。

## 一、入职办理清单

### 报到前（offer 接受后、到岗前）

- [ ] 确认报到日期、地点、需携带材料（身份证、学历证明、离职证明、银行卡、照片等）
- [ ] 发送入职须知（报到流程、着装、作息、联系人）
- [ ] 通知用人部门到岗时间，确认带教人
- [ ] 准备劳动合同（岗位、期限、试用期、工资标准填写完整）
- [ ] 准备员工手册、制度签收页、保密/竞业协议（如岗位适用）

### 报到当天

- [ ] 核验证件原件，收存复印件/扫描件（**不得扣押证件原件**）
- [ ] **签订书面劳动合同**（用工之日起 1 个月内必须完成，建议入职当天签）
- [ ] 确认试用期期限合法（对照合同期限：3 个月–1 年 → 试用期 ≤1 个月；1–3 年 → ≤2 个月；3 年以上/无固定 → ≤6 个月）
- [ ] 办理工资卡信息登记、个税专项附加扣除信息采集
- [ ] 社保公积金增员申报（属地规定时限内办理）
- [ ] 开通办公账号：邮箱、OA、考勤、业务系统（权限按最小必要）
- [ ] 领取办公设备与物资：电脑、工牌、文具（行政配合，领用登记签字）
- [ ] 安排工位、门禁卡/权限
- [ ] 建立员工档案（纸质/电子，信息保密）

### 入职 30 天内（融入期）

- [ ] 完成新员工入职培训：公司介绍、制度、考勤休假、信息安全与保密
- [ ] 带教人对接，明确首月工作目标与试用期考核标准
- [ ] 试用期目标书面确认（员工签字，作为转正评估依据）
- [ ] 第 1 周、第 1 个月回访（适应情况、问题收集）
- [ ] 转正前评估与面谈，转正手续或试用期处理（**试用期不符合录用条件解除须有书面考核依据并在试用期内作出**）

## 二、离职办理清单

### 提出/通知阶段

- [ ] 员工书面辞职（主动离职）或公司解除通知（被动离职，**先核合法性与补偿**，见合规束）
- [ ] 确认最后工作日、工资结算截止日
- [ ] 启动工作交接，指定交接接收人

### 离职当天前

- [ ] 工作交接：未完成事项、客户/供应商联系人、文件资料、系统数据，交接清单双方签字
- [ ] 资产回收：电脑、工牌、门禁卡、钥匙、备用金、借款
- [ ] 账号回收：邮箱、OA、业务系统、VPN（与 IT 确认停用时点，避免提前停用影响交接）
- [ ] 薪酬结算：最后月工资、未休年假折算、加班费、报销款（**工资应在解除/终止劳动合同时一次付清，按属地工资支付规定执行**）
- [ ] 社保公积金减员申报（次月生效，注意时点）
- [ ] 出具**离职证明**（法定义务，写明合同期限、岗位、在职年限，不得写负面评价）
- [ ] 档案、社保关系转移告知
- [ ] 竞业限制人员：确认是否启动竞业、补偿金支付安排（如有约定）
- [ ] 离职面谈：记录离职真实原因（薪酬/管理/发展/家庭），归档用于流失分析

### 离职后

- [ ] 员工档案按规定年限保存（劳动争议仲裁时效为离职后 1 年，材料至少留存备查）
- [ ] 离职数据更新：编制台账、人力成本报表
- [ ] 季度流失率分析与改进建议

## 常见卡点

| 卡点 | 处理 |
|------|------|
| 员工拒签合同 | 书面通知签订并留存证据；超 1 个月未签存在二倍工资风险，见合规束 |
| 试用期想辞退 | 必须有「不符合录用条件」的书面依据（岗位说明书+考核记录），且在试用期内作出 |
| 离职不交接 | 可暂缓出具离职证明以外的手段有限——核心在入职时约定交接义务与制度；扣工资有限度且属地有规定，谨慎 |
| 被动离职 | 先分清协商解除/过失性解除/无过失性解除，补偿口径（N、N+1、2N）完全不同，见 [合规束决策树](../../labor-law-compliance/concepts/02-termination-and-severance.md) |
