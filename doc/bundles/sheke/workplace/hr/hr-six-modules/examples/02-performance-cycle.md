# 绩效周期实操指南

> 说明：本指南为原创通用框架，适用于季度/半年度/年度绩效周期。模板可直接复制使用；绩效结果用于解除劳动合同时有法定程序限制，见文末边界提醒。

## 一、周期节奏（以季度为例）

| 时点 | 动作 | 产出物 |
|------|------|--------|
| 周期第 1 周 | 公司/部门目标分解到个人，上下级共同制定目标 | 绩效目标表（双方签字） |
| 每月 1 次 | 一对一过程沟通：进展、障碍、资源支持 | 沟通记录（1–2 行纪要） |
| 周期中 | 关键事件记录（突出贡献/失误），避免年底凭记忆 | 关键事件记录 |
| 周期末 | 员工自评 → 主管评分 → 校准（部门间平衡） | 考核结果 |
| 结果出来 1 周内 | 绩效面谈：结果反馈、原因分析、下期改进 | 面谈记录、下期目标初稿 |
| 结果应用 | 奖金、调薪、晋升、培训、改进计划 | 薪酬调整与人才发展动作 |

## 二、绩效目标表模板（可复制）

| 字段 | 填写内容 |
|------|---------|
| 员工/岗位 | 姓名、部门、岗位 |
| 周期 | 2026 年 Q_ |
| 目标 1 | 目标描述：____；衡量标准（数量/质量/时限）：____；权重：__% |
| 目标 2 | 目标描述：____；衡量标准：____；权重：__% |
| 目标 3 | 目标描述：____；衡量标准：____；权重：__% |
| 能力发展项 | 本周期重点提升的 1 项能力 + 行动 |
| 员工签字/日期 | |
| 主管签字/日期 | |

目标写法示例对比：

- ❌ 「做好招聘工作」（无法衡量）
- ✅ 「本季度完成 3 个关键岗位招聘，到岗周期 ≤45 天，新人 30 天留存率 100%」

## 三、绩效面谈提纲

**开场（5 分钟）**：说明面谈目的——回顾结果、对齐认知、讨论改进，不是单向批评。

**员工自评（10 分钟）**：
- 「这个周期你最满意的是哪件事？为什么？」
- 「哪个目标没达到？你觉得卡在哪里？」

**主管反馈（15 分钟）**：
- 先说结果与事实依据（引用关键事件记录，不贴标签：说「Q2 有 3 次交付延期」而非「你责任心不够」）
- 肯定具体行为 → 指出差距 → 确认员工是否认同事实
- 员工有异议时：回到目标表与过程记录核对，不争辩印象

**改进与展望（10 分钟）**：
- 「下周期你希望公司/我提供什么支持？」
- 共同确定下期 3 个目标与 1 个能力发展项
- 低绩效员工：明确改进要求与改进期限，书面记录（后续若进入不胜任处理程序，这是证据链起点）

**收尾**：双方在面谈记录上签字；记录不要求员工「认同评价」，但确认「已沟通」。

## 常见卡点

| 卡点 | 处理 |
|------|------|
| 目标中途因业务变化失效 | 周期中可书面调整目标并双方确认，不要拿过期目标考核 |
| 老好人打分（全员高分） | 部门间校准会：用事实分布对照，强制分布慎用但校准必要 |
| 员工拒签面谈记录 | 记录「员工拒绝签字，已于 X 日当面告知结果」，由见证人签字 |
| 低绩效想直接辞退 | **不能**。「不能胜任工作」须先培训或调岗，仍不能胜任的才可解除，且须提前 30 日通知并支付经济补偿（N+1 口径）——见 [劳动合规束](../../labor-law-compliance/concepts/02-termination-and-severance.md) |
