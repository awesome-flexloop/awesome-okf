# HR 六大模块与三支柱知识包

本知识包是行政人事进修的「专业骨架」：用六大模块（人力资源规划、招聘与配置、培训与开发、绩效管理、薪酬福利管理、劳动关系管理）建立完整的知识地图，用三支柱（COE 专家中心、HRBP 业务伙伴、SSC 共享服务中心）理解大企业 HR 的组织逻辑，并配套招聘入离职、绩效周期、薪酬结构的可复制模板。

> 阅读提示：六大模块与三支柱是管理实践框架（框架佐证来自职业教育资料与公开出版物，已在 facts.md 标注信源等级），不是法规；涉及合同、社保、工时、补偿的法定标准，一律以同组 [劳动法律合规实务](../labor-law-compliance/index.md) 的法规信源为准。
