## 一、职业资格制度改革

| 编号 | 事实内容 | 信源 |
|------|---------|------|
| F-001 | 企业人力资源管理师职业自 2003 年起纳入国家职业资格全国统一鉴定，由人社部门组织全国统一考试。【P0】 | S1 |
| F-002 | 2020 年 7 月 20 日，人力资源社会保障部办公厅印发《关于做好水平评价类技能人员职业资格退出目录有关工作的通知》（人社厅发〔2020〕80号）。【P0】 | S1、S2 |
| F-003 | 80 号文明确：水平评价类技能人员职业资格分批退出国家职业资格目录；企业人力资源管理师与劳动关系协调员同列该文附件第 67 项「人力资源服务人员」。【P0】 | S2 |
| F-004 | 第一批水平评价类技能人员职业资格于 2020 年 9 月 30 日前退出目录，企业人力资源管理师属于第一批退出范围。【P0】 | S1、S2 |
| F-005 | 退出目录后，企业人力资源管理师转为**社会化职业技能等级认定**：由经人社部门备案的用人单位和社会培训评价组织按照国家职业技能标准开展评价，对合格者颁发职业技能等级证书。【P0】 | S1 |
| F-006 | 退出目录前已取得的企业人力资源管理师职业资格证书继续有效，可作为持证者专业能力的证明；该职业属于水平评价类而非准入类，证书本身不是就业上岗的行政许可。【P0】 | S1 |
| F-007 | 职业技能等级证书信息纳入技能人才评价证书全国联网查询系统（osta 平台，jndj.osta.org.cn），用人单位与个人可联网核验；未经备案机构颁发的「培训合格证」「结业证」不属于职业技能等级证书。【P0】 | S1、S3 |
| F-008 | 现行评价依据为《企业人力资源管理师国家职业技能标准（2019 年版）》。【P0】 | S1 |
| F-009 | 该职业技能等级由低到高设四个等级：四级/中级工、三级/高级工、二级/技师、一级/高级技师。【P0】 | S1 |
| F-010 | 劳动关系协调员与企业人力资源管理师同批退出水平评价类职业资格目录，退出后同样实行社会化职业技能等级认定。 | S2 |
| F-011 | 经济专业技术资格（人力资源管理方向）是**独立于技能等级体系的职称序列**：设初级、中级、高级，通过全国统一考试取得，由人事考试机构组织，官方报名平台为中国人事考试网（cpta.com.cn）。【P0】 | S1、S4 |
| F-012 | 国家职业资格目录区分准入类与水平评价类：水平评价类技能人员资格退出目录后，技能人才评价改为「政府宏观调控、备案机构自主评价、证书联网查询」的社会化机制；准入类职业资格仍依法保留。 | S1 |

## 二、岗位版图与职业层级（市场实践）

| 编号 | 事实内容 | 信源 |
|------|---------|------|
| F-013 | 企业人力资源（HR）岗位常见层级为：人力资源专员、人力资源主管、人力资源经理、人力资源总监；模块分工通常围绕人力资源规划、招聘配置、培训开发、绩效管理、薪酬福利、劳动关系六大模块展开。 | S5 |
| F-014 | 大型企业 HR 组织常按三支柱设置岗位：COE（专家中心，负责政策方案设计）、HRBP（人力资源业务合作伙伴，派驻业务单元）、SSC（共享服务中心，集中处理入离职、社保、薪酬核算等标准化事务）。 | S5 |
| F-015 | 行政岗位常见职能覆盖：办公物资采购与台账、固定资产管理、会议保障、公文收发、印章管理、档案与证照管理、商务接待、差旅预订、后勤（物业/网络/保洁/车辆）、行政预算、安全消防与保密、企业文化活动等。 | S5 |
| F-016 | 中小企业普遍将行政与人事合并设置为「行政人事」复合岗位（一个部门或一人兼顾招聘、考勤、社保、物资、接待等）；大型企业则分设人力资源部与行政部。 | S5 |
| F-017 | 公开招聘信息中，人事岗高频硬性要求包括：熟悉劳动合同法与当地社保政策、能独立办理入离职与社保公积金、会用 Excel/HR 系统；行政岗高频要求包括：办公软件熟练、沟通协调、台账细致、有接待与会议保障经验。 | S5 |
| F-018 | 人力资源服务业中还存在招聘顾问/猎头、劳务派遣与外包服务、培训师、劳动关系协调（调解）等市场化岗位方向，与企业内部 HR 岗位构成不同职业路径。 | S5 |

## 放弃的未核验事实（不作为本知识包断言）

1. **各等级报考条件明细**：《企业人力资源管理师国家职业技能标准（2019 年版）》对学历、从业年限有分级要求，但本束未逐字核验标准原文条款，且各地备案评价机构的报考审核口径存在差异，不做逐条断言；报考前应以经备案的评价机构公告为准。
2. **考试科目、题型与考期**：社会化职业技能等级认定由各备案机构分别组织，无全国统一考期；经济师考试科目细节（如具体科目名称、题型）本束未逐字核验中国人事考试网当年度考务文件，不做断言。
3. **薪资数据**：招聘平台薪资区间随城市、行业、企业规模波动极大，任何「HR 月薪 X 万」的数字均不采作事实。
4. **证书与积分落户/技能补贴的挂钩政策**：各地技能提升补贴、积分落户加分政策属地差异大且逐年调整，本束不登记具体金额与条件。
5. **培训机构排名与通过率**：属于商业营销口径，一律不采。
