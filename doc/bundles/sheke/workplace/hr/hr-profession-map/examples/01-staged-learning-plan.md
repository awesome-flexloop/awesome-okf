# 分阶段进修行动清单

> 说明：本清单为知识包原创编排，按「合规底座 → 模块深度 → 系统视角」的能力树设计。每个阶段都以「产出物」为完成标志——行政人事是实务岗位，能拿出来用的模板、清单、方案才是能力证据。

## 使用方法

1. 先对照 [岗位版图](../concepts/01-hr-admin-landscape.md) 判断自己所在企业规模与岗位类型（复合岗 / 模块岗 / 三支柱岗）。
2. 按当前年限进入对应阶段，每阶段建议 3–6 个月完成一轮。
3. 每完成一项在 `[ ]` 中打勾，并把产出物存入个人「工作作品集」文件夹。

## 第一阶段：0–1 年 · 入行期——先不出错

**合规底座（最高优先级）**

- [ ] 通读《劳动合同法》关键条文（第 10/14/19/39/40/47/83/87 条），能说出试用期上限、N/N+1/2N 的适用情形
- [ ] 掌握本地五险一金的缴费比例、基数上下限与经办流程（增员、减员、申报时间）
- [ ] 掌握工时与加班费规则（工作日 150%、休息日 200%、法定节假日 300%；月计薪天数 21.75）
- [ ] 掌握年休假天数规则（5/10/15 天）与产假基本规定
- [ ] 知道劳动争议仲裁时效（1 年）与「仲裁前置」程序
- [ ] 系统学习见 [劳动法律合规实务](../../labor-law-compliance/index.md)

**事务 SOP 化（把每件事做成清单）**

- [ ] 入职流程清单：offer → 合同（1 个月内订立）→ 社保增员 → 考勤开通 → 办公用品 → 入职培训
- [ ] 离职流程清单：离职申请 → 工作交接 → 社保减员 → 离职证明 → 工资结算 → 档案转移
- [ ] 行政台账：办公用品台账、固定资产台账、用印登记表（模板见 [行政管理实务全景](../../../admin/admin-operations/index.md)）

**工具能力**

- [ ] Excel：VLOOKUP/XLOOKUP、IF 嵌套、数据透视表、日期函数（算工龄、合同到期）
- [ ] 熟悉公司 OA/HR 系统的入离职、考勤、审批流配置
- [ ] 公文写作入门：通知、会议纪要、请示报告（见 [公文写作与职场文书](../../../admin/official-writing/index.md)）

**阶段自检**：能独立办完一名员工从入职到离职的全套手续且无合规遗漏；能说清「试用期最长几个月、什么情况下赔 2N」。

## 第二阶段：1–3 年 · 成长期——做深一个模块

**选主模块**（招聘 / 薪酬绩效 / 培训 / 员工关系 择一为主，其余为辅）

- [ ] 招聘方向：独立写 JD、建立面试问题库、统计招聘周期与到岗率、跑通过一次批量招聘
- [ ] 薪酬绩效方向：独立完成月度薪资核算、设计过一次绩效考核表、理解 KPI 与 OKR 区别
- [ ] 员工关系方向：处理过违纪谈话、组织过离职面谈、完整跟过至少一件争议咨询
- [ ] 模块方法论见 [HR 六大模块与三支柱](../../hr-six-modules/index.md)

**法规升级**

- [ ] 从「记数字」升级到「查原文」：会用人社部官网、中国政府网、全国人大网核验政策
- [ ] 建立个人政策收藏夹：按「合同/社保/工时休假/工伤/争议」分类，每条标注发文号与时效
- [ ] 精读 3–5 个官方发布的劳动争议典型案例，能讲清裁判逻辑

**行政线专项**（行政或复合岗）

- [ ] 主导一次大型会议或接待全流程并形成复盘清单
- [ ] 完成一次固定资产全盘，做到账实相符
- [ ] 编制过一次部门年度预算并跟踪执行率

**阶段自检**：在主模块上拥有 3 个以上「我独立做过」的完整项目；遇到人事问题第一反应是查条文而非问群聊。

## 第三阶段：3–5 年 · 进阶期——从模块到系统

**制度设计**

- [ ] 主笔或大幅修订过一项公司制度（考勤、绩效、薪酬、报销、印章管理），并推动落地
- [ ] 能做一次人力成本测算：人头、工资、社保公积金、招聘与培训费用的年度预算
- [ ] 理解职级体系与调薪矩阵的基本逻辑

**视角升级**

- [ ] 用三支柱框架（COE/HRBP/SSC）重新梳理本部门工作，指出哪些是「政策设计」、哪些是「业务嵌入」、哪些是「事务交付」
- [ ] 能看懂公司损益表中与人力、行政相关的成本项，汇报时用「成本/风险/效率」语言而非「我做了什么」
- [ ] 带过新人或实习生，能把个人 SOP 变成团队 SOP

**证书与资质**（按需，不盲从）

- [ ] 体制内/国企发展：备考经济师（人力资源管理），中国人事考试网报名
- [ ] 企业实务：按需参加经备案的企业人力资源管理师技能等级认定，认准 osta 可查
- [ ] 证书决策与防骗见 [证书报考与防骗指南](02-certification-guide.md)

**阶段自检**：主导过一项跨部门制度落地且没有引发劳动风险；向管理层汇报时能提出 2–3 个有数据支撑的改进方案。

## 常见卡点

- **「工作太忙没时间学」**：把学习绑定到手头任务——办一次离职就把离职相关法条学透，做一次盘点就把资产管理标准建立。实务即教材。
- **「小公司接触不到大模块」**：复合岗的优势是全流程视角；缺什么模块就主动争取（如主动承担年会、主导一次制度修订），并用本知识包的清单补齐认知。
- **「学了就忘」**：每个知识点转成一份模板或一个检查项放进自己的 SOP 库；输出是最好的记忆。
