# HR 劳动合规自查与证据留存清单

> 说明：本清单为原创通用自查工具，建议每半年对照检查一次。地方政策（社保基数、最低工资、奖励产假等）以属地最新口径为准；发现问题项先固定证据再整改。

## 一、劳动合同与入职

- [ ] 所有在职员工均已签订书面劳动合同（入职 1 个月内）
- [ ] 试用期期限与合同期限匹配：3 个月–1 年合同 → ≤1 个月；1–3 年 → ≤2 个月；3 年以上/无固定 → ≤6 个月
- [ ] 无「延长试用期」「二次试用」安排；不满 3 个月合同未约定试用期
- [ ] 试用期工资 ≥ 约定工资 80% 且 ≥ 当地最低工资
- [ ] 录用条件、岗位说明书入职时书面告知并签收
- [ ] 员工档案信息完整（身份证、学历、离职证明、合同）；未扣押证件原件、未收取押金
- [ ] 合同到期台账提前 60 天预警，续订/终止书面化

## 二、规章制度

- [ ] 员工手册/考勤/奖惩制度经民主程序制定（职工代表大会或全体职工讨论记录）
- [ ] 制度已公示或告知员工（签收记录、培训签到、邮件确认）
- [ ] 「严重违纪」情形在制度中有明确列举，与解除条款对应
- [ ] 制度修订后重新履行公示告知程序

## 三、薪酬、工时与休假

- [ ] 工资按月足额发放，工资表员工可确认（电子或纸质）
- [ ] 工资不低于当地最低工资标准
- [ ] 加班费按 150%/200%/300% 核算并在工资单单列
- [ ] 日工资折算使用 21.75 天
- [ ] 加班有审批与考勤记录；月加班不超过 36 小时
- [ ] 不定时/综合工时岗位有劳动行政部门审批批复
- [ ] 年休假按累计工龄核定 5/10/15 天，未休部分按 300% 结算
- [ ] 考勤记录定期由员工确认

## 四、五险一金

- [ ] 入职当月按时增员、离职按时减员（属地时点）
- [ ] 缴费基数按实际工资申报，未按最低基数违规操作
- [ ] 无「自愿放弃社保」协议（如有，风险标注并安排补缴整改）
- [ ] 工伤保险全员参保（个人不缴费，但单位必须缴）
- [ ] 公积金按 5%–12% 比例缴存
- [ ] 女职工产假、生育津贴流程明确；怀孕 7 个月以上不安排加班夜班

## 五、解除与离职

- [ ] 辞退前先定性：39 条（过失，证据链）/40 条（前置程序+N 或 N+1）/协商（书面协议）
- [ ] 39 条解除备齐：制度依据 + 违纪事实证据 + 程度相当 + 工会通知
- [ ] 40 条「不胜任」解除备齐：考核记录 + 培训或调岗记录 + 再次考核
- [ ] 第 42 条保护人群（三期、医疗期、工伤、15 年+距退休 5 年）未走 40/41 条解除
- [ ] 协商解除协议写明补偿金额、费用结清、无其他争议
- [ ] 离职出具解除/终止证明（15 日内，按属地要求），工资结清
- [ ] 离职员工档案与合同至少保存 2 年以上备查

## 六、工伤与特殊情形

- [ ] 工伤事故 30 日内申报机制明确，现场证据（监控、证人、考勤）即时保全
- [ ] 知道员工 1 年内可自行申报工伤，未参保待遇全部由单位承担
- [ ] 三期女职工台账完整，合同到期顺延至哺乳期结束
- [ ] 医疗期员工有医疗证明归档，不在医疗期内解除

## 七、证据归档速查（仲裁高频举证项）

| 争议类型 | 单位须备出的证据 |
|---------|-----------------|
| 二倍工资 | 劳动合同文本（签收） |
| 试用期解除 | 录用条件告知书 + 试用期考核记录 + 试用期内作出解除的证明 |
| 严重违纪解除 | 合法规章制度 + 公示证据 + 违纪事实证据（处罚记录/监控/证人） |
| 不胜任解除 | 岗位标准 + 考核结果 + 培训或调岗记录 + 再次考核 |
| 加班费 | 考勤记录（员工确认）+ 工资表 + 加班审批 |
| 工资差额 | 工资支付记录（2 年以上） |
| 年休假 | 工龄证明 + 休假记录 + 未休结算记录 |
| 工伤 | 事故报告 + 申报受理文书 + 缴费记录 |

**归档原则**：凡员工签字的材料一人一档；电子记录定期导出备份；送达文件保留签收或邮寄凭证。参考 [劳动争议处理与证据留存](../concepts/06-labor-dispute-resolution.md)。
