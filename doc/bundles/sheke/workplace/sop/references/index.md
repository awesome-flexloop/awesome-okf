## 信源等级说明

本知识包按以下五档分级信源（从高到低）：

| 等级 | 定义 | 本知识包中的用途 |
|------|------|----------------|
| **L1 权威词典** | 权威语言机构发布的词义与词源条目 | F-001、F-002（词源定锚） |
| **L2 法规原文** | 国家 / 国际监管机构发布的正式法规文本 | F-015、F-016（GMP 要求定锚） |
| **L3 同行评审论文** | 经双盲或单盲评审的学术期刊论文 | F-008、F-009（WHO 手术清单 RCT 数据） |
| **L4 国际组织指南** | WHO / NTSB 等机构的公开指南与建议 | F-010、F-012、F-013 |
| **L5 行业实务资料** | 行业媒体、咨询机构、厂商博客发布的实务文章 | F-017～F-020、F-021～F-024、F-025～F-027 |
| **L6 管理百科** | 管理学术百科对行业通识的整理与转述 | F-003、F-004、F-028～F-031 |
| **放弃核验** | 自媒体流传但无权威出处、或无法交叉验证的数据 | 记入 facts.md 放弃核验清单，不作为断言 |

### 可信度声明

- **L1–L3 事实**：可直接引用作为本知识包的断言基础。
- **L4 事实**：指南性质，权威性略低于法规，但仍可作为行业共识引用。
- **L5–L6 事实**：代表通行实务或管理学通识，适用于方法描述与现象归纳，不支撑法规或疗效断言。
- **放弃核验清单**：作为"本知识包不承诺的事实"公开标注，供读者自行判断。

## 本知识包信源概览

共引用 **10 条独立信源**（S1–S10），详细登记见 [01-source-registry.md](01-source-registry.md)。

信源覆盖四大行业实证：
- 医疗：NEJM 同行评审论文（S2）+ WHO 指南（S3）+ 学术书评（S4）
- 航空：FlightSafety / global-aero 行业媒体（S5）
- 制药：21 CFR 原文（S6）+ 行业实务资料（S7）
- IT：Uptime Labs / Sonat / runframe.io 行业实践资料（S9）
- 词源 / 定义：Merriam-Webster（S1）+ MBA 智库（S8）+ 实务指南（S10）
