# 执行记录表单设计指引

> 洞察 5 指出：**最小可审计单元是"SOP + 执行记录"**。本文提供表单设计原则、字段规范与完整示例，帮助新人跳过"知道重要但不知道怎么设计"的卡点。

---

## 一、设计原则（ALCOA+ 对齐）

| ALCOA+ 属性 | 字段设计含义 | 设计检查项 |
|------------|------------|-----------|
| **A**ttributable（可归因） | 谁执行的 | 必须有签名/工号字段 |
| **L**egible（清晰可读） | 能否辨认 | 打印版字体 ≥ 10pt；手写区有足够空间 |
| **C**ontemporaneous（同步） | 何时做的 | 必须有精确到分钟的时戳字段 |
| **O**riginal（原始） | 是否是第一手记录 | 禁止"事后补录"栏；允许更正但须留痕 |
| **A**ccurate（准确） | 内容是否正确 | 关键数值字段标注单位与容差范围 |
| **C**omplete（完整） | 是否遗漏 | 必填项标注 \*；允许"N/A"但有理由说明 |
| **C**onsistent（一致） | 格式是否统一 | 同一 SOP 的所有记录表单格式相同 |
| **E**nduring（持久） | 能否长期保存 | 纸质表单用 archival-quality 纸张；电子表单存 PDF/A |
| **A**vailable（可获取） | 审计时能否找到 | 与 SOP 同编号、同版本管理，存放位置明确 |

---

## 二、表单字段规范

### 2.1 表头（元数据区）

| 字段 | 必填 | 说明 |
|------|------|------|
| 表单编号 | ✅ | 与 SOP 编号关联（如 SOP-001 对应 FORM-001） |
| 表单名称 | ✅ | 描述记录内容（如"设备点检记录"） |
| 关联 SOP | ✅ | 标明引用的 SOP 编号 |
| 版本 | ✅ | 与关联 SOP 版本号一致 |
| 密级 | 可选 | 公开/内部/机密 |

### 2.2 记录正文（数据区）

每条记录至少包含以下五要素：

| 要素 | 字段名 | 示例 |
|------|--------|------|
| 时间 | 操作时间 | 2026-09-08 14:30 |
| 人员 | 操作者签名/工号 | 张三 / EMP-00123 |
| 内容 | 做了什么 | 检查 A 线压力阀，读数 0.42 MPa |
| 结果 | 判定 | ✅ 正常 / ❌ 异常 → 已报修 |
| 异常备注 | 如有异常 | 压力偏高，已通知维修组 |

### 2.3 表尾（审核区）

| 字段 | 说明 |
|------|------|
| 复核人签名 | 第二人核对（双人复核制度） |
| 复核时间 | 复核人签字时间 |
| 归档位置 | 纸质存哪个档案盒 / 电子存在哪个路径 |

## 四、表单与 SOP 版本联动规则

| 场景 | 操作 |
|------|------|
| SOP 修订 | 关联表单同步修订，版本号递增 |
| 新增检查项 | 表单新增行，SOP 对应步骤更新引用 |
| 表单废止 | SOP 更新"参考文件"字段移除关联，表单标记"[已废止]" |
| 版本脱节检测 | 每季度核查：表单版本号是否落后 SOP 版本号超过 1 个迭代 |

## 五、常见表单设计错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 表单没有编号 | 审计时无法溯源 | 添加"表单编号"字段，与 SOP 编号体系对齐 |
| 手写区太小 | 字迹潦草，不 legible | 每行高度 ≥ 8mm，预留足够书写空间 |
| 缺少复核字段 | 无双人确认，合规风险 | 增加"复核者签名 + 时间"栏 |
| 无归档位置 | 审计时找不到 | 表尾明确纸质/电子归档路径 |
| 允许涂改无痕迹 | 数据完整性风险 | 增"更正栏"：原值 → 更正值，签名 + 日期 |
