# 通用 SOP 模板（可复制）

> 本模板参考 ALCOA+ 原则（F-019）与四层文件体系（F-017），可直接复制到组织内作为 SOP 骨架使用。**所有示例占位符须替换为真实业务内容**，并经质量 / 法规部门审核后生效。

## 模板骨架（Markdown 表格版）

> 移动端友好版本，ASCII 框图见上方。以下为表格形式，复制后可直接编辑。

| 字段 | 填写说明 |
|------|---------|
| **单位全称** | 填写组织正式名称 |
| **SOP 编号** | 唯一标识，含系统前缀（如 `QA-SOP-001`） |
| **页码** | 格式：`__ / __页` |
| **生效日期** | YYYY-MM-DD 格式 |
| **关键词** | 3～5 个检索关键词 |
| **密级** | 公开 / 内部 / 机密 |
| **复审周期** | 月数（默认 12） |
| **1. 目的** | 一句话说明为什么需要这份 SOP |
| **2. 适用范围** | 适用岗位/设备/流程/场所 |
| **3. 职责** | 3.1 执行者 / 3.2 监督者 / 3.3 批准者 |
| **4. 操作步骤** | 每个步骤含：输入 / 工具材料 / 关键控制点 / 预期输出 / 记录表单 |
| **5. 注意事项** | 5.1 安全 / 5.2 质量 / 5.3 应急 |
| **6. 相关记录表单** | 列出表单名称 + 编号 |
| **7. 修订记录** | 版本 / 日期 / 修订内容 / 编制人 / 审核人 / 批准人 |

## 字段填写说明（对齐 ALCOA+）

| 字段 | ALCOA+ 对应 | 填写要点 |
|------|-----------|---------|
| 编号 | **A**（Attributable） | 唯一、含系统前缀、与记录表单同序列 |
| 生效日期 | **C**（Contemporaneous） | 日期格式统一（YYYY-MM-DD），与记录表单生效同步 |
| 编制人 | **A** | 实际编写者，通常为一线技术骨干 |
| 审核人 | — | 技术正确性审核，通常为同组资深人员 |
| 批准人 | **O**（Original） | 质量部门或主管，授权生效 |
| 步骤中的"预期输出" | **A**（Accurate）+ **C** | 写清楚"什么是正确结果"，避免"拧紧""适当"等无验收标准词 |
| 表单编号 | **C** + **E**（Enduring） | 与 SOP 同编号、同版本，确保可追溯 |

## 禁用词汇清单

依据 EU GMP 与行业惯例（F-019、F-032），以下词汇禁止出现在 SOP 正文：

| 禁用词 | 替代写法 |
|--------|---------|
| "拧紧"（无扭矩） | "使用扭力扳手以 XX N·m 扭矩拧紧" |
| "适当温度" | "加热至 75±2℃" |
| "及时记录" | "操作完成后 15 分钟内填写 [表单编号]" |
| "加强检查" | "每 30 分钟检查一次，填写 [表单编号] 第 ___ 项" |
| "视情况处理" | 列出所有可能情形及对应动作（条件分支） |

## 版本管理要点

1. **每个 SOP 必须有唯一 owner**（通常为编写者或其直属主管），owner 离任时须交接。
2. **复审周期默认 12 个月**，变更触发即时复审；高风险 SOP（手术、动火、用印等）复审周期不超过 6 个月。
3. **废止 SOP 须回收全部副本**并在文档管理平台标记为"[已废止]"——避免误用旧版（F-032）。
