# 《爱的五种语言》知识包

本知识包介绍美国婚姻辅导者盖瑞·查普曼（Gary Chapman）的畅销读物《爱的五种语言》（*The Five Love Languages*，1992 年初版）及其提出的"五种爱之语"框架。内容覆盖作者背景与成书出版、核心隐喻"爱箱"、五种爱语、爱语的发现方法，并**以同等篇幅呈现学界对该框架的实证检验与批评**，帮助读者把它当作一个沟通启发工具来使用，而非一套经过科学验证的人格理论。

> 阅读提示：本书属于大众自助（self-help）读物，其框架来自作者长期牧灵辅导中的临床观察，而非受控研究。书中的实用性建议与关系科学的实证结论之间存在差距，本知识包在 [概念04](concepts/04-evaluation-and-boundaries.md) 与 [事实清单](facts.md) 中对此作了明确区分。
