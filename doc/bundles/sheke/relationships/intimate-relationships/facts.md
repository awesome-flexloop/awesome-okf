## 五、学科定位与理论脉络

| 编号 | 事实内容 | 信源 |
|------|---------|------|
| F-034 | 出版社官方介绍称本书是关系科学（relationship science）的综合综述，汲取社会心理学、沟通研究、家庭研究、社会学、临床心理学、神经科学、人口学、经济学等学科成果 | mhe-9e；learningally-6e |
| F-035 | 第6版中译本内容提标称本书汲取社会心理学、沟通研究、家庭研究、认知心理学、发展心理学、演化心理学、社会学、传播学及家政学等学科成果 | douban-6e |
| F-036 | 本书第6章“相互依赖”以社会交换与相互依赖理论为框架，使用结果、比较水平（CL）、替代比较水平（CLalt）等核心概念；该理论由 John Thibaut 与 Harold Kelley 于1959年提出、1978年系统化 | vanlange-rusbult；spt-afirstlook |
| F-037 | 成人依恋研究的奠基论文为辛迪·哈赞（Cindy Hazan）与菲利普·谢弗（Phillip Shaver）1987年发表于《人格与社会心理学杂志》的《浪漫之爱概念化为依恋过程》（52卷3期，511–524页，DOI: 10.1037/0022-3514.52.3.511） | hazan-shaver-1987 |
| F-038 | 哈赞与谢弗1987年的两项问卷调查发现，成人中安全型、回避型、焦虑/矛盾型三种依恋类型的相对比例与婴儿期研究大致相同，三类成人的浪漫爱情体验存在可预测的差异 | hazan-shaver-1987 |
| F-039 | 进化心理学择偶研究的代表作是戴维·巴斯（David M. Buss）1989年发表于《行为与脑科学》的37文化择偶偏好研究（33国37个样本，N=10047）：女性普遍更看重伴侣的经济前景与抱负勤勉，男性普遍更看重伴侣的年轻与外貌 | buss-1989 |
| F-040 | 自我延伸模型（self-expansion model）由阿瑟·阿伦（Arthur Aron）与伊莱恩·阿伦（Elaine Aron）提出，代表作为1986年《爱与自我的延伸》（Love and the Expansion of Self），1996年在《个人关系》杂志发表模型综述（3卷45–58页） | aron-biblio |
| F-041 | 社会渗透理论（social penetration theory）由欧文·奥特曼（Irwin Altman）与达尔马斯·泰勒（Dalmas Taylor）于1973年提出，以“洋葱模型”描述自我表露由表层到核心、由浅入深的关系发展过程 | spt-rutgers；spt-afirstlook |
| F-042 | “归属需要”（the need to belong）理论出自罗伊·鲍迈斯特（Roy F. Baumeister）与马克·利里（Mark R. Leary）1995年发表于《心理学公报》的论文（117卷，497–529页） | niigata-ref |
| F-043 | 约翰·戈特曼（John Gottman）经四十余年、逾3000对伴侣的观察研究提出“末日四骑士”——批评、蔑视、防御、筑墙（冷战）四种负面互动模式，其中蔑视被其研究列为离婚的最强单一预测因素 | gottman-horsemen；gottman-srh |
