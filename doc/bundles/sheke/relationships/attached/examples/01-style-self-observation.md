# 依恋倾向自察与追—逃场景分析

本篇是原创的自察工具。它不复现原书的测验题，而是提供"情境对照 + 反思提问 + 循环拆解"三组练习。建议在平静时（而非刚吵完架时）完成，把注意力放在**行为模式与触发条件**上，而不是给自己判定一个固定类型。

## 练习一：两组情境中的自动反应

阅读下列两组常见情境，注意哪一种反应更接近你的"第一反应"。第一反应没有对错之分，它提示的是依恋系统的默认设定。

**情境 A：伴侣回复消息明显变少，且解释含糊。**

- 反应 1：反复看手机，忍不住连发消息或打电话确认；心里开始列出"他最近变了"的证据；想试探（"你是不是不想谈了"），又怕一试成真。
- 反应 2：有点不舒服，但会先把注意力转开，等对方联系时再看；即使在意，也倾向于不表现出来，觉得"说了显得我很闲"。
- 反应 3：会直接问一句"今天怎么回得这么少，是太忙了吗"，对方给个合理说法就翻篇；不倾向于把它上升为关系判决。

**情境 B：关系明显升温，对方提出同居/见家长等更亲近的安排。**

- 反应 1：兴奋且期待，恨不得关系马上确定下来；如果对方态度有一丝犹豫就非常不安。
- 反应 2：第一反应是压力，开始想"会不会太快""我会不会失去自己的空间"，下意识拖延或挑出推进过程中的毛病。
- 反应 3：愿意认真考虑，既看到亲近的好处也讨论实际安排，节奏可以商量。

自察要点：两组情境中反应 1 偏向焦虑端（高激活），反应 2 偏向回避端（高去激活），反应 3 偏向安全端。多数人不会在所有情境中一致——记录下你在什么条件下会切换反应，比得出一个"型"更有价值。

## 练习二：七个反思问题

准备一张纸，按时间顺序回忆**最近一次让你明显情绪波动的关系事件**，回答：

1. 触发事件是什么？（对方具体做了或没做什么——只写行为，不写评价）
2. 我脑子里冒出的第一个念头是什么？（"他不爱我了""她在控制我"……）
3. 这个念头出现时，我身体和情绪上有什么感觉？（心慌、胸闷、烦躁、麻木、想逃）
4. 我随后实际做了什么？（追问、冷战、翻手机、讲道理、转移注意力）
5. 这个动作是想让对方靠近，还是想拉开距离？
6. 对方实际反应是什么？我的动作让结果变好还是变坏了？
7. 如果回到那一刻，一个更安全的回应会是什么？

问题 5 是枢纽：让对方靠近的动作多属激活策略，拉开距离的动作多属去激活策略（机制见 [依恋系统的运作机制](../concepts/02-attachment-system-at-work.md)）。连续记录 3–5 次事件，你自己的策略模式会自然浮现。

## 练习三：追—逃循环拆解模板

以一个**虚构的典型案例**演示如何拆解（人物与情节为教学编排，非原书案例）：

> 小林（焦虑倾向）和阿哲（回避倾向）同居。周五晚上阿哲说周末要独自去骑车，小林嘴上说"好"，心里开始不舒服。周六小林连发十几条消息追问行程，阿哲越骑越烦，索性不回。晚上阿哲回家后沉默看电视，小林崩溃质问"你心里根本没有我"，阿哲回了一句"你能不能别这么黏人"，随后两天两人冷战。

按下表填写你自己的版本：

| 拆解项 | 案例填写示范 | 你的版本 |
|--------|-------------|---------|
| 触发事件 | 伴侣宣布需要独处时间 |  |
| 焦虑方的解读 | "他不想和我待在一起，我不重要了" |  |
| 激活策略 | 连发消息、追问行程、崩溃质问 |  |
| 回避方的解读 | "她在控制我，我连独处都不行" |  |
| 去激活策略 | 不回消息、沉默、贴"黏人"标签 |  |
| 循环的自我证实 | 小林：他果然冷漠；阿哲：她果然逼得紧 |  |

## 练习四：直接表达改写

把抗议式/冷战式表达改写为直接表达（方法见 [走向安全](../concepts/04-toward-secure.md)）。仍用上述虚构案例演示：

| 原型（抗议/去激活） | 改写（直接表达需求） |
|--------------------|--------------------|
| "你心里根本没有我！"（质问） | "你一整天没消息的时候，我会很不安。我不是要拦着你骑车，是希望出发前和休息时能收到你一句消息。" |
| 已读不回、冷战两天（沉默） | "我需要一点时间消化，但这不是不想谈；今晚我们聊十分钟好不好？" |
| "你能不能别这么黏人"（贴标签） | "我骑车时需要完全放空，回消息会让我很紧绷。我们约个固定的报平安时间，其他时候我晚一点回，行吗？" |

改写的三个要点：①说自己的感受和具体需求，不评判对方人格；②需求小而具体、可执行（"一句消息""十分钟"），而不是"你要更在乎我"；③给对方留出协商空间，直接表达不等于最后通牒。

## 自察记录模板（可复用）

```
日期：
触发事件（仅行为）：
第一念头：
情绪/身体反应：
我采取的策略（激活/去激活）：
对方反应：
结果评估（关系更近还是更远）：
下次的替代回应：
```

坚持记录四周，回看时重点看两件事：触发我的事件有没有共性（不回消息？迟到？态度敷衍？），以及我的策略是否在重复同一种效果。模式被看见，改变才有可能开始。
