# 婚姻关系自查清单

> **性质说明**：本清单是知识包编订者依据戈特曼公开的七原则框架与四骑士概念**原创编排**的自查工具，用于个人反思与伴侣沟通，**不是**《幸福的婚姻》原书量表的复制或翻译，也不具备任何临床诊断效力。若关系中存在暴力、长期严重痛苦或心理创伤，请寻求专业伴侣治疗或心理咨询。

## 使用方法

- 每题按最近一个月的真实情况打分：**2 = 基本符合，1 = 偶尔符合，0 = 基本不符合**；
- 建议夫妻各自独立作答，再交换结果——答案差异本身就是爱情地图的更新材料；
- 观察对象是“行为发生的频率模式”，不是“谁对谁错”；请按事实作答，不按理想状态作答。

## 维度 A：爱情地图（对应原则 1）

- [ ] A1. 我能说出配偶最近一周最烦心的一件工作/生活事务。
- [ ] A2. 我知道配偶目前最要好的两三个朋友是谁。
- [ ] A3. 我能讲出配偶童年经历中影响其性格的一两件关键往事。
- [ ] A4. 最近一个月我们聊过各自的梦想、期待或担忧，而不只是事务安排。
- [ ] A5. 配偶生活中发生变化（新同事、新压力）时，我会主动追问细节。

**维度参考**：得分低于 5（满分 10）提示对配偶内心世界的测绘已经过期，先从每天一个开放式问题补起。

## 维度 B：喜爱与赞美（对应原则 2）

- [ ] B1. 最近一周我至少一次口头感谢或欣赏过配偶的具体行为。
- [ ] B2. 我能立刻列出配偶三个让我敬重的特质。
- [ ] B3. 发生矛盾时，我仍能想起“我当初为什么欣赏这个人”。
- [ ] B4. 我不会在他人（含孩子、朋友、家人）面前贬低配偶。
- [ ] B5. 当我想到配偶为家庭的付出时，会觉得那是“被我看见的”，而非理所当然。

**维度参考**：B4 是底线题——习惯性对外贬低配偶，提示蔑视模式已外溢。

## 维度 C：彼此靠近（对应原则 3）

- [ ] C1. 配偶跟我分享琐事（“你看这个”）时，我通常会停下手里的事回应，而非只哼一声。
- [ ] C2. 最近一周我们有过至少两次超过十分钟、不谈事务的轻松聊天。
- [ ] C3. 我能察觉到配偶发出的“求关注/求安慰”信号，即使表达得很笨拙。
- [ ] C4. 我们每天有至少一个固定的连接时刻（如一起吃饭、睡前聊几句）。
- [ ] C5. 我发起的小邀请（聊天、互动提议）多数能得到配偶的回应。

**维度参考**：C5 同时反映你对配偶的回应模式——戈特曼研究中稳定婚姻的邀请回应率为 86%，走向离婚者平均 33%[^emotional-bank]，可据此粗估自己的“靠近率”。

## 维度 D：接受影响与权力共享（对应原则 4）

- [ ] D1. 做重要决定时，我会主动问自己“配偶会怎么看”，并真的纳入考量。
- [ ] D2. 意见分歧时，我能在对方立场中找到至少一点合理之处并说出来。
- [ ] D3. 我不会用“算了不跟你争”的方式单方面宣布结束讨论。
- [ ] D4. 家里的重大事务（开支、子女、老人安排）是双方共同决策，而非一方主导。
- [ ] D5. 当配偶指出我考虑不周时，我多数时候能调整，而不是立刻辩解。

## 维度 E：冲突开端与四骑士（对应原则 5 前置 / 危险信号）

- [ ] E1. 我们发生争执时，我能做到就事论事，不上升到“你总是/你从来不”。
- [ ] E2. 争吵中我不会翻白眼、冷笑、嘲讽或模仿对方（蔑视自查）。
- [ ] E3. 被批评时，我能先承认自己有份的部分，而不是立刻反击或喊冤。
- [ ] E4. 情绪上头时我会说“我需要暂停一会儿”，而不是直接沉默走开或摔门。
- [ ] E5. 争执的前三分钟，我们通常还能保持基本平和（软性开端自查）。

**维度参考**：E2 是全清单最重要的单项——蔑视（嘲讽、翻白眼、辱骂）是戈特曼体系中最具破坏性的模式[^psychology-horsemen]。若 E2 为 0 且持续存在，优先处理这一项，其他技巧都应让位。

## 维度 F：修复与降温（对应原则 5）

- [ ] F1. 争吵中对方递台阶（玩笑、示好、转移话题）时，我愿意接住。
- [ ] F2. 我自己也会主动发出修复信号（道歉、递水、“先吃饭吧”）。
- [ ] F3. 暂停之后我们会真的回到话题，而不是让矛盾烂尾。
- [ ] F4. 吵完之后我们通常能在当天（至少睡前）有所缓和。
- [ ] F5. 我们之间没有“一碰就炸、谁都不许再提”的永久禁区话题。

**维度参考**：F5 为 0 提示存在僵局（gridlock）信号——同一话题反复卡死，应转入维度 G 的处理思路，而非继续硬吵。

## 维度 G：僵局共处与共同意义（对应原则 6、7）

- [ ] G1. 对于我们反复争吵的老话题，我能说出“对方为什么这么在意”，即使我不认同。
- [ ] G2. 我理解某些分歧可能永远不会消失，我们在学习与差异共处，而非等待对方改变。
- [ ] G3. 我们有共同珍视的仪式（节日过法、纪念日、家庭惯例）。
- [ ] G4. 我们对未来一两年有至少一个共同目标。
- [ ] G5. 我觉得这段婚姻里有“我们俩”的东西，而不只是两个人搭伙过日子。

## 结果解读

| 总分（满分 70） | 参考解读 | 建议方向 |
|----------------|----------|----------|
| 56–70 | 互动模式整体健康，友谊账户余额充足 | 保持高频小动作，重点维护维度 G 的意义建设 |
| 42–55 | 友谊基础尚可，但有 1–2 个明显薄弱维度 | 按最低维度对应的概念文档补课：A/B/C → 友谊系统；D/E/F → 冲突机制；G → 僵局与意义 |
| 28–41 | 多个维度亮灯，四骑士可能已成模式 | 建议先读 [末日四骑士](../concepts/01-four-horsemen.md) 与 [修复机制](../concepts/04-ratio-repair.md)，伴侣共同讨论；考虑戈特曼方法伴侣治疗 |
| 0–27 | 关系处于高风险状态 | 不建议仅靠自助；优先寻求专业伴侣咨询；如有安全风险先保障人身安全 |

**比总分更重要的是单项红旗**：E2（蔑视）、F5（僵局禁区）、B4（对外贬低）任何一项为 0，都应作为首要处理事项，不受总分影响。

## 使用提醒

1. 本清单三个月做一次即可，重点看**趋势**而非单次分数；人在刚吵完架时作答会系统性偏低，避免在冲突后 24 小时内使用。
2. 清单不替代对原书的阅读——它给出“在哪”，概念文档解释“为什么”，原书提供“怎么练”的完整细节。
3. 配合 [七原则实践计划](02-principles-practice-plan.md) 使用：自查定位短板，实践计划安排动作。
