# 指数基金定投全流程操作清单

> 说明：本清单为可直接照做的通用操作框架，**全程不出现具体基金名称、代码或平台名**——同类产品按「低费率、低跟踪误差、规模稳定」自行比较。方法依据见 [05 指数基金与有效市场](../concepts/05-index-funds-emh.md) 与 [04 资产配置](../concepts/04-asset-allocation.md)。

## 一、准备阶段（动手投之前）

- [ ] 已备应急基金：3–6 个月生活支出，放在货币基金等高流动性工具里（F-032）
- [ ] 已配置保障型保险：医疗、重疾、定期寿险、意外（先保障后理财，F-032）
- [ ] 高息负债（年化两位数的消费贷、信用卡分期）已优先偿还（F-032）
- [ ] 已确定每月可投金额：用「月收入 − 支出 − 弹性储备」倒算，不因定投影响生活
- [ ] 已确认这笔钱 5 年以上不用（指数基金适合长期资金，短期要用的钱放货币基金或储蓄国债，F-011、F-043）
- [ ] 已选定固定扣款日：工资日后 1–3 天，避开月末缴费高峰
- [ ] 已写下一页纸投资计划：目标股债比例、月投额、再平衡规则（防临场情绪，见 [06 行为金融](../concepts/06-behavioral-discipline.md)）

## 二、选基阶段（只选类别与规则，不追热门）

- [ ] **先选宽基指数**：入门核心仓位选覆盖全市场或大盘的宽基指数（A 股代表性宽基如沪深 300 于 2005-04-08 发布，F-016）；行业主题基金不做核心仓
- [ ] **看跟踪误差**：指数基金的职责是复制指数，跟踪误差越小越合格（F-015、F-016）
- [ ] **看综合费率**：管理费 + 托管费 + 申购/赎回费 + 销售服务费一并算；1% 的年费差在 30 年复利下可差出终值的约 1/4（F-023，算例见 [05 概念篇](../concepts/05-index-funds-emh.md)）
- [ ] **场内 ETF 还是场外指数基金**（F-016）：
  - 场内 ETF：在证券账户内像股票一样实时交易，费率通常低，需手动下单、价格实时波动有买卖价差
  - 场外指数基金：按净值申购赎回，可设自动定投扣款，省心——定投优先选场外
- [ ] **A 类还是 C 类份额**（F-044）：
  - A 类：申购时付申购费（常打折）、持有期间无销售服务费 → 预计持有 1 年以上选 A
  - C 类：无申购费、按日计提销售服务费 → 持有期短或不确定选 C
  - 判断口径：持有时间越长，A 类越划算；不确定就用「计划持有年限 × 年销售服务费率」与「申购费率」比较
- [ ] **基金合同与托管**：确认是公募基金（受证监会监管、银行托管，基金公司不能直接挪用资产，F-014）
- [ ] **销售机构资质核验**：在证监会、基金业协会官网可查（F-045），查不到的渠道不用

## 三、执行阶段（机械化，不看脸色）

- [ ] 已设置自动定投：每月固定日、固定金额自动扣款（F-010）
- [ ] **下跌时不止投**：净值低同样金额买到更多份额，定投摊薄成本正是在下跌期发生（F-010）
- [ ] **「越跌越加」的纪律条件**（事先写好，不临时起意）：
  - 条件示例（教学假设）：指数自近期高点回撤每满 10 个百分点，当月定投额增加一档（如 0.5 倍），加仓总额度设上限（如月投额的 3 倍封顶），且只用预留现金
  - 加不加都必须继续基础定投；加不了也不焦虑——基础定投本身已在低位多买份额
- [ ] 上涨时不加码追投：定投金额不因行情上调，避免近因偏差（F-029）
- [ ] 不做「单笔抄底」：想用存量资金一把投入时，改为分 3–6 个月分批进场，仍由自动计划执行

## 四、维护阶段（年检，不日检）

- [ ] **每年固定一次再平衡**（如生日月）：算出股债实际比例，与目标比例对照（F-009）
- [ ] **阈值检查**：任一资产偏离目标 ±5 个百分点即触发，卖出涨多的、买入跌多的（F-009）
- [ ] 再平衡操作步骤：① 查各基金最新市值与占比；② 算每类应调到的目标金额；③ 优先用**新增定投资金**补低配资产（省申赎费）；④ 不够再赎回超配资产
- [ ] 每年读一次基金年报/季报：确认跟踪误差没有恶化、规模没有异常缩水（F-015）
- [ ] 每周看盘不超过一次；频繁查看会诱发过度交易，交易越多净收益越低（F-031）
- [ ] 记录每一次「计划外操作」的理由，季度复盘时对照行为偏差清单（见 [示例 03](03-behavior-self-check.md)）

## 五、退出阶段（按日历，不按预测）

- [ ] **目标日期前 3–5 年启动降权益**：随用钱日期临近，逐年把股票目标比例下调（生命周期逻辑，F-034），例如目标前每年降 5–10 个百分点
- [ ] 降权益用「新增资金全买债券 + 到期不补股票」的渐进方式，不做一把清仓
- [ ] **不用市场预测决定退出时点**：不猜顶部、不因为「感觉要跌」提前清仓——感觉是近因偏差与过度自信（F-029）
- [ ] 用钱分笔规划：到期用钱按月赎回，避免被迫在某一个低点全部变现（流动性风险，F-006）
- [ ] 长期持有的税收意识：股票分红持股超 1 年暂免个税（F-040）；基金分红与申赎差价暂免个税（F-041）——频繁换基金会弄丢这些制度红利
- [ ] 税优账户单独管理：能享受个人养老金税优的，每年用足额度并长期锁定（年缴上限 1.2 万元、领取按 3% 计税，F-038）

## 六、常见操作错误速查

| 错误做法 | 为什么错 | 依据 |
|---|---|---|
| 看近一年排名选冠军基金 | 主动基金业绩持续性弱；指数基金则应看跟踪误差与费率 | F-022、F-023 |
| 跌了就停投、涨了加仓 | 与定投机制完全相反，变成高买低卖 | F-010、F-029 |
| 每月手动下单 | 临场情绪一定会干预，自动化才是纪律 | F-010、F-031 |
| 同时定投七八只主题基金 | 看似分散实则重叠，核心仓位给宽基 | F-007、F-016 |
| 再平衡凭感觉「差不多就行」 | 不写阈值就不会执行，再平衡价值在于强制 | F-009 |
| 临用钱还满仓股票 | 期限错配，低点被迫变现 | F-006、F-034 |

> 制度规则（税费、份额、账户）可能调整，以官方最新口径为准；本清单不构成投资建议（F-046）。
