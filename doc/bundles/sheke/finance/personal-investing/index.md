# 个人投资实操通识知识包

![金币大树生长在逐渐陡峭上扬的复利曲线上，穿破云层，晨光温暖。](/_static/bundles/sheke/finance/personal-investing/images/hero-compound-growth.jpg)

本知识包是普通人理财入门的「通识地图」：不荐股、不预测市场、不承诺收益，只把被几十年市场数据与学术研究反复验证、且能被普通人直接执行的道理整理成规则、算例与清单。全部事实采用双信源体系——**理论与方法**挂经典著作与诺奖级学术源头（格雷厄姆、博格、马尔基尔、马科维茨、卡尼曼、法玛、席勒），**中国制度与规则**挂全国人大、国务院、人民银行、财政部、证监会等官方文件（46 条事实、18 个信源）。

> 阅读提示：本包讲的是全国性通识与长期规律；具体产品费率、税率细则、个人养老金产品名录等会调整，实务中以金融机构公告与监管官网最新文件为准。**本包为通识教育材料，不构成投资建议、收益承诺或产品推荐。市场有风险，决策需谨慎。**
