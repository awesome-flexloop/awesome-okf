# 个人投资实操通识知识包

本知识包（bundle）覆盖个人投资六大主题：收益与风险的数学基础、投资之前的理财优先级、资产类别与工具谱系、资产配置与再平衡、指数基金与有效市场、行为金融与投资纪律，以及中国市场制度与规则。全部论断按事实编号（F-001 ~ F-046）溯源至两类信源——**理论事实**挂 S1–S9 经典著作与诺贝尔奖官方记录，**制度事实**挂 S10–S17 中国官方文件；有学术争议的理论（如有效市场假说、资产配置贡献度）按原文主张客观登记，不写成定律。

> **定位提示**：本包为教学与通识用途，所有算例均为教学假设，**不构成投资建议**；费率、税率、产品规则等时效敏感内容以财政部、税务总局、证监会、人民银行等官方最新发布为准。
