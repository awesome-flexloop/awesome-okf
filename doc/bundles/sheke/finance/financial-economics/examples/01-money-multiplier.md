# 货币乘数与货币供给算例

> 本算例为教学演示，数字均为假设，不对应任何国家或年份的实际数据。现实中的 M2 还受财政存款、同业业务、外汇占款、理财分流等影响，不能直接用简化公式精确预测。

## 一、假设

| 变量 | 符号 | 数值 |
|------|------|------|
| 基础货币 | MB | 100 亿元 |
| 法定存款准备金率 | r | 10% |
| 超额准备金率 | e | 2% |
| 现金漏损率（现金/存款） | c | 5% |

## 二、公式

简化货币乘数（F-014）：

> m = (1 + c) / (r + e + c)

广义货币：

> M2 = m × MB

存款与现金拆分：

> M2 = C + D，且 C = c × D
>
> D = M2 / (1 + c)
>
> C = M2 − D

准备金：

> 法定准备金 = r × D
>
> 超额准备金 = e × D
>
> 准备金总额 = (r + e) × D

## 三、逐步计算

**第 1 步：计算分母。**

> r + e + c = 0.10 + 0.02 + 0.05 = 0.17

**第 2 步：计算货币乘数。**

> m = (1 + 0.05) / 0.17 = 1.05 / 0.17 ≈ **6.18**

**第 3 步：计算 M2。**

> M2 = 6.18 × 100 = **618 亿元**

**第 4 步：拆分存款与现金。**

> D = 618 / 1.05 ≈ **588.6 亿元**
>
> C = 618 − 588.6 ≈ **29.4 亿元**

**第 5 步：拆分准备金。**

> 法定准备金 = 0.10 × 588.6 ≈ **58.9 亿元**
>
> 超额准备金 = 0.02 × 588.6 ≈ **11.8 亿元**
>
> 准备金总额 ≈ **70.7 亿元**

**第 6 步：核对基础货币。**

> C + 准备金总额 = 29.4 + 70.7 = **100.1 亿元** ≈ MB

四舍五入造成 0.1 亿元误差，逻辑闭合。

## 四、结果汇总

| 项目 | 金额（亿元） | 占 M2 比例 |
|------|-------------|-----------|
| M2 | 618.0 | 100% |
| 存款 D | 588.6 | 95.2% |
| 现金 C | 29.4 | 4.8% |
| 法定准备金 | 58.9 | 9.5% |
| 超额准备金 | 11.8 | 1.9% |
| 基础货币 MB | 100.0 | 16.2% |

货币乘数 6.18 的含义是：每 1 元基础货币，最终支撑约 6.18 元 M2。这个放大来自银行体系的贷款创造存款（F-015），但受现金漏损、准备金率与超额准备金约束。

## 五、敏感性分析

### 5.1 法定准备金率变化

固定 c = 5%、e = 2%：

| 法定准备金率 r | 分母 r+e+c | 货币乘数 m | M2（亿元） |
|----------------|-----------|-----------|-----------|
| 8% | 0.15 | 7.00 | 700.0 |
| 10% | 0.17 | 6.18 | 618.0 |
| 12% | 0.19 | 5.53 | 553.0 |
| 15% | 0.22 | 4.77 | 477.0 |

准备金率上升 2 个百分点（10% → 12%），M2 从 618 亿元降到 553 亿元，降幅约 10.5%。这就是「降准/升准」的数量效应。

### 5.2 现金漏损变化

固定 r = 10%、e = 2%：

| 现金漏损 c | 分母 | 货币乘数 | M2（亿元） |
|------------|------|---------|-----------|
| 3% | 0.15 | 6.87 | 687.0 |
| 5% | 0.17 | 6.18 | 618.0 |
| 10% | 0.22 | 5.00 | 500.0 |
| 15% | 0.27 | 4.26 | 426.0 |

现金漏损上升，意味着公众把更多钱放在银行体系外，货币乘数下降。支付习惯、危机恐慌、地下经济都会影响 c。

### 5.3 超额准备金变化

固定 r = 10%、c = 5%：

| 超额准备金 e | 分母 | 货币乘数 | M2（亿元） |
|--------------|------|---------|-----------|
| 0% | 0.15 | 7.00 | 700.0 |
| 2% | 0.17 | 6.18 | 618.0 |
| 5% | 0.20 | 5.25 | 525.0 |
| 10% | 0.25 | 4.20 | 420.0 |

银行越谨慎、越不愿意放贷，超额准备金越高，货币乘数越低。这就是「宽货币」难以变成「宽信用」的机制之一。

## 六、政策含义

1. **基础货币是原材料，不是成品。** 央行可以投放基础货币，但 M2 能否扩张，取决于银行放贷意愿、企业借款需求与现金漏损。
2. **降准有数量效应，但不保证信贷扩张。** 如果银行把释放的资金用于购买债券或作为超额准备金，实体信贷未必增加。
3. **货币乘数是结果，不是政策工具。** 用固定乘数预测 M2 会出错；应把乘数当作观察银行体系行为的指标。
4. **中国语境要看社融。** M2 是负债端，社融是资产端；两者背离时，单看 M2 会误判金融条件（F-079）。

## 七、边界与提醒

- 本算例忽略了财政存款、同业业务、外汇占款、理财分流、法定准备金付息等现实因素。
- 中国货币层次与统计口径会调整（F-011、F-012），实际分析应使用人民银行公布的同口径数据。
- 算例不构成对货币政策、利率或资产价格的预测。
