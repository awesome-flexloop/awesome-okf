# 现值、年金与债券定价算例

> 本算例为教学演示，利率、金额与期限均为假设，不对应任何真实产品。实际房贷有手续费、保险、税费与提前还款条款；实际债券有信用风险、税收与流动性差异。

## 案例一：100 万元房贷，30 年，年利率 5%

### 1.1 参数

| 参数 | 数值 |
|------|------|
| 贷款本金 PV | 1,000,000 元 |
| 年利率 | 5% |
| 月利率 r | 5% / 12 = 0.416667% |
| 期限 | 30 年 = 360 期 |
| 还款方式 | 等额本息（每期还款额相同） |

### 1.2 公式

等额本息月供（F-020）：

> PMT = PV × r / [1 − (1 + r)^(−n)]

### 1.3 计算

先算折现因子：

> (1 + r)^360 = (1.00416667)^360 ≈ 4.4677
>
> (1 + r)^(−360) ≈ 0.22383
>
> 1 − 0.22383 = 0.77617

再算月供：

> PMT = 1,000,000 × 0.00416667 / 0.77617
>
> PMT ≈ 4166.67 / 0.77617 ≈ **5,368 元**

### 1.4 总还款与总利息

| 项目 | 金额 |
|------|------|
| 月供 | 约 5,368 元 |
| 总还款（360 期） | 约 1,932,480 元 |
| 总利息 | 约 932,480 元 |
| 利息/本金 | 约 93.2% |

### 1.5 利率敏感性

同样 100 万元、30 年：

| 年利率 | 月供（约） | 总利息（约） |
|--------|-----------|-------------|
| 3% | 4,216 元 | 517,760 元 |
| 4% | 4,774 元 | 718,640 元 |
| 5% | 5,368 元 | 932,480 元 |
| 6% | 5,996 元 | 1,158,560 元 |

利率从 5% 降到 3%，月供减少约 1,152 元，总利息减少约 41.5 万元。长期贷款对利率高度敏感，这就是再融资/提前还款决策的核心。

## 案例二：项目 NPV 与 IRR

### 2.1 参数

| 年份 | 现金流（万元） |
|------|---------------|
| 0 | −100（初始投资） |
| 1 | +40 |
| 2 | +50 |
| 3 | +60 |

折现率（机会成本）为 10%。

### 2.2 NPV 计算

公式（F-019）：

> NPV = Σ[CF_t / (1 + r)^t] − C0

| 年份 | 现金流 | 折现因子（10%） | 现值 |
|------|--------|----------------|------|
| 1 | 40 | 1 / 1.10 = 0.9091 | 36.36 |
| 2 | 50 | 1 / 1.21 = 0.8264 | 41.32 |
| 3 | 60 | 1 / 1.331 = 0.7513 | 45.08 |
| 合计 | | | 122.76 |

> NPV = 122.76 − 100 = **+22.76 万元**

NPV 为正，项目在 10% 机会成本下创造价值。

### 2.3 IRR 计算

IRR 是使 NPV = 0 的折现率。试算：

| 折现率 | NPV（万元） |
|--------|------------|
| 20% | +2.78 |
| 21% | +1.08 |
| 22% | −0.58 |

用线性插值：

> IRR ≈ 21% + 1.08 / (1.08 + 0.58) × 1% ≈ **21.65%**

精确值约为 21.6%。IRR 高于 10%，项目可行。

### 2.4 NPV 与 IRR 的冲突

如果另一个项目初始投资 10 万元、一年后回收 12 万元，IRR = 20%，NPV（10%）= 0.91 万元。它的 IRR 低于上例，但 NPV 也低于上例。若两个项目互斥，应选 NPV 更大的上例（22.76 万元），而不是 IRR 更高的项目。

> 规则：**互斥项目看 NPV；IRR 只适合做直观沟通。** 规模、时序、现金流符号变化都会让 IRR 误导。

## 案例三：三年期债券定价与久期

### 3.1 参数

| 参数 | 数值 |
|------|------|
| 面值 F | 100 元 |
| 票息 C | 5 元/年 |
| 期限 n | 3 年 |
| 付息方式 | 每年付息一次，到期还本 |

### 3.2 不同 YTM 下的价格

公式（F-021）：

> P = C/(1+y) + C/(1+y)^2 + (C+F)/(1+y)^3

| YTM | 第 1 年 | 第 2 年 | 第 3 年 | 价格 |
|-----|---------|---------|---------|------|
| 4% | 4.8077 | 4.6228 | 93.3446 | **102.78** |
| 5% | 4.7619 | 4.5351 | 90.7029 | **100.00** |
| 6% | 4.7170 | 4.4500 | 88.1601 | **97.33** |

### 3.3 久期计算（YTM = 4%）

| 年份 | 现金流现值 | 权重 | 时间 × 权重 |
|------|-----------|------|------------|
| 1 | 4.8077 | 4.68% | 0.0468 |
| 2 | 4.6228 | 4.50% | 0.0900 |
| 3 | 93.3446 | 90.82% | 2.7246 |
| 合计 | 102.7751 | 100% | 2.8614 |

> 麦考利久期 D ≈ **2.86 年**
>
> 修正久期 D* = 2.86 / 1.04 ≈ **2.75**

### 3.4 利率冲击近似

若 YTM 从 4% 上升到 5%（Δy = +1%）：

> 价格变化率 ≈ −D* × Δy = −2.75 × 1% = **−2.75%**
>
> 近似价格 ≈ 102.78 × (1 − 0.0275) ≈ **99.95 元**

实际价格在 5% YTM 下为 100.00 元，近似误差约 0.05 元，效果很好。

若 YTM 从 4% 上升到 6%（Δy = +2%）：

> 近似变化率 ≈ −2.75 × 2% = −5.50%
>
> 近似价格 ≈ 102.78 × 0.945 ≈ **97.13 元**
>
> 实际价格 = **97.33 元**

利率变动越大，久期的线性近似误差越大；凸性（convexity）会修正这个误差。对普通读者，记住「久期越长，利率风险越大」即可。

## 四、三个案例的共同逻辑

1. **一切资产定价都是「未来现金流 + 折现率」。** 房贷、项目、债券只是现金流形态不同。
2. **折现率包含时间、通胀与风险。** 不同风险现金流不能用同一个折现率。
3. **利率变动通过久期放大到价格。** 长期、低票息资产对利率最敏感。
4. **NPV 是决策基准，IRR 是辅助指标。** 不要被百分比迷惑，要看价值增量。

## 五、边界与提醒

- 房贷案例未考虑手续费、保险、税费、提前还款罚金与利率重定价。
- 项目案例未考虑税收、折旧、营运资金与残值；实际投资决策应使用税后现金流。
- 债券案例假设无违约、无税收、无流动性折价；信用债与流动性差的债券需要更高折现率。
- 所有数字为教学假设，不构成投资建议。
