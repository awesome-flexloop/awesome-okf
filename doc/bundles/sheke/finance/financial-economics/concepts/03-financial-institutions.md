# 金融机构与银行体系：期限转换与脆弱性

## 是什么

银行不是简单的「资金中转站」。它做的是三件互相缠绕的事：把短期存款变成长期贷款（期限转换）、把不愿承担风险的存款人的钱变成愿意承担风险的企业投资（风险转换）、在借款人信息不透明时替存款人做评估与监督（信息生产）。

这三件事让银行创造了信用，也让银行天然脆弱：存款人随时可以提款，贷款却要到期才收回。只要所有人同时来提款，一家资产质量良好的银行也可能倒下。理解这种脆弱性，就理解了存款保险、央行最后贷款人、资本监管与宏观审慎为什么存在。

## 一、一张资产负债表看懂银行

银行资产负债表遵循恒等式（F-028）：

> 资产 = 负债 + 所有者权益

| 资产端 | 负债与权益端 |
|--------|-------------|
| 现金与准备金 | 存款（活期、定期） |
| 贷款（企业、居民、同业） | 同业负债、发行债券 |
| 债券与其他证券 | 向央行借款 |
| 固定资产与其他资产 | 所有者权益（股本、留存收益） |

银行用负债（主要是存款）支持资产（主要是贷款）。所有者权益是吸收损失的第一道缓冲：如果贷款损失 5 亿元，而银行权益只有 3 亿元，银行就资不抵债。

**杠杆率 = 资产 / 资本**（F-070）。假设一家银行资产 1,000 亿元、资本 50 亿元，杠杆 20 倍。资产价值下跌 5%，损失 50 亿元，资本被全部吃掉；若下跌 6%，银行破产，而资产只跌了 6%。杠杆把温和的资产波动放大成生存问题。

## 二、期限转换、流动性转换与信用中介

银行的三个核心功能（F-027）：

1. **期限转换**：存款多为短期，贷款多为中长期。银行用短端负债支持长端资产，赚取期限溢价，同时承担再融资风险。
2. **流动性转换**：存款人要求随时可取的流动性，借款人需要稳定的资金。银行把流动性「转换」给双方，但自己承担挤兑风险。
3. **信用中介与信息生产**：银行评估借款人、监控贷款用途、在违约时处置抵押品。相比分散的储户，银行有规模经济与专业能力。

这三项功能解释了为什么银行不能像普通企业那样「资产跌了就卖」：贷款市场流动性差，折价出售会放大损失；存款人又会先跑。银行的资产负债表天生是「不透明 + 期限错配 + 高杠杆」的组合。

## 三、挤兑：个体理性，集体非理性

Diamond 与 Dybvig（1983）的模型说明（F-029、F-073）：即使银行资产最终能覆盖所有存款，只要存款人担心别人先提款，自己就会先去提款；当所有人都这样想，挤兑就成为自我实现的均衡。

挤兑的触发点可能是一条谣言、一份财报、一次评级下调，甚至只是社交媒体上的恐慌。银行的应对手段包括：

- 持有流动性资产（现金、准备金、高等级债券）。
- 央行流动性支持（贴现窗口、常备借贷便利）。
- 存款保险，降低存款人挤兑动机。
- 暂停提款（极端手段，通常伴随监管介入）。

**存款保险**是中国金融安全网的一部分：《存款保险条例》自 2015-05-01 施行，最高偿付限额 50 万元（F-030）。同一存款人在同一投保机构的存款本金合并计算。它的作用是保护小额存款人、稳定预期，但不是「银行不会倒闭」的承诺；超过限额的部分按清算受偿。

## 四、最后贷款人与道德风险

最后贷款人原则（Bagehot）认为（F-031）：央行应向**有偿付能力但暂时缺乏流动性**的机构提供贷款，要求合格抵押品与惩罚性利率。这样既能止住挤兑，又不至于补贴失败机构。

难点在于区分「流动性问题」与「清偿力问题」：

- 如果只是暂时缺现金，救助是对的。
- 如果资产已经资不抵债，救助只是把损失转给纳税人，并激励机构继续冒险。

这就是**道德风险**：当机构预期「出事会有人救」，就会倾向于承担更多风险。监管的应对包括：限制业务、要求更高资本、设定处置计划、让股东与债权人先承担损失（自救）。

## 五、资本充足率与巴塞尔协议

资本充足率是银行资本与风险加权资产的比率。巴塞尔协议 III 设定了国际最低标准（F-032）：

| 指标 | 最低要求 |
|------|---------|
| 核心一级资本充足率（CET1） | 4.5% |
| 一级资本充足率（Tier 1） | 6% |
| 总资本充足率 | 8% |
| 资本留存缓冲 | 2.5%（在最低要求之上） |

巴塞尔 III 于 2010 年达成，2017 年完成修订。除资本外，还引入流动性覆盖率（LCR）、净稳定资金比例（NSFR）等流动性标准。

> 常见误读：资本充足率不是「银行有多少现金」，而是「股东权益等高质量资本相对于风险加权资产的比例」。资本是吸收损失的缓冲，不是放在金库里的钱。

资本监管也有顺周期性：经济下行时，坏账上升、风险权重上升，银行被迫收紧信贷，反而加剧衰退。宏观审慎政策因此引入逆周期资本缓冲、压力测试等工具（F-076）。

## 六、影子银行：功能补位与监管套利

影子银行指传统银行体系之外、具有信用中介功能的机构与活动（F-033）：理财、信托贷款、同业代付、货币市场基金、资产证券化等。它并不都是「非法」或「坏」的：有些是满足实体融资需求的创新，有些则是规避资本、准备金与信贷额度的监管套利。

影子银行的风险在于：

- **期限错配更严重**：短募长投、滚动发行。
- **杠杆不透明**：多层嵌套，最终风险承担者难以识别。
- **隐性刚兑**：投资者以为「银行卖的就会兜底」，一旦打破刚兑引发恐慌。
- **监管真空**：跨机构、跨市场，单一监管者看不到全貌。

中国 2018 年资管新规（银发〔2018〕106 号）对同类业务实施统一监管：打破刚性兑付、禁止资金池、实行净值化管理、限制多层嵌套（F-081）。这不是消灭影子银行，而是把「类信贷」活动纳入可监测、可约束的框架。

## 七、其他金融机构：各做各的转换

- **保险公司**：通过大数法则分散风险，把不确定的大额损失变成确定的小额保费；同时是长期资金的重要来源。
- **公募基金**：集合投资、专业管理、分散风险；投资者按净值承担盈亏，基金公司收取管理费。
- **证券公司**：经纪、投行、资管、自营；连接发行人与投资者。
- **信托公司**：受人之托、代人理财，可做贷款、股权投资、资产证券化等，业务范围广，监管要求也复杂。
- **养老金与主权基金**：长期资金，偏好长久期资产，是债券市场的重要需求方。

这些机构与银行共享一个特征：**用别人的钱做投资或放贷，因此需要资本、流动性、信息披露与受托责任约束。** 区别在于风险承担方式：银行承担信用风险并受存款保险保护；基金与理财原则上由投资者自担风险；保险受偿付能力监管。

## 八、系统重要性机构与「大而不能倒」

当一家机构的失败会通过资产负债表、共同风险暴露、支付清算或市场信心传染到整个体系时，它就被视为系统重要性机构（F-034、F-075）。全球系统重要性银行（G-SIBs）需要：

- 更高的附加资本。
- 更严格的监管审查。
- 恢复与处置计划（living will）。
- 总损失吸收能力（TLAC）要求。

目的是让机构「可失败」：即使倒闭，也能在不引发系统性危机的前提下处置，由股东与债权人承担损失，而不是纳税人。

## 九、中国机构图谱（详见 09 篇）

中国金融体系以银行为主导，机构包括：

- **政策性银行**：国家开发银行、进出口银行、农业发展银行。
- **大型商业银行**：工、农、中、建、交、邮储。
- **股份制银行、城商行、农商行、村镇银行**。
- **非银机构**：券商、基金、保险、信托、理财公司、金融租赁、消费金融。
- **监管**：人民银行、国家金融监督管理总局、证监会、外汇局（F-077）。

不同机构的监管指标、业务范围与风险特征不同；09 篇会展开「一行一局一会」的架构与改革节点。

## 十、常见误读

**误读一：银行把存款贷出去，所以存款人不能同时取钱。** 现代银行是「贷款创造存款」，不是先有存款再贷出；但期限错配与部分准备金仍然存在，挤兑风险不变（F-015、F-029）。

**误读二：存款保险等于银行不会倒闭。** 存款保险保护限额内的存款人，不保护银行股东与超过限额的债权人，也不阻止银行失败（F-030）。

**误读三：资本充足率越高越好。** 资本太高可能意味着银行过度保守、信贷供给不足；监管要求的是「足够吸收损失」，不是无限高。平衡点在风险与效率之间。

**误读四：影子银行都是非法集资。** 影子银行是功能描述，不是法律定性；合法与非法要看具体业务是否持牌、是否遵守资管新规与投资者适当性要求（F-033）。

## 小结

- 银行的核心是期限转换、流动性转换、信用中介与信息生产（F-027）。
- 资产负债表恒等式与杠杆，决定了银行对资产损失极度敏感（F-028、F-070）。
- 部分准备金与期限错配使挤兑成为自我实现的均衡（F-029、F-073）。
- 存款保险、最后贷款人、资本监管与宏观审慎，共同构成金融安全网（F-030–F-032、F-076）。
- 影子银行补位与套利并存，资管新规将其纳入统一监管（F-033、F-081）。
- 系统重要性机构需要附加资本与处置计划，以降低「大而不能倒」（F-034）。
