- **零基础按序阅读**：00 建立总图 → 01 理解货币 → 02 学会折现 → 03 看懂银行 → 04 认识市场 → 05 搭宏观框架 → 06 理解政策 → 07 打开国际视野 → 08 认识风险 → 09 落到中国 → 10 看数字金融 → 11 回到个人。
- **有金融基础可跳读**：先读 00、02、05、06、08、09，再按兴趣补 01、03、04、07、10、11。
- **只关心个人决策**：00 → 02 → 05（通胀与利率部分）→ 11 → [个人投资实操通识](../../personal-investing/index.md)。
- **只关心中国制度**：09 为主，配合 01（货币层次）、06（货币政策）、08（风险监管）。
- **对照事实核查**：每篇末尾有「事实卡」，F 编号可在 [facts.md](../facts.md) 查到出处；P0 核验结论见 [02-verification.md](../references/02-verification.md)。
