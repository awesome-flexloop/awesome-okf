# 国际金融与开放经济：汇率、收支与货币体系

## 是什么

开放经济里，一国经济与外部世界通过三条纽带相连：**贸易**（商品与服务）、**资本**（投资与借贷）、**货币**（汇率与储备）。国际金融研究这三条纽带如何相互作用，以及政策在开放条件下受到什么约束。

对普通人，国际金融解释了很多日常现象：为什么出国旅游换汇价格每天都在变？为什么美联储加息会影响人民币汇率与A股？为什么有些国家外汇储备很多却突然爆发货币危机？答案都藏在汇率、国际收支与资本流动的机制里。

## 一、汇率：两种标价，一个相对价格

汇率是两种货币的相对价格。标价方式有两种（F-061）：

- **直接标价**：1 单位外币 = 若干本币。例如 1 美元 = 7.1 元人民币。数值上升，表示本币贬值。
- **间接标价**：1 单位本币 = 若干外币。数值上升，表示本币升值。

中国常用直接标价。看到「人民币汇率中间价 7.1」，意思是 1 美元折合 7.1 元人民币；数值从 7.1 降到 7.0，是人民币升值，不是贬值。方向搞反，是初学者最常见的错误。

汇率还有名义与实际之分（F-062）：

> 实际汇率 = 名义汇率 × 外国价格水平 / 本国价格水平

实际汇率衡量本国商品相对于外国商品的竞争力。名义汇率不变，但本国通胀高于外国时，实际汇率升值，出口竞争力下降。这就是为什么高通胀国家难以维持固定汇率。

## 二、购买力平价：长期锚，不是短期预测器

购买力平价（PPP）有三层（F-063）：

1. **一价定律**：同一商品在两国价格换算后应相等（忽略运输成本与贸易壁垒）。
2. **绝对 PPP**：两国价格水平之比等于汇率。
3. **相对 PPP**：汇率变化率约等于两国通胀率之差。

PPP 在长期有解释力：高通胀国家的货币倾向于贬值。但短期偏离很大，原因包括：

- 不可贸易品（服务、住房）价格差异。
- 贸易壁垒、运输成本、税收。
- 资本流动与风险偏好。
- 央行干预与汇率制度。

所以 PPP 适合判断「长期高估/低估」，不适合预测下个月的汇率。用 PPP 做短线交易，是最常见的误用之一。

## 三、利率平价：利差与汇率预期的连线

利率平价描述两国利差与汇率升贴水的关系（F-064）：

- **抛补利率平价（CIP）**：两国利差约等于远期升贴水。投资者可以用远期锁定汇率，消除风险。
- **非抛补利率平价（UIP）**：预期汇率变化约等于利差。它假设投资者风险中性，现实中常因风险溢价、资本管制与套利限制而偏离。

直觉是：如果本国利率高于外国，投资者愿意持有本币资产，但担心本币贬值；远期市场会通过升贴水把利差「抵消」掉。若 CIP 明显不成立，通常意味着资本管制、流动性摩擦或危机风险。

## 四、国际收支：一张必须平衡的账

国际收支平衡表按 BPM6 编制（F-065）：

> 经常账户 + 资本与金融账户 + 净误差与遗漏 = 0

- **经常账户**：货物、服务、初次收入（投资收益、工资）、二次收入（转移支付）。
- **资本与金融账户**：直接投资、证券投资、其他投资、储备资产。
- **净误差与遗漏**：统计差异的平衡项。

储备变动计入金融账户。经常账户顺差意味着本国储蓄大于投资，对外净贷出；逆差意味着本国投资大于储蓄，需要外部融资。顺差不是「赚了」，逆差也不是「亏了」；关键是资金流向与可持续性。

中国长期经常账户顺差、外汇储备规模全球第一（F-066）。这既是安全垫，也带来管理挑战：储备过多意味着资源未充分用于国内消费与投资，且面临汇率与估值风险。

## 五、三元悖论：开放经济的硬约束

三元悖论（Mundell-Fleming）指出（F-067）：以下三个目标最多同时实现两个：

1. 固定汇率。
2. 资本自由流动。
3. 独立货币政策。

组合示例：

- **固定汇率 + 资本自由流动** → 放弃独立货币政策（如香港联系汇率制度）。
- **固定汇率 + 独立货币政策** → 必须实施资本管制。
- **资本自由流动 + 独立货币政策** → 汇率必须浮动。

这不是「政策选择偏好」，而是套利机制决定的硬约束。理解三元悖论，就能理解为什么大国通常选择浮动汇率+独立货币政策，而小型开放经济体常选择钉住汇率+资本自由流动。

## 六、汇率制度谱系

IMF 按汇率灵活性与政策框架，把汇率制度分为多类（按 S26/S27 的一般分类）：

- **硬钉住**：美元化、货币联盟、货币局制度。
- **软钉住**：传统钉住、爬行钉住、钉住一篮子货币、水平区间。
- **浮动**：管理浮动、自由浮动。

没有一种制度适合所有国家。固定汇率提供 nominal anchor、降低交易成本，但牺牲货币政策独立性，且在高通胀或外部冲击下容易积累失衡；浮动汇率提供缓冲，但可能波动过大、传递通胀。选择取决于经济规模、开放度、资本账户状态、金融体系深度与制度信誉。

## 七、布雷顿森林体系与美元体系

1944 年，布雷顿森林体系建立（F-068）：

- 美元与黄金挂钩（35 美元/盎司）。
- 其他货币与美元挂钩，形成固定汇率体系。
- 成立 IMF 与 World Bank，负责国际收支支持与重建。

这个体系内生于「特里芬难题」：美国需要向全球提供美元流动性（长期逆差），但长期逆差又削弱美元兑换黄金的信誉。1971-08-15，美国关闭黄金兑换窗口，布雷顿森林体系瓦解，世界进入以美元为主导的浮动汇率时代。

美元体系的特征是：

- 美元是全球最主要的储备货币、结算货币与融资货币。
- 美国国债被视为无风险资产，是全球金融体系的抵押品。
- 美联储的货币政策通过美元流动性、汇率与全球风险偏好外溢到其他国家。

这不是单纯的「霸权」叙事，而是网络效应、金融市场深度、法治与惯性共同形成的结构。理解美元体系，才能理解为什么美国利率上升会收紧全球金融条件。

## 八、人民币国际化与 SDR

人民币于 2016-10-01 加入 IMF 特别提款权（SDR）篮子，初始权重 10.92%；2022 年审查后权重上调至 12.28%，2022-08-01 生效（F-068）。

人民币国际化的路径包括：

- 跨境贸易人民币结算。
- 离岸人民币市场（香港、新加坡、伦敦等）。
- 双边本币互换协议。
- 人民币计价的债券、股票与大宗商品。
- 资本账户渐进开放。

国际化的收益包括降低汇率风险、提升融资便利、增强金融话语权；挑战包括资本流动管理、金融市场深度、法治与政策可预期性。国际化不是「取代美元」的短期目标，而是一个长期的、由市场选择与制度信任驱动的过程。

## 九、货币危机的一般机制

固定汇率 + 资本自由流动 + 外债期限错配，是货币危机的经典组合：

1. 本国利率高于外国，资本流入，外债增加。
2. 外部冲击或信心动摇，资本外流。
3. 央行动用储备干预，储备下降。
4. 市场预期贬值，挤兑本币。
5. 央行放弃钉住，汇率暴跌，外债负担骤增，银行与企业违约。

危机的核心不是「汇率本身」，而是**资产负债表货币错配**：资产本币、负债外币，贬值直接击穿净值。这也是为什么新兴市场国家强调外储、宏观审慎与资本流动管理。

## 十、常见误读

**误读一：贬值一定是坏事。** 贬值提升出口竞争力、降低外债实际负担（以本币计），但也推高进口价格、加剧资本外流。好坏取决于经济结构、外债水平与通胀。

**误读二：外汇储备可以随便花。** 外储是央行负债对应的资产，需要维持流动性、安全性与偿付需求；大规模动用会影响汇率与信心。外储不是财政存款。

**误读三：人民币国际化就是取代美元。** 国际化是提高人民币在贸易、投资、储备中的使用比例，受市场选择与制度信任约束；短期目标是降低交易成本与汇率风险，不是挑战美元地位。

**误读四：PPP 可以预测短期汇率。** PPP 是长期锚，短期汇率由资本流动、利差、风险偏好与政策决定；用 PPP 做短线交易，胜率很低。

## 小结

- 汇率是相对价格；直接标价下数值上升是本币贬值（F-061）。
- 实际汇率衡量竞争力；PPP 是长期锚，不是短期预测器（F-062、F-063）。
- 利率平价连接利差与汇率预期，CIP/UIP 各有假设（F-064）。
- 国际收支必须平衡；经常账户与金融账户是一枚硬币的两面（F-065）。
- 外储是安全垫，不是财政资金（F-066）。
- 三元悖论是开放经济的硬约束（F-067）。
- 布雷顿森林体系 1944 年建立、1971 年瓦解；人民币 2016 年入 SDR，2022 年权重升至 12.28%（F-068）。
