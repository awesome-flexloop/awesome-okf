# 利率、现值与资产定价基础

## 是什么

利率是资金的价格，也是把未来现金流折算成今天的尺子。它同时包含三样东西：

- **时间补偿**：今天借出 1 元，明天才拿回，要求补偿。
- **通胀补偿**：如果物价上涨，名义利息要覆盖购买力损失（F-017）。
- **风险补偿**：借款人可能违约、资产可能波动、资金可能被锁死，都要加价。

因此，市场上不存在一个抽象的「利率」，而是一组利率：政策利率、银行间拆借利率、国债收益率、贷款利率、信用债收益率、房贷利率……它们期限不同、风险不同、流动性不同。理解金融资产定价，先要理解这组利率如何形成、如何传导。

## 一、名义利率与实际利率

费雪方程把名义利率 i、实际利率 r 与通胀率 π 连起来（F-017）：

> (1 + i) = (1 + r) × (1 + π)
>
> 低通胀时近似：i ≈ r + π

举例：名义利率 5%，通胀 3%，实际利率约为 1.94%（精确值 1.05/1.03 − 1），近似为 2%。如果名义利率 2%、通胀 3%，实际利率约为 −0.97%，存款购买力在下降（F-026）。

这解释了为什么「高利率」不一定是「高回报」：如果通胀更高，实际利率可能为负。判断资金松紧，要看实际利率，不只看名义数字。

## 二、复利、现值与 72 法则

复利终值公式（F-018）：

> FV = PV × (1 + r)^n

其中 PV 是现值，r 是每期收益率，n 是期数。连续复利为 FV = PV × e^(r×n)。

反过来，把未来的一笔钱折回今天，就是现值（F-019）：

> PV = FV / (1 + r)^n

**72 法则**是复利的心算近似（F-102）：本金翻倍所需年数 ≈ 72 ÷ 年化收益率的百分比数字。年化 6% 约 12 年翻倍，年化 8% 约 9 年，年化 12% 约 6 年。它只适用于中等收益率，精确值是 ln2 / ln(1+r)。

复利的关键不是公式，而是「时间 + 再投资」。同样的年化收益，早开始十年，终值差距往往大于收益率差一两个百分点。这一点在 [个人投资实操通识](../../personal-investing/concepts/00-why-invest.md) 中有更详细的个人视角算例。

## 三、年金与房贷：把一串现金流折现

普通年金是每期期末等额的现金流。其现值公式为（F-020）：

> PV = PMT × [1 − (1 + r)^(−n)] / r

永续年金（n 趋于无穷）简化为 PV = PMT / r。

**算例：100 万元房贷，30 年，年利率 5%，按月还款。**

- 月利率 r = 5% / 12 = 0.4167%
- 期数 n = 30 × 12 = 360
- 月供 PMT = 1,000,000 × r / [1 − (1 + r)^(−360)] ≈ **5,368 元**
- 总还款 ≈ 5,368 × 360 ≈ **193.2 万元**
- 总利息 ≈ **93.2 万元**

这个算例说明两件事：第一，长期贷款的大部分还款是利息，不是本金；第二，利率小幅变化对月供与总利息影响很大。若利率从 5% 降到 3%，同样 100 万元、30 年，月供约 4,216 元，总利息约 51.8 万元——利息几乎减半。

## 四、NPV 与 IRR：项目值不值得做

净现值把项目所有未来现金流按机会成本折现，再减去初始投资（F-019）：

> NPV = Σ[CF_t / (1 + r)^t] − C0

NPV 大于 0，说明项目在给定折现率下创造价值；NPV 小于 0，说明不如把资金投向同等风险的替代机会。

**算例：项目初始投入 100 万元，未来三年现金流分别为 40、50、60 万元，折现率 10%。**

- 第 1 年：40 / 1.10 = 36.36
- 第 2 年：50 / 1.21 = 41.32
- 第 3 年：60 / 1.331 = 45.08
- 现值合计 = 122.76
- NPV = 122.76 − 100 = **+22.76 万元**

内部收益率（IRR）是使 NPV 等于 0 的折现率。上例 IRR 约为 **21.6%**，高于 10% 的机会成本，因此项目可行。

> 注意：IRR 与 NPV 在项目规模、现金流时序差异很大时可能给出相反排序。此时应以 NPV 为准，因为 NPV 直接衡量「增加了多少价值」。IRR 适合做直观沟通，不适合替代 NPV 做最终决策。

## 五、债券定价与到期收益率

债券的价格等于未来票息与面值的现值之和（F-021）：

> P = Σ[C / (1 + y)^t] + F / (1 + y)^n

其中 C 是每期票息，F 是面值，y 是到期收益率（YTM），n 是期数。YTM 是使债券全部现金流现值等于市场价格的折现率（F-022）。

**算例：面值 100 元、票息 5 元、3 年期、每年付息一次。**

| 市场 YTM | 价格计算 | 价格 |
|---------|---------|------|
| 4% | 5/1.04 + 5/1.04² + 105/1.04³ | **102.78 元** |
| 5% | 5/1.05 + 5/1.05² + 105/1.05³ | **100.00 元** |
| 6% | 5/1.06 + 5/1.06² + 105/1.06³ | **97.33 元** |

三条结论：

1. **价格与 YTM 反向**：YTM 上升，债券价格下跌（F-021）。
2. **票息低于市场利率时，债券折价**；票息高于市场利率时，溢价。
3. **YTM 不等于票息率**。票息率是合同约定的利息比例；YTM 是市场对整笔现金流的综合折现率，随价格变化。

## 六、久期：利率风险的度量

久期衡量债券现金流的加权平均回收时间，也衡量价格对利率的敏感度（F-023）：

> 修正久期 D* = D / (1 + y)
>
> 价格变化率 ≈ −D* × Δy

上例 3 年期、票息 5%、YTM 4% 的债券，麦考利久期约为 **2.86 年**，修正久期约为 **2.75**。若 YTM 上升 1 个百分点（100 个基点），价格约下跌 **2.75%**，从 102.78 元降至约 99.95 元；实际精确价格约为 99.94 元，近似效果很好。

久期的三个直觉：

- 期限越长，久期越大，利率风险越高。
- 票息越低，久期越大（更多价值集中在最后的面值）。
- 零息债券的麦考利久期等于到期期限。

> 常见误读：把「久期」当成「到期时间」。对于付息债券，久期通常小于到期时间；只有零息债券两者相等。

## 七、利率期限结构：为什么长短期利率不一样

同一时点，不同期限的国债收益率形成一条曲线，叫收益率曲线。解释它的三种理论（F-024）：

- **预期理论**：长期利率是未来短期利率预期的平均。若市场预期未来加息，曲线向上倾斜。
- **流动性偏好理论**：长期债券流动性较差、价格波动更大，投资者要求期限溢价，因此曲线通常向上倾斜。
- **市场分割理论**：不同期限的资金供需由不同机构决定（银行偏好短端、保险与养老金偏好长端），曲线形状由各段供需决定。

收益率曲线倒挂（短期利率高于长期利率）常被视为衰退信号，但不是机械规律：它反映的是市场对未来的预期与期限溢价，可能被央行操作、监管需求与全球资金流动扭曲。

## 八、政策利率如何传导到你的贷款

央行不直接设定房贷利率，而是通过政策利率影响银行间短端利率，再传导到贷款利率、债券收益率与资产价格（F-025）。传导链条大致是：

> 政策利率 → 银行间拆借/回购利率 → LPR/最优惠贷款利率 → 企业贷款、房贷、信用债收益率 → 投资与消费

传导可能阻塞：银行风险偏好下降、企业不借钱、存款利率刚性、监管额度限制，都会让「降息」无法顺利变成「宽信用」。这就是为什么央行常同时使用价格工具（利率）与数量工具（准备金率、再贷款、信贷政策）。

## 九、常见误读

**误读一：低利率一定是好事。** 低利率降低借款成本，但也可能意味着经济低迷、风险溢价上升、储蓄者实际收益为负。对退休者、靠利息生活的人尤其不利。

**误读二：债券是「保本」的。** 持有到期的国债在名义上通常保本，但中途卖出会面临价格波动；信用债还有违约风险；外币债还有汇率风险。债券的「安全」是相对的。

**误读三：YTM 就是票息。** YTM 随价格变化，票息是合同固定值。溢价买入时，YTM 低于票息；折价买入时，YTM 高于票息。

**误读四：久期只对债券交易员有用。** 对普通人也有用：它解释了为什么长期债券基金在加息时跌得比短债基金多，为什么「锁久期」是一种风险选择。

## 小结

- 利率 = 时间补偿 + 通胀补偿 + 风险补偿；实际利率才反映购买力变化（F-017、F-026）。
- 复利与现值是全部资产定价的底层算术（F-018、F-019）。
- 年金公式可以算清房贷、养老金与租赁现金流（F-020）。
- NPV 是项目决策的基准，IRR 是辅助指标（F-019）。
- 债券价格与 YTM 反向；久期衡量利率敏感度（F-021–F-023）。
- 期限结构由预期、期限溢价与市场分割共同决定（F-024）。
- 政策利率通过银行间市场与信贷渠道传导，可能阻塞（F-025）。
