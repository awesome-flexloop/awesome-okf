# 参考文献与信源索引

本目录登记本知识包使用的信源与核验记录，回答两个问题：**每条事实从哪里来**，以及**哪些结论只是估计或存在争议**。

## 文档列表

| 文档 | 内容 | 使用方式 |
|------|------|---------|
| [01 经典教科书、经典论文与权威信源索引](01-classics-and-authorities.md) | 按「教科书骨架—经典论文源头—国际组织标准—中国官方文件」四层登记 S1–S45，给出与 11 篇概念文档的对应关系 | 想核对某个定义、理论归属或官方口径时查此表 |
| [02 P0 核验报告与口径说明](02-verification.md) | 日期、比率、制度安排、统计口径与历史节点的核验结果；口径差异、单源项与未核验清单 | 想知道「这条事实有多可靠」时先看此报告 |

## 使用顺序

1. 先在概念文档末尾的事实引用中看到 F 编号。
2. 到 [facts.md](../facts.md) 查该编号的事实内容与 S 编号。
3. 到 [01 信源索引](01-classics-and-authorities.md) 查 S 编号对应的文献/机构。
4. 若该条标记【P0】，再到 [02 核验报告](02-verification.md) 查核验方式与结论。

> 本包不提供实时数据接口。汇率、利率、GDP 增速、市值等高频数据请以人民银行、国家统计局、IMF、BIS 等机构的最新发布为准。
