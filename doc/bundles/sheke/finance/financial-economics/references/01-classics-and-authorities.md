# 金融经济经典教科书、经典论文与权威信源索引

## 一、为什么分四层信源

金融经济是一个「教科书共识、学术争议、制度细节、实时数据」混在一起的领域。同一句「利率下降会刺激投资」，在教科书里是机制，在实证论文里是要检验的假设，在央行文件里是政策目标，在新闻里可能只是当日行情。若不区分信源层级，读者很容易把机制当预测、把估计当定律、把时点数据当长期规律。

本索引因此按四层组织：

1. **教科书骨架**：提供定义、恒等式、模型结构与标准术语，适合建立认知框架。
2. **经典论文源头**：提供某个理论的原始表述、假设与经验证据，适合核对「谁提出、何时提出、原文主张什么」。
3. **国际组织标准**：提供跨国的统计口径、监管标准与政策框架，适合做国际比较。
4. **中国官方文件**：提供中国监管架构、法规生效日、统计口径与政策工具，适合回答「中国具体怎么规定」。

> 使用原则：**教科书回答「一般怎么运作」，官方文件回答「中国现在怎么规定」，论文回答「这个结论有多强」，新闻只回答「今天发生了什么」。** 本包不把新闻当事实底座。
