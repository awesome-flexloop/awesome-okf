# 提桶者 vs 管道建造者：两种收入模式

## 是什么

Burke Hedges 在《管道的故事》中提出了一个根本性的二分法：世界上有两种赚钱的方式——**提桶**和**建造管道**。这个区分不是关于"赚多少钱"，而是关于"收入的结构"——你的收入是与你投入的时间线性挂钩，还是由一个系统持续产生。

这个观念之所以重要，是因为绝大多数人终其一生都在"提桶"，却从未意识到还有另一种选择。他们追求的是"更大的桶"（更高的薪水、更好的职位），而不是"建造管道"（创建能持续产生收入的系统）。

## 一、提桶者：用时间换金钱

提桶者的收入模式可以用一个简单公式描述（F-001）：

> **收入 = 工作时间 × 单位时间报酬**

这个模式的特征是：

1. **线性关系**：收入与投入时间成正比。工作1小时赚1份钱，工作8小时赚8份钱。
2. **即时回报**：工作当天就能拿到报酬，所见即所得。
3. **停止即中断**：一旦停止工作——无论是生病、休假、裁员还是退休——收入立即停止或大幅减少。
4. **天花板效应**：人的时间是有限的，每天最多24小时，所以提桶收入存在天然上限。

书中指出，绝大多数人都是提桶者（F-002）：

- 工薪族：按月领薪，停止工作即停止收入
- 自由职业者：按项目收费，没有项目就没有收入
- 专业人士（医生、律师）：按服务收费，不接诊/不接案就没有收入
- 甚至企业高管：虽然薪水很高，本质仍是提桶——离职即失去收入

提桶者最大的风险不是"赚得少"，而是**收入结构脆弱**——一旦无法工作，收入立即归零（F-003）。

## 二、管道建造者：用系统创造持续收入

管道建造者的收入模式截然不同（F-004）：

> **收入 = 系统产出 × 时间（系统持续运行）**

这个模式的特征是：

1. **非线性关系**：收入与建造者的当前工作时间脱钩。管道建成后，建造者不工作也有收入。
2. **延迟回报**：管道建造期间（前期）收入可能减少甚至为零，需要忍耐和坚持。
3. **持续不断**：管道一旦建成并运转，收入24小时不间断，与建造者是否在工作无关。
4. **复利增长**：管道可以扩展、复制、叠加，收入随时间呈指数增长而非线性增长。

管道的例子包括（F-005）：

- **投资管道**：股票、债券、房地产——资本持续产生分红、利息、租金
- **知识产权管道**：书籍、音乐、专利、软件——创作完成后持续产生版税和许可费
- **企业系统管道**：可脱离创始人运营的企业——系统自动产生利润
- **网络/数字管道**：网站、APP、在线课程、会员社区——数字资产持续产生收入

## 三、核心对比

| 维度 | 提桶者 | 管道建造者 |
|------|--------|-----------|
| 收入公式 | 时间 × 报酬 | 系统 × 时间 |
| 收入特征 | 线性、即时 | 非线性、延迟 |
| 停止工作后 | 收入中断 | 收入持续 |
| 收入上限 | 受时间限制（24h/天） | 无上限（系统可扩展） |
| 前期投入 | 低（直接开始） | 高（需建造期） |
| 风险类型 | 收入中断风险（生病/裁员） | 建造失败风险（管道可能不成） |
| 适合人群 | 所有人（短期生存必需） | 有远见且愿忍耐的人（长期自由） |

## 四、为什么大多数人选择提桶

书中分析了为什么大多数人终其一生都是提桶者（F-006）：

1. **即时满足偏好**：提桶的收入是即时的、确定的；管道的收入是延迟的、不确定的。人类天生偏好即时回报。
2. **社会教育导向**：学校教育培养的是"找一份好工作"的提桶思维，而非"创建一个系统"的管道思维。
3. **管道建造的恐惧**：建造管道需要前期投入且不保证成功，大多数人害怕这段"收入真空期"。
4. **缺乏榜样**：大多数人身边没有管道建造者的成功案例，看不到管道的真实可能。

## 五、关键澄清：不是非此即彼

书中强调，提桶和建造管道**不是非此即彼的选择**（F-007）：

- Pablo 在建造管道的同时仍然提桶维持生计——**用提桶的收入支撑管道的建造**
- 大多数成功的管道建造者都经历了"白天提桶、晚上建管道"的阶段
- 提桶是短期的生存策略，建造管道是长期的自由策略
- 理想路径是：**用提桶维持生存，用业余时间建造管道，直到管道收入足以替代提桶收入**

## 怎么做

1. **识别你当前的桶**：列出你所有的收入来源，判断哪些是提桶收入（与你的时间挂钩），哪些是管道收入（与你脱钩）。
2. **计算你的"提桶依赖度"**：如果你的全部收入都来自提桶，你的"提桶依赖度"是100%——这意味着你一旦无法工作，收入立即归零。
3. **确定你的管道方向**：基于你的技能、资源和兴趣，选择一个可能的管道方向（投资、创作、企业、数字产品）。
4. **开始投入管道时间**：每天挤出1-2小时，从最小的管道开始建造。详见 [04 建造管道的五个步骤](04-five-steps-to-pipeline.md)。

## 常见坑与边界

- **把提桶当管道**：有些人以为"自由职业"就是管道，但如果你的收入仍然与你的工作时间直接挂钩，你只是换了个桶，没有建造管道。
- **追求"更大的桶"而非管道**：加薪、升职、跳槽到更高薪的公司——这些都是"换更大的桶"，收入结构没有改变。
- **忽视管道建造的风险**：不是所有管道都能建成。管道建造存在失败风险，需要谨慎评估和持续调整。
- **急于求成**：管道建造需要时间，急于求成容易导致半途而废或选择不靠谱的"快速管道"（通常是骗局）。
- **完全放弃提桶**：在没有管道收入保障的情况下辞职去"建造管道"，风险极高。书中主张的是"边提桶边建管道"。
