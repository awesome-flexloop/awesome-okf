# 个人防骗自查清单

> **使用方法**：任何人给你推荐"理财/投资/项目"，在你转任何一笔钱之前，逐条回答下面 15 个问题。任何一条回答"是"，就先暂停，不要投。3 条以上回答"是"，立刻拒绝，并把这个清单转给他看。

## 第一组：收益与风险（必查）

- [ ] **1. 它承诺的年化收益是否显著高于银行定期存款与国债？**（超过 5 个百分点以上 = 红旗）
- [ ] **2. 它是否使用了"保本""稳赚""无风险""刚性兑付"这些词？**
- [ ] **3. 它的历史回报曲线是否几乎没有回撤、月月正收益？**（真实投资一定有波动）
- [ ] **4. 它是否催促你"今天最后一天""名额有限""再不上车就晚了"？**

## 第二组：资质与托管（必查）

- [ ] **5. 这个产品/公司是否在证监会、国家金融监管总局、人民银行公开查得到牌照？**
- [ ] **6. 你的钱是转入独立第三方托管账户（银行/券商/基金），还是直接转账给某公司/个人账户？**
- [ ] **7. 它是否愿意由你指定的独立会计师/律师审计账目？**
- [ ] **8. 你能否随时看到底层资产明细（借款合同、发票、真实交易对手）？**

## 第三组：销售方式（警惕）

- [ ] **9. 你是怎么知道这个项目的？**（如果只来自微信群、熟人饭局、线下讲座——警惕）
- [ ] **10. 群里是否有人持续晒收益截图、晒"老师"指导、晒出金到账？**
- [ ] **11. 它是否邀请你参加线下大会、年会、旅游、感恩晚宴？**
- [ ] **12. 它是否让你"先小额试一下，赚到了再加大投入"？**（这是经典鱼饵策略）

## 第四组：出金信号（最危险）

- [ ] **13. 你或身边人是否已经遇到出金变慢、提现被限额、要求续投才能取旧钱？**
  - **命中此条 = 骗局已进入死亡螺旋。不要再追加任何一分钱，立即报案。**
- [ ] **14. 客服是否开始联系不上、办公地点人去楼空、APP 突然打不开？**
  - **命中此条 = 立即整理全部证据到就近经侦大队报案。**
- [ ] **15. 你是否已经在心里替它找理由——"再等等就会好的""我相信老板""警察不懂我们这个模式"？**
  - **命中此条 = 你已经被沉没成本绑架。请找一个不从中赚钱的家人，把你的全部持仓告诉他，让他帮你做决定。**

## 给父母的特别提醒（老年人专项）

根据 SEC 专门面向老年人的庞氏骗局警示，以下话术是专门针对老年人设计的：

- "您这个年纪应该做稳健理财，我们这个产品国债级安全，收益还高"；
- "您孩子不懂，我帮您把钱打理好"；
- "名额是专门给叔叔阿姨留的，年轻人都抢不到"；
- "今天现场刷卡送鸡蛋/米/油/体检"。

**底线规则**：父母任何单笔超过 1 万元的"理财"决定，必须先和子女通一次电话核实。

## 证据留存清单（一旦发现疑似）

在你还没报警之前，先把这些材料整理到一个文件夹：

1. [ ] 投资合同、协议、收据 PDF
2. [ ] 全部银行/支付宝/微信转账记录
3. [ ] 项目方宣传材料（海报、PPT、公众号、短视频）
4. [ ] 与业务员/客服的全部聊天记录
5. [ ] 收到的所有对账单、收益明细
6. [ ] 公司营业执照、业务员名片（如有）

---

**这张清单基于美国 SEC Investor.gov 官方红旗清单、FINRA 投资者警示与中国《防范和处置非法集资条例》整理，仅作风险识别教育用途，不构成法律意见。**
