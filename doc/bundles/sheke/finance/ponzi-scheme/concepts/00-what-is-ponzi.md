# 什么是庞氏骗局

## 是什么

**庞氏骗局（Ponzi Scheme）** 是一种投资诈骗：组织者把新投资者缴入的资金，当作"投资回报"支付给早期投资者，而不是把资金投入任何真实的经营活动、生产活动或可产生利润的资产（F-001、F-002）。

美国证券交易委员会（SEC）旗下投资者教育平台 Investor.gov 的定义是（F-001）：

> A Ponzi scheme is an investment fraud that pays existing investors with funds collected from new investors.
> （庞氏骗局是一种投资欺诈：用从新投资者那里收取的资金，支付给已有投资者。）

SEC 投资者警示进一步指出：在许多庞氏骗局中，诈骗者根本没有把钱投出去，而是直接用来支付早期投资者，剩余部分中饱私囊（F-003）。

这个名字来自意大利移民 **Charles Ponzi（查尔斯·庞兹）**，他在 1920 年的波士顿靠"国际回邮券套利"故事吸引了数万名投资者，承诺 45 天 50%、90 天 100% 的回报，不到一年崩盘（F-011、F-012）。但"用新钱还旧钱"这种做法远早于庞兹本人——见 [01 历史源流](01-history-origin.md)。

## 一、定义三要素

判断一个项目是不是庞氏骗局，不必看它披什么外衣（外汇、黄金、加密货币、理财、消费返利、养老投资、影视众筹），只看三个要素是否同时成立（F-004）：

| 要素 | 含义 | 验证方式 |
|------|------|----------|
| ① 无真实利润来源 | 承诺的回报不来自任何可审计的经营、生产、交易或租金收入 | 要求看审计报告、托管账户、真实交易对手 |
| ② 借新还旧 | 支付给早期投资者的钱，来自后期新投资者的本金 | 看资金流水是否与经营收入对应 |
| ③ 承诺高收益低风险 | 普遍以"保本""稳赚""年化 X%—Y%"为卖点，且收益显著高于无风险利率 | 与同期国债、银行存款利率对比 |

**三要素同时成立，即为庞氏结构**。只占一两条——例如一个合法投资也可能短期回报不错——不构成庞氏。

## 二、资金流向：一张图看懂

```
        新投资者 B 的本金
              │
              ▼
        ┌─────────────┐
        │  骗局组织者  │◄──── 抽成（中饱私囊、奢华生活、
        │  （hub）     │       雇佣金销团队、媒体投放）
        └──────┬──────┘
               │
               ├──► 老投资者 A 的"利息/分红"
               │     （A 看到账单真的涨了，继续投、拉朋友投）
               │
               └──► 老投资者 C 的"到期本金"
                     （C 顺利取出，成为"活广告"）
```

关键点：**A 收到的"收益"不是投资赚来的，就是 B 刚交进来的本金**。B 以为自己在投资，实际上他的钱直接被转付给了 A（F-005）。

## 三、为什么叫"骗局"而不是"高风险投资"

合法投资也可能亏损，但它与庞氏骗局有本质区别（F-006）：

| 维度 | 合法投资 | 庞氏骗局 |
|------|----------|----------|
| 收益来源 | 企业利润、利息、租金、资产增值 | 新投资者的本金 |
| 资产去向 | 由独立托管方持有、可审计 | 进入组织者控制的单一账户 |
| 信息披露 | 定期公布经审计财报 | 只有组织者自己发的"对账单" |
| 新资金用途 | 用于业务扩张 | 用于支付旧投资者本息 |
| 退出机制 | 按市场价格卖出资产 | 依赖下一个接盘者 |
| 失败时 | 价格下跌、部分本金损失 | 组织者卷款或资金链断裂，几乎全损 |

## 四、与"庞兹金融"（Ponzi Finance）的区别

经济学家海曼·明斯基（Hyman Minsky）在金融不稳定假说中提出过 **"Ponzi finance"（庞兹融资）** 这个术语（F-007）：指借款者的现金流连利息都覆盖不了，必须靠借新债或出售资产才能维持偿债。这是一个**分析性概念**，描述任何高杠杆、靠再融资续命的债务结构（包括企业、政府甚至整个经济体）。

- 日常用语的"庞氏骗局"= 故意诈骗、从一开始就没有真实业务；
- 明斯基的"庞兹融资"= 可能是真实企业在某阶段陷入的现金流困境，不一定有诈骗故意。

两者资金链断裂时表现相似，但**法律性质完全不同**：前者是犯罪，后者可能只是经营失败。阅读学术文献时不要混淆。

## 怎么做

1. **遇到任何"投资机会"，先问一个问题**：它付给我的利息，从哪个真实的经营活动里赚出来的？答不上来，就是庞氏候选。
2. **要求独立托管与审计**：正规理财的钱由银行/券商/基金托管，不经手机构自有账户；庞氏骗局的钱都进组织者个人账户或关联公司账户。
3. **和无风险利率对比**：中国 1 年期国债收益率约 1.5%—2% 量级（以发行时为准）。任何"年化 8% 以上、保本、随时取"的产品，先假设它是骗局再找反证。
4. **不要把"已经按时返利"等同于"安全"**：前几个人拿到钱，恰恰是庞氏骗局用来钓更多人的鱼饵——见 [02 机制解剖](02-mechanism-anatomy.md)。

## 常见坑与边界

- **"这次不一样"**：每次新骗局都有新外衣——1920 年是回邮券，2000 年代是对冲基金"稳赚策略"，2010 年代是 P2P/消费全返，2020 年代是加密货币质押/AI 量化。外衣换了，三要素没变。
- **"有政府背景/名人站台/知名写字楼"**：e租宝曾租用央视广告、善林金融曾在全国开数百家门店（F-041、F-043）。渠道光鲜不等于项目合法。
- **"我朋友已经赚了一年了"**：早期投资者确实能拿到钱——但那是因为后面还有更多人进来。你的朋友是"活广告"，不是"风控证明"。
- **把庞氏与传销混为一谈**：庞氏骗局主要靠"投资收益"吸金，不强制发展下线；传销主要靠"拉人头"计酬。两者在中国刑法上是不同罪名，但常常交织——见 [04 与传销、非法集资的边界](04-vs-pyramid-mlm.md)。
