## 六、博文陈述：一周验证法（F-018 ~ F-025、F-027）

| 事实编号 | 事实内容 | 信源 |
|---------|---------|------|
| F-018 | 方案承诺：一周可执行；不需要特殊技能、不需要投钱、不需要粉丝 | 微信博文（作者方案） |
| F-019 | 第 1 天：在小红书、闲鱼、抖音搜"模板、教程、指南、避坑、清单"；重点看三五千粉丝但橱窗已售几千单的小账号；把能做的方向至少记三个 | 微信博文（作者方案） |
| F-020 | 第 2 天：选一个方向发"测试内容"（"大部分人不知道的XX技巧"/"关于XX我踩过的三个坑"），发小红书/朋友圈/知乎；不看点赞，只看有没有人问"怎么做/还有吗"，没有就换方向 | 微信博文（作者方案） |
| F-021 | 第 3 天：做"最小产品"——三五页 PDF，写清问题、解法、踩坑；WPS/飞书文档排版导出；两小时以内 | 微信博文（作者方案） |
| F-022 | 第 4 天：挂出去标价 9.9/19.9 元，不要免费；挂闲鱼、小红书、朋友圈，写清是什么、解决什么问题、适合谁 | 微信博文（作者方案） |
| F-023 | 第 5 天：写三篇"搜索型内容"——用户本来就会搜的问题（例："应届生简历最容易犯的三个错""夜景怎么拍才不糊"）；内容不爆但每天有人搜，搜到的人顺手买产品 | 微信博文（作者方案） |
| F-024 | 第 6 天：看数据做判断——有没有人买、有没有人问、有没有人问"能不能再详细一点"；没人买就调方向或调标题描述 | 微信博文（作者方案） |
| F-025 | 第 7 天：迭代或换方向——有人买就优化（更新案例、改标题、加问答）；没人买就从第 1 天重来；"试错的成本比你想象的低得多" | 微信博文（作者方案） |
| F-027 | 博文引歌德："每个人心中都有一种真理，只等待一种合适的方式表达出来。"（**核验：⚠️ 出处不可考、疑似中文网络伪托，见 F-034**） | 微信博文 |
