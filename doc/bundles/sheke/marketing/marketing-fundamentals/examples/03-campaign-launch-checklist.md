# 营销活动上线全流程清单（含合规自查）

> 说明：本清单为原创通用工具，可直接复制用于每次活动的过审与复盘。合规部分依据《广告法》（M-042）、《个人信息保护法》（M-043）与行业专项审查要求（M-044）整理，仅为通识自查；具体行业与情境以监管部门最新规定与专业法律意见为准（M-048）。原理见 [07 营销策划、预算、定价心理与合规红线](../concepts/07-planning-budget-compliance.md)。

## 一、策划阶段

- [ ] **目标 SMART 化**：目标写成「在某时间前，让某人群完成某动作，达到某数字」，可度量、有期限（M-031）
- [ ] **受众明确**：写出目标人群与核心场景，不说「所有人」（M-007、M-008；可用 [示例 01 工作坊](01-stp-positioning-workshop.md) 产出）
- [ ] **定位词一致**：本次活动卖点与品牌定位词一致，不临时换词（M-009、M-021）
- [ ] **预算方法选定**（M-037，四选一）：
  - [ ] 销售额百分比法（按销售额提固定比例，简单但逻辑倒置）
  - [ ] 量入为出法（小公司保命用，波动大）
  - [ ] 竞争对等法（对标竞品，注意目标未必相同）
  - [ ] **目标任务法**（推荐：目标→任务→费用倒推，M-037）
- [ ] **渠道与计价匹配**：曝光目标用 CPM、引流用 CPC、转化用 CPA/CPS，目标与不错配（M-032）
- [ ] **漏斗指标预设**：认知、点击、注册、激活、付费各层目标转化率写明（M-025；算例见 [示例 02](02-funnel-metrics-playbook.md)）

## 二、创意阶段

- [ ] **卖点一句话**：对谁、解决什么痛点、凭什么信，三要素齐全（M-022）
- [ ] **信任状真实可查**：数据、销量、引语均有出处，无「编一个」的内容（M-044）
- [ ] **素材与定位咬合**：画面、话术、价格带传递同一个词（M-021）
- [ ] **落地页对齐**：广告承诺与落地页内容一致，转化路径不超过必要步数
- [ ] **定价技巧适度**：锚定价格真实存在、诱饵选项厚道、「限时」是真限时；无虚构原价（M-041、M-046）
- [ ] **私域承接**：每个流量入口都有沉淀动作（加群、关注、留资的理由）（M-033）

## 三、合规自查表（上线前强制关卡）

### 3.1 广告法：极限词逐词对照（M-042）

文案全文搜索以下词汇，命中即删除或改为可证实的具体表述（M-042）：

- [ ] 「最」字头：最好、最优、最低价、最先进、最受欢迎
- [ ] 「第一」：全国第一、行业第一、销量第一（除非有可查的权威依据且标明出处与时间）
- [ ] 「国家级」：国家级产品、国家级团队、国家指定
- [ ] 「顶级/极致」：顶级、顶尖、极品、极致、绝佳
- [ ] 其他绝对化表述：100% 有效、永久、绝无仅有、史无前例
- [ ] 虚假广告排查：效果承诺、使用前后对比、用户评价均真实有据（M-042、M-044）
- [ ] AIGC 生成内容已人工事实核验，无 AI 编造的「数据」「评价」（M-035）

### 3.2 行业专项资质（M-044）

- [ ] 金融类：无保本、保收益、稳赚等承诺性表述（M-044）
- [ ] 医疗/保健食品：无疗效宣称、无患者名义证明，资质齐全（M-044）
- [ ] 教育类：无对升学率、通过率、效果的保证性承诺
- [ ] 数据与对比宣传：所有统计数据、对比结论有真实可查依据（M-044）

### 3.3 个人信息保护（M-043）

- [ ] 注册/留资表单为**主动勾选**授权，无默认勾选、无强制捆绑同意（M-043）
- [ ] 采集字段遵循**最小必要**：不收集与活动无关的通讯录、位置、身份证信息（M-043）
- [ ] 明示信息使用目的与方式，隐私政策可访问（M-043）
- [ ] 精准推送/用户画像场景提供**拒绝个性化推送**的入口（M-043）
- [ ] 短信、私信、群发给用户提供**退订/拒收**入口
- [ ] 第三方工具（表单、统计、客服 SDK）的数据流转已确认

### 3.4 反不正当竞争与伦理底线（M-046）

- [ ] 不刷单、不刷量、不虚构好评（M-046）
- [ ] 不贬低竞品、不捏造竞品负面信息
- [ ] 抽奖、赠品规则明确，无欺骗性促销
- [ ] 不利用未成年人与弱势群体设计诱导机制（M-046）

## 四、执行阶段

- [ ] **灰度先行**：小流量或小范围先上线，确认无流程断点再放量（M-036）
- [ ] **A/B 测试设计**：一次只动一个变量；预设判断指标与最小样本量（M-036）
- [ ] **埋点监测就位**：曝光、点击、注册、付费各层数据能逐层看到（M-025、M-026）
- [ ] **对照组保留**：评估活动真实增量，不全量覆盖（M-036）
- [ ] **客服话术同步**：活动规则、售后口径、投诉应对提前培训，话术与广告承诺一致
- [ ] **异常熔断**：设定预算消耗速度、投诉量、负评率的暂停阈值

## 五、复盘阶段

- [ ] **数据对照目标**：各层实际转化率 vs 策划阶段预设值，逐层找差距（M-025）
- [ ] **最大漏损层定位**：转化率最低的一层单独分析原因（M-025）
- [ ] **效果核算**：ROAS = 广告带来收入 ÷ 广告费；再用毛利口径算 ROI，不以流水当利润（M-031；算法见 [示例 02](02-funnel-metrics-playbook.md)）
- [ ] **单位经济检查**：本轮 CAC、LTV/CAC 是否在健康区间（M-030）
- [ ] **合规留痕**：素材终稿、授权记录、资质文件归档备查
- [ ] **经验记录**：按「假设—结果—放大/放弃」归档，胜出版本写明推广条件，失败版本写明原因（M-036）
- [ ] **下一轮输入**：本次发现的最大漏损层，列为下一轮实验的第一假设（M-036）

## 六、归档与责任分工

- [ ] 每项检查指定**责任人**：策划归营销负责人、极限词归文案与法务双签、数据授权归技术与运营（M-042、M-043）
- [ ] 素材终稿（含被否版本）、合规自查表签字记录归档留存，备查与复盘两用
- [ ] 投放后台、埋点数据、客服记录在复盘后导出备份，避免平台数据过期丢失
- [ ] 复盘结论写入团队共享文档：有效动作进「放大」清单，无效动作进「放弃」清单，均注明假设与数据（M-036）
- [ ] 下一轮活动的第一假设，来自本次复盘定位出的最大漏损层（M-025）

## 使用提醒

- 第三部分（合规自查）为**一票否决关卡**：任一检查项未过，活动不得上线（M-042、M-043、M-044）。
- 本清单覆盖全国性通识规则；金融、医疗、教育、保健食品等行业的专项审查清单以主管部门最新规定为准（M-044、M-048）。
- 清单是检查工具不是答案：每次活动的人群、目标与预算方法请先过 [01 STP 与定位工作坊](01-stp-positioning-workshop.md)，数据口径参照 [02 漏斗与单位经济算例手册](02-funnel-metrics-playbook.md)。
