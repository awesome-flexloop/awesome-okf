## 一、营销的本质与观念演进

| 编号    | 事实内容                                                                                                                                                                                                                        | 信源    |
| ----- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----- |
| M-001 | 彼得·德鲁克（Peter Drucker）《管理的实践》（The Practice of Management，1954）提出：企业的唯一有效目的是创造顾客；企业只有两项——也仅有两项——基本职能：营销与创新，其余都是成本。他另有一句广为引用的论断：「营销的目的是让推销成为多余」。【P0】                                                                           | S1    |
| M-002 | 营销观念演进五阶段（营销史学共识）：生产观念（19 世纪末—20 世纪初，供不应求，重心在提高效率、扩大产量）→ 产品观念（认为顾客偏好高质量、多功能产品，易患「营销短视」）→ 推销观念（20 世纪 30–40 年代大萧条后，重心在强力推销与广告）→ 市场营销观念（20 世纪 50 年代起，以目标顾客需求为起点、以整合营销为手段、以利润为结果）→ 社会营销观念（20 世纪 70 年代起，兼顾顾客需求、企业利润与社会长期福利）。【P0】 | S2    |
| M-003 | 西奥多·莱维特（Theodore Levitt）1960 年在《哈佛商业评论》发表《营销短视症》（Marketing Myopia）：衰退行业的企业把自己定义为「生产某种产品」而非「满足某种顾客需求」——铁路公司以为自己做的是铁路生意而非运输生意，好莱坞一度以为自己做电影而非娱乐；文章主张企业应是「顾客满足过程」而非「产品生产过程」。【P0】                                                | S3    |
| M-004 | 营销与推销的根本区别：推销以卖方需要为出发点（把现有产品卖出去），营销以买方需要为出发点（先发现需求再组织产品与服务）；推销关注把产品变成钱，营销关注通过产品与创造、交付、沟通价值的全过程来满足需求。                                                                                                                        | S1、S2 |
| M-005 | 需要、欲望、需求三分（科特勒体系）：需要（needs）是人类基本匮乏状态（衣食住行、归属、尊重）；欲望（wants）是文化与个性塑造下对具体满足物的向往；需求（demands）是有购买力支撑的欲望。营销不创造需要，而是影响欲望、把欲望转化为对特定产品的需求。                                                                                           | S2    |

## 二、STP：营销战略骨架

| 编号    | 事实内容                                                                                                                                                                                                                                                                        | 信源    |
| ----- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----- |
| M-006 | 市场细分（Segmentation）概念由温德尔·史密斯（Wendell Smith）1956 年论文《产品差异化与市场细分作为可选营销战略》提出：与其用一种产品打整个市场，不如把市场切成需求相似的子市场。【P0】                                                                                                                                                                 | S4    |
| M-007 | 四类常用细分变量：地理（地区、城市级别、气候）、人口（年龄、性别、收入、职业、家庭生命周期、教育）、心理（生活方式、价值观、性格）、行为（使用场景、使用率、忠诚度、追求利益、决策阶段）。B2B 场景另有行业、企业规模、采购类型等变量。                                                                                                                                                       | S2    |
| M-008 | 目标市场选择（Targeting）：科特勒教材给出五种细分市场覆盖模式——密集单一市场（只做一个细分市场，资源集中）、有选择的专门化（选若干个互不相关但各自有吸引力的细分市场）、产品专门化（一种产品卖给若干类顾客）、市场专门化（为一类顾客提供多种产品）、完全市场覆盖（用各种产品满足各类顾客需求，大企业战略）；对应的营销组合策略有三种——无差异营销（一个组合打全市场）、差异化营销（多个组合对应多个细分市场）、集中化营销（集中资源做一个或少数几个细分市场，中小企业常用）。选择依据是细分市场的规模成长性、结构吸引力与企业自身能力匹配。 | S2    |
| M-009 | 定位（Positioning）理论由艾·里斯（Al Ries）与杰克·特劳特（Jack Trout）提出：思想先见于 1972 年《广告时代》（Advertising Age）系列文章《定位时代》，1981 年出版《定位：争夺用户心智的战争》（Positioning: The Battle for Your Mind）。核心主张：营销的终极战场不在产品、不在渠道，而在潜在顾客的心智；定位要在心智中占据一个代表品类或特性的词。【P0】                                                  | S5    |
| M-010 | STP（细分—目标—定位）作为营销战略三步骨架由科特勒体系系统化：S 与 T 决定「在哪个战场打」，P 决定「在顾客心里占什么位置」；定位之后才是 4P 战术组合。【P0】                                                                                                                                                                                      | S2    |
| M-011 | 定位陈述（positioning statement）常用模板：「对于……（目标顾客及其需求），我们的品牌是……（品类），它能够……（关键利益/理由），不同于……（主要竞品），我们的不同在于……（差异化理由）」；该模板是内部战略对齐工具，不是对外广告语。                                                                                                                                             | S2、S5 |

## 三、4P/4C：战术组合

| 编号    | 事实内容                                                                                                                                                                         | 信源 |
| ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -- |
| M-012 | 4P 由杰罗姆·麦卡锡（E. Jerome McCarthy）1960 年《基础营销》（Basic Marketing）提出：产品（Product）、价格（Price）、渠道（Place）、促销（Promotion）；科特勒《营销管理》（Marketing Management，1967 年初版）将其发扬光大，成为营销组合的经典框架。【P0】 | S6 |
| M-013 | 产品整体概念分层（科特勒）：核心产品（顾客真正购买的利益）、形式产品（质量、特色、品牌、包装）、期望产品、延伸产品（售后、保证、信贷、服务）、潜在产品；竞争越来越发生在延伸与潜在层次。                                                                                 | S2 |
| M-014 | 定价三种导向：成本导向（成本加成）、竞争导向（随行就市/投标）、价值导向（按顾客感知价值定价）；两种典型新产品策略：撇脂定价（高价进入、逐步降价，适合有壁垒的创新品）与渗透定价（低价快速抢占份额）。经济学上价格歧视分三级（按顾客、按数量/版本、按市场）。                                              | S2 |
| M-015 | 渠道（Place）：产品从生产者到顾客的路径，涉及经销商、代理商、零售商等中间商；经销商买断货物再转卖（承担风险、赚差价），代理商不取得所有权、赚取佣金；渠道决策包括长度（层级数）、宽度（每层级中间商数量：独家/选择/密集分销）与渠道冲突管理。                                                   | S2 |
| M-016 | 促销组合（Promotion Mix）工具：广告、人员推销、销售促进（打折、赠品、券）、公共关系（PR）、直复营销与数字营销；推式策略（把产品推向渠道）与拉式策略（直接激发顾客需求拉动渠道）。                                                                             | S2 |
| M-017 | 4C 由罗伯特·劳特朋（Robert Lauterborn）1990 年提出，是 4P 的顾客视角转换：顾客需要与欲望（Consumer wants）对应产品、顾客成本（Cost）对应价格、便利（Convenience）对应渠道、沟通（Communication）对应促销；4C 不是取代 4P，而是提醒企业从顾客侧设计战术。          | S7 |
| M-018 | 服务营销扩展为 7P：Booms 与 Bitner 1981 年在 4P 基础上增加人员（People）、过程（Process）、有形展示（Physical Evidence）——服务的无形性、不可分离性、可变性、易逝性使这三个要素直接决定顾客体验。                                                | S2 |

## 四、品牌与心智

| 编号    | 事实内容                                                                                                                                                               | 信源    |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----- |
| M-019 | 凯文·凯勒（Kevin Lane Keller）提出基于顾客的品牌资产模型（CBBE），《战略品牌管理》（Strategic Brand Management，1998 年初版）给出品牌共鸣金字塔：自下而上为品牌显著性（识别）、绩效与形象（含义）、评判与感觉（响应）、共鸣（关系），强调强势品牌是逐层建立的顾客关系。【P0】 | S8    |
| M-020 | 大卫·艾克（David Aaker）《管理品牌资产》（Managing Brand Equity，1991）提出品牌资产五要素：品牌忠诚度、品牌认知度、感知质量、品牌联想、其他专有资产（专利、商标、渠道关系）；品牌资产使顾客愿意为同等产品支付溢价。                                       | S8    |
| M-021 | 心智规律（里斯与特劳特系列著作，如《22 条商规》《与众不同》）：心智容量有限（记不住第 N 名）、心智厌恶混乱（信息越简单越好）、心智缺乏安全感（从众与证据）、心智难以改变（改变认知难，利用认知易）、心智会失去焦点（品牌延伸稀释定位）；领先法则——成为第一胜过做得更好。                           | S5    |
| M-022 | 定位的四种差异化来源（科特勒/特劳特归纳）：产品/服务本身（最优质、最专业）、人员（员工专业度）、渠道（独家/便捷）、形象（品牌识别与象征）；差异化必须是顾客在乎的、竞争者没有的、企业能长期兑现的。                                                                | S2、S5 |

## 五、顾客旅程：从 AIDA 到 5A 与增长漏斗

| 编号    | 事实内容                                                                                                                                                                                                                   | 信源     |
| ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| M-023 | AIDA 模型由广告人 E. St. Elmo Lewis 于 1898 年提出：注意（Attention）→兴趣（Interest）→欲望（Desire）→行动（Action），是最早的购买漏斗模型，描述顾客从接触广告到下单的心理阶段。【P0】                                                                                            | S9     |
| M-024 | 科特勒在《营销 4.0》（Marketing 4.0，2017）中提出 5A 顾客路径：了解（Aware）→诉求（Appeal）→询问（Ask）→行动（Act）→倡导（Advocate）；与传统漏斗的关键区别是终点从「购买」延伸到「拥护」（推荐、复购、UGC），且顾客会在各阶段间反复而非线性前进。【P0】                                                              | S10    |
| M-025 | 营销漏斗（funnel）的通用结构：认知→考虑→转化→留存→推荐；每一层到下一层都有转化率，整体转化率是各层转化率的连乘积；漏斗思维要求分层度量、定位漏损最大的环节优先优化。【P0】                                                                                                                            | S2、S11 |
| M-026 | AARRR「海盗指标」由戴夫·麦克卢尔（Dave McClure）2007 年在《Startup Metrics for Pirates》提出：获取（Acquisition）→激活（Activation）→留存（Retention）→收入（Revenue）→推荐（Referral），成为互联网产品增长度量的通用骨架。【P0】                                                    | S11    |
| M-027 | 增长黑客对漏斗顺序的修正（RARRA）：肖恩·埃利斯等增长实践者主张把留存（Retention）置于首位——没有留存，获取越多漏得越快；留存率（尤其同期群留存曲线是否走平）是产品有没有 PMF 的先行指标。                                                                                                                | S12    |
| M-028 | PMF（Product-Market Fit，产品—市场契合）概念由马克·安德森（Marc Andreessen）2007 年博文《The Only Thing That Matters》推广：产品满足了一个好市场中的好需求，表现为需求自然拉动、用户自发传播、增长不靠硬推；PMF 之前规模化投放是浪费。肖恩·埃利斯给出的经验检验：若「不能再使用该产品会非常失望」的用户占比达到 40% 左右，视为达到 PMF 的信号。【P0】 | S12    |
| M-029 | 病毒传播的 K 因子：K = 每个用户发出的邀请数 × 邀请转化率；K > 1 时传播可自增长，K < 1 时需持续外部投放维持增长；推荐环节还受 NPS（净推荐值，Reichheld 提出）度量。                                                                                                                    | S12    |

## 六、数字营销与增长的度量

| 编号    | 事实内容                                                                                                                                                                                          | 信源      |
| ----- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- |
| M-030 | 单位经济（unit economics）两个核心指标：CAC（Customer Acquisition Cost，获客成本=获客总投入/新增客户数）与 LTV（Lifetime Value，客户终身价值=客户全生命周期贡献的毛利）；经验健康线为 LTV/CAC ≥ 3，CAC 回收期（多久赚回获客成本）通常要求短于 12 个月（SaaS 行业经验值，不同行业差异大）。【P0】 | S12、S13 |
| M-031 | 效果度量常用指标：转化率（Conversion Rate）、ROAS（广告支出回报=广告带来的收入/广告费）、ROI（投资回报率）、客单价、复购率、 churn rate（流失率）；「北极星指标」（North Star Metric）指最能代表产品向顾客持续交付价值的单一领先指标（如 Airbnb 的预订间夜数）。                                | S12     |
| M-032 | 数字广告主要形态：搜索营销（SEM，竞价排名；SEO 为搜索引擎优化，赚取自然流量）、信息流广告（嵌入内容流、按算法定向）、效果广告（按转化/点击计价）与品牌广告（按曝光计价、目标是心智）；广告计价方式包括 CPM（千次曝光）、CPC（每次点击）、CPA/CPS（每次行动/成交）。                                                 | S13     |
| M-033 | 内容营销：以对目标顾客有用的内容（文章、视频、直播、白皮书）吸引和留住受众，而非直接打断式推销；内容营销学院（Content Marketing Institute）的定义强调「持续创造与分发有价值、相关、一致的内容」。中国市场对应的突出形态是私域运营——通过微信公众号、企业微信、社群、小程序等可免费、反复、直接触达的渠道沉淀顾客资产，与依赖平台采买的公域流量相对。【P0】  | S13、S16 |
| M-034 | 中国电商与内容生态特有形态：KOL（关键意见领袖）/KOC（关键意见消费者）带货、「种草」（内容激发欲望）、直播电商；抖音电商于 2021 年提出「兴趣电商」概念（以内容激发潜在兴趣、货找人），与传统「搜索—比价」的货架电商形成补充。                                                                         | S16     |
| M-035 | AIGC 进入营销生产链：2023 年起大语言模型与图像/视频生成模型规模化用于文案、素材、短视频、客服与个性化推荐内容生产，显著降低内容供给成本、提升千人千面的内容密度；同时带来内容同质化、虚假宣传与版权合规的新风险。                                                                                | S16、S17 |
| M-036 | 增长实验方法：A/B 测试（同时分流两个版本比较指标）、对照组（holdout）评估增量、灰度发布；增长团队以「假设—实验—度量—放大/放弃」的高频节奏运转，每个实验预设判断指标与最小样本量。                                                                                              | S12     |
| M-037 | 营销预算四种编制方法：销售额百分比法（按预期/历史销售额提固定比例）、量入为出法（小公司常见）、竞争对等法（对标竞品）、目标任务法（先定目标与任务再倒推预算，科特勒推荐的逻辑顺序）。                                                                                                   | S2      |
| M-038 | 安索夫矩阵（Igor Ansoff，1957）：以「现有/新产品」×「现有/新市场」给出四象限增长路径——市场渗透、市场开发、产品开发、多元化，多元化风险最高。【P0】                                                                                                          | S14     |
| M-039 | SWOT 分析：优势（Strengths）、劣势（Weaknesses）、机会（Opportunities）、威胁（Threats），框架成型于 20 世纪 60 年代斯坦福研究院的企业战略研究，经肯尼斯·安德鲁斯《公司战略概念》（1971）推广；SWOT 本身只是清单，价值在于交叉策略（SO 增长、WO 改进、ST 防御、WT 规避）。                    | S14     |

## 七、B2B、定价心理与合规

| 编号    | 事实内容                                                                                                                                                 | 信源      |

| M-040 | B2B 与 B2C 营销差异：B2B 决策链长（使用者、影响者、决策者、采购者分离）、决策理性（看重 ROI 与风险）、客户数量少但单客价值高、内容需要专业深度（白皮书、案例、试用）；B2C 决策快、情感与品牌权重高、触点以大众媒介与电商为主。                           | S2      |

## 放弃核验清单（本包不做断言的内容）

1. 任何具体平台的当下流量成本、算法规则与投放后台操作（以季度为单位过时）；
2. 具体品牌的定位得失与市场数据（除非引述公开财报与权威第三方报告）；
3. CAC、LTV、LTV/CAC 健康线在具体行业的数值（只给跨行业经验值，行业基准差异大）；
4. CNNIC 报告的最新一期精确数字（给规模量级，精确数以官网最新报告为准）；
5. 具体广告案例的真伪与效果（案例仅作教学转述，数据以企业公开披露为准）；
6. 各行业专项广告审查的逐条清单（金融、医疗、教育等以主管部门最新规定为准）；
7. 对任何企业「应该怎么做营销」的确定性处方（框架是检查清单而非答案）；
8. AIGC 工具的具体产品形态与版权判例（领域仍在快速演化）。
