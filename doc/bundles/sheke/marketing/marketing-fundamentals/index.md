# 现代营销实操通识知识包

![以顾客为中心的营销罗盘，指针指向需求方向，四周环绕产品、价格、渠道与促销符号。](/_static/bundles/sheke/marketing/marketing-fundamentals/images/hero-marketing-compass.jpg)

本知识包是营销入门的「思维骨架」：不追平台热点、不堆黑话术语，把德鲁克、科特勒、里斯与特劳特、凯勒、麦克卢尔、肖恩·埃利斯等一脉的经典框架讲清楚，并把《广告法》《个人信息保护法》等中国合规红线落到可执行的清单。全部事实按「谁提出、何年提出、原文主张什么」溯源——**理论事实**挂经典著作与论文（S1–S14），**合规事实**挂全国人大与中国政府网官方法规（S15–S18），共 48 条事实。

> 阅读提示：营销学分骨架层与技巧层——STP、定位、4P、漏斗等框架跨周期有效，具体平台的算法、流量成本与投放玩法以季度为单位过时。本包只沉淀骨架层；平台技巧请以各平台官方最新规则为准。**本包为通识教育材料，不构成具体经营建议；合规判断以监管部门最新规定与专业法律意见为准。**
