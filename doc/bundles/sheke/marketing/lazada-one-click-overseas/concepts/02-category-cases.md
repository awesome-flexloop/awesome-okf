# 品类案例：泰国时尚与越南电竞

> ⚠️ **本节全部为 Lazada 对自有 9.9 大促成绩的自宣（P0-8）**，无独立第三方审计。**机制结构可参考，具体倍率数字不升级为中立事实**。

## 1. 案例一：泰国时尚（F-015/F-017~019）

- **背景**：9.9 大促泰国时尚品类成交额较 6.6 **增长超三成**（F-015）。
- **打法（内容驱动）**：
  1. Lazada 联合 **Vogue 推出时尚企划**，把 Crying Center 等品牌融入亚洲流行趋势穿搭展示（F-017）。
  2. 站外穿搭内容吸引关注 → 站内品牌资源与主题会场承接浏览与选购（F-019 转述）。
  3. 联盟营销合作伙伴通过社交媒体 / 社群推广；平台配合限时活动、内容投流、LazLive 直播（F-019 转述）。
- **自宣成绩**：Crying Center 9.9 销售额较 6.6 **增长超九倍**；一款重点商品四天内贡献全店超三成成交额，其中超三成来自联盟营销（F-018/019）。

## 2. 案例二：越南电竞（F-016/F-020~026）

- **背景**：越南约有 **6500 万** 游戏玩家（F-020，⚠️ 单源）；2026 年 3-7 月电竞相关品类贡献 Lazada 越南**电子产品过半**成交额（F-021）。
- **打法（圈层驱动）**：
  1. 与知名电竞战队 **GAM、MVK 合作**（F-022）。
  2. 围绕战队匹配**游戏达人、主播、社区内容资源**，用职业选手实际使用场景给电竞设备展示（F-022）。
  3. GAM / MVK 上线 **Lazada Minishop** 集中展示精选电竞装备（F-023）。
  4. 职业选手直播导购 + 平台站内活动会场、首页流量、促销资源衔接购买（F-023 转述）。
- **自宣成绩**：越南电竞品类较 6.6**增长超一倍**，**键盘鼠标贡献近九成成交额**；AULA、MOVESPEED、KTC 等中国品牌成交额**翻倍以上**；三场战队直播销售额达上一轮电竞周**三倍多**（F-024~026）。

## 3. 机制抽象：本地"品类 × 人群 × 内容 × 渠道"匹配模型

```
        本地消费洞察（品类机会）
                 │
   ┌─────────────┼─────────────┐
   ▼             ▼             ▼
 判定目标人群  匹配本地资源   承接购买
 (时尚族/玩家) (Vogue/战队达人) (会场/Minishop/直播)
```

- **泰国**：人群=关注潮流的年轻时尚消费者；内容=Vogue 穿搭；承接=站内时尚会场。
- **越南**：人群=约 6500 万游戏玩家；内容=战队/达人/主播；承接=Minishop + 直播。

> 核心启示：**不要只"卖货到市场"，用当地族群熟悉的内容把产品讲进场景**，再于站内闭环转化（可迁移主张，见 [knowledge-map](../knowledge-map.md) I2）。

## 4. 阅读与复用纪律

1. **数字标注 Lazada 自宣**：引用"+9 倍、+100%、~90%、翻倍"等，须注明"Lazada 对自有活动成绩自宣、无第三方审计"。
2. **⚠️ 幸存者偏差**：文中案例（Crying Center、AULA、MOVESPEED、KTC）均为 Lazada 主动挑选的**已成功样本**，未公开失败参与者与整体转化率；据此推断"同类肯定能成"会落入确认偏误，只能作"机制可行"的弱证据。
3. **机制可借鉴**："内容出圈 → 达人/圈层信任 → 站内会场承接"的闭环模型结构上可迁移到其他品类与平台。
4. **跨市场差异化**：越南电竞与泰国时尚验证了"同平台、不同国家、不同品类机会"——选品应先看当地人群释放的需求。
