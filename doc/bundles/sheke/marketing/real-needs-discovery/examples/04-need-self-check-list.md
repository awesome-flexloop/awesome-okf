# 需求自检清单：四道门 + 打分卡

> 用途：立项前、评审前、融资故事开写前，给任何一个"需求陈述"做 20 分钟体检。四道门对应本包概念层主线——本体（00 篇）、伪需求（01 篇）、证据（00/05 篇）、边界（07 篇）。事实溯源至 [../facts.md](../facts.md)。
>
> 评分阈值为【P2】经验区间，不是精密测量——打分卡的价值在于**强制回答**，不在于分数本身。

## 门一：本体门（它在说哪一层？）

| # | 检查项 | 过关标准 |
|---|---|---|
| 1.1 | 这条陈述说的是需要、欲望，还是有购买力支撑的需求？ | 明确落在第三层，或能说明购买力从哪来（F-001） |
| 1.2 | 能否翻译成"用户要的结果"（要洞不要钻头）？ | 一句话说清用户完成的任务，而非产品功能（F-003） |
| 1.3 | 目标人群与场景是否具体？ | "谁、在什么情景下"完整，非"所有人/年轻人"（F-016 情景依赖） |
| 1.4 | 是真需求三角齐备吗？ | 价值成立、相关方有共识、交付模式可持续运转（F-007） |

**任何一项不过 → 停止，回 [../concepts/00-what-is-real-need.md](../concepts/00-what-is-real-need.md) 重写需求陈述。**

## 门二：伪需求门（踩了哪个温床？）

| # | 检查项 | 危险信号 |
|---|---|---|
| 2.1 | 技术自恋检查：是先有技术再找场景吗？ | "我们有 AI/区块链/硬件，能做 XX"（F-060） |
| 2.2 | 补贴剥离测试：撤掉补贴、停掉 PR、放三个月，还剩什么？ | 订单随补贴同涨同落（F-057、F-058） |
| 2.3 | 痒点脉冲检查：数据是脉冲型还是持续型？ | 爆红登顶后留存骤降（F-059） |
| 2.4 | 模式可持续检查：单位经济在补贴外成立吗？ | 梁宁三角的"模式"一角缺失（F-007） |

**笨问题必答**："如果一分钱营销预算都没有，这个需求会以什么形式被用户自己说出来？"答不上来 → 回 [../concepts/01-fake-need-taxonomy.md](../concepts/01-fake-need-taxonomy.md) 对照三温床。

## 门三：证据门（证据到 L 几？）

按 [../concepts/00-what-is-real-need.md](../concepts/00-what-is-real-need.md) 第 4 节的证据等级盘点手上全部材料：

| # | 检查项 | 过关标准 |
|---|---|---|
| 3.1 | 最高证据等级是多少？ | L1 恭维不计；L2 仅作线索；进入决策需 L3+ |
| 3.2 | 有无"过去的真实代价"记录？ | 用户为此花过的钱/时间/迁移努力（访谈可采） |
| 3.3 | 有无"面向未来的真实代价"实验？ | 留资/预付/预售（L4~L6，F-044） |
| 3.4 | 恭维是否已被剔除？ | 整理材料时把"夸我们的话"单独标记不采信（F-015） |

**当前等级不足 L4 且本季度要重投 → 先跑一周验证（[03-one-week-validation-plan.md](03-one-week-validation-plan.md)）再决策。**

## 门四：边界门（结论在什么范围内成立？）

| # | 检查项 | 危险信号 |
|---|---|---|
| 4.1 | 鸿沟检查：证据来自尝鲜者还是主流用户？ | 早期信号直接外推主流市场（F-061） |
| 4.2 | 漂移检查：这个判断是多久以前形成的？ | 需求清单一年以上未重跑（F-065、F-029） |
| 4.3 | 非消费检查：服务对象是存量用户还是原本不消费的人？ | 用存量市场逻辑服务非消费者（F-062） |
| 4.4 | 伦理检查：实验与访谈的成本由谁承担？ | 用户被试成本大于零且无善后（F-068、F-041） |
| 4.5 | 时势检查：点线面体的周期位置支持这个需求吗？ | 逆行业/平台/经济周期硬推（F-009） |

## 打分卡

每道题 0~2 分（0=答不出或答案危险，1=部分满足，2=明确过关），共 17 题满分 34：

| 总分 | 处置建议（【P2】经验区间） |
|---|---|
| 28~34 | 需求陈述健康，进入排期与验证节奏 |
| 20~27 | 有明确短板：哪门失分多回哪篇概念补课，补完重测 |
| 12~19 | 结构性缺陷：大概率停在 L2 或踩了伪需求温床，回四路径重新发现（[../concepts/02-discovery-method-map.md](../concepts/02-discovery-method-map.md)） |
| <12 | 这个"需求"目前只是供给方的愿望——恭喜，体检替你把失败成本降到了 20 分钟 |
