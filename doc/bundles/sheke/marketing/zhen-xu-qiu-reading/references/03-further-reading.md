# 延伸阅读与交叉参照

本篇登记两类参照：同分组可直接互链的姊妹知识包，以及与本书主题相通的经典框架。经典框架只作简述，不提供未经核验的具体网址。

### 建议的交叉读法

- 本书提供“价值—共识—模式”的**整体框架**，通识包提供访谈与验证的**具体工具**：先用本书定位问题在哪一环，再到姊妹包取操作手册；
- 品牌与传播动作可参照 marketing-fundamentals 的 STP 与定位章节，把本书“认知战”落到合规的营销计划中；
- 任何在本书启发下产生的新业务设想，建议先过 sell-before-build-validation 的验证顺序，再进入投入阶段。

## 二、经典营销与产品框架（简述）

以下框架长期被行业复用，与本书概念可互相参照；具体版本与译者信息请以图书馆目录或出版方信息为准，本页不附未经核验的链接。

| 框架 / 著作 | 提出者 | 与本书相通之处 |
|---|---|---|
| 营销管理与需要分析 | 科特勒（Philip Kotler） | 需要、欲望、需求的三分，与本书“真需求”概念互参；STP 与本书用户人设、场景概念对应 |
| 定位理论 | 里斯、特劳特（Al Ries / Jack Trout） | 在心智中占据一个词，与本书认知战、信息包设计是同一命题的不同表述 |
| 客户开发 | 史蒂夫·布兰克（Steve Blank） | “走出办公室”验证假设，与江阴试点式小闭环一致 |
| 精益创业 | 埃里克·莱斯（Eric Ries） | 构建—测量—学习循环与 MVP，与本书“先验证、后放大”互证 |
| JTBD 任务理论 | 克里斯坦森（Clayton Christensen）等 | 用户“雇用”产品完成任务，可补充本书对功能与场景的分析 |
| KANO 模型 | 狩野纪昭 | 魅力型、期望型、基础型需求的区分，与价值组合及满意度判断相关 |
| 增长漏斗（AARRR） | 增长黑客实践 | 获取、激活、留存、收入、推荐，适合把模式部分的变现逻辑落到指标 |

使用提醒：这些框架产生于不同行业与年代，没有任何一个可以单独替代对自身事实的调研；它们与本书一样，是排查问题的视角，而非保证结果的公式。

## 三、中文语境的相关参照

- 本书“产品价值＝功能价值＋情绪价值＋资产价值”的公式由商业观察家蔡钰提出（书中注明）；蔡钰著有《情绪价值》（新星出版社 2024 年版），对情绪价值这一层有专门展开，可作为本书第二章的延伸读物。
- 国内互联网行业关于用户价值、产品定位的公开讨论与实践（如各大公司的公开方法论），可作为案例素材，但引用其具体说法时应核对原始出处，避免沿用以讹传讹的“名言”。
- 本书后记提到，作者下一本预计名为《小天地》，将展开“因果链、生态位、定价权”的倒三角框架；截至本包生成时该书信息以作者后续发布为准。
