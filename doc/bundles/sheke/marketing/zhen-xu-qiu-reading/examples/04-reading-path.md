# 阅读路径与实践建议

本篇面向不同背景的读者，给出四条进入《真需求》的路径，以及与姊妹知识包配合使用的方法。可按自身目标任选一条，不必严格按原书顺序。

## 路径一：快速入门路径（约半天，建立全景）

适合目标：第一次接触本书，想先拿到思维地图。

1. 读本包总框架：[价值—共识—模式三角](../concepts/00-book-and-framework.md)，理解圆心是真需求；
2. 读[价值总览与产品价值公式](../concepts/01-value.md)，掌握功能、情绪、资产三类价值；
3. 读三个故事的“概念印证总表”：[手机](../concepts/00-book-and-framework.md)、[脑白金](02-melatonin.md)、[网络媒体](03-webmedia-30y.md)各看结尾一张表；
4. 回看本包 [index](../index.md)，把全书四部分的关系串起来。

入门阶段不追求记住所有工具，只要能用三句话回答：这件事为谁创造什么价值？凭什么让对方现在行动？自己靠什么持续活下去？

## 路径二：全书通读路径（1–2 周，按原书结构）

适合目标：希望系统吸收、用理论整合已有经验的读者。

1. 从序言与导读开始，先建立“商业闭环”的极简模型；
2. **PART ONE 价值**：依次读功能、情绪、资产三类价值，再读价值组合与品牌，最后以 [价值故事：中国手机 30 年](01-mobile-phone-30y.md) 复盘全部分概念；
3. **PART TWO 共识**：先读四层分歧，再读认知战与关系，以 [共识故事：脑白金认知战](02-melatonin.md) 复盘；
4. **PART THREE 模式**：读能力系统、变现逻辑、分配机制，以 [模式故事：网络媒体 30 年](03-webmedia-30y.md) 复盘；
5. **PART FOUR 求真**：读应然与实然、第一性原理，最后读后记，理解本书落点是“造物之心”而非单纯技巧。

通读建议：每个 PART 读完先合上书，自己复述该部分概念，再读对应长篇故事检验；三个故事篇每篇文末的复盘问题，至少书面回答 3 条。

## 路径三：工具导向路径（带着具体业务问题取用）

不必通读，按角色取用所需章节。

### 面向创业者

关注顺序：真需求与总框架 → 变现逻辑 → 能力系统 → 分配机制 → 模式故事。

- 先回答“需求是否真实存在”，再谈增长；
- [网络媒体故事](03-webmedia-30y.md) 中“物种极限”的视角适合判断自己切入的是不是一张新牌桌；
- 史玉柱用最小市场验证全部假设的做法见 [脑白金故事](02-melatonin.md) 的江阴试点段落。

### 面向产品人

关注顺序：三类价值 → 价值组合 → 共识与四层分歧 → 用户人设与场景概念 → 价值故事。

- 用“功能＋情绪＋资产”拆解自己负责的功能，确认用户究竟付费在哪一层；
- [手机故事](01-mobile-phone-30y.md) 中魅族、小米、OPPO 的作品/工具/玩具之分，适合给产品定位；
- 对“用户嘴上说要”的功能保持警惕，结合行为证据判断。

### 面向品牌人

关注顺序：品牌价值 → 认知战 → 信息包 → 关系 → 共识故事。

- [脑白金故事](02-melatonin.md) 完整展示了信息包的编排：名字、形态、软文、书摘、病句、包装与陈列；
- [手机故事](01-mobile-phone-30y.md) 中苹果 Think Different 段落回答的是“我是谁”，适合品牌主张层面的参照；
- 注意网红与大牌的分野：话题度负责续航，责任感与辨识度才能沉淀长期品牌。

## 与姊妹通识包配合阅读

本包是对梁宁《真需求》一书的**单书精读**；同分组的 [real-needs-discovery 通识包](../../real-needs-discovery/index.md) 则把需求发现放进中西框架对照中。建议这样配合：

| 阶段 | 本包（单书框架） | 通识包（方法地图） |
|---|---|---|
| 建立判断 | 价值—共识—模式三角 | 需要/欲望/需求三分、用户价值公式 |
| 发现需求 | 用户人设、场景概念 | 问/看/算/试四路径、Mom Test 与 JTBD |
| 验证需求 | 江阴试点式小闭环 | MVP 谱系、行为证据等级、验证闭环 |
| 排序决策 | 价值组合 | Kano、ODI、RICE |
| 动手练习 | 三个故事的复盘问题 | 访谈工作坊、一周验证计划、自检清单 |

推荐顺序：先用本包建立“价值、共识、模式”的整体感，再到通识包中取用具体的访谈与验证工具；做完通识包的实操练习，回本包用三个长篇故事做整体系复盘。

同组还可参照：[marketing-fundamentals 营销系统通识](../../marketing-fundamentals/index.md)（STP、定位、4P/4C、AARRR）与 [sell-before-build-validation 先售后建验证](../../sell-before-build-validation/index.md)（需求验证的逆向顺序）。

## 实践提示

- **本书是经验框架，不是操作手册**：它提供的是排查生意的视角与清单，具体战术带有作者所处的时代与行业语境；
- **重大商业决策需结合自身事实**：进入新市场、投入重资产或作出长期承诺前，应完成自己的用户访谈与最小闭环验证，不能以书中案例直接类推；
- **先验证、后放大**：故事里真正决定成败的动作都发生在大投放之前——江阴试点、山寨档口的贴身观察、iPhone 之前对范式的判断；
- **框架用于理解，不用于定罪**：无论是评判竞争对手还是自己的项目，“不符合框架”不等于“必然失败”，反之亦然；
- **数据要回查出处**：本包引用的数字均标注原书页码，公开引用或用于决策时建议回查原书及更新口径。
