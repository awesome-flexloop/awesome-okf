# 数字经济报告阅读清单

> 本文是教学导读清单：报告与机构名称取自本束信源，核对动作可直接执行；所有引用的数字均可回溯本束 [事实清单](/facts.md) 的 F 编号。不提供政策建议，不构成投资建议。

## 一、先分清报告的两类身份

- **官方统计与政策报告**（发布机构为国家统计局、国务院、国家数据局、工业和信息化部、海关总署、农业农村部、市场监管总局等）——量化数字优先采信。
- **研究机构与行业报告**（中国信息通信研究院、中国互联网协会等）——引用时须标注「机构估算值」；其中中国信通院已在报告中声明其数据「不代表政府官方数据口径」（F-022）。

## 三、必须带口径标签的数字（红线）

- 凡涉「数字经济占 GDP 比重」：必须写清是「数字**核心产业**增加值」还是「数字经济增加值 / 数字经济规模」（F-035、F-070、F-065）。
- 凡涉信通院测算：一律补注「机构估算值」（F-064、F-065、F-066）。
- 凡涉网上零售额：区分月度初步值（F-051，130816 亿元、26.8%）与年度公报终值（F-052，127878 亿元、26.5%），正式引用用终值（勘误 3）。
- 凡涉就业数字：标注发布主体与年份（F-076 为专家文章测算、F-077 为信通院 2018 年测算）。
- 凡涉国际比较：逐一注明统计范围与基年，禁止跨口径比较、换算或平均（勘误 4）。

## 四、常见误读对照

| 误读 | 正确读法 | 依据 |
|---|---|---|
| 把 10.5% 与 43.8% 当「矛盾数据」 | 两者层级不同：核心产业 vs 广义规模 | F-035、F-065 |
| 把「10% 左右」「10.4%」「10.5%」混用 | 量化以国家统计局 10.5% 为权威，其余并列标注发布机构 | F-072、F-073、勘误 2 |
| 把软件业务收入与数字技术应用业增加值直接比较 | 两者为不同指标，不可直接比较 | F-042 |
| 用「占 GDP 60%」概括全球数字经济 | 该值为信通院 5 国合计口径；全球无国际组织官方汇总指标 | F-069、F-028 |
| 把「数字中国」等同「数字经济」 | 前者为更广概念（含数字政府、数字社会、数字生态） | F-081 |

## 五、跨束提示

数字经济治理涉及数据安全与个人信息保护的基础法律框架（《网络安全法》《数据安全法》《个人信息保护法》），其制度细节与合规边界归 [数字资产束](../../digital-asset/index.md) 展开（F-080）——读数字经济报告遇到「数据合规」议题时，请转该束继续。

## 六、阅读动作清单（可勾选）

- [ ] 打开报告先看发布机构与发布月份。
- [ ] 找「口径说明 / 注释」页，确认指标定义。
- [ ] 对每个待引数字填「发布机构—口径名称—统计时点」三件套。
- [ ] 同一指标出现两个来源时，并列标注而非取其一。
- [ ] 引用机构测算值时补「机构估算值」字样。
- [ ] 同一指标存在时点差异时（如「5G+工业互联网」项目数、灯塔工厂家数），使用最新时点值并注明时点（勘误 6）。
