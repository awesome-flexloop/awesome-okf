# 数字经济通识知识包

本知识包是「数字经济」的**阅读坐标系**：不预测行业走向、不推荐任何产品，只把官方统计口径、政策文件与机构测算的分工讲清楚——让你在任何一个「数字经济占比 XX%」的数字面前，都能问出正确的问题：**这是谁发的、什么口径、哪一年、能不能和别的数字比。**

全部事实采用**双轨溯源**：**中国官方统计与政策**挂国家统计局、国务院、工业和信息化部、国家数据局、海关总署、农业农村部、市场监管总局等发布的文件与数字（含文号与日期）；**国际与机构口径**挂 OECD、IMF、UNCTAD 与国际／国内研究机构的报告（82 条事实、43 个信源），并明确区分「官方发布值」与「机构估算值」。

> 阅读提示：数字经济规模与占比属高时效数据，年度值会随核算方法修订与普查结果更新；本包数字以 2026-10 可核实的公开口径为准，实务中以发布机构最新文件为准。**本包为通识教育材料，不构成投资建议、商业决策依据或政策解读意见。**

## 知识包立场

| 维度 | 本知识包的处理方式 |
|------|------------------|
| 内容性质 | 数字经济的概念、测度、结构与制度通识整理，面向希望读懂数字经济数字的普通读者与从业者 |
| 事实与观点 | 82 条事实双轨溯源：官方统计与政策挂文件文号与日期，机构测算挂报告与自我口径声明；判断性内容入 insights.md 并与事实区分 |
| 口径处理 | 官方发布值与机构估算值分区呈现、不混用；同一指标多口径并列留痕（勘误 1–7），不做静默调和 |
| 时效处理 | 规模数据与政策条款以 2026-10 可核实口径为准，stale_after 设为 2027-09-30 |
| 边界声明 | 不预测数字经济增速与行业走势；不推荐任何产品或平台；不解读政策意图，只登记文件与数字 |
| 免责声明 | 通识教育材料，不构成投资建议、商业决策依据或政策解读意见 |
