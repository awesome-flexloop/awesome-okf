# 💠 数字经济与数字资产

本分组收录数字经济与数字资产主题的知识包，回答两组问题：**数字经济是什么、规模多大、怎么测度、政策怎么管**，以及**数字资产有哪些形态、哪些受法律保护、边界在哪里**。

## 收录原则

- **口径先行**：任何规模、占比、增速数字必须携带「发布机构 + 口径名称 + 统计时点」三件套；中国信通院等研究机构的测算值一律标注「机构估算值」，**不与国家统计局官方发布值混用、相加或换算**；同一指标存在多口径时并列留痕、不做静默调和。
- **官方信源优先**：政策与制度事实挂中共中央、国务院、全国人大、国家统计局、国家数据局、工业和信息化部、财政部、中国人民银行、网信办等官方文件（含文号与日期）；国际比较挂 OECD、IMF、UNCTAD、BIS、FATF 等国际组织口径。
- **境内与境外口径并列不混同**：涉及加密资产、稳定币、代币化等主题时，中国境内口径与香港/欧盟/美国口径在同一处并列呈现并标注法域，**禁止以境外制度推导境内合规结论**。
- **不荐不评**：不推荐任何产品、平台、币种或交易场所，不评价投资价值，不预测价格；不构成投资建议、法律意见或合规意见。
- **时效分层**：规模数据与监管条款时效敏感，`stale_after` 统一设为 2027-09-30；引用时以发布机构最新口径为准。

**收录边界**：本组承接宏观与制度层面的数字经济议题与数字资产形态辨析；AI 产业与商业趋势归 [AI 行业与商业趋势](../industry/index.md)，个人理财与投资通识归 [个人理财与投资](../finance/index.md)，数据工程与容器/构建等技术实现归技术域。
