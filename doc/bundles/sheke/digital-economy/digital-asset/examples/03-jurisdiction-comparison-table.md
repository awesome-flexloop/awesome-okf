# 数字资产监管口径对照表

> **本表不构成合规意见**，不构成投资建议。表中口径均取自本束 [事实清单](/facts.md) 的 F 编号，四方并列呈现、**不混同**。任何一格结论都不可脱离该法域单独引用；**禁止以「境外允许」推导「境内可行」，亦禁止以「境内禁止」描述境外制度**（勘误 1、勘误 5，F-090）。

## 一、四方 7 主题对照表

| 主题 | 中国境内 | 香港 | 欧盟 | 美国 | 出处 |
|---|---|---|---|---|---|
| 法律定性 | 虚拟货币是「特定的虚拟商品」，不具法偿性，相关业务活动属**非法金融活动** | 走发牌与合规框架（SFC / HKMA 分工） | MiCA 分 ART / EMT / 其他加密资产，分类牌照监管 | 无统一定性，按既有证券 / 商品法律分别认定 | F-005、F-080、F-082、F-090 |
| 交易所 / 服务商准入 | 禁止境内交易与相关业务；境外交易所向境内提供服务亦属非法 | 须持牌 | 须获 MiCA 授权 | 按州 / 联邦分业 | F-083、F-090 |
| 稳定币 | 无专门法规，按虚拟货币非法金融活动处置 | 《稳定币条例》发牌制，2025-08-01 生效 | EMT/ART 规则 2024-06-30 适用（MiCA 2023-06-29 生效） | GENIUS Act 2025-07-18 成法，监管「支付稳定币」 | F-063、F-065、F-066、F-090 |
| 挖矿 | 全产业链整治、严禁新增 | 未专门禁止 | 未统一禁止 | 未禁止（部分州有限制与激励） | F-084、F-086、F-089 |
| NFT | 遏制金融化证券化，禁集中 / 持续挂牌 / 标准化合约交易（**行业倡议，非强制法规**） | 视是否构成证券纳入虚拟资产框架 | 一般纳入 MiCA 或既有金融法规 | 按是否构成证券认定 | F-074、F-075、F-090 |
| RWA / 代币化 | 未开放境内代币化交易 | 官方鼓励（政策宣言 2.0、Ensemble 试验） | MiCA + DLT 试点制度 | 证券法框架下探索 | F-076、F-079、F-090 |
| CBDC | 数字人民币（e-CNY）：M0 定位、双层运营、可控匿名 | 数码港元研究 + Ensemble | 数字欧元处于准备阶段 | 无零售 CBDC | F-067、F-068、F-069、F-090 |

## 二、适用主体与合规后果摘要

| 主题 | 适用主体 | 合规后果要点 |
|---|---|---|
| 法律定性 | 面向中国境内居民开展虚拟货币业务的机构与个人 | 虚拟货币相关业务活动被定性为**非法金融活动**（F-082） |
| 准入 | 境内交易平台；以互联网向境内居民提供服务的境外交易所 | 均在禁止 / 非法范围内（F-083） |
| 稳定币 | 香港发行法币稳定币或宣称锚定港元价值者；欧盟 ART/EMT 发行与交易主体；美国支付稳定币发行人 | 分别须获发牌 / 授权 / 受联邦立法约束（F-063、F-065、F-066） |
| 挖矿 | 虚拟货币「挖矿」上下游全产业链主体 | 严禁新增、推动存量有序退出；综合采取电价、补贴、授信等约束措施（F-084） |
| NFT | 数字藏品交易相关主体 | 受三协会行业倡议约束（非法规），禁止集中与持续挂牌交易（F-075） |
| RWA / 代币化 | 参与境外代币化项目的相关主体 | 香港、新加坡等境外有官方激励项目；境内未开放（F-076、F-077、F-079） |
| CBDC | 零售支付场景各方 | e-CNY 为法定货币（M0），与加密资产性质不同（F-067、F-070） |

## 三、使用纪律（可勾选）

- [ ] 引用任一格时，同时写出**法域标签**（中国境内 / 香港 / 欧盟 / 美国）。
- [ ] 不把香港、欧盟、美国口径拼接为「全球监管趋同」（勘误 5）。
- [ ] 涉稳定币时先问四件事：谁发行、储备是什么、赎回条件如何、在哪个法域（F-057、F-060、F-090）。
- [ ] 涉代币化案例时区分三层：**技术可行性 / 境外监管可行性 / 境内合规可行性**（F-078、F-079）。
- [ ] 本表以 2026-10 可核实的公开口径为准；各法域规则持续更新，实务以官方最新发布为准（`stale_after` 2027-09-30）。
- [ ] 涉及数据侧准入与出境议题时，另见 [数字经济束](../../digital-economy/index.md) 相关概念，与本表口径分别适用。
