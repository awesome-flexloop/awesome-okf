# 👥 社会科学

本域存放社会科学相关的知识包，覆盖三个方向：

- **职场与管理**：面向行政、人事、秘书等岗位的系统进修——人力资源职业地图与六大模块、劳动法律合规、行政管理实务与公文写作。法规类内容逐条挂全国人大、人社部、国务院等官方信源，实践类内容附可直接复制的清单、模板与算例。
- **亲密关系与两性情感**：两性关系经典著作知识包——学术实证、哲学经典与通俗实践三层谱系。
- **性学经典**：性学/性文化经典著作阅读教程（六大板块提要·译本指南）、《汉书·艺文志》房中八家专题研读与马王堆房中简帛专题深读。

**收录边界**：现代社会科学著作归本域；中国古代房中养生典籍归 [医学与养生](../yixue/index.md) 域。
