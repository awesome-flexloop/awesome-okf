# 👥 社会科学

本域存放社会科学相关的知识包，覆盖五个方向：

- **职场与管理**：面向行政、人事、秘书等岗位的系统进修——人力资源职业地图与六大模块、劳动法律合规、行政管理实务与公文写作。法规类内容逐条挂全国人大、人社部、国务院等官方信源，实践类内容附可直接复制的清单、模板与算例。
- **亲密关系与两性情感**：两性关系经典著作知识包——学术实证、哲学经典与通俗实践三层谱系。
- **性学经典**：性学/性文化经典著作阅读教程（六大板块提要·译本指南）、《汉书·艺文志》房中八家专题研读与马王堆房中简帛专题深读。
- **个人理财与投资**：面向零基础普通人的个人投资通识——复利与风险数学、投前优先级、资产配置与再平衡、指数基金与行为纪律、中国市场制度规则。理论事实挂经典著作与诺贝尔奖官方记录，制度事实挂中国政府网与监管部门文件；不荐产品、不预测市场，附配置算例、定投清单与防骗自查。
- **市场营销**：面向创业者、运营与职场人的营销思维骨架——营销本质、STP 战略、定位与品牌、4P/4C 战术、顾客旅程、AARRR 增长与单位经济、内容私域、营销计划与合规底线。理论事实挂经典著作与提出年份，合规事实挂官方法规；附 STP 工作坊、算例手册与上线合规清单。

**收录边界**：现代社会科学著作归本域；中国古代房中养生典籍归 [医学与养生](../yixue/index.md) 域。
