## 三、核心概念（F-CON，15 条）

| 编号 | 事实内容 | 信源 |
|------|---------|------|
| F-CON-001 | "气"（精气、神气）是马王堆出土养生书最基本的理论基础，食气、行气、养气、治气、接气等概念贯穿全书，并将气功、房中、服食融会贯通 | S4 |
| F-CON-002 | 马王堆房中书以"气"为理论核心，将两性和谐视为养生延寿之术 | S28 |
| F-CON-003 | 《天下至道谈》系统论述"七损八益"：八益为治气、致沫、知时、畜气、和沫、窃气、侍赢、定倾；七损为闭、泄、竭、勿、烦、绝、费 | S16、S28 |
| F-CON-004 | 《天下至道谈》："气有八益，有七孙（损），不能用八益去七孙（损），则行年册而阴气自半也"；"善用八益去七损，耳目聪明，身体轻利、阴气益强，延年益寿，居处乐长" | S16 |
| F-CON-005 | 《十问》核心方法包括"食阴拟阳""玉闭坚精"，主张通过节制房事、调和气血达到延年益寿 | S17 |
| F-CON-006 | 《十问》曹熬答黄帝问提出"玉闭坚精，必使玉泉毋倾，则百疾弗婴，故能长生"，并列举"壹至勿泻"至"九至勿泻"的九层效验 | S17、S18 |
| F-CON-007 | 《十问》容成答问以天地之道论养生："君若欲寿，则顺察天地之道"，主张治气抟精、宿气夜散、新气朝最 | S17、S18 |
| F-CON-008 | 《十问》尧问舜"天下孰最贵"，舜答"生最贵"；又论"阴与人俱生而先身去"，即生殖器与身俱生却先身而衰 | S18、S32 |
| F-CON-009 | 房中术在古代又称"接阴之道"（见《十问》）或"御妇人之术"（见《后汉书·方术列传》注），是以男子为对象的技术 | S9 |
| F-CON-010 | 马王堆养生思想特点：一主张祛病健身以延年益寿，二讲究兼修众术（服食、行气、导引、房中、祝由）反对偏执一法，三以气论贯通诸术 | S4 |
| F-CON-011 | 出土医书为房事制定节制法则，如《养生方》"男女之齐至相当，毋伤于……"等论述 | S4 |
| F-CON-012 | 《十问》"食阴之道"一段存在多种释读分歧：整理者、周一谋与萧左桃、马继兴、魏启鹏与胡翔骅、连劭名各持一说，涉及"三咎"是否读为三焦等争议 | S15 |
| F-CON-013 | 《合阴阳》与《天下至道谈》均论"五音"（五声），整理者认为《十问》"五声乃对"之五声即此五音 | S15 |
| F-CON-014 | 《十问》论养生与行气的段落可与战国玉佩《行气铭》对读，二者所述行气原理基本相合 | S15 |
| F-CON-015 | 《天下至道谈》开篇"黄神问于左神"论"阴阳九窍十二节俱产而独先死"，是房中书以身体观立论的代表段落 | S18 |
