# 马王堆房中简帛阅读教程

1973 年，长沙马王堆三号汉墓（下葬于汉文帝前元十二年，即公元前 168 年）出土大批帛书与医简，其中竹简《十问》《合阴阳》《天下至道谈》《杂禁方》与帛书《养生方》《杂疗方》《胎产书》构成**现存最早的房中医学文献实物**。本知识包是以"出土文本为经、研究著作为纬"的专题阅读教程：从发掘现场与文本形制出发，逐篇讲读核心命题（七损八益、精气论），再沿 1974 年帛书整理小组、2014 年《长沙马王堆汉墓简帛集成》、2024 年修订本的整理出版脉络，进入四条现代研究路径。

> **内容边界**：本知识包为学术教育性阅读教程。出土公版文献仅引篇名、核心命题与少量代表性片段，以学术介绍口吻呈现；现代研究著作只介绍观点与结构，不录原文；技术性术语以文献学/医学史口径呈现，全文无露骨描写。
