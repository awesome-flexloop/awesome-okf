## 前置认知：你面对的是什么

《汉书·艺文志·方技略》房中类著录八家房中书，共"百八十六卷"。这八家全部亡佚，无一完整传世；我们今天能读到的，是著录本身（书名、卷数、小序）加上后世文献的零星引文与出土简帛。因此，"研读房中八家"的第一步不是找原文，而是先读懂著录。

房中八家著录总表（书名、卷数四信源完全一致）：

| 书名 | 卷数 | 班固自注 |
|---|---|---|
| 容成陰道 | 二十六卷 | 无 |
| 務成子陰道 | 三十六卷 | 无 |
| 堯舜陰道 | 二十三卷 | 无 |
| 湯盤庚陰道 | 二十卷 | 无 |
| 天老雜子陰道 | 二十五卷 | 无 |
| 天一陰道 | 二十四卷 | 无 |
| 黃帝三王養陽方 | 二十卷 | 无 |
| 三家內房有子方 | 十七卷 | 无 |

> 小计原文："右房中八家，百八十六卷。"注意：逐家卷数实际合计为 191 卷，与小计相差 5 卷。《汉书新注》按语已指出此差异，颜师古归因于"转写脱误，年代久远，无以详知"。引用卷数时以逐家数字为准，小计差异作为版本校勘信息保留，不要为凑整擅自修改原文数字。

## 第一步：选定一家作为研读锚点

零基础读者建议从 **《容成陰道》（二十六卷）** 入手，理由有三：

1. 托名人物"容成"在传世文献与出土文献中线索最多：《汉志》阴阳家类另有《容成子》十四篇，马王堆《十问》有"黄帝问于容成"章，天文历法书亦托名容成，便于做跨类、跨材料互证。
2. 卷数居中（二十六卷），不似《務成子陰道》三十六卷之繁，也不似《三家內房有子方》十七卷之简，体量适中。
3. 与出土文献的对应关系最清晰，首次研读容易获得"互证成功"的正反馈。

备选：若你对帝王托名系统更感兴趣，可选《堯舜陰道》或《湯盤庚陰道》，二者与《十问》"尧问于舜""帝盘庚问于耇老"章直接对应。

## 第二步：核对著录信息，建立事实卡片

打开著录原文信源（见 [../references/catalog-sources.md](../references/catalog-sources.md)），至少对照两个信源（如维基文库白文 + 中华书局点校本系统注本），逐字核对所选一家的：

- 书名原文（繁体照源保留，如"容成陰道"）
- 卷数（二十六卷）
- 有无班固自注（房中八家均无班固自注，亦无颜师古注——这是房中类与六艺略易类的重要体例差异，易类书目下有班固自注小字）

将核对结果写成一张事实卡片，注明信源与核对日期。凡两个信源不一致处，标注【待核验】，不要凭记忆补写。

## 第三步：解析书名中的托名人物

房中八家书名本身就是内容证据。对《容成陰道》做托名解析：

1. **人物**：容成。查《汉志》他类著录——阴阳家类有《容成子》十四篇，说明"容成"是跨知识门类的托名人物。
2. **术语**："陰道"。今注本释为"御婦人之術"一类表述，属今人新注而非班固原注，引用时须注明注者。
3. **出土对照**：马王堆《十问》有"黄帝问于容成"问答章，答语题署"容成之……道"。将出土问对组合与书名托名并置，可证该托名传统在西汉初年（前 168 年下葬）已定型。

把"书名→托名人物→他类同名著录→出土问对"这条线索画成一张简表，这就是你的第一份托名结构分析。

## 第四步：通读房中小序，定位该类知识性质

房中类小序（注意"性情/情性"异文：维基文库作"性**情**之極"，中华书局点校本校改为"**情性**之極"）：

> 房中者，性情之極，至道之際，是以聖王制外樂以禁內情，而為之節文。傳曰：「先王之作樂，所以節百事也。」樂而有節，則和平壽考。及迷者弗顧，以生疾而隕性命。

通读要点：小序强调"乐而有节"方能"和平寿考"，定调是**节制养生**而非纵欲；方技略总序称方技为"生生之具，王官之一守"，房中在汉代是与医经、经方并列的官方知识门类。把这两句抄入事实卡片，作为理解房中性质的坐标。

## 第五步：登记研读结论，规划下一步

完成以上四步后，写一段 200 字左右的研读小结，至少包含：

- 所选一家的著录信息（书名、卷数、无自注）与信源
- 托名人物及其跨类、跨材料线索
- 小序对该类知识性质的界定
- 至少一条【待核验】事项（如卷数差异成因、异文版本依据）

下一步建议：进入 [02-佚文对照阅读](02-fragment-reading.md)，学习如何处理亡佚文本的辑佚引文；或按 [03-分阶段研读计划](03-reading-plan.md) 将研读扩展到全部八家。

## 常见误区

- **误把今人新注当班固原注**：房中八家下无任何班固自注与颜师古注，《汉书新注》中的注释均为今人所作。
- **误把小计卷数当逐家卷数**：186 与 191 之差是文本流传史证据，不是数据缺陷。
- **以后世框架倒推汉代定位**：房中在汉代不是禁书，其边缘化是《隋志》并类、《四库总目》剔除两次具体目录学操作的结果。
