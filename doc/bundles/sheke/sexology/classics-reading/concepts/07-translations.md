## 为什么译本选择是中文读者的第一道门槛

性学经典的中译市场呈现"热书多译、冷书无译、热书滥译"的格局：《性学三论》这类公众知名度高的著作动辄有十几个译本，其中不少为拼凑编译；而《性精神病态》等专业著作至今没有权威全译。选错译本，轻则读不懂，重则读到被编译者改写过的"伪书"。本篇给出可操作的选本方法。

## 一、选译本四原则

1. **译者学术背景**：优先选择译者本身是相关领域学者（医学史、性社会学、精神分析）的译本，而非"多译者合译"或匿名编译。
2. **出版社与丛书**：优先学术出版社（商务印书馆、三联、译林学术线等）与有学术编辑传统的丛书；书市上以"精装插图珍藏"为卖点的性学译本通常值得警惕。
3. **底本说明**：合格的学术译本会在前言交代所据外文底本及版次（如《性学三论》各语言版差异很大，不交代底本的译本不可靠）。
4. **注释密度**：性学文本充满历史名词与人名，零注释的"流畅译本"往往意味着删节或改写。

## 二、重点著作的译本现状

| 著作 | 中译入口 | 状况说明 |
|------|---------|---------|
| 霭理士《性心理学》 | **潘光旦译注本（1946 年商务印书馆，后多次重印）** | 中文读者的标准入口：潘译以译注加入大量中国文献佐证，兼具翻译与学术研究价值，选它几乎不会错 |
| 弗洛伊德《性学三论》 | 多译本并存 | 市面版本极多、质量参差；有出版物的译者署名版本信息（如浙江文艺版译者姓名）待核验，选购时按四原则核对 |
| 克拉夫特-埃宾《性精神病态》 | 无权威中文全译本 | 节译情况待核验；建议先读导论性研究再决定是否查英译 |
| 金赛报告 | 中文全译本状况待核验 | 警惕以"金赛"为名的传记式、猎奇式读物冒充报告译本 |
| 马斯特斯与约翰逊 | 全译本未见（待核验） | 专业著作，读导读即可 |
| 《性史》（福柯） | 有多个中译（佘碧平、张廷昱等译本流传）【译者署名待核验】 | 选购时核对所据法文底本与卷次；第一卷与二、三卷常分开出版 |
| 《欲经》 | 伯顿 1883 英译激增了其西方流行；现代学术译本推荐 Doniger 与 Kakar 合译（牛津 2002） | 中文译本多为自英译转译，底本链条须留意 |
| 《中国古代房内考》（高罗佩） | 李零等译（商务印书馆 2007） | 学术界通行中译本；另有上海人民出版社早期译本（1990） |

## 三、待核验条目怎么办

本 bundle 的 facts.md 中，凡标注【待核验】的版本信息（译者、年份、出版社）均表示调研时未能从权威馆藏级信源确认。处理方式：

1. **不要引用未核验条目**做学术写作；
2. 按下方"馆藏核验三步"自行确认：查国家图书馆/高校图书馆 OPAC 著录 → 查出版社官网在售信息 → 必要时查阅实体书版权页；
3. 对两说并存的条目（如中华性文化博物馆创办年 1994/1995），引用时保留"一说"表述。

## 四、古典文献的"版本"问题

中国古典房中文献的阅读版本不是"译本"问题而是"辑本"问题：《素女经》《玉房秘诀》等均无传世完帙，今天的文本来自《医心方》辑佚与叶德辉《双梅景闇丛书》刊本，其文字可信度受辑佚者取舍影响。严肃阅读应从《长沙马王堆汉墓简帛集成》（中华书局）等现代整理本入手，而非清末辑刊丛书的翻印本——详见 [/concepts/01-ancient-china.md](01-ancient-china.md)。
