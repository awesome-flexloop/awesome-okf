# 信息如何进入价格：事件研究对照演示

> **重要声明**：以下公司、日期、收益率与图表全部是**教学假设**，用于演示「信息入价」的检验逻辑，**不构成任何投资建议或市场预测**。

## 一、要检验什么问题

[05 章](../concepts/05-emh-three-forms.md) 说**半强式有效**的含义是：价格已反映**所有公开信息**（F-050）。怎么检验？看一个**公开消息公布**时，价格如何反应：

- 若价格**在公布当日就跳到新水平**，之后不再系统性移动 → 支持半强式有效；
- 若公布后价格还**持续朝同一方向漂移** → 说明「反应不足」，是**挑战**。

这就是**事件研究法**（F-063）：以事件日为「第 0 天」，观察**事件窗口**内的**超额收益**（相对某个基准模型的收益）。

## 二、情景 A：利好消息公告日

教学假设：某公司于 T 日公布「业绩超预期」。

| 相对日 | 累计超额收益（教学假设） | 说明 |
|---|---|---|
| T−3 | 0.0% | 公告前无异常 |
| T−1 | +0.1% | 接近 0（无内幕泄漏迹象） |
| **T（公告日）** | **+4.5%** | **当日跳涨，信息迅速入价** |
| T+1 | +4.6% | 仅微幅 |
| T+5 | +4.7% | 基本无漂移 |
| T+20 | +4.8% | 平稳 |

**读法**：这正是**支持半强式有效**的典型形态——价格在公告当天**一步到位**，之后无系统性机会（F-050、F-064）。

```mermaid
flowchart LR
    A["T−1 平稳"] --> B["T 日跳涨 +4.5%"]
    B --> C["T+1~T+20 平稳"]
    C --> D["无公告后机会<br/>支持半强式"]
```

## 三、情景 B：公告后漂移（挑战）

教学假设：另一家公司同样在 T 日公布利好，但走势不同。

| 相对日 | 累计超额收益（教学假设） | 说明 |
|---|---|---|
| T | +2.0% | 公告日只涨了一部分 |
| T+5 | +3.0% | 继续上行 |
| T+20 | +4.5% | 仍在漂移 |
| T+60 | +6.0% | 逐步「补涨」完毕 |

**读法**：这是**公告后漂移（post-earnings-announcement drift, PEAD）** 的形态——市场**反应不足**，信息被**逐步**吸收。它是 EMH 一方**最难解释**的现象之一，也是 [07 章](../concepts/07-evidence-for-and-against.md)「证据之争」中的经典异象（F-064、F-067）。

## 四、为什么这构成了「争议」而不是「定论」

同一方法，两种结果，必须理解它们的**解释张力**（回顾 [05 章](../concepts/05-emh-three-forms.md) 联合假设问题 F-053）：

| 结果形态 | EMH 一方的解释 | 挑战一方的解释 |
|---|---|---|
| 情景 A（当日到位） | 支持半强式有效 | 同意 |
| 情景 B（公告后漂移） | 可能是**风险补偿**、或**数据挖掘/交易成本**吞掉了纸面收益 | 市场**系统性反应不足**，EMH 不成立 |

**关键提醒**：情景 B 的「漂移」是否**可交易获利**，还要扣掉：

1. **交易成本**（买卖价差、佣金、冲击成本）；
2. **风险补偿**（承担了某种被定价的风险）；
3. **样本外稳定性**（历史上显著，未来还显著吗？）。

这三条都过不了，「漂移」就只是**纸面异象**，不构成可实用的反驳（F-067）。

## 五、本示例的方法论收获

| 收获 | 对应概念 |
|---|---|
| 事件研究法用「事件窗口超额收益」检验信息入价 | F-063 |
| 公告日一步到位 = 支持半强式 | F-050、F-064 |
| 公告后漂移 = 挑战，但需扣除成本与风险补偿 | F-064、F-067 |
| 「模型错了」与「市场无效」无法分开 = 联合假设问题 | F-053 |

> **一句话**：**事件研究是「EMH 争论的显微镜」——它让「信息入价快不快」变成可测量的量，但也暴露了「快慢」与「有效无效」之间隔着成本、风险与模型选择三重大山。**
