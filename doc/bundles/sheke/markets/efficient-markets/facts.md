## 一、市场是什么：从交换到秩序（对应 [00 章](concepts/00-what-is-a-market.md)）

| 编号 | 事实内容 | 信源 |
|------|---------|------|
| F-001 | 市场是买者与卖者相互作用、交换商品与服务的机制或安排，不必是物理场所；其本质是「交换的制度化」，可表现为集市、交易所或线上撮合系统。 | S2、S30 |
| F-002 | 市场的核心功能是把资源引导到最有价值的用途（资源配置）；亚当·斯密 1776 年在《国富论》中提出「看不见的手」——个体追求自身利益，经价格机制引导，可能促进社会整体福利。【P0】 | S1 |
| F-003 | 市场的四类参与者：家庭（消费与劳动供给）、企业（生产与投资）、政府（税收、支出、监管）、金融中介（连接储蓄与投资）。 | S30 |
| F-004 | 市场的四大功能：资源配置、价格发现、风险分担、提供流动性。 | S2、S30 |
| F-005 | 市场的类型谱系：按竞争程度分为完全竞争、垄断竞争、寡头、垄断；按标的分商品市场、劳动市场、资本市场、金融市场。 | S30 |
| F-006 | 完全竞争模型（众多买卖者、同质产品、自由进出、完全信息）是**理论基准**（分析标尺），现实中很少完全满足；它的价值在于提供「偏离在哪里」的判断尺度。 | S2、S30 |
| F-007 | 市场运转的制度前提：产权界定、契约执行、货币、反欺诈等；缺少这些制度，交换与价格机制难以运转。 | S6、S30 |
| F-008 | 分工受市场范围限制（斯密 1776）：市场越大、交换越便利，专业化分工越深，生产效率越高。 | S1 |

## 二、供给、需求与价格形成（对应 [01 章](concepts/01-supply-demand-price.md)）

| 编号 | 事实内容 | 信源 |
|------|---------|------|
| F-009 | 需求定律（其他条件不变，价格上升则需求量下降）与供给定律（价格上升则供给量增加）是市场分析的两条基本规律。【P0】 | S2 |
| F-010 | 均衡价格与市场出清：供给量与需求量相等时的价格为均衡价格；价格高于均衡产生过剩（有下行压力），低于均衡产生短缺（有上行压力）。【P0】 | S2 |
| F-011 | 「曲线移动」与「沿曲线移动」的区别：**价格本身变化**导致沿曲线移动（需求量/供给量变化）；**价格以外的因素变化**导致曲线整体移动（需求/供给变化）。混淆二者是最常见入门错误。 | S2 |
| F-012 | 需求价格弹性：需求量对价格变化的敏感度；弹性小（刚需）时价格变动对数量影响小、价格反应大，弹性大（可选）时数量反应大。 | S2 |
| F-013 | 马歇尔 1890 年《经济学原理》系统化了供需曲线、局部均衡分析与弹性概念，是微观经济学教材体系的奠基。 | S2 |
| F-014 | 瓦尔拉斯 1874 年《纯粹经济学要义》提出一般均衡理论：所有市场同时出清，通过「试探性调整」（tâtonnement）过程趋向均衡。 | S3 |
| F-015 | 市场具有自我修正倾向：过剩推动降价、短缺推动涨价，价格趋向均衡——**前提是无价格管制且竞争充分**。 | S2 |
| F-016 | 蛛网模型：在农产品等「生产决策滞后于价格」的市场中，价格与产量可能围绕均衡作周期性波动，甚至发散（而非收敛）。 | S2 |
| F-017 | 价格的双重功能：**传递信息**（反映稀缺程度）+ **提供激励**（引导节约与增产）——二者是价格机制协调分散决策的核心。 | S4 |
| F-018 | 广告与品牌可作为质量信号：在信息不对称下，企业通过广告投入与品牌声誉向买方传递质量信息，降低买方的不确定性。 | S9 |

## 三、价格发现与信息：哈耶克的知识分工（对应 [02 章](concepts/02-price-discovery-and-information.md)）

| 编号 | 事实内容 | 信源 |
|------|---------|------|
| F-019 | 哈耶克 1945 年在《美国经济评论》发表《知识在社会中的运用》，提出经济中最重要的知识是「关于特定时空环境的知识」（某块地的收成、某台机器的状态、某人此刻的偏好），它分散在无数个体手中、无法被中央机构完整收集。【P0】 | S4 |
| F-020 | 价格是传递分散信息的机制：以「锡短缺」为例，用锡者只需看到价格上涨即自动节约、替代、回收，无需知道短缺原因；价格以极少的信息传输量实现了巨大的协调效果。【P0】 | S4 |
| F-021 | 价格发现（price discovery）：市场通过交易把分散信息聚合进价格的过程；价格不是某人算出来的，而是无数买卖决策合成的结果。 | S4 |
| F-022 | 信息效率：价格迅速、充分地反映可得信息的程度，是衡量市场「信息维度」有效性的指标。 | S16 |
| F-023 | 法玛 1970 年提出的有效市场假说（EMH）**主要讨论的是信息效率**（价格对信息的反映程度），**不**直接断言「市场配置资源一定最优」。 | S16 |
| F-024 | 资源配置效率：资本流向社会最优用途的程度；**信息效率不蕴含资源配置效率**——价格反映信息 ≠ 资本流向最该去的地方（外部性、泡沫是反例）。 | S16 |
| F-025 | 私有信息通过交易逐步被价格吸收：掌握私有信息的交易者通过下单把信息传递进市场，私有信息逐步转化为公共信息。 | S4、S16 |

## 四、竞争、套利与均衡（对应 [03 章](concepts/03-arbitrage-and-equilibrium.md)）

| 编号 | 事实内容 | 信源 |
|------|---------|------|
| F-026 | 套利（arbitrage）：在同一或相关资产上同时买卖，以锁定无风险价差的交易。 | S16、S30 |
| F-027 | 一价定律（law of one price）：在无摩擦、可自由交易的市场中，同一资产（或等价资产）应有同一价格；价格偏离会被套利纠正。 | S2、S30 |
| F-028 | 无套利假设（no-arbitrage）：若不存在无风险套利机会，价格之间必须满足特定关系；它是现代资产定价最核心的假设之一，**不需要知道投资者偏好**，只看价格之间是否自洽。 | S17 |
| F-029 | 竞争抹平超额收益：某人发现可获利机会→更多资金涌入→价差被抹平→超额收益衰减；**「发现者」获得的超额收益本质是其承担信息成本与风险的补偿**。 | S11 |
| F-030 | 格罗斯曼—斯蒂格利茨悖论（1980，《论信息有效市场的不可能性》）：若价格已反映全部信息，则无人有动力花成本搜集信息（可免费搭便车）；若无人搜集信息，价格又不可能反映这些信息。**故完全信息有效的市场不可能存在。**【P0】 | S11 |
| F-031 | 均衡只能是「部分有效」：价格必须**足够有信息量以补偿信息采集者**、又**不能完全揭示**，才能让「生产信息」有利可图；因此效率**有程度、有边界、因市场而异**（商品市场与股票市场效率不同）。【P0】 | S11 |
| F-032 | 市场是自适应系统：参与者的行为改变价格，价格又反过来改变参与者的机会与行为（反馈回路）；市场不是静态的自动售货机，而是参与者与规则不断相互作用的系统。 | S27 |
| F-033 | 信息扩散速度与价格反应速度正相关：市场交易越频繁、参与者越多、信息扩散越快，价格对新信息的反应就越迅速（这是信息效率高低的市场间差异来源）。 | S16 |
| F-034 | 流动性与价格效率相互促进：流动性好→交易成本低、下单冲击小→信息更易通过交易反映进价格；价格效率高→吸引更多参与者→流动性更好。 | S16 |

## 五、市场失灵与效率边界（对应 [04 章](concepts/04-market-failure.md)）

| 编号 | 事实内容 | 信源 |
|------|---------|------|
| F-035 | 市场失灵（market failure）：在特定条件下，市场自发配置资源**无法达到帕累托最优**的情形；它描述的是**边界条件下的例外**，不代表「市场总是坏的」。 | S30 |
| F-036 | 市场失灵的五大类：外部性、公共品、信息不对称、市场势力、宏观不稳定（协调失灵）。 | S30 |
| F-037 | 外部性（externality）：经济活动对**未直接参与交易的第三方**产生的影响；负外部性（排污、噪音）导致过度生产，正外部性（疫苗、基础研究）导致供给不足。 | S5 |
| F-038 | 庇古税（庇古 1920《福利经济学》）：对产生负外部性的行为征税（税率 = 边际外部成本）、对正外部性的行为补贴，使私人成本与社会成本重新对齐；碳税、排污费属此思路。 | S5 |
| F-039 | 科斯定理（科斯 1960《社会成本问题》）：**若产权清晰界定且交易成本为零**，无论产权最初分给谁，双方都能通过自愿谈判把外部性内部化；现实交易成本很少为零，故当事人多、搭便车严重时仍需政府介入。【P0】 | S6 |
| F-040 | 公共品（萨缪尔森 1954）：具有**非排他性**（无法阻止未付费者使用）与**非竞争性**（多一人消费不减少他人消费量），导致**搭便车问题**与私人供给不足，通常需税收融资供给；与**公共资源**（非排他但竞争，导致公地悲剧）失灵方向相反。 | S7 |
| F-041 | 信息不对称（information asymmetry）：交易一方掌握另一方不知道的关键信息；是金融市场最典型、最深刻的失灵。 | S8 |
| F-042 | 逆向选择 / 柠檬市场（阿克洛夫 1970《柠檬市场》）：买家只愿按「平均质量」出价→好车卖家退出、次品（柠檬）留下→平均质量进一步下降→市场可能萎缩甚至崩溃；即**坏东西把好东西挤出市场**。发生在**签约前**。标准教科书叙述见曼昆《经济学原理》。【P0】 | S8、S30 |
| F-043 | 道德风险（moral hazard）：交易达成**后**，因风险由对方承担，一方的行为变得不那么谨慎（如全额保险后停车更随意）；是**委托—代理问题**的核心，与逆向选择的区别在于**时点**（签约后 vs 签约前）。 | S30 |
| F-044 | 信号与筛选：**信号**（斯彭斯 1973）指信息优势方以高成本、难伪造的行动自证（如名校文凭）；**筛选**指信息劣势方设计机制试出真相（如不同免赔额）。阿克洛夫、斯彭斯、斯蒂格利茨因对信息不对称市场的分析**共获 2001 年诺贝尔经济学奖**。【P0】 | S8、S9、S10、S30 |
| F-045 | 信贷配给（斯蒂格利茨与韦斯 1981）：银行**不**通过提高利率出清信贷市场——高利率会赶走低风险借款人（逆向选择）、激励高风险项目（道德风险）；银行改把利率定在出清价以下、采用**配给**。说明**价格同时承担配置与筛选功能**，冲突时价格失灵。 | S10 |
| F-046 | 市场势力与政府失灵：垄断/寡头使产量低于竞争水平、价格高于边际成本，产生**无谓损失**；但干预本身也会失灵（监管者信息不足、可能被俘获、可能好心办坏事）。理性的立场是比较**市场失灵成本**与**政府失灵成本**，取相对更小者。 | S30 |

## 六、有效市场假说：三种形态（对应 [05 章](concepts/05-emh-three-forms.md)）

| 编号 | 事实内容 | 信源 |
|------|---------|------|
| F-047 | 尤金·法玛 1970 年发表《有效资本市场：理论与实证研究综述》（*Journal of Finance*），正式提出**有效市场假说（EMH）**；法玛获 2013 年诺贝尔经济学奖。【P0】 | S16 |
| F-048 | EMH 的定义：价格**完全反映所有可得信息**；其机制基础是套利与竞争把信息「压进」价格——是一条**均衡命题**（不是因为人聪明，而是逐利行为使然）。 | S16 |
| F-049 | 弱式有效（weak form）：价格已反映历史价格与成交量信息 → **技术分析无法持续获利**；检验方式为收益可预测性（序列相关）检验。 | S16 |
| F-050 | 半强式有效（semi-strong form）：价格已反映所有**公开**信息（财报、公告、宏观数据）→ **基本面分析也难持续跑赢**；检验方式为事件研究。 | S16 |
| F-051 | 强式有效（strong form）：价格已反映**所有**信息，包括内幕信息 → 连掌握内幕者也无法获超额收益；检验方式为内幕交易者/专业机构收益。 | S16 |
| F-052 | 三种形态的嵌套关系：**强式 ⇒ 半强式 ⇒ 弱式**，层层包含；反之不成立（弱式有效可与半强式无效并存）。 | S16 |
| F-053 | 联合假设问题（joint hypothesis problem）：检验 EMH 必须**先有一个定价模型**；一旦发现价格偏离模型，**无法区分**是「市场无效」还是「模型错了」。故 EMH **从不是单独可检验的**，这是其争论长期难有终判的方法论根源。【P0】 | S16 |
| F-054 | 现实的判断：**弱式基本成立、半强式大体成立但有不少反例、强式基本不成立**（信息不对称与禁止内幕交易的存在说明内幕有利可图）。**「有效」指信息反映效率，不意味「价格正确」**——若所有参与者都错了，价格反映的是**错误的共识**，泡沫可在有效市场中形成。【P0】 | S16、S24 |

## 七、随机游走与理性预期（对应 [06 章](concepts/06-random-walk-and-rational-expectations.md)）

| 编号 | 事实内容 | 信源 |
|------|---------|------|
| F-055 | 巴舍利耶 1900 年博士论文《投机理论》首次用随机过程（布朗运动）描述资产价格，提出涨跌方向不可预测；该论文长期被埋没，后被公认为**数理金融开山之作**。 | S12 |
| F-056 | 肯德尔 1953 年分析英国股价指数序列，本欲寻找周期规律，却发现股价序列**近似随机数字、无可预测模式**。 | S13 |
| F-057 | 萨缪尔森 1965 年给出理论证明：在竞争性市场中，若价格**充分反映**可得信息，则价格变动必然**不可预测**——因为「可预测」本身就是一条尚未被反映的信息，会被套利立刻用掉。**「信息有效」与「可预测的获利机会」在逻辑上不能同时成立。**【P0】 | S14 |
| F-058 | 随机游走（random walk）：下一期价格变动**与过去路径无关**，期望增量近似为零。 | S14 |
| F-059 | 鞅（martingale）：$E[P_{t+1}\mid I_t]=P_t$，即在已知当前信息的条件下，下一期价格的期望值等于当前价格——「用今天的信息无法系统性预测明天的涨跌方向」。 | S14 |
| F-060 | 新信息不可预测：价格变动由新信息驱动，而新信息的本质是「意外」；可被预测的部分早已反映进价格，故价格变动（对意外的反应）不可预测。 | S14 |
| F-061 | 理性预期（穆斯 1961）：个体的主观预期**平均而言**与真实经济模型（客观概率分布）一致，**不会系统性地犯错**；它不要求「人人理性」，只要求个体的错误**不构成可反复利用的获利机会**。【P0】 | S15 |
| F-062 | CAPM（夏普 1964 年前后）给出风险与预期收益的均衡关系（承担更多系统性风险应获更高预期收益）；与 EMH 合起来构成「风险—收益—信息」自洽世界观。马尔基尔 1973 年《漫步华尔街》把随机游走 + 指数投资 + 低成本理念普及给大众。CAPM 本身受大量质疑，其动摇会连带影响「用 CAPM 检验 EMH」的结论。 | S17、S21 |

## 八、证据之争：支持与挑战（对应 [07 章](concepts/07-evidence-for-and-against.md)）

| 编号 | 事实内容 | 信源 |
|------|---------|------|
| F-063 | 事件研究法（event study）由法玛、费雪、詹森、罗尔 1969 年在研究股票拆分的论文中系统化：以事件日为「第 0 天」，考察**事件窗口**内相对基准模型的**超额收益**；是最直接检验**半强式有效**的方法。 | S18 |
| F-064 | 事件研究证据：早期研究多显示价格在公告日**迅速跳到新水平、之后无系统性漂移**，支持半强式有效；但**公告后漂移（PEAD，反应不足）** 等现象构成挑战，且其可获利性需扣除交易成本、风险补偿与样本外稳定性。 | S18 |
| F-065 | SPIVA（S&P Indices Versus Active，标普道琼斯指数公司）：以 15 年左右长周期看，**约九成**美国大盘主动基金未跑赢 S&P 500；短周期跑赢比例波动大，拉长后持续走低；更关键是**业绩持续性弱**（上一期赢家下一期大概率不是）。【P0】 | S28 |
| F-066 | 规模与价值异象（法玛与弗伦奇 1993）：**小市值**股票与**高账面市值比（价值股）** 长期取得超额收益，构成三因子模型（市场、规模、价值）的基础。**争议在解释**：EMH 一方视为风险补偿，挑战方视为定价错误。【P0】 | S19 |
| F-067 | 动量异象（杰加迪什与蒂特曼 1993）：过去 3–12 个月表现好的股票在接下来数月**倾向继续跑赢**，是**最难用风险补偿解释**的异象之一；拉长到 3–5 年尺度则存在**长期反转**（前期猛涨者表现最差，与动量尺度不同、方向相反）。**2013 年诺贝尔经济学奖同时颁给观点对立的法玛（市场有效）与席勒（市场会错）**。方法论警戒：哈维、刘、朱 2016 年提出**数据挖掘/多重检验**问题，新因子的 t 值门槛应远高于 2。【P0】 | S20、S24、S29、S30 |

## 九、行为金融与适应性市场（对应 [08 章](concepts/08-behavioral-finance-and-amh.md)）

| 编号 | 事实内容 | 信源 |
|------|---------|------|
| F-068 | 适应性市场假说（AMH，罗闻全 2004）：**效率不是「有或没有」的静态属性，而是随竞争与参与者演化的动态状态**。市场像生态系统——赚到钱的策略被模仿、被套利掉（效率上升），环境变化又产生新机会（效率下降）；因此**效率有周期**。它把「EMH 对不对」的二元问题，变成「在什么条件下、什么时期、什么市场，效率有多高」的可分析问题。【P0】 | S27 |
| F-069 | 前景理论（卡尼曼与特沃斯基 1979，*Econometrica*）：损失带来的痛苦约为等额收益快乐的 **2–2.5 倍**（损失厌恶）、参照点依赖、概率权重扭曲；卡尼曼获 2002 年诺贝尔经济学奖（特沃斯基于 1996 年去世未及授奖）。这是「理性人」假设首次被实验系统性撼动。【P0】 | S22 |
| F-070 | 系统性认知偏差清单：**过度自信**（高估判断与信息优势、导致过度交易）、**锚定效应**（被买入价等无关数字锚定）、**羊群效应**（追涨杀跌）、**处置效应**（过早卖出盈利股、长期套牢亏损股）、**近因偏差**（用最近行情外推未来）、**心理账户**（把不同来源的钱区别对待）。这些是**人类认知的默认设置**，专业投资者同样受影响。 | S22、S25 |
| F-071 | 席勒过度波动实证（1981，*AER*）：股价波动幅度**远超**未来股息真实变化所能解释的程度，价格变动含大量与基本面无关的「情绪」成分。《非理性繁荣》（2000）进一步分析股市与房地产的情绪周期，并提出 **CAPE（周期调整市盈率）**；席勒 2013 年获诺贝尔经济学奖。【P0】 | S23、S24 |
| F-072 | 塞勒 2017 年获诺贝尔经济学奖：研究**心理账户、禀赋效应、自我控制问题**，并用于政策设计——**「助推」（nudge）**：不禁止选择，而是设计**选择架构**引导更好决策（如默认加入养老金计划）。标志行为经济学从「异端」变「主流」。【P0】 | S25 |
| F-073 | 有限套利（施莱弗与维什尼 1997）：错误定价可能**先变得更错**（套利者账面亏损、被迫平仓）；套利者用别人的钱、客户可能在最坏时点赎回；很多市场**限制卖空**。因此**「价格错了」不等于「你能赚钱」**——这是格罗斯曼—斯蒂格利茨悖论的现实版本。 | S26 |

## 十、对我们的含义：投资、政策与治理（对应 [09 章](concepts/09-implications.md)）

| 编号 | 事实内容 | 信源 |
|------|---------|------|
| F-074 | 主动/被动的零和结构：**全体投资者合起来就是市场**，主动者相互交易是**零和**的（有人跑赢必有人跑输），而主动管理还要扣除更高的费用与交易成本，故**主动投资整体必然落后于市场平均**——这是一个**算术结论**，不是「努力不够」。少数人长期跑赢是可能的，但**事前识别**极难且业绩持续性弱。 | S28、S16 |
| F-075 | 费用的确定性：收益不确定，但**费用确定发生**；长期复利下费率差异会显著放大（回顾 [05 章](concepts/05-emh-three-forms.md) 的复利侵蚀逻辑）。**降低成本是普通投资者唯一确定能改善结果的动作**——这是指数基金与被动投资的理论落脚点。【P0】 | S21、S28 |
| F-076 | 信息披露与反欺诈的经济学理由：**强制信息披露**直接针对信息不对称（让公开信息可信、可比、及时，降低全体投资者的信息成本）；**禁止内幕交易**针对信息优势的不公平利用（维护信任与流动性）；**反欺诈与注册制**针对逆向选择的极端形式（避免劣币驱逐良币）。这些规则的本质是**用制度替代缺失的「零交易成本」**。 | S8、S30 |
| F-077 | 效率边界对政策设计的启示：目标不应是「让价格反映一切」（逻辑上不可达），而是**降低信息与交易成本、让效率靠近上限**；干预须在**市场失灵与政府失灵**之间比较，且**干预收益必须大于其扭曲成本**。 | S11、S30 |
| F-078 | 个人参与的成本与纪律原则：承认「难以持续战胜市场」，据此选择**低成本、分散、长期、有纪律**的参与方式；**战略性被动要求理解零和结构与费用机制**，而非无知地跟风。本知识包为通识教育材料，不含任何具体产品、买卖时点或收益承诺。 | S21、S28 |

| 项目 | 处理方式 | 原因 |
|---|---|---|
| 任何具体基金/股票/产品的收益率 | 不收录 | 时效敏感、构成产品推荐 |
