# 行为金融与适应性市场

## 是什么

EMH 假设人是「不**系统性**犯错」的；**行为金融（behavioral finance）** 用心理学与实验证据反驳：**人会系统性地犯错，且这些错误会留在价格里**。这一章讲行为金融的核心证据，以及罗闻全给出的**调和框架**——适应性市场假说。

## 前景理论：人不是「理性计算器」

丹尼尔·卡尼曼与阿莫斯·特沃斯基 1979 年发表**前景理论（prospect theory）**，用实验证明人在不确定下的决策**系统性偏离理性**（F-069）：

- **损失厌恶**：同样金额，损失的痛苦约为收益快乐的 **2–2.5 倍**——这解释了为什么人「套牢不卖」；
- **参照点依赖**：人评估的是「相对于某个参照点」的盈亏，而非绝对财富；
- **概率权重扭曲**：对小概率（如中奖）过度加权，对中大概率低估。

卡尼曼因此获 2002 年诺贝尔经济学奖（特沃斯基于 1996 年去世，未及授奖）。这是**「理性人」假设第一次被实验系统性地撼动**。

## 系统性偏差清单

行为金融的实证积累出一批**可重复**的偏差（F-070），注意它们的关键词是「**系统性**」——不是随机噪声，而是**方向一致的错误**：

| 偏差 | 表现 |
|---|---|
| **过度自信** | 高估自己的判断与信息优势，导致过度交易 |
| **锚定效应** | 被买入价等无关数字锚定，估值偏离基本面 |
| **羊群效应** | 追涨杀跌的群体模仿，放大波动 |
| **处置效应** | 过早卖出盈利股、长期套牢亏损股（「截断利润、让亏损奔跑」） |
| **近因偏差** | 用最近行情外推未来 |
| **心理账户** | 把不同来源的钱区别对待，违背整体最优 |

这些偏差**不是个别「笨人」的毛病**，而是**人类认知的默认设置**——专业投资者同样受其影响，只是程度不同。

## 席勒的实证：价格波动超过基本面所能解释

罗伯特·席勒 1981 年发表《股价是否波动过度？》，用实证指出（F-071）：

> **股价的波动幅度，远超「未来股息真实变化」所能解释的程度**——也就是说，价格的变动里含有大量**与基本面无关的「情绪」成分**。

他后来在《非理性繁荣》（2000）中进一步分析股市与房地产的情绪周期，并提出 **CAPE（周期调整市盈率）** 作为长期估值的观察指标（F-071）。席勒 2013 年与法玛同获诺贝尔经济学奖（见 [07 章](07-evidence-for-and-against.md) F-067）。

## 塞勒与「助推」

理查德·塞勒 2017 年获诺贝尔经济学奖，因其**在行为经济学上的贡献**（F-072）：他研究**心理账户、禀赋效应、自我控制问题**，并把这些洞见用于政策设计——**「助推」（nudge）**：不禁止选择，而是设计选择架构，引导人做出更好的决策（如默认加入养老金计划）。塞勒的获奖标志着**行为金融从「异端」变成「主流」**。

## 关键问题：为什么错误定价不被套利抹平？

这是行为金融必须回答、也最容易忽视的一环（F-073）。若价格错了，理性套利者为什么不纠正它、顺便赚钱？

答案是**有限套利（limits to arbitrage）**（施莱弗与维什尼 1997）：

1. **套利有风险**：错误定价可能**先变得更错**，套利者账面亏损、被迫平仓（「市场保持非理性的时间，可能比你保持不破产的时间更长」）；
2. **资金有限**：套利者用别人的钱，客户在亏损时赎回，逼他在最坏时点退出；
3. **做空受限**：很多市场禁止或限制卖空，无法做空高估的资产。

因此，**「价格错了」不等于「你能赚钱」**——这正是 [03 章](03-arbitrage-and-equilibrium.md) 格罗斯曼—斯蒂格利茨悖论的现实版本。

## 适应性市场假说（AMH）：把两面统一起来

罗闻全 2004 年提出**适应性市场假说（Adaptive Markets Hypothesis, AMH）**（F-068），试图调和 EMH 与行为金融：

> **效率不是「有或没有」的静态属性，而是「随竞争与参与者演化」的动态状态。**

AMH 的要点（F-068）：

- 市场像**生态系统**：参与者用不同策略竞争，赚到钱的策略被模仿、被套利掉（效率上升），环境变化又产生新机会（效率下降）；
- 因此**效率有周期**：有时接近有效（赚钱难），有时明显无效（机会多）——**取决于竞争程度与「机会大小 vs 利用成本」**；
- 它直接继承 [03 章](03-arbitrage-and-equilibrium.md) 的「市场是自适应系统」直觉，也解释了为什么**同一市场在不同时期表现出的有效性不同**。

```mermaid
flowchart LR
    O["出现获利机会"] --> P["部分参与者发现并获利"]
    P --> C["策略被模仿、资金涌入"]
    C --> E["机会被抹平、效率上升"]
    E --> S["环境变化/新信息"]
    S --> O
```

> **AMH 为什么重要**：它让「EMH 对不对」这个二元问题，变成「**在什么条件下、什么时期、什么市场，效率有多高**」这一**可分析的问题**（F-068）。

## 小结

- **前景理论（卡尼曼-特沃斯基 1979）**：损失厌恶等系统性偏差，撼动理性人假设；
- **系统性偏差清单**：过度自信、锚定、羊群、处置效应、近因、心理账户；
- **席勒（1981）**：价格波动超基本面所能解释，含大量情绪成分；《非理性繁荣》与 CAPE；
- **塞勒（2017 诺奖）**：心理账户、禀赋效应、助推——行为经济学主流化；
- **有限套利（施莱弗-维什尼 1997）**：错误定价≠可获利，套利有风险、有资金约束、有做空限制；
- **AMH（罗闻全 2004）**：效率是随竞争演化的动态状态，把 EMH 与行为金融统一为「何时更有效」的问题。

## 常见坑

- **把行为金融读成「EMH 被推翻」**：它推翻的是「**完全**理性」这个**强假设**，而非「套利会压缩获利机会」这一机制本身（F-068、F-070）。
- **以为「发现有偏差」就能套利**：有限套利说明**认知偏差与获利机会之间存在鸿沟**（F-073）。
- **把 AMH 当「EMH 的别名」**：AMH 的核心恰恰是**效率会随时间与条件变化**，这与「效率恒定」截然不同（F-068）。
- **把偏差当「别人会犯、我不会」**：偏差是**人类默认设置**，专业者与业余者都会中招（F-070）。
