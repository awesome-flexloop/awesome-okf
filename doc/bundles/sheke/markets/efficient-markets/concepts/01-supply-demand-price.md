# 供给、需求与价格形成

## 是什么

价格不是谁「定」的，而是在供给与需求的相互作用中「涌现」出来的。这一章给出价格形成的最小模型：**两条曲线决定一个均衡点**。

## 两条定律

- **需求定律（law of demand）**：其他条件不变时，价格上升，需求量下降（F-009）。
- **供给定律（law of supply）**：其他条件不变时，价格上升，供给量上升（F-009）。

两条曲线的交点决定**均衡价格**与**均衡数量**：在此价格下，买方想买的量恰好等于卖方想卖的量，市场「出清」（clears）（F-010）。

```
价格
 ↑        供给 S
 |       ／
 |     ／
 |   ✕  ← 均衡点 (P*, Q*)
 |  ／ ＼
 | ／     ＼  需求 D
 └──────────────→ 数量
       Q*
```

## 关键区分：曲线「移动」vs 沿曲线「移动」

这是初学者最常混的一对概念（F-011）：

| | 触发原因 | 图形表现 |
|---|---|---|
| **沿曲线移动** | 价格自身变化 | 在同一条曲线上滑动 |
| **曲线整体移动** | 收入、偏好、技术、投入成本、预期、相关品价格等**外生因素** | 整条曲线左移或右移 |

例如：咖啡豆价格上涨 → 咖啡的**供给曲线左移**（每个价格下的供给量都减少）→ 新的均衡价格更高、数量更少。这个推演会在 [示例 01](../examples/01-supply-demand-shock.md) 中完整展开。

## 价格弹性：为什么涨价不总是增收

**需求价格弹性 = 需求量变动百分比 ÷ 价格变动百分比**（F-012）：

- 弹性 > 1（富有弹性）：涨价使总收益**下降**（量跌得比价涨得多）；
- 弹性 < 1（缺乏弹性）：涨价使总收益**上升**（刚需品如食盐）；
- 弹性 = 1：总收益不变（单位弹性）。

弹性是「价格机制如何影响各方」的定量钥匙：它决定了税收由谁承担、涨价对谁有利、管制价格会造成多大的短缺或过剩。

## 从局部均衡到一般均衡

- **阿尔弗雷德·马歇尔《经济学原理》（1890）**系统化了供给需求与均衡分析方法，奠定了「新古典经济学」的分析框架，被称为局部均衡分析（F-013）。
- **莱昂·瓦尔拉斯 1874 年《纯粹经济学要义》**把视野扩展到**一般均衡（general equilibrium）**：不是单个市场出清，而是**所有市场同时出清**的价格向量。他用「试探调整」（tâtonnement）——一个假想的拍卖人不断喊价、根据超额需求调整价格——来描述价格如何被调整到均衡（F-014）。

一般均衡的思想极其重要，因为它把「市场」从一个一个的孤立图景，提升为一个**相互联动的价格系统**——这也是 [02 价格发现与信息](02-price-discovery-and-information.md) 里哈耶克要处理的问题。

## 市场为什么「能自己纠偏」

均衡具有**自我修正倾向**（F-015）：

- 价格**高于**均衡价 → 出现**过剩**（供大于求）→ 卖方竞相降价 → 价格回落；
- 价格**低于**均衡价 → 出现**短缺**（供不应求）→ 买方竞相加价 → 价格回升。

这就是「市场机制」的第一层含义：**不需要中央指挥，价格自身的涨落就把供需拉回均衡**。但要注意，这个倾向是有条件的：

- 当供给对价格的反应存在**时滞**（如农产品要一季生长），价格与产量可能围绕均衡**震荡甚至发散**——这就是**蛛网模型（cobweb model）**（F-016）；
- 当市场被管制、垄断或信息不对称扭曲时，自我修正可能失效（见 [04 市场失灵](04-market-failure.md)）。

## 价格的双重功能

价格同时承担两种功能（F-017）：

1. **信息功能**——价格是稀缺程度的信号（贵＝相对稀缺），把「该省着用」的信息告诉所有人；
2. **激励功能**——价格引导生产与消费（贵＝有利可图，吸引供给；贵＝抑制需求）。

广告、品牌与口碑则部分承担「质量信号」的作用，缓解买卖双方的信息落差（F-018，详见 [04 市场失灵](04-market-failure.md) 的信号理论）。

## 小结

- 价格 = 供给与需求交互的产物，均衡点是双方意愿的一致处；
- 会区分「曲线移动」与「沿曲线移动」，才能正确做供需分析；
- 弹性决定了价格变动对总收益与各方负担的影响；
- 均衡有自我修正倾向，但有时滞（蛛网）与失灵（管制/垄断/信息）的边界。

## 常见坑

- **把「需求增加」与「需求量增加」混用**：前者是曲线右移（外生因素），后者是沿曲线移动（价格变化）（F-011）。
- **以为涨价一定增收**：取决于弹性（F-012）。
- **把均衡当成「必然到达」**：均衡是趋势性吸引点，路径上可能有震荡（蛛网）甚至长期偏离（F-016）。
