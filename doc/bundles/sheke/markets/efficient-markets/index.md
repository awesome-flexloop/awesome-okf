# 市场机制与有效市场通识知识包

本知识包是一份「市场是怎么运转的、它到底有多有效」的通识地图：上半部用经济学的教科书结论讲清**价格如何形成、信息如何进入价格、市场在什么情况下失灵**；下半部专门讲**有效市场假说（EMH）**——它主张什么、凭什么成立、有哪些反例、以及它对投资与政策意味着什么。

不荐股、不预测市场、不承诺收益。全部事实采用双信源体系——**机制与理论源头**挂经济学经典教科书与奠基论文（斯密、马歇尔、瓦尔拉斯、哈耶克、科斯、阿克洛夫、格罗斯曼—斯蒂格利茨等），**证据与数据**挂金融学术文献与数据源（法玛、法玛—弗伦奇、席勒、罗闻全、SPIVA 报告、诺贝尔奖官方记录），共 78 条事实、30 个信源。

> 阅读提示：**有效市场假说是有争议的假说，不是定律。** 本包把支持方（法玛、随机游走、SPIVA 长期数据）与反对方（席勒、行为金融、异象、适应性市场）的证据并列呈现，不替读者下结论。**本包为通识教育材料，不构成投资建议、法律意见或政策建议。**
