# 经济学经典教科书与金融学术信源索引

> 本包事实采用双信源体系：**机制与理论**以经济学经典教科书与奠基性学术论文为准（S1–S21）；**证据与数据**以金融学术论文、行业统计报告与诺贝尔奖官方记录为准（S22–S30）。论文出版信息以期刊卷期为准；译本版本众多，下举常见中文版。所有理论均有学术争议，登记的是「谁提出、何年提出、原文主张什么」，不把假说写成定律。

## 三、核验方式

- **诺贝尔奖记录**：nobelprize.org 检索 Akerlof / Spence / Stiglitz（2001）、Kahneman（2002）、Fama / Shiller / Hansen（2013）、Thaler（2017）。
- **学术论文**：以期刊卷期页码为准，可在 JSTOR、各期刊官网或 Google Scholar 检索原文标题核验；引用时标注卷期。
- **行业统计**：SPIVA 报告可在标普道琼斯指数公司官网（spglobal.com / spindices.com）按年下载，注意区分不同市场与不同统计期。
- **教科书叙述**：供需模型、外部性、公共品、逆向选择等属标准教科书内容，以主流经济学教材交叉核对。

## 四、使用建议

1. **机制先于假说**：先读 S1–S15（机制与理论奠基）建立「市场如何运转」的坐标系，再读 S16–S27（EMH 及其争论）。
2. **理论、证据分开读**：EMH、CAPM、理性预期是**描述市场的理论模型**，不是操作指令；SPIVA、异象是**证据**，两者不可混为一谈。
3. **争议必须两面并读**：法玛（S16）与席勒（S23、S24）的观点在同一年获诺奖（2013），任何只引用一方的读法都是选择性引用。
4. **警惕以经典为名的营销**：经典著作与学术结论被大量「荐股」「代客理财」内容引用背书；凡承诺收益、催促开户、拉群荐股的，均不属于本知识体系（见 [facts.md](../facts.md)）。
