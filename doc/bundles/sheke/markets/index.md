# 📈 市场与有效市场

本分组收录「市场如何运转」与「市场是否有效」主题的知识包。它回答一组彼此咬合的问题：**价格是怎么被定出来的、市场靠什么把分散的信息聚进价格、市场在什么情况下会失灵，以及「有效市场假说」到底说了什么、有什么证据支持与反对、对投资与政策意味着什么。**

## 收录原则

- **假说与定律分开**：有效市场假说（EMH）是**有学术争议的假说**，不是「价格永远正确」的定律。凡有争议处，一律按「谁提出、何年提出、原文主张什么」客观登记，并把支持与反对两方证据并列呈现（如法玛与席勒同年获诺奖这一事实本身即是张力的注脚），**禁止把假说写成结论、把模型写成现实**。
- **机制层与假说层分层**：上半部（概念 00–04）讲市场机制的教科书结论——供需、价格发现、套利、市场失灵；下半部（概念 05–09）讲 EMH 及其争议与含义。机制层是理解假说层的前提，二者不混讲。
- **信源双体系**：机制层与理论源头挂经济学经典教科书与奠基论文（斯密、马歇尔、瓦尔泽、哈耶克、科斯、阿克洛夫、格罗斯曼—斯蒂格利茨等），证据层挂金融学术文献与数据源（法玛、法玛—弗伦奇、席勒、罗闻全、SPIVA 报告、诺奖官方记录）。
- **不荐不评**：不推荐任何产品、平台或策略，不预测价格或指数点位，不评价投资价值；全部分析服务于「理解机制」与「理解争议」，不构成投资建议、法律意见或政策建议。
- **时效分层**：教科书层面的机制结论时效稳定；数据类证据（SPIVA 等）时效敏感，`stale_after` 统一设为 2028-09-30，引用时以数据发布机构最新一期为准。

**收录边界**：本组承接「市场机制」与「市场有效性」的一般理论；金融体系、货币、利率与监管的完整框架归 [金融经济与个人理财](../finance/index.md) 组，个人投资实操与指数基金落地归该组的 individual 束，数字资产与数据要素归 [数字经济与数字资产](../digital-economy/index.md) 组。
