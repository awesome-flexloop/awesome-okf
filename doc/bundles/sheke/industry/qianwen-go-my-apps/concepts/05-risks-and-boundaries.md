# 05 · 风险与边界

> 本页只登记**可识别的风险与证据边界**，不做产品好坏判断。每条风险都给出触发信号、影响与缓解动作；缓解动作均为可逆的通用做法。

## 一、九类风险

| # | 风险 | 触发信号 | 影响 | 缓解 |
|---|---|---|---|---|
| R1 | **厂商口径被当成实测** | 媒体标题与公告措辞高度一致；无第三方评测 | 高估能力、做出错误选型 | 引用时标注「厂商自述/未实测」（C4~C9、C18） |
| R2 | **邀测不确定性** | 需排队申请；无开放时间表（F-034~F-036） | 功能随时变更、限额或停服 | 只做非关键试点，保留替代方案（I4） |
| R3 | **计费关系不明** | 公告不谈价格；Meoo 有独立价目（F-046、F-047） | 长期成本不可预估 | 在申请时书面确认千问Go 侧收费与额度（G8） |
| R4 | **数据留存与导出不明** | 只说「持续保存」；免费版配额限时免费、代码导出需付费档（F-046、F-047） | 迁移/退出成本高，数据可能丢失 | 先验证导出；不把唯一副本放在平台（G10） |
| R5 | **个人数据授权边界** | 云端 Pro 可读淘宝/高德/大麦/夸克网盘（单源，F-030） | 隐私暴露、授权范围过大 | 最小授权、逐项确认、可撤回（F-033；G3、G5） |
| R6 | **分享链接可见性** | 公告只说「分享给朋友」（F-010） | 链接被转发导致数据泄露 | 确认是否支持密码/有效期/白名单；敏感数据不上传（G5） |
| R7 | **内容与合规责任** | 生成内容、用户提交数据、儿童场景（F-024~F-026） | 侵权、违规内容、未成年人信息风险 | 建立人工复核；儿童场景需监护人同意与最小化收集 |
| R8 | **截图造成预期偏差** | 16 张截图经挑选，无样例链接（F-013、G7） | 实际效果低于预期 | 以自己的一周验证为准，不以截图为准 |
| R9 | **抽奖规则缺失** | 抽 3 位送 500 元礼品卡，无开奖时间/规则/地区（F-037、G6） | 参与成本与预期收益不匹配 | 不把抽奖当作使用动机；如需参与，保留公告截图 |

## 二、风险分层

```
证据风险（最容易被忽略）
  R1 厂商口径 → R8 截图偏差
        │
        ▼
可用性风险
  R2 邀测 → R3 计费 → R4 数据留存/导出
        │
        ▼
合规与隐私风险
  R5 个人数据 → R6 分享权限 → R7 内容/儿童
        │
        ▼
活动风险
  R9 抽奖
```

**为什么把证据风险放最上层**：本包核验发现，媒体全部为同稿转述（C18），没有任何独立实测；如果读者把「公告 + 转载」误当成「多方验证」，后续所有判断都会建立在未经验证的前提上。

## 三、本知识包的边界

| 边界 | 说明 |
|---|---|
| **不是评测** | 未取得邀测资格，未创建应用，未验证生成质量、持久化、分享或云端 Pro（C4~C9） |
| **不是教程** | 公告无步骤、提示词、入口链接与价格（F-007、G2），本包不补造操作流程 |
| **没有 `examples/`** | 操作可复现性两问均不满足（见[知识地图](../references/knowledge-map.md)） |
| **不构成推荐** | 不推荐购买、申请或放弃；不构成投资、采购、法律或安全建议 |
| **不替代官方文档** | 计费与配额以秒悟官方文档为准（S5）；产品能力以千问App 内实际界面为准 |
| **时效有限** | `stale_after: 2026-12-31`；产品处于邀测，信息可能快速变化 |

## 四、不可用范围

本包内容**不得**用于：

- 证明「千问Go 应用已可稳定商用」；
- 证明「免费」「无限量」「永久保存」；
- 作为向客户承诺交付周期、成本或 SLA 的依据；
- 作为与低代码平台、外包开发、自建全栈的性价比对比结论；
- 作为儿童教育、医疗、金融等强合规场景的可行性依据。

## 六、一句话总结

**这是一个「入口 + 平台 + 邀测」的产品事件，不是一个已被验证的生产力结论。** 可以用它理解行业方向、设计自己的小规模验证；不能用它替代实测、合同与合规评估。
