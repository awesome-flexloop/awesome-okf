# 定制图像服务：从需求到验收

作者举头像、壁纸、卡通照、情侣与亲子头像为起步项目，并扩展到 Logo、产品图和出版配图（F-006～F-010）。这些是作者举例，不是审核通过或行业均价证明；单价、工时及平台订单预算全部单源（F-007、F-012、F-017）。

## 卖的是确定的结果

执行者建议先把“帮忙出一张好看的图”改写成可确认的交付约定。下面是待验证的需求卡，不是现成平台合同。

| 栏目 | 需明确的信息 |
|---|---|
| 客户与用途 | 谁使用，私人头像还是商业宣传，在哪里发布 |
| 输入材料 | 照片、角色、商标、文案来源及授权，是否允许上传外部工具 |
| 交付格式 | 尺寸、文件类型、背景处理、是否含可编辑文件 |
| 风格与禁项 | 可用参考、不应出现的元素、不得模仿或盗用的内容 |
| 验收 | 相似程度、文字准确、细节、版式与用途适配由谁确认 |
| 变更与售后 | 修改范围、额外需求如何处理、退款与完成时间 |
| 展示与留存 | 能否放作品集、何时公开、输入文件如何删除 |

客户同意作图不当然等于同意上传照片给任何工具，更不等于允许公开展示。上传与留存先按[授权合规](06-rights-and-compliance.md)核对；无法明确权利和工具处理范围时，不接收或上传该输入。

## 交付判断顺序

1. 复述用途和需求，确认对方需要的不是单纯“漂亮”，而是可用结果。
2. 核对输入权利、平台与工具限制，未知事项先解决。
3. 以合法材料验证能否达到约定，不承诺作者所说的十分钟。
4. 完成可视细节检查与文件检查，按约定让客户验收。
5. 记录修改与总工时，再判断相同类型服务是否值得继续。

这是执行者设计的实践顺序，没有本轮真实接单试验。Logo 涉及商标使用，产品图涉及真实性，出版配图涉及发行用途，不能只按头像经验升价或扩大承诺。

## 平台接单的前提

作者推荐米画师、涂鸦王国、画师联盟（F-016）。已读取米画师关于商用与授权约定的说明（F-046），也找到 huashilm 自称官网的企业服务页（F-048），但没有因此确认课程所指渠道的 AI 投稿权限；涂鸦旧链接已改版，政策未核验。

这些平台只作为调查候选，不是“可直接上传 AI 图”的操作推荐。先确认当前准入、项目规则、原创要求及客户是否接受 AI 辅助，再讨论报价；预算几百至几千不能当真实成交或净收入（F-017）。本页与[素材产品](02-reusable-assets.md)的区别在于：定制先有明确客户，素材先有可复用产品，风险账不能混算。
