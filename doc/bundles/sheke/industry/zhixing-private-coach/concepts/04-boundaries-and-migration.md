# 边界、反模式与迁移

## 一、适用边界

| 维度 | 适用 | 不适用 |
|---|---|---|
| 交付形态 | 月度订阅制 1v1 深度辅导（一周一次 × 一小时） | 一次性大课、训练营等批量交付 |
| 时间投入 | 能保证固定时段的人 | 无法固定时间的兼职状态（F-025） |
| 动机 | 想「成就一个人，我还收钱」（F-055） | 把私教想象成被动收入（前四次质量决定复购，F-043、F-059） |
| 能力状态 | 有一技之长即可启动，第一个客户可对赌免费（F-036、F-061） | 完全没有可交付技能的人（先练技能再谈私教） |
| 证据强度 | 单一团队内部培训口径，用于学习链路设计 | 作为普适商业定律或收益承诺使用 |

## 二、跨场景迁移

> 以下迁移场景为本包整理者的推演，会上未涉及；其作用是展示核心结构的可移植边界，不是会上口径。

这套链路的核心结构是「**订阅制深辅导 = 固定节奏 + 前置期待管理 + 结果负责**」。换到相邻场景仍然成立：

- **企业内导师制**：月度 1v1 的四个动作（固定时间、前置谈期待与底线、每日固定动作共创、支持不了时升级求助）可以直接搬进新员工辅导，物谈对应「试用期目标对齐」。
- **健身私教/饮食教练**：F-081 的「腰疼程度」类比本就是健康场景——需求力度决定客单价与成交路径，一般需求卖课程、强需求卖私教。
- **课程助教/班主任**：「经常关心固定时间有没有在做」正是助教促活的标准动作（F-029、F-030）。

反向提醒：涉及分润与价格统一的纪律（F-040~F-052）依赖平台/团队语境，单人无渠道场景下只剩「私接单全归自己」一条通道（F-051），不构成完整方法论。

## 三、总体反模式清单

1. **先有能力才收钱**——错过上手机会，能力永远在准备中（反例见 F-061）。
2. **定价不分钱**——永远自己干销售，没有被动接单（F-042）。
3. **双轨不同价**——渠道信任一次性断裂（F-045、F-052）。
4. **不作物谈**——最坏结果没对齐，交付风险留在暗处（F-028）。
5. **包办每日动作**——对方没有为自己做事的体感（F-039）。
6. **死磕不求援**——透支交付质量，成功案例目标落空（F-031、F-032）。
7. **需求不够硬转私教**——双方都累，还占掉服务强需求用户的带宽（F-080）。
8. **只练话术不练提问**——跳段练习，成交力度上不去（F-084~F-086）。

## 四、总体检验标准（做完怎么知道做对了）

- **定位**：一句话说清服务人群 + 具体问题，且在擅长范围内（F-021、F-022）。
- **定价**：分润倒推成立，全渠道价格一致（F-050、F-052）。
- **交付**：五动作清单本月全部有记录（见[02 交付五动作](02-delivery-standards.md)第八节）。
- **引流**：前端有可体验的单次 1v1 与限量供给（F-068）。
- **销售**：能按三段进阶指出自己当前的阶段与下一段练法（F-085）。
- **结果**：本月产生一个可讲述的成功案例——这是整套链路的最终验收物（F-010~F-012）。
