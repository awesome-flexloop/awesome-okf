# 第一个私教客户启动跑表

用法：适合「还没有力量收钱、先找一个人免费/对赌跑流程」的启动路径（F-036），也适用于第一个付费客户。每条对应会议事实编号。

## 第 0 步：路径确认（当天）

- [ ] 明确二选一：能收钱就如实收钱 / 不能收钱就找一个人免费（或对赌）服务，先上手（F-036、F-062）
- [ ] 如选对赌：写明对赌条款（「对赌」指以结果赌收费——约定什么结果算什么成、成则收费不成则不收或退费；道久第一个年度私教即采此形式，F-061）

## 第 4 步：月末复盘与复购谈话

- [ ] 对照物谈的「理想结果」盘点本月体感：从知到行的证据是 ＿＿＿＿＿＿（F-058）
- [ ] 能量层级/识别系统变化记录（F-035）
- [ ] 复购谈话：月度私教可复购，下月很大概率对方愿意续（F-054、F-059）
- [ ] 成功案例归档：这是整套链路的最终验收物，也是下一轮引流的素材（F-010~F-012）

| 客户把每周对话往回拖 | 回到第 1 步固定时间纪律；同时检查每日固定动作是否共创到位（F-037、F-025） |
