## 第 2 节：分润倒推定价

| 项 | 数值 | 说明 |
|---|---|---|
| 目标月度到手价 | ＿＿＿＿ 元 | 每月四次咨询（一周一次 × 一小时）你认为合理的到手额 |
| 计划让利比例 | ＿＿＿＿ % | 会上建议把一半空间让利给平台和销售——主讲人个人口径（F-050，逐字稿 28:27），非验证过的行业结构 |
| 平台分成 | ＿＿＿＿ % | 参考口径：滴滴司机平台分成 29%–30%（F-041） |
| 销售分成 | ＿＿＿＿ % | 分少对方不干活、分多自己不舒服（F-040） |
| **对外定价（倒推值）** | ＿＿＿＿ 元 | 到手价 ÷（1 − 平台% − 销售%） |
| 私接单到手价 | 同上 | 不经过平台/销售时全部归自己（F-051） |

## 第 3 节：一致性检查

- [ ] 对外定价全渠道一致：平台价 = 私下价 = 海报价（F-052）
- [ ] 分润后到手价仍可接受：分完不「受伤」（F-044）
- [ ] 该定价别人有的可分、愿意帮你卖（F-046）
- [ ] 月度框架可交付：一周一次 × 一小时 × 四次（F-015）
- [ ] 已写明复购条件：本月拿到从知到行的体感（F-058、F-059）
