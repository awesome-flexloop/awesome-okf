# 03 · 引流文案与话题：把口令变成钩子

## 一、文案的作用：把观众导向自己的壁纸库

发布信息页的**描述区（文案区）**须填入**固定引流文案**（F-020），其核心是**口令引导语**——引导观众输入口令获取同款壁纸（F-021）。文案格式由**讲师统一提供，学员照抄即可**（F-022），目的是**把观众引导到自己的壁纸库/小程序口令**（F-023）。

```
[固定引流文案模板 —— 由讲师提供]
   ……
   「输入口令【你的口令】，获取同款壁纸」
```

> ⚠️ **注意**：信源视频**未逐字给出文案原文**（ASR 转写中仅以「固定文案 + 口令」概括），本包**不代拟具体文案措辞**，只登记其**结构要件**与**作用**。
>
> **信源等级**：`video_claim`（讲师口播）。

## 二、文案结构要件

| 要件 | 说明 | 事实编号 |
|---|---|---|
| 固定文案模板 | 讲师统一提供，照抄 | F-020、F-022 |
| 口令引导语 | 提示观众「输入口令获取同款壁纸」 | F-021 |
| 导流目标 | 自己的壁纸库 / 小程序口令 | F-023 |

**文案的「钩子」逻辑**：

```
观众刷到作品（壁纸图集）
      │ 读描述区文案
      ▼
「输入口令【XXX】获取同款壁纸」
      │ 观众复制口令
      ▼
进入推图社小程序 → 输口令 → 取同款壁纸 → 触达发布者壁纸库
```

## 三、话题：用「#」加 2~3 个高播放量标签

- 在描述区点「**#**」（**井号键**）插入话题（F-024）；
- 话题须选**播放量高**的——讲师举例「**五点几亿**」「**一点几亿**」量级（F-025）；
- 建议添加 **2~3 个**高播放量话题以**蹭热点**（F-026）；
- 话题添加完毕后「**碰一下空格**」即可结束话题输入（F-027）。

> **信源等级**：`video_claim`（讲师口播）。
>
> ⚠️ **「五点几亿 / 一点几亿」是讲师口播的举例性描述**，**不是可引用的阈值**，也不构成「必须选某某量级话题」的规则（见[成效数字溯源表](../references/verification.md)清单 2）。话题的具体名称信源中听辨不清，本包不作臆测。

## 四、其他编辑入口「都不用点」

讲师明确说明：话题区以外的**其他编辑入口在本流程中「都不用点」**（F-028）——即本流程只使用「描述区文案 + 井号话题」两项编辑能力，其余编辑项保持默认。

## 五、检查要点

- [ ] 描述区已填入讲师提供的**固定文案**
- [ ] 文案中**包含口令引导语**（不是只写壁纸好看）
- [ ] 已用「**#**」添加 **2~3 个**高播放量话题
- [ ] 话题输入已用**空格**结束，话题未黏连成文本
- [ ] 未误点其他编辑入口（F-028）
