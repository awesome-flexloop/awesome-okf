# 00 · 总览：信源性质、引流目标与内容结构

> **⚠️ 信源性质声明（强制）**：本包**信源不是原始文本**。源微信公众号图文的正文**没有任何知识性文字**——`js_content` 仅约 3588 字符，内容就是一个 4 分 02 秒（242.67 秒）的视频与两则红字警示（F-005）。因此本包全部操作条目来自**该视频音轨的本地离线 ASR 转写**，属**讲师口播口径**，存在**音近误识**风险（已知疑误词见[引文逐字核对表](../references/article-source.md)与[核验报告](../references/verification.md)清单 4），**不是平台官方规则**。引用前请先读[核验报告](../references/verification.md)。

## 一、这套流程在做什么

一句话：**用「推图社」小程序的口令，在快手发布壁纸图集作品，把看到作品的观众导向自己的壁纸库**。

链路可概括为「**取口令 → 发作品 → 留钩子 → 交作业**」四段：

| 段 | 动作 | 归属文档 |
|---|---|---|
| 取口令 | 从「推图社」小程序取得属于发布者本人的口令 | [01 · 小程序与口令](01-miniprogram-and-coupon.md) |
| 发作品 | 在壁纸库内触发「发快手」→ 相册选图 → 编辑 → 填写文案话题 → 设置权限 → 发布 | [02 · 发布全流程](02-kuaishou-publish-workflow.md)、[03 · 文案与话题](03-traffic-copy-and-hashtags.md)、[04 · 发布前设置](04-pre-publish-settings.md) |
| 留钩子 | 描述区固定引流文案 + 口令引导 + 2~3 个高播放量话题 | [03 · 文案与话题](03-traffic-copy-and-hashtags.md) |
| 交作业 | 「我的」查看 → 截图交作业（不转发） | [05 · 发布后与作业](05-post-publish-and-assignment.md) |

> **注意**：本包描述的是一次**课程作业式的实操演示**，「交作业」「当天只发一条」等属**讲师对学员的课程约束**，**不是快手平台规则**（F-045、F-046）。

## 二、内容三层结构

本包按「为什么 → 怎么做 → 注意什么」三层组织：

1. **机制层**（01）：小程序是什么、口令是什么、为什么能跳转快手发布 —— 解释「发快手」这一挂载能力的来源（已由快手开放平台官方文档佐证，F-048）。
2. **操作层**（02、03、04、05 + `examples/`）：从取口令到点发布的完整分步操作，含界面按钮位置、文案结构、话题选择与权限设置。
3. **边界层**（06 + `references/`）：图片数量三口径冲突、ASR 误识、UI 时效性、账号安全与未闭环项。

## 三、读者可获得的与不可获得的

**可获得**：

- 一条**完整可复述**的「小程序 → 快手图集发布 → 引流文案 → 权限收口」操作链路（[examples/01](../examples/01-publish-walkthrough.md)）；
- 一份**发布前核对清单**（[examples/02](../examples/02-pre-publish-checklist.md)）；
- 对每个数字/开关**信源等级**的明确标注（讲师口径 / 官方文档 / 第三方 / 无官方口径）。

**不可获得（本包明确不承诺）**：

- ❌ **任何收益、涨粉、播放量成效**——信源视频未给出引流成效数据，本包亦不作承诺；
- ❌ **平台官方规则**——全部操作口径来自讲师口播，非快手官方指引；
- ❌ **图片数量上限**——三口径冲突（9/12/31 张）且无官方口径，见 [06](06-risks-and-open-questions.md)；
- ❌ **「允许下载」关闭的平台机制定论**——仅有讲师推论与第三方间接提及。
