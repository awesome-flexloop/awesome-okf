# 发布前核对清单（可勾选）

> **适用提醒**：本清单复述的是**第三方讲师真机演示的操作口径**（信源为 ASR 转写），**非快手官方规则**。界面按钮位置可能随 App 版本变动（缺口 G4）；图片数量与「允许下载」效果**无官方口径**（缺口 G2、G3）。照做时**以实际界面为准**。引用前请先读[核验报告](../references/verification.md)。

## 阶段一 · 取口令

- [ ] 已打开快手并进入「**推图社**」小程序（顶部**放大镜**搜「推图社」**或** **左上角「三横杠」→ 常用小程序**）
- [ ] 已输入**自己的口令**完成身份绑定
- [ ] 已核对**壁纸库**内容为自己要推广的图

## 阶段二 · 进入发布页

- [ ] 已在壁纸库界面**右上角「三个小点」**（更多菜单）点「**发快手**」
- [ ] 在发布页**只点「相册」**，未误入「随手拍」拍摄流程

## 阶段三 · 选图与编辑

- [ ] 已从**本地相册**选取壁纸图片（讲师演示约 **9~15 张**）
- [ ] 已点**右下角「下一步」**进入编辑页
- [ ] 背景音乐已就位（**默认即可**，或已自选替换）
- [ ] 已再次点「下一步」进入**发布信息填写页**

> ⚠️ **口径提示**：「9~15 张」是演示值，**不是平台上限**。信源中图片数量存在三口径冲突（9 / 12 / 31）且**无官方口径**（缺口 G2，核验 C6 ❌ 未通过）——不要把它写成平台规则。

## 阶段四 · 文案与话题

- [ ] 描述区已填入**讲师提供的固定文案**（照抄，勿自由发挥）
- [ ] 文案中**包含口令引导语**（引导观众「输入口令获取同款壁纸」）
- [ ] 已用「**#**」（井号键）插入 **2~3 个**话题
- [ ] 所插话题为**高播放量**话题（讲师演示口径）
- [ ] 已「**碰一下空格**」结束话题输入，话题未黏连成正文
- [ ] 其他编辑入口**均未点**（本流程只用「描述区文案 + 井号话题」）

## 阶段五 · 发布前设置

- [ ] **位置**：**未**点选（不附加定位）
- [ ] **可见范围**：已设为「**公开可见**」
- [ ] **关联小程序**：**未**点
- [ ] 已进入「**更多设置**」并把「**允许下载**」**关闭**（开关呈**灰色**即关闭）
- [ ] 已点「**叉掉**」关闭「更多设置」面板，返回发布信息页

> ⚠️ **口径提示**：讲师称「允许下载」关闭后他人无法下载该作品，此**效果表述未获官方口径**（缺口 G3，核验 C7 ⚠️ 部分通过）——不要作为平台机制断言。

## 阶段六 · 发布与交作业

- [ ] 已点「**发布**」，作品提交成功
- [ ] 已关掉**发布成功界面**
- [ ] 已从**右下角「我的」**确认作品已出现在作品列表
- [ ] 已**截图**作品（点进详情页截图发老师交作业）

> ⚠️ **口径提示**：「**当天只发一条**」是**课程作业约束**，**不是平台规则**（讲师口径，见 [05 · 发布后与作业交付](../concepts/05-post-publish-and-assignment.md)）。同时**不随意转发**作品。

## 一页速查（对照表）

| 阶段 | 关键动作 | 易错点 |
|---|---|---|
| 取口令 | 搜「推图社」或三横杠→常用小程序 → 输自己的口令 | 口令用成**他人**的 |
| 进发布页 | 壁纸库右上角**三个小点** → 发快手 | 误点「随手拍」 |
| 选图编辑 | 相册选图 → **右下角**下一步 → 音乐默认 → 下一步 | 把 9~15 张当**上限** |
| 文案话题 | 固定文案 + 口令引导 → `#` 2~3 个高播放量话题 → **空格**结束 | 话题黏连成正文 |
| 权限设置 | 位置不点 / **公开可见** / 关联小程序不点 / **允许下载关闭** → 叉掉 | 漏关「允许下载」 |
| 发布交付 | 点发布 → 右下角「我的」→ **截图**交作业 | 把「当天一条」当**平台规则** |

## 关键红线复述

- ❌ **不把「9~15 张」当平台上限**（三口径冲突、无官方口径）；
- ❌ **不把「当天只发一条」当平台规则**（是课程作业约束）；
- ❌ **不把「允许下载关闭」当官方机制断言**（无官方规则文档）；
- ❌ **不承诺任何收益或引流效果**；
- ✅ 文案具体措辞与话题名称以**讲师实际提供**为准（本包未逐字转录）。

分步说明见 [01 · 照做版：从口令到发布的分步流程](01-publish-walkthrough.md)；原理与边界见 [concepts/](../concepts/index.md)。
