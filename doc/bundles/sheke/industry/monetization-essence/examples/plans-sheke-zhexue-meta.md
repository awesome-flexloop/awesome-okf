## 一、AI 变现通道类（源：sheke/industry/ai-monetization 等）

### M-S01 免费增值 AI 工具（Freemium）
- **变现机制**：agent 提供免费基础版（每日限额、水印、基础模型）获客；观测用户触达用量上限或权益敏感点时，在 UI 内自动唤起升级付费版（Pro）转化；按订阅月费/年费计费。
- **价值本质**：A3 稀缺（高级能力/去水印/优先算力被锁定为稀缺）+ A2 交换（先体验后付费降低成交门槛）。稀缺来源=功能分层。
- **信源溯源**：`sheke/industry/ai-monetization` concepts/09-scenario-consumer.md（免费增值是 ToC AI 最主流路径，转化率 2%-5%，Notion AI/Canva AI/秘塔写作猫案例）。
- **成本·风险·周期**：成本中（免费用户占算力）；风险中（免费墙过宽转化低、过窄获客受阻）；回报周期短。
- **道家对齐**：道法自然——让用户先真实体验价值再付费，不造伪需求；免费墙是低摩擦通道（无为），而非拦截。

### M-S02 SaaS 订阅制 AI 助手
- **变现机制**：agent 以「按席位或功能等级按月/年收费」交付稳定可用的 AI 能力（写作、绘图、客服等）；持续观测使用深度并推动升级（expansion），以续费率为北极星指标；收入可预测。
- **价值本质**：A7 循环（订阅=可重复正循环，续费复利积累）+ A2 交换（持续使用对应持续付费）。
- **信源溯源**：`sheke/industry/ai-monetization` concepts/03-business-models.md（SaaS 订阅制：收入可预测、续费率高、估值友好，典型 Midjourney/Notion AI/Cursor）。
- **成本·风险·周期**：成本中；风险中（Churn 风险、与实际用量脱节）；回报周期中。
- **道家对齐**：上善若水——以持续稳定交付换取持续信任；但须知止，避免「订阅却不交付更新」的竭泽而渔。

### M-S03 按量计费（Usage-based）
- **变现机制**：agent 按实际消耗（Token/次数/分钟/生成秒数）计费；提供用量仪表盘与成本归集，让客户为真实价值付费；对边际成本显著的推理按量定价避免亏损。
- **价值本质**：A2 交换（计费单位与价值单位对齐，用多少付多少）+ A4 交易成本（自助开通低摩擦）。
- **信源溯源**：`sheke/industry/ai-monetization` concepts/03-business-models.md（按量计费：客户启动成本低、与价值对齐，OpenAI API/Runway 案例；07-profitability-strategy.md 边际成本结构判据）。
- **成本·风险·周期**：成本中高（需精细成本归集）；风险中（收入不可预测、可能抑制使用）；回报周期中。
- **道家对齐**：道法自然——顺应用量真实发生而计费，不设人为消费陷阱；损有余补不足，单价克制。

### M-S04 API 调用计费（ToD 集成）
- **变现机制**：agent 将底层能力（检索/生成/风控/翻译）封装为 API，按调用次数或数据量计费；提供文档、免费额度、开发者社区（PLG）拉新；面向开发者/应用集成方规模化。
- **价值本质**：A4 交易成本（标准化接口大幅降低集成方的交易成本）+ A3 稀缺（能力本身稀缺）。
- **信源溯源**：`sheke/industry/ai-monetization` concepts/03-business-models.md（API 调用计费：易规模化、生态杠杆强、边际成本低，Replicate/Hugging Face Inference API 案例；决策树 ToD→API+免费额度）。
- **成本·风险·周期**：成本低（复用底层模型）；风险中高（同质化价格战、客户迁移成本低）；回报周期短。
- **道家对齐**：无为而无不为——把能力开放出去让生态自然调用，而非事事亲为；不争——以差异化能力而非价格战取胜。

### M-S05 交易抽佣撮合
- **变现机制**：agent 作为双边/多边平台撮合供需（如 AI 招聘、AI 法律文书撮合），从促成交易的成交额中抽取分成；观测成交闭环与纠纷，构建可验证的交易记录。
- **价值本质**：A3 稀缺（信息/匹配稀缺）+ A2 交换（撮合双方效用均提升）；A7 循环（交易越多数据越多匹配越准）。
- **信源溯源**：`sheke/industry/ai-monetization` concepts/03-business-models.md（交易抽佣：与客户利益深度绑定、天花板高；决策树「业务增长/撮合→交易抽佣+订阅」，AI 招聘/法律文书撮合案例）。
- **成本·风险·周期**：成本高（建交易闭环、合规与资金流复杂）；风险高（冷启动难）；回报周期长。
- **道家对齐**：不争——差异化撮合不红海竞价；上善若水——让双方都受益的利他撮合，而非单边榨取。

### M-S06 数据增值服务
- **变现机制**：agent 基于自有稀缺数据资产（行业语料、知识图谱、用户行为数据）产出洞察/报告/评分，按订阅或按份售卖；数据飞轮：使用越多数据越厚。
- **价值本质**：A3 稀缺（独有数据）+ A7 循环（数据飞轮复利）。
- **信源溯源**：`sheke/industry/ai-monetization` concepts/03-business-models.md（数据增值服务：数据飞轮效应、差异化强，金融风控/医疗影像案例；07 增值收入中的「数据服务」）。
- **成本·风险·周期**：成本中；风险中高（数据合规与隐私、采集成本）；回报周期中。
- **道家对齐**：损有余补不足——克制数据垄断；合道前提=匿名化与用户授权（见 M-S17 火山方舟的授权机制）。

### M-S07 行业定制解决方案（ToB 项目制）
- **变现机制**：agent 面向大企业/政府/国企提供端到端 AI 方案（需求调研→开发→集成→运维），按「一次性项目费 + 年度许可费 + 运维服务费」收费；定制中沉淀行业 Know-How 后抽象为标准模板。
- **价值本质**：A3 稀缺（行业 Know-How + 客户关系）+ A5 信任（私有化部署与合规能力）。
- **信源溯源**：`sheke/industry/ai-monetization` concepts/08-scenario-enterprise.md（定制化路径：项目费 50 万-2000 万、年度许可 15%-25%；第四范式/海康威视案例；「定制→平台→嵌入」演进）。
- **成本·风险·周期**：成本高（人力密集）；风险中（难规模化、毛利受挤压）；回报周期长。
- **道家对齐**：不争——深耕垂直蓝海不广撒网；上善若水——先服务好少数头部客户沉淀真知，再产品化。

### M-S08 开源商业化
- **变现机制**：agent 将核心引擎开源培育社区与标准，以「企业版收费 + 托管服务 + 咨询/培训」变现；观测社区采用率与贡献者生态。
- **价值本质**：A5 信任（开源降低信任成本）+ A4 交易成本（社区免费传播降低获客成本）+ A7 循环（生态正循环）。
- **信源溯源**：`sheke/industry/ai-monetization` concepts/03-business-models.md（开源商业化：生态杠杆、信任成本低、行业标准潜力，Hugging Face/Stability AI/Llama 生态；决策树「行业标准潜力→开源商业化+企业版」）。
- **成本·风险·周期**：成本中；风险中（变现周期长、社区与商业平衡难）；回报周期长。
- **道家对齐**：上善若水——先利他开源、后利己变现；自化——让社区驱动生态自进化。

### M-S09 多层级定价（Tiered Pricing）
- **变现机制**：agent 设计 免费→基础→专业→企业 四层（含「杀伤性功能」锁定下一层用户渴望的能力）；层级价差 3-5 倍驱动自然向上销售；企业版做锚点与定制入口。
- **价值本质**：A2 交换（按支付意愿分层定价，各层效用均提升）+ A3 稀缺（高级功能稀缺化）。
- **信源溯源**：`sheke/industry/ai-monetization` concepts/07-profitability-strategy.md（四层定价示例：免费 0/基础 99/专业 399/企业 1999 起；「免费做漏斗、基础做转化、专业做利润、企业做锚点」切分原则）。
- **成本·风险·周期**：成本低（一次产品设计）；风险中（层级断层或升级动力不足）；回报周期短。
- **道家对齐**：损有余补不足——以免费/低价惠及大众、以专业/企业层支撑经营，平衡普惠与可持续。

### M-S10 价值定价 / 结果分成
- **变现机制**：agent 以客户可量化的价值为锚（如风控挽回损失、营销增收），按「挽回损失/新增收入的 10%-30% 分成」收费；需 ROI 证明与基线对比。
- **价值本质**：A2 交换（价格直接对齐创造的价值）+ A5 信任（按结果收费建立信任）。
- **信源溯源**：`sheke/industry/ai-monetization` concepts/07-profitability-strategy.md（价值定价：风控模型按挽回损失 10% 分成；「成本加成保底+价值定价探索」双轨制）。
- **成本·风险·周期**：成本中；风险高（价值量化依赖客户数据、销售周期长）；回报周期中。
- **道家对齐**：上善若水——价值创造先于价值捕获（先证明价值再收费）；合道，但需「动善时」设定分成上限防过度索取。

### M-S11 嵌入式 API 变现（ToB 嵌入路径）
- **变现机制**：agent 将 AI 能力以 API/SDK 嵌入客户既有 ERP/CRM/OA 工作流，用户在原系统内无感调用；按调用量/嵌入席位/SKU 授权计费，或与 ISV 按增量收入分成。
- **价值本质**：A4 交易成本（嵌入降低用户切换与集成的交易成本）+ A7 循环（嵌入越深迁移成本越高）。
- **信源溯源**：`sheke/industry/ai-monetization` concepts/08-scenario-enterprise.md（嵌入式路径：OpenAI API/Stripe Radar 案例，按交易量计费；「嵌入反哺数据→平台」演进）。
- **成本·风险·周期**：成本中（需稳定 API 基础设施）；风险中（单次调用价值低、易被替代）；回报周期中。
- **道家对齐**：无为而无不为——把能力嵌入别人系统让其自然运转；不争——以嵌入深度与稳定建立护城河。

### M-S12 AI 客服「订阅 + 超额按量」双轨
- **变现机制**：agent 面向中小企业客服场景：基础订阅 499 元/月起含 1000 次会话，超额按 0.5 元/次会话计费；5 分钟接入企业知识库；按结果付费（未解决不计费）。
- **价值本质**：A2 交换（计费单位=会话价值单位对齐）+ A3 稀缺（行业知识包差异化）。
- **信源溯源**：`sheke/industry/ai-monetization` concepts/03-business-models.md（AI 客服九宫格画布：订阅+超额按量，解决率 30%→75%、人效+40% 的价值主张设计）。
- **成本·风险·周期**：成本中（推理+客服交付）；风险中（算力成本占比约 45% 需控制）；回报周期中。
- **道家对齐**：道法自然——顺应真实客服需求（不造伪需求）；知止——对未解决不计费，克制承诺。

### M-S13 数据飞轮风控 API
- **变现机制**：agent 提供反欺诈/信用评分 API，按调用次数 0.1-5 元/次计费；调用越多数据越多模型越准，形成千亿级高频稳定现金流。
- **价值本质**：A7 循环（数据飞轮=可持续正循环）+ A3 稀缺（行为数据与模型稀缺）。
- **信源溯源**：`sheke/industry/ai-monetization` concepts/08-scenario-enterprise.md（同盾科技案例：API 调用计费 0.1-5 元/次、累计 API 调用超千亿次、数据飞轮是终极护城河）。
- **成本·风险·周期**：成本中；风险中（金融合规严苛）；回报周期中。
- **道家对齐**：自化——模型从反馈自进化；合道前提=合规（联邦学习数据不出域）与不滥用用户数据。

### M-S14 广告变现
- **变现机制**：agent 提供免费高频 ToC 工具（AI 搜索/内容生成），以广告/流量变现；观测 DAU 与时长，通过 CPM/CPC/信息流广告获取收入。
- **价值本质**：A3 稀缺（注意力稀缺）+ A4 交易成本（免费降低使用门槛）。
- **信源溯源**：`sheke/industry/ai-monetization` concepts/03-business-models.md（广告变现：获客成本低、规模效应强，AI 搜索引擎案例；ToC 低频突发场景推荐「按量+广告」）。
- **成本·风险·周期**：成本中（免费用户算力成本）；风险中高（体验与商业化冲突、ARPU 低）；回报周期中。
- **道家对齐**：上善若水——先免费利他积累注意力；但需知止——广告密度不可侵蚀用户体验（重营销轻交付是反模式）。

## 二、成本与路由类（源：sheke/industry/copilot-cost）

### M-S15 多模型智能路由降本服务
- **变现机制**：agent 为客户构建 L0/L1/L2 三层模型路由：简单任务跑平价模型、复杂任务跑旗舰模型、兜底用自家便宜模型；观测每请求成本与质量，自动路由并输出降本账单（订阅+节省分成）。
- **价值本质**：A4 交易成本（自动路由降低算力成本）+ A6 再分配（净收益=创造价值−成本，降本即增净收益）。
- **信源溯源**：`sheke/industry/copilot-cost` concepts/analysis-report.md（多模型架构从可选项变必选项；「明牌让用户选」vs「隐藏模型智能路由」两条路线；80% 推理调用将跑在开源模型）。
- **成本·风险·周期**：成本低（复用现有 API）；风险中（路由误判质量波动）；回报周期短。
- **道家对齐**：道法自然——按任务难易自然分流，不强行堆旗舰；知止——设定质量红线，不为省钱牺牲关键任务。

### M-S16 Agent 成本审计与套餐精算服务
- **变现机制**：agent 为企业 Agent 化产品做成本结构审计（多轮调用放大/长上下文累积/多工具开销三维拆解），产出「无限包月→按用量计费」的定价重构方案；按项目/按节省比例收费。
- **价值本质**：A4 交易成本（精算让计费与成本结构对齐）+ A6 再分配（帮客户识别被让渡的利润）。
- **信源溯源**：`sheke/industry/copilot-cost` concepts/analysis-report.md（Copilot 两阶段演进：Agent 化带来成本非线性激增，「太能干」成商业问题，迫使微软放弃无限包月转向按用量计费）。
- **成本·风险·周期**：成本中；风险中（方案落地依赖客户配合）；回报周期中。
- **道家对齐**：损有余补不足——把被高估的「无限额度」重新校准为公平计价；知止——不为多收费而设计陷阱套餐。

## 三、平台生态类（源：sheke/industry/volcengine-ecosystem 等）

### M-S17 「数据换免费 Tokens」奖励计划
- **变现机制**：agent（作为平台方）以「授权采集推理数据→返还等量免费资源包」的机制获客与采集高质量训练数据；冷启动包即时发放、每日 T+1 返还、个人/企业分级权益、随时可撤回授权。
- **价值本质**：A2 交换（双向价值交换：用户降本、平台获数据）+ A7 循环（数据飞轮闭环）+ A5 信任（透明授权+匿名化=信任三角）。
- **信源溯源**：`sheke/industry/volcengine-ecosystem` concepts/07-reward-plan-analysis.md（火山方舟协作奖励计划：每日每模型最高采集 500 万 Tokens 次日返还等量奖励包；「数据即货币」）。
- **成本·风险·周期**：成本中（免费 Token 边际成本随规模递减）；风险中高（数据合规、隐私）；回报周期中。
- **道家对齐**：合道但需改造——「数据换额度」需以用户知情同意为道法自然前提，撤回机制=知止；强制采集/不透明授权为反模式。

### M-S18 企业级 Agent 平台「最后一公里」
- **变现机制**：agent（作为平台服务商）帮企业从 PoC 到生产落地：Harness 配置即部署、零信任安全、Serverless 弹性、端到端评测；按席位/资源用量/项目年费收费。
- **价值本质**：A4 交易成本（解决 PoC→生产鸿沟=降低落地交易成本）+ A5 信任（安全合规即壁垒）。
- **信源溯源**：`sheke/industry/volcengine-ecosystem` concepts/00-agentkit-platform-analysis.md（AgentKit 定位「打通最后一公里」，快速投产/安全可信/存量焕新/质量可见四支柱）。
- **成本·风险·周期**：成本高（平台基建）；风险中高（冷启动难、客户教育）；回报周期长。
