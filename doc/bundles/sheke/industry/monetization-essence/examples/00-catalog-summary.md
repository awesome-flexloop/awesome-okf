## 三、跨域洞察（G2 质量门，四元组）

> 每条洞察 = 现象 / 证据（F 编号）/ 反常识 / 行动。证据均见 [facts.md](../facts.md)。

### 洞察 1：技术域稀缺性迁移——能力差让位于数据/协议/合规差
- **现象**：jishu 域纯"会用框架"能力快速普及化，协议工程（MCP/A2A）、行业数据与合规工程仍是高价稀缺点。
- **证据**：MCP 月下载 9700 万次、公开 server 9400+（F-102）；A2A v1.0 获 150+ 组织支持（F-103）；中国 2026-07-15 生效全球首个 Agent 专项监管（F-106）。
- **反常识**：框架越易得，框架本身越不值钱——"我会搭 Agent 框架"不是护城河，"我拥有某行业独家数据/协议接入/合规资质"才是。
- **行动**：方案稀缺定位放在协议托管（M-T01）、合规审计（M-T06）、行业数据（M-T15）、私有化主权（M-T13），避开"再造一个框架"同质红海。

### 洞察 2：Agent 品类成熟顺序由「客观正确性信号」决定，而非模型能力
- **现象**：各 Agent 品类可靠性分化极大，分化原因在领域是否有机器可自验的反馈信号。
- **证据**：编码 Agent 100 次重复测试可靠性 60-72%（F-105，有编译/测试信号）；浏览器 Agent 仅 38-48%（无客观信号）。
- **反常识**：找成熟 Agent 品类，不应问"模型最擅长什么"，应问"哪个领域有自动反馈机制"——SQL 校验、部署状态、数值精度都可自验。
- **行动**：优先选「有客观验收信号」的闭环——编码部署（M-T07 编译/测试验收）、模型优化（M-T24/M-T25 精度基准验收），让 Agent"自化"纠错、交付可证。

### 洞察 3：sheke 域稀缺不在「AI 能力」，而在「合规边界内的稀缺位置」
- **现象**：社科/职场域纯生成能力快速同质化，溢价集中在法律、金融、婚姻、性学等需"红区合规"约束的稀缺位置。
- **证据**：ToC 底层模型趋同、30 日留存 <20%（F-205）；ToB 嵌入核心流程续约率 80%+（F-204）；免费增值转化率 <5%（F-202）。
- **反常识**：直觉上"能做得多"最有价值，sheke 域反而"明确不能做什么"（红线声明）最稀缺——边界越清晰，信任越高，定价权越强。
- **行动**：方案显式声明合规边界（金融不荐股、健康不诊断、性学不低俗、学术不代写）作为卖点，把"边界工程"做成可交付模块。

### 洞察 4：知识变现通道随「可验证性」递进——内容→工具→撮合/认证
- **现象**：sheke/meta 域呈现清晰递进：内容付费（转化率 <5%）→ 工具订阅 → 撮合/认证（单价高但冷启动难）。
- **证据**：ToB 项目费 50 万-2000 万（F-203）；GodGPT 订阅 + 30% 持续佣金联盟（F-206/F-207）；okf-kit 三模共享导航内核（F-208/F-209）。
- **反常识**：最"轻"的内容付费最卷，最"重"的撮合/认证反而因稀缺与信任获得最高单价；知识变现终局是卖「经过验证的信任」（A5）。
- **行动**：按"内容引流→工具留存→撮合/认证变现"三级漏斗设计，先占工具层拿数据，再向撮合/认证层爬。

### 洞察 5：合道变现本质是「再分配让渡」内嵌于模式设计，而非事后补税
- **现象**：高客单价 ToB、广告与数据增值若不主动设计让渡机制，易滑向"竭泽而渔"反道模式；内嵌让渡反而换来信任复利。
- **证据**：免费增值本质是让渡免费能力换信任（F-201/F-202）；okf-kit 三模共享、LLM 可关体现"能力开放"（F-208）；GodGPT 30% 佣金把让渡给推广者构成增长闭环（F-207）。
- **反常识**：把"少收钱"（让渡）当损失是错觉——合道方案中让渡换取 A5 信任与 A7 循环的复利，总现值高于一次性榨取。
- **行动**：每个方案 6 要素设计时显式回答"让渡给谁、让渡什么、换回什么"，把让渡比例写进模式参数（如订阅价 15%-30% 回馈生态）。

## 四、挑选指南

> 对第一次使用本目录的读者：**三筛法**——先按落地等级筛掉 🔴（无牌照不碰），再按成本·风险筛掉"实现成本 高 + 回报周期 长"的，最后按道家对齐筛掉"不合道"的，剩余即优先候选。

| 筛选维度 | 优选信号 | 避雷信号 |
|---|---|---|
| 落地等级 | 🟢 即时可落地 | 🔴 需牌照（无授权勿入） |
| 成本·风险·周期 | 实现成本 低/中 ｜ 风险 低/中 ｜ 周期 短/中 | 成本 高 + 周期 长 双高 |
| 稀缺来源 | 数据差/协议差/合规差/许可差 | 纯能力差（框架民主化后归零） |
| 客观验收信号 | 有编译/测试/基准可自验 | 无反馈信号的品类（浏览器 Agent） |
| 道家对齐 | 合道（道法自然/无为/不争/自化/知止） | 不合道（竭泽而渔/制造伪需求） |

**快速上手的 10 个推荐方案**（低成本 + 高合规 + 强道家对齐）：M-T05 提示词工程、M-T31 字幕本地化、M-T34 桌面应用定制、M-S22 book-to-skill、M-S31 劳动法合规、M-S37 第一性原理课程、M-G29 化学史科普、M-G30 科学论文精读、M-G40 艺术治疗科普、M-G42 声乐教学陪练。

## 五、反模式速查（G3 质量门，≥3 个）

> 全部来自真实教训（束内失败案例与对抗审查 V-06/V-07），而非理论推演。

| 反模式 | 表现 | 违反公理/教训 | 对应方案避雷 |
|---|---|---|---|
| **伪需求制造** | 为工具而工具，无真实需求方效用 | 违反 A1（价值源于需求方效用）；GodGPT 靠强品牌才撑起订阅 | 方案需先验证"谁付费、为什么付费" |
| **竭泽而渔** | 一次性榨取，无让渡与循环 | 违反 A6/A7（再分配+循环）；ToC 30 日留存 <20%（F-205） | 方案内嵌让渡比例，避免"获客即流失" |
| **红区越界** | 荐股/诊断/迷信收费，无合规边界 | 违反 A5（信任崩塌指数放大）；V-07 合规责任 | 方案显式声明红线，平台红区禁行 |
| **同质红海** | 再造一个框架/通用生成器 | 稀缺性迁移洞察（能力差归零） | 避开"再造框架"，定位数据/协议/合规差 |
