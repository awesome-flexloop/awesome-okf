# 个人变现方向发现：从「我是谁」到市场愿意付费的方向

本知识包回答一个问题：**从「我是谁」出发，如何找到市场愿意付费的候选变现方向。** 它按「事实 → 方法 → 路径」三层组织，并配一套可填写的工具。

- **先破三类误区**：① **跟风赛道**——不加自评就追随热门赛道，把「别人赚钱的领域」当自己的方向；② **爱好即能力**——把「喜欢做」等同于「擅长做」再等同于「可变现」，三者并不等同；③ **只学技巧不问匹配**——只收集变现技巧/增长套路，从不做「我是谁 → 市场要什么」的匹配核对。
- **再走四步法**：**自我盘点**（职业锚排序 + 优势/心流清单 + 资源约束 + 内在动机）→ **候选方向生成**（个人商业模式画布 + 特定知识×杠杆×担责矩阵 + 问题优先，产出 3~5 个候选）→ **需求验证**（JTBD 三问 + Mom Test 问过去行为 + 最小验证实验与信号阈值）→ **决策启动**（信号汇总 → go/no-go → 首个 30 天行动 → 退出/迭代条件）。四步法正是对上述三类误区的逆向纠正。
- **最后选路径**：按起点（在职副业 / 全职转型 / 技能型创作者 / 被动转型）与资源约束（时间 / 资金 / 技能 / 关系）给出四条主路径与切换条件，并明确边界红线。

## 已知边界

- **非决定论**：性格 / 天赋测评类工具（MBTI、RIASEC、CliftonStrengths、grit 等）**具科学效度争议，不得作为变现方向判定依据**，仅可作自我反思的启发式参照（对齐 F-041，详见 [02 篇](concepts/02-strengths-talent-facts.md)）。
- **非承诺**：本包中一切收益 / 规模类表述（如 1000 True Fans 的数学条件、$100 Startup 的样本成效）均为**原作者在其限定语境下的主张或样本观察，非对读者的收益承诺**。
- **单源清单**：F-026 / F-037 / F-040 为工具方（利益相关）口径单源；F-052 **待核验，正文不得作结论引用**；F-065 / F-066 为作者口径。引用须连同单源标注转述，明细见 [核验报告](references/verification.md) 第 5 节。
- **时效**：核验时点为 **2026-10-17**，`stale_after: 2027-06-30`；其中工具类内容（CliftonStrengths、VIA、MBTI 测评规格等）若工具方更新版本或信效度结论，须重核后更新。
- **不做推荐**：本包不推荐任何具体测评产品、课程或付费工具，不提供任何收益保证；本包为「事实 + 方法 + 路径 + 工具」四层型 bundle，故设 `examples/`。
