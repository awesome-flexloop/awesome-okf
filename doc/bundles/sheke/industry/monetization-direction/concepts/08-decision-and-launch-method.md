# 步骤 4 决策与启动：信号汇总、go/no-go 与 30 天行动

> **非决定论声明**：本步的 go / no-go 阈值是本方法自定义的启发式参数，非实证结论，不构成对方向成立与否的判定。
> **非承诺声明**：本步不承载任何收益、规模或成功概率的承诺。

## 1. 本步在四步法中的定位

本步承接步骤 3 的**验证记录**（见 [需求验证](07-needs-validation-method.md)），把信号汇总为决策，并把决策转成可执行的首个 30 天行动。本步**不含路径层的人群矩阵**（见 [路径矩阵](09-path-matrix.md)）。

## 2. 输入项

- 步骤 3 产出的验证实验卡、Mom Test 访谈记录、信号记录表。
- 步骤 1 的资源约束四栏表（硬约束须带入行动拆解）。

## 3. 信号汇总表

把步骤 3 的全部信号归入一张表，每个候选方向一行，列含：

| 列 | 含义 |
|---|---|
| 候选方向 | 来自步骤 2 的候选卡编号 |
| 已验证假设 | 该方向在本轮验证中实际测试的假设 |
| 强信号 | 真实付费 / 真实使用 / 重复使用等已发生行为 |
| 弱信号 | 留资、预约、口头意向等未发生付费的行为 |
| 无效信号 | 恭维 / 空话 / 他人点子 / 点赞（依 F-077） |
| 未验证假设 | 尚未测试的风险项 |

**判定标准**：强 / 弱 / 无效信号三类分行登记，无效信号列不得留空（留空视为未做反模式过滤）。

信号汇总表模板见 [决策清单](../examples/04-decision-checklist.md)。

## 4. go / no-go 判定阈值

**阈值定义（本方法自定义参数，非实证结论）**——满足以下任一即进入 go，否则进入 no-go：

- **go**：存在**至少一项强信号**，且该强信号来自陌生或半熟人样本；且已验证假设覆盖候选卡的「最大不确定性」。
- **no-go**：仅有弱信号，或强信号全部来自熟人样本；或「最大不确定性」尚未被任何实验触及。
- **待补验**：介于两者之间——强信号存在但来源单一，或存在未验证的高风险假设。

**判定规则**
1. 阈值在汇总前写定，禁止据结果反向调整。
2. 判定结果须注明依据的具体信号行。
3. 「待补验」不等于 go，须先补一轮实验再判。

## 5. 首个 30 天行动拆解（原子化）

判定为 go（或补验后 go）的方向，拆解为首个 30 天行动清单。拆解遵守两条纪律：

- **单一职责**：每项行动只完成一件事，可用一句话表述「做什么 → 交付什么」。
- **可独立验证**：每项行动均有可观察的完成标志，不依赖其他行动的完成状态。

**操作步骤**
1. 从验证阶段遗留的**未验证假设**出发，倒推所需行动。
2. 每项行动标注：负责人、完成标志、所需资源（须落在步骤 1 的资源约束以内）。
3. 按周排布，标出关键路径项。

**判定标准**：每项行动均可被独立验证，且全部行动的资源需求不超过资源约束四栏的上限。

## 6. 退出 / 迭代条件

在启动前预先登记退出与迭代条件，避免事后合理化：

- **迭代条件**（继续但调整）：出现新的「最大不确定性」假设被证伪，但强信号仍存在时，重写假设并补一小型实验（机制见 [需求验证](07-needs-validation-method.md) §5）。
- **退出条件**（停止该方向）：在预设的观察期内，强信号未出现且弱信号无增长趋势时，停止该方向并回到步骤 2 更换候选。
- **观察期**：本方法建议为 30 天（设计参数，非实证结论）；须在启动前写定。
- **回退路径**：退出后回到步骤 2 的候选池，直接启用次优候选卡而非重新从零开始。

## 8. 完成本步的达标条件

- [ ] 信号汇总表三类信号分行登记，无效信号列非空。
- [ ] go / no-go 阈值在汇总前写定，且判定注明依据信号行。
- [ ] 每项 30 天行动单一职责、可独立验证，资源需求不超约束。
- [ ] 已预先登记退出与迭代条件及观察期。

## 9. 边界

- 〔洞察〕go / no-go 判定对信号质量的依赖
  - 现象：同等数量的强信号，来自陌生 / 半熟人样本者与全部来自熟人样本者，在本步判定中分别落入 go 与 no-go 两档（阈值定义见 §4）。
  - 根因：判定依据是步骤 3 实际采集的信号质量；样本偏差或时机偏差未受控时，信号本身即被污染（机制说明见 [边界与风险](10-boundaries-and-risks.md)；本包未给出量化模型，属待研究方法问题）。
  - 影响：判定结果的可信度随之下移，可能对一个实际尚未验证的候选给出 go。
  - 建议：在 §3 信号汇总表的「强信号」列逐行注明样本来源，并执行 §4 判定规则 2「判定结果须注明依据的具体信号行」；不确定者归入「待补验」并先补一轮实验（见 [需求验证](07-needs-validation-method.md) §5）。
- 本步只给出「是否投入 30 天」的启发式判定，不预测任何结果。
