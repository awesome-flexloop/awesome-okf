# 边界与风险：伪科学自评、画饼式路径与收益不确定性

> **本页性质**：本页为**边界与风险登记**，**不承载任何正向方法**。正向操作步骤见 [自我盘点](05-self-inventory-method.md) 至 [决策与启动](08-decision-and-launch-method.md) 与 [路径矩阵](09-path-matrix.md)。
> **非承诺声明**：本页不承载任何收益、规模或成功概率的承诺。

## 1. 伪科学自评警示

### 1.1 强制标注：测评属非决定论工具

性格 / 天赋类测评（含 MBTI）具科学效度争议，属**非决定论**工具，**不得作为变现方向判定依据**——仅可作自我反思的启发式参照（F-041）。

### 1.2 争议双方口径（须并列，禁单取一方）

| 立场 | 主张 | 出处 |
|---|---|---|
| 学术批评 | Stein & Swan (2019) 指出：MBTI 的荣格式理论在严格理论标准下**失败**——与已知事实不符、缺乏可检验性、存在内部矛盾（F-038） | 同行评议论文 |
| 学术批评 | 广为引用的统计为「5 周重测期内约 50% 的受试在一个或多个量表上被重新分类」（Pittenger 1993）（F-039） | 第三方综述引一手期刊 |
| 官方反方（**单源，利益相关口径**） | Myers-Briggs 公司回应：上述 50% 统计源自单篇文章并被广泛误传，并援引 Capraro (2002) 元分析称 MBTI 信度良好（F-040） | 工具官方 |
| 官方自述（**单源，利益相关口径**） | MBTI Form M 内部一致性信度 ≥ .90（F-037） | 工具官方 |

**结论**：两方口径**必须并列**呈现，**禁单取一方作结论**；争议未解。对应勘误 E-02（「MBTI 结果稳定可靠，可作职业方向依据」属伪精确 / 伪决定性）。

### 1.3 其他测评与构念的同类警示

- **RIASEC**：congruence 的预测力为「modest」（有限），且调节变量研究结论不一致（F-011）；其局限含六类型过度简化、样本多为西方英语人群（文化偏差）、单次问卷为静态快照、存在性别差异（F-012）。**六类型适用于兴趣而非能力匹配**——「享受某事 ≠ 擅长某事」。
- **grit**：二因子模型存在缺陷——「consistency of interests」子量表无法预测学业成就等结果；且 grit 与尽责性高度重叠（F-043）。
- **刻意练习**：Macnamara 等 (2014) 元分析实测，刻意练习解释的绩效变异为游戏 26%、音乐 21%、体育 18%、教育 4%、**职业 <1%**（F-034）；与 Ericsson 1993 定义之争并存（F-033 / F-035）。禁把 <1%（职业域）当作「练习无效」（对应勘误 E-04）。
- **ikigai 四圆图**：**非日本传统概念**——2011 年由 Andrés Zuzunaga 创作 purpose diagram，2014 年 Marc Winn 改注为「ikigai」（F-021）。对应勘误 E-03（误植溯源）。

## 2. 画饼式路径证伪

以下流行表述在信源层面**丢前提或丢限定**，须以权威口径为准：

| 画饼表述 | 证伪要点 | 出处 |
|---|---|---|
| 「1000 个铁杆粉丝就能养活自己」 | Kelly 原文前提为每位粉丝约 $100/年 + 直接关系 + 直接付费（绕开中间商），1,000 位 ≈ $100,000/年；且原文为文化创作者的可能性主张而非保证 | F-056 / F-057（勘误 E-01） |
| 「低投入必然做到年入五万美元」 | 作者识别 1,500 位以低投入建立年收入 ≥$50,000 业务者、精选 50 例；样本选择偏差未披露，**非普遍规律** | F-066 |
| 「某书销量 / 共创者数字证明方法有效」 | BMC 的「470 位共创者 / 超 500 万册」仅第三方陈述、**待核验、不作结论**；Personal MBA 销量 >100 万册为**作者口径** | F-052 / F-065 |
| 「职业锚只有 5 种（或只有 9 种）」 | 版本口径混乱：1978 初始版本 5 类、1990 扩为 8 类 | F-004 / F-005（勘误 E-05） |

**证伪纪律**：凡出现「必然 / 保证 / 一定 / 只需……」的收益表述，须回查是否为原文前提被剥离。

## 3. 相关性 ≠ 因果

- 测评结果与职业结果之间为**相关性描述**，非因果预测——RIASEC congruence 的预测力本身即为「modest」（F-011）。
- 刻意练习与绩效之间的解释比例随领域差异极大（职业域 <1%，F-034）。
  〔洞察〕比例差异的含义
  - 现象：同一元分析中，刻意练习解释的绩效变异从游戏 26% 到职业域 <1%，差距极大（F-034）。
  - 根因：本包未给出，属待研究方法问题（F-034 只报告解释比例，未给出领域间差异的成因；F-035 的 Ericsson 回应属定义之争，不是成因解释）。
  - 影响：把职业域 <1% 读作「练习无效」，或反向读作「成绩全由多因素随机决定」，都会得出超出该元分析口径的结论（对应勘误 E-04）。
  - 建议：引用时保留「任意练习」与 Ericsson 严格定义的口径差异（F-033 / F-035），并按本节禁止条款处置——个案不得转述为因果证据。
- **禁止**把「某人用某路径成功」转述为「该路径带来成功」——个案不具备因果证据地位。

## 4. 收益不确定性

- 一切规模 / 收益类数字（F-052 / F-056 / F-065 / F-066）均为**单源、作者口径或待核验**，不得作为预期收益依据。
- 1000 True Fans 的算式（F-056）为作者原文中的**可能性主张**，不构成收益承诺。
- $100 Startup 的样本（F-066）存在**幸存者 / 选择偏差**，未披露失败基数。
- 〔洞察〕「收益非承诺」的依据
  - 现象：本包一切规模 / 收益类数字均为单源、作者口径或待核验（F-052 / F-056 / F-065 / F-066），其中 F-066 的样本选择偏差未披露、F-052 待核验不作结论。
  - 根因：上述来源限制（单源、作者口径、幸存者 / 选择偏差未披露）使这些数字不具备预测效力；本包未获得可外推的收益样本，属待研究方法问题。
  - 影响：若以这些数字作为预期收益依据，即构成对读者的收益画饼。
  - 建议：引用时一律连同单源 / 口径 / 待核验标注转述（见 §5.2 单源清单与 [核验报告](../references/verification.md) 第 5 节），并在任何收益语境处保留「非承诺」声明。
