# 步骤 1 自我盘点：职业锚、优势与资源约束

> **非决定论声明**：本步涉及的职业锚自评、优势清单、心流清单与性格 / 天赋类测评，均属启发式参照工具。作者主张与实证反论并存（F-003 / F-006 / F-041），**不得作为变现方向判定依据**。详见 [边界与风险](10-boundaries-and-risks.md)。
> **非承诺声明**：本步不承载任何收益、规模或成功概率的承诺。

## 1. 本步在四步法中的定位

四步法链路为：**① 自我盘点（本步）→ ② 候选方向生成 → ③ 需求验证 → ④ 决策与启动**。本篇只回答「我是谁、我手上有哪些可支配的输入」，不作为方向结论。候选生成见 [候选方向生成](06-candidate-generation-method.md)，验证见 [需求验证](07-needs-validation-method.md)，决策见 [决策与启动](08-decision-and-launch-method.md)。

本步的产出是**过程性输入**（自评盘点表），不是**结论性输出**（候选方向）。

## 2. 输入项 → 操作步骤 → 判定标准

以下四项子任务可并行执行，互不依赖；每项均给出「输入项 / 操作步骤 / 判定标准」三要素。

### 2.1 职业锚自评排序

**输入项**
- 职业锚类型清单（须注明**版本年**：1978 初始版本为 5 类，F-004；1990 年新增三锚扩为 8 类，F-005）。
- 本人经历过的 3~5 个关键职业决策事件（行业切换、岗位取舍、离职 / 留任）。

**操作步骤**
1. 对照锚类型清单，逐锚记录「在面临艰难职业决策时，我不愿放弃的核心价值、需求与动机」——此为作者主张的锚定义（F-003〔主张〕）。
2. 对每个锚按「不愿放弃程度」打 1~5 分，并写下打分依据的具体事件。
3. 按分值排序，取**主导锚 + 次主导锚**候选。

**判定标准**
- 排序表每行均附**具体事件**佐证（无事件佐证的行视为未完成）。
- 若多个锚并列且无法排序，如实记录为「待澄清项」。
- **边界**：作者主张个体由单一主导锚支配其职业决策（F-003〔主张〕），但已有以 880 名工程师为样本的实证反论提出「多主导锚」（F-006）。〔洞察〕排序结果更适合用作自我反思的线索，而非判定依据。

### 2.2 优势 / 心流时刻清单

**输入项**
- 过往 12 个月内的具体工作 / 学习事件记录。

**操作步骤**
1. 回溯并记录出现「完全投入」体验的具体场景（时间、任务、对象）。
2. 对每个场景标注当时的**技能水平**与**挑战水平**。
3. 另记一份「他人反馈清单」：他人曾就哪类任务向你求助。

**判定标准**
- 每条线索须附**至少一个具体事件**，禁止仅写性格形容词。
- 产出「优势线索清单」与「心流场景清单」两张表（模板见 [自评盘点表](../examples/01-self-inventory-worksheet.md)）。
- **边界**：
  - 技能习得五阶段模型（F-031）为**描述性研究**，作者主张随技能提升从业者越来越少依赖抽象规则、越来越多依赖具体经验（F-032〔主张〕）；该模型不预测个体在某一领域的可达水平。
  - 〔洞察〕心流场景常标记出「挑战与技能相匹配」的领域：作者主张心流的核心条件之一是挑战与技能平衡（过高趋向焦虑、过低趋向厌倦）（F-045〔主张〕）。清单只列线索，不作能力判定。

### 2.3 资源约束盘点（时间 / 资金 / 技能 / 关系）

**输入项**
- 可支配时间（每周可投入小时数）、可投入资金（可承受损失上限）、已具备技能、可动用关系网络。

**操作步骤**
1. 按「时间 / 资金 / 技能 / 关系」四栏逐项填写当前值。
2. 对每项标注**硬约束**（3 个月内不可改变）或**软约束**（可规划改变）。
3. 标注每项的最大可用量与下限。

**判定标准**
- 四栏均有数值或明确等级，且每项附约束类型标签。
- 硬约束不可在后续步骤中被默认忽略。资源约束的路径适配见 [路径矩阵](09-path-matrix.md)。

### 2.4 内在动机核对

**输入项**
- 2.1 与 2.2 产出的主导锚排序与优势线索清单。

**操作步骤**
1. 对每个候选锚 / 优势方向，就三种基本心理需要各打 1~5 分——作者主张 SDT 认为人类有三种基本心理需要：**自主（autonomy）、胜任（competence）、关联（relatedness）**（F-047〔主张〕，理论提出于 1985 年，F-046）。
2. 汇总三项分值，标注低谷项。

**判定标准**
- 三个需要维度均有打分，无空缺。
- 三项均偏低的方向列入「观察区」，留待步骤 2 生成候选时重新评估。

## 3. 产出物

本步产出 **自评盘点表**，含：职业锚排序表、优势 / 心流时刻清单、资源约束四栏表、内在动机自检表。

- 可填写模板：[自评盘点表（worksheet）](../examples/01-self-inventory-worksheet.md)

## 4. 完成本步的达标条件

- [ ] 职业锚排序表每行附具体事件佐证。
- [ ] 优势线索与心流场景均在「至少一个具体事件」的粒度。
- [ ] 资源约束四栏均有数值或明确等级，并标注硬 / 软约束。
- [ ] 内在动机三需要维度均完成打分。
- [ ] 已阅读并接受本步的**非决定论**边界。

## 5. 边界与反模式

| 反模式 | 问题 | 纠正 |
|---|---|---|
| 把测评类型直接当作方向判决 | 把「我是某类型」等同于「我该做某事」 | 测评仅作自我反思的启发式参照（F-041） |
| 只写性格形容词，不写具体事件 | 清单不可验证 | 每条线索须附具体事件 |
| 忽略版本年 | 混用 1978 与 1990 口径（F-004 / F-005） | 引用锚类型时注明版本年 |
| 忽略硬约束 | 后续步骤生成不切实际的候选 | 硬约束须带入步骤 2 |
