# 路径矩阵：四条主路径与切换条件

> **非决定论声明**：路径划分为启发式分类，非决定论工具；路径选择不构成对方向成立与否的判定。
> **非承诺声明**：本页不承载任何收益、规模或成功概率的承诺；各路径的观察期与门槛均为方法自定义参数，非实证结论。

## 1. 本页在知识包中的定位

本页为**路径层**：把方法层的四步（盘点 → 生成 → 验证 → 决策）适配到不同起点与资源约束的个体身上。方法层的操作细节**不在本页重复**，一律以链接引用：

- 步骤 1 自我盘点 → [05-self-inventory-method](05-self-inventory-method.md)
- 步骤 2 候选方向生成 → [06-candidate-generation-method](06-candidate-generation-method.md)
- 步骤 3 需求验证 → [07-needs-validation-method](07-needs-validation-method.md)
- 步骤 4 决策与启动 → [08-decision-and-launch-method](08-decision-and-launch-method.md)

## 2. 复用要素与读取方式

以下复用 BMY 画布的人群分析要素命名（BMY 方法论见 F-049；九模块画布母版见 F-050 / F-051）：

| 要素 | 在本页的作用 |
|---|---|
| 目标对象（Target Audience） | 路径服务的人群边界 |
| 起点（Starting Point） | 该路径的出发状态（在职 / 全职 / 已有作品 / 被动离场） |
| 利润（Profit） | 该路径的收入结构形态（不承诺具体数额） |
| 生成器（Generator） | 该路径的价值生成方式（技能交付 / 内容 / 产品） |

> 上述要素为 BMY 框架内的术语命名，用于分类；本页不对其作事实性断言。

## 3. 两条维度轴

- **起点轴**：在职副业 / 全职转型 / 技能型创作者 / 被动转型（四类）。
- **资源约束轴**：时间 / 资金 / 技能 / 关系（四类）；取值来自步骤 1 的资源约束四栏表，并区分**硬约束**与**软约束**。

两张轴交叉得到四条主路径。每条路径均给出：**起点条件 → 准入门槛 → 分阶段行动 → 退出 / 切换条件**。

## 4. 四条主路径

### P1 在职副业型

| 项 | 内容 |
|---|---|
| 起点条件 | 仍在全职岗位；每周可支配可变现时间有限；资金可承受损失上限较低 |
| 准入门槛 | 时间硬约束可被明确标出；存在 1 个可在业余时间验证的候选方向；关系网络中有可访谈对象 |
| 分阶段行动 | ① 完成 [步骤 1](05-self-inventory-method.md) 与 [步骤 2](06-candidate-generation-method.md)（时间预算优先）；② 以 [步骤 3](07-needs-validation-method.md) 的**落地页型 / 预售型**实验做低成本验证；③ 按 [步骤 4](08-decision-and-launch-method.md) 判定是否继续 |
| 退出 / 切换条件 | 观察期内强信号未出现 → 回到步骤 2 换候选；岗位时间约束收紧至不可支撑 → 转 P4 或暂停 |

### P2 全职转型型

| 项 | 内容 |
|---|---|
| 起点条件 | 已离开或即将离开全职岗位；时间储备较充裕；现金流需在有限周期内重建 |
| 准入门槛 | 明确的可承受损失上限与观察期；至少 1 个候选方向已通过初步访谈 |
| 分阶段行动 | ① 以 [步骤 3](07-needs-validation-method.md) 的 **MVP 型**实验并行验证 2~3 个候选；② 按 [步骤 4](08-decision-and-launch-method.md) 择一启动 30 天行动；③ 保留「回退计划」为硬约束 |
| 退出 / 切换条件 | 可承受损失上限触达 → 暂停并回退；两个观察期内均无强信号 → 转 P1（先恢复稳定现金流再并行验证） |

### P3 技能型创作者型

| 项 | 内容 |
|---|---|
| 起点条件 | 已有可交付的技能或作品；生成器（Generator）以内容或可复制产出物为主 |
| 准入门槛 | 存在可展示的作品或样本；目标对象可被具体描述 |
| 分阶段行动 | ① 以 [步骤 2](06-candidate-generation-method.md) 的「特定知识 × 杠杆 × 担责」矩阵锁定可替代性低的项；② 以 [步骤 3](07-needs-validation-method.md) 的**预售型**实验检验付费意愿；③ 按 [步骤 4](08-decision-and-launch-method.md) 拆解 30 天行动 |
| 退出 / 切换条件 | 作品更新停滞且信号无增长 → 回到候选池；付费意愿始终停留在弱信号 → 转 P2 重新验证方向 |

### P4 被动转型型

| 项 | 内容 |
|---|---|
| 起点条件 | 因外部变化被动离场（岗位裁撤、合约终止等）；时间可支配但决策窗口紧 |
| 准入门槛 | 先完成现金流与可承受损失上限的盘点；关系网络中有可立即访谈的对象 |
| 分阶段行动 | ① 优先完成 [步骤 1](05-self-inventory-method.md) 的资源约束盘点（含硬约束标注）；② 跳过长周期验证，采用 [步骤 3](07-needs-validation-method.md) 中成本最低的实验形态；③ 按 [步骤 4](08-decision-and-launch-method.md) 尽快形成 30 天行动 |
| 退出 / 切换条件 | 现金流触底 → 恢复稳定收入后转 P1；方向验证连续两轮失败 → 回到步骤 2 重选候选 |

## 5. 路径切换条件矩阵

| 从 \ 到 | P1 在职副业 | P2 全职转型 | P3 技能型创作者 | P4 被动转型 |
|---|---|---|---|---|
| **P1** | — | 时间约束解除且已备损失上限 → 转 P2 | 已有可展示作品 → 转 P3 | 岗位意外终止 → 转 P4 |
| **P2** | 损失上限触达 → 转 P1 | — | 作品驱动且技能可交付 → 转 P3 | 现金流告急 → 转 P4 |
| **P3** | 需稳定现金流 → 转 P1 | 需加速验证 → 转 P2 | — | 收入中断 → 转 P4 |
| **P4** | 恢复收入后 → 转 P1 | 备足损失上限 → 转 P2 | 已有作品 → 转 P3 | — |

**切换纪律**：切换发生在「起点条件不再成立」或「退出条件触达」时；切换后须回到对应路径的门槛检查，不得直接沿用上一路径的实验结论。

## 6. 资源约束适配表

| 硬约束资源 | 适配原则 |
|---|---|
| 时间不足 | 优先选「落地页 / 预售」类低成本实验形态；推迟需长交付周期的候选 |
| 资金不足 | 避免需先投入成本结构的候选；以可复制产出物替代资本投入 |
| 技能不足 | 〔洞察〕**现象**：准入失败常表现为**可交付样本的缺失**；**根因**：本包未给出，属待研究方法问题（技能习得五阶段模型 F-031 为描述性解释，不是进度预测；2026-10-17 深入研究亦**未获**相关实证研究——该缺口如实保留）；**影响**：以「没有可交付样本」直接判定方向不成立，会过早放弃可深化的候选（对照 [步骤 2](06-candidate-generation-method.md) §4「待深化」处置）；**建议**：先按 [步骤 1](05-self-inventory-method.md) §2.2 的优势 / 心流清单定位可产出样本的技能项，再以上方「时间不足」行的低成本实验形态取得首个样本；本方法**假设**样本缺失可通过短期练习逐步补齐（方法前提假设，非实证结论） |
| 关系不足 | 访谈样本以半熟人 / 陌生人为先，减少对熟人样本的依赖（依 F-077） |

## 7. 边界

- 〔洞察〕路径划分的作用边界
  - 现象：四条主路径共用同一套方法层步骤，差异集中在**门槛取值**与**实验形态选择**上（见 §4、§5）。
  - 根因：本包未给出，属待研究方法问题（路径划分为 BMY 要素命名（F-049）下的启发式分类，不是实证分类）。（2026-10-17 深入研究：已检索「生涯路径 / 变现路径的实证分类」，**未获**同行评议分类学研究——该缺口**如实保留**，见 [核验报告](../references/verification.md) §9.3。）
  - 影响：若把「选到某条路径」读作方向已成立，即把分类工具误作判定依据。
  - 建议：路径选择只用于缩小搜索范围（§3 两轴交叉 + §5 切换矩阵）；过门槛检查后仍回到步骤 1~4 的「输入项 / 操作步骤 / 判定标准」链路，方向结论只由 [步骤 4](08-decision-and-launch-method.md) 的 go / no-go 给出。
