## 表 2 Mom Test 十问提问脚本

方法要点：问**过去的具体行为**，不问未来承诺（F-078〔主张〕）；识别并丢弃 compliments / fluff / ideas 三类回答（F-077）。逐问记录受访者的**原话要点**。

| # | 问题 | 受访者原话要点 | 是否为已发生行为 |
|---|---|---|---|
| 1 | 你上一次遇到这个问题是什么时候？ | （填写） | □ 是 □ 否 |
| 2 | 当时你具体做了什么？ | （填写） | □ 是 □ 否 |
| 3 | 当时你用的是哪个现成方案或工具？ | （填写） | □ 是 □ 否 |
| 4 | 那个方案哪一点让你不满意？ | （填写） | □ 是 □ 否 |
| 5 | 你为它实际付出过什么（时间 / 钱 / 精力）？ | （填写） | □ 是 □ 否 |
| 6 | 现在你通常怎么处理这个问题？ | （填写） | □ 是 □ 否 |
| 7 | 你最近一次为此付费或投入是什么时候？ | （填写） | □ 是 □ 否 |
| 8 | 你之前试过别的做法吗？后来结果如何？ | （填写） | □ 是 □ 否 |
| 9 | 这个问题在过去是否给你带来过实际损失？ | （填写） | □ 是 □ 否 |
| 10 | 回顾当时，你最希望有人替你做什么？ | （填写） | □ 是 □ 否 |

> 使用纪律：仅保留「已发生行为」记录；对恭维、空话、他人点子打标并**不计入有效样本**。

## 反模式自查（逐项勾选确认已避免）

- [ ] 未问「你会不会买」。
- [ ] 样本未全部来自熟人。
- [ ] 未把点赞 / 好评当作付费意愿。
- [ ] 未事后调整信号阈值。
- [ ] 未把 MVP 做成「功能简陋的半成品」。
- [ ] 未只验证最容易的假设。
- [ ] JTBD 三问未用功能名词替代 job。

## 完成检查

- [ ] 每张候选卡至少有一条可被证伪的假设。
- [ ] 每张实验卡含「假设 / 对象 / 动作 / 信号阈值」四要素，阈值实验前登记。
- [ ] 验证记录均含具体过去行为。
- [ ] 反模式自查全部勾选通过。
