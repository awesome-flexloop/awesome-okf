# 从选题库到成稿：脚本批量生产中的人工判断节点
> **路线：chaptered-summary（深度摘要 + 原创改写）· 状态：flagged。** 本页来自课程录播的 ASR 派生稿，只回答「课堂讲了什么」，不认证方法有效性；页内表格均为本包自拟，不是课堂原表。证据范围见[课堂覆盖与证据分层](../references/lecture-coverage.md)]。


## 适用与不适用

- 适合已有账号定位与垂直赛道、需稳定批量产出短视频脚本与文案，且已跑通单条、想把临时起意改为可交接流程者；前提是默认机器只铺量出候选、判断权不外包。
- 不适用：未定定位与方向时先补定位；只做单条内容、无批量需求时分层流程收益有限。
- 不适用：期待工具全自动出爆款、不看不改直接发；涉事实强校验或对外负责的表述，本页只给流程、不给结论、不替代专业判断。

## 方法链

整条链按"选题来源 → 标题候选 → 输入框架 → 结构化脚本 → 人工把关 → 热点风控"单向推进，每步产物为下一步输入；机器只铺量出初稿，以下逐节点标注人只在何处判断、何时必须人工接管。

### 一、建选题来源：常备库与热点双轨

先建常备库再接热点。常备库是按主题、按日推进的汇总表，用于落实定位、指引素材收集：把受众常搜关键词、生活场景及痛点、对标切入角度铺成候选，再让工具基于某个关键词或场景扩成具体选题，换平台会改变表达风格。对标借鉴三步——记录角度、归纳优点、按优点写风格相近而表达不雷同的新题，只借视角不复制文案；让工具带"我是谁"构思可避免千人一面。热点为第二轨，从多渠道榜单、新闻端、本领域动态捕捉，先归清背景再从自己领域切入。可迁移做法：同一素材换领域词或受众视角即得差异化选题。判据是三分法——回应需求、叠加实用/社交/情绪价值、体现垂直定位，缺一退回。人只判断：契合定位、自己感兴趣、能否落实。必须接管：候选与赛道无关或无力落实即弃用。常见误用：泛追热点、不指定输入、照抄对标文案。

### 二、出标题候选并做筛选

先给冲击再给信息，批量铺标题候选再收敛成一个定稿。可用"先学习再优化"（先让工具复述对某类手法的理解并确认，再据此撰写）或自提示兜底（先归纳"好标题特质"再据以创作，换平台重新归纳），同一任务可交不同模型各跑一遍择优。判据：标题须关联已成稿正文而非推理过程，才贴合已写内容，生成后逐条核对。人只判断：哪个自己读得下去、与正文对得上。必须接管：未指定输入项而工具自行模拟、或题文不符，一律作废重来。常见误用：把标题挂推理过程、一题多稿不收敛、只看花哨不兑现正文。

### 三、定输入框架与约束

先把跨平台通用框架教给工具并让其确认，再按平台与题材写文案；框架按钩子引入 → 过渡解决方向 → 引导决策 → 鼓励行动分层推进。按人设提要求（活泼或严肃），把成分、参数、详情或已验证信息一并喂入以减少虚构，篇幅按平台调。字段是"写给模型看的示例"、由模型生成，不是让人逐格填表；结构化语法（层级、列表、表格、引用）让模型更准执行，同一框架可换领域换平台复用。判据：调教好的上下文要保留，另起一处等于无记忆新实例、需重喂框架。人只判断：喂入信息是否真实、是否写明"只基于所给信息创作"。必须接管：涉真人真事、数据、引用的输入先核实再喂入。常见误用：整段复制、初稿当终稿、另起对话忘补框架致风格漂移。

### 四、由粗到细生成结构化脚本

顺序固定、逐级细化：视频创意 → 基础信息（标题/类型/受众/核心目标/风格参考）→ 内容构架（信息分层/痛点与方案/呈现方式与时长占比）→ 分镜头设计（时间/画面/镜头语言/音频/字幕）→ 统一视觉风格（色彩/字体/运镜节奏）。每步以上一步产出为输入，产出是"文字设计"而非画面本身。骨架可套若干类成熟结构（痛点共鸣、悬念反转、借势热点、情感共振、颠覆认知、感官刺激），按运营目的有侧重地选、不每条堆满要素；反常识观点抛出后须自我论证。判据：内容构架用来查方向走偏与结构完整，段数不足当轮纠正；长链生成主动管理上下文，被"忘掉"的关键信息贴回本次要求即可续写；需检索新事实才开外部检索、只做构思则关掉。人只判断：方向取舍、结构完整性、风格要素能否落地。必须接管：方向走偏或结构缺段时当轮纠正，不带错进入下一步。常见误用：把文字设计当成片、风格要素全采纳、全篇推倒。

### 五、人工质量把关与局部润色

初稿非终稿，按"输入—润色—检查"收口，核心是逐段改而非全篇重写：先整体肯定，再粘贴指定段落提具体要求（更简洁、控篇幅、加设问反问、加对话），以控制变量、不否定本来不错的部分；一段可要求不同修辞/场景/语气产出多个互有差异的备选择优，也可让另一模型以评审身份互评，或先归纳"高质量内容特质"再让工具据以自我反思、分段修改。四类硬伤即"必须接管"清单：①编造信息——含人物/事件/数据/引语的句子逐条复核来源与上下文，事前只喂已验证信息更稳；②枯燥没"人味"——补比喻、对比、反问、不同句式与生活化词；③缺深度、正确的废话——让工具对第一版自我质疑、指出不切实际处再给可落地应对；④原创度风险——用个人设与特定风格差异化，单句相似度偏高就换例、换修辞、口语化重写。人只判断：哪条建议有说服力、哪个备选更贴受众、哪句需亲自改写。常见误用：一锤子买卖、全篇推倒、把润色文本当已核实事实。

### 六、热点风险控制与人工接管

热点用于破圈触达与增加"人味"，但风险最高、判断权须收回。切入先灌定位并约定产出条数，再让其了解背景，最后据背景构思选题；背景可自行按要素归纳（人事、时地、做法、原因、原话），也可让工具代归纳后与已知核对再采用。受众侧可从趋利避害、析因、长见闻、求认同多角度各做一条；"热点—提问—回答"是稳妥骨架，好问题要能指引行动、含对比冲突或人群关键词以筛选受众。机会面：跨领域破圈、跨领域带货（人群画像相近）、过往沾边内容改表述再发、优先选有持续讨论潜力者并备好不同走向评论。必须接管三道关：相关性（与赛道无结合的热点带来冲乱定位的泛流量，弃用）、题材排查（生命财产损失类灾害与恶性事件、把握不了要点的宏观政策、易引发人群对立的议题，新手避开；负面事件不做营销）、真伪核实（训练数据有滞后，直接问"今天的热点"可能编造，须结合权威媒体核实，不迷信自媒体也不迷信工具输出）；预制改写只改表述、不整段复制。常见误用：直接追问当日热点、蹭负面蹭对立、把代归纳背景当事实。

全链判断与接管节点归纳如下：

| 环节 | 机器主要产出 | 人只在何处判断 | 必须人工接管的情形 |
| --- | --- | --- | --- |
| 选题来源 | 关键词/场景/对标/热点候选 | 定位契合度、自己是否感兴趣且能落实 | 泛追热点、照抄对标、不指定输入 |
| 标题候选 | 多版标题 | 哪个贴合正文、读得下去 | 关联推理过程、未指定输入、题文不符 |
| 输入框架 | 结构化初稿 | 喂入信息是否真实、约束是否写明 | 真人真事/数据/引语凭空补、丢上下文 |
| 结构化脚本 | 逐级细化的文字设计 | 方向、结构完整性、风格可落地性 | 把设计当成片、风格全采纳、全篇推倒 |
| 把关润色 | 备选与评审意见 | 取舍哪条建议、哪个备选 | 编造、没人味、正确的废话、相似度偏高 |
| 热点风控 | 背景归纳与多角度选题 | 相关性、题材、真伪三道确认 | 负面/对立/灾害题材、直接问当日热点、整段搬运 |

## 判据与检查清单

- [ ] 每条选题标注受众需求、价值类型（实用/社交/情绪）、垂直定位，缺一退回重拟。
- [ ] 标题关联已成稿正文而非推理过程；一题只留一个定稿，且自己读得下去、有能力落实。
- [ ] 每轮生成主动指定具体输入项；模型自行模拟、或输出与输入不匹配，一律作废重来。
- [ ] 脚本逐级以上一步产出为输入；每步留"方向走偏/结构完整"书面检查，缺段当轮纠正。
- [ ] 含人物、事件、数据、引语的句子逐条复核来源与上下文；未验证信息事前喂入并约束"只基于此创作"。
- [ ] 热点经"相关性 → 负面/对立排查 → 权威来源核实"三道人工确认才放行；初稿逐段润色不整篇推倒，单句偏相似即换例重写。

## 边界与负向

下列口播内容一律登记为"出现但不采信"、不作事实：各类具体数字（黄金秒数、单镜头/分镜秒数、公式与配比数目、时长字数阈值、字数条数耗时、平台热度、点击率、播放量瓶颈、点赞量、月薪、金额、比例数据等）；效果与收益承诺（踩中一个要素即有播放、几者融合更易爆、短时间海量脚本、一定学得会、一天十几条选题、流量飞速增长、破圈涨粉、品效合一与带货转化、联网质量更高、某公式更易涨粉/卖货等）；身份背书（讲者从业背景、多年经验、课程制作人身份、平台高赞经历、品牌合作经历、对某模型主观评价及所引作家言论）；具体工具名、产品名、平台名、作品名、人名、机构名、金额、条文号等专名已全部泛化或略去，出现但不采信。

归给外部规则或官方口径者一律标为待核验主张、不写成事实：各页分发与审核查重机制、算法茧房、内容生态治理规定、罪名与法律条文、平台热度榜、模型自带思考过程与联网能力、工具"洞察网民习惯"、不同模型思维差异、思想可借鉴而文案不可照抄的法规解释、著作权判定、相似度含义、同对话框保留记忆，及权威数据与名人比例等外部归因。
