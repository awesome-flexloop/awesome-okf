# 从分镜到成片：视觉素材的生产链与收口
> **路线：chaptered-summary（深度摘要 + 原创改写）· 状态：flagged。** 本页来自课程录播的 ASR 派生稿，只回答「课堂讲了什么」，不认证方法有效性；页内表格均为本包自拟，不是课堂原表。证据范围见[课堂覆盖与证据分层](../references/lecture-coverage.md)]。


## 适用与不适用

- 适合已有视频创意或初级脚本、要落成画面并合成成片的阶段；只讲流程与结构，不针对某一款软件，也不替代动手实拍与逐张挑选。
- 适合三类素材混用：自己实拍、生成式产出、网络配图或模板细节；动手前先分清各自产出形态与核对责任。
- 不适合脚本还在概念层、分镜不能逐条描述的阶段，应先补分镜；也不适合当操作手册或合规结论用。
- 授权、标注与平台规范的判断本页不给结论、不构成法律意见，统一登记为待核验主张。

## 方法链

### 一、把分镜与关键帧描述写到位

完整视频里可独立生成的一个小单元是分镜头，描述它该长什么样的文字是分镜脚本；成片逐分镜生成，不是一次出整片。本步产出是后面所有环节的输入，顺序不可颠倒。

**先做什么、后做什么**：把前序创意、分镜表、风格约定交回模型回顾上下文，产出更细更连贯的分镜表；按阶段切分时间轴，对画面、动态、镜头、音效、字幕逐项细化；再把每个分镜转成一条绘图提示词，供后续出关键帧。

**可迁移做法**：两层提示词分开维护——一层是指导模型写提示词的结构化指令，一层是交给绘图工具的绘图提示词。不自己硬写主体、环境、构图的内容，而维护一段按公式组织的指令让模型逐条批量产出。基础公式取主体、环境、构图、风格、参数；要求更高时按复杂度升档，把主体拆成描述与动作情绪、环境拆成场景与光线与前后景细节、风格拆成色调与艺术风格，用示例锚定格式；创意简单时基础版即可。

**判据与检查点**：提示词须与公式要素对应、无需二次拼接即可使用；同一分镜用基础版与升档版各出一组图，从可用张数、风格丰富度、动作神态、前后景细节对比后决定是否升档。

**常见误用**：合并两层提示词；把模型「可直接使用」当免检信号，实际仍需人工核对、多次生成择优。

这是成片质量的第一个决定点：链路顺序不可逆，分镜与关键帧描述一旦粗疏，后续拼接、配乐、包装只能修饰不能补救，质量下限在此被锁定。

### 二、按来源组织素材，并把授权合规前置

三类来源产出形态与核对责任不同，先分清再动手。

- **自拍实拍**：产出无配乐、无字幕的原始画面。先做扎实光与稳定再谈参数：优先自然光、自检顺光，不是就补光或换机位；稳定按「先物理支撑、再电子兜底」；构图用中心、三分、引导线、留白一类通用法，背景简洁或虚化突出主体；按投放场景先定横竖，不盲目追最高规格。
- **生成产出**：产出关键帧静态图与由关键帧动起来的无声、无字幕、无配乐片段。先按「风格＋主体＋背景」结构化提示词，再贴入、调整设置、多次生成择优。
- **网络配图**：只取亮眼细节作参考图学风格与构图，不整版照搬；配图须与上下文关联，不为配图而配图。

**可迁移做法**：结构化提示为补足画面信息——只给孤零零的主体名词，易出肢体错误与机器感；补上风格与质量描述、主体动作神态、环境光照后细节才立得住，改动其中一小部分即能派生多样画面。提示词可借自动补写扩细节、借参考范例固定风格词；参考图按「想固定什么」选维度：只改局部、保留主体换背景、沿用面相与角色特征、沿用色调构图。

**合规边界（不写成结论）**：可让工具学风格流派，但不要生成受保护的具象美术形象，换服装换风格只要仍含该形象就有风险；避开真人肖像二次创作，泛化形象可以、移接真人姿势不行；配图画风与尺寸一致、避免非本人水印。

**常见误用**：把「合理使用」「生成内容标注要求」「封面规范」「商用授权与版权检测结论」当已确认规则照做；这些归给外部规则或平台口径的说法均标为待核验主张。

生成素材的风险要逐类人工核对，把课堂散落的核对动作归成一张自拟表：

| 风险类别 | 典型表现 | 人工核对动作 |
| --- | --- | --- |
| 结构与要素 | 肢体错误、机器感、动作神态缺失 | 逐条对照分镜编号与画面描述，确认提示词对应公式要素 |
| 随机性与质量 | 不保证按提示词出图、不保证质量稳定 | 确认提示词与设置无误仍不佳才多次生成取最优；不用抽卡替代提示词优化 |
| 形象与肖像 | 受保护具象形象、真人肖像移接、非本人水印 | 逐张确认形象边界、上下文关联、画风尺寸一致；授权与标注另行核验 |
| 识别与转写 | 自动生成音乐、自动识别字幕与歌词有错字误识 | 试听择优、逐条改错字、校对字幕起止点，批量套用后仍抽查 |
| 规格与清晰 | 初稿画质偏低、高控制度参考限制画面 | 先做画质提升再入链，确认参考范围与强度符合构图 |

> 表格 ≠ 课堂原表：本表为教程自拟归纳，课堂讲义表格／模板截图未取得。

几类易被当成「自动即终稿」而漏检：提高创意自由度却降低提示词遵循的开关，严格按脚本出片时不宜依赖；轮廓、景深、姿势一类高控制度参考会大幅限制提示词；自动产出一律要过「试看试听 → 逐条校对 → 再入轨」人工关。

### 三、用视觉一致性约束贯穿全片

**先做什么、后做什么**：分镜阶段就固定一套风格约定（写实或艺术化路线、色调、画风、比例），后面自拍机位光位、生成参考图、后期滤镜都对齐它，不各自发挥。

**可迁移做法**：把风格约定作为独立模块随上下文交回模型，避免分镜与设定脱节；生成侧用同类图做综合风格参考，实拍侧固定同一光位与背景基调，设计侧字体统一、标题与正文层级清晰、对齐规整、要素呼应重复。封面主体突出、文字简略、留视觉钩子，内页承载信息且不喧宾夺主。

**判据与检查点**：全片画风与尺寸一致；比例先定一次、不反复。

**常见误用**：靠后期滤镜抹平上游风格漂移——一致性要在素材生产时约束，收口补救已晚；转场与特效别过多。

### 四、拼接、配乐、字幕、封面的成片收口

前提是素材已就位，先素材后剪辑。顺序：按剧本逻辑拼接 → 配乐与插曲 → 校对字幕 → 花字包装 → 封面设置 → 导出。

**可迁移做法**：拼接按导入、排定先后、逐段剪断与调尺寸推进，区分「往轨道里加什么」与「对素材做什么」。卡点类短片以音乐为主体，先在重音处标基准再逐段对齐。曲库无贴合曲目、曲目受版权限制或情节需专属音乐时考虑原创配乐，按有无歌词分插曲与背景音乐，用曲风关键词检索试听，以与画面节奏是否匹配为采纳判据；原创曲目一次性说清主题、文化元素、风格与节奏情绪，多版择优。音效按画面物件关键词检索、放到对应片段轨道。字幕按素材类型选路径：歌曲语音自动识别、自口播去语气词、已有文稿直接导入；识别后逐条改错字，改一处模板让其余样式跟随。花字用大字与动效强化层级，做好一处复制到同类画面。封面可生成、截取画面或套文字模板，须符合平台封面规范（归平台口径，待核验），可在导出时加到片头。

**判据与检查点**：字幕起止点对齐对应声音起点与素材；音效比配乐长就裁掉多余；硬切结尾给音效加淡出；全片预览一遍再收口。

**常见误用**：把自动生成结果当终稿；把「持续发布即可带来流量」当方法（见边界与负向）。

这是成片质量的第二个决定点：收口段不生产新画质，作用是别损失上游质量、把自动产出校对到可用。决定可用度的是「进入时间线的素材是否已逐张挑选、逐条校对」，而非包装堆得多满。

### 五、导出前检查

**先做什么、后做什么**：跑通完整流程后，先逐项核对导出参数，再填标题、选位置导出。

**可迁移做法**：检查分辨率、帧率、编码、容器格式、码率、比例与音频导出；容器选通用兼容的一类；规格越高，存储与渲染开销越大，草稿规格低于导出设置时可智能补足，帧率不统一时统一，其余保持默认。

**判据与检查点**：比例与投放场景一致；导出前全片预览，确认字幕起止点、音效淡出与封面就位；逐项核对参数。

**常见误用**：把「码率越高越清晰」「某格式大部分平台都支持」当事实照搬（经验说法，见边界与负向）；只记界面分区不跑完整流程。

## 判据与检查清单

- [ ] 分镜提示词是否逐条与公式要素对应、无需二次拼接即可用；两版是否做过同分镜出图对比？
- [ ] 两层提示词是否分开维护、分别核对？
- [ ] 每条生成素材是否经过「试看试听 → 对照分镜要素 → 多次生成择优」；自动字幕是否逐条改过错字？
- [ ] 全片画风、尺寸、色调、比例是否一致；风格约定是否在上游固定，而非靠后期滤镜补救？
- [ ] 是否逐张确认形象边界、无真人肖像移接与非本人水印、配图关联上下文；授权与标注是否另行核验？
- [ ] 导出前是否逐项核对分辨率、帧率、编码、容器格式、码率与比例，并全片预览确认字幕起止点、音效淡出与封面？

## 边界与负向

- 出现但不采信：清晰度、分辨率与帧率档位、耗时、生成数量、免费次数、配图频次等经验数值与规格；「质感翻几倍」「码率越高越清晰」「持续发布即可带来流量增长」等效果与收益承诺；「上手最简单」「免费功能足够用」等主观比较与身份背书，均只登记、不写成事实。
- 待核验主张：把素材商用授权、版权检测结论、著作权合理使用、生成内容标识、平台封面规范与标注要求、平台用户协议、投放比例要求、工具计费口径等归给「官方规则」或外部口径的说法，一律标为待核验主张，不写成事实、不构成法律意见。
