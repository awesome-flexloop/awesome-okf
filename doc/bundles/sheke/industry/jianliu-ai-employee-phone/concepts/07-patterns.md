# 07 · 可迁移模式

> 两个模式均为 **L1（单案例，待验证）**：来源是 2026-11-01 对剪流AI 官网的单次解构。它们已在迁移示例中做过跨场景演练，但尚未在第二个真实项目中复现。

## 模式一：四层证据分层法

| 项 | 内容 |
|---|---|
| **名称** | 四层证据分层（L0 官方登记 / L1 页面事实 / L2 厂商自述 / L3 同稿软文） |
| **触发场景** | 评估对象的**主要信源由厂商自己掌握**（官网、白皮书、官方公众号、招商页），且缺乏第三方实测 |
| **一句话** | 先给每条主张贴层，再决定它能进哪张表——L2 进「引用区」，L3 只进「传播行为样本区」，永不进证据区 |

### 核心步骤（5 步）

1. **划线**：把全部主张按来源切成四层，写进一张表（F 编号 + 层 + 定位）。
2. **降级**：凡来自厂商或厂商供稿媒体的，一律降为 L2；凡多篇软文使用同一句式/同一数字，判为同稿。
3. **找矛盾**：同一主体在不同页面/不同信源上的表述做机械比对，列出矛盾清单。
4. **留可复核路径**：为每个 L0 项写出「去哪查、查什么、记录哪几个字段」。
5. **限定引用**：所有 L2 引用必须带「厂商自述/未实测」限定词，禁止与 L0/L1 数字混算。

### 反模式（3 个，均来自本次实录）

- ❌ **把「多篇媒体转载」当多源验证**：搜狐号、北京科技报、中华网使用同一备案编号与同一句式，属同稿（见[采集台账](../references/source-manifest.md)「同源判定」）。
- ❌ **把「页面数字一致」当交叉验证**：首页、`/solutions/`、`/phone/` 的「8 模块 / 40+ 功能」来自同一文案源（F-002、F-014）。
- ❌ **L2 与 L1 直接相除**：用「4,980 元/台」除「一年省几十万」得出 ROI——分子分母不在同一层，且后者无凭证。

### 检验标准

- [ ] 每条主张都能指到唯一一层；
- [ ] 至少列出 3 条矛盾或缺口（本次实录 5 条矛盾 + 10 项缺口）；
- [ ] 每个 L0 项都有可执行查询路径；
- [ ] 全文搜索「厂商称/页面称」等限定词，L2 覆盖率 100%。

### 迁移示例（非当前领域）

**医疗设备采购评估**：厂商提供的临床数据属 L2；国家药监局注册证属 L0；医院公开的使用报告属 L1（若可查）；行业媒体转载稿属 L3。同一台设备的「年节省人力」与「注册证适用范围」不能混算——与本案例的分层逻辑完全同构。

## 模式二：三账验收法

| 项 | 内容 |
|---|---|
| **名称** | 三账验收（功能账 → 任务账 → 资产账） |
| **触发场景** | 评估「一机多岗」「一人多能」「一套系统顶 N 个人」类方案——即价值锚定在**替代人力**而非**完成功能**的产品 |
| **一句话** | 不验收能力清单，验收三本账；顺序不可颠倒，资产账权重最高 |

### 核心步骤（4 步）

1. **功能账**：从能力清单里只挑与采购目的句相关的项，现场演示，不能演示的记缺口。
2. **任务账**：1 个岗位 × 1 类客户 × 10 条真实线索 × 2 个人（第二人用于测可复制性），记录耗时、返工、异常。
3. **资产账**：导出全量台账、模拟离职交接、核对权限回收。**资产可导出率必须 100%。**
4. **定线**：五项验收指标（功能覆盖率 ≥90%、耗时降幅 ≥30%、返工率 ≤基线、可导出率 =100%、缺口关闭率 ≥4/6）在试点**开始前**由采购方定，不由厂商定。

### 反模式（3 个）

- ❌ **只验收功能清单**：46 条目全部演示通过，但没人回答「哪个任务变快了」——本次实录的功能条目存在 6 项跨模块重复（F-013），清单本身不等于工作量。
- ❌ **用厂商提供的演示线索**：演示线索通常已被清洗，任务账会虚高；必须用真实线索。
- ❌ **跳过资产账**：终端与 AI 都能换供应商，客户台账换不了；不验资产账，等于把最贵的东西交给最不可控的一方。

### 检验标准

- [ ] 采购目的句含时间/任务/频次/质量下限四项；
- [ ] 任务账有两人数据；
- [ ] 资产账有导出包与交接记录；
- [ ] 五项指标在试点前书面确定；
- [ ] 结论未使用任何厂商提供的效果数字。

### 迁移示例（非当前领域）

**AI 编码助手评估**：功能账 = 支持的代码补全/重构类型；任务账 = 同一个真实缺陷由两名工程师分别用/不用助手修复，记录耗时与返工；资产账 = 代码仓库、知识库、提示词资产能否迁走（换工具后是否被锁定）。同构关系：**替代人力的话术 → 必须用任务账还原；锁定风险 → 必须用资产账兜住。**
