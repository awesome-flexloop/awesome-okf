# 规则条款

> 本篇登记细则中与**资格、内容、权利、发放**相关的条款，逐条挂 F 编号。凡涉及"能否获奖""奖怎么发"的推理性判断均标注「洞察/推断」。
>
> 活动规则可依 F-106 由主办方调整（提前通知后在活动页公示），本篇所有内容以采集时点 2026-10-24 的页面版本为准。

## 一、有效参与的两项资格条件

| # | 条件 | 事实 |
|---|---|---|
| ① | 拥有有效的 WorkBuddy 账号，并通过**资料库活动入口**完成投稿 | F-081 |
| ② | 提交本人原创或在已有作品基础上完成**实质改造**的应用，并提供**可核验的发布链接或体验方式** | F-081 |

- 细则明示：**仅提交创意说明或静态设计稿不视为有效作品**（F-082）。
- 细则另有一条：使用 WorkBuddy 创作并发布一件**可供他人体验**的作品，题材不限（F-023）；网页应用定义中包含**资料库网页作品**（F-024）。

> **口径辨析（事实归纳）**：细则在两处对"作品"提出可核验性要求——F-081 的「可核验的发布链接或体验方式」与 F-023 的「可供他人体验」。前者强调**链接可核验**，后者强调**体验可达成**；表单侧对应 F-059「上传未能正常体验的链接不作为有效体验链接」。三条合起来构成同一个门槛的两面。

## 二、八类资格取消情形

主办方有权单方面取消参与资格与获奖资格，并有权追回已发放的奖品（F-083）：

| # | 情形 | 事实 |
|---|---|---|
| 1 | 不符合参与资格 | F-083 |
| 2 | 同一实际参与主体重复提交相同作品（有权**合并重复投稿**或取消相关资格） | F-083、F-084 |
| 3 | 提供虚假信息 | F-083 |
| 4 | 虚假交易或恶意破坏活动 | F-083 |
| 5 | 以机器人软件、蜘蛛软件、爬虫软件、刷奖软件或**任何自动方式**、不正当手段参与 | F-083 |
| 6 | 违反诚实信用、公序良俗、公平、公正等原则 | F-083 |
| 7 | 作品存在违法违规或侵权内容 | F-083 |
| 8 | 其他违反相关法规、本规则的行为 | F-083 |

- 缺口 G-05：细则**未给出"何谓相同作品"的判定阈值**，仅授权主办方合并重复投稿。

> **落点（洞察/推断）**：第 5 项把"任何自动方式"列为取消资格事由，指向的是**刷奖自动化**而非参赛过程自动化——但条文措辞宽泛。稳妥做法是**全部操作手工完成**：手动填表、手动分享、手动上传截图，不使用任何自动填表或批量提交工具。

## 三、有效发放的构成要件与异常发放

### 有效发放的三项构成要件（须同时满足）

1. 发放对象具备参与资格且未违反本规则；
2. 发放的奖励种类、数量、面值与活动载明的应发内容一致；
3. 发放过程未受下述异常发放情形影响。

事实：F-085。

### 异常发放的处理

| 项 | 内容 | 事实 |
|---|---|---|
| 触发情形 | 系统漏洞、程序缺陷、配置错误、数据同步异常、库存超卖，或网络攻击、第三方服务中断、不可抗力等**非因主办方真实意思表示**的原因 | F-086 |
| 法律效果 | 导致的少发、多发、错发或重复发放，**自始不发生给付效力** | F-086 |
| 主办方权限 | 有权直接冻结或收回相关奖励 | F-086 |
| 用户义务 | 奖励已被使用、转赠、兑换或提现而无法原状返还的，用户应返还等值价款 | F-086 |
| 抵扣权 | 经通知后用户未在 **15 日**内返还的，主办方有权从其他奖励、收益或应付未付款项中抵扣等值金额，并保留依法追偿及要求承担合理维权费用的权利 | F-087 |
| 应发未发 | 主办方应在合理期限内补发礼品，或经用户同意以等值替代礼品履行 | F-088 |

> 缺口 G-10：结果公布后 7 个工作日的发放起算点（公示当日 or 另有通知节点）未明确。

## 五、作品内容要求

### 5.1 权属与脱敏

| 要求 | 内容 | 事实 |
|---|---|---|
| 独立制作 | 投稿内容应为本人独立制作 | F-094 |
| 不侵权 | 保证不侵犯第三方合法权益，含著作权、商标权、形象权、名誉权 | F-094 |
| 不泄密 | 避免展示、上传或披露任何保密信息、商业秘密、客户信息、个人信息或第三方受保护内容；如需展示工作流，**应使用脱敏、示例化或公开资料** | F-095 |

> 缺口 G-14：细则**未给出正面许可清单**——是否允许第三方素材、第三方 API 或他人模型输出没有明示。仅"不侵权"与"不得泄密"两条约束。

### 5.2 禁止内容清单

不得含有（F-096）：

1. 违反国家法律法规、危害国家安全统一、破坏社会稳定、违反公序良俗以及侮辱、诽谤、淫秽或含有任何性或性暗示、暴力的内容；
2. 侵害他人名誉权、肖像权、知识产权、商业秘密等合法权利的内容；
3. 涉及他人隐私、个人信息或资料的内容；
4. 骚扰、广告信息及垃圾信息；
5. 恶意虚构事实、隐瞒真相以误导、欺骗他人的内容；
6. 其他违反法律法规、政策及公序良俗、社会公德或侵犯其他用户或第三方合法权益内容的信息。

**另有专项禁止**（F-025）：作品不得提供违反社会公序良俗或法律法规要求的内容，细则点名禁止**算命、占卜、塔罗牌占卜、八字排盘、星盘占星**等以预测命运、运势为目的的功能或内容；主办方将结合作品实际功能及展示文案审核，不符合要求的作品不予展示或参与评奖（F-026）。

>
> | 束 | 实测内容 | 风险判定 |

### 投诉举报

发现活动展示投稿侵犯合法权益或违反法律法规的，可发送邮件至 `workbuddy@tencent.com` 投诉举报，主办方在审核后及时处置并告知结果。事实：F-100。

> **与撤回的关系（事实归纳）**：撤回是**投稿人**对自己投稿的处置，投诉是**任何人**对已上墙投稿的举报，两者邮箱相同但法律效果不同——撤回只影响评审资格，投诉可触发主办方对**他人**作品的下架处置。
