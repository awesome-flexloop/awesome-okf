# P0 核验报告

> 本报告核验对象为 [原文事实清单](article-source.md) 登记的 F-001~F-196。
> **结论摘要**：22 个 P0 细分项中 ✅3 / ⚠️13 / ⭕3，**❌3**。
> 原文最常见的失效方式不是把数据说反，而是**省掉统计口径、跨时点拼接、以及用比喻替代定义**；但也有 3 项确属**事实错误**（E-19 日本杠杆率见顶年份、E-21 杠杆率年度降幅、E-23 S7 核心预测被官方数据证伪），另有 2 项原列为"方向成立"却在勘误中被**升级为硬错误**（E-01、E-09）——它们不是事实相反，而是**结论与事实相反**（按原句使用会得出错误决策）。
> 此外，S7 发布后一个月内的官方数据已**证伪**其核心预测（见第 18 项与 E-23），构成最直接的单源失效证据。
> 因此本知识包采 `status: flagged`。

## 核验方法与可回溯性声明

- 核验以**公开发布主体**为第一信源：国家统计局、国家资产负债表研究中心、中国人民银行、巨潮资讯网（法定信息披露）、交易所年报与审计报告、文旅部、尼尔森 IQ；辅以公开检索交叉比对。
- **深链 URL 不固化**：本报告记录「发布主体 + 指标名 + 时点 + 结论」，不固化具体页面深链。原因是检索结果的链接稳定性受平台改版影响，固化深链会在数月内转为死链，反而制造伪可溯源。读者可按上列三元组（主体 / 指标 / 时点）复核。
- **单源标注**：凡在正文中以事实语气出现、但检索不到独立出处的数字，一律标 ⭕（单源），并在勘误清单中单列；不得因其出现在原文中而升格为已核验事实。
