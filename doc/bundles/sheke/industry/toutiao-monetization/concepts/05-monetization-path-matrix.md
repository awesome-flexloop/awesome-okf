# 变现路径矩阵：体裁选择、粉丝档位与推进节奏

> **零承诺声明**：本篇不含任何收益点值或保底承诺。官方不发布单价（F-047），所有收益表达均用公式结构与倍数区间（依据 [02 篇](02-revenue-formula.md)）。社区流传的单价数字（F-087、F-092、F-101）一律不作引用。

## 一、路径选择的三问

在选体裁前先回答三个问题，答案决定后续所有动作：

1. **能否稳定产出 72 小时内不跨平台发布的独家内容？**——决定是否声明首发（F-006、F-025、F-026）。
2. **能否持续制造可被计数的互动行为？**——决定能否拿到 1~3 倍的互动系数（F-039）。
3. **是否有可验证的垂类受众？**——决定能否挂上五大质量标准中的「用户价值」（F-016）与「信息增量」（F-014）。

三问中有任意一问为否，则**放弃首发声明**，只做基础分成路径——这是风险敞口最小的选择（详见 [01 篇](01-first-publish-incentive.md) 第二节三态结构）。

## 二、体裁 × 权益矩阵

| 体裁 | 开通门槛 | 收益公式适用 | 独有收益项 | 关键约束 | F 编号 |
|---|---|---|---|---|---|
| **文章** | 0 粉（加入创作者计划） | 千次阅读单价 × 互动系数 × 获利阅读量/1000 + 首发补贴 | 「阅读时长」纳入千次阅读单价计算（F-040）→ 长文单价含时长权重 | 需投放广告（F-067）；单篇成本高 | F-050、F-040、F-066、F-067 |
| **微头条** | 0 粉（2023-11-20 起） | 同上 | 发布门槛最低 | **非转发抽奖类**才有收益（F-064）；单价含「阅读量」项（F-040） | F-063、F-064、F-050 |
| **视频** | 0 粉（加入创作者计划） | 视频创作收益，广告展示在视频开始或结尾处 | — | 中视频伙伴计划**已停止加入审核**（F-082），新作者无该通道 | F-050、F-082 |
| **问答** | 口径缺口（千粉为历史官方口径） | — | 原创回答可获「原创」标识与更多推荐与分成 | 现行权益阶梯未列出该权益（F-050~F-052） | F-077、F-078、F-050 |
| **图文 / 视频赞赏** | **千粉** | 读者自愿打赏，收益全部归作者 | — | 需粉丝达 1000（F-051） | F-051 |
| **付费专栏** | **万粉** | 用户付费后按比例分成 | 「睡后收入」形态 | 需粉丝达 10000（F-052） | F-052 |
| **商品卡** | **万粉** | 用户购买并**确认收货**后获佣金 | 电商化收益 | 需粉丝达 10000（F-052）；选品与转化率自担 | F-052 |
| **头条抽奖** | **万粉** | 本身不直接产生收益 | 互动与涨粉工具 | 需粉丝达 10000（F-052） | F-052 |

**体裁建议（分析推断，非平台口径）**：

- **起步期**：文章 + 微头条双轨。微头条单篇成本低、试错快（F-063、F-064），用于测垂类与话题；文章用于沉淀可长期分发的原创资产（F-040 时长权重）。
- **视频**：中视频通道对新作者已关闭（F-082），除非已有西瓜 / 剪映发布习惯，否则不宜作为起步体裁。
- **粉丝未到千粉前**：赞赏、专栏、商品卡三条变现通道**均不可用**（F-051、F-052），此时唯一收入来源是基础分成 + 首发补贴。

## 三、90 天推进节奏

各阶段的动作与验收标准（不含收益预期）：

### 第 1-7 天：合规起步与权益开通

| 动作 | 依据 |
|---|---|
| 注册正式版今日头条 APP（**极速版与专业版不支持查看创作权益页**，F-120） | 官方权益入口在正式版 APP 的「我的 - 创作中心」（F-059） |
| 完成实名认证（个人账号提现前置，F-065） | F-065 |
| 加入创作者计划 → 开通文章 / 微头条 / 视频创作收益 | F-059、F-050 |
| 在「创作权益」页确认信用分**不低于 60 分**（60-99 分可使用已有权益；100 分是申请/恢复新权益的门槛） | F-054、F-057、F-058 |
| 确认账号「内容同步授权」默认状态（影响首发判定） | F-026 判例四 |

> **两条入口都要知道**：手机端「我的 - 创作中心 - 查看创作权益」；电脑端头条号后台「成长指南 - 创作权益」（F-059）。**提现、赞赏开通等后台操作必须在电脑端完成**，仅用 APP 会找不到入口。

**验收**：创作中心「权益中心」显示三项基础权益已点亮（F-050）。

### 第 8-30 天：垂类定位与互动基线

| 动作 | 依据 |
|---|---|
| 锁定单一垂类，产出 15-20 篇覆盖该垂类的文章 + 微头条 | 互动系数与用户价值需垂类语义一致（F-016、F-039） |
| 每篇文末设**具体**问题（而非「欢迎留言」） | 引导评论与进评论区（F-039） |
| 每 5 篇做一篇「值得收藏」的清单 / 工具型内容 | 收藏与进主页是计数互动项（F-039） |
| 每周复核一次信用分 | F-055、F-058 |

**验收**：后台「图文创作收益 - 创作收益构成 - 文章」可查看千次阅读单价与作者系数，点击「系数详情」查看各系数计算规则（F-046）；并记录单篇的阅读量、评论数、收藏数（官方给出的间接观测口径，F-105、F-107）。

> **⚠️ 不可作为验收项**：**互动系数当前无官方查看渠道**（F-105）。不要把「在后台看到互动系数」写成操作目标——官方明确「平台暂未开放『互动系数』的查看渠道」，创作者只能通过内容分析板块的单篇数据（阅读量 / 评论数 / 收藏数）间接判断互动表现。官方给出的低互动率诊断口径是「评论量 < 5、收藏量 < 5」（F-107）。

### 第 31-60 天：首发策略试水

| 动作 | 依据 |
|---|---|
| 挑 3-5 篇**确信能过五大质量标准**的内容声明首发 | F-005、F-012~F-016 |
| 发布前逐条核对原创 / 非首发认定清单 | F-022~F-026、F-027 |
| 72 小时内不在其他平台发同内容（含自动同步） | F-006、F-026 |
| 对比首发篇与非首发篇的实际收益构成 | F-011 的分解结构 |

**验收**：在后台「创作中心 - 收益数据」可分别查看千次阅读单价、首发补贴、基础分成收益三项（F-105、F-121），据此对比首发篇与非首发篇的补贴项差异。

### 第 61-90 天：档位解锁或结构固化

| 分支 | 条件 | 动作 | 依据 |
|---|---|---|---|
| A | 粉丝 ≥ 1000 | 开通图文 / 视频赞赏权益 | F-051 |
| B | 粉丝 ≥ 10000 | 评估付费专栏 / 商品卡 | F-052 |
| C | 粉丝未达标 | 继续加固互动系数与首发质量 | F-039、F-034 |
| D | 出现低质内容提示 | 停止扩产，回到内容质量自查 | F-035、F-062 |

### 第 91-180 天：下一档动作（承接「然后呢」）

| 分支 | 30 天动作 | 可观测验收 |
|---|---|---|
| A（已千粉） | 开通图文赞赏后，在高共鸣长文与视频中主动引导打赏；同时保留基础分成主线，不依赖打赏 | 赞赏权益卡片显示已开通（F-051）；单篇开始出现赞赏记录 |
| B（已万粉） | ① 付费专栏：先以 3-5 篇系列内容试水，验证完读与复购意愿再定价；② 商品卡：从与垂类强相关、售后风险低的品类起步，观察「购买并确认收货」的转化口径 | 专栏 / 商品卡权益卡片已点亮（F-052）；收益明细中开始出现对应收益项 |
| C（仍低粉） | 转向「单篇质量最大化」：每篇必过五大质量标准（[01 篇](01-first-publish-incentive.md) 第三节），并把内容拆成系列以积累长尾阅读 | 首发篇的补贴项在收益明细中可辨识（F-105）；单篇评论数 / 收藏数高于第 8-30 天基线 |
| 全部 | 关注**创作认证权益**（新锐 / 领航）——2026-02-02 起其收益激励改为按自然周累计阅读量达标解锁现金或分成翻倍奖励（F-112~F-117） | 创作权益页「创作认证权益」卡片可查看具体规则（F-118） |

## 四、收益表达纪律（对外沟通时必须遵守）

| 不可说 | 应说 | 理由 |
|---|---|---|
| 「头条千次阅读单价是 X 元」 | 「收益按千次阅读单价 × 互动系数（1~3 倍）× 获利阅读量计算，单价由平台逐篇动态评定」 | 官方不发布单价（F-047、F-046）；F-087/F-092/F-101 为第三方估算 |
| 「声明首发拿 3 倍收益」 | 「声明首发可获得动态额外补贴，优质内容有机会达 5 倍上限，无 3 倍保底」 | F-034、F-032、F-076 |
| 「每天发 X 篇，月入 Y 元」 | 用「阅读量区间 × 系数区间 × 补贴区间」表达，并标注为区间估算 | F-037、F-039、F-034 |
| 「微头条要 100 粉才能开收益」 | 「微头条创作收益为 0 粉基础权益」 | F-063、F-050 |
| 「新账号能加入中视频计划拿三平台分成」 | 「中视频伙伴计划自 2024-09-09 停止加入审核」 | F-082 |

## 五、退出与止损条件

任一条触发即应暂停该策略：

| 条件 | 处置 | 依据 |
|---|---|---|
| 信用分跌破 60 分 | 收益权益已熔断，先恢复合规（连续 10 天无违规 + 10 分），期间阅读量不计入收益 | F-058、F-074、F-055 |
| 首发功能被冻结 | 14 天内不可声明首发（F-020），期间放弃该杠杆 | F-020 |
| 累计 2 次被识别为不鼓励内容 | 首发功能永久关闭，需重建内容策略 | F-021 |
| 多次发布低质内容被移出创作者计划 | 全部权益失效，需从内容质量层重建 | F-062 |
| 单篇评论数 / 收藏数持续低于官方诊断线（评论 < 5、收藏 < 5） | 回到 [04 篇](04-mechanism-insights.md) 洞察一的互动钩子设计（互动系数无查看渠道，以单篇数据替代观测） | F-107、F-039、F-105 |
| 千次阅读单价 / 作者系数持续走低 | 检查体裁与内容结构（文章靠阅读时长、微头条靠阅读密度进入单价计算，F-040），并对照「系数详情」定位是哪一项系数在跌 | F-040、F-046 |

## 六、迁移说明

本矩阵的**结构**（合规前置 → 权益开通 → 互动调优 → 独家加杠杆）可迁移到其他平台自媒体运营：把「平台规则版本」替换为对应平台的现行规则即可复用骨架，但**所有门槛与倍率必须重新按各自平台官方口径核验**，不可平移头条数值。
