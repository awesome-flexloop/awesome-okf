## 6. flagged 判定

**核心结构声明获多源确认**：首发激励计划存在性与其规则全文（S1 + S4 + S5 三源交叉）、文字分成公式与三次升级时点（S7 + S8 + S12）、创作者计划三档权益与信用分三档（S2 + S3 + S9）、中视频计划停止加入与存量处置（S11 + S17 双源）、新锐 / 领航认证权益点值（S16）。

**判为 flagged 的理由**：

1. **单源占比**：121 条事实中 15 条为 UGC / 商业站单源，占比约 12%，虽均已降级为对照用途，但整包事实清单仍含此部分；
2. **官方口径缺口 3 项**未闭环（见第 5 节）；
3. **规则高频变动**：2024-06 至 2026-02 的 20 个月内至少变更六次（F-036、F-042、F-044、F-099、F-100、F-117），变动频率约 3~6 个月一次；
