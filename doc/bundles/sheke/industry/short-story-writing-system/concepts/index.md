# 教程路径

先分清四种陈述，再看课程结构；准备把任何方法用于真实投稿前，务必读完第 04 篇的证据分层与第 06 篇的适用范围。七篇可以单独阅读，但结论不要跨篇混用：结构篇回答「材料长什么样」，方法篇回答「公开材料里有哪些可迁移的做法」，两者不是同一种断言。

| 篇目 | 读者要回答的问题 |
|---|---|
| [先分清四种陈述](00-reading-and-evidence.md) | 哪些已核验，哪些只是单源宣传，哪些是第三方转述，哪些是本包自己下的定义？ |
| [课程结构与两套大纲](01-course-structure-and-two-syllabi.md) | 39 节课怎么构成？为什么详情页、售卖页、宣传图的目录对不上？ |
| [拆爆款与找素材](02-deconstruct-hits-and-source-hunting.md) | 「拆爆款」能拆出什么？素材从哪里来？七步骨架为什么不能当唯一公式？ |
| [短篇文体规范](03-short-story-form-conventions.md) | 这类短篇有哪些形式特征可检查？这些检查项是谁写的？ |
| [投稿与变现口径](04-submission-and-monetization.md) | 收稿、反馈、分账三类说法分别是谁说的，能不能互相印证？ |
| [AI 辅助写作边界](05-ai-assisted-writing-boundary.md) | AI 被放在链路的哪些位置？平台侧规则为什么要另查？ |
| [单源主张与适用边界](06-claims-and-boundaries.md) | 哪些句子不能用，什么时候该重读？ |
