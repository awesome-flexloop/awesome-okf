# 人物立得住：从原型到弧光的检查顺序

## 方法链

### 主路径有先后：原型 → 框架 → 加工 → 真实

课堂把「把扁平人物写成人」拆成四步，并明确顺序不可跳：先从现实里找到人物最早的影子，再在动笔前把框架想透，然后做个性化加工，最后校验真实感。给出的反例是「写到一半才回头补设定」——框架没搭好，后面会越写越崩。可迁移的判据是：**人物先成立，故事才撑得起来；框架决定成立，加工决定被记住**，两者是不同工序，不能用「多写几段细节」代替其中任何一步。

找原型这一步给了两个长期动作：给身边熟悉的人各写几行观察日记，按性格、习惯、兴趣、身姿、动作、语言、信念等维度逐项记，能写出具体细节才算到位；随身记下一句有趣对话、一个反常动作、一句戳人的台词，并**定期回看整理**，碎片才会连成线索。观察维度清单与两个记录动作都是可照做的检查项，但本包不认证其效果。

### 框架：人物三维，以及「先定读者再设三维」

框架用一个可复用的三分法：外在因素（外貌、穿着、动作，决定读者第一眼怎么判断）、社会因素（身份、地位、教育、职业、关系处境，决定人物处在什么位置、如何与人互动）、心理因素（性格、价值观、秘密与心魔，决定人物怎么做选择）。判据是**人物的一切行为与选择都应能回到这三维里得到解释**；缺一维，人物就薄一层。

顺序同样硬：先确定「写给哪类读者、什么题材」，再设三维。课中给的读者匹配反例是青春题材配老成世故的主角、同类题材对不同年龄或身份读者套同一套人设。可迁移的结论是人物设定服务于读者，不是反过来。

### 加工三方向：高亮特点、层次与矛盾、标志性动作

- **高亮特点**：给主角强辨识度，但硬约束是这个特点必须与整个故事和谐、连续、完整。反例是高智商布局类题材把主角设成冲动易怒——醒目是醒目了，却与周密设定打架，抬高理解成本。判据是「既醒目，又刚好长在故事需要的位置」。
- **层次与矛盾**：立体感来自性格复杂性，矛盾须是人物内心真实冲突、有来处，而不是凭空加戏；把人写成单一标签是禁忌。
- **标志性动作**：安排能代表生活习惯的小细节，判据不是精彩而是**足够真实**，能让读者产生「这像我」的连接。

人物成立之后还有一步「更有趣」：创造反差（极强与极弱、极冷与极暖并置）与强调对比（表象属性对外表露，真相属性只在**付出代价的选择**中揭示）。反差要自然，生硬就变成刻意；对比靠两者落差制造推动力。

### 弧光三柱与真实感

弧光被定义为人物变好或变坏的变化轨迹线。短篇里落成三柱：① **目标**——主角要有贯穿全文的目标，能自己作决定、其行为能带来变化，无目标／不决定／不影响变化就是无趣的反例；② **意外**——先让读者相信主角有能力追目标，再安排意外制造转弯与张力；③ **结果**——终极目标不变但中途可多次转弯，由意外引出转折、转折带来改变，人物走向归宿。三者齐备才撑得起弧光。

最后校验真实感：它不等于人物必须现实存在，也不等于照搬丝毫不差，而是人物在故事里符合自身设定的喜怒哀乐，且读者能在他身上看到与自己相像之处。代入方法是先明确写给谁，再把自己带入「一个具体存在的人」，按其人生阶段、面临的主要事件、关系处境、家庭状况与社会关系复杂度去写。共情不必来自正面形象，也可来自让人看清本性的选择。

### 配角：两类作用与短篇数量约束

配角只承担两类作用：**推动情节**（阻碍或帮助主角达成愿望，逼主角动起来）与**塑造主角**（从侧面映射性格与成长）。判据是每个配角都应让主角离目标更近或更远一步、是主角的一面镜子，而不是背景板或凑数；配角自身也要有亏欠、经历与个性。课中给出的短篇专用约束是数量不宜多、并给了明确上限，理由是多一个配角就多一份交代成本，视角频繁切换会稀释主角、读者觉得注水；反例是主角主线还没想明白就大量给配角加戏。**该上限属课堂口述的具体数值，本包登记为课堂主张而非可核验规则**，不用它推断平台标准。

### 人设取向：反套路与接地气

两项取向分工不同：反套路负责「脱颖而出」，做法是在题材惯例内部打破读者预期（把传统陪衬类型提为主角、把本该后期反转的设定一路保持），约束是情理之中、意料之外，不为反而反；接地气负责「让人相信」，做法是优先选大众认知度高的身份背景，让读者省去理解动机的成本，判据是一个出场动作就能让读者脑补出人物状态。课中把后者归因于外部传播形态，登记为待核验背景，只保留其推理结构。

当堂收束为三组动作：**立主角**（原型→三维→加工→反差／对比→弧光→真实感）、**搭配角**（推动情节、塑造主角、数量精简）、**记人设取向**。作业式检查是只设计两个人物、把三维想透而**先不写剧情**；构思时对照全路径逐项核对有没有漏步。

| 搭框架 | 动笔前想透三维；先定读者与题材再设三维 | 写到一半回头补设定；人设与读者错位 |

| 配角 | 每个配角归入「推动情节」或「塑造主角」 | 背景板、主角未定就加戏 |
| 真实感 | 有一个特点能撩动目标读者 | 把真实感等同于现实存在 |

## 与前四课的衔接

本节把前序已建立的工作顺序落到了「人物」这一具体对象：把「先看受众」具体化为先定读者再设三维，把「框架先于行文」具体化为动笔前想透三维、先不写剧情，把「分类素材库」具体化为人物专属的观察日记与随身记录，把「带框架读作品」具体化为当堂回想与构思自检；新增的是人物专属工具——三维、弧光三柱、配角数量约束与两项人设取向。
