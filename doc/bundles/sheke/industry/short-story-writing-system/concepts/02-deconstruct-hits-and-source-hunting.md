# 拆爆款与找素材：三步骨架与七个版本的公式

已上线正课中，唯一形成连续主题的是三节录播，标题依次指向「拆解爆款故事」「在平淡生活中寻找素材」「隐藏的爆款故事类型」（F-023）。这三个标题本身不含方法内容，本包不推测课堂讲了什么，只把它们抽象成一条**可检查的工作顺序**：先拆已有作品的结构，再确定取材范围，最后给题材归类。宣传长图的模块二也落在同一段链路上，写的是「掌握爆款选题」与「人物塑造与结构设计，完成故事大纲」（F-036）。两处材料在这一层的方向一致，但都不构成可照做的步骤说明。

## 拆解可以拆哪些维度

下列维度是本包据公开材料整理的工作表，**不是课堂原表，也不是平台规则**：

| 维度 | 观察什么 | 明确不推断什么 |
|---|---|---|
| 结构性事实 | 篇幅区间、章节数、视角人称、对话符号、段落形态 | 不推断「平台偏好」或「过稿标准」 |
| 情节骨架 | 是否有明确目标、阻碍、行动、意外、转折、结局 | 不推断该骨架来自哪门课、哪个公式 |
| 情绪设计 | 开篇是否设钩子、情绪曲线走向、反转出现的位置 | 不把「有效」当结论 |
| 素材来源 | 是否改编自新闻、节令、社区话题或生活观察 | 不推断权利状态与授权范围 |
| 表达层 | 具体措辞、人物姓名、场景细节 | 不做低改动搬运，本包不复制任何原文片段 |

第三行最容易越界：第三方开源材料给出过「反转在 70–85% 位置」这类数值（F-052），它是某个仓库的自拟检查项，不是平台公布的阈值。把它写进教程时只能当「一个可检验的观察角度」，不能当「合格线」。

## 素材来源的四类公开提法

学员自述与招募推文合计提到四类取材方向，本包按可核验程度分列（F-051）：

1. **公共事件改编**：自述称某篇改编自社区内可见的原新闻事件，另一篇改编自新闻热点；本包只登记「存在这种取材说法」，不核验具体作品的改编关系。
2. **节令与流量时点**：自述称某篇按教学方法踩中节日上架并获平台推流；这是单方陈述，不构成方法与流量之间的因果证据。
3. **社区自带话题**：自述称社区论坛本身携带话题与素材，并指向「世情文」这一题材叫法；题材叫法未给定义，本包不补写。
4. **日常生活观察**：正课标题「在平淡生活中寻找素材」指向这一类，但公开面没有展开方法。

四类提法的共同边界是：**素材可见 ≠ 可自由改写**。本包不提供权利判断，遇到改编真实事件、他人作品或平台内内容时，须自行核对目标平台的原创、搬运与授权口径。

## 「七步故事法」至少有三个版本

公开检索里流传着多个同名或近似的「七步」骨架，步骤名称与顺序并不一致（F-053、F-060）：

| 出处类型 | 步骤序列 |
|---|---|
| 写作站转载 | 目标 → 阻碍 → 行动 → 意外 → 转折 → 结果（文中另给「目标／阻碍／行动／转折」四要素版） |
| 课程笔记转述 | 设定目标 → 构建阻碍 → 主角努力 → 呈现结果 → 意外转折 → 剧情转弯 → 故事结局 |
| 拆书类材料 | 描述背景 → 发生倾斜 → 奋起斗争 → 遭遇挫折 → 做出抉择 → 迎来转折 → 获得结果 |
| 自媒体整理 | 开场 → 触发事件 → 第一次尝试 → 加深危机 → 转折 → 高潮对决 → 收尾 |

四行都自称「七步」，但没有一行来自本课程的官方文本；招募推文里出现过「7 步故事法」这个课程名目，同样没有给出步骤内容（F-054）。因此本包**不写「课程的七步法」**，也不提供唯一公式。可读的结论只有一条：这些转述共享一个更基础的骨架——「目标遇阻 → 行动 → 意外 → 转折 → 结局」，差异出现在「结果」放在意外之前还是之后，以及是否把背景、抉择、高潮单列。把某个版本当标准答案，等于把二手整理升格成课程原文。

## 反套路：自述里最有用的一条

学员自述记录了一次拒稿，理由是「情节设计套路化或情节张力不足」，并把后来的调整描述为「反套路、微创新」，理由是人工审稿者已读过大量同类题材，需要新素材、新设定、新情节（F-048）。这段是**单方个案**，不能证明方法有效；但它给出一个可迁移的检验角度：把「按公式填充」与「在何处引入差异」分开记录，投稿前自问「这一篇与拆解样本的差异在哪里」。本包把它整理成一条自拟检查项，不冒充课堂要求。

同理，媒体报道里受访学员的负面体验——课程让学员对爆款文章做拆解与仿写、但「没有任何写作技巧方面的」，投稿未过审的理由是「主线不够清晰，叙事拖沓、混乱」——与上述自述构成方向相反的个案（F-046）。两者都是单源，本包并列登记，不合并成「效果如何」的结论。

## 本包不覆盖

课程三节正课的具体讲授内容、七步法的原始讲义、任何题材类型的定义与清单、素材改编的权利判定、平台收稿偏好与审核标准、以及任何「按此拆解即可过稿」的效果推断。
