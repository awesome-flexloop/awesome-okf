# 类型地图与三步构思：从选赛道到落笔前

这一篇接第 08 篇：素材有了、爆款拆过了，接下来是**选哪一类写**与**动笔前把故事校准到什么程度**。内容来自课程主线录播的 ASR 派生稿，经本包原创改写，不是逐字稿；与第 03 篇（第三方风格清单）、第 02 篇（公开流传的骨架）分属不同通道，不合并成一张总表（F-112）。

## 一张类型地图，两种读法

课堂把常见短篇归为三大类，并另列两个被鼓励尝试的方向（F-102）：

| 大类 | 支线 | 读者为什么读 |
|---|---|---|
| 情感向 | 古代背景／现代背景／家庭与社会关系 | 代入门槛低，情绪共鸣强 |
| 脑洞向 | 机制创新型／既有作品再解读型 | 设定与形式本身构成看点 |
| 真实向 | 职业视角／案件梳理 | 真实质感加专业差异感 |
| 鼓励方向 | 科幻、逻辑推理 | 竞争相对不饱和，改编想象空间较大 |

这张表容易被读成「哪类更容易成功」的排行榜，那就错了。课堂在讲类型之前先给了一条限制：**选你读得进去、写得出来的那一类**，并提醒同类稿件在编辑侧已经堆积。也就是说，分类的作用是帮你定位自己的优势、决定去读哪一批作品，不是替你挑赛道。本包把这条限制与表格一起保留，不单独摘出表格传播。

## 求新是换位置，不是加元素

三类各有求新位置，本包改述为一张对照（F-103，**非课堂原表**）：

| 类型 | 可换的位置 | 典型做法 |
|---|---|---|
| 情感向 | 人设、职业、人物关系 | 让主角具备当下特征；换一个不常见的职业；把冲突从一种关系挪到另一种关系 |
| 脑洞向 | 内核视角、表现形式、剧情机制 | 换非典型观察者；换叙述载体；在时间或因果上做机制改动 |
| 真实向 | 真实性、稀缺性、获得感 | 由当事人或可穿针引线的角色讲述；找特别的切口而非堆猎奇；讲完还留下可带走的知识 |

课堂在这里给了两处很实用的边界：写不熟悉的职业容易出逻辑漏洞，所以职业要选自己了解的；真实向内容若一味追求刺激，反而失去差异化，关键是把证据链讲清楚、把人物放进去。这两条是**风险提示**，不是成功保证。

## 灵感不等于构思

新增解锁的那一节讲的是「构思」，它的起点是把两个常被混用的词分开：**灵感**只提供动笔的冲动与碎片，**构思**负责校准方向并把碎片组装成能走到终点的故事（F-104）。课堂描述的症状是：脑子里想得很完整，落笔后却跑偏、卡住，成品与设想差距很大。归因不是文笔不够，而是没做构思。

构思被拆成三步：**向读者找共鸣 → 小范围做剪辑 → 选视角与人称**。三步各回答一个问题：拿什么打动读者、故事从哪讲到哪、用谁的眼睛看。构思完成时要能明确说出这三件事，而不是「把所有素材都塞进去」。

**第一步**给了一份共鸣筛选清单，本包改述为四问（F-105）：这段材料有趣或有用吗；能否激起真实情绪；有没有意外感、认同感或被理解的慰藉；读完后能不能带走一点思考上的支撑。课堂还区分了**轻微矛盾**与**威胁到前途、生存、精神状态的强冲突**：后者带来的触动量级不同。与此同时它给自我表达留了位置——把读者纳入考虑不等于迎合，克制表达也不等于情感浓度低；只是不建议新手在内核力量不足时先学克制。

**第二步**用的是剪辑师比喻：面对一大堆素材，把平淡的日常果断压缩甚至删掉，把情感浓度最高的少数片段放大、慢放、反复给细节；整篇的铺垫与过渡都为一到两个「名场面」服务（F-106）。课堂给了两则来自稿件的反面案例，病因相同：一个从小冲突出发却不断倒叙发散，线索跳来跳去；一个题材张力很强，却把二十年里所有有趣的碎片都堆进去，**爆点多不等于故事强**。对应的取舍原则是：短篇优先把一种情绪打透，疏密有致，别贪多求全。

**第三步**把视角问题压成一句「谁站在何处看到了什么」（F-107）。课堂逐一讲了三种人称的适用场景：全知视角适合多立场、多线索；第一人称代入感最强但要避免叙述者与事件毫无关联（否则像转述八卦）；第二人称属实验性写法，成熟案例少。比人称更细的是**心理距离**：叙述者站得远近会影响人物可信度，想写「体贴」却被读成「矫情」往往是距离没控住。课堂给的练习是动笔前写人物小传，先理解各立场下角色的真实感受，用经历和性格推动行为，而不是贴标签；并明确补了一句边界——理解动机不等于替角色洗白，仍要守住内容尺度。
