## 机制层（三条洞察，均为假设）

以下三条是对「这篇复盘为什么这样写」的解释，**标记为假设，不写入事实表**。每条含现象、证据、反常识、机制假设、影响与行动六要素。

**洞察 1：「抄≠抄袭」是结论，不是判据。**
现象：源文先建议抄封面抄标题，再用一句「但是抄≠抄袭」划界（F-013、F-014），只给「万能公式／排版风格」作可模仿对象（F-015）。证据：F-014、F-015、F-033、F-035、F-040。反常识：通常认为一句话划界能降低新手顾虑；实际它把「需要逐项判断的权利问题」压缩成一个无需判断的肯定句。机制假设：课程材料用断言消解合规顾虑，以便学员先行动。影响：读者可能把「改了标题公式」等同于「不侵权」。行动：把模仿对象拆成结构层与表达层，表达层逐项问权利来源并查目标平台规则，不采信任何单句免责。

**洞察 2：四指标映射是诊断启发式，不是因果模型。**
现象：四条「指标低 → 优化 X」一一对应（F-026～F-029），却未给阈值、分母与观测位置（F-038、F-039）。证据：F-010、F-026～F-029、F-038。反常识：通常认为「表越整齐越可执行」；实际整齐的一一对应最容易掩盖共同上游（选题与受众错配）。机制假设：单指标归因降低复盘的心理门槛，便于课堂传达。影响：同一内容常同时低点击与低转粉，逐项单改会反复无效；「缺乏人设」不可直接观测（F-029）。行动：把四行当待检验假设清单，一次只改一个变量，记录改动前后，再决定是否进入下一行。

**洞察 3：一篇复盘里混着两种文体。**
现象：方法段落之外，首尾出现专家背书、课时安排、加餐通知与效果承诺（F-011、F-012、F-030）。证据：F-002、F-007、F-011、F-030。反常识：通常把「课后复盘」整体当知识材料；实际它同时承担知识回顾与续课动员。机制假设：课程运营内容与教学内容共用同一发布通道。影响：动员话术会被误读为方法有效性证据。行动：先做文体切分，只把可操作陈述送进教程层；动员话术登记为 `single-source/flagged`，不进入结论、不参与排序。

## 迁移层

可迁移的做法只有一组，且都需要读者自己补数据：把外部清单当候选而非结论；每个「表达层」要素单独问权利来源；到目标平台自己的规则页核对；改写成自己受众的语言；小批量发布并保留改动前后记录；只在出现可复现信号后扩量。

## 模式：模仿分层过闸（L1，单案例待验证）

- **触发条件**：从课程、爆款拆解或他人经验得到一组「可模仿要素」，准备投入生产。
- **不适用于**：已有明确授权与许可的素材复用（走授权流程即可）；纯内部学习笔记（无需发布）；需要法律意见的争议场景（本模式不给法律意见）。
- **核心步骤**：
  1. 把要素拆成**结构层**（标题公式、版式、需求类型、章节顺序）与**表达层**（具体文案、图片、配音、音乐、措辞）。
  2. 表达层逐项问「权利从哪来」，无答案即剔除或替换。
  3. 到**目标平台**规则页核对原创、搬运与标识口径；不得用其它平台条款代替（F-040）。
  4. 结构层改写成自己选题与受众的语言，保留信息增量，不做低改动搬运。
  5. 小批量发布，一次只改一个变量，记录改动前后；无复现信号即停止扩量。
- **反模式**（5 条，均来自本案例与条款对照）：① 把「抄≠抄袭」当免责声明；② 用 A 平台条款给 B 场景背书；③ 把四指标映射当因果结论直接照改；④ 把课程动员话术当效果证据；⑤ 整段复述他人举例充当自己的案例。
- **检验标准**：每个表达层要素都能回答「权利从哪来」；每个优化动作都能对应一条只改一个变量的记录；教程中不出现未标注来源的效果数字；所有平台口径都标注了适用平台与读取日期。
- **跨领域迁移示例**：借鉴一份开源项目的 README 时，结构层可学「安装 → 快速开始 → 配置 → FAQ」的章节顺序，表达层须核对原项目许可证、保留署名与版权声明，不得复制其项目介绍文案。这验证了该模式不依赖内容创作领域。
- **成熟度**：L1，单案例、未跨平台复验；模式未经第二篇独立材料验证，不得标注「已验证」。

## 可复现性两问

1. 源文是否给出读者可照做的安装、配置、调用或发布流程？**否**（F-007、F-008 只有原则与映射，F-011 的课时安排指向未提供的前期课程）。
2. 这些流程是否经作者实测并具备版本、输入输出与步骤顺序？**否**（F-038 无样本、无数据、无平台路径）。

两问皆否，因此本包**不设 `examples/`**。空示例目录会制造「有操作教程」的错觉，比没有更糟；第 02、03 篇中的三问与记录法均显式标注为「本包自拟的检查顺序」，不是源文步骤，也不是平台流程。
