# 知乎盐言作者平台与中长篇创作官方手册

> **⚠️ flagged：** 本包内容全部来自**知乎平台自身页面**，无第三方独立复核源。平台入口、菜单结构、字数门槛与活动规则**随平台改版即时失效**，请在 `stale_after: 2026-12-31` 前复核。已知的采集边界（长篇创作马拉松各板块正文、作者福利具体权益条目、创作风向 TOP50 明细）见 [信源清单](references/01-source-manifest.md)。

本知识包整理知乎面向中长篇创作者的**官方口径**，按「平台地图 → 创作流程 → 签约与完结 → 曝光渠道 → 选题信号 → 活动规则 → 权利边界 → 演进风险」组织：

- **平台与流程层**（00–04）：盐言作者平台的导航结构与功能地图、中长篇创作五步流程（创建作品 → 开始连载 → 申请签约 → 签约上架 → 申请完结）、签约与完结的双字数闸门与审核反馈链、三 App 展示与被推荐后才可见的曝光机制、创作风向的高热问题 TOP50 与投稿热点信号；
- **活动与规则层**（05–07）：以采集时点的「津派文化」主题征文活动为**完整样本**，解剖字数门槛、五档奖项、6 条评选说明、6 条无效融入情形、流量券与回答的绑定规则、参赛方式与细则、以及承诺书中的 AI 红线与授权条款；
- **风险层**（08）：平台改版导致的入口漂移、规则时效、以及「平台单源」本身的引用纪律。
