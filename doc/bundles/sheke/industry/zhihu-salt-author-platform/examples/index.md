# 示例文档

本目录共 3 篇，为可直接套用的工作模板。三篇均以 [事实清单](../facts.md) 的 F 编号为依据，模板中的每一个字段都标注了它约束哪条 F。

| 文档 | 用途 | 适用时机 |
|---|---|---|
| [01 · 投稿前合规自查表](01-pre-submission-checklist.md) | 逐项勾选的投稿前检查清单，覆盖字数、主题契合、AI 红线、授权、账号资格、流量绑定七组内容与资格项 + 一组提交动作核对 | 提交投稿动作前的最后一道闸 |
| [02 · 中长篇连载排期表](02-longform-schedule.md) | 以 2000–8000 字小节为单位的连载排期模板与小节字数台账，含中篇/长篇两条闸门路线 | 立项阶段与每周更新复盘 |
| [03 · 参赛决策树](03-campaign-decision.md) | 「是否参赛 / 走哪种载体 / 是否配置关联回答 / 是否值得投入长篇」的决策路径 | 活动公告发布后、报名窗口关闭前 |

## 使用建议

- 三份模板是**同一套判据的三种视图**：自查表管「能不能投」，排期表管「写不写得完」，决策树管「值不值得投」。三者在 F 编号上**存在 12~23 条重叠**（01∩02=12、01∩03=23、02∩03=11），但**视角不同**，可交叉引用，**不可当作互斥清单**使用。
- 所有模板中带 `⚠️` 标记的项为**硬性资格项**（不满足即失去参与资格或评选资格），其余为**评分倾向项**（影响融合维度评价）。
- 模板不包含任何收益估算。活动的金额口径见 [事实清单 F-050](../facts.md)，其发放条件见 F-076、F-077。
