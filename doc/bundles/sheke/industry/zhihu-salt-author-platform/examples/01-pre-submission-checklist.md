# 01 · 投稿前合规自查表

> **使用方式**：在点击「申请签约」前逐项打勾。带 ⚠️ 的是**硬性资格项**——不满足即失去参与资格或评选资格；其余为**评分倾向项**——影响文化融入维度评价（依据 F-060 的六条负面情形）。
> **重要前提**：本表按采集时点（2026-10-23）「津派文化」活动的条款编制。**换活动必须重新通读活动页原文**（见 [08 复核清单](../concepts/08-migration-risk.md) 第 11、12 项）。

## A 组 · 字数与结构门槛

| # | 检查项 | 依据 | ⚠️ |
|---|---|---|---|
| A1 | 作品总字数落在活动规定区间内（短篇 8000 含–3 万不含 / 中篇 3 万含–10 万不含） | F-045 | ⚠️ |
| A2 | 字数口径为「不含/含」边界已确认（如 3 万字含、不含 3 万） | F-045 | ⚠️ |
| A3 | 每个小节字数在 2000-8000 字之间 | F-016 | ⚠️ |
| A4 | 篇幅选择与实际字数匹配（创建作品时「篇幅」栏选短篇/中篇） | F-067 | ⚠️ |
| A5 | 【参与征稿】栏已选择本次活动标签 | F-067、F-052 | ⚠️ |
| A6 | 作品已按要求完结（字数达标 **且** 所有小节已公开） | F-076、F-077、F-029 | ⚠️ |
| A7 | 所有小节均已通过安全审核并自动公开（无待审或未通过章节） | F-017、F-018 | ⚠️ |

> **A3 与 A6 的联动**：A6 的「所有小节已公开」要求每一节都通过审核（F-018）。任何一节审核未过，A6 即不成立。

### A 组附表 · 未通过时的处理动作

| 失败点 | 判定依据 | 未通过时的处理动作 |
|---|---|---|
| 小节审核未通过 | F-017、F-018 | 修正该小节后重新点击右上角「公开小节」，重新进入安全审核（F-017、F-018） |
| 申签审核未通过 | F-025 | 按知乎私信通知修正作品后重新提交（F-025） |
| 润稿复提 | F-026 | 前往「盐选作者平台 - 作品管理」按润稿建议修正后再次提交（F-026） |
| 完结不达标 | F-029 | 继续连载直到字数达标且所有小节已公开，再点击「申请完结」（F-029、F-030） |

> **口径缺口**：官方未披露审核未通过的具体理由构成、修正轮次上限与时限，本表不推测该行为，仅按「可重复提交」处理。

## B 组 · 主题契合与文化融入

| # | 检查项 | 依据 | ⚠️ |
|---|---|---|---|
| B1 | 作品与活动主题存在明确关联（天津可作为发生地、家乡、职业背景、情节线索或精神归属） | F-055 | ⚠️ |
| B2 | 关联性不只停留在标题、人物籍贯或个别段落 | F-058 | |
| B3 | 主题元素**对人物和情节产生了作用**，而非仅作数量堆叠 | F-054 | |
| B4 | 未以集中罗列地名、景点、美食或非遗名称代替文学表达 | F-056、F-060 第 2 种情形 | |
| B5 | 未将其他城市的通用故事直接替换为天津地名 | F-060 第 3 种情形 | |
| B6 | 虚构的地方习俗、历史事件、城市数据已在文中注明为文学演绎 | F-060 第 4 种情形、F-057 | |
| B7 | 未使用真实企业、机构或人物名称编写违法、负面或争议情节 | F-060 第 5 种情形 | ⚠️ |
| B8 | 无贬损、刻板化或事实失真的城市表达 | F-060 第 6 种情形 | ⚠️ |
| B9 | 涉及真实历史、非遗、地理、机构、现代企业的信息尊重基本事实 | F-057 | |

> **B3/B4 的判定问句**：把文中每个文化元素逐个删掉——若故事不受影响，该元素就是「标签化」的（对应 F-060 第 1 种情形）。

## C 组 · AI 红线（最高优先级）

| # | 检查项 | 依据 | ⚠️ |
|---|---|---|---|
| C1 | 作品文本未由 AI 生成、续写或改写 | F-043、F-071 | ⚠️ |
| C2 | **作品文本从未被粘贴进任何外部 AI 模型的输入框**（含润色/自查/扩写/续写工具） | F-044 | ⚠️ |
| C3 | 未将作品全部或部分内容用于模型训练、参数优化、语料库建设 | F-044 | ⚠️ |
| C4 | 本次参赛**不使用任何 AI 辅助**，含平台内置 AI 校对（F-004、F-015） | F-043、F-044、F-071 | ⚠️ |
| C5 | 本次参赛使用的工具已在白名单内，无越界工具 | F-043、F-044、F-071 | |

> **C2 是最容易违反、后果最直接的一项**：它约束的是**上传/输入行为**，与内容是否由 AI 生成无关。存在疑问时按最严解释。
>
> **C4 的口径**：F-044 的禁令对象表述为「任何 AI 模型、工具或平台」，**官方未明确平台自带 AI 校对是否落入该表述**；从严解释下参赛期间不使用任何 AI 辅助（含平台校对）。

## D 组 · 原创性与授权

| # | 检查项 | 依据 | ⚠️ |
|---|---|---|---|
| D1 | 作品为本人独立创作 | F-071、F-086 | ⚠️ |
| D2 | 作品未在全球范围内发表；若已发表过，已在其他平台或渠道删除下架 | F-086 | ⚠️ |
| D3 | 该作品未重复参与其他活动、未一稿多投 | F-086 | ⚠️ |
| D4 | 不侵犯他人知识产权（含作者经纪合作、作品合作、保密协议等第三方约定） | F-086 | ⚠️ |
| D5 | 封面上传素材合法合规、满足权利需求（选用本地上传封面时） | F-011 | ⚠️ |
| D6 | 已理解并接受赛事使用授权（免费、非独家；范围含全部或部分内容；含必要技术处理；赛后可用于非商业性作品集展示/学术交流/公益类奖项申报） | F-079 | |
| D7 | 已理解 IP 开发池条款（若被实际公布纳入，允许提供给他赛道参赛者做复制/剧本改编/AI 短剧漫剧等改编制作参赛评审展示；不因改编取得原 IP 著作权） | F-078 | |

> **D6/D7 是知情项而非勾选义务**——它们在投稿时即已通过勾选《参赛承诺书》生效（F-067、F-072）。此处的作用是确认作者确实读过这两条。

## 判读规则

- **任一 ⚠️ 未通过 → 停止投稿**，回到对应概念页定位原因。
- **B 组有 3 项以上未通过 → 修改稿件后再投**：对应 F-054 的「元素是否对人物和情节产生作用」为主判据，F-060 的六条为具体反例。
- **C 组有任一项存疑 → 按最严解释处理**（F-044 的对象是上传行为本身）。
- **A6 未通过 → 即使其他项全过也可能被取消评选资格**（F-077），且奖金不再发放。
