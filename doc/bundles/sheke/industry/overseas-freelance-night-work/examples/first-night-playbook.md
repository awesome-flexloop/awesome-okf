# 第一晚行动剧本

以下步骤是**非官方的组合式行动建议**，依据博文 F-026 与各平台官方页面编排，不代表任何平台的录用或收入承诺。

## 路径 A：中文教学

1. 核对 italki 当前教师申请页、语言资格和身份要求。
2. 录制 1–3 分钟自我介绍视频。
3. 写一节可交付的试听课大纲。
4. 提交申请并记录费率页截图/链接。
5. 不以试听课收入推算长期收入；italki 官方抽成表见 F-028。

## 路径 B：Upwork 文件交付

1. 选择字幕、修图、短视频或自动化中的一个细分服务。
2. 做一份小样品：十分钟字幕、二十张去背景图片或一分钟短视频。
3. 完整填写档案，写清输入、输出、交付时间和修改次数。
4. 只投递与样品高度匹配的小项目。
5. 看到合同费率后再计算净收入，Upwork 服务费见 F-031。

## 路径 C：CrowdGen 数据任务

1. 查看所在地是否有可申请项目。
2. 完成身份、手机和支付方式设置。
3. 先确认项目按小时还是按单位计费。
4. 记录支付提供商费用，不把仪表盘金额当到账金额。
5. 以项目页面和付款页面为准，见 F-034、F-035、F-037。

## 路径 D：Gumroad 数字模板

1. 选择一个已有需求的模板，如预算表、看板或简历模板。
2. 完成一个可下载文件和使用说明。
3. 创建产品页，明确版本、许可和退款边界。
4. 先用直链测试购买和付款路径。
5. 将 10%+0.50 美元直链费率、30% Discover 费率和提现方式纳入定价，见 F-036。
