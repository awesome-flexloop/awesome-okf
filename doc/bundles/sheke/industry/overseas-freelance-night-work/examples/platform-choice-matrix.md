# 平台选择矩阵

对每条路径回答“是/否”。只要资格或收款为“否”，就先停止投入。

| 问题 | 中文教学 | 文件交付 | 数据任务 | 数字模板 |
|---|---:|---:|---:|---:|
| 两小时内能形成明确输出？ | 是 | 是 | 通常是 | 是 |
| 需要客户实时在线？ | 是 | 否 | 否 | 否 |
| 能用现有作品证明能力？ | 部分 | 是 | 部分 | 是 |
| 地区资格已确认？ | 申请前确认 | 申请前确认 | 必须确认 | 付款前确认 |
| 收款路径已验证？ | 必须验证 | 必须验证 | 必须验证 | 必须验证 |

## 选择规则

- 擅长教学且能固定晚间时段：先验证 italki。
- 有字幕、修图、剪辑作品：优先做 Upwork 的小型文件交付。
- 愿意接受项目分配和任务波动：核对 CrowdGen。
- 已有可复用数字资产和获客渠道：再测试 Gumroad。

该矩阵只用于缩小实验范围，不用于预测收入、通过率或长期职业结果。
