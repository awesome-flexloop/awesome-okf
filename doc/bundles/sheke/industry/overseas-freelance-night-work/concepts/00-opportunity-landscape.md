# 夜间海外项目机会全景

## 核心判断

文章的可迁移价值不在“七个项目”这个固定清单，而在一个筛选模型：先看北京时间 20:00–22:00 是否需要实时协作，再看任务能否拆成两小时内可交付的最小单元，最后看平台资格与收款通道。文章将项目分成“时差对上”和“交付不看时间”两类（F-002、F-003）。

## 七类项目

| 类别 | 典型平台 | 交付形态 | 关键前置 |
|---|---|---|---|
| 中文教学 | italki | 实时服务 | 语言能力、教师资料、时段匹配 |
| 中文字幕 | Upwork/Rev | 文件交付 | 双语能力、字幕样本、岗位资格 |
| 图片去背景/精修 | Upwork | 批量文件 | 图像工具、质量一致性 |
| 短视频剪辑 | Upwork | 短视频文件 | 剪辑工具、作品集 |
| 自动化流程 | Upwork | 流程配置 | Zapier/Make/n8n 等工具经验 |
| 数据标注 | CrowdGen | 任务/小时 | 地区、语言和项目匹配 |
| 数字模板 | Gumroad | 可下载产品 | 模板内容、销售页、收款路径 |

平台费率与资格不是收入保证：italki、Preply、Upwork、Rev、CrowdGen、Gumroad 的官方规则各自不同，必须按申请时页面复核（F-028~F-039）。

## 第一性原理式筛选

1. **时间约束**：是否要求客户同时在线？
2. **交付约束**：能否定义一个两小时内完成的输出？
3. **质量约束**：是否能用一份样品证明能力？
4. **通道约束**：能否合法注册、接单和收款？
5. **验证约束**：六周后是否能用真实数据判断继续或停止？

这个顺序把“想赚多少”改成“能否完成一次闭环”，减少被平台标价和成功案例带偏的风险。
