# 00 · 总览与阅读地图

> 本篇是**导航与方法说明**，不含规则事实。所有规则性陈述以 [事实底账](../references/facts.md) 的 F 编号为准。

## 1. 这次任务是怎么被编排的

用户指令为「/七概念 全面学习 <活动页>，生成 okf wiki 教程，并给出参赛方案」。按 `.agents/commands/seven-concepts.md` 的场景识别表，这不是单一场景：

| 命中线索 | 场景 | 标准链路 |
|---|---|---|
| 「全面学习…生成 wiki 教程」 | 知识沉淀 | R→I→E→V→入库 |
| 「给出参赛方案」 | 创新突破 / 方案设计 | F→V→I→C |

故按 `scenario=auto`、`depth=standard`、`with_validation=true` 组合为 **R→F→I→E→V→A→C** 一条链，保留对抗审查 V。顺序不可颠倒（R 在 I 前、I 在 E 前、V 在 C 前、A 在 C 前）：

| 阶段 | 本包落点 | 关键动作 |
|---|---|---|
| **R** 复盘/事实 | [事实底账](../references/facts.md) | 从活动页四个载体采集 72 条客观事实，剥离因果词；缺口单独成 G 族 |
| **F** 第一性原理 | [02 · 评分机制](02-scoring-and-awards.md) | 把 100 分拆成不可再分的两类量：相对项 70 与绝对项 30 |
| **I** 洞察 | [04 · 机制洞察](04-mechanism-insights.md) | 四条洞察，每条含陈述 / 证据 / 反常识 / 行动四元组（G2 门逐项验） |
| **E** 萃取 | [核验报告](../references/verification.md) | 抽取可跨赛事迁移的判定，与被否证的判定分列，不伪装成官方口径 |
| **V** 对抗审查 | [核验报告](../references/verification.md) §4 | 四视角 7 条实质攻击，6 采纳 + 1 部分采纳，全部在产出中落地 |
| **A** 原子化 | 本包 12 篇文档 | 单一职责拆分：事实 / 机制 / 方案 / 核验 / 索引互不混写 |
| **C** 落盘 | 索引与门禁 | 五级索引计数同步、toctree 可达、UTF-8 无 BOM；不做 git 提交 |

**质量门逐项结果**：G1 事实层无因果词（条件—后果条款的逐字转录已豁免声明）✅；G2 四条洞察四元组完整 ✅；G3 判定可迁移到至少 1 个非本赛事场景 ✅；G4 倒排行动项单一职责、可验证、有 Owner、有时点 ✅；V 门 7 条意见 ≥5 且采纳 ≥2 ✅。

## 6. 三条硬边界（继承参赛作战手册）

1. **不输出获奖概率、名次预测、评审口味**——评审机制与分数分布官方未披露（G-02）。
2. **不把推断写成规则**——官方未给的口径一律进 G 族并登记。
3. **规则未确认前不做不可逆投入**——不公开发布、不提交投稿、不做无法撤回的动作。
