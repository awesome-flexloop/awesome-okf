# 进阶算例：两层单位经济（符号化工作表）

> **这是什么**：由**编者构造**的练习框架，把 [03 篇](../concepts/03-attention-economics-first-principles.md) 的「L1 总量 / L2 分配」两层模型下沉成可复算的方程组。它只使用符号与比值，不引入任何原文未给的新事实数据。
> **这不是什么**：不是行业模型、不是收益预测、不是对任何公司经营状况的判断、不是创业/定价/投资/裁撤建议。`A`、`k`、`n`、`s`、`F`、`α` 六个量**原文一个都没给**，全部是编者符号或读者自填的占位参数。算术自洽 ≠ 数据真实，代数成立 ≠ 现实成立。
> **与 01 的关系**：[01 单位经济算例](01-unit-economics-worksheet.md) 练「同一组数字在不同口径下会得出不同结论」，产出的是**禁令**；本篇练「把口径固定之后，结构如何决定方向」，产出的是**条件性恒等式**。两者互补，但**禁止互相代入数值**（见 §八 禁用 5）。

## 一、为什么需要进阶：01 回答不了的三问

| 01 已经能算 | 01 明确回答不了 |
|---|---|
| 成本降幅 60%（模块 A） | 为什么 F-020 说「省下的人力成本没变成老板利润」 |
| 平均单部流水降到约 18%（模块 B） | 为什么平台侧 +230% 与「机构难活」可以同时为真（E-11） |
| 两种人效差 6~10 倍（模块 C） | 什么样的观测会**推翻**「注意力不变」这条公理 |
| 假设题的口径依赖（模块 D） | 「降本」与「扩产」哪一个在固定注意力下占优 |

这四问的共同点是：它们问的不是数字对不对，而是**结构容不容得下这个数字**。禁令无法回答结构问题，所以需要一组显式假设下的方程。

| 符号 | 含义 | 来源 | 类型 |
|---|---|---|---|
| `A` | 可被内容占用的注意力总量 | 公理 F-043、F-044 | **编者符号**，原文未给数值 |
| `k` | 单位注意力变现系数 | 编者占位 | **原文未给** |
| `n` | 同质供给方数量 | 编者占位 | **原文未给** |
| `S` | 行业总供给部数 | 定义式 `S = n·Q` | 定义 |
| `Q` | 单家月产量 | F-016 | 受访者自述 ⭕ |
| `p` | 单部平均流水 | 定义式 `p = kA/S` | 由公理推出，非原文数据 |
| `c` | 单部变动成本 | 路径 2 的编者占位 | **原文未给**（原文只给「总成本」） |

> **路径隔离声明**：§四（结构法，用 `A/k/n/s/F/c`）与 §五（阈值法，用 `p/C/α`）是**两条独立的参数化路径**，各自口径自洽，互不代入。原文 F-010、F-011 的「一部标准化作品总成本」未区分固定/变动，因此不能同时充当路径 2 的 `c·Q + F`。

## 三、模块 E：注意力守恒下的分配恒等式（L1 / L2 的可复算化）

显式写下三条假设，缺一不可：

- **H1 同质供给**：`n` 家供给方，每家产量 `Q`，作品在争夺同一注意力池时无差异。
- **H2 注意力固定**：`A` 在观察期内不变；行业总流水 `R_total = k·A`，是一个**固定项**。
- **H3 均匀分配**：单部平均流水 = 总流水 / 总供给。

```
S        = n · Q
R_total  = k · A                              ← L1 总量层，与 n、Q 无关
p        = R_total / S = kA / (nQ)
R_i      = Q · p = kA / n                    ← 单家流水与自身产量 Q 无关
π_i      = R_i · (1 − s) − c · Q − F
         = (kA / n) · (1 − s) − c · Q − F    ← L2 分配层
```

**两条可直接验算的偏导**（读者可自行对 `Q`、`n` 求导）：

| 关系 | 结果 | 条件 | 读法 |
|---|---|---|---|
| `∂π_i / ∂Q` | `−c < 0` | `c > 0` | 在 H1~H3 下，**单家增产严格降低自身利润**；产量只增加成本，不增加分到的注意力 |
| `∂π_i / ∂n` | `−kA(1−s)/n² < 0` | `k, A > 0` 且 `s < 1` | 进入者增加摊薄每家份额 |

**这恰好把 E-11 从禁令升级成可判定的不等式**：设行业总流水增长 `g` 倍（`kA → g·kA`）、供给方增长 `h` 倍（`n → h·n`），则第一项变为 `(g/h)·(kA/n)(1−s)`。

| 条件 | L1 总量 | L2 分配 | 对应 |
|---|---|---|---|
| `h > g` | 增长 | 恶化 | 平台侧收入 +230% 与「机构难活」同真（E-11） |
| `h < g` | 增长 | 改善 | 03 篇失效条件 1：新人群 / 新场景 / 出海打开 `A` |
| `h = g` | 增长 | 持平 | 降本 `c` 成为唯一改善项 |

> 平台披露的「签约 5000 多个个人及个人工作室」（F-058，2026-10-16，E-10）可作 `n` 上升的**方向性旁证**，但签约数 ≠ 活跃供给方数，且属平台自述，**不得代入 `n` 参与任何计算**。

**反常识**：`R_i = kA/n` 里完全没有 `Q`。这解释了 [01 模块 C](01-unit-economics-worksheet.md) 的「30 倍人效」为什么推不出盈利能力——物理产能与分配份额是两件事（E-02）。

## 四、模块 F：盈亏平衡与「增产陷阱」（路径 2，纯符号）

在路径 2 内令 `π_i = 0` 求盈亏平衡产量：

```
Q* = [ (kA/n) · (1 − s) − F ] / c
```

- 若 `(kA/n)(1−s) ≤ F`，则 `Q* ≤ 0`：**不存在正的盈亏平衡产量**，增产只会扩大亏损。
- 这与 §五 的 `m₁ ≤ 0` 是同一现象在两条路径下的不同表述，**只可并列、不可互相代入**。

再看「技术降本 vs 进入者增加」的赛跑。设 `β = n₁/n₀ > 1`（进入者倍数）、`γ = c₁/c₀ < 1`（单位成本残留比），并假设 `Q`、`F`、`s`、`kA` 不变：

```
π₁ − π₀ = (kA/n₀)(1−s) · (1/β − 1)  +  c₀·Q·(1 − γ)
              ↑ 负项：进入者摊薄            ↑ 正项：技术降本

净改善 ⟺ c₀·Q·(1 − γ) > (kA/n₀)(1−s) · (1 − 1/β)
```

这条判据不代入任何真实数字，只说明：**降本幅度必须与进入者增速赛跑，而不是与自身历史成本比较**。`γ = 0.4`（对应 01 模块 A 的降 60%）本身不保证净改善。

## 五、模块 G：成本率阈值（路径 1，只接 01 的两个输出）

**前置假设 H4**（编者假设，原文未检验）：所讨论的单家只生产标准化批量剧，且 `R` 全部来自该品类。若 H4 不成立，`p = R/Q` 与 `C` 不同口径，本节整体失效。

在此前提下，把 01 的两个输出归一化：`p₀ = 1`，令 `α = C₀/p₀` 为读者自填的初始成本率；`p₁/p₀ = 0.18`（01 模块 B 中值，区间 `0.13~0.25`），`C₁/C₀ = 0.40`（01 模块 A）。

```
单部口径余量  m₀ = p₀ − C₀ = 1 − α
              m₁ = p₁ − C₁ = 0.18 − 0.40α

m₁ > 0  ⟺  α < 0.18 / 0.40 = 0.45
```

> **口径警告**：`m` 是「平均单部流水 − 单部总成本」的**口径余量**，不是会计学贡献毛利。原文既未把 `C` 拆成固定/变动，也未说明 `R` 是否含非批量剧收入；H4 只是让练习可算，不是对现实的描述。

| 读者自填 `α` | `m₀` | `m₁` | 读法 |
|---|---|---|---|
| 0.30 | 0.70 | 0.06 | 余量压缩约九成 |
| 0.45 | 0.55 | 0 | 临界 |
| 0.60 | 0.40 | −0.06 | 降本后余量为负 |

**阈值本身也有区间**：`p₁/p₀ ∈ [0.13, 0.25]` → `α* ∈ [0.325, 0.625]`。所以「45%」只是中值口径下的示例，取端点会改变结论——这与 01 的区间提醒一致。

**这一节回答了开头第一问**：成本降 60% 看起来很大，但在中值口径下，只要初始成本率高于 45%，仍追不上平均单部流水约 82% 的降幅。F-020「省下的人力成本没变成利润」因此不需要额外假设就能被结构化地理解——**它是两个不同降幅的比较，不是矛盾**。注意这只是模型内的算术，不构成对该公司经营状况的判断。

> **禁止相乘（E-03）**：本节只接 01 模块 A、B 的**两个比值**，不接 F-019 的「差 10 倍不止」`D`，也不接 01 模块 C 的人效；归一化已消除量纲，不得再反推营收。

## 六、模块 H：证伪清单（01 缺失的一层）

01 的「三条禁用」告诉读者不能算什么；本节反过来列出**什么观测会推翻本算例**。三条失效条件与 03 篇 §五一一对应。

| 失效条件 | 模型内表示 | 可观测判据（须有发布主体与时点） | 失效的推导步 |
|---|---|---|---|
| 注意力并非固定（新增人群 / 新场景 / 出海） | `A → A(t)` | 总观看时长与作品数同比例增长 | §三 `R_total = kA` 不再固定，`∂π/∂Q` 可能转正 |
| 可累积 IP / 品牌，存在差异化 | 打破 H1，`p_i ≠ p` | 少数作品跨周期复播、单部收入不随 `S` 摊薄 | §三 `p = kA/S` 不成立 |
| 平台规则 / 算法 / 版权改变分配 | `s → s(t)` 或非均分 | 分成比例、推荐权重、保底机制公开变更 | §三 `R_i = kA/n` 不成立 |
| 变现效率提升 | `k → k(t)` | 单位观看时长的广告 / 付费收入上升 | L1 增长，且 L2 也可能改善（`g > h`） |

> F-036 的出海月产量常被当作「`A` 在增加」的证据，但它是**受访者转引渠道、9 月为预估值**（E-07），且产量增长不等于注意力总量增长。按 [05 篇](../concepts/05-historical-analogy-and-prediction-boundary.md) 的预测降级纪律，此处只能登记为待检验命题。

## 七、模块 I：跨领域参数替换模板（G3 迁移验证）

核心三问：**哪个是固定项、谁持有它、哪个环节可无限进入**。下表是结构类比，不是数据类比。

| 领域 | 固定项 `A` | 可进入项 `n` | 变现 `k` | 分成 `s` | 差异化来源 |
|---|---|---|---|---|---|
| AI 漫剧 | 用户总观看时长 | 制作机构 / 超级个体 | 单位时长变现 | 平台分成 | IP / 长期记忆 |
| 应用商店 | 装机量与使用时长的注意力 | 开发者 | 单次下载 / 内购变现 | 商店抽成 | 品牌 / 网络效应 |
| 电商 | 搜索与购买注意力 | 商家 / 店铺 | 转化率 × 客单 | 佣金 / 流量费 | 复购 / 私域 |
| 本地生活 | 用餐时段与订单注意力 | 商户 | 单均变现 | 平台佣金 / 配送 | 位置 / 口碑 |
| 短视频 | 刷屏时长 | 创作者 | 单位播放变现 | 平台分成 | 人格化 IP |

**迁移验证**：任取一行，把 §三 的 `kA` 替换为该领域的固定项，检查 `∂π/∂Q` 的符号是否仍只由「单位可变成本」决定。若某行出现「多供给反而抬高固定项」（如网络效应），则该行不适用，须显式登记为**反例**而不是强行套用。

## 八、六条禁用（继承 01 三条 + 新增三条）

1. **不得据本表估算行业规模、行业均价或行业收入变化**（继承 01）：输入全部是单源自述、编者符号或读者自填，无行业统计分母。
2. **不得跨口径相乘、相除或并列**（继承 01）：总量流水 / 单部爆款、批量剧 / 精品剧、部·人月 / 营收·人、实测 / 预估四组口径各自独立（E-02、E-03、E-04、E-07、E-12）。
3. **不得把任何结果当作创业、定价、投资或裁撤依据**（继承 01，对应核验报告编者视角采纳项）。
4. **不得把符号参数当实测**：`A/k/n/s/F/α` 均为编者符号或读者自填，原文未给；代入具体数字得出的只是「该参数组合下的模型输出」。
5. **不得把两条路径串联代入**：§四（结构法）与 §五（阈值法）口径隔离，不得用 §五 的 `C` 去充当 §四 的 `c·Q + F`。
6. **不得把方向性结论写成预测**：`∂π/∂Q < 0` 只在 H1~H4 下成立；它既不是「机构会消失」的论证（E-05），也不含任何时间尺度。
