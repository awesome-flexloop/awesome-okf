# 补篇：把「内容判断力」写进方程

> **回答 03 进阶算例留下的问题**：[02 篇](../concepts/02-content-judgement-as-scarce-asset.md) 说「内容判断力成为稀缺资产」，在 [03 进阶算例](03-two-layer-unit-economics.md) 的方程里该改写哪个符号？
> **答案**：不是给某个已有符号赋值，而是**替换 H3 均匀分配假设本身**。`p = kA/S` 里根本没有判断力的位置——「每部作品分到同样注意力」已经把差异抹平了。判断力只能出现在注意力份额 `φ_i` 里。
> **边界**：本篇仍是编者构造的符号练习，`θ / γ / φ` 原文一个都没给；不构成对任何能力、岗位或组织的测量，不含训练方案与行动建议（02 篇新人视角采纳项）。
>
> **编号约定**：本篇下文所称「03」一律指 [examples/03 进阶算例](03-two-layer-unit-economics.md)（H1/H2/H3、模块 E~I、`∂π/∂Q = −c` 均出自该文档）；概念层的 [concepts/03 第一性原理篇](../concepts/03-attention-economics-first-principles.md) 一律写作「concepts/03」。两者不是同一份文档，不得混引。

## 一、从 H3 到权重分配

保留 03 篇的 H2（`kA` 固定）与路径隔离约定，**只替换 H3**：

```
旧 H3（均匀）: p = kA / S,   R_i = Q_i · p = kA / n
新 H3′（加权）: R_i = φ_i · kA,        Σ_i φ_i = 1
                φ_i = θ_i^γ / Σ_j θ_j^γ              (γ ≥ 0)
                π_i = φ_i · kA · (1 − s) − c · Q_i − F
```

| 符号 | 含义 | 类型 | 原文是否给出 |
|---|---|---|---|
| `θ_i` | 供给方 `i` 的**选品命中率**（筛选能力的参数化代理） | 编者符号，读者自填 | 无 |
| `γ` | 注意力集中度（`0` 均匀，越大越赢家通吃） | 编者符号，读者自填 | 无 |
| `φ_i` | 注意力份额 | 定义式 | 无 |
| `A/k/n/s/c/F` | 沿用 03 篇的符号 | 编者符号 | 无 |

> **`θ` 不是能力测评分数**：它没有量表、没有样本、没有时点，只是「在模型里给筛选能力留一个可求导的位置」。02 篇明确说筛选能力是「被环境筛出来的结果」而非可培训技能，本补篇不提供任何培养方案。
> **函数形式是假设**：`θ^γ` 只是权重函数的一个可选形式；本篇所有结论只用「`γ = 0` 时退化为均匀」这类**不依赖具体函数形式**的性质。

## 二、模块 J1：判断力什么时候**不**值钱

```
γ = 0  →  θ_i^0 = 1  →  φ_i = 1 / n  →  完全退回 03 篇模块 E
此时  ∂π_i / ∂θ_i = 0
```

无论选品多准，份额都不变。**这就是「内容判断力」从口号变成可证伪命题的关键**：它成立需要两个条件同时满足——

1. `γ > 0`：注意力按差异**非均匀**分配；
2. `θ_i` 在供给方之间**确实有差异**（若所有人 θ 相同，`φ` 仍是 `1/n`）。

**可观测判据**：若平台按投稿量或时长均匀分发、或推荐权重与内容表现无关，则条件 1 不成立，02 篇的瓶颈迁移不会发生——这正是 02 篇 §三「选择可被可靠自动化」失效条件的可复算版本。

## 三、模块 J2：瓶颈迁移的偏导数写法

在 `γ > 0` 且 `θ` 有差异时：

| 求导变量 | 结果 | 读法 |
|---|---|---|
| `∂π_i / ∂θ_i` | `> 0` | **选择端**：筛选能力提高注意力份额 |
| `∂π_i / ∂Q_i` | `−c < 0`（`φ` 不随 `Q` 变时） | **执行端**：多产仍只增加成本 |

两行写在同一张表里，就是 02 篇「稀缺性从执行端迁移到选择端」的可复算版本，也解释了 E-02 为什么「30 倍人效」推不出盈利能力。

> **常见误读**：这两条偏导不冲突，因为它们是**对不同变量求导**。读成「产量无用」或「判断力万能」，都是漏看了「`φ` 不随 `Q` 变」这个前提——§四 正是把它打开。

## 四、模块 J3：什么时候「多产」重新有意义（广撒网条件）

若份额由「至少命中一部爆款」决定（呼应 01 篇模块 D 的爆款口径依赖）：

```
φ_i ∝ 1 − (1 − θ_i)^{Q_i}
∂φ_i/∂Q_i ∝ −(1 − θ_i)^{Q_i} · ln(1 − θ_i)  > 0      (0 < θ < 1)

∂π_i/∂Q_i = kA(1 − s) · ∂φ_i/∂Q_i − c
多产有利  ⟺  kA(1 − s) · ∂φ_i/∂Q_i  >  c
```

**反常识推论**：`θ` 越高，`(1−θ)^Q` 衰减越快，广撒网的边际收益越小。也就是说——**判断力越强，越不需要靠多产碰运气**；`θ` 低时多产是第一反应，但其边际收益随 `Q` 迅速趋零，而成本 `c·Q` 线性增长。

这条不等式把 02 篇引用的「产能越大，亏得越多」（F-055，**记者推论**）与 03 篇的 `∂π/∂Q = −c` 接了起来：两者不矛盾，差别只在于 **`φ` 是否随 `Q` 变**。

> 不得拿 F-019「差 10 倍不止」或 F-034 的「30 万部」当作 `θ` 或 `Q` 的取值（E-03、E-08）；本模块只给条件，不给数值。

## 五、模块 K：三种「内容判断力」在模型里的位置（承接 02 篇 §一）

| 02 篇的区分 | 模型内对应 | 能否表达 | 边界 |
|---|---|---|---|
| 生产 / 写稿能力 | `c` 下降（技术降本） | 可，但与 `θ` 无关 | 属 01 篇要素替代，不是筛选 |
| **筛选 / 选品能力** | `θ_i` ↑ | **是，本篇主角** | 只在 `γ > 0` 且 `θ` 有差异时生效 |
| 可培训性 | `θ` 的可复制性 / 分布 | 模型外，无数据 | 不得推断「可培训 / 不可培训」 |

**一句话**：「内容判断力」不是一个符号，而是「`θ` 有差异 × `γ > 0`」这个**乘积条件**。任一因子为零，它就退回口号。

## 六、模块 L：四个归一化例题（无真实数据）

设 `n = 2`、`θ = (0.6, 0.4)`、`kA = 1`、`s = 0`、`c = 0`、`F = 0`（纯归一化，只比较份额）：

| `γ` | `φ₁` | `φ₂` | 读法 |
|---|---|---|---|
| 0 | 0.500 | 0.500 | 均匀，判断力无效（J1） |
| 1 | 0.600 | 0.400 | 按 `θ` 比例分配 |
| 2 | **0.692** | 0.308 | 集中度上升，差距放大 |
| → ∞ | 1.000 | 0.000 | 赢家通吃 |

算式：`γ = 2` 时 `φ₁ = 0.6² / (0.6² + 0.4²) = 0.36 / 0.52 ≈ 0.692`。

**填空练习**：把 `θ` 改成 `(0.9, 0.1)`，`γ = 2` 时 `φ₁ = ______`；再令 `θ₁ = θ₂`，看 `φ` 回到多少：______

> `c = F = 0` 只是让例题只显示份额，不是现实假设；一旦 `c > 0`，§四 的产量项立即回来。

## 七、证伪与引用边界

| 若观测到 | 失效的推导 | 处置 |
|---|---|---|
| 平台按投稿量 / 时长均匀分发，推荐权重与内容表现无关 | `γ → 0`，J1 | 退回 03 篇模块 E，02 篇瓶颈迁移不适用 |
| 所有供给方 `θ` 趋同（选择被可靠自动化） | `θ_i = θ_j → φ = 1/n` | 02 篇 §三 失效条件的可复算版本 |
| 少数作品跨周期复播、收入不随 `S` 摊薄 | H1 同质与 H3′ 同时被打破 | 需引入跨周期资产项，超出本包；**登记不建模** |
| 单部爆款收入下跌但头部份额上升 | F-044「单价在跌」与 `γ` 上升并列 | 两者**不互相解释**，不得写成因果（G1） |

> F-044「爆款通胀的根因是注意力单价在跌」是**记者判断**（C 层），`γ` 是编者符号，二者只能并列登记，不能互相印证。
> 全局引用规则见 [P0 核验报告 §五](../references/verification.md)：F-025、F-031、F-032、F-055 须带「受访者自述 / 据报道」限定；F-026 亏损率无分母（E-06），不得作为行业统计引用。

## 九、四条禁用（继承 01 / 03 + 新增两条）

1. **不得据本表估算行业规模、均价、收益或任何能力水平**（继承 01 / 03）：全部输入是单源自述、编者符号或读者自填。
2. **不得把任何结果当作创业、定价、投资、招聘、培训或裁撤依据**（继承 01 / 03，含 02 篇新人视角采纳项）。
3. **不得把 `θ` 当作可测量的能力分数**：无量表、无样本、无时点；`γ` 与权重函数形式均为编者假设。
4. **不得与 01 或 03 的两条路径串联代入**：本篇是**第三条参数化路径（份额法）**，只改 H3，其余沿用 03 的 H2；`θ / γ / φ` 不进入 01 的任何算式，也不进入 03 的路径 1（阈值法）与路径 2（结构法）。
