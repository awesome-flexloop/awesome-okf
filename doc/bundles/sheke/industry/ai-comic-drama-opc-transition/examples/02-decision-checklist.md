# 判据清单：读行业预测的四问

> **这是什么**：由**编者从概念层归纳**的可勾选学习工具，用来在引用一句行业断言之前先做四次核对。
> **这不是什么**：不是原文提供的建议清单，不是评分模型，不产出「该不该相信」的结论，也不构成创业、择业、投资或裁撤建议。原文本身没有可复现步骤，本清单只是把本包的引用纪律变成可填写的表格（对抗审查·编者视角采纳项）。

## 用法

对任意一句准备引用的话，依次走 Q1→Q4。任一步出现「红线信号」，就**只登记、不引用为事实**；四问全过也不代表该句为真，只代表你知道自己站在什么材料上。

---

## Q1 · 谁在说，这是哪一层陈述？

- [ ] 写明了发布主体与身份（平台方 / 受访者 / 记者 / 编者 / 未知）
- [ ] 写明了时点与载体
- [ ] 给这句话贴上了唯一标签：

| 标签 | 本包对应 | 可用来做什么 |
|---|---|---|
| A 平台方公开口径 | F-058~F-061 | 可作事实引用，须带「阅文」「2026-10-16」；多源转述一致 ≠ 经审计 |
| B 受访者自述 | F-008~F-024、F-036 | 只作「某公司负责人口述」，不升格为行业事实 |
| C 记者判断 | F-013、F-043~F-046 | 只作**论证结构**分析，追问省略了什么前提 |
| D 假设计算 | F-034 | 只作算例骨架，引用时保留「如果未来」（E-08） |
| E 预测 | F-056、F-062 | 只作**待检验命题**，须带「预测」二字（E-05） |

🚩 **红线信号**：出现「行业数据显示」「普遍认为」「多方共识」但找不到发布主体；把同源转载当成独立印证（见 [信源清单 §二](../references/sources.md)）；把平台自述写成审计数据。

---

## Q2 · 分母与口径是什么？

- [ ] 单位写全（元/分钟、部/人月、元/人、部/月、营收/单部分账 …）
- [ ] 分母有定义（作品？项目？公司？行业？时点？抽样方法？）
- [ ] 主体、时点、地域范围明确
- [ ] 确认没有跨口径相乘、相除或并列

| 常见混用 | 本包勘误 |
|---|---|
| 部/人月 与 元/人 两种人效 | E-02 |
| 公司总流水 与 单部爆款收入 | E-03、E-04 |
| 批量剧 与 精品剧两条路线 | E-12 |
| 实测 与 预估（出海 9 月 20 万部） | E-07 |
| 「90% 以上亏损」无分母与抽样 | E-06 |

🚩 **红线信号**：数字没有单位；比例没有分母；同一段里两个数字靠「所以」连接但分母不同；用算术自洽代替外部核验（[P0 第 13、15、16、18 项](../references/verification.md) 都是这个陷阱）。

---

## Q3 · 能否证伪？何时对照？

- [ ] 关键名词有可操作定义（例如「机构」指 ≥N 名全职雇员的制作主体，N 先固定并公开）
- [ ] 写了什么观察算**支持**、什么观察算**证伪**
- [ ] 写了对照时点与对照材料类型（平台披露 / 工商登记 / 行业普查 / 财报）
- [ ] 没有使用全称量词或不可检验的措辞（「一定」「没有」「很快」「核心」）

🚩 **红线信号**：全称判断无失效条件；同一来源给出两个未处理的时间尺度（F-056「很快」与 F-062「3~5 年」）；用「如果」起头的算式被写成趋势（F-034）；「明年」这类相对时间未换算为绝对年份。

> 四步降级示范见 [05 篇 §三](../concepts/05-historical-analogy-and-prediction-boundary.md)，事后检验清单见 [05 篇 §四](../concepts/05-historical-analogy-and-prediction-boundary.md)。

---

## Q4 · 哪一层在受益，固定项在谁手里？

- [ ] 区分 **L1 总量层**（平台收入、总播放、内容供给量）与 **L2 分配层**（单部收入、利润率、议价权）
- [ ] 标出该行业的**固定项**（注意力入口、IP、算力、发行渠道、牌照）与**可无限进入的环节**
- [ ] 判断主张说的是 L1 还是 L2，没有互相替代
- [ ] 检查说话人的利益立场，两方叙事方向一致时**不合并计为独立印证**

🚩 **红线信号**：拿平台收入增长直接反驳「制作方难赚钱」，或反过来（E-11）；把机构创始人的收缩叙事与平台推 OPC 的叙事当作两个独立信源（[04 篇 §三](../concepts/04-opc-transition-and-organization.md)）；只讨论被技术替代的那一项职能，忽略被上移到平台的职能。

## 演练：F-056 走一遍四问

| 问 | 结果 |
|---|---|
| Q1 | E 层，酱油文化创始人黄浩南在 2026-10-17 报道中的**预测**，非事实 |
| Q2 | 「机构」未定义，全称量词「没有」无分母与抽样 |
| Q3 | 不可证伪；须先自拟人数阈值、写出支持/证伪观察、定 2027 上半年对照（E-05） |
| Q4 | 该主张说 L2 组织形态；同期平台数据是 L1，不能互相否定（E-11）；平台与机构叙事不独立 |

**结论**：只登记为待检验命题，不写成结论，不作为决策依据。完整展开见 [05 篇](../concepts/05-historical-analogy-and-prediction-boundary.md)。

## 使用边界（总声明）

- **不判定真伪**：四问只做陈述分层与口径登记，不输出「可信/不可信」。核验结论另见 [P0 核验报告](../references/verification.md)。
- **不产出建议**：清单不含任何行动项、评分、排序或决策阈值；参数（如人数阈值 N）由使用者自行固定并公开，属方法自定义值，非实证结论。
- **不替代原文**：所有 F 编号指向 [原文事实清单](../references/article-source.md)；编者归纳的框架（两层模型、职能上移、预测四步降级）不得写成「报道指出」。
- **时效**：`stale_after: 2027-04-30`；到期须重核各条 E 勘误与 [05 篇事后检验清单](../concepts/05-historical-analogy-and-prediction-boundary.md)。
