# 怎样倒排，卡住后走哪条退路

这不是给每个人套用的“两天必交付”计划。用户权限、实际作品和可投入时间未知；先记录依赖，再决定本轮做什么。活动时点来自2026-10-27研究，工作日不在本页换算成未经核实的日历截止。

## 三条线分别排

| 线 | 自己能完成的检查 | 外部依赖 | 前置未满足时 |
|---|---|---|---|
| 资格 | 确认目标入口、真实工具链、素材来源和适用条款 | 看山权限、平台回复、本人首发权益、完整协议 | 保留私有稿；不勾协议、不声称获得资格 |
| 作品 | 固定版本、跑核心任务、真实截图/视频、脱敏对话 | 正式部署、评审可读链接、认可平台范围 | 缩小功能或只选一个符合真实工具链的入口；静态图不能顶替体验 |
| 发布 | 区分三种对象、登记发表历史、独立论证、核话题与材料 | 审核、公示、首发适用起点及同步规则 | 暂停公开、另写真正独立稿、放弃首发或下一轮；不洗稿恢复 |

依据F-006/F-012/F-014/F-018/F-038/F-042/F-061至F-066及G-001至G-004/G-010/G-014/G-020至G-024。具体版权前提与算式集中在[版权页](05-rights-and-publication-order.md)，不由排期表另行裁定。

## 把官方时点和计划时点分开

| 节点 | 来源时点 | 本指南处理 |
|---|---|---|
| 知乎征集 | 2026-10-09至10-31，F-002 | 10月27日位于日期窗内；钟点/时区未知，不输出精确“最晚发头条时间” |
| 知乎审核和发奖 | 结束后统一资格审核；结束后20工作日名单，名单后20工作日奖励，F-021/F-024 | 名单与发奖是两段，不当成投稿延期或个人获奖承诺 |
| WorkBuddy投稿 | 2026-10-21至11-01 23:59细则无时区，F-030 | 前端UTC+8 23:59:59仅实现证据F-033；不抹掉两层差异 |
| WorkBuddy评审与公示 | 11-02至11-09评审、11-10公示，F-031/F-032 | 提交≠审核通过≠T+1展示；按平台实际结果，不推固定重提工期 |
| WorkBuddy撤回 | 截止11-01 23:59前邮件，F-060 | 不自动删除其他平台内容；不要先删第三方正文再声称未发表 |
| 头条首发窗口 | 发出后72小时未在站外发布，F-061/F-064 | 没有共同赛事截止；按真实时刻算，并核起点/时区/恰边界G-024 |

例如在UTC+8的10月30日12:00发表，72小时到11月2日12:00，晚于WorkBuddy前端截止；不能写“等满三天还能赶上”。这是演算，不是平台批准的发布方案。更多演算与无许可时的分支见版权页。

## 按实际剩余能力倒排

1. **先做可行性门**：列目标、真实工具、当前权限、核心成果、尚缺条款。若工具链已冲突，停止该作品多投计划。
2. **先跑最小核心任务**：做一个能解释问题的输入—操作—输出，不为了题目显大再加功能。失败时先修或缩小断言。
3. **先确认体验再扩材料**：保留真实版本、链接、截图与对话；第三人不能体验时先解决入口，不先堆宣传。
4. **在私有区组织文章**：分别写读者问题、证据和失败边界，核字数/图片/字段，但不公开实际首发正文。
5. **公开前重新核三线**：用当日规则及实际时刻判断，不把计划节点写成已完成；缺协议或未通过审核就执行退路。

每步耗时由实际进展记录，不能凭本指南给出个人工期、审核SLA或收益预测。安全上优先无密钥演示，或服务端秘密管理；公开源码、对话和图片中均不放测试或真实密钥。

## 阻塞与备用路径

| 阻塞或失效 | 立即动作 | 能保留的成果 |
|---|---|---|
| 工具权限未开或已混用 | 不伪造过程；只选符合实际链的入口，或另做真实新作品 | 私有问题定义、许可资料与可复用核证方法 |
| 正式链接未就绪/评审不可读 | 核正式发布及平台认可通道；来不及则不宣称有效投稿 | 本地真实成果与失败记录，不把预览可用写保证 |
| 审核仍等待或驳回 | 看实际理由与重提条件，未知时不承诺本轮赶上 | 材料清单及修正记录，标待确认 |
| 72小时与活动截止相交 | 真正独立撰文、少选一个入口或不声明首发；先核其他权利 | 各稿独立问题/证据结构，不保留伪首发声明 |
| 已有站外相似正文 | 不靠等待、删重发或换词恢复；适用资格未知则询问 | 真实发表记录与独立的新分析方向 |
| 赛事日期已过且无延期依据 | 停止沿用本轮可参赛状态，转后续普通作品或下一轮准备 | 方法可复用，奖项/工期/规则数字不迁移 |
| 平台或协议更新 | 回核受影响F/G/E和实际入口，未确认前暂停承诺 | 保留旧时点与差异，不静默覆盖历史 |

“退路”是降低错误承诺的方法，不是绕过规则。保留私人创作证据不等于同意公开；投稿成功也不等于评审通过、获奖或首发收益。
