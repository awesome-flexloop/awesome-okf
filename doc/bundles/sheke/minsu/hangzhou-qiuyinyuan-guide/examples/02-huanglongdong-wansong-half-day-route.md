# 民俗点半日路线：黄龙洞月老祠 + 万松书院

## 适用说明

- 两个点位性质不同：黄龙洞圆缘民俗园是婚恋民俗主题城市公园（月老祠祈良缘，F-051、F-053），万松书院是书院景区兼周六公益相亲角举办地（F-058、F-063）——串联逻辑与背景见 [05 篇](../concepts/05-huanglongdong-yuelao-shrine.md)、[06 篇](../concepts/06-wansong-academy-matchmaking-corner.md)；
- 本篇给两套时间轴：**平日版**（任意开放日可用）与**周六相亲角版**（相亲角仅周六上午，时间两说并列）；费用与时间数据采集于 2026-10，**以官方最新公告与现场公告为准**；
- 相亲角现场涉及真实个人信息，本篇不含任何可识别个人信息；到场参与的隐私红线见文末与 [06 篇](../concepts/06-wansong-academy-matchmaking-corner.md)。

## 周边串联建议（西湖爱情文化地标）

杭州市文广旅游局主题文将黄龙洞月老祠、三生石、三情人桥、万松书院等并列为杭州爱情文化地标（F-008）。半日路线体力充裕时，可按动线选一至两处串联：

- **三情人桥**（F-056）：长桥（梁祝十八相送故地）、断桥（《白蛇传》许仙白娘子相会）、西泠桥（苏小小与阮郁故事）；
- **我心相印亭**（F-057）：小瀛洲三潭印月景区南端，情侣打卡点；
- **三生石**（F-015）：位于法镜寺后，需另排天竺线行程，见 [01 篇一日路线](01-faxi-lingyin-one-day-route.md)。

提醒：这些地标的爱情寓意依附于民间传说，属文化符号层，作民俗知识了解即可（见 [05 篇](../concepts/05-huanglongdong-yuelao-shrine.md) 与 [07 篇](../concepts/07-etiquette-and-rational-mindset.md)）。

## 相亲角隐私红线（到场前必读）

- 现场的征婚信息牌属于他人个人资料，**不拍照、不翻拍、不发社交平台**；
- 与现场参与者交流不追问不必要的隐私细节，联系方式交换以双方自愿为前提；
- 如自行准备资料，只放必要联系方式，警惕以相亲为名的推销与诈骗，涉及金钱往来一律拒绝；
- 按入场券与志愿者引导参与（F-063、F-065），不围堵、不喧哗。
