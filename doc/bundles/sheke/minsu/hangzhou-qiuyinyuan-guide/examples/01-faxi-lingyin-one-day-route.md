# 寺院一日参拜路线：法喜寺天竺线 + 灵隐飞来峰景区

## 适用说明

- 路线结构：上午灵隐飞来峰景区（灵隐寺 + 永福寺），下午天竺线（法镜寺三生石 → 法净寺 → 法喜寺）——与 [03 篇](../concepts/03-lingyin-feilaifeng-scenic-guide.md) 的灵隐约上午场、下午走天竺线建议一致，求姻缘符号最集中的三生石（F-015）安排在天竺线第一站；
- 全程费用与时间数据采集于 2026-10，**以官方最新公告与现场公告为准**；概念背景见 [02 篇](../concepts/02-faxi-temple-and-tianzhu-line.md)、[03 篇](../concepts/03-lingyin-feilaifeng-scenic-guide.md)；
- 本路线不含任何灵验程度断言，各点位的文化寓意解读见 [07 篇](../concepts/07-etiquette-and-rational-mindset.md)。

## 行前必办：灵隐实名预约

灵隐飞来峰景区自 2025-12-01 起免票开放、实行实名预约制（F-027，P0-01 双源一致），**不预约无法入园**：

| 预约要点 | 规则（采集于 2026-10） | 依据 |
|---|---|---|
| 预约窗口 | 提前 1 天，可约未来 7 日名额 | F-028（P0-03） |
| 预约限额 | 每个手机号最多约 5 人、同一证件每日限约 1 次 | F-028 |
| 场次 | 上午场最晚 13:00 前入园、下午场最早 11:00 后可入园 | F-029 |
| 爽约代价 | 爽约分别处以 30/60/90 日禁约——**确定行程再约** | F-029 |
| 免预约 | 六类优待对象免预约 | F-029 |
| 咨询 | 0571-87969691 | F-028 |

本路线按**约到次日上午场**设计；只约到下午场时的调整见文末备选方案。

## 用餐与体力分配

- **用餐**：午餐安排在灵隐景区周边或天竺路沿线，按现场选择（本束未收录具体餐饮商户信息，不作推荐）；建议自备饮水与少量干粮，天竺线沿途商业密度低于市区；
- **体力**：灵隐寺占地约 87000 平方米（F-024），上午体力最佳时段走主景区；天竺三寺沿天竺路自下而上爬坡，法喜寺在最高处（F-013），午后保留爬坡体力，穿适合步行的鞋；
- **可舍弃项**：灵顺寺在北高峰山巅（海拔 314 米，F-037），登山强度大，时间紧或体力不足可整段舍弃，不影响主线闭环。

## 风险提示与备选方案

1. **只约到灵隐下午场**：上午先走天竺线（法喜寺 06:30 即开门，F-009），按 法喜寺 → 法净寺 → 法镜寺三生石 自上而下游览，11:00 后凭下午场进灵隐（F-029）——注意 17:00 停止入园（F-028）；
2. **爽约代价**：约好后行程有变，爽约将被处以 30/60/90 日禁约（F-029），不确定就不要提前占位；
3. **历史票价误导**：2025-09 前后的旧攻略仍载飞来峰 45 元 + 灵隐寺 30 元的 75 元双票，该口径已废止，现行以免票通告为准（F-031）；
4. **节假日客流**：灵隐节假日预约量达 6.5 万/日（F-028），法喜寺为社交平台热门机位（F-010）——节假日出行务必早到，并把预约、交通、缓冲时间打宽。
