# 框架对勘："学造连" vs 特定知识+担责+杠杆

> ⚠️ 本页是整包 flagged 的核心证据页。博文把一个**无出处的三字诀**（F-021）挂在真实人物 Naval 名下，且转述中丢失了原始框架最关键的机制。完整 7 项核验见 [核验报告](../references/verification.md)；Naval 本人框架见上一篇 [00 Naval 其人](00-naval-and-source-framework.md)。

## 二、逐项拆解

### 学（F-005~F-010）：唯一转述基本准确的一节，但有两处偏差

**说对的部分**：特定知识概念准确（F-025）。博文"无法标准化教学，结合经历特长思考沉淀""普通知识人人能搜到，独有认知拿不走"与 Naval 的不可替代性论述方向一致；"带着现实问题学、深耕一个领域"也符合他追随好奇心与在实践中积累的主张。

**两处偏差**：

1. **剂量缩水**："每天 30 分钟就足够"（F-008）没有 Naval 出处。Naval 在 Shane Parrish 访谈等多处自述每天阅读 **1–2 小时**（F-023），且把阅读当作一种生活方式而非打卡下限；30 分钟更像是为降低行动门槛做的自媒体化改造；
2. **"学习是一切财富的起点"（F-010）是作者加码**：在 Naval 框架里，学习只产出"特定知识"这一个支柱，不经过担责与杠杆，知识不会自动变财富——否则图书馆员和教授早就是最富有的人。这是典型的把必要条件说成充分条件。

## 三、造（F-011~F-013）：对应 build，但缺了并列的 sell

博文"把认知落地成可交付作品""先完成再迭代"本身是合理的行动建议，但放在 Naval 名下时存在概念截断：

- 原文是 "**learn to build and sell**"——造（build）与卖（sell）是并列的两大技能，没有谁是谁的附庸（F-020）；
- 博文把 sell（面向市场的分发、销售、说服）整个砍掉，后续用"连（链接客户）"（F-015）轻描淡写带过，把一种**硬性商业能力**降格成"展示作品等人来问"；
- 博文虽提到"解决别人问题的成果才可换取回报"（F-013），但没解释为什么作品能换钱——Naval 的回答是**杠杆**：代码与媒体让一份成果零边际成本复制给百万用户（F-022）。缺了这层，"持续创造"可能只是在生产按件计费的定制服务，依旧是线性收入。

## 四、连（F-014~F-016）：最严重的错位

这是"学造连"中问题最大的一字。

1. **Naval 框架里没有"人脉"支柱**（F-021）。他甚至对传统"搞关系"持冷淡态度——机会来自你有特定知识与杠杆后变得可被发现，而不是去链接圈子；
2. **"作品当名片、吸引同频靠近"（F-016）至多算媒体杠杆的弱化版**：公开发布作品确实属于 permissionless leverage 的一种用法，但 Naval 的推论终点是"零边际成本分发 + 持有股权"，不是"合作资源机会慢慢靠拢"这种模糊许诺（F-027）；
3. **两个硬概念被彻底替换**：
   - Accountability（担责）：以个人名义为产品判断负责、愿赌服输地建立公开声誉；
   - Equity（股权）：拿到公司/产品所有权的一块，使你的收入与劳动时间脱钩。
   两者在博文 1088 字中零次出现（F-022）。

## 五、两处数字勘误及其对预期管理的破坏

| 博文数字 | 权威值 | 读者若照单全收的后果 |
|---------|-------|---------------------|
| 每天 30 分钟（F-008） | 每天 1–2 小时（F-023） | 低估特定知识的积累强度；真信"30 分钟足够"的人很可能在浅层次徘徊 |
| 三年被动收入超工资 / 三年质变（F-002、F-017） | 复利通常 10–20 年、有时 5 年（F-024） | 两三年没结果就判定"方法没用"或"自己失败"，恰恰在复利曲线起势前放弃 |

## 六、校正后的行动映射（仅作框架理解，非教程）

按 Naval 本人逻辑校正博文三字诀，应大致映射为：

| 博文 | 校正后（Naval 口径） |
|------|---------------------|
| 学 | 每天足量阅读+实践，积累"对你像玩、对人像干活"的特定知识 |
| 造 | build——用代码/媒体这类无需许可的杠杆造可零边际复制的产品/内容 |
| （缺） | **sell**——练销售与分发，把作品推到市场，而非等人发现 |
| （缺） | **担责**——以个人名义下注、公开负责，积累声誉资本 |
| 连 | 不是经营人脉，而是**公开运用媒体杠杆**让自己可被发现，并以此争取**持有股权**（资产 > 工资） |
| 三年循环 | 以 5–20 年复利尺度配置预期，每年检查资产性收入占比而非盯速成结果 |
