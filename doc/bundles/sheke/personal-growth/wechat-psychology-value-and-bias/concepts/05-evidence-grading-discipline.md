# 证据分级阅读纪律：把可检验的框架带走

> **本篇的特殊性**：前四篇讲的是**作者讲了什么**，本篇讲的是**如何判断该带走什么**。它的全部方法不是来自作者，而是来自本 bundle 对这篇文章本身所做的核验实践（见 [核验报告](../references/verification.md)）——**用一个单源样本，演示如何处理单源**。

## 一、为什么需要这套纪律

这篇文章是一篇**评论文章**，不是研究报告。它的所有事实性内容都来自它自己引用的 8 条参考源。

这带来一个特别有价值的情况：**引用忠实度是可被逐条检验的**。作者引用了原话吗？数值对得上吗？转述时省略了原研究的哪些部分？这些都有客观答案。

本文的纪律正是从这次检验中提炼出来的。它适用于任何科普、评论、自媒体内容，**不限于心理学**。

## 二、四级证据分级

| 级别 | 判据 | 本 bundle 中的例子 | 你应该怎么做 |
|---|---|---|---|
| **A** | 有可回源的原始文献，量化数据可**逐字核对** | Nature 综述的 183 项试验 / 22,811 人（F-054）；「原生家庭就是一个人最大的命运」（F-019） | 可以引用，**但必须带上效应量与限制条件** |
| **B** | 有独立官方或机构页面可确认**存在与大意**，但细节未披露 | 清华发布的《2025年中国人幸福感报告》（F-047/F-052） | 可以引用**事实本身**，不可引用未披露的量级 |
| **C** | 单一作者的观点，有案例但无对照、无信源 | 三个偏差的框架（F-007~F-011）、四个方面的归纳（F-059~F-063） | 当作**视角**而非结论使用 |
| **D** | 转述他人且**无任何来源** | 周文强课程中的「你所有的一切都是你创造出来的」（F-037） | 只当"某人说过"，**不引用为事实**，不据此评价任何人 |

**这套分级的关键不在标签，而在每一级对应的动作。** 分级本身没有价值，"A 级要带限制条件、C 级当视角、D 级不引用"这些动作才有。

### 2.1 A 级的纪律：引用时必须带上三样东西

A 级最容易被滥用，因为"有原始文献"给人以确定感。但**只引结论不引效应量，等于没引**。

本 bundle 的实例：作者转述 Nature 综述时给了"183 项试验、22,811 人"（F-054，逐字准确），但**没给效应量**。核验补出的数字是：

- 运动 + 心理联合干预：SMD 0.73（95% CI 0.27–1.20）
- 正念 / 慈悲 / 单一积极心理学 / 瑜伽 / 运动：SMD 0.41–0.49
- **自然类干预未显著优于对照**

省略数值后，读者只能得到"有效"这个二值结论；而原研究说的是"在群体平均水平上，相对无活动对照，某些干预类别有中小到中等的效应，且效果因干预类型而异"。**这两句话不是同一句话。**

> **一条自检**：如果你的引用去掉所有数字后读起来毫无变化，那说明你引的其实是"方向"而不是"研究"——方向可以引，研究不能只引方向。

### 2.2 B 级的纪律：存在 ≠ 量级

B 级来源最容易被反向滥用：**"清华的报告说了……"这句话里，如果"清华的报告"是唯一的支撑，那它能支撑的只有"有这样一个报告存在"，不能支撑报告里的任何具体数字。**

本 bundle 的实例：F-052 说《2025年中国人幸福感报告》"通过大样本问卷"。清华页面确认了报告发布、主办方、承办方与四个实践方向，但**未披露问卷样本量**。因此"大样本"这一量级判断被降级为 `flagged`。

同一条 B 级事实还带出两个容易被忽略的细节，都写进了[核验报告](../references/verification.md)：

- 该报告由高校研究中心主办、**商业品牌承办**（lululemon）；
- 页面未显示同行评议信息。

**这两个细节不推翻报告的价值，但决定了它能承担多大的论证重量。** 一个主办方清晰、承办方明确、未经同行评议的报告，适合支撑"有研究者正在做这件事、提出了哪些方向"，不适合支撑"该结论已被确证"。

### 2.3 C 级的纪律：框架可以带走，结论不能引用

C 级是本 bundle 的主体——三个偏差、四个方面、知识/能力/成熟三层，全是作者自设的框架。

**C 级内容该怎么用？** 用它的**提问方式**，不用它的**结论**。

| 作者的框架 | 可以带走（提问方式） | 不能带走（结论） |
|---|---|---|
| 三个偏差 | "我是在理解还是在判定？" | "多数人都有归因偏差" |
| 知识/能力/成熟三层 | "他学过什么？练过什么？从失败里改过什么？" | "心理学学位不保证心理能力"（对个体的断言） |
| 四个方面 | "我最近一次用理论解释别人时，也用它解释过自己吗？" | "心理学的真正价值就是这四方面"（学科定义权） |

**C 级框架还有一个致命软肋，本 bundle 已显式标注：边界模糊。** 同一现象可以同时落进多个偏差——一篇用心理学概念解释他人的文章，既是"归因偏差"，也是"知识与实践的距离"，如果还带成功承诺，甚至同时是"目的偏差"。**一个分类如果任何样本都能落进至少两类，它就没有分类能力。**

### 2.4 D 级的纪律：只登记"谁说过"，不登记"说了什么为真"

F-037 是一个 D 级的典型：作者说周文强的课程里出现过「你所有的一切都是你创造出来的」，但**没有提供课程名称、时间、原始页面**，8 条参考源中无一对应。

对 D 级内容，本 bundle 的处理是**在事实表中把归属权写清楚**：

> 登记为"作者转述周文强课程中出现了这句话"，**不登记**"周文强说过这句话"。

**这不是吹毛求疵。** 归属一旦丢失，后续的批评就可能落到一个从未说过这话的人身上，而当事人无从辩解。

## 三、三条引用忠实度检查

这套检查是本 bundle 实际用过的，可以直接迁移。

### 检查一：引文是否被截取？

实例（F-019）：作者引用武志红的「原生家庭就是一个人最大的命运」，但同一段落的紧接下一句是"**人格一旦形成，改变就非常困难**"——这句比作者引用的更强烈，且直接与作者"早期影响不等于终身决定"的立场冲突。

**作者摘掉了对自己论证不利的那半句。** 结果是：论证方向被保留了（决定论式推论确实过强），但论证的完整性被削弱——读者会低估原主张的强度。

> **操作**：引用别人的话之前，先去原文读**前后各一句**。被引句的前一句和后一句，往往才是真正的争议所在。

### 检查二：原结论有没有被选择性转述？

实例（F-055）：作者转述了 Nature 综述的正面结论（"多数干预相比无活动对照可改善幸福感"），也保留了偏倚警告（"风险偏倚常为中到高"），但**省略了效应量与"自然类干预未显著优于对照"这一反向发现**。

注意：这个省略**不构成失实**。所有被写下的内容都是真的。**选择性转述是比造假更难发现的一类问题**，因为句句属实、结论方向也不偏。

> **操作**：读一篇转述研究的内容时，回去看原文的**限制与局限**一节，然后对照转述里有没有提到它们。如果转述保留了坏消息（偏倚高）却省略了量化细节（效应量），几乎可以确定这是一种**朝"更可信"方向的编排**，而不是中立摘要。

### 检查三：证据链有几层？

实例（F-027）：作者说"据俞敏洪友人张翔转述，俞敏洪决定不回应"。回到 src-004 原文，实际结构是三层：

```
罗永浩公开抨击  →  张翔（自称俞敏洪 20 多年好友）公开辩护，
                        称"与俞敏洪沟通后，了解到俞敏洪不会回应"
                        →  作者再转述张翔
```

原文中的"不会回应"是**张翔对他人意图的判断**，不是俞敏洪的公开声明。而张翔在这篇报道中还是主动站出来替俞敏洪说话的利益相关方。

**层数越多，结论越需要降级表述。** 这里作者的处理其实很妥当——他保留了"据……转述"的限定词，没有写成"俞敏洪表示不回应"。**这是一个正例：转述链条被完整标注，而不是被抹平。**

> **操作**：任何"据某某说"的表述，问三个问题：**谁是原始来源？这是第几手转述？转述人有没有说这句话的动机？** 第三个问题的答案通常比前两个更重要。

## 四、识别常见误用的信号

当一段内容在把"框架"包装成"事实"时，通常会出现以下信号。识别它们不需要专业训练。

| 信号 | 例子 | 背后的操作 |
|---|---|---|
| **量级缺失** | 给了"大样本""数千人"，但查不到具体数字 | 用一个大词覆盖掉无法核实的细节 |
| **方向替代数值** | 只说"研究表明 X 有效"，不说效应量 | 传播只保留二值的那一半 |
| **引用无源** | 转述某人的课程、观点、书籍，但没有出处 | 归属不可查，风险不可追 |
| **截取引文** | 引用一句强势的话，省略紧接的限定句 | 保留立场，削掉复杂度 |
| **样本即论证** | 用几个名人案例支撑"大多数人如何如何" | 案例集非随机，频率不可推断 |
| **积极框架 + 消极问责** | 一边讲成长心态，一边把未成功归因于心态 | 见[上一篇](02-purpose-bias.md)的两种逻辑错误 |

这六条信号里，**"量级缺失"和"方向替代数值"最隐蔽**，因为它们留下的文字完全正确。

## 五、把主张转成可证伪命题

如果前面几篇都在讲"什么值得带走"，本节给出具体路径：**拿到任何一条主张，把它改写成可以被推翻的形式。**

### 5.1 三步改写

**原句**："读心理学的人，更容易在人际冲突中误判他人。"

**第一步：抽出因果结构**。"读心理学 → 更容易误判"，中间缺一个机制。

**第二步：补上机制与条件**，写成可检验的形式：
> "在**解释他人行为**这一任务上，使用心理学概念会**提高**给出确定性诊断（而非开放假设）的概率。"

**第三步：给出证伪条件**：
> "如果随机分配两组被试完成同一组冲突情境描述任务，使用概念组生成的诊断性结论数量**不高于**不含概念组，则该命题不成立。"

**结果**：原句是一个无法被反驳的印象，改写后是一个可以设计的实验。

### 5.2 三个问题判真假

改写时反复问这三个问题：

1. **Y 的判定标准是什么，由谁定？** —— 若标准未公开或由主张方定义，则无法判定成败。
2. **失败的人被解释成什么？** —— 若答案是"他们不够努力/心态不对"，则该主张**同时提供了失败的解释权**，这类主张在实践中极其危险。
3. **有没有说 Y 不可能实现的条件？** —— 说不出失效条件的主张无法被证伪，因而更接近信仰而非方法。

### 5.3 一个必须做的动作：标出你自己无法核实的部分

本 bundle 的做法可以照搬：

- 66 条事实按 `page_fact`（页面可见）与 `author_claim`（作者观点）分层登记，**执行者的解读一律不进事实表**；
- 每条 `author_claim` 都标注来源 ID 与定位；
- 每条定量或权威性声明都要么给出独立信源，要么明确标 `single-source` / `flagged`；
- **核验结论中明确写出"未采纳"的部分**——例如媒体化表述"NPD 几乎是一个无法被治疗的禁区"被作者弃用，本 bundle 也随之弃用。

最后一条尤其重要：**记录"什么没有被采纳"，与记录"什么被采纳"同样构成证据链。** 它让读者能看到筛选标准，而不只是筛选结果。

## 六、一句话总结

> **带走的不是结论，是提问方式、证据等级和证伪条件。**

对本 bundle 而言，这句话的实际含义是：

- 三个偏差框架可以带走（作为提问方式），但不能当作心理学界的公认分类引用；
- 「原生家庭就是一个人最大的命运」可以引用，但要连同"人格一旦形成，改变就非常困难"一起引用；
- Nature 综述可以引用，但要连同效应量、自然类干预的反向结果和偏倚警告一起引用；
- 「你所有的一切都是你创造出来的」只能作为"作者转述某门课程中出现过的话"提及，不能作为该课程内容的定性依据。

## 边界与失效场景

- 本篇方法**不适用于**需要快速判断的场景。分级与回源是有成本的；面对时效性强的信息，"先标注不确定性、暂不引用"往往比"查完再引用"更实际。
- 本篇的四级分级是**为本次核验任务定制的**，不是通用文献评价体系。不同学科、不同来源类型需要各自的判据。
- 本 bundle 自身的核验是**单次编写者自审**，不是独立审稿或多人交叉验证——D 级与 C 级的判定带有编写者判断，不应被当作对该文的终局评价。
- **本篇示范的纪律不自动适用于本 bundle 自身的框架**："可证伪性优先"是一条好原则，但把它当作绝对的准入条件，会排除掉大量尚未被研究、但清晰可表述的主张。**框架可以是假设，假设不需要已被验证才有价值——它需要的是边界清楚、可被检验。**

## 边界声明

本篇只讨论证据处理方法，不评价任何真实人物的言论、课程或专业能力；所有示例均取自本 bundle 已登记并标注核验状态的事实；不对任何研究结论的普适性作独立断言。
