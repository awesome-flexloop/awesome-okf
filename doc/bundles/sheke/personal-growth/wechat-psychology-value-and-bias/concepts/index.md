# 心理学能解释什么：三个偏差、四个方面与证据纪律

本目录把一篇公开公众号评论文章改写为六篇可独立阅读的概念文档。00 为总纲——心理学能解释什么、又不能解释什么；01~03 处理作者提出的三个偏差——用理论解释他人（归因偏差）、用理论兑换成功（目的偏差）、以及把知识当作能力（知识与实践的距离）；04 处理作者眼中唯一的建设性方向——把幸福感当作可研究的目标；05 给出可迁移的证据分级阅读纪律。
