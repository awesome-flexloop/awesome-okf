# 00 情境画像：相亲刚加微信，到底在发生什么

> 返回 [知识包首页](../index.md) ｜ 下一篇：[01 开场与自我介绍](01-opening-and-self-intro.md)

## 1. 一分钟情境画像

经介绍人引荐，你们在见面之前先加了微信。好友申请通过的那一刻，你们**没有任何直接交往记录**（F-003），你掌握的全部信息来自介绍人的转述（F-006）；接下来的首次对话将在微信上以异步文字方式进行（F-002、F-007），而这个阶段的约定流程是"微信联系 → 线下见面 → 进一步了解"（F-005）。

这意味着初次微信聊天同时承担三件事：

1. **对上号**：确认微信对面的人与介绍人描述的是同一个人；
2. **给判断**：让对方获得"这人是否正常、是否好沟通"的初步可预测性（F-009、F-010）；
3. **铺路径**：为线下见面这一高带宽场景做预约（F-004 决定了微信承载不了深度了解）。

## 2. 目标函数：什么是"聊得好"

| | 错误目标 | 正确目标 |
|---|---|---|
| 目标 | 让她喜欢我、觉得我有趣 | 让不确定性降低：身份确认 + "正常、好沟通"的判断 |
| 成功判据 | 聊得热火朝天、她一直笑 | 对上号、各给出 2 项以上表层信息、在好情绪里收尾、一周内可邀约 |
| 时间观 | 聊越久越有戏 | 30—60 分钟，微信只是预约渠道（见 I-2） |
| 姿态 | 考生面对考官，努力表现 | 双向筛选，双方都有继续或终止的选择权（F-008） |

## 3. 六个常见错误假设（F 阶段已剥离）

| 常见假设 | 归零后的事实 |
|---|---|
| 必须幽默风趣、惊艳开场 | 对方此刻评估的是"正常吗、安全吗"而非"有趣吗"；表演增加不确定性 |
| 聊得越久越有戏 | 初次长聊透支话题、拖延见面；微信的使命是预约见面 |
| 查户口不礼貌，所以少问 | 被讨厌的是只索取不交换；"我先说我的，你呢"不是查户口 |
| 要展示高价值 | 刻意展示与平等初识的场景不匹配；初次要的是真实感 |
| 话题内容决定成败 | 情绪体验（轻松、无压力、被尊重）比内容更影响后续意愿 |
| 通过好友 = 对我有意思 | 通过可能只是给介绍人面子；兴趣是在互动中产生的 |

## 4. 五条公理（逐条标注来源性质）

| # | 公理 | 锚定 |
|---|---|---|
| 1 | **信任传递**：初始信任来自介绍人，任务是"不辜负这份背书"——做一个与介绍描述一致的正常人 | 理论锚定：F-011 的主动策略（向第三方获取信息）、F-006 |
| 2 | **不确定性递减**：每次互动的价值 = 降低了多少不确定性 | 理论锚定：F-009、F-021 |
| 3 | **带宽约束**：文字不承载深度了解，只承载"要不要进入高带宽场景"的决策 | 理论锚定：F-004、F-019 |
| 4 | **双向筛选**：跪舔和傲慢都破坏筛选，双方地位平等 | session 推导（见首页 I-4 的证据 F-008） |
| 5 | **目的显性**：推进见面是心照不宣的共同目标，节奏要让对方舒适 | session 推导（F-005、F-013 的预期未来互动条件） |

> ⚠️ 文化边界：URT、SPT 均形成于 1970 年代美国样本，华人相亲中"介绍人背书权重""家庭信息敏感度"可能不同；上述公理按机制参考使用。
