# 02 话题与高点收尾：聊什么、什么时候停

> 返回 [知识包首页](../index.md) ｜ 上一篇：[01 开场与自我介绍](01-opening-and-self-intro.md) ｜ 下一篇：[03 邀约与风控](03-invitation-and-risk.md)

## 1. 话题地图（按优先级）

| 优先级 | 话题来源 | 怎么聊 |
|---|---|---|
| ★★★ | **介绍人给过的信息**（她的职业、爱好） | 真诚问一句细节："你做设计平时主要做哪类作品呀？" |
| ★★★ | **她最近 1—2 条朋友圈** | 评论 + 一个开放小问题："看你上周去了 XX，那家好吃吗？" |
| ★★ | **同城生活**：周边逛吃、周末去处、通勤 | 先讲自己的体验再问她 |
| ★★ | **轻兴趣**：宠物、美食、电影、运动 | 点到为止，不做观点输出 |
| ★ | **日常状态**：今天忙不忙、工作节奏 | 只作寒暄过渡，不连续使用 |

话题的广度（聊几类）比深度（聊多深）更适合首聊——初次互动的信息交换在 SPT 中以广度铺开、深度随关系阶段推进（F-015、F-017）。

## 2. 朋友圈纪律

- **只看最近 1—2 条**，并只围绕这 1—2 条开口；
- 不点赞她半年前的动态，不评论旧照；
- 她朋友圈是**三天可见或空白**：不追问"你怎么不发朋友圈"，直接退回同城/兴趣话题。

## 3. 话题边界：第一晚不碰什么

| 类别 | 具体内容 |
|---|---|
| 私密信息 | 收入、存款、房车明细、家庭负担 |
| 关系议题 | 前任、择偶清单、什么时候结婚、要不要孩子 |
| 立场对立 | 政治、宗教、地域评价、男女对立话题 |
| 越界内容 | 土味情话、任何荤梗、评价身材长相 |
| 压力动作 | 连续语音、要求视频、追问"怎么不回我" |

这些不是"聊了会扣分"，而是规范违背——对方可能直接据此给出整体负面判断（F-018、F-017）；自我表露对亲密度的收益只在一定范围内，过界不产生额外回报（F-023）。

## 4. 高点收尾：在最好的时刻主动结束

**判据**：她回复积极（有内容、有表情、愿意反问你）时，就是高点。不要等到话题自然死亡。

**话术**：

> 今天聊得挺轻松的，不早啦，你早点休息，改天再聊～

或：

> 跟你聊天还挺舒服的，我这边准备洗漱了，先不打扰你，改天聊 😊

| 为什么高点收尾 | 依据 |
|---|---|
| 把最后印象留在积极情绪上 | F-009：互动记忆支撑下一次的意愿判断 |
| 主动结束 = 无压力，降低"被缠着"的风险 | F-008：对方随时可终止，让她保留舒适感 |
| 控制时长，不把首晚节奏拉满 | 节奏会成为后续基准（见首页 I-4） |
| 为"改天聊"和邀约留下自然接口 | F-013：预期未来互动维持对方动机 |

整场控制在 **30—60 分钟**为宜。

## 5. 聊天中的节奏纪律

- 回复速度大致跟随她：她十分钟回，你不必秒回；她秒回，你可以快一点；
- 她回复变短（"嗯""哈哈"）→ 这是话题或精力信号，**缩短内容并准备收尾**，不补发、不硬找新话题；
- 全程不做的事：连发三条、长段小作文、深夜还在找话题。
