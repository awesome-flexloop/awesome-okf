# 02 · 每日四问：完整结构与用法

> **这是本包中最可直接照做的一篇。** 其余各篇是理解框架，本篇是今天就能开始的工具。

## 1. 出处与原文

**出处**：陶行知在**育才学校三周年纪念晚会**上向全校师生提出（F-TX-070，B 级来源：维基百科条目「每日四问」章节；上海市行知中学工具书同源）。

**原文**（F-TX-071）：

> 我的身体有没有进步？如果有，进步多少？
> 我的学问有没有进步？如果有，进步多少？
> 我的工作有没有进步？如果有，进步多少？
> 我的道德有没有进步？如果有，进步多少？

**关键细节（F-TX-072）**：每一问都带「**如果有，进步多少？**」的后追问。这个后追问是四问与普通自我检查清单的**分水岭**——它要求一个**增量值**，而不是一个状态判断。

## 2. 四问的顺序不是随意的

### 2.1 身体为什么排第一

陶行知对第一问有明确解释（F-TX-073）：

> 「健康第一，没有了身体，一切都完了！」

背景是当时**学校曾有学生因病去世**，而国家经济落后、学校无力请校医（F-TX-073）。因此他提出要建立「健康的堡垒」，并给出四策略（F-TX-074）：

| 策略 | 内容 |
|---|---|
| 一 | 科学的观察与诊断 |
| 二 | 饮食的调节与改进 |
| 三 | 预防疲劳的休息 |
| 四 | 用卫生教育代替医生 |

> **推断**：他不是把健康当成「个人事务」，而是当成**教育的基础设施**。第四策略「用卫生教育代替医生」尤其关键——在资源极度匮乏时，他用**普及教育替代专业服务**，这本身就是「生活教育」思路的体现。

### 2.2 道德为什么排在最后（但最重要）

陶行知对第四问的表述（F-TX-077）：

> 「道德是做人的根本。根本一坏，纵然有一些学问和本领，也无甚用处。」

并主张「建筑人格长城」，认为道德是人格长城的基础。

人民日报客户端的阐释文章进一步说明其逻辑（F-TX-077）：「没有道德的人，学问和本领愈大，就能为非作恶愈大」。

> **为什么排最后而不是最前（推断）**：
>
> 这是一个**刻意设计的排序策略**，不是优先级失误。
>
> - 若把道德放第一，它会变成「最容易表演」的检查项——人人都可以说「我今天道德很好」，因为道德无法被第三方客观验证；
> - 放最后，前三问（身体/学问/工作）都是**可客观测量的**（体检报告、学习产出、工作成果），它们为第四问提供**可信的基础**。
> - 换言之：**前三问是第四问的可信度锚点**。当一个人身体、学问、工作都在进步时，他对「我今天道德有没有进步」的回答才可信。

> **这条推断是本包最重要的一次结构性解读**：它把一个「四句话」变成了「**三层可测量 + 一层不可测量**」的分层度量结构。详见 [../../huge-actor-craft/](../../huge-actor-craft/index.md) 中胡歌案例的同构验证。

## 3. 每问的配套方法

### 3.1 学问问：五字箴言「一、集、钻、剖、韧」

陶行知为「学问有没有进步」提供了具体方法（F-TX-075）：

| 字 | 含义 | 原文解释 |
|---|---|---|
| **一** | 专一 | 围绕一个专一的问题进行研究 |
| **集** | 搜集 | 强调大量搜集资料 |
| **钻** | 深入 | 要求深入研究问题 |
| **剖** | 解剖 | 强调辨别材料的真伪 |
| **韧** | 坚韧 | 提倡长期坚持研究 |

> **这五字的顺序就是一次完整的研究流程**（推断）：先聚焦（**一**）→ 再广泛收集（**集**）→ 然后钻进去（**钻**）→ 辨真伪（**剖**）→ 长期坚持（**韧**）。
>
> **注意「剖」这一步的存在**：它明确要求**辨别材料真伪**。这意味着陶行知的「学问进步」定义里，**包含了对信息质量的审查**——不是「读得多」就算进步。这与本包其他两个 bundle 中的信源核验纪律（F 编号体系）完全同构。

### 3.2 工作问：三点建议

陶行知为「工作有没有进步」给出三点（F-TX-076）：

1. **站好岗位**——不越位、不敷衍
2. **敏捷正确**——快且对，不是快而错
3. **做好为止**——不做完不算完

> **三点合起来是一个交付质量的三重门**（推断）：岗位意识（为谁做）→ 效率与正确性（做得怎样）→ 完成度（做到什么程度）。注意「做好为止」是**明确反对半成品**的。

### 3.3 道德问：没有配套方法，这是有意的

值得注意：身体有四策略、学问有五字、工作有三点，**唯独道德问没有配套方法**（对照 F-TX-074/075/076）。

> **推断**：这不是遗漏，而是承认**道德无法被提供方法论**。任何「道德提升三步法」都值得怀疑。
>
> 这给出了一个重要的判断标准：**当某个领域出现大量「方法论」时，往往正是它最不需要方法论的时候。**

## 4. 怎么用才不沦为口号（推断层，本包提出）

四问失败的最常见方式是变成「今天身体很好、学问有长进、工作努力、道德良好」这种全项通过的自评。四个防失效设计：

### 设计一：给每问设「可测量对象」

| 问 | 可测量对象（举例） |
|---|---|
| 身体 | 睡眠时长 / 步数 / 连续运动天数 / 体脂率 |
| 学问 | 新读页数 / 笔记条数 / 输出字数 / 独立核验的事实条数 |
| 工作 | 交付物数 / 缺陷数 / 评审通过率 |
| 道德 | **无可测量对象**——只能记录事件，不记分 |

**关键设计**：前三问必须**绑定一个具体数字或产物**，「有进步」是判断，「从 0 到 1 页笔记」才是记录。

### 设计二：给「后追问」一个必答的量

「如果有，进步多少？」不能答「有」。必须答一个增量：今天比昨天多了什么？如果昨天是 0，今天是 1 也要写 1。

### 设计三：道德问只记事件，不记结论

因为道德不可打分（F-TX-077 的逻辑），正确做法是**记录一件今天做的与道德有关的事**（守诺、拒绝、帮助、诚实、沉默），**不给自己下结论**。下结论就是表演。

### 设计四：给第四问设置「延迟结算」

道德进步往往当天看不到。**建议把道德问从「今天」改成「这一周」**——每周只回答一次「这一周有没有做一件让我自己认可的事」。理由是：道德行为常常有成本（拒绝一件事、承认一次错误），这类行为在当天问容易因为「牺牲了当下利益」而被误判为退步。

> 这四设计中「延迟结算」是本包新增的（推断层），其余三个是对「可测量/后追问/道德不记分」的机制化。

## 5. 与他要求教职员工的标准（同一把尺子）

值得注意：陶行知对教职员工提出了对称的要求（F-TX-080）：

> 要学生做的事，教职员躬亲共做；要学生学的知识，教职员躬亲共学；要学生守的规矩，教职员躬亲共守。

并称「共学、共事、共修养」才是真教育。

> **这条事实的意义（推断）**：四问不只对学生，也对校长 himself。**当一套自我检查标准只要求下属遵守而不要求自己遵守时，它就不是标准，是话术。** 四问的可信度恰恰来自它对所有人一视同仁——包括提出它的人（他 1946 年去世时 55 岁，最后 100 天做了 100 多次讲演，F-TX-094）。
