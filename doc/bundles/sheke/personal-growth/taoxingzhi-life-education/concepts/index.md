# 概念文档（陶行知 · 生活教育）

本目录 6 篇教程按「**生平 → 体系 → 日常 → 品质 → 边界**」递进：先看清他在什么处境下做出什么选择，再吃透三大命题的运作机制，然后是「每天四问」这一可直接照做的工具，接着是「六大解放」这一创造力操作系统，最后是品质量信号与迁移边界。

## 学习路径

| 序号 | 文档 | 核心问题 |
|---|---|---|
| 00 | [生平谱系与关键抉择](00-life-and-decisions.md) | 他在哪些岔路口做了选择？那些选择透露了什么决策原则？ |
| 01 | [三大命题：生活教育体系](01-three-propositions.md) | 生活即教育／社会即学校／教学做合一，各自解决什么问题？ |
| 02 | [每日四问：完整结构与用法](02-daily-four-questions.md) | 四问怎么问才不是口号？五字箴言与四策略怎么落地？ |
| 03 | [六大解放与创造教育](03-six-liberations.md) | 创造力被什么裹住？六大解放是诊断表还是方法论？ |
| 04 | [品质信号：十二句教诲与日常细节](04-quality-signals.md) | 从十二条教诲、四块糖、放弃高薪里能读出什么品格结构？ |
| 05 | [适用边界与迁移禁区](05-boundaries.md) | 哪些能学、哪些不能照搬？理解到什么程度算过度？ |
