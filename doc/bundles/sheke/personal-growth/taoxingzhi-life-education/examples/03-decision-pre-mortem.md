# 03 · 关键抉择预演表

> **依据**：陶行知六次关键抉择及其处境还原见 [../concepts/00-life-and-decisions.md](../concepts/00-life-and-decisions.md)；六条决策原则为本包 D 级推断。

## 一、六次抉择的完整还原

| # | 时间 | 抉择 | 情境特征 | 提炼出的原则 |
|---|---|---|---|---|
| 1 | 1923 | 放弃月薪 400 银元职位，编写《平民千字课》奔走全国十余省市（F-TX-005，C 级） | 资源稀缺，回报延迟 | **换分母**：受益人数×受益时长 > 个人收益 |
| 2 | 1927 | 在荒山办晓庄，招生广告写「小名士、书呆子、文凭迷最好不来」（F-TX-007/008/009） | 资源近零，人才稀缺 | **门槛筛选** > 说服教育 |

| 4 | 1934 | 反复改名：文濬 → 知行 → 行知 → 行知 → 陶行知（F-TX-046/047/048） | 认知与实践脱节 | **命名即优先级声明** |
| 5 | 1939 | 战时办不收费难童学校，经费不足时倡导「跟武训学」（行乞兴学）（F-TX-023/024） | 极端不确定 | **用道义正当性换生存弹性** |

## 二、三问式预演框架

面对一个真实决策，按三问填写（推断层）：

### 第一问：这个决策会摧毁什么载体？

对应原则 3（资产存于方法）。

```
我的计划依赖哪些具体载体？（机构/项目/团队/平台/身份标签）
如果这个载体明天消失，我的价值还剩下什么？
```

**判定**：如果答案是「什么都不剩」，说明你把资产存错了位置。

### 第二问：这个决策的收益，分母是谁？

对应原则 1（换分母）。

```
这个决策的收益是：
  □ 只归我（个人收益）
  □ 归我 + 若干人（可数的人数：___ 人 × ___ 持续时间）
```

**判定**：如果分母只有自己，且这件事的回报周期超过 3 年，需额外确认「我是否用个人视角评估了一件公共事务」。

### 第三问：资源不足时，我的动机叙事是什么？

对应原则 5（用道义正当性换生存弹性）与陶行知的「跟武训学」实践（F-TX-024）。

```
我现在对资源缺口的说辞是：
  □ 「我们缺钱/缺人/缺资源」        → 只引来同情
  □ 「我们在做一件值得做且值得被认同的事」 → 吸引认同者
```

**事实依据**：陶行知在育才经费困难时，公开倡导「跟武训学」（行乞兴学），这一叙事直接带来了两位具体结果——名人（剪伯赞、郭沫若、贺绿汀、夏衍、田汉等）来兼职教职（F-TX-024），以及学校得以维持。

**判定**：**动机叙事不是修辞，是资源杠杆**。它决定了「愿意帮你的人从哪里来」。

## 三、三个使用场景

### 场景 A：职业转向（对应抉择 1、2）

**填表**：

```
【第一问】我现在的职业身份依赖什么载体？______
  载体消失后剩下的：______

【第二问】新方向的收益分母：
  只归我 □   /  归多人 □，人数约 ___，持续 ___

【第三问】新方向的动机叙事（一句话，不许用「机会」「前景」）：
  ______
```

**加入抉择 2 的门槛筛选提问**：

```
我是否已经明确写清「谁不适合这条路」？
  □ 写了，内容：______
  □ 没写 → 建议：先写再走（这比继续劝说来者更省力，F-TX-008）
```

### 场景 B：坚持还是放弃（对应抉择 3）

用于判断「载体被摧毁后，是否值得继续」。

```
【第一问】我的价值在「方法」里还是「机构」里？
  方法是什么：______（能写出来 = 存对了位置）
  机构是什么：______（写不出方法 = 价值全部押在载体上）
```

**陶行知的判定**（F-TX-017）：晓庄被查封后，他坚持「种子已遍撒全社会」——因为**方法已经扩散，载体只是容器之一**。

**判定标准**：
- 能写出「方法」→ 继续（原载体死了可以另建）
- 写不出「方法」→ 先别急着重启，**先把这个方法写出来**

### 场景 C：资源不足时的叙事重构（对应抉择 5）

```
【当前动机叙事】：______
  是否包含「为什么这件事值得」？□ 有 □ 没有

【重写后的叙事】（一句话，必须包含「值得」的理由）：
  ______
```

**检验**：把这句话给你认识的一个人看，如果他问「那你有什么好处」——**动机叙事就失败了，需要重写**。成功的动机叙事能承受这个问题。

## 四、两个预防性提醒

### 提醒一：陶行知六次抉择都不是「最优解」，是「他认定的最优解」

**他放弃了 400 银元月薪**（F-TX-005）——在当时他判断公共教育更值得。这个判断在当时是主观的，可能因人、因时代而不同。

**抄原则，不抄结论**（推断）：
- ✅ 可抄的是「换分母」这个**算法结构**
- ❌ 不可抄的是「放弃高薪做教育」这个**具体选择**

### 提醒二：六次抉择都发生在「有长期主义视角」的位置上

陶行知能做这些决策，因为他构建了「每天四问」这样的长期度量衡（F-TX-070）。**没有长期视角的人，会在第一次挫折时放弃**。

**这就是本 bundle 的内在逻辑**：

```
00 长期度量衡（每天四问）  →  才有资格做长期决策
01 体系与操作系统（三大命题 + 六大解放）  →  知道怎么在约束下做
02 关键抉择  →  在具体节点上做
```

**顺序不能颠倒**。没有度量衡先做长期决策，是赌博；没有操作系统先谈原则，是空谈。
