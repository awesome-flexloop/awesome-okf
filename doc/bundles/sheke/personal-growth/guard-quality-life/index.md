# 守护品质生活（Guard Quality Life）生活方式方案库

> **⚠️ 性质声明**：本 bundle 是**自有主题「守护品质生活」的原创整合方案库**，非对任何文章/书籍的搬运。它把"如何守护日常品质生活"做成可按域检索、可执行的方案知识树。所有条目为通用通识与常识的**整合表达**，**不构成医疗、法律、投资或心理诊断建议**——重大决策请咨询执业医师/律师/持牌机构并核对当期有效法规/官方指南。

> **📌 生成时点（2026-10）**：本包为 2026-10-10 生成。凡涉及官方指南（如身体活动量、睡眠时长、膳食方向）均以 WHO/中国疾控/NIH 当期通识为准；通用常识类条目为跨社会共识，可独立验证。随官方指南更新按需修订（`stale_after: 2027-04-30`）。

《守护品质生活》解决常见生活建议的两个问题——**没有框架**（一堆碎片）或**没有边界**（把经验当铁律）。本包用统一的 **五要素**（目的 / 可执行步骤 / 成本收益 / 证据级 A·B·C / 禁忌边界）把每个建议结构化，并把 11 个生活域组织成知识树。按 R→I→E→V→C 转化流程生成：**46 条事实登记**（F-001~F-046）、7 篇概念文档、2 篇信源文档，并配套一个 FastAPI 变现 MVP 网站。

### 已知边界

1. **非专业建议**：健康条目不替代医疗（症状/确诊/用药遵医嘱）、法律财务条目不替代律师/持牌意见、心理条目不构成诊断/处方。
2. **证据分层**：A 级为官方通识、B 级为通用常识、C 级为经验优选；C 级与场景化方案不得当普适硬证据。
3. **不等同 HowToLiveBetter**：同组 `how-to-live-better` 是开源书精读（循证决策框架），本包是自有主题方案库（按五要素组织的可执行建议）——前者偏"决策框架+条目库"，后者偏"分域方案库"。
4. **常识不逐条联网核验**：通用常识类主张以通用共识呈现，未给每条捏造"研究出处"；官方通识类已核验。
5. **时点局限**：膳食/法规/金额类内容以 2026-10 通识方向为准，具体数值以当期官方为准。
