# 守护品质生活的核心理念与方案框架

> 本篇是**框架层**：这套方案库"是什么、凭什么、怎么读"。它是整个概念层的总纲——先理解五要素与证据分级，再进入 [01 域总览](01-domains.md) 和各分域 SOP。所有主张回溯到本文末尾所挂的事实编号（F 编号），F 编号全集见 [../references/article-source.md](../references/article-source.md)。

## 1. 「守护品质生活」是什么

**「守护品质生活」是一套生活方式方案库**：把"如何守护日常品质生活"做成**可按域检索、可执行**的方案知识树，覆盖家居/健康/饮食/睡眠/效率/财务/关系/心理/出行/数字生活/安全 11 个域（F-001）。

它有三个关键定位（F-001、F-013）：

- **自有主题的原创整合方案库**——没有单一外部信源，而是以 WHO/中国疾控/NIH 等**官方通识**为锚、叠加面向普通人的**通用可执行生活常识**、再用本包自己的框架做方案化组织；不搬运任何第三方文章/书籍全文（F-013）。
- **"方案库"而非"建议清单"**——每条是一个可照做的方案，而不是一句看完就忘的结论词（F-002）。
- **按域可检索**——11 个域各成一个入口，想解决哪一块就进哪一块（F-001、F-012）。

## 2. 五要素表达法：每条方案都长一个样子

为了让读者能"照做"而不是"只看结论"，本包的每个可执行条目**统一用五要素表达**（F-002）：

| 要素 | 回答的问题 | 示例（家庭安全检查，见 [02-home.md](02-home.md)） |
|---|---|---|
| **目的** | 为什么做这件事 | 及早发现并排除家庭安全隐患 |
| **可执行步骤** | 具体怎么做 | 每月测一次烟雾报警器按键、检查有效期 |
| **成本收益** | 花什么、换回什么 | 时间少许、金钱几乎为零、毅力低 |
| **证据级** | 靠什么撑起可信度 | B（【通用常识】） |
| **禁忌边界** | 什么情况下不能/不该照做 | 油锅起火先盖锅盖、不开窗泼水 |

五要素的意义在于：把一条建议从"一句话结论"展开成"能做、知道代价、知道可不可信、知道何时不适用"的完整单元（F-002、F-007）。

## 3. 证据分级 A/B/C：每一档代表什么

本包给每条主张打一个证据档（F-003）：

| 档位 | 含义 | 能否当硬证据 |
|---|---|---|
| **A** | 官方健康/安全机构通识，或强共识 | 可作决定依据 |
| **B** | 广泛认同的常识性方法（族群共识、主流做法） | 方向可信，非专业意见 |
| **C** | 经验性/场景化的方案优选（作者判断） | **不得当普适硬证据**，仅作经验参考 |

要点（F-003、F-042）：

- **C 级不冒充证据**。像收纳、效率这类经验优选方案多属 C 级【经验优选/框架主张】，读者应把它当可尝试的方案而非普适规律。
- **引用时区分档位**。正文里每条都会标注 A/B/C，读者据此判断该用多大力度照做（F-007）。

## 4. 成本收益三轴：不承诺量化收益

本包对"值不值"不做硬数字化——成本收益用**时间 / 金钱 / 毅力**三轴描述，**不做跨资源换算、不承诺量化收益**（F-004）。

- 时间：花多少时间。
- 金钱：花多少钱（或几乎为零）。
- 毅力：需要坚持到什么程度。

三条纪律（F-004）：

- 三轴各自描述，**不换算**（不说"省下的 10 分钟等于多少钱"）。
- **不承诺量化收益**（不说"这样做每月省 X 元/延寿 X 年"）。
- 因此"值不值"由读者结合自身权衡，而非被一个数字替你做结论。

## 5. 边界声明：什么情况这些建议"不算数"

健康/法律/财务相关条目**一律标注【非专业建议边界】**（F-005），并在文件适当位置给出统一边界声明：

- 本包健康条目是通用通识整理，**不替代医疗诊断/治疗**；确诊、症状、用药一律遵医嘱/就医（F-039）。
- 法律/财务条目是常识方向性，**不替代律师/持牌财务意见**；金额档位与法规以当期官方为准（F-040）。
- 心理条目是自我照顾通识，**不构成诊断/处方**；持续困扰寻求专业帮助（F-041）。

这一工具存在的理由：本包是面向普通人的常识整理，**不是专业机构意见**；重大决策（医疗、法律、大额财务）应咨询执业医师/律师/持牌机构并核对当期法规（F-005）。

## 6. 时效：数字会过期

- 本包所有条目以 **2026-10 为生成时点**（F-043）；易变数字（若有）一律带「截至 2026-10」并附"核对权威来源"指引（F-006）。
- 随官方指南更新按需修订（F-043）。
- 引源用机构主域 + 描述，**不硬编 URL**，避免过期链接失效（F-045）。

## 7. 三层主张：事实 / 常识 / 观点

本包主张分三层，正文逐条标注，读者可自行辨析（F-007）：

| 层 | 含义 | 对应分级 |
|---|---|---|
| **事实** | 可核验到官方通识 | A |
| **常识** | 通用可执行的普遍主张 | B |
| **观点** | 本包的方案设计（方法论/经验优选） | C【经验优选/框架主张】 |

三层与证据分级的对应关系说明：A 层可核验、B 层是普遍常识、C 层是本包自己的方案设计。读者据此既能用、也知道每条的底气在哪（F-003、F-007）。

## 8. 如何读本包 / 如何用框架评估任意生活建议

### 怎么读本包

1. **先框架**：读本篇，理解五要素与证据分级（F-002、F-003）。
2. **再域总览**：进 [01 域总览](01-domains.md) 找到想解决的那个域（F-014~F-034）。
3. **后进分域**：读对应分域篇（[02-home.md](02-home.md)~[06-how-to-use.md](06-how-to-use.md)），挑出可直用的条目。
4. **查边界**：涉及健康/法律/财务，优先读对应边界声明（F-039~F-041）。

本包随 2027-04-30 后官方指南更新按需修订——使用前留意时效（F-043、F-006）。

### 怎么用五要素评估任一"外部生活建议"

当你在别处（文章、短视频、朋友）听到一条生活建议，可以用本包的五要素做一次快速体检。可复制的工作表见写法：

| 问 | 记录 |
|---|---|
| 目的 | 这条建议想解决什么？ |
| 可执行步骤 | 我能照着做吗？步骤具体吗？ |
| 成本收益 | 花时间/金钱/毅力各多少？它承诺了什么收益（是否值得警惕）？ |
| 证据级 | 靠得住吗？A 官方通识 / B 常识 / C 个人经验？ |
| 禁忌边界 | 什么情况下不该照做？有没有人/场景不适配？ |

对照本包的纪律（F-004、F-003）：**承诺量化收益的要警惕**，**C 级经验不当地硬证据**，**健康/法律/财务重大决策咨询专业人士**。
