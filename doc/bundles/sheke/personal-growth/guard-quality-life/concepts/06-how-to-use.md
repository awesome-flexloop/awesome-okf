# 如何使用本知识包与迁移

> 本篇是**使用与迁移层**：教你怎么从头到尾用这套知识库——怎么读、怎么在网站检索、怎么拿五要素框架评估任何外部建议，以及什么时候该"迁移"（更新/求助/参考其他资料）。

## 1. 怎么读本包：框架 → 域 → 条目

三步递进（F-002、F-001）：

1. **框架**：先读 [00-framework.md](00-framework.md)——理解五要素（F-002）与证据分级 A/B/C（F-003），这是读所有条目的"语感"。
2. **域总览**：再读 [01-domains.md](01-domains.md)——在 11 个域里找到你想解决的问题域（F-001、F-014~F-034）。
3. **分域条目**：进对应分域篇（[02-home.md](02-home.md)~[05-finance-relations-mind.md](05-finance-relations-mind.md)），看条目五要素照做。

> 提示：本包是方案库不是任务清单（F-001）——**按需进入，不必全读**。挑你想解决的域即可。

## 2. 在网站按域浏览 / 搜索

网站 `apps/guard-quality-life-site`（FastAPI，Python 3.14+）承载**同一 11 域知识树**（F-035）：

- **按域浏览**：站点与概念层使用同一 11 域名结构（home/health/diet/sleep/efficiency/finance/relation/mind/travel/digital/safety），可进对应域挑条目（F-012、F-035）。
- **验证信号**：站点埋入三信号——订阅/兴趣登记、推荐位占位、访问埋点，用于验证主题是否被需要（F-036）。
- **阅读优先视觉**：站点 UI 遵循「暖灰纸感」——暖灰底、米白卡片、深灰褐文字、柔和层级、禁纯黑深色（F-037）。
- **MVP 定位**：站点不接重型外部服务（SQLite 仅标准库），验证信号后续可替换为真实订阅/推荐/分析（F-038）。

在网站里，"按域浏览"对应"找域→看条目的五要素"；"搜索"帮你定位某个具体生活问题（F-035）。

## 3. 用五要素评估任一外部生活建议

当你在别处（文章、短视频、朋友）听到一条生活建议，可以用本包的**五要素工作表**（F-002）快速体检：

| 问 | 记录 | 判定提示 |
|---|---|---|
| **目的** | 这条建议要解决什么？ | 与我的问题对上吗？ |
| **可执行步骤** | 我能照着做吗？步骤具体吗？ | 模糊的"多喝水/多运动"不算步骤 |
| **成本收益** | 时间/金钱/毅力各多少？承诺了什么收益？ | 承诺量化收益的要警惕（F-004） |
| **证据级** | 靠得住吗？ | A 官方通识 / B 常识 / C 个人经验（F-003） |
| **禁忌边界** | 什么情况不该照做？ | 有没有不适配的人群/场景 |

本包纪律（F-004、F-003、F-042）：

- **不承诺量化收益**——凡"照做就省 X/延寿 X/保底赚 X"都要警惕（F-004）。
- **C 级经验不当地硬证据**——场景化/个人经验建议当参考，不当普适规律（F-042）。
- **健康/法律/财务重大决策咨询专业人士**——本包与外部建议都不替代执业意见（F-005、F-039~F-041）。

## 4. 边界：什么时候"本包不能替你决定"

- **健康**：本包是通用通识整理，**不替代医疗诊断/治疗**——确诊、症状、用药遵医嘱/就医（F-039）。
- **法律/财务**：本包为常识方向性，**不替代律师/持牌财务意见**——金额档位与法规以当期官方为准（F-040）。
- **心理**：本包为自我照顾通识，**不构成诊断/处方**——持续困扰求专业帮助（F-041、F-028）。
- 上述边界共同指向一条：**重大决策咨询执业医师/律师/持牌机构并核对当期法规**（F-005）。

## 5. 时效与迁移

- **时点**：本包所有条目以 **2026-10** 为生成时点（F-043）；易变数字带「截至 2026-10」并提供核对权威来源指引（F-006）。
- **P0 核验范围**：官方通识类（F-009/010/011）与车辆安全类（F-029）经重点核验；常识类不逐条联网核验但标注【通用常识】（F-044）。
- **引源方式**：无硬编 URL，用机构主域 + 描述，避免过期链接失效（F-045）。
- **随更新而迁移**：官方指南更新后按需修订（F-043）；你在别处看到**更新/更权威**的口径时，以当期官方为准并回本包核对（F-006、F-040）。
- **追求更权威口径时的迁移路径**：本包为常识整理 → 需要核验/专业时迁移到【官方通识源】（机构主域）或【专业人士】→ 参考引用源见 [../references/article-source.md](../references/article-source.md)。
