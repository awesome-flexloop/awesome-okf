# 福格行为模型：B=MAP 的完整框架与常见转述偏差

作者在文章第②节转述了福格行为模型："专门研究'行为如何发生'，结论是行为 = 动机 x 能力 x 提示" [F-022](../references/facts.md#f-022)，并由此推出一个应用判断："能力，无法快速提升；动机，也不会忽然强烈……只有提示，可以现在、立刻、马上设定" [F-023](../references/facts.md#f-023) [F-024](../references/facts.md#f-024)。本篇把模型的完整语义讲清楚，并对照作者转述的偏差——这是本 bundle 最重要的知识校准点（完整勘误见[核验记录](../references/verification.md)）。

## 模型本身：行为 = 动机 + 能力 + 提示，三要素同时汇聚

福格行为模型（Fogg Behavior Model，B=MAP）由斯坦福大学行为设计实验室创始人 B.J. Fogg 提出。核心主张是：一个行为要发生，需要**动机（Motivation）、能力（Ability）、提示（Prompt）三要素在同一时刻汇聚**——任一要素缺失，行为就不会发生。

| 要素 | 含义 | 通俗例子 |
|---|---|---|
| 动机 | 想做这件事的程度（欲望、期待、逃避痛苦等） | 想瘦、想被认可、怕生病 |
| 能力 | 做这件事的难易程度（时间、金钱、体力、脑力、日常安排是否冲突） | 去健身房（难）vs 做 2 个俯卧撑（易） |
| 提示 | 触发行为发生的信号（人物、情境、行动三类） | 闹钟响、有人提醒、刷完牙的"下一步"感 |

**关键语义是"同时"**：动机再强，行为太难就做不了；能力足够，没有提示也想不起来；提示来了，但动机为零或能力不足，也不会行动。作者用乘号"x"连接三要素是通俗写法，官方语义强调三者缺一不可的汇聚关系。

## 作者转述的偏差：把"缩小行为"这一关键杠杆丢掉了

作者接下来说"能力无法快速提升"——这句与 Fogg 方法论的原意**相悖**（见[核验记录](../references/verification.md)的勘误）：

- Fogg 的核心立场恰恰是**能力可以通过"把行为缩小"立即改变**。他的标志性方法 "Tiny Habits" 要求把新行为缩到 1 分钟以内（例如"用牙线剔一颗牙""做完作业后把书放回书包"），使能力门槛趋近于零。你不需要提升体能才能运动，你只需要把"运动"缩成"做 2 个俯卧撑"。
- 作者把"能力"理解为需要长期训练的稳定素质，因此得出"只有提示能马上改"。这个结论在**把行为难度当作不可变**的前提下才成立——但行为难度恰恰是三个要素中最容易、最快速可设计的。
- 同样，"动机不会忽然强烈"方向上有合理成分（Fogg 也承认动机波动如波浪），但 Fogg 的应对不是"等动机"，而是**不依赖动机**：把行为缩小到即使动机低落也能完成。

因此，"把提示做得足够明显就算用好福格模型" [F-024](../references/facts.md#f-024) 是作者的**简化发挥**，不是模型本身。按 Fogg 的完整做法，设计一个新行为至少有三步：

## 完整做法：缩小行为 + 锚点提示 + 即时庆祝

### 1. 缩小行为（解决能力）

把目标行为缩到**每天都能完成的最小版本**。判断标准：它是否小到"即使今天很累、很忙、没心情，也能完成"？

- 目标：每天阅读 → 缩为"翻开书读 1 页"；
- 目标：每天写作 → 缩为"打开文档写 3 行"；
- 目标：每天运动 → 缩为"做 2 个俯卧撑"。

行为一旦发生，就比"没发生"好；持续发生后再逐步扩大。**先让行为稳定发生，再追求规模**。

### 2. 锚点提示（解决提示）

不要依赖"记得要做"，而是把新行为挂在**每天必定发生的既有惯例之后**：

```
刷完牙 → 做 2 个俯卧撑
泡完咖啡 → 写下今日最重要的一件事
锁上门 → 检查手机钱包钥匙
```

锚点提示是 Fogg 分类中的"行动提示"，比外部闹钟更可靠（见[第三篇](02-prompt-and-forgetting.md)）。作者举例的"设定 8 个闹钟"属于情境提示，是提示的一种，但闹钟多了会麻木，且无法针对具体行为链。

### 3. 即时庆祝（强化回路）

完成微小行为后**立刻**给自己一个正反馈：内心说"做到了"、微笑、握拳，或任何让你感到成功的小动作。Fogg 认为庆祝让大脑把行为与积极情绪绑定，从而固化习惯。这是作者完全没提到的环节，也是 Tiny Habits 中与"缩小行为"并列的核心组件。

## 为什么"只调提示"容易失败

按作者的做法（只设明显提示），如果行为本身太难或动机太弱，提示再响也不会行动，失败后还可能产生自我怀疑："我连提示都设了还是不行"。这不是你的问题，而是**行为设计缺了两个要素**。正确顺序是：

1. 先把行为缩小到"不可能做不到"（能力）；
2. 再挂到既有惯例后（提示）；
3. 完成后庆祝（强化）。

这样设计出的系统，对动机波动的依赖最小——这才是福格模型在行为改变中的真正用法。

## 一句话带走

福格行为模型是真实且可独立验证的行为科学模型：**行为需要动机、能力、提示三要素同时汇聚**。作者的"只有提示能马上设定"是对模型的简化——能力恰恰可以通过缩小行为立即改变，庆祝也不可省略；**完整的 Tiny Habits 式做法是"缩小行为 + 锚点提示 + 即时庆祝"，不依赖任何付费工具。**
