# 确定性误区与福格行为模型：用"缩小行为+提示设计"开始行动

本 bundle 把一篇公开公众号文章中"确定性下降 → 持续进步 → 用福格模型设计行动 → 工具辅助"的论述，改写为一套可审视、可迁移、且明确标注边界的行为设计教程：为什么"等看到 100% 确定性再行动"会系统性地延迟行动；福格行为模型（B=MAP）三要素的完整含义与作者转述的偏差；提示为什么重要、又为什么"设定提示的提示"本身需要可靠性设计——以及如何在不依赖任何付费工具的前提下实践这些方法。

## 内容边界

- **单源 + 第一人称**：全部内容来自一篇个人公众号文章，作者自述为"日更 891/1000 天"的自媒体人；其身份、邻居故事与经营情况均未独立核验。
- **福格模型已独立溯源，但源文应用存在偏差**：行为 = 动机 × 能力 × 提示（B=MAP）确为 B.J. Fogg 提出的真实模型（经官方行为设计实验室资源核验）；但作者"能力无法快速提升、只有提示可以马上设定"的断言（F-023/F-024）**偏离模型原意**——Fogg 方法论的核心恰是通过缩小行为立即改变能力门槛。本 bundle 以模型原意为准并显式勘误。
