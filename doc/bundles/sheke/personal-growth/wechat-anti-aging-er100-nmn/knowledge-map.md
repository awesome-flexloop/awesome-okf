## 三、迁移层（可带走的判断力）

1. **三级跳跃识别**：看到「逆转 X%」拆成「读数 → 生理 → 寿命 → 人体疗效」四级，验证每一步是否有证据。
2. **限定词清单**：物种 / 组织 / 读数类型 / 时间窗口，缺一项即降级。
3. **带货漏斗识别**：科研背书 → 具体产品 → 私域降价的三段式，把前置科普当转化素材看。
4. **引文审查**：带引号名言先查逐字出处，查不到只作「信源转述」。
5. **边界自觉**：膳食补充剂不能替代药物；不做医学建议、不做产品推荐。

## 四、三条四元组洞察（现象 + 根因 + 影响 + 建议）

> 以下为编写者对单篇文本的归纳，属**假设性提炼**，不构成因果结论。

### 洞察一：为何「表观遗传时钟读数」被改写成「逆转衰老 75%」——读数≠寿命≠人体疗效的三级跳跃

- **现象**：源文用「6 到 8 周细胞生物年龄回退约 75%」作为标题级卖点（F-007），并在图 04 用小鼠照片强化「变年轻」的直观印象（F-064、F-065）。
- **根因（假设）**：证据的真实口径是**小鼠 + 表观遗传（DNA 甲基化）时钟读数 + 多组织 50–95%**；把「时钟读数」直接命名为「生物年龄逆转」，再把物种与组织限定词省略，就完成了**读数 → 生理 → 疗效**的三级跳跃（勘-02、勘误③）。
- **影响**：读者会把一项**实验室读数**误读为「人体已被证实能逆转衰老」，进而对尚未验证的干预（乃至保健品）产生过高期待；一旦后续证据不支撑，信任反噬。
- **建议**：对任何「逆转 X%」类声明，先做**四级拆解**（时钟读数 / 生理指标 / 寿命 / 人体疗效），并补齐**物种·组织·读数·时间窗**四限定；缺项即视为营销口径。

### 洞察二：为何带货文的科研引用会「真中掺假」——文献真实存在但结论被拔高、编号错位

- **现象**：源文列出 8 篇**真实存在**的文献（F-036~F-043），但 [4][6] 的**第二、三作者有误**（勘-08、勘-09），图 04 的**引用编号 [4][8] 错位**（F-061、勘-05），且把 2013 年研究拔高为「逆转所有分子层面衰老表现」「首次证实补充 NMN 提升 NAD+」（勘-06）。
- **根因（假设）**：**引用真实文献**能快速建立可信度、且难以被普通读者核查；而**结论拔高与编号错位**藏在细节里，成本极低、收益（说服力）极高。这是一种「**真中掺假**」——底座为真、结论为假。
- **影响**：读者看到「有文献」就默认「结论被文献支持」，忽略「文献存在 ≠ 结论被支持」，从而把营销话术当成科研共识。
- **建议**：**文献核验只做「存在性 + 元数据」不够**，还要**逐条核对「文献结论是否支持该声明」**；对带编号的图注（尤其编号与题录对不上）保持高度怀疑。

### 洞察三：保健品内容的三段式可信度衰减——独立研究 → 厂商自述 → 私域转化

- **现象**：源文前半是**独立研究**（ER-100、NAD+、专家共识、文献），中后段滑向**厂商自述**（供应哈佛、全球首个全酶法、99.99% 纯度），结尾是**私域降价**（999 → 649 元/瓶）（F-048~F-058）。
- **根因（假设）**：三段中**可信度逐级衰减、转化意图逐级增强**：独立研究层最硬但最不「可卖」，厂商自述层可卖但难核验，私域转化层直接变现。文章用「科研背书」为「具体产品」与「私域降价」做信用背书。
- **影响**：读者若不分层，会把整篇当作「中立科普 + 顺手推荐」，把**厂商自述数据**（供应哈佛、99.99%）误当作**已核验事实**接收。
- **建议**：**按来源距离给每段打折**——独立研究层照单接收并查询原始文献；厂商自述层逐条要求独立出处（本束 F-049/F-053 均判「无独立出处」）；私域转化层只作事实披露、**不接受任何推荐**（本束不提供购买入口）。
