# 厂商自宣声明分层与保健品内容阅读纪律（商业与迁移层）

源文前半讲科研，后半转入**自家产品**——品牌为「美因」（膳食补充剂品牌方公众号），产品线为**基因港（GeneHarbor）的 NMN 产品**。本篇是本 bundle 的**迁移层核心**：把厂商话术逐条降级，并给出一套可复用的**保健品内容阅读纪律**。

> **本束立场**：**不推荐任何产品、不提供购买入口、不复制带货话术**；只对源文中的可观察声明做分层核验与转述。

## 一、人物履历：逐项降级

| 源文声明 | 核验结果 | 处理 |
|---|---|---|
| 「王骏博士是 1975 年诺贝尔生理学或医学奖得主霍华德·特明的**学生**」（F-045） | Temin 的 1975 诺奖身份 ✅；但现有来源仅显示王骏在威斯康星与 Temin **相识/共事**，「**学生**」身份**未获独立证实**，且出处为推广稿 | 降级为「曾与 Temin 相识/共事」，不写「学生」（勘误④） |
| 「王骏是**前香港中文大学医学院教授**」（F-046） | 1992 年加入港中大、1999 年升任**生物化学系教授**，现为**兼职/客座教授** | 修正为「曾任香港中文大学生物化学系教授、现为兼职」（勘误④） |
| 「王骏**深耕生物合成 30 余年**」（F-047） | 多个来源口径为「**四十余年**」 | 按保守表述「数十年」，并注源文口径（勘-10） |

以下声明在核验中均属**厂商自述**（部分**无独立出处**），本束逐条标注，不将其升级为研究结论：

| 声明 | 源文口径 | 分层结论 |
|---|---|---|
| 全酶法工业化量产（F-048） | 「**全球首个**全酶法 NMN 工业化量产」 | 基因港 2017 年实现量产属实；但**「全球首个」与邦泰（BONTAC）等竞品「首家全酶催化量产」声明冲突**，降级为「**率先实现之一**」（勘-11） |
| 供应哈佛实验室（F-049） | 「**连续多年**为哈佛 Sinclair 实验室供应 NMN 原料」 | **厂商自述｜无独立出处**：仅见品牌推广稿，无 Sinclair 实验室或哈佛方独立确认 |
| 国际期刊人体临床（F-053） | 「**多项**发表于国际期刊的人体临床」 | **厂商自述｜无独立出处**：国际 NMN 人体试验存在，但**无证据显示其为基因港产品**，主体归属未证实 |

| 纯 β 型 / 无内毒素 / 无化学残留（F-051） | 「纯 β 型天然构型、无内毒素、与人体内源 NMN 完全一致」 | 厂商自述（P1） |
| 植物素食胶囊 / 一物一码（F-052） | 「植物素食胶囊、无填充剂、无防腐剂、每瓶一物一码可溯源」 | 厂商自述（P1） |
| 营销话术（F-054） | 「品牌讲再多，都不如『实验室真的在用』有说服力」 | 厂商自述（话术本身即**诉诸权威**的转化术） |

## 三、源文给读者的「三个选购标准」

源文（F-057）给出「**三个选购标准**」：**一看纯度**（有效成分含量是否清晰标注）、**二看原料**（生产工艺和第三方检测是否可查）、**三看科研背书**（有没有真实的实验室合作）。

- 这三条作为**一般判断方向**可用；但需注意：①它们由**同一带货主体**提出，标准与产品是绑定关系；②「科研背书」最容易造假/夸大——本束第二节中「供应哈佛」无独立出处、「全球首个」与竞品冲突，正是反例。
- 属**选购判断**，非可复现的操作流程（这也是本 bundle 不设 `examples/` 的原因之一，见 [知识地图](../knowledge-map.md)）。

## 四、迁移层核心：带货漏斗识别与阅读纪律

### 4.1 三段式转化漏斗

源文的结构是一个可识别的**三段式漏斗**：

1. **科研背书段**：先讲真实的科研进展（ER-100、NAD+、专家共识、8 篇文献）建立权威感；
2. **具体产品段**：把「NAD+ 通路」落到**某品牌某产品**，用「纯度/原料/科研背书」三标准衔接；
3. **私域降价段**：文末以**私域通道**给出低于公域的价（F-055）并引导进入转化路径（F-058）。

识别方法：**当一篇科普文在中后段出现「这个原理 → 具体品牌 → 限时低价」的链条时，前面的科研内容就应被视为转化前置素材**，而不能当作中立科普。

### 4.2 价格声明（源文自述，无官方口径）

- 源文（F-055）称**公域统一价 999 元/瓶**，**本文私域通道价为 649 元/瓶**。
- **核验结论**：**未检索到官方 999 元口径**；第三方渠道同类 NMN12000 产品标价约 1500 元。因此 999→649 属**源文自述价格**，属时点信息，**无官方口径可核**（single-source）。
- 本束只作**客观陈述**：文末私域渠道价低于其自述公域价；**本束不提供任何购买入口或参与方式**。

### 4.3 「比共识、比文献」话术的可信度边界

源文主张「比起听谁推荐，能写进共识、登上期刊的证据更值得参考」（F-034）。方向正确，但存在**两个陷阱**：

- **陷阱一：共识/文献存在，但被改写。** 例：2013 年研究被改成「首次证实补充 NMN 提升 NAD+」（勘-06）、图 04「逆转所有分子层面衰老表现」属拔高（勘-06）。
- **陷阱二：文献真实存在 ≠ 结论被支持。** 8 篇文献**确实存在**（见 [NAD+ 与 NMN 通路](02-nad-nmn-pathway.md)），但 [4][6] 的作者序列有误（勘-08、勘-09），图 04 的引用编号还错位（F-061、勘-05）——**「真中掺假」**正是带货文的常见手法。

### 4.4 可复用的保健品内容阅读纪律

1. **分层读**：把内容拆成「已核验事实 / 厂商自述 / 未知」三层，凡**成效数字**默认找独立出处。
2. **查限定词**：见到「逆转 X%」「寿命翻倍」先问**物种、组织、读数类型**（本束 F-007/F-008 即教科书级反例）。
3. **看转化结构**：识别「科研背书 → 具体产品 → 私域降价」漏斗，把前置科普当作转化素材看。
4. **审引文**：带引号的名人名言先查逐字出处（F-018、F-019 均无独立逐字出处，只作「信源转述」）。
5. **守边界**：膳食补充剂**不能替代药物**（F-056）；有健康问题请咨询执业医师。

## 五、本篇要点速览

- 王骏履历逐项降级：「Temin 学生」未证实、港中大身份为「曾任生化系教授/现兼职」、「30 余年」应为「四十余年」（F-045~F-047、勘-10）。

- 带货漏斗 = 科研背书 → 具体产品 → 私域降价；999→649 属**源文自述价格**（F-055）。
- 本束**不推荐任何产品、不提供购买入口、不复制带货话术**；本品为膳食补充剂，不能替代药物（F-056）。
