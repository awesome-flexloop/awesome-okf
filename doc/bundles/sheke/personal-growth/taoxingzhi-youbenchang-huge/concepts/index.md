# 概念文档（三人关联洞察）

> **本目录是整个主题簇的枢纽**。它不重复三个主体包的内容，而是回答三个问题：**他们之间是什么关系（00/01/02）、我该怎么用这三份材料（03/04/05）、具体怎么开始（06）**。

## 三条使用约束

| 约束 | 内容 |
|---|---|
| **不吹捧** | 不做三人比较、不做排名、不判断「谁更值得学」 |
| **不伪造因果** | 陶行知与后二者无影响关系证据；游本昌与胡歌的公益是**同向而非因果** |
| **不做私人评判** | 不涉及三人的感情、家庭、争议 |

## 与三个主体包的关系

本包**不重复**主体包内容，只做三件事：

1. **横向对照**（00/01/02）：把三人的机制放在一起，找共通与差异；
2. **框架化**（03/04/05）：从三人材料中抽出三个可复用的框架；
3. **行动化**（06）：把前面五个转成有序的执行路径。
