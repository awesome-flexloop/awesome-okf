## 车祸细节层的降级说明

**F-HG-020~F-HG-027、F-HG-036、F-HG-039** 的核心事实（时间、地点、伤亡、缝合针数、植皮、后遗症、心理反应）**主要来自 C 级深度报道**。

**本包的处理**：
1. 统一标注 C 级，正文引用时明示；
2. **关键事实做多源交叉**：车祸时间地点（A 级中青在线 + C 级多家）、希望小学（A 级中国慈善家 + C 级）、近二十年赡养（A 级中青在线 + C 级南方娱乐网）；
3. **对「100 多针 / 120 多针」「近 10 次 / 几十次植皮」等分歧并列登记**，正文取多数说法并在信源表标明。

## 三条伦理约束（本包自我约束）

1. **创伤不是教材**：车祸相关事实仅在「与重建机制直接相关」时登记，不做励志化渲染；
2. **他人不是论据**：张冕、张冕父母、司机小凯、薛佳凝等仅在与胡歌方法论直接相关时登记，**不做因果归因、不做价值判断**；
3. **私人生活不评判**：感情、家庭、社交争议一概不做推测性记录（`facts.md` 中已不登记感情相关内容）。

## 一条需要特殊标注的事实

**F-HG-033**（「如果外表无法复原，那就用思想去填满它吧」）：

- 该表述在中文互联网上广为流传，但**未取得 A 级信源直接确认**（C 级转述）。
- 本包在 `../concepts/05-boundaries.md` 中已将其**降级为「特定处境下的自我对话」**，明确不作为可普遍使用的方法引用。
- **理由**：该句省略了具体处境（医院里对镜中的疤说），易被误读为「只要想开点就能变强」。
