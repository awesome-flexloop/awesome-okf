# 概念文档（胡歌 · 功夫与重建）

> **本包的方法论立场**：胡歌案例的核心不是「他多努力」，也不是「他多惨」——**而是他把一次不可逆的损失，转换成了长达十年的定向投入**。本目录拆解这个转换的结构。

本目录 6 篇按「**事件 → 机制 → 转化 → 影响 → 关系 → 边界**」递进。
