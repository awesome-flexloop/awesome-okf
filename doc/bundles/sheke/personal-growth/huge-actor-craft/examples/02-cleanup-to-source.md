# 02 · cleanup → source 升级表

> **依据**：他在长江源公益宣传片中的表述（A 级 F-HG-075）：
>
> 「**垃圾是捡不完的，要彻底解决垃圾的问题，还是要从源头抓起。**」
>
> 他同时倡导商家生产包装材料时尽量选择可再生可降解材料、消费者尽量选购可再生可降解包装的商品（**注意：这一条直接指向生产与消费结构，不是清理**）。
>
> **本表的目标**：**检查你正在做的事处于哪一层，并判断是否需要升级。**

## 一、行动层级四分类

| 层级 | 定义 | 特征 | 效果特征 | 风险 |
|---|---|---|---|---|
| **L1 Symptom（处理症状）** | 收拾已经产生的问题 | 打扫、清理、救济、道歉 | **有成效但会复发** | 疲劳 |
| **L2 Practice（改变做法）** | 改变产生问题的行为 | 优化流程、换工具、换习惯 | 有成效且部分持续 | 中 |
| **L3 Structure（改变结构）** | 改变产生行为的条件 | 改规则、改激励、改环境 | **一次改变长期生效** | 低 |
| **L4 System（改变系统）** | 改变结构之间的连接 | 改产业链、改政策、改生态 | 生效最慢但最难被逆转 | 最低 |

> **关键特征：L1 会复发**（推断）。
>
> **判据很简单**：如果你做这件事的时间越长、它回来得越频繁，那它就是 L1。
>
> **例**：捡垃圾（L1）→ 不用一次性塑料（L2）→ 改产品包装设计（L3）→ 改产业链/政策（L4）。

## 二、常见行动的层级定位

请把你正在做的 3–5 件事填进来，并判断层级（推断层分类）：

| 我做的事 | 层级 | 它回来吗？（是/否） | 如果不回来是因为什么？ |
|---|---|---|---|
| | L__ | | |
| | L__ | | |
| | L__ | | |

**判读**：

- **有「是」且层级在 L1** → **这是升级的首选目标**（见第三节升级四问）
- **全部是「否」** → 你可能在 L3/L4，**注意是否已过度投入于结构改造而忽略了基本执行**（见第五节）
- **有「否」但你也说不清为什么** → 可能是**运气**而非结构（诚实地标出来）

> **第三行「说不清为什么」是本表最诚实的一栏**（推断）：
>
> **如果一件事没有回来，但你也说不出机制原因，那它很可能只是「这段时间恰好没有发生」。**
>
> **这与本包在陶行知 bundle 中提出的「季节性 vs 结构性」判断同族**——但更重要的是：**诚实地标注「运气」会防止你在下一个人为它邀功时把功劳归给方法。**

## 三、升级四问

当你发现自己在 L1 反复做同一件事时，用这四问判断能否升级：

```
第一问：这个问题的源头是谁/什么在决定？
  → 答不上来 = 你还在症状层

第二问：如果源头不变，我这件事做一万次的结果是什么？
  → 「还会回来」= L1 天花板

第三问：我能动源头吗？
  □ 能（我有权限/影响力/技术）
  □ 不能完全，但能影响一部分
  □ 完全不能

第四问：如果不能升级到源头，我能不能「减少需要的产生」？
  → 这是 L2 的一个有效中间态
```

**填写**：

```
我反复在做的事（L1）：______

第一问 源头是：______
第二问 做一万次的结果：______
第三问 我能动源头吗：□ 能 □ 只能影响一部分 □ 不能
第四问 我能减少需要产生吗：______

结论：
  □ 可以直接升级到 L__（请写出具体动作）
  □ 只能升到 L2（请写出具体动作）
  □ 只能留在 L1 → **接受它，并限制投入**（见第五节）
```

## 四、一个今天就能做的检查

> **本节是全表最实用的部分**（推断）。

**标题：找出你正在做的一件事，问它属于哪一层。**

**步骤（5 分钟）**：

1. 写下你上个月做的一件「善举/改进/加班/修复类」的事
2. 问：**「这件事如果我不做，会怎样？」**
3. 问：**「如果我做了 10 倍，会怎样？」**
4. 问：**「这件事半年后还会需要吗？」**

**四种答案的解读**：

| 答案组合 | 层级 | 建议 |
|---|---|---|
| 不做会出问题 + 做 10 倍也出问题 + 半年后还需要 | **L1** | 考虑升级；或**限制投入**并接受它 |
| 不做会出问题 + 做 10 倍有效 + 半年后不需要 | **L2** | **这是最好的位置，继续做** |
| 不做会慢慢出问题 + 做 10 倍有效 + 半年后不需要 | **L2** | 好，但要防止「慢慢出问题」变成「突然出问题」 |
| 不做也没事 + 做 10 倍也没用 + 半年后不需要 | **无效** | **诚实承认，这是在消耗自己** |

> **最后一行需要说几句**（推断）：
>
> **「无效」不是道德问题，是资源配置问题。** 很多人不愿意承认自己在做的事无效，因为承认了就要停止，而停止会引发「我是不是在偷懒」的自我怀疑。
>
> **但本包的判断是：诚实地停止一件无效的事，是对自己资源的最负责的处理。**
>
> **对照**：「一个人的力量非常有限，我们可能对环境的改变没有那么多，最重要的是对自身的改变」（A 级 F-HG-077）——**注意这句话的结构：先说「对环境的改变没有那么多」，再说「最重要的是对自身的改变」。** 他没有说「环境不重要」，他说的是**不要把有限的自己投在无效的地方**。

## 五、「接受 L1 并限制投入」——第四种结论

**这是本表最容易被忽略、但最可能用到的一栏。**

不是所有 L1 行动都值得升级。有些 L1 行动是**世界本来就需要有人做的**（倒垃圾、清雪、照顾具体的某个人）。

> **对这类行动，正确的做法不是「升级」，是「限制投入」**（推断）：
>
> ```
> 错误做法：要么全力做（会耗尽）→ 要么完全放弃（世界少了一个做的人）
> 正确做法：设一个投入上限，把它变成「可持续的小事」
> ```

**填写**：

```
我决定「接受为 L1 并限制投入」的事：______

我设的上限：□ 时间（每周 ___ 小时）□ 金钱（每月 ___ 元）□ 精力（每周 ___ 次）
我为什么要设上限（诚实回答）：______
```

> **诚实回答这一栏的三个可能答案**（推断）：
> - 「因为我做不了更多」——合理
> - 「因为这让我感觉自己在做好事」——**诚实，但需要注意这个动机的真实性**（对照游本昌的「我不是公益人士」——A 级 F-YB-097，他拒绝把这件事定义为善行）
> - 「因为我不敢停下来面对别的事」——**这个答案最值得警惕**

> **第三个答案为什么最值得警惕**（推断）：**如果一件事的全部功能是让你不必面对另一件事，那它不是 L1 行动，是回避策略。**
>
> **这与本包在胡歌 concepts/05 中提出的「幸存者偏差」是同一族问题**——**用一件持续的小事，替代对核心问题的处理。**
