# 证据分级与统计数字素养

> 证据等级回答的问题只有一个：**"这个数字可不可信？"** 它和"这件事值不值得做"（性价比档）是两条互相独立的轴——一条建议可以证据是 A 级但性价比一般（贵的带状疱疹疫苗），也可以证据只有 C 级但性价比极高（出境前把行程发给家人）（F-034）。

## 1. A / B / C 三级：界线在"有没有具体数字 + 数字从哪来"

| 等级 | 判定（F-028） | 现行数量 | 典型条目 |
|---|---|---|---|
| **A** | 有**具体数字可查**，且出处是荟萃分析、跟踪很多人很多年的大型队列、或随机分组试验（RCT），能说出降了多少（HR/RR/下降百分比） | 415 | 低钠盐、CPR、降压、溶栓、安全带、加班费三档 |
| **B** | 有研究支持，但说不出一个确切数字；或只有小样本、单一研究撑着 | 151 | 烟雾报警器、车速与死亡、BE-FAST 卒中筛查、青光眼急诊 |
| **C** | 作者自己的经验，或大家公认的做法，**没有直接研究文献** | 49 | 出境发行程给家人（作者明确承认性价比档本身按本书标准也只算 C 级，F-034） |

B 和 C 不是"错"，而是**证据硬度不够**：烟雾报警器只有一项病例对照研究（所以 B），但它"三十元换六成死亡风险下降"的方向性结论仍然值得照做；反过来，A 级也不等于对你个人适用——低钠盐的 A 级证据来自高危老人，肾功能不全者换盐反而危险（F-062）。

## 2. 两套防自欺机制：争议 与 TODO

- **"争议"标记（现行 57 条，F-029）**：A/B 级条目若存在反方证据，标"争议"并把反方研究一并列出。低钠盐条目同时附生态学反方研究与禁忌人群；运动延寿条目注明观察性数据"不能完全排除反向因果"（生病的人本来就运动少）。
- **"TODO 待核实"（现行 35 处，F-030）**：拿不到可逐字核对的官方原文时，把缺口本身写出来。例如"闻到燃气味后的标准处置步骤""全国电动自行车火灾年度数字""公安部公布的骗局类型占比"，宁可标 TODO 也不编一个像样的数字。

这两套机制比"结论正确"更重要：它让读者知道**这条知识的边界在哪里**。

## 3. 来源纪律：只引一手

全部 615 条的来源只有两类：**期刊论文**（附 DOI 或 PubMed 链接）与**官方机构文件/法规原文**（WHO、CDC、国家统计局、全国人大法律、国务院条例），不引二手转述（F-031）。

2026-09-28 的独立 P0 核验从外部为这套纪律做了一次抽检：被抽中的 10 项医学研究/报告**全部真实存在、DOI 全部可解析**，RR/OR、置信区间、样本量几乎逐字吻合（核验总表见 [../references/verification.md](../references/verification.md)，F-070）。抽检同时发现两处应采用核验口径的地方：

- **卒中溶栓时间窗**：原书写"16 项静脉溶栓随机试验、6,756 名患者"，论文（Emberson 2014，Lancet）实际纳入 **9 项 RCT**；三个 OR（≤3h 1.75、3–4.5h 1.26、>4.5h 1.15）与人数均正确（F-072）。
- **中国院外心脏骤停数据**：79.2% 发生在家中（30,282/38,227）正确；但"旁观者按压率 20.3%、存活出院 1.2%"在论文摘要里是**全队列**分母（35,090 与 38,227），原书把它写在"家中这批人里"名下，分层归属未能从原文证实（F-073）。

本知识包的 [04 标杆精读](04-high-value-entries.md) 一律采用核验后的口径。

## 4. 统计数字素养：九组最常出现的术语

条目默认读者没学过统计，但要求读者能识别"这是什么种类的证据"。以下九组按使用频率排序（全书 41 条术语表见原仓 README，F-039）：

| 术语 | 它在说什么 | 读到它时怎么想 |
|---|---|---|
| **RCT（随机对照试验）** | 用抽签方式把人分两组，一组干预、一组对照，再比结果 | 证据金字塔顶端；组间差别最有资格归因于干预本身（低钠盐 SSaSS 就是中国农村 600 村、20,995 人的整群 RCT，F-071） |
| **荟萃分析（meta）** | 把很多项研究的数据合并重算出一个总数字 | 样本量最大、结论最稳，但仍取决于纳入研究的质量（头盔结论合并了 61 项研究中的高质量子集，F-044） |
| **队列研究** | 挑一大群人跟踪很多年，记录谁出了事 | 能看长期、看罕见结局；但只是"一起出现"，不能证明因果 |
| **观察性研究** | 研究者只记录、不安排谁做什么 | 结果"打点折看"——容易被下面两个偏差带偏 |
| **混杂** | 第三个因素同时牵动前因后果（爱吃菜的人往往也更爱运动） | 看到"A 导致 B"先问：有没有一个 C 同时影响两者？ |
| **反向因果** | 因果方向反了（不是睡得多让人早死，而是病重的人睡得多） | 运动、睡眠、饮酒类条目最常见，原书会在备注里显式提示 |
| **RR / HR / OR** | 两组风险之比。0.87≈低 13%，1.21≈高 21%；RR 是相对风险、HR 带时间快慢、OR 在罕见事件时≈RR | 一律看"降/涨百分之几"，不用纠结三者算法差别 |
| **95% CI（置信区间）** | 真实值很可能落在的范围 | **倍数类数字区间跨过 1、加减类跨过 0，就说明差别可能只是碰巧**——原文会写"无统计学意义"（F-041）。例：>4.5 小时溶栓 OR 1.15（0.95–1.40）即无效 |
| **风险差 vs 相对风险** | RR 0.5 说"风险减半"，风险差说"每一千人里少几个" | 决策时两个都看：罕见病"降 50%"可能只是每千人少 1 人 |

一个直接的练习：第 1 章安全带条目里，45%/60% 来自 NHTSA 用事故数据库算出的**估计值**（不是 RCT），WHO 的中国道路死亡 248,099 是**模型推算**（同年中国官方登记为 62,218，口径差近四倍）——条目备注把这两件事都写明了（F-043、F-074）。**数字本身准确 ≠ 数字代表的口径可以混用**，这是读这本书最该带走的统计直觉。

## 5. 读者操作：三步质疑法

读到任何让你心动或心惊的数字，按顺序问：

1. **哪一级？** A/B/C 在条目标签行直接给；C 级当经验听，B 级看方向，A 级再认真对待数字。
2. **什么研究？** RCT > 荟萃 > 队列 > 病例对照 > 经验；观察性研究主动找备注里的混杂/反向因果提示。
3. **边界是什么？** 看"备注"：争议（反方说了什么）、禁忌（谁不适用）、TODO（作者自己也没核到什么）。
