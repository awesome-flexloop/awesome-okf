# 适用边界与方法迁移

> 最后一篇做两件事：先划清**这本书不能替代什么**，再把它的决策框架抽出来，变成你评估任何生活建议时都能复用的工作表。

## 1. 六条适用边界

### ① 地域与法域边界：中国大陆现行口径

法律条目（第 5、7–9、11–12、14–15、18–19、21、24–27、31–33 章大量条款）依据的是**中华人民共和国大陆地区**法律、行政法规与部门规章，核验时点为 **2026-09 有效版本**（F-076~F-081）。港澳台与境外不适用；留学/旅行章涉及境外规则时也以"使领馆与当地官方"为最终依据。条款会修、罚则会调、机构会改——照做之前查一次现行有效文本（全国人大法规库、中国政府网、各部委官网）。

### ② 时间边界：金额、补贴、处罚档次都是时点值

"成本栏"按章首导语自陈只是市面价格粗估、"不要拿去引用"（F-040）；育儿补贴、医保报销比例、罚款区间、保险费率、证书政策都强时效。**本知识包与原书条目里的具体金额，读法是"量级参考"而非报价**。作品本身在高速演进（2026-09-07 上线；2026-09-17 二手博文快照为 498 条；2026-09-28 原仓已为 615 条、33 章），任何打印件/转发件/二手文章都可能滞后（F-013、F-020）。

### ③ 角色边界：不构成医疗、法律或投资建议

原书是**信息汇编与决策框架**，不是诊疗意见、法律意见或投资顾问服务。条目反复示范了正确的转介动作：急症打 120、换盐前问医生、被指控先请律师、保险与理财按自己的合同与风险承受力决策。本知识包同样如此——涉及个体诊断、具体案件与大额资金时，请咨询执业医师、律师或持牌机构。

### ④ 证据外推边界：样本人群 ≠ 你

即使 A 级证据也有适用人群：低钠盐 RCT 的对象是中国农村**卒中史或老年高血压高危人群**，健康年轻人与肾功能异常者处境不同（F-062）；头盔 OR 值来自摩托车手而非电动自行车（F-044）；择偶预测实验样本是欧美大学生（F-068）。读 A 级数字时连同"这条证据在谁身上测出来的"一起读，是条目的备注栏存在的理由。

### ⑤ 证据类型边界：观察性结论要防混杂与反向因果

队列/病例对照只证明"一起出现"，不证明"前者造成后者"。本书的处理方式是显式提示（运动延寿注明不能排除反向因果、45%/60% 注明是数据库估计、WHO 中国道路死亡数注明模型推算口径，F-041、F-074）。你在外部读到"研究发现 X 的人更 Y"的标题时，默认执行同样的打折。

### ⑥ 版本与署名边界

原书以 **Unlicense** 发布（公共领域等效，可自由复制改编，但引用时保留出处是基本学术规范）；第三方介绍博文 mushroom.cv 为 **CC BY 4.0**（转载须署名作者 Mycelium Protocol 并附原文链接，F-006）。本知识包是**二次导读与核验转化**，不是原书：只精读 21 条标杆条目（[第 04 篇](04-high-value-entries.md)），全书 615 条以原仓为准；原书自带的 57 条争议标注与 35 处 TODO（截至 2026-09 现行版，F-018）比本包更细、更新更快。

## 2. 本书可被攻击的地方（对抗视角自查）

按"魔鬼代言人"视角，这套方法有几个已知软肋，读者应自行补足：

1. **性价比档是作者判断**——作者自己承认为 C 级（F-034）。阈值（如"降 20% 算大"）合理但人为；三成本等权、毅力不可与钱互换等假设没有外部验证。
2. **条目的选择与排序有人的口味**——"哪些话题值得收、什么算同口径内更值"无法完全机械化；C 级 49 条尤其依赖作者经验。
3. **法律条文的"字面正确"不等于"实务结果"**——执法尺度、地区差异、证据留存、维权时间成本无法全部量化；条目给的是起点不是胜诉保证。
4. **核验只覆盖抽样**——本包 2026-09-28 独立核验了 19 项 P0（10 项医学研究全部坐实，但发现 5 处应采用核验口径的条款号/分层/出处差异，详见 [核验报告](../references/verification.md)）；615 条全量引文的持续核对依赖原书自身的 `引用对照.md` 与 `核实记录/`（F-012）。

## 3. 方法迁移：评估任意一条生活建议的七步工作表

本书真正可迁移的资产不是这 615 条答案，而是生产答案的算法（综合 [01](01-evidence-grading.md) 与 [02](02-cost-benefit-model.md)）。下次在任何地方（短视频、长辈群、课程广告、新闻）看到一条"你应该做 X"的建议，按下表逐格填写，填不出来的格子就是这条建议的风险敞口：

| 步骤 | 自问 | 填什么 | 不及格信号 |
|---|---|---|---|
| 1. 定口径 | 它声称换回什么？ | 寿命 / 时间精力 / 金钱 / 自由（只能选一个主口径） | 一条建议同时承诺"又健康又发财" |
| 2. 找证据 | 数字从哪来？ | RCT / 荟萃 / 队列 / 官方文件 / 经验 | 只有"专家说""研究表明"，无出处无样本 |
| 3. 评等级 | 按 A/B/C 粗判 | 有具体数字+硬研究=A；方向有研究=B；纯经验=C | 把动物实验、体外实验、个例说成 A 级 |
| 4. 拆成本 | 我付哪三种代价？ | 钱（量级）/时间（每次多久）/毅力（是否对抗习惯） | 只谈收益不谈代价 |
| 5. 量收益 | 在口径内是大是小？ | 套第 02 篇的阈值表 | 把中间指标（血脂降了）说成最终收益（多活几年） |
| 6. 查边界 | 谁不适用？有没有反方？ | 禁忌人群、争议证据、适用地域与时效 | 绝对化表述（"所有人都该……"） |
| 7. 定受益人 | 好处落在谁头上？ | 自己/家人/朋友同事/陌生人（第④档连风险一起看） | 劝你"为你好"但收益归说话人的 |

**合成判断**：通过 1–6 格且三成本接近零 = 这本书定义的"极高性价比"，优先做；填到第 4 格发现要花大钱/长期毅力 = "一般"档——不是不做，而是承认这是你的个人权衡，别让广告替你拍板。

### 示范：用工作表盘问一条网红建议（框架演示，不评价具体产品）

> 声称："每天用某某方法三分钟，一个月根治某慢性病。"

- 步骤 1 口径：寿命/健康；步骤 2 证据：多为前后对比个例（≈C）；步骤 3：无 RCT、无样本量，达不到 A/B；步骤 4 成本：产品往往钱=多、时间=少、毅力=是；步骤 5："根治"是最终结局承诺但只有中间指标或自述；步骤 6：慢性病管理的强证据通常是规范用药+生活方式（参照本书第 16 章与 F-049 降压逻辑），"根治"叙事与证据等级不匹配；步骤 7：受益人排序里销售方靠前。→ 合档失败，不进入"高性价比"；同理，任何建议都可这样被盘问一遍。

## 4. 结语：这本书在"优化"什么

它优化的不是人生，而是**人生决策时的检索成本与证据纪律**：把"我好像听人说过"替换成"这条有 DOI、有代价、有反方、有时点"；把跨口径的冲动换算（"健康值多少钱"）替换成"各算各的账，再由我自己权衡"。

615 条会过时、会增删（498 只是 2026-09-17 二手博文的快照时点，9-28 已为 615），但"**只认带出处的数字、只做同口径的比较、先看零成本高收益、永远把禁忌和反方读完**"这套动作不会过期。这也是本知识包希望读者最终带走的东西。
