# 概念文档（Concepts）

本知识包的核心教程，按"**事实 → 机制 → 导航 → 应用 → 使用 → 迁移**"六段递进：先认识项目本身，再吃透它的两套评价系统，然后拿到全书地图、看一批标杆条目怎么读，最后学会使用工具并把方法迁移到自己的决策中。

## 学习路径

| 序号 | 文档 | 核心问题 |
|---|---|---|
| 00 | [项目全貌与版本演进](00-project-landscape.md) | 这是本什么书？谁做的、什么许可、怎么长出来的？ |
| 01 | [证据分级与统计数字素养](01-evidence-grading.md) | "这个数字可不可信？"——A/B/C、争议与 TODO、如何读 HR/RR/CI |
| 02 | [四资源与性价比决策模型](02-cost-benefit-model.md) | "这件事值不值得做？"——成本、收益量级、性价比档、受益人排序 |
| 03 | [33 章导览与长文地图](03-chapter-map.md) | 全书都覆盖什么？每章解决什么问题、算什么口径？ |
| 04 | [标杆条目精读 21 条](04-high-value-entries.md) | 好条目长什么样？跨四大板块逐条拆解 |
| 05 | [如何使用：检索页、离线版与 AI skill](05-how-to-use.md) | 怎么查、怎么筛、怎么离线读、怎么让 AI 按这本书回答 |
| 06 | [适用边界与方法迁移](06-boundaries-and-method.md) | 数字什么时候会过期？怎么用这本书的框架评估任何建议？ |

```
00 事实层（项目、版本、生态）
   ↓
01 机制层 · 证据轴（数字可不可信）
   ↓
02 机制层 · 决策轴（值不值得做）
   ↓
03 导航层（33 章地图）
   ↓
04 应用层（21 条标杆精读）
   ↓
05 使用层（检索页/离线/AI skill）
   ↓
06 迁移层（边界意识 + 评估任意建议）
```
