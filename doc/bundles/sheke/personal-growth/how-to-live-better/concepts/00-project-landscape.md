# 项目全貌与版本演进

> 本篇是**事实层**：项目是什么、如何组织、怎样演进。所有计数均标注时点——这部作品在上线后的前三周处于高频更新期，同一数字在不同日期的信源里不一样是正常现象。事实编号见 [../references/article-source.md](../references/article-source.md)。

## 1. 一句话定位

**HowToLiveBetter（《高性价比人生指南》）是一部按"性价比"排序的循证中文生活决策手册**：每一条建议都写明四件事——花掉什么、换回什么、证据有多硬、来源在哪；只引期刊论文（附 DOI/PubMed）与官方文件，不引二手转述（F-001、F-031）。

它覆盖的话题从安全带、低钠盐、CPR，到加班费怎么算、被裁拿 N 还是 2N、爬虫会不会判刑、彩礼婚前房产归谁、怀孕生产做什么、出国留学身份怎么保、残疾后能领哪些补贴——按仓库自述，"长寿防病、急救、省钱理财、法律红线、失业与工伤、医保社保、恋爱婚育、怀孕育儿、创业与做平台合规、出国与技能"（F-001）。

## 3. 内容是怎么组织的：数据即网页

这本书没有数据库、没有后端：**`README.md` + `book/` 目录里的 33 个 Markdown 文件就是全部数据**，GitHub Pages 上的检索页是一个纯静态阅读器，正文一改页面自动更新（F-008、F-011）。

```
HowToLiveBetter/
├── README.md        # 徽章、33 章问题索引、读法、四资源/分级/档位说明、41 条术语表
├── book/            # 01-不要早死.md … 33-残疾之后怎么活.md（正文 615 条）
├── docs/            # 5 篇独立长文 + 引用对照.md（约 110KB）+ 核实记录/ 目录
├── skills/          # life-decision-guide（Claude Code / Codex 可装载的 AI skill）
├── tools/           # EPUB / 离线 HTML / PDF 三种电子版的构建器
└── index.html       # 纯静态检索页（必须经 http 打开，直接双击本地文件为空白）
```

正文里每条建议是固定的六行结构（F-026、F-032）：

- **成本**——花多少钱、多少时间、要不要毅力；
- **说人话**——把统计数字翻译成"低约两成"式判断，只用收益栏已有信息、不添新数字；
- **收益**——研究/法规原文数字（RR/OR/置信区间/罚款档次）原样保留；
- **证据等级**——A/B/C；
- **来源**——DOI 链接或官方法规原文；
- **备注**——争议反方、适用禁忌、TODO 待核实。

机器可读的成本标签以 HTML 注释藏在每条标题下（钱=0/少/多、时间=少/中、毅力=否/些/是、收益=大/中/小、口径=死亡率/金钱/时间/自由），检索页据此筛出"不花钱不花时间不要毅力且收益大"的 104 条（F-027、F-042）。

## 5. 围绕正文的生态

- **在线检索页**：关键词 + 章节 + 证据等级 + 三项成本 + 收益口径组合筛选；术语悬浮释义；条目互引（"见第 N 节第 M 条"）可就地预览、一键跳转（F-008、F-038）。
- **离线三件套**：单文件 HTML（双击即开、可微信转发）、PDF（A4、两百多页、书签、每节另起页）、EPUB（Send to Kindle）；由 Release 流水线随正文自动重新生成，**下载链接固定**，但转发出去的副本不会随原文更新（F-013）。
- **5 篇独立长文**（docs/）：《结婚划不划算》《家庭应急装备清单》《生物钟和夜班》《遇到陌生人出事该不该停》《做平台要办哪些证》——把条目里算不清的大话题展开成专题（F-012，导览见 [03-chapter-map.md](03-chapter-map.md)）。
- **`引用对照.md`（约 110KB）与 `核实记录/` 目录**：项目自带的引文核对与核实过程工件——这是它区别于普通"经验帖"的结构性证据（F-012）。
- **life-decision-guide AI skill**：Claude Code 与 Codex 可装载；行为被严格限定为"先从正文查出相关条目，再照书里的算账方式排序回答，每条注明第几节第几条；查不到就说查不到，不凭记忆编数字"。安装与使用见 [05-how-to-use.md](05-how-to-use.md)（F-014）。

## 6. 作者姿态：备选单，不是任务清单

README"怎么读"开篇即声明（F-024，作者观点）：

> 不用全做：这是一份按性价比排好的备选单，不是任务清单。挑走一两条就算数，剩下的放着，需要时再回来查。作者自己也没做到其中大部分，写下来是为了要用的时候找得到。

这解释了本书的产品形态：它不承诺"读完就能变好"，而是让你在**具体决策点**（该不该换盐、要不要签担保、被裁怎么谈）能用极低检索成本查到一条带来源、带代价、带反方证据的答案。
