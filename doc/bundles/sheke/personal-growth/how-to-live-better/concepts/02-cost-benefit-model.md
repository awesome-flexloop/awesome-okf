# 四资源与性价比决策模型

> 如果说证据分级解决"数字可不可信"，本篇的模型解决另一个问题：**"我为什么要做这件事、先做哪件？"** 全书条目不是按类别（健康/法律/理财）排，而是按性价比从高到低排——本章拆解这个排序背后的完整算法。

## 1. 四种资源：记账单位只有四个，且**不互相换算**

这本书想帮你多留住的东西一共四类（F-025）：

| 资源 | 怎么衡量 | 检索页口径 |
|---|---|---|
| **寿命** | 总死亡率（全因死亡率）变化、特定死因下降幅度 | 换寿命 |
| **时间与精力** | 每天/每周省多少小时、注意力消耗降低 | 换时间精力 |
| **金钱** | 金额：万元级 / 数百至数千 / 几十元 | 换钱 |
| **人身自由** | 避免刑事责任 / 拘留行政处罚 / 民事纠纷 | 换人身自由 |

最反直觉、也是全书最重要的一条纪律：**"总死亡率降 12%"和"每年省 500 元"不在一把尺子上，不做换算**（F-025）。这不是偷懒，而是防"伪量化"——一旦给寿命标价，排序就会被任意设定的兑换率操纵。检索页因此要求你先选"换回什么"口径，再在同一口径内比较。

章与章之间也各算各的：第 13 章导语明说，急救条目算特定死因和存活率，骗局条目算钱和自由，"两类数字不互相换算"（F-040）。

## 2. 成本三件套：钱、时间、毅力

每条条目的成本拆成三个独立维度，各自只取粗档（F-026、F-027）：

- **钱**：0 / 少（几十到几百元）/ 多（上千上万）；
- **时间**：少（每次几秒几分钟）/ 中（每次数小时或要专门去一趟）；
- **毅力**：否（顺手就能做）/ 些（要忍住点什么）/ 是（长期对抗习惯）。

三个维度独立打分，所以"戒烟"与"换低钠盐"虽然都救寿命，成本画像完全不同：前者钱=0、时间=0、毅力=是；后者钱=少、时间=少、毅力=否。这也是为什么检索页允许把三个成本维度任意组合筛选（F-042）。

> 成本数字另有一条诚实声明：章首导语写明成本栏是"作者按市面价格的粗略估计，**只用来互相比较，不要拿去引用**"（F-040）。也就是说，证据等级管"收益"栏，成本栏天生只是粗刻度。

## 3. 收益量级：事先定好的界线，不凭感觉

"大/中/小"不是形容词，而是按每类资源的**事前固定阈值**套出来的（F-033）：

| 口径 | 大 | 中 | 小 |
|---|---|---|---|
| 换寿命 | 风险降 ≥20% | 降 10–20% | 降 <10%，或只量到中间指标（如血压降了但没量死亡） |
| 换钱 | 万元级 | 数百至数千 | 几十元 |
| 换人身自由 | 避免**刑事责任** | 避免拘留/行政处罚 | 避免民事纠纷 |
| 换时间精力 | 每天省出小时级 | 每周小时级 | 只省一次 |

"只量到中间指标"这一格很关键：某药降了血压但没被证明降低死亡，收益就只能算小——它防止把"化验指标变好"偷换成"活得更长"。

## 4. 性价比三档：合成规则与"作者自承 C 级"

合档规则完全机械（F-034）：

| 档位 | 规则 | 现行数量 |
|---|---|---|
| **极高** | 收益**大**，且钱/时间/毅力三项成本**全为零** | 104 条（17%） |
| **高** | 收益大但成本不高；或收益中等且成本为零 | 279 条（45%） |
| **一般** | 其余——需要自己权衡那笔花销 | 232 条（38%） |

作者在这里做了一件罕见的自我约束（F-034，作者观点）：

> 这一档是作者自己的判断，不是证据，按本书的标准它本身只算 C 级；它和证据等级是两回事，谁也不影响谁。

即：**证据等级与性价比是两条正交的轴**。原书举的例子是带状疱疹疫苗——有大规模三期 RCT 背书（证据 A，原书称效力 97.2%，该数字为原书举例、未经本包独立核验，F-087），但两针三四千元、带状疱疹很少致命（性价比一般）；出境前把行程发给家人没有任何文献（证据 C），但零成本且可能收益巨大（性价比极高）。

"一般"档最大，是刻意的（F-035，作者观点）：收益本就只分三级，再细分"就是装出来的精确"；而且"**'一般'不等于不该做**——全书条目都是建议做的，只是这一档要你自己掂量那笔花销值不值"。

## 5. 受益者四档：好处落在谁头上，分开记账

每条收益还要标注**受益人**，按"好处将来有多大可能回到你自己身上"从高到低分四档，**不同档不合并求和**（F-036）：

1. **你自己**；
2. **配偶和直系亲属**（父母、子女、祖父母外祖父母、孙子女）；
3. **朋友、同事和其他亲属**——互惠关系，帮出去的将来可能回来；
4. **陌生人**——回报概率最小，且你不了解对方，还有被讹、被反咬、被报复的一面；写这一档时**好处与风险必须一起写**。

这个排序在急救章落地为一组很具体的判断（F-037）：

- 中国 38,227 例院外心脏骤停登记中 79.2% 发生在家里（F-073 核验：该比例可靠）——**学 CPR 首先是为了救自家人**；
- "看到陌生人溺水自己不下水""撞见斗殴别上手拉架"被明确写成**自保规则而非冷漠**：防的是旁观者变成第二个伤者；
- 对陌生人要不要出手，条目把免责条款（民法典第 184 条"好人法"）、自保动作和风险面都列清，**但不替你做决定**。

## 6. 排序、互引与"怎么用这本书做决策"

- **排序**：全书按性价比排、每节内部也从高到低；急救章另用"这事多常见 × 做对做错差多少条命"排序（F-026、F-040）。
- **互引**：条目之间用"见第 N 节第 M 条（标题）"互相指路，检索页里可以就地预览再跳转（F-038）。决策常常是跨章的——"老人摔倒"条目会同时指向 CPR、反诈留证、救人受伤费用等多条。
- **使用姿势**：它是备选单不是任务清单（F-024）。实际用法是：带着一个具体处境来（"朋友让我替他担保签不签"），先在同口径内比较，再读该条的成本三项、收益量级、证据级、争议与禁忌，最后由你自己拍板"一般"档的权衡。

## 7. 一页速记：本书决策算法

```
第 1 步  这建议换回什么？     → 寿命 / 时间精力 / 钱 / 自由（选定口径，不跨口径比较）
第 2 步  收益量级多大？       → 套该口径的事前阈值，大 / 中 / 小
第 3 步  我要付哪三种成本？   → 钱、时间、毅力（各自 0/少/多）
第 4 步  合成性价比档         → 极高 / 高 / 一般
第 5 步  数字有多硬？         → A / B / C，查争议反方、禁忌人群、TODO
第 6 步  好处落在谁头上？     → 自己 / 家人 / 朋友同事 / 陌生人（第④档风险一起看）
第 7 步  "一般"档自己拍板     → 全书都建议做，但这笔花销值不值只有你能定
```
