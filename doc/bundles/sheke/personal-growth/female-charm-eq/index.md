# 《女性魅力与情商》知识包

本知识包把「女性魅力」与「情商」两个常被鸡汤化的话题，重建为**可核验的知识体系**：魅力不是玄学，而是可以被社会心理学解释的**信号与归因过程**（接近性、曝光、相似、互惠、光环、第一印象）；情商不是性格标签，而是以 **Mayer-Salovey 能力模型**为学界标准的**可习得技能**（情绪感知、利用、理解、管理），并有 Goleman 混合模型、人格重叠、增量效度等争议边界需要标注。

> **证据分级说明**：本知识包每条事实标注可信度层级——**学界共识**（多来源交叉核验或成熟元分析）、**单一研究**（单篇实证，可能未被复制）、**通俗主张**（实践者框架/畅销书主张，非受控验证）、**自媒体经验**（网络经验帖，质量参差）。实操条目中的「实证/经验」标记保留在括号内。凡涉及「复制失败」「效应夸大」的条目（如吊桥效应 CM-06、power posing CM-23、Asch 复制失败 CM-16），均在 [事实清单](facts.md) 与 [概念文档](concepts/index.md) 中如实登记。

## 两大模型骨架

1. **魅力模型**：Cabane 三要素（临在/力量/温暖）为实践框架，Riggio 六技能为训练视角，Goffman 拟剧论为自我呈现的理论底座，Fiske 温暖-能力双维度为他人感知的底层坐标——**魅力是被他人归因出来的，但可通过信号管理训练**。
2. **情商模型**：Mayer-Salovey 四分支能力模型为学界标准（MSCEIT 测量），Goleman 五要素为大众化转译（混合模型，争议见 concepts/05），情绪调节落地于 Gross 过程模型与情绪标注、重评等实证技术。
