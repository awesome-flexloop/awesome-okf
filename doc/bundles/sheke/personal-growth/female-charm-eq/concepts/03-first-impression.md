# 第一印象与自我呈现——前几秒如何决定，又如何被调节

「第一印象只有一次机会」是被反复强调的社交信条。证据支持它的一半：第一印象形成得**极快**。但证据同样支持被忽视的另一半：**快 ≠ 不可逆**——第一印象可以被情境、后续信息与呈现方式调节。这一篇拆开 CM-13~CM-22 与 CM-26 的证据，给出一个既重视前几秒、又不被前几秒绑架的框架。

## 第一印象有多快

- **薄片判断（thin-slicing）**：Ambady 与 Rosenthal 1993 年发现，仅凭 30 秒无声视频即可预测教师学期末评估，相关 r=.76；且多次被复制（CM-13）。
- **100ms 定印象**：Willis 与 Todorov 2005 年发现，100ms 曝光即足以形成可信度/能力判断，延长曝光只增加自信而不改变判断（CM-14）。

反常识点：这两个经典结果说明观察者会用极少的「薄片」信息快速推断人格与能力，而且**判断先于意识、先于理性校准**。对自我呈现的含义是：你「在场」的头几秒所传递的非言语信号（姿态、表情、着装、声音），权重远高于你以为的。

## 温暖-能力双维模型：坐标可靠，优先级不可教条

Fiske、Cuddy 与 Glick 2007 年提出社会认知的两大普适维度——**温暖**（warmth，意图是否友善可信）与**能力**（competence，是否有本领）（CM-15）；其经典源头是 Asch 1946 年的 warm/cold 中心特质实验与首因效应（CM-15）。

但本知识包必须如实标注一条**复制危机案例**：Nauts 等人 2014 年未发现「温暖首要性」效应——温暖的作用高度依赖情境（CM-16）。结论：**「温暖 > 能力」不是铁律**，不能当作万能开场策略；双维坐标本身有跨文化支撑（SCM 刻板印象内容模型在 26+ 国复制，PR-18），但「哪一维优先」要看语境——专业考核语境能力权重上升，亲密关系语境温暖权重上升。

## 自我呈现的理论底座

- **拟剧论**：Goffman 1959 年提出日常互动即「表演」——前台/后台（front/back stage）、印象管理（impression management）、戏剧化实现与神秘化（CM-17）。这是印象管理思想的**理论底座**（学界共识，理论层面）。
- **镜中自我**：Cooley 1902 年的 looking-glass self——「以他人为镜看自己」——是印象管理思想的源头（CM-18）。

反取悦澄清：拟剧论常被误读为「人设=欺骗」。Goffman 的本意是**所有人际互动都包含呈现**——呈现不是虚伪，而是社会互动的语法；问题只在于呈现是否服务于真实意图（呼应 CM-25 的「技巧服务于真实性」）。

## 着装与外在信号：信号是真实的

- **着装即信号**：Oh、Shafir 与 Todorov 2019 年发现，同一张脸配「显贵」服装在 130ms 内被判定更有能力，**明确要求观察者忽略服装也无济于事**（CM-19）。
- **着装认知（enclothed cognition）**：Adam 与 Galinsky 2012 年发现白大褂的象征意义会改变穿着者自身的注意力表现（CM-20）——衣服不只影响别人，还影响自己。
- **女性着装后果**：Fasoli 等人 2018 年发现毕业生穿职业装被评更有能力、更合适；性感装反而降低能力感知（CM-21）——这是「避免物化」的实证支点。
- **正装效应**：Kraus 与 Mendes 2014 年发现西装提升谈判成果与支配感；Oliver 等人 2021 年发现教师着装正式度在 warmth/competence 之间存在权衡（CM-22）。

## 「美即好」的双刃

光环红利（CM-05）与性化减分（CM-21）并存，构成 **CM-26 的平衡视角**：同样的外在呈现，在能力评价语境可能是加分项也可能是减分项。因此本知识包的写作框架是「**内在状态 + 外在呈现**」的统一——单靠外在不持久，单靠内在不达意。
