# 情商能力模型——学界主流与可测的能力

学界与大众对「情商」的落差，比任何其他心理学概念都大。大众语境里情商约等于「会说话、让人舒服」；学界标准里情商是一门**可测量、可训练的心理能力**。这一篇以 Salovey-Mayer 能力模型为主线（EQ-01~05、EQ-07~08、EQ-25），说清「能力模型为什么是主流」，以及它与「自评」「混合模型」的本质差异。

## 概念源流：三代定义

- **1990 年提出**：Salovey 与 Mayer 在《Imagination, Cognition, and Personality》正式提出 emotional intelligence——「监测与区分自己与他人感受，并利用其指导思维与行动的能力」（EQ-01）。
- **1997 年修订**：Mayer 与 Salovey 将 EI 修订为**四分支能力模型**，奠定学界标准（EQ-02）。
- **2016 年更新**：Mayer、Caruso 与 Salovey 在《Emotion Review》明确——EI 是**心理能力**，须按能力而非自陈测量，即采用**正确性评分**（EQ-03）。
- **1995 年大众化**：Goleman 把概念带给大众，主张 EQ 可能比 IQ 更能预测成功——但 Goleman 是科学记者，**非概念提出者**（EQ-04）。大众对情商的印象主要来自 Goleman，学界标准始终在能力模型一侧。

## 四分支模型：从感知到管理

MSCEIT 的四分支是（EQ-07）：

1. **感知情绪**：识别自己与他人情绪、以及环境中的情绪信息；
2. **利用情绪促进思维**：让情绪参与推理与决策；
3. **理解情绪**：把握情绪的语言、成因、演化与组合；
4. **管理情绪**：调节自己与他人的情绪。

四分支按**从基本心理过程到更高整合过程**排列——感知最早习得，管理最成熟综合（EQ-08）。这个排列有教学含义：训练应自下而上，先练「认得清」，再练「用得上、懂因果」，最后练「管得住」。

## MSCEIT：把情商「考」出来

2002 年发布的 MSCEIT 是四分支的**能力型表现测验**：它不是自评问卷，而是像智商测试一样有**正确性评分**（EQ-05）。两个关键实证后果：

- 能力型 EI 与**自陈式 EI 量表几乎不相关**（Brackett & Mayer, 2003；EQ-05）；
- 因此「自评情商高」与「测出情商高」是两回事（EQ-25）。

反常识点：你认为自己情商高，与你的情绪能力测试得分，基本预测不了彼此。这也解释了为什么「情商书籍读了很多、自评提升了」之后，能力未必变化——**自评改善的是自我概念，不是能力**。

## 能力模型为什么是学界主流

1. **可测量**：MSCEIT 按正确性评分，可重复、可比较（EQ-03、EQ-05）；
2. **与人格几乎无关**：能力型测量不依赖自我报告，规避了「换标签的人格测量」批评（EQ-05 的推论，对照 EQ-23）；
3. **有边界但仍可核验**：能力型 EI 对工作绩效的增量效度有限（r≈.23，约为认知能力的 1/3；EQ-24），但它至少能被检验——争议可证伪，这正是科学模型的标志。

## 证据边界与常见误解

| 误解 | 澄清 |
|------|------|
| 「情商=会说话」 | 那是混合模型里的社交技能成分（EQ-06），非能力模型定义 |
| 「情商测试=自评问卷」 | 能力型必须按正确性评分（EQ-05） |
| 「情商就是性格」 | 能力模型与人格几乎无关（EQ-03、EQ-05） |

证据分级：EQ-01~05、EQ-07~08 均为**学界共识**。能力模型是后续 [混合模型与争议](05-eq-mixed-model.md)、[情绪觉察](06-emotional-awareness.md)、[情绪调节](08-emotion-regulation.md) 的骨架。
