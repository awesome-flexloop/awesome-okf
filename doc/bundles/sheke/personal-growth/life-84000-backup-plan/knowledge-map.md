## 3. I 阶段：三条四元组洞察

> **G2 判定**：3 条洞察各含陈述 / 证据（F 编号）/ 反常识 / 行动；维度分别为「资源结构」「判定边界」「信源层级」，互不重叠。

### I-1　「还有别的路」本质是资源余量问题，不是心态问题

- **陈述**：源文把 84000 从「无限可能」去浪漫化为一项前置条件：事先布局、可携能力积累与时间资源安排（F-028/F-029），并把可选择性明确挂到可支配余量与资源调配上，而非主观愿望（F-022）。可操作的支点落在可支配时间余量，而非情绪状态。
- **证据**：F-019、F-020、F-021、F-022、F-028、F-029。
- **反常识**：默认读法把「多一种可能」当成认知升级或心态转变；源文自己给出的判据却是「每天时间已被占满、没有任何余量时，更多可能性只能停留在想法层面」（F-021）。先问「心态够不够开放」会漏掉真正卡住的地方。
- **行动**：把「我还有别的选择吗」改写成可计量的问题——「过去 7 天，我有多少段可自由支配的半小时，分别流向了能力积累、必要恢复、无意识消耗」（F-020）。只记录，先不做评分。

### I-2　「事败 ≠ 人败」是切断单点绑定的判据，不是安慰话

- **陈述**：源文把失败拆成「方案、时机、外部条件」三项不匹配（F-014），与「单一方案断裂→价值体系跟着崩塌」（F-010/F-011）对读，其作用是把事件结果与自我价值判定解耦；一旦解耦，单一路径中断不再自动触发整体否定。
- **证据**：F-010、F-011、F-013、F-014、F-016、F-017。
- **反常识**：常见读法把它归入励志安慰。但它真正的用途是**复盘格式**：若一次失利被写成「我能力不行」，就没有任何可修改的对象；写成三栏（方案 / 时机 / 外部条件）才有下一次可调整的入口。源文同时写「试错是有成本的」（F-017），说明这不是免复盘许可。
- **行动**：每次失利用三栏写事实，禁止出现「我就是不行」式终审句；再补一栏「最坏结果是否可控」（F-017），不可控的方向不启动。

### I-3　二手诠释会悄悄改写方法定义与引语归属

- **陈述**：本包 P0 核验出现两类偏移。其一，34 枚金币在一手报道里是 17 小时按半小时切分、含红黄绿「高效／浪费」判定的记账法（F-037/F-038），书评把它重述为「不压榨、回归盘点本质」（F-019/F-022/F-042）；其二，文末引联未标出处（F-007），独立核验归属为于丹自创的一联诗（F-039/F-040/F-041）。
- **证据**：F-007、F-019、F-022、F-037、F-038、F-039、F-040、F-041、F-042、E-1、E-2。
- **反常识**：读者默认「读书评 ≈ 读书」，实际拿到的是书评作者筛过、重排、再诠释过的一层。这一层可能比原书更好读，但不能反过来当成原书定义或引语出处的证据。
- **行动**：凡涉及「某方法是什么」「某句话出自哪」，回一手信源核验；两种口径冲突时并列保留、标注各自层级，不合并抹平，也不用更好听的那句替换另一句。

## 4. E 阶段：可迁移模式「余量预案」（L1-draft）

**一句话**：先把价值绑定的单点画出来，再盘出可支配余量，用最坏结果可控的小步测试把「可能性」从想法变成可查的预案。

| 要素 | 内容 |
|---|---|
| **适用于** | 单一路径依赖（价值系于一份工作/一个身份标签）；赛道收缩期的焦虑梳理；想启动第二方向但「没时间」；失败后容易整体自我否定的复盘场景 |
| **不适用于** | 急性危机需即时救济（失业、重大健康事件、债务）；需要专业心理干预或医疗判断；重大不可逆决策（辞职、大额投资、迁徙）单独拍板；组织级战略规划；把本模式当作职业咨询或投资建议 |
| **核心步骤（6 步）** | ① **画单点**：写下当前唯一的价值绑定路径，以及「若它断裂，我会具体失去什么」（F-010/F-011）。<br>② **盘余量**：以固定粒度记录 7 天时间流向，分「积累能力 / 必要恢复 / 无意识消耗」三类，只记事实不做道德评分（F-019~F-022；F-037 一手口径并列）。**10 分钟起步样例**：取昨天，按半小时为一行，只填三类之一，不写评价；填不出的格子标「记不清」即可，不补猜。<br>③ **定最坏**：为每一个候选方向写出「最坏结果」与「是否可控」，不可控则不启动（F-017）。<br>④ **拆能力**：把当前岗位做的事拆成可携资产清单（五类见 `concepts/03`，F-024）；只列能举例的行为，不列形容词。<br>⑤ **小测**：选成本最低的一次小范围测试，设定观察期，观察期内不预设成功判据（F-026/F-027）。<br>⑥ **留痕**：记录「该方向是否已从想法变为可用」，只写可观察事实，不写励志结论（F-029）。 |
| **检验标准** | 能说出过去 7 天可支配余量的粒度与三类占比；每个候选方向都写了最坏结果与可控性；至少一次小范围测试留下观察记录；复盘文本中无终审式自我判定；未出现「忍到某天一次性翻盘」式计划（F-017/F-028）。 |
| **反模式（5 条）** | ① 把「多可能」当心态许愿，从不盘时间余量（对应 I-1）；② 用 84000 的字面数量鼓励到处尝试或孤注一掷（F-005/F-017/F-044）；③ 把「事败≠人败」读成免复盘（F-014/F-017）；④ 照抄书评的再诠释当方法原始定义，或把引语归给错的书（E-1/E-2）；⑤ 把迷茫当警报，急于抓一个确定答案（F-026/F-027）。 |
| **跨域迁移** | **软件项目单点依赖治理**：唯一云厂商/唯一大客户＝单点绑定；工程师机动工时＝余量；可移植接口层与可迁移技能＝可携资产；小范围灾备演练＝小测；演练记录＝留痕。共同结构是「先定位单点 → 盘可用余量 → 拆可携能力 → 低成本演练 → 只记事实」。 |
| **成熟度** | **L1-draft**：基于单篇书评 + 11 个独立信源首次成型，45 条事实与 3 条洞察支撑，`validation_count=1`、`reuse_count=0`。升级 L2 条件：在第二个非同谱系领域（如项目治理或团队复盘）完成一次完整六步应用并回填修订记录。 |

> 本模式是**审视清单**，不是效果承诺。它不保证「多一种可能」会实现，也不替代原书、职业咨询或专业判断。
