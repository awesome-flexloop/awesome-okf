# 01 单一路径风险：把「事败」和「人败」分开

书评开篇提出的问题不是「怎样更努力」，而是「为什么一次环节断裂会让人整体塌掉」。这一篇把该问题改写成可以检查的结构。

## 1. 单点绑定长什么样

源文的主张是：多数人的不安来自只准备了一套人生方案，方案运转顺利时一切安稳，其中一环断裂时，自我价值的判定也被一并带走（F-010/F-011 `[作者主张]`）。

把它画成结构，是三层叠在一起：

| 层 | 内容 | 检查问句 |
|---|---|---|
| 路径层 | 一条既定的读书—择业—晋升—成家路线 | 我现在实际依赖的是哪一条？ |
| 身份层 | 「我是某岗位／某职级／某种收入水平的人」 | 这条路线若中断，我具体会失去什么？ |
| 判定层 | 用结果反过来给「我这个人」下终审结论 | 上一次失利，我写下的句子是在改方案，还是在判人？ |

**本包定义**：「单点绑定」指路径层、身份层、判定层被压成一条，任一环节失效直接触发整体否定。这是可审视的结构描述，不是心理学诊断，也不是对任何人的状态判定。

## 2. 「事败 ≠ 人败」是一个复盘格式

源文把一次失利限定在方案、时机与外部条件三项同情境的适配上，明确否定把它当作对人的最终判定（F-014 `[作者主张]`），并补了两条护栏：优秀不等于完美、疲惫与做不到是正常状态（F-016）；奋斗初衷不是碾压他人，而是守住底线持续输出（F-018）。

把这句话当安慰读，会停在情绪层；当**格式**读，才有下一次可改的对象。本包据此给出一个三栏加一栏的记录法：

| 栏 | 只写什么 | 禁止写什么 |
|---|---|---|
| 方案 | 这次用了什么做法、哪一步没生效 | 「我能力不行」 |
| 时机 | 启动时间、外部窗口、准备周期 | 「我总是错过」 |
| 外部条件 | 不由自己控制的约束与信息缺口 | 「就是运气差」式笼统归因 |
| 最坏结果 | 这个方向最坏会怎样、是否可控（F-017） | 空栏 / 「应该没事」 |

> 源文同时给出成本约束：尝试有代价，孤注一掷不在推荐之列，只有最坏结果仍在可控范围内的才值得启动（F-017）。所以解耦**不是免复盘许可**：把「我这个人不行」换成「这三栏都没写」，同样没有可改的对象。

一条观察见[知识地图](../knowledge-map.md) I-2：解耦的作用发生在判定层，而不是让人「感觉好一点」。

## 3. 84000 不是路径计数器

页面写「84000 源自八万四千法门」（F-005 `[作者转述]`），并把书名数字读作「出路不止一条」这一层判断（F-012）。

独立核验给出两个不同的口径：

| 口径 | 内容 | 信源 |
|---|---|---|
| 书名取意 | 艾力因「佛法共有 84000 种法门」选此数，表达「极多」之意 | S02 / F-033 |
| 术语原义 | 众生有八万四千烦恼，佛为之说八万四千法门；又作法藏／法聚／法蕴 | S05 / F-034 |

**语义边界**：佛教语境里的 84000 是「对治烦恼的法门总数」，不是「通往高光的道路数量」（F-044）。本包保留「极多」这一书名取意，也保留「多路径」这一书评解读，但两者不能互相替换，更不能把这个数字读成「应该去试八万四千次」。这与源文「不支持孤注一掷、最坏结果可控」（F-017）恰好同向。

另有一处页面表述异常（该句后半的动词与同句前半的否定并列结构不一致，F-045），本包按上下文语义理解，不改动源文文字，也不引用该句作论据。

## 4. 可以怎么做

1. 用 §1 的三层表写下当前单点，只写名词与事实，不写评价。
2. 取最近一次失利，按 §2 四栏填一遍；出现终审句就划掉重写。
3. 给每个想试的方向补一句「最坏结果是什么、可控吗」，不可控的先搁置（F-017）。
4. 到这里先停：**不要**立刻做方向决定。余量还没盘，见[02 时间余量](02-time-residual-audit.md)。

## 5. 本包不覆盖

不提供心理诊断、危机干预或治疗建议；处于急性困境（失业、重大健康事件、债务、自伤风险）时本框架不构成处置方案，应转专业支持。不评价任何具体职业、行业或人生选择；不承诺「解耦」会带来情绪或绩效改善。以上主张均为单源书评观点，未经独立实证（F-009）。

## 6. 常见误读

| 误读 | 校正 |
|---|---|
| 「多一种可能」＝心态放平 | 源文自己把支点放在时间余量与可迁移能力上（F-021/F-022） |
| 「事败≠人败」＝不用复盘 | 三栏加最坏结果栏，恰恰是复盘格式（F-014/F-017） |
| 84000 意味着到处试 | 原义是对治烦恼的法门总数；且源文明写试错有成本（F-034/F-017） |
| 迷茫要赶紧找答案 | 见[04 迷茫作为信号](04-muddle-as-signal.md) |
