# 00 阅读与证据：先分清四种陈述

一篇书评里至少叠着四种不同的话。把它们混在一起读，最容易出现的后果不是「理解偏差」，而是把某位作者的一次取舍当成已验证的事实继续转引。本包因此把分层放在第一篇。

## 1. 四种陈述

| 类型 | 回答的问题 | 本包标记 | 例子 |
|---|---|---|---|
| **页面事实** | 页面上写了什么、有哪些章节、没写什么 | `A 组` / `D 组` 事实 | 页面有 6 个小标题（F-003）；页面未给出 ISBN 与参考文献（F-008/F-009） |
| **作者主张** | 书评作者怎么看、怎么取舍 | `[作者主张]` / `[作者转述]` | 「不安来源于只准备了一套方案」（F-010）；「34 枚金币回归本质」（F-019） |
| **独立核验** | 一手信源里同一件事是什么口径 | `C 组` + 信源 ID | 图书出版信息（F-031）；方法的一手操作口径（F-037）；引联归属（F-039） |
| **本包操作化定义** | 为了可审视，本包把主张改写成什么可判定形式 | 显式写「本包定义」 | 把「余量」定义为「过去 7 天可自由支配的固定粒度时段」 |

> 分层不是给源文挑错。书评作者做的是筛选与重述，这本身就是书评的价值；问题只在于**读者把这一层当成了原书或事实**。

## 2. 术语速查（V-4 采纳）

| 术语 | 本包内的含义 | 常见混淆 |
|---|---|---|
| **备选方案 / 预案** | 提前布局、可查、可接受最坏结果的方向；不是「随时能换的心情」 | 不等于「幻想」，也不等于「立刻辞掉现有路径」 |
| **余量** | 可自由支配、尚未被本职与琐事占满的时间段 | 不是「空闲越多越好」，也不等于娱乐时间 |
| **可迁移能力** | 换岗位、换行业后仍可带走的做事能力（F-024） | 不等于证书、职级或平台资源 |
| **第二曲线** | 在现有路径之外另行积累的第二条能力/价值线（F-021） | 不等于兼职数量，也不等于跟风转行（F-023） |
| **单点绑定** | 自我价值系于一份工作或一个身份标签的状态（F-010/F-011） | 不等于「专注」，专注不必然伴随价值绑定 |
| **八万四千法门** | 佛教术语，指对治八万四千烦恼的法门总数（F-034） | **不是**「八万四千条人生路径」；书名取「极多」之意（F-033） |
| **34 枚金币** | 艾力提出的半小时粒度时间记账法（F-036/F-037） | 书评里「回归本质」的说法是再诠释，不是一手定义（F-042/E-2） |
| **表格 ≠ 原书表格** | 本包所有表格为原创改述 | 不是图书原表、不是书评原表、不是平台后台字段 |

## 3. 时间线（V-8 采纳）

```
2014-04  34 枚金币方法已有公开报道（S07/F-036）
2015-07  于丹《有梦不觉人生寒》出版，引联为其自创（S11/F-039）
2016-01  《你一年的 8760 小时》升级版，仍以该方法为核心（S03）
2017-01  《人生的 84000 种可能》出版（S02/S04/F-031）
2015-07  于丹书 ↖ 与本书无公开可查的归属关系（E-1）
2026-11-03  本书评发布（S01/F-001）
2026-11-17  本包采集与核验
```

这条时间线提醒两件事：本包处理的不是「2026 年的新观点」，而是对一本 2017 年图书的 2026 年解读；而方法本身比这两本书都更早公开。

## 4. 10 分钟起步（给想直接动手的读者）

先不谈方向选择，只做一件事：拿昨天，按半小时一行，每行只填「能力积累 / 必要恢复 / 无意识消耗」之一，填不出的格子写「记不清」，不补猜、不评分。做完你会得到本包唯一需要先有的东西——**余量的实况**，而不是对余量的印象。完整六步见[知识地图](../knowledge-map.md) §4「余量预案」模式。

## 5. 本包不覆盖

本包不是图书原文转载、不是书摘集、不提供可替代原书的阅读捷径（route: `chaptered-summary`）；不诊断、不治疗、不做职业咨询与投资建议；不承诺任何方法的效果；不推荐付费产品、课程或社群；不把作者主张升级为研究结论。事实台账之外的具体声明一律不写入正文。
