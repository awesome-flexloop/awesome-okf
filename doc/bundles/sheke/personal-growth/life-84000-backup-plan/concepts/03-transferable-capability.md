# 03 能力迁移：哪些东西能跟着人走

书评把行业周期、岗位调整、年龄门槛列为客观存在的现实风险，并把安全感脆弱归因于自我价值只挂靠在单一岗位或单一身份上（F-010/F-011 `[作者主张]`）。这一篇只处理其中一个可操作的分支：**能力迁移**。

## 1. 跨界 ≠ 转行

源文明确把「跨界」与「跟风转行、频繁跳槽」区分开，说前者的核心是能力迁移（F-023 `[作者主张]`）：岗位与行业都可能失去原有的稳定性，做事层面的能力却可以随人转移（F-024）。

| 说法 | 关注点 | 本包是否处理 |
|---|---|---|
| 转行／跳槽 | 换一个赛道、换一家公司 | 不处理（涉及具体行业判断，超出单源材料能力） |
| 能力迁移 | 换环境后仍可复用的做事方式 | **处理**，改写为一张可填写的清单 |
| 身份标签 | 职位、职级、平台背书 | 只作为对照项，不当作资产 |

## 2. 五类可携资产（行为化判据）

源文列出五类（F-024 `[作者主张]`）：其一信息搜集、其二拆解问题、其三复盘修正、其四沟通协作、其五压力耐受。本包给每类配一个「能举例才算」的判据——只列形容词等于没盘。

| 类别 | 判据问句 | 可填写的行为证据 |
|---|---|---|
| 信息搜集 | 面对陌生议题，我能在限定时间内找到哪几类一手材料？ | 上次为某个决定列出的信源清单与筛选理由 |
| 拆解问题 | 我能否把一团模糊的困扰拆成可分别验证的子问题？ | 一次把「做不成」拆成方案／时机／外部条件的记录（见[01](01-single-path-risk.md)） |
| 复盘修正 | 上一次改动是基于哪条可观察事实？ | 一条「观察 → 调整 → 结果」的三行记录 |
| 沟通协作 | 我能否把分歧写成双方都认可的事实描述？ | 一次把争执改写成待确认清单的文档 |
| 压力耐受 | 在结果未定时，我靠什么维持可继续的最低动作？ | 一段持续执行的最小动作及其触发条件 |

> **本包定义**：「可携资产」指**换环境后仍能被举例说明的做事行为**，不含证书、职级、平台资源与人脉名单。这条定义是本包为可审视性所设，不是源文原话，也不是人力资源领域的标准术语。

## 3. 为什么它和余量是一对

[02 时间余量](02-time-residual-audit.md) 给出的是「有没有空」,本篇给出的是「空下来能长出什么」。源文把两者连在一起：新方向、第二条能力线与可携能力都要靠空余时段供养（F-021）。缺任一边，预案都停在纸面：

| 余量 | 可携资产 | 状态 |
|---|---|---|
| 无 | 有 | 有能力但排不进日程，只能等 |
| 有 | 无 | 有时间但不知往哪投，容易跟风口 |
| 有 | 有 | 才具备做小范围测试的前置条件（F-026/F-027） |

## 4. 沟通这一支：只取可判定的部分

源文另有一节谈沟通，把要点收敛为两件事：把自己的意思说明白，把对方的意思按原样接收，并说话术、博弈、拿捏人心能换来短期便利，代价往往是持续内耗（F-025 `[作者主张]`）。

本包只保留其中可判定的一条：**把分歧改写成双方都能核对的事实描述**，作为上表「沟通协作」的行为证据。源文关于「干净坦荡的选择容错空间更大」「靠花招拿到的便利隐患藏在后面」等判断属于价值主张，无独立证据（F-009），本包登记但不作结论、不外推到谈判技巧或人际策略。

## 5. 可以怎么做

1. 按 §2 五类各写一条**具体行为证据**；写不出就留空，不用形容词补位。
2. 把写出来的条目与[02](02-time-residual-audit.md) 的「能力积累」时段对照：两处对不上，说明记录口径或自我认知至少有一处需要复核。
3. 选一条最便宜的做小范围测试（F-027）：限定观察期，期内不预设成功判据。
4. 记录「该方向是否已从想法变为可用」，只写事实（F-029）。

## 6. 本包不覆盖

不评价具体行业前景、岗位需求或年龄门槛；不提供转行路径、简历建议、面试技巧或薪酬判断；不把「可迁移能力」当作就业保障的承诺。源文未提供样本、统计或效果数据（F-009），五类能力的有效性未经本包验证。涉及重大不可逆的职业决策时，本清单不构成决策依据。
