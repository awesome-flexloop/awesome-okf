# 05 边界与主张：哪些句子不能用、为什么

单源材料做成教程，交付质量不由「写了多少篇」定义，而由「明确声明不产什么、哪些句子不能外推」定义。这一篇把本包的边界集中列清楚。

## 1. 勘误 E-1：结尾那联诗不是这本书的

页面结尾引「无迹方知流光逝，有梦不觉人生寒」，未标注作者与出处，并把它归入所评图书的语境（F-007）。

独立核验结果：

| 项 | 核验值 | 信源 |
|---|---|---|
| 该联作者 | **于丹自创**，其本人在 2015 年访谈中称「这是我自己特别喜欢的一联诗」 | S09 / S10 / F-039 |
| 关联著作 | 于丹《有梦不觉人生寒》，长江文艺出版社 2015 年 7 月，书名即取自该联 | S11 / F-039 |
| 于丹本人释义 | 「人生的寒，就是梦想的代价」；梦想需加实干才成理想 | S09 / S10 / F-040 |
| 与所评图书的关系 | 页面未说明；本包未取得原书文本，**未闭合缺口**，不作断言 | P0-9 / F-041 |

**处置**：本包不沿用「放在这本书里」的说法，不把该联归给艾力或《人生的 84000 种可能》，也不推测原书是否引用过它。教程正文凡提及此联，一律标注其公开归属为**于丹**。这是[核验报告](../references/verification.md) 的正式勘误 E-1，也是本包相对源文最主要的核验增量。

> 这条勘误的价值不在于挑错，而在于演示 I-3：二手解读里最容易被顺手转引的，恰恰是没标出处的漂亮句子。

## 3. 三项未闭合缺口（不补写推测）

1. 艾力原书正文是否引用了 F-007 那一联——未逐页核对原书。
2. 书评「回归本质」的判断是否有原书对应段落——未取得原书章节文本。
3. 公众号账号主体身份、文章传播数据——页面未展示，无第三方可核验来源。

缺口见[来源清单](../references/source-manifest.md) §5 与[核验报告](../references/verification.md) §4。**检索不到不等于可以凭印象补一句**；本包全篇不引用上述推测值。

## 4. route 与合规边界

`route: chaptered-summary`（深度摘要 + 原创改写），不采用逐字转录。本包：

- 不是图书原文转载、书摘集、金句汇编或可替代原书的阅读捷径；
- 不保存源文全文、不做全文镜像、不留原始 HTML（见[来源清单](../references/source-manifest.md) §1）；
- 所有表格为原创改述，**表格 ≠ 原书表格，也 ≠ 源文原表**；
- 不设 `examples/`：操作可复现性两问皆否（F-043），理由见[知识地图](../knowledge-map.md) §2。

## 5. 产出项 ↔ 不覆盖声明（成对登记）

| 本包产出了什么 | 同时声明不产什么 | 机械判据 |
|---|---|---|
| 6 篇教程 | 不逐字转录、不保留连续长引 | 12 字连续片段比对命中 0 |
| 45 条事实 | 不引入台账之外的编号 | 全包 F 引用 ⊆ F-001~F-045 |
| 三层目录 | 不建 `examples/`、不建 `.trae/specs/` 副本 | 目录不存在、台账仅一份 |
| 1 个模式 | 不承诺效果、不推荐付费产品 | 关键词扫描命中 0 |
| 三级导航 | 不留孤立文档 | `check-toctrees.py` 退出码 0 |

逐条落盘即跑结果见[更新日志](../log.md)；成对表的完整版与四视角攻击见[对抗审查](../references/adversarial-review.md) §2。

## 6. 时效与复核
