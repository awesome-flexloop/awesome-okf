# 08 · 古为今用：《诫子书》与六阶链

> 素材事实见 [事实清单第四节](../facts.md)（F-HE-037~048）；同构论证见 [架构洞察 洞察 6](../insights.md)。
> **一句话边界**：《诫子书》原文是 verified 的公版经典；它与六阶提纲的对应关系是**本包解读**，照片没有画出连线（F-HE-047），不可写成「诸葛亮认为……六阶段」。

## 一、原文与版面事实

照片栏目名「古为今用」，所录为诸葛亮《诫子书》今通行本（F-HE-038，共 86 字）：

> 夫君子之行，静以修身，俭以养德。非淡泊无以明志，非宁静无以致远。夫学须静也，才须学也，非学无以广才，非志无以成学。**淫慢**则不能励精，**险躁**则不能治性。年与时驰，意与日去，遂成枯落，多不接世，悲守穷庐，将复何及！

照片仅对「淫慢」「险躁」二词作了颜色标注（F-HE-039）。全文五段结构（F-HE-046）：

```mermaid
flowchart LR
    A["① 立论<br/>静以修身 · 俭以养德"] --> B["② 推进<br/>淡泊明志 · 宁静致远"]
    B --> C["③ 条件链<br/>静→学→才→志"]
    C --> D["④ 反面警戒<br/>淫慢 ↔ 险躁"]
    D --> E["⑤ 时间警示<br/>年与时驰 · 将复何及"]
```

## 二、逐句白话（译文为本包口语化转述，非权威译文）

| 原文 | 白话 |
|------|------|
| 静以修身，俭以养德 | 用「静」修治自身，用「俭」蓄养德性——静是向内降噪，俭是向外节欲 |
| 非淡泊无以明志，非宁静无以致远 | 不淡薄眼前的欲望噪声，真志向显不出来；内心不安静，走不到远处 |
| 学须静也，才须学也 | 学习需要静，才干来自学习 |
| 非学无以广才，非志无以成学 | 不学不能增长才干；没有志向，学习完不成（坚持不成体系） |
| 淫慢则不能励精，险躁则不能治性 | 放纵懈怠就振奋不起精神；轻薄浮躁就修养不了性情 |
| 年与时驰，意与日去，遂成枯落，多不接世 | 年华随时间飞逝，意志逐日消磨，最终像枯叶般凋落，大多对社会没有用处 |
| 悲守穷庐，将复何及 | 到时悲凉地守着困窘的小屋，后悔还来得及吗 |

## 三、与六阶链的同构映射（本包解读）

| 《诫子书》 | 六阶链 | 今日用法 |
|-----------|--------|---------|
| 静以修身 | [1 情绪内耗](01-stage-emotion.md) | 「静」是全链闸门：信号系统不被反刍占满，后面的谈钱、定位、组织才启动得了 |
| 俭以养德 / 淡泊明志 | [2 财富关系](02-stage-wealth.md) · [3 核心价值](03-stage-value.md) | 降低伪欲望噪声，真需求与真定位才显形；不是不要钱，而是不被眼前热点牵走 |
| 宁静致远 | [5 盘活资源](05-stage-resources.md) · [6 联合创造](06-stage-cocreation.md) | 长期主义的组织与合伙，要求不被短期声量牵动（正防「流量跑偏」反模式） |
| 静→学→才→志 | 「（练）」与 [教会测试](../examples/03-teaching-test.md) | 志驱动学、学产出才、教会检验学；与「学会不如教会」同一闭环的古典表达 |
| 淫慢 / 险躁 | 第 1 阶两类反模式 | 见下节分型自测 |
| 年与时驰，将复何及 | 全链时间维度 | 六阶不是终身排队的课表；一次只攻一阶，但要尽快开始 |

## 四、淫慢 / 险躁：内耗的两种古典分型

本包对照片两处标色的解读：它们标记了内耗的**两个相反方向**（F-HE-045 释义）。

> **课程同向印证（弱信源）**：Day6 课程对这四字给出白话——「淫慢（讲作『慢』）则不能励精」＝放纵怠慢，举例为吃夜宵、刷短剧、拖延；「险躁则不能治性」＝危险浮躁，使本性难归、无法入静（F-HE-083）。这与本包下表的方向判断一致，且**举例层面高度吻合**（刷手机/拖延正落在「淫慢」侧）。来源为 AI 纪要，非逐字稿，仅作方向印证，不作引文。

| | 淫慢（松的内耗） | 险躁（紧的内耗） |
|---|---|---|
| 状态 | 放纵、懈怠、提不起劲、瘫 | 浮躁、冒进、想太多、乱 |
| 典型表现 | 报复性熬夜/刷手机、计划无限推迟、「励不了精」 | 同时开八件事、追热点、频繁切换、「定不下性」 |
| 误治（会加重） | 再打鸡血、立更多 flag（更瘫） | 再逼自己更快、加更多任务（更乱） |
| 对症动作 | **立小约**：选一个 25 分钟可启动的最小动作，先动起来 | **减事项**：停掉/暂停一件并行任务，先静下来 |
| 六阶关联 | 多见于卡在第 1–2 阶的「动不起来」 | 多见于跳过第 1 阶直接冲第 3、5 阶的「学了很多」 |

**分型自测（30 秒）**：回想最近一次明显的消耗状态——事后主要感受是「瘫、空、没劲」→ 淫慢型，做立小约；是「乱、烦、停不下来」→ 险躁型，做减事项。判据是事后身体感受，不是事件本身。分型后再进入 [三行书写](../examples/02-positive-reframing-practice.md)。

## 五、「静」不是什么（反模式）

1. **静 ≠ 不行动**：全文以「接世」为归宿（多不接世是警告之一），静是行动前的信号治理，不是避世。
2. **静 ≠ 压抑情绪**：与 [01 的安全边界](01-stage-emotion.md) 同源——静来自解读与校准，不来自压制；压制出来的「静」会以淫慢或险躁回潮。
3. **俭 ≠ 反财富**：俭在本文是「节欲以明志」，与第 2 阶经营真实财富关系不矛盾；把俭读成「不要搞钱」是对六阶链与《诫子书》的双重误读。
4. **古为今用 ≠ 古训照搬**：映射只取最低公共语义，不把三国时期的家族诫命（受诫人是诸葛瞻）当成现代个体职业设计；不做「诸葛亮早就发明了 OKR」式的比附。

## 六、版本异文（引用时的学术纪律）

《诫子书》传世有两组异文（F-HE-042/043）：

| 位置 | 宋本类书系统（《艺文类聚》《太平御览》） | 宋儒以下通行系统（《小学》《戒子通录》等） |
|------|--------------------------------------|------------------------------------------|
| 第 6 句 | 险躁则不能**治**性 | 险躁则不能**理**性 |
| 学志句 | 非**志**无以成学 | 非**静**无以成学 |

照片与今日教材采用「治性 / 非志」组合（F-HE-044）。引用建议：日常学习用通行本即可；做文本讨论时注明所选系统，不把异文当错字。详细考辨见孙甲智 2024 年版本学文章（S15）。

### 7.1 第三例：Day6 课程（2026-10-06 直接采集）

2026-10-06 直接采集的「如何找到真需求Day6」元宝纪要中，讲师**逐句讲解**《诫子书》并将其与六阶挂钩，覆盖面远大于前两例的引用式提及：

- **讲「非志无以成学」的循环结构**：励志去学才有才，而才支撑志向，构成循环（F-HE-084）。
- **讲「淫慢/险躁」的白话**：「慢则不能励精」被解为放纵或怠慢（所举例：吃夜宵、刷短剧、拖延）；「险躁则不能治性」被解为危险浮躁，使本性难归、无法入静（F-HE-083）。**举例层面与本包下表的「淫慢＝松/瘫」高度吻合**，构成本包分型方向的一次外部印证（仍为 AI 纪要，仅作方向印证，不作引文）。
- **讲「险躁」与真我的关系**：真我**不会放弃**，只会暂放曾承诺或遇过的事；这与因险躁而放弃不同，是合一的关键区别（F-HE-083）。本包认为这是对「险躁」最精细的一次现代解读——它把「放弃」从「懈怠的自然后果」重新定义为「伤到真我的行为」，正好接上 [04 的放下 ≠ 放弃](04-stage-self.md#二点五增补放下-放弃真我不会被误认成可以丢弃的东西)。
- **讲「悲守穷庐」的现代出路**：课程给出的解法是组织自己的道场（组局），而非困守（F-HE-088 相关）。
- **以 86 字为「永恒价值投资」的例证**：课程称《诫子书》仅 86 字、悟透受益一生，用以论证经典跑得赢时间（F-HE-084）。

> **同构强度升级说明**：三例共现中，本次（第三例）讲师是逐句讲解并挂钩第1、4、6 阶，覆盖面最大。这提高了「《诫子书》× 六阶」话语组合的实际流行度，但**依然不改变提纲出处的 flagged 状态**——三例之间未发现作者或出处关联。

### 7.2 待核项：讲师关于「南怀子」的转述不采用

Day6 纪要中讲师提到「非淡泊无以明志，非宁静无以致远」并非诸葛亮原创，而是参考一位被称为「南怀子」者的说法，并提示该句并非「宁静致远」一语之源（F-HE-099）。

**本包处理：登记不采用。**理由：该转述存在明显讹误风险——「南怀子」未见于传世文献，通行说法源自《淮南子·主术训》，而《淮南子》为西汉作品，在三国诸葛亮身后；将年代记为「秦朝」亦与通行的西汉说冲突。纪要为AI 加工产物，存在人名转写错误的可能（课程讲授中「淮南子」被误记为「南怀子」是常见讹误）。

因此：**本包不把这条转述写入正文的版本学讨论，也不据此修改[第六节的版本异文表](#六版本异文引用时的学术纪律)**。上表维持宋本类书系统与宋儒以下通行系统的两处异文（治性/理性、非志/非静），不引入第三项。后续若需处理《诫子书》前史问题，应另查《文选》《淮南子》等原典，而非依据课程转述。

## 八、一页练习：每日「静」功课（5 分钟）

1. 分型（30 秒）：此刻偏淫慢还是险躁？
2. 静（2 分钟）：只呼吸、不输入（不刷手机不听东西），让念头过去不追。
3. 约/减（2 分钟）：淫慢型写下今天一个最小启动动作；险躁型划掉今天清单里的一件事。
4. 志（30 秒）：用一句话回答「我现在学/做的这件事，服务于哪个志？」答不上来，是淡泊不足或任务跑偏的信号。
