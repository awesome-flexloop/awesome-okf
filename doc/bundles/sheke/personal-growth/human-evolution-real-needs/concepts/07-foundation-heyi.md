# 07 · 底座：【实事求是】合一

> 提纲原文（最新版独有，F-HE-020）：**「【实事求是】合一」**
> 该行在早期版画面中不存在（F-HE-021），是最新版增加的收束语。

## 一、两个词各自的来路

**实事求是**：通行最早出处为《汉书·景十三王传·河间献王》「修学好古，实事求是」（F-HE-032）；毛泽东在 1941 年《改造我们的学习》中给出经典阐释——「实事」是客观存在着的一切事物，「是」是客观事物的内部联系即规律性，「求」是去研究（F-HE-033）。这一阐释把它从治史态度提升为一般工作方法：**从事实出发，研究规律，指导行动**。

**合一**：在本提纲中与「陪跑」相连（F-HE-015），在中文哲学语境里连着王阳明的「知行合一」（F-HE-034）。本包的操作定义见 [04 阶段四](04-stage-self.md#二合一的操作性定义)：所说、所信、所做持续一致。

## 二、为什么底座必须是「实事求是 → 合一」

本包解读末行的句法：方头括号把「实事求是」标成限定词，去修饰「合一」——即提纲要求的合一**以实事求是为前提**。

这解决了第 4 阶最大的风险：合一感可以伪造。一个人可以真诚地感觉「我与我的事业合一」，但若这感觉不经过事实校验，它可能只是自洽的幻想。顺序因此是：

```
实事（事实层：真实发生了什么） → 求（研究层：规律与差距是什么）
→ 是（判断层：我该校准什么） → 合一（行动层：说信做重新对齐）
```

没有前三个动作的「合一」是表态；经过前三个动作的合一才是校准。

## 三、实事求是的三条校验

把底座落到每一阶，本包给出三条可反复执行的校验：

1. **事实校验（对抗应然叙事）**：我的判断后面跟着可核查的事实吗？
   - 话术对照：「我的客户很喜欢」→ 请出示复购、转介绍或原话记录（对应第 2–3 阶）。
2. **行动校验（对抗知行分裂）**：我说的原则，在我上一周的日历和账单里找得到吗？
   - 话术对照：「我重视交付」→ 上周时间分配里交付占比是多少（对应第 4 阶）。
3. **结果校验（对抗自我感动）**：事情在我不在场时是否仍然变好？伙伴是否因共创真实受益？
   - 话术对照：「团队被盘活了」→ 哪件事无你在场也高质量完成了（对应第 5–6 阶）。

三条校验共享同一个动作：**在宣布任何高阶状态（找到真需求、定位成立、活出真我、资源盘活、共创成功）之前，先回到事实层取证。**

## 四、底座在全链中的位置

```
六阶进化链（横向推进）
        ↑ 每一阶宣布完成前，都要向下扎到底座取证
【实事求是】合一（纵向校验）
```

这也是本包把这份提纲评定为「有结构感而非鸡汤清单」的主要理由（本包判断）：它没有让链条终止于自我感觉良好，而在末行补了一个事实校验器。但需再次声明：提纲仅有此四字，以上机制全部为本包解读（见 [边界与延伸阅读](../references/03-boundaries-further-reading.md)）。

## 五、反模式

1. **精神化合一**：只要状态感不要事实校验，把「合一」当自我感动的终点（与 [04 的反模式](04-stage-self.md#五反模式) 同源，此处是其底座级形态）。
2. **事务主义**：只埋头「实事求是」地处理琐事，放弃方向与意义校准；实事求是服务于求「是」（规律），不是加班的同义词。
3. **教条化引用**：把经典出处当权威背书，跳过自己眼前的事实研究；词源只是来路，不能替代对当下这件事的「求」。
4. **一次校准定终身**：事实在变，今天校准过的合一明天会出现新缺口；校验是节律性动作（建议月度），不是一次性的考试及格。
