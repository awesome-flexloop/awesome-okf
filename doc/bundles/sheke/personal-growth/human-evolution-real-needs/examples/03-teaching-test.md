# 教会测试：15 分钟教学闭环练习

> 提纲标语（F-HE-019）：**「学会不如教会！！！」**
> 本练习把这条标语变成每一阶的毕业考试。机制依据是「教会迫使结构化、暴露缺口、获得外部反馈」；**注意**：网传「学习金字塔：教授他人留存率 90%」缺乏可查的原始实验证据（F-HE-035），「费曼学习法」也是后世冠名（F-HE-036），引用本练习时不要使用这两个伪数字背书。

## 一、测试流程（15 分钟）

1. **选对象（2 分钟）**：找一个对该主题完全外行的人（同事、家人均可），说明「我要试着给你讲明白一件事，共 15 分钟，请你随时打断」。
2. **四句讲解（8 分钟）**：严格按四句脚本讲，不展开成讲座。
3. **对方复述（3 分钟）**：请对方用自己的话回答两个问题（见评分表）。
4. **记录断点（2 分钟）**：标注自己卡壳、对方误解、不得不退回重讲的位置——断点就是回炉点。

## 二、四句讲解脚本

| 句 | 内容 | 对应检验 |
|---|------|---------|
| 1 | 这是什么（用大白话 + 一个生活化类比） | 我能否脱离术语 |
| 2 | 什么时候该用 / 不该用 | 我是否掌握边界 |
| 3 | 第一次用，第一步具体做什么 | 我是否把它拆成了动作而非口号 |
| 4 | 最容易做错的一件事是什么 | 我是否真的踩过/见过坑 |

任何一句讲不下去，说明那一阶的对应理解还停留在「认得句子」而非「掌握结构」——与本库 [正面解读师框架](../../taoxingzhi-youbenchang-huge/concepts/05-framework-positive-reader.md) 的纪律一致：不接受句子，接受结构。

## 三、复述评分表（对方答完后填写）

| 检验问题 | 对方能复述（√/×） | 对方原话记录 |
|---------|:-----------------:|-------------|
| Q1：「如果你的朋友遇到 X 情况，你会告诉他第一步做什么？」 |  |  |
| Q2：「这件事在什么情况下不适用 / 做了反而有害？」 |  |  |

通过标准：两题均 √，且 Q1 的第一步与概念文档一致、具体到可执行。

## 四、六阶教会测试题库（每阶考什么）

| 阶 | 讲解主题 | 外行必须能复述的「第一步」 |
|---|---------|---------------------------|
| 1 | 什么是正面解读 | 写下事实、信号、48 小时行动三行 |
| 2 | 怎么判断一个需求是不是真需求 | 找语言、行动、复购三类证据中的两类 |
| 3 | 怎么写一句定位 | 填「为谁、在什么场景、怎么解决、与谁不同」 |
| 4 | 什么是合一 | 做说信做三列缺口表 |
| 5 | 盘活资源从哪开始 | 盘点人/事/场，选人事物场都齐的一件事组织一次 |
| 6 | 找人共创前先确认什么 | 先单次小事协作，再谈长期绑定 |

## 五、回炉规则

- 两题中错 1 题：回到对应概念文档的该节，用自己的话改写后重测一次（换一个听众）。
- 四句脚本中卡壳 ≥2 处：本阶判定为「认得，没学会」，回炉整阶，不进入下一阶学习。
- 连续 2 次通过：该阶「教会测试」毕业，在 [六阶自检工作表](01-six-stage-self-check.md) 为该阶记一次证据。
