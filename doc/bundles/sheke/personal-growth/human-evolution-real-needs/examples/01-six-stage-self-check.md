# 六阶自检工作表（可填写）

> 用法：60 分钟一次，独自书写。先打分，再写证据，最后判定主卡点。**纪律：每个高分必须附一个事实证据，证据标准见 [底座三校验](../concepts/07-foundation-heyi.md#三实事求是的三条校验)。**

## 一、六阶评分（1–5 分）与证据

| 阶 | 评分问题 | 分数(1–5) | 事实证据（具体事件/数据，不写形容词） |
|---|---------|:---------:|--------------------------------------------------|
| 1 情绪内耗 | 内耗出现时，我能否在 24 小时内完成解读并产生一个行动？ |  |  |
| 2 财富关系 | 过去 90 天，我有几次「对方用行为证明需求真实」的交换（付费/复购/转介绍）？ |  |  |
| 3 核心价值 | 客户向别人介绍我时，是否使用一句与我定位一致的话？ |  |  |
| 4 活出真我 | 上周日历/账单与我宣称的原则，最大缺口是什么？ |  |  |
| 5 盘活资源 | 哪件事在我不在场时仍高质量发生过？ |  |  |
| 6 价值投资 | 我是否有关系经「单次协作→系列共创」验证后进入长期绑定？ |  |  |

评分参考：5 = 有反复发生的事实证据；3 = 有一两次证据但不稳定；1 = 只有想法没有事实。

> **第 4 阶加问（课程增补）**：最近三个月里，你「放下」过的某件事，现在写得出**重启条件与时点**吗？写不出，说明那是放弃而非放下——放弃会伤到真我，而真我不会因险躁而放弃，只是暂放。判据见 [04 放下 ≠ 放弃](../concepts/04-stage-self.md#二点五增补放下-放弃真我不会被误认成可以丢弃的东西)。
>
> **第 5 阶加问（课程增补）**：上一场你组织的活动结束后，你手上留下的是「到场多少人、气氛多好」，还是「谁的真需求被满足了」？只有前者，说明做的是「线」而没打到「点」，属于组织幻觉。判据见 [05 点·线·面](../concepts/05-stage-resources.md#32-先做到点再谈线与面课程增补判据)。
>
> > **两处加问的来源提示**：这两条来自2026-10-06 采集的「如何找到真需求Day6」课程纪要（AI 加工产物，非逐字稿，弱信源）。它们是本工作表目前**最可能测出真问题**的两问——因为课程本身指出第 5 阶是六阶中最易卡住的一阶（F-HE-057），而传统评分表对第 4、5 阶的「合一」与「组织」都问得太抽象。

## 二、主卡点判定规则

1. 沿 1 → 6 顺序找**第一个 ≤3 分的阶**，即当前主卡点——即使后面的阶分数也低。
2. 理由（本包解读）：链条有向，前阶是后阶条件；在第 2 阶未完成时优化第 5 阶，往往是用组织/流量动作逃避真实交换。
3. 主卡点只选一个，攻 4 周后重新评分。同时修两阶以上视为本工作表未完成。
4. **第 5 阶的断裂高发提醒（课程增补，弱信源）**：课程讲师明确指出第 5 阶是六阶中最容易卡住的一步（F-HE-057）。本包采信该方向——原因是前 4 阶的作用单位都是「我自己」，第 5 阶第一次要求单位变成「事」与协作系统，**跳跃的是主语而非难度**。因此：
   - 若你的第 4 阶 ≥4 分但第 5 阶 ≤3 分，这是**典型的正常断裂**，不是你的失败。优先做 [04 的合一缺口测试](../concepts/04-stage-self.md#四合一缺口测试三层升级版)，而不是加办更多活动；
   - 反之，若第 1 阶 ≤3 分却在做第 5 阶的事，按本表第 2 条判定为**用组织动作逃避基本功**，主卡点仍在第 1 阶。

## 二点五、三条随堂速查（课程增补）

以下三条来自课程讲授（F-HE-077/086/072），本包判定为**最值得随身自问的三句**，各自只需十几秒：

| 速查 | 自问 | 出处阶 |
|------|------|-------|
| **放下 vs 放弃** | 这件事我写得出重启条件与时点吗？写不出，就是放弃 | [04](../concepts/04-stage-self.md#二点五增补放下-放弃真我不会被误认成可以丢弃的东西) |
| **点 / 线 / 面** | 我最近一次组织的活动，事后手上留下的是「谁的真需求被满足了」，还是只有气氛？ | [05](../concepts/05-stage-resources.md#32-先做到点再谈线与面课程增补判据) |
| **乙方陷阱** | 我说这三个词时，对方还当我是个要提供服务的人吗？（真问题/真目标/真需求——顶级水平时一个字都不说） | [02](../concepts/02-stage-wealth.md#31-练的方向修正别把自己卖得更用力课程增补) |

## 三、各阶最小练习（4 周选做表）

| 阶 | 每周最小动作 | 完成判据 |
|---|-------------|---------|
| 1 | 每周 2 次 [三行书写](02-positive-reframing-practice.md) | 每次第③行写出 48 小时内动作 |
| 2 | 3 个交换场景的三证据记录（见 [02 概念文档](../concepts/02-stage-wealth.md)「练的最小单元」一节） | 每场景有对方行为证据 |
| 3 | 写定位一句话 + 找 3 个目标对象试听并收集复述 | 2/3 能正确复述你与替代者差异 |
| 4 | 完成 1 次陪跑 + 月末 [合一缺口测试](../concepts/04-stage-self.md#四合一缺口测试三层升级版) + 每日一条感恩/敬畏记录（[07 两条路径](../concepts/07-foundation-heyi.md#三点五合一的两条日课路径感恩与敬畏课程增补)） | 三列写齐并有缝合动作；感恩/敬畏记录满 7 天 |
| 5 | 先在「点」上做1 次（真实满足单人真需求，事后对方视你为「自己人」），再组织 1 次三人以上协作并事后输出流程复盘 | 复盘文档含可复用步骤，且含一份「谁的真需求被满足了」记录 |
| 6 | 与候选伙伴完成/回顾 1 次单次协作并对照 [四条件](../concepts/06-stage-cocreation.md#二联合创造的四个成立条件) 打分 | 四项条件各有判断依据 |
