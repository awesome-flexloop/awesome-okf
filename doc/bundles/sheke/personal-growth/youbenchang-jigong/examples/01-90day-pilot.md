# 01 · 90 天最小可复制试点

> **核心命题**：如果一件事**你走了之后就没了**，那它不是资源，是**一次性消费**。
>
> 本篇把「种子计划」的核心设计（[../concepts/03-seed-program.md](../concepts/03-seed-program.md)）移植到个人/小团队场景。

## 一、为什么是「先培养人」而不是「自己做」

游本昌的选择逻辑（A 级 F-YB-087/089）：

| 方案 | 我在时 | 我走后 |
|---|---|---|
| 我亲自做（驻村/驻场/亲自教） | 效果好 | **停止** |
| 我培养本地人做 | 效果中等 | **继续** |

被舍弃的是「效果好但不可持续」；被选中的是「效果中等但可持续」。

> **这个决策之所以难，是因为它牺牲了可见性**（推断）：亲自做能立刻看到成果、立刻被感谢。培养人看不到即时效果。
>
> **判断问句**：`我走了之后，这件事还在吗？`

## 二、90 天试点设计表

### 第 1 步：明确「要传什么」（第 1 周填）

```
我要传的是：
  □ 一项具体技能（如：Excel 透视表 / 某项手艺 / 某类咨询方法）
  □ 一套判断方法（如：如何评估一个机会）
  □ 一个视角（如：如何看问题）

这个东西的接收者是：______（写具体的人，不是「团队」）

**检验**：接收者具体到一个人了吗？□ 是 □ 否 → 否的话，先细化到人
```

> **为什么必须具体到一个人**（推断）：因为「教好 3 个人」和「教会 1 个人」是完全不同的设计。种子计划的做法是明确的——培训一年的乡村教师（A 级 F-YB-087），**接收者是具体的人**。

### 第 2 步：把方法降到零门槛（第 2 周填）

> 依据：A 级 F-YB-092 —— 「戏剧被游本昌视为一种成本最低的教育方式……随便拿起你身边任何一样东西，孩子们就能感受到戏剧的乐趣。」

**填写：**

```
我要传的方法，最小版本是什么？（接收者零经验时能做的最小动作）
  ______

这个最小版本需要「设备/资料/预算」吗？
  □ 不需要（零门槛）    ← 最佳
  □ 需要，是：______
  □ 需要，且是长期门槛 → 这会让接收者无法自行启动，必须先解决

**参照 F-YB-088 第 4 步**：他用「拿起一个矿泉水瓶，它还能是什么？」来同时解决想象力和道具问题。**你的方法能不能找到这样一个「它还能是什么」的替代物？**
```

### 第 3 步：让接收者能自己继续（第 3–8 周）

> 依据：A 级 F-YB-089 —— 他发现派专业老师去乡村上课效果不佳，因为连接是短期的，「有些孩子会直接跟老师说，反正你会走，你干吗要来？」

**检验清单（每项打勾）**：

| # | 检验项 | 通过标准 |
|---|---|---|
| 1 | 我不在场时，接收者能继续吗？ | 接收者能在没有我指导的情况下独立做一次 |
| 2 | 接收者理解「为什么」吗？ | 他能用自己的话说出这个方法解决什么问题 |
| 3 | 接收者能教别人吗？ | 他能把这个方法讲给第三个人听（哪怕只讲一个要点） |

> **第 3 项是核心**（推断）：**教别人 = 能力真正固化的标志**。
>
> 这与陶行知的「教学做合一」三步循环中的第三步「教」是同一机制（见 [../../taoxingzhi-life-education/concepts/01-three-propositions.md](../../taoxingzhi-life-education/concepts/01-three-propositions.md) 第 3.4 节），也与游本昌教戏剧课同时也在训练自己表演的结构同源（F-YB-081）。
>
> **「能教别人」是本试点的验收标准**，不是「学会了」。

### 第 4 步：撤出测试（第 9–13 周）

**这是最关键、也最容易被跳过的一步。**

```
撤出测试设计：
  第 9 周：我明确告诉接收者「接下来 4 周我不再主动指导」
  第 10–12 周：我只在他主动问时回答
  第 13 周：他是否产出了东西？
    □ 是 → 通过（能力已在他身上）
    □ 否 → 未通过（他在依赖我，而不是在复制能力）

未通过时的诊断：
  □ 他不知道该做什么 → 第 1 步「最小版本」没写清
  □ 他做了但没完成 → 执行问题，不是设计问题
  □ 他根本不想做 → 动机问题，这个试点对他无效（诚实结论）
```

> **撤出测试的设计逻辑**（推断）：**这 4 周的沉默，是让接收者暴露「他真正会什么」的唯一窗口。** 如果你一直在线上，他永远不需要暴露。
>
> 这也对应王明礼说的那句：专业老师的支教问题是「连接是短期的」（F-YB-089）。**短线不可持续，长线可复制。**

## 三、三个真实场景的改写

### 场景 A：技术团队

| 步骤 | 填写 |
|---|---|
| 要传什么 | 不是「这个框架」，而是「排查线上问题的三个步骤」 |
| 零门槛版本 | 三个步骤写成一张纸贴在工位上（不写成文档） |
| 我不在场时 | 他按那张纸能走完流程 |
| 撤出测试 | 我停 4 周主动指导，看他是否真用上了 |
| **注意** | 不要写成 wiki 文档——**文档需要「被查」的动机，纸贴在工位是「被看见」**（推断：降低使用门槛比增加内容重要） |

### 场景 B：带新人

| 步骤 | 填写 |
|---|---|
| 要传什么 | 不是「公司的所有业务」，而是「这个岗位每天做的三件核心事」 |
| 零门槛版本 | 三件事各配一个「做对的样例」（不是「原则」） |
| 我不在场时 | 他能独立完成其中一件 |
| 撤出测试 | 我不主动介入 2 周，看他是否来找我**问问题而不是要答案** |
| **注意** | 关键指标是「**他来问问题**」而不是「他没来问我」——不来问可能是没遇到问题，也可能是放弃（推断） |

### 场景 C：把一项个人技能传出去

| 步骤 | 填写 |
|---|---|
| 要传什么 | 一项你自己会、且能拆成步骤的技能 |
| 零门槛版本 | **拆到最笨的版本**：假设接收者什么都不懂，缺一步都不行的程度 |
| 我不在场时 | 他能照着做完 |
| 撤出测试 | 我 4 周不答疑 |
| **注意** | 「拆到最笨」是关键——**大部分人失败在把方法拆得太聪明**，接收者卡在「这还需要我判断」的地方（推断） |

## 四、三种失败模式（本包预设）

| # | 失败模式 | 症状 | 根因 | 修复 |
|---|---|---|---|---|
| 1 | **我忍不住插手** | 撤出测试第 2 周就破功 | 可见性上瘾 | 规定「只在被问时回答」，不主动 |
| 2 | **拆得太聪明** | 接收者反复卡在「这我该自己判断吗」 | 拆分时用了自己的隐含知识 | 假设接收者是完全的外行，缺一步都不行 |
| 3 | **指标错了** | 只看「他学了吗」，不看「他走了之后呢」 | 用教学指标代替机制指标 | 把验收标准改成「我退出后他仍能做」 |

> **失败模式 1 最常见**（推断）：因为**「忍不住」是设计缺陷，不是意志力问题**——如果你的设计没有物理上阻止你插手，你一定会插手。所以：

**建议的物理隔离**（推断）：

```
撤出测试期间：
  □ 关闭该项目的消息通知
  □ 不在对方的工作空间附近
  □ 如果是同事，把「我暂时不主动指导」明确说出口
```

**说出来是有效的**——因为它把「我不介入」从沉默变成了承诺，而承诺比沉默更难违背。

## 五、试点结束后的判断

90 天后，填这张表：

| 问题 | 回答 | 判断 |
|---|---|---|
| 接收者现在能独立做吗？ | □ 能 □ 不能 | 能力是否转移 |
| 我退出后，产出还在吗？ | □ 在 □ 不在 | **机制是否建立** |
| 接收者能教第三个人吗？ | □ 能 □ 不能 | 能力是否可复制 |
| 我在这 90 天里的实际投入小时数 | ___ 小时 | 成本 |
| 如果重做一次，我会砍掉哪一步 | ______ | 精简 |

> **最关键的是第二问**（推断）：**「我退出后，产出还在吗」是机制存在的唯一检验。** 第一问只能证明你教了一个好学生，第二问才能证明你建立了一个机制。
