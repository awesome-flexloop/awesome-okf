# 00 · 复利台账

> **为什么需要这个工具**：「长期积累，偶然得之」（A 级 F-YB-053）这句话的问题在于——**它无法被验证**。你无法判断自己是在积累还是在拖延，因为两者从外部看一模一样（都是「暂时没结果」）。
>
> 本台账的目的：**把「我在积累」从一个信念变成一个可被检验的记录。**

## 一、四栏台账结构

### 栏 1：投入栏（每周记）

| 周次 | 投入的具体动作 | 耗时 | 完成度（完成/半成/放弃） |
|---|---|---|---|
| 第 1 周 | 例：读 20 页专业书 | 2.5h | 完成 |
| 第 2 周 | | | |
| 第 3 周 | | | |

> **「完成度」这一列是全表的关键**（推断）：它强制你区分「做了」和「做完了」。**长期主义者的失败模式不是不投入，是持续半成品**——因为半成品不产生复利。

### 栏 2：无反馈期栏（记「多久没结果」）

| 从第几周开始投入 | 第一次外部反馈 | 无反馈时长 |
|---|---|---|
| | | ___ 周 |

> **为什么必须单独记这一栏**（推断）：
>
> 「无反馈期」是长期投入**唯一真实的敌人**——不是因为痛苦，而是因为**没有反馈时，你无法判断自己是在积累还是在空转**。
>
> **明确记下「我已经 N 周没收到反馈了」，比模糊地感觉「好像很久没进展」要健康得多**——因为前者是事实，后者是情绪。

### 栏 3：转折点栏（记「第一个信号」）

| 转折点 | 日期 | 触发事件 | 当时我在做什么 |
|---|---|---|---|
| | | | |

> **「当时我在做什么」是全表最重要的一列**（依据 [../concepts/00-career-arc.md](../concepts/00-career-arc.md) 的转机判据二）：
>
> 复盘转折点时，**答案往往是「我在做另一件事」**——游本昌被选中演爷叔时在拍抖音（不是等着），被选中演济公时在练步态（不是等着）。
>
> **如果转折点到来时你「在等」，那这次转折是运气；如果你在做别的事，那这次积累已经起作用了。**

### 栏 4：复利溢出栏（记「投入开始产生回报的地方」）

| 时间 | 意外获得的回报 | 来源是哪个投入 |
|---|---|---|
| | | |

> **这一栏捕捉的是「非计划性回报」**（推断）：复利的特征是**回报会出现在你没预期的地方**。游本昌的例子：80 多岁随手拍视频 → 被王家卫选角团队注意（C 级 F-YB-036）。
>
> **如果这一栏在两年内完全空白**，说明你的投入可能还在第一层（积累但未形成能力），或者方向需要重新检视。

## 二、慢成 vs 拖延：五条区分判据

摘自 [../concepts/01-patience-and-compounding.md](../concepts/01-patience-and-compounding.md) 第 6 节，改为可勾选形式：

| # | 判据 | 慢成（复利区） | 拖延（无复利区） |
|---|---|---|---|
| 1 | 你在做最小单位的事吗？ | □ 是 | □ 不是（在等机会/灵感/准备好） |
| 2 | 完成标准是「完成」还是「完美」？ | □ 完成 | □ 完美（等状态好/设备齐） |
| 3 | **如果这件事永远不给你回报，你还做吗？** | □ 会做 | □ 不会 |
| 4 | 我在第几层复利？（技能/身份而非机会） | □ 第二三层 | □ 还没进第一层 |
| 5 | 一年后回看，今天的投入留下了什么？ | □ 留下了能力 | □ 什么都没留下 |

> **第 3 条是决定性的一条**。它直接对应 19 秒的农奴（C 级 F-YB-011）——**它必然没有回报，而它做了。**
>
> **凡是能通过第 3 条测试的投入，都是复利区的投入。**

## 三、「是否该继续」的三问判定算法

台账记满 12 周后，用这三问判断继续/调整/停止：

```
第一问：我的「复利溢出栏」有内容吗？
  □ 有（≥1 条） → 进第二问
  □ 无         → 进「方向检视」（见下）

第二问：我做的动作在第几层？
  □ 第二/三层（技能/身份积累）→ 继续，同一方向
  □ 第一层（还在等机会）      → 调整：把动作往技能层推
  
第三问：过去 12 周的「完成度」列，有多少是「完成」？
  □ ≥ 60% → 继续
  □ < 60% → 不是方向问题，是执行问题：先解决完成度，再谈方向
```

### 「方向检视」的三个问题（第一问为「无」时使用）

1. 我投入的这件事，**完成后**具体能做什么？（写出具体动作，不是「提升自己」）
2. 这个动作是**可重复**的吗？（做 100 次是否还有意义）
3. 如果做完了，**下一个动作**是什么？（能答出下一个，才是路径）

> **三个问题都答不出 → 该换方向了**（推断）。这不是失败，是**台账在正常工作**——它帮你在第 12 周止损，而不是第 60 周。

## 四、三个真实场景的改写

### 场景 1：学写作

| 栏 | 填写 |
|---|---|
| 投入栏 | 每周写 800 字（不修改），完成后写 200 字复述 |
| 无反馈期栏 | 前 8 周大概率无反馈（正常） |
| 转折点栏 | 第一次有人读完并给出具体意见 = 信号 |
| 复利溢出栏 | 写着写着发现自己擅长什么（这通常在 20 周后出现） |

**关键调整（推断）**：**不要以「有没有人读」作为反馈指标**——这会把「写」变成「讨好读者」。用「我自己能不能写完 800 字」作指标。**读者反馈属于第二层。**

### 场景 2：转行/学新技能

| 栏 | 填写 |
|---|---|
| 投入栏 | 每周做一个小项目（12 周 = 12 个极小项目） |
| 无反馈期栏 | 12 周内几乎没有市场反馈，这是**预期之内**的 |
| 转折点栏 | 第一个别人主动问「这个你做过吗」的时刻 |
| 复利溢出栏 | 第 12 周时，你可能发现新技能和旧技能组合出了新用途 |

**关键调整（推断）**：**12 个极小项目比 1 个大项目更容易完成度达标**——对应「完成/半成/放弃」那一列。

### 场景 3：做一个长期副业

| 栏 | 填写 |
|---|---|
| 投入栏 | 每周固定投入，不因「这周没收入」而中断 |
| 无反馈期栏 | **明确写下：前 6 个月大概率无收入**（写下具体月数） |
| 转折点栏 | 第一次「有人主动付钱」或「有人主动推荐」 |
| 复利溢出栏 | 累积到第 6–12 个月时，可能出现与本职工作结合的机会 |

**关键调整（推断）**：「无反馈期栏」对副业尤其重要——**提前写下 6 个月这个数字，能大幅降低中途放弃的概率**，因为你不再把「没收入」当作异常信号。

## 五、六个月后的复盘模板

```markdown
## 复盘（第 24 周）

### 1. 投入统计
- 总周数：___ 周
- 完成度「完成」占比：___ %
- 累计耗时：___ 小时

### 2. 无反馈期
- 实际无反馈时长：___ 周（预期是 ___ 周）
- 实际 / 预期：□ 符合预期  □ 短于预期  □ 长于预期（→ 检视是否方向错误）

### 3. 转折点
- 第一个信号出现在第 ___ 周
- **当时我在做什么**：______
- 判断：□ 我在做别的事（积累起作用了）  □ 我在等（运气）

### 4. 复利溢出
- 列出所有非预期的回报：______
- 判断：已进入复利区 / 仍在积累层

### 5. 下一年决定
- □ 继续同一方向
- □ 调整动作（往技能层推）
- □ 换方向（依据三问判定）
```
