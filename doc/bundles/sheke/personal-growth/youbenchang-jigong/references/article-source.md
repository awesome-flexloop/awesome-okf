## 六、引用纪律

1. 正文每处具体年份、数字、机构、语录均就近标注 F 编号；
2. **最高频引用的五条语录**（「不能爱艺术中的自己」「长期积累，偶然得之」「我不是公益人士」「以文艺化导人心」「拿到自己最好的名次」）**均为 A 级**，可放心引用；
3. **场景类细节**（童年、龙套生涯、19 秒农奴、卖房细节）多为 C 级，正文已标 C 级或注明「据报道」；
4. **规模数据必须带 C 级标注**，且不得作为独立论据支撑结论；
5. **身后信息**（2026-09 后）引用前须重新核验；
6. **政治相关内容**（入党时间线，C 级聚合来源）不作为方法论论据，见 `../concepts/05-boundaries.md` 边界 5；
7. **本包不做生平评价、不做艺术成就排名**，只做方法论萃取。
