## 使用说明

- 正文引用采用脚注 `[^source-id]` 形式，信源 ID 可回溯至上表；同一条信源在不同文档使用相同 ID。
- 经文、传文原文以 `ruan-ke-shisanjing` 为文字基准，`ctext-zhouyi` 与 `wikisource-zhouyi` 为逐字核对双源；电子文本与底本偶有出入处从底本并在正文加注。
- 出土文献释文片段只引自 `zhang-jiaodu`、`yu-jiaozhu`、`shangbo-3`、`han-fuyang`、`wang-wangjiatai` 等正式整理本，残损与缺字显式标注，不以网络文本替代整理本。
