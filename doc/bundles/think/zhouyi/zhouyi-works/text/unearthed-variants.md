# 出土文献异文选录

本稿**分层著录并选录**《周易》四大出土文本系统的存佚范围、版本/卦序特征与关键异文：**马王堆帛书《六十四卦》**（帛书卦序、卦名通假）、**上博楚竹书《周易》**（残简、阴爻"八"形、红黑首尾符）、**阜阳汉简《周易》**（残片、卜辞连缀）、**王家台秦简《归藏》**（卦画阴爻"∧"形、仅卦辞无爻辞）。

**著录与引用纪律**（详见 [references/unearthed-sources.md](../references/unearthed-sources.md)）：
- 所有释文片段脚注**落到正式整理本**（`zhang-jiaodu`/`yu-jiaozhu`/`shangbo-3`/`han-fuyang`/`wang-wangjiatai` 等信源）；网文（如陈仁仁汇总）仅用于存佚与字数数据互勘[^chen-chutu-xingtai]。
- **残损显式标注**：残字、缺字、模糊字以"□"（残字）、"（缺）"等方式标注，不据上下文径补，**不编造**。
- 出土数字以整理本与发掘报告为准；不同来源不一致时并列标注。

### 关键异文：卦名通假

帛书《六十四卦》卦名大量使用**通假字**，与今本卦名异文（F-023）。下列对读以张政烺校读本为据[^zhang-jiaodu]，于豪亮校注本可互参[^yu-jiaozhu]：

| 今本卦名 | 帛书卦名 | 说明 |
|---------|---------|------|
| 乾 | **键** | 通"乾"（F-023） |
| 坤 | **川** | 通"坤"（F-023） |
| 艮 | **根** | 通"艮"（F-023） |
| 兑 | **夺** | 通"兑"（F-023） |
| 需 | **襦** | 通"需"，此与王弼注"襦"（被须）相合 |
| 履 | **礼** | 帛书多以"礼"代"履" |
| 泰 | **柰** | 通"泰" |
| 同人 | **与** | 通"同人" |
| 谦 | **嗛** | 通"谦" |
| 临 | **林** | 通"临" |
| 大畜 | **泰蓄** | 通"大畜" |
| 坎 | **习赣** | 帛书以"习赣"写"习坎" |

> **校勘说明**：上表仅列出学界公认、整理本收录的典型通假对读，供示其例；完整六十四卦帛书/今本卦名对照表以张政烺《马王堆帛书〈周易〉经传校读》[^zhang-jiaodu]、于豪亮《马王堆帛书〈周易〉释文校注》[^yu-jiaozhu] 为准，本稿不臆补未核实者。

### 关键异文：《系辞》缺"大衍之数"章

见 [zhuan-xici.md](zhuan-xici.md) 文尾说明：帛书《系辞》**不分上下篇**，内容含今本《说卦传》前三章，而**无今本《系辞上传》"大衍之数五十"一章**（F-028）。[^zhang-jiaodu][^liao-boshu-lunji]

| 项目 | 内容 | 依据 |
|------|------|------|
| 来源 | 1994年春上海博物馆从香港文物市场购藏 | F-040 |
| 整理本 | 马承源主编、濮茅左释文考释《上海博物馆藏战国楚竹书（三）》，上海古籍出版社2003年 | F-041 |
| 规模 | 现存**58简**，涉及**34卦**，共**1806字**（含合文3、重文8、卦画25处） | F-042 |
| 形制 | 每卦占2至3简，简长约44厘米；**只有经文、没有传文** | F-043 |
| 年代 | 目前所见年代最早的《周易》写本，抄写约当战国晚期 | F-046 |

### 关键异文：阴爻"八"形与红黑首尾符

- 楚简卦画中**阴爻写作"八"字形**（非今本断线"--"式）[^shangbo-3]（F-044）。
- 每卦卦画**前后有红、黑两色六种"首符""尾符"标记**，为区分卦与卦、篇与篇、疑有篇章/等次之用的标志[^shangbo-3]（F-044）；其具体表义濮茅左另有专论[^shangbo-pu-maozuo]。

### 关键异文：残损与缀合（例）

残简、缺字在整理本中以"□"标出，本稿照录不补。可举两则已见于整理本的完整信息：

- 第**54简**保留有**抄手补抄脱漏字**的痕迹（F-045）。[^shangbo-3]
- 香港中文大学所藏一枚残简可与上博第**32简缀合**（F-045）。[^shangbo-3]

> **残损标注**：就具体卦爻辞的整条释文而言，凡简文残损之处，整理本均依形以残字作"□"、整字缺失作"（缺）"。本稿不引用未经核对整条释文；读者需逐条引文请以《上海博物馆藏战国楚竹书（三）》彩色图版与释文为据[^shangbo-3]。

### 卦序问题

上博残简卦序存在分歧（F-047）：濮茅左推测其卦序与通行本不同；李尚信、姜广辉、孙沛阳等学者主张残简卦序**同于通行本、且已分上下篇**。[^shangbo-pu-maozuo][^sun-peiyang-guaxu]

| 规模 | 易类碎简共**752片**、计**3119字**（其中经文约1110字、卜辞约2009字） | F-071 |
| 卦序 | 残破严重，**卦序无法复原** | F-071 |

| 整理本 | 韩自强《阜阳汉简〈周易〉研究》，初刊《道家文化研究》第18辑（2000），专著上海古籍出版社2004年 | F-074 |

### 关键异文

- 阜阳汉简**阴爻写作"八"字形**（与上博楚简同形，F-072）。[^han-fuyang]
- 阜阳汉简《周易》在**卦爻辞之后连属具体卜问事项的卜辞**，呈现**日常占筮实用格式**（F-073）：如以"卜病""卜求妇"等实用卜问为目连缀于卦爻辞后，与今本纯经文之体迥异。[^han-fuyang]

> **残损说明**：阜阳汉简皆为残片，断简处整理本以"□"与简号标注；本稿不逐简引录整条残文，具体残片释文以韩自强整理本为据[^han-fuyang]。

## 四、王家台秦简《归藏》（1993，湖北江陵王家台）

### 存佚著录

| 项目 | 内容 | 依据 |
|------|------|------|
| 出土 | 1993年江陵（荆州）郢北村王家台15号秦墓 | F-060 |
| 规模 | 易类竹简编号者164支、未编号者230支，合计**394支**、约4000余字 | F-061 |
| 卦画 | 存卦画70组（去重后54种） | F-062 |
| 卦名 | 存卦名76个（去重后53个） | F-062 |
| 定性 | 王明钦指出存在两种抄本；李家浩、廖名春、李零等认定其内容即《归藏》 | F-065 |

### 关键异文

- 秦简卦画**阴爻写作"∧"形**（与帛书、上博、阜阳各系统之"八"形阴爻形制不同，F-063）。[^wang-wangjiatai]
- 文例格式为**"卦画→卦名→'曰'→卜事之辞→卦辞"**（F-063）。[^wang-wangjiatai]
- **只有卦辞、没有爻辞**（F-064）；卦辞中多载古史占例，涉及**黄帝、炎帝、穆天子、周武王、羿**等人物（F-064）。[^wang-wangjiatai]

> **定性说明**：《归藏》为古文三易之一（《周礼·春官·大卜》，F-011/F-012）；王家台秦简《归藏》是《归藏》佚文的重要出土本，可与清人马国翰《玉函山房辑佚书》所辑《归藏》[^guicang-jiben] 对读。李家浩考据详见《王家台秦简〈易〉占为〈归藏〉考》[^li-guicang]。
