## 底本、字形与体例说明

- **底本**：（魏）王弼、（晋）韩康伯注，（唐）孔颖达等疏《周易正义》，以（清）阮元校刻《十三经注疏》本为文字基准（信源 `ruan-ke-shisanjing`）。
- **双源核对**：经文与所录传文经 [ctext.org](https://ctext.org/book-of-changes/zh)（底本《武英殿十三经注疏》本）与[维基文库](https://zh.wikisource.org/wiki/周易)逐字核对；分层抽样卦（乾、坤、屯、泰、谦、咸、既济、未济等）与《系辞》上下、《说卦》《序卦》《杂卦》全篇比对，记录见 [log.md](../log.md)。
- **字形**：正文采用现代规范汉字（与中华书局、上海古籍现代点校/译注本一致）；保留今本用字特征，如"无咎""无妄"用"无"（不用"無"），第三十三卦卦名作"遯"。出土本通假字（如帛书"键/川"）归入 [unearthed-variants.md](unearthed-variants.md)，不窜入今本经文。
- **经文界线**：上经、下经两篇（jing-shang.md、jing-xia.md，待补）只录卦辞与爻辞（经），不含《彖》《象》《文言》（传）；卦画符号（如 ䷀）据 ctext 所录 Unicode 卦象。
- **爻题体例**：每卦六爻自下而上为初、二、三、四、五、上；阳爻称"九"、阴爻称"六"。乾卦多"用九"、坤卦多"用六"。
