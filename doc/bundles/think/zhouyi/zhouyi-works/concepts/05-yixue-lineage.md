# 历代易学谱系

本文档依时序梳理易学研究的主要流派：汉易象数 → 魏晋义理 → 唐代义疏与集解 → 宋易图书与程朱 → 清代朴学 → 现代学术。诸流派立场各异、各有所长，本文档以并置方式呈现，不执一端。

## 汉易象数（孟喜、京房、郑玄、荀爽、虞翻）

汉代是象数易学的大本营。代表学者：

- **孟喜**（西汉）：卦气说的代表[^facts-114]。
- **京房**（西汉）：卦气说、纳甲、八宫卦序[^facts-114]。
- **郑玄**（东汉）：爻辰说[^facts-114]，兼注群经。
- **荀爽**、**虞翻**（东汉）：卦变、之正诸例[^facts-114]，虞翻尤其以博大的卦变体系著称。

汉代象数把卦爻系统与四时、方位、干支、月令乃至星历相配，建构起一套天人感应的宇宙图式，为后世象数派所宗。

## 魏晋义理（王弼、韩康伯）

王弼（226—249）主扫象数、阐义理，著《周易注》，开魏晋玄学解《易》风气[^facts-090]。其注未及《系辞》以下传文[^facts-090]；晋韩康伯（332—380）续注《系辞》《说卦》《序卦》《杂卦》，与王弼注合为通行注本系统[^facts-091]。

王弼以老庄玄理说《易》，其思想与《老子》注互有交涉，详见 `think/laozi/laozi-works` 的王弼相关条目。

## 唐代义疏与集解（孔颖达、李鼎祚）

- **孔颖达**（574—648）等奉敕撰《周易正义》，以王弼、韩康伯注为底本作疏，为唐代科举官学标准本[^facts-092]。
- **李鼎祚**撰《周易集解》，博采汉魏至唐三十五家《易》说（以荀爽、虞翻、郑玄、干宝等汉儒为主），是保存汉代象数易学最主要的文献[^facts-094]，为后世汉易之渊薮。

唐代"正义/义疏"与"集解"双轨并行：前者定于一尊（王弼注）、后者保存汉易遗说，为宋代以下分流张本。

## 宋易图书与程朱（陈抟、邵雍、程颐、朱熹）

- **图书易学**：以陈抟、邵雍为代表，传先天图、后天图、河图洛书之说[^facts-115]。
- **程颐主义理**：《伊川易传》以儒理、史事说《易》，不谈图书象数[^facts-095][^facts-115]。
- **朱熹兼收图书与占筮**：《周易本义》强调"《易》本卜筮之书"，恢复经传分列古本，同时兼容河洛图书[^facts-096][^facts-115]。

程颐与朱熹同为宋代易学重镇，但一义理、一兼收图书占筮，途辙不同，清人遂以"程传朱义"并尊而又判为两路。

## 清朴学（惠栋、张惠言）

清代朴学复兴汉易，致力于清理并复原汉代象数：

- **惠栋**（1697—1758）《周易述》，专主虞翻、荀爽，追复汉儒象数[^facts-098]。
- **张惠言**（1761—1802）《周易虞氏义》，专研虞翻一家之学，条理卦变、之正诸例[^facts-098]。

清朴学以训诂考据为方法，把汉易（尤其虞翻之学）重新确立为可研究、可复原的学问传统。

## 现代学术（古史辨派、出土学、哲学史）

20 世纪以来，《周易》研究出现多种进路：

- **古史辨派**：高亨"以经观经、以传观传"[^facts-100]，李镜池以筮辞、民俗解卦爻辞[^facts-101]。
- **义理/经学**：金景芳、吕绍刚主《易传》出于孔子、以义理说《易》[^facts-102]。
- **综合译注**：黄寿祺、张善文《周易译注》经传全译、兼采汉宋[^facts-103]。
- **象数+出土**：刘大钧《周易概论》兼采象数义理、重视出土文献[^facts-104]。
- **出土文献学**：廖名春以帛书、楚简论经传年代与作者[^facts-105]；李零从数字卦与出土易类文献考辨方术背景[^facts-106]。
- **哲学史**：朱伯崑《易学哲学史》（四卷）系统梳理汉—清—现代易学的范畴与思维方式，为易学哲学通史[^facts-107]。
