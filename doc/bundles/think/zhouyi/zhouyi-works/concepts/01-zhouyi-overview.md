# 《周易》名实与经传结构

《周易》是中国传统"五经""十三经"之首，其文本身份涉及"易""周易""易经"三名的分合，"经""传"二分的结构，以及成书年代的层累诸说。本文档并置各家立场，不作唯一断言。

## 易、周易、易经：三名之辨

- **易**：本为卜筮之书的总名。《周礼》以"三易"并称时，"易"既是类名（连山、归藏、周易统称三易），也可泛指该项学术[^facts-011][^facts-012]。
- **周易**：专指传世这部以"周"为目、以六十四卦为体的经典。"周易"之名，"周"或指周代/周王朝，或训"周普""周遍"；名实来源古来有分歧，此处不作裁断。
- **易经**：汉人尊经，称《易》为《易经》，《汉书·艺文志》六艺略著录"《易经》十二篇"[^facts-issue-006]。后世"易经"一词常与"周易"混用，但在严格的经学语境中，"易经"传统上指经文（卦爻辞）部分，或泛指经传合一的本子。

文本上，《周易》由**经**与**传**两大部分构成[^facts-001]："经"指六十四卦的卦辞与爻辞；"传"指秦汉间阐释经文的十篇文献（即"十翼"），详见 [十翼结构与归属](04-shiyi-ten-wings.md)。

## 经文结构：卦、爻、卦爻辞

- 经文共六十四卦，每卦六爻，合计三百八十四爻；乾卦另附"用九"、坤卦另附"用六"两条[^facts-002]。
- 六十四卦分上下两篇：上经三十卦（乾至离），下经三十四卦（咸至未济）[^facts-003]。
- 爻题自下而上为初、二、三、四、五、上；阳爻题"九"、阴爻题"六"，如"初九""六二""上九""上六"[^facts-004]。

通行本的编次与文字以三国魏王弼、晋韩康伯注、唐孔颖达等疏的《周易正义》系统为主流，清阮元校刻《十三经注疏》本为近代以后通行底本[^facts-008][^sources-ruan-ke]。

## "人更三圣"与成书年代的层累诸说

传统经学以《汉书·艺文志》"人更三圣，世历三古"为纲领[^facts-006]，形成成书配属的层累框架[^facts-007]：

| 作者配属（传统说） | 所著 |
|------|------|
| 伏羲 | 画八卦 |
| 周文王 | 重卦并作卦辞 |
| 周公 | 作爻辞 |
| 孔子 | 作十翼（传） |

这套"人更三圣（或三圣加周公为四圣）"之说本身经历了历史层累，各环节配属并无坚实的先秦内证[^facts-007]。

关于**成书年代**，学界诸说分歧较大，本文档并置不作断言：

- **传统经学立场**：经文成自文王、周公之手，传文成自孔子，即"经成先秦、传成春秋末至战国"。
- **古史辨派与现代出土学立场**：视卦爻辞为上古筮辞与史料之汇编，其写定年代可能在西周至春秋战国之间；高亨主张"以经观经"，不以后出传文附会经义[^sources-gao]。
- **出土文献冲击**：上博楚简《周易》抄写年代约当战国晚期，是目前所见最早的《周易》写本[^facts-046]，说明经文至迟战国晚期已有相当稳定的文本；帛书《周易》（西汉文帝初年抄写，下葬于前168年）则呈现另一套卦序[^facts-020][^facts-021][^facts-024]。

因此，本文档对"文王拘而演周易""周公作爻辞"等具体作者配属**不作单一断言**，仅如实记录传统说与辨伪说并存之局面。

> 关于"变卦之法"的表述：经文卦爻辞的体例如何编排（如上下篇分合、用九用六性质）应以文本实证为准，不宜以某家臆说作定论；详见 [文本系统与古三易](02-text-systems.md) 与 [核心概念](03-core-concepts.md)。
