| CAT-002 | 《汉志》著录房中八家：《容成阴道》26卷、《务成子阴道》36卷、《尧舜阴道》23卷、《汤盘庚阴道》20卷、《天老杂子阴道》25卷、《天一阴道》24卷、《黄帝三王养阳方》20卷、《三家内房有子方》17卷。 |
| CAT-003 | 房中小序原文（通行本）："房中者，情性之极，至道之际，是以圣王制外乐以禁内情，而为之节文。传曰：'先王之作乐，所以节百事也。'乐而有节，则和平寿考。及迷者弗顾，以生疾而陨性命。" |
| CAT-004 | 八家著录卷数合计为 191 卷；《汉志》小序总结作"房中八家，百八十六卷"（186卷），两者相差 5 卷，差异原因学界无定论，标待考（林富士《略論早期道教與房中術的關係》引《汉志》亦作"共計186卷"）。 |
| CAT-005 | 《汉志》房中八家原书全部亡佚，无一部传世；今所见题为《素女经》《玉房秘诀》等房中文献均非《汉志》著录之原书。 |
| CAT-006 | 《隋书·经籍志》医方类著录房中相关书目：《杂嫁娶房内图术》4卷、《彭祖养性经》1卷、又《彭祖养性》1卷、《玉房秘诀》10卷、又《玉房秘诀》8卷、又《新撰玉房秘诀》9卷、《素女秘道经》1卷（并《玄女经》）、《素女方》1卷、《郯子说阴阳经》1卷、《序房内秘术》1卷（葛氏撰）、《徐太山房内秘要》1卷（据高文铸《〈医心方〉房中养生文献述略》辑录）。 |
| CAT-007 | 《旧唐书·经籍志》著录《玉房秘术》1卷、《玉房秘录诀》1卷；《新唐书·艺文志》著录《彭祖养性经》1卷、《葛氏房中秘术》1卷、《冲和子玉房秘诀》10卷（据高文铸上文）。 |
| CAT-008 | 葛洪《抱朴子内篇·遐览》著录道经书目，其中房中书约 8 种：《玄女经》《素女经》《彭祖经》《陈赦经》《子都经》《张虚经》《天门子经》《容成经》（厦门大学学位论文《战国秦汉的房中文献概述》引述，皆为一卷本）。 |
| CAT-009 | 葛洪《抱朴子内篇·极言》有"黄帝论道养性，则资玄素二女"语，是"玄素"（玄女、素女）作为房中代称的早期出处之一。 |
| CAT-010 | 王充《论衡·命义》已有"素女对黄帝陈五女之法"的记述，张衡《同声歌》有"素女为我师，仪态盈万方"句，说明汉代素女传说已进入士人文学。 |
| CAT-011 | 《云笈七签》（北宋张君房编，1019年进上）卷一百《轩辕本纪》载黄帝"于玄女、素女受房中之术，能御三百女"。 |
| CAT-012 | 陶弘景（456-536）《养性延命录》2卷，卷下有《御女损益篇》，辑录晋唐间房中佚文；该书被《云笈七签》卷三十二全文收录。 |
| CAT-013 | 《汉志》小序以"乐而有节，则和平寿考；及迷者弗顾，以生疾而陨性命"确立房中论述的节欲框架，此框架为后世医家房中论述的基本基调。 |
| CAT-014 | 高文铸统计：汉、唐史志著录的房中书"没有一部能流传下来"，今天可见的汉唐房中文献主要靠《医心方》卷二十八等域外/类书引文保存。 |
| CAT-015 | "房中"在历代目录中的归属有迁移：《汉志》入方技略；《隋志》《两唐志》入医方类；《宋史·艺文志》以后房中专著基本退出官修目录。 |
| CAT-016 | 房中类文献在历代又有"阴道""养阳""接阴之道""玄素之术""黄赤之道""御女之术""房内"等异称；"房中"为《汉志》正式类目名。 |
