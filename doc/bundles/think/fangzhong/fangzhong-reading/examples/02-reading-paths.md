# 四条阅读路径——按兴趣进入房中文献

本束 9 篇概念文档不必通读。按学科兴趣选择路径，配合 [references/02 纸本版本指南](../references/02-print-editions.md) 取用文献。

## 路径 A：零基础通览（约 3 小时）

目标：建立"房中是什么、材料在哪里、哪些是真问题"的整体地图。

1. [00 房中是什么](../concepts/00-what-is-fangzhong.md)——界定与内容边界
2. [01 目录学史](../concepts/01-catalog-history.md)——《汉志》八家到退出官目
3. [02 出土文献](../concepts/02-excavated-texts.md)——马王堆改写成书史
4. [03 《医心方》与辑佚链](../concepts/03-yixin-fang-and-jiyi.md)——佚文如何保存
5. [08 辨伪方法与信源分级](../concepts/08-authenticity-and-sources.md)——识别网络陷阱

配套书：高罗佩《中国古代房内考》（商务 2007）通读 + 江晓原《性张力下的中国人》（华师大 2011）对照。

## 路径 B：中医与医学史方向

目标：房中在中医理论与养生文献中的位置。

1. [04 医家性医学](../concepts/04-medical-tradition.md)——《素问》天癸、《千金》房中补益、三元延寿四不可、求嗣种子线
2. [02 出土文献](../concepts/02-excavated-texts.md)——《胎产书》与求嗣线的源头
3. [03 《医心方》与辑佚链](../concepts/03-yixin-fang-and-jiyi.md)——医籍保存佚文的渠道（《外台秘要》《养生要集》）
4. 专题：刘鹏《被隐晦的历史关联：房中与中医》论文（2019）——房中与肾—髓—脑理论的知识关联

配套书：马继兴《马王堆古医书考释》（湖南科技 1992）；人卫影印《医心方》（1955/1993）。

## 路径 C：道教与内丹方向

目标：道教对房中"保存—净化—内丹化"的三重处理。

1. [05 道教房中](../concepts/05-daoist-fangzhong.md)——黄书合气、寇谦之改革、葛洪节宣论
2. [06 内丹清修与双修之争](../concepts/06-neidan-qingxiu-shuangxiu.md)——《参同契》《悟真篇》、南宗两系、东派西派、三家四派
3. [03 《医心方》与辑佚链](../concepts/03-yixin-fang-and-jiyi.md)——道教系统的佚文保存（《遐览》《养性延命录》《云笈七签》）
4. 专题：林富士《略論早期道教與房中術的關係》（中研院 PDF 公开）；胡孚琛《道学通论》丹道篇

配套书：陈国符《道藏源流考》（中华 1963）；Wile《Art of the Bedchamber》（SUNY 1992）含道教房中章。

## 路径 D：社会史与文学方向

目标：性观念、文学书写与图像材料。

1. [07 文学与社会史料](../concepts/07-literary-social.md)——《大乐赋》、明清小说、春宫版画的学术定位
2. [01 目录学史](../concepts/01-catalog-history.md)——房中在官方知识体系中的升降
3. 专题：高罗佩《秘戏图考》（1951 限印，图书馆查阅）→《中国古代房内考》明清章节 → 江晓原"性张力"修正说
4. 专题：刘达临《中国古代性文化》（宁夏人民 2003）通史参照

配套图像材料：P.2539 写本数字图像（e-Dunhuang，公开）用于文献学考察；春宫版画本束不提供链接，需在学术机构经正式渠道查阅。

## 通用建议

- 先读 [08 辨伪方法](../concepts/08-authenticity-and-sources.md) 再上网搜原文，可避开 90% 的网络陷阱；
- 任何"房中术教程/功法/姿势详解"类现代读物都不属于本束文献范围，也不代表古籍内容；
- 健康与生育问题以现代医学为准，古籍主张一律作文献登记。
