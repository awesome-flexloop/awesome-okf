# 房中典籍阅读教程

本知识包（bundle）是面向中文读者的**中国古代性文化（房中）典籍权威阅读指南**。"房中"之名始见《汉书·艺文志·方技略》，与医经、经方、神仙并列，是汉代国家知识分类中的正式方技门类；《汉志》著录房中八家共 191 卷（小序作 186 卷），但其原书后世全部亡佚。今天能读到的房中古籍，来自三条文本通道：**出土简帛**（马王堆三号汉墓《十问》《合阴阳》《天下至道谈》，下葬于公元前 168 年）、**域外医书引文**（日本丹波康赖《医心方》卷二十八《房内》，984 年成书，引《素女经》《玄女经》《玉房秘诀》《洞玄子》等汉唐佚文）、**清末辑佚**（叶德辉《双梅景闇丛书》，1903-1911 年，主要辑自《医心方》并补敦煌写本《天地阴阳交欢大乐赋》）。

本束覆盖**六层文献**：①目录著录与源流；②出土文献；③辑佚传世文献；④医家性医学；⑤道教房中与内丹；⑥文学社会史料与现代学术。所有在线全文链接均经核验，所有纸本指南均给出版社、年份与 ISBN；托名、辑佚、断代争议两说并陈。

## 🎯 内容边界声明

> **本知识包为学术史、文献学与社会史研究内容，研究对象为公版古籍与公开出版物。**
>
> 本束**不收录露骨描写，不提供任何性行为、养生术或内丹功法的实践操作指导**。古籍中"还精补脑""采阴益阳"等主张均属特定时代的历史文献，反映古人的知识与信仰，**未经现代医学验证，本束仅作文献学登记，不作功效背书或有效性判断**（FRG-114）。任何健康问题请咨询具备资质的现代医疗机构与执业医师。
