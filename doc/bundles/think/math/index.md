# 数学经典阅读知识包

本分组收录国外数学经典（古希腊—阿拉伯—欧洲传统）原著阅读教程，覆盖从欧几里得《几何原本》（约公元前 300 年）到布尔巴基《数学原本》（1939 年起）的经典谱系，回答三个问题：**原文在哪里获取**、**权威译本与注本如何选用**、**经典的核心数学思想如何理解**。
