# 国外数学经典阅读教程

本知识包是国外数学经典原著的**阅读教程与思想解读**：覆盖从欧几里得《几何原本》（约公元前 300 年）到布尔巴基《数学原本》（1939 年起）约 2300 年间 21 位数学家的代表性著作，回答三个问题——**原文在哪里获取**（公共领域数字图书馆）、**权威译本与注本如何选用**（Heath、Fitzpatrick、Blanton 等谱系）、**经典的核心数学思想如何理解**（五时段思想解读）。

所有外部链接均经实际检索验证（验证清单见调研留痕），现代版权译本仅作推荐、不复制文本。

## 快速开始

如果你从未读过数学经典原文：

1. 先读[为什么读数学原文](concepts/00-why-read-originals.md)，确认投入预期
2. 打开[最短上手路径](examples/02-first-originals-starter.md)，今天就读第一份（推荐 David Joyce《几何原本》网络版，无需外语）
3. 跟着[欧几里得精读示范](examples/01-euclid-close-reading.md)学会"命题三层读法"
4. 一个月后按[分阶段通读路线图](examples/03-reading-roadmap.md)进入系统阅读

如果你有本科数学基础、想理解思想源流：

1. 从概念 05–13 按顺序读，每篇先看"核心思想"一节
2. 遇到兴趣点，用每篇末尾的"原文入口"直接跳到免费扫描本
3. 配合[现代解读信源](references/modern-expositions.md)中的 MacTutor 传记与 Sandifer 专栏

如果你关心方法论迁移：

1. 读[架构洞察](insights.md)中的两个可迁移模式（三入口递进阅读法、版权三问决策法）
2. 这两个模式可直接迁移到哲学、物理学、经济学经典的原文阅读
