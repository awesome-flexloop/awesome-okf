# 注本分级与选用决策树

本文件登记「孔子相关著作阅读教程」所依据的**注疏层**文献（后人对经文的解释），与[权威底本信源](01-authoritative-editions.md)登记的**经文层**信源互补。本包概念文档引用注家观点时均注明注家与书名，关键章句至少呈现两种立场（今文 vs 古文、汉注 vs 宋注）。信源 URL 均出自[事实清单](../facts.md)。

## 三级注本体系

| 层级 | 名称 | 性质 | 适用读者 |
|------|------|------|---------|
| 一阶 | 注疏（汉唐古注） | 文言注疏，保存古训并建立义理正统 | 进阶读者、专题研究者 |
| 二阶 | 现代注译 | 现代学者的训诂整理与白话译注 | 一般读者建立文义 |
| 三阶 | 普及读本 | 白话讲读、选编，可读性强但学术性弱 | 入门读者 |

## 立场标注表

本包沿「今古文之争」（F-009~F-011）区分注家立场，读者据此判断每条解释的解释学位置：

| 注家/著作 | 立场 | 方法特征 |
|-----------|------|---------|
| 《公羊传》《穀梁传》及其注 | 今文 | 以解经为主，阐发微言大义（F-019） |
| 《左传》及杜预注 | 古文 | 以叙事为主，重在史实（F-019） |
| 郑玄注 | 兼采 | 以《鲁论》为基础参校《齐论》《古论》编校（F-055） |
| 何晏《论语集解》 | 汉学 | 集汉魏诸家古训 |
| 朱熹《论语集注》《诗集传》《周易本义》 | 宋学 | 汇理学义理，为元明以来科举基准 |
| 欧阳修《易童子问》 | 疑古 | 疑《系辞》《文言》非孔子作（F-048） |

## 三阶普及读本

ctext.org 提供白话译文页（如《论语》/zhs 页，见[权威底本信源](01-authoritative-editions.md)），可作「三阶普及」层快速查义；中国孔子网（chinakongzi.org）百科词条提供六经的通俗导读。三阶层不用于权威引用。

## 选用决策树

```
读孔子相关著作，选哪个注本？
│
├─ 目标：建立文义、快速读懂
│   └─ 二阶现代注译（杨伯峻《论语译注》《春秋左传注》等）
│
├─ 目标：理解义理体系 / 科举正统
│   └─ 一阶宋学（朱熹《论语集注》《诗集传》《周易本义》）
│
├─ 目标：查汉魏古训 / 经字本义
│   └─ 一阶汉学（何晏《论语集解》、郑玄注、毛传郑笺）
│
├─ 目标：厘清「孔子是否作某经」的辨伪问题
│   └─ 并列并读今古文两立场（F-009~F-011）+ 疑古注（欧阳修 F-048）
│
└─ 目标：权威引用 / 找异文
    └─ 经文层：ctext + 维基文库双源核对（见[权威底本信源](01-authoritative-editions.md)）
       注疏层：阮刻《十三经注疏》校勘本
```

> 本决策树为[洞察三·注家分层选用法](../insights.md)（可复用阅读模式三）的操作化落地：经文层／注疏层／现代解读层三者不混淆，按问题选用注本，关键章句强制并读 ≥2 种立场并标注出处。
