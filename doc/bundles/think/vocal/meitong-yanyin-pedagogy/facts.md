## 一、意大利咽音传统与术语源流

| 编号 | 事实内容 |
|------|---------|
| F-001 | "咽音"名称直接译自意大利文 Voce faringea（英文 pharyngeal voice）；林俊卿著述表述：咽音居于发真声与发假声之间，"真声、咽音和假声，每种都可以单独被应用"。[党媒·中国青年报转引林著](http://zqb.cyol.com/html/2012-05/16/nw.D110000zgqnb_20120516_1-12.htm) |
| F-002 | 英国歌唱家、声乐教育家 Edgar Herbert-Caesari（凯沙雷）在《The Musical Times》文章 "The Pharyngeal Voice"（1950）及著作《The Voice of the Mind》（1951）中使用 pharyngeal voice 术语翻译意大利文 voce faringea，并称该机制为老意大利学派培养了三百余年的特殊音质。[学术·维也纳音乐与表演艺术大学 Alexander Mayr 研究项目站](https://voce-faringea.com/index.html) |
| F-003 | 该机能在历史文献中的其他名称包括 voix pharyngienne、voix sur-laryngienne、faucet、voix mixte、voce mezzo falso、voce finta（feigned voice）、falsettone、Schlundkopfregister 等，被视为真声（胸声）与假声之间的过渡/混合机制。[学术·Mayr 与 Sundberg 合作论文](https://voce-faringea.com/wp-content/uploads/2015/06/Str%C3%B6mungsglottogramm.pdf) |
| F-004 | Mayr 研究（VOX HUMANA 12.2, 2016；专著《Voce faringea: Eine Kunst der Belcanto-Tenöre》，Bärenreiter 2018，ISBN 978-3-7618-2468-9）记述：该技法是 18 世纪至 19 世纪初 tenori di grazia（罗西尼—贝里尼—多尼采蒂时期优雅男高音）演唱超高音（《清教徒》至 F5）的手段。[学术·ResearchGate](https://www.researchgate.net/publication/305442585_Die_vergessene_Kunst_der_Belcanto-Tenore) |
| F-005 | 同研究记述：1837 年 Duprez 在巴黎唱出 ut de poitrine（胸声 high C）后，该技法随新男高音风格走向衰落。[学术·同上](https://www.researchgate.net/publication/305442585_Die_vergessene_Kunst_der_Belcanto-Tenore) |
| F-006 | 声乐史学者 Rodolfo Celletti 称阉人歌手之声为"强化的假声"；早期咽音男高音 Ansani、老 Manuel García 均曾师从阉人歌手。[西方声乐教学研究站·Belcanto Vocal Studio](https://www.belcantovocalstudio.co.uk/bel-canto/the-pharyngeal-voice) |
| F-007 | 林俊卿《"咽音"练声的八个步骤》书后附两篇译文：凯沙雷《一种被人忽略了的发音法——"咽音"》（林俊卿译）、维娜德《歌唱的机能与技巧》（林俊卿译）。[出版社·原书全文 PDF](https://media.saoyu.fun/%E5%92%BD%E9%9F%B3-%E5%85%AB%E4%B8%AA%E6%AD%A5%E9%AA%A4-%E6%9E%97.pdf) |
| F-008 | 林俊卿书引凯沙雷等著述称"咽音……产生于三百多年前意派的'黄金时代'"；并称"卡鲁索原嗓子很一般，他能成为世界著名的男高音歌唱家，百分之百归功于'咽音'练声法"。按：此为林著转引凯萨雷一脉说法，卡鲁索本人无含"咽音"字样的原著被直接核验，属转述链。[出版社·原书全文 PDF](https://media.saoyu.fun/%E5%92%BD%E9%9F%B3-%E5%85%AB%E4%B8%AA%E6%AD%A5%E9%AA%A4-%E6%9E%97.pdf) |
| F-009 | 林俊卿书引卡鲁索哼鸣经验："闭口唱法使嗓音增加灵活性，而又使声带得到休息……有些由于过度疲劳而毁坏了嗓音的人，是通过这种方法而恢复正常的"，注明出处为苏联那查连科编著《歌唱艺术》168 页（人民出版社 1981 年 8 月出版）。[出版社·原书全文 PDF](https://media.saoyu.fun/%E5%92%BD%E9%9F%B3-%E5%85%AB%E4%B8%AA%E6%AD%A5%E9%AA%A4-%E6%9E%97.pdf) |
| F-010 | 林俊卿书据卡鲁索夫人《卡鲁索的一生》记载：卡鲁索每天把口极端张大、把舌部伸出很长，对着镜子练发高的鼻音（林俊卿判为"事实上即是'咽音'"）。[出版社·原书全文 PDF](https://media.saoyu.fun/%E5%92%BD%E9%9F%B3-%E5%85%AB%E4%B8%AA%E6%AD%A5%E9%AA%A4-%E6%9E%97.pdf) |
