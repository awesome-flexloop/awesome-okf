# 信源参考索引

本目录登记"养生经典阅读"知识包所依据的文献信源，供示例与概念文档溯源引用。

| 信源文件 | 内容 | 对应文档类型 |
|---------|------|------------|
| [core-editions.md](core-editions.md) | 六部核心经典的推荐整理本、底本信息、出处类型与免费在线资源 | 一级文献/版本登记 |
| [modern-studies.md](modern-studies.md) | 现代研究与现代框架（官方素养文件、术语规范、影印丛书、世界记忆名录） | 现代视角 |
| [extended-reading.md](extended-reading.md) | 扩展脉络文献（食养/导引/道教养生/早期文献） | 扩展阅读 |

## 信源使用说明

- 全部事实依据集中于 bundle 根目录的 [facts.md](../facts.md)，本目录各文件只做信源登记与 URL 指向
- 概念文档通过 frontmatter 的 `sources` 字段引用信源
- URL 以 facts.md 登记的 Web 调研信源为准；facts.md 未登记、经本次 Web 核验补充的 URL 均在对应条目处注明
- 核心六部经典的成书、卷次、篇目、版本事实逐条编号于 facts.md 第一至六节；扩展脉络事实见第七至九节；现代研究视角见第十节
