## 一、《黄帝内经》（素问 + 灵枢）

| 编号 | 事实内容 |
|------|---------|
| F-001 | 《黄帝内经》由《素问》与《灵枢》组成，各 81 篇共 162 篇；素问今通行本 24 卷，灵枢今通行本 12 卷 |
| F-002 | 书名首见《汉书·艺文志·方技略》，著录"《黄帝内经》十八卷"；有学者据刘向、刘歆校方技（前 26 年）定为成书下限 |
| F-003 | 系托名"黄帝"而作，非一时一人之手的汇编 |
| F-004 | 成书年代有战国说、西汉说、东汉说等分歧；主流观点为主体成于战国至秦汉 |
| F-005 | 《素问》第七卷早佚；唐王冰（762 年注成）补入运气七篇大论并重新编次为 24 卷 |
| F-006 | 《素问》第 72、73 篇（《刺法论》《本病论》）原文已佚，世称"遗篇" |
| F-007 | 核心养生篇目：《上古天真论》"法于阴阳，和于术数，食饮有节，起居有常，不妄作劳"；《四气调神大论》"不治已病治未病" |
| F-008 | 今通行《素问》为明嘉靖二十九年（1550）顾从德翻宋刻本，底本经宋校正医书局林亿校正（1057） |
| F-009 | 《灵枢》由南宋史崧整理成今之定本，通行本为明赵府居敬堂刊本；现存最早刻本为元胡氏古林书堂刻本 |
| F-010 | 人民卫生出版社 1956/2015 年出版素问、灵枢影印本，1963 年出校勘排印本 |
| F-011 | 郭霭春主编《黄帝内经素问校注》（人卫 1996；中国中医药出版社 2023 第 2 版）广收 50 余种善本作校本 |
| F-012 | 2011 年《黄帝内经》列入联合国教科文组织《世界记忆名录》 |

## 二、嵇康《养生论》

| 编号 | 事实内容 |
|------|---------|
| F-014 | 嵇康（223-262，一作 224-263），字叔夜，谯国铚县人，三国魏文学家、思想家、"竹林七贤"之一，官中散大夫 |
| F-015 | 《养生论》为早期系统养生专论，约两千字，收入《昭明文选》卷五十三；又见《全三国文》卷四十八 |
| F-016 | 核心论点为形神相须："形恃神以立，神须形以存"；主张清虚静泰、少私寡欲、呼吸吐纳、服食养身 |
| F-017 | 以"精神之于形骸，犹国之有君也"设喻，列举情志影响形体的例证 |
| F-018 | 主张"导养得理，以尽性命"；又谓神仙"特受异气，禀之自然，非积学所能致" |
| F-019 | 论饮食嗜欲之害："饮食不节以生百病，好色不倦以致乏绝" |
| F-020 | 向秀作《难养生论》驳难，嵇康撰《答难养生论》回应，提出"嗜欲虽出于人，而非道之正" |
| F-021 | "养生五难"（名利不去、喜怒不除、声色不去、滋味不绝、神虑精散）见《千金要方》卷 27 引"嵇康曰" |
| F-022 | 《嵇中散集》现存最早刊本为明嘉靖四年（1525）黄省曾仿宋刻本，10 卷 |
| F-023 | 鲁迅以明吴宽丛书堂钞本为底本辑校《嵇康集》10 卷（1913-1931 年间校订，1938 年收入《鲁迅全集》第 9 卷） |
| F-024 | 戴明扬《嵇康集校注》1962 年由人民文学出版社出版 |
