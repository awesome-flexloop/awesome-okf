# 养生经典阅读教程

## 🚀 快速开始

如果你之前从未接触过养生经典：

1. 先读[为什么读养生经典](concepts/00-why-yangsheng.md)了解阅读价值
2. 再读[养生五脉谱系](concepts/06-schools-lineage.md)，建立五脉知识地图
3. 打开[零基础四周阅读计划](examples/02-reading-plan.md)，从《养生论》《上古天真论》等短小篇目起步
4. 按计划推进时逐部阅读[概念01-05](concepts/01-huangdi-neijing.md)的专论
5. 遇到选书问题时查[如何选读版本与注本](concepts/07-choosing-editions.md)
