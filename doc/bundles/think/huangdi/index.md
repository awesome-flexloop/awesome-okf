# 📜 黄帝经典（Huangdi）

本分组收录托名黄帝的经典知识包。首束为《黄帝阴符经》阅读教程——《阴符经》约四百余字，历代注疏逾百种，在道教经典中的地位仅次于《道德经》与《南华真经》。该知识包以正统道藏洞真部本文类白文本为底本，经 5 个在线信源逐字比对（25 处异文登记），诚实区分"托名层/文本层"，并以立场表呈现历代注家的多视角解读。
