# 权威原文全录（双源核对版）

《阴符经》无统一祖本传世，唐宋传抄刻本分化为多个异文系统，任取单本自称"原文"都会与另系冲突（I3，见 [架构洞察](../insights.md)）。本篇按**双源逐字核读法**（P1，见 [架构洞察](../insights.md)）制作：先定底本，再以多个独立在线信源逐字比对，建立字符级异文清单（V1–V31），异文加注、不改底本一字。

- **底本**：R7 中华文库《黄帝阴符经》——正统道藏洞真部本文类白文本，带章名 [R7]（F18：道藏白文经本属洞真部本文类 [R6][R7]）。
- **对校本**：R6 维基文库《黄帝阴符经疏》卷上/中/下（洞真部玉诀类疏本，经文以"疏曰"逐句夹注）[R6]、R3 维基文库《七注阴符经》（太公、张良、诸葛亮等七家注本）[R3]、R1 ctext.org《黃帝陰符經》（敦懷堂洋務叢鈔本七注經系統）[R1]、R8 藏外道书李筌《黄帝阴符经注》全文页（含李筌注经文与张果注经文两个 witness）[R8]。
- **异文数量说明**：facts.md F17 依五信源比对登记字符级异文 31 处（V1–V31）[R1][R3][R6][R7][R8]。本篇按 P1 第③步以实际抓取文本重新逐字比对，得**字符级异文 31 处（V1–V31）**，与 F17 登记数量一致；编号覆盖同句内拆分的微差异点，并纳入 R8 页内张果注 witness 的下篇异文（如"三返昼夜""擒之制在气"），如实按实际数量编号。

## 一、底本声明与整理原则

1. **底本**：R7 中华文库《黄帝阴符经》，即《正统道藏》洞真部本文类白文经本，一卷，撰人不详，带三章章名 [R7]。
2. **整理原则**：
   - 经文文字**以底本 R7 简体转录逐字照录**，包括底本用字"馀"（至乐性馀）、"气"（禽之制在气）等，一律不改；
   - 底本以句读号"。"断句，本篇保留底本全部标点，**分行系整理添加**，不增删一字；
   - 异体字如对校本之"炁"（R6、R1、R3）予以**保留并注明**，不回改为"气"；
   - 简繁转写对应字（馀/餘、沉/沈、历/曆等）不列为异文。
3. **对照原则**：**异文加注、不改字**——正文严格保持底本文字，一切异文进入第三节异文表，不在正文中混入他本文字。
4. **噪声判定**（本 bundle 归纳）：网页转录中的疑似 OCR/讹字（如 R3"天性入也"之"入"、R8"入封甲子"之"入封"）如实登记并标注疑讹，**不计为版本异文**；R8 页卷首白文与该页注文经文用字不一致，系同页两个不同抄录层，分别登记。

## 五、如何核对本文

1. **取底本**：打开 R7 中华文库《黄帝阴符经》（URL 见下），对照本篇第二节全录逐字核读——本篇分行与个别处句读为整理添加，文字（含"馀""气"等用字）应与 R7 完全一致。
2. **取对校本**：依次打开 R6 卷上/卷中/卷下、R3、R1、R8（两页），凡与本页不符处，先查第三节异文表是否已登记（表内"底本作/对校本作"两栏即对照结论）。
3. **发现新异文**：若发现异文表未登记的差异，先排除三类噪声——简繁转换对应字、网页 OCR 讹字（参照第四节判定）、标点/分行差异；确认属文字差异后按 V 编号续编登记至 [facts.md](../facts.md)。
4. **结构对照**：核对三章章名、"天生天杀"句位置、"我以时物文理哲"后的段落取舍与"自然之道静"尾附段（F2、F4、F5、F12）。
5. **延伸阅读**：异文系统与字数谱系的系统讨论见[文本与传本谱系](01-text-versions.md)；名句解读与异文的关系见[核心概念立场表](04-core-concepts.md)。
