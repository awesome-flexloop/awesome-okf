# 《黄帝阴符经》阅读教程

《阴符经》全文约四百余字，历代注疏逾百种，在道教经典中的地位仅次于《道德经》与《南华真经》（facts F33、F50–F52）。本知识包（bundle）是面向普通读者与研究者的《黄帝阴符经》系统中文阅读教程，特点有三：

1. **原文经 5 个在线信源逐字比对**——以正统道藏洞真部本文类白文本为底本，31 处字符级异文全部登记（V1–V31），不隐不改；
2. **托名层/文本层诚实区分**——经题托名黄帝，成书诸说并列呈现，不作单一裁决；
3. **解读以立场表呈现**——丹道、兵机、理学、佛家等注家立场并列，拒绝"标准答案"式转述。

## 🚀 快速开始

如果你之前从未读过《阴符经》：

1. 先读[什么是《阴符经》](concepts/00-what-is-yinfujing.md)了解经名由来与地位
2. 打开[七日通读计划](examples/02-seven-day-plan.md)，按第一天计划开始读原文
3. 通读一遍后，再回来看[权威原文全录](concepts/03-full-text.md)对照异文

如果你已读过通行本（或网络拼合本）：

1. 从[文本与传本谱系](concepts/01-text-versions.md)开始，理解三大异文系统
2. 读[核心概念立场表](concepts/04-core-concepts.md)，看"五贼""三盗"的多立场解读
3. 跟着[上篇名句多视角解读](examples/01-shangpian-reading.md)做立场表实操
4. 参考[注本分级表](references/commentaries.md)选择进阶注本
