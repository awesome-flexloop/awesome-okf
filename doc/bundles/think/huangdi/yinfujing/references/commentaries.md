# 注本分级表

《阴符经》注疏数量在道家道教著作中仅次于《道德经》与《南华真经》：唐《旧唐书·艺文志》著录唐代诠释六种，郑樵《通志略》著录三十九部，《正统道藏》收注本二十二种，吕坤统计历代注疏一百余种（F33）。注家身份（道士／兵家／儒家／医家／佛家）决定解经取径，"一书多解"是本经的常态（I2）。本表将常用注本按**入门／进阶／研究**三级分级，全部事实与信源编号以 [facts.md](../facts.md) 为准。

## 二、按学习目标的选用策略（本 bundle 归纳）

- **想读原文** → 从[中华书局三全本](#一三级分级表)入手，再回到[权威底本清单](core-texts.md)与[权威原文全录](../concepts/03-full-text.md)核对异文；
- **想懂丹道** → 张果《黄帝阴符经注》（F36 [R9]）、王道渊《夹颂解注》（F40 [R25]）、刘一明（清代龙门派内丹，见 F41；其五行相克说仅存转述辅证 [R27]）；
- **想懂兵机** → 《黄帝阴符经集注》（题太公、范蠡、鬼谷子、张良、诸葛亮、李筌等集注，F34 [R22]）与李筌注（"乘天杀之机，起陆而帝"等史例解，F46 [R8]）；
- **想研究文献** → 《子藏·阴符经卷》92 种汇印（F42 [R11]）＋ 王明定年研究（F27 [R16]）＋ 刘泳斯成书年代考（F31 [R15]），辅以《文献集成》前言梳理的著录线索（[R17]）。

## 三、托名注本阅读提醒

《黄帝阴符经集注》题太公、范蠡、鬼谷子、张良、诸葛亮、李筌等集注（中国兵学大系本列广成子至李筌十二家），属**托名注本**（F34 [R22]）。阅读此类注本时须保持"托名层"意识：署名与授受传说只作文化史陈述，注家立场不等于经文本义（呼应 I1，判读框架见 P2）。托名与成书诸说的完整并列，见[成书与作者之争](../concepts/02-authorship-debate.md)。
