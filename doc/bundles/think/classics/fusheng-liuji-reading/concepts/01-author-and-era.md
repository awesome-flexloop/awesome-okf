## 沈复其人与其时代

沈复，字三白，号梅逸，清代苏州府长洲县人，约生于乾隆二十八年（1763年），卒年无确载，学界并存卒于道光五年（1825年）之后与卒于道光十二年（1832年）之后等异说。他是《浮生六记》的作者，也是一生未曾应科举、以游幕与手艺谋生的"市井文人"。理解他的生平与时代，是读懂这部自传的前提。

## 生平时间线

| 时间 | 事件 |
|------|------|
| 约1763年（乾隆二十八年） | 生于苏州府长洲县 |
| 少年至青年 | 一生未应科举，以游幕（充当官府幕僚）、卖画、经商为生 |
| 成年后 | 娶表姐陈芸为妻（芸年长沈复十个月） |
| 1803年（嘉庆八年） | 陈芸因血疾去世，时年约四十一岁；育有一子逢森、一女青君 |
| 1808年（嘉庆十三年） | 随册封琉球国王正使齐鲲、副使费锡章出使琉球 |
| 1825年或1832年之后 | 卒年无确载，两说并存 |

## 乾嘉时期的江南游幕文人

沈复所生活的乾隆至嘉庆年间，是江南幕府文化极为兴盛的时期。所谓"游幕"，是指士人受聘于地方官府或官员幕中，充当处理文书、刑名、钱谷等事务的幕僚（俗称"师爷"）。对于没有取得功名或无意仕进的江南文人来说，游幕是介于"入仕"与"隐居"之间的一条常见生计之路。

沈复正是这条路上的典型一员。他以游幕为主业，兼以卖画、经商补贴生计，一生在苏州、扬州、汉口乃至海上之间流转。这种辗转幕府、漂泊江湖的经历，既成就了《浪游记快》卷中丰富的游历见闻，也构成了他经济拮据、聚少离多的家庭底色。

## "不科举的市井文人"的处境

在以科举为正途的传统社会中，沈复选择了一条"边缘"的生存路径：不参加科举考试，不追求功名，靠手艺与谋生技能活于市井。这带来两重后果——

- **经济上不稳定**：幕僚收入依附于人、时有时无，加上沈复不善经营，家庭常陷贫困，这在《坎坷记愁》卷中多有记载。
- **身份上"不上不下"**：他识文断字、通晓书画，具备文人的才情与趣味，却又没有功名身份，游走于文人圈与市井之间。

这种处境本身，正是乾嘉时期大批"落第文人"或"不仕文人"的共同写照。沈复的价值在于，他没有像多数同侪那样留下应酬诗文，而是把这种市井文人的真实生活写进了自传。

## 《浮生六记》作为"幕僚文人自传"的史料价值

在传统文献中，留下自传的往往是达官显宦、名儒硕学；像沈复这样"不科举的市井文人"能留下一部以自身经历为主线的完整自传，本身就极罕见。因此《浮生六记》具有独特的史料价值：

1. **社会史价值**：记录了清代中期江南下层文人的生计方式、游幕生态与家庭经济状况。
2. **家庭史价值**：详细书写了夫妻关系、亲子关系与亲族变故，是难得的婚姻家庭实录。
3. **文化史价值**：呈现了江南市井生活中的节日、饮食、游赏、园艺等日常文化细节。

当然，自传不等于客观史料——沈复的叙述带有个人记忆的选择与情感滤镜，使用时需与地方志、档案等外部史料互相参证。
