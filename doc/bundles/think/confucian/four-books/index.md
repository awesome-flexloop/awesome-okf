# 儒家四书阅读教程

本知识包（bundle）是儒家四书——《大学》《中庸》《论语》《孟子》——的阅读教程，目标是提供权威、可靠的原文与解读：

- **原文双源核对**：全部引文以 ctext.org 与 zh.wikisource.org 双源逐字核对为标准，底料登记于事实清单 F-066；单源文本单独标注，不作合并改动（F-067）
- **注家立场分开**：核心概念均呈现 ≥2 种注家立场（汉魏古注、朱熹理学、清代考据、现代译注），注明注家与书名；经文层、注疏层、现代解读层三层不混淆
- **文献学诚实**：朱熹补《大学》格物致知传属拟作、亲民/新民之辨、古本与改本之争等诠释史公案如实呈现，不断代裁断
