# 全书概览：五溺三变与真三不朽

王阳明（1472—1529），名守仁，字伯安，浙江余姚人，世称阳明先生（facts F1、F2）。读阳明生平，最忌把心学读成"龙场一夜顿悟"的传奇——本束以三个同时代或近源的框架组织其成学历程，再以"真三不朽"定位其历史地位，最后给出三线互证的读法。

## 一、五溺：成学经历（湛若水《墓志铭》）

湛若水与阳明同为明中期心学代表人物，其所撰《阳明先生墓志铭》总结阳明早年五段沉溺（fact F6）：

| 次序 | 所溺 | 对应人生阶段 |
|------|------|--------------|
| 初溺 | 任侠之习 | 少年尚气，15 岁间行出居庸关、逐胡儿骑射（fact F11） |
| 再溺 | 骑射之习 | 留心边事，26 岁精究兵法、聚果核列阵势 |
| 三溺 | 辞章之习 | 两次会试落第后归余姚结诗社，驰骋文辞 |
| 四溺 | 神仙之习 | 新婚日入铁柱宫与道士谈养生忘归（fact F9） |
| 五溺 | 佛氏之习 | 出入佛老，南京时期门人王嘉秀、萧惠好谈仙佛，阳明自警"吾幼时求圣学不得，亦尝笃志二氏" |

湛若水的结论是："正德丙寅（正德元年，1506），始归正于圣贤之学"——即下诏狱、谪龙场的那一年（fact F12）。五溺框架说明：阳明 35 岁前的精神世界是侠、武、文、仙、佛五度出入，并非单线直入圣学。

## 二、学三变：思想轨迹（黄宗羲《明儒学案》）

黄宗羲《明儒学案·姚江学案》评阳明"其学凡三变而始得其门"（fact F7）：

1. **始泛滥于词章**——辞章之学；
2. **继而遍读考亭（朱熹）之书，循序格物**——即 21 岁格竹事件（fact F8，格竹年龄另有 16 岁异说，登记不改字），"顾物理吾心终判为二，无所得入"；
3. **于是出入于佛、老者久之**——佛老消化期；
4. **及至居夷处困（龙场），动心忍性，因念圣人处此更有何道？忽悟格物致知之旨**——龙场悟道（fact F15）。

学案另有"学成之后三变"（默坐澄心→致良知→晚年圆熟）之说，本束从略，重点在"得其门"之前的三变。

## 三、教三变：教法展开（钱德洪）

阳明高足钱德洪总结其师教人方法的三次转变（facts F37、F30）：

| 阶段 | 地点与时间 | 教法 |
|------|-----------|------|
| 第一变 | 居贵阳时（1509 年前后） | 首论"知行合一"（fact F17） |
| 第二变 | 自滁阳后（1513 年督滁州马政后） | 多教学者静坐 |
| 第三变 | 江右以来（1521 年南昌始揭） | 单举"致良知"三字，直指本体 |

钱德洪说"是教之三变也"。加上嘉靖六年（1527）天泉证道的"四句教"（fact F32），阳明晚年教法有了最终的教典化表述。

> 三框架的关系：五溺是**经历层**（他走过哪些路），学三变是**思想层**（他如何想通），教三变是**教法层**（他如何教人）。三层互相对应：神仙佛氏之溺对应思想层的佛老出入，龙场悟道对应教法层的知行合一，百死千难的军政历练对应致良知的提出。

## 四、真三不朽：立德、立功、立言

《左传》以"太上有立德，其次有立功，其次有立言"为三不朽。方志远《"知行合一"与王阳明的"三不朽"》（光明日报）论阳明为少有的"真三不朽"者（fact F7 信源 R7）：

| 不朽 | 阳明的对应实绩 | 本束出处 |
|------|----------------|----------|
| 立德 | 龙场悟道、讲学授徒、教条四条（立志/勤学/改过/责善）；临终"此心光明"之境（异文登记） | [02 龙场悟道](02-longchang-awakening.md)、[04 晚年归宿](04-tianquan-and-final.md) |
| 立功 | 平南赣（1517—1518）、四十三天平宸濠（1519）、平思田与八寨断藤峡（1528）；《明史》评"终明之世，文臣用兵制胜，未有如守仁者" | [03 文治武功](03-shigong.md) |
| 立言 | 《传习录》、《王文成公全书》；知行合一、致良知、四句教；万历十二年（1584）从祀孔庙 | [04 晚年归宿](04-tianquan-and-final.md) |

卒后隆庆元年（1567，另有 1568 异说）追赠新建侯、谥文成，世称王文成公（facts F5、F35）。

## 五、三线互证读法

本束建议以三条线索交叉阅读，而非单线条讲故事：

1. **生平线（时间）**：1472 余姚出生 → 1506 下诏狱 → 1508 龙场 → 1517 南赣 → 1519 平濠 → 1521 揭致良知 → 1527 天泉证道 → 1529 卒南安（详见 [01 生平年表](01-life-chronology.md)）；
2. **思想线（命题）**：格竹困惑 → 吾性自足（1508）→ 知行合一（1509）→ 静坐（滁阳）→ 致良知（1521）→ 四句教（1527）；
3. **事功线（实践）**：龙冈书院教条 → 十家牌法/乡约/社学 → 平濠军事 → 忠泰之变的政治考验 → 思田八寨。

三线的咬合点正是心学命题的诞生现场：龙场绝境出"吾性自足"，贵阳书院讲"知行合一"，百死千难后揭"致良知"，出征前夜证"四句教"（facts F15、F17、F29、F32）。
