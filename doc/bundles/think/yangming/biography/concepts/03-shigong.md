# 文治武功：南赣平濠与思田

阳明事功集中在 1516—1529 十三年间：南赣平盗（1517—1518）、平定宸濠（1519）、征思田与八寨断藤峡（1527—1528）。三组事功不是单纯的军事行动，而是"剿抚并用、政教并举"的治理实验，其纲领即名言"破山中贼易，破心中贼难"（fact F24）。

## 一、巡抚南赣（1516—1518）

### 1. 受命与到任

正德十一年丙子（1516）九月，升都察院左佥都御史、巡抚南赣汀漳等处地方，由兵部尚书王琼特荐（fact F18）。正德十二年丁丑（1517）正月十六日至赣州开府。《年谱》记其到任即两手并施："入赣日，即选募民兵，行十家牌法。"（周建华《王阳明南赣活动年谱》据《王阳明全集》牌谕逐日系年，R15）

### 2. 三大战役与三县设立

| 时间 | 战役 | 结果 | 建制 |
|------|------|------|------|
| 1517 年二月（丁丑） | 平福建漳南寇（詹师富等，象湖山/长富村之役） | 旬月之间破巢 | 1517 年五月奏设福建**平和县**（fact F19） |
| 1517 年十月至十一月 | 破横水、桶冈诸寨 | 谢志珊（征南王）、蓝天凤就擒 | 1517 年十二月奏设江西**崇义县**，次年三月准奏（fact F20） |
| 1518 年正月至三月（戊寅） | 平广东浰头、大帽诸巢 | 池仲容就擒 | 1518 年五月奏设广东**和平县**（fact F21） |

平和、崇义、和平三县皆为奏设新县，县名寄寓"崇尚仁义、化民成俗"之意——军事之后即以行政建制固化治理。

### 3. 治理三件套：十家牌法、乡约、社学

**十家牌法**（1517 年正月即颁）：到任即颁《十家牌法告谕各府父老子弟》《案行各分巡道督编十家牌》（fact F22）。十家为一牌，逐户登记户籍人口、职业、去向，轮日告知，互相保任；一面清查奸宄（防止贼寇内应），一面申明孝悌和睦。这是把"心贼"之防落实到基层编户的制度设计。

**《南赣乡约》**：平定之后推行的乡规民约组织。龚文瑞《王阳明与〈南赣乡约〉》（R16）考其参酌北宋陕西蓝田《吕氏乡约》（熙宁九年，1076，我国最早村规民约）改造而成；邹守益《南赣乡约后语》原文："此中丞阳明王公参酌蓝田乡约，以协和南赣山谷之民也"（fact F23）。乡约设约长、约史，会众讲约，彰善纠过。

**兴举社学**：正德十三年戊寅（1518）四月班师后即颁《兴举社学牌》，《年谱》："四月，班师，立社学"；同年九月整修赣州濂溪书院（后更名阳明书院）（fact F23）。又有《训蒙大意示教读刘伯颂等》论童蒙教育当"顺导其志意，调理其性情"，反对鞭挞绳缚。

> 十家牌法（编查防奸）—乡约（成人道德自治）—社学（童子教化）构成"破心中贼"的三层制度：从外层的治安管控，到中层的乡党自治，到底层的童蒙教育。

## 二、"破山中贼易，破心中贼难"

出处为《王文成公全书》卷四《文录一·与杨仕德薛尚谦》书（e-yangming 原文，R10；张昭炜《中华读书报》2025 引录，R17）：

> "某向在横水，尝寄书仕德云：'破山中贼易，破心中贼难。'区区剪除鼠窃，何足为异？若诸贤扫荡心腹之寇，以收廓清平定之功，此诚大丈夫不世之伟绩。"

要点登记（fact F24）：

- 此语是**书札**中的话（写给弟子杨骥、薛侃），非军令文告；
- "山中贼"指横水、桶冈、浰头诸寨，"心中贼"指人心之贪欲与寇乱之源；
- 【系年异说】柯兆利《阳明"破心中贼"新解》与张昭炜文系于正德十二年丁丑（1517）；束景南《王阳明年谱长编》考证系于正德十三年戊寅（1518）——两说并列登记，不改字。

## 三、四十三天平宸濠（1519）

### 1. 事变与起兵

正德十四年己卯（1519）六月，宁王朱宸濠在南昌起兵反叛。六月十五日阳明奉敕勘处福建叛军，行至丰城闻变，立即返回吉安起义兵（fact F25）。《年谱二》（R2）逐日载其调度：伪撒援兵、檄列郡兵、集伍文定等郡县官。

### 2. 作战时序

| 日期（己卯） | 行动 |
|--------------|------|
| 六月十五 | 丰城闻变，返吉安 |
| 七月十三 | 率伍文定等发吉安 |
| 七月十五 | 樟树镇会兵 |
| 七月二十 | 乘虚直拔南昌（宁王巢穴） |
| 七月二十四 | 黄家渡之战，叛军回救 |
| 七月二十五 | 八字脑之战 |
| 七月二十六 | **获宸濠于樵舍，江西平** |

《年谱》："二十六日，获濠于樵舍，江西平。"（fact F25）

### 3. 纪功碑

正德十五年庚辰正月晦（1520 年正月三十），阳明于庐山开先寺读书台壁书《平定宸濠纪功碑》摩崖（e-yangming 录文，R11；纪念馆杨德俊文亦据摩崖校录，R9）：

> "正德己卯六月乙亥，宁藩宸濠以南昌叛，称兵向阙……七月辛亥，臣守仁以列郡之兵复南昌，宸濠还救，大战鄱阳湖。丁巳，宸濠擒。"

【异说登记】通行作历时 43 天（六月十五闻变至七月二十六擒濠），e-yangming 注"也有说 35 天"——两说并列（fact F27）。碑文干支纪日与《年谱》干支小异（乙亥/辛亥/丁巳），本束并存不校改。

### 4. 忠泰之变

平濠之后，阳明遭遇政治险境（fact F28）：

- 武宗朱厚照已自称"威武大将军"亲征，张忠、许泰等幸臣欲争功、进谗言（史称"忠泰之变"）；
- 阳明将宸濠交付太监张永，称病避居杭州西湖净慈寺；
- 纪功碑刻意归功朝廷（"于赫皇威！神武不杀"），纪念馆考订指出碑中时间叙事有回护之笔；
- 《明史·王守仁传》总评："终明之世，文臣用兵制胜，未有如守仁者也。"

平濠与忠泰之变的"百死千难"体验，正是后来"致良知"之教的直接背景——《年谱二》："自经宸濠、忠、泰之变，益信良知真足以忘患难，出生死"（fact F29）。

## 四、晚年：思田与八寨断藤峡（1527—1528）

嘉靖六年丁亥（1527）五月，阳明起复总督两广兼巡抚，征广西思恩、田州（fact F32、F34）：

| 时间 | 事功 |
|------|------|
| 1527 年九月 | 发绍兴；出征前夜有天泉证道，途中有严滩问答（见 [04](04-tianquan-and-final.md)） |
| 1528 年二月（戊子） | 思恩、田州土酋卢苏、王受受抚，思田平（以抚为主） |
| 1528 年七月 | 乘胜袭破八寨、断藤峡（长期未平的僮瑶起事据点） |
| 1528 年十月 | 上疏请告，不报；因肺疾日重，不待命而东归 |
| 1529 年 1 月 9 日（戊子十一月二十九） | 行至江西南安府青龙铺，卒于舟中（见 [04](04-tianquan-and-final.md)） |

南赣与广西的治理思路一脉相承：军事行动之后必随行政设县、乡约社学——"破山中贼"之后即着手"破心中贼"。这也是阳明事功与其心学实践不可分割的根本原因（参见 [00 概览](00-overview.md) 三线互证读法）。
