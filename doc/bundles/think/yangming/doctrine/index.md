# 阳明心学教义体系——心即理·知行合一·致良知

王阳明（1472–1529），名守仁，字伯安，号阳明，浙江余姚人，世称阳明先生，明代哲学家、军事家、教育家，姚江学派（阳明学）开创者（facts F1）。其教义体系的载体主要是《传习录》三卷与《大学问》：《传习录》卷上为徐爱、陆澄、薛侃所录，卷中为阳明亲笔书信（答顾东桥书、答陆原静书等），卷下为陈九川、黄直（字以方）、黄修易、黄省曾、黄以方诸门人所录并钱德洪跋；《大学问》为嘉靖丁亥（1527）阳明起征思田前口授、钱德洪录成的"师门之教典"（facts F2–F3）。本知识包（bundle）面向普通读者与研究者，特点有三：

1. **命题与年代双轴组织**——五大命题（心即理、知行合一、致良知、四句教、万物一体）各有形成节点：正德三年戊辰（1508）龙场悟道"圣人之道，吾性自足"，正德四年己巳（1509）贵阳始论知行合一，正德十六年辛巳（1521）南昌"始揭致良知之教"，嘉靖六年丁亥（1527）天泉证道四句教与《大学问》口授（facts F6–F9）；
2. **核心引文双源逐字核对**——全部关键语段以维基文库《传习录》三卷、《大学问》（《王文成公全书》系统文本）为第一信源，以高校古籍所、学术论文、《年谱》数字化文本为第二信源逐字比对；异文（四句教"无善无恶是心之体/无善无恶心之体"、"见满街人都是圣人/满街都是圣人"）登记不改字（facts F9、F24）；
3. **录者分节与文本层级声明**——卷下各条标注录者归属（岩中花树属黄省曾录第二十八条，天泉证道首见《传习录下》与《年谱三》两处），《大学问》为口授记录、《传习录》卷中为亲笔书信，层级分明（facts F2–F3、F13）。

## 🚀 快速开始

如果你之前从未接触过阳明心学：

1. 先读[教义体系总览](concepts/00-overview.md)，了解《传习录》三卷与《大学问》的文本结构
2. 读[心即理与心外无物](concepts/01-mind-is-principle.md)，抓住"心即理"这个全部教义的立足点
3. 打开[义理地图](examples/01-doctrine-map.md)，按图把握五大命题的年代推进与格物新训贯穿线

如果你已有儒学或中国哲学基础：

1. 从[致良知](concepts/03-innate-knowing.md)开始，对照《大学问》"致吾心之良知焉耳"
2. 读[四句教与万物一体](concepts/04-four-sentence-teaching.md)，理解天泉证道"二君相取为用"的判教
3. 读[格物与《大学》](concepts/05-investigation-of-things.md)，辨明朱王格物分歧与《大学》古本/改本之争
4. 对照[事实清单](facts.md)的信源表逐条核对原文
5. 参考[信源登记](references/sources.md)选用维基文库《传习录》白文作研读底本
