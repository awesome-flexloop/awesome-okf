## 五、选用策略

1. **研读**：《王文成公全书》本《传习录》三卷 + 《大学问》（维基文库白文）——卷下随条标注录者，卷中注意亲笔书信体。
2. **检索**：维基文库白文 + ctext《孟子》对读；年代节点查识典古籍《年谱》。
3. **核对**：任何引文至少两个跨系统信源核对（原典库 × 高校/学术信源）后方可引用；通行引述与原文差异登记不改字。
4. **避坑**：不以名句站/百科转述替代原文（"满街都是圣人"省"见"字、"无善无恶心之体"省"是"字）；不把卷下语录与卷中亲笔书信的文本层级混同；不把龙场悟道误述为致良知之悟（致良知 1521 年始揭）。
