## 五、选用策略

1. **研读**：以中华书局点校本《明儒学案》为分派骨架，配《王阳明全集》本《传习录》；争议处取《学蔀通辨》《困知记》《尚书引义》原书对勘。
2. **检索**：第一层原典全文库核对原文，第二层学术媒体核对观点出处，第三层百科/PDF 仅作旁证与线索。
3. **核对**：任何关键引文至少两个独立信源核对后方可引用；信源类型须为"原典全文 + 学术论文"组合，不以两个百科词条互证充数。
4. **避坑**：① 判词读立场——黄宗羲"惟江右为得其传"出自蕺山—江右正统观，不与泰州、龙溪文献混为定论；② 接受史不回挂——日本阳明学的行动化读法（"事业元素"、志士实践）属再诠释，不当阳明本义引用；③ 近代叙事分层——"明治维新精神动力"为倡导说与质疑说并存的建构层议题，引用时须标注所持一说；④ 政治人物文献只登记文本事实与各自立场，不作师承或因果判断。
