# 三级书单与五阶段进学路径

本页给出王阳明心学谱系的研读路线：先按"白文—学案—研究"三级备料，再按五阶段推进。全部底本选择与信源分级见 [信源登记](../references/sources.md)；本束争议处（《朱子晚年定论》性质、明治维新叙事、"阳明学"名称源流、天泉证道真伪、格竹系年）均须对勘 ≥2 说，不采单断言。

## 一、三级书单

| 书 | 说明 |
|----|------|
| 《传习录》白文 | 阳明语录主体，先通读不看注；配合概念页 [02 朱王之辨](../concepts/02-zhu-wang-divergence.md) 读格竹、古本诸条 |
| 《大学》古本 | 与朱子改本对读（facts F13），理解格物之争的文本焦点 |

## 三、研读方法提示

1. **异文不改字**：遇到陆九渊卒年（1192/1193）、大盐生年（1793/1794）、西乡生年（1826/1828）、藤树转信年龄（32/37 岁）、格竹系年（21 岁/十五六岁）等异文，照录两说并标注出处（参 [facts.md](../facts.md) F5、F12、F30、F31）。
2. **判词读立场**："惟江右为得其传""泰州龙溪跻阳明而为禅"均出自黄宗羲特定立场，须与被批评方文献对读，不单独引为定论。
3. **引文双源核对**：凡引用关键原文（如"以明心见性之空言，代修己治人之实学"、"销行以归知"），先按 [log.md](../log.md) 双源核对清单确认，再用 [信源登记](../references/sources.md) 的在线全文库复核。
4. **跨束衔接**：本知识包规划中的**束1（阅读计划束）**将给出逐周诵读日程，**束3（实践手册束）**将给出致良知功夫的日常操练法；本页仅为谱系研读路径，待两束建成后衔接使用。
