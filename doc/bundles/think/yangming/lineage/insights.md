# Insights — 王阳明心学谱系束洞察与模式（I/E 阶段 · G2/G3）

## 洞察（G2 四元组：现象/根因/影响/建议）

### I1 阳明学的"两次下行"：泰州民间化与日本志士行动化，同构地放大行动性、也同构地招致流弊之讥
- 现象：第一次下行在晚明——王艮以灶户布衣倡"百姓日用即道"，泰州一脉"多能以赤手搏龙蛇"，传至颜山农、何心隐"遂复非名教之所能羁络"（facts F19、F21、F22）；第二次下行在江户末至幕末的日本——中江藤树以下，大盐平八郎起义、吉田松阴、西乡隆盛、高杉晋作等志士以阳明学练心胆、蹈死生（facts F30、F31）。两次下行都把阳明学从书斋推向民间与行动，也都在当时及后世招来"狂禅""异端""以学乱政"一类批评（facts F19、F27、F32）。
- 根因：阳明"心即理""知行合一""致良知"把道德判断的根据收归当下本心，天然弱化外部经典与阶序的中介；此结构在民间语境中被读作"百姓日用即道"的平民化命题，在革命/维新语境中被读作"知行合一"的行动哲学——接受端按自身需要放大了同一组命题的行动性维度。
- 影响：两次下行构成阳明学传播史上影响最大的段落（"风行天下"与"明治维新精神动力"叙事均由此而来），也使"阳明学"在明清易代与日本近代两个节点上都被部分论者视为需对风气负责的靶子；流弊叙事与动力叙事一体两面。
- 建议：讲述下行史时两端并陈——既登记"风行天下/维新动力"的倡导说（三岛由纪夫、章炳麟、梁启超、高濑武次郎），也登记现代学界的建构性质疑说（沟口雄三、邓红、吴震）（facts F32、F33）；不以后学流弊反疑阳明立教本旨，也不以立教本旨替接受史的再诠释背书。

### I2 "本体提掇过重 → 功夫悬空 → 救正"的三段循环，在王门内部与外部反复出现
- 现象：龙溪四无说把心体推至"无善无恶"，江右聂豹以"归寂"、罗洪先以"摄于寂静"救正；泰州以现成良知行乎日用，刘宗周以"慎独""诚意"从心学内部补正，东林顾宪成、高攀龙以朱子学读书穷理从外部夹持，顾炎武、王夫之更以"实学"全面纠弹（facts F17、F20、F23、F26、F27、F28、F29）。黄宗羲的判词精确描述了这一张力："有泰州、龙溪而风行天下，亦因泰州、龙溪而渐失其传"（fact F19）。
- 根因：四句教"无善无恶是心之体"与"为善去恶是格物"之间本含本体与功夫的张力；重本体者易得"简易直截"之效也易滑向玄虚冒认，重功夫者能踏实却可能被讥为"支离"——这正是朱陆之辨在王门内部的重演（鹅湖"尊德性/道问学"之争，facts F6、F7）。
- 影响：王门各派的分化表面是师承地域之别（浙中/江右/泰州），实质是本体-功夫配比之争；读谱系若只按地域标签归类，会把命题分歧误读为地方学风。
- 建议：后学部分按"命题分歧"而非"地域名录"组织——每派登记其核心命题（四无/四有、归寂通感、百姓日用、止修）与对本体-功夫张力的回答；判词（如"惟江右为得其传"）注明判词作者的立场（黄宗羲承蕺山-江右正统观），与被评一派的自有文献对读。

### I3 "阳明学为明治维新原动力"与"阳明学"名称，都是近代建构层，须与学术研究层分判
- 现象：19 世纪末日本出现三宅雪岭、高濑武次郎、井上哲次郎等倡导的阳明学热潮与《阳明学》杂志（1896 年吉本襄创刊），"阳明学是明治维新原动力"叙事随之形成并经梁启超、章太炎、张君劢等返销中国；现代学界（沟口雄三"两种阳明学"、邓红"社会运动说"、吴震"名称回流说"）指出该叙事含学术建构成分（facts F32、F33）。
- 根因：近代化转型期需要本土精神资源与行动哲学，日本国粹主义运动借"阳明"之名塑造"国民道德"，中国变革者则借日本成功叙事反哺国内动员；名称与叙事都是接受史的产物，而非明代思想的自明标签——明代人称"姚江之学""王学"，"阳明学"作为学科名称定型于 19 世纪末的日本。
- 影响：把建构层叙事当成史实层断言，会高估阳明学对明治维新的直接因果权重，也会把日本"心本主义"的行动化读法回挂到阳明本人的"理本/心本"结构上（沟口所谓中日"两种阳明学"之异）。
- 建议：概念使用上分三层——①明代的"姚江之学/王学"（史实层）；②19 世纪末日本的"日本阳明学"社会运动（建构层）；③战后至今的王阳明哲学思想研究（学术层）；引用维新叙事与名称由来时一律并列 ≥2 说（facts F32、F33 已作三说并列）。

### I4 调停性文本必先过文献关：《朱子晚年定论》触发考据反弹的教训
- 现象：阳明 1515 年成《朱子晚年定论》、1518 年刊行，摘朱子书信三十四封证朱陆"晚同"；罗钦顺当即致书指出所取何叔京书实为早年之作，陈建 1548 年成《学蔀通辨》四编十二卷系统反驳，指其"颠倒早晚，矫诬朱子，以弥缝陆学"（facts F14、F15）。
- 根因：调停朱陆的动机属义理层策略，而摘编文献属考据层操作；以义理需要剪裁文献早晚，在考据成熟的明代语境中必然触发文献学反弹——罗钦顺、陈建的批评武器正是考据本身。
- 影响：《晚年定论》成为思想史上"调停反致分裂"的典型案例；它也提示，朱王之争的核心在义理结构（心即理/性即理、格物内向/外向），文献早晚之辩只是外围。
- 建议：处理思想史上的"调和文本"时双轨登记——义理动机（调停两可、引朱就王）与考据结论（择取失当、早晚颠倒）分属两层，两说并列不裁决（fact F16）；今人引用《晚年定论》须同时标注罗钦顺、陈建的反驳文献。

## 可复用模式（E · G3）

### P1 学派源流图绘制法：师承-命题-分化三维并录，争议旁注
- 触发场景：整理任何思想家的后学派系（王门七派、儒家道统、佛学法脉等）知识时。
- 核心步骤：①**师承维**：录亲炙/私淑/再传关系与关键年代（如王艮 1520 年师事阳明、聂豹殁后称门人）；②**命题维**：每派录一句核心话头（四无/四有、归寂以通感、百姓日用即道、止修），不录空泛门派名；③**分化维**：录分化触发事件与争议点（天泉证道、狱中悟归寂、以知为体之辩）；④**旁注**：判词注明立场来源（黄宗羲"惟江右为得其传"出自《江右王门学案》序，承蕺山-江右正统观），异文异说（生卒年、系年）登记不改字，悬案（天泉证道真伪）标注不裁决。
- 反模式：只画师承树不录命题，把地域标签当思想差异；直接搬用某一派的判词作为全谱定评；静默统一生卒年异说。
- 迁移示例：本 bundle [concepts/00-overview.md](concepts/00-overview.md) 的 mermaid 总图与 [concepts/03-disciples-schools.md](concepts/03-disciples-schools.md) 的四派对照表均按三维组织。

### P2 概念旅行的"双端原典"读法
- 触发场景：追踪一个思想命题跨地域/跨时代传播（知行合一在日本、良知在朝鲜、敬天爱人在企业界）时。
- 现象依据：同一命题在原产语境与接受语境含义会偏移——"知行合一"在明代是道德修养论（一念发动处便即是行），在幕末日本被读作行动哲学与革命心法，在孙中山处则被批评为"不合于实践之科学"并代以"知难行易"（facts F30、F31、F36）；"敬天爱人"在中国典籍中本无此固定搭配，其社训形态出自西乡隆盛书法（facts F35）。
- 核心步骤：①读原产端原典，登记命题的原始含义与语境；②读接受端文献，登记再诠释的内容与再诠释者的处境；③双端对照，显式标注"偏移点"；④禁止把接受端读法回挂原作者；⑤接受端的社会效果（维新、创业）与命题本身分两层陈述。
- 反模式：见日本志士讲阳明学便断言"阳明学导致明治维新"；见企业家用阳明语录便追溯为"阳明本人的管理思想"。
- 迁移示例：本 bundle [concepts/05-east-asia-modern.md](concepts/05-east-asia-modern.md) 日本、朝鲜、稻盛三节均按双端结构书写。

### P3 争议论断登记法：≥2 说并列、各自给信源、事实层不裁决、洞察层再提炼
- 触发场景：遇到学术史上尚无定论、且各方都有文献支撑的论断（《晚年定论》性质、明治维新影响强度、"阳明学"名称源流、格竹系年、天泉证道真伪）时。
- 核心步骤：①在 facts 层以"两说并列/三说并列"格式登记，每说标注持者与信源键（如 F16 甲说 [R12]、乙说 [R13]）；②异文（生卒年、系年、引文用字）登记不改字；③事实层全文禁用单向裁决措辞；④在 insights 层才允许提炼模式（如 I3 的"建构层/史实层/学术层"三分），且提炼结论仍须回指事实层的并列登记；⑤正文概念页引用时复述并列结构，不取巧单说。
- 反模式：择一说明示或暗示为定论；以"一般认为"掩盖未核对的单源；把异文直接改成通行写法。
- 迁移示例：facts F5、F12、F16、F18、F30、F31、F32、F33 均按本模式登记；concepts 02/04/05 各设"争议并列"小节。
