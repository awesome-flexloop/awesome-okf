# 思想远源：孟子、陆九渊与白沙甘泉

阳明心学不是凭空而起。其远源可分三层：先秦孟子的良知话头（fact F1）、南宋陆九渊的心学开山（F2–F7）、明中期陈献章与湛若水的岭南心学（F8–F10）；阳明本人早年则经历泛滥词章、遍读考亭、出入佛老的"学凡三变"（F11）。

## 一、孟子：四条话头的先秦渊源

阳明"良知""致良知""立大体"的话头均可上溯至《孟子》四条原文（fact F1，[G] 原典常识）：

| 话头 | 《孟子》原文 | 篇名 |
|------|--------------|------|
| 良知良能 | "人之所不学而能者，其良能也；所不虑而知者，其良知也。" | 《尽心上》 |
| 万物皆备 | "万物皆备于我矣。反身而诚，乐莫大焉。" | 《尽心上》 |
| 求其放心 | "学问之道无他，求其放心而已矣。" | 《告子上》 |
| 先立其大 | "先立乎其大者，则其小者不能夺也。" | 《告子上》 |

> 读法提示：孟子论"良知"本指孩童爱亲敬长的先天道德情感，阳明将其提升为贯通心物的本体概念；"万物皆备于我"在孟子处是反身而诚的修养境界，阳明后学（尤其泰州、龙溪）将其与"心外无物"命题相接。读源头须注意概念在后代的扩容。

## 二、陆九渊：心学开山与鹅湖之会

**陆九渊**（1139—1193），字子静，号象山，江西抚州金溪人，乾道八年（1172）进士，南宋心学开创者，学者称象山先生（fact F2，[R1][R3]）。卒年有异文：《中国历代大儒》系于 1192 年，百科系于绍熙三年十二月（即公历 1193 年 1 月）——异文登记不改字（fact F5）。

核心命题：

- **"宇宙便是吾心，吾心即是宇宙"**（百科引《陆九渊全集·卷二十二》，fact F3，[R1]）；
- 十三岁悟"宇宙内事乃己分内事，己分内事乃宇宙内事"，并言"东海有圣人出焉，此心同也，此理同也；西海……南海北海……此心同也，此理同也"（杨简《象山先生行状》，fact F4，[R2]）。

**鹅湖之会**（fact F6，[R4][R5]）：

| 项 | 内容 |
|----|------|
| 时间地点 | 南宋淳熙二年（1175）六月初，信州（今江西上饶）鹅湖寺 |
| 主持 | 吕祖谦，意在调和朱陆 |
| 朱方主张 | "道问学""即物而穷其理""泛观博览而后归之约" |
| 陆方主张 | "尊德性""先发明本心""先立乎其大" |
| 相互批评 | 朱讥陆为禅；陆讥朱"支离"，和诗有"易简工夫终久大，支离事业竟浮沉"句 |
| 结局 | 辩论三日，不欢而散 |

黄宗羲《宋元学案·象山学案》总评："先生之学，以尊德性为宗……同时紫阳之学，则以道问学为主"（fact F7）。朱陆鹅湖之争的"道问学/尊德性"张力，在三百年后以朱王之辨的形式重演（见 [02 朱王之辨](02-zhu-wang-divergence.md)）。

## 三、陈献章与湛若水：岭南心学

**陈献章**（1428-11-27—1500-03-09），字公甫，号石斋，学者称白沙先生，广东新会人，师吴与弼，筑春阳台静坐多年，创江门学派（岭南学派），主"静中养出端倪"（一作"静坐中养出端倪"），有"天地我立，万化我出，宇宙在我"之语；黄宗羲《明儒学案·白沙学案》评"有明之学，至白沙始入精微"；后谥文恭，从祀孔庙（fact F8，[R6]）。

**湛若水**（1466—1560），字元明（一作民泽），号甘泉，广东增城人，陈献章衣钵传人（弘治十二年/1499 受江门钓台），倡"随处体认天理"，历南京礼、吏、兵三部尚书（fact F9，[R7][R8]）。

**王湛友诤**（fact F10，[R9][R8]）：弘治十八年（1505）王、湛在北京一见定交，"共以昌明圣学为事"，时称"王湛之学"；分歧如湛若水言："吾之所谓心者，体万物而不遗者也，故无内外。王阳明之所谓心者，指腔子里而为言者也。"《明儒学案·甘泉学案》称"王、湛两家，各立宗旨……亦犹朱陆之门下递相出入也"。

> 读法提示：白沙"静中养端倪"重静坐体悟，甘泉"随处体认天理"重随事随物体察，二者一静一动；阳明与甘泉并世而立、相互论学，心学在明代的展开是多脉并行而非单线传承。

## 四、阳明早年：出入佛老与学凡三变

龙场悟道前的为学历程，《明儒学案·姚江学案》载（fact F11，[R10][R11]）：

> "先生之学，始泛滥于词章，继而遍读考亭之书，循序格物，顾物理、吾心终判为二，无所得入。于是出入于佛、老者久之。及至居夷处困……忽悟格物致知之旨，圣人之道，吾性自足，不假外求。其学凡三变而始得其门。"

三变即：**泛滥词章 → 遍读考亭（朱子）循序格物 → 出入佛老久之**，最终在龙场"居夷处困"中悟"吾性自足，不假外求"。其中"遍读考亭、循序格物"的失败经验，集中表现为格竹事件（两说系年，见 [02 朱王之辨](02-zhu-wang-divergence.md)，fact F12）。

## 小结

远源三层与阳明早年历程的关系：孟子提供"良知"话头与"立大"方向；陆九渊确立"心即理"形态并预演朱陆（后为朱王）之争；白沙、甘泉在明代本土把心学推向精微与随处体认；阳明本人则从朱子学内部入、经佛老、在困厄中悟道。此即"其学凡三变而始得其门"的谱系含义。
