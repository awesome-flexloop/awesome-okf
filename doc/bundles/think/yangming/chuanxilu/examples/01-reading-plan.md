# 《传习录》三轨阅读计划

> 本计划按"语录体三卷分层核读法"（模式 P1）组织：先分层（语录/书信/续编）、再定位（卷次录者＋陈荣捷条号双轨）、后对勘（双源异文登记）。三轨可独立执行，也可拾级而上（facts F13–F17、insights I1–I2）。

## 前置准备（1 小时）

1. 选一个在线全文入口：维基文库《傳習錄》三卷（https://zh.wikisource.org/wiki/傳習錄 ）或中华文库（https://www.zhonghuashu.com/wiki/傳習錄 ）；有条件者备陈荣捷《王阳明传习录详注集评》（重庆出版社 2017，ISBN 978-7-229-11797-9）或邓艾民《传习录注疏》（上海古籍 2015）作研读底本（facts F38、F39）；
2. 读 [全书概览](../concepts/00-overview.md) 与 [三卷结构与编号](../concepts/02-volumes-structure.md)，记住"卷上语录 1–129／卷中书信 130–200／卷下语录 201–342"的地图；
3. 准备一个"异文本"：读到用字不同处，照 [选读原文](../concepts/04-selected-readings.md) 的注记格式登记（某本作某字），不改字。
