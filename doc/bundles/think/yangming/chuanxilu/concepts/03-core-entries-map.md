# 核心命题地图

《传习录》义理以"心即理—知行合一—致良知—万物一体"为主干，以"事上磨练"为工夫法门，晚年由"四句教"收纲（facts F20–F31）。本图按命题给出卷次、录者篇名与陈荣捷条号定位；语录体文本是"因病发药"的问答记录，同一命题在不同对话中侧重不同侧面，引用时须连同语境（insights I3）。

## 六大命题脉络

### 一、心即理

"心即理也。天下又有心外之事、心外之理乎？"（卷上·徐爱录，fact F22）。此命题针对朱子"即物穷理"、理在心外的工夫路向而立，主张理不外于吾心；亲民/新民之辨（fact F21）即其在《大学》文本上的展开——"宜从旧本作'亲民'"，"亲民"兼教养意。

### 二、知行合一

三见而表述递进（fact F23）：

1. 卷上·徐爱录："知是行的主意，行是知的功夫；知是行之始，行是知之成"——知行是一个功夫的两面；
2. 卷上·陆澄录："知者行之始，行者知之成。圣学只一个功夫，知、行不可分作两事"；
3. 卷中·答顾东桥书："知之真切笃实处即是行，行之明觉精察处即是知，知行工夫本不可离"（"即/既"异文见 F23）。

配套命题："未有知而不行者；知而不行，只是未知"（卷上·徐爱录，fact F24）。

### 三、致良知

阳明晚年宗旨，自道"我这个话头，自滁州到今，亦较过几番，只是'致良知'三字无病。医经折肱，方能察人病理"（卷下·钱德洪录，fact F25）；又以"良知是造化的精灵，这些精灵，生天生地，成鬼成帝，皆从此出，真是与物无对"状良知本体（fact F25）。"随你去静处体悟也好，随你去事上磨练也好，良知本体原是无动无静的：此便是学问头脑"——致良知统摄静坐与事上工夫。

### 四、四句教与天泉证道

嘉靖丁亥年九月（1527），阳明起复征思、田，临行前夜在天泉桥，钱德洪与王汝中（王畿）论学，阳明折中定本（fact F26）：

> 无善无恶是心之体，有善有恶是意之动，知善知恶是良知，为善去恶是格物。

文本有"是"字系与无"是"字系（"无善无恶心之体……"）两系传本，古诗文网片段又作"无善，无恶是心之体"——三系异文登记不改字（fact F26）。同段论"利根之人"与"二君相取为用"：四有、四无两路相取，不可各执一边。其后严滩问答"有心俱是实，无心俱是幻；无心俱是实，有心俱是幻"（卷下·黄以方录，fact F27）是天泉证道的余响，傅锡洪有专文考证（R33）。

### 五、万物一体与拔本塞源

卷中·答顾东桥书条 142"拔本塞源"论（陈龙正曾单独刻行，标"拔本塞源论"，fact F30）："夫圣人之心，以天地万物为一体，其视天下之人，无外内远近，凡有血气，皆其昆弟赤子之亲，莫不欲安全而教养之，以遂其万物一体之念"（fact F31）。《大学问》首段以"大人者，以天地万物为一体者也"起论，由孺子入井之怵惕、鸟兽哀鸣觳觫、草木摧折、瓦石毁坏四层指证"一体之仁"，归本于"根于天命之性而自然灵昭不昧"的"明德"（fact F37）——两篇对读，可见万物一体论的伦理与《大学》诠释两面。

### 六、事上磨练

针对"徒知养静，而不用克己工夫"而发（卷上·陆澄录，fact F29）："人须在事上磨，方立得住，方能静亦定，动亦定"；卷下·陈九川录（条 204）重出："人须在事上磨鍊，做功夫乃有益。若只好静，遇事便乱，终无长进。那静时功夫亦差：似收敛，而实放溺也"（"磨/磨鍊"异文，fact F29）。此命题是阳明心学区别于主静一路的工夫纲领，与致良知"无动无静"之说相贯（fact F25）。
