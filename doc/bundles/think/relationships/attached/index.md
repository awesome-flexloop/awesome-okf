# 《依恋》成人依恋知识包

本知识包（bundle）解读阿米尔·莱文（Amir Levine）与蕾切尔·赫勒（Rachel Heller）合著的大众心理学读物《依恋》（*Attached: The New Science of Adult Attachment and How It Can Help You Find—and Keep—Love*，Tarcher/Penguin，2010）。这本书把发展心理学中成熟的**依恋理论**（attachment theory）系统引入成人浪漫关系，用"焦虑型、回避型、安全型"三种依恋风格解释人们在恋爱中的典型行为模式，并给出识别风格、表达需求、选择伴侣的实践建议。

> **定位提示**：依恋理论本身是有六十余年积累的成熟科学（鲍尔比—安斯沃斯传统）；《依恋》是面向大众的**科普应用读物**，其通俗化主张（如类型可较快改变、类型决定关系成败）在学术上存在简化。本知识包在每个关键处区分"本书主张"与"学界共识"，学术边界集中说明见 [走向安全](concepts/04-toward-secure.md) 与 [学术脉络与延伸阅读](references/02-further-reading.md)。
