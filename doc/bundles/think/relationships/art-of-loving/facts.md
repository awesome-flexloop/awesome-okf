## 作者生平

| 编号 | 事实内容 | 信源 |
|------|---------|------|
| F-001 | 艾里希·弗洛姆（Erich Fromm），1900年3月23日生于德国美因河畔法兰克福（Frankfurt am Main）。 | s-britannica；s-db；s-ifef |
| F-002 | 弗洛姆于1980年3月18日逝世，地点为瑞士提契诺州（Ticino）的穆拉尔托（Muralto，属洛迦诺/Locarno）。 | s-britannica；s-db；s-ifef |
| F-003 | 弗洛姆出身正统犹太家庭，父亲为酒商；1922年在海德堡大学获博士学位，博士论文指导教师为社会学家阿尔弗雷德·韦伯（Alfred Weber）。 | s-britannica；s-db |
| F-004 | 弗洛姆曾在慕尼黑大学学习精神病学，并在柏林精神分析研究所接受精神分析训练，训练分析师为汉斯·萨克斯（Hanns Sachs）。 | s-britannica；s-db |
| F-005 | 1930年，弗洛姆经马克斯·霍克海默（Max Horkheimer）引荐加入法兰克福大学社会研究所（法兰克福学派核心机构），负责社会心理学方向。 | s-db；s-kellner；s-surf |
| F-006 | 纳粹上台后弗洛姆离开德国，先至日内瓦，1934年移居美国；1940年取得美国国籍。 | s-britannica；s-db |
| F-007 | 1934年至1941年，弗洛姆任教于纽约哥伦比亚大学；1941年起任教于佛蒙特州本宁顿学院（Bennington College）。 | s-britannica |
| F-008 | 1951年，弗洛姆受聘为墨西哥国立自治大学（UNAM）精神分析教授；1957年至1961年兼任密歇根州立大学教授；1962年回到纽约，任纽约大学精神病学教授。 | s-britannica |
| F-009 | 1974年，弗洛姆移居瑞士穆拉尔托度过晚年，1980年在该地逝世。 | s-ifef；s-db |
| F-010 | 弗洛姆与卡伦·霍妮（Karen Horney）、哈里·斯塔克·沙利文（Harry Stack Sullivan）等同属美国新弗洛伊德主义"文化学派"（neo-Freudian culturalist school）。 | s-frommnet；s-handwiki |
| F-011 | 弗洛姆一生三次结婚：1926年与精神分析师弗里达·赖希曼（Frieda Reichmann）结婚（1942年离婚）；1944年与亨尼·古尔兰（Henny Gurland）结婚（1952年丧偶）；1953年与安妮斯·弗里曼（Annis Freeman）结婚。 | s-ifef；s-db |
| F-012 | 弗洛姆是纽约威廉·阿兰森·怀特精神病学、精神分析与心理学研究所（William Alanson White Institute）的创始人之一。 | s-handwiki |

## 内容要点

| 编号 | 事实内容 | 信源 |
|------|---------|------|
| F-029 | 弗洛姆提出，真正的爱作为一种主动活动包含四个基本要素：关心（care）、责任（responsibility）、尊重（respect）、认识（knowledge）。 | s-wiki-en；s-wiki-es |
| F-030 | 第二章讨论的爱的对象与形态包括：博爱（兄弟之爱，brotherly love）、母爱与父爱（motherly and fatherly love）、性爱（erotic love）、自爱（self-love）、对上帝的爱（love of God）。 | s-wiki-en；s-wiki-es |
| F-031 | 弗洛姆区分"坠入情网"（falling in love）的瞬时体验与"立于爱中"（standing in love）的持久状态，认为前者按其本性不能持久。 | s-surf；s-wiki-en |
| F-032 | 弗洛姆把当代西方社会中两人彼此完全专注、对周围他人漠不关心的恋爱观称为"égoïsme à deux"（法文，意为"两人的自私"）。 | s-wiki-en |
| F-033 | 第四章"爱的实践"提出，掌握任何一门艺术都需要四项条件：纪律（discipline）、专注（concentration）、耐心（patience）、对掌握该门艺术的最高关注（supreme concern）。 | s-sobrief；s-15min |
| F-034 | 第四章开头，弗洛姆预先声明：期待在本章获得"如何自己去做"的操作处方的读者将会大失所望。 | s-wiki-en |
| F-035 | 1950年代末，弗洛姆在迈克·华莱士（Mike Wallace）电视访谈中阐述本书观点，称人其实不可能"坠入"情网，而是"立于"爱中；访谈实录存档于得克萨斯大学奥斯汀分校哈里·兰塞姆中心。 | s-wallace；s-wiki-en |
| F-036 | 弗洛姆区分自爱与自私：自私不是自爱过多，而是自爱不足；不能恰当地爱自己的人也不能真正爱他人。 | s-wiki-en；s-sobrief |
| F-037 | 弗洛姆对母爱与父爱的概括为：母爱是无条件的肯定，父爱是有条件的、需要凭努力赢得；成熟的人在自身之内整合这两种原则。 | s-sobrief；s-wiki-en |
| F-038 | 弗洛姆认为，现代人因与自然、与他人分离而深陷孤独，爱是对人类这一生存问题的成熟回答——在保持自身完整与独立的前提下与他人结合。 | s-wiki-es；s-wiki-en |
| F-039 | 弗洛姆批判当代文化把爱的关系变成类似劳动力市场的交换：人们依据自身"交换价值"在"人格市场"上寻找最划算的对象。 | s-surf；s-philbreak |
