# 庄子内篇阅读教程

本知识包（bundle）以《庄子》**内篇七篇**为核心，收录逐字双源核对的原文、核心概念与名寓言解读，并自觉区分三层文本：**内篇（庄子本人自著）** 的原文忠实呈现、**外杂篇（门人后学）** 的概述与精选、**注家层（历代解说）** 的立场标注。与同域《老子》知识包互补，本 bundle 侧重"如何读懂庄子本人"而非"版本如何流传"。

## 🚀 快速开始

如果你从未系统读过《庄子》：

1. 先读[庄子与《庄子》](concepts/00-what-is-zhuangzi.md)建立人物与文本的基本定位
2. 读[内/外/杂三层作者分层](concepts/02-authorship.md)，理解"哪些是庄子本人"
3. 打开[庄子通读计划](examples/03-reading-plan.md)，按内篇顺序开始读[内篇七篇全文](concepts/03-neipian-full-text.md)

如果你读过《庄子》但想读得更"真"：

1. 从[三十三篇本的源流](concepts/01-text-versions.md)理解"今本为何是 33 篇"
2. 对照[内篇七篇全文](concepts/03-neipian-full-text.md)的异文标注逐字核读
3. 跟着[《逍遥游》逐段精读](examples/01-xiaoyaoyou-reading.md)体会多立场对照法
