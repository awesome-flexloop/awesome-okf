# 三十三篇本的源流

读《庄子》之前，必须先回答一个问题：**你手里的「庄子」是谁定的本？** 今传三十三篇并非先秦原貌，而是经过晋代郭象删定的结果。本文梳理这一「定本过程」，并登记今可回查的数字底本。

## 一、五十二篇：汉代著录的旧本

- 《汉书·艺文志》著录《庄子》**五十二篇**（F-012），这是最早见于正史艺文志的篇数。
- 唐陆德明《经典释文》记载司马彪、孟氏所注即为五十二篇，其结构为：**内篇七、外篇二十八、杂篇十四、解说三**（F-013）。

可见汉代《庄子》的「内篇」已是七篇，但外、杂篇的数量与今本差异很大。

## 二、郭象删定：今传三十三篇的起点

今通行本的篇目格局由**郭象（晋）**奠定——他注《庄子》并删定为**三十三篇：内篇七、外篇十五、杂篇十一**（F-014）。郭象注本较五十二篇本**逸去十九篇**（F-015）。

郭象的删定是「抢救」与「塑造」并行的动作：

- 抢救：从庞杂的五十二篇本中确立一个精当的通行文本。
- 塑造：被郭象判定为「依托附益」而刊去的内容，客观上塑造了后人所能读到的「庄子」面貌（详见 [架构洞察](/insights.md) 洞察 2）。

郭象注《庄子》与删定行为，是今本《庄子》的通行起点（F-036）。

## 三、并行的古本篇数（均早于或近于郭象）

在郭象本之前或并行，还有多种注本篇数：

| 注本 | 篇数 | 依据 |
|------|------|------|
| 崔譔注 | 二十七篇（内七、外二十） | F-016 |
| 向秀注 | 二十六篇（一作二十七、二十八篇），无杂篇 | F-017 |
| 司马彪、孟氏注 | 五十二篇（内七、外二十八、杂十四、解说三） | F-013 |

这些古本篇数各异，说明汉代至魏晋《庄子》文本尚未定型。

## 四、宋以后：郭象本独行

宋朝以后郭象本**独行于世**，《庄子》的篇目次第渐成定局（F-018）。也就是说，今人所读「《庄子》三十三篇」的次序与归属，是宋代以后才固定下来的。

## 五、佚文：删定留下的「失文」

郭象刊去的「依托附益」内容今已散佚，后世学者从类书、注疏中辑集：

- 王叔岷搜集各典籍所见《庄子》佚文凡**一百七十六条**（F-046）。
- 马叙伦辑《庄子佚文》一卷，从《新论》《昌言》《博物志》等书辑得六十事，合旧辑得一百余事（F-047）。
- 王应麟《困学纪闻》录《世说注》《文选注》《后汉书注》《艺文类聚》《太平御览》所引《庄子》佚文凡三十九事（F-048）。

这批佚文提醒我们：「流传下来的」并不等于「全部原文」。

## 六、今可回查的数字底本

由于《庄子》至今无出土全本（与《老子》有帛书、郭店简、汉简不同），「最权威原文」只能靠**传世注本系统 + 数字底本**的多方比勘来逼近（详见 [架构洞察](/insights.md) 洞察 3）：

- ctext.org《庄子》数字底本以《续古逸丛书》本《南华真经》为据（F-020）。
- ctext.org 同时提供《续古逸丛书》本、《四部丛刊初编》本《南华真经》、《庄子集释》《庄子集解》《钦定四库全书》本《庄子注》等多种底本资源（F-045）。

权威底本的完整清单与信源 URL 见 [权威底本清单](/references/core-texts.md)。

## 小结

- 今传《庄子》三十三篇是**郭象删定本**，非汉代五十二篇原貌。
- 内篇七篇自古稳定；外、杂篇篇数在郭象删定时才定型。
- 无出土全本的现实下，读「权威原文」应依赖多方底本比对，异文显式登记而非强行裁决。
