# 四个纸笔实验，自己验证书上的图

本实操不要求任何术数基础，只需纸和笔。每个实验按「输入 → 动作 → 预期结果 → 检验标准」组织，做完即可知道图式里哪些是可验算的数学事实。图式背景见 [概念 05](../concepts/05-zhuxi-qimeng.md)、[概念 06](../concepts/06-shaoyong-xiantian.md)、[概念 08](../concepts/08-numerology.md)。

## 实验一：洛书幻方，八条线是否都等于十五

**输入**：甄鸾《数术记遗》注口诀（[事实清单](../facts.md) F-015）："二四为肩，六八为足，左三右七，戴九履一，五居中央。"

**动作**：

1. 在纸上画一个 3×3 方格，按口诀填数（戴＝头顶格，履＝脚踏格）：

```
┌───┬───┬───┐
│ 4 │ 9 │ 2 │   ← 二四为肩（4 左上、2 右上）
├───┼───┼───┤
│ 3 │ 5 │ 7 │   ← 左三右七
├───┼───┼───┤
│ 8 │ 1 │ 6 │   ← 六八为足（8 左下、6 右下）
└───┴───┴───┘
```

2. 数出横三行、竖三列、对角两条线，共 **8 条线**，逐条把三数相加。

**预期结果**：

| 线 | 算式 | 和 |
|----|------|----|
| 上横 | 4+9+2 | 15 |
| 中横 | 3+5+7 | 15 |
| 下横 | 8+1+6 | 15 |
| 左竖 | 4+3+8 | 15 |
| 中竖 | 9+5+1 | 15 |
| 右竖 | 2+7+6 | 15 |
| 主对角（↘） | 4+5+6 | 15 |
| 副对角（↙） | 2+5+8 | 15 |

**检验标准**：

- ✅ 8 条线和全部为 15，且 1—9 每个数恰好出现一次 → 你手里的就是三阶幻方（洛书图式的数字内容）；
- ✅ 再做一个变形：把整个方格旋转 90° 或翻面镜像，重排后再算 8 条线，仍然全为 15 → 幻方有 8 个等价形式；
- ✅ 对照《大戴礼记·明堂》"二九四七五三六一八"（F-010）：把它按三字一组横排（二九四／七五三／六一八），是同一幻方的镜像排法。

**历史注记**：这个数序在汉代叫"九宫"（《乾凿度》太一行九宫，F-013），是太乙九宫占盘（双古堆出土，F-049）的实际排布；它被称作"洛书"是 12 世纪宋代图书学的事（F-046）——你验算的是**真数学**，但"洛书"这个名字是后贴的标签。

## 实验二：河图生成数，清点五十五点

**输入**：朱熹/蔡元定定本河图配数（F-022）："一与六居北，二与七居南，三与八居东，四与九居西，五与十居中……天一生水，地六成之；地二生火，天七成之……"

**动作**：

1. 画一个十字方位图（上南下北、左东右西——古图方位），把五对数填入五个方位（奇数用○白点、偶数用●黑点表示）：

```
        南（火）
      ●二  ○七
东（木）      西（金）
○三  ●八    ●四  ○九
      ○五  ●十（中，土）
      ○一  ●六
        北（水）
```

2. 清点：白点（奇数/天数）有哪些数？黑点（偶数/地数）有哪些数？分别求和。
3. 验证五对"生数—成数"关系：1/6、2/7、3/8、4/9、5/10——每对差 5，且生数（1—5）与成数（6—10）一一对应。

**预期结果**：

- 白点（天/奇）：1+3+5+7+9 = **25**
- 黑点（地/偶）：2+4+6+8+10 = **30**
- 合计：25+30 = **55**
- 与《系辞上》"天数二十有五，地数三十，凡天地之数五十有五"（F-005）逐字吻合。

**检验标准**：

- ✅ 白黑点数与《系辞》天地之数三方一致（点数＝经文＝算术）；
- ✅ 五对数的方位—五行配属（1/6 北水、2/7 南火、3/8 东木、4/9 西金、5/10 中土）能与《汉书·五行志》"天以一生水……水之大数六，火七，木八，金九，土十"（F-019）逐条对上；
- ❓ 思考题：点数密合证明了什么、没证明什么？——证明宋代图式**严格按照《系辞》《汉志》的数字设计**；它不证明上古传下过这张图（图式定型见 F-037）。

## 实验三：先天卦序，加一倍法推到六十四卦

**输入**：邵雍《观物外篇》"太极既分，两仪立矣……四象生矣"（F-029）与加一倍法（一分为二）。

**动作**：从下往上画分层树，每一层每个符号再分阴阳两支：

```
第0层        太极
              │
第1层       阴 ── 阳              （2 = 两仪）
             │╲   ╱│
第2层     太阴 少阳 少阴 太阳       （4 = 四象）
            ...每支再分...
第3层   八卦：坤艮坎巽震离兑乾      （8 = 八卦）
第4层              16
第5层              32
第6层              64 = 六十四卦
```

1. 数一数每层符号数：第 0 层 1，第 1 层 2，第 2 层 4，第 3 层 8……
2. 写出通项：第 n 层符号数 = 2ⁿ。
3. 推到底：六画成卦（每卦六爻），需要加倍到第几层才得 64 卦？

**预期结果**：1 → 2 → 4 → 8 → 16 → 32 → **64**，共六次加倍；2⁶ = 64。

**检验标准**：

- ✅ 六层加倍得 64，与《系辞》"八卦而小成"（八卦为三爻）、重卦为六爻六十四卦的结构一致；
- ✅ 关键的跨文化验证：把阳爻记作 1、阴爻记作 0，六爻从初爻到上爻读出，六十四卦恰对应二进制 000000（0）到 111111（63）——这正是 1703 年莱布尼茨见到白晋寄去的邵雍卦图时发现的对应关系（F-047）；
- ⚠️ 注意年代方向：莱布尼茨 1679 年已发明二进制，1703 年才见卦图——卦图是二进制的**古代同构实例**，不是其发明来源（[概念 11](../concepts/11-legacy-east-west.md)）；
- ✅ 出处辨识：先天八卦（乾南坤北的对称方位）出自邵雍首倡，宋代之前流行的是后天八卦（震东离南），两者并存于《周易本义》卷首（F-031）。

## 实验四：太极图，五层生成顺读

**输入**：周敦颐《太极图说》（[概念 07](../concepts/07-taijitu-shuo.md)）。

**动作**：对照通行《太极图》（朱熹定本），从上到下读五个圈层，每读一圈写出生成物：

1. 最上圈（无极而太极）→ 终极开端；
2. 第二圈（阴阳动静：太极动而生阳、静而生阴）→ 两仪；
3. 第三圈（五行：水火木金土，五气顺布）→ 五行；
4. 第四圈（乾道成男、坤道成女）→ 人类/乾坤；
5. 最下圈（万物化生、生生不穷）→ 万物。

**预期结果**：得到序列 无极/太极 → 阴阳 → 五行 → 男女（乾坤）→ 万物，即"顺以生人"的生成方向。

**检验标准**：

- ✅ 能说出与河洛图式的接口：太极（一）→阴阳（二）→五行（五）与河图"天一生水、地二生火"的生成数序列在朱熹体系中互相诠解；
- ✅ 版本敏感：开篇文字《周元公集》本作"自无极而为太极"、朱熹定本作"无极而太极"（异文 Y-01），读任何引文时先问"哪个版本"；
- ✅ 方向敏感：同一图式在道教内丹传统中自下而上读（"逆则成丹"，万化→无极），清儒黄宗炎考陈抟《无极图》五圈即此读法（F-042，转引见 U-04）——读图先定读向。
