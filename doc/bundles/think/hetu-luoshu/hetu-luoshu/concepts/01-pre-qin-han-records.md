## 名物层：六条记载，零张图

先秦两汉文献中，"河图""洛书"共出现于以下核心记载。逐条核读后可以看到一个共同事实：**它们都是文字叙述中的名物——或为祥瑞符号，或为朝廷宝物，或为天赐大法的隐喻——没有任何一条附带图式，也没有任何一条描述图上的黑白点阵列**。这与宋代以后"河图洛书＝两张数字图"的印象完全不同。

## 一、《论语·子罕》：孔子的感叹

> 子曰：「凤鸟不至，河不出图，吾已矣夫！」

——出处：《论语·子罕》，信源：[中国哲学书电子化计划 ctext.org](https://ctext.org/analects/zi-han/zh)（F-001）

凤鸟至、河出图，是上古圣王受命的祥瑞。孔子以"凤鸟不至、河不出图"感叹圣王不出、吾道不行。这里的"河图"是**祥瑞符号**，与凤鸟对举，通篇未涉任何图像内容。

## 二、《尚书·顾命》：丧礼上陈列的"河图"

> 越玉五重，陈宝，赤刀、大训、弘璧、琬琰、在西序。**大玉、夷玉、天球、河图，在东序。**胤之舞衣、大贝、鼖鼓，在西房；兑之戈、和之弓、垂之竹矢，在东房。

——出处：《尚书·顾命》，信源：[ctext.org](https://ctext.org/shang-shu/testamentary-charge/zh)，底本《武英殿十三经注疏》本《尚书正义》（F-002）

《顾命》记周成王驾崩后康王即位的丧礼陈设。"河图"与大玉、夷玉、天球并列陈于东序（东墙），是一件**具体的宫廷宝物**。它是什么？汉唐注疏无图像说明；郑玄注以为"图出于河，帝王圣者之所受"，仍属受命宝物的性质。这是全部先秦文献中"河图"唯一作为实物出现的记载，但原文同样没有任何图样描述。

## 三、《尚书·洪范》：天赐"九畴"

> 箕子乃言曰：我闻在昔，鲧堙洪水，汩陈其五行。帝乃震怒，不畀『洪范』九畴，彝伦攸斁。鲧则殛死，禹乃嗣兴，**天乃锡禹『洪范』九畴，彝伦攸叙。**

——出处：《尚书·洪范》，信源：[ctext.org](https://ctext.org/shang-shu/great-plan/zh)（F-003）

《洪范》记箕子向周武王陈述治天下的大法九类（九畴：五行、五事、八政、五纪、皇极、三德、稽疑、庶征、五福六极）。叙事框架是：禹治水成功，"天乃锡禹洪范九畴"。注意这里只说天赐"九畴"（九类大法），**没有出现"洛书"字样**——"洛书"与《洪范》九畴的对应是汉代才明确建立的（见 [02 汉易象数基础](02-han-xiangshu-foundation.md) 刘歆说，F-017、F-018）。

## 四、《周易·系辞上》："河出图，洛出书，圣人则之"

> 是故天生神物，圣人则之。天地变化，圣人效之。天垂象，见吉凶，圣人象之。**河出图，洛出书，圣人则之。**易有四象，所以示也。系辞焉，所以告也。定之以吉凶，所以断也。

——出处：《周易·系辞上》，信源：[维基文库（简体录文）](https://zh.wikisource.org/zh-hans/周易/繫辭上)（F-004；ctext 繁体本该页抓取截断于第 8 章，此段仅维基文库单源，登记 U-08）

这是"河出图，洛出书"六字最著名的出处，在《系辞上》论"圣人则天地以作《易》"的段落中，与"天生神物（蓍龟）""天垂象（天象）"并列，是圣人取法的三类天启之一。

同篇还有被图书学奉为数理总纲的"天地之数"章：

> 天一地二，天三地四，天五地六，天七地八，天九地十。天数五，地数五，五位相得而各有合。天数二十有五，地数三十，凡天地之数，五十有五，此所以成变化，而行鬼神也。大衍之数五十，其用四十有九，分而为二以象两，挂一以象三，揲之以四以象四时，归奇于扐以象闰，五岁再闰，故再扐而后挂。

——出处同上（F-005；单源见 U-08）

以及宇宙生成与形而上学名段：

> 是故易有太极，是生两仪，两仪生四象，四象生八卦，八卦定吉凶，吉凶生大业。

> 形而上者谓之道，形而下者谓之器，化而裁之谓之变，推而行之谓之通，举而错之天下之民谓之事业。

——出处同上（F-006、F-008；单源见 U-08）

需要注意：《系辞》（"十翼"）成书于战国至秦汉间，**并非孔子亲作**——北宋欧阳修已系统论证此点（F-035，见 [09 清代辨伪学史](09-qing-skepticism.md)）。篇中虽有"河出图，洛出书"，但同样**没有描述任何图式**；"天地之数五十有五"被朱熹直接指认为"即所谓河图者也"（F-024），那是宋代的诠释，不是《系辞》的自述。

## 五、《礼记·礼运》：祥瑞清单中的"河出马图"

> 故天不爱其道，地不爱其宝，人不爱其情。故天降**膏露**，地出醴泉，山出器车，**河出马图**，凤皇麒麟皆在郊**棷**，龟龙在宫沼……

——出处：《礼记·礼运》，经《艺文类聚》卷九十八、《古今图书集成·庶征典》卷六转引核实（F-009）

> **异文标注**（Y-2）："膏露"，《艺文类聚》引作"甘露"。
>
> **异文标注**（Y-5）："郊棷"之"棷"，一作"郊薮"。

《礼运》列的是一组太平祥瑞：膏露、醴泉、器车、马图、凤皇、麒麟、龟龙。"河出马图"即黄河出马背负图，是祥瑞清单中的一项，性质与《论语·子罕》的"河不出图"一致，仍无图式描述。

## 六、《大戴礼记·明堂》：一组神秘数字

> 明堂者，古有之也。凡九室：一室而有四户、八牖，三十六户、七十二牖。以茅盖屋，上圆下方。

> 明堂月令，赤缀户也，白缀牖也。**二九四七五三六一八。**堂高三尺，东西九筵，南北七筵，上圆下方。九室十二堂……

——出处：《大戴礼记·明堂》，信源：[ctext.org](https://ctext.org/da-dai-li-ji/ming-tang)（F-010、F-011）

这是名物层中唯一与"图式"直接相关的记载。"二九四七五三六一八"九个数字，若按三行三列排出（二九四／七五三／六一八），正是后世三阶幻方"洛书"的一种排列（横、竖、斜三数之和皆为十五）。但《明堂》原文只把这组数字与明堂九室方位相配（月令居明堂各室），**没有称它为"洛书"，也没有画成黑白点图**。清代胡渭据此判定："后世以九宫为河图，实造端于明堂月令之说"（F-039）——即宋代图书的数理种子埋在这里，但名称与图式都是后世嫁接的。

## 小结：名物层的实况

| 记载 | 河图洛书的性质 | 有无图式 |
|------|----------------|----------|
| 《论语·子罕》 | 祥瑞（与凤鸟对举） | 无 |
| 《尚书·顾命》 | 宫廷陈列的宝物（与大玉、天球并列） | 无 |
| 《尚书·洪范》 | 未提洛书；"天锡九畴"的叙事框架 | 无 |
| 《周易·系辞上》 | 圣人则效的天启（与神物、天象并列） | 无 |
| 《礼记·礼运》 | 太平祥瑞之一（河出马图） | 无 |
| 《大戴礼记·明堂》 | 九室方位数序（二九四七五三六一八） | 有数序无图式 |

这正是胡渭"河图之象不传"（F-037）一语的含义：先秦两汉有"河图洛书"之名、有相关数序之实，但黑白点图式之"象"确实不见于这一阶段的任何文献。下一篇 [02 汉易象数基础](02-han-xiangshu-foundation.md) 将展示：图式的数理零件（九宫幻方、五行生成数）在汉代如何一一成型。
