# 河图洛书核心概念

本目录为河图洛书 OKF 知识包的概念文档层（concepts），在 [facts.md](../facts.md)（事实清单）、[insights.md](../insights.md)（洞察）、[patterns.md](../patterns.md)（可复用模式）三件产物之上，面向读者系统梳理河图洛书与宋代图书学的知识脉络。
