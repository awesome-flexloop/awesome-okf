# 河图洛书知识包·架构洞察（Architecture Insights）

> 基于事实清单（facts.md，F-001～F-053）得出，每条洞察遵循四元组结构（陈述/证据/反常识/行动）。

## 洞察 1：名实三层——"河图洛书"是一个被层累使用了两千年的名字，三个时代指三种东西

| 四元组 | 内容 |
|--------|------|
| **陈述** | "河图洛书"在历史上存在三个互不相同的所指层：① **名物层**（先秦—汉唐）：河图是与大玉、夷玉并列的陈宝玉器（F-002），"河出图"是圣王受命的祥瑞符号（F-001/F-003/F-009），此层**无任何图式描述或图式流传**；② **图式层**（宋代定型）：黑白点十数河图、九数洛书配合先天图、太极图构成三图系（F-020/F-022/F-023/F-031）；③ **附会层**（后世民俗）：风水、术数、占卜、宇宙密码类演绎。三层共享同一名字，但实体、年代、证据类型完全不同；关于河图洛书的几乎所有争论，都是把三层混为一谈造成的。 |
| **证据** | F-001～F-011（名物层六条记载，均无图式描写）；F-037（胡渭"河图之象不传，故周易古经及注疏未有列图书于其前者，有之自朱子本义始"）；F-020/F-022/F-023（宋代图式配置的文献实物）；F-046（幻方与洛书合名在 12 世纪）；F-043（四库"两派六宗"对附会膨胀的收口）。 |
| **反常识** | 挑战"名字不变则对象不变"的默认假设。一个名字可以先后承载宝物、祥瑞、数学图式、哲学图式、民俗符号五种对象而不改名；因此"河图洛书是什么"这个问题本身是错的——正确的问法是"某时代的某文献说的河图洛书指哪一层"。顾颉刚式层累造成的中国古史，在符号史上有同构现象：不是古人造假，而是每一代人往旧名字里装新内容。 |
| **行动** | 知识包以名实三层框架开篇（概念 00），全部 12 篇概念文档按层组织；每处引文标注所属层；附会层内容仅作学术辨析对象、不提供操作教程（AC-4）；读者在任何争论现场先做"分层定位"再判断是非。 |

## 洞察 2："宋代定型"不是贬低——图式是真零件的再装配，辨伪否定的是神圣来源而非数学内容

| 四元组 | 内容 |
|--------|------|
| **陈述** | 胡渭以降的辨伪传统证明图式不古（黑白点图出自宋代，F-037/F-038/F-039），但这不等于图式内容是"假的"：洛书九数就是三阶幻方（八条线皆 15，F-015/F-046，可亲手验算），其数序在汉代已是占盘实物（F-049/F-050）与明堂制度（F-010/F-011）；河图十数是五行生成数（F-019）与天地之数 55（F-005）；先天卦序是严格的二进制排列（2⁶=64，F-029）。宋代图书学做的事是**把汉代已有的数理零件重新装配、命名并系于圣人**——装配与命名是宋代的，零件是古老的，数学是真的。 |
| **证据** | F-013/F-014（太一行九宫，汉易）；F-015（九宫口诀，北周）；F-019（五行生成数，《汉书》）；F-040（唐代九宫坛已用幻方配置）；F-049/F-050（西汉占盘实物）；F-022/F-023（朱熹/蔡元定的装配说明）；F-038（胡渭区分"仰观俯察中之一事"与"作易之由"）；F-047（莱布尼茨独立验证卦序的数学结构）。 |
| **反常识** | 挑战"辨伪＝否定价值"与"古老＝神圣"两个对称误区。清儒否定的是"伏羲受图、圣人则之作《易》"的起源叙事（F-017 刘歆模式、F-037 胡渭判决），而不是幻方的数学性质；反过来，图式的数学为真也**不支持**其起源叙事为真——数学正确性与历史起源是两个独立问题。民间神秘化（"宇宙密码"）与过度疑古（"全是骗局"）犯的是同一个错误：把来源问题与内容问题绑在一起。 |
| **行动** | 概念 08 与示例 02 设"硬核/附会分界表"与四个纸笔实验，让读者亲手验证哪些内容可验算；概念 09 明确辨伪"否定神圣来源、不否定研究价值"的定位；行文始终把"数学事实""命名史""起源叙事"三件事分开陈述。 |

## 洞察 3：可验算性分级——同一图式运动里，数学图式、哲学图式、术数附会的证据硬度相差三个数量级

| 四元组 | 内容 |
|--------|------|
| **陈述** | 图书学三图系的内容硬度并不均匀：洛书幻方可做八条线加法验算（F-015）、河图 55 点可清点（F-005/F-022）、先天卦序可做 2⁶=64 推演（F-029），属**可验算数学**；太极图"无极而太极→阴阳→五行→万物"的五层生成（F-032）是**哲学图式**，其价值在义理系统而非可算命题；风水排盘、占卜应验类内容则属**不可证伪附会**。三级共存于同一传统，却要求完全不同的信任方式。 |
| **证据** | F-015/F-045/F-046（幻方：有构造法、有等价变换、有跨文化独立发现史）；F-029/F-047（卦序：莱布尼茨独立发现其二进制同构）；F-032/F-044（太极图说：版本异文 Y-01 与朱陆辩论显示其为义理文本）；F-043（四库"九流百家俱可窜入"描述附会膨胀机制）；F-041/F-042（清儒溯源本身也显示图式与内丹术的纠缠）。 |
| **反常识** | 挑战"一个传统要么全信要么全疑"的阵营化思维。最容易被神秘化的部分（术数附会）恰恰证据最软，最不起眼的部分（幻方算术）恰恰证据最硬；而哲学图式（太极图）既不能用验算证明也不能用辨伪消灭，它属于第三种真值状态——思想史事实。读者需要的不是立场而是分级工具。 |
| **行动** | 知识包对每个图式标注证据类型（可验算/义理/附会）；示例 02 只对可验算部分设计动手实验；概念 07 把太极图作为哲学文本处理（版本公案＋辩论史）；附会层全篇无操作步骤，并在概念 08 给出分界判据（能否给出可复算的输入—输出）。 |

## 洞察 4：出土证据链有层级——实物能证明"数术传统存在"，不能直接证明"图名/图式/义理"

| 四元组 | 内容 |
|--------|------|
| **陈述** | 出土文献在河图洛书话题中的证明力必须分层：双古堆太乙九宫占盘（前 2 世纪，F-049/F-050）证明**九宫数术在西汉早期已是实用器物**——这是硬证据；但它不证明"洛书"之名（合名在 12 世纪，F-046）、不证明黑白点图式、不证明伏羲起源。凌家滩玉版（约 5800—5300 年前，F-051）的"原始八卦"解释（F-052）是学者对无文字纹饰的**解释性假说**，且同年即有严肃异议（F-053 饶宗颐：论据资料晚出、说服力不强）。从实物到"这就是河图洛书/八卦"之间，隔着名称史、图式史、传播链三重缺口。 |
| **证据** | F-049/F-050（占盘：有明确年代、有发掘报告、数序与文献互证）；F-046（图名合名年代的英文文献独立证据）；F-039/F-040（九宫传统的文献链：明堂月令→唐九宫坛）；F-051/F-052/F-053（凌家滩：发掘事实为硬、图形解释为假说、双方论文并列）。 |
| **反常识** | 挑战"考古发现证实了上古传说"的流行叙事结构。考古实物最有力的用法是证明**传统的年代下限**（某观念在某年已存在），而不是给传说发"属实证书"；把玉版直接叫"五千年前的洛书"是把硬证据（纹饰、年代）与软推测（纹饰含义）焊接成一个看似全硬的陈述。莱布尼茨事件（F-047）是同一错误的镜像：二进制 1679 年已成稿、1703 年才见卦图，流行叙事却把因果倒转。 |
| **行动** | 概念 10 设"能证明/不能证明"边界表与争议并列对照表（F-052 vs F-053 双方依据同页呈现）；概念 11 用时间线表强制呈现莱布尼茨事件的先后顺序；全知识包规则：推测一律以"某某认为"引出并与可核原文分层；U-01～U-09 未核项显式登记不吞没。 |
