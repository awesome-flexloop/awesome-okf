# 河图洛书（Hetu-Luoshu）知识包

本目录收录与河图洛书及宋代图书学相关的 OKF 知识包。"河出图，洛出书"在先秦两汉文献中本为**祥瑞名物符号**（《论语·子罕》《周易·系辞上》《礼记·礼运》）或具体宝物（《尚书·顾命》陈设于东序的"河图"）；今日通行的黑白点图式（十数河图、九数洛书）则**定型于宋代**——经陈抟—种放—穆修传授谱系之传述、刘牧《易数钩隐图》之图名配置、朱熹/蔡元定《易学启蒙》《周易本义》之官方定本而成为后世标准；清代胡渭《易图明辨》、黄宗羲、黄宗炎、毛奇龄等辨伪考定其源流；凌家滩玉龟玉版、阜阳双古堆太乙九宫占盘等出土实物又将相关数理符号的实物证据推向史前与西汉。本组知识包以"**名实三层不混同**"（先秦两汉祥瑞名物层 → 宋代定型图式层 → 后世术数民俗附会层）为组织基调，核心段落原文双源核对、异文登记、争议双方并列，术数内容仅作学术辨析、不提供操作教程。
