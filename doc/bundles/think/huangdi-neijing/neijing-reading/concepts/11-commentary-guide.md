# 注本导航：怎么选、怎么用

> 完整书目见 [references/commentaries.md](../references/commentaries.md)；本篇解决"什么阶段查什么注本"。

## 一、先建立一个意识：王冰注是《素问》文本的一部分

今天读到的《素问》，白文与王冰注从 762 年起就合刻流传，林亿《新校正》又以"新校正云"的形式插入按语。读 ctext 四部丛刊本时：

- 大字为经文（王冰整理后的白文）
- 小字为**王冰注**
- "新校正云"之后为**林亿校语**（引全元起本、《太素》、《甲乙经》等异文）

读经文遇到难解处，先看紧随其后的王冰注——王冰是整理者，他对文句分合与训释有"立法者"地位；再看《新校正》提供的版本异文。

## 二、按学习阶段选用

### 入门期（读名篇、建立框架）

| 注本 | 用法 |
|------|------|
| 明·李中梓《内经知要》 | 8 类节选（道生、阴阳、色诊、脉诊、藏象、经络、治则、病能），节选精当、注文简明，三百年通行入门书；与本 bundle 八篇精读重叠最多 |
| 元·滑寿《读素问钞》 | 最早的类分节抄本（12 类），汪机有续注；想了解"类分读法"的源头时用 |
| 王洪图《内经选读》（现代教材） | 现代学术规范下的选篇精讲，含篇章题解、字词注释与理论阐释，入门主力 |

### 进阶级（专题深读）

| 注本 | 用法 |
|------|------|
| 明·张介宾《类经》 | **专题研究首选**。将《素问》《灵枢》经文打散重编为 12 大类 390 目（摄生、阴阳、藏象、脉色、经络、标本、气味、论治、疾病、针刺、运气、会通），32 卷；同一主题的经文按类聚齐，注文融会贯通。七篇大论的注以张氏最详 |
| 隋·杨上善《黄帝内经太素》 | 现存最早的类分注本（19 类，存 25 卷），保存唐以前古注与经文旧貌；校勘价值极高，遇文字疑义时查它 |
| 清·黄元御《素问悬解》 | 黄氏以"中气升降"自成一家，注文有主见；cloudtcm 有全文，适合看一家之言（如正反治异文处保留"热因寒用"读法） |

### 考据期（遇异文、争议）

| 注本 | 用法 |
|------|------|
| 日本·丹波元简《素问识》《灵枢识》 | 江户汉方考据学代表，广引中日前代注本、罗列异说而不轻下断语，等于一部"注本索引"；遇争议先查此书 |
| 日本·丹波元坚《素问绍识》 | 《素问识》续编 |
| 林亿《新校正》（随梅花本） | 异文校勘的第一层依据 |
| 郭霭春《黄帝内经词典》 | 字词障碍的工具书层 |

### 全注参考

马莳《黄帝内经素问注证发微》《灵枢注证发微》（明代全注，《灵枢》部分尤受重视）、吴崑《素问吴注》、张志聪《黄帝内经素问集注》《灵枢集注》（集同学集体之力）、高世栻《素问直解》（张志聪弟子，力求通俗，对病机十九条有心/火改读）。

## 三、一个实用的查注流程

遇到经文难句，按此顺序：

```
1. 梅花本王冰注 + 新校正          → 理解文句、知道有哪些异文
2. 《内经选读》教材对应章节        → 现代白话解释与理论定位
3. 《类经》按主题查同类经文会聚    → 看该句在理论体系中的位置
4. 《素问识》/《太素》             → 遇到异文、异说时的考据层
5. 《黄帝内经词典》                → 字词层面的独立疑难
```

## 四、类分法本身就是一种读法

从杨上善（19 类）→ 滑寿（12 类）→ 张介宾（12 类 390 目）→ 李中梓（8 类）→ 沈又彭《医经读》（4 类：平、病、诊、治），历代医家不断把《内经》重组得更便于检索。本 bundle 的"概念（concepts）+ 精读（examples）+ 信源（references）"结构，正是这一类分传统在知识包形态下的延续——读原文时逐篇读，用理论时按类查。
