# 五运六气与七篇大论

## 一、什么是七篇大论

《素问》第 66–71 篇与第 74 篇，篇目都以"大论"结尾，合称七篇大论：

| 篇序 | 篇名 | 中心内容 |
|------|------|----------|
| 66 | 天元纪大论 | 五运六气总纲，引《太始天元册》 |
| 67 | 五运行大论 | 五运推演、五方气候 |
| 68 | 六微旨大论 | 六气盛衰、亢害承制 |
| 69 | 气交变大论 | 运气异常与物候、病候 |
| 70 | 五常政大论 | 五运平气、太过、不及 |
| 71 | 六元正纪大论 | 六十年运气周期的系统推演 |
| 74 | 至真要大论 | 六气病机（病机十九条）与治法——运气学说的临床落地 |

这七篇在王冰次注之前的《素问》传本中已缺（全元起本第七卷亡佚），王冰称得自"先师张公秘本"补入。其文体、术语与其余诸篇差异明显，历代学者多认为其来源独立（或与已佚的《阴阳大论》有关），是《内经》文献史上最大的"补入单元"。读这七篇时必须带着这一文献学意识。

## 二、五运：天干化运

五运以天干推演年度的大运（中运）及各季节运的太过不及：

- **甲己之岁，土运统之；乙庚之岁，金运统之；丙辛之岁，水运统之；丁壬之岁，木运统之；戊癸之岁，火运统之**（《天元纪大论》）
- 阳干（甲丙戊庚壬）主太过，阴干（乙丁己辛癸）主不及
- 如甲年为土运太过（雨湿流行），己年为土运不及（木来乘之）

五运之外又分主运（年年固定的五步季节运）与客运（逐年流转如客之来去）。

## 三、六气：地支化气

六气指风、寒、暑（君火）、湿、燥、火（相火），以地支推演：

- **子午之上，少阴主之（君火）；丑未之上，太阴主之（湿土）；寅申之上，少阳主之（相火）；卯酉之上，阳明主之（燥金）；辰戌之上，太阳主之（寒水）；巳亥之上，厥阴主之（风木）**
- 主气固定（按厥阴风木→少阴君火→少阳相火→太阴湿土→阳明燥金→太阳寒水分主六个时段），客气逐年流转
- 每年客运与主运、客气与主气之间的加临关系，推演该年气候与疾病的总体倾向

## 四、为什么今天还要读它

1. **病机十九条出自《至真要大论》**：它是六气病机的归类示范（"诸暴强直皆属于风……皆属于火/热/寒/湿"），金元医学的火热论、燥气论直接从此生发，详见 [concepts/08 治则](08-treatment-principles.md)
2. **方法论价值**：运气学说是中国古代最大尺度的"气候—物候—疾病"统计模型尝试，其结构（周期推演+异常校正〔胜复郁发〕+临床验证）具有独立的思想史意义
3. **"亢则害，承乃制"**（《六微旨大论》）：系统自我制约思想，影响后世整个病机理论

## 五、争议与阅读策略

七篇大论是《内经》研究中争议最大的部分：

- **来源争议**：王冰补入说之外，成书年代有东汉、魏晋、唐初诸说
- **有效性争议**：六十年周期推演与实际气候、发病的吻合程度，历代医家（如缪希雍、张倬）与现代学者多有质疑
- **阅读门槛**：推演体系庞大，需专门图表（龙仲光、任应秋等有运气专著图解）

**普通读者策略**：

1. 先精读《至真要大论》的病机十九条与治法段（本 bundle examples/06），这是七篇中思想密度最高、脱离推演也能成立的部分
2. 运气推演框架（五运六气如何配天干地支）了解概念即可，不必记忆六十年全表
3. 不把运气推演当作气候或疾病预测工具使用——它在古代也是"常变对勘"的参考系而非宿命表
4. 深入研究：教材用任应秋《运气学说》、王洪图教材运气章节；古注以张介宾《类经·运气类》最便（张氏对七篇用力最深）
