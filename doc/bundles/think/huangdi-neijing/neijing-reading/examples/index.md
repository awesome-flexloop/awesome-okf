## 阅读顺序建议

- **最短路径**：01 → 02 → 09（计划），先建立养生篇的实感
- **理论路径**：03 → 04 → 05 → 06，配合 [concepts/03~08](../concepts/index.md)
- **《灵枢》路径**：07 → 08，配合 [concepts/05](../concepts/05-meridians-and-nine-needles.md)

## 底本与用字说明

- 《素问》原文以 ctext 四部叢刊景印《重廣補註黃帝內經素問》为底本（繁体原貌）；《灵枢》以 ctext 四部叢刊景印《靈樞經》为底本
- 底本用字照录：鍼（非針）、麤（非粗）、寫（瀉）、藏（臟）、府（腑）、云（非雲，仅"吹云"处）、鬭（鬥）、无（無，仅"恬惔虛无"处）
- 异文处理：双录并注（如"热因热用/热因寒用"），不以一本擅改另一本
- 现代白话译文受著作权保护，本目录不复制；三层解读中的现代层为编者自撰概述
