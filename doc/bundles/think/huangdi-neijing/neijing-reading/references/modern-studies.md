# 现代整理本、教材与工具书信源

## 一、现代校注语译本

| 出版年 | 著作 | 说明 |
|--------|------|------|
| 1959 | 南京中医学院《黄帝内经素问译释》《灵枢经译释》（上海科学技术出版社） | 较早的现代语译本，医界长期使用 |
| 1981 | 郭霭春《黄帝内经素问校注语译》《灵枢经校注语译》（天津科学技术出版社） | 按原文、校勘、注释、语译四项编排，校勘用功深 |

## 二、院校教材（体系化入门首选）

| 著作 | 说明 |
|------|------|
| 王洪图主编《内经选读》（上海科学技术出版社 1997，ISBN 7-5323-4438-X/R-1177） | 普通高等教育中医药类规划教材；选篇精讲，含《上古天真论》《四气调神大论》《生气通天论》《阴阳应象大论》《至真要大论》等本 bundle 精读篇 |
| 王洪图主编《黄帝内经》（人民卫生出版社 21 世纪课程教材） | 全本教材化讲解 |
| 《王洪图内经讲稿》（人民卫生出版社 2008） | 课堂讲稿整理，口语化，适合配合原文读 |

> 王洪图（1937—2009），北京中医药大学教授，《内经》学科带头人；其讲课视频与讲稿在中医教育界流传极广，本 bundle 至真要大论治法段即参考其讲课记录（zhongyijinnang.com 存档 PDF）。

## 三、工具书

| 工具书 | 说明 |
|--------|------|
| 郭霭春主编《黄帝内经词典》（天津科学技术出版社 1991） | 文字以 1963 年人卫梅花本为依据；收单字 2747 个（含繁体异体 608 个）、词条 7118 条；读经文遇字词障碍先查此 |
| 人卫梅花本校勘记（随 1963/2012 本） | 异文校勘的案头依据 |

## 四、现代读本使用建议

1. **第一遍**：人卫《中医临床必读丛书》白文本（2005，简体轻便）或梅花本简体新版（2012）+《内经选读》教材，只选篇读
2. **查字词**：《黄帝内经词典》
3. **要语译对照**：郭霭春《校注语译》或南京中医学院《译释》二选一即可，不必兼收
4. **听讲解**：《王洪图内经讲稿》配合精读篇使用
