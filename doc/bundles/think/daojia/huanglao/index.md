# ② 黄老之学

黄老之学与先秦诸子并行（战国—西汉），以「道生法」为纲，道法结合、兼采刑名阴阳。本段含阴符经（既有独立分组）、黄帝四经（马王堆帛书出土孤本）、淮南子（集道家大成）及尹文子、慎到田骈辑佚。

## 判读要点

- 黄帝四经无传世本，仅马王堆帛书出土本（1973 年三号汉墓出土，抄于汉文帝前）；定名《黄帝四经》与《黄帝书》两说并载。
- 「黄帝」系著作书名均为托名层；出土文献只作为成书下限硬约束，不作为全书定型的充分证据。
