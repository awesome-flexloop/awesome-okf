# 全书概览

## 书名沿革

《淮南子》有三个名称，对应三个层面（facts F1、F2）：

| 名称 | 层面 | 说明 |
|------|------|------|
| 《淮南内》 | 目录学著录名 | 《汉书·艺文志》著录名，列杂家类，二十一篇 |
| 《淮南鸿烈》 | 书本自称/注本名 | "鸿，大也；烈，明也"——高诱注本题《淮南鸿烈解》 |
| 《淮南子》 | 后世通行名 | 唐宋以后通行简称，今通用 |

## 二十一篇结构

今传本二十一篇，末篇《要略》为全书总序（facts F4、F5）。按《要略》自述的篇次：

| 序 | 篇名 | 《要略》篇旨提示 |

| 2 | 俶真 | 穷逐终始之化——真人与至德之世 |
| 3 | 天文 | 和阴阳之气，理日月之光 |
| 4 | 坠形 | 穷南北之修，极东西之广 |
| 5 | 时则 | 上因天时，下尽地力 |
| 6 | 览冥 | 言至精之通九天 |
| 7 | 精神 | 原本人之所由生 |
| 8 | 本经 | 明大圣之德，通维初之道 |
| 9 | 主术 | 君人之事，秉数持要 |

| 11 | 齐俗 | 一群生之短修，同九夷之风气 |
| 12 | 道应 | 揽掇遂事之踪，考验乎老庄之术 |
| 13 | 氾论 | 兆见得失之变，与化推移 |
| 14 | 诠言 | 譬类人事之指，解喻治乱之体 |

## 双重定位：杂家著录与道家为本

两种定位并存，不作单一裁决（facts F2、F12，insights I2）：

- **目录学定位**：《汉志》列杂家类——取其"兼儒墨、合名法"的兼综特征。
- **义理定位**：以道家"道"论为本，兼综儒、墨、名、法、阴阳——全书主干为道论与"无为而无不为"的政治哲学。

## 全书自我定位

《要略》末段自述（fact F17）：

> 若刘氏之书，观天地之象，通古今之事，权事而立制，度形而施宜……故置之寻常而不塞，布之天下而不窕。

总括语（fact F18）："故著书二十篇，则天地之理究矣，人间之事接矣，帝王之道备矣。"
