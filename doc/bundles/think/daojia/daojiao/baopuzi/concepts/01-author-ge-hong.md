# 作者：葛洪其人

> 本篇按"生平—师承—著述"三节组织（作者明确文本不设托名分层，见 insights I1）。

## 一、生平

- 葛洪字稚川，自号抱朴子，丹阳句容（今属江苏镇江句容）人，生于晋武帝太康四年（283）；《清微仙谱》称之为"小仙翁"（facts F7）。
- 出身江南士宦豪族：祖父葛系为三国吴大鸿胪，父葛悌为晋邵陵太守；年十三父卒，家道中落，饥寒困瘁，躬执耕穑，日伐薪卖之以给纸笔；年十六广览众书近万卷（facts F8）。
- 晋惠帝太安二年（303）石冰起义，葛洪受檄为将兵都尉，攻石冰别率获胜，迁伏波将军；事平投戈释甲，径至洛阳欲搜求异书（facts F8，R20）。
- 司马睿为丞相，辟为掾；咸和五年（330）赐爵关内侯；后选为散骑常侍、领大著作，固辞不就；以年老欲炼丹祈遐寿，闻交趾出丹砂求为句漏令，至广州为刺史邓岳款留，止罗浮山炼丹，著述不辍（facts F8，R20）。

## 二、师承谱系

葛洪的方术传承有清晰的四代谱系（自述于《金丹》篇，facts F8、F19）：

```
左元放（左慈）——天柱山中精思，神人授金丹仙经
    ↓
葛玄（葛洪从祖，世称葛仙公）——受太清丹经三卷、九鼎丹经一卷、金液丹经一卷
    ↓
郑隐（郑思远，郑君）——葛洪亲事之，洒扫积久
    ↓
葛洪——于马迹山中立坛盟受之，并诸口诀之不书者
```

另师事南海太守鲍玄（鲍靓，字太玄），鲍玄"内学"，见洪深重之，以女妻洪；洪传玄业，兼综冶炼、医药术（facts F8）。

## 三、著述

据《自叙》与《晋书》本传（facts F2、F12）：

| 著作 | 卷数 | 说明 |
|------|------|------|
| 《抱朴子内篇》 | 二十卷 | 本知识包对象 |
| 《抱朴子外篇》 | 五十卷 | 言人间得失、世事臧否，属儒家 |
| 《神仙传》 | 十卷 | 撰俗所不列者，证"神仙实有" |
| 《隐逸传》 | 十卷 | 撰高尚不仕者 |
| 《金匮药方》 | 一百卷 | 《晋书》本传著录 |
| 《肘后要急方》 | 四卷 | 即《肘后备急方》，医学名著 |
| 碑颂诗赋、军书檄移等 | 百余卷 | 另有抄撮五经七史百家之言等 |

成书年代自述："洪年二十余，乃计作细碎小文，妨弃功日，未若立一家之言，乃草创子书。会遇兵乱，流离播越……至建武（317）中乃定"（facts F9）。

## 小结

葛洪是作者明确、自序存、正史有传的道教理论家——本包因此不设托名分层章节，但卒年等细节争议仍并列登记（facts F10）。
