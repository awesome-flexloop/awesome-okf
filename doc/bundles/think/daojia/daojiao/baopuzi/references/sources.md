## 一、权威性评级

**评级：A**（按道家分组判读口径：A＝传世本为主、整理本权威且文本大体完整；本包无出土本，故 A 级依据为"作者明确 + 文本完整 + 整理本权威"三重支撑）。

| 评级维度 | 本包情况 |
|----------|----------|
| 作者 | 明确——葛洪自序存、《晋书》有传，非托名（facts F13） |
| 文本 | 大体完整——二十卷全传，无辑佚问题（facts F1、F4） |
| 传本 | 传世本系统（道藏本、明刻本系统），无出土本（facts F4） |
| 整理本 | 王明《抱朴子内篇校释》（中华书局增订本）——集大成性质（facts F5） |

## 五、选用策略

1. **研读**：王明《抱朴子内篇校释》（中华书局增订本）——唯一汇校+注释的集大成本。
2. **检索**：ctext.org——全文检索、版本切换、中英对照。
3. **核对**：任何引文至少两个独立信源核对后方可引用（本包判读口径）。
4. **避坑**：网络名句（如"我命在我不在天"）须回原典核对卷次篇名，勿信单一转述（见 facts F24 出处更正）。
