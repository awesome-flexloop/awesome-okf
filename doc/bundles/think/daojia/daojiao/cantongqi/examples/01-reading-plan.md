# 四周阅读计划

《周易参同契》三卷约六千字，词韵皆古、奥雅难通，论述多用隐语，零基础读者不宜逐章硬读，建议按"注本为先、义理为纲"原则分四周选读（facts F4、F15）。底本用彭晓《周易参同契分章通真义》分章本系统（fact F15）。

## 总原则

1. **注本为先**：原文隐语密集，须借彭晓、朱熹、俞琰、陈致虚诸注破读，不裸读白文；
2. **义理为纲**：以"三道由一—乾坤鼎器—坎离日月—同类相从"四条义理主线选章，不按九十章次序硬读；
3. **先读史源**：第一周先读《神仙传》魏伯阳传与彭晓序，建立作者与传授的历史坐标；
4. **隐语章略读**：廋辞隐名、鼎器歌赋等章以"观其大略"为度。

- 通读一遍后，补读月体纳甲诸章（圣人上观章第四"三日出为爽，震庚受西方"）；
