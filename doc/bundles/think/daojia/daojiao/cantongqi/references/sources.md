## 五、选用策略

1. **研读**：彭晓《周易参同契分章通真义》分章本系统——通行本所本；辅以朱熹《考异》、俞琰《发挥》校勘。
2. **检索**：维基文库分章页面 + 汉典古籍全文对照。
3. **核对**：任何引文至少两个独立信源核对后方可引用；注文与经文分判，错简增窜处不妄改。
4. **避坑**：作者诸说（独撰/合著/伪书）属托名层，不与"东汉末成书"的文本层结论混同；内丹外丹之辨属诠释层，三说并列不裁决。
