# 版本系统

## 传本概况

《清静经》仅传世本，无出土本（调研基座 [G]）：

| 传本系统 | 说明 |
|------|------|
| 道藏本 | 明《正统道藏》收录《太上老君说常清静经》及诸家注本；中华文库收录白文与注本链接（fact F10） |
| 杜光庭注本 | 唐末道士杜光庭注本为最早注疏本，经后补成书来历一段，出现后该经传播更广（facts F6–F7） |
| 宋元诸注 | 南宋白玉蟾分章本、金侯善渊注本、宋无名氏注本、宋末元初李道纯注本、元终南山王元晖注本（fact F11） |

> 唐宋以后，此经成为道教全真派日常持诵的功课经之一（fact F20）。

## 底本选择原则

1. **原文正字**以《正统道藏》白文（中华文库底本）为准；
2. **异文登记**：各本异文（"名谓/名为""欲/慾""不名道德/不明道德""葛玄/葛翁""拥护其人/拥护其神"等）登记不改字；
3. **层级声明**：注文与经文分判——杜光庭注本经后所补成书来历属注本增文，非经文本身；赞语三段（葛翁、左玄真人、正一真人）为经后附文，与经文正文分层。
