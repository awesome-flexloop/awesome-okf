# 全书概览

## 书名沿革

《清静经》有多个名称（facts F1–F2）：

| 名称 | 说明 |
|------|------|
| 《太上老君说常清静经》 | 全称，明《正统道藏》收录名 |
| 《太上老君说常清静妙经》《太上老君说常清静真经》 | 别名 |
| 《常清静经》《清静经》 | 简称 |
| 《太上混元上德皇帝说常清静经》 | 又称 |

"清静"一词出自老子《道德经·四十五章》："清静为天下正"（fact F3）。"太上"系道门最高之辞，"太上老君"为道教徒对老子的尊称；"常"为恒，"清"为元，"静"为炁，"经"为法（fact F19）。

## 一卷三段结构

全经一卷，全部经文约 391 字，加上经后赞语约四百余字（fact F2）。经文以"老君曰"起，分三段，后附三段赞语：

| 段落 | 内容 | 要点 |
|------|------|------|
| 上段 | 道体论 | "大道无形，生育天地；大道无情，运行日月；大道无名，长养万物" |
| 中段 | 澄心遣欲 | "夫人神好清，而心扰之；人心好静，而欲牵之" |
| 下段 | 妄心苦海 | "众生所以不得真道者，为有妄心" |
| 赞语 | 葛翁、左玄真人、正一真人 | 传授谱系与持诵功德 |

> 论述内容主要围绕"清静"二字展开，探讨老子的清静无为思想，讲述道家核心的"道"本体论，主张修道者要澄心守静、减少欲望（fact F18）。

## 定位：功课经之首与修心要典

三种定位陈述并置（facts F18、F20）：

- **修持定位**：《玄门日诵早晚功课经》把《清静经》放在众经之首，每日持诵，是道教徒修持的一部非常重要的上乘经典；
- **思想史定位**：其道教心性修养道法被尊为最高法门圣典，在道教思想史上占据重要地位；
- **艺术史关联**：该经由于在道教历史上的重要地位而被书法家专门书写，对中国传统艺术风格影响深远。

## 全书自我定位

经文上段开篇（fact F14，双源核对）：

> 老君曰：大道无形，生育天地；大道无情，运行日月；大道无名，长养万物；吾不知其名，强名曰道。夫道者：有清有浊，有动有静；天清地浊，天动地静；男清女浊，男动女静。降本流末，而生万物。清者浊之源，动者静之基。人能常清静，天地悉皆归。
