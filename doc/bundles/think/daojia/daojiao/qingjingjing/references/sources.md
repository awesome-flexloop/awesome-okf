## 五、选用策略

1. **研读**：《正统道藏》白文（中华文库底本）——辅以杜光庭注破读。
2. **检索**：维基文库白文 + 中国道教协会官网全文对照。
3. **核对**：任何引文至少两个独立信源核对后方可引用；注文与经文分判，杜光庭注本经后补叙属注本增文。
4. **避坑**：老君说经与葛玄书录传说属托名层，不与"成书三说"的文本层结论混同；赞语三段为经后附文，不与经文正文混引。
