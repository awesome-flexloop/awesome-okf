## 五、选用策略

1. **研读**：内景用《正统道藏》洞玄部本文类白文，外景用务成子注本——辅以梁丘子注（《云笈七签》）义理参照。
2. **检索**：中华文库分章页面 + 古文网全文对照。
3. **核对**：任何引文至少两个独立信源核对后方可引用；注文与经文分判，书法写本异文不据以改经。
4. **避坑**：魏夫人传授诸说属托名层，不与"外景至迟 255 年定型"的文本层结论混同；内外景先后二说属考证层，并列不裁决。
