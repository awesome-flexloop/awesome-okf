# 版本与辑校本

## 今本残存状况

《太平经》原书一百七十卷，今本残佚严重（facts F17、F20）：

| 传本 | 说明 |
|------|------|
| 明《正统道藏》本 | 正统九年（1444）修，现存唯一本子；仅存五十七卷，甲、乙、辛、壬、癸五部全佚，其余几部各亡佚若干卷 |
| 《太平经钞》十卷 | 唐末闾丘方远节录本（诠三十篇，备尽枢要），道藏太平部；校补残卷之唯一别本（fact F18） |
| 敦煌写本残卷 | 见王明《合校》附录"敦煌写本太平经目录"（fact F21） |

## 权威辑校本：王明《太平经合校》

| 项目 | 内容 |
|------|------|
| 编者 | 王明 |
| 出版 | 中华书局 1960 年 2 月第一版（道教典籍选刊，平装上下两册，763 页，ISBN 9787101008784） |
| 底本 | 明《道藏》本 |
| 方法 | 据《太平经钞》及其他二十七种引书加以校、补、附、存（补苴处标"〔并〕"字） |
| 成效 | 基本上恢复一百七十卷的面貌，为通行辑校本（facts F19） |

> 研读底本选择王明《太平经合校》；残卷标"阙题"处不据《太平经钞》径补而不注（[../references/sources.md](../references/sources.md) 选用策略）。

## 历代著录线索

葛洪《抱朴子·遐览篇》著录"太平经五十卷。又甲乙经一百七十卷"；牟子《理惑论》称"神书百七十卷"——汉晋之际已有五十卷本与一百七十卷本两种传本（fact F5）。

## 底本选择原则

1. **原文正字**以王明《太平经合校》（道藏底本系统）为准；
2. **异文登记**：道藏本与《太平经钞》节录本异文、"于/干""徧/遍""於/于"等古今字登记不改字；
3. **残卷处理**：合校本以钞补经处均有标识，引用时注明卷次与篇名，阙题处不妄补。
