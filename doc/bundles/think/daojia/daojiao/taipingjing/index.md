# 《太平经》阅读教程

《太平经》又名《太平清领书》，十部一百七十卷，托"天师"（老君）授干吉（于吉），实为东汉长期累积成形之作，是道教第一部（系统性）经典，早期太平道奉为主要经典（facts F1–F4、F10–F11、F16）。今本残佚严重：明《正统道藏》本仅存五十七卷，甲、乙、辛、壬、癸五部全佚；王明《太平经合校》（中华书局 1960）以《太平经钞》及二十七种引书校补附存，基本上恢复一百七十卷面貌，为通行辑校本（facts F17–F19）。本知识包（bundle）是面向普通读者与研究者的《太平经》系统中文阅读教程，特点有三：

1. **托名层/文本层双层分判**——神授干吉传说（《神仙传》天仙授书、《仙苑编珠》帛和授素书、《太平经复文序》传授谱系）诸说并列登记为托名层，"东汉累积成形、非一时一人所作"为文本层，两层显式分判、不作史实裁决（facts F7–F11）；
2. **关键原文双源核对**——"太平"释义、三合相通与身国同构、承负定义、深自养四组选读段落经至少两个独立信源逐字比对，异文（"徧/遍""於/于""小小失之/小小过失""怳怳/悦悦"）登记不改字；转引类引文如实标注信源层级（facts F22–F28）；
3. **残本优先、教义为纲**——阅读计划只排残存五部（丙丁戊己庚），以"太平—承负—三合相通—深自养"四条教义主线选篇，不逐卷平推。

## 🚀 快速开始

如果你之前从未读过《太平经》：

1. 先读[全书概览](concepts/00-overview.md)了解书名沿革与十部结构
2. 读[成书与神授传说](concepts/01-origin-transmission.md)，分清神授传说与东汉成书两个层面
3. 打开[四周阅读计划](examples/01-reading-plan.md)，第一周先读《后汉书·襄楷传》史源与合校本前言

如果你已有道教知识基础：

1. 从[版本与辑校本](concepts/02-versions.md)开始，理解道藏残本、《太平经钞》与王明《合校》的关系
2. 读[核心概念](concepts/03-core-concepts.md)，抓"太平—承负—身国同构"义理主干
3. 对照[选读段落](concepts/04-selected-passages.md)核对四组双源原文
4. 参考[信源登记](references/sources.md)选用王明《太平经合校》作研读底本
