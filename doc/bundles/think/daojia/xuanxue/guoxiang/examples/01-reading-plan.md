# 四周阅读计划

郭象《庄子注》三十三篇注文体系庞大，零基础读者建议按"版本判读先行"原则分四周通读（insights I2、P2）。底本用郭庆藩《庄子集释》（王孝鱼点校，中华书局）（fact F23）。

## 总原则

1. **版本判读先行**：第一周先明版本系统与底本选择，再读正文；
2. **内篇为纲**：第二周读内篇要篇，抓独化/玄冥/性分观念骨架；
3. **外杂篇为用**：第三周读外杂篇要篇，看观念在政治与处世上的展开；
4. **对读收束**：第四周与成玄英疏及向郭注案对读，回查版本与诠释差异。

| 1 | 通读[全书概览](../concepts/00-overview.md)与[版本系统](../concepts/02-versions.md) | 建立集释本/四库本/注疏本系统地图（facts F23–F25） |
