# 郭象《庄子注》阅读教程

郭象（约 252—312，字子玄）注《庄子》三十三篇，是今传《庄子》的主流本，分内篇七、外篇十五、杂篇十一（facts F1、F5、F7）。郭象注《庄子》在晋惠帝之世，其注与向秀注的关系是玄学史著名公案——《晋书·向秀传》"述而广之"说与《晋书·郭象传》《世说新语》"窃注"说并载，今人研究又有三种意见，本知识包诸说并列、不作裁决（facts F11–F16）。郭注以"独化""玄冥""性分""名教即自然"为核心观念，是魏晋玄学庄学的集成之作（facts F17–F21）。本知识包（bundle）是面向普通读者与研究者的郭象《庄子注》系统中文阅读教程，特点有三：

1. **注案并列不裁决**——"述而广之"说与"窃注"说及今人三说分层登记、并列不裁决；
2. **版本判读先行**——郭庆藩《庄子集释》（中华书局点校本）为权威底本，四库本《庄子注》、《南华真经注疏》、《庄子义疏》诸系统各有异文，引用前须知底本；
3. **关键注文双源核对**——逍遥游篇题注、齐物论天籁注、罔两问景注、大宗师玄冥注等 9 条注文经国学导航集释本 × 汉典古籍/点藏网/识点古籍信源逐字核对，异文登记不改字。

## 🚀 快速开始

如果你之前从未读过郭象《庄子注》：

1. 先读[全书概览](concepts/00-overview.md)了解书名沿革与三十三篇结构
2. 读[生平与时代](concepts/01-life-era.md)，理解向秀注公案两说并列
3. 打开[四周阅读计划](examples/01-reading-plan.md)，按第 1 周计划先读版本判读与逍遥游
4. 通读逍遥游、齐物论后，再看[选读注文](concepts/04-selected-annotations.md)按层选读

如果你已熟悉《庄子》白文本或其他注本：

1. 从[诠释方法](concepts/03-interpretive-method.md)开始，抓独化/玄冥/性分观念骨架
2. 读[版本系统](concepts/02-versions.md)，理解集释本、四库本与注疏本的版本分系
3. 参考[选读注文](concepts/04-selected-annotations.md)对读郭注与成玄英疏
4. 跟着[四周阅读计划](examples/01-reading-plan.md)补齐外杂篇与向郭对读
