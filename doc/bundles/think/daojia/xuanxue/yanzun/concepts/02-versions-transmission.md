# 传本残缺与卷数诸说

## 一、卷数著录诸说（并列，不裁决）

《老子指归》卷数著录历来不一（facts F3、F12）：

| 卷数 | 出处 |
|------|------|
| 十四卷 | 陆德明《经典释文·叙录》、《旧唐书·经籍志》、《新唐书·艺文志》（严遵《老子指归》） |
| 十一卷 | 《隋书·经籍志》（严遵注） |
| 十三卷 | 冯廓《老子指归》（新旧《唐志》）、晁公武《郡斋读书志》、明《正统道藏》本 |

> 本知识包诸说并列，不作裁决。日常引用以王德有点校本（道藏本系统，十三卷存七卷）为准。

## 二、今传本残缺状况

今传本**残缺**（facts F4、F5、F14）：

- **道藏本**：明《正统道藏》洞神部玉诀类收《道德真经指归》十三卷（能字号），原缺卷一至六，仅存《德经》七卷（卷七至卷十三）；
- **六卷本**：题《道德指归论》，明胡震亨《秘册汇函》本、毛晋《津逮秘书》本、张海鹏《学津讨原》本；较道藏本又缺第十三卷，仅存三十四篇；删去经文（仅取每篇开头数字作篇题）、删谷神子注，胡氏改易卷目次序题为一至六卷，并将卷末谷神子注文改题谷神子《道德指归序论》置于卷首。

道经部分亡佚：宋以后仅存德经七卷；道经佚文散见于唐宋《老子》注疏（强思齐《玄德纂疏》、陈碧虚《藏室纂微篇》、李霖《取善集》、刘惟永《集义》），蒙文通、王德有、樊波成先后辑集（facts F14）。

## 三、两大版本系统对比

| 维度 | 道藏本系统 | 六卷本系统 |
|------|-----------|-----------|
| 书名 | 《道德真经指归》 | 《道德指归论》 |
| 代表本 | 明《正统道藏》、怡兰堂丛书本 | 秘册汇函、津逮秘书、学津讨原 |
| 卷数 | 十三卷（存七卷，卷七至十三） | 六卷（卷一至六） |
| 篇数 | 四十篇（德经全） | 三十四篇（缺"人之饥也"至"圣人之道"六篇） |
| 经文 | 保留全文 | 删去，仅取篇首数字作篇题 |
| 谷神子注 | 保留 | 删去，改题《道德指归序论》置卷首 |

（facts F4、F5、F12）

## 四、真伪两说（并载，不裁决）

### 疑伪说

- 明曹学佺《元羽外编序》："近刻严君平《道德指归论》乃吴中伪作"——指吴中刻本改易卷篇、妄加篇名、删去经文、以谷神子注为序而言（facts F15）；
- 焦竑《庄子翼》：《指归》"称引庄子者多矣"，今《庄子》书皆不载，以为皆《庄子》逸篇（facts F15）；
- 《四库全书总目》承二说，断为"赝托"，又指"说目"一篇为好事者据吴澄《道德经注》跋造作（facts F15）。

### 肯定说

- 张岱年据内证肯定为严君平著作：指斥秦楚、颂扬神汉之时代特点；解《老》多引《周易》语句与卜筮之业相合（facts F16）；
- 唐鸿学、蒙文通、张岱年、王利器、李学勤、王德有、那薇、樊波成等从注文用韵、语词字句、律例制度、军制、思想观念考证，认定展现西汉时代特色（facts F16）；
- 学界多认定非伪作，惟承认掺杂部分后人附益（张岱年 1982）（facts F16）。

> 本知识包两说并载，不作裁决。日常阅读以"题严遵撰"表述，涉及真伪论断时注明所持学说。

## 五、权威底本与底本选择

**王德有点校《老子指归》**（中华书局 1994）为权威底本（facts F17）：
- 以道藏本为底本；
- 参校《津逮秘书》本、《怡兰堂丛书》本；
- 从唐宋《老子》注解辑录道经佚文为补遗。

**底本选择建议**：
- 日常阅读：王德有点校本（道藏本系统，含辑佚补遗）；
- 校勘研究：道藏本 × 津逮本 × 怡兰堂本三本对校；
- 引用原文：声明底本（王德有点校本优先），异文登记不改字。

## 六、小结

《老子指归》今传本残缺（仅存德经七卷）、卷数著录有十四/十一/十三卷诸说、真伪有疑伪与肯定两说。阅读前须知：今存七卷非全书，道经已佚；引用须声明底本；真伪问题两说并载不裁决。此为残缺书阅读的基本判读框架。
