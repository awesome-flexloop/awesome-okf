# 四周阅读计划

《南华真经注疏》道藏本三十五卷、注疏合刊，零基础读者建议按"版本判读先行"原则分四周通读（insights I2、I3）。底本用曹础基、黄兰发点校本《南华真经注疏》（中华书局·道教典籍选刊）（fact F15）。

## 总原则

1. **版本判读先行**：第一周先明版本系统与底本选择，再读正文；
2. **疏序为纲**：第一周读疏序，抓"述重玄之妙旨，明独化之窅冥"总纲；
3. **内篇为主**：第二、三周读内篇要疏，逐篇标记双遣落点；
4. **对读收束**：第四周郭注与成疏对读，区分玄学层与重玄层。

## 进阶建议

- 通读一遍后，补读郭庆藩《庄子集释》（收录成玄英全部疏文），看成疏如何被集释引用（fact F17）；
- 对照曹础基黄兰发点校本校记与道藏本异文（facts F15、F16），体会版本系统差异；
- 参考 [信源登记簿](../references/sources.md) 选择在线信源做原文核对练习（模式 P2）；
- 对读成玄英《道德经义疏》辑校本（蒙文通、严灵峰、藤原高男三种），看重玄方法在《老》《庄》两疏中的贯通（fact F10）。
