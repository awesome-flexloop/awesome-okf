# 成玄英《南华真经注疏》阅读教程

《南华真经注疏》为西晋郭象《庄子注》与唐初成玄英疏的合编（唐玄宗天宝元年诏封庄子为"南华真人"，《庄子》遂称《南华真经》），道藏本三十五卷，句下先列郭注、后列成疏（facts F1、F2、F12）。成玄英字子实，陕州人，贞观五年（631）召至京师，赐号"西华法师"，永徽中流郁州；其疏"依子玄所注"三十三篇、"研精覃思三十年"而成，是唐代重玄学以"双遣""重玄"方法疏解《庄子》、融摄老庄与佛教中观的代表作（facts F5–F11、F17–F26）。本知识包（bundle）是面向普通读者与研究者的《南华真经注疏》系统中文阅读教程，特点有三：

1. **生平层与文本层分离**——成玄英生平（召京、赐号、流放）与《庄子疏》文本（卷数诸说、成书年代）分层登记，生卒年诸说并列不裁决；
2. **版本判读先行**——曹础基、黄兰发点校本（中华书局·道教典籍选刊）为权威整理本，道藏本、古逸丛书覆宋本、《庄子集释》本各有分卷与用字差异，引用前须知底本；
3. **关键疏文双源核对**——疏序总纲、《逍遥游》疏、《齐物论》疏、《大宗师》疏及重玄总论等 11 处注文经诗词汇本 × 道藏本系统信源逐字核对，异文登记不改字。

## 🚀 快速开始

如果你之前从未读过《南华真经注疏》：

1. 先读[全书概览](concepts/00-overview.md)了解书名沿革与注疏合编结构
2. 读[生平与时代](concepts/01-life-era.md)，理解成玄英其人与唐初重玄学风气
3. 打开[四周阅读计划](examples/01-reading-plan.md)，按第 1 周计划先读版本判读与疏序
4. 通读《逍遥游》《齐物论》诸疏后，再看[选条导读](concepts/04-selected-annotations.md)按层选读

如果你已熟悉郭象注本《庄子》：

1. 从[诠释方法](concepts/03-interpretive-method.md)开始，抓双遣与重玄
2. 读[版本系统](concepts/02-versions.md)，理解道藏本与点校本的版本分系
3. 参考[选条导读](concepts/04-selected-annotations.md)对读郭注与成疏
4. 跟着[四周阅读计划](examples/01-reading-plan.md)补齐内篇、外杂篇
