# 版本系统

《南华真经注疏》版本分三大系统：道藏本（三十五卷）、曹础基黄兰发点校本（权威整理本）、《庄子集释》本（成疏流传载体）。引用前须先判版本系统与底本（insights I2）。

## 一、道藏本

| 要素 | 说明 |
|------|------|
| 卷数 | 三十五卷 |
| 出处 | 《正统道藏》洞神部玉诀类第 507—519 册 |
| 体例 | 句下先列郭注、后列成疏，注疏合刊 |
| 参校本 | 清《四库全书》本、清光绪二年浙江书局刻本、宋陈碧虚《庄子阙误》 |
| 版本特征 | "玄"字不避讳，可见为宋以后人所編集（facts F2、F16） |

## 二、曹础基黄兰发点校本（权威整理本）

| 要素 | 说明 |
|------|------|
| 书名 | 《南华真经注疏》 |
| 点校 | 曹础基、黄兰发 |
| 出版 | 中华书局·道教典籍选刊，1998 年第 1 版，2023 年第 2 版（ISBN 978-7-101-16051-2） |
| 底本 | 《古逸丛书》覆宋本 |
| 校本 | 《道藏》本、《道藏辑要》本、郭庆藩《庄子集释》、《续古逸丛书》本、世德堂本、刘文典《庄子补正》等（facts F15） |

日常阅读与引用正字以点校本为准；校勘时加道藏本与《庄子集释》本对勘（insights I2）。

## 三、《庄子集释》本

清郭庆藩《庄子集释》（中华书局·新编诸子集成，王孝鱼点校）收录成玄英全部疏文，为成疏流传之重要载体（fact F17）。注意：《庄子集释》本分卷与道藏本不同，以道藏本卷次定位《庄子集释》本必然错位（insights I2）。

## 四、卷数诸说（并列不裁决）

| 出处 | 卷数 |
|------|------|
| 成玄英疏序自云 | "依子玄所注三十三篇，辄为疏解，总三十卷"（一作"依子玄所注三十篇"） |
| 两《唐志》著录 | 成玄英《庄子疏》十二卷 |
| 《文献通考·经籍考》 | 三十三卷 |
| 《天一阁书目》 | 《南华经注疏》三十五卷 |
| 道藏本 | 三十五卷，盖后人所析（facts F3、F33） |

## 五、版本判读流程

1. **定底本**：日常用曹础基黄兰发点校本（《古逸丛书》覆宋本为底本）；
2. **定卷次**：卷次只在所据系统内使用，不跨系统定位；
3. **记异文**：各系统用字差异（如"鉗撻／鉗揵""官冥／窅冥"）登记不改字（facts F31、F32）；
4. **辨讹字**：网络转录本存在系统性替代字（"元"代"無"、"淇"代"冥"、"束"代"東"），引用前须双源核对（insights I4）。
