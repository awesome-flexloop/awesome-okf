# 生平与时代

成玄英，字子实，陕州（今河南陕县）人，唐初道士、道教学者，重玄学集大成者（facts F5、F11）。其生平史料有限，本知识包按"生平层／文本层"分离原则陈述：生平诸说并列不裁决，成书背景独立登记（insights I1）。

## 史传生平

《新唐书·艺文志》道家类注（fact F4）：

> 玄英，字子实，陕西人，隐居东海，贞观五年，召至京师。永徽中流郁州。书成，道王元庆遣文学贾鼎就授大义，嵩高山人李利涉为序，惟《老子注》《庄子疏》著录。

生平要点（facts F5、F6）：

| 事项 | 记载 |
|------|------|
| 字号籍贯 | 字子实，陕州（今河南陕县）人 |
| 隐居 | 曾隐居东海 |

| 流放 | 永徽（650—655）中流郁州（今江苏连云港云台山），于流放期间注疏《老》《庄》 |

## 自述：研精覃思三十年

成玄英疏序自述（双源核对，facts F8、F33）：

> 玄英不揆庸昧，少而习焉，研精覃思三十年矣。依子玄所注三十三篇，辄为疏解，总三十卷。

- "依子玄所注"表明成疏以郭象注为基础作疏（fact F1、F29）；
- "三十三篇"句有异文：道典词典引序作"依子玄所注三十篇"（登记不改字，fact F33）。

## 佛道论争与《道德经》梵译

贞观年间成玄英参与佛道论争；贞观二十一年（647）与蔡子晃等参与玄奘主持的《道德经》梵译（fact F9）：

- 成玄英负责为玄奘讲解《道德经》义，欲译"道"为 bodhi（菩提），玄奘不许，改译 mārga（道迹）；
- 又奏请同译《河上公注》，亦被拒。

此事是唐初佛道交涉与成疏"融摄中观"诠释取向的时代坐标（facts F9、F22）。

## 著述与流传

成玄英著述（fact F10）：

| 著作 | 存佚 |
|------|------|
| 《周易流演》 | 佚 |
| 《度人经注疏》 | 佚 |
| 《老子道德经开题序诀义疏》 | 已佚，散见辑本 |
| 《道德真经义疏》 | 已佚，散见强思齐《道德真经玄德纂疏》与顾欢《道德真经注疏》 |
| 《庄子疏》 | 存，收入《南华真经注疏》与郭庆藩《庄子集释》 |

今有蒙文通《老子成玄英疏》六卷、严灵峰《道德经开题序诀义疏》五卷、〔日〕藤原高男《辑校赞道德经义疏》三种辑校本（fact F10）。

蒙文通谓道家之学"唐代前期，首推成、李"（李即李荣）；成玄英被公认为重玄学集大成者（fact F11）。

## 唐初道教背景

| 要素 | 说明 |
|------|------|
| 王朝崇道 | 李唐尊老子为远祖、崇奉道教，组织佛道论争，道教地位抬升 |
| 成书背景 | 成玄英《庄子疏》成书于此背景之下（fact F12） |
| 重玄谱系 | 杜光庭《道德真经广圣义》：注老以"重玄"为宗始于魏隐士孙登；此后梁孟智周、臧玄静，陈诸柔，隋刘进喜，唐成玄英、蔡子晃、黄玄颐、李荣、车玄弼、张惠超、黎元兴，皆明重玄之道（fact F14） |
| 集成定位 | "重玄之理"肇源于郭象《庄子注》，孙登运用于诠释《老子》，最后由成玄英在《庄子疏》和《道德经义疏》中集成（fact F13） |

## 阅读提示

读成玄英疏须知：

1. 成玄英为唐初道士，生平史料有限，生卒年诸说并列，引用时统一表述"唐初道士成玄英（约活动于贞观、永徽年间）"；
2. 疏序所述庄子生平（"师长桑公子，受号南华仙人"）为成玄英所述，含传说成分，不可当作信史（fact F7）；
3. 理解成疏的重玄与融摄中观取向，须置于唐初崇道、佛道论争与重玄学派谱系之中（facts F9、F13、F14）。
