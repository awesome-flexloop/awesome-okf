# Insights — 《河上公章句》洞察与模式（I/E 阶段 · G2/G3）

## 洞察（G2 四元组：现象/根因/影响/建议）

### I1 托名书的署名须分"托名层/文本层"两层陈述
- 现象：《河上公章句》题河上公撰，"河上公授汉文帝"之说始见于三国吴葛玄《序诀》与晋葛洪《神仙传》；《史记》仅载战国末"河上丈人"而未言作注；成书年代有西汉、东汉、两汉之际、魏晋以后诸说并列（facts F5–F16）。
- 根因：汉代托古著书为通行成书方式，依托传说（托名层）与文本实际成书（文本层）年代可以相距数百年；早期目录学著录（《隋志》）已把传说当作事实著录。
- 影响：直题"汉文帝时河上公著"会把托名传说当史实，进而以传说年代裁剪文本思想；反之完全否认传说又与著录传统冲突。
- 建议：统一采用"题河上公撰（旧题汉河上公注）"表述；传说与成书年代诸说分层登记、并列不裁决；涉及年代论断时注明所持学说与代表学者。

### I2 注本引用须先判版本系统
- 现象：《河上公章句》有道藏本、影宋本、敦煌唐写本等六大类版本；敦煌诸本与唐代诸本均无章名，章名为后人所加；道藏本与维基文库本在"生長／長生""五藏配属次序"等处存在异文（facts F17–F21、F29–F36）。
- 根因：该书流传跨度长（唐抄至明道藏），各系统经翻刻、辑录产生分化；章题体制本身是层累形成的。
- 影响：不判版本直接抄录，会把某一系统的异文或章名当作全书原貌；以章名定位敦煌本必然落空。
- 建议：引用前声明底本（日常用王卡点校本，校勘加敦煌本与影宋本）；异文登记不改字；章名只在道藏本/宋本系统内使用。

### I3 "治身治国双线"是河上注的第一读法
- 现象：陆德明概括此书要旨为"言治身治国之要"；注文中大量出现"治國者……治身者……"对举句式（如"治國者當愛民財……治身者當愛精氣""治國煩則下亂，治身煩則精散"）；侧重之判王明、王卡两说并载（facts F22–F25、F34）。
- 根因：汉代黄老学本以无为治国与清净养生为一事之两面，注者将《老子》政治命题与养生命题互训。
- 影响：只按政治哲学读会漏掉养生论注文（"谷神不死"被解为养神不死）；只按养生读会漏掉治国维度，且无法解释注文的双语句式。
- 建议：通读时以"双线"为默认框架，逐章标记注文落在治国、治身还是并举；侧重问题（养生为主还是并重）两说并载不裁决。

### I4 网络通行注本存在版本混拼，注文引用须双源核对
- 现象：本次核对发现维基文库本与道藏本在体道第一注（"生長／長生"）、成象第六注（五藏配属次序与"意"字有无）等处存在异文；维基文库章题无"第几"字样，道藏本、宋刊本有（facts F29、F31、F36）。
- 根因：在线文本各据不同版本系统转录（维基文库所据底本与道藏本不同），且章题、标点为转录者所加。
- 影响：单一信源抄录会把某一系统的异文当作定本；章题差异会造成跨版本定位混乱。
- 建议：入库注文至少经两个独立信源（维基文库 + 道藏本系统）逐字核对；异文处登记不改字；正字以王卡点校本为准。

## 可复用模式（E · G3）

### P1 托名书判读框架
- 触发场景：整理托名古籍（《河上公章句》《黄帝内经》《列子》等）知识时。
- 核心步骤：①拆托名层（依托对象与传说，最早文献出处）；②拆文本层（成书年代诸说并列，各说代表学者与论据）；③两层分开陈述，不以传说年代裁剪文本。
- 反模式：把托名传说当作者生平；用单一断代掩盖诸说分歧。
- 迁移示例：concepts/01-authorship-dating 按两层组织。

### P2 双源逐字核读法（《河上公章句》版）
- 触发场景：任何需要给出《河上公章句》原文/注文片段的写作/整理任务。
- 核心步骤：①声明底本（王卡点校本优先）；②选至少 2 个独立在线信源（维基文库 + 道藏本系统如点藏网/道人家）；③分别抄录目标段落；④逐字比对并登记异文（位置/各本作某）；⑤异文处加注不改字；⑥章名只在道藏本/宋本系统内使用。
- 反模式：单一百科/文库直接抄录；把章名套到敦煌本上；静默统一异文。
- 迁移示例：本 bundle 双源核对记录见 [log.md](log.md)，核对结果登记于 [facts.md](facts.md) F29–F36。

### P3 双线注文标记读法
- 触发场景：通读治身治国型注本（河上注、《老子指归》等）。
- 核心步骤：①通读时逐章标记注文落点（治国/治身/并举）；②汇总对举句式（"治國者……治身者……"）作为旨要证据；③以目录学要旨概括（如陆德明"言治身治国之要"）回验标记结果。
- 反模式：只按单一维度（政治或养生）选读注文；忽略对举句式。
- 迁移示例：concepts/03-interpretive-features 与 examples/01-reading-plan 按此组织。
