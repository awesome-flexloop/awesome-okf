# 版本系统

《河上公章句》版本系统复杂，王卡分为六大类（fact F17）：唐代抄本及引述文献、日本旧抄本和刻本、宋刻本、纂图互注本、道藏诸本、明清刻本。阅读与引用须先判版本（insights I2、P2）。

## 权威底本：王卡点校本

| 项目 | 内容 |
|------|------|
| 书名 | 《老子道德经河上公章句》 |
| 点校者 | 王卡 |
| 出版 | 中华书局·道教典籍选刊，1993 年第 1 版（ISBN 7-101-01080-6/B·207） |
| 底本 | 道藏本（《正统道藏》洞神部玉诀类《道德真经注》） |
| 参校 | 四部丛刊影宋本（宋建安虞氏刊本）、敦煌 S.477、S.3926 号写本 |

（fact F21，调研基座 [G]）原文正字与校勘以此本为首选。

## 三大版本系统

### 一、道藏本系统

- 明《正统道藏》洞神部玉诀类收《道德真经注》（题"河上公章句"）四卷；"匡"字减笔避宋太祖讳，当系从北宋政和刊旧道藏翻刻，其篇第近古（fact F19）。
- 另有全录或节录河上公注文之《道德真经注疏》（顾本）、《道德真经玄德纂疏》（强本）、《道德真经集注》（集注本）等数种（fact F19）。
- 王卡点校本即以道藏本为底本。

### 二、宋刻本系统（影宋本）

- 代表为四部丛刊影印常熟瞿氏铁琴铜剑楼藏宋建安虞氏刊本（影宋本）；编首节录葛玄《老子道德经序诀》以为序，正文各章前有章名（fact F20）。

### 三、敦煌唐写本系统

敦煌遗书中有唐抄《老子河上公章句》四种（fact F18）：

| 编号 | 内容 | 备注 |
|------|------|------|
| S.477 | 起第三章，终第二十章 | 各章无章名 |
| S.4681-P.2639 | 德经，起第三十八章，终第七十七章 | — |
| S.3926 | 德经，起第三十九章，终第八十一章 | — |
| BD0004 | 写本 | — |

> **关键版本学结论**：敦煌诸本及唐代其他版本均无章名，章名当系后人所加，唐以前无此（facts F18、F36）。

## 版本选择建议

| 用途 | 推荐版本 |
|------|---------|
| 日常阅读与引用正字 | 王卡点校本（中华书局） |
| 校勘与异文研究 | 王卡点校本校记 + 敦煌写本 + 影宋本 |
| 道教义理研究 | 道藏本系统（含顾本、强本、集注本） |
| 早期文本形态 | 敦煌唐写本（无章名形态） |

## 与王弼本的关系

河上公本与王弼本为《老子》传世本两大系统，与严遵《老子指归》、傅奕本合称传世本四大体系；河上本多被道教人士与民间推崇，王弼本广为文人学士喜好（fact F27）。两本文字、分章、注文风格均有差异，对读见[选读章句](04-selected-chapters.md)。
