# 全书概览

## 三书结构

王弼注系统由三书构成，另有《老子指略》辑本（facts F5、F6）：

| 书名 | 对象 | 说明 |
|------|------|------|
| 《老子道德经注》 | 《老子》 | 王弼本《道德经》系统所附注本，以「以无为本」为宗 |
| 《周易注》 | 《周易》 | 为《周易正义》所据注本，后世与韩康伯注合行（fact F9） |
| 《周易略例》 | 《周易》体例 | 分明彖、明爻通变、明卦适变通爻、明象、辩位、略例下、卦略七篇（fact F7） |
| 《老子指略》 | 《老子》旨要 | 又名《老子微旨例略》，辑本，底本《正统道藏》正一部（fact F6） |

## 注经体制

王弼注为自著注，文本基本可信，与河上公等托名注本不同（facts F1、F6）。其注经体制要点：

1. **随文作注**——《老子道德经注》《周易注》均逐句随文注，注文嵌入经下；
2. **略例总纲**——《周易略例》独立成篇，总括《周易》诠释体例，"大则揔一部之指归，小则明六爻之得失"（fact F7）；
3. **指略提要**——《老子指略》以玄学本与论概述《老子》旨要，"无形无名者，万物之宗也"（fact F15）。
