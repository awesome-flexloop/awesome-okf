# 版本系统

王弼注的版本判读分两条线：《老子道德经注》的王弼本系统，与《周易注》的正义底本系统（insights I2）。

## 一、《老子道德经注》版本

### 王弼本系统

王弼本《老子》为《老子》传世本两大系统之一（与河上本分系）。以王弼本为代表的今本系统与出土帛书、竹简系统有别：帛书甲乙本"常"均作"恒"，王弼本、河上公本四句后无语气词"也"字（fact F8、R12）。

洪颐烜所记早期传本与今本王弼本的分章差异（fact F8）：

> 道德经王辅嗣本，今世所行，俱有分章。此本虽不记章数，然每章皆空一格以别之。其中亦有与今王本不同者，如今王本"道冲而用之"至"象帝之先"为三章，"天地不仁"至"不如守中"为四章，"谷神不死"至"用之不勤"为六章，此本皆并为一。

**注意**：今本王弼本分章为后人所定，早期传本分章与之不同；引用分章时须知所据底本。

## 二、《周易注》版本

王弼《周易注》为孔颖达《周易正义》所据注本；后世与韩康伯注合行（fact F9）。

**注意**：合行本中王弼注与韩康伯注分属不同卷次，引用时须注明所据为王注还是韩注。

## 三、《周易略例》版本

《周易略例》七篇（明彖、明爻通变、明卦适变通爻、明象、辩位、略例下、卦略），卷首有唐四门助教邢璹序（fact F7）。维基文库载全篇（R6）。

## 版本判读要点

1. 引用《老子》注先声明底本（日常用楼宇烈校释本）；
2. 王弼本与河上本、帛书本分系，跨本对读时注明系统；
3. 《周易注》引用注明王注/韩注；
4. 在线信源异文登记不改字（facts F16–F24）。
