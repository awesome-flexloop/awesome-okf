# 王弼《老子道德经注》《周易注》阅读教程

王弼（226—249），字辅嗣，曹魏山阳高平人，正始玄学代表（facts F1）。其《老子道德经注》《周易注》《周易略例》以「以无为本」为宗，倡「崇本息末」「得意忘言」，援道入儒，开魏晋义理注经之风（facts F5）。王弼注为自著注，文本基本可信，与河上公等托名注本不同（facts F6）。《老子注》附于王弼本《道德经》系统，《周易注》为《周易正义》所据注本，后世与韩康伯注合行（facts F4、F6）。本知识包（bundle）是面向普通读者与研究者的王弼注系统中文阅读教程，特点有三：

1. **生平与文本层合一**——王弼为信史注家，生平（《三国志》附传）与注本成书（正始年间）一体陈述，无托名分层问题；
2. **版本判读先行**——楼宇烈《老子道德经注校释》《王弼集校释》（中华书局）为权威底本，王弼本《道德经》与河上本分系，引用前须知底本；
3. **关键注文双源核对**——首章、四十章、十一章、《周易略例·明象》、复卦注等注文经中华文库 × 流芳阁/道德经.org/汉典古籍等信源逐字核对，异文登记不改字。

## 🚀 快速开始

如果你之前从未读过王弼注：

1. 先读[全书概览](concepts/00-overview.md)了解王弼三书结构与注经体制
2. 读[生平与时代](concepts/01-life-era.md)，理解王弼为正始玄学代表、注为自著
3. 打开[四周阅读计划](examples/01-reading-plan.md)，按第 1 周计划先读版本判读与首章注
4. 通读首章、四十章诸注后，再看[选条导读](concepts/04-selected-annotations.md)按层选读

如果你已熟悉河上公注本《老子》：

1. 从[诠释方法](concepts/03-interpretive-method.md)开始，抓「崇本息末」「得意忘言」
2. 读[版本系统](concepts/02-versions.md)，理解王弼本与河上本的版本分系
3. 参考[选条导读](concepts/04-selected-annotations.md)对读王弼注与河上注
4. 跟着[四周阅读计划](examples/01-reading-plan.md)补齐《老》注、《易》注
