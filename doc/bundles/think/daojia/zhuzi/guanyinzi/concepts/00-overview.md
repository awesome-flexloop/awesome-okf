# 全书概览

《关尹子》题周关令尹喜撰，是唐宋之际依托而成的道家著作，宋徽宗尊号《文始真经》（facts F5、F7）。全书以道为本，论心性、生死、梦觉，四库提要评其"核其词旨，固远出《天隐》《无能》诸子上，不可废也"（fact F13）。

## 书名与作者

- 书名即作者之号。"关尹"为守关之官，尹喜为周之关令（守函谷关），相传老子西出函谷关时，尹喜望见紫气浮关，知真人将至，候物色而迩之，请老子著《道德经》上下篇（facts F7、F9）。
- 《汉书·艺文志》道家类著录"《关尹子》九篇"；刘向《列仙传》作《关令子》（fact F1）。
- 托名层：传统题周关令尹喜；《经典释文》载喜字公度；李道谦《终南祖庭仙真内传》称终南楼观为尹喜故居（facts F7、F8）。
- 《庄子·天下》篇以关尹与老聃并称——此为托名层依托的历史依据，非今本《关尹子》文本之证（fact F9）。

## 篇卷结构

今传本一卷九篇（南宋徐蒇所得永嘉孙定家本系统）（facts F3、F6）：

| 篇 | 篇题释义 | 内容大旨 |
|----|---------|---------|
| 一宇 | 宇者，道也 | 道论总纲：不可言、不可思、不可为、不可致 |
| 二柱 | 柱者，建天地也 | 天地阴阳之建（观天地之运） |
| 三极 | 极者，尊圣人也 | 圣人观：以一己治天下与以天下治天下 |
| 四符 | 符者，精神魂魄也 | 精神魂魄五行论、生死一气聚散 |
| 五鉴 | 鉴者，心也 | 心性论：心蔽、识智、情波性水 |
| 六匕 | 匕者，食也 | 养生食味之喻 |
| 七釜 | 釜者，化也 | 变化陶铸之喻 |
| 八筹 | 筹者，物也 | 物情筹算 |
| 九药 | 药者，杂治也 | 杂治众病（应物之方） |

篇题各系释义，葛洪序与篇题同（"宇者道也，柱者建天地也……"）（fact F6）。

## 思想定位

- 调研基座定位：以「道」为本，论心性、生死、梦觉（权威性评级 C）[G]。
- 四库提要："其书虽出于依讬，而核其词旨，固远出《天隐》《无能》诸子上，不可废也"（fact F13）。
- 四库提要同时指出其书"多法释氏及神仙方技家"（变识为智、一息得道、金楼绛宫之类）——文本层的唐宋特征（facts F11、F20）。
- 本教程采用"唐宋依托道书，心性梦觉思想有独立价值"的定位（见 [03-core-concepts.md](03-core-concepts.md)）。

## 历史评价

- 宋濂《诸子辩》疑永嘉孙定伪为，又谓"其文峻洁，而颇流于巧刻"（facts F10、F11）。
- 四库提要折中："或唐、五代间方士解文章者所为也"，而"不可废"（facts F12、F13）。
