# 三周阅读计划

《关尹子》一卷九篇篇幅不大（约一万五千字），但为依托道书且真伪问题特殊，零基础读者建议按"真伪之辩先行"原则分三周通读重点篇（insights P3）。底本用维基文库本；在线对照用维基文库本 × 古诗文网本（四库影印/道藏影印作第三方）（facts F22、R3/R4）。

## 总原则

1. **真伪之辩先行**：第 1 周先读真伪文献（宋濂《诸子辨》、四库提要、《墨庄漫录》反证），建立"依托而不可废"的判读框架再入文本——这是本书区别于一般先秦子的阅读起点；
2. **道论为入路**：第 1 周后半读《一宇》，从道的否定性定义入手（文从字顺，易建立信心）；
3. **心性为纲**：第 2 周读《三极》《五鉴》，抓圣人观与心性梦觉的义理主干；
4. **方技收束**：第 3 周读《四符》与余篇，回查真伪之辩验证理解。

## 进阶建议

- 通读一遍后，以四库本与道藏本对照异文（fact F26），体会版本系统差异；
- 延伸阅读《天隐子》《无能子》（四库提要用作对比的同类依托道书），完成"依托道书"的对照阅读（fact F13）；
- 对照《庄子·天下》篇关尹、老聃并称段，理解托名层的历史依据（fact F9）。
