# 《管子》道家四篇阅读教程

「管子道家四篇」指《管子》书中的《心术上》（第三十六）、《心术下》（第三十七）、《白心》（第三十八）、《内业》（第四十九）四篇（facts F1）。《管子》全书托名春秋齐相管仲，《汉书·艺文志》列入道家类（facts F3、F5）；四篇的文本层则为战国中晚期稷下道家（黄老）作品，作者佚名，非管仲自著——这是学界共识（facts F6）。四篇作者归属存在两说并置：郭沫若《宋钘尹文遗著考》（1944）主张四篇为宋钘、尹文学派遗著；蒙文通、裘锡圭、白奚等则主张泛稷下黄老（道家）说，认为不必确指何人之书（facts F7–F10）。四篇以精气说、心术论、静因之道为义理主干，是先秦道家"以心受道"的代表文本（facts F12–F18）。

本知识包（bundle）是面向普通读者与研究者的四篇系统中文阅读教程，特点有三：

1. **关键原文双源核对**——《内业》精气段、《心术上》静因段、《白心》开篇等 10 处原文经 ctext.org、维基文库、汉典古籍等独立信源逐字核对，异文登记不改字；
2. **托名层与文本层分离**——全书托名管仲（托名层）/四篇为战国稷下道家作品（文本层）两层陈述，不题"管仲著四篇"；
3. **作者归属两说并置**——宋钘尹文遗著说与泛稷下黄老说并列陈述，不作单一裁决。

如果你之前从未读过四篇：

1. 先读[全书概览](concepts/00-overview.md)了解《管子》今本结构与四篇位置

3. 参考[版本与注本](concepts/02-versions.md)选择权威整理本
4. 跟着[选读导读](concepts/04-selected-passages.md)逐段核对原文
