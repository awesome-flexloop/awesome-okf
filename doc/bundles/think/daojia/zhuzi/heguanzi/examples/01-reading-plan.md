# 三周阅读计划

《鹖冠子》三卷十九篇篇幅不大（约二万余字），但义理密度高且真伪问题特殊，零基础读者建议按"真伪之辩先行"原则分三周通读重点篇（insights I1）。底本用黄怀信《鹖冠子校注》（fact F33）；在线对照用 ctext（四部丛刊本）× 维基文库（四库本/标点本）（facts F32、R1/R4/R5）。

## 总原则

1. **真伪之辩先行**：第 1 周先读真伪文献（韩愈《读鹖冠子》、柳宗元《辩鹖冠子》、四库提要），建立判读框架再入文本——这是本书区别于一般先秦子的阅读起点；
2. **政治刑名为入路**：第 1 周后半读《博选》《天则》，从选贤与法度入手（文从字顺，易建立信心）；
3. **道论为纲**：第 2 周读《环流》《泰鸿》《度万》，抓宇宙生成与太一观念的义理主干；
4. **兵学收束**：第 3 周读兵学四篇与名句篇，回查真伪之辩验证理解。

## 进阶建议

- 通读一遍后，补读卷中《王鈇》（成鸠氏之制，刑名落实到制度的最长样本，fact F26）与卷下《备知》《世贤》《天权》《能天》；
- 对照四库本与四部丛刊本异文（fact F35），体会版本系统差异；
- 以黄怀信《鹖冠子校注》逐篇精读，关注其汇校按语（fact F33）；
- 延伸阅读马王堆帛书《黄帝四经》（《经法》《十六经》），完成黄老系统的对照阅读（fact F18）。
