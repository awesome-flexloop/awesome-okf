# ⚖️ 法家（Legalism）知识包

本域收录先秦法家经典著作的 OKF 知识包。法家文献多为学派结集（托名管仲、商鞅等），各知识包均显式标注成书性质，原文经多源实抓核对、异文显式登记，不虚构任何引文。

## 知识包列表

| 知识包 | 定位 | 说明 |
|--------|------|------|
| [管子](guan-tzu/index.md) | 稷下学宫法治经济思想总集 | 以《经言》四篇为核心概念源，覆盖仓廪礼节论、牧民纲领、任法治国、轻重调控之术、稷下学派编纂五大概念域，附《牧民》《任法》精读与校释传统信源 |
| [商君书](shang-jun-shu/index.md) | 商鞅学派耕战法治思想总集 | 托名商鞅、实为商鞅学派结集；覆盖农战一体、壹赏壹刑壹教、弱民强国论、历史进化观、法治工具论五大概念域，附《更法》《开塞》三源精读与蒋礼鸿锥指、Pines 译注两份信源谱系 |
| [韩非子](han-fei-tzu/index.md) | 法家集大成的法·术·势体系阅读教程 | 以九篇核心篇章为骨架，覆盖法术势三纲、性本利论、参验方法论、刑名之学、法不阿贵等八大概念域，附《五蠹》《孤愤》《说难》三篇双源精读 |
| [早期法家辑佚](early-legalists/index.md) | 申不害·慎到残籍与法家源流 | 《申子》《慎子》辑佚残篇细读（佚文逐条标注辑佚出处），附法家源流谱系（李悝→申商→韩非）、《汉书·艺文志》著录、黄老到法家过渡与辑佚/西方研究信源 |
