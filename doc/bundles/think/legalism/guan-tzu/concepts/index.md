# 管子概念总目

《管子》概念体系围绕"富国—治民—任法"三轴展开。本分区收录五个核心概念，每个概念文档独立成篇，事实依据可回溯至信源事实登记（F-GZ 编号）。

| 稷下编纂 | [jixia-compilation.md](jixia-compilation.md) | 托名管仲的学派文集 | F-GZ-001 至 F-GZ-011 |

## 概念间关系

- 仓廪礼节论为牧民纲领提供物质基础论证，牧民纲领以四维约束补足教化维度。
- 任法治国与牧民纲领构成治理的刚柔两面：法为轨度，民心为向背。
- 轻重之术是富国目标在经济层面的操作化，与仓廪论同属经济思想链条（F-GZ-037）。
- 稷下编纂说明以上概念的多源混合性质：法家、道家、儒家成分并存（F-GZ-009）。
