# 任法精读

## 原文层（实抓引文）

法的恒常地位（实抓）：

> "法者不可不恒也，存亡治乱之所以从，圣君所以为天下大仪也。"

（信源：https://ctext.org/guanzi/ren-fa/zhs，底本《四部丛刊初编》本《管子》）

任法四不任（实抓）：

> "圣君任法而不任智，任数而不任说，任公而不任私，任大道而不任小物。"

（信源：https://ctext.org/guanzi/ren-fa/zhs）

法法对举句（实抓，同系统参照）：

> "不法法，则事毋常；法不法，则令不行。"

（信源：https://ctext.org/guanzi/fa-fa/zhs）

## 结构层

《任法》篇以"任法"为题，论证分四步：

1. **法本体**：法为存亡治乱之所从（国家命运的依从对象）、天下大仪（最高仪则）——F-GZ-031。
2. **施政方式**：任法/任智、任数/任说、任公/任私、任大道/任小物四组对举，排除君主个人智巧、辩说、私意对小物的干预——F-GZ-032。
3. **法之效力**：《法法》篇"不法法，则事毋常；法不法，则令不行"以对举句式论证法须被一体遵行——F-GZ-034。
4. **篇名自证**：《法法》篇名取"以法行法"之意，法之效力高于君主个人好恶——F-GZ-033。

## 释义层

- "存亡治乱之所以从"将法置于国家命运的解释变量位置：法非工具而是轨度——回链 [任法治国](../concepts/ren-fa-governance.md)。
- 四不任结构将君主权力置于法下：任数（法度之数）不任说（私辩）、任公不任私，与《立政》三本（德位、功禄、能官相称，F-GZ-026）共同构成官职授受的法度化方案。
- 与《牧民》的关系：《任法》立刚性轨度，《牧民》立民心判据与四维教化（F-GZ-014、F-GZ-013）——两篇合观呈现管子法治的刚柔并置结构，为其稷下多源性质（F-GZ-009）的一例。
