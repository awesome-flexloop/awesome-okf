# 早期法家概念总目

早期法家概念体系围绕"法—术—势"三支柱及其学派生成脉络展开：申不害以"术"驭臣（循名责实），慎到以"势"立君（贤势之辩），商鞅以"法"齐民；三源汇于韩非"帝王之具"（F-EL-008）。学派生成则经历黄老道德之术—刑名—法家的演进（F-EL-003、F-EL-010）。本分区收录四个核心概念，每个概念文档独立成篇，事实依据可回溯至信源事实登记（F-EL 编号，共 31 条）。

## 概念间关系

- 法家源流提供著录与谱系框架：汉志十家著录（F-EL-001）是全部存佚判断的书目学基线，李悝—申—慎—商—韩谱系（F-EL-008、F-EL-026、F-EL-028）提供概念演进的时间轴。
- 申不害之术与慎到之势分别回答"君如何驭臣"（循名责实的行政监察）与"君何以立"（权位先于贤德）两个问题，二者与商鞅之法在韩非处合流。
- 从黄老到法家解释学派出处：申、慎均自黄老道德之术转出而主刑名（F-EL-003、F-EL-010），稷下学宫"不治而议论"（F-EL-011）是其制度温床。
