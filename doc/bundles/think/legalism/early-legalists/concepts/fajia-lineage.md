# 法家源流与《汉书·艺文志》著录

## 一、汉志法家类著录：十家二百一十七篇

《汉书·艺文志》诸子略法家类著录十家，凡二百一十七篇（F-EL-001）：

| 著录 | 篇数 | 注语 |
|---|---|---|
| 《李子》 | 三十二篇 | 名悝，相魏文侯，富国强兵 |
| 《商君》 | 二十九篇 | 名鞅，姬姓，卫后也，相秦孝公，有《列传》 |
| 《申子》 | 六篇 | 名不害，京人，相韩昭侯，终其身诸侯不敢侵韩 |
| 《处子》 | 九篇 | （无注） |
| 《慎子》 | 四十二篇 | 名到，先申、韩，申、韩称之 |
| 《韩子》 | 五十五篇 | 名非，韩诸公子，使秦，李斯害而杀之 |
| 《游棣子》 | 一篇 | （无注） |
| 《晁错》 | 三十一篇 | （无注） |
| 《燕十事》 | 十篇 | 不知作者 |
| 《法家言》 | 二篇 | 不知作者 |

这份清单是本包全部存佚判断的书目学基线：十家中今有完本传世者唯《韩子》（五十五篇大体存）；《商君》残为今本二十六篇实存二十四篇（另见本库商君书知识包）；《申子》《慎子》散佚最重，构成本包的辑佚对象；《李子》《处子》《游棣子》《燕十事》《法家言》则几乎全赖他书转述。

汉志法家小序给出学派定位："法家者流，盖出于理官，信赏必罚，以辅礼制。"（F-EL-002）

## 二、司马谈《论六家要旨》的法家评语

司马谈《论六家要指》（《史记·太史公自序》引）评法家："法家严而少恩，若尊主卑臣，明分职不得相逾越，虽不能弗能改也。"（F-EL-027，转引）

评语分两层：先下一句总断（严而少恩），再指出其不可替代处——"尊主卑臣，明分职不得相逾越"正是"信赏必罚"（F-EL-002）的另一种表述。司马谈以"虽不能弗能改也"承认法家之术有百世不可废者，与班固"以辅礼制"（F-EL-002）同样将法家定位为体制的执行装置而非价值源头。

## 三、李悝：《法经》起点与李悝李克公案

源流的起点是李悝。汉志法家类首列《李子》三十二篇，注"名悝，相魏文侯，富国疆兵"；而儒家类著录《李克》七篇，注"子夏弟子，为魏文侯相"。章太炎断李悝、李克"当是一人"（《检论·原法》注）（F-EL-028）。

李悝著《法经》，见《晋书·刑法志》（F-EL-028）。《法经》今亡，其"富国强兵"事功与"《法经》立法"意义均赖史源转述——这决定了早期法家源头文献只能以辑佚方式处理。

侯外庐《前期法家及其历史的觉醒》给出源流的义理判语："礼在于'别'，而法在于'齐'"，"'范天下之不一，而归之于一'（《说文》）"，并称法家为"中国古代商品关系的理论完成者"（F-EL-028）。

## 四、术、法、势三分与韩非集大成

谱系的中间环节由《韩非子·定法》固定下来："申不害言术，公孙鞅为法……此不可一无，皆帝王之具也。"（F-EL-008、F-EL-026）慎到的位置则由汉志注语"先申、韩，申、韩称之"（F-EL-001）与《吕氏春秋·慎势》高诱注"在申不害、韩非前，申、韩称之"（F-EL-024）锁定。

韩非在《定法》中同时给出集大成判词与批评：申不害"不擅其法，不一其宪令"之弊（F-EL-008）说明术无法则乱，法无术则弊——集大成不是并置，而是以互补论证完成收编。
