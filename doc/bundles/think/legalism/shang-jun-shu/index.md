# 商君书（Shang Jun Shu）

《商君书》历代著录异名有《商君》《商君书》《商子》三种（F-SJS-008）。《汉书·艺文志》法家类著录《商君》二十九篇（F-SJS-001）；今传本共五卷二十六篇，其中第十六篇《刑约》存目无文、第二十一篇篇名亡佚有录无文，实存正文二十四篇（F-SJS-002）。

## 成书性质（托名与结集）

此书非商鞅亲著、为商鞅学派结集，本包在全部文档中显式标注这一属性：

- 《四库全书总目提要》评："殆法家流，掇鞅余论，以成是编。"（F-SJS-009）
- 《更法》《错法》《徕民》等多篇涉及商鞅死后之事，学界以此为非商鞅亲著的重要依据（F-SJS-010）。
- 《四部丛刊》景印天一阁刻本所附提要考辨："孝公卒后，鞅即逃死不暇，安得著书？如为平日所著，则必在孝公之世，又安得开卷第一篇即称孝公之谥？"（F-SJS-011）
- 学界作者归属三说：基本伪书说（郭沫若、黄云眉、顾实、刘汝霖）、基本商鞅自著说（吕思勉、谭献）、商鞅遗著与后学合编说（高亨）（F-SJS-012）。
- 司马迁《史记·商君列传》赞语："余尝读商君开塞耕战书，与其人行事相类。"（F-SJS-014）

本包不裁决作者归属争议，按"商鞅学派结集"呈现文本，诸说并存于[信源谱系](references/index.md)。

## 核心概念一览

1. **农战一体**（[concepts/nong-zhan-yiti.md](concepts/nong-zhan-yiti.md)）——国之所以兴者农战，官爵之授与农战直接挂钩
2. **壹赏壹刑壹教**（[concepts/yi-shang-yi-xing-yi-jiao.md](concepts/yi-shang-yi-xing-yi-jiao.md)）——利出一孔的赏刑教三位一体体系
3. **弱民强国论**（[concepts/ruo-min-qiang-guo.md](concepts/ruo-min-qiang-guo.md)）——民弱国强、民强国弱的国民张力命题
4. **历史进化观**（[concepts/historical-evolution.md](concepts/historical-evolution.md)）——不法古不修今、三代异势而皆可以王
5. **法治工具论**（[concepts/fa-as-instrument.md](concepts/fa-as-instrument.md)）——以刑去刑、国皆有法而无使法必行之法

## 学习路径

1. 先读本页"成书性质"与[历史进化观](concepts/historical-evolution.md)，确立读此书的方法论前提：文本为学派结集，概念为战国秦政论产物。
2. 读[农战一体](concepts/nong-zhan-yiti.md)与[壹赏壹刑壹教](concepts/yi-shang-yi-xing-yi-jiao.md)，掌握商鞅学派的富国强兵纲领。
3. 进入两篇精读：[《更法》](examples/geng-fa.md) → [《开塞》](examples/kai-sai.md)，逐句对照三源底本与异文标注。
4. 延伸至[弱民强国论](concepts/ruo-min-qiang-guo.md)与[法治工具论](concepts/fa-as-instrument.md)，理解其国家主义逻辑链条。
5. 以[信源谱系](references/index.md)收束：校本用蒋礼鸿《商君书锥指》，西学读 Yuri Pines 译注。
