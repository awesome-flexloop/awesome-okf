# 商君书精读总目

本分区收录《商君书》两篇核心篇章的精读，均为三源实抓核对：

| 精读 | 篇次 | 核对源 | 异文登记 | 入口 |
|---|---|---|---|---|
| 《更法》精读 | 卷一第一 | 古诗文网 + 新度书库 + 百度百科（河南社科联参校） | 3 处（疑行无名/无成、不脩古/不循古、曲学多辨/多辩） | [geng-fa.md](geng-fa.md) |
| 《开塞》精读 | 卷二第七 | 古诗文网 + 中华典藏 + 百度百科 | 2 处（脩/修、刑者/利者） | [kai-sai.md](kai-sai.md) |

## 精读体例

1. **原文为实抓文字**：全部引文来自信源页面实抓并登记为 F-SJS 事实（《更法》为 F-SJS-017 至 F-SJS-022，《开塞》为 F-SJS-030 至 F-SJS-035）；未登记的文句一律不作引录，仅以概述性语言交代结构。
2. **异文显式标注**：凡各源文字有出入处，均并列呈现"某源作某"、注明事实编号、不作裁决；影响义理的重大异文（如《开塞》"刑者/利者"）在正文单独分析。
3. **说话人归属依登记语境**：引文的对话归属（如"公孙鞅驳甘龙语""孝公末语"）一律依事实登记语境标注，不作超出登记范围的推断。
4. **托名结集属性随文提示**：《更法》开篇称"孝公"谥号这一考辨依据（F-SJS-011）在精读中显式呈现，防止将论战叙事误读为现场实录。

## 选篇理由

- 《更法》：全书第一篇，变法正当性的论战形态，入门必读。
- 《开塞》：理论密度最高，一篇串联历史进化观、壹赏壹刑壹教、法治工具论三大概念域；且为西汉初已见称引的篇章（F-SJS-014、F-SJS-015）。
