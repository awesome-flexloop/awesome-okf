# 校本系统

## 一、成书与编定层

- 通行本《韩非子》共五十五篇，篇数与《汉书·艺文志》著录一致（F-HF-001）。
- 《韩非子》本称《韩子》，唐代为与韩愈区分改称《韩非子》；今通行本经汉代刘向编定（F-HF-002）。

作者归属的分层记载见《史记·老子韩非列传》：《孤愤》《五蠹》《内外储》《说林》《说难》十余万言为司马迁明录的韩非亲著层（F-HF-033）。

## 二、传本线索

ctext.org《韩非子》以《四部丛刊初编》本为底本，篇页同时列出四种传本线索（F-HF-003）：

| 传本 | 性质 |
|---|---|
| 《韩非子集解》 | 注释汇编本 |
| 《钦定四库全书》本 | 清代官修丛书本 |
| 《摛藻堂四库全书荟要》本 | 四库荟要本 |
| 《正统道藏》本 | 明代道藏本 |

本包未对四传本作逐字对校；传本线索仅作检索入口登记。

## 三、本包校本使用方式

- **底本对**：ctext.org（底本《四部丛刊初编》本）+ moocky.net（据《四部丛刊》本整理）双源核对（F-HF-005）。
- **异文处理原则**：凡两源文字有出入处，一律以异文事实（F-HF-042 至 F-HF-050）显式登记"某本作某"，不作隐性裁断；影响义理的异文（如有度攻/救宾语互倒，F-HF-043）在精读文档中单独分析。
- **史源对校**：《说难》篇以《史记》全录文字作汉代史源对校，登记"实／阴"一处异文（F-HF-035）。
- **录文讹字层**：moocky 录文存在形误层（如果园/果围 F-HF-050、诸侯/诸候 F-HF-046），此类属录文质量而非传本异文，本包在精读异文表中标注性质，不作校勘学处理。
