# 写本与刊本信源登记——《医心方》古写本与江户刊本

本表登记《医心方》现存主要古写本与江户刊本。《医心方》成书时抄录三部：献皇室之"御本"（后成半井家本）、呈关白藤原氏之"宇治本"（原本失传，再抄本为仁和寺本）、丹波家自用之"医家本"（原件已佚）。据杉立义一统计，现存写本达 52 点（广州中医药大学医史馆转述为 53 种），多为据宇治本流传下来的版本。以下仅登记与本教程直接相关的核心版本；全部事实依据本包 [事实清单](../facts.md)。

## 二、版本要点备注

- **半井家本**：现存所有抄本中年代最古且全三十卷齐备者。平安时代抄本中二十五卷书于楮纸，由十人左右分担抄写；二十五卷文中有天养二年（1145）据宇治本写下的训点与校异；卷二十五、卷二十九纸背有长承二年（1133）具注历及保安、大治年间文书约五十通。半井家规定该本不得出家门，除安政元年（1854）一度借与幕府外，直到近年不曾公开。
- **仁和寺本**：因后世写注较少，被认为较接近丹波康赖编纂时原本形态，为安政本主要校本。宽政二年（1790）残卷 22 包自京都送至江户，次年制成影写本两部。
- **安政本**：安政元年（1854）幕府命将半井家本借与江户医学馆校勘影写，多纪元坚、多纪元昕主持，元琰、元佶续成；以半井家本为底本、仁和寺本（多纪家影写系统）为主校本。杨守敬评其"刊刻之精，校订之密，当为日本摸刻古书第一"。目前我国《医心方》主流刊本为安政本。
- **御本下赐半井家年代**：各信源表述并存——室町时代赐半井光成说（东京国立博物馆）、永禄三年（1560）赐半井瑞策说（中国中医药网）、天正年间说（广州中医药大学医史馆）；安政本序文仅记"正亲町帝时赐典药头半井氏"。此处不做裁断。
