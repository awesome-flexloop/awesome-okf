# 金刚般若波罗蜜经阅读教程

本知识包（bundle）是《金刚般若波罗蜜经》（简称《金刚经》，鸠摩罗什译，通行三十二分）的权威原文与解读指南。与《心经》一样，汉传《金刚经》的「原文」本身是梵文的汉译本，因此本 bundle 以「译本系统标注 + 《大正藏》底本 + 三十二分结构说明 + 多句著名经文逐字精读 + 多重注家立场」保证权威性与真实性。

> 关键提醒：通行本所分「三十二分」（如「妙行无住分」「如理实见分」）及其品名，是南朝梁昭明太子萧统所加，**并非**梵文原本或罗什译文原有结构；阅读时应区分「原文」与「分章装置」。
