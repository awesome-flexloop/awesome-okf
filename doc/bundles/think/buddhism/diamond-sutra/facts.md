# 事实清单（Facts Inventory）

## 经典基本信息

| 编号 | 事实内容 |
|------|---------|
| F-001 | 《金刚般若波罗蜜经》，简称《金刚经》，属般若部经典 |
| F-002 | 鸠摩罗什译本收于《大正新修大藏经》第 8 册，编号 T08 No.235 |
| F-003 | 鸠摩罗什（344-413），龟兹人，中国佛教四大译经家之一 |
| F-004 | 鸠摩罗什于后秦弘始年间（401 年起）在长安译出《金刚经》 |
| F-005 | 「金刚」喻般若智慧之坚利，能断一切烦恼 |
| F-006 | 「波罗蜜」为梵语 pāramitā 音译，意为「到彼岸」 |
| F-007 | 通行《金刚经》分「三十二分」（品），为南朝梁昭明太子萧统所分，非梵本或译文原有 |
| F-008 | 各分品名（如「妙行无住分」「如理实见分」）亦为后人所立 |

## 译本系统与流传

| 编号 | 事实内容 |
|------|---------|
| F-009 | 除鸠摩罗什本外，《金刚经》尚有菩提流支、真谛、玄奘、义净等汉译本 |
| F-010 | 玄奘译本名《能断金刚般若波罗蜜多经》 |
| F-011 | 汉传《金刚经》通行本以鸠摩罗什译为最流行 |
| F-012 | 《金刚经》梵文本现存多种，属般若经系中流传极广者 |
| F-013 | 《金刚经》开篇「如是我闻，一时，佛在舍卫国祇树给孤独园」点明说法地点为舍卫国祇树给孤独园 |
| F-014 | 经中「大比丘众千二百五十人俱」为常随众之数量 |
| F-015 | 经中当机请法者为须菩提（梵语 Subhūti，音译亦有「善现」） |

## 核心名相与名句

| 编号 | 事实内容 |
|------|---------|
| F-016 | 《金刚经》的核心论题是「应云何住，云何降伏其心」（第二品「善现启请分」） |
| F-017 | 「我相、人相、众生相、寿者相」合称「四相」 |
| F-018 | 「若菩萨有我相、人相、众生相、寿者相，即非菩萨」出自第三品「大乘正宗分」 |
| F-019 | 「凡所有相，皆是虚妄；若见诸相非相，即见如来」出自第五品「如理实见分」 |
| F-020 | 「菩萨于法，应无所住，行于布施」出自第四品「妙行无住分」 |
| F-021 | 「应无所住，而生其心」出自第十品「庄严净土分」 |
| F-022 | 「是故须菩提，诸菩萨摩诃萨，应如是生清净心」紧承「应无所住而生其心」之后 |
| F-023 | 「离一切诸相，即名诸佛」出自第十四品「离相寂灭分」 |
| F-024 | 「过去心不可得，现在心不可得，未来心不可得」出自第十八品「一体同观分」 |
| F-025 | 「是法平等，无有高下」出自第二十三品「净心行善分」 |
| F-026 | 「若以色见我，以音声求我，是人行邪道，不能见如来」出自第二十六品「法身非相分」 |
| F-027 | 「如来者，无所从来，亦无所去，故名如来」出自第二十九品「威仪寂静分」 |
| F-028 | 「一切有为法，如梦幻泡影，如露亦如电，应作如是观」出自第三十二品「应化非真分」 |
| F-029 | 经中反复使用「A，即非 A，是名 A」的三段句式，被后人称作「金刚三句义」 |
| F-030 | 《金刚经》对禅宗影响深远，六祖惠能相传因闻「应无所住而生其心」而开悟 |
