# 法华诸喻

《法华经》以「喻」说法，后人归纳出「法华七喻」，构成理解本经义理的「故事函数库」：每个喻把一个抽象命题映射到具体场景。七喻如下（依品次排列）。

| 喻 | 品次（罗什本） | 喻体 | 喻义 |
|----|---------------|------|------|
| 火宅喻 | 譬喻品第三 | 长者以羊车、鹿车、牛车诱诸子出火宅 | 三乘（声闻/缘觉/菩萨）是诱出火宅的方便，究竟唯大白牛车（一佛乘） |
| 穷子喻 | 信解品第四 | 富家子流落为佣，不认其父 | 声闻但修小乘，不知自身本有佛性大业 |
| 药草喻 | 药草喻品第五 | 一雨普润，草木各得生长 | 佛以一乘法雨普润众生，众生随根机各得受用 |
| 化城喻 | 化城喻品第七 | 导师化作化城令众休息，再指宝所 | 二乘涅槃是方便所化的「化城」，非究竟宝所 |
| 衣珠喻（系珠喻） | 五百弟子受记品第八 | 贫人衣里系珠而不知 | 众生本具佛性，为无明所覆而不自知 |
| 髻珠喻（顶珠喻） | 安乐行品第十四 | 转轮王髻中明珠不轻与人 | 《法华经》为诸佛秘要，最上妙法，不轻易宣说 |
| 医子喻 | 如来寿量品第十六 | 良医外出，诸子饮毒，父归与药，不服者父诈死令醒 | 佛以「示现涅槃」令放逸众生醒悟，实则佛寿无量 |

## 两则最重要的喻

- **火宅喻 + 三车**：直接承载「会三归一」。羊车、鹿车、牛车喻声闻、缘觉、菩萨三乘，皆是为诱出火宅（三界）的方便；出宅后同得大白牛车（一佛乘）。「三界无安，犹如火宅」即出此品。
- **医子喻（如来寿量品的「良医喻」）**：直接承载「久远实成」。佛为救放逸众生而「示现灭度」，实则寿命无量，此喻是《如来寿量品》的文学核心。

> 「法华七喻」之名是后人归纳，并非经中自带清单；七喻分布前后各品，选读时须「先认喻、再回品」核对上下文（见 [选读模式](../insights.md) 模式二）。
