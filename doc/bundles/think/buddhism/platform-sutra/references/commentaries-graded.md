# 注本分级

## 注疏分级

| 级别 | 注疏 | 说明 |
|------|------|------|
| 一级（校本） | 郭朋《坛经校释》 | 通行校本，逐字校勘 |
| 二级（研究） | 杨曾文《敦煌新本六祖坛经》 | 敦煌本系统整理 |
| 三级（讲解） | 宗宝本历代解说 | 禅门内讲解 |

## 选用原则

- 释「得法偈」首选敦煌本/宗宝本对照 + 郭朋《坛经校释》。
- 释「顿渐」结合禅宗史研究。
