# 事实清单（Facts Inventory）

## 基本与作者

| 编号 | 事实内容 |
|------|---------|
| F-001 | 《六祖坛经》，简称《坛经》，是中国僧人著作中唯一被称为「经」的典籍 |
| F-002 | 《坛经》作者为惠能（638-713），禅宗第六代祖师 |
| F-003 | 惠能俗姓卢，岭南新州（今广东新兴）人 |
| F-004 | 《坛经》记录惠能于韶州大梵寺等处的说法 |
| F-005 | 敦煌本《坛经》全称含「南宗顿教最上大乘摩诃般若波罗蜜经六祖惠能大师于韶州大梵寺施法坛经」 |
| F-006 | 惠能门下法海集记《坛经》文本 |

## 版本系统

| 编号 | 事实内容 |
|------|---------|
| F-007 | 《坛经》主要版本系统有敦煌本、惠昕本、契嵩本、宗宝本 |
| F-008 | 宗宝本为目前最通行的版本，分十品 |
| F-009 | 敦煌本（法海集记系统）为现存较早的版本系统 |
| F-010 | 宗宝本十品依次为：行由、般若、疑问、定慧、坐禅、忏悔、机缘、顿渐、护法、付嘱 |
| F-011 | 敦煌本与宗宝本在惠能得法偈上存在文字差异 |

## 得法偈与名句

| 编号 | 事实内容 |
|------|---------|
| F-012 | 神秀偈（宗宝本）：「身是菩提树，心如明镜台，时时勤拂拭，勿使惹尘埃」 |
| F-013 | 惠能偈（宗宝本）：「菩提本无树，明镜亦非台，本来无一物，何处惹尘埃」 |
| F-014 | 惠能偈敦煌本第三句异文作「佛性常清净」（非「本来无一物」） |
| F-015 | 「本来无一物」一偈标显惠能的顿悟立场 |
| F-016 | 「菩提自性，本来清净，但用此心，直了成佛」出自宗宝本「般若品」 |
| F-017 | 「不是风动，不是幡动，仁者心动」出自宗宝本「行由品」风幡之议 |
| F-018 | 「佛法在世间，不离世间觉；离世觅菩提，恰如求兔角」出自「般若品」 |
| F-019 | 「无念为宗，无相为体，无住为本」为《坛经》的核心修行纲领 |
| F-020 | 惠能主张「自性本自清净」，与神秀「时时勤拂拭」的渐修立场相对 |

## 禅宗史脉络

| 编号 | 事实内容 |
|------|---------|
| F-021 | 惠能北上黄梅从五祖弘忍求法，得传衣钵 |
| F-022 | 五祖弘忍为禅宗第五代祖师 |
| F-023 | 禅宗「顿教」以惠能为南宗代表，神秀为北宗代表 |
| F-024 | 《坛经》对「不立文字、教外别传」的禅宗宗旨有重要影响 |
| F-025 | 惠能主张「自性能生万法」，强调即心即佛 |
| F-026 | 惠能「定慧一体」观主张「定即慧、慧即定」，非先后次第 |
| F-027 | 敦煌本《坛经》抄本为研究早期禅宗史与《坛经》流变的关键文献 |
| F-028 | 《坛经》风幡公案展现了禅宗对「心性」的强调 |
