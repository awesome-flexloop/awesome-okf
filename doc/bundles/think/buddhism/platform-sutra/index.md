# 六祖坛经阅读教程

本知识包（bundle）是《六祖坛经》（简称《坛经》，禅宗六祖惠能说法记录）的权威原文与解读指南。与汉译佛经不同，《坛经》是中国祖师著作，其「权威与真实」的关键在于**版本系统的呈现（敦煌本/宗宝本的文字差异）**，尤以惠能得法偈「本来无一物」与「佛性常清净」之异为典型。

> 关键提醒：通行宗宝本与早期敦煌本存在文字差异（如得法偈第三句），阅读时应区分「哪个版本」的原文，而非笼统宣称唯一的「坛经原文」。
