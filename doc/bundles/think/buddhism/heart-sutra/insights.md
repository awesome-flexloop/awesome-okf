# 架构洞察（Architecture Insights）

## 洞察 1：《心经》的权威在于「译本可考 + 略本/广本可辨」而非「唯一原典」

| 四元组 | 内容 |
|--------|------|
| **陈述** | 汉传《心经》的「原文」是梵本汉译，通行玄奘 260 字只是「略本」；法成、法月、智慧轮、施护等「广本」另含序分与流通分。其权威来自「译者/年代可考 + 《大正藏》卷次可核 + 略本/广本可区分」这一可复现链条。 |
| **证据** | F-002（T08 No.251）、F-003（260 字）、F-004（略本无序分流通分）、F-014（广本）、F-007/F-008（罗什本 No.250） |
| **反常识** | 一般人以为《心经》是「佛亲口所说」的全本，但通行 260 字略本无序分（无「如是我闻」），主说者实为观自在菩萨对舍利子说法（广本中佛在场）；把「略本」当作「全本」会误判经文结构与说者。 |
| **行动** | bundle 以「标注玄奘/罗什译者与《大正藏》编号 + 区分略本广本 + 260 字全文分段精读」替代「宣称唯一原文」 |

## 洞察 2：「空」不等于「无」——色空不二是中道

| 四元组 | 内容 |
|--------|------|
| **陈述** | 「色不异空，空不异色；色即是空，空即是色」不是否定色的存在，而是双向遮遣：以「色即是空」破对色的实体化执着，以「空即是色」破对「空」本身实体化的断灭见，落于中道。 |
| **证据** | F-025（色空四句）、F-026（受想行识亦复如是）、F-024（照见五蕴皆空度一切苦厄） |
| **反常识** | 初学者易把「空」读成「什么都没有」的断灭空，但经文同时肯定「空即是色」，并以「能除一切苦」收束——空是积极观照而非虚无。 |
| **行动** | 用「色空双遣法」模式（见下）阅读，避免堕入断灭见 |

## 洞察 3：「无……」遮遣系列是破执法，不是存在论断言

| 四元组 | 内容 |
|--------|------|
| **陈述** | 从「无眼耳鼻舌身意」到「无苦集灭道」「无智亦无得」，整串「无」不是列举「这些对象不存在」，而是对凡夫所执取的十二处、十八界、十二因缘、四谛层层遮遣，最终落于「无所得」。 |
| **证据** | F-028 至 F-032（遮遣系列） |
| **反常识** | 读者易把「无苦集灭道」误解为《心经》否定佛教自身教义（四谛），实为遮遣对四谛的实体化执着，二谛层面仍「不可毁」四谛。 |
| **行动** | 用「遮遣自检法」模式（见下），读到「无 X」时回问「我是否执着 X 为实有」 |

## 洞察 4：同一「空」在中观/唯识/禅宗三系呈现不同面向

| 四元组 | 内容 |
|--------|------|
| **陈述** | 中观释「空」为缘起性空、唯识释「空」为遣遍计执而显二空、禅宗释「空」为明心见性（本来无一物），同一「照见五蕴皆空」被导向不同理论归宿。 |
| **证据** | F-036（窥基/唯识）、F-037（法藏/华严）、F-038（憨山/禅宗）、F-039（印顺/中观） |
| **反常识** | 读者易把某一宗派的解读当作「经典唯一本义」；但经典本义本身开放，权威性在「如实并列多立场」而非「独占唯一正解」。 |
| **行动** | 在 [空性中道](concepts/03-emptiness.md) 与 [历代注家立场](concepts/05-commentaries.md) 并列三系，不做唯一结论 |

## 阅读模式（可复用）

### 模式一：色空双遣法

| 要素 | 内容 |
|------|------|
| **触发场景** | 读到「色不异空，空不异色，色即是空，空即是色」，或面对「某物有无实在性」的追问 |
| **核心步骤** | 1）取一现前对象 X → 2）观 X 缘起而无自性（色即是空）→ 3）不因此落入「X 不存在」的断灭（空即是色）→ 4）安立 X 为缘起假名、照常作用 → 5）回到「照见五蕴皆空，度一切苦厄」 |
| **反模式** | 把「色即是空」读作「色＝无」的断灭；只作思辨而不作观照 |
| **迁移示例** | 用于《金刚经》「A，即非 A，是名 A」、中观「二谛」、日常对得失成败的执着 |

### 模式二：遮遣自检法

| 要素 | 内容 |
|------|------|
| **触发场景** | 读到连续的「无……」句式（无眼耳鼻舌身意……无苦集灭道……无智亦无得），或觉察自己执着某概念为实有 |
| **核心步骤** | 1）列出经中被遮遣的对象（五蕴/十二处/十八界/十二因缘/四谛/智/得）→ 2）每见「无 X」即自问「我是否把 X 执为自性实有」→ 3）松脱实体化执着 → 4）汇归「以无所得故」 |
| **反模式** | 把「无 X」当作「X 不存在」的知识清单背诵，而不作对治 |
| **迁移示例** | 对治「有一个固定自我」「有一个可得之果」的执着；用于阅读中观破自性、唯识遣遍计 |
