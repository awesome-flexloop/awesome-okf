# 西方极乐世界的依正庄严

## 一、方位与国名

经中称「从是西方，过十万亿佛土，有世界名曰极乐」。此是「信仰语言」的方位表法，标示「舍此趋彼」的方向性，而非坐标意义上的地理定位。

## 二、依报庄严

「依报」指国土环境。经中列举：

| 庄严 | 经文要点 |
|------|---------|
| 栏楯罗网行树 | 「七重栏楯、七重罗网、七重行树」，四宝围绕 |
| 七宝池八功德水 | 「七宝池、八功德水」充满其中 |
| 无有众苦 | 国名「极乐」，义为「无有众苦，但受诸乐」 |

## 三、正报庄严

「正报」指佛与众生。经中称「其土有佛，号阿弥陀，今现在说法」——阿弥陀佛（Amitābha 无量光 / Amitāyus 无量寿）恒在说法，是最核心的正报庄严。

## 四、信仰语言的边界

「七重栏楯」「七宝池」等描述是净土信仰的「愿力呈现」，属「依正庄严」的宗教语言，不应以现代地理/物理标准作字面执实（见 [架构洞察](../insights.md) 洞察 4）。其着力点是「信愿的状态」而非「坐标的位置」。
