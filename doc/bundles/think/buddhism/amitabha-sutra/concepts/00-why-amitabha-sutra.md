# 为什么读《阿弥陀经》

## 一、在净土经系中的位置

《阿弥陀经》是净土宗「三经」之一（《无量寿经》《观无量寿经》《佛说阿弥陀经》），并因篇幅较《无量寿经》（大经）短小，世称「小经」。与般若系经典重「破执」「空」的义理思辨不同，本经重在「信愿行」的行门——以「执持名号、一心不乱、临终往生」为修行正途。

- 净土三经分工：《无量寿经》详述阿弥陀佛因行果德与四十八大愿，《观无量寿经》明十六观与三辈九品，《阿弥陀经》则以最简短的篇幅总摄「称名往生」法门。
- 三经关系详见 [交叉引用](../references/cross-ref.md)。

## 二、阅读价值

1. **简明行门**：核心法门「执持名号」（称名念佛）人人可持，是「易行道」的典型表达（见 [执持名号与一心不乱](03-name-recitation.md)）。
2. **信愿架构**：「信、愿、行」三资粮为净土修学的总框架（见 [三资粮](04-three-provisions.md)）。
3. **课诵常经**：本经为汉传佛教「朝暮课诵」常诵经典，诵持与阅读并重。
4. **难信之法**：经末「五浊恶世」「难信之法」点出此法「理虽易行、信实难生」的特质。
