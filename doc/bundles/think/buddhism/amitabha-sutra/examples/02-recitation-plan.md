# 持名修行建议

## 一、三阶段进阶

| 阶段 | 目标 | 做法 |
|------|------|------|
| 1. 诵持 | 熟悉全文与名句 | 每日诵经一遍，重点诵「执持名号」「临终接引」等段 |
| 2. 明义 | 理解称名法门 | 依 [执持名号](../concepts/03-name-recitation.md) → [三资粮](../concepts/04-three-provisions.md) → [依正庄严](../concepts/02-sukhavati.md) 顺序读 |
| 3. 落实 | 信愿行合流 | 以「三资粮自检法」逐项检验信、愿、行是否闭环 |

## 二、诵持要点

- 本经为朝暮课诵常诵经典，日课可诵全文一遍；短时用功则专诵「执持名号」「一心不乱」两段。
- 诵时持名重在「系念」而非追求声量，落点在「一心不乱」。
