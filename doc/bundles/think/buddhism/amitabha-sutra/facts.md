# 事实清单（Facts Inventory）

## 经典基本信息

| 编号 | 事实内容 |
|------|---------|
| F-001 | 《佛说阿弥陀经》，简称《阿弥陀经》，属净土宗根本经典 |
| F-002 | 鸠摩罗什译《佛说阿弥陀经》收于《大正新修大藏经》第 12 册，编号 T12 No.366 |
| F-003 | 玄奘另有异译本《称赞净土佛摄受经》 |
| F-004 | 《阿弥陀经》为净土宗「三经」之一（《无量寿经》《观无量寿经》《佛说阿弥陀经》） |
| F-005 | 「阿弥陀」为梵语 Amitābha（无量光）/ Amitāyus（无量寿）之音译 |
| F-006 | 经中说法对象为长老舍利弗（舍利子） |
| F-007 | 鸠摩罗什（344-413）于后秦译出此经 |

## 依正庄严

| 编号 | 事实内容 |
|------|---------|
| F-008 | 经中称「从是西方，过十万亿佛土，有世界名曰极乐」 |
| F-009 | 经中称「其土有佛，号阿弥陀，今现在说法」 |
| F-010 | 「极乐」意为「无有众苦，但受诸乐」 |
| F-011 | 经中称极乐国土有「七重栏楯、七重罗网、七重行树」，四宝围绕 |
| F-012 | 经中称极乐国土有「七宝池、八功德水」 |
| F-013 | 「依正庄严」为后世对极乐世界「依报」「正报」庄严的总称 |

## 称名法门与往生

| 编号 | 事实内容 |
|------|---------|
| F-014 | 「执持名号」为《阿弥陀经》的核心修行法门（称名念佛） |
| F-015 | 经中「一心不乱」为往生的关键条件表述 |
| F-016 | 经中称「临命终时，阿弥陀佛与诸圣众现在其前」 |
| F-017 | 经中「心不颠倒，即得往生阿弥陀佛极乐国土」 |
| F-018 | 「不可以少善根福德因缘，得生彼国」出自本经 |
| F-019 | 经中列举六方诸佛证诚赞叹此经 |
| F-020 | 「信、愿、行」三资粮为后世对净土修学的归纳架构 |
