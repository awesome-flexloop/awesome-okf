## 释文原则

1. **溯源原则**：每处释文标注来源整理本，不凭空编造。
2. **残毁标注**：帛书甲本残毁处以「□」或说明文字标注，不臆测补字。
3. **通假说明**：出土本文中通假字（如「胃」通「谓」）保留原字，必要时括注今字。
4. **篇序尊重**：按出土本原篇序（德经在前）呈现，另标传世本对应章次。
