# 相关道家著作概览

本概念文档概览三部与老子本人或老子思想直接相关、常被并提的道家著作——《文子》《关尹子》《阴符经》。三者成书真伪各有争议，但均在道家一系，主题与老子思想有承继关系。

## 《文子》

| 维度 | 内容 |
|------|------|
| 传世题名 | 周文子撰（托名老子弟子文子） |
| 真伪 | 传统多疑为依托之作，定其中大量内容抄袭《淮南子》 |
| 出土佐证 | 1973年河北定县八角廊汉墓出土《文子》竹简，证实其文本汉代已流传 |
| 与老子关系 | 以老子「道」「德」「无为」为宗，杂糅儒法，属黄老道家一系 |

《文子》竹简的出土，动摇了「《文子》全为抄袭《淮南子》」的旧说，说明《文子》文本有更早的来源[^wang-deyou-yanzun]。

## 《关尹子》

| 维度 | 内容 |
|------|------|
| 传世题名 | 周关令尹喜撰（托名老子关令尹喜） |
| 真伪 | 学界多定为后人依托，成书时代与作者均不可考 |
| 与老子关系 | 尹喜相传为《老子》的最早传人，此书托其名而以虚无为宗 |

## 《阴符经》

| 维度 | 内容 |
|------|------|
| 传世题名 | 旧题黄帝撰（又称《黄帝阴符经》） |
| 真伪 | 学界多定为唐宋间成书的道教经典，非先秦古书 |
| 与老子关系 | 阐发「观天之道，执天之行」「盗机」之论，思想承接老子「道法自然」，属道教修身经典 |

> 说明：本知识包以老子本人著作（《老子》/《道德经》）的出土文献原文与权威解读为主体；《文子》《关尹子》《阴符经》作为相关著作仅作概览，不展开逐章原文考据，以免偏离「老子本人著作」的主题边界。

## 与老子思想的承继关系

三部著作共同体现老子之后道家思想的分化：

- **黄老方向**（《文子》）：老子「无为」与法家「刑名」结合，走向治国之术。
- **道教方向**（《阴符经》）：老子「道」「自然」与天人感应、养生结合，走向宗教修持。
- **虚无方向**（《关尹子》）：老子「无」的本体义被推向极致。
