# 架构洞察（Insights)

> 基于事实清单（facts.md）与资料分析得出，每条洞察遵循四元组结构（现象/根因/影响/建议）

---

## 洞察1：出土文献的价值在于「求古」而非「求真」

| 四元组 | 内容 |
|--------|------|
| **现象** | 用户要求「最真实原文」，但出土文献各系统文字互有差异，郭店本缺「绝仁弃义」，帛书本「德经在前」，无唯一本可称「最真」。 |
| **根因** | 《老子》文本在战国至西汉间处于流动状态，各传抄本因时间、地域、避讳、通假而分化。 |
| **影响** | 若以单一本（如帛书）为「唯一真本」，会遮蔽文本流动史与异文的义理价值。 |
| **建议** | 以「出土文献为主基准 + 显式呈现异文与争议」替代「单一真本」，让读者看到文本的多重面貌而非唯一答案。 |

## 洞察2：三线解读的正确用法是「分层对照」，而非「择一而信」

| 四元组 | 内容 |
|--------|------|
| **现象** | 出土校注、历代注本、现代注本三线解读，注家立场差异甚大（王弼「以无为本」vs 李零「处世智慧」）。 |
| **根因** | 不同注家分属不同时代与思想传统，其「道」观承载各自哲学预设。 |
| **影响** | 若择一而信，会把某家的哲学预设误当作老子本义。 |
| **建议** | 三线分层：校注管文本、历代管义理史、现代管综合；关键分歧显式化为「争议与不确定性」。 |

## 洞察3：避讳字与通假字是判断文本年代的关键线索

| 四元组 | 内容 |
|--------|------|
| **现象** | 帛书「恒/邦」与传世本「常/国」的差异，初看是文字小异。 |
| **根因** | 「恒→常」避汉文帝讳、「邦→国」避汉高祖讳，可据以推定抄本年代。 |
| **影响** | 避讳规律是出土文献断代的重要依据，也是理解文本演变的关键。 |
| **建议** | 在原文与异文文档中标注避讳、通假的位置与性质，供读者理解版本差异的成因。 |

## 洞察4：本 bundle 与既有 bundle 分工互补

| 四元组 | 内容 |
|--------|------|
| **现象** | 已有 boshu-reading（怎么读帛书）、laozi-lineage（版本源流谱系），缺「老子著作原文与解读本体」的知识包。 |
| **根因** | 既有 bundle 侧重阅读方法学与版本流传学，未聚焦「原文 + 解读本体」的横向专题。 |
| **影响** | 用户找「最权威原文与解读」时，需跨多个 bundle 拼凑，碎片化。 |
| **建议** | 本 bundle 承担「原文与解读本体」的横向整合，与 boshu-reading（方法）、laozi-lineage（源流）三点互补，通过交叉引用互联。 |
