## 🚀 快速开始

如果你之前从未读过《道德经》：

1. 先读[为什么读帛书本](concepts/00-why-boshu.md)了解帛书价值
2. 打开[三周通读计划](examples/03-reading-plan.md)，按照第一周计划开始读《帛书老子注读》
3. 通读一遍后，再回来看[四大版本系统](concepts/01-four-systems.md)和[核心异文选读](concepts/04-key-variants.md)

如果你已经读过传世本（如王弼本或陈鼓应注本）：

1. 从[德经在前的阅读策略](concepts/02-de-before-dao.md)开始，理解篇序差异
2. 读[核心异文选读](concepts/04-key-variants.md)，对照6组最重要的异文
3. 跟着[开篇对照阅读](examples/01-first-chapters.md)重新理解开篇
4. 参考[如何使用历代注本](concepts/05-using-commentaries.md)选择进阶注本
