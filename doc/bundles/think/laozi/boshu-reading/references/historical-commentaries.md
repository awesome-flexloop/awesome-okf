# 历代注本信源

历代注本是理解《老子》阐释史的重要资源。本地收藏的"老子合辑134种"收录了从汉代到民国的130余种注本，"老子集成"（熊铁基主编）收录了更系统的历代文献。本文件对最具学术价值的注本进行分级标注。

## 选用策略

1. **第一阶段（通读期）**：只用现代注本（陈鼓应+帛书注读），不读古注，避免被旧注束缚
2. **第二阶段（对比期）**：读王弼注+河上公注，理解传世本两大系统的解释差异
3. **第三阶段（专题期）**：按兴趣方向选读1-2家（内丹选白玉蟾/黄元吉，哲学选王夫之/徐梵澄，校勘选范应元/高亨）
4. **检索性使用**：焦竑《老子翼》和《老子集成》作为工具书检索，不必通读
