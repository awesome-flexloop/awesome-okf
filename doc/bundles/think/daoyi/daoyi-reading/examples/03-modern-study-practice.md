# 现代学术地图与纸本获取指南

## 六位核心学者与读法

| 学者 | 代表作 | 定位与读法 |
|------|--------|-----------|
| **盖建民** | 《道教医学》（宗教文化2001，ISBN 7-80123-318-2）；《道教医学精义》（2014，ISBN 9787802547988） | 入门首选。前书是第一部系统专著（卿希泰指导博士论文），分期框架（汉魏六朝/隋唐至元/明清汇入）与"以医传道、道医辈出"章节最实用；后书更精炼，"先医药，后符咒"论断出此（AX-001~005） |
| **胡孚琛** | 《道学通论》（社科文献1999；2009修订版 ISBN 9787509708149） | 丹道与道教医药学的理论框架；方术篇第二章"医药、服食和养生"讲以气为本、身神存神、内丹取代外丹（AX-006、AX-007） |
| **姜生、汤伟侠** | 《中国道教科学技术史》第一卷（2002，ISBN 7-03-009971-0）、第二卷（2010，ISBN 9787030275462） | 资料最丰的科技史框架；第Ⅲ部"医学与养生学"第一章即"医·道同源"；第三卷（宋元明清）在研未出（AX-008、AX-009） |
| **林富士** | 道士医术四类分法（医者之术/养生之术/巫者之术/自创仪式疗法） | 用于给任何道医材料"分类归位"的工具性框架（AX-010） |
| **郑志明** | 《道教生死学》（中央编译2008，ISBN 9787802117150） | 从生死观看医疗与养生的宗教语境（AX-011） |
| **吉元昭治** | 《道教与不老长寿医学》（杨宇译，成都出版社1992） | 三圆模型（汤液本草针灸／导引调息内丹辟谷内视房中／符占签咒斋禁祭祀）是速记道医结构的最佳工具（AX-014） |

辅助：丁贻庄1985年道医定义（收入《中国大百科全书·宗教卷》1988，AX-012）；李贵海《道医学初探》（《世界宗教文化》2019年第5期）做词源与三层结构（AX-015、AX-016）；马继兴的出土医书整理与考释是出土文献领域的权威（EXC-003、EXC-012）。

## 陈撄宁《静功疗养法》的阅读法

《静功疗养法》是1957年8月陈撄宁（1880-1969，道号圆顿子，1961年任中国道教协会第二任会长）在杭州屏风山疗养院的讲稿，含问答27条、静功总说、治遗精特效法（DAO-021、DAO-022）。全文：http://www.homeinmists.com/Sitting_Quiet_Treatment.htm （雾隐之斋，直访验证）。

阅读时的三条边界：

1. **历史文献属性**：它记录1950年代疗养院合作语境下的实践，语言和疗效表述（如"特效法"）是历史提法，不代表现代循证医学结论；
2. **不替代医疗**：文中方法不构成对任何疾病的治疗建议，健康问题请就医；
3. **不据文习练**：静功实践需有合格指导，本束不提供练功指导。

文集可参《陈撄宁仙学精要》（胡海牙、武国忠主编，宗教文化2008，ISBN 978-7-80123-997-6）（DAO-023）。

## 纸本获取指南

1. **图书馆优先**：人卫"中医古籍整理丛书"、中华书局"道教典籍选刊"、《中华道藏》《正统道藏》与出土整理本价格高、卷帙大，优先通过高校图书馆/省馆馆际互借；
2. **点校本选购**：个人入门建议先购人卫"中医临床必读丛书"重排本（如《景岳全书》李继明整理本，ISBN 978-7-117-34524-8），研究再上"整理丛书"校注本；
3. **道藏使用**：《中华道藏》49册有现代标点，比三家本影印本便于使用；查卷次用涵芬楼/三家本的册次记录（AX-018~021）；
4. **出土整理本**：《长沙马王堆汉墓简帛集成》（中华2014，ISBN 9787101101683）、《天回医简》（文物2022，ISBN 978-7-5010-7835-6）等新版优先于旧版，吸收了最新拼缀与释文成果；
5. **敦煌图版**：彩色图版免费查国际敦煌项目 IDP（idp.bl.uk，SRC-008）；
6. **避坑**：祝守明《道医讲义》（道长自编试用教材，AX-024）、王爱品《道医论》（民间作者，AX-025）学术权威性低，不作入门依据；zysj.com.cn 网站遭博彩SEO污染，禁用（FRG-006）。
