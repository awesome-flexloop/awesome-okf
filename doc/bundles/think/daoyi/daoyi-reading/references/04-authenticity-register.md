# 辨伪信源登记——争议书、低权威读物与未证实清单

道医领域托名古籍与现代附会极多。本登记遵循 **两说并陈、证据优先、疑则传疑** 原则：每部争议书列出题署、最早著录、年代证据、主真/主伪两方代表，最后给出阅读建议。凡无法证实的流行说法，列入文末「未证实清单」，不进入概念页正文。

## 一、五部争议书登记

### 1.《中藏经》（题华佗）

- **题署**：旧题东汉华佗撰。
- **最早著录**：首见《宋史·艺文志》。
- **年代证据**：内征用"山药"（避宋英宗赵曙讳，1064年以后才通行"山药"一词）、"太平钱"等宋代名物。
- **主真说**：孙星衍等主"六朝说"，认为有古本渊源——**少数派**。
- **主伪说**：主流意见据避讳与名物判定**北宋成书**，系托名华佗的辑缀之作。
- **阅读建议**：可作**宋代方书与脏腑辨证思想**材料读，绝不可作为华佗或汉代医学证据；引用时标注"题华佗，北宋成书说为主流"。在线文本见 [在线信源矩阵](01-online-sources.md)。

### 2.《辅行诀脏腑用药法要》（题陶弘景，传敦煌卷子）

- **题署**：题梁陶弘景撰。
- **流传经过**：张偓南1918年购于敦煌，传其孙张大昌（1926-1995）；1966年原卷毁；1974年抄本寄中医研究院。
- **主真说**：马继兴判定"绝非今人仿造、下限不晚于宋初"，收入《敦煌古医籍考释》（1988）；钱超尘主信真，编《辅行诀五脏用药法要传承集》（收14种抄本）。
- **主伪说**：张政烺、李学勤1975年意见为"非近代伪，但不可能早到梁代"；田永衍《南京中医药大学学报（社会科学版）》2015年文主伪。
- **阅读建议**：**两说并存，学术上按"唐宋间佚名道医文献、传本系统复杂"处理**。可读其五脏补泻方药与《汤液经法》图式，但不得称"陶弘景原著"；研究须用《传承集》比对抄本系统。

### 3.《医道还元》（又名《吕祖医道还元》）

- **性质**：9卷＋《奇症新方》1卷，清光绪二十年甲午（1894）**扶乩降著**，托名吕祖（吕洞宾）。
- **版本**：中医古籍出版社2013年沈道昌整理本，ISBN 978-7-5152-0336-2；巴蜀书社2008年程雅君校注本。
- **两说**：不存在真伪之争——其降著年代与方式明确；争论在价值定位：一方视为清末道门医理（命门、阴阳）的系统表达，一方视为乩坛文献。
- **阅读建议**：作为**清末民间道医思想与乩坛文化**标本读，非唐前古道医文献；医理发挥多而实证少，不作临床与学术引文依据。

### 4.《扁鹊心书》

- **真实作者与年代**：南宋窦材撰，绍兴十六年（1146），3卷＋神方94方——作者年代本无争议。
- **"争议"所在**：清王琦《医林指月》1765年重刊时已发现书中**掺有后人内容**；其要语"保命之法：灼艾第一，丹药第二，附子第三"，重灸关元、气海、命关、中脘，载睡圣散（早期麻醉方），温补倾向极端。
- **阅读建议**：作为**南宋道门灸法与扶阳思想**文献可读；引用具体方药与穴位须核对重刊本与掺入部分；其"丹药"主张含外丹背景，不可据以服用。

### 5.《华佗神医秘传》

- **结论**：系**1920年代上海出现的伪书**，无真说代表。
- **阅读建议**：**不读、不引、不推荐**。凡网络署名"华佗"的方书（除正史著录脉络外），先查《宋史·艺文志》以后著录情况。

## 三、未证实说法清单（待考，不采入正文结论）

1. **陈撄宁《道教与养生》（华文出版社1989年）**：该版本信息未获证实，不采；陈撄宁文献用《陈撄宁仙学精要》（宗教文化出版社，2008）与《静功疗养法》原文（雾隐之斋全文）。
2. **《道医集成》版次信息**：该丛书由中国道教协会2015年启动、李光富/高文柱主编、收摄养类文献178种，但其出版社、出版年份、册数、ISBN 均未查到，**标待考**，不著录。
3. **《汉书·艺文志》房中家卷数**：《汉志》方技36家868卷中，医经7家216卷、经方11家274卷、神仙10家205卷；房中家具体卷数未查到，标待考。
4. **潘毅《寻回中医失落的元神》出版年份**：广东科技出版社，年份未查到，标待考。

## 四、辨伪方法速查（详见 [概念08：辨伪方法论与信源分级](../concepts/08-authenticity-and-sources.md)）

1. **托名规律**：越早越大名的作者（黄帝、扁鹊、华佗、陶弘景）越可疑；查"最早著录"年代。
2. **避讳字断代**：如"山药"（避宋英宗赵曙讳，原作"薯蓣"）指示北宋以后文本。
3. **名物制度**：钱名（太平钱）、官制、书名引用链。
4. **降著/乩坛特征**：扶乩、神授、梦中得书的成书叙事，定位为民间宗教文献而非古道经。
5. **近代伪书特征**：1920-1940年代上海书业冒名出版物，无任何早期著录。
6. **在线信源分级**：识典＞维基文库＞ctext 主库＞道藏阁；zysj.com.cn 全站禁用。
