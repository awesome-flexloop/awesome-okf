## 为什么要先选范式

性学经典不是一类书，而是四种问题意识不同的书：考订"古人在什么文本里写了什么"，测量"人们实际做什么"，解释"谁在定义正常"，追问"这些定义如何被生产"。选错入口，最容易发生的事是把《性精神病态》的历史结论当成现代共识，或者把《欲经》当成"行为指南"而不是文本文献。本篇给出四大范式的划分与自测，帮助你用五分钟决定第一本书。

## 读者自测

逐题选择更接近你阅读目的的选项：

1. 你更想知道：A. 古人留下了哪些文本、真伪如何 / B. 身体反应的机制 / C. 人群行为的真实分布 / D. "正常/变态"这类标签从哪来
2. 面对一个历史文本，你先问：A. 版本源流 / B. 当时医学怎么解释 / C. 它反映的社会行为 / D. 谁在借它说话
3. 你能接受的阅读难度：A. 愿意面对整理本与注释 / B. 接受专业教科书 / C. 接受数据与表格 / D. 接受理论抽象

**判读**：多数选 A → 从 [01-中国古代性文献](01-ancient-china.md) 进入；选 B → 从 [03-西方性学奠基期](03-foundations.md) 进入；选 C → 从 [04-现代性科学](04-modern-science.md) 或 [06-中国现代性学](06-china-modern.md) 进入；选 D → 从 [05-女性主义与社会建构论](05-feminism-construction.md) 进入，并配读 [08-权力与审查视角](08-censorship-power.md)。

## 阅读顺序建议

- **单范式深入**：按对应概念篇 → 该篇推荐的第一本书 → [examples/02-古典文本三步法](../examples/02-ancient-text-reading.md)（古典范式）或 [examples/01-第一本书实操](../examples/01-entry-path.md)（其余范式）
- **跨范式通读**：建议顺序为 古典文献学 → 临床医学 → 社会科学 → 建构论批判（从"文本"到"测量"到"反思"），总量按 [examples/03-分阶段阅读计划](../examples/03-reading-plan.md) 的 16 周安排
- **随时回查**：译本/版本拿不准时查 [07-译本与版本选择指南](07-translations.md)；想理解某本书为何被禁时查 [08-权力与审查视角](08-censorship-power.md)
