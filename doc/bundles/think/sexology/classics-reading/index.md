# 性学经典著作阅读教程

阅读性学经典，最难的不是找书，而是不知道从哪里进入、信哪个译本、如何面对有争议的版本。本知识包以**阅读教程为主、著作提要为辅**定位：不按年代堆砌书目，而是按"方法论范式"组织入口——古典文献学、临床与实验医学、社会科学、建构论批判四大范式，各自给出代表著作、中文读者可用入口与阅读顺序。

> **内容边界**：本知识包为学术教育性教程。公版古典文献仅引篇名、核心命题与少量代表片段；现代版权著作只做提要，不录原文；全文无露骨描写。
