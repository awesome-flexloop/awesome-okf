# 《汉书·艺文志》房中八家研读教程

《汉志·方技略》房中类著录八家、百八十六卷，至迟隋初全部亡佚，两千年间只作为目录条目存在。本知识包是以**著录为锚点、辑佚与出土互证为方法、可追溯事实为底座**的专题深读教程，按"著录原文 → 亡佚辑佚 → 出土互证 → 现代解读"四线组织，回答三个问题：八家是什么书、如何亡佚又如何回流、现代学者如何解读。

> **内容边界**：本知识包为学术性文献导读。公版古典文献仅引篇名、核心命题与少量代表短句；涉及性内容一律以学术转述呈现，不做露骨展开。
