# RTX Spark 核验与边界

核验日期为 2026-10-27。结论是**发布与支持声明可追溯，实际性能未独立验证**。同一公司的中英文稿、产品页与开发博客是同主体佐证；微软与 Adobe 也属于合作方，不能当作无利益关联的性能评测。

## 路由决定

| 候选位置 | 决定 | 理由 |
|---|---|---|
| `jishu/iot/rtx-spark/` | 采用 | 既有端侧 AI 硬件资讯与源码包相邻，容纳异构计算、容量和任务评估 |
| `jishu/ai/products/` | 不采用 | 现有分类以任务型软件产品为主，本文主线为硬件平台 |
| `jishu/systems/` | 不采用 | Windows/WSL 只是本文一部分，避免把创作与游戏归入 OS 教程 |
| 新 NVIDIA 分组 | 不采用 | 单篇发布稿不创建新分组 |

子项目 AGENTS 允许公开知识进入 `doc/bundles/`，覆盖父仓根 `docs/` 的一般路径。按子项目轻量自治规则，不建立父仓Spec或第二份facts.md；事实单一台账为article-source.md，验收改用编号连续性、正文引用与核验表双向覆盖，不声称双份台账一致。此任务是新知识包生成，不是代码变更或已有大文档迁移。原文无可复现安装/测试流程；“操作步骤”和“作者实测完整性”两问未同时满足，因此不设 `examples/`。补充微软示例只用于理解支持边界，不升级成本包实测。

## V 审查记录

独立审查与机械门禁的最终结果记入[更新日志](../log.md)。审核范围为本页23项核验、64条登记事实与7篇概念页，不以营销结论代替证据。四视角发现按主题合并处理：补登宣传上限、修正日期身份、补前置知识与练习、约束云退路、区分许可准入与费用、加入事件触发复核及证据短摘录。

维护时以2026-10-31计划窗口结束、2026-11-30桌面计划窗口结束，以及GA发布、延期、撤回或目标SKU/版本变化触发复核；2026-12-31是兜底到期日，不是等待复核的唯一时点。Adobe/RTX Video尚无本包可引用的精确beta构建号，须从目标发行通道补证，不自动升级状态。
