# 供应链自主权——车企真正的焦虑

> 对应事实：F-005~F-012、F-041（核验状态见 [P0 核验报告](../references/verification.md)，V1~V3）

## 1. 焦虑的落点不是性能，是"十年后还有没有退路"

博文的切入点是 2026 年车规芯片竞争的新拐点：高安全等级 RISC-V 汽车 MCU 迎来量产元年（F-005）。但作者强调，这件事真正卡住的**不是芯片够不够快，而是一个架构师的长期焦虑**（F-007）。

原因在于时间尺度——**一辆车的生命周期往往长达十年以上**（F-006）。在这个尺度上，车企最怕的不是某颗芯片当下性能弱，而是十年之后同时遭遇：

- **供应商断供**：关键芯片供应中断，整车无法持续生产与维护；
- **授权受限**：架构授权条款变化或续约受阻；
- **架构绑定**：整个软件栈被单一架构锁死，切换成本高到无法承受。

作者把这份焦虑收敛为一个词：**供应链自主权**（F-008）。

## 2. RISC-V 给出的"活路"

博文认为 RISC-V 恰好提供了一张"活路"，理由有三层：

| 层次 | 主张 | 对应事实 |
|------|------|---------|
| 规范层 | RISC-V 是**开源、免费的芯片指令集规范**；**基础规范定死不改**，任何厂商都能照着造核 | F-009 / F-010 |
| 商业层 | 车企可以**随时更换供应商**，上层软件不必重写 | F-011 |
| 风险层 | 可**绕开 ARM 的授权费用与潜在的断供风险** | F-012 |

其中"基础规范定死不改"是核验中**最扎实**的一条：RISC-V International 的规范库显示基础 ISA（RV32I/RV64I/RV32E/RV64E）已 ratified 并冻结，基本集的稳定使软件与工具链投资可长期受益（F-035/F-036，核验 V2 ✅）。

## 3. 核验视角：三层主张的可信度并不相同

10 项核验中，本主题相关三条结论如下（详见 [verification.md](../references/verification.md)）：

- **F-009/F-010（开源免费 + 基础规范冻结）——✅ 权威源一致**：官方规范库可证。
- **F-012（绕开授权费与断供风险）——✅ 产业共识**：ARM 授权模式下每颗芯片需支付专利费、地缘政治波动可能导致供应受限，这是 RISC-V 作为替代路线的公认产业动因（F-041）。
- **F-011（换供应商不用重写软件）——⚠️ 只是"理想上限"**：这是本文自己在前文提出、又在第五节自我修正的判断（见 [concepts/02](02-four-industry-realities.md) 现实一，F-018）。核验确认：**指令集兼容 ≠ 外设/HAL 兼容**，真正"不重写"需要 AUTOSAR 等上层抽象配合（F-021，核验 V7 ✅）。

> 读法提示：第 2 节的三条主张是文章的**论证骨架**，但强度递减——规范层是硬事实，商业层是趋势，风险层是产业共识；其中"不重写软件"必须理解为**目标上限**而非现状。
