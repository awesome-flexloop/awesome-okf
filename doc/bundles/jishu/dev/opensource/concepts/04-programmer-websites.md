# 程序员常用网站

> **时点说明**：本文基于 2020 年前后教程（简书连载《开源的世界》中的《程序员需要了解的网站》）整理的网站盘点。所列网站为 2020 年前后的信息，部分站点可能已改版、迁移或停止服务，仅作历史参考。

## 重点网站分节（F-231、F-232、F-233）

文章先分节介绍六个重点网站：

- **W3Schools**（需要梯子）：为初学者和有经验的 Web 开发人员学习各种编程语言的最佳网站之一，可学习 HTML5、CSS3、PHP、JavaScript、ASP 等；网站内有嵌入式编辑器可在站内尝试和练习代码。注意：国内网站 w3school.com.cn 提供类似的中文内容，但二者似无关系
- **GeeksforGeeks**：主要专注于计算机科学，有大量的算法、解决方案和编程问题，也有很多面试中经常问到的问题
- **TutorialsPoint**：可以找到几乎所有语言框架的教程
- **StackOverflow**：代码遇到问题时的问答社区，几乎所有的问题都得到了答案，可获多个观点
- **HackerRank**：可参与各种编码竞赛并检测竞争能力，赢得比赛可增加分数
- **Codebeautify**：可以使代码易于阅读，也支持让代码不能被某个人读取

## 资讯类网站（F-234）

- 知乎周刊——知乎工作人员和志愿者团队合作制作
- 码农周刊——专为程序员打造的 IT 技术周刊，每周一发送，完全免费
- PyCoder's Weekly——提供 Python 每周资讯
- Hacker News——提供最新国际威胁情报、黑客动向以及维基解密资讯
- InfoQ——实践驱动的社区资讯站点，致力于促进软件开发领域知识与创新的传播
- FreeBuf——互联网安全新媒体平台
- WooYun——漏洞报告平台

## 在线学习类网站（F-235）

- 实验楼——IT 在线实训平台，提供课程内容 + 在线环境，即学即练
- Codecademy——免费有趣的在线互动编程学习网站
- Teamtreehouse——在线网站设计教育平台
- 优达学城（Udacity）——硅谷大佬们的优质内容
- 慕课网——提供视频教学内容
- Coursera——大型公开在线课程项目，可以找到优质国外名校课程内容
- leetcode——算法学习网站，每天刷两道算法题

## 社区与工具类网站（F-236）

- 开源中国——中文开源社区
- 博客园——开发者的网上家园，非常老牌的技术社区
- CSDN——老牌专业 IT 技术社区
- V2EX——关于分享和探索的地方，上面有很多各大公司的员工、程序员
- GitHub——文章描述为"最大的同性交友网站，拥有代码托管功能"，还有大量资源

## 竞赛类网站（F-237）

- HackerRank——编码竞赛，含算法、数学、SQL、函数式编程、人工智能等，可在线完成挑战
- TopCoder——最早的在线竞技编程平台之一，每月举行几次"单轮比赛"
- Coderbyte——提供 200 多项编码挑战，挑战者可使用 10 门编程语言中的任意一种在线解决；提供官方解答并允许查看其他用户答案，适合准备面试刷题
- CodeChef——位于印度的编程竞赛网站，提供数百种挑战，可在线编程并查看分类好的题目
- CodeEval——提供很多公司发起的挑战，完成得好有机会得到工作
- Kaggle——数据发掘和预测竞赛平台，很多企业发布任务
- Codeforces——俄罗斯的编程比赛网站，定期举办竞赛，要求高深的数学和算法知识
- CodeSignal——不仅提供代码挑战题，还搭建工程师找工作的平台，拥有"公司机器人"功能（人机对战或挑战其他玩家）

## 现状

- 本文基于 2020 年前后教程，属于**非操作教程的资源盘点**。文中网站描述（定位、特色功能）以 2020 年时点为准。
- 部分网站状态可能已变化：WooYun（乌云漏洞平台）已停止运营；CodeEval 指向 hirevue 的测评产品；Hacker News、StackOverflow、GitHub 等社区仍活跃。使用时以各站当前状态为准。
- "需要梯子"为原文对网络可达性的标注（2020 年前后），不代表当前访问状况。
