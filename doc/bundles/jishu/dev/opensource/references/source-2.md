## 内容要点

- 开源的含义：任何人都可以出于任何目的查看、使用、修改和分发你的项目；权限通过开源许可（opensource.org/licenses）强制实施
- 开源的原因：协作（如 Exercism 拥有 350 多个贡献者）、采用和重组（如 WordPress 派生自 b2 项目）、透明度（对政府、受监管行业及 Let's Encrypt 等安全软件重要）
- 开源不是"免费"的同义词："免费"只是开源的总体价值的一个副产品，不是开源定义的一部分；可通过双重许可或有限功能间接收费
- 每个开源项目应包括的文档：Open source license、README、Contributing guidelines、Code of conduct；放在仓库根目录并使用推荐文件名有助于 GitHub 识别并自动显示
- 许可证：MIT、Apache 2.0、GPLv3 都很流行，可通过 choosealicense.com 选择；"启动开源项目时，请务必包含许可证"
- README 应尝试回答：What / Why / How / Help / Who；灵感来源 @18F 的"让 README 可读"与 @PurpleBooth 的 README 模板
- CONTRIBUTING 文件可包含如何提交错误报告、如何建议新功能、如何配置环境和运行测试；模板参考 @nayafia 与 @mozilla；行为规范可参考《贡献者公约》（contributor-covenant.org）
- 项目命名与品牌（Sentry、Thin、node-fetch 示例）；pre-launch checklist 涵盖文档/代码/人三方面检查项
