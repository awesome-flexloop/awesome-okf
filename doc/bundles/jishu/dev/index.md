# 🔧 开发工具与开源协作

本分组是简书连载《开源的世界》（nb/40234132）转化生成的开发工具与开源协作知识束，基于 2020 年前后教程整理，覆盖 Git 版本控制、GitHub 平台与开源实践三大主题，遵循 [OKF v0.2 规范](https://github.com/awesome-flexloop/awesome-okf)。

| 束 | 简介 | 入口 |

| **Git** | Git 学习路线、Git Flow 分支模型与团队协作、下载加速与容量限制解除 | [git/](git/index.md) |
| **GitHub** | Gist 代码片段分享、GitHub Actions 工作流 | [github/](github/index.md) |

## 学习路径建议

1. **版本控制**：git（学习路线 → 分支模型导论 → 团队实战）→ github（Gist 轻量分享 → Actions 自动化）
2. **开源实践**：opensource（参与贡献 → 开启项目 → README 写作 → 图库与网站资源）
3. **交叉阅读**：git 的分支模型配合 github 的 Actions 触发事件、opensource 的贡献流程构成「开源协作全链路」
