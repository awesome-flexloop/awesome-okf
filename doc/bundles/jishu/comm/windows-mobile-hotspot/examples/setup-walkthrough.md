# 照做版：从插线到手机上网的分步流程

> **使用方式**：按顺序执行。每步都有**判定标准**——达标才进入下一步，不达标看**失败即停**分支。全部界面路径基于微软官方支持文档（`s2-ms-support-hotspot`）与源文（F-003~F-005）；中文系统上的措辞可能略有差异。

## 阶段 0 · 前置检查（30 秒）

| # | 动作 | 判定标准 | 不达标怎么办 |
|---|---|---|---|
| 0.1 | 确认电脑**有无线网卡** | 设备管理器 → 网络适配器 中有无线网卡条目 | 无解：只能改用有线连接或外接 USB 无线网卡 |
| 0.2 | 确认**主机本身能上网**（先不开热点） | 浏览器能正常打开网页 | 先解决主机上网问题；主机都不通，热点不可能通 |
| 0.3 | 确认上行链路就位 | 网线已插 / 已连上游 Wi-Fi / 蜂窝数据已开启 | 补齐上行链路 |
| 0.4 | 关闭自动休眠 | 「设置 > 系统 > 电源」中睡眠设为「从不」 | 不关则热点会随休眠失效（F-014） |
| 0.5 | 退出可能占用网络栈的软件 | VPN 客户端、抓包工具、虚拟机网络驱动已退出 | 冲突软件会干扰 ICS 与 DHCP（F-019 的放行前提） |

## 阶段 1 · 开启热点（3 步）

### 步骤 1 — 进入移动热点设置

**动作**：开始菜单 → 「设置」→「网络和 Internet」→「移动热点」。
**快捷方式**：按 `Win + R`，输入 `ms-settings:network-mobilehotspot` 回车。

**判定标准**：页面上方出现「移动热点」开关。

> **失败即停 A：整页找不到「移动热点」**
> 可能原因：① 系统不是 Windows 11；② 页面被策略隐藏（域环境 / 组策略）；③ 无线网卡驱动不支持 SoftAP。
> 处置：先在「网络和 Internet」列表里确认是否存在该项；再更新无线网卡驱动。**不要**改用 `netsh wlan set hostednetwork` —— 那是另一代技术（见 [Hosted Network 辨析](../concepts/frequency-and-compatibility.md#hosted-network)）。

### 步骤 2 — 选「共享我的 Internet 连接来源」

**动作**：展开「共享我的 Internet 连接来源」下拉，选择要共享的那条连接。

**判定标准**：下拉里能看到你期望的那条连接（以太网 / 上游 Wi-Fi / 蜂窝数据）。

**选择建议**：

| 你的上行 | 选它 | 理由 |
|---|---|---|
| 网线 | **以太网** | 无线网卡专职发热点，最稳（F-004、F-012） |
| 只有无线 | **上游 Wi-Fi** | 同一网卡兼任 STA + AP，稳定性依赖驱动（F-032） |
| 带 5G/4G 的设备 | **蜂窝数据** | 消耗流量套餐（F-025） |

> **失败即停 B：下拉里没有你期望的连接**
> 说明该链路当前未建立（网线没插好 / 上游 Wi-Fi 没连上 / 蜂窝数据被关）。**先把上行接通再回来**，不要在热点设置里反复折腾。

### 步骤 3 — 选「共享方式」

**动作**：展开「共享方式」下拉，选 **Wi-Fi**（默认、通常更快）或 **蓝牙**（F-026）。

**判定标准**：所选项已高亮。

> **失败即停 C**：选了蓝牙但对端设备找不到热点 —— 蓝牙 PAN 的兼容性面窄得多。**改回 Wi-Fi**。

### 步骤 4 —（可选）编辑属性

**动作**：展开「属性」→ 点「编辑」→ 设置三项 → 「保存」。

| 项 | 建议 | 依据 |
|---|---|---|
| **网络名称（SSID）** | 用 ASCII 字母数字，避免中文与特殊符号 | F-006（经验口径）/ F-020 的编码逻辑 |
| **密码** | **8–63 个 ASCII 可打印字符**（码位 32–126）；至少 12 位随机字符串更稳妥 | F-020（官方 L2）；复杂度建议见 F-021 |
| **网络频段** | 设备构成确定 → 显式指定 5 GHz 或 2.4 GHz；不确定 → 「任何可用频率」 | F-008（源文口径）；F-027（官方仅称 network band） |

**判定标准**：点「保存」后无报错，且属性区显示出新的名称/密码。

> **失败即停 D**：密码保存时被拒 —— 说明含非 ASCII 字符或长度越界。**改用纯 ASCII、长度 8–63**（F-020）。

### 步骤 5 — 打开开关

**动作**：把页面顶部的「移动热点」开关打开。

**判定标准**：
- 开关变为开启态；
- 页面显示你的网络名称与密码；
- 其他设备的 Wi-Fi 列表里**能扫到**这个网络。

> **失败即停 E**：开关打不开 / 一开就断
> 排查顺序：① 上行是 Wi-Fi 吗 → 改选以太网试；② 无线网卡驱动是否为最新；③ 是否有其他软件占用无线网卡。

## 阶段 2 · 连接设备（30 秒）

**动作**：在手机/平板的 Wi-Fi 设置里找到该网络 → 选「输入密码」或「扫描二维码」（F-028）。

**判定标准（三段都要过）**：

| 段 | 观察点 | 通过标志 |
|---|---|---|
| ① Wi-Fi 层 | 是否已关联 | 显示「已连接」，能拿到 IP |
| ② IP 层 | 客户端拿到的地址 | 是 `192.168.137.x` 一类的私网地址，**不是** `169.254.x.x` |
| ③ 出口层 | 能否打开网页 | 网页能加载，域名能解析 |

> **只过了 ① 没过 ②** → DHCP 层有问题（见 [排障清单 · 症状 S2](troubleshooting-checklist.md#s2-connected-no-ip)）。
> **过了 ② 没过 ③** → DNS 或 NAT 层有问题（见 [症状 S3](troubleshooting-checklist.md#s3-ip-no-dns) / [S4](troubleshooting-checklist.md#s4-dns-no-web)）。

## 阶段 3 · 收尾

- **查看连接数**：任务栏快速设置 → 移动热点快捷操作，开启时会显示已连接设备数（F-029）。
- **关闭**：关掉开关即可；**下次开启无需重新设置**（F-011）。
- **安全**：不用时关闭；若共享过给不信任的人，**改密码**即可踢掉已自动重连的旧设备。

```
  └─ 顶部「移动热点」开关 → 开
```
