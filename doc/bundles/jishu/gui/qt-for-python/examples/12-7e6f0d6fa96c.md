# 示例 12：GUI 相关术语2：GUI toolkit

> **信源**：[简书文集《Qt for Python（PySide2）官方文档学习笔记》](https://www.jianshu.com/nb/46707335) · 作者 **水之心** · [原文链接](https://www.jianshu.com/p/7e6f0d6fa96c) · 发布于 2020-08-17
> **对应事实**：F-034 ~ F-036

部件工具箱（widget toolkits， widget library，GUI toolkit，UX library）在程序设计中指的是某些基本的 GUI 的构件元素的集合。他们一般以库或者应用程序框架的形式出现。

一套部件工具箱是否有广大的使用人群，与以下几个因素有关：支持的操作系统是否多样，支持的操作系统市场占有率是否大，使用是否方便，是否有良好的“[所见即所得](https://zh.wikipedia.org/wiki/%E6%89%80%E8%A7%81%E5%8D%B3%E6%89%80%E5%BE%97)”（[WYSIWYG](https://zh.wikipedia.org/wiki/WYSIWYG)）的开发工具支持，是否有经济实力的雄厚的大公司支持等等。
