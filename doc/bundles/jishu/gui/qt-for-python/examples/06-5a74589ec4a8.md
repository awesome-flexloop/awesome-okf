# 示例 06：QML 简单类型

> **信源**：[简书文集《Qt for Python（PySide2）官方文档学习笔记》](https://www.jianshu.com/nb/46707335) · 作者 **水之心** · [原文链接](https://www.jianshu.com/p/5a74589ec4a8) · 发布于 2022-08-12
> **对应事实**：F-016 ~ F-018

参考：[QML Tutorial - Qt for Python](https://doc.qt.io/qtforpython/overviews/qml-tutorial.html)

学习 QML 基本类型，创建自己的 QML 组件、属性和信号，将在 states 和 transitions 的帮助下创建简单的动画。

先看简单的例子。

```qml
// view.qml
import QtQuick 2.0

Rectangle {
    id: page
    width: 320; height: 480
    color: "lightgray"

    Text {
        id: helloText
        text: "Hello world!"
        y: 30
        anchors.horizontalCenter: page.horizontalCenter
        font.pointSize: 24; font.bold: true
    }

}
```

大多数 QML 文件将从 `QtQuick` 导入内置的 QML 类型（如 [Rectangle](https://doc.qt.io/qt-6/qml-qtquick-rectangle.html) , [Image](https://doc.qt.io/qt-6/qml-qtquick-image.html)）

这里声明根类型为 [Rectangle](https://doc.qt.io/qt-6/qml-qtquick-rectangle.html)，包含 [Text](https://doc.qt.io/qt-6/qml-qtquick-text.html) 类型。

直接调用 Python 接口渲染。

```python
import sys
from PySide6.QtWidgets import QApplication
from PySide6.QtQuick import QQuickView

if __name__ == "__main__":
    app = QApplication()
    view = QQuickView()

    view.setSource("view.qml")
    view.show()
    sys.exit(app.exec())
```

需要注意：这里两个类型都有属性 `id`，用于标识该类型。

也可以给矩形添加边框：

```qml
// view.qml
import QtQuick 2.0

Rectangle {
    id: page
    width: 320; height: 480
    color: "lightgray"
    border.color: "black"
    border.width: 5

    Text {
        id: helloText
        text: "Hello world!"
        y: 30
        anchors.horizontalCenter: page.horizontalCenter
        font.pointSize: 24; font.bold: true
    }

}
```

显示为：

![](/_static/bundles/jishu/gui/qt-for-python/images/5a74589ec4a8-1114626-67b0bbce11666a7c.png)

也可以添加渐变效果：

```qml
// view.qml
import QtQuick 2.0

Rectangle {
    id: page
    width: 320; height: 480
    border.color: "black"
    border.width: 5
    gradient: Gradient {
        GradientStop { position: 0.0; color: "lightsteelblue" }
        GradientStop { position: 1.0; color: "blue" }
    }

    Text {
        id: helloText
        text: "Hello world!"
        y: 30
        anchors.horizontalCenter: page.horizontalCenter
        font.pointSize: 24; font.bold: true
    }

}
```
