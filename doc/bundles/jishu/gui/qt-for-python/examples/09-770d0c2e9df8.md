## Glade

[Glade](https://glade.gnome.org/index.html) is a RAD tool to enable quick & easy development of user interfaces for the [GTK+](http://www.gtk.org/) toolkit and the [GNOME](http://www.gnome.org/) desktop environment.

The user interfaces designed in Glade are saved as XML, and by using the [GtkBuilder](http://library.gnome.org/devel/gtk/stable/GtkBuilder.html) GTK+ object these can be loaded by applications dynamically as needed.
