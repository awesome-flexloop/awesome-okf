## 学习资源地图（F-THB-18 核验登记）

手册《Tk/Tcl 资源》篇列出的 8 项资源，按名称核对的官方入口：

- [TkDocs Tutorial](https://tkdocs.com/) — 跨语言 Tk 高质量教程
- [Tklib（Great Unified Tcl/Tk Extension Repository）](https://core.tcl-lang.org/tklib/home) — Tcl/Tk 扩展仓库
- [An Introduction to Tkinter (Work in Progress)](https://effbot.org/tkinterbook/) — Frederik Lundh 著，effbot Tkinterbook，本手册多篇译介来源
- [Tkinter 8.5 reference: a GUI for Python](https://web.archive.org/web/2020/https://effbot.org/tkinterbook/) — effbot Tkinter 8.5 参考存档
- [tkDND - Man Page](https://tkdnd.sourceforge.net/) — Tk 原生拖放扩展手册
- GUI drag & drop style GUI Builder for Python Tkinter — 原文仅列名称，无入口
- [Tk Commands/wm](https://www.tcl.tk/man/tcl/TkCmd/wm.html) — Tk 窗口管理器命令手册
- [TIP 236: Absolute Positioning of Canvas Items](https://tip.tcl.tk/236) — 画布项绝对定位改进提案
