# 示例 06：PyQt5 数据可视化

> **信源**：[简书文集《Qt Python GUI 学习（《PyQt5快速开发与实战》笔记）》](https://www.jianshu.com/nb/46416111) · 作者 **水之心** · [原文链接](https://www.jianshu.com/p/a24a4dfdd544) · 发布于 2020-07-01
> **对应事实**：F-016 ~ F-018

参考：[Data Visualization Tool Tutorial](https://doc.qt.io/qtforpython/tutorials/datavisualize/index.html#data-visualization-tool-tutorial)

本文以 [All earthquakes](https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_day.csv) 数据为例进行说明。

```python
import argparse
import pandas as pd

from PyQt5.QtCore import QDateTime, QTimeZone

def transform_date(utc, timezone=None):
    utc_fmt = "yyyy-MM-ddTHH:mm:ss.zzzZ"
    new_date = QDateTime().fromString(utc, utc_fmt)
    if timezone:
        new_date.setTimeZone(timezone)
    return new_date

def read_data(fname):
    # Read the CSV content
    df = pd.read_csv(fname)
    # Remove wrong magnitudes
    df = df.drop(df[df.mag < 0].index)
    magnitudes = df["mag"]
    # My local timezone
    timezone = QTimeZone(b"Europe/Berlin")
    # Get timestamp transformed to our timezone
    times = df["time"].apply(lambda x: transform_date(x, timezone))
    return times, magnitudes

if __name__ == "__main__":
    options = argparse.ArgumentParser()
    options.add_argument("-f", "--file", type=str, required=True)
    args = options.parse_args()
    data = read_data(args.file)
    print(data)
```

在 Python 控制台输入：
