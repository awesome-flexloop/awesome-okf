## 1 架构简介

Qt 是一组 C++ 库和开发工具，包括用于图形用户界面，网络，线程，正则表达式，SQL数据库，SVG，OpenGL，XML，用户和应用程序设置，定位和位置服务，短距离通信（ NFC 和蓝牙），网页浏览，3D 动画，图表，3D 数据可视化以及与应用商店的接口。PyQt5 将这些类中的 1000 多个实现为一组 Python 模块。

PyQt5 是 Digia 的一套 [Qt5](http://www.riverbankcomputing.co.uk/news) 与 Python 结合的可以在 Unix, Windows, and Mac OS 这些主流平台运行的应用框架。PyQt5（PyQt5 官方网站：<https://www.riverbankcomputing.com/software/pyqt/>，模块介绍的官网地址是：<https://www.riverbankcomputing.com/static/Docs/PyQt5/module_index.html>）。

Python 如此强大的功能之一就是能够采用 C 或 C++ 编写的现有库，并将它们用作 Python 扩展模块。这种扩展模块通常称为**库的绑定**（bindings for the library）。PyQt5 是使用 SIP 绑定生成器（[SIP bindings generator](https://www.riverbankcomputing.com/software/sip/)，细节可参考 [SIP documentation](https://www.riverbankcomputing.com/static/Docs/sip/introduction.html#overview)）构建的。必须安装 SIP[[2]](#fn2) 才能构建和使用 PyQt5。可以使用 pip 从 Python 软件包索引中[安装 SIP](https://pypi.org/project/SIP/)。即：

```shell
$ pip install sip
```

PyQt5 包含能够使用 Python 代码扩展的插件：Qt Designer 和 qmlscene。有关详细信息，请分别参见 [Writing Qt Designer Plugins](https://www.riverbankcomputing.com/static/Docs/PyQt5/designer.html#ref-designer-plugins) 和 [Integrating Python and QML](https://www.riverbankcomputing.com/static/Docs/PyQt5/qml.html#ref-integrating-qml)。

PyQt5 还包含许多实用程序（utility programs）：

- **pyuic5** 对应于 Qt 的 **uic** 实用程序。它可以将使用 Qt Designer 基于 [QtWidgets](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qtwidgets/qtwidgets-module.html) 创建的 GUI 转换为 Python 代码。
- **pyrcc5** 对应于 Qt **rcc** 实用程序。它在 Python 模块中嵌入由资源收集文件描述的任意资源（例如，图标，图像，翻译文件）。
- **pylupdate5** 对应于 Qt **lupdate** 实用程序。它从 Python 代码中提取所有可翻译的字符串，并创建或更新 `.ts` 转换文件。然后，Qt **Linguist** 使用它们来管理这些字符串的翻译。

[**DBus**](http://www.freedesktop.org/wiki/Software/DBusBindings) 支持模块安装为 dbus.mainloop.pyqt5。该模块以与标准 `dbus-python` 绑定软件包中随附的 dbus.mainloop.glib 提供对 GLib 事件循环的支持相同的方式，为 Qt 事件循环提供支持。该 API 在 [DBus支持](https://www.riverbankcomputing.com/static/Docs/PyQt5/dbus.html#ref-dbus) 中进行了描述。仅当安装了 `dbus-python` v0.80（或更高版本）绑定软件包时，该选项才可用。[QtDBus](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qtdbus/qtdbus-module.html) 模块为 DBus 提供了更 Qt-like 的接口。

配置 PyQt5 后，将生成一个名为 `PyQt5.api` 的文件。[QScintilla](https://www.riverbankcomputing.com/software/qscintilla/) 编辑器组件可以使用它来在编辑 PyQt5 代码时启用自动完成和调用提示。如果已经安装 [QScintilla](https://www.riverbankcomputing.com/software/qscintilla/)，则会自动安装该 API 文件。

PyQt5 包含大量示例。这些是 Qt 提供的许多 C++ 示例的 Python 端口。它们可以在示例目录中被找到。PyQt5 包含 SIP 用来生成 PyQt5 本身的 `.sip` 文件。开发人员可以将其用于其他基于 Qt 的类库的绑定。

| 模块名 | 描述 |

| [QtGui](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qtgui/qtgui-module.html) | 包含用于窗口系统集成，事件处理，2D图形，基本图像，字体和文本的类。它是小部件和 OpenGL GUI 共有的核心类。 |
| [QtWidgets](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qtwidgets/qtwidgets-module.html) | 包含提供一组 UI 元素的类，以创建经典的桌面样式用户界面。 |
| [QtDesigner](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qtdesigner/qtdesigner-module.html) | 所包含的类允许使用 PyQt 扩展Qt Designer。 |
| [sip](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/sip/sip-module.html) | 绑定开发人员和用户的实用程序。 |
| [uic](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/uic/uic-module.html) | 用来处理 `.ui` 文件，该文件由 Qt Designer 创建，用于描述整个或者部分用户界面。它可以将 `.ui` 文件编译为 `.py` 文件，以便其他 Python 程序调用。 |
| [QtLocation](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qtlocation/qtlocation-module.html) | 用于创建映射应用程序的类。 |
| [QtMultimedia](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qtmultimedia/qtmultimedia-module.html) | 包含用于处理多媒体内容的类和用于访问相机和 Radio Functionality 的 API。 |
| [QtMultimediaWidgets](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qtmultimediawidgets/qtmultimediawidgets-module.html) | 提供额外的与多媒体相关的小部件和控件（widgets and controls）。 |
| [QtBluetooth](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qtbluetooth/qtbluetooth-module.html) | 包含用于蓝牙设备连接和交互的类。 |
| [QtChart](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qtchart/qtchart-module.html) | 支持 2D 图表创建的类。 |
| [QtDBus](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qtdbus/qtdbus-module.html) | 使用 D-Bus 协议支持 IPC 的类。 |
| [QtDataVisualization](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qtdatavisualization/qtdatavisualization-module.html) | 支持 3D 数据可视化的类。 |
| [QtNetwork](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qtnetwork/qtnetwork-module.html) | 模块包含用于网络编程的类。这些类通过使网络编程更加容易和可移植，来简化 TCP / IP和 UDP 客户端和服务器的编码。 |
| [QtNetworkAuth](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qtnetworkauth/qtnetworkauth-module.html) | 网络授权类。 |
| [QtPositioning](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qtpositioning/qtpositioning-module.html) | 包含用于通过使用各种可能的来源（包括卫星，Wi-Fi 或文本文件）确定位置的类。 |
| [QtWebChannel](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qtwebchannel/qtwebchannel-module.html) | 在 Python 和 HTML / JavaScript 之间进行点对点通信的类。 |
| [QtWebEngine](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qtwebengine/qtwebengine-module.html) | 用于将 QML Web Engine 对象与 Python 集成的类。 |
| [QtWebEngineCore](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qtwebenginecore/qtwebenginecore-module.html) | Web 引擎的核心类。 |
| [QtWebEngineWidgets](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qtwebenginewidgets/qtwebenginewidgets-module.html) | 基于 Chromium 的 Web 浏览器。 |

| [QtHelp](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qthelp/qthelp-module.html) | 包含了用于创建和查看可查找的文档的类。 |

| [QtXml](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qtxml/qtxml-module.html) | 包含用于处理 XML 文件的类。该模块提供了 SAX 和 DOM API 的实现。 |

| [Qt3DInput](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qt3dinput/qt3dinput-module.html) | 使用 `Qt3D` 时处理用户输入的类。 |

| [Qt3DRender](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qt3drender/qt3drender-module.html) | 启用 2D 和 3D 渲染(rendering)的类。 |
| [Qt3DExtras](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qt3dextras/qt3dextras-module.html) | 与 `Qt3D` 一起使用的预构建元素。 |

| [QtPrintSupport](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qtprintsupport/qtprintsupport-module.html) | 使打印更轻松，更便携的类。 |
| [QtPurchasing](https://www.riverbankcomputing.com/static/Docs/PyQt5/api/qtpurchasing/qtpurchasing-module.html) | 支持从应用程序商店进行应用程序内购买的类。 |

PyQt5 只支持最新风格的信号和槽的写法。`SIGNAL()` 和 `SLOT()` 的调用将不会被长时间支持。
