# 示例 08：PyQt5 之 Button 的简单例子

> **信源**：[简书文集《Qt Python GUI 学习（《PyQt5快速开发与实战》笔记）》](https://www.jianshu.com/nb/46416111) · 作者 **水之心** · [原文链接](https://www.jianshu.com/p/00e7c13bbefc) · 发布于 2020-07-01
> **对应事实**：F-022 ~ F-024

先载入一些包：

```python
from PyQt5.QtWidgets import QApplication, QPushButton
from PyQt5.QtCore import pyqtSlot as Slot # from PySide2.QtCore import Slot
```

本文将展示如何 Pythonic 的处理 **signals and slots**。Signals and slots 机制是 Qt 的特性，它可以让你的图形界面中的组件间、组件与 Python 代码间进行通信。

定义一个 slot 函数：

```python
# Greetings
@Slot()
def say_hello():
    print("Button clicked, Hello!")
```

接着便可以调用 Qt，创建界面：

```python
# Create the Qt Application
app = QApplication([])
# Create a button, connect it and show it
button = QPushButton("Click me")
button.clicked.connect(say_hello)
button.show()
# Run the main Qt loop
app.exec_()
```

效果是每次点击按钮，便会在控制台（console）打印信息：
