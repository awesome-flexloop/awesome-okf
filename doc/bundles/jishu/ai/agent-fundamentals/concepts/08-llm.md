# 08 LLM（大语言模型）— 推理引擎基底

> 对应事实：F-071~F-080
> 知识层级：事实层

---

## 一、什么是 LLM？

**LLM（Large Language Model）** 是所有 AI 应用的推理核心，负责语言理解、推理和生成。

---

## 二、代表性模型

| 模型 | 厂商 | 特点 |
|------|------|------|
| Claude 3.5 | Anthropic | 长上下文、代码能力强 |
| GPT-4o | OpenAI | 多模态、生态完善 |
| Gemini | Google | 多模态、搜索整合 |
| DeepSeek V3 | DeepSeek | 开放权重、性价比高 |

---

## 三、LLM 在架构中的位置

```
四层架构（从外到内）：
┌─────────────────────────────────────────┐
│ 外部工具/数据源                          │ ← 文件、数据库、API
├─────────────────────────────────────────┤
│ MCP / Skills（能力封装层）               │ ← 标准化协议 & 能力包
├─────────────────────────────────────────┤
│ Agent（执行循环层）                      │ ← 感知-决策-执行-反思
├─────────────────────────────────────────┤
│ LLM（推理核心层）                        │ ← 语言理解与推理
└─────────────────────────────────────────┘
```

> **核心认知**：LLM 不是"上层建筑"，而是所有能力的**推理引擎基底**。没有 LLM，上层架构无法运转；但仅有 LLM，没有 Tool/MCP/Skill/Agent，AI 只能纸上谈兵。

---

## 四、LLM 与其他层的关系

| 上层 | 对 LLM 的依赖 | LLM 的支撑 |
|------|-------------|-----------|
| Agent | 需要 LLM 进行规划和推理 | 提供推理能力 |
| Skill | 需要 LLM 理解 SKILL.md | 提供指令执行能力 |
| MCP | 需要 LLM 理解协议格式 | 提供工具调用的语义理解 |
| Tool | 需要 LLM 生成调用参数 | 提供函数选择能力 |
| Prompt | 需要 LLM 解析指令 | 提供语义理解能力 |
| Context | 需要 LLM 维护对话状态 | 提供记忆管理能力 |
| Token | 需要 LLM 内部分词 | 提供文本处理基础 |
