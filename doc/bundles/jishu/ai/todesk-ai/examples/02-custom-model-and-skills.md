# 接入自定义模型与技能管理

> 本篇整合原文"切换/自定义模型"与"技能（Skills）"两章的操作性内容。

## 1. 切换内置模型

在对话栏右下角的模型选择器中切换默认模型。3.0.x 时点内置五款（F-049，⚠️ 单源、快速迭代项）：

| 模型 | 适用场景 |
|------|---------|
| GLM-5V-Turbo 32+ | 深度思考与代码编排 |
| Qwen 3.5 Plus | 复杂代码与终端执行 |
| Kimi-k2.5 | 长文本与深度研报 |
| 豆包 2.0 Pro | 视觉推理与多模态 |
| MiniMax-M2.7 | 记忆检索与日常办公 |

## 2. 接入自定义模型（第三方 API）

### 前置：确认 Key 类型（易错点）

仅支持**按量计费** API Key——按实际调用 Token 数扣费，通常 `sk-` 开头；套餐制的 **Token Plan Key**（预购固定额度包）与标准接口兼容但**不受支持**（F-051）。

### 支持的厂商（F-050）

智谱AI (GLM)、月之暗面 (Kimi)、火山引擎 (豆包)、深度求索 (DeepSeek)、小米 (MiLM)、阿里云 (通义千问)、稀宇科技 (MiniMax)。Base URL、API Key、Model ID 均从对应厂商控制台获取。

### 配置五步（F-052）

1. **获取 API Key**：前往厂商官网注册、创建 Key 并妥善保存（通常只显示一次）；
2. **进入设置**：ToDesk AI → 左下角头像 → 模型管理与模型计费 → 自定义模型管理；
3. **填写模型信息**：模型名称（如"我的 DeepSeek"）、Base URL、API Key、Model ID；
4. **测试连接**：点击「测试连通性并保存」，看到"模型配置保存成功"即生效；
5. **开始使用**：返回对话界面，在模型选择器中选用自定义模型。

## 3. 技能安装

三种获取方式（F-034）：

| 方式 | 操作 | 适合 |
|------|------|------|
| 对话创建 | 用自然语言描述需求，AI 自动生成专属技能 | 个性化、定制化任务 |
| 导入技能 | 将技能文件夹压缩为 zip 导入 | 已有现成 Skill |
| 技能市场 | 在"探索"页按分类（办公提效/编程开发/投资研究等）浏览安装 | 通用能力 |

> 导入注意：即使只有 SKILL.md 一个文件，也必须先放入文件夹再压缩为 zip（F-034）。

## 4. 技能管理（F-035）

- 支持为**不同智能体独立安装**技能；
- 在"已安装"页查看已装技能，按行开关；
- 点击技能卡"..."菜单可卸载。

## 5. 技能调用（F-036）

- **自动调用**：系统根据对话内容自动识别并调用合适技能，无需手动选择；
- **显式调用**：在对话框用 `/技能名称` 指定，例如让 AI"跟我一起用 /skill-creator 创建一个技能，并加入我的技能列表"。

## 6. 用技能降低积分消耗（F-058）

官方给出的省积分两法之一：把执行成功的重复任务**封装为 skills**，下次新开会话发布类似任务时直接调用——配合"新开会话避免历史记录冗重"，双管齐下（积分机制见 [references/article-source.md F-056/F-057](../references/article-source.md)）。

## 本篇检查清单

- [ ] Key 是按量计费型（sk- 开头），非套餐制
- [ ] Base URL / API Key / Model ID 三要素齐全
- [ ] 点击过「测试连通性并保存」并看到成功提示
- [ ] 技能 zip 内含文件夹层级（非裸 SKILL.md）
- [ ] 重复任务已考虑封装为 skill 复用
