# 智能体、技能与模型体系

产品在"助手"之上构建了三层扩展体系：**智能体**（人格与分工）、**技能**（能力插件）、**模型**（推理引擎）。本篇按三层展开。

## 1. 智能体（Agent）层

- **创建与配置**：可新建/编辑智能体，配置项包括智能体名称（预设名或自定义）、您的称呼、性格设定、能力定位（F-024）。
- **多智能体协同**（4月17日更新）：可创建多个定位不同、性格各异的智能体一起协同工作（F-025）。
- **AI 记忆**（3.0.0.2 更新）：能记住用户的习惯与偏好，越用越顺手（F-025）。

## 2. 技能（Skills）层

### 定位

技能是为智能体扩展专业能力的插件，按任务需求自动匹配调用（F-031）。官方的类比是把 Skill 理解为 AI 的"专业工具箱"——把某一领域的操作方法、知识库和执行脚本封装在一起，按需加载、即装即用。

### Skill 的文件夹结构（F-032）

```
skill-folder/
├── SKILL.md        # 定义 Skill 的功能与调用方式
├── scripts/        # 短脚本，定义 AI 具备的操作能力
├── references/     # 知识库，提供专业领域参考资料
└── assets/         # 资源文件（图标、样式等）
```

> 与 Anthropic Agent Skills 的目录约定同构（SKILL.md 为入口清单 + 资源目录），见主题关联 [Matt Pocock Skills 生态解读](../../mattpocock-skills/index.md)。

### 四大核心特性（F-033）

| 特性 | 说明 |
|------|------|
| 灵活组合 | Skill 自由组合，AI 自动装配出适配任务的工具集 |
| 一次开发多平台适配 | App、PC 编辑器、API 均可调用 |
| 按需加载 | 用时加载，不占上下文，灵活释放资源 |
| 不止对话 | 内置专业场景，AI 能真正"动手"完成任务 |

### 获取、管理与调用

- **获取三方式**（F-034）：①对话创建——用自然语言描述需求，AI 自动生成专属技能；②导入技能——zip 包导入（即使只有 SKILL.md，也须先放入文件夹再压缩）；③技能市场——在"探索"页按分类（办公提效、编程开发、投资研究等）浏览。
- **管理**（F-035）：支持为不同智能体独立安装技能；"已安装"页可逐项开关；点击"..."可卸载。
- **调用**（F-036）：系统按对话内容自动识别并调用，无需手动选择；也可用 `/技能名称` 显式指定。
- **内置技能示例**：技能审查员、Word/DOCX、Excel/XLSX、PowerPoint/PPTX、桌面控制（F-036 注）。

### 积分视角下的技能复用

官方给出的省钱建议之一就是把重复任务封装为 skills，新开会话直接调用（F-058）——技能层同时是"能力扩展"与"成本优化"的抓手。

## 3. 模型层

### 内置模型（3.0.x 时点五款，⚠️ 单源）（F-049）

| 模型 | 适用场景 |
|------|---------|
| GLM-5V-Turbo 32+ | 深度思考与代码编排 |
| Qwen 3.5 Plus | 复杂代码与终端执行 |
| Kimi-k2.5 | 长文本与深度研报 |
| 豆包 2.0 Pro | 视觉推理与多模态 |
| MiniMax-M2.7 | 记忆检索与日常办公 |

> 模型列表为官方文档单源声明，且属快速迭代项（更新日志显示早期版本曾支持 7 种可选模型含 Lite 变体），引用前请复核。

### 自定义模型接入（F-050/F-051/F-052）

- **七厂商接口**：智谱AI (GLM)、月之暗面 (Kimi)、火山引擎 (豆包)、深度求索 (DeepSeek)、小米 (MiLM)、阿里云 (通义千问)、稀宇科技 (MiniMax)。
- **Key 类型约束**：仅支持按量计费 API Key（按 Token 扣费，通常 `sk-` 开头）；套餐制的 Token Plan Key 不受支持。
- **配置五步**：获取 API Key → 左下角头像 → 模型管理与模型计费 → 自定义模型管理 → 填写模型名称/Base URL/API Key/Model ID → 测试连通性并保存 → 在模型选择器中选用。实操细节见 [接入自定义模型](../examples/02-custom-model-and-skills.md)。

## 三层关系小结

```
模型（推理引擎，可切换/可自定义）
  ↑ 驱动
智能体（人格 + 记忆 + 分工，可多个协同）
  ↑ 装配
技能（能力插件，按需加载，/名称 显式调用）
  ↓ 执行
Computer Use / 文件操作 / 定时任务（见 01/02 两篇）
```

智能体决定"谁来做"，技能决定"会做什么"，模型决定"用什么脑子做"——三者解耦，各自可独立扩展。
