# 三大核心能力

原文以能力图谱形式给出三大核心能力（F-007），本篇按"执行—操控—追溯"三层展开。

## 1. 多端远程执行

覆盖"指令从哪来、任务在哪跑"两个维度（F-008/F-009）：

| 维度 | 能力点 |
|------|--------|
| 指令入口 | 多端指令入口（手机或电脑均可下达）、限时发起异步执行 |
| 执行侧 | 跨设备直达目标电脑；异步处理——用户离线后任务仍在目标设备后台持续运行 |
| 设备互联 | 手机指挥电脑；Windows/macOS/iOS/Android 全平台；异地远程访问 |

## 2. Computer Use 可视化操控

这是产品区别于对话型助手的核心层（F-002/F-012）：以屏幕视觉感知为输入，以模拟真人键鼠为输出，直接操控第三方软件与网页，不依赖命令行或 API。能力图标注的三个特性：增强视觉识别、拟人化操作、主软件兼容。

触发机制是自动的：当任务涉及需要操作软件界面才能完成的步骤时，AI 自动启用 Computer Use（F-022）。典型触发场景包括在即时通讯工具发消息、登录企业内部系统、使用无命令行接口的桌面软件。机制细节与能力边界单独成篇，见 [Computer Use 运行机制与能力边界](02-computer-use.md)。

## 3. 过程可追溯（安全保障）

面向合规与信任的第三层（F-011/F-013）：

- **授权执行机制**：AI 的操作范围与访问权限可以限制；
- **操作记录存档**：Computer Use 的完整操作记录（含截图、操作步骤、执行结果）可在「审计日志」中查看（F-047）；
- **传输安全**：端到端加密传输保障远程连接。

## 横向能力：IM 深度集成

产品将指令入口延伸进聊天工具（F-010/F-048）：已接入微信、企业微信、飞书，在对话中发送指令即可触发任务，完成后自动在会话中反馈结果。配合设备绑定（PC 端扫码），会话会在所有设备上的 ToDesk AI 内同步——这一层把"远程执行"包装进了日常协作动线，用户无需打开专用界面。

## 小结

三层的分工可以概括为：**多端远程执行解决"任务在哪跑"**，**Computer Use 解决"怎么操作 GUI"**，**过程可追溯解决"敢不敢让它跑"**。IM 集成则是把三层能力接入既有工作流的入口层。
