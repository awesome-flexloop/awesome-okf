# 内容模式、零成本本地方案的真实门槛与边界

## WebUI 里到底有几种"模式"

推文截图配文里出现的模式名是"快速创作、自定素材、数字人口播等"（F-011）。对照官方文档，这是**对截图界面的近似转述**，准确对应关系如下（F-025、F-032）：

| 推文用词 | 官方准确概念 | 输入与用途 |
|---|---|---|
| 快速创作 | **AI 生成内容**模式 | 输入一个主题（如"为什么要养成阅读习惯"），LLM 自动写解说词并拆分镜，最快路径 |
| 自定素材 | **自定义素材**功能（2025-12-04） | 上传自己的照片/视频，由 VLM 智能分析素材后生成脚本——盘活已有素材、提高画面独特性 |
| 数字人口播 | **数字人口播**模块（2026-01-14） | 上传一张人物参考图 + 解说音频，生成对口型的 talking-head 口播视频 |
| —（推文没提） | **固定文案内容**模式（2025-12-08） | 直接粘贴完整文案跳过 AI 写作，支持按段落/行/句子三种方式切分分镜 |

也就是说，从"内容从哪来"的角度官方实际是**两条主线**（AI 生成 / 固定文案）加**一个素材入口**（自定义素材）和**一类画面形态**（数字人口播，本质是视觉工作流）。数字人口播、卡通、小说推文、个人成长、知识科普、横屏等推文列举的品类，都能在 README 示例区找到对应成片（韩语数字人、斗破苍穹小说解说、如何提升自己、养生知识、副业赚钱横屏等，F-007、F-027）。

## 批量生产模式

推文提到"有批量的需求这里可以选择批量生产模式"（F-012）。官方对应能力 2025-11-18 上线：支持一次批量创建多个视频任务，使用 RunningHub 时并行处理，并新增历史记录页面查看任务（F-026）。批处理的吞吐上限取决于所选路径——本地 ComfyUI 受单机 GPU 串行约束，RunningHub 云端有并发上限可配置（2025-12-28 起），12 月又增加了对 48G 显存机器的调用支持（F-023、F-035）。

## "免费本地化部署"的完整含义（帖文省略了前提）

推文把"支持免费本地化部署"称为最关键卖点（F-009）。官方 FAQ 确实给出 0 元方案，但**同段带明确的硬件前提**（F-029）：

| 方案 | LLM | 画面/语音 | 现金成本 | 前提条件 |
|---|---|---|---|---|
| **完全免费** | Ollama（本地） | ComfyUI 本地工作流（FLUX/WAN/Index-TTS 等） | **0 元** | **本地有显卡（GPU）**；还要会装 ComfyUI 并导入工作流 |
| 推荐（性价比） | 通义千问（云端 API） | ComfyUI 本地 | LLM API 极低 | 有 GPU，但不用本地大模型 |
| 云端 | OpenAI 等 | RunningHub 按量付费 | 较高 | 无 GPU 也能用，但持续产生费用 |

官方原话的选择建议是"**本地有显卡**建议完全免费方案，否则推荐使用通义千问"（F-029）。因此准确表述应是：**软件免费 + Apache-2.0 可商用，本地全链路零 API 费用，但把成本换成了 GPU 硬件与 ComfyUI 运维能力**；无显卡用户并不会自动免费，而是走付费云路径。整合包只免去了 Python/ffmpeg 的安装，**没有也不可能免去 GPU 需求**（本地生图/生视频/Index-TTS 克隆都重度依赖显卡）。

> Windows 一键整合包（start.bat → localhost:8501）装的是 Pixelle-Video 本体和 Python 依赖；若选本地 ComfyUI 路径，ComfyUI 及其模型权重（通常数 GB 起）仍需另行部署。

## 适用与不适用（基于官方定位的客观边界）

**适合**（官方示例与第三方实测集中的方向）：
- 几十秒到三分钟的口播、知识科普、情感语录、小说/影视解说、图文轮播类短视频；
- 需要高频/批量产出、对单条精致度要求适中、愿意接受"草稿→人工微调"工作方式的自媒体与企业内宣；
- 多语言口播（多语言 TTS + 数字人）与利用自有素材二创（自定义素材）。

**不适合 / 已知短板**（综合官方"调优 FAQ"与第三方一致评价，后者仅作定性参考）：
- 电影级画面精品、复杂运镜与长视频连贯叙事——这正是官方把它定位成"短视频引擎"、第三方用 VideoClaw 补足长视频的原因（F-020）；
- 没有 GPU 又想零成本长期使用——云端路径按量付费，不存在硬件、费用两免的方案；
- 期望文案直接达到发布水准——官方自己给出的不满意处理第一条就是"更换 LLM，不同模型文案风格不同"（F-034），本质是**提效工具 + 模板出草稿**，而非无人的内容团队。

## 分发侧风险：AI 生成内容的平台规则

工具解决"产得出"，不解决"发得出去"。2025–2026 年主流短视频平台普遍要求对 AI 生成内容进行**标识**，批量 AI 内容还可能触发同质化/低质限流。Pixelle-Video 的模板化、批量化特性在提升产能的同时，恰好落在平台治理的关注点上；是否需要加 AI 标签、同一模板批量产出是否被判重复，属平台规则范畴（各平台规则频繁调整，具体以发布时平台最新公告为准）。**工具文档不承诺流量，工具方也不为分发结果背书**——这是所有"AI 视频工厂"类工具的共同外部边界，本包只作风险提示，不引用任何"日更 X 条/月入 X"的效果承诺（F-040）。
