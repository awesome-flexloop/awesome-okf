## 勘误落实

1. ERR-01：效果保证改为章级上下文设计与人工一致性检查；见[上下文教程](../concepts/01-chapter-context.md)。

3. ERR-03：“本地完全免费”改为无必需云 API 费用但有本地运行成本；见[模型接入](../concepts/03-models-and-data.md)。
4. ERR-04：“作品在本地”补充云模型接收相关文本和本地配置存 Key；见[模型接入](../concepts/03-models-and-data.md)。
5. ERR-05：1.3.2 截图与 1.3.0 历史演示分别说明；不把正文待写称为定稿样例。
