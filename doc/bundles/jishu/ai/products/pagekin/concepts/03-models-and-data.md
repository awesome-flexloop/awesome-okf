# 模型接入、费用与数据边界

Pagekin 不附带模型和调用额度，维护者说明支持 OpenAI 兼容与 Gemini 原生协议，可连接商业服务或本地 Ollama。软件免费和生成免费是两件事，云端费用由所选服务商另收（F-023、F-028）。

## 接入要同时对齐协议与端点

协议是请求和响应的约定，Base URL 是该约定的入口地址。地址能访问不代表消息结构、流式结果或模型能力都匹配。官网明确不承诺任意第三方服务只换 URL 和 Key 就能使用；Ollama 官方也只承诺 OpenAI API 的子集（F-034、F-043）。

| 路径 | 已核查范围 | 待验证范围 |
|---|---|---|
| OpenAI 兼容云服务 | 官网点名 OpenAI、DeepSeek 等兼容接口 | 当前模型名、实际 API、流式结果、服务商价格 |
| Gemini 原生 | 官网说明原生协议支持 | 当前模型与账号权限、具体设置项 |
| 本地 Ollama | 官方本地文档支持 `/v1/` 兼容入口 | Pagekin 连通、所选模型能力与资源占用 |
| 自定义或 NovelAI 等预设 | 文章提及 | 完整预设与具体协议未查实现，不保证可用 |

文章列出的 SiliconFlow、BigModel、xAI 等预设地址未逐一核查，不把它们组成可直接照用的兼容矩阵（F-024）。配置时以该服务商当前官方文档及当前 Pagekin 界面为准，不猜 API 路径。

## Ollama 本地配置

下列字段来自文章，并由 Ollama 官方文档核对端点；**本轮未实测 Pagekin 到 Ollama 的连接**（F-025、F-042）。

```text
服务商：Ollama 或自定义
协议：OpenAI 兼容
Base URL：http://127.0.0.1:11434/v1
API Key：本地直连可按界面要求填写非秘密占位值
模型：当前 Ollama 已安装、可运行的实际模型名
```

`/api` 属于另一套原生接口，不能把其地址填进本流程的兼容端点字段。Ollama 官方本地示例的客户端需要 Key 字段，但本地服务忽略其值；这不表示远程代理、云模型或其他服务无需鉴权（F-042）。不要把本地测试的占位值复制到生产服务。

安全建议：上述 HTTP 地址仅用于本机回环连接，不把无鉴权的服务暴露到局域网或公网。远端云服务或代理使用其官方 HTTPS 入口，核对域名和证书；遇到证书错误应停止排查，不关闭证书验证。

文章举 `qwen3:14b`，但本轮未核验该模型在用户机器上的安装状态或运行资源（F-026）。先选能稳定运行的已安装模型，核查空闲内存及上下文成本，不为照抄示例而下载大模型。本文不作固定内存下限或速度承诺。

## 三个位置分别判断

| 事项 | 官网说明 | 使用前的判断 |
|---|---|---|
| 作品保存 | 项目目录和本地 SQLite | 本机文件访问、备份和恢复 |
| 生成计算 | 可用云模型或本地模型 | 相关提示词、正文和设定发送到哪里 |
| API Key | 本机用户目录的模型配置文件 | 谁能读文件，是否被同步、截图或打包 |

这些是维护者声明，不是本轮磁盘或网络审计（F-031、F-032）。不能据此推断 Key 明文或已加密，不能声称所有模型调用都不会外发。连接云模型时，相关正文与设定会发送给所选服务商。

SQLite 是保存项目数据的本地数据库，不是隐私保护证明。上传前具体核查服务商的文本保存期限、是否用于训练、删除机制及处理地域；不预设“不训练”或“不留存”。无法确定权限或条款时，不上传商业设定及第三方稿件。

未发表小说、商业 IP 设定或第三方稿件，需先核对上传权限和服务条款。只做功能试验时使用独立虚构文本；分享故障截图前隐藏 Key、服务地址中的秘密参数和私有稿件。

## 成本与安装边界

本地推理可减少必需的云 API 费用，但硬件、内存、存储和电力有成本；云模型收费按服务商政策判断（F-026、F-028）。先测试少量章节材料，再决定是否批量生成，不从“软件免费”推导“生产成本为零”。

费用建议：调用前核对计费单位、输入材料规模和输出限制，设定本次预算与最大重试次数；先做一次短请求，失败后查原因而非连续重试。服务商如提供硬额度限制应优先启用并核对生效范围，余额提示和费用告警不一定是硬封顶。本轮未验证任何服务商的预算控制能力。

维护者公开说明 Windows 安装包未代码签名，Mac 包未 Developer ID 签名且未公证（F-033）。未签名不自动证明恶意，也不能据此省略来源检查。只使用维护者指向的 Release，核对平台、版本和发布资产；系统阻止时先核查来源，不全局关闭安全保护。本轮未下载或验证这些文件。
