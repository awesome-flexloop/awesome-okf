# 无需模型的章节蓝图与连续性练习

维护者的蓝图教程将章节位置、本章目的、关键事件和悬念钩子分开，模板是普通文本，不是一键导入项目（F-041）。以下小样由执行者独立创作，**不是 Pagekin 生成结果或质量测评数据**。不需要安装软件、配置模型或付费。

## 练习输入

故事设定：修钟师林简发现一只停摆的钟里藏着一把钥匙。仓库只有管理员乔禾能进入。林简尚不知道钥匙属于哪里；乔禾知道仓库门锁最近换过，但不知钥匙已被发现。

上一章已确认：林简把钥匙放进工具袋，未向任何人提起。下一章目标：林简找到识别钥匙的方法，仍不能直接进入仓库。

## 填一章蓝图

| 字段 | 原创练习内容 |
|---|---|
| 章节位置 | 发现钥匙之后、进入仓库之前 |
| 本章目标 | 林简取得旧门锁的拓印，判断钥匙可能匹配哪里 |
| 关键事件 | 林简询问旧锁去向；乔禾拒绝交出原件；林简改用维修档案中的拓印 |
| 结果 | 钥匙形状与旧仓库锁相符，但新锁已更换，无法直接开门 |
| 悬念 | 换锁记录上的签名与乔禾平时签名不同 |

目标需落实成事件，不只写“展示人物性格”。阻碍解释人物为什么换一种办法；结果改变人物掌握的信息；悬念保留后续问题。蓝图可以随作者意图调整，不把这份小样当固定叙事公式。

## 找出草稿中的矛盾

故意写入一段待检查文本：

> 乔禾一见林简便说：“你工具袋里的钥匙能开现在的仓库门。”林简拿着钥匙，径直打开仓库，拿走了旧门锁。

这段文本是为练习设计的反例，不是软件实测故障。先不用模型，直接对照输入：

| 问题 | 输入中的依据 | 应如何处理 |
|---|---|---|
| 乔禾知道钥匙位置 | 林简未提起，乔禾也不知钥匙发现 | 补出合法得知过程，或删掉这句知情话 |
| 钥匙直接开现门 | 门锁已换，钥匙只可能匹配旧锁 | 不让钥匙直接开门，或明确修改世界事实并同步其他材料 |
| 林简直接进入仓库 | 仓库权限仅属于乔禾，且本章目标不包含进入 | 保留阻碍，改用档案拓印实现目标 |

检验不是让模型承认错误，而是每个冲突都能指向已确认输入。若作者决定改设定，要同步更改蓝图和后续材料，不同时保留互相矛盾的版本。

## 写完后更新什么

本章允许林简增加“钥匙可能匹配旧仓库锁”及“换锁记录签名不同”的认识，仍不能知道换锁签名者身份。原有钥匙线索继续保留，新增签名线索记录于本章；乔禾是否知道钥匙取决于实际正文，而非作者脑中设想。

一种原创改写参考如下，维修档案与签名细节来自本练习蓝图，不是官方小说：

> 林简问起旧门锁。乔禾只告诉他锁已更换，拒绝交出原件。林简转而翻查维修档案，把旧锁拓印与工具袋里的钥匙对照：形状相符，却不能据此打开现门。离开前，他注意到换锁记录的签名与乔禾平时不同。他收起钥匙，没有向乔禾提及发现。

| 记录项 | 本章结束状态 | 后续限制 |
|---|---|---|
| 林简的知识 | 钥匙形状与旧锁相符；换锁记录签名不同 | 不知道签名者身份，不能凭旧钥匙打开现门 |
| 乔禾的知识 | 知道林简询问旧锁 | 本段未让他知道钥匙已经发现 |
| 钥匙线索 | 推进，尚未回收 | 匹配形状不等于已证明用途 |
| 签名线索 | 新增，未解 | 后章需另写识别或证据过程 |
| 仓库权限 | 未改变，林简未进入 | 进入需另获合法条件 |

练习完成标准：能从输入定位上述冲突，改写不新增未授权能力，蓝图目标在正文里落实，新增知识和未解线索记录清楚。这个标准验证作者的检查方法，不证明任何模型或软件有长期记忆能力。
