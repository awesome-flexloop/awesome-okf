## 勘误登记

### 勘误-1：原文疑似笔误（非源文错误数字）

原文 page-8："已完成的定时任务可在【已完成】**钟**检查任务完成状态和任务执行结果"。

**处理**："钟"为"中"之笔误（OCR 转录忠实保留原文，正文转述按"中"呈现）。不影响事实内容。

### 勘误-2：更新日志年份缺失（源文口径限制）

更新日志各条目仅记月日（如"ToClaw 4月4日 2.1.0更新说明"），未注年份。

**处理**：正文引用版本时间线时一律标注"原文未注年份"；推断依据（3.0.0.0 更名节点 + 文档获取时间 2026-09 + 版本号递增序列）记录于此。**不做无标注的年份断言。**

### 勘误-3：OCR 边界页章节标题缺失（提取口径限制）

page-8→9 交界"3.跨设备使用"、page-16→17 交界"7.文件上传"章节标题因 canvas 分页截断未完整捕获。

**处理**：依据文档左侧目录（完整捕获）与正文结构确认章节存在性；两章节内容完整，仅标题行来自目录侧转录。已在 article-source.md 疑点登记表注记。

### 勘误-4：版本跳跃（腾讯文档 → 官网）

腾讯文档最新记录为 3.0.0.6（7月6日），官网下载区已到 3.1.0.0（Windows _142 / MacOS _110）。中间版本（3.0.0.7~3.0.x）无更新日志可查。

**处理**：时间线表格新增 3.1.0.0 条目，标注"官网下载区版本号"；浏览器插件功能（F-059~F-065）归入 3.1.x 阶段。不做无依据的中间版本推断。

### 勘误-5：官网口径 vs 文档口径差异

官网首页将产品能力表述为四大维度（Computer Use 可视化操作 / 专属远程多端能力 / IM 操作便捷性 / 远程安全把控能力），文档为三大能力（多端远程执行 / Computer Use / 过程可追溯）+ IM 横向集成。

**处理**：在 concepts/01-core-capabilities.md 新增"官网口径对比"节，逐项对照差异来源（宣传侧重 vs 操作说明侧重），实质内容一致。
