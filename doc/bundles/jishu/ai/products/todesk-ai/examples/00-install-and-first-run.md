# 安装登录与首次会话

> 本篇为可照做的实操流程，整合自原文"二、安装和登录"与"三、快速开始"两章。

## 0. 环境自检

| 检查项 | 要求 | 不满足时的处理 |
|--------|------|---------------|
| Windows 版本 | Windows 10 及以上（不支持 7/8/8.1） | 更换设备（F-014/F-018） |
| macOS 版本 | 环境表为 macOS 11+；3.0.0.6 起最低支持调整至 macOS 10.15 | 升级系统或确认当前版本（F-014） |
| iOS 设备 | 需可安装 TestFlight | 见下文 iOS 安装流程（F-015） |
| WebView2 | PC 端界面渲染组件 | 缺失时按弹窗提示手动安装（F-017） |
| 杀毒软件 | 360/火绒等可能隐藏入口 | 临时关闭后再试（F-018） |

## 1. 下载

访问 ToDesk AI 官网（todeskai.com），按操作系统选择对应版本下载（F-004/F-070）。3.1.0.0 时点直链：

| 平台 | 下载链接 |
|------|---------|
| Windows (x64) | `https://dl.todeskai.com/windows/ToDeskAI_Setup_3.1.0.0_142_x64.exe` |
| macOS | `https://dl.todeskai.com/mac/ToDeskAI-v3.1.0.0_110.pkg` |
| Android | `https://dl.todeskai.com/android/ToDeskAI_3.0.0.1.243.apk` |

## 2. 分平台安装

### Windows

1. 双击安装包；若弹出系统授权对话框（"你要允许此应用对你的设备进行更改吗？"），选择"是"；
2. 选择安装位置（默认 `C:\Program Files\ToDesk AI\`），勾选同意《用户隐私协议》，点击"立即安装"等待完成。

### macOS

1. 双击安装包，点击"继续"；
2. 输入设备开机密码，点击"安装软件"，等待完成。

### iOS

经 TestFlight 分发，共三步（F-015）：

1. 在下载页点击"在 App Store 中查看"，安装 TestFlight 后返回页面；
2. 点击"在 TestFlight 中查看"，进入 ToDesk 下载页完成安装；
3. 安装成功后打开应用即可使用。

### Android

官网提供独立 APK 下载（F-067），版本 3.0.0.1.243。在 todeskai.com 下载区直接下载 APK 安装包安装即可。

## 3. 登录

初次登录两种方式任选：手机验证登录，或微信扫码登录（F-016）。

## 4. 首次发起会话

登录后进入主窗口，先认识四个核心操作位（F-019）：

| 操作位 | 用途 |
|--------|------|
| 对话栏 | 下达任务指令（输入框提示语："直接说，我来做"） |
| 工作目录 | 查看/设置/切换 AI 可读取、写入文件的目录 |
| 选择设备 | 选择要操作的远程设备，AI 在该设备上执行任务 |
| 上传文件 | 截图或拖拽上传 PDF/CSV/图片/TXT（F-020/F-053） |

### 第一次任务建议

从低风险任务开始验证环境，以下为原文给出的五类示例方向（F-021）：

- 文件操作：让 AI 查找某目录下所有 jpg 文件，或按"日期+原文件名"规则重命名；
- 网页搜索：查股价、登录后台提交日报；
- 文档处理：合并多个季度 Excel、生成周报模板；
- 定时任务：设一个"每早 9 点整理 AI 新闻"的提醒；
- 信息整理：总结 PDF 报告核心观点、提取会议纪要待办。

### 界面形态补充

- **小窗口模式**：点击左上角小窗图标切换；小窗支持新建对话（清空上下文）、窗口置顶、切回主窗口，底部输入区与主窗口一致（F-023）；
- **验证 Computer Use**：给一个只靠界面才能完成的任务（如在微信里给某人留言），观察 AI 自动启用 GUI 操控（F-022；机制见 [concepts/02](../concepts/02-computer-use.md)）。

## 常见安装问题速查

| 现象 | 处理 |
|------|------|
| 群内链接无法下载 | 复制到外部浏览器打开或更换浏览器 |
| 安卓端无入口 | 退出软件、清缓存后重新登录 |
| PC 端无入口 | 关闭 360/火绒等杀毒软件后重试；Win7 不支持 |
| 提示安装 WebView2 | 按弹窗"安装"按钮手动装（F-017） |
| 开 VPN 后不可用 | VPN 环境冲突，关闭后使用 |
