# 添加账号、作品/评论监控与关键词采集

> 覆盖官方 README「基本使用」第 1–2 节。界面名称以 v0.2.4 为准；未实机复跑，平台页面变化可能导致步骤差异。

## 一、添加账号

1. 在顶部选择平台（抖音 / 小红书 / 快手 / 视频号）。
2. 打开左侧「账号」。
3. 选择登录方式：扫码、创作者登录或 Cookie 登录（F-036）。
4. 登录完成后，在账号列表中刷新资料、检测状态或重新登录（F-036）。

### 平台差异

| 平台 | 可用登录 | 注意 |
|---|---|---|
| 抖音 | 扫码 / 创作者 / Cookie | 无桌面环境时可改用 Cookie（F-036、F-055） |
| 小红书 | 扫码 / 创作者 | 扫码只获取主站读取态；**发布需另用「创作者登录」**（F-036） |
| 快手 | 扫码 / 创作者 | — |
| 视频号 | 扫码 | 仅本账号数据，不能监控他人（F-045） |

### 小红书链接要点

- 添加笔记或创作者监控时，建议使用**包含 `xsec_token` 的完整链接**（F-072）。
- 链接解析失败时，重新复制包含有效 `xsec_token` 的完整链接（F-055）。
- 提示“页面可见但详情媒体未读取到”通常是访问参数或页面结构不兼容，不应单凭该错误判定账号失效（F-036）。

## 二、作品监控

1. 打开监控功能，新建监控。
2. 添加创作者主页、作品链接、短链或平台 ID（F-038）。
3. 选择执行账号、扫描频率与采集策略。
4. 保存后，发现新作品自动入库（F-038）。

### 关键选项

- **历史回填**：默认只监控订阅后的作品；可回填最近若干条。配置 `monitor_initial_backfill_count=0` 表示只监控新作品，`-1` 表示尽可能回填（F-058）。
- **多账号监控同一主页**：抖音、小红书、快手支持不同执行账号分别订阅同一主页，各任务独立维护扫描进度、策略与作品记录（F-038）。
- **去重**：同账号同主页只允许一条任务（含已暂停任务）；更换执行账号时也会检查重复（F-038）。
- **频率**：作品/评论/弹幕支持秒级预设或自定义 1–86400 秒；分钟可填小数，换算后须为整秒（F-069）。

> 不建议把频率设到秒级然后长期挂着：平台风控看的是“行为节奏”，不是“任务配置”。先用默认 300 秒观察几天（F-058）。

## 三、评论监控

- 可订阅**单条作品**，也可监控**账号近期作品**的评论（F-039）。
- 评论与作品是独立订阅：只建作品监控不会自动聚合全部评论，需要另建评论监控（F-039）。
- 评论记录可查看来源任务与抓取时间（README 界面说明）。

## 四、弹幕监控（仅抖音）

1. 新建弹幕监控，选择自己的视频（创作中心）或公开视频（播放器拦截）。
2. 设置时间范围、关键词、文本长度、点赞数与容量上限。
3. 记录按视频内时间轴排序并持久化到 SQLite（F-040）。

> 弹幕适合做“第几秒观众在讨论什么”的内容复盘；它不是评论的替代品。

## 五、关键词批量采集

1. 选择平台：抖音或小红书（快手、视频号不支持）（F-037）。
2. 输入关键词，**一次最多 20 个**（F-037）。
3. 设置每词作品数、采集深度、排序、发布时间、作品类型、互动门槛、每作品评论数、二级评论、媒体下载（F-037）。
4. 提交后进入任务队列；结束后可编辑配置、保留结果去重续跑、导出 Excel（F-037）。

### 口径纪律

- 关键词采集是**一次性批处理**，不是持续订阅；要持续盯新作品，另建作品监控（F-037）。
- 结果是**采集上限**，受平台排序、账号登录态与当前可见范围影响，不代表平台全量（F-037）。
- 小红书主站登录态用于采集；发布走创作者登录态（F-036）。

## 六、任务队列观察

- 「任务队列」统一展示采集、发布、自动评论、账号动作、下载（F-047）。
- 支持按平台、队列类型、状态、关键词筛选（F-047）。
- 被额度、时段、代理或冷却拦下的任务保持 `pending`，重启后恢复（F-049）。
- 登录态失效时任务保留，等待重新登录（F-049）。

## 验收清单

- [ ] 目标平台账号登录成功，账号列表能刷新资料与检测状态。
- [ ] 小红书发布账号已单独完成「创作者登录」。
- [ ] 新建 1 条作品监控，能看到扫描进度与新作品入库。
- [ ] 新建 1 条评论监控（单作品或近期作品）。
- [ ] 关键词采集任务完成，能导出 Excel。
- [ ] 任务队列中能看到上述任务及状态。

## 常见问题

| 现象 | 处理 | 依据 |
|---|---|---|
| 抓取不到作品或评论 | 检查登录态、目标链接、网络；必要时重新登录并降低频率 | F-070 |
| 小红书链接解析失败 | 重新复制含有效 `xsec_token` 的完整链接 | F-070 |
| 扫码登录无弹窗 | 确认桌面环境；抖音改用 Cookie | F-055 |
| 同一主页无法再建任务 | 同账号同主页只允许一条；换执行账号或编辑原任务 | F-038 |
| 采集结果比预期少 | 受排序/登录态/可见范围影响，调大每词上限或换排序 | F-037 |
