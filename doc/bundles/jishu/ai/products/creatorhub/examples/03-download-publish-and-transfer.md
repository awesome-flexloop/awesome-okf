# 下载、发布、跨平台转发与分享链接下载

> 覆盖官方 README「基本使用」第 3–4 节与「分享链接命令行下载」。所有写操作都受队列与风控约束，先读 [任务队列与风控](../concepts/03-task-queue-and-risk-control.md)。

## 一、下载内容

### 面板内下载

- 监控/采集任务可勾选媒体下载；下载支持断点续传与失败重试（F-041）。
- 抖音可选画质；小红书支持图集和视频；快手支持视频（F-041）。
- 多个任务下载同一媒体到同一路径时，串行写入并复用已有文件；需要分别保存时，为任务设置不同下载目录（F-041）。

### 链接下载

1. 打开「链接下载」。
2. 粘贴完整分享文案或链接，系统自动提取地址并下载（F-041）。
3. 在下载历史中查看结果。

### 命令行（只解析或下载）

只解析链接、不访问网络：

```bash
python -m app.engine.share_downloader --links-only "完整分享文案或链接"
```

下载内容：

```bash
python -m app.engine.share_downloader "完整分享文案或链接" -o ./data/media/share -q 1080
```

依据：F-057。`-q` 为画质参数示例，实际支持范围以当前版本为准。

## 二、发布

| 平台 | 发布方式 | 能力 |
|---|---|---|
| 小红书 | 面板内发布 | 图集、视频、定时发布（F-042） |
| 抖音 | 对应创作平台 | 浏览器流程发布（F-042） |
| 快手 | 对应创作平台 | 浏览器流程发布（F-042） |
| 视频号 | 对应创作平台 | 浏览器流程发布（F-042） |

发布编辑器提供素材与文案实时预览；发布前可修改标题、正文和话题（F-042）。

> 不要把“能发布”理解成“可无人值守批量刷屏”。发布是写操作，受同账号写间隔、小时/每日额度与平台规则约束（F-048）。

## 三、跨平台转发（搬运）

官方支持两条路径（F-042）：

1. 已下载的**抖音作品** → 转发到**小红书**或**视频号**。
2. 已下载的**小红书作品** → 转发到**抖音**。

发布前可修改标题、正文和话题（F-042）。

重要边界：

- “统一发到多个平台”应收窄为“各平台分别发布 + 下载后跨平台转发”；README 未声明一次提交自动分发全平台（F-066）。
- 转发他人作品涉及著作权；下载不等于授权，公开再发布前确认权利状态（F-059）。

## 四、自动评论 / 回复

1. 在自动评论/回复规则中设置关键词、排除词、多模板、回复冷却、最大消息年龄（F-043）。
2. 默认生成**待审核草稿**；确认后发送（F-043）。
3. 选择免审核时，仍受活跃时段、统一写间隔、小时/每日上限与风险冷却约束（F-043）。
4. 提交结果不确定时不会自动重试；先到平台核对（F-043、F-049）。

> 建议长期保持“待审核”模式。自动回复的价值是减少重复输入，不是替你做判断；错误回复的公关成本远高于省下的几分钟。

## 五、通知

- 通知渠道：Bark、钉钉、Telegram（F-046）。
- 可启用作品健康监控：零播放、违规或下架状态发送提醒（F-046）。
- v0.2.4 增加 Webhook 事件出站与 HMAC-SHA256 签名，可接自建告警（F-071）。

## 六、“结果待确认”怎么处理

发布、私信、评论出现以下情况会标记待确认：

- 浏览器连接中断、页面反馈缺失、接口回执不确定（F-043、F-049）。

处理顺序：

1. 不要立刻重试。
2. 到对应平台后台核对是否已发布/已发送。
3. 已执行 → 标记完成；未执行 → 确认账号状态与代理后手动重试。
4. 若反复待确认，检查登录态、代理出口与风控中心账号状态（F-053）。

## 七、排障

| 现象 | 处理 | 依据 |
|---|---|---|
| 下载只有音频却得到 MP4，或视频无声音/画质受限 | 更新依赖；安装系统 ffmpeg 并加入 `PATH` | F-070 |
| 下载中断 | 支持断点续传，重新执行同任务 | F-041 |
| 发布按钮点击后无反馈 | 等任务状态；不要连续点击（提交只点一次） | F-043 |
| 发布失败且账号在冷却 | 到风控中心看冷却截止与原因，等恢复 | F-049、F-053 |
| 小红书发布失败但采集正常 | 发布需「创作者登录」态，不是主站读取态 | F-072 |
| 代理测试失败 | 代理失败关闭，不会直连；修复代理后重试 | F-050 |

## 验收清单

- [ ] 链接下载成功，文件落在预期目录。
- [ ] 小红书发布（图集或视频）成功，或明确看到定时任务。
- [ ] 完成一次抖音→小红书（或反向）转发，标题/正文/话题可编辑。
- [ ] 自动回复生成待审核草稿，未自动发送。
- [ ] 通知渠道收到一条测试消息。
- [ ] 能区分“待确认”和“失败”，并按平台核对。
