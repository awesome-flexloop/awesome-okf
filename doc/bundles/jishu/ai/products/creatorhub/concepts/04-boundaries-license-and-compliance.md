# 许可、合规与安全边界

> 本文是采用决策的边界清单，不是法律意见。涉及商用、分发、大规模采集时，请咨询专业法律顾问并核对平台最新条款。

## 一、许可：公开 ≠ 开源

事实：仓库公开，但**根目录没有 LICENSE 文件**，GitHub API `license` 字段为 `null`（F-023）。按默认版权规则，作者保留全部权利（F-065）。

这意味着：

| 行为 | 是否需要授权 | 说明 |
|---|---|---|
| 阅读代码、克隆到本地、自行部署使用 | 通常不需要额外许可（版权法允许的必要使用） | 仍需遵守平台条款与法律 |
| 修改代码供自己使用 | 处于灰色地带，建议取得授权 | 无许可时“ derivative work ”权利未授予 |
| 对外分发、镜像、打包售卖 | **需要**作者书面授权 | 默认版权保留 |
| 企业内部多设备部署 | 建议做许可审查 | 不属于“个人学习”时风险上升 |
| 引用代码片段/架构进自己产品 | **需要**授权或确认许可 | 不要以“GitHub 公开”为由复制 |

> 源文写“开源，能自己部署”。“能自己部署”成立；“开源”不成立。本包统一用“公开仓库 / source-available”，避免把“可读”误当“可分发”。

## 二、平台条款：工具不豁免规则

项目 README 明确：用于技术学习和个人内容管理，不提供账号、Cookie、代理或平台数据；使用时须遵守目标平台规则及所在地法律法规，尊重内容版权和个人隐私（F-059）。

需要自行确认的高风险动作：

1. **批量采集**：关键词批量采集、评论/弹幕抓取可能触及平台“未经许可的数据抓取”条款；公开可见不等于允许批量复制。
2. **自动评论/回复/私信**：多数平台对自动化互动有明确限制；即使工具做了频率控制，也不代表平台允许。
3. **多平台发布/搬运**：跨平台转发他人作品涉及著作权；下载≠获得授权，转发前确认权利状态。
4. **账号矩阵**：多账号操作可能触发平台“关联账号/批量运营”规则；同设备、同出口、同内容会提高关联概率。

> 合规判断的顺序应是：**平台条款 > 当地法律 > 项目 README > 工具默认值**。工具默认值只是技术保护，不是合规许可。

## 三、账号与凭据安全

### 登录态等于账号权限

`data/profiles/` 保存每个账号的 Cookie、缓存与 LocalStorage（F-032），其敏感性等同账号登录权限：

- 不要打包分享 `data/profiles/`、`config.yaml`、`creatorhub.db`。
- 备份使用加密盘；迁移后旧设备彻底删除。
- 共用电脑时使用独立系统账户，避免他人读取。
- 代理凭据写在 `config.yaml` 或账号设置中，同样按密钥管理（F-050）。

### 项目本身的信任边界

- 架构上账号登录态留在本地，不经作者服务器（F-030、F-032）；但**未检索到公开的独立安全审计**，不能据此推断“零第三方接触”（F-067）。
- 浏览器会访问平台域名；可选 fingerprint-chromium 与 `browserscan.net` 体检页会暴露出口 IP 与浏览器特征（F-052）。
- README 展示住宅代理赞助商 IPWO（含推广码）（F-060）。赞助不改变功能事实，但使用其代理意味着流量经第三方，需自行评估。

### Windows 安装包

v0.2.0 的已知说明：安装包**暂未配置发布者代码签名**，请仅从本项目 GitHub Releases 下载（F-071、F-054）。无签名意味着无法用系统信任链验证来源，下载后建议核对发布页与文件哈希（如提供）。

## 四、内容版权与隐私

- 下载的媒体落在 `data/media/`，版权仍属原作者；本地留存用于个人备份与复盘，公开再发布需授权（F-059）。
- 评论、私信、粉丝列表包含他人个人信息；采集与存储应遵循最小必要原则，不对外分享、不用于画像或营销骚扰。
- 弹幕与评论可能含未成年人信息；涉及公开研究时须脱敏。

## 五、供应与运维风险

| 风险 | 表现 | 缓解 |
|---|---|---|
| 单维护者 | 平台改版后修复速度取决于作者 | 锁定可用版本、备份、保留自行修复能力（F-033） |
| 平台风控变化 | 采集/发布突然失败 | 关注 Issue、降低频率、准备手动流程（F-049） |
| 无 LICENSE | 无法合法分发或商用 | 取得授权或仅自用（F-065） |
| 数据单点 | 本机故障丢失 DB/Profile/媒体 | 定期备份 `config.yaml` + `data/`（F-059） |
| 安装包无签名 | 供应链风险 | 只从官方 Releases 下载并核验（F-054） |

## 六、采用建议（决策清单）

1. **先确认用途**：个人学习/自用 → 风险可控；对外分发/商用 → 先解决许可。
2. **先确认平台**：视频号只能管本账号；需要竞品监控就别把它算进方案（F-045）。
3. **先小号验证**：新环境用非主力账号跑通登录、监控、发布各一条（F-018）。
4. **先备份再升级**：`config.yaml` 与 `data/` 一起备份（F-059）。
5. **先读条款再放量**：自动互动与批量采集的合规责任在使用者，不在工具（F-059）。
