# 35 艺术风格配方卡与 9 解说语法机制

> **机制层**：本页是被抽象出的"这套 skill 是怎么工作的"机制，包含三套平行资产（风格配方卡 / 解说语法卡 / 参数化片段）与一条贯穿其中的骨架。

## 一、三套核心资产总览

官方"里面有什么"（F-039~F-044）：

| 资产 | 数量 | 位置 |
|------|-----|------|
| 艺术风格配方卡 | 35 张 | `references/风格配方/` |
| 对应场景代码 | 35 个 | `scripts/engine/scenes/` |
| 解说动画语法卡 | 9 份（8 种附示范片+参数化片段+示例 spec） | `references/`（语法卡） |
| 参数化片段 | 8 种 | `scripts/engine/examples/` |
| 绘画与动画库（笔刷/渲染器/后期/骨架/镜头/图表/排版） | 17 个 | `scripts/engine/lib/` |
| 方法文档 | 12 篇 | `references/01`–`12` |

## 二、艺术风格配方卡 = "可执行的工程文档"

每一张配方卡不只是视觉参考，而是一份可执行工程文档（F-009/F-040），明确写清四件事：

1. **参数**：颜色、笔触粗细、画布比例等具体数值
2. **母题动作**：该风格下典型的运动元素（梵高的星旋、埃及壁画的横移、马赛克的颜色流动）
3. **签名转场**：该风格特有的转场方式（水墨晕染、纸面卷动、像素淡入）
4. **当前短板**：哪些地方目前做不好，需要手动补帧或用生成模型合成

风格覆盖从岩洞壁画、埃及壁画、莫奈、梵高、克林姆特、包豪斯、Kirby 漫画、8-bit 像素、蒸汽波到新海诚风格（F-008）。

> **关键设计**：配方卡把"怎么做对"沉淀为可执行参数 + 母题动作 + 签名转场 + 已知短板四元组，让 agent 不只"画得像"，还"动得像、转场像、知道哪里做不到"。（见移迁实践）

## 三、9 种解说动画语法卡

对 coding agent 说"我要做 Kurzgesagt 风格的科普动画"，agent 就知道怎么画（F-014）。完整 9 种（F-014~F-020/F-037）：

| # | 语法 | 特征 |
|---|------|------|
| 1 | Kurzgesagt | 扁平无描边、尺度穿行（地球→星系、DNA→细胞） |
| 2 | Vox | 剪报、红线、荧光笔——新闻截图/数据图表/手绘红线拼贴 |
| 3 | 白板动画 | 笔尖揭开线稿，跟着口播一步步把图画出来 |
| 4 | 3Blue1Brown | 对象形变成下一个，用几何变换做视觉隐喻 |
| 5 | Storytime | 反应特写、笑点停顿——讲段子的节奏 |
| 6 | 动态文字 | 主词砸进来，用文字本身当视觉元素 |
| 7 | 发布会 UI | 光斑底、毛玻璃卡、大数字——发布会质感 |
| 8 | 财经图表 | 先坐标轴、后数据、只标一件事 |
| 9 | 讲解员式财经科普 | 更复杂的变体，需自备角色素材，语法卡+整片代码作参考 |

> ⚠️ **勘误**：文章衔接处写"8 种"，官方 README 为 **9 种**（8 种附示范片 + 第9种讲解员式为代码快照）。（F-013/F-037/F-038）

## 四、8 种参数化片段 = "动画积木"

前 8 种语法都有示范片和参数化片段：**给一份 JSON spec，就能导出一段时长精确到帧的动画**（横屏、竖屏甚至透明底）（F-019/F-021）。

示例（财经图表）：`--spec scripts/engine/examples/t3_finance_chart.json --out 财经图表.mp4` 读取 JSON 里的时间轴、数据、标签参数，渲染完整动画（F-051）。

## 五、长卷穿越片骨架

"最有意思"的参数化积木（F-021~F-023/F-050），基本架构：

- 每个画风世界是**一个单独的段文件**
- 主角一路往右走（可换自己的卡通形象）
- **跨边界时画风自动切换**——"世界和他自己的画风一起换"
- 镜头只进不退，保持向前的节奏

骨架自带 3 段示范：**埃及壁画 → 莫奈《日本桥》→ 8-bit 像素**（F-051）。花叔的《花叔穿越名画》就是基于该骨架扩展到 23 画风、2 分 08 秒（F-024/F-041）。

## 六、机制层洞察（四元组）

1. **陈述**：动画风格的"可复现性"不在于生图 prompt，而在于一份把参数、运动、转场、短板都写明的**可执行配方卡**。
2. **证据**：35 张配方卡每张都是可运行场景 + 渲染器 + 签名转场（F-008/F-009）；风格从公元前 40000 年岩洞穿到 2026 年（F-041）。
3. **反常识**：与"AI 生图即一切"的直觉相反，这套 skill 用**纯代码**处理场景/转场/运动，只用生图模型补最难的"人"——把 AI 放在它最该被放的位置（F-031/F-049）。
4. **行动**：复刻动画时先拆解（量转场/节拍/运动热图）再用代码复刻，而不是"一张张画之间做转场"（F-028/F-041）。
