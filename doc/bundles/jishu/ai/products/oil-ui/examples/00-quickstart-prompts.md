# 六条可直接复制给 Agent 的提示

> **门槛说明**：oil-ui 的安装命令（`npx skills add oil-oil/oil-ui`）与下列提示皆有明确输入/步骤/可观察输出，满足操作可复现性两问（有输入与流程、可独立执行并验证），故设 examples/ 层。

## 提示 1——先认品类

```
帮我做一个"独立开发者作品集"落地页。用八步设计法第 1 步：
先告诉我这是什么品类、读者会拿它做什么；然后找同类里风格最鲜明的 2~3 家，
拆解它们怎么做、为什么这样做，再决定哪些沿用、哪些换掉。
```

## 提示 2——先定调性（五刻度）

```
我想要的调性是：能量 高、完成度 足够、密度 疏松、分量 轻、严肃度 中等。
请先用这五个刻度各给我一句"你打算怎么落地"的判断（用什么字、留多少白、颜色占多大面积），
确认后再开画。
```

## 提示 3——从具体的东西出发

```
这个方向别从"简洁大气"出发。给一个具体的起步素材：
材质=深空星云，环境=太空站指挥舱，场景/角色=指挥官查看任务进度。
从这个具象画面推整套视觉语言。
```

## 提示 4——先问首屏给谁看

```
这是"内容页"不是"说服页"（用户来看内容/挑选作品）。首屏直接放第一排内容本身，
不要先做传单式 slogan。确认首屏信息层级后，再动工。
```

## 提示 5——拉开方向·自查撞车

```
给我 3 个设计方向。约束：任意两个方向的 骨架/字体/色彩/主视觉 最多一项相同。
开画前先自查一遍这些维度，把我冲突的地方标出来针对性解决。
```

## 提示 6——对比页 + 实际画面为准

```
把上面 3 个方向全部放进同一个对比页里，分别按电脑和手机两种尺寸截图给我。
我先挑方向，再说具体喜欢/不喜欢哪里；你据此迭代，最后以实际画面为准做减法：
一页只有一个主角，删掉不影响理解的文字、重复的线、多余的容器。
```
