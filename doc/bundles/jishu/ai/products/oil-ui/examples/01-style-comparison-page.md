# 用风格对比页在多方向间决策

oil-ui 风格对比页（ProfileComparer）把多个设计方向**并排**放进同一页面，让"挑方向"变为可操作决策（F-018 / F-006✅）。

## 对比页长什么样

- 每个方向独立成卡。
- 每卡突出**一项差异化**（骨架 / 字体 / 色彩 / 主视觉）。
- 以 **HTML / 图片 / 可运行页**三种形态呈现，便于在真实尺寸下观察。

## 决策工作流

```
1. 让 Agent 用八步法产出 3 个方向（第 1~5 步）
2. Agent 把 3 方向全部装入同一个对比页（第 7 步）
3. 你按"电脑 + 手机"两种截图尺寸查看（第 8 步）
4. 你挑一个方向，并说明具体喜欢/不喜欢哪里
5. Agent 据此迭代，最多再做减法（一页一个主角）
6. 若需要，可在开源版范围内请一位没看过制作过程的独立评审
```

## 决策要点

- **先挑再改**：先选方向，再说细节，避免边看边否定。
- **以画面为准**：不要凭"感觉高级"下判断，看真实截图。
- **只动一处**：一次只调一个维度（如只换色彩，不动骨架），便于归因。

