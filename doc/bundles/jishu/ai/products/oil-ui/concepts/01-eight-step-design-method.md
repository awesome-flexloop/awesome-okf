# 八步设计法与五种调性刻度

本文是 oil-ui 的**机制层**：方法论如何把"高级""简洁"这类模糊审美词，翻译成 AI 能执行的、每一步都有判断标准和输出物的工作流。以下八步以 GitHub 官方 README 为唯一权威口径（F-030），并标注每一步"要做什么 / 不做什么"。

## 八步设计法

    E --> F["6️⃣ 留一处让人记住的地方<br/>一两处做到极致，其余安静"]

| 步 | 要做什么 | 官方要点（F-030） |
|----|---------|------------------|
| 1. 先认品类 | 看同类最好的产品 | 说出这是什么产品，找出同类里风格最鲜明的两三家，拆开看它们怎么做、为什么这样做，再决定哪些沿用、哪些换掉 |
| 2. 先定调性 | 翻成看得见的决定 | 从题材、受众和品牌语气推出**五刻度**："高级""简洁"翻成用什么字、留多少白、颜色占多大面积 |
| 3. 从具体的东西出发 | 具体引擎起步 | 每个方向从一个材质+环境+场景/角色，或另一领域的整套表现形式起步；内容从产品本身找，不从形容词出发 |
| 4. 先问首屏给谁看 | 内容页 vs 说服页 | 来看内容/挑东西/干活的页面，首屏是第一排内容本身；要说服人的页面才选骨架、画线框、写文案 |
| 5. 检查方向差别 | 强制拉开距离 | 骨架/字体/色彩/主视觉四项里，任意两个方向**最多一项相同**；小样并排眯眼看明暗块面，太像就重选骨架 |
| 6. 留一处记住的地方 | 一两处做到极致 | 不求整页用力，只把一两处做到极致（一次点按反馈、付款成功那一下、AI 干活过程、一个 404）；其余保持安静 |
| 7. 品味由你来定 | 用户决策 | 小样进同一对比页，你来挑，再说具体喜欢/不喜欢哪里 |
| 8. 以实际画面为准 | 验证与做减法 | 电脑+手机双尺寸截图检查，可请未看过制作过程的独立评审；最后做减法：一页只有一个主角，删掉不影响理解的文字、重复的线和多余容器 |

## 五种调性刻度：把审美翻成数字

五刻度是方法论的精华——把模糊审美翻译成 AI 能理解的**数值范围**（F-008 / F-030）：

| 刻度 | 连续区间 | 含义 |
|------|---------|------|
| **能量** | 高 / 低 | 视觉冲击力与情绪强度 |
| **完成度** | 够不够 | 打磨精细程度 vs 概念草图感 |
| **密度** | 疏松 / 紧凑 | 信息排布疏密 |
| **分量** | 轻 / 重 | 视觉重量感 |
| **严肃度** | 轻松 / 正式 | 语气与调性的正式程度 |

> **设计意图**：这些刻度让"先定调性"可执行——把"我要高级一点"这种无法量化的诉求，拆成可调节、可对比、可让 AI 照着调的参数（F-008）。

## 关键约束（不做什么）

- **不问空泛形容词出发**：禁止从"简约""大气"这类词直接开画，必须从具体的东西出发（步骤 3）。
- **不默认懒方案**：禁止默认 Inter + Tailwind 默认调色板 + 8px 圆角 + 淡阴影（见三痛点·痛点三，F-007）。
- **不允许方向撞车**：任意两个方向的骨架/字体/色彩/主视觉最多一项相同（步骤 5）。
- **不求整页用力**：只留一两处记忆点，其余安静（步骤 6）。
