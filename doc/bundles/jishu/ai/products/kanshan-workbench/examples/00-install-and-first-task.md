# 从安装到第一个任务：跑通一条最小链路

> **说明**：以下步骤来自官方手册（F-061~F-070），本包**未在真机执行**。不同客户端版本的按钮文案可能略有差异；以你安装时的界面为准。

## 适用对象

- 第一次使用看山工作台；
- 想在正式处理工作文件前，先用一个无关紧要的 Excel 验证「读取—分析—写回」链路；
- 使用 macOS 或 Windows（目前不支持 Linux，F-059）。

## 准备物

| 物品 | 要求 |
|---|---|
| 系统 | macOS 或 Windows |
| 账号 | 知乎账号（F-063） |
| 测试文件 | 一个不含敏感信息的 Excel，例如 20 行模拟销售数据 |
| 工作目录 | 新建 `KanshanWorkspace` 目录，只放测试文件 |

## 步骤 1：下载与安装

### macOS

1. 下载 `.dmg` 安装包；
2. 打开安装包；
3. 将「看山工作台」拖入 Applications 文件夹；
4. 打开应用并完成登录。

依据：F-061。

### Windows

1. 下载 `.exe` 安装包；
2. 双击运行安装程序；
3. 按页面提示完成安装；
4. 打开应用并完成登录。

依据：F-062。

**验收点**：应用能正常启动，未出现系统拦截提示；如出现「无法验证开发者」等系统提示，按 macOS/Windows 的常规安全设置流程处理（原文未展开）。

## 步骤 2：登录

使用知乎账号授权登录（F-063）。

**验收点**：登录后能看到主界面与任务入口；若卡在授权页，检查浏览器是否拦截了授权回调，或换用系统默认浏览器重试。

## 步骤 3：设置文件访问权限

1. 按系统提示授予看山工作台所需权限；
2. 选择允许访问的本地目录，指向准备好的 `KanshanWorkspace`；
3. 确认应用不会访问未授权目录。

依据：F-064、F-065、F-015。

**验收点**：在应用内能看到 `KanshanWorkspace` 下的测试文件；未授权的目录不应出现在可选范围中。

> 建议：不要在这一步授权整个用户主目录或磁盘根目录。工作目录与个人文件分离，后续排查「AI 看到了什么」会简单很多。

## 步骤 4：设置快捷键（可选）

默认快捷键为 macOS ⌘K、Windows Ctrl+K；如与其他应用冲突，在「设置」中修改（F-022、F-066）。

**验收点**：在任意文本编辑器中选中一段文字，按快捷键能唤起 Quick Bar。

## 步骤 5：第一个任务——分析 Excel

在对话中选择测试 Excel，输入类似指令：

```text
读取 ~/KanshanWorkspace/模拟销售数据.xlsx 的「Sheet1」工作表。
分析各渠道的销售额与转化率，找出增长最快和下滑最明显的两个渠道。
把结论写入一个新工作表「分析结论」，保留原工作表不变。
完成后告诉我：读取了多少行、用了哪些列、结论写到了哪个工作表。
```

依据：F-011、F-070、F-071。官方示例包括「分析 Excel 销售数据，找出增长最快和下滑最明显的品类，并将分析结论写入一个新的工作表」（F-012）。

**验收点**：

- [ ] 应用正确识别工作表与列；
- [ ] 原工作表未被修改；
- [ ] 新增「分析结论」工作表，内容与指令一致；
- [ ] 应用报告了读取行数、使用列与写入位置；
- [ ] 打开文件后公式与关键数字正常（若含公式，F-074）。

## 步骤 6：确认「另存为新文件」策略

第一个任务跑通后，建议把默认策略固定下来：

```text
以后处理 Excel 时，默认另存为新文件，不覆盖原文件。
文件名规则：原文件名 + "_" + 任务类型 + ".xlsx"。
写回前告诉我目标工作表、写入范围与是否保留原数据。
```

依据：F-071、F-093、F-098。看山没有内建文件历史面板，也没有操作级回滚；另存新文件是最低成本的「后悔药」。

## 常见问题

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 看不到工作目录 | 目录未授权或授权范围不对 | 回到「设置」重新选择目录（F-065） |
| Excel 读取失败 | 文件被其他程序占用、格式特殊、公式复杂 | 关闭占用程序；另存为普通 `.xlsx` 再试 |
| 写回后公式错位 | 公式重算依赖 LibreOffice，当前环境可能受限（F-074） | 让 AI 只写值；或写回后在 Excel 中人工修正公式 |
| Quick Bar 无反应 | 快捷键冲突或应用不支持读取选中内容 | 在设置中改快捷键；换一个应用试（F-024、F-066） |
| 登录失败 | 授权回调被拦截 | 换默认浏览器重试；检查系统时间与网络 |
