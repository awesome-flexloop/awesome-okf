# 浏览器任务与 Quick Bar 实操：从公开网页到选中文处理

> **说明**：步骤来自官方手册（F-017~F-024、F-075~F-078），本包未真机执行。网页结构会变化，任务失败时先检查页面是否改版、是否需要登录。

## 一、安装并启用浏览器工具插件

1. 打开「设置」；
2. 进入「插件管理」；
3. 找到浏览器工具插件，安装并启用。

依据：F-017、F-075。

**验收点**：插件状态显示已启用；新建任务时能看到浏览器相关能力。

## 二、两类网页任务

### 任务 A：竞品官网对比（公开页面）

```text
任务：对比 [A]、[B]、[C] 三家竞品官网的产品功能与价格。
范围：只读取公开页面；不登录、不提交表单、不下载文件。
输出：一张对比表，列包括「产品名 / 核心功能 / 价格档位 / 免费额度 / 信息来源 URL / 读取时间」。
约束：每个价格必须附页面 URL 与读取时间；找不到的单元格写「未披露」，不要猜测。
保存：把对比表导出为 Excel，保存到 ~/KanshanWorkspace/竞品对比.xlsx。
```

依据：F-018（官方示例：查看竞品官网，整理产品功能和价格信息）。

**验收**：

- [ ] 三家都覆盖，没有漏项；
- [ ] 每个价格有 URL 与读取时间；
- [ ] 「未披露」单元格没有被模型猜测填充；
- [ ] 导出的 Excel 能正常打开。

### 任务 B：网页表格提取

```text
任务：打开 [页面 URL]，提取页面中的 [表格名称] 表格。
范围：只读取当前页面，不点击分页、不展开登录内容。
输出：Excel，保留原表头与行顺序。
约束：如果页面有多个表格，先列出所有表格的标题与行数，等我确认后再提取指定表格。
保存：~/KanshanWorkspace/页面表格.xlsx。
```

依据：F-018（官方示例：提取页面里的表格信息，整理成 Excel）。

**验收**：

- [ ] 表格标题与行数先列出，确认后再提取；
- [ ] 表头与行顺序与原页面一致；
- [ ] 合并单元格、空值处理有说明；
- [ ] 没有把导航栏、页脚等噪声混入表格。

## 三、需要登录的页面怎么处理

默认浏览器环境不继承日常浏览器的 Cookie 与登录状态（F-019、F-076）。遇到登录页时，有两条路径（F-020）：

### 路径 1：可见浏览器窗口手动登录

1. 切换任务到可见浏览器窗口；
2. 由你在窗口中完成账号密码、验证码或扫码；
3. 登录成功后，把控制权交回任务。

**适合**：一次性、低频率的登录页面。

### 路径 2：启用真实浏览器连接器

1. 在设置中启用真实浏览器连接器；
2. 确认连接的是你希望使用的浏览器；
3. 关闭无关的敏感标签页；
4. 再发起任务。

**适合**：需要复用登录态的高频页面。

> ⚠️ 原文未披露连接器的权限范围、能否读取其他标签页、操作日志保存在哪里（F-117）。连接前关闭网银、邮箱、企业内部后台等高敏页面。

## 四、Quick Bar 四个实操

### 4.1 翻译

1. 在任意应用中选中一段外文；
2. 按 macOS ⌘K / Windows Ctrl+K；
3. 选择「翻译」或直接输入「翻译成中文」。

依据：F-022、F-023、F-078。

### 4.2 总结成三点

1. 选中一段长文；
2. 唤起 Quick Bar；
3. 输入「总结成三点，每点不超过 30 字」。

依据：F-078。

### 4.3 提取行动项和责任人

1. 选中会议纪要或邮件正文；
2. 唤起 Quick Bar；
3. 输入「提取行动项和责任人，输出表格：行动项 / 责任人 / 截止时间」。

依据：F-078。

### 4.4 分析表格单元格异常值

1. 在 Excel 中选中一组数值单元格；
2. 唤起 Quick Bar；
3. 输入「分析这些单元格中的异常值，说明判定规则和异常单元格坐标」。

依据：F-078。

**验收点**：Quick Bar 能正确读取选中内容；如果只读到剪贴板或空内容，说明当前应用不允许读取选中内容，换应用或改用复制粘贴（F-024、F-106）。

## 五、组合工作流：网页 → 总结 → 落盘

1. 浏览网页时，用 Quick Bar 对关键段落做「总结成三点」（F-078）；
2. 把总结粘贴到本地 Markdown 笔记；
3. 需要对多个网页做系统对比时，改用浏览器任务输出 Excel（F-018）；
4. 最后用本地文件能力把 Excel 与笔记合并成报告（F-073）。

## 六、失败排查表

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 插件找不到 | 未安装或版本不匹配 | 回到「设置 → 插件管理」重新安装（F-017） |
| 页面停在登录页 | 默认环境无 Cookie | 用可见窗口手动登录，或启用真实浏览器连接器（F-020） |
| 验证码无法通过 | 自动化无法完成人机验证 | 切换可见窗口人工完成（F-020） |
| 表格提取缺列 | 页面使用动态渲染或合并单元格 | 先列出表格结构确认，再指定列（F-018） |
| Quick Bar 读不到选中内容 | 应用限制或权限不足 | 换应用；检查系统辅助功能权限（F-024、F-106） |
| 价格抓取错误 | 页面地区/币种/登录态不同 | 要求附 URL 与读取时间，人工复核（F-018） |
