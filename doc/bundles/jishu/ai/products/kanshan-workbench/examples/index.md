## 使用顺序建议

1. 第一次使用：先跑 00，确认安装、登录、授权与写回链路。
2. 主要处理表格：直接用 01 的模板，按「另存新文件」策略执行。
3. 需要网页信息：先装插件，再按 02 的任务模板约束范围与出处。
4. 需要团队协作或自动化：按 03 连接平台、创建定时任务、再考虑 Coding 任务。

## 统一纪律

- **先副本后写回**：默认另存为新文件（F-071、F-098）。
- **先只读后写入**：网页与企业数据任务先探查，再写入/外发（F-018、F-080）。
- **先试跑后定时**：定时任务先手动执行一次，再启用周期（F-085）。
- **先提交后批量**：批量改文件前创建 Git 提交或备份（F-098、F-101）。
