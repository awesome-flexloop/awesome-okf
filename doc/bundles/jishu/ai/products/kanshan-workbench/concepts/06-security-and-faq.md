# 安全、权限与 FAQ：使用前的风险清单

## 1. 四条官方安全承诺

| 承诺 | 原文口径 | 依据 |
|---|---|---|
| 文件访问由用户授权 | 不默认访问电脑中的全部文件；用户主动选择可访问范围；仅在授权范围内读取和处理 | F-015、F-108 |
| 本地文件不上云 | 本地文件不会上传到云端；读取、修改、保存在用户电脑中完成 | F-016、F-051、F-102、F-109 |
| 任务记录与文件历史可查 | 可查看定时任务执行记录；Git 仓库历史可用只读 Git 命令查看；改变仓库状态前需确认；非 Git 目录无文件历史面板 | F-110 |
| 重要操作人工确认 | 重要文件、批量修改、公式调整、覆盖保存，建议执行前明确范围、执行后检查结果 | F-111 |

## 2. 六条常见问题（官方 FAQ 摘要）

| 问题 | 官方回答 | 依据 |
|---|---|---|
| 本地文件会上传到云端吗？ | 不会，仅在用户电脑和授权范围内读取、修改与保存 | F-102 |
| 支持哪些操作系统？ | macOS 和 Windows，目前不支持 Linux | F-103 |
| 可以直接修改 Excel 并写回吗？ | 可以；建议明确目标工作表、修改范围、写入位置与保存方式，完成后检查关键数据与公式 | F-104 |
| 支持企业私有化部署吗？ | 不支持 | F-105 |
| Quick Bar 可以在哪些应用中使用？ | 多数桌面应用；读取与处理能力受操作系统、应用限制与权限设置影响 | F-106 |
| AI 修改文件出错怎么办？ | Git 仓库可查历史、恢复前确认；非 Git 目录需事先备份；不支持操作级回滚与自动快照 | F-107 |

## 3. 数据流向：能承诺什么、不能承诺什么

原文的承诺是「本地文件不会上传到云端」（F-016、F-051、F-102、F-109），同时又说云端能力用于模型推理、复杂任务规划、多模态理解和内容生成（F-049）。两者之间有一个未披露的细节：**本地文件内容以什么形式参与云端推理**（F-116）。

因此，本包把可引用边界分成两档：

| 档位 | 可以怎么说 | 不能怎么说 |
|---|---|---|
| 文件本体 | 文件不会作为附件上传到云端（官方承诺） | 「文件绝不会离开本机」 |
| 文件内容 | 原文未披露传输形式（文本/单元格/特征） | 「任何数据都不离开本机」 |
| 云端推理 | 模型推理在云端完成（官方口径） | 「完全离线运行」 |

**敏感材料的正确做法**：

1. 先做脱敏副本（去掉姓名、手机号、客户 ID、金额、地址）；
2. 只把脱敏副本放进授权目录；
3. 任务结束后删除临时副本与导出物；
4. 需要更强保证时，改用本地模型或离线工具，不要依赖本产品。

## 4. 按任务类型的风险等级

| 任务 | 风险点 | 等级 | 建议 |
|---|---|---|---|
| 公开网页信息整理 | 抓取范围、页面变化 | 低 | 只读公开页，要求附 URL 与时间 |
| 本地文档总结 | 内容进入云端推理的形式未披露 | 中 | 脱敏后再处理 |
| Excel 写回 | 覆盖原文件、公式错位 | 中高 | 另存新文件，写回后人工复核公式 |
| 批量修改文件 | 无操作级回滚、无自动快照 | 高 | 先 Git 提交或整目录备份 |
| 企业数据读取/外发 | 授权范围、身份（用户 vs 机器人） | 高 | 最小授权，外发前人工确认 |
| Coding 任务 | 代码改动、依赖安装、服务回收 | 高 | Git 仓库内操作，逐次 diff，跑测试 |
| 定时任务推送到协作平台 | 无人值守、覆盖/外发 | 高 | 保留执行记录，先在测试目录试跑 |

## 5. 授权与权限清单

- **目录授权**：只授权当次任务需要的目录；不把整个用户主目录或磁盘根目录授权给应用（F-015、F-065）。
- **平台授权**：只连接当前任务需要的平台；不用的平台及时断开（F-025、F-039）。
- **身份区分**：飞书/钉钉为用户 OAuth，企业微信为机器人授权；外发消息、提交审批前确认执行身份（F-034）。
- **连接器边界**：真实浏览器连接器的权限与数据回流未披露（F-117）；连接前关闭敏感标签页。
- **技能来源**：SkillHub 技能与自定义技能的审核机制未披露（见 [verification.md](../references/verification.md) 的 S-4）；只安装可信来源的技能，安装前阅读技能说明。

## 6. 一套可执行的安全习惯

1. **单一工作目录**：所有待处理文件放入 `~/KanshanWorkspace/`，不散落在桌面与下载目录。
2. **先副本后写回**：任何写回操作都先另存为新文件，确认后再替换。
3. **先提交后批量**：批量修改前创建 Git 提交或整目录备份。
4. **先只读后写入**：网页与企业数据任务先只读探查，确认范围后再写入/外发。
5. **先试跑后定时**：定时任务先在测试目录手动跑一次，确认输出与记录正常，再启用周期。
6. **先脱敏后上云**：敏感材料先脱敏，不把「文件不上云」当作「数据不离机」。

## 7. 一页检查表

- [ ] 只授权必要目录，未授权整个主目录或磁盘根目录（F-015）。
- [ ] 敏感文件已脱敏，未把「文件不上云」扩写为「数据不离机」（F-116）。
- [ ] Excel 写回另存新文件，写回后复核公式与关键数字（F-101、F-104）。
- [ ] 批量修改前有 Git 提交或备份（F-098）。
- [ ] 企业数据外发前人工确认身份与范围（F-034、F-039）。
- [ ] 定时任务先手动试跑，并保留执行记录（F-085、F-087）。
- [ ] 真实浏览器连接器使用前关闭敏感标签页（F-117）。
