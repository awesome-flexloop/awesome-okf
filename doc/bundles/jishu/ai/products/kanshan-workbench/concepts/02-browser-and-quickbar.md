# 浏览器辅助与 Quick Bar：让 AI 看网页、处理选中文

## 1. 浏览器辅助：先装插件，再发指令

浏览器能力不是开箱即用：首次使用前，需要在「设置 → 插件管理」中安装并启用浏览器工具插件（F-017、F-075）。启用后，直接用自然语言发起网页任务即可。

官方给出四类典型任务（F-018）：

| 任务类型 | 官方示例 | 适合的输出 |
|---|---|---|
| 价格/信息查询 | 打开网站查看最新价格 | 单点信息或简短结论 |
| 竞品对比 | 查看几个竞品官网，整理产品功能和价格信息 | 对比表 |
| 公开资料简报 | 查询公司最近公开资料，生成简报 | 结构化简报 |
| 表格提取 | 提取页面表格信息，整理成 Excel | Excel/CSV |

## 2. 独立环境与登录边界

这是最容易踩坑的一条：浏览器工具**默认运行在独立的临时环境中，不会继承用户日常浏览器中的 Cookie 和登录状态**（F-019、F-076）。

后果很直接：

- 公开页面（新闻、官网、公开价格页）通常可直接读取；
- 需要登录的页面（企业后台、付费内容、个人账户页）在默认环境下会停在登录页；
- 遇到验证码、短信确认、扫码登录时，自动化流程无法自行完成。

官方给出两条替代路径（F-020、F-076）：

1. **启用真实浏览器连接器**：让工具连接到用户已登录的浏览器环境；
2. **切换到可见浏览器窗口**：由用户在可见窗口中手动完成登录，再把控制权交回任务。

> ⚠️ **边界未披露**：原文没有说明真实浏览器连接器的权限范围、能否读取其他标签页、操作日志保存在哪里（F-117）。连接真实浏览器前，建议先关闭无关的敏感标签页，并避免在连接状态下处理网银、邮箱、企业内部后台等高敏页面。

## 3. 网页任务的写法

一个可复用的网页任务模板：

```text
任务：对比 A、B、C 三家竞品官网的产品功能与价格。
范围：只读取公开页面，不登录、不提交表单、不下载文件。
输出：一张对比表，列包括「产品名 / 核心功能 / 价格档位 / 免费额度 / 信息来源 URL」。
约束：每个价格必须附页面 URL 与读取时间；找不到的单元格写「未披露」，不要猜测。
```

关键约束：

- **只读公开内容**：明确「不登录、不提交表单、不下载文件」；
- **要求出处**：价格、功能、额度都要附 URL 与读取时间；
- **允许「未披露」**：避免模型用常识补全不存在的价格；
- **限定页面范围**：给出具体域名或页面，避免漫游式抓取。

## 4. Quick Bar：全局快捷入口

Quick Bar 是看山工作台的全局快捷入口：在其他应用中选中内容后，可以快速唤起处理（F-021）。

### 4.1 快捷键

| 系统 | 默认快捷键 | 依据 |
|---|---|---|
| macOS | ⌘K | F-022 |
| Windows | Ctrl + K | F-022 |

如果与其他应用冲突，可以在「设置」中修改（F-066）。

### 4.2 七类常见操作

官方列出的 Quick Bar 操作包括（F-023）：

1. 翻译；
2. 总结；
3. 改写与润色；
4. 提取要点和行动项；
5. 分析观点；
6. 生成回复；
7. 转换格式。

### 4.3 使用步骤

官方给的步骤是：先在当前应用中选中文本、表格或单元格，再唤起 Quick Bar（F-077）。示例包括「翻译成中文」「总结成三点」「提取行动项和责任人」「分析这些单元格中的异常值」（F-078）。

一个实用细节：**选中什么，决定 Quick Bar 能处理什么**。选中一段文字得到文本处理；选中表格单元格得到表格分析；如果只唤起而不选中内容，Quick Bar 只能处理剪贴板或手动输入的内容。

### 4.4 能力限制

Quick Bar 的读取能力可能受操作系统、当前应用和用户授权范围影响（F-024、F-106）。实践中的表现包括：

- 某些应用不允许第三方工具读取选中内容；
- 某些系统对辅助功能/屏幕读取有额外权限要求；
- 跨应用选中内容时，格式可能丢失（如表格变成纯文本）。

**建议**：第一次在某个应用中使用 Quick Bar 时，先用一段不敏感的文字试跑，确认能正确读取选中内容，再处理正式材料。

## 5. 浏览器 + Quick Bar 的组合用法

两者可以串成一条轻量工作流：

1. 在浏览器中看到一段有用内容，选中后用 Quick Bar 总结成三点（F-078）；
2. 把总结结果复制到本地笔记；
3. 如果需要对多个网页做系统对比，再改用浏览器工具发起结构化任务（F-018）；
4. 最后用本地文件能力把结果整理成 Excel 或 Markdown（F-073）。

这条链路的好处是：**轻量任务用 Quick Bar，结构化任务用浏览器工具，落盘用本地文件能力**，不必每次都启动完整任务。

## 6. 一页检查表

- [ ] 浏览器工具插件已安装并启用（F-017）。
- [ ] 任务只读公开页面，明确「不登录、不提交表单、不下载文件」（F-018）。
- [ ] 需要登录时，优先用可见窗口手动登录，或确认真实浏览器连接器的边界（F-020、F-117）。
- [ ] 网页结果要求附 URL 与读取时间，找不到就写「未披露」（F-018）。
- [ ] Quick Bar 快捷键已确认，冲突时在设置中修改（F-022、F-066）。
- [ ] 首次在某个应用使用 Quick Bar，先用非敏感内容试跑（F-024、F-106）。
