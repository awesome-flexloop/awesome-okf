# 看山工作台是什么：从对话窗口进入真实工作环境

## 一句话定位

看山工作台是知乎推出的 **AI 桌面工作平台**（F-001）。它不只回答问题，而是进入用户日常使用的电脑环境，在明确授权范围内处理本地文件、辅助操作浏览器、连接企业协作工具、执行周期性任务，并可在指定项目目录中协助代码阅读、修改和测试（F-002、F-003、F-005、F-006）。

> **采集时点**：2026-10-23。页面未标注发布日期与版本号（F-112），下文所有「当前」口径只对采集时点成立。

## 它想改变什么：三个转变

官方用三组对比描述产品价值（F-007~F-009）：

| 转变 | 旧方式 | 看山工作台的方式 |
|---|---|---|
| 搬运材料 → 直接处理 | 整理材料、上传、提问、等待、下载、搬回原环境（F-004） | 授权后直接读取本地文件与当前内容，减少上传、下载、复制、粘贴（F-007） |
| 回答问题 → 交付结果 | 只给建议 | 读取文件、分析数据、整理网页、生成文档，写回 Excel 或保存到指定位置（F-008） |
| 一次性使用 → 持续执行 | 每次重新交代背景 | 借本地记忆、定时任务、企业协作连接与 Skills 参与日报、周报、经营分析、资料整理与知识沉淀（F-009） |

这三组对比对应的是一套**执行链路**：授权本地目录 → 读取材料 → 调用云端模型规划/推理 → 本地 Agent 执行文件或浏览器操作 → 把结果写回原位置或导出。理解这条链路，比记住功能清单更重要。

## 云端能力与本地 Agent 如何分工

官方把架构描述为「云端能力 + 本地 Agent 协同」（F-048）：

| 层 | 职责 | 依据 |
|---|---|---|
| 云端能力 | 模型推理、复杂任务规划、多模态理解、内容生成 | F-049 |
| 本地 Agent | 连接电脑环境，执行本地文件访问、系统工具调用、浏览器辅助操作、本地任务 | F-050 |

**关键承诺**：本地文件不会上传到云端，只在用户授权的本地范围内读取和处理（F-016、F-051、F-102、F-109）。

> ⚠️ **口径边界**：原文同时说云端负责「模型推理、多模态理解」，但没有说明本地文件内容以何种形式参与云端推理——是文件本体、提取文本、表格单元格还是图片特征（F-116）。因此可以引用「文件不会上传」的字面承诺，但不应扩写为「任何数据都不离开本机」。涉及敏感文件时，建议先用脱敏副本试跑。

## 四类硬边界（先看再动手）

| 边界 | 官方口径 | 依据 |
|---|---|---|
| 操作系统 | 支持 macOS 与 Windows；目前不支持 Linux | F-059、F-103 |
| 部署方式 | 目前不支持企业私有化部署 | F-060、F-105 |
| 定时任务并发 | 当前最多 3 个并发任务；上限可按产品版本与企业配置调整 | F-046、F-089、F-118 |
| 文件恢复 | 没有内建文件历史面板，不提供操作级回滚或自动快照 | F-093、F-098、F-107 |

这四条边界决定了适用场景：**个人或小团队在 Mac/Windows 桌面上处理本地材料**是主场；**需要 Linux、私有化部署、强审计回滚的生产环境**目前不合适。

## 六项核心功能一览

| 功能 | 一句话说明 | 展开阅读 |
|---|---|---|
| 本地文件直接处理 | 授权目录内读取 Excel、CSV、PDF、Word、PPT、Markdown 等，支持 Excel 读改写回与多文件综合处理（F-010~F-014） | [01 · 本地文件与 Excel](01-local-files-and-excel.md) |
| 一句话操作浏览器 | 安装插件后用自然语言发起网页任务；默认独立环境，不继承 Cookie（F-017~F-020） | [02 · 浏览器与 Quick Bar](02-browser-and-quickbar.md) |
| Quick Bar 全局唤起 | macOS ⌘K / Windows Ctrl+K，对选中内容翻译、总结、改写、提取行动项等（F-021~F-024） | [02 · 浏览器与 Quick Bar](02-browser-and-quickbar.md) |
| 企业协作工具连接 | 飞书 lark-cli、企业微信 wecom-cli、钉钉 dws 三条接入路径（F-025~F-040） | [03 · 企业协作工具](03-enterprise-collaboration.md) |
| 本地记忆 | 记住职业背景、术语、指标、输出偏好，可从其他平台导入（F-041~F-044） | [04 · 本地记忆与定时任务](04-memory-and-scheduled-tasks.md) |
| 周期性定时任务 | 每天/每周/工作日/Cron 周期执行，最多 3 个并发（F-045~F-047、F-084~F-089） | [04 · 本地记忆与定时任务](04-memory-and-scheduled-tasks.md) |

另有一项跨功能能力：**Coding 任务**——在授权项目目录中读改代码、跑测试、装 Node.js 依赖、启动本地开发服务、用 Git 查历史（F-090~F-092），详见 [05 · Coding 任务与文件恢复](05-coding-and-file-recovery.md)。

## 适合与不适合

| 适合 | 不适合 |
|---|---|
| 每天在 Mac/Windows 上处理 Excel、PDF、Word 等本地材料的知识工作者 | 必须使用 Linux 桌面的团队（F-059） |
| 需要把「读文件—分析—写回/导出」串成一条链的个人或小团队 | 要求企业私有化部署、数据必须留在内网的组织（F-060） |
| 希望用 Quick Bar 在任意应用中快速翻译、总结、提取要点的人 | 需要操作级回滚、自动快照、强审计的生产变更场景（F-093、F-098） |
| 需要把飞书/企业微信/钉钉的文档与消息纳入日常流程的团队 | 期待完全离线、本地模型推理的用户（原文为云端+本地协同，F-048、F-049） |
| 想在授权项目目录里让 AI 帮忙读代码、跑测试的开发者 | 需要把本地开发服务长期作为公开服务托管的场景（F-091） |
