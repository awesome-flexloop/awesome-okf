# 安装与首次转发：官方三步上手

> ⚠️ **操作来源声明**：源文没有任何安装步骤（F-039），本篇**全部**来自官方 README「三步上手 / 下载安装 / 隐私设计」
> 章节（F-077、F-078、F-079、F-082、F-092），是**官方文档化流程的整理**，
> **不是源文作者实测，也不是本知识包在 macOS 上的实机验证**。
> 实际执行请以官方 [使用指南 `USAGE.zh-CN.md`](https://github.com/freestylefly/WeChatBridge/blob/main/USAGE.zh-CN.md) 为准（F-101）。
> 本篇适用平台为 **macOS**；Windows / iOS 状态见 [concepts/05 §3](../concepts/05-boundaries-selection-and-patterns.md)。

## 0. 前置检查

| 检查项 | 要求 | F 编号 |
|--------|------|--------|
| 操作系统 | macOS 14 及以上（官方下载表列 Apple Silicon 与 Intel 均可） | F-052、F-078 |
| 微信版本 | macOS 微信 **4.1.13 或更高版本** | F-053、F-077 |
| 目标应用 | 若目标是 AI Agent，该 Agent 本身要装好并完成授权 | F-055 |
| 预期行为 | 只处理你**主动选中并合并转发**的聊天，不做全量自动归档 | F-054 |

> 微信 4.1.13 是关键前提：官方说明「macOS 微信 4.1.13 起，多选聊天记录后可以『合并转发』给第三方应用」
> 并生成含 TXT、图片、视频的 ZIP（F-013、F-081）。低于该版本，本流程无输入。

## 1. 第一步：安装

官方「下载安装」表（F-078、F-079）：

| 平台 | 安装方式 | F 编号 |
|------|---------|--------|
| macOS 14+ | 打开 DMG，把「微信流」拖入「应用程序」 | F-079 |
| Windows | 解压后按目录内说明运行 | F-079 |

- 安装包经蓝奏云发布，提取密码为「`向明`」（F-078）；页面有「免费下载 macOS | Windows」徽章（F-078）。
- 官方标注「免费下载」，许可证为 MIT（F-066）。
- 源文另称「已签名公证、装好即用」（F-015）——**「已签名公证」未在官方 README 得到逐字确认**（F-103），
  本篇不作为安装前提断言；若遇系统拦截，请查官方使用指南而非引用源文。

## 2. 第二步：打开入口

官方逐字路径（F-077、F-092）：

1. 打开「**微信流 → 设置 → 入口**」，勾选要用的目标，例如「发给 Codex」「沉淀到 Obsidian」。
2. 也可前往「**系统设置 → 通用 → 登录项与扩展 → 共享**」管理这些分享入口。

> 机制说明：系统「转发到其他应用」列表只显示带 Share Extension 的应用（F-080），
> 微信流把十二个 Share Extension 组装进 `.app`（F-096）。入口开关实际上是在启用这些扩展。
> 十二个内置入口清单见 [concepts/02](../concepts/02-entry-matrix.md)。

**权限准备**（官方隐私设计六条中的两条，逐字，F-083、F-084）：

- 屏幕录制权限：「只用于识别微信标题栏中的聊天名，图像仅在内存中处理」。
- 辅助功能权限：「只用于激活目标应用和执行粘贴」。

首次使用时按系统提示授予；若本地构建用了 ad-hoc 签名，macOS 可能要求重新授予辅助功能权限（F-093）。

## 3. 第三步：转发

官方路径（F-077）：

```text
微信里多选聊天记录
  → 「合并转发」
  → 「转发到其他应用」
  → 选择微信流的入口
```

官方演示图的说明为「多选群聊 → 转发到其他应用 → 选『发给 Codex』和场景 → Agent 收到聊天记录并开始总结」（F-065 相关演示）。
若选的是「沉淀到 Obsidian」，官方行为是「创建 Markdown 笔记并保存原始附件，通知可打开笔记」（F-070）。

### 首次转发的四个检查点

| # | 检查点 | 期望 | F 编号 |
|---|--------|------|--------|
| 1 | 转发菜单里能看到微信流入口 | 已启用的入口出现在「转发到其他应用」列表 | F-077、F-080 |
| 2 | 选了 Agent 入口 | 目标应用被激活、场景指令带上、聊天归档被粘贴 | F-019、F-069、F-087 |
| 3 | 选了沉淀入口 | 生成 Markdown，原始附件/原始 ZIP 保留，按聊天名组织 | F-020、F-070、F-075 |
| 4 | 目标未装或权限不足 | 文件仍保留在**剪贴板**，可手动粘贴（失败兜底） | F-035、F-075 |

> 若第 4 项发生，不要重复转发：先到剪贴板取回文件，再补齐目标应用或权限后，
> 用记录页的「重新发送」（F-036、F-075）或「复制到剪贴板」入口（F-073）处理。

## 4. 超过 100 条时

官方：「微信一次最多转发 100 条，用『分批收集到微信流』分几批选，收齐后一次发出去」（F-085）。
此时第三步改为多轮「分批收集」，流程见 [examples/02](02-scenes-skills-and-batch-workflow.md) 与
[concepts/04](../concepts/04-batch-collection-and-records.md)。
