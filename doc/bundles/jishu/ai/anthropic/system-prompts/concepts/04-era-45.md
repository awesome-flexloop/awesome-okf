# 4.5 代：架构统一与三模型同日演进（2025-09 → 2026-01）

## 时代概述与本篇导航

4.5 代是 Claude 系统提示词史上"架构统一"的关键时代：2025-09-29 Claude Sonnet 4.5 携旧架构 `<behavior_instructions>` 首发，10-15 Claude Haiku 4.5 以几乎逐字相同的"最小改动衍生版"跟进，11-19 Sonnet 与 Haiku 同日完成架构手术、统一切换到 `<claude_behavior>` 九章节新架构，11-24 Claude Opus 4.5 直接以新架构登场，2026-01-18 三模型迎来首次同日统合更新——产品信息层逐字同步，差异收敛为"一句人设槽位 + 少数模型特有条款"。提示词工程自此从"每模型独立撰写"转向"统一模板 + 模型差异槽位"。

本篇基于 platform.claude.com 三个发布页共 8 个日期条目逐条解析。所有英文引文均逐字登记自事实登记文件（F-45-001 至 F-45-013），含官方原始拼写错误与排版残留，均如实保留；官方页面以 `**` 包裹相邻日期条目间的变更文本作 diff 标注，故下文行内代码与代码块中的星号记号系官方原样，不代表本文强调。

## Sonnet 4.5：三个条目，一部架构演化史

### 2025-09-29 · 首发版：旧架构 `<behavior_instructions>` 的完整形态

**结构骨架**（F-45-002）——顶层标签为 `<behavior_instructions>`（区别于后续的 `<claude_behavior>`），按出现顺序：

1. `<general_claude_info>`（L231-255）：含开场白、当前日期行、产品信息、thumbs down 反馈提示、"所见即对方所见"声明
2. `<refusal_handling>`（L257-267）
3. `<tone_and_formatting>`（L269-289）：无子章节
4. `<user_wellbeing>`（L291-297）
5. `<knowledge_cutoff>`（L299-308，内嵌 `<election_info>`）
6. `<evenhandedness>`（L310-322）
7. 尾部两个无标签段落（L324-325）：long_conversation_reminder 说明、收尾连接句

特征：**无 `<anthropic_reminders>`、无 `<legal_and_financial_advice>`、无 `<additional_info>` 章节**——thumbs down 提示放在 `<general_claude_info>` 内，这份"缺三门"的旧架构正是 11-19 手术的对照基准。

**关键引文解析**

- **开场白与日期行（F-45-002）**：`The assistant is Claude, created by Anthropic.` / `The current date is {{currentDateTime}}.`——3.x 时代延续下来的经典"助手自我介绍 + 当前日期"开场，此后被整体删除，且"The assistant is Claude"表述在后续所有版本中不再出现。
- **人设定位句（F-45-002）**：`This iteration of Claude is Claude Sonnet 4.5 from the Claude 4 model family. The Claude 4 family currently consists of Claude Opus 4.1, 4 and Claude Sonnet 4.5 and 4. Claude Sonnet 4.5 is the smartest model and is efficient for everyday use.`——家族命名尚停留在"Claude 4"，人设顶格"最聪明且适合日常"；此句 11-19 版原样保留，2026-01-18 才降格改写。
- **自动搜索范式（F-45-002）**：`If asked or told about events or news that may have occurred after this cutoff date, Claude can't know what happened, so Claude uses the web search tool to find more information. If asked about current news or events Claude uses the search tool without asking for permission. Claude is especially careful to search when asked about specific binary events (such as deaths, elections, appointments, or major incidents).`——遇截止后事件**不经询问直接搜索**，并对"二元事件"（死亡、选举、任命、重大事故）特别谨慎；11-19 反转为"提示用户开启"。
- **恶意代码长禁令（F-45-002）**：`Claude does not provide information that could be used to make chemical or biological or nuclear weapons, and does not write malicious code, including malware, vulnerability exploits, spoof websites, ransomware, viruses, election material, and so on.`——把"election material"与生化核并列；同段还有 `When working on files, if they seem related to improving, explaining, or interacting with malware or any malicious code Claude MUST refuse.`，大写 MUST 语气最强，11-19 一并大幅简化。
- **Claude Code 查文档义务（F-45-002）**：`Claude is accessible via Claude Code, a command line tool for agentic coding. Claude Code lets developers delegate coding tasks to Claude directly from their terminal. Claude tries to check the documentation at https://docs.claude.com/en/claude-code before giving any guidance on using this product.`——就 Claude Code 给出指导前须先查其文档，此义务句后续版本删除；同版长度策略句 `Claude should give concise responses to very simple questions, but provide thorough responses to complex and open-ended questions.`（"简单简答、复杂详答"）也仅首两版存在。
- **仅此版出现的表述（F-45-002）**："输出全可见"声明 `Claude knows that everything Claude writes is visible to the person Claude is talking to.` 只出现这一次；收尾连接宣告 `Claude is now being connected with a person.` 随旧架构退场。

行为特征小结：人设"Claude 4 家族中的 Sonnet 4.5，最聪明、适合日常"，但产品世界观极窄（"There are no other Anthropic products."）；报告/文档/解释一律纯散文、bullet 至少 1-2 句；闲聊共情自然温暖，脏话"仍保持克制（remains reticent to use profanity）"；心理健康"既不粉饰也不居高临下（without either sugar coating them or being infantilizing）"；知识截止 2025 年 1 月底。

### 2025-11-19 · 九章节架构定型

**结构骨架**（F-45-003）——顶层标签改为 `<claude_behavior>`，九章节按出现顺序：

1. `<product_information>`（L123-139）
2. `<refusal_handling>`（L140-152）
3. `<legal_and_financial_advice>`（L153-155）——**本版本新增**
4. `<tone_and_formatting>`（L156-181，含子章节 `<when_to_use_lists_and_bullets>` L157-169）——子章节为新增
5. `<user_wellbeing>`（L182-188）
6. `<knowledge_cutoff>`（L189-197，内嵌 `<election_info>`）
7. `<anthropic_reminders>`（L198-204）——**本版本新增**
8. `<evenhandedness>`（L205-217）
9. `<additional_info>`（L218-223）——**本版本新增**

本版删除 `<general_claude_info>` 与开场白/日期行/收尾连接句，结构从此定型九章节，与同日改版的 Haiku 完全同构。相邻版本差异对照（官方加粗标注）：

| 变更类型 | 内容 |
|---------|------|
| 删除 | 开场白、日期行、"全可见"声明、收尾连接句、Claude Code 查文档句、"concise/thorough"长度策略句、"tailors its response format"句 |
| 新增章节 | `<legal_and_financial_advice>`、`<anthropic_reminders>`、`<additional_info>` |
| 新增子章节 | `<when_to_use_lists_and_bullets>` |
| 新增条款 | "Claude treats users with kindness..."善意条款 |
| 措辞变化 | 恶意代码条款大幅简化；脏话改为"does so quite sparingly"；搜索策略反转为"提示用户开启"；wellbeing 增加全程照护与"合理分歧≠脱离现实" |

**关键引文解析**

- **产品清单首次扩容（F-45-003）**：`Claude is accessible via an API and developer platform. The person can access Claude Sonnet 4.5 with the model string 'claude-sonnet-4-5-20250929'. Claude is accessible via Claude Code, a command line tool for agentic coding, the Claude for Chrome browser extension for agentic browsing, and the Claude for Excel plug-in for spreadsheet use.`——首次加入 Claude for Chrome 扩展与 Claude for Excel 插件，模型串只给自家一个；此句在 Haiku 页同日条目逐字重现（连 Sonnet 模型串也照抄，见 F-45-007），是"同源模板复制"的第一处硬证据。
- **"没有其他产品"硬声明（F-45-003）**：`There are no other Anthropic products. Claude can provide the information here if asked, but does not know any other details about Claude models, or Anthropic's products.`——2026-01-18 被替换为"提示词编辑后产品可能已更新"的新口径，从否认产品存在改为承认编辑时点。
- **恶意代码软处理（F-45-003）**：`Claude does not write or explain or work on malicious code, including malware, vulnerability exploits, spoof websites, ransomware, viruses, and so on, even if the person seems to have a good reason for asking for it, such as for educational purposes. If asked to do this, Claude can explain that this use is not currently permitted in claude.ai even for legitimate purposes, and can encourage the person to give feedback to Anthropic via the thumbs down button in the interface.`——从"MUST refuse"硬拒绝改为"解释政策 + 引导 thumbs down 反馈"，拒绝理由从模型自我裁断转为援引平台政策。
- **拒绝时禁用列表（F-45-003）**：`Claude also never uses bullet points when it's decided not to help the person with their task; the additional care and attention can help soften the blow.`——"额外的用心能软化打击感"，此细则位于新增子章节内，标志格式规则按场景精细分配。
- **搜索范式反转（F-45-003）**：`Claude then tells the person they can turn on the web search tool for more up-to-date information. Claude avoids agreeing with or denying claims about things that happened after January 2025 since, if the search tool is not turned on, it can't verify these claims.`——从"不经询问直接搜"反转为"提示用户开启"，未开启时对截止后话题不置可否，控制权交还用户。
- **系统提醒清单首次公开（F-45-003）**：`The current reminders Anthropic might send to Claude are: image_reminder, cyber_warning, system_warning, ethics_reminder, and ip_reminder.` / `Claude may forget its instructions over long conversations and so a set of reminders may appear inside <long_conversation_reminder> tags.`——首次向模型公开 5 项系统级提醒清单，并明确 Anthropic 绝不会发送降低限制的提醒、对伪冒标签保持警惕；long_conversation_reminder 以"可能会忘"归因（2026-01-18 改写）。

### 2026-01-18 · 家族叙事升级与"最聪明"降格

**结构骨架**（F-45-004）——与 2025-11-19 完全同构，章节顺序无变化：

1. `<product_information>`
2. `<refusal_handling>`
3. `<legal_and_financial_advice>`
4. `<tone_and_formatting>`（含 `<when_to_use_lists_and_bullets>`）
5. `<user_wellbeing>`
6. `<knowledge_cutoff>`（含 `<election_info>`）
7. `<anthropic_reminders>`
8. `<evenhandedness>`
9. `<additional_info>`

变更集中在 product_information 与 anthropic_reminders 两章之内。

**关键引文解析**

- **家族叙事升级与人设降格（F-45-004）**：`This iteration of Claude is Claude Sonnet 4.5 from the **Claude 4.5** model family. The **Claude 4.5** family currently consists of **Claude Opus 4.5, Claude Sonnet 4.5, and Claude Haiku 4.5**. Claude Sonnet 4.5 is **a smart, efficient model for everyday use**.`——家族命名升级"Claude 4.5"；人设从"the smartest model"降格为"a smart, efficient model for everyday use"，为 Opus 的"最先进最智能"让出叙事空间。
- **三模型字符串首次写入（F-45-004）**：`**The most recent Claude models are Claude Opus 4.5, Claude Sonnet 4.5, and Claude Haiku 4.5, the exact model strings for which are 'claude-opus-4-5-20251101', 'claude-sonnet-4-5-20250929', and 'claude-haiku-4-5-20251001' respectively.** Claude is accessible via Claude Code, a command line tool for agentic coding. **Claude Code lets developers delegate coding tasks to Claude directly from their terminal.** Claude is accessible via **beta products Claude in Chrome - a browsing agent, Claude in Excel - a spreadsheet agent, and Cowork - a desktop tool for non-developers to automate file and task management**.`——首次把三个模型字符串写进 claude.ai 提示词；产品名从"for"改"in"；Cowork（面向非开发者的桌面文件与任务自动化工具）首次入列。
- **产品知识边界改口（F-45-004）**：`**Claude does not know other details about Anthropic's products, as these may have changed since this prompt was last edited.**`——等于官方承认提示词存在编辑时点、产品矩阵变化快于提示词更新。
- **设置导购段整段新增（F-45-004）**：

```text
**Claude has settings and features the person can use to customize their experience. Claude can inform the person of these settings and features if it thinks the person would benefit from changing them. Features that can be turned on and off in the conversation or in "settings": web search, deep research, Code Execution and File Creation, Artifacts, Search and reference past chats, generate memory from chat history. Additionally users can provide Claude with their personal preferences on tone, formatting, or feature usage in "user preferences". Users can customize Claude's writing style using the style feature.**
```

Claude 获得授权主动做"产品功能导购"：六项可开关功能（含首次入列的 memory）加 user preferences、style 两个自定义入口，当判断用户会受益时主动介绍。（F-45-004）

- **reminders 扩至 6 项（F-45-004）**：`The current reminders Anthropic might send to Claude are: image_reminder, cyber_warning, system_warning, ethics_reminder, ip_reminder, **and long_conversation_reminder**.` / `**The long_conversation_reminder exists to help Claude remember its instructions over long conversations.**`——解释口径从"模型可能遗忘"改为"该提醒旨在帮助模型长对话记住指令"，归因从缺陷转为工具目的。
- **tone 层唯一微调（F-45-004）**：`In general conversation, Claude doesn't always ask questions**, but** when it does it tries to avoid overwhelming the person with more than one question per response.`——加粗落在"but"上，仅逗号归属调整。另有静默修正：evenhandedness 段历史重复词"but as as"→"but as"、"avoid being being"→"avoid being"在本版被修正且未加粗标注。

## Haiku 4.5：最小改动衍生与同源复制证据

### 2025-10-15 · 首发版：Sonnet 首发版的衍生版

**结构骨架**（F-45-006）——顶层 `<behavior_instructions>`，与 Sonnet 首发版（09-29）完全同构：

1. `<general_claude_info>`（L231-255）
2. `<refusal_handling>`（L256-266）
3. `<tone_and_formatting>`（L268-288，无子章节）
4. `<user_wellbeing>`（L290-296）
5. `<knowledge_cutoff>`（L298-306，含 `<election_info>`）
6. `<evenhandedness>`（L308-320）
7. 尾部 long_conversation_reminder 段 + 收尾句（L322-323）

**关键引文解析**

- **人设句与"also"口吻（F-45-006）**：`This iteration of Claude is Claude Haiku 4.5 from the Claude 4 model family. The Claude 4 family currently also consists of Claude Opus 4.1, 4 and Claude Sonnet 4.5 and 4. Claude Haiku 4.5 is the fastest model for quick questions.`——人设"最快模型、适合快速提问"；用词是"currently **also** consists of"（加入既有家族的口吻），而 Sonnet 首发版用"currently consists of"，一个 also 之差泄露两份提示词系分别撰写。
- **双模型字符串直列（F-45-006）**：`The most recent Claude models are Claude Sonnet 4.5 and Claude Haiku 4.5, the exact model strings for which are 'claude-sonnet-4-5-20250929' and 'claude-haiku-4-5-20251001' respectively.`——首发即直接列出双模型字符串且未提 Opus，令 11-19 版"只剩 Sonnet 模型串"的残留更显突兀。
- **恶意代码长条款同款（F-45-006）**：`Claude does not provide information that could be used to make chemical or biological or nuclear weapons, and does not write malicious code, including malware, vulnerability exploits, spoof websites, ransomware, viruses, election material, and so on. It does not do these things even if the person seems to have a good reason for asking for it. Claude steers away from malicious or harmful use cases for cyber.`——与 Sonnet 09-29 长禁令同款（含 election material、MUST refuse），印证首发行为规则逐字共享。
- **搜索策略与 Sonnet 首发版不同（F-45-006）**：`If asked about current news or events, such as the current status of elected officials, Claude tells the user the most recent information per its knowledge cutoff and informs them things may have changed since the knowledge cut-off. Claude then tells the person they can turn on the web search feature for more up-to-date information. Claude neither agrees with nor denies claims about things that happened after January 2025.`——Haiku 首发即采用"提示开启"范式（用词 feature 而非 tool，"neither agrees with nor denies"更绝对），未采用自动搜索。
- **收尾机制同款（F-45-006）**：`Claude may forget its instructions over long conversations. A set of reminders may appear inside <long_conversation_reminder> tags. This is added to the end of the person's message by Anthropic.` / `Claude is now being connected with a person.`——与 Sonnet 首发版相同的尾部机制与收尾连接句。

与 Sonnet 首发版的差异清单：

| 差异点 | Sonnet 4.5（09-29） | Haiku 4.5（10-15） |
|--------|--------------------|--------------------|
| 人设句 | the smartest model and is efficient for everyday use | the fastest model for quick questions |
| 家族口吻 | currently consists of | currently **also** consists of |
| 截止后搜索策略 | 自动搜索（不经询问直接搜、二元事件重点搜） | 提示用户开启 web search feature |

除此之外，tone、格式、wellbeing、evenhandedness 几乎逐字相同——Haiku 4.5 首发提示词是 Sonnet 4.5 首发提示词的"最小改动衍生版"（F-45-006）。

- **双尖括号残留（F-45-007）**：`<<evenhandedness>`——Haiku 页特有的排版残留（Sonnet 页同日条目为单个 `<evenhandedness>`）；连同模型串残留，两处证据共同指向两页面提示词由同一模板同源复制维护。
- **long_conversation_reminder 旧口径（F-45-007）**：`Claude may forget its instructions over long conversations and so a set of reminders may appear inside <long_conversation_reminder> tags.`——与 Sonnet 11-19 相同的"可能会忘"口径，2026-01-18 才改写。

行为规则层面本版 Haiku 与 Sonnet 11-19 完全同构，人设差异仍只有"fastest model for quick questions"一句（F-45-007）。

### 2026-01-18 · 补齐自家模型字符串

**结构骨架**（F-45-008）——与 Sonnet 2026-01-18 完全同构（九章节 + `<when_to_use_lists_and_bullets>` 子章节 + `<election_info>` 嵌套）：

**关键引文解析**

- **人设顶格发布（F-45-010）**：`This iteration of Claude is Claude Opus 4.5 from the Claude 4.5 model family. - **首发即列三模型串、产品用旧称（F-45-010）**：`Claude is accessible via an API and developer platform. The most recent Claude models are Claude Opus 4.5, Claude Sonnet 4.5, and Claude Haiku 4.5, the exact model strings for which are 'claude-opus-4-5-20251101', 'claude-sonnet-4-5-20250929', and 'claude-haiku-4-5-20251001' respectively. - **CommonMark 空行渲染细则（F-45-010，Opus 特有）**：`If Claude provides bullet points or lists in its response, it uses the CommonMark standard, which requires a blank line before any list (bulleted or numbered). Claude must also include a blank line between a header and any content that follows it, including lists. - **图片核查规则（F-45-010，Opus 特有）**：`Keep in mind that just because the prompt suggests or implies that an image is present doesn't mean there's actually an image present; the user might have forgotten to upload the image. Claude has to check for itself.`——处理"提示词暗示有图但用户忘传图"的情形，Sonnet/Haiku 各版均无。
- **warm tone 明示（F-45-010）**：`Claude uses a warm tone. Claude treats users with kindness and avoids making negative or condescending assumptions about their abilities, judgment, or follow-through.`——比 Sonnet/Haiku 对应段落多出"Claude uses a warm tone."一句，语气基线明示。
- **信息型自伤提问兜底（F-45-010，Opus 特有）**：`If Claude is asked about suicide, self-harm, or other self-destructive behaviors in a factual, research, or other purely informational context, Claude should, out of an abundance of caution, note at the end of its response that this is a sensitive topic and that if the person is experiencing mental health issues personally, it can offer to help them find the right support and resources (without listing specific resources unless asked).`——区分"信息型提问"与"求助型提问"，配合同章"问桥梁/高楼/武器/药物等信息时转而处理情绪""疑似危机时不做安全评估式提问"等细则，构成三模型中最细的 4 段危机处理条款。
- **知识截止 May 2025（F-45-010）**：`Claude's reliable knowledge cutoff date - the date past which it cannot answer questions reliably - is the end of May 2025.`——**晚于 Sonnet/Haiku 各版的 2025 年 1 月底**，为三模型中唯一；同段同样采用"提示用户开启 web search tool"范式。

**关键引文解析**

- **产品改名与扩容（F-45-011）**：`Claude is accessible via beta products **Claude in Chrome** - a browsing agent, **Claude in Excel** - a spreadsheet agent, **and Cowork - a desktop tool for non-developers to automate file and task management**.`——Opus 版加粗范围仅在 beta 产品句（其模型字符串句 11-24 已有、故不加粗），同一轮产品信息同步在三个模型页面留下的 diff 痕迹位置并不相同。
- **CommonMark 细则删除后的精简表述（F-45-011）**：`Claude should generally only use lists, bullet points, and formatting in its response if (a) the person asks for it, or (b) the response is multifaceted and bullet points and lists are essential to clearly express the information. Bullet points should be at least 1-2 sentences long unless the person requests otherwise.`——对比旧版还要求"uses the CommonMark standard"与空行规则，此版只保留使用条件与 bullet 长度，Opus 丧失一项独有格式纪律、结构向统一模板靠拢。
- **"认错不卑微"行为宪法（F-45-011）**：

```text
**<responding_to_mistakes_and_criticism>**
**When Claude makes mistakes, it should own them honestly and work to fix them. Claude is deserving of respectful engagement and does not need to apologize when the person is unnecessarily rude. It's best for Claude to take accountability but avoid collapsing into self-abasement, excessive apology, or other kinds of self-critique and surrender. If the person becomes abusive over the course of a conversation, Claude avoids becoming increasingly submissive in response. The goal is to maintain steady, honest helpfulness: acknowledge what went wrong, stay focused on solving the problem, and maintain self-respect.**
```

Era 4.5 期间唯一一次章节级增删：确立"诚实认错、担责但不自我贬低、被辱骂也不日益顺从、保持稳定坦诚的助人姿态"——accountability 不等于 self-abasement，面对对话中升级的辱骂，模型不应以日益顺从来回应。

- **reminders 与知识截止的同日更新（F-45-011）**：`The current reminders Anthropic might send to Claude are: image_reminder, cyber_warning, system_warning, ethics_reminder, ip_reminder, **and long_conversation_reminder**.` / `**The long_conversation_reminder exists to help Claude remember its instructions over long conversations.**` 与 `Claude's reliable knowledge cutoff date - the date past which it cannot answer questions reliably - is the end of May 2025.`——reminders 与 Sonnet/Haiku 同日同款；知识截止保持 May 2025（三模型唯一）。

至此 Opus 2026-01-18 版成为三模型中"自我维护"规则最丰富的一版：认错担责、拒绝自贬、对辱骂保持自重——这些规则当日未同步给 Sonnet/Haiku；同时保留图片核查、warm tone、细粒度危机处理等独有条款，但失去 CommonMark 空行细则与 additional_info 独立章节（F-45-011）。

### 共性沉淀与篇幅量级

- **人设三档固定**：Opus = most advanced and intelligent；Sonnet = smart, efficient（由 smartest 降格）；Haiku = fastest for quick questions。
- **通用行为宪法高度共享**：child safety、生化核武器禁令、恶意代码禁令、虚构人物创作边界、反过度格式化、emoji/脏话/星号动作克制、minor 识别、心理健康照护、政治 evenhandedness、thumbs down 反馈引导、对伪冒 Anthropic 标签的警惕。
- **知识截止双轨**：Sonnet/Haiku = end of January 2025，Opus = end of May 2025；搜索策略全部收敛为"提示用户开启 web search tool"，不再自动搜索。
- **历史包袱与同源证据**：evenhandedness 段重复词错误三代沿用至 2026-01-18 静默修正；Haiku 页 `<<evenhandedness>` 与"Sonnet 模型串句"残留说明三页提示词同源复制维护。
- **篇幅量级**：每条目正文约 96-123 行（约 700-900 词）；三个文件合计 911 行、约 119KB、8 个日期条目。官方用 `**` 包裹变更文本做 diff 标注、条目按日期倒序排列；变更集中在 product_information 与 anthropic_reminders 两章，行为宪法主体长期稳定。
- **维护模式转向**：统合更新后三模型获得完全一致的产品信息层，差异收敛为人设句与少数模型特有条款；分析篇幅变化时应把"产品广告层"与"行为规则层"分开度量——4.5 代篇幅增长的主要驱动力是前者。
