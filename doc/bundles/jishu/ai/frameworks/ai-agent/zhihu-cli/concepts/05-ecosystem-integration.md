# 05 生态集成与兼容性

> 对应事实：F-041、F-042、F-096~F-105、F-010、F-040
> 知识层级：应用层

## 一、Agent 平台支持

Zhihu CLI 支持多种主流 AI Agent 集成 [F-041]：

| Agent 平台 | Skill 接入 | MCP 接入 | 事实编号 |
|-----------|-----------|----------|----------|
| Codex Agent | ✅ | ✅ | [F-096] |
| Claude Code | ✅ | ✅ | [F-097] |
| Cursor | ✅ | ✅ | [F-098] |

每种 Agent 均支持 Skill 和 MCP 两种接入方式 [F-042] [F-099]。

> **勘误说明**：除了 Skill 和 MCP 两种 Agent 接入方式外，底层还有 API 直接调用方式，共计三种接入方式 [E-001]。

### Skill 接入方式 vs MCP 接入方式

| 维度 | Skill + CLI | 托管式 MCP |
|------|-------------|------------|
| 本地安装 | 需要安装 CLI 二进制 | 不需要，托管式服务 |
| 工作原理 | Agent 读取 Skill 文档 → 调用本地 CLI → CLI 调 API | Agent 通过 MCP 协议 → 知乎托管 MCP 服务 → 后端 API |
| 数据能力 | 完全一致 | 完全一致（共用后端接口）[F-102] |
| Access Secret | 需要配置 | 需要配置（共用同一套）[F-047] |
| 调试便利 | stderr 直接可见 | 依赖 MCP 宿主日志 |
| 适用场景 | 喜欢本地可控、需要调试 | 追求便捷、不想管理本地依赖 |

### 共用后端接口

三种接入方式（API、Skill+CLI、MCP）共用同一套后端接口和 Access Secret [F-055] [F-102]，这意味着：

- 数据能力完全一致
- 同一个 Access Secret 可用于不同接入方式
- 后端升级对所有接入方式同步生效

## 二、平台兼容性

### 操作系统支持

| 操作系统 | 支持状态 | 说明 | 事实编号 |
|----------|---------|------|----------|
| Linux | ✅ 支持 | 明确支持 | [F-010] |
| macOS | ✅ 支持 | Keychain 凭证存储 | [F-035] |
| Windows | ✅ 支持 | Credential Manager 凭证存储，注意 PowerShell 坑 | [F-035] [F-040] |

### Windows 平台注意事项

Windows 安装有一个已知的坑：**PowerShell 5.1 对 UTF-8 无 BOM 编码的 `.ps1` 文件会报解析错误** [F-040]。

**解决方案**：
1. 升级到 PowerShell 7+（推荐）
2. 确保安装脚本使用 UTF-8 with BOM 编码
3. 或通过直接下载二进制的方式安装

### macOS 平台特性

- Access Secret 存储在 macOS Keychain 中 [F-035]
- 系统级安全存储，无明文落盘

## 三、第三方生态

### 社区封装工具

社区有第三方封装的 zhihu-search 工具（作者 klarkxy） [F-034] [F-103]。

> **说明**：本知识包聚焦官方 Zhihu CLI，对社区第三方工具仅作简要提及，不深入对比。如需使用社区工具，请自行评估其安全性和可靠性。

### 办公工具集成

可与飞书等办公工具集成实现定时推送 [F-104]，典型场景：

- 定时推送知乎热榜到飞书群组
- AI 分析热榜话题后推送摘要
- 个人创作数据日报/周报推送

### 智能硬件场景

📝 **作者观点**：Zhihu CLI 可用于智能硬件看板等场景 [F-105]，例如：

- 3D 打印微屏显示热榜
- WorkBuddy 桌面伙伴集成
- 电子墨水屏信息看板

> 这属于探索性应用方向，社区已有讨论但尚未形成成熟方案。

## 四、生态发展现状

知乎数据开放平台截至 2026 年 9 月处于邀测阶段 [F-005]，生态仍在快速发展中：

- 官方 Skills 已提供 4 套（热榜、站内搜索、全网搜索、直答）[E-003]
- Zhihu CLI 作为统一入口工具，版本已迭代到 v0.5.0 [F-009]
- 支持主流 Agent 平台（Claude Code、Cursor、Codex）
- 社区开始出现创意玩法和第三方工具

⏰ **时效性提示**：产品处于快速迭代期，功能、接口、生态都可能快速变化，建议以官方最新公告为准。
