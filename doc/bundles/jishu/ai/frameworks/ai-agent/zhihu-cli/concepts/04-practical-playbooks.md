# 04 实战玩法与创意应用

> 对应事实：F-071~F-095
> 知识层级：应用层

社区观点认为，让 Agent 读取分析自己过去积累的知乎内容是最有价值的玩法之一 [F-077]。公共内容 + 个人数据结合的玩法具有独特价值 [F-084]。以下介绍五种经过社区验证的实战玩法。

## 一、玩法一：创作生涯全身体检

### 玩法描述

全量拉取个人创作数据，进行多维度分析，生成一份"创作体检报告" [F-071]。

### 数据来源

- 使用 `me contents` 命令全量拉取个人创作数据 [F-089]
- 支持分页拉取，可获取历史全部内容

### 分析维度

创作数据分析可从以下维度展开 [F-073] [F-085]：

| 分析维度 | 产出内容 | 价值 |
|----------|----------|------|
| 年产量分布 | 各年产量分布图 | 了解创作节奏变化 |
| 互动数据累计 | 历年赞同收藏累计图 | 观察影响力增长曲线 |
| 创作方向分布 | 创作方向分布图 | 识别擅长领域与盲区 |
| 高价值内容识别 | 赞同×收藏散点图 | 找出表现最好的内容 |

> 社区观点：赞同×收藏散点图可用于识别高价值内容——双高的内容是"代表作"，高赞同低收藏的可能是"争议性爆款"，低赞同高收藏的可能是"干货工具文" [F-086]。

### 案例：老狼的创作数据

关于老狼的知乎创作数据，存在两种口径 [P0-010]：

| 口径 | 数据 | 来源 | 可能的统计维度 |
|------|------|------|----------------|
| 口径 A | 9 年、430 篇文章 | S6 回答 | 创作年限 + 文章数 |
| 口径 B | 15 年、约 49 万字 | S4 回答3 | 注册年限 + 全内容字数 |

> 口径差异可能因统计维度不同（如"创作年限"vs"注册年限"、"文章数"vs"全内容字数"），非事实错误。无论哪种口径，都可以通过 CLI 全量拉取后自行统计分析 [F-072]。

## 二、玩法二：写作风格蒸馏成 Skill

### 玩法描述

把自己的全部知乎正文作为专属语料，让 AI 提炼出个人写作风格，蒸馏成一个专属写作 Skill [F-074]。

这种玩法被多位社区作者提到 [F-095]。

### 语料准备

- 使用 `me contents` 命令拉取全量创作内容 [F-089]
- 提取所有正文作为语料输入 [F-087]
- 语料越全，风格蒸馏越准确

### 风格提炼维度

风格蒸馏可从以下维度提炼个人写作特征 [F-075]：

| 维度 | 说明 |
|------|------|
| 论证结构 | 常用的论证框架和逻辑推进方式 |
| 段落长度 | 段落平均长度、长短段搭配节奏 |
| 术语密度 | 专业术语的使用频率和偏好 |
| 惯用类比 | 喜欢用的类比、比喻、举例方式 |
| 开头结尾方式 | 文章开篇和收尾的典型模式 |

### 产出

最终产出一个个人专属的写作 Skill，AI 可以用"你的风格"来生成内容，实现"风格分身"。

## 三、玩法三：选题雷达

### 玩法描述

让热榜替你盯梢，定时拉取热榜数据，与个人创作领域标签匹配，自动发现适合你的选题灵感 [F-076]。

### 实现要素

选题雷达玩法需要以下要素 [F-088]：

1. **定时任务**：定期执行 `hot`/`trending` 命令拉取热榜 [F-090]
2. **热榜数据**：知乎热榜的实时话题数据
3. **个人标签匹配**：将热榜话题与个人创作领域标签进行匹配

### 工作流程

```
定时触发 → 拉取热榜 → 话题分类 → 匹配个人领域 → 输出选题建议
```

### 价值

- 不用手动刷热榜，节省时间
- 精准发现与自己领域相关的热点
- 把握创作时机，提高内容时效性

## 四、玩法四：智能硬件看板集成

### 玩法描述

将知乎数据（热榜、个人数据等）展示在智能硬件看板上，实现"数据可视化 + 物理存在感" [F-082]。

### 典型形态

- **3D 打印微屏**：自制小型显示屏，实时展示热榜 Top10
- **WorkBuddy 等桌面伙伴**：桌面智能硬件集成知乎数据
- **电子墨水屏日历**：结合日程和知乎热榜提醒

> 📝 **作者观点**：智能硬件看板是一种被提到的创意应用方向 [F-082] [F-105]，属于较前沿的探索性玩法。

### 技术思路

1. CLI 拉取数据（JSON 格式）[F-022]
2. 后端脚本处理数据
3. 通过 WiFi/蓝牙发送到硬件设备
4. 设备屏幕展示

## 五、玩法五：飞书热榜推送

### 玩法描述

定时拉取知乎热榜，经过 AI 分析筛选后，推送到飞书等办公工具 [F-083] [F-104]。

### 实现方式

1. 定时任务调用 `hot`/`trending` 命令 [F-090]
2. AI 对热榜话题进行分类、摘要、价值评估
3. 通过飞书机器人 API 推送到指定群组或个人

### 增强版：AI 深度分析

不只是简单转发热榜，而是让 AI 对热榜话题进行深度分析：
- 话题背景梳理
- 多方观点汇总
- 与个人/团队关注领域的关联度评估
- 行动建议输出

## 六、更多创意方向

社区还提到了以下创意方向 [F-081]：

- **AI loop engineering**：将 CLI 数据融入 AI 的工作循环，打造自动化的内容生产流水线
- **竞品/话题监控**：监控特定话题或领域的知乎讨论热度
- **知识管理**：将收藏内容自动整理为结构化知识库
- **社交图谱**：基于关注关系分析社交网络

> 这些方向目前以社区观点和探索性实践为主，具体实现方式需要结合个人需求定制开发。
