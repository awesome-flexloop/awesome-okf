# 工具分工与安装前的边界

作者把一个照片文件夹交给豆包工作，要求使用 Remotion 制作摩托短片（F-007、F-013、F-014）。这个案例可以拆成三种工作：理解需求并安排任务、查阅视频制作知识、把设计渲染为文件。它们的负责人和验收方式不同。[事实登记](../references/article-source.md)

## 谁负责什么

| 角色 | 在本案例中的任务 | 能核验什么 | 不宜推定什么 |
| --- | --- | --- | --- |
| 用户 | 选择素材、说明用途、批准镜头与声音 | 素材权限、叙事是否准确、审美是否合意 | “随便做”能得到符合发布要求的作品 |
| 豆包工作 | 作者称它拆任务并操作本地环境 | 作者报告的进度与结果 F-009/F-016 | 任何版本都能无条件自动安装或质检 |
| Remotion Skill | 给编码 Agent 提供 Remotion 操作与制作知识 | 官方技能职责 F-023–F-025 | 安装 Skill 等于安装完全部运行依赖 |
| 编码 Agent | 官方流程中负责生成或改动项目代码 | 前置要求与预览步骤 F-026/F-027 | 不写代码的用户背后没有代码与环境 |
| Remotion | 以项目和 composition 渲染静帧或视频 | 官方 CLI F-028/F-030 | 能替用户自动裁决素材授权与故事真实性 |

`composition` 可以理解为项目里一条有独立标识的视频定义；渲染时用这个标识指定作品。Skill 是供 Agent 阅读和使用的知识，不是剪辑软件成片本身。官方 `remotion-markup` 描述 React 画面、动画、排版、声音和时序，`remotion-render` 负责调用渲染（F-025）。

## 官方技能目录的读法

2026-11-04 读取的页面标注更新于 2026-11-01（F-036）。其中 `remotion-best-practices` 是聚合技能，包含其他技能知识；另外 12 个专项标题分别负责创建、markup、Studio、渲染、地图、字幕、SaaS、交互、文档、许可、升级、多媒体（F-024/F-025）。

作者说配齐 12 个技能（F-011），不能据此保证任何安装都会得到这个集合。页面后来更新、聚合项与专项项的统计口径不同，安装工具也可能让用户选择范围。先查安装清单再谈数量，不用 GitHub Star 代替运行验收。作者的历史 Star 数 F-008 尚未取得对应时点证据。

## 安装是一项有副作用的操作

以下为已读官方文档的学习参考，**本次未执行，不是豆包安装成功记录**。

官方技能页给出（F-023）：

```bash
npx skills add remotion-dev/skills
```

官方 Coding Agents 页给出的新项目路径是（F-027）：

```bash
npx create-video --yes --blank my-video
cd my-video
npx remotion skills add
npm run dev
```

这两段对应不同入口，不要求读者顺序重复执行。已有项目先看当前目录和配置；新项目流程会创建文件并可能下载依赖，`npm run dev` 用于预览，不是成片导出。Node.js 与编码 Agent 是官方前置条件，具体受支持版本须查看执行时官方文档（F-026）。

作者的安装截图是一句自然语言请求（F-010），不是供终端粘贴的命令。实际使用时可先要求 Agent 报告项目路径、技能来源、准备运行的命令、已有依赖与下载预算，批准后再写入。建议限制它只读素材副本、只写指定输出目录；安装就绪至少需要看到项目可预览和指定静帧可生成，而不是只有“装好了”的回复。

## 本地执行与隐私

作者选择“本地电脑”（F-009），这说明案例的执行环境选择，不证明模型推理或所有素材处理均离线。产品是否读取照片、是否上传缩略图、日志保存多久，需查实际服务条款和权限提示，本次没有取得这些契约。

建议默认禁止向第三方上传照片、缩略图或含隐私的日志；本地读取目录的批准不含外传授权。必须外传时，先确认接收方、用途、数据范围与留存条件；任一不明则停止，不用“本地执行”代替这项核对。

建议先用不含人脸、车牌、住址和定位的素材副本学习。涉及车友、婚礼或客户照片时，征得授权，移除不必公开的信息；不要把整个桌面或云盘根目录交给 Agent。环境安装、读取私域素材和发布作品分别确认，避免一次模糊授权涵盖全部动作。

## 免费资格不等于总成本为零

已读 Remotion 条款允许个人、最多 3 名员工的营利组织、非营利组织及非商业评估符合免费资格；其他主体需公司许可（F-033）。它并非 MIT 或无条件免费许可，销售、出租、重新许可 Remotion 衍生软件另受限制（F-034）。

制作视频成品和出售基于 Remotion 的视频生成软件是不同用途。公司许可页还区分 Creators 与 Automators 场景，AI agents 和 Studio 出现在低量手工创作的说明中（F-035）；不能只看到“Agent”一词就自行判定许可类别。企业采用前应按主体和实际用途核对最新条款，本页不代替法律意见。

总投入还包括编码 Agent 订阅、渲染资源、人工审核与音乐授权。豆包 30 天体验及签到信息仅有部分证据（F-022），不据此安排长期预算。[核验台账](../references/verification.md)

建议分别约定下载量、总费用上限和重试次数；购买、订阅、许可开通或超预算不由一次安装批准自动涵盖。实际采用时保存条款版本、主体、用途和审批记录，`verified-doc` 不作为采购放行凭证。
