# 05 · 响应式协同效应：依赖是带类型的键

> 一句话：组件不从环境里「随手取」，而是声明一组带类型的键；系统在这些键上维护一张有限表，表一变就按依赖规范给受影响的组件分类通知。

## 1. 协同效应上下文

**Definition 19**（F-034）：`Σ ≔ (k : K) ⇀ 𝒱k`，是键到值的**有限偏函数**，类型族 `𝒱` 保证每个键有对应值类型。有限性不是装饰：`dom(σ)` 有限，所以后面的满足谓词可判定（F-036）。

**Definition 20**（F-035）是全篇最关键的一步：`set(k, v)` 的类型是 `𝔈*Σ`——**协同效应操作本身就是一次效应**，其逆为 `λσ'. σ' ∖ k`。也就是说「注册一个服务」与「注册一个定时器」走同一套带回程的机制，effect 与 coeffect 在这里开始合流。

**§3.2.2 / Definition 21**（F-036、F-037）：满足谓词 `σ ⊧ d ≔ ∀k ∈ d. k ∈ dom(σ)`；协同效应规范 `𝔇Σ ≔ Set(K)`，即组件的依赖就是一个键集。

## 2. 响应式：notify 三分类

**Definition 22**（F-037）定义 `notify_d(σ, σ')`，把一次上下文变化相对于依赖规范 `d` 分为：

| 分类 | 含义 | 后续动作 |
|---|---|---|
| `activating` | 依赖从「不满足」变为「满足」 | 组件可开始激活 |
| `deactivating` | 依赖从「满足」变为「不满足」 | 组件须停用 |
| `neutral` | 依赖满足性未变 | 不打扰 |

这解释了「响应式」三个字：生命周期不是由用户显式 load/unload 驱动的，而是由**依赖满足度的变化**驱动的。Cordis 侧的对应动作见 [理论符号 ↔ API 映射](../references/theory-api-mapping.md) 的 Algorithm 3。

**Definition 23**（F-038）给出两种 realization：

- **in-place**：原地修改上下文，产生非平凡逆；
- **derived**：派生一个新上下文，逆是恒等，回收时**整体丢弃派生上下文**。后者对应 Cordis 的子 `fiber.ctx`，是「隔离」能低成本实现的原因。

## 3. 隔离与拦截

**Definition 24–25**（F-039）：`Σ_iso ≔ (K ⇀ R) × ((r : R) ⇀ 𝒱r)`，把键解析拆成两层 `k → ρ(k) → σ(ρ(k))`。同一键在不同 realm 里可以指向不同值，插件之间因此不会抢同一个全局注册项。

**Definition 26–27**（F-040）：`Σ_inter ≔ ((k:K) → ℳk) × ((k:K) ⇀ (ℳk → 𝒱k))`。`get` 把组件声明与上下文元数据合并，且**合并右偏使上下文元数据优先**——宿主可以在不改动组件代码的前提下覆盖其声明值。工程上对应 `ctx[@@isolate]` / `ctx[@@intercept]` 三个符号槽（F-061）。

## 4. 交换性：谁承担义务

多个组件可能同时写同一张 `Σ`，于是必须回答「它们的效应能否交换」。

**Theorem 45**（F-043）：**不同键上的操作相互独立**。这是最让人安心的一条：只要键集不交，顺序无关。

**Definition 46**（F-043）：witnessed coeffect 要求**每个键携带交换性证明**，且义务落在**提供方**——提供值的人要说明「读/写这个键的操作是否满足交换性」，而不是让调用方猜。

**Theorem 47**（F-043）：当 provision 与 operation 的键集不交、且共享键上的操作可交换时，两个效应迭代器独立。

这里必须配一个反面清单（论文 §3.4.2）：**有序中间件链**、**要求返回最低可用描述符的 `open`** 都不满足交换性。把这类键当成可交换，独立性证明直接失效，且运行时不会报错（F-059）。

## 5. 一条常见的过度推广

`Σ` 只提供**按 key 的名义链接**，没有版本链接或结构链接（F-069）。因此：

- 键名相同但值结构不同的提供方可以互换，接口漂移不会被类型系统拦住；
- 键碰撞把无关组件绑在一起；
- 论文给出的三条应对是键命名空间、peer dependencies（Cordis 当前采用）、结构兼容性，其中后两条属于**缓解措施而非形式保证**。

这也是 [10 · 边界与相关工作](10-boundaries-and-related-work.md) 会再次提到的限制。
