# 04 · 可逆效应：把撤回做成值

> 一句话：一次效应不再是 `Γ → Γ`，而是 `Γ → Γ × (Γ → Γ)`——它必须同时交出新状态和「怎么退回去」，且逆在看到具体状态的那一刻就地生成。

## 1. 核心类型

§3.1 把效应建模为（F-024）：

```
Γ → Γ × (Γ → Γ)
 γ  ↦  ( 新状态 γ′ , 逆函数 g )
```

`g` 不是全局撤销表，而是**这次修改专属**的逆。论文的口号可译作「去程与回程同源」：两者在同一表达式里产生，清理的完整性因此成为局部可检验的性质，而不用跨文件比对 `activate` 与 `deactivate`。

## 2. 扭转组合与幺半群

**Definition 1**（F-025）定义对 `(f, g)` 的扭转组合：

```
(f₁, g₁) ∘ (f₂, g₂) ≔ (f₁ ∘ f₂, g₂ ∘ g₁)
```

正变换按常规顺序复合，**逆变换反过来复合**——这正是 LIFO 卸载的代数形状。这些对构成幺半群 `𝔗Γ`，单位是 `(idΓ, idΓ)`。

**Definition 2**（F-026）定义效应上下文 `∂Γ ≔ Γ × (Γ → Γ)`，即 `(γ, φ)`，其中 `φ` 是逆的**累积器**；初始态 `(γ₀, idΓ)`。

**Definition 3**（F-027）给出追踪步：

```
trackΓ = (f, g) ↦ (γ, φ) ↦ ( f(γ), φ ∘ g )
```

**Theorem 5**（F-028）证明 `trackΓ` 是从 `𝔗Γ` 到 `∂Γ → ∂Γ` 的幺半群同态。这条结论的工程含义是：连续多次效应可以合并成一个累积器，且合并方式满足结合律，运行时不必为每次效应单独维护撤销栈。

## 3. 恢复与 soundness invariant

**Definition 6**（F-029）：`recoverΓ = (γ, φ) ↦ (φ(γ), idΓ)`，即把累积器一次性逆序应用后清空。

**Theorem 7**（F-029）：在 `g(f(γ)) = γ` 的前提下，soundness invariant `φ(γ) = γ₀` 在每次追踪步后保持。翻译成人话：只要每个逆真的能退回它自己那一步，中间任何时刻执行 recover 都回到起点。

> ⚠️ **前提不要丢**：`g(f(γ)) = γ` 是假设，不是框架检查出来的性质。见 §6。

## 4. 两点局限与见证版效应

§3.1.2 明确列出朴素 track/recover 的两个局限（F-030）：

1. **逆在看到状态前即固定**：普通 `Γ → Γ × (Γ → Γ)` 里，`g` 无法利用「施加效应后的那个具体状态」。
2. **recover 全有或全无**：累积器只能整体应用，无法支持分步、异步、按依赖顺序的拆卸。

**Definition 8**（F-030）因此定义 `𝔈Γ` 与见证版 `𝔈*Γ`。见证版只要求 `g(δ) = γ` 在**施加效应的那个状态** `δ` 上成立，而不要求 `g` 是全局逆。这是一个刻意放宽：组件只需对自己刚造成的那次修改负责。

**Definition 9 / Theorem 10**（F-031）：定义效应组合 `f ⋄ g`，`(𝔈Γ, ⋄)` 为幺半群，单位 `ηΓ ≔ γ ↦ (γ, idΓ)`。

**Theorem 15**（F-032）指出 `effectΓ` **并不**把 `𝔈*Γ` 映入 `𝔈*∂Γ`（除 `g∘f = idΓ` 外），但 soundness invariant 仍恒成立；**Theorem 16** 证明逆序回退使每个 revert 恰好恢复其 application 所针对的状态。

这一对定理是论文诚实度较高的地方：它没有声称「提升操作保持见证性」，而是把保持性弱化成仍可证明的不变量。

**Definition 17**（F-033）定义递归的效应迭代器 `ℑΓ`：每次迭代产出新状态、逆函数与 `Maybe(ℑ)` 续延。迭代器正是后面演算里「一个组件可以分步激活、中途被 divert」的形式基础（F-045）。

## 5. 必须写明的免责声明

论文 §5.1.1 说得很直接（F-059）：运行时**不校验 witness**。逆是否真能回退、键上操作是否可交换，都是组件作者的义务；Cordis 只是保存并逆序调用组件交回的回调。

因此「结构性保证」应理解为：**框架保证按正确的时机与顺序调用逆，并保证多个组件的逆不会互相串扰**；它不保证**逆的内容正确**。把前者读成后者，等于把 Theorem 7 的前提当成框架赠品。这一点同时是 [回程同源](../references/pattern-return-ticket-with-effect.md) 模式反模式表第 6 条。
