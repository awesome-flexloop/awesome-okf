# 06 · 上下文范式：统一 effect 与 coeffect

> 一句话：论文用一个递归定义的上下文 `Γ∞` 把「撤销记录」和「依赖键表」装进同一个东西，于是所有 effect / coeffect 都通过同一层中介，多个组件的效应才能在观测等价意义下独立交织。

## 1. 统一上下文

**Definition 28**（F-041）：

```
Γ∞ ≔ μΓ. Γ × (Γ → Γ) × Σ
```

三个投影分别是：**递归状态**（更内层的上下文）、**本级逆累积器**、`Σ` **协同效应上下文**。递归不动点 `μ` 对应运行时的上下文树——每个子 fiber 有自己的一层，父层可以整体持有子层。

这个定义的意义在于**消灭两个平行的机制**：传统框架里「撤销栈」和「服务注册表」是两套独立设施，彼此不知道对方状态；这里两者是同一个值的两个投影，所以「一个组件停用」可以同时触发「撤销它注册的服务」与「通知依赖方」，无需跨设施同步。Cordis 中对应一等公民 `ctx`（F-058）。

## 2. 观测等价 ≃S

§3.3.2 用「**无操作序列可区分**」定义 `≃S`（F-042）：两个上下文状态等价，当且仅当不存在任何后续操作序列能对二者给出不同观察结果。

由此 §3.1 的所有等式改按该等价读取。这条约定是必需而非偷懒：多个组件的效应共享同一上下文，要求物理状态逐字节相同会强到不成立；而「观察不出差别」恰好是时间可组合性真正需要的强度（F-009）。

> ⚠️ 边界：`≃S` 覆盖的是**系统内可观察状态**。已经越出边界的 emission（发出的字节、消息）不在其中，恢复不等于物理复原（F-066）。Theorem 68 的 recovery exactness 也只在这个意义上成立（F-052）。

## 3. 迭代器独立性

**Definition 42**（F-042）给出两个效应迭代器相互独立的**两个条件**，两条都要满足：

1. **变换两两交换**：任取双方的一步变换，先 A 后 B 与先 B 后 A 得到观测等价的状态；
2. **互不扰动对方产物**：一方的变换不得扰动另一方已产出的**逆函数**与**续延**（continuation）。

第 2 条常被忽略，却是最要紧的：即使状态变换本身可交换，如果组件 A 的后续操作改写了组件 B 之前交回的逆，B 的卸载就不再正确。`𝔈*Γ` 的见证性只保证「在施加效应的那个状态上成立」（F-030），所以独立性必须额外要求跨迭代器的产物不被扰动。

Theorem 45 与 Theorem 47 分别给出两类满足这两条的充分条件（不同键操作；键集不交且共享键可交换），见 [05](05-reactive-coeffects.md)。

## 4. 为什么这一篇是枢纽

- 向上：演算规则 [07](07-dynamic-composition-calculus.md) 里的每一次 transition 都在 `Γ∞` 上做，confinement（F-050）限制的正是「组件能碰 `Γ∞` 的哪些位置」。
- 向下：可逆效应 [04](04-revertible-effects.md) 的累积器与 [05](05-reactive-coeffects.md) 的 `Σ` 是 `Γ∞` 的两个投影。
- 向工程：Cordis 用 Proxy 沿 fiber 链向上解析属性（Algorithm 6，F-063），就是 `Γ∞` 递归结构在 TypeScript 里的实现方式；遇到「声明但未提交」抛 `INACTIVE_ACCESS`，到根仍未声明抛 `UNDECLARED_ACCESS`。

## 5. 一个诚实的限定

论文 §3 开篇就说明**局部保证止于其他组件进入**（F-023）。`Γ∞` 与 `≃S` 是为「多组件交织」准备的答案，但这个答案依赖组件满足独立性与交换性条件，而运行时不校验这些条件（F-059）。所以「上下文范式」提供的是**一套让正确性可表达、可证明的结构**，不是自动检测到违规并拒绝的能力。
