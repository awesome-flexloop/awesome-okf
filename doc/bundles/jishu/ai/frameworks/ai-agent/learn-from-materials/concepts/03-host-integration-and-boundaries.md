## ⚠️ 宿主口径差异：豆包工作

这是一个**双源并列登记**的差异点，**不判定原文有误**（F-033、核验报告第 8 项）：

| 口径 | 内容 |
|------|------|
| **源文口径** | 作者明确称"我把这个 Skill 装到「豆包工作」"，并给出豆包工作内的三步操作与逐字提示词（F-029） |
| **官方口径** | README 宿主清单仅列 WorkBuddy、Codex、Claude Code、GitHub Copilot CLI，**未列豆包工作** |

**为什么判定为"口径差异"而非"源文错误"**：

1. 豆包工作**确有官方技能安装机制**——官方文档《技能》页含技能页安装按钮、"我安装的"管理、"更多技能"入口，并注明"技能无需安装也可在任务中直接使用"；豆包开放平台《技能接入指南》亦证实终端用户可在「插件&技能&伙伴」页面安装已上架技能（核验第 7 项）
2. 本 Skill **基于开放 Agent Skills 规范**（F-013），`SKILL.md` 为标准格式，理论上可被任何识别 `SKILL.md` 的宿主加载
3. 官方 README 的清单性质是**"已验证宿主清单"**，未覆盖豆包工作不等于不支持
4. 二者为**不同公司产品**：豆包工作 = 字节跳动；WorkBuddy = 腾讯

> 📌 读者须知：本文档**并列保留两种口径**，不使用"官方支持豆包工作"或"原文有误"这类单向断言。

## 兼容边界：什么时候用不了（F-035~F-037）

### 纯聊天环境不可用

无文件系统访问或无法执行 Python 的环境，**只能使用部分提示流程**，无法完成：

- 材料提取
- 覆盖校验
- HTML 渲染

也就是说，纯聊天窗口里拿不到完整的六板块学习网页。

### 扫描件与图片型材料有限制

扫描 PDF 与图片密集型幻灯片**需要 OCR 或视觉能力**；缺少能力时，对应范围会被**标记为未核验**（F-036）——读者不应默认全部材料都能解析。

### 复杂材料的模型要求

长书、多材料交叉分析、专业论文、复杂开放题，更适合**长上下文、高推理能力**的模型（F-038）。
