# 五分钟速查

## 提示词骨架（照着填）

| 顺序 | 写什么 | 一句话示例 |
| --- | --- | --- |
| 1 任务 | 生成什么 / 改成什么 | "为〈品牌〉制作〈品类〉海报" |
| 2 骨架 | 什么图、什么构图、版面怎么分 | "9:16 竖版，上三分之一标题，中部产品，下部卖点" |
| 3 结构 | 分区、层级、模块关系 | "四栏卖点区，每栏一图标＋两行说明" |
| 4 文字 | 引号逐字＋字体字重颜色对齐行数 | "主标『〈文案〉』，暖红，居中，一行" |
| 5 约束 | 保留什么、不要什么 | "保持人物身份与机位不变；不画网格线" |
| 6 风格 | 风格词与美学词 | "手刻粗字，暖调胶片颗粒" |

前五步来自手册 9 条 Prompt 指导（F-023—F-032），第 6 步才用词库。

## 五步开工清单

1. **定模型入口**：要可复现就先在对话框输入 `/seed` 显式选技能；日常出图用默认入口（F-014）。
2. **判身份**：人像、装修、产品类先写"保留……"，纯创作类跳过。
3. **数结构**：能数出来的（区块、物料、值）全部列成清单。
4. **锁文字**：把要出现的字逐字写进引号，再补层级与位置。
5. **只改一个变量**：多轮时每轮一个变化项，其余写成保留栏（F-030、F-031）。

## 五个坑

| 坑 | 表现 | 改法 |
| --- | --- | --- |
| 风格词打头 | 版面被牺牲，图和文案对不上 | 任务句放第一句（F-024） |
| 用抽象词当验收 | "氛围感"永远对不上 | 换成"浓雾""过曝""浅景深"这类可观测词（F-027、F-033） |
| 编辑不写保留项 | 改一处带崩全图 | 双栏表：保留栏＋变化栏（F-030） |
| 多轮用指代 | "上一轮那个"越改越偏 | 每轮自包含，位置与对象写全（F-031） |
| 文字只给内容 | 字糊、重复、乱断行 | 五字段：内容/层级/字体/位置/行数（F-028） |

## 两条触发式规则

- **透明底**：提示词须含"透明背景""PNG 透明底""无背景""alpha 通道"之一（F-021）。写"纯白背景"得到的是白底，不是透明底。
- **文字**：要出现的字必须用中文引号逐字给出，并可说明层级（F-022）。没引号＝让模型自由发挥。

## 验收只查三处

上一轮改过的地方 → 本轮没提的地方 → 新旧交界处（边缘、投影、接触点）。三处都过再进下一轮。[多轮编辑](../concepts/02-multi-turn-editing.md)
