## 组合规则

三词一组不是随机拼的，每组覆盖**不同维度**（题材、机位、景别、色温、饱和、光位、介质、氛围）。据此有一条实用规则：

> 组内不要取两个同维度的词。

例如"高饱和＋低饱和"互相抵消，"俯拍＋侧面视角"互相冲突。跨组组合时按维度各取一：一个题材词 + 一个机位/景别词 + 一个色/光词。

## 与风格词叠加

风格词与美学词叠用时的顺序建议是：**风格词定语言，美学词定拍摄参数**。

| 组合 | 效果 |
| --- | --- |
| 工笔风格 + 冷色调、数字艺术、全景 | 传统笔法套现代观感 |
| 老照片滤镜风格 + 黑白摄影、逆光、动态模糊 | 滤镜风格与去色重复，二选一 |
| 丝网印刷风格 + 特写镜头、暖色调、高饱和 | 印刷套色与高饱和同向，成立 |

第二行是警示：风格词里已经含"滤镜/去色"语义时，不要再叠一个同义美学词，两者会互相吃掉细节。

- 词库只提供**风格层**，任务句与结构句仍需自己写（[提示词骨架](../concepts/01-prompt-anatomy.md)）。
