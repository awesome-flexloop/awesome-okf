# 文字与结构：图里的中文字怎么才不糊

手册把"文字更清晰"列为第四项改善，在亮点区写成"小字渲染能力：复杂场景文字准确、小字准确率达 95%、结构合理、画布排版/配色优化"（F-016）。同时给出一条操作规则：生成指定文字内容时需用中文引号引出具体文字，并可进一步说明文字之间的层级关系（F-022）。[事实台账](../references/facts.md)

规则只有一句，但它是**触发式**的：写了引号，模型进入"渲染这段字"模式；没写引号，模型按画面需要自由发挥。所以文字任务的本质不是"让字变好看"，而是"让模型知道字是什么"。

## 文字任务书：五个字段

技巧 ⑤ 要求逐字给全、分层级，按需写清字体、字重、颜色、对齐方式、行数（F-028）。落成模板就是五个字段：

| 字段 | 写法 | 为什么必须写 |
| --- | --- | --- |
| 内容 | 用中文引号逐字给出，一字不改 | 引号是触发标记；改一个字就是另一个任务 |
| 层级 | 主标题 / 副标题 / 正文 / 角标分别列出 | 层级决定字号与字重的相对关系 |
| 字体与字重 | 如"墨黑细小手写引题""手刻粗字" | 字体是风格的一部分，缺省会被填成通用黑体 |
| 位置与对齐 | 顶部横幅、右下角竖排、居中、左对齐 | 位置决定可读性，也决定与图的关系 |
| 行数与换行 | 明确几行、在哪断行 | 行数不写，长标题会被压成一行或强行断词 |

手册示例里的一条完整文字任务同时给了内容、颜色、位置、次数约束——"上方墨黑细小手写引题'…'；下方两行手刻粗字'…'（暖红）和'…'（灰蓝），各一次"。"各一次"就是次数约束，属于防重复渲染的必要声明。

## 结构：先版式，再内容

技巧 ③ 说结构比形容词重要（F-026），技巧 ② 说开头先定骨架（F-025）。文字密度高的任务尤其吃这一点：手册示例把信息图拆成"顶部标题横幅＋中部插画与说明交错的主体区＋底部横排三个知识小框"，三区定完才谈笔触与配色。

结构声明的最小集：

1. **画布**：比例与朝向（横版、竖版、超长竖版、正方形）。
2. **分区**：几个功能区、各在图中的位置。
3. **顺序**：阅读顺序（从上到下、从中心向外、沿时间轴）。
4. **留白**：哪里必须空着。

留白常被漏掉，但手册示例里有明确写法："人物与文字互不遮挡""留白充足""疏密自然"。否定式约束（"不遮挡""不画网格线"）比肯定式更有效，因为它排除的是一整类错误。

## 三条常见失败与对应改法

| 现象 | 常见成因（推断，非手册结论） | 改法 |
| --- | --- | --- |
| 字被压成一团、糊成一串 | 只给了内容，没给行数、层级与位置 | 补齐五字段，尤其行数与换行位置 |
| 出现重复的字或多余装饰字 | 未声明"各一次""仅呈现最终文案" | 加次数与排除约束（"不要伪文字与额外装饰"） |
| 版式对了但风格不对 | 结构写全、风格词缺失；或风格词与字体冲突 | 结构段之后单独补风格段，字体与风格词同源 |

第三行值得展开：字体本身承载风格。手册风格词示例里，"手刻粗字""钢笔墨线""粗头马克笔"这些词既描述笔画，也描述风格强度。写"日式手绘时装漫画海报"却要求"微软雅黑"，结构再好也出不来。

## 验收口径

文字任务验收只查四项：

1. **逐字对照**——引号内的每个字是否都在、位置是否对、有没有错字或多余字。
2. **层级是否成立**——主标题是否在视觉上明显强于副标题（字号、字重、颜色三者至少两项成立）。
3. **版式是否守住**——分区、顺序、留白是否与任务书一致。
4. **可读性下限**——缩到发布尺寸（手机屏、印刷 A4）后是否还能读清。

关于"95%"：手册未给样本口径（字号、语言、字数、评价方式均未写明），本包按厂商单方口径记录，不作为验收阈值（F-016）。自己那批字的错字率才是有意义的指标。
