# 信源参考

本层是事实与判断的可追溯底座，三份文件互相引用：

| 文档 | 作用 |
|---|---|
| [事实台账 F-001~F-052](facts.md) | 逐条编号的客观事实，每条挂信源 id；G1 门要求「无因果词、可验证、数字完整」 |
| [信源清单](source-manifest.md) | 14 个信源的 URL、性质、日期与可信度分层；含官方文档的 GitHub 源文件定位 |
| [冲突口径与对抗审查](conflicts-and-adversarial-review.md) | C-01~C-06 六组口径差异并列登记；V 门四视角审查记录与已采纳修正 |

**引用约定**：正文中的 `F-xxx` 指事实台账条目，`S-xx` 指信源清单条目，`C-xx` 指冲突登记条目。厂商自述与第三方数据一律标注来源与截点，不写成本库结论。

**原子化口径说明**：本束 10 篇内容页（4 概念 + 3 示例 + 3 参考）均落在 500~5000 字符区间，符合原子化门。`facts.md` 为表格型登记台账（52 条编号事实，约 9950 字符），按本库既有惯例作为单一可信源整页保留，**不拆分**——拆分会让 F 编号跨文件，破坏「区间上界 ↔ 统计表 ↔ 交叉引用」三处对账。bundle 根 `index.md` 因内嵌 14 条 `sources` 溯源字段而超过 5000 字符，属导航入口而非内容页，同样不拆分。
