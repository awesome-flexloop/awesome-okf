# 安装与模型配置：四步跑通第一个对话

课程把这一段拆成四步，每一步都有一个看得见的成功标志（F-042~F-052）。判断自己有没有走完，不看「感觉装好了」，只看标志。

| 步骤 | 你要做的 | 成功标志 |
|------|----------|----------|
| 1 安装 | 把课程版安装包装进手机 | App 能打开，通知权限已允许 |
| 2 配置 | 填 Base URL、两个模型名、API Key，开无障碍 | 设置页保存后不再回到空表单 |
| 3 自检 | 发两条指令 | 有回复（聊天通）；手机自己跳到 Wi-Fi 页（操作通） |
| 4 任务 | 发一个淘宝任务 | 停在确认前，你核对后决定是否允许 |

## 第 1 步：装到手机上

课程版安装包名为 `xiaoman-course.apk`，课程称约 60 MB（F-042）；附件元数据为 62,163,177 字节，与「约 60 MB」一致（F-088）。源码核验：公开课程分支 `camp/xiaoman` 的 versionName 为 `0.1.0`、versionCode 为 1（S-004）；课程 APK 的具体构建号未提供。

两种方式选一种（F-043、F-044）：

**方式一：手机直接下载**

1. 在手机上打开课程文档，点附件下载；也可以用课程通知里的下载链接。
2. 下载完成后点安装包。
3. 按提示允许「安装未知来源应用」。
4. 在外部来源提示里勾选「已了解风险」后继续安装（F-045）。

**方式二：电脑下载后传到手机**

1. 在电脑上下载附件。
2. 用数据线拷到手机，或用微信、飞书的文件助手发到手机。
3. 在手机的文件管理里点开安装。

安装完成后还会遇到两个系统请求，都要处理（F-046、F-047）：

- **通知权限**：首次打开时允许发送通知——后面的提醒依赖它。
- **无障碍服务**：在系统设置里打开对应开关，弹窗点「允许」——助手靠它读屏幕、点按钮。

> 不同品牌的系统界面略有差异。找不到无障碍开关时，在系统设置里直接搜索「无障碍」是最快的路径。

## 第 2 步：给自己配一个「大脑」

### 先理解你在配什么

App 要填两个模型（F-028）：

- **聊天模型**：理解你的话、规划步骤、组织回报。
- **操作模型**：看屏幕截图，判断按钮在哪、当前是不是目标页面。它必须能看图。

两个填同一个也可以。判据很简单：**这个模型要不要看屏幕**。

### 方舟开通五步

课程给的顺序是（F-029~F-033）：

| 步骤 | 动作 | 注意 |
|------|------|------|
| 1 | 注册火山引擎并完成实名认证 | 需要本人刷脸，建议课前完成 |
| 2 | 进入方舟控制台，开通模型 | 讲师示范使用 doubao-seed-2-1-pro-260915 |
| 3 | 创建 API Key | 只填进手机 App，不发群、不截图公开 |
| 4 | 记下 Base URL | `https://ark.cn-beijing.volces.com/api/v3`，App 默认即它 |
| 5 | 查看额度 | 免费额度、推理限额与「安心体验」开关都在控制台 |

Base URL 已由官方文档多页确认（F-079）；模型也已收录在官方模型列表，能力含多模态理解与 GUI 任务处理（F-080）。课程称新用户每个模型有 50 万免费 token（F-033）；官方产品页当前展示「免费额度 50 万 tokens」，同时另列协作奖励计划（F-082），两种口径不要混用——**费用一律以方舟控制台账单为准**。

### 课程划的一条红线

课程明确不让 TRAE 代点注册、实名、开通模型与创建 Key（F-072），理由有三条：实名要本人刷脸；开通模型等于同意按量计费；Key 一出现在页面上，替你点击的 AI 也会读到它。

找不到按钮时，正确做法是把控制台截图发给 TRAE 问「下一步点哪里」，**截图前确认没有露出 Key**（F-073）。

## 第 3 步：自检，确认两条链都通

按顺序发两条指令（F-049、F-050）：

```text
你好，介绍一下你自己。
```

有回复，说明**聊天模型通了**。

```text
打开设置里的 Wi-Fi 页面。
```

手机自己跳到 Wi-Fi 页，说明**操作模型和无障碍都通了**。

### 自检失败的分诊

| 现象 | 判断 | 处理 |
|------|------|------|
| 第一条没回复 | 聊天链断 | 查聊天模型的 Base URL、模型名、Key 与余额 |
| 第一条通，第二条不动 | 操作链断 | 查操作模型配置、模型是否支持图片、无障碍是否被系统关掉（F-066） |
| 报 429 SetLimitExceeded | 额度或限额被卡 | 到方舟检查推理限额、「安心体验」与余额；只充值不一定恢复（F-065） |

> **评论区反馈（未核验，仅作排查线索）**：有学员遇到配置后 401/404、安装包提示 `package info is null`；也有人用百度网盘镜像下载源码、用 OpenRouter 免费模型替代方舟（F-094）。这些不是课程给出的标准路径，遇到时仍按上表先分链、再查配置。

## 第 4 步：跑第一个任务

前置条件：**手机上的淘宝已经登录**（F-051）。然后发：

```text
帮我在淘宝挑一本20元以内的A5笔记本，选好后给我确认。
```

接下来手机会自己动起来。你只做两件事（F-052）：

1. 它弹确认时，看清楚再点「允许一次」。
2. 它停下来以后，对照结算页核对店铺、规格、数量和金额。

> **这一步不是「让它买」，而是「让它停在买之前」**。任务书写的是「选好后给我确认」，停点是明确的；付款这一步由你决定。课程明确它不会自己付款，付款、发送、删除前都会先问你，密码框它也不能输入（F-067）。

### 遇到滑块或验证码

本人手动划过去，再回到对话里说「继续」（F-053）。课程的说法是「验证码本来就该由人来过」——这不是妥协，而是身份核验的设计目的。

## 费用怎么估

课程给的口径是（F-064，【讲师口径】）：简单任务几分钱；淘宝这类十几二十步的长任务大约几毛钱到一块钱。原因是每一步都要发一张截图给模型（F-068）。实际以方舟控制台的用量和账单为准。

需要分开看两件事：

- **计费单位**：Token，按实际推理量结算（F-033、F-064）。
- **步数**：决定你发多少张截图、消耗多少 Token。所以「把任务写清楚、少走弯路」不只是体验问题，也是成本问题。

## 装完之后的自检清单

- [ ] App 能打开，通知权限已允许
- [ ] 无障碍服务已开启，弹窗已点允许
- [ ] 设置页两个模型都填了 Base URL、模型名、Key
- [ ] 第一条自检有回复
- [ ] 第二条自检手机跳到 Wi-Fi 页
- [ ] 淘宝任务能停在确认前，核对完能退出结算页
- [ ] 知道 429 与「手机不动」分别该查什么

七项都过，再进行 [04 记忆与提醒](04-memory-and-reminders.md)。
