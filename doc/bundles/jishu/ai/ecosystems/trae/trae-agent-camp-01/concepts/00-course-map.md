# 课程地图：这一课到底交付什么

## 一句话定位

这一课不教你从零写一个手机 Agent，而是让你**在别人的底座上，用自己的模型，办成第一件事**：装上课程版助理（小满），接上火山方舟的模型，跑通一个淘宝任务，再教它记住一条偏好。读码、改码、跑命令交给 TRAE，你负责说清需求、在手机上核对结果（F-002、F-003、F-006）。

## 四项收获与对应篇章

| 课程收获 | 你会得到什么 | 本包对应篇章 |
|----------|--------------|--------------|
| 弄清楚什么是 Agent | 能区分 Chatbot 与 Agent，能说出模型外面围着哪几块 | [01 Chatbot 与 Agent](01-chatbot-vs-agent.md)、[02 Agent 解剖](02-agent-anatomy-react.md) |
| 安装手机上的 Agent 助理 | 手机上出现一个能读屏、能点击、能对话的助手 | [03 安装与模型配置](03-install-and-model-config.md) |
| 跑通助理 | 自检两条都过、淘宝任务停在确认前、偏好被记住、提醒能弹出 | [03](03-install-and-model-config.md)、[04 记忆与提醒](04-memory-and-reminders.md)、[05 任务设计](05-task-prompt-design.md) |
| 学会配置大模型 | 方舟开通、双模型填好、Key 不外泄 | [03 安装与模型配置](03-install-and-model-config.md) |

## 先确认你的设备在不在范围内

课程给出的边界很明确（F-004、F-005）：

| 设备 | 本课能否装 App | 说明 |
|------|----------------|------|
| 安卓手机 | 可以 | 课程主线路径 |
| 鸿蒙 5 以下 | 可以 | 按安卓安装包处理 |
| iPhone | 本期不支持 | 课程给出的原因是系统不允许一个 App 读取和操作别的 App |
| 鸿蒙 5 及以上 | 本期不支持 | 课程给出的原因是该系统不再运行安卓安装包 |

> **文档口径差异**：同一页开头写「鸿蒙 5 以下可装」，收获段写「安卓和鸿蒙 4.x 及以下装 App」（F-092）。两者取交集，**按「鸿蒙 4.x 及以下」准备更稳妥**。评论区另有学员反馈鸿蒙 4.2.0 实测闪退、雷电模拟器可用（F-093，社区反馈未核验）。

设备不在范围内时，课程给的替代路径是：跟着直播看，把「用 TRAE 读项目」的部分放到电脑上做——那部分不依赖手机（F-006）。这条替代路径本身也值得学：它决定了你后面能不能自己改助理。

## 学习者与 TRAE 的分工

这是本课最容易被忽略、但最重要的一条规则（F-006、F-062）：

| 角色 | 负责什么 | 不负责什么 |
|------|----------|------------|
| 你 | 说清需求、给条件、定停止点、在手机上核对结果、决定是否允许 | 不需要读懂每一行代码 |
| TRAE | 读代码、改代码、跑命令、解释目录与调用链 | 不替你承担不可逆操作的责任（付款、实名、发 Key） |

分工的判据是**可逆性**：可逆的动作（读、讲、改本地文件、跑测试）可以交给 AI；不可逆的动作（付款、发送、删除、实名、创建计费资源）必须人来做。这条判据会在 [07 安全与权限](07-safety-and-permissions.md) 展开。

## 与第二节课的衔接

第一课结束后，课程安排了三项课前准备（F-076、F-077）：

1. 电脑装好 Python 3.8 及以上与 adb；安卓手机开 USB 调试，`adb devices -l` 能看到 device 那一行即连好。
2. 淘宝保持登录，滑块提前手动划过去。
3. 写好「3-2-1」：3 条偏好、2 件常做的事、1 条底线，且不写敏感个人信息。

第二节课会用 TRAE 做今日开工卡、健康闹钟、淘宝比价、每日出题、资讯速览（F-078）。换句话说，第一课交付「能跑」，第二课交付「按你的习惯跑」。

## 本课不承诺什么

- 不承诺全自动：付款、发送、删除前它都会先问你（F-067）。
- 不承诺跨平台：iPhone 与鸿蒙 5 及以上本期不支持（F-005）。
- 不承诺零成本：简单任务几分钱，长任务按步数累加，费用以方舟控制台账单为准（F-064）。
- 不承诺一次成功：滑块、验证码、权限被系统回收都会打断任务，处理方式见 [07](07-safety-and-permissions.md)。
