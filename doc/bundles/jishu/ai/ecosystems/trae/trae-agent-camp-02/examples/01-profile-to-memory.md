# 示例一：把 3-2-1 写成个人档案并推到手机

## 这个示例解决什么

第一课是一条一条说「记住：……」。当偏好超过五条，逐条发就会漏、会互相冲突、也不好改。这个示例用一份结构化档案替代零散记忆，并且用 adb 一次推送、可反复更新。

## 前置条件

- [ ] 第一课的四步已跑通（App 可用、两个模型自检通过）
- [ ] 电脑能运行 adb（让 TRAE 装好即可）
- [ ] 手机已开 USB 调试，插线后能点「允许」
- [ ] 已用 TRAE 打开 xiaoman 源码文件夹

## 第 1 步：写下 3-2-1

在备忘录里写（F-017）：

```text
3 条偏好：
- 买东西先看评价，预算宁低勿高
- 回复先说结论，别太长
- 晚上 10 点以后别给我排事

2 件常做的事：
- 每天早上排一下今天要做的事
- 备考期间每天做几道题

1 条底线：
- 付款、对外发消息之前，一定先问我
```

写完之后用「可判定」自查：有没有数字、时间点、明确的动作。没有就补。

## 第 2 步：让 TRAE 整理成档案

发（F-018）：

```text
下面是我的 3 条偏好、2 件常做的事和 1 条底线：
（贴上你写的内容）
请帮我整理成一份助手能用的个人档案：每条偏好写成一句清楚的规则，并给一个例子；
常做的事写成“我说什么 → 希望它怎么做”；底线单独列出。
不要加入我没提到的信息，地址和手机号先不要写进去。
```

**期望结果**：每条偏好是一句规则 + 一个例子；常做的事是「我说什么 → 它怎么做」；底线单独成段。

**检查**：有没有出现你没说过的内容（如「你喜欢喝咖啡」）？有就删掉——这是模型在补全。

## 第 3 步：搭 adb 桥

| 步骤 | 做什么 | 成功标志 |
|------|--------|----------|
| 1 | 电脑装 adb（可让 TRAE 装） | 能运行 `adb devices -l` |
| 2 | 手机开 USB 调试：设置 → 关于手机，连点「版本号」7 次，进开发者选项打开 USB 调试 | 开关是开的 |
| 3 | 插能传数据的线，手机上点「允许」 | 不再弹授权窗 |

让 TRAE 运行 `adb devices -l`，按判读表看结果（F-024）：

| 末尾 | 说明 | 怎么办 |
|------|------|--------|
| device | 成功 | 继续第 4 步 |
| unauthorized | 手机没点允许 | 解锁手机点允许 |
| offline | 连接不稳 | 换线重插 |
| 无设备 | USB 调试未开 | 回第 2 步 |

## 第 4 步：整份推送到手机

发（F-026）：

```text
请把刚才整理好的个人档案存进手机上小满的记忆，用 adb 来做：
1. 先运行 adb devices -l，确认手机那一行显示 device；没连通就先告诉我哪里不对。
2. 按 docs/ARCHITECTURE.md“记忆”一节的格式，把档案写成一份 Markdown 笔记，存到电脑上的 memory/profile.md：
   标题用“个人档案”，偏好、常做的事、底线每条占一行，内容和档案一致，不要增减。
3. 用 adb push 把它放到手机的 /sdcard/Android/data/dev.xiaoman.app/files/memory/profile.md。
4. 推完用 adb shell ls 看一下这个文件夹，告诉我手机上多了什么。
手机里已有的记忆不要删，也不要覆盖。
```

**期望结果**：TRAE 逐步回报四步结果，最后列出手机目录里的文件。

## 第 5 步：到手机看

打开 App 底部「记忆」，应能看到「个人档案」（F-027）。没看到就退出记忆页再进；仍没有，把 TRAE 的回复原样发回给它查原因。

## 第 6 步：三句话验证

```text
记住：买东西先看评价，预算宁低勿高。
帮我挑个耳机。
今天帮朋友买，预算放宽到 200。
```

| 你发 | 期望 | 验证什么 |
|------|------|----------|
| 第一句 | 回复已记住，记忆页多一条 | 能存 |
| 第二句 | 未再提要求，也先看评价、按偏低预算 | 换说法仍生效 |
| 第三句 | 按 200 元挑，原偏好仍在 | 当次优先 |

三句都对上，本示例完成（F-030）。哪句不对，把回复原样贴给 TRAE，让它改写档案对应条目再重新推送（F-031）。

## 后续更新

档案有改动时，对 TRAE 说「把改好的档案再推到手机」（F-028），不必重复第 1~3 步（桥已搭好）。

## 边界

- 记忆文件在 App 私有目录，卸载 App 会清掉；换机、重置前先备份。
- 档案里不写地址、手机号、证件号、银行卡号（F-018）。
- 分享记忆文件前删掉个人信息（F-100）。
- 档案格式参考 `docs/ARCHITECTURE.md` 的「记忆」一节；课程文档未展开格式细节（核验缺口 G-05）。
