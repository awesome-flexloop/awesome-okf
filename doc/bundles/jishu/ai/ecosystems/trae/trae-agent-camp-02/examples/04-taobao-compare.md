# 示例四：淘宝比价（taobao-compare）

## 这个示例解决什么

买指定商品时想找最便宜的一家。本课先做最基本的一步：比较**当天淘宝搜索结果里的前几家**，用表格回报，最后停在最便宜那家的商品页。

历史低价与跨平台比价课程明确列为课后挑战，不在本节范围（F-100）。

## 前置条件

- [ ] adb 桥已搭好
- [ ] 淘宝已登录，滑块已由本人划过（F-062）
- [ ] 手机端能验收（无安卓设备可与同学结对）

## 第 1 步：在手机上先试一次

发（F-059）：

```text
在淘宝搜“得力 A5 笔记本”，比较前 3 家的价格、销量和店铺，告诉我哪家最便宜。打开那家的商品页，不要加购，不要下单。
```

**观察点**：信息全不全？有没有把看不清的地方瞎填？最后停在哪一页？

记下这句原话，第 3 步原样复测。

## 第 2 步：在 TRAE 里改技能并推送

发（F-060）：

```text
请参考 skills/examples 里现有的淘宝相关写法，新建技能 skills/examples/taobao-compare。
我说“比价 + 商品名”时：在淘宝搜索，比较前 3 个商品的到手价、销量和店铺名，
有“券后价”的按券后价比，看不清的写“页面未显示”，不要猜。
结果用表格回给我，再打开最便宜的那家商品页。
不能做：不加购、不下单、不领需要付费的券。完成后帮我校验并推送到手机，再说明改了什么。
```

三条规则值得单独记：

| 规则 | 防的是什么 |
|------|------------|
| 有券后价按券后价比 | 到手价口径不一致，比出来的「最便宜」是假的 |
| 看不清写「页面未显示」 | 模型编数字 |
| 只到商品页，不加购不下单 | 不可逆动作越界 |

## 第 3 步：回到手机复测

对助理说「比价 得力 A5 笔记本」，核对（F-061）：

- [ ] 前 3 个商品的价格、销量、店铺名齐全
- [ ] 看不清的写「页面未显示」
- [ ] 不足 3 个时如实说明
- [ ] 停在最便宜那家的商品页
- [ ] 没有加购、没有下单、没有付款

> **停在商品页只能算找到了，不能说成「已经买到」。** 这是课程的原话要点（F-061）。

## 结果不对时

课程录屏里的一次真实失败：回复里没有店铺名，也没排成表格（F-063）。排查顺序：

1. 把截图、运行 ID、执行轨迹交给 TRAE（见 [证据链排障](../concepts/07-evidence-debugging.md)）。
2. TRAE 定位到技能里的输出要求不完整。
3. 补全技能要求 → lint → push → 手机复测。
4. 复测回复变成四列表格，看不到的信息写「页面未显示」。

如果行为对了、但**表格显示**还是乱，那是程序层的问题：表格渲染改在 App 程序里，要重新构建、安装 APK 才生效（F-104）。不要继续改技能。

## 验收清单

- [ ] 表格有价格、销量、店铺名三列以上
- [ ] 不确定的信息如实标出
- [ ] 停在最便宜那家的商品页
- [ ] 全程没有加购、下单、付款
- [ ] 能说清这次失败（如有）落在技能层还是程序层

## 边界

- 只比当天淘宝搜索结果里的价格；不承诺历史低价与跨平台（F-100）。
- 登录与滑块由本人完成；遇到验证码先手动过，再说「继续」。
- 价格以当天页面为准，本示例不提供固定价格结论。
