# 实战示例

六篇按「先记忆、再技能」的顺序排列。每篇都是可复制的三步或六步流程，含提示词原文、期望结果、验收清单与边界。

| 序号 | 示例 | 落在哪一层 | 验证什么 |
|------|------|------------|----------|
| 01 | [个人档案推到手机](01-profile-to-memory.md) | 记忆 | 3-2-1 → 档案 → adb 推送 → 三句话验证 |
| 02 | [今日开工卡](02-today-plan.md) | 技能 | 排序规则、最多 3 件、同意后设提醒 |
| 03 | [健康闹钟](03-health-alarms.md) | 技能（gui） | 按作息挑空档、内置链接、不动原有闹钟 |
| 04 | [淘宝比价](04-taobao-compare.md) | 技能（gui） | 前 3 家、看不清如实标、停在商品页 |
| 05 | [每日出题](05-daily-quiz.md) | 技能（chat） | 答前不给答案、错题进记忆、能复习 |
| 06 | [资讯速览](06-ai-news-brief.md) | 技能（chat） | 按偏好筛、附来源、不编新闻 |

> 六篇示例的流程与提示词均来自课程原文（F-026、F-048~F-073）。它们能复现「课程版 App + 方舟模型」这条主线，但不承诺在所有设备与版本上一致——课程未给 App 版本号（缺口 G-01），仓库与分支也未独立核验（G-03）。
