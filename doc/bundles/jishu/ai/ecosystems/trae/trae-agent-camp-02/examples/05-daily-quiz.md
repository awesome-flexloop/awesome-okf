# 示例五：每日出题与错题本（daily-quiz）

## 这个示例解决什么

备考时需要有人按方向出题、批改、把错题存起来。这个场景不操作其他 App，只在对话里完成，是五个场景里最适合先练手的一个（F-068）。

## 前置条件

- [ ] 小满可正常对话
- [ ] 已用 TRAE 打开 xiaoman 源码（改技能需要）
- [ ] adb 桥已搭好（推送需要）

## 第 1 步：先记下备考方向

发（F-065）：

```text
记住：我在备考 NSCA 体能教练证，重点是训练计划设计和营养，题目用中文。
```

**为什么先记**：出题技能的第一条规则是「先读记忆里的备考方向」（F-066）。方向不在记忆里，出题就没有依据。

## 第 2 步：在 TRAE 里改技能并推送

发（F-066）：

```text
请参考 docs/skills.md 里“聊天工作流（channel: chat）”的写法，新建技能 skills/examples/daily-quiz。
我说“出题”时：先读记忆里的备考方向，出 3 道单选题，每题 4 个选项，先不给答案；
我答完再逐题讲解。答错的题，把题目、正确答案和一句解析写进记忆，标题以“错题：”开头。
我说“复习错题”时，从记忆里取出错题重新考我。
不确定的知识点要说明“建议对照教材核实”，不要编造出处。完成后帮我校验并推送到手机，再说明改了什么
```

四条规则对应四种失败模式：

| 规则 | 防的是什么 |
|------|------------|
| 先不给答案 | 一次把答案说出来，练不到 |
| 错题写进记忆 | 错了就过去了，没有复习入口 |
| 复习错题重新考 | 错题本只存不练 |
| 不确定就说核对教材、不编出处 | 模型编造教材页码与出处 |

## 第 3 步：回到手机复测

对助理说「出题」，核对（F-067）：

- [ ] 3 道中文单选题，每题 4 个选项
- [ ] 你答之前不给答案
- [ ] 答完逐题讲解
- [ ] 故意答错一道后，记忆页出现以「错题：」开头的条目，且有正确答案与一句解析
- [ ] 说「复习错题」会拿这道题重新考你
- [ ] 不确定的知识点提示「建议对照教材核实」

最后一条别跳过：**练习题本身也要对照教材核一遍**。模型出的题可能方向对、细节错。

## 验收清单

- [ ] 出题前读了记忆里的备考方向
- [ ] 题量、选项数符合规则
- [ ] 答前无答案、答后有讲解
- [ ] 错题进记忆且能复习
- [ ] 无编造出处
- [ ] 对照教材核过至少一道题的答案

## 变体练习

换一个考试方向，保持四问完整：

```text
记住：我在备考中级经济师，重点是财政与金融，题目用中文，难度接近真题。
```

然后把技能里的「3 道单选」改成「5 道单选 + 1 道多选」，再走一遍「试 → 改 → 验」。

## 边界

- 记忆里的错题会进入模型上下文；不要写与考试无关的个人信息。
- 出题质量受模型知识限制；课程明确要求「不确定就建议核对教材」，不要把练习当权威答案。
