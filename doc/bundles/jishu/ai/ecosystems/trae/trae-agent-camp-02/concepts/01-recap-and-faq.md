# 回顾与高频问题：先把第一课的债还掉

## 第一课你已经有的东西

课程回顾的五件事（F-009）：手机上的 Agent 助理、接好的大模型、一次淘宝挑笔记本任务、一条偏好记忆、一次提醒。第二课在这套基础上改造，安装包与第一课是同一份，已装好的不用重装（F-002）。

如果这五件事里有没跑通的，先按本篇排查，再进入改造——**基线不稳时改技能，分不清「本来就坏」和「改坏了」**。

## 六组高频问题

> 课程标题写「7 个问题」，正文表格实际列出 6 行（「双模型」一行合并了「能否用 DeepSeek」「能否共用一个 Key」等子问题）。本包按 6 组呈现，并保留这一计数差异（F-124，见核验报告）。

### 1. 课程材料与源码在哪

源码在 GitHub：https://github.com/aduoge/xiaoman。点 Code 再选 Download ZIP，解压后用 TRAE 打开 xiaoman 文件夹；这节课改的技能都在里面（F-010）。

APK 解压后找不到 README.md，通常是打开错了层级——课程要求打开的是含 README.md、cli、skills 的那个 xiaoman 文件夹。

### 2. 体验额度领不到

课程称上节课领取人数过多导致领取页暂停，本节课重新开放（F-011）。体验服务的 Base URL 与模型名由课程在直播中另行给出。

> **本包不转载领取入口、服务地址与令牌**：它们属一次性课程运营内容，且已随结课失效（核验报告 P0 第 4 项）。长期使用请换自己的方舟 Key。

### 3. 为什么要填两个模型

| 模型 | 负责什么 | 硬要求 |
|------|----------|--------|
| 聊天模型 | 听懂你的话、挑技能 | 能正常对话即可 |
| 操作模型 | 看手机截图决定点哪里 | **必须支持图片输入** |

「兼容 OpenAI 接口」指请求格式与 OpenAI 一致，国内外多数模型平台都支持（F-012）。两个模型可以填同一个，只要它同时具备对话与视觉能力。

### 4. 报错 401 / 404 怎么办

| 错误 | 课程归因 | 先查什么 |
|------|----------|----------|
| 401 | Key 填错、过期，或模型尚未开通 | Key 是否完整、模型是否在控制台开通 |
| 404 | Base URL 或模型名不对 | Base URL 是否只填到 `/api/v3`（方舟）或 `/v1`；模型名是否与平台显示完全一致 |

关键规则：**Base URL 只填到版本层**，后面的 `/chat/completions` 由程序自己拼（F-013）。多填一层就会 404。

### 5. 无障碍在哪打开

手机设置里搜「无障碍」，在「已下载的应用」或「已安装的服务」里找到小满，打开开关并在弹窗点允许（F-014）。各品牌位置不同；系统升级或清理后可能被关掉，需要重新打开。

判断它是否生效：发「打开设置里的 Wi-Fi 页面」，手机自己跳过去就说明操作链通了（见第一课的自检思路）。

### 6. 没有安卓手机怎么办

两条路（F-015、F-004）：

1. **模拟器**：电脑装安卓模拟器（课程示例为 MuMu），把 APK 装进去跟着做；模拟器也能用 adb 连接，推送技能的命令照样可用；连不上时让 TRAE 查端口。
2. **结对**：iPhone 与鸿蒙 5 及以上的同学，在 TRAE 里写档案、读技能、改技能，手机验收与安卓同学结对或看录屏。

## 鸿蒙支持范围的两课口径

| 来源 | 表述 |
|------|------|
| 01 课 | 安卓手机以及鸿蒙 5 以下可装 App |
| 02 课 | 安卓手机与鸿蒙 4.x 及以下支持；iPhone 与鸿蒙 5 及以上本期不支持 |

本包取交集：**鸿蒙 4.x 及以下可用**。两课表述差异属口径不统一，不是能力变化（见核验报告口径对照表）。
