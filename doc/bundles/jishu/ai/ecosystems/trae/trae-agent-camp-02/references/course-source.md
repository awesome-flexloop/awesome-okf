## 三、个人档案与记忆层

| 编号 | 事实 | 类别 |
|------|------|------|
| F-016 | 让助理了解用户分两步：先在 TRAE 里把习惯整理成个人档案；再把档案内容告诉助理、存进记忆。 | 记忆 |
| F-017 | 课程要求先写下「3-2-1」：3 条偏好、2 件常做的事、1 条底线；示例偏好为「买东西先看评价，预算宁低勿高」「回复先说结论，别太长」「晚上 10 点以后别给我排事」；示例常做含「每天早上排一下今天要做的事」「备考期间每天做几道题」；示例底线为「付款、对外发消息之前，一定先问我」。 | 记忆 |
| F-018 | 档案整理提示词要求：每条偏好写成一句清楚的规则并给一个例子；常做的事写成「我说什么 → 希望它怎么做」；底线单独列出；不加入用户未提到的信息；地址和手机号先不写。 | 记忆 |
| F-019 | 档案生成后先逐条读一遍，不认同的直接改，确认无误后再存进记忆。 | 记忆 |
| F-020 | 存法一（手动）：在手机上给每条前面加「记住：」再发送，等它回复已记住后再发下一条。 | 记忆 |
| F-021 | 存法二（自动）：先连通电脑与手机，再对 TRAE 说一句话，整份档案一次放进手机。 | 记忆 |
| F-022 | 课程把 adb 比作电脑与手机之间的一座「桥」；adb 命令由 TRAE 运行，不需要用户自己敲。 | 工具 |
| F-023 | 连通三步：电脑装好 adb；手机打开 USB 调试（设置 → 关于手机，连点「版本号」7 次，再进开发者选项打开「USB 调试」）；插上能传数据的线并在手机上点「允许」。 | 工具 |
| F-024 | adb devices -l 的判读：末尾显示 device 表示桥已搭好；unauthorized 表示手机上未点允许；offline 表示连接不稳需换线重插；一台设备都没有则多为 USB 调试未打开。 | 工具 |
| F-025 | Wi-Fi 方案：手机与电脑连同一 Wi-Fi，在开发者选项打开「无线调试」（Android 11 及以上），点「使用配对码配对设备」，把 IP、端口与配对码告诉 TRAE；手机重启或换 Wi-Fi 后需重新告知；课堂优先用数据线。 | 工具 |
| F-026 | 自动存档提示词含四步：先运行 adb devices -l 确认 device；按 docs/ARCHITECTURE.md「记忆」一节的格式写成 memory/profile.md；用 adb push 放到手机的 /sdcard/Android/data/dev.xiaoman.app/files/memory/profile.md；再用 adb shell ls 确认。手机里已有记忆不要删、不要覆盖。 | 记忆 |
| F-027 | 存档后验收：打开 App 底部「记忆」能看到「个人档案」；没看到就退出记忆页再进；仍没有则把 TRAE 的回复原样发回查原因。 | 记忆 |
| F-028 | 档案后续改动：对 TRAE 说「把改好的档案再推到手机」。 | 记忆 |
| F-029 | 验证三句：先发「记住：买东西先看评价，预算宁低勿高。」，再发「帮我挑个耳机。」，最后发「今天帮朋友买，预算放宽到 200。」 | 验证 |
| F-030 | 三句的期望：第一句后记忆页多一条；第二句未重复要求也先看评价、按偏低预算挑；第三句按 200 元挑且原偏好仍在。 | 验证 |
| F-031 | 三句都对上说明助理记住了用户且能区分长期偏好与当次要求；没对上则把回复原样贴给 TRAE，让它改写档案对应条目再重新告知。 | 验证 |

## 五、五个场景

| 编号 | 事实 | 类别 |
|------|------|------|
| F-047 | 场景一目标：早上要做的事散在各处，让助理排一份最多 3 件的开工卡，用户同意后给第一件设提醒。 | 场景 |
| F-048 | 场景一试跑指令：「我今天要做：交实验报告（今晚 12 点截止）、回导师邮件、买牛奶、复习英语 30 分钟。帮我排一下。」 | 场景 |
| F-049 | 场景一技能 today-plan 的规则：按「今天不做会卡住谁」和截止时间排序，最多挑 3 件写成开工卡，其余放进「可以先放放」；不确定截止时间的先问、不要猜；最后问是否给第一件设提醒，同意才设并告知时间；不替用户发消息、不替用户付款。 | 场景 |
| F-050 | 场景一验收三点：开工卡最多 3 件；按上述规则排序且其余进「可以先放放」；未写截止时间的事会先问；最终顺序由用户决定。 | 场景 |
| F-051 | 场景一提醒的限制：只响一次，不保证准点，可能晚一点。 | 场景 |
| F-052 | 场景二目标：久坐易忘活动与喝水，让助理按用户作息挑空档，直接在系统时钟里设好闹钟。 | 场景 |
| F-053 | 场景二试跑指令：「帮我在今天下午 3 点、4 点、5 点各设一个闹钟，标签写『起来活动，喝水』。设好后打开闹钟列表给我看。」 | 场景 |
| F-054 | 场景二技能 health-alarms 的规则：参考 set-alarm，用内置链接 xiaoman://alarm/set 打开预填好的新建闹钟页，不要拨滚轮；按记忆里的作息挑空档；标签写清做什么；设之前把时间列给用户确认；设完打开闹钟列表逐条核对，少了告知；不删除、不修改原有闹钟。 | 场景 |
| F-055 | 场景二前置：记忆里还没有作息时，先在手机上记一条，例如「记住：我工作日上午 9 点到 12 点上课，下午 2 点到 3 点开会。」 | 场景 |
| F-056 | 场景二补充：推送后若今天的空档已过，助理会先问改到哪天、几点。 | 场景 |
| F-057 | 场景二验收：时间与标签正确；原有闹钟未被修改或删除、开关状态未变；不同品牌时钟界面不同，以手机上的列表为准；练完删除练习闹钟。 | 场景 |
| F-058 | 场景三目标：比较当天淘宝搜索结果里的前几家，先做最基本的一步。 | 场景 |
| F-059 | 场景三试跑指令：「在淘宝搜『得力 A5 笔记本』，比较前 3 家的价格、销量和店铺，告诉我哪家最便宜。打开那家的商品页，不要加购，不要下单。」 | 场景 |
| F-060 | 场景三技能 taobao-compare 的规则：比较前 3 个商品的到手价、销量与店铺名；有券后价按券后价比；看不清的写「页面未显示」、不要猜；结果用表格回复；再打开最便宜那家的商品页；不加购、不下单、不领需要付费的券。 | 场景 |
| F-061 | 场景三验收：前 3 个商品的价格、销量、店铺名齐全；看不清写「页面未显示」；不足 3 个如实说明；最终停在最便宜那家的商品页；停在商品页只能算找到，不能说成已买到。 | 场景 |
| F-062 | 场景三前置：淘宝的登录与滑块验证由用户本人完成。 | 安全 |
| F-063 | 场景三排错案例：某次回复没有店铺名、也没排成表格；做法是把截图、运行 ID 与执行轨迹交给 TRAE；技能部分 lint、push 后立即生效；表格显示改在 App 程序里，需重新构建并安装 APK 才生效。 | 排障 |
| F-064 | 场景四目标：按备考方向出题，答错的题存进记忆，之后再复习。 | 场景 |
| F-065 | 场景四前置：「记住：我在备考 NSCA 体能教练证，重点是训练计划设计和营养，题目用中文。」 | 场景 |
| F-066 | 场景四技能 daily-quiz 的规则：说「出题」时先读记忆里的备考方向，出 3 道单选题、每题 4 个选项，先不给答案；用户答完再逐题讲解；答错把题目、正确答案与一句解析写进记忆，标题以「错题：」开头；说「复习错题」时从记忆取出重考；不确定的知识点说明「建议对照教材核实」、不编造出处。 | 场景 |
| F-067 | 场景四验收：3 道中文单选、每题 4 选项、答前不给答案、答后逐题讲解；故意答错后记忆页出现「错题：」条目；说「复习错题」会重考；不确定处提示核对教材；练习题本身也要对照教材核一遍。 | 场景 |
| F-068 | 场景四不操作其他 App，只在对话里完成。 | 场景 |
| F-069 | 场景五目标：只挑与用户相关的几条资讯，每条说明为什么相关并附来源。 | 场景 |
