# Insights - code-your-own-llm

> I阶段架构洞察，基于 facts.md 提炼。

## 洞察一：文档即产品——格式规范与代码实现同等重要

**陈述**：code-your-own-llm 将"第零章 格式模板和规范指南"作为 AGENTS.md 置于项目根目录，意味着该项目的核心交付物不仅是代码，更是一套严格遵循排版规范的教学文档。规范覆盖了从标题层级、中英文混排、图像表格编号，到 Google Python Style Guide 代码风格、LaTeX 数学公式排版、APA 参考文献格式的全部细节。

**证据**：
- F-006：AGENTS.md 实际为"第零章 格式模板和规范指南"
- F-007~F-013：规范涵盖结构、内容、图像、表格、代码、公式、参考文献七大维度
- F-002：项目定位为"全栈式参考指南"，五个维度中"原理解读"排在首位

**反常识**：通常开源项目将代码风格指南放在 CONTRIBUTING.md 或 docs/ 深处，而本项目将其提升为"第零章"并命名为 AGENTS.md，暗示文档质量本身就是项目成熟度的核心指标，而非附属品。这与 Datawhale 作为开源学习社区的定位一致——学习者首先阅读的是文档，代码是文档的配套实现。

**行动**：学习本项目时，应先阅读 AGENTS.md 理解文档约定，再按章节顺序学习；为项目贡献内容时，必须严格遵循七大维度规范，尤其是代码的类型注解和 docstring 要求。

## 洞察二：全栈式 LLM 学习路径——覆盖从数据到安全的完整生命周期

**陈述**：项目设计了 12 章+附录的完整学习路径，按 LLM 生命周期顺序排列：环境配置→数据→分词→模型架构→预训练→中期训练→SFT→强化学习→推理→评估→安全，而非零散的知识点集合。这种编排让学习者能够端到端地理解"定义一个大语言模型"所需的全部环节。

**证据**：
- F-004：12章结构完整覆盖 LLM 训练到部署全流程
- F-002：明确强调"从零训练到工程落地的整套流程"和"端到端定义大语言模型的每一个细节"
- F-005：站在 nanochat、nanoGPT、transformers、pytorch、llms-from-scratch 五个项目的肩膀上

**反常识**：多数 LLM 教程聚焦于模型架构（Transformer）和微调（SFT/RLHF），对中期训练（Midtrain）、模型安全与红队测试、评估体系等环节着墨较少。本项目将这些"非主流但工程必需"的环节独立成章（第7、11、12章），体现了"全栈"而非"算法精选"的教学理念。

**行动**：按章节顺序系统学习，不要跳过"数据""中期训练""评估""安全"等常被忽视的章节；已完成章节（1、2、3、5、8、9）可立即学习，在建章节（4、6、7、10、11、12）可持续关注项目更新。
