# 示例索引

本项目当前为 Alpha 内测版，核心代码和示例随各章文档逐步发布。

## 示例来源

项目的代码示例内嵌于各章节文档中，遵循以下原则：

- 代码块不超过 50 行，超长代码只展示关键部分
- 完整代码存放在项目的 `code/` 目录下
- 所有代码遵循 Google Python Style Guide
- 函数包含完整 docstring 和类型注解

## 推荐阅读

由于本项目源码尚未完全开放，建议通过以下方式获取代码示例：

1. 阅读 [第5章 模型架构](https://datawhalechina.github.io/code-your-own-llm/) 中的从零实现代码
2. 参考上游项目 [nanochat](https://github.com/karpathy/nanochat) 和 [nanoGPT](https://github.com/karpathy/nanoGPT) 的代码示例
3. 关注项目 GitHub 仓库的更新动态
