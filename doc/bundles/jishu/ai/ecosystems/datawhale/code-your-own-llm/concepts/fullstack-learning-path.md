# 全栈式 LLM 学习路径

code-your-own-llm 的核心价值在于提供了一条**端到端的大语言模型学习路径**。与多数只聚焦 Transformer 架构和微调技术的教程不同，该项目将 LLM 的完整生命周期拆解为 12 个章节，按"从数据到部署"的工程顺序排列。

## 章节编排逻辑

学习路径遵循 LLM 实际研发流程：

1. **引言与环境**（第1-2章）：项目概述、学习建议、开发环境搭建
2. **数据准备**（第3章）：数据采集、清洗及质量评估
3. **分词处理**（第4章）：分词算法原理与词表构建
4. **模型构建**（第5章）：从零实现模型核心架构
5. **训练阶段**（第6-7章）：大规模预训练、领域适应与持续学习
6. **对齐微调**（第8-9章）：有监督微调（SFT）、强化学习与偏好对齐
7. **推理部署**（第10章）：高效推理与量化加速
8. **评估与安全**（第11-12章）：评估指标体系、安全对齐与红队测试
9. **附录**：数学基础与前沿论文解读

## 设计特点

### 生命周期完整性

路径覆盖了工业界 LLM 研发的全部关键环节，尤其是独立设置了常被教程忽视的章节：

- **第7章 中期训练（Midtrain）**：领域适应与持续学习，介于预训练和微调之间
- **第11章 模型评估**：系统化的评估指标体系与基准测试方法
- **第12章 模型安全与红队测试**：安全对齐实践与红队测试方法论

### 代码极简主义

项目强调"最简洁的代码实现"，采用：

- 极致扁平化结构，无复杂封装和层层继承
- 零层级嵌套，降低阅读门槛
- 极简项目依赖，减少环境配置负担

这一设计继承自 Karpathy 的 nanochat/nanoGPT 哲学——用最少的代码暴露核心原理。

## 五个覆盖维度

每个章节的内容都从以下五个维度展开：

| 维度 | 关注点 |
|------|--------|
| 原理解读 | 算法背后的数学原理与设计动机 |
| 工程实现 | 可运行的简洁代码实现 |
| 实践指导 | 复现教程与调参建议 |
| 优化分析 | 前沿优化技术与性能对比 |
| 可视化展示 | 交互式可视化辅助理解 |

## 当前完成状态

截至 Alpha 内测版，6 章已完成（引言、环境、数据、架构、SFT、强化学习），7 个部分在建中。建议学习者从已完成章节入手，同时关注在建章节的更新动态。
