# 秒悟 Meoo 平台总览：一句话到上线的产品形态

> 本篇是全束的导航起点。先建立产品全貌，再沿「怎么构建」（[01](01-agent-modes.md)–[05](05-visual-editing.md)）、「平台服务」（[06](06-cloud-services.md)–[10](10-root-file-seo-geo.md)）、「扩展生态」（[11](11-skills-authoring.md)–[13](13-connectors.md)）三条线展开。

## 1. 它是什么

按官方主页定义，秒悟 Meoo 是一款**云端 AI 开发工具**，自我比喻为「会编程、懂设计、自部署的全能 AI 伙伴」（F-002，厂商自述）。三句话概括它承诺的使用方式（F-003）：

1. 无需搭建本地环境；
2. 无需单独采购服务器资源；
3. 无需编写代码——用日常语言描述需求即可。

需求示例也是「大白话」级别的：做一个员工考勤系统、上线一个电商网页、生成一个产品介绍页（F-003）。产品入口是 `https://meoo.com/`（F-009）。

## 2. 它交付什么：四项自动完成

从一句需求到可分享的产品，官方把交付物拆成四块（F-004）：

| 交付物 | 官方表述 | 后续概念页 |
|---|---|---|
| 前端 UI 界面 | 精美的前端 UI 界面（网页/移动端） | [03](03-web-app-build.md)、[05](05-visual-editing.md) |
| 后端逻辑 | 完整的后端逻辑（服务器） | [06 云服务](06-cloud-services.md) |
| 数据库 | 数据库搭建（数据存储） | [06 云服务](06-cloud-services.md) |
| 部署上线 | 一键部署上线，发布即可分享 | [03](03-web-app-build.md)、[04 小程序](04-wechat-miniprogram.md) |

总括话术是「你说，它做。从一个想法到能用的产品，全程像聊天一样简单。」（F-005，厂商自述）

## 3. 五个核心亮点（含可信度标注）

主页列出五个亮点（F-006），阅读时要区分**宣传语**与**后续页面有功能事实支撑的部分**：

| 亮点 | 营销表述 | 功能事实出处 |
|---|---|---|
| ⚡️ 极速应用构建 | 「分钟级」交付第一个落地想法 | 无 SLA 承诺，仅厂商自述 |
| 💬 自然语言驱动 | 像聊天一样描述需求，AI 转成代码 | [03 四阶段流程](03-web-app-build.md)（F-032–F-037） |
| ⚙️ 全栈能力构建 | 自动创建前端、后端、数据库完整应用 | [06 云服务](06-cloud-services.md)（F-065–F-067） |
| ☁️ 一键云端部署 | 无需服务器配置，点击发布、全球可访问 | 发布出链接（F-045）；CLI 部署见姊妹束 |
| 🤝 团队协作 | 邀请成员共同编辑、版本管理 | 多人实时协作（F-031）；协作专页本束未覆盖 |

> 洞察（证据分级型）：营销页的每个「亮点」在后栏功能页都能找到对应机制，但「分钟级」「全球可访问」这类性能与覆盖承诺没有任何量化条款支撑。读厂商文档时应自动把主张拆成「可逐页回溯的机制」与「无法核验的形容词」两层——本束所有概念页都按此规则挂 F 编号。

## 4. 为谁而来：四类人群

主页给出四类目标人群与各自的典型场景（F-007）：

| 人群 | 官方痛点话术 | 场景示例（官方） |
|---|---|---|
| 创业者/独立开发者 | 预算有限、时间宝贵，要快速验证市场 | 一句话生成带登录页和后台管理的原型，当天发给潜在用户收集反馈 |
| 业务人员 | 营销活动等不及开发 | 节日促销 H5 活动页，几分钟生成上线、发群里看转化 |
| 设计师/内容创作者 | 设计稿无法 100% 还原、不会代码 | 作品集/文字描述生成可交互作品集网站 |
| 中小企业/传统行业管理者 | 想数字化转型但不懂技术、预算有限 | 水果选购页：在线选水果、预约自提、带商品展示和购物车 |

## 5. 能做什么：六类应用

主页列举的六类可交付（F-008），也是后续功能页的应用边界：

1. **产品落地页（Landing Page）**：快速生成、测试市场反响；
2. **内部管理系统**：CRM、OA、员工考勤、库存管理；
3. **电商/服务页**：在线预订、社区团购、内容付费；
4. **互动营销游戏（H5）**：抽奖、答题、投票等活动页面；
5. **个人/企业官网**：作品集、博客、品牌展示站点；
6. **AI 智能应用**：集成 AI 能力的剧本杀、智能客服等——对应平台内置的 [07 AI 服务](07-ai-service.md)。

两条交付通道：网页应用（web 与 H5 双端适配，F-033）与微信小程序（[04](04-wechat-miniprogram.md)）。注意一条官方合并声明：**原首页的 H5 构建能力已合并至网页应用**（F-047），H5 不再是独立入口。

## 6. 坑点与边界

- **营销语不是承诺**：「分钟级」「成本趋近于零」「像素级还原」均为主页厂商自述（F-001–F-006），没有价格页与 SLA 页背书；套餐与积分的实际规则在 `docs.meoo.com/pricing`（本束未抓取，F-010），不要据主页话术做成本测算。
- **「无需编写代码」有边界**：平台同时提供代码下载（限套餐，F-110）、代码图标直接改源码（F-061）、CLI 与全栈自定义部署（见姊妹束 [miaowu-cli-open-guide](../../miaowu-cli-open-guide/index.md)）——复杂项目终究会触达代码层。
- **「全栈」是有条件的**：不开云服务时应用只是纯前端「展示页」，登录、存数据、上传、多人更新都做不了（F-066）。
- **微信生态有平台主权**：小程序账号、审核、备案都在微信侧，Meoo 只是第三方服务商（F-048，详见 [04](04-wechat-miniprogram.md)）。
