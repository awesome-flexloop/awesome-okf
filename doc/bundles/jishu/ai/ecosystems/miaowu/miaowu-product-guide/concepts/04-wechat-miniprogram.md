# 微信小程序构建与发布：七步流程与三方权责

> 该能力面向已有业务想法、活动需求、商品服务或内部工具，想尽快做成微信小程序的个人、商家和团队：不需要学习小程序工程结构，也不需要本地开发环境（F-046）。
>
> 理解本页最重要的一句话：**Meoo 帮你跑顺「开发和发布链路」，但小程序账号属于你，审核规则属于微信**（F-048）。

## 1. 平台角色边界（先读）

发布阶段，秒悟以**微信第三方服务商**身份接入你的授权账号，代做四件事：代码上传、体验版生成、提交审核、版本发布（F-048）。但三条主权不变：

1. 小程序账号仍然属于你；
2. 微信审核和平台规则由微信小程序平台执行；
3. 平台给的风险提醒「仅出于 Meoo 侧的构建经验，最终是否通过仍以小程序平台的说明为准」（F-049 步骤二）。

另外注意：**原首页的 H5 构建能力已合并至网页应用**（F-047）；要做 H5/网页走 [03 网页应用主线](03-web-app-build.md)。

## 2. 七步完整流程

| 步骤 | 你做什么 | 平台/微信做什么 |
|---|---|---|
| ① 创建小程序项目 | Meoo 首页选「小程序」类型，输入项目名称和初始需求（可粗到「做一个活动报名小程序」） | 准备代码生成、预览和后续发布所需环境（F-049） |
| ② 通过对话生成和修改 | 像和产品同事沟通一样描述页面、功能、样式、业务规则（如「增加购物车」「首页改成双列商品瀑布流」） | 生成小程序代码、支持追问修改；出现服务类目/隐私/内容安全/包体积风险时尽量提前提醒（F-049） |
| ③ 绑定自己的微信小程序账号 | 在微信公众平台注册小程序账号（参考[小程序接入指南](https://developers.weixin.qq.com/miniprogram/introduction/)），注册主体、邮箱、管理员、主体类型、主体校验均在微信侧填写；按页面引导完成授权 | 授权后才能以第三方服务商身份上传代码、生成体验版、提审、发布（F-049） |
| ④ 预览确认 | 先用 H5 快速预览边聊边改，再扫码微信真机预览，**以真机预览结果作为最终确认依据** | H5 预览在 Meoo PC 端直接查看；真机预览由平台构建体验版二维码（F-050） |
| ⑤ 完成小程序备案 | 在微信侧提交主体信息、负责人信息、证件材料、前置审批或其他补充材料，并保证真实有效 | 平台发布前检查备案状态，不满足则提示去微信侧处理（F-051） |
| ⑥ 提交微信审核 | 在平台填写版本说明、功能说明、测试账号等审核信息 | 平台把代码包提交微信；微信按服务类目、页面内容、功能完整性、隐私保护、资质材料、平台规范审核；平台同步状态，驳回时展示微信返回原因并辅助定位（F-052） |
| ⑦ 正式发布上线 | 审核通过后在平台点击发布 | 小程序进入正式可访问状态，微信用户可在微信内搜索、扫码、分享或通过其他入口访问（F-053） |

后续迭代通常再走一轮「生成新版本 → 预览确认 → 提交审核 → 发布上线」（F-053）。

### 两类预览怎么分工

- **H5 快速预览**：Meoo PC 端直接看页面结构、视觉效果和基础交互，快，适合边聊边改；
- **微信真机预览**：微信扫码、真实微信环境，更接近正式运行环境；
- 源页建议：提交审核前以真机预览为准；二者不一致时 FAQ 同样答复「以微信真机预览为准」（F-050、F-058）。

## 3. 微信登录配置（新能力）

开启入口（逐字，F-054）：

```text
进入项目 →「云服务」→「登录认证」→ 配置个人 APPID 和 SECRET 信息
```

配置后 AI 自动配置微信登录功能。认证底座属于云服务能力（GoTrue，见 [06 云服务](06-cloud-services.md) F-072）；APPID/SECRET 在微信公众平台获取（微信侧具体操作源页未展开）。

## 4. 三方权责关系表（10 行）

源页用 10 个事项划分你、Meoo、微信平台三方的责任（F-055）：

| 事项 | 你（用户/小程序主体） | Meoo 侧 | 微信小程序平台 |
|---|---|---|---|
| 小程序账号注册 | 注册账号、选择主体、设置管理员 | 提供绑定入口和操作指引 | 提供账号体系和注册入口 |
| 主体资质与认证 | 提交真实资质、承担主体责任 | 提醒缺失项，不替代资质审核 | 审核主体、认证和平台权限 |
| 小程序备案 | 提交备案材料并保证准确 | 检查备案状态、提示去微信侧处理 | 提供备案入口和备案规则 |
| 需求描述与内容 | 确认业务内容、商品服务和页面文案 | 根据描述生成页面、功能和代码 | 按平台规则审核线上内容 |
| 代码生成与构建 | 确认生成结果是否符合预期 | 负责 AI 生成、构建、预览和代码上传 | 提供小程序运行与上传审核通道 |
| 账号授权 | 授权自己的小程序给平台代开发 | 以第三方服务商身份接入授权能力 | 提供第三方平台授权机制 |
| 服务类目 | 选择匹配实际业务的类目并补齐资质 | 发布前提示类目和资质风险 | 维护类目范围和审核要求 |
| 隐私与用户数据 | 对用户数据的收集、使用和保护负责 | 提供隐私配置提示和技术实现辅助 | 审核隐私保护指引和数据合规要求 |
| 审核和发布 | 确认提交，处理驳回后的修改 | 代提交、同步状态、辅助修复 | 作出审核结论并控制发布通道 |
| 线上运营 | 负责经营、客服、售后和违规处理 | 提供版本管理和问题排查辅助 | 监管平台秩序和违规处置 |

## 5. 五项关键配置

1. **小程序账号和主体**：个人与非个人主体开放的服务类目并不完全相同；交易、医疗、教育、金融、政务等场景通常有更严格资质要求。参考[小程序开放的服务类目](https://developers.weixin.qq.com/miniprogram/product/material.html)（F-056）。
2. **小程序信息**：名称、头像、简介、服务类目、隐私保护指引发布前需完善；名称和简介影响用户识别，也影响审核时对功能与类目的判断；展示内容、实际服务、所选类目要一致（F-056）。
3. **服务器域名和业务域名**：小程序访问后端服务、图片、文件上传下载需满足微信的域名和 HTTPS 要求；平台侧服务域名尽量自动处理；自有后端、支付、客服、地图、物流等第三方能力可能还需在微信侧补充域名配置（F-056）。
4. **隐私保护指引**：收集手机号、地理位置、头像昵称、订单信息、表单信息、文件、相册等用户数据时，需在微信侧配置隐私保护指引，并确保实际收集行为与指引一致；平台可帮助生成配置建议，但数据使用需由你确认（F-056）。
5. **微信认证、微信支付和开放平台绑定**：某些能力要求完成微信认证；收款交易需申请微信支付商户号，按要求配置商户信息、结算账户和交易规则；要与 App、公众号等打通用户身份，可能需绑定微信开放平台账号（F-056）。官方入口：[微信支付](https://pay.weixin.qq.com/doc/v3/merchant/4012062524)、[微信开放平台](https://developers.weixin.qq.com/doc/oplatform/open/intro.html)。

## 6. 提交审核前检查清单（7 项）

源页给出的提交前自查（F-057）：

- [ ] 小程序账号已注册，主体信息真实有效；
- [ ] 已完成必要备案，或已按微信提示进入可提交状态；
- [ ] 名称、头像、简介、服务类目、隐私保护指引已完善；
- [ ] 真机预览可正常打开，主要页面、按钮、表单、跳转和接口请求可用；
- [ ] 页面内容与服务类目一致，没有未完成页面、测试文案、占位图或无法使用的入口；
- [ ] 涉及游戏、登录、交易、预约、内容发布、会员、抽奖、医疗、教育、金融等功能的，已补齐对应资质、协议、测试账号和审核说明；
- [ ] 使用微信支付、订阅消息、位置、相册、手机号等能力的，已完成对应权限、模板或隐私配置。

## 7. FAQ 六条速查

| 问题 | 官方答复要点 |
|---|---|
| 平台可以替我注册微信小程序账号吗？ | 不可以。需自行在微信公众平台注册并确认主体信息；授权后平台以第三方服务商身份协助开发、上传、提审、发布（F-058） |
| 授权后小程序归谁？ | 仍归你的账号主体所有；授权只允许平台在授权范围内代开发/代上传/提审/发布；可按微信规则管理或取消授权（F-058） |
| 平台能保证审核通过吗？ | 不能保证。生成和提交前尽量提示风险、驳回后辅助修改；审核结论由微信平台依据规则作出（F-058） |
| H5 预览和真机预览不一致？ | 以微信真机预览为准；H5 用于快速迭代（F-058） |
| 上线后还能继续修改吗？ | 可以；修改后生成新版本，通常需再次预览、提审，通过后再发布（F-058） |
| 需要懂代码吗？ | 不需要，对话描述即可；复杂业务、外部系统接入、特殊资质类目或深度定制可能需要更细的需求描述、测试账号或人工确认（F-058） |

## 8. 坑点与边界

- **别把第三方服务商当账号主体**：注册、主体资质、备案材料、客服售后全在你这一列（F-055）；Meoo 不替你注册账号、不保证过审（F-058）。
- **备案是发布前置条件**：平台会在发布前检查备案状态，不满足会被挡下（F-051）；备案规则以微信最新说明为准，源页明确政策可能调整。
- **驳回修改要闭环**：平台展示微信返回原因并辅助定位代码/内容/配置（F-052），但修改后仍需重新走预览→提审→发布（F-053）。
- **域名与 HTTPS 是微信硬要求**：自有后端和第三方能力的域名配置可能要在微信侧补做（F-056），别只配 Meoo 平台侧。
- **隐私收集必须言行一致**：指引里写了什么收集项，实际才能收什么（F-056）。
- **源页信息边界**：备案材料明细、审核时限、类目全表、APPID/SECRET 的微信侧获取步骤均在微信官方站，本束不抓取不脑补；四篇微信官方链接见 F-059。
