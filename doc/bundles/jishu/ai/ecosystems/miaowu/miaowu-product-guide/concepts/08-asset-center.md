# 素材中心：图片/视频/音频的生成与资产管理

> 秒悟素材中心提供**从素材生成到资产管理的一站式能力**：在首页通过自然语言或参数化方式生成图片、视频、音频；在素材中心统一查看、筛选、收藏、下载和再次引用历史素材（F-088）。

## 1. 心智模型：一条链路，两个落点

```text
「素材制作」Tab（生产侧）          左侧边栏「素材」（资产侧）
  对话生成 ──────────────→ 自动落库 ──→ 卡片墙/筛选/收藏夹/详情
        ↑                                    │
        └────────── 拖拽引用 / 分享链接 / 做同款 ──┘
```

生成完成后自动落库（F-103）；历史素材又能拖回输入框继续生成（F-104），形成「生成 → 管理 → 再引用」闭环。

## 2. 入口与发起

### 2.1 进入素材生成链路

打开秒悟首页，点击顶部平台切换栏中的**「素材制作」Tab**；该 Tab 专用于图片、视频、音频等素材类内容的生成（F-089）。平台切换栏默认展示常用创作模式，不要去应用构建区找素材生成入口。

### 2.2 在对话里用已有素材

两种方式（F-090）：

1. 对话输入框**加号 →「从素材库中添加」**；
2. **复制素材分享链接**直接使用。

### 2.3 发起生成的三种方式

| 方式 | 说明 |
|---|---|
| **直接描述** | 自然语言描述想要的图片/视频/音频，Agent 自动选择合适模型 |
| **灵感卡片** | 点输入框上方卡片，一键套用示例提示词 |
| **拖拽参考** | 本地文件拖入输入框，作为参考素材继续生成 |

点击发送后，系统创建**新的素材会话**并跳转到对话页（F-091）。

## 3. 两种模式：Agent 还是直连

这是素材生产侧最重要的选型，与 [01 构建器 Agent 模式](01-agent-modes.md)同名但作用于素材会话：

| | Agent 模式（默认） | 直连模式 |
|---|---|---|
| 进入状态 | 进对话页默认就是（F-092） | 底部工具栏点当前模式（默认显示「Agent模式」）下拉切换（F-093） |
| 交互 | 自然语言，AI 自动拆任务、选工具 | 直接指定「图片生成/视频生成/音频生成」类别和参数 |
| 适合 | 需求不明确、需要多轮调整（F-092） | 已明确要生成什么类型，减少对话轮次（F-093） |
| 计费可见性 | 对话推进 | 发送按钮旁显示**预计消耗积分**（F-094） |

官方 Agent 模式示例（逐字，F-092）：

> - 「帮我生成一张夏日海滩的产品背景图，画面明亮、右侧留白放文案。」
> - 「把这张参考图转成 3 秒的动态视频，镜头缓慢推进。」

### 积分预估的两种显示（F-094）

- 总价可确定时：显示**总积分**；
- 歌曲、背景音等**按时长计费**的内容：显示**「积分/秒」**。

部分模式还有二级选项：图生视频、参考生视频、文本配音等。

## 4. 直连三类生成

### 4.1 图片

可设置参数：**比例、风格、模型**等（F-095）。具体可选项以产品面板为准（源页参数明细在截图中，不脑补）。

### 4.2 视频：两个二级玩法

| 玩法 | 所需输入 | 适用场景 |
|---|---|---|
| **全能参考** | 纯文本，或上传参考图/参考视频/参考音频/文件 | 用任意参考素材控制生成结果；**无参考时即文生视频** |
| **首尾帧** | 上传首帧图片（可选再传尾帧） | 让画面从首帧自然过渡到尾帧 |

上传参考素材后，「全能参考」会自动在文生视频与参考生视频之间切换（F-096）。

### 4.3 音频：三个子模式

| 子模式 | 说明 | 典型用途 |
|---|---|---|
| **文字朗读** | 输入文字，选音色、语速生成语音 | 旁白、解说、播报 |
| **歌曲生成** | 输入歌词或风格描述，生成带人声的歌曲 | 主题歌、广告歌 |
| **背景音生成** | 输入风格描述，生成纯器乐背景音 | BGM、氛围音（F-097） |

> 直连模式在首页「素材制作」**和**素材中心底部输入框中均可使用，界面不同但能力一致（F-098）。

> 洞察（交互型）：Agent/直连双模在素材侧复现了 [01 构建器模式](01-agent-modes.md) 的同一个设计母题——**模糊期交给对话，确定期交给参数面板**。但素材侧多了一个直连专属信号：**积分预估**（F-094）。多模态生成按秒/按张计费（对照 [07 AI 服务](07-ai-service.md) F-077 的两档计费），成本在发送前就可见，使直连不只是「更快」，也是「可预算」的模式。

## 5. 素材中心管理

### 5.1 进入与形态

左侧边栏点**「素材」**进入；所有素材以**卡片形式平铺**（F-099）。

### 5.2 两类筛选

**来源筛选**（F-100）：

| 选项 | 范围 |
|---|---|
| 全部 | 所有素材 |
| AI生成 | 仅 AI 生成 |
| 我的上传 | 仅本地上传 |
| 最近删除 | 回收站，**保留 30 天** |

**类型筛选**：全部模态 / 图片 / 视频 / 音频。

### 5.3 收藏夹

- 新建 / 重命名 / 删除收藏夹；
- 素材移入或移出收藏夹；
- **整夹拖拽引用到输入框**；
- ⚠️ 删除收藏夹只移除分组，**夹内素材仍保留在素材库中**（F-101）。

### 5.4 素材详情

点任意卡片进入详情页（F-102）：

- 大图 / 视频 / 音频预览；
- **生成参数、模型、提示词**——这是复现一条素材的完整配方；
- 「做同款」「去生成」快捷操作；
- 分享、下载、删除。

### 5.5 生成中任务与单卡操作

- 提交任务后中心展示生成中占位，点击看实时进度，完成后自动落库（F-103）；
- 单卡片：鼠标悬停显示操作按钮，支持拖动（到文件夹或输入框参考）、加入收藏夹、删除（F-104）。

### 5.6 批量操作

批量选择模式下可勾选多个素材或收藏夹，统一：**移入收藏夹、下载、删除、去生成**（F-104）。

## 6. 常用链路速查（源页原表）

| 目标 | 操作路径 |
|---|---|
| 快速生成一张图 | 首页 → 素材制作 Tab → 输入描述 → 发送 |
| 精确控制视频生成 | 进入会话 → 工具栏切「视频生成」→ 选择子模式 → 填写参数 → 生成 |
| 管理历史素材 | 左侧边栏「素材」→ 筛选 / 搜索 / 收藏夹 |
| 用已有素材做同款 | 素材中心 → 点击素材 → 详情页「做同款」 |
| 把素材作为参考继续生成 | 拖拽素材到底部输入框 → 补充提示词 → 发送（F-105） |

## 7. 坑点与边界

- **「素材制作」是独立 Tab**：它与「网页应用/小程序」平级（F-089），素材生成不是某个应用内部的功能；生成产物再通过素材库/链接/CDN 进入应用（对照 [07 视觉理解](07-ai-service.md) 的图片 URL 入参、[09 存储桶 CDN](09-file-storage.md)）。
- **删收藏夹 ≠ 删素材**（F-101）：清理分组前不用担心误删资产；真正要删素材走卡片删除 + 30 天回收站（F-100）。
- **按时长计费看「积分/秒」**（F-094）：歌曲和背景音的成本随时长线性增长，发送前用预估核算。
- **「做同款」依赖配方留存**：详情页的参数/模型/提示词（F-102）是官方提供的复现路径；模型或参数若下线，同款结果可能变化，源页未承诺长期可复现。
- **源页截图边界**：Tab 外观、加号菜单位置、图片参数面板明细、卡片墙布局全部在截图中（源页含十余张操作截图），本束只转写文字层，不脑补界面。
- **与 [07 AI 服务](07-ai-service.md) 的关系**：素材中心是**产品化的多模态生成工作台**（面向人操作、按积分计费）；AI 服务是**应用内运行时 API**（面向代码调用、按 Token/张数计费），二者模型与计费口径不混用。
