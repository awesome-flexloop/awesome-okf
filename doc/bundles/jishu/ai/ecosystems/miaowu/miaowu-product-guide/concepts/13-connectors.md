# 连接器：外部 API 接入、连接生命周期与积分计费

> 侧边栏归属「功能特性 → 扩展能力」。连接器把**外部服务**接入秒悟，让你在对话和应用中使用外部工具、获取数据或完成操作（F-141）。如果说 [11 Skill](11-skills-authoring.md) 封装的是「知识和流程」，连接器封装的就是「外部系统的一个具体 API 工具」。

## 1. 使用前两条须知

### 1.1 计费：按工具价格消耗积分

调用连接器会按所使用工具的价格**消耗积分，部分工具免费**。具体费用以本次调用的工具为准——使用前在连接器详情页的**「价格与额度」**中查看各工具的调用价格和免费额度（F-142）。

这与 [07 AI 服务](07-ai-service.md) 的 Token/张数计费、[08 素材直连](08-asset-center.md) 的积分预估构成平台三类可计量成本，连接器的特点是**费率随工具而变、调用前在详情页可见**。

### 1.2 能力范围（dated ⚠️）

源页原话（F-143，逐字）：

> 「当前支持连接器接入外部 API 能力，后续将支持接入 MCP 等更多类型的连接器。」

即：成文时点（2026-10-18）连接器 = 外部 API 接入；**MCP 是规划中的后续能力，不是现有功能**，不要在方案里把 MCP 连接器当作已可用项引用。注意区分：构建器模型 GLM-5.2「支持 MCP 协议」是模型侧能力（F-028），与此处平台连接器规划不是一回事。

## 2. 安装连接器：本质是「建立一个连接」

关键概念：**连接器**（一类外部服务的适配器）与**连接**（一份带凭证、可被项目引用的具体实例）是两层。点击「安装连接器」的过程实际上就是使用/建立连接的过程（F-144）。

1. 进入**扩展市场**，切换到连接器；搜索或浏览目标连接器，打开详情查看：功能、使用说明、各工具维度说明、调用价格、免费额度；
2. 点**「安装连接器」**；
3. 针对每个连接填写便于识别的**连接名称**——**连接将被应用在各个项目之中**（账号级资源）；
4. 部分连接器需要**访问凭证**，按要求提示填写；
5. 点**「保存」**（F-144）。

> 洞察（架构型）：「安装连接器 = 建立连接、连接账号级共享」（F-144）解释了后面所有权限行为：凭证只填一次、各项目复用；解绑只断当前项目关联而不删连接（F-148）；删除连接才是账号级销毁，且必须先解除所有应用绑定（F-145）。这是典型的「连接资源（connection）→ 项目绑定（binding）」两层模型，与 [06 云服务 Secrets](06-cloud-services.md) 里密钥集中管理、项目引用的思路同源。

## 3. 账号级管理

安装完成后在 **设置 > 连接 > 连接器** 查看当前账号已安装的全部连接器，可按名称搜索或按使用状态筛选（F-145）。

管理连接的两个入口：连接器右侧 **··· > 管理连接**，或连接器详情页右上角**更多操作 > 管理连接**。可做（F-145）：

- 查看该连接器下的所有连接及**关联应用**；
- 编辑访问凭证；
- 删除不再需要的连接。

三条操作纪律（F-145）：

1. **删除连接前，必须先解除它与所有应用的绑定**；
2. 连接无法使用时，在这里检查和更新凭证；
3. 修改凭证时，留意正在使用该连接的应用——凭证是账号级的，一改影响所有关联项目。

## 4. 两种使用场景

| 场景 | 机制 | 源页示例（逐字） |
|---|---|---|
| **构建过程中使用** | 让 Agent 调用外部工具、查询资料、获取数据，辅助完成构建任务 | 「使用这个连接器查询数据，帮我整理成看板的展示方案。」 |
| **注入应用中使用** | 将连接器接入应用，让应用运行时使用外部服务 | 「把这个连接器接入应用，做一个支持搜索和筛选的数据看板。」 |

两场景同为 F-146。差别在于前者只服务构建期对话（数据进来辅助开发），后者成为应用的运行时依赖（最终用户间接调用）。

### 4.1 调用入口

- 连接器详情页点**「去使用」**，或在对话输入框中选择已安装连接器；有多个连接时选择本次要用的那一个；
- 也可在对话框**添加选项**中选择所需连接的已安装连接器，说明希望它完成什么；
- 秒悟根据需求使用相应工具；需要将连接器接入应用时，按对话提示点**「确认连接」**（F-147）。

### 4.2 项目内监控与解绑

在目标项目的 **Chat 页面右侧工作区顶部点「连接」**，打开连接器面板（F-148）：

- 点连接器名称展开 → 查看当前项目使用的连接及状态；
- 鼠标悬停连接器名称 → 查看当前项目的**调用次数和积分消耗**；
- 点连接右侧**解绑图标** → **解绑只解除当前项目与该连接的关联；账号下的连接仍保留，其他项目不受影响**。

### 4.3 积分消耗明细

从秒悟左下角进入 **设置 > 积分管理**，在**积分明细 > 消耗**中按时间范围和**「支出类型」**筛选连接器记录；团队账号可在**「历史记录」**中查看（F-149）。

## 5. 创建自己的连接器

可以把自己的 API 或所需外部服务注册成连接器，供 Agent 调用或注入应用使用——源页称这样「效果更加稳定」（F-150）。

入口：**连接市场右上角**或**设置 > 连接 > 连接器**中点**「注册连接器」**。流程：

1. 按页面提示填写基本信息；
2. 配置访问凭证方式；
3. 配置 API 工具并进行调试；
4. 完成测试后提交发布。

注册完成并测试通过后，即可通过自己注册的连接器创建连接，在与 Agent 对话中调用或注入构建的应用（F-150）。

## 6. 生命周期速查

```text
扩展市场 > 连接器          设置 > 连接 > 连接器（账号级台账）
  详情页看「价格与额度」  →   安装连接器 = 建连接（命名 + 凭证）
        │                          │
        ▼                          ├─ 管理连接：看关联应用 / 改凭证
 去使用 / 对话框选择                ├─ 删除连接：先解除所有应用绑定
        │                          └─ 凭证失效：此处检查更新（影响全部项目）
        ├─ 构建期：Agent 查数据
        └─ 注入应用：确认连接 → Chat 右侧「连接」面板
                                   ├─ 看状态/调用次数/积分消耗
                                   └─ 解绑（仅当前项目，连接保留）
  成本：设置 > 积分管理 > 积分明细 > 消耗（支出类型=连接器）
  没有合适的？注册连接器（基本信息 → 凭证方式 → API 工具调试 → 发布）
```

## 7. 坑点与边界

- **先看「价格与额度」再安装调用**（F-142）：不同工具费率不同，部分免费；注入应用后调用量来自最终用户，成本可能随使用量增长。
- **MCP 还不能用**（F-143，dated）：需要 MCP 类连接器前以产品最新公告为准。
- **改凭证是账号级变更**（F-145）：一个连接被多个项目引用时，更新凭证前要评估影响面。
- **删连接有前置条件**：必须先解除与所有应用的绑定（F-145）；只想让当前项目停用，用项目内解绑（F-148）而不是删除。
- **「解绑」与「删除」别混**：解绑是项目级动作、可逆（连接还在，可再绑定）；删除是账号级动作（F-148/F-145）。
- **成本监控有两处**：项目级实时看次数和消耗（F-148），账号级对账看积分明细（F-149）；注入应用上线后建议定期对账。
- **凭证存储未文档化**：源页只说安装时按提示填写访问凭证（F-144），未说明是否与 [06 Secrets](06-cloud-services.md) 同源；排查凭证问题统一走「设置 > 连接 > 连接器 > 管理连接」（F-145）。
- **源页截图边界**：扩展市场、凭证弹窗、确认连接、Chat 面板等界面均为截图承载，本束只转写文字路径。
