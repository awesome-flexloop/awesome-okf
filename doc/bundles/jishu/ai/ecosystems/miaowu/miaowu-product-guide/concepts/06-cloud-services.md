# 云服务：不开就是展示页的应用后台工具箱

> 云服务为应用提供后端支持（F-065）。它是对话式开发背后真正的「服务器 + 数据库 + 认证 + 存储」落点。本篇只讲云服务本身；其中两项能力各有专篇深化：文件存储细节见 [09](09-file-storage.md)，AI 能力见 [07 AI 服务](07-ai-service.md)。

## 1. 为什么必须理解它：一句话分水岭

> 开启云服务后，可以让应用支持登录、存数据、上传文件、多人更新；**不开启云服务时应用只是一个纯前端的展示页面，无法进行登录、存数据、上传等操作**（F-066）。

这是全束最重要的产品边界之一。对照 [00 平台总览](00-platform-overview.md) 主页宣传的「全栈能力构建」（F-006），「全栈」的实际门槛就是云服务开关：

| 你想要的 | 不开云服务 | 开启云服务 |
|---|---|---|
| 固定内容展示（官网/落地页） | ✅ | ✅ |
| 用户登录 | ❌ | ✅ |
| 数据持久存储 | ❌ | ✅ |
| 文件上传 | ❌ | ✅ |
| 多人实时更新同一份数据 | ❌ | ✅ |

## 2. 四大核心特性

1. **云端存储**：为应用提供云端数据库、文件存储和图片存储等后端支持，解决数据管理需求（F-067）；
2. **按需启用**：在应用内按需启用云服务，通过直观界面管理数据；可在云端进行文件管理、实时查看应用数据（F-068）；
3. **用户认证**：内置**登录认证**功能，支持多种认证方式，为应用提供用户身份验证能力（F-072）；
4. **数据库管理**：支持数据库的数据导入导出；支持 **CSV** 数据格式，便于数据分析和备份（F-069）。

## 3. 怎么开启与查看

- 开启入口：在项目里按需启用云服务（F-068）；对话式一键建库的话术是「**开启数据库，并且把前端与数据库链接**」（F-038，见 [03 阶段二](03-web-app-build.md)）。
- 数据查看：开启后通过云服务界面管理数据、实时查看应用数据（F-068）；表结构与记录的可视化管理界面细节主要在源页截图中，本束不脑补。

## 4. 各子能力速查

### 4.1 数据库

- 建库：对话一句话触发（F-038）；
- 数据管理：云端界面管理（F-068）；
- 导入导出：支持 CSV，定位是数据分析和备份（F-069）；
- 微信登录所需的用户表等由认证底座提供（见 4.3）。

### 4.2 文件管理与存储

- 文件管理界面支持**单个文件最大 50MB**（F-070）——注意这与对话框上传附件「单文件 5MB、最多 10 个」（F-108）是**两个不同语境**：

| 维度 | 对话框附件上传 | 云服务文件管理 |
|---|---|---|
| 场景 | 开发对话中给 AI 传参考材料 | 应用云存储中的文件管理 |
| 限额 | 单文件 5MB，最多 10 个（F-108） | 单个文件最大 50MB（F-070） |
| 详细规则 | [09 文件存储](09-file-storage.md) | 本条 |

> 洞察（语义消歧型）：同一个产品里出现 5MB 和 50MB 两个数字不是矛盾，而是「**对话通道**」与「**运行时存储通道**」两套容量设计。官方为两者之间还提供了桥接：项目文件 >5MB 时用存储桶 + CDN 四步法供小程序引用（F-115，见 [09](09-file-storage.md)）。读文档时先问「这个限额属于哪条通道」，能避免绝大多数数字打架。

- 10 种可上传格式与存储桶创建细节统一见 [09](09-file-storage.md) F-106–F-115。

### 4.3 登录认证

- 定位：内置功能，多种认证方式（F-072）；
- 技术底座：登录认证服务基于 **GoTrue** 框架实现，提供用户注册、登录、身份验证等完整认证服务（F-072）；
- 微信登录：在「云服务 → 登录认证」配置个人 APPID 和 SECRET（F-054，见 [04 微信小程序](04-wechat-miniprogram.md)）。

### 4.4 Secrets（环境变量管理）

- 定位：云服务面板中的**密钥（Secret/环境变量）**管理能力——对接第三方服务的 API Key 不写进代码，而是填入密钥中让 AI 引用密钥变量，用于安全存储密钥、Token、敏感配置（F-071）；
- 在 AI 服务场景的具体用法：项目开通 AI 服务后，平台自动创建环境变量 **`MEOO_PROJECT_API_KEY`**，Edge Functions 中通过该变量引用密钥（F-078）。
- 安全含义：密钥不硬编码进代码，这也是 [07](07-ai-service.md) 三段调用示例的统一前提。连接器所需的访问凭证在安装连接时按提示填写（F-144，见 [13 连接器](13-connectors.md)），源页未说明其与 Secrets 面板是否为同一存储，不做等同推断。

## 5. 坑点与边界

- **不开云服务 = 展示页**是硬边界（F-066）：需求评审时先问「这个应用要不要登录/存数据/上传」，答案为是就默认要开云服务，别等预览时发现功能不可用。
- **CSV 是唯一明示的数据库导入导出格式**：源页只写数据库支持 CSV 导入导出（F-069），未承诺 Excel/JSON 导入；另一条通道——AI 生成文件下载——暂不支持 `.zip`/`.json` 格式下载（F-111，见 [09 文件存储](09-file-storage.md)），两件事不要混为一谈。
- **50MB 是文件管理界面口径**（F-070）：CDN 分发、存储桶、对话附件各自还有限额（见 [09](09-file-storage.md)），不要拿 50MB 去推断其他通道。
- **GoTrue 是框架名不是服务名**：对用户暴露的是「登录认证」开关，底层框架 GoTrue 解释了它的用户表结构与 API 形态（F-072）；源页未给自托管 GoTrue 的配置说明，不要推断可自带认证服务。
- **源页截图边界**：两张截图为图床直链（具体 URL 仅登记入台账转写噪声登记，不进入教程正文），按钮位置以产品实际界面为准。
