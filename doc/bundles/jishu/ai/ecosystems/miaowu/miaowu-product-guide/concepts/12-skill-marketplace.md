# 技能市场：语义搜索、标签浏览、权限差异与 zip 上传

> 侧边栏归属「功能特性 → 扩展能力」。技能市场是 [11 Skill](11-skills-authoring.md) 的分发面：自己发布的技能、官方技能、他人技能在这里汇合，地址 `https://meoo.com/skills`（F-132）。

## 1. 市场是什么

秒悟 Meoo 技能市场是平台面向开发者与普通用户提供的技能集合页面，汇集各类**开箱即用的 AI 技能**，用户可直接浏览、查看、一键使用，也可上传、下载技能，覆盖日常开发、办公自动化、业务场景落地等需求（F-135）。

### ⚠️ 先厘清「8 类型」与「7 标签」

同页出现两个数字，各自属实、不可混写（核验见 [verification.md](../references/verification.md) 核验项六）：

| 口径 | 内容 | 出处语境 |
|---|---|---|
| **文案 8 种类型** | 开发、测试、回复、文档、数据、设计、效率、运维 | 介绍段对市场覆盖面的描述（F-135） |
| **实际筛选 7 类标签** | 通用、开发、UI设计、测试、文档、数据、效率 | 浏览页标签筛选条（F-136） |

差异：文案里的「回复」「设计/运维」在筛选条分别没有对应标签（筛选条改以「通用」「UI设计」呈现），本教程引用时两处数字保留各自原文，不替官方「对齐」。

## 2. 找技能：语义搜索优先

搜索框直接输入想找的技能即可查询（F-135）。关键能力是**融合 AI 语义搜索**，支持基于用户意图的动态检索——直接用自然语言描述需求，系统智能识别意图并精准定位。源页示例（逐字）：

> 「请帮我找一个能做财务报表的技能」（F-135）

含义：不需要知道技能的确切名称或作者，描述**要解决的事**即可；这与 [08 素材中心 Agent 模式](08-asset-center.md)「直接描述、自动选模型」（F-091）同为自然语言优先的交互取向。

## 3. 逛技能：视图、标签与添加

### 3.1 两个视图 + 七个标签

- 视图：**全部技能**（官方和个人上传的各种技能）/ **我创建的**（F-136）；
- 标签筛选：**通用、开发、UI设计、测试、文档、数据、效率**（F-136）。

### 3.2 添加到使用

点击**「添加」**，再点击**「使用技能」**，即可立即在创建应用的对话框中使用（F-136）。

> 源页该句句末疑漏「能」字（原文状态留痕于 [source-ledger.md](../references/source-ledger.md) 噪声登记与 F-138），完整语义即「使用技能」，与 [11 方式一](11-skills-authoring.md) F-132 表述一致。

### 3.3 详情页：权限按「谁的技能」分两套

点**「查看详情」**进入技能详情页（F-137）：

| 操作 | 官方/他人创建的技能 | 我创建的技能 |
|---|---|---|
| 添加为常用技能 | ✅ | —（直接可用） |
| 使用技能 | —（添加后在对话框用） | ✅ |
| 改造技能 | ❌ | ✅ |
| 设置技能访问权限 | ❌ | ✅ |
| 复制分享技能链接 | ✅ | ✅ |
| 下载技能 | ✅（下载） | ✅（下载技能到本地） |
| 删除技能 | ❌ | ✅ |

两条逐字来源：对官方或他人技能「可添加为常用技能、复制分享技能链接、下载技能」（F-137）；对自有技能「可使用技能、改造技能、设置技能访问权限、复制分享技能链接、下载技能到本地、删除技能」（F-138）。

> 洞察（权限模型型）：矩阵呈现的是典型的**消费侧只读 / 所有者可管理**二分：他人物品的动作集是「加入自己的工具箱（添加为常用）+ 取走副本（下载）+ 传播（分享链接）」，物品本身不可改、不可删、不可设权限；自有物品才出现「改造/权限设置/删除」三个治理动作。写市场相关操作文档时，先判定当前对象归属，再选动作列，能避免把「改造他人技能」当成平台 bug。

## 4. 上传本地技能包（zip）

技能市场支持上传本地已有技能包（F-139）：

1. 点击**「上传技能」**，点击选择本地技能**或拖拽 zip 包**到指定区域；
2. 根据弹窗提示填写对应内容，点击**「发布到我的技能」**，完成上传；
3. 即可在技能市场查看上传的技能（F-140）。

这与 [11 构建对话框的「上传技能」](11-skills-authoring.md)（F-129，支持上传本地技能包）形成两个入口：构建中随用随传走对话，成品分发包走市场上传；包形态源页明示为 **zip**。

## 5. 使用链路速查

```text
找现成技能：meoo.com/skills → 自然语言搜 / 标签筛 → 查看详情
  → 添加 → 使用技能 → 创建应用对话框中@用

发自己技能：技能构建 → 发布（勾选是否上架，F-131）
分发离线包：上传技能 → 选/拖 zip → 填信息 → 发布到我的技能
管理：我创建的 → 详情页 → 改造/权限/分享/下载/删除
```

## 6. 坑点与边界

- **搜索用自然语言，不用猜命名**：语义搜索按意图检索（F-135）；搜不到时换「要做什么」的表述，而不是换技能名关键词。
- **8 类型 ≠ 7 标签**（F-135/F-136）：写文档/做培训时两数字各归其语境，不要声称筛选条有 8 类或介绍文案只有 7 类。
- **他人技能不可改造/设权限/删除**（F-137/F-138）：需要定制时先下载再作为本地包改造上传，形成你自己的技能（注意遵守原技能的分享条款——源页未给许可协议细则）。
- **zip 是唯一明示包格式**（F-139）：源页未给包结构规范与大小限制，打包要求以弹窗提示为准。
- **访问权限的具体选项未在文档页列出**：F-138 只确认存在「设置技能访问权限」动作，公开/私有/链接分享等粒度以产品弹窗为准，不脑补。
- **源页截图边界**：搜索框、筛选条、详情页布局、上传拖拽区均为截图承载。
