## S2：Agent 模式事实（F-011–F-015）

来源：[不同Agent模式差异](https://docs.meoo.com/features/agent-modes)，应用构建能力栏目。

| 事实编号 | 事实内容 | 来源 |
|---------|---------|------|
| F-011 | 页面 H1「不同Agent模式差异」；秒悟构建器提供四种 Agent 模式：Agent（复杂任务）、Swarms（蜂群模式）、Plan（规划模式）、Design（设计模式） | S2 |
| F-012 | Agent（复杂任务）定位「深度推理，复杂需求、长任务处理」；适用情形：任务非常复杂、涉及多个文件和技术栈；对代码质量要求极高、不能容忍低级逻辑错误；需要构建完整的、可运行的系统原型；不介意等待更长时间换取更好结果 | S2 |
| F-013 | Swarms 蜂群模式定位「蜂群并发，极致速度、更快交付」；适用情形：任务简单、明确、单一；正在探索思路、需要快速看到代码样例（Drafting）；只需解释代码或进行简单重构；在赶时间或 Token 预算有限 | S2 |
| F-014 | Plan 规划模式定位「提前规划，步骤拆解、确认再执行」；适用情形：任务涉及完整应用构建，需明确功能、架构及实施步骤；希望编码前审查整体计划、确认技术选型与逻辑无误；确认后系统自动连续执行、无需中途干预；追求过程透明，避免黑盒操作导致方向偏差或返工 | S2 |
| F-015 | Design 设计模式定位「设计探索，多方案选择，择优后实现」；适用情形：未确定最终风格、希望先看到不同设计方向；做视觉导向页面、要求审美层次和完成度；不想围绕不满意初稿反复修改；希望先确认设计方向再正式制作、减少返工和沟通成本 | S2 |
