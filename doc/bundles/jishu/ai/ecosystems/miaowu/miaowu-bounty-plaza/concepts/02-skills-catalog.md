## 4. 系列族说明：条目数 ≠ 技能数 ≠ 创作者数

三个口径不可混为一谈：

- **条目数 = 25**：广场列出的技能条目总数。
- **技能数 ≤ 25**：同一技能的多个平台变体被拆成多条条目占位，故条目数可能**高估**技能数。
- **创作者数 = 22**：同一创作者以系列投稿多次出现，故条目数会**高估**创作者多样性（25 条对应 22 位）。

原因是**系列族**：投稿侧把同一技能的多个变体拆成独立条目链接（平台侧存在变体数量限制），形成两条显式系列族：

- **Store Release Kits（×3）**：编号 05 / 023 / 024，同一创作者「空格的键盘」的三个平台变体（F-025、F-043、F-044）。
- **多平台推广视频生成（×2）**：编号 013 / 025，同一创作者「一起Vibe」的两条投稿链接（F-033、F-045）。

因此做供给统计时应以「条目数 25 / 去重创作者 22 / 系列族 2 组」三口径并列，避免只数条目导致的重复计算（详见 [01-growth-stages.md](01-growth-stages.md) 与束内洞察）。
