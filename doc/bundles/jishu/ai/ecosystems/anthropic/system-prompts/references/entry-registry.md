# 条目事实登记表：F 编号索引

## 关于本表

- 本表是本束全部 F 编号事实的登记索引。原始登记散布于主仓库 spec 目录（`d:\spaces\SpecWeave\.trae\specs\create-claude-system-prompts-wiki\` 下的 `facts-overview.md` 与 `facts-era-*.md`，不在束内、不随文档发布），本表为其检索视图：先查本表定位编号与含义，再回 spec 文件核对逐字原文。
- F 编号引用规范：束内各文档正文在陈述事实处标注（F-XX-nnn），如（F-OV-001）；洞察同理以 I 编号标注，如（I-07）。引用规范与信源时效见[信源索引](source-index.md)。
- 编号段命名规则：`F-OV` = 总览层（overview 页面体系与采集口径）；`F-3X` = 3.x 时代；`F-40` = 4.0/4.1 时代；`F-45` = 4.5 代；`F-46` = 4.6→5.x 固定快照时代。
- 编号内部排序约定：每段编号内部大体按"页面元信息 → 条目正文/跨页对比 → 时代小结"排列；"页面元信息"条目（登记 title/url/description、条目数、日期清单、文件规模）与"条目正文"条目（登记结构骨架、逐字引文、行为特征）分行登记。

### 登记口径说明

spec 登记文件中的条目分四类，本表逐条列出、不加合并：

1. **页面元信息**：登记页面 frontmatter 三字段逐字抄录、条目数、日期清单、文件规模（行数/KB）、变体结构与页面级特殊说明（如 `**` 标注说明句、时间错位现象）；
2. **条目正文**：登记单个日期条目的结构骨架（章节/段落顺序）、关键原文摘录（逐字引用 + 本地行号，官方原文瑕疵保留）与行为特征（中文转述）；
3. **跨页/跨版对比**：登记相邻日期条目或同日跨模型条目的行级 diff 结论（新增/删除/措辞变化分段列出），如 F-40-005、F-45-012；
4. **时代小结**：登记时代级形态演进、共性条款与关键转折，如 F-3X-015、F-40-013、F-45-013（F-46 的时代小结未编号，见下文"编号边界说明"）。
