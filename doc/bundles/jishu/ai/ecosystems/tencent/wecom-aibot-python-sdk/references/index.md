# 信源与证据

本目录存放本知识包的证据层，不承担教学职责。阅读顺序建议为：先用「源码事实登记」查证一条断言，再用「四元组洞察」理解其工程含义，最后用「信源登记」确认上游坐标与可复现命令。

| 文档 | 内容 | 适用场景 |
|---|---|---|
| [facts.md](/references/facts.md) | 59 条零推测事实（F-001 ~ F-059），按包元数据、公开 API、连接生命周期、帧协议、流式回复、模板卡片、事件回调、文件下载解密、配置示例九节编排 | 需要核对具体取值、行号、默认值时 |
| [insights.md](/references/insights.md) | 6 条四元组洞察（陈述 / 证据 / 反常识 / 行动）与概念文档知识地图 | 需要判断「这个设计意味着什么」「踩坑点在哪」时 |
| [sources.md](/references/sources.md) | 上游地址、commit、许可证、19 文件清单、版本双口径、核对命令、关键信源文件表 | 需要复现基线或撰写问题单时 |

## 证据使用约定

- 正文中的 `F-0xx` 一律指向 `facts.md` 的同编号条目，不指向外部链接。
- facts.md 只登记取值、位置、签名与默认值，不含推断；推断性结论集中在 insights.md，并以「陈述」与「行动」显式标注。
- 版本一律双写：打包 `1.0.1`，运行期 `1.0.0`。
