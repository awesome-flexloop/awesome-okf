# 概念篇

本目录用 6 篇文档拆解 `wecom-unified` 的运行机制：从「它到底是什么」开始，经过环境门禁、意图路由与知识组织，最后落到脚本工具链与 PPT 模板系统。6 篇之间存在明确的依赖关系，建议按下面的三组顺序阅读；每组内部前后相承，组与组之间可并行。

## 学习路径

**第一组：建立边界（00 → 01）**
先确认 Skill 包与 `wecom-cli` 是两条独立交付链，再掌握「版本 → 授权 → 初始化」的硬门禁与输出侧的 ID 禁令。读完这一组，应能判断「环境是否可用、结果能否直接给用户看」。

**第二组：理解知识组织（02 → 03）**
先看一句话如何被分到 14 个业务域，再看 133 篇扁平 reference 如何用文件名承担索引。读完这一组，应能独立完成「从需求到域入口，再到具体细则」的定位。

**第三组：进入工程实现（04 → 05）**
先掌握 6 个脚本的输入输出与依赖，再看 9 套 PPT 模板的注册、组装与校验。读完这一组，应能判断某类物料任务需要哪些本地依赖、会在哪一步失败。
