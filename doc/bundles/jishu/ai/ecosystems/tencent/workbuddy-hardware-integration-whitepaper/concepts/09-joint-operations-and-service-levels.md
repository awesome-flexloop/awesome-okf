# 联合运营与服务水平：三级支持、SLA 与共创机制

本篇回答：接入上线之后，合作方能得到什么——技术支持怎么分级、SLA 承诺了哪些硬指标、售后责任怎么分、数据看板给什么、联合宣发怎么谈、版本怎么迭代。事实取材白皮书第 13 章（F-177 ~ F-188）。

## 分层供给总则

上线不是终点。联合运营按合作分层供给：自助接入的伙伴**默认享有**标准技术支持、SLA 保障与数据看板；联合宣发、专项支持与共创机制则面向深度合作（认证级）伙伴（F-177）。换言之，标准支持是默认权益，专项与宣发是需要资格的增量。

## 三级支持体系

| 层级 | 覆盖内容 | 事实 |
| --- | --- | --- |
| L1 · 常规支持 | 文档、FAQ、开发者社区 | F-178 |
| L2 · 技术支持 | 企业微信 / 邮件工单，工作日 24h 内响应 | F-178 |
| L3 · 专项支持（深度合作伙伴） | 专属技术对接人，重大问题小时级响应 | F-178 |

## SLA 承诺

四项硬指标如下（数值原样）：

| SLA 项 | 承诺值 | 事实 |
| --- | --- | --- |
| 核心 API 可用性 | ≥ 99.9% | F-179 |
| P0 故障响应 | ≤ 30 分钟 | F-180 |
| P1 故障响应 | ≤ 2 小时 | F-181 |
| 版本变更通知 | ≥ 30 天预告 | F-182 |

## 终端用户售后分工

- 硬件本身：由合作方售后；
- WorkBuddy 账号 / 会员 / 云端能力：由 WorkBuddy 客服承接；
- 联合问题：双方联合处理，通过共享工单系统流转（F-183）。

## 数据看板与洞察

合作正式上线后，WorkBuddy 向合作方提供专属数据看板与定期洞察报告，覆盖设备健康度、用户使用行为、商业化表现及反馈质量等维度；具体数据范围与交付形式在合作启动后由双方对齐确认（F-184）。可见「看哪些维度」有既定框架，而「交付形式与粒度」属合作启动后的事后对齐项。

## 联合宣发

联合宣发**不属于**自助接入的默认权益：涉及 WorkBuddy 品牌与 Logo 的宣发物料需先取得品牌授权；在产品与包装上使用「WorkBuddy 认证」标识需先通过官方认证（F-185）。常见方向有四个（F-186）：

- **发布节点**：新品发布联合站台、双方渠道同步发声；
- **内容共创**：联合场景视频、评测与用户故事等内容共建；
- **渠道曝光**：WB 生态内专区曝光、消息触达及会员活动联动；
- **共同预算**：关键节点联合投放，费用与效果按约定分摊。

以上方向均需双方商务与市场团队评估确认后执行，具体权益与节奏 case by case 对齐（F-186，`商务框架性参考`）——白皮书只给方向与原则，不给具体的资源承诺。

## 版本迭代与共创机制

WorkBuddy 侧节奏：能力版本 = 季度大版本 + 月度小版本；Break Change 给予 ≥ 30 天预告 + 兼容期；Beta 通道让核心合作伙伴优先试用新能力（F-187）。

合作方共创机制（面向深度合作伙伴）三条：季度对齐会（路线图共享、需求互通）、共研专项（面向战略合作方，联合定义新能力）、Case 复盘（每半年一次数据 + 体验联合复盘）（F-188）。

## 默认权益与认证级增量一览

把上面的条款按「谁享有」重新列一遍，可以看出供给是分层的（F-177）：

| 权益项 | 自助接入（默认享有） | 深度合作（认证级） | 事实 |
| --- | --- | --- | --- |
| 标准技术支持与 SLA | 有（L1 常规支持、L2 技术支持 + 四项 SLA） | 在默认基础上另享 L3 专项支持 | F-177、F-178 |
| 数据看板与洞察 | 有（设备健康度、用户行为、商业化、反馈质量） | 有，并可参与半年一次 Case 复盘 | F-177、F-184、F-188 |
| 联合宣发 | 不属默认权益，涉及品牌/Logo 需先授权 | 评估通过后可走发布节点等四个方向 | F-185、F-186 |
| 共创机制 | 不属默认权益 | 季度对齐会、共研专项、Case 复盘 | F-177、F-188 |

## 本篇要点回顾

- 支持体系分三级：L1 文档/FAQ/社区、L2 工单（工作日 24h 内响应）、L3 专属对接人（重大问题小时级响应）（F-178）。
- SLA 四项硬指标：可用性 ≥ 99.9%、P0 ≤ 30 分钟、P1 ≤ 2 小时、版本变更 ≥ 30 天预告（F-179 ~ F-182）。
- 售后按「硬件归合作方、账号/会员/云端能力归 WorkBuddy、联合问题共享工单」分工（F-183）。
- 看板维度有框架、交付形式事后对齐（F-184）；联合宣发与共创仅属认证级增量，且均为 `商务框架性参考`（F-185、F-186）。
- 版本节奏为季度大版本 + 月度小版本，Break Change ≥ 30 天预告，Beta 通道优先给核心伙伴（F-187）。
