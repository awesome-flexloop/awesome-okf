# 边界、版本与口径：能不能接入、支持哪些端与资产

本篇把两篇公告中分散的**边界条件**集中登记，供接入决策与推广排期判断。本束核验时点为 **2026-10-15**（F-057，`核验时点 2026-10-15`）。

## 一、版本门槛与时效落差

| 观察点 | 值 | 事实 |
| --- | --- | --- |
| 两篇公告发布日期 / 栏目 | 2026-10-14 / 平台公告（两篇同日同栏目） | F-018、F-035、F-058 |
| 公告要求客户端版本 | **5.8.0 及以上**（低于该版本无法唤起） | F-028、F-046 |
| 本束核验时点 | 2026-10-15 | F-057 |
| 同组 `workbuddy-official-docs` 束核验的官方文档更新日志最新版本 | **5.7.7（2026-10-08）** | 该束事实 081、082 号（本束 F-059） |
| 同组该束核验的历史版本下载页最新版本 | v5.7.7（2026-10-09） | 该束事实 042 号（本束 F-060） |

**落差判定**：公告（**2026-10-14 / 5.8.0**）**先行于**产品文档版本线（**5.7.7 / 2026-10-08**）——两口径**并列登记、不择一**（F-059、F-060，`版本时效`）。引用「5.8.0 门槛」时须标注「公告口径（2026-10-14）」；引用「5.7.7」时须标注「`workbuddy-official-docs` 束 2026-10-15 核验的文档线」。该落差与同组 `wecom-5-0-12-release`、`workbuddy-official-docs` 记录的两个独立核验先例（「通稿先行于产品文档」）一致，对照方见 [WorkBuddy 官方站点与四区文档](../../workbuddy-official-docs/index.md) 与 [企业微信 5.0.12 版本快照](../../wecom-5-0-12-release/index.md)。

## 二、端边界

| 端 | 状态 | 公告原话 | 事实 |
| --- | --- | --- | --- |
| PC 端（Windows 应用 / macOS 应用） | 分享能力接入**当前已支持** | 「当前支持 PC 端接入（Windows 应用 / macOS 应用）」 | F-023、F-030 |
| 移动端（Android / iPhone / 鸿蒙应用） | **规划态（未支持）** | 「移动端（Android / iPhone / 鸿蒙应用）将陆续开放」 | F-031 |
| 推广分享链接可打开的端（A2） | 移动端与 PC 端**均可**打开，先展示资产详情页 | 「在移动端或 PC 端打开后均会先展示资产详情页」 | F-044 |

> **勿混淆**：A2 的推广分享链接可在移动端打开，与 A1「分享能力接入**仅 PC 端**」是**两条不同能力**（F-030、F-044，`端边界`）。移动端一律标注为「公告原话『将陆续开放』、属**规划态**」，**不得**写成已支持。

## 三、开放对象与身份门槛

- 分享能力接入面向**已通过企业认证的开发者**开放，应用创建与密钥生成均在开放平台完成（F-029，`开放门槛`）。**不得**写成对任意个人开发者开放。
- 公告**未**展开「企业认证」流程细节，本束仅登记「面向已通过企业认证的开发者开放」这一门槛事实（F-063，`平台现状`）。
- 相关模块入口：「认证信息」`/settings/cert-info`（F-015）、「开发者信息」`/settings/developer`（F-016），均为`未采集`、仅登记入口。

## 四、资产类型与付费边界（汇总）

- **资产类型维度**：专家与技能类资产支持「分享链接 + 微信小程序码」；连接器**暂时仅支持**「分享链接」；Buddy 应用分享功能**正在规划中**（F-051、F-052、F-053，`资产与付费边界`）。
- **付费维度**：免费资产支持「分享链接 + 微信小程序码」；付费资产**暂时仅支持**「分享链接」（F-054、F-055）。
- 限定词「**暂时仅支持**」「**正在规划中**」须保留，不得写成已支持或永久不支持；两条维度相互独立，须分别登记。逐项差异表见 [02-promotion-management.md](02-promotion-management.md)。

## 五、品牌规范

在应用分享入口展示 WorkBuddy 标识时须遵循 WorkBuddy 品牌设计规范，该标识**仅表示已接入分享能力**（F-032，`公告口径`）。该品牌设计规范公告未展开，仅登记为指引入口——本束不展开学习、不做站外递归抓取（F-062，`未采集`）。

## 六、公告未给出的信息清单（`平台现状`）

两篇公告正文均**未**给出：① 接口字段 / 端点路径；② 请求参数与响应格式；③ 错误码与失败处理；④ 鉴权 / 签名算法细节（公告仅要求登记「应用标识与签名信息」，未给算法）；⑤ 审核细则（仅给「7 个工作日内完成」，未给通过 / 驳回判据）；⑥ 限流、配额、调用次数等任何数字；⑦ 客户端唤起协议与分享链接 URL 结构（F-061，`平台现状`）。如需接口级内容，须另立新束学习《PC 端开发手册》（F-062）。

**采集边界**：本束**未**采集开放平台后台「注册应用」「新建推广」等**操作型页面**（需真实账号且会产生真实数据）（F-064，`未采集`）。模块地图 13 项入口逐项标注「本次未采集，仅登记入口」，见 [00-open-platform-overview.md](00-open-platform-overview.md)。
