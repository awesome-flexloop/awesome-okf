## 二、口径 1：官网宣传口径 vs 文档可配置项

这是本束最需要分层的一组——官网首页面向决策者的表述，与文档站可实际配置的项并不一一对应。

| 官网首页宣传口径 | 原文要点 | 文档侧对应 | 落差判定 |
| --- | --- | --- | --- |
| 全链路数据加密 | 「传输与存储全程 TLS/AES-256 加密，密钥独立托管」（F-515） | 隐私声明第七章：采取加密等安全保护措施（F-446）；安全中心含「传输加密」分组（F-202） | ⚠️ **算法与密钥托管口径仅官网单源**；文档侧未出现 TLS/AES-256 或密钥托管的逐项说明（本次采集切片未取得唯一编号） |
| 精细权限管控 | 「基于角色的多级权限体系与操作审计日志，管理员可精确控制谁能访问、编辑与导出每一份内容」（F-516） | 安全中心分组含审计中心、文件安全三态规则、命令安全、网络安全、工具管控（F-202）；权限模式两档（F-198 ~ F-201）；资料库成员权限四档「查看/编辑/管理/无权限」（F-166） | ⚠️ **机制存在但粒度不同**：文档侧是「沙箱 + 文件/命令/网络规则 + 角色档位」，官网表述的「每一份内容」级控制在文档中未见对应描述 |
| 权威合规认证 | 「已通过 ISO 27001、SOC 2 与等保三级认证，数据存储符合本地化合规要求」（F-517） | **文档站四区未出现 ISO 27001 / SOC 2 / 等保三级任一项**；相近表述为企业版产品优势的「安全六项＝资产安全、身份管控、企业级加密、模型可信、审计合规、内容安全」（F-483） | ❌ **文档侧零印证**：三项认证仅见于官网首页，且官网未提供证书查询入口 |
| 数据本地化 | 「数据存储符合本地化合规要求」（F-517） | 隐私声明：在中国大陆收集的用户信息存储于中国大陆境内（F-445） | ✅ 文档侧可印证 |
| 腾讯生态打通 | 「无缝连接办公 IM、文档、邮箱、会议、知识库等常用办公工具」（F-520） | 连接器支持 QQ 邮箱、腾讯文档、腾讯乐享、腾讯会议、TAPD、腾讯网盘（F-127）；助理支持微信/企微/QQ/钉钉/飞书（F-105、F-013） | ✅ 文档侧可印证且更细 |

**引用建议**：把官网首页的三项认证与加密算法表述标注为「官网宣传口径」，与文档侧的「可配置安全项」分开引用；不要把官网认证写进产品能力清单当作已核实事实。

## 三、口径 2：三端差异（桌面端 / App / 小程序）

同名功能页在三端存在**措辞与能力集合不一致**的情况。下表按主题归并（原始逐条事实见 F-315、F-323、F-327、F-332、F-335、F-338、F-341、F-345、F-352、F-356、F-360、F-364、F-368、F-372 ~ F-375、F-379、F-382 ~ F-384、F-387、F-390、F-395、F-399、F-403 ~ F-405、F-409、F-412、F-415）。

| 主题 | 桌面端（`/docs/workbuddy/`） | App 端（`/docs/workbuddyapp/`） | 小程序端（`/docs/workbuddymini/`） |
| --- | --- | --- | --- |
| 产品名与入口页 | 「WorkBuddy 简介」 | 「简介」，登录可选 QQ/微信/其他 | 「WorkBuddy 小程序简介」，**授权手机号登录** |
| 执行环境命名 | 工作空间（本地目录） | **云端工作 / 连接电脑** | **云上模式 / 本机模式**（☁ / 🖥） |
| 欢迎区形象 | 桌面工作台 | **WorkBuddy 吉祥物** | **虾虾吉祥物** |
| 工具面板入口 | 侧边栏「专家·技能·连接器」 | 输入栏 `+`：拍照 / 照片视频 / 手机文件 / 腾讯文档 / 定时任务 / **专家中心** | 输入栏 `+`：摄像头 / 照片视频 / 手机文件 / **微信文件** / 腾讯文档 / 添加技能 / **ima 知识库** |
| 发起任务方式 | 自然语言 + 提示词模板 + 选择工作空间 + @ 上下文 | 直接输入 / 场景标签 / 侧边栏新建 / **系统分享入口（App 独有）** / **语音输入** | 直接输入 / 快捷入口 / 侧边栏新建（**仅三节**） |
| 专家页 | 专家中心（专家 / 专家团 / Skill 三者对比） | 页名「**专家**」 | 页名「**专家中心**」，标注「专家（Agent 型）/ 专家团（Team 型）」 |
| 模型选择页 | 功能说明 `Model`（三档模式 + 内置模型列表） | slug `features/Model`，仅能力标签与推荐场景，**未列倍率** | slug `features/Select-Model`，**给出具体倍率表**（如 GLM-5.2 x0.79、Deepseek-V4-Flash x0.06），并注明「首句话发送后模型选择才可显现」 |
| 定时任务 | 本地 / 项目 / 云端三类来源，可推送企业微信 | 页面内 `+`，**无选模型/技能项** | 右下角 `+`，**支持选择不同模型与技能** |
| 设置页 | 通用/个人主页/套餐与积分/外观/快捷键/智能体/模型/助理设置/数据与安全 | 含注销账号、主题和语言、分享日志/清除日志/意见反馈、隐私清单 | 改为「切换登录账号 / 我的分享 / 关注服务号 / 使用帮助」，注明**暂不支持换绑手机号** |
| 多端协同建联 | 面板选「连接移动端」 | 面板选「**App**」分页，系统通知，右上角新建 | 面板选「**小程序**」分页，**微信订阅通知**（一次授权只推一次），左上角新建，额外含「连接腾讯文档」「连接 ima 知识库」 |
| 产物分享 | 可上传到云端网盘 / 腾讯文档 / ima / 乐享 | 「产物查看与分享」四节（查看/分享/导出/重新生成） | 「产物分享」**明显更简**，**分享链接有效期 30 天** |
| 任务执行末节 | — | 末节「**重新生成**」 | 末节「**查看引用来源**」（含公开信息源与已授权个人资料） |
| 微信文件打开 | — | 操作「预览 / 插入输入框」，前置为已安装并登录 App | 操作「查看 / 加入对话」，前置为**已在微信中登录过小程序** |

**引用建议**：①不要在未注明端别的情况下引用「设置里有 X」——三端设置页集合不同；②「云上模式」「云端工作」是同一概念的不同端命名，需并列说明而非互相替换；③小程序端特有入口（微信文件、ima 知识库、微信订阅通知、30 天分享有效期）不得写成桌面端能力。

## 四、口径 3：企业版 vs 个人版边界

| 能力 | 归属 | 事实 |
| --- | --- | --- |
| 席位管理与起购量 | 企业版专属 | 企业旗舰版 **1 个坐席起购**；企业专享版**缩容下限 100 个**（F-505、F-508） |
| 每成员积分限额 | 企业版专属 | 企业版**每成员默认 2000 积分限额，超限不可用**（F-507） |
| 企业统一身份（成员管理） | 企业旗舰版专属 | 旗舰版已接入「腾讯统一身份」，除 CodeBuddy 管理员外还需添加腾讯统一身份管理员；**专享版未接入**（F-490、F-491、F-442） |
| Skill 下发策略 / 成员自定义 Skill 策略 | 企业版专属 | 双层策略架构，优先级「黑名单 > 白名单 > 默认允许」（F-495、F-496）；成员自定义 Skill 仅本人可见（F-501） |
| 内置 Skill 数量 | 企业版侧披露 | **301 个**（F-494）——注意这是企业后台页的披露值，个人版未给同一口径 |

| 企业智能体（CloudAgent） | 需企业坐席 | 创建 Agent 需「登录分配了**企业坐席**的个人账号」（F-122）；Runtime/Session 生命周期管理（F-120 ~ F-126） |
| 交付形态 | 企业版专属 | 公有云 SaaS / 专属（SaaS+API）/ **私有化部署**三种（F-484） |
| 产品矩阵归属 | 企业版总品牌 | WorkBuddy Enterprise ＝ CodeBuddy + WorkBuddy + WorkBuddy Managed Agents（F-478） |
| 资料库容量 | 按个人会员版本 | 体验版 5GB / 标准版 10GB / 高级版 20GB / 旗舰版 50GB（F-164、F-070） |
| 个人套餐与积分 | 个人版 | 体验版免费、标准版 99、高级版 199、旗舰版 999 元/月；WorkBuddy 与 CodeBuddy 同账号积分共享（F-067 ~ F-071） |

**引用建议**：①`enterprise` 区的能力（席位、模型部署管理、日志管理、研发度量、IP 白名单、Playbook、Connector 管理等）一律标注「企业版管控面」，不得写成个人版可用；②「旗舰版」一词在个人套餐（999 元/月）与企业旗舰版（SaaS 企业版）中**同名不同义**，引用时必须带上下文限定（F-068 vs F-485）。

## 七、信源距离与厂商叙事评估

| 维度 | 评估 |
| --- | --- |
| 信源主体 | **单一厂商（腾讯）**：官网 + 官方文档站 + 官方隐私声明，全部为第一方自述；**无第三方独立评测、无公开评测数据** |
