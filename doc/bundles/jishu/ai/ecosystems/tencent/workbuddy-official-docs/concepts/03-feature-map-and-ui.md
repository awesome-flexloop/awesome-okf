# 界面功能区地图：侧边栏、右侧边栏、设置与各功能入口

> 覆盖桌面端「功能说明」中的界面相关页；除标注外均为「文档可配置项」口径（核验时点 2026-10-15）。

| 界面功能区 | 能做什么 |
| --- | --- |
| 左侧侧边栏 | 四块结构，一级入口含「更多」收纳的低频入口（F-222、F-223） |
| 右侧边栏 | 产物/工作空间文件/变更/浏览器/终端标签页，可开多个/1/1/多个/多个（F-213、F-214） |
| 内置浏览器 | 网址或关键词（非网址走搜狗搜索）、登录态按账号隔离、设备工具栏、截屏（F-215、F-216） |
| 终端与消息中心 | 终端可多开标签页；消息整页平铺并可跳转任务（F-217） |
| 设置面板 | 账号/外观/模型/数据等全部配置，桌面端独立窗口（F-218、F-219） |
| 独立文件浏览器 | 单窗十类格式、人机双写、可设为默认打开方式（F-149、F-150） |
| 数据管理 | 我分享的文件与已归档任务（F-132、F-133、F-134） |
| 设计创意模式 | Ardot 画布一句话出 UI/PPT/海报并可生成应用代码（F-135、F-139） |
| 灵感 | 案例浏览与做同款，可发送到对话/任务（F-155、F-157） |
| Buddy 应用 | 企业与行业定制的专属工作台，可同客户端切换（F-116） |

## 1. 左侧侧边栏

自上而下四块：顶部（版本号、发现应用）、一级入口（新建任务、助理、项目、专家·技能·连接器、定时任务、资料库、更多）、任务与空间、底部（消息中心、多端协同、账号头像）（F-222）。「更多」收纳我的邮箱、腾讯文档、ima、乐享知识库、灵感、Genie BaaS（F-223）。右键可「自定义菜单」，分「一级菜单」「更多」两组、可拖动排序与跨组移动（F-224）；边界：「新建任务」固定不可拖动、不可收进「更多」，「更多」无条目时不显示，自定义结果仅存当前设备、**不跨设备同步**（F-225）。

## 2. 右侧边栏

产物、工作空间文件、变更、浏览器、终端以标签页共存，可同时打开随时切换（F-213）；可开数量为产物多个、工作空间文件 1 个、变更 1 个、浏览器多个、终端多个（F-214）。内置浏览器网址栏兼收网址与关键词，非网址走搜狗搜索；登录态持续保留且**按账号隔离**，可清除 Cookie 与缓存；更多菜单含查找、缩放、设备工具栏（视口切换）、截屏到剪贴板（F-215、F-216）。终端可执行命令并多开标签页；消息中心整页平铺、点击可跳转任务（F-217）。

## 3. 设置面板

入口为侧边栏底部头像 → 用户菜单 → 设置，桌面端以独立窗口打开、不占主窗口（F-218）。分组含通用、套餐与积分、外观、快捷键、智能体、模型、助理设置、数据与安全（数据管理、应用管理、安全中心）（F-219）。通知项含桌面通知（需系统允许）、提示音（灵动/晴朗/沉稳，默认无音效）、定时任务产物通知（默认开启）（F-220）。用户级 `.codebuddy` 配置自动加载并与项目级按优先级合并（F-221）。**三端差异**：桌面端、移动端与小程序端的设置页集合不同。

## 4. 独立文件浏览器

独立窗口，可打开本机文件、多开与标签页切换，右侧对话栏支持「人机双写」，可设为系统默认「打开方式」（F-149）。一窗覆盖 Word/Excel/PPT/PDF/Markdown/HTML/图片/音频/TXT，其中 Word、Excel、PPT、Markdown、HTML 支持人机双写（F-150）。不登录时正文可看，Office 编辑**需登录**、Markdown 也能看能编辑（F-151）。保存：Office 手动 Ctrl+S，Markdown 自动保存，HTML 点「编辑」/「退出编辑」并自动保存（F-152）。

## 5. 数据管理

入口 头像-设置-数据管理，管理「我分享的文件」与「已归档任务」（F-132）。前者可复制链接、下载、取消分享，取消后链接失效（F-133）；后者可删除（二次确认）或取消归档（F-134）。

## 6. 设计创意模式与腾讯设计 Ardot

Ardot 是腾讯自研的 AI 设计智能体协作平台，「设计创意模式」集成其画布，可一句话生成 UI、PPT、海报并实时对话修改（F-135）。入口为 首页新建任务 → 最右侧「设计创意」Tab；首次使用需授权，用登录手机号自动关联 Ardot 身份、**无需单独注册腾讯设计账号**（F-136）。授权含读/编辑画布与云端同步；默认品牌模板含 TDesign、Apple、Meta、Miro、Notion、Spotify、Discord、Linear、X AI、Ferrari（F-137）。支持移动端 App 界面、网站页面/Landing Page、品牌 Logo、海报/Banner、PPT，可导出 PNG/SVG/PDF（F-138）。从设计稿可一键生成应用代码，生成后继续用对话改代码；PPT 可导出 PPTX 或 PDF（F-139、F-140）。

## 7. 灵感

汇集官方与社区案例，可按场景浏览、收藏、做同款；选中案例会填入 Prompt 并加载对应 Skill 与专家配置（F-155）。三者定位不同：Skill＝能力（能做什么）、专家＝能力（谁能帮我做）、灵感＝成果（实际做出了什么）（F-156）。复用可套版复刻（比从零生成更省积分），或把产物发送到对话、任务（F-157）。详情页双栏（左产物、右信息与提示词），浏览不收集个人信息、不调用本地权限（F-158）。

## 8. 意见反馈与智能诊断

两个入口：左下角头像 → 用户菜单「意见反馈」，或 头像 → 设置 → 「获取帮助」→「填写反馈」（F-146）。点「智能诊断」会跳转诊断页分析原因并给建议，答复自动回写关联记录，但**不替代反馈提交流程**（F-147）。帮助文档入口为 设置 → 获取帮助 →「查看文档」；反馈建议附截图并勾选上传日志（F-148）。

## 9. Buddy 应用

面向企业与行业场景的专属 AI 工作台，可在同一客户端切换企业定制工作空间（专属品牌界面、场景入口与专家/技能/连接器）（F-116）。授权流程：发现应用 → 确认授权 → 绑定账号（部分需绑第三方账号，可跳过）→ 第三方授权（微信扫码/手机号）；灰度或内测阶段可能仅对部分用户开放（F-117）。撤销入口「设置 > 应用管理 > Buddy 应用」，二次确认、不影响已产生会话；若应用方配置「不允许在其他版本中使用」，会话可见但输入框置灰（F-118）。审核通知 6 类（发布与信息审核的通过/驳回、强制下架、资料违规），经开放平台通知中心、端内消息中心、开发者邮箱三渠道送达（F-119）。

## 10. 小结

易踩边界：自定义菜单不跨设备同步（F-225）、工作空间文件与变更各仅 1 个（F-214）、Markdown 不登录可编辑而 Office 编辑需登录（F-151）。
