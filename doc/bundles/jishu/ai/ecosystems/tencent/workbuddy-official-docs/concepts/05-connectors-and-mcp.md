# 连接器与 MCP：外部服务与数据接入的边界

> 本篇属**接入层**：连接器与 MCP 解决的是「WorkBuddy 怎么用上外部服务与数据」，与之配套的还有专家/技能（见 [专家、专家团、技能与插件](04-experts-skills-and-plugins.md)）。事实编号见[事实登记](../references/article-source.md)，口径分层与未取得页清单一并见[核验报告](../references/verification.md)。

## 连接器：两种实现形态

连接器将 WorkBuddy 与外部服务对接，引入外部数据和能力，分两种形式：**MCP + CLI（标准化协议）** 与 **Skill + CLI（内置脚本）**（F-127）。官方已支持清单含**QQ 邮箱、腾讯文档、腾讯乐享、腾讯会议、TAPD、腾讯网盘**等（F-127）。

> **未取得**：本束事实源未登记独立的「自定义连接器」条目；自行扩展的路径体现为 MCP 可视化配置接入外部工具与服务（F-180、F-183）。

## 怎么添加、怎么使用

- **添加路径（文档可配置项）**：左侧边栏「专家·技能·连接器」→ 连接器页签 → 卡片右上「+」→ 完成登录授权（F-128）。
- **三种使用方式**：①在连接器页面点「去对话」；②创建任务时 `+` > 连接器启用；③**执行任务时按需连接**——出现连接引导卡片，授权后自动继续当前任务（F-128）。
- **通过对话管理连接器**：安装（说明名称）、查看（如问「我安装了哪些连接器」，含已授权但当前关闭的）、卸载（弹出确认并列出移除清单）；**内置连接器不支持卸载**（F-129）。

## 授权与权限边界

- **三条铁律**：每个连接器**独立授权**、**不主动定时抓取**、**不超出已有权限范围**（F-131）。
- **具体授权范围举例**：连接 QQ 邮箱需 QQ 邮箱 App 7.1.5 / 鸿蒙 0.2.9 及更新版本，权限含账号信息、读取邮件（近一个月）、发送邮件、删除邮件（可选）；连接腾讯乐享支持微信登录、手机号登录（F-130）。
- **企业版与个人版授权通道不同**：企业版连接器通过**企业统一身份**完成授权、无需单独扫码、由企业统一管理且**不支持解绑**；个人版连接器用个人微信扫码授权、支持随时解绑；两者授权状态相互独立、互不影响（F-261）。同一服务在企业账号下可能同时提供企业版与个人版两个连接器（F-260）。
- **项目内的授权分级**：连接器按授权方式分**公共授权**（管理员配置一次、全员共用同一套票据）与**个人授权**（每位成员各自授权、票据不共享），同一连接器可同时以两种方式存在（F-210）；**协作任务中个人授权连接器全部禁用、仅公共授权可用，且其调用日志仅管理员可见**（F-212）。

## 积分边界：搬运免费、加工计费

连接器**自身的读写不消耗积分**；只有 WorkBuddy 去**理解、汇总**连接器带回的外部数据时才消耗积分（F-131）。也就是说，「把数据搬进来」免费，「让模型读懂它」计费——这是判断一次连接器调用是否花积分的分界线。

## MCP：不写代码的接入方式

MCP（Model Context Protocol，模型上下文协议）用于将外部工具和服务接入 WorkBuddy。WorkBuddy 已将 MCP 配置集成到界面中：**无需编码、无需手动改配置文件，可视化操作即可完成接入**（F-180）。其核心价值为四项：上下文共享、工具调用、可组合工作流、数据控制；同时提供现成的 MCP 资源入口，可访问**腾讯云 MCP 市场**获取开放生态能力（F-181）。

- **配置级别两级（文档可配置项）**：**用户级** `~/.workbuddy/mcp.json`（配置一次，所有项目复用）与**项目级** `<项目目录>/.workbuddy/mcp.json`（仅当前项目生效）（F-182）。
- **配置入口与状态**：侧边栏 插件 → 右上角「MCP 服务器」→「配置 MCP」；状态指示灯**绿色＝连接成功、红色＝配置异常**（F-183）。

## 连接器 vs MCP

| 维度 | 连接器 | MCP |
| --- | --- | --- |
| 实现形态 | 两种：MCP + CLI 标准化协议 / Skill + CLI 内置脚本（F-127） | 单一协议接入，把外部工具与服务暴露给模型（F-180） |
| 配置方式 | 连接器页签卡片右上「+」后完成登录授权（F-128） | 侧边栏 插件 → 「MCP 服务器」→「配置 MCP」，可视化配置、无需手改配置文件（F-180、F-183） |
| 配置级别 | 无用户级/项目级之分；项目内另按授权方式分公共授权与个人授权（F-128、F-210） | 用户级 `~/.workbuddy/mcp.json` / 项目级 `<项目目录>/.workbuddy/mcp.json`（F-182） |
| 适用场景 | 对接官方已支持清单中的办公服务（邮箱、文档、会议、TAPD、网盘等），开箱即用（F-127） | 自行接入外部工具与服务、复用开放生态的 MCP 资源（F-180、F-181） |
| 积分 | 自身读写不计费，理解汇总外部数据才计费（F-131） | 未取得 MCP 专属积分口径（未取得） |

## 企业版口径

- **官网宣传口径**：企业版产品优势宣称「**全面兼容 MCP 协议**」（F-482）。该表述出自企业版产品优势章节（同章另有「研发 > 办公 > 运营」贯通、安全六项、三种交付形态，F-481、F-483、F-484），属厂商对外宣称，可与客户端侧 MCP 能力描述（F-180）互相印证，但不代表企业侧新增了管控项。
- **未取得**：企业侧 **Connector 管理页在核验时未取得**——该页仅返回「正在加载文档…」占位、无正文（F-451）；企业版 sitemap 的 `adminguide/*` 等语义路径多数未呈现独立正文，被重定向/别名至「产品概述」（F-512）。因此企业版对连接器的具体管控能力在本束**未取得**，引用时须据实标注。
