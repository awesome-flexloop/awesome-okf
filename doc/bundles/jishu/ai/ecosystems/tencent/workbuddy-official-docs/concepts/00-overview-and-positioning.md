# WorkBuddy 是什么：定位、界面与版本演进

WorkBuddy 是**腾讯出品的全场景 AI 工作台**：用自然语言描述需求，由它自主规划并执行任务，交付文档、表格、PPT 等可直接使用的完整成果（F-002）。官网首页给出的定位原文是「WorkBuddy 是腾讯出品的全场景 AI 办公工作台。说出要求、开始执行任务、交付完整成果。完美连接腾讯办公生态，你的办公好搭子」（F-518，**官网宣传口径**）。两处措辞略有差异（「工作台」与「办公工作台」），本束以文档口径 F-002 为主、官网原文并列保留。

## 它与传统 AI 对话差在哪

文档给出四点差异：能实际执行任务、能自动操作本地文件、能处理多步骤复杂任务、交付可验收的结果（F-005）。对应地，核心能力被归纳为六项：自然语言交互、自主规划与执行、多模态任务处理、本地文件操作、多任务并行、结果交付与验收（F-003）。

## 产品矩阵与出品方

在企业版「产品概述」页，同一总品牌下并列三款产品：CodeBuddy（智能编码）、WorkBuddy（AI 办公协同）、WorkBuddy Managed Agents（智能体托管与规模化运行）（F-478，**企业版专属**，**核验时点 2026-10-15**）。

## 适用场景七类

适用场景被归为七类（F-004）；其中三类在文档中另有更细的展开：

| 场景 | 文档证据 | 要点 |
|---|---|---|
| 日常办公 | F-007 | 文档处理、金融信息辅助分析、数据分析及可视化、个人工作台、幻灯片、深度研究、视频生成、产品管理、最新新闻、帮我写作、日常翻译、生活小知识、工作技巧、旅游攻略 |
| 代码开发 | F-008 | 日常开发、网站开发、小程序、Agent 应用、Skill 开发、CI/CD、文档 |
| 设计创意 | F-091 | 自 5.5.5 起新增创意设计能力：图片生成、视频生成、品牌设计 |
| 项目协作 | F-004（仅名目） | 文档侧仅列出场景名目，未在本束来源中展开细则 |
| 专业任务 | F-004（仅名目） | 同上 |
| 服务协作 | F-004（仅名目） | 同上 |
| 资料与知识 | F-004、F-029 | 产物可分享至腾讯文档、ima 知识库、乐享知识库 |

小程序是代码开发场景的落地形态之一：支持通过对话生成，可直接预览、测试和托管发布，无需搭建开发环境或安装微信开发者工具（F-009）；发布支持创建试用版（无微信小程序账号，试用版有效期 14 天）或绑定已有小程序账号（体验版、正式版，无固定有效期）（F-010）。

## 版本演进线（2026-08 ~ 2026-10）

官网「WorkBuddy 更新日志」是倒序汇总页，最新 5.7.7（2026-10-08），标头可见范围回至 5.3.8（2026-07-30）（F-081）。本条线不逐条罗列各版本，只抓能力主线：

| 版本 | 日期 | 主线 |
|---|---|---|
| 5.4.0 | 2026-08-20 | 创建 Worktree 任务，在同一工作区并行处理多个开发任务，代码改动互不干扰；代码开发模式新增 Git 分支展示与安全切换、独立本地终端、后台命令运行面板（F-103） |
| 5.5.0 | 2026-09-01 | 新增行业 Buddy 应用（按场景提供专属首页、专家、技能与连接器）；新增图片处理能力（去文字或水印、修复、增强、美颜、透明背景抠图）（F-096） |
| 5.7.0 | 2026-09-28 | 定时任务页面焕新（模板、配置、运行记录集中查看）；新增全局搜索，可查资料库内容与聊天记录（F-087） |
| 5.7.5 | 2026-10-03 | 新增定时任务汇总页（同一任务历次运行按时间线展示）；新增 Outlook 连接器（海外版）（F-084） |
| 5.7.6 | 2026-10-04 | 海外版新增 Gmail 连接器，授权后可直接读取和发送邮件（F-083） |
| 5.7.7 | 2026-10-08 | 优化成长计划体验问题（F-082） |

主线可概括为三条：**并行与本地工程能力**（5.4.0）、**场景化包装与多模态创作**（5.5.0）、**自动化与外部连接器**（5.7.x）。

**同一版本两个日期**：更新日志标注 5.7.7 为 2026-10-08（F-082），历史版本下载页同一版本号标注 2026-10-09（F-042）——即发布日与打包上线日相差一天（勘误 E-5，见 [核验报告](../references/verification.md)）。历史版本下载页最新安装包体积为 macOS Apple 芯片 340.8 MB / macOS Intel 368.4 MB / Windows 64 位 415.7 MB（F-042）。引用版本号时须带核验时点（2026-10-15）。

## 引用提示：官网宣传口径 vs 文档口径

> **官网首页给出三项安全宣称，本文档站四区未获逐项印证，请分层引用：**
> - **全链路数据加密**：「传输与存储全程 TLS/AES-256 加密，密钥独立托管」（F-515，**官网宣传口径**）——算法与密钥托管表述仅官网单源，文档侧未见逐项说明。
