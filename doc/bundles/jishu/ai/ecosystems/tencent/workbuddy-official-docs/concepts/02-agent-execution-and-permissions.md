# Agent 执行机制与权限边界

> 除标注外均为「文档可配置项」口径（核验时点 2026-10-15）。

## 1. 任务隔离与执行确认

每个对话对应一个独立任务，互不影响、各自维护独立工作空间与上下文；未指定目录时自动创建独立工作目录，支持多任务并行（F-230）。**循环执行确认**：检测到任务可能出现循环执行时，会在工具调用执行前暂停弹窗，可选「继续执行」或「终止请求」（F-231）。另有三种工作模式：默认（Agent，可改文件）、计划（Plan，先规划、确认后才执行）、仅问答（Ask，只答不做），Plan 确认前不执行（F-232、F-233）。

## 2. 模型档位与上下文

| 档位 | 适用 | 特征 |
| --- | --- | --- |
| 快速模式 | 简单明确的任务 | 响应最快、消耗最低（F-194） |
| 均衡模式 | 绝大多数任务 | 默认区间（F-194） |
| 极致模式 | 复杂任务 | 响应稍慢、消耗更高、结果更稳定（F-194） |

支持自接入第三方大模型；含 API Key 的参数**仅存本地 `workbuddy/models.json`、不上传云端**（F-193）。上下文窗口默认 200K，每轮完整发送、越大越费积分；Max 模式关闭时系统择机自动压缩上下文，开启则全程不压缩（F-195）。内置模型含 GLM-5.3（1M 上下文）、MiniMax-M3、Kimi-K3、Deepseek-V4-Pro 等（F-196）。**企业版专属**：管理员禁用的模型会在客户端选择器隐藏或置灰（含 auto）不可选；接入方式含提供商接入、本地 Ollama 部署与自定义（F-197）。

## 3. 权限模式与安全中心

权限入口为输入框底部的常驻状态按钮，默认显示「默认权限」（F-198）。默认权限需**逐次确认**四类高风险操作：写入受保护/敏感路径、删除受保护文件·重要目录·批量删除、执行脚本命令或外部程序、网络访问或敏感能力（F-199）。完全访问权限对当前客户端内所有已存在与后续新建任务统一生效、**不跨设备**，切换时弹「确认允许完全访问？」并列出放开的能力（文件操作、终端命令、访问互联网）（F-200）。

| 能力维度 | 默认权限 | 完全访问权限 |
| --- | --- | --- |
| 文件访问 | 受沙箱约束，越界需请求允许（F-201） | 可访问计算机任意位置（F-201） |
| 删除修改 | 需逐次确认（F-201） | 多数直接执行（F-201） |
| 终端命令 | 需确认（F-201） | 可直接装软件、改系统设置（F-201） |
| 联网 | 受控（F-201） | 放开访问互联网（F-200） |

安全中心分组含沙箱安全、文件安全（读/写/删三态规则）、命令安全（前缀）、网络安全（域名/URL）、自动备份、工具管控、安全网关、传输加密、敏感保护、删除保护、批量删除审批、内置运行时、审计中心（F-202）。默认保护：批量删除达默认 50 需审批（须先开删除保护）；自动备份默认开启（改文件前生成快照、共享备份空间默认上限 3000 MB）；敏感保护默认开启并覆盖各类 API Key（F-203）。口径分层：官网的「全链路数据加密」「精细权限管控」属**官网宣传口径**（F-515、F-516），文档侧可印证的是安全中心与权限档位（F-202）。

## 4. 记忆机制

记忆从会话历史提取事实信息、偏好习惯、人物关系、近期跟进事项等并定期更新，后续对话把相关记忆作为背景参考（F-189）。提取频率为每晚整理当天会话，**仅本人可见、默认开启**（F-190）；可在「设置 - 记忆」查看/编辑/删除/一键关闭，也可用对话告诉它记住或忘记什么（F-191）。支持导入其他 AI 的使用习惯；该功能**不消耗积分、不涉及第三方共享**（F-192）。

## 5. Worktree 并行任务

工作空间含 Git 仓库时才能做 Git 操作，创建任务时可显示/切换分支（本地或远程、支持搜索），普通文件夹置灰（F-237）；存在未提交改动时可选 Commit 到当前分支（默认）、Stash 或丢弃（二次确认）（F-238）。Worktree Task 基于 git worktree 为并行任务提供完全隔离的工作目录，与主仓库共享分支和 Git 对象；非 Git 项目不显示开关（F-239）。创建时在 `~/WorkBuddy/Worktrees` 下建独立目录，基于 Base Branch 的 HEAD commit 新建分支 `workbuddy/{基础分支}-{8位随机哈希}`，Base Branch 创建后锁定（F-240）。清理阈值：达 25 个提示清理；达 50 个弹「任务工作区已达上限」，需选择清理超过 7/15/30 天前的工作区，取消则阻塞创建（F-241）。V1 不支持：云端使用、非 Git 或跨多仓库、fork 已有 Worktree Task、任务内切换分支（F-242）。

## 6. 项目协作

项目以「项目→任务」两层共享上下文与知识，统一组织指令、连接器、专家、技能和资料（F-207）。公共配置含名称、指令（全局行为规则，所有任务自动继承）、连接器、专家、技能，创建任务时自动注入任务上下文（F-208）。项目级代码配置读取工作目录下 `.codebuddy/`（`rules/`、`agents/`、`skills/`、`commands/`、`CODEBUDDY.md`），与 CodeBuddy Code 一致、可提交版本控制，按「项目级 > 用户级」生效（F-209）。连接器分公共授权（管理员配一次、全员共用票据）与个人授权（各自授权、票据不共享），同一连接器可并存两种方式（F-210）。**协作任务中个人授权连接器全部禁用、仅公共授权可用，其调用日志仅管理员可见**（F-212）。任务流转自动打包产物、进度摘要、自定义字段与附件（F-211）；项目资产配额默认 5 GB，资料库内容以 RAG 注入任务上下文（F-212）。

## 7. 企业智能体（需企业坐席账号）

云端 AI Agent 运行平台，提供 Runtime 创建管理、实时对话（ACP/SSE）、版本与快照（Checkpoint/Version）与部署产物发布（F-120）。三概念：Agent（模型/角色/技能工具配置）、Runtime（独立云端沙箱，含 Linux 文件系统与终端、Manifest、多个 Session）、Session（独立对话历史与上下文）（F-121）。创建 Agent 需登录分配了**企业坐席**的个人账号，基础配置含名称、模型（Auto 或内置）、System Prompt（F-122）。Manifest 为声明式 JSON（`manifestVersion` 1.0），必填 `id`/`name`/`manifestVersion`，`system_prompt` 与 `system_prompt_file` 互斥，能力含 `rules`/`skills`/`plugins`/`mcp`/`subagents`（F-123）。工作空间 `workspaces[].name` 必填、secrets 经安全通道注入（F-124）；渠道可接入企微 AIBot、QQ 机器人、飞书与钉钉（F-125）。Session 超 10 分钟无访问自动休眠、再访问自动唤醒；删除 Session 永久清除对话与文件；Runtime 状态分运行中/休眠/失败；Agent 评测消耗个人积分（F-126）。

## 8. 小结

可控点四层：循环确认（F-231）、Plan 闸门（F-233）、权限模式与安全中心（F-198~F-203）、协作期连接器收敛（F-212）；记忆默认开启但零积分成本（F-190、F-192），Worktree 仅限本地 Git、V1 不覆盖云端（F-242）。
