# 企业版管控面与安全合规

> 本篇回答：企业版管控面有哪些、后台能配什么、隐私与安全合规到什么程度。**四层安全说法并存，可核实程度差别很大，引用必须带标签。**

## 1. 产品形态（企业版专属）

WorkBuddy Enterprise 是**腾讯云面向企业的一站式 AI 智能体平台**（F-476），**以腾讯混元大模型为核心、支持多模型混合接入**（F-477），由三款产品构成：**CodeBuddy（智能编码）、WorkBuddy（AI 办公协同）、WorkBuddy Managed Agents（智能体托管与规模化运行）**（F-478）。Managed Agents **基于 WorkBuddy Harness 内核，内置 Agent 内核编排与独立沙箱，直连腾讯云全栈底座与 TKE 弹性算力**（F-479）。

产品优势章节为「全场景一体化覆盖 / 自主执行的智能体能力 / 灵活的模型与开放生态 / 企业级安全可信 / 灵活的交付形态」（F-480），能力贯通「**研发 > 办公 > 运营**」（F-481），宣称**全面兼容 MCP 协议**（F-482）；交付形态三种＝**公有云 SaaS / 专属（SaaS+API）/ 私有化部署**（F-484）。以上为**企业版专属**口径，**核验时点 2026-10-15**。

## 2. 登录与身份

- **企业旗舰版（SaaS 企业版）**：**手机验证码 / 邮箱 / SSO**（SSO 需输入企业域名）（F-485）；
- **企业专享版（专有云企业版）**：**账号密码**登录，客户端需**向企业管理员索取**（F-486）；
- 客户端更新路径「**账户 → 检查更新 → 立即安装**」（F-487）；该页页脚最后更新 **2026-07-31**（F-488）。

**统一身份**：旗舰版已接入「**腾讯统一身份**」做成员管理，除 CodeBuddy 管理员外**还需添加腾讯统一身份管理员**；专享版**未接入、不需要**（F-490）。管理员须在「**账号超级管理员**」与「**CodeBuddy 管理员**」两个角色下**分别添加**（F-491）；**创建人不能移除**（F-492）。腾讯统一身份接入亦见隐私声明（F-442）。

## 4. 企业 Skill 管理（取得正文）

企业 Skill 管理用于**统一下发与管理组织内 CodeBuddy / WorkBuddy 的能力扩展**（F-493），**内置 Skill 301 个**（F-494）；要点：

- **双层策略**：Skill 下发策略 + 成员自定义 Skill 策略（F-495）；
- **优先级**：黑名单 > 白名单 > 默认允许（F-496）；
- **包结构**：`SKILL.md`（必填）+ `manifest.yaml`（必填）+ `scripts/` + `references/` + `assets/`，上传 `.zip`（F-497）；
- 分类名称 2–20 字符、描述 ≤500 字符（F-498）；**删除分类不删除 Skill**（F-499）；
- 管理员只控「**能使用哪些 Skill**」，**不干预客户端实际调用**（F-500）；
- **成员自定义 Skill 仅上传者本人可见**（F-501）；
- 入口「**AI 资源管理 - Skill 管理**」（F-502），页脚最后更新 **2026-07-06**（F-503）。

## 5. 安全与合规：分层呈现

### 5.1 官网宣传口径（W0）

**全链路数据加密**——「传输与存储全程 TLS/AES-256 加密，密钥独立托管」（F-515）；**精细权限管控**——「基于角色的多级权限体系与操作审计日志，管理员可精确控制谁能访问、编辑与导出每一份内容」（F-516）；**权威合规认证**——「已通过 ISO 27001、SOC 2 与等保三级认证，数据存储符合本地化合规要求」（F-517）。**落差判定**：**核验时点 2026-10-15**，三项认证与密钥托管在文档站四区**零印证**，官网**无证书查询入口**（[核验报告](../references/verification.md) 口径 1）——引用必须写「**官网宣传口径、文档侧未印证**」。

### 5.2 企业版产品优势口径（W2）

**安全六项**＝资产安全、身份管控、企业级加密、模型可信、审计合规、内容安全（F-483）——**仅名目，无机制细节**。

### 5.3 文档可配置项（W1）

安全中心含 **13 个分组**：沙箱安全、文件安全（读/写/删三态规则）、命令安全（按前缀）、网络安全（按域名 URL）、自动备份、工具管控、安全网关、传输加密、敏感保护、删除保护、批量删除审批、内置运行时、审计中心（F-202）。**批量删除审批**默认一次删除达 **50** 需审批且**需先开删除保护**；**自动备份默认开启**（改前生成快照、共享备份空间默认上限 **3000 MB**）；**敏感保护默认开启**并内置覆盖各类 API Key 的规则库（F-203）。

### 5.4 隐私声明（P1）

`/privacy` 实为《腾讯云代码助手**隐私保护声明**》（F-427），**生效 2025-09-26**（F-440），适用范围指向 `cloud.tencent.com/product/acc`（F-441），**全文以「腾讯云代码助手」为主体、未出现 WorkBuddy 品牌**（F-427，**核验时点 2026-10-15**）。要点：接入**腾讯统一身份**（F-442）；企业认证收集的个人敏感信息清单（F-444）；信息**存储于中国大陆境内**（F-445）；第七章「信息安全」——加密保护、限制访问人员范围并审计、泄露启动应急预案并按《国家网络安全事件应急预案》上报（F-446）；**第三方共享清单**列明「腾讯统一身份（含集成 SDK）」（F-447）；邮箱 `acc@tencent.com`、验证后 **15 天内**回复，账号注销需经腾讯统一身份后台（F-448）。

### 5.5 安全口径三层对照

| 口径层级 | 可核实程度 | 证据编号 |
|---|---|---|
| 官网宣传口径 | 文档站四区**零印证**；认证为自述、**无证书查询入口** | F-515、F-516、F-517 |
| 企业版产品优势口径 | 渲染核实，仅**六项名目**、无机制细节 | F-483 |
| 文档可配置项 | 给出**可照做的配置项**，操作类事实可靠度较高 | F-202、F-203 |
| 隐私声明 | 全文为《腾讯云代码助手隐私保护声明》，**品牌主体不符**（勘误 E-4） | F-427、F-440 ~ F-448 |

## 6. 数据与本地处理

**所有文件处理默认在本地完成、原始数据不上传云端**；服务端**仅处理数据片段、用后即弃，不保存也不用于模型训练**；只能访问**主动授权**的文件夹，**敏感目录自动拦截**、高危操作二次确认（F-027）——属**文档可配置项**，与官网「全链路加密」（F-515，**官网宣传口径**）不同层。

## 7. 账号注销

支持**个人账号**注销，提交后进入 **15 天冷静期**，期满正式注销、**数据永久删除不可恢复**（F-037）。后果：数据删除（资料/任务/文件/知识库/对话记忆/定时任务/AI 产出/记忆库）、**订阅终止且剩余积分不予折现**、第三方授权（GitHub/CNB/TAPD）解除、**关联 CodeBuddy 账号同步注销**、**15 天内该手机号不支持重复注册**（F-038）。**暂不支持换绑手机号**，无法绕过 15 天限制（F-039）；小程序端设置页同样注明（F-401，**三端差异**）。流程三步：①风险确认并勾选协议 → ②手机号短信验证码 → ③键入「**确认注销**」四字激活按钮后提交（F-040）。
