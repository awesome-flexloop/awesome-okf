# 资料库与知识库：内容组织、协作与集成

WorkBuddy 通过**资料库**收拢人与 Agent 的产出，并以连接器接入腾讯文档、乐享、ima 等外部知识源。本页说明其组织、协作、发布与联动方式。

## 资料库：人与 Agent 共同的产物存放地

资料库是「人和 Agent 共同的产物存放地」，由**内容管理、多人多 Agent 协作、轻量发布**三块能力组成（F-159）。它区别于普通网盘，在于让 **MD、CSV、HTML 互相引用、彼此联动**——文档被页面引用、表格被页面渲染，改一处处处生效（F-160）；分工为 **MD 决定内容、CSV 存储数据（唯一数据源）、HTML 负责表达**（F-162）。目录树容纳 MD/CSV/HTML、PDF/Word/PPT/Excel、PNG/JPG/MP3/MOV，区分个人与团队分区；**Agent 读写资料库的权限与当前用户完全一致、不越权**（F-161）。

- **权限**：「我的文档」仅本人可见；团队空间按权限档位可见；「发布为网站」默认关闭，开启后任何获得链接者都可访问，域名 `workbuddy.link`（F-163）。
- **配额**：体验版 5GB、标准版 10GB、高级版 20GB、旗舰版 50GB（F-164，另见 F-070）。
- **存储与计费**：由腾讯网盘提供存储；**存储、检索不消耗积分，AI 加工消耗积分**（F-164）。

## 团队空间与权限

团队空间在资料库左栏「+ 新建空间」创建，可嵌套整理；放资料含新建文档或表格、上传本地文件、剪藏网页链接、让 Agent 直接生成（F-165）。成员权限四档：**查看**（浏览不可改）、**编辑**（新建修改整理）、**管理**（管成员与权限）、**无权限**（不可访问）（F-166）。企业版管控：**允许组织外协作**时任何人登录可加入；**仅允许组织内协作**时默认「组织内」、无法邀请外部账号（F-167，企业版专属）。**人看不到的内容 Agent 也读不到**（F-168）。

MD 审阅模式：划词评论每条为讨论线程（多轮回复、@ 提及、状态流转）；**AI 修订不覆盖原文、标「待确认」**并列出「原文/改后」对照，接受后才写入正文（F-169）；**MD 划词需审阅接受，HTML 划词直接修改即时可见**，撤销/重做支持逐层回退（F-170）。

## 内容管理

界面分「我的文档」（个人空间）与「团队空间」（项目共享资料）（F-171）。入库两条路径：**会话中让 Agent 保存**，或**分享即存入**（分享 → 发布页签开启「发布为网站」）（F-172）。企业版发布范围由管理员配置：**允许全网发布**时免登录可访问，**仅允许组织内发布**时须登录并校验身份（F-173，企业版专属）。入库格式含 MD/CSV/HTML、PDF/Word/PPT/Excel、PNG/JPG/MP3/MOV 及剪藏网页链接（F-174）。本地 HTML 可视化编辑含手动调样式与 AI 编辑，JS 动态生成元素受保护、仅 AI 可改（F-175）；Markdown 编辑器含划词菜单（AI 编辑｜加粗/斜体/下划线/删除线/链接/行内代码）与悬浮快捷菜单（列表/表格/代码块/Mermaid/图片/视频等）（F-176）。

## 轻量发布

把本地 HTML 上传为在线链接，配合 CSV 作数据底座即成轻应用（F-177）。路径：页面右上角「分享」→「发布」页签 → 打开「发布为网站」；**「邀请协作」是共同编辑，「发布为网站」是只读对外访问**（F-178）。链接用 `workbuddy.link` 域名，形如 `https://workbuddy.link/p/{页面 ID}`；**页面修改写回数据表、数据表修改页面也跟着变**（F-179）。

## 外部知识源与四类载体对比

腾讯文档、乐享、ima 均经连接器接入，与资料库在定位、授权与解绑上差异明显；下表按四维对照。

| 载体 | 定位 | 授权方式 | 可存回 / 联动 | 解绑 |
| --- | --- | --- | --- | --- |
| 腾讯文档 | 多人实时协作的云端办公文档工具，搜索/预览/引用/回写一站完成（F-250） | 资料库 →「腾讯文档」→ 立即前往授权；授权含读取内容、编辑管理文件、微信/QQ 扫码登录（F-251） | MD 产物默认建为「智能文档」；支持语义与关键词搜索（F-254） | 仅个人账号支持端内解除绑定（F-254） |
| 乐享知识库 | 面向企业与团队的 AI 知识库，四大能力（F-255） | 资料库 →「乐享知识库」→ 立即前往授权 → 微信扫码/手机号登录（F-256） | 产物按「团队空间」存回（F-258） | 均支持「更多（⋯）→解除绑定」（F-258） |
| ima 知识库 | 「搜、读、写」一体的 AI 知识工作台（F-259） | 企业账号＝企业版＋个人版双连接器；其他企业旗舰版＝仅个人版（F-260） | 按个人/共享/订阅三类知识库存回（F-263） | 个人版随时解绑；企业版由企业统一管理、不支持解绑（F-261） |
| 资料库 | 人和 Agent 共同的产物存放地（F-159） | Agent 权限与当前用户完全一致（F-168） | 自身即存放地，MD/CSV/HTML 互相联动（F-160） | 不适用 |

## 人机双写

右侧边栏文件预览区的 AI 协作编辑能力，可手动编辑或下令增删改写排版，底层由**腾讯文档提供技术支持**（F-243）；本地与云端沙箱任务均可直接使用、体验一致（F-244）。**AI 编辑**针对选区调整（润色、排版、生成、公式批量处理），**手动编辑**处理错别字、字号等简单操作（F-246）；**手动编辑不消耗积分，AI 编辑消耗积分**，且仅对主动打开的文档操作、不扫描其他文件（F-249）。三端差异：**云端任务的人机双写仅 PC web 提供，项目与助理场景暂不支持**（F-247）。入口在有工具栏品类（Word/PPT）位于工具栏最左侧，无工具栏品类（Excel/Markdown）选中后浮出图标；Enter 加入输入框、Ctrl/Cmd+Enter 直接发送（F-248）。

## ima 实践教程簇的方法（概括）

官方 ima 实践教程（F-264 ~ F-283）共享同一方法：**先按近期任务建主题知识库（非大而全）、首批资料 10–20 条**，再把有复用价值的产物回传 ima 形成知识复利（F-264、F-266、F-267）。OPC 一日（F-268 ~ F-272）、创作者策略（F-273 ~ F-276）、学习助手（F-277 ~ F-279）、求职展示（F-280 ~ F-283）四类场景均为同一「知识库＋产物回传」骨架的套用，非固定模板（F-268）。

## 引用口径与核验时点

能力、限额、域名、权限档位为**文档可配置项**；企业版权限与发布范围标注**企业版专属**，云端人机双写范围标注**三端差异**；乐享「四大能力」、腾讯文档「一站完成」为**官网宣传口径**。核验时点 **2026-10-15**，口径分层与勘误见 [核验报告](../references/verification.md)。
