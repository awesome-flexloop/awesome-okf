# 实战 05 · 知识库工作流

WorkBuddy 的资料库是「人和 Agent 共同的产物存放地」，由内容管理、多人多 Agent 协作、轻量发布三块能力组成（F-159）；它区别于普通网盘之处在于让 MD、CSV、HTML 三种载体互相引用、彼此联动（F-160）。本篇演示如何组织资料库、接入外部知识源，并把产物回存形成知识复利。机制说明见 [concepts/06-knowledge-base-and-library](../concepts/06-knowledge-base-and-library.md)。

## 前置条件

- 已登录 WorkBuddy 客户端。
- 资料库容量随会员版本变化：体验版 5GB、标准版 10GB、高级版 20GB、旗舰版 50GB（F-164、F-070，F-070 口径为官网定价页）。
- 连接对应集成需要授权：腾讯文档（F-251）、乐享知识库（F-256）、ima 知识库（F-262）均需先完成授权。
- 了解资料库定位：内容管理 + 多人多 Agent 协作 + 轻量发布（F-159）。

## 操作步骤

### A. 组织资料库

资料库界面分「我的文档」（个人空间，你和 Agent 共同产物的默认落脚点）与「团队空间」（项目共享资料）两块（F-171）。

1. 在团队空间点标题右侧「+ 新建空间」创建空间，可像文件夹一样嵌套整理文档树（F-165）。
2. 往空间放资料有四条路径（F-165）：新建文档或表格 / 上传本地文件 / 剪藏网页链接 / 让 Agent 直接生成到团队空间。

### B. 设置成员权限

成员权限四档（F-166）：

| 权限档位 | 能力 |
| --- | --- |
| 查看 | 浏览，不可修改 |
| 编辑 | 新建、修改、整理内容 |
| 管理 | 管理成员与权限设置 |
| 无权限 | 不可访问 |

- 获得链接的人可单独设定访问方式（F-166）。
- **企业版专属**：可配置「允许组织外协作」（任何人登录后可加入）或「仅允许组织内协作」（分享范围默认「组织内」，无法邀请组织外账号）；空间默认不对外公开（F-167）。
- Agent 按同一权限读取，不必为 Agent 单独维护权限，人看不到的内容 Agent 也读不到（F-168）。

### C. 连接腾讯文档

1. 左栏「资料库」→「腾讯文档」→「立即前往授权」，即获文档读取权限；授权项含读取文档内容、编辑与管理文件、微信/QQ 扫码登录对应文档账户（F-251）。
2. 三种导入方式（F-252）：导入本地文件 / 导入本地文件夹（整目录导入、保留目录结构）/ 从腾讯文档个人版导入（需先在腾讯文档选择器完成登录；**部分版本不提供该方式**）。
3. 引用与搜索：支持语义搜索与关键词搜索（可搜标题与所有者）；任务引用点「添加到任务」（F-254）。

### D. 连接 ima 知识库

1. 个人版连接步骤：资料库 → 选「ima 知识库」→「立即前往授权」→ 微信扫码登录 → 确认授权（F-262）。授权后可查看知识库列表、查看或搜索资料，并将知识库文件添加到任务或保存回 ima。
2. 连接器数量因账号环境不同：**企业账号提供 ima 知识库企业版 + 个人版双连接器；其他企业旗舰版仅提供个人版连接器**（F-260，企业版专属）。
3. 解绑差异：企业版经企业统一身份授权、由企业统一管理且**不支持解绑**；个人版使用个人微信扫码授权、**支持随时解绑**；两连接器授权状态相互独立（F-261）。

### E. 连接乐享知识库

1. 左栏「资料库」→ 选「乐享知识库」→「立即前往授权」→ 微信扫码登录 / 手机号登录（首次需绑定手机号）（F-256）。
2. 授权后获得读取知识库、搜索和查询知识内容、创建和编辑知识内容的权限（F-256）。
3. 产物可按「团队空间」储存回乐享（F-258）。

### F. 让产物回存形成知识复利

1. 打开生成内容 → 产物区域「上传到云端」→ 选「ima 知识库」→ 保存到对应主题知识库（F-267）。
2. 也可按团队空间存回乐享知识库（F-258）。

> 未在本机实跑，依据官方文档（F-159、F-164、F-070、F-171、F-165、F-166、F-167、F-168、F-251、F-252、F-254、F-260、F-261、F-262、F-256、F-258、F-267）。

## 结果判据

- 新建或导入的资料出现在资料库目录树对应空间下（F-165）。
- 授权成功后获得目标知识库的读取/搜索/编辑权限（F-251、F-256、F-262）。
- 产物上传后出现在目标知识库（F-267），或按团队空间存回乐享（F-258）。

## 限制与边界

- **建库方法论**（F-264 ~ F-266）：按任务目标建立主题知识库，不要一开始就建「大而全」的知识库（如「我的资料库」「AI 资料库」）；第一批资料建议控制在 10–20 条以内，避免将多个无关主题混在同一个知识库中。
- **三端差异**：云端任务的人机双写当前仅在 PC web 端提供，项目与助理场景暂不支持（F-247）。
- **登录态差异**：Office 文档（Word/Excel/PPT）编辑需要登录；Markdown 不登录也能看、能编辑（F-151）。
- **积分边界**：存储检索等不消耗积分、AI 加工消耗积分（F-164）。
- **企业版专属**：发布范围由管理员配置——允许全网发布时无需登录即可访问，仅允许组织内发布时须登录并以组织内身份校验后才能查看（F-173）。
- 相关口径以核验时点 2026-10-15 的官方文档为准，未在本机实跑。
