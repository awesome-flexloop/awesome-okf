# 让任务自己跑：定时任务、云端执行与企业智能体

> 适用场景：把「每天 / 每周固定要做的事」交给 WorkBuddy 按时间自动执行，并了解云端执行与企业智能体（CloudAgent）的能力与边界。桌面端助理（远程控制）部分见[云助理、定时任务与企业智能体](../concepts/07-cloud-agent-and-automation.md)。

## 前置条件

- 桌面端已安装并登录 WorkBuddy；官网下载入口分桌面端（Mac / Windows / Linux 到系统应用商店下载 / 鸿蒙电脑版）与移动端（iOS / Android / 鸿蒙手机版扫码、小程序扫码体验）（F-519，`官网宣传口径`）。
- 若希望任务在无人值守时也照常执行，需将执行权限切到**完全访问权限**——该模式推荐用于无人值守、工具调用无需逐次确认；默认权限下敏感操作需确认，人不在电脑前任务会停在等待确认状态（F-112）。
- 定时任务按来源分三类：**本地**（电脑端创建、本机执行）、**项目**（项目中创建）、**云端**（云端沙箱执行，卡片带云端标识）（F-110）。

> 未在本机实跑，依据官方文档（F-110 ~ F-126）。本束未安装 WorkBuddy、未创建过定时任务，也未开通企业版。

## 操作步骤

### A. 创建定时任务（三种方式，F-111）

1. **手动新建**：精确指定时间 / 权限 / 推送渠道。
2. **从任务新建**：用一句话描述需求。
3. **从模版新建**：从常见场景快速上手。

（三种方式与配置项同见 F-111。）

### B. 配置项与推送约束（F-111 ~ F-113）

配置项含名称、提示词、模型 / 专家 / 技能 / 连接器、工作空间、权限、重复、时间、有效期与「消息推送到企业微信」（F-111）；执行权限两档、重复规则七种可选（F-112）。

| 配置项 | 可选值 / 说明 | 事实 |
|---|---|---|
| 名称、提示词 | 任务名称与执行提示词 | F-111 |
| 模型 / 专家 / 技能 / 连接器 | 按需选择 | F-111 |
| 工作空间 | 任务工作目录（云端任务编辑时无需选择） | F-111、F-114 |
| 权限 | 完全访问权限（推荐、无人值守）/ 默认权限（敏感操作需确认） | F-112 |
| 重复 | 间隔 / 单次 / 每天 / 每周 / 每双周 / 每月 / 每年 | F-112 |
| 时间、有效期 | 执行时点与有效期 | F-111 |
| 消息推送到企业微信 | 见下方两条硬约束 | F-111、F-113 |

企业微信推送的两条硬约束（F-113）：推送对象可选「助理的企业微信 bot」或「独立 bot」，但**助理的 bot 必须选用 WebSocket 长连接方式，URL 回调方式无法推送**；推送**仅作结果通知、不写入助理对话上下文**，推送**失败也不影响任务本身执行**。

### C. 运行记录与排障（F-115）

运行记录可**按状态（成功 / 失败 / 运行中）**与**任务类型（本地 / 项目 / 云端）**筛选；失败可查看原因，常见原因为**连接器未授权、登录已失效、电脑离线错过执行时间**等（F-115）。本地任务执行期间请勿关闭电脑或退出客户端（F-115）。

### D. 云端定时任务的边界（F-114）

- 编辑时**无需选择工作空间和权限**；
- **不支持推送到企业微信**；
- **云端沙箱无法访问本机文件**；
- **删除云端任务后，已产生的云端会话仍保留**；
- **离线时只能查看、联网后才能操作**（F-114）。

### E. 企业智能体 CloudAgent（`企业版专属`，F-120 ~ F-126）

1. **进入**：创建 Agent 需登录**分配了企业坐席**的个人账号，点右上角「企业智能体」进入企业后台；基础配置含名称、模型（Auto 模式或内置模型）与 System Prompt，添加的技能 / 专家 / MCP 会自动同步到 Manifest（F-122）。
2. **理解三概念**（F-121）：Agent＝定义模型 / 角色 / 技能工具的完整配置；Runtime＝独立云端沙箱（含完整 Linux 文件系统与终端、Manifest 配置，可含一个或多个 Session）；Session＝独立对话历史与上下文。
3. **写 Manifest**：声明式 JSON，`manifestVersion` 当前为 **1.0**，基础必填 `id` / `name` / `manifestVersion`，且 `system_prompt` 与 `system_prompt_file` **互斥**；能力配置含 rules / skills / plugins / mcp / subagents（F-123）。
4. **配工作空间与密钥**：`workspaces[].name` 必填并映射到 `/workspace/<name>/`，可选 Git 仓库 URL、源码包 URL、ref 与初始化命令；`secrets` 经安全通道注入、**不写入沙箱文件**，系统自动注入 `AGENTOS_RUNTIME_ID`（F-124）。
5. **接渠道**：支持企微 AIBot、QQ 机器人、飞书、钉钉，每条接入记录对应一个 **Bot → Session 绑定**；凭据加密存储与代理注入，运行时由代理层解密注入请求头（F-125）。

> 未在本机实跑，依据官方文档（F-120 ~ F-126）；本束未开通企业版，未创建 Agent、Runtime 或 Session。

## 结果判据

- 定时任务出现在任务列表中，按设定重复规则与时间自动执行，并集中保存每次运行的结果与产物（F-110、F-111）。
- 运行记录可按状态与任务类型筛选；失败项可查看原因（F-115）。
- 企业智能体侧：Session 超过 **10 分钟**无访问会自动休眠、再次访问自动唤醒；删除 Session 将永久清除对话记录和文件；Runtime 状态分**运行中 / 休眠（空闲超时自动暂停）/ 失败**（F-126）。

## 限制与边界

| 边界项 | 约束 | 事实 |
|---|---|---|
| 本地任务执行期间 | 请勿关闭电脑或退出客户端 | F-115 |
| 云端沙箱 | 无法访问本机文件；离线时只能查看 | F-114 |
| 云端任务推送 | 不支持推送到企业微信 | F-114 |
| 企业微信推送 | 助理 bot 须用 WebSocket 长连接，URL 回调无法推送 | F-113 |
| Session | 10 分钟无访问自动休眠；删除即永久清除对话记录与文件 | F-126 |
| Runtime | 状态分运行中 / 休眠 / 失败 | F-126 |
| Agent 评测 | 消耗**个人积分** | F-126 |
| 准入 | 企业智能体需企业坐席，`企业版专属` | F-122 |

- 远程控制（助理）与本章自动化 / 云端能力的职责边界，见 [云助理、定时任务与企业智能体](../concepts/07-cloud-agent-and-automation.md)。
- 口径标签：E 节为 `企业版专属`；下载入口为 `官网宣传口径`（F-519）；其余为 `文档可配置项`。核验时点 **2026-10-15**。
