# 操作用例

本目录收录 WorkBuddy 知识包的 9 篇操作用例，从安装上手（00 ~ 02），到扩展集成（03 ~ 05），再到自动化与企业落地（06 ~ 08）。所有用例均转述官方文档与官网页面描述，**本知识包未在本机安装或实跑过 WorkBuddy**。
