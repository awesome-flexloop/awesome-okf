# 从零开始：安装 WorkBuddy 并跑出第一个任务

> 本知识包**没有在本机安装或实跑过 WorkBuddy**。下文所有步骤、判据与限额均转述官方文档与官网页面描述，不是操作记录；核验时点为 2026-10-15。

## 前置条件

- **桌面端设备**：Windows 或 macOS。官方历史版本归档中，每个版本同时提供 macOS（Apple 芯片 / Intel）与 Windows 64 位安装包（F-041）；最新版本 v5.7.7（2026-10-09）三个包体分别约 340.8 MB、368.4 MB、415.7 MB（F-042，核验时点 2026-10-15）。
- **下载入口**：官网 https://www.workbuddy.cn/ 。官网首页给出的端别清单为——桌面端 Mac / Windows / Linux（请到系统应用商店下载）/ 鸿蒙电脑版，移动端 iOS / Android / 鸿蒙手机版扫码与小程序扫码体验（F-519，**官网宣传口径**）。
- **可微信扫码的账号**：首次进入需扫码登录，个人用户选「个人」，企业版用户选「企业」（F-012）。

## 操作步骤

1. 打开官网 https://www.workbuddy.cn/ ，悬停「下载」按钮，选择与自己系统匹配的 WorkBuddy 版本（F-011）。
2. 下载完成后双击运行安装包（F-011）。
3. 跟随安装指引完成安装；官方建议选择「仅为我安装」（F-011）。
4. 启动 WorkBuddy，用微信扫码登录，并按账号类型选「个人」或「企业」（F-012）。
5. 在主界面点击「新建任务」（F-012）。
6. 在对话框里用自然语言描述你想要的成果（文档、表格、PPT 等可直接使用的交付物）（F-002、F-012）。
7. 点击「发送」，WorkBuddy 即开始自主规划与执行任务（F-012）。

> 以上 7 步均**未在本机实跑**，依据官方文档（F-011、F-012、F-002）。

## 结果判据

以下是官方文档描述的应然状态（**未在本机实跑**，仅作判据参照）：

- 登录成功后可看到工作界面四区域：顶部工具栏、左侧边栏（任务列表按文件夹分组）、中间对话区、右侧结果区（F-006）。
- 点击发送后任务进入执行；任务状态可取：进行中、已完成、失败、待处理、规划中、已归档（F-020）。
- 右侧结果区提供四类内容：概览（工作空间文件）、浏览器、变更（本次任务文件修改）、产物（任务生成的文件与交付物）（F-028）。

## 限制与边界

- **积分消耗**：所有对话相关请求都需消耗积分，消耗量随任务复杂度与所用高级模型而异；高级模型输入 / 输出 Token 单价更高，长代码分析、多轮对话、知识库检索类复杂任务消耗更多（F-032、F-033）。积分按月发放、当月有效、不累积结转（F-035）。
- **本地文件与隐私边界**：所有文件处理默认在本地完成，原始数据不上传云端；服务端仅处理数据片段、用后即弃，不保存也不用于模型训练；WorkBuddy 只能访问你主动勾选授权的文件夹，敏感目录自动拦截、高危操作二次确认（F-027）。
- **版本选择**：官方建议下载官网最新版本；历史版本下载页按二级版本号分组、组内按发布时间倒序，归档版本提供至 4.8.x 系列（如 v4.8.1，2026-04-04）（F-041、F-043）。
- **端别口径差异**：官网首页的端别清单比文档站更宽（含 Linux 与鸿蒙），属**官网宣传口径**，实际可下载范围以官网下载入口为准（F-519）。

### 账号注销边界

- WorkBuddy 支持**个人账号**注销；提交后进入 **15 天冷静期**，冷静期结束账号正式注销，所有数据永久删除且不可恢复（F-037）。
- 注销后果：个人资料 / 任务 / 文件 / 知识库 / 对话记忆 / 定时任务 / AI 产出文件 / 记忆库一并删除；订阅服务终止且剩余积分不予折现；GitHub、CNB、TAPD 第三方授权自动解除；关联 CodeBuddy 账号同步注销；15 天内该手机号不支持重复注册（F-038）。
- **暂不支持换绑手机号**：想用其他手机号只能登录其对应账号，无法借换绑绕过 15 天重新注册限制（F-039）。
- 注销流程共三步，前一步通过才能进下一步：风险确认并勾选协议 → 手机号短信验证码 → 精确键入「确认注销」四字激活按钮后提交（F-040）。执行前请先确认是否已完成数据备份诉求。
