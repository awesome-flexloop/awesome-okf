# 企业版开通与后台配置

> 适用场景：企业管理员需要开通 WorkBuddy 企业版、为成员分配管理员角色，并把组织级的 Skill 统一下发到 CodeBuddy / WorkBuddy 客户端。企业管控面总览见[企业版管控面与安全](../concepts/11-enterprise-admin-and-security.md)。

## 前置条件

- **`企业版专属`**：WorkBuddy Enterprise 是腾讯云面向企业打造的一站式 AI 智能体平台（F-476），交付形态含公有云 SaaS、专属（SaaS+API）与私有化部署（F-484）；后台配置对象为企业旗舰版（SaaS 企业版）或企业专享版（专有云企业版）。
- **席位与起购量**：企业旗舰版 **1 个坐席起购**；企业专享版**缩容下限 100 个**（F-505、F-508）。
- **客户端获取**：企业专享版使用账号密码登录，**客户端需向企业管理员索取**（F-486）。
- 版本时效：企业版文档页脚时间戳区间为 2026-07-06 ~ 2026-09-19，**落后于其 sitemap 时间戳（2026-10-14）约 3 个月**，故企业版细节须带核验时点引用（核验时点 2026-10-15，详见[核验报告](../references/verification.md)）。

> 未在本机实跑，依据官方文档（F-485 ~ F-509）。本束未开通企业版，未进入过企业管理后台。

## 操作步骤

### A. 购买与开通（F-504 ~ F-506、F-509）

1. 购买入口为 **`workbuddy.cn/pricing/`**（F-504）。
2. 可按**月**或按**年**订阅（F-506）。
3. 管理后台入口为 **`workbuddy.cn/admin/`**（F-509）。
4. 购买方式章节另含账单管理 / 团队管理 / 用量管理 / 变配与续费 / 发票管理（F-510）。

### B. 登录（F-485 ~ F-487）

| 版本 | 登录方式 | 事实 |
|---|---|---|
| 企业旗舰版（SaaS 企业版） | 手机验证码 / 邮箱 / SSO（SSO 需输入企业域名） | F-485 |
| 企业专享版（专有云企业版） | 账号密码（客户端向企业管理员索取） | F-486 |

客户端更新路径为「**账户 → 检查更新 → 立即安装**」（F-487）。

> 客户端侧「登录」入口的逐条描述本次采集**未取得独立事实编号**，因此本页不将其列为可照做步骤，只给出上表登录方式。

### C. 添加管理员（F-489 ~ F-492）

1. 登录企业管理后台 → 左侧导航「**成员授权**」→ 管理员角色 → 添加管理员 → 选择成员并确定（F-489）。
2. **企业旗舰版**还需在腾讯统一身份后台的「**账号超级管理员**」与「**CodeBuddy 管理员**」两个角色下**分别添加**——两个角色均需添加，添加不全可能导致无法完整管理企业通讯录（F-490、F-491）。
3. **企业专享版未接入腾讯统一身份**，仅添加 CodeBuddy 管理员即可（F-490）。
4. **创建人不能移除**（F-492）。

### D. Skill 统一下发（F-493 ~ F-503）

企业 Skill 管理用于统一下发与管理组织内 CodeBuddy / WorkBuddy 能力扩展（F-493），当前内置 Skill 为 **301 个**（F-494）。

1. 进入「**AI 资源管理 - Skill 管理**」（F-502）。
2. 在 Skill 列表点右上角 `+` 上传 Skill：填写 **Skill 标识、显示名称、分类**（必填），版本与描述选填；上传本地 Skill 包 **`.zip`**（F-493、F-497）。
3. 切换到「**分类管理**」新建分类：**名称 2–20 字符、描述 ≤500 字符**（F-498）。
4. 进入「**Skill 下发策略**」新建**白名单或黑名单**策略并设定作用范围（F-493、F-495）。

Skill 包结构为 `SKILL.md`（必填）+ `manifest.yaml`（必填）+ `scripts/` + `references/` + `assets/`，上传支持 `.zip`（F-497）。

### E. 成员自定义 Skill 策略（F-495）

进入「**成员自定义 Skill**」页签 → 修改策略 → 在**白名单 / 黑名单 / 允许所有 / 禁止所有**之间选择 → 保存（F-495，与 D 节构成双层策略架构）。

> 未在本机实跑，依据官方文档（F-489 ~ F-503，`企业版专属`）。

## 结果判据

- 管理员添加成功后，该成员具备企业后台管理权限（F-489）。
- Skill 上传后在列表中可见，并带有状态与可见范围；分发策略保存后**即时生效**（F-493、F-495 ~ F-499）。
- 成员自定义 Skill 策略仅对**上传者本人**可见（F-501）。

## 限制与边界

| 边界项 | 约束 | 事实 |
|---|---|---|
| 每成员积分 | 企业版每成员**默认 2000 积分限额**，超限不可用 | F-507 |
| 策略优先级 | **黑名单 > 白名单 > 默认允许** | F-496 |
| 管理员权限范围 | 只控「能使用哪些 Skill」，**不直接干预客户端实际调用** | F-500 |
| 成员自定义 Skill | 仅上传者本人可见 | F-501 |
| 分类删除 | 删除分类**不删除 Skill**，仅解除关联 | F-499 |
| 脚本执行风险 | Skill 包内脚本将在客户端沙箱中执行，建议对含敏感操作的 Skill 配白名单 | F-497 |
| 模型管控 | 管理员后台**禁用的模型会在客户端模型选择器同步隐藏或置灰（含 auto）** | F-197 |
| 账号注销 | 企业账号及最终用户账号注销需经腾讯统一身份管理后台操作（官方隐私声明 F-448） | F-448 |

- **核验状态提示（`未取得`）**：企业管理后台的多数子页——**模型管理、模型部署管理、提示词管理、自定义指令、专家管理、Playbook、Connector 管理、知识库管理、日志管理、IP 白名单、研发度量、席位管理、飞书 / 企业微信集成、计费页**——在核验时属「**未取得**」（语义路径别名至产品概述或客户端渲染占位，F-512、F-513）。本页因此**只对已取得正文的 Skill 管理与管理员添加给出步骤，其余项不编造配置步骤**。
