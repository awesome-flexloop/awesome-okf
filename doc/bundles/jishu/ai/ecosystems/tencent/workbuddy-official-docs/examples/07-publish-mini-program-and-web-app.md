# 把成果发布出去：微信小程序、网站应用与云服务

> 适用场景：把业务想法、活动或内部工具做成可对外访问的微信小程序 / 网站应用，并按需接入云服务。三端差异见[多端协同与腾讯生态](../concepts/09-multidevice-and-tencent-ecosystem.md)。

## 前置条件

- 已登录 WorkBuddy。WorkBuddy 可按需求生成微信原生小程序与网站应用，并协助完成代码上传、提交审核与版本发布（F-284、F-296）。
- 发布**正式版**需已有微信小程序账号，并**完成备案**、通过微信审核（F-289、F-293）。
- 云服务的使用额度由**会员版本**决定（F-309）。

> 未在本机实跑，依据官方文档（F-284 ~ F-312）。本束未生成、也未发布过任何小程序或网站应用。

## 操作步骤

### A. 生成小程序（F-286 ~ F-287）

1. 首页进入「代码开发」选「**小程序**」，用推荐场景创建（F-286）。
2. 或直接描述需求，并建议写明**「微信小程序」**（F-286）。
3. 已有网页可让 WorkBuddy 改写为微信小程序（F-286）。
4. 需要云服务时**不必写具体技术方案**，说明「数据长期保存、用户登录、图片上传、多人参与」等实际需求即可（F-286）。

### B. 发布小程序（F-288 ~ F-293）

小程序制作完成后，点预览区右上角「**分享**」进入发布流程（F-288）。两条路径：

- **创建试用版**：分享面板选「创建试用版小程序」→ 微信扫码关注 WorkBuddy 服务号 → 服务号点「创建试用小程序」完成授权 → 返回 WorkBuddy 点「发布」（F-290）。
- **绑定已有小程序账号**：小程序管理员微信扫码选账号并按提示授权 → 返回 WorkBuddy 勾选需发布的版本点「发布」（F-292）。

| 版本 | 用途 | 需已有账号 | 需微信审核 | 要点 |
|---|---|---|---|---|
| 试用版 | 快速验证效果 | 否 | 否 | 14 天有效，到期自动注销（F-289、F-291） |
| 体验版 | 上线前调试验收 | 是 | 否 | 仅有体验权限的用户可访问（F-289、F-292） |
| 正式版 | 对外长期运营 | 是 | 是 | 须完成备案并通过审核（F-289、F-293） |

### C. 正式版发布前检查（F-293）

在分享面板「**小程序设置**」依次检查三项：**小程序备案**（未完成时微信可能限制新用户访问或暂停服务）、**用户隐私保护指引**、**用户生成内容场景（UGC）信息安全声明**（F-293）。每个微信小程序**每周可提交 3 次正式版审核**，且审核期间不能再次提交新的正式版更新（F-293）。

### D. 生成与发布网站应用（F-296 ~ F-302）

1. 首页「代码开发」选「**网站开发**」或「**Agent 应用**」（F-298）。
2. 需要 AI 能力时，需求中说明「**接入大模型**」即可，**无需申请 API Key 和配置模型服务**（F-299）。
3. 生成完成后对话中出现网站应用卡片，可在右侧预览区查看运行效果（F-300）。
4. 发布：点预览区工具栏「分享」，或直接在对话中说「**发布**」「**上线**」，得到独立链接；任何获得链接的人都可以访问（F-300）。
5. 发布前建议检查登录、数据保存与角色权限是否正常，并确认页面数据适合对外公开（F-301）。

### E. 接入云服务（F-304 ~ F-308）

云服务让应用能保存和管理用户提交的数据，共四项能力（F-305）：

| 能力 | 用途与要点 | 事实 |
|---|---|---|
| 数据库 | 保存报名、预约、订单、打卡等记录；「数据」页可找到对应数据表 | F-306 |
| 身份认证 | 支持邮箱、手机验证码、微信登录；邮箱登录支持平台托管发信或自定义发信服务 | F-307 |
| 文件存储 | 保存用户上传的图片与文档；**单文件不超过 20 MB** | F-308 |
| 数据统计 | 查看总用户数、新增用户数、注册趋势与用户列表 | F-308 |

注意：在页面开启登录方式**不会自动在应用中添加登录功能**，需要用户登录时直接告诉 WorkBuddy 使用场景和登录方式（F-307）。

> 未在本机实跑，依据官方文档（F-284 ~ F-312）；上述配置项均来自官方文档描述。

## 结果判据

- 生成完成后对话中出现「**微信小程序**」产物卡片，可在右侧预览区查看效果并通过对话修改（F-287）。
- 网站应用生成后出现**应用卡片**，可在右侧预览区查看运行效果（F-300）。
- 进入「**设置 > 数据管理 > 应用**」可集中查看各应用发布状态与发布链接、管理云服务（F-295、F-303）。

## 限制与边界

- **试用版限制**（F-291）：一个微信号最多创建 **5 个**；有效期 **14 天**，到期自动注销、原小程序码无法访问；最多 **15 人**体验。**试用版不能直接转为正式版**（F-290）。
- **体验版**：最多 **15 名**体验成员，其他用户首次打开需申请体验权限、由管理员批准（F-292）。
- **更新与下线**：线上版本**不会自动同步**，需点「更新」（更新正式版需重新提交微信审核）；**目前只有正式版支持下线**（F-294）。网站应用更新后链接不变，下线后原链接无法打开、数据仍保留（F-302）。
- WorkBuddy **不代注册长期运营账号**（F-295）。
- **云服务额度**（F-309）：

| 会员版本 | 可开启云服务的应用数 | 每应用每月资源点 | 隔离期 |
|---|---|---|---|
| 体验版 | 10 | 5,000 | 15 天 |
| 标准版 | 30 | 25,000 | 30 天 |
| 高级版 | 50 | 50,000 | 30 天 |
| 旗舰版 | 99 | 150,000 | 60 天 |

- 资源点**按应用独立发放、独立消耗**，从启用当天起每满一月自动刷新；用完后云服务进入**隔离并停止访问**、数据暂不支持导出（F-310）。隔离期内升级版本云服务立即恢复，否则超期数据将被**永久删除且无法找回**（F-311）。
- **预览版与已发布版本共用同一云服务**，预览测试数据会进入正式数据，**发布前请清理**；目前**不支持单独关闭云服务**（F-312）。
