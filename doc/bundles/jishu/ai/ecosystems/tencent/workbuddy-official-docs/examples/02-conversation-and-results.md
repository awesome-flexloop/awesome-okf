# 对话追问与结果验收

> 本知识包**没有在本机安装或实跑过 WorkBuddy**。下文步骤与判据转述官方文档描述，不是操作记录；核验时点为 2026-10-15。

## 前置条件

- 有一个已执行完成（或正在执行）的任务，例如按 [创建、管理与续用任务](01-create-and-manage-tasks.md) 发送过一句话需求。

## 操作步骤

1. **顶部操作区**（从左到右）：对话内搜索、分享任务（自动生成公开链接）、历史提问、显示详情面板（F-023）。
2. **执行中继续追问**：模型执行时仍可发消息，消息先进入输入框上方的「队列」，可编辑、删除、拖动排序；点击发送会立即发出并引导会话，但**不打断当前输出**（F-024）。
3. **切换右侧结果区**四类内容：概览、浏览器、变更、产物（F-028）。
4. **分享产物**：在预览右上角点分享图标，可上传到 我的云端网盘 / 腾讯文档 / ima 知识库 / 乐享知识库（F-029）。
5. **多页签浏览**：在产物栏导航右侧点「+」新建页签，各页签保持独立的网址与前进 / 后退历史；关闭当前页签会自动选中相邻页签（F-030）。
6. **核对变更**：进入「变更」视图，查看本次修改涉及的文件列表、每个文件的改动情况，以及选中文件的具体变更内容（F-031）。

> 以上步骤均**未在本机实跑**，依据官方文档（F-023 ~ F-031）。

## 结果判据

（以下为官方文档描述，**未在本机实跑**验证。）

- 任务生成的文件出现在结果区的「**产物**」页签，而不是「概览」页签——「概览」列的是工作空间文件本身（F-028）。
- 「**变更**」视图给出本次修改涉及的文件列表与逐文件改动详情，适合在代码开发、脚本生成、配置调整场景下先行核对（F-031）。
- 分享出去的产物会在目标位置（我的云端网盘 / 腾讯文档 / ima 知识库 / 乐享知识库）生成可访问的副本（F-029）。

## 限制与边界

- **可上传的文件类型**（F-026，**文档可配置项**）：PDF、Word、TXT、Markdown、RTF、Excel、CSV、TSV、PPT、常见图片（JPG/PNG/GIF/BMP）、ZIP/RAR 压缩包，以及各类编程语言代码文件。清单之外的类型不在官方支持范围内。
- **链接打开方式三态**（F-025，**文档可配置项**）：直接打开（内置浏览器）、在浏览器打开、复制链接。设置默认「按需」——本地预览内开、普通网页走系统浏览器；可改为「始终内置」或「始终外部」。
- **分享可撤销**：在 头像 → 设置 → 数据管理 →「我分享的文件」中可复制分享链接、下载文件或**取消文件分享**；取消后文件从列表移除，他人无法再通过该链接访问（F-133）。
- **任务公开链接**：对话区顶部的「分享任务」会自动生成公开链接（F-023），分享前需自行评估对话内容是否含敏感信息。
- **预览 ≠ 导出 / 分享**（**三端差异**）：桌面端结果区的预览与分享（F-029）解决的是「看」与「分发」；导出能力集中在 App 端——电脑产物会自动回传 App 并以产物卡片展示，支持导出 PDF / DOCX / Markdown 或导出到腾讯文档（F-355），App 端同名页为「产物查看与分享」，小程序端同类页仅保留分享与链接有效期（F-356）。详见 [多端与腾讯生态](../concepts/09-multidevice-and-tencent-ecosystem.md)。
