# 创建、管理与续用任务

> 本知识包**没有在本机安装或实跑过 WorkBuddy**。下文步骤与判据转述官方文档描述，不是操作记录；核验时点为 2026-10-15。

## 前置条件

- 已按 [从零开始：安装 WorkBuddy 并跑出第一个任务](00-install-and-first-task.md) 完成桌面端安装与微信扫码登录。
- 先想清楚三件事：要交付什么（输出格式）、可提供哪些输入材料、有哪些约束条件——这三点正是官方建议的「补充说明」内容（F-017）。

## 操作步骤

### 创建任务

1. **一句话描述需求**：WorkBuddy 的核心是理解自然语言，一句话即可让它自主规划并执行；官方示例含「生成分析报告」「整理图片」「根据会议纪要生成 PPT」「调研 AI 行业趋势」等（F-014）。
2. **可选：套用提示词模板**。创建任务页按场景（日常办公、代码开发、设计创意）提供模板；悬停模板时输入框显示灰色预览文案，**仅预览、不入草稿、也不会被发送**（F-015，**文档可配置项**）。
3. **可选：指定工作空间**。点击输入框左下角「选择工作空间」指定工作目录；也可以不指定直接开始，WorkBuddy 会在默认目录生成结果（F-016）。
4. **添加上下文（四种方式）**：通过 `@` 引用文件 / 文档 / 规则；Ctrl/Cmd+V 粘贴截图；上传或拖拽文件；用文字补充说明（目标、输入、输出格式、约束条件）（F-017）。
5. 点击「发送」，任务开始执行（F-012）。

> 以上步骤均**未在本机实跑**，依据官方文档（F-012、F-014 ~ F-017）。

### 任务列表、检索与管理

| 维度 | 官方文档口径 |
|---|---|
| 任务列表 | 左侧分「任务」（最近访问或更新）与「空间」（按工作空间整理）两个板块；空项目不显示，分组默认只展示部分任务（F-018） |
| 全局搜索 | 覆盖任务 / 空间 / 产物三类对象，快捷键 Cmd+K（Windows 对应 Ctrl+K）；分「全部 / 任务 / 空间 / 产物」四类独立排序（F-019） |
| 管理菜单 | 悬停任务行点「⋯」或右键，菜单分三组——任务自身（置顶 / 重命名 / 分享任务）、打开与批量、收尾（归档 / 删除）（F-021） |
| 删除提示 | 普通任务提示「将从你的所有设备中移除，且无法恢复」；运行中任务提示「该任务正在执行中，删除将立即终止运行」（F-022） |

### 工作模式与 Plan 流程

- **三种工作模式**（F-232）：默认（Agent）高效执行且可修改文件；计划（Plan）先规划、等确认后再执行；仅问答（Ask）只问答、不执行。
- **Plan 四步流程**（F-233）：开启 Plan → 围绕关键变量提问补信息 → 在右侧面板审阅完整方案 → 确认执行或调整计划；**确认之前不会开始执行**。

## 结果判据

（以下为官方文档描述，**未在本机实跑**验证。）

- 任务进入执行后状态位随进展变化，可取：进行中、已完成、失败、待处理、规划中、已归档；侧边栏状态标记只有三种（进行中、已完成未读、待确认），聚合优先级为 待确认 > 已完成未读 > 进行中（F-020）。
- 每个对话对应一个独立任务，任务之间互不影响、各自维护独立的工作空间与上下文；未提前指定目录时系统会自动创建独立工作目录，并支持多任务并行处理（F-230）。
- 归档不等于消失：进入 头像 → 设置 → 数据管理 →「已归档任务」，可**取消归档**（恢复到任务列表），也可**删除**（弹窗二次确认，删除后不可查看也不能继续对话）（F-134）。

## 限制与边界

- **运行中删除即终止**：对执行中的任务执行删除，会立即终止其运行（F-022）。
- **默认工作目录**：未指定目录时由系统自动创建独立工作目录，产物落在该目录而不是你熟悉的路径下（F-230）。
- **输入区限额**（F-235，**文档可配置项**）：

| 项目 | 官方限额 |
|---|---|
| 拖拽添加文件 | 最多 50 个文件；单个文件大小不限；添加后不会自动发送 |
| 超长粘贴 | 超过 3000 字符自动收起为可展开条目 |
| 历史输入召回 | 最多保留 20 条 |

- **模式选择会改变行为**：默认（Agent）模式会实际修改文件；只想了解结论而不改动文件时应选「仅问答（Ask）」（F-232）。需要人工把关长流程时选 Plan，确认前不会执行（F-233）。
