# 实战 03 · 接入连接器与 MCP

连接器与 MCP 是 WorkBuddy 与外部世界对接的两条通道：连接器把具体服务（邮箱、文档、知识库等）接进来，MCP 把外部工具与数据源按标准协议接进来。本篇给出两条通道的可照做步骤。相关机制见 [concepts/05-connectors-and-mcp](../concepts/05-connectors-and-mcp.md)，口径与信源核验见 [references/verification](../references/verification.md)。

## 前置条件

- 已登录 WorkBuddy 客户端（登录方式见官方「FirstTask」页，扫码登录后即可新建任务，F-012）。
- 了解连接器能接什么：连接器分 `MCP + CLI`（标准化协议）与 `Skill + CLI`（内置脚本）两种形式，已支持 QQ 邮箱、腾讯文档、腾讯乐享、腾讯会议、TAPD、腾讯网盘等（F-127，口径为文档可配置项）。
- 部分服务有客户端版本要求：连接 QQ 邮箱扫码授权需 QQ 邮箱 App 7.1.5 / 鸿蒙 0.2.9 及更新版本（F-130）。
- MCP 接入无需编码、无需手动修改配置文件，界面可视化操作即可完成（F-180）。

## 操作步骤

### A. 添加一个连接器

1. 左侧边栏点「专家·技能·连接器」，切到「连接器」页签（F-128）。
2. 找到目标服务卡片，点卡片右上角的「+」（F-128）。
3. 按提示完成登录/授权；若该服务走扫码授权，用对应 App 扫码（如 QQ 邮箱，F-130）。
4. 授权完成后卡片才显示可用图标（F-088）。

### B. 在三种位置使用连接器

| 使用场景 | 入口 | 说明 |
| --- | --- | --- |
| 页面内直接使用 | 连接器卡片上的「去对话」 | 进入已带该连接的对话（F-128） |
| 创建任务时启用 | 创建任务时通过 `+` > 连接器启用 | 在发起任务前挂载连接器（F-128） |
| 执行任务时按需连接 | 任务运行中弹出的连接引导卡片 | 卡片显示服务名称和头像，授权后自动继续当前任务；仅在任务实际用到该服务时出现（F-144） |

### C. 用对话管理连接器

| 目的 | 对话输入 | 结果 |
| --- | --- | --- |
| 安装 | 说明要安装的连接器名称 | 触发该连接器安装（F-129） |
| 查看 | 「我安装了哪些连接器」 | 返回列表，**含已授权但当前关闭的**（F-129） |
| 卸载 | 说明要卸载的连接器 | 弹出确认并列出移除清单；**内置连接器不支持卸载**（F-129） |

### D. 配置一个 MCP 服务器

1. 侧边栏「插件」→ 右上角「MCP 服务器」→「配置 MCP」（F-183）。
2. 选择配置级别（F-182）：
   - **用户级**：`~/.workbuddy/mcp.json`，配置一次所有项目复用；
   - **项目级**：`<项目目录>/.workbuddy/mcp.json`，仅当前项目生效。
3. 在界面可视化填写连接信息，无需编码、无需手改配置文件（F-180）。
4. 需要现成资源时，可访问腾讯云 MCP 市场获取开放生态能力（F-181）。

> 未在本机实跑，依据官方文档（F-012、F-088、F-127、F-128、F-129、F-130、F-144、F-180、F-181、F-182、F-183）。

## 结果判据

- 连接器授权成功后，卡片出现可用图标（F-088）。
- MCP 服务器状态指示灯：**绿色＝连接成功、红色＝配置异常**（F-183）。
- 按需连接场景会弹出连接引导卡片，并在授权后自动继续当前任务（F-144）。
- 在对话中输入「我安装了哪些连接器」，应返回列表且包含已授权但当前关闭的项（F-129）。

## 限制与边界

- **权限边界**：每个连接器独立授权、不主动定时抓取、不超出已有权限范围（F-131，文档可配置项）。
- **积分边界**：连接器自身读写不消耗积分；WorkBuddy 理解汇总外部数据时消耗积分（F-131）。
- **项目连接器两类授权**（企业版专属）：公共授权由管理员配置一次、全员共用同一套票据；个人授权由每位成员各自授权、票据不共享；同一连接器可同时以两种方式存在（F-210）。
- **协作任务中**（企业版专属）：个人授权连接器全部禁用、仅公共授权可用；其调用日志仅管理员可见（F-212）。
- 内置连接器不支持卸载（F-129）。
