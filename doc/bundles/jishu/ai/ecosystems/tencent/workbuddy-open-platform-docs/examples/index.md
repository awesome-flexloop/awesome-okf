# 操作用例

本目录收录 WorkBuddy 开放平台知识包的 5 篇操作用例，覆盖「入驻 → 开发与提交 → 授权调用 → 变现」主链路。所有用例均**转述厂商自有开发者文档描述**，**本知识包未在本机实跑**任何注册、认证、提交审核、发布或接口调用流程。

| 构建并提交技能上架 | [01 构建并提交技能](01-build-and-submit-a-skill.md) | 已有开发环境、要发布技能的开发者 | 已完成身份资质认证 | D4 |
