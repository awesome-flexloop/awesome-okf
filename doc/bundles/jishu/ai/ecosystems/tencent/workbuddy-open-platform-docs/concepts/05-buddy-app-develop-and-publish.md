# Buddy 应用：垂直行业的 AI Harness——配置、发布与企业单管理

> 本篇归纳 WorkBuddy 开放平台开发者文档 D8「Buddy应用」页（2026-10-16 采集，服务端渲染 `/docs/` 页正文，核验时点 2026-10-16），F 编号区间 **F-211～F-268**。信源为**厂商单源**开发者文档；**未在本机实跑**任何配置、预览、提交或上架流程。

## 一、产品概述与核心定位

- **产品概述原话**：Buddy 应用是**垂直行业的 AI Harness**（F-211）。伙伴无需从零构建一套 AI 产品，而是通过 Buddy 应用这层 Harness 封装，把自身行业 know-how 整合进 WorkBuddy 的 AI 底座，最终用户打开即获得专属于该行业的完整 AI 工作台（F-212）。
- **核心定位三关键词**（F-213）：

| 关键词 | 说明 |
| --- | --- |
| **行业 Harness** | 伙伴不造产品，造配置；WorkBuddy 提供产品框架与 AI 底座 |
| **开箱即用** | 用户无需学习，打开即进入行业专属工作台 |
| **场景优先** | 价值不在于堆叠能力清单，而在于将高频场景做深做顺 |

## 二、六大自定义维度

原文表述为「伙伴可通过**六个维度**，将垂直行业的完整能力装入 Buddy 应用」（F-214）。但该页在**架构总览图之后仅给出 5 个 h3 小节**（F-214），逐节为：

| # | 维度小节 | 定义与要点 | F 编号 |
| --- | --- | --- | --- |
| 1 | **工作模式** | 定义垂直场景的 System Prompt 与内置 Skill，构成**模式级 Harness**，在当前模式下全程生效。含 System Prompt（设定 AI 角色、行业术语规范、输出结构要求等）与绑定 Skill（预绑定该模式的 Skill，覆盖模式下所有对话，用户无需感知） | F-215 |
| 2 | **场景胶囊** | 围绕具体任务组装**场景级 Harness**：用户看到「你可能需要做的事」，点击后叠加在当前工作模式之上。含推荐场景（输入框上方的快捷提示词模板）与绑定专家／Skill／案例（覆盖场景下所有对话，用户无需感知） | F-217 |
| 3 | **模型配置** | 定义该应用可用的模型列表与展示排序。含模型列表（从平台模型池勾选适合本行业的模型如 HY、GLM 等，默认跟随）与排序（拖动调整用户侧模型展示顺序并指定默认模型） | F-219 |
| 4 | **垂直行业市场** | 自定义应用内的能力市场，决定用户可发现和使用哪些生态资产。含四类资产：Skill（技能）、专家（领域专家或专家团）、连接器（第三方服务集成）、灵感案例（最佳实践与使用示范）；能力可自建，也可直接引用 WorkBuddy 生态中已有的模块 | F-220 |
| 5 | **内嵌已有功能** | 可不抛弃已有建设，将伙伴现有系统通过 MCP Apps（通过 MCP 协议将已有服务接入 AI 对话流）无缝集成进 Buddy 应用；设计理念为不要求伙伴推倒重来，而是让 AI 长在已有系统之上 | F-221 |

## 三、WorkBuddy 基础能力（F-222）

以下 5 项底层能力由 WorkBuddy 团队持续投入建设，伙伴**无需重复造轮子**，开箱即用：多 Agent 协同运行、上下文压缩工程、记忆工程、工具调用编排、安全与权限管控。

## 四、配置指引：5 个配置模块

Buddy 应用通过 WorkBuddy 开放平台配置，采用**左侧模块导航 + 右侧表单**的单页布局，共包含 **5 个配置模块**（F-223）。

**配置规则**（F-224）：

| 规则 | 说明 |
| --- | --- |
| **允许跳步骤** | 模块之间可自由切换编辑，不强制按顺序完成 |
| **本地可预览** | 支持导出配置 JSON 文件在本地环境测试验证 |

### 模块 1：创建应用（F-225、F-226）

| 配置项 | 说明 |
| --- | --- |
| 应用 ID | 系统自动生成，不可修改 |
| 应用头像 | 上传品牌图标（建议 256×256） |
| 应用名称 | 面向用户展示的应用名称 |
| 应用简介 | 简要描述应用定位与核心能力 |
| 授权列表 | 配置应用运行所需的 OAuth 授权项 |
| 授权回调 URL | OAuth 授权回调地址 |
| 可信 Origin | 允许访问的域名白名单 |

创建后将生成 **Client ID** 和 **Client Secret**；Client Secret **仅此一次完整展示**，关闭后将无法再次查看，请注意保存（F-226）。

### 模块 2：首页配置（F-227、F-228）

| 配置项 | 说明 |
| --- | --- |
| 首页标题（Slogan） | 应用打开后的欢迎语标题 |
| 场景胶囊 | 输入框上方的快捷提示词模板，引导用户快速启动高频场景 |
| 工作模式 | 预置的对话场景（建议配置 3–5 个），每个模式对应不同 System Prompt |
| 内置连接器 | 进入应用后自动启用的连接器能力（可选） |

内置连接器需为**支持 OAuth 方式认证的 MCP**；用户首次进入 Buddy 应用并完成 Buddy 应用授权后会有绑定应用弹窗，点击「绑定」即可跳转 MCP OAuth 认证（F-228）。

### 模块 3：市场配置（F-229）

| 板块 | 说明 |
| --- | --- |
| 专家 | 配置可用的专家 / 专家团，可设置分类标签；**专家团为可选开启项** |
| 技能 | 配置可用的 Skill 列表 |
| 连接器 | 配置可用的连接器列表 |
| 精选场景 | 可选开启，在市场页做推荐位展示（关联专家或专家团） |

### 模块 4：其他配置（F-230～F-233）

共 4 项：① 跳过首次绑定应用授权（应用不需要使用绑定能力、如内置连接器使用非 OAuth 方式授权时可配置跳过）；② 绑定应用授权文案；③ 输入框占位符配置；④ 从平台模型池中选择适合行业场景的模型组合。

- **绑定应用授权文案**（F-231）：配置后弹窗文案为「绑定后，即可获取「绑定应用授权文案」专业能力」；不设置则为应用名，即「绑定后，即可获取「应用名」专业能力」。
- **输入框占位符**（F-232）：当对话框内未输入时用作提示文案引导用户输入，**需支持中英文两种文案**。
- **模型操作三项**（F-233）：

| 操作 | 说明 |
| --- | --- |
| 模型勾选 | 从模型池中选择 |
| 排序调整 | 拖动调整用户侧模型展示顺序 |
| 默认模型 | 指定一个默认选中的模型 |

> 模型池的**完整清单官方未给**（文档仅见「从模型池中选择」等操作描述，F-233），不得据此推断可选模型全集。

### 模块 5：预览调试（F-234）

配置完其他模块、提交审核之前，通过预览链接下载对应版本 WorkBuddy 端，通过链接打开预览态，查看是否符合配置需求。

## 五、发布流程（F-238～F-243）

发布流程串（逐字照抄原文）：

```
创建应用 → 填写基础信息 → 创建审核通过 → 分模块配置 → 预览调试 → 提交审核 → 发布上线
```

关键节点说明（原文）：

| # | 节点 | 说明 | F 编号 |
| --- | --- | --- | --- |
| 1 | 创建审核 | 首次提交应用基础信息后需通过平台审核，审核通过后进入"草稿"状态 | F-239 |
| 2 | 草稿态编辑 | 审核通过后可继续编辑各配置模块，不限顺序 | F-240 |

## 六、Buddy 应用设计规范（F-235～F-237）

- **应用 icon**：icon 尺寸 **16px\*16px**，线宽 **1.2px**，有断口，圆角平滑 **100%**，风格需与示例 icon 保持一致（F-235）。
- **专家页精选场景背景图**：模块 3 市场配置中，专家页精选场景**支持配置两套背景图**；图片尺寸 **1000px\*910px**，结构为**底图 + 3 层渐变蒙层**，需提供**日夜间 2 套资源**，建议底图内容采用**极简插画风格**（F-236）。

## 八、企业单管理（F-249～F-268）

### 8.1 概述（F-249～F-251）

企业单管理用于将你已发布的 Buddy 应用**授权给指定企业使用**：在开放平台创建企业单并生成授权链接，发送给企业管理员完成确认授权后，应用会自动出现在该企业的管理后台，由管理员分配给员工使用（F-249）。

| 概念 | 说明 | F 编号 |
| --- | --- | --- |
| 指定企业 | 特指已购买企业版 WorkBuddy，并有对应管理员操作企业版管理后台的企业 | F-250 |
| 企业管理员 | 在企业版管理后台可以管理对应企业的人员；企业版管理后台地址：`www.workbuddy.cn/admin` | F-250 |
| 企业单 | 授权凭据，标识一个 Buddy 应用对一个企业的授权关系，单号由系统生成（示例：`EO-6050u1gow7bp`） | F-251 |
| 授权模式 | 全员制 — 企业全员可见；席位制 — 由管理员按席位分配 | F-251 |
| 授权链接 | 授权动作入口，长期有效，一次性使用 | F-251 |

### 8.2 前置条件（F-252、F-253）

- Buddy 应用**已上架**，分发范围已勾选 **发布到企业**；已发布状态可点「设置」按钮修改发布范围，未发布状态可点「发布」按钮选择发布范围（F-252）。
- 需联系对应企业员工获取四项信息：企业ID、企业名称、企业联系人姓名与手机号、商定的授权模式与授权时长（F-253）。

### 8.3 接入流程（F-254～F-263）

**1. 创建企业单**：进入 `开放平台 → 能力管理 → Buddy 应用 → 应用卡片 → 企业单管理 → 新建企业单`，填写字段并提交（F-254）。**当前同一 Buddy 应用暂且支持发企业单给同一企业一次**；若目标企业已存在过企业单，则无法再次创建新单，初期还请谨慎创建，后续会考虑放开（F-255）。

企业单字段表（逐字照抄原文，F-256）：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 企业ID | 是 | 企业唯一标识 |
| 企业名称 | 是 | 需与 企业ID 匹配 |
| 授权模式 | 是 | `全员制` / `席位制` |
| 席位数量 | 席位制必填 | 管理员可分配的员工上限 |
| 授权时长 | 是 | `3 个月` / `半年` / `1 年` |
| 企业联系人姓名 | 是 | 将同步至授权中间页 |
| 企业联系人手机号 | 是 | 将同步至授权中间页 |

提交后系统生成授权链接；若 企业ID 与企业名称不匹配，页面即时提示，可修改后重提（F-257）。**席位数量的具体上限（数字口径）官方未给**（字段说明仅表述为「管理员可分配的员工上限」，F-256），不得推断。

**2. 分发授权链接**：在企业单详情页的「授权链接」区点击「复制链接」，通过邮件、企微或其他线下渠道发送给企业管理员（F-258）。链接特性（F-259）：长期有效不设过期时间；一次性使用，管理员确认后自动失效；与企业ID 绑定，仅目标企业管理员可授权；开发者手动取消企业单时链接同步失效。

**3. 等待管理员完成授权**：管理员打开链接后进入两步页面——中间页展示企业单信息与授权范围并点「前往企业版授权」跳转；确认页在企业版 admin 后台登录并点「确认授权」（F-260）。管理员确认后企业单变更为 **已生效**，应用自动出现在该企业管理后台，管理员按授权模式分配员工，员工端 Buddy 应用入口即可看到并使用；开发者会同步收到站内消息通知（F-261）。

**4. 管理已创建的企业单**：企业单列表支持按状态 Tab 筛选：全部／待确认授权／已生效／待确认终止／已终止／已取消（F-262）。企业单状态机（F-263）：

| 状态 | 触发方式 | 可执行操作 |
| --- | --- | --- |
| 待确认授权 | 创建成功 | 取消企业单 |
| 已生效 | 管理员确认授权 | 提前终止 |
| 待确认终止 | 你发起终止 | — |
| 已终止 | 管理员确认终止 或 到期停止 | — |
| 已取消 | 你主动取消 | — |

### 8.4 生命周期操作（F-264～F-268）

- **取消企业单**（F-264）：仅 **待确认授权** 状态可操作；详情页点击后二次确认，企业单变更为 **已取消**，授权链接同步失效。
- **提前终止**（F-265、F-266）：仅 **已生效** 状态可操作；填写终止原因（必选）与补充说明（可选，支持上传截图），提交后系统生成「终止确认链接」，复制发送给管理员；管理员确认后企业单**即时**变更为 **已终止**，应用从企业管理后台移除。**终止申请提交后不可撤回**，终止链接规则与授权链接一致（F-266）。
- **到期处理**（F-267）：授权到期当天企业单自动变更为 **已终止**，应用从企业管理后台移除，你和企业管理员均会收到通知。
- 当前版本支持的最长授权时长为 **1 年**（F-268）。
