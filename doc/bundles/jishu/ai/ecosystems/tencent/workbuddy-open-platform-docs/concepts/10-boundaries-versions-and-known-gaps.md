## 二、跨页口径不一致并列登记（两处）

两处均为**两处官方口径并列**，非任一方错误；一律**并列表述、不择一、不替官方判定**（登记见 [核验报告](../references/verification.md) 第四节）。

## 七、「官方未宣告」与「本束未采集」的区分

- **「官方未给」**：指文档**提及**某功能或机制（如结算关系、席位数量、模型池），但**未给出具体数字或细节**；处理方式为标记「官方未给」，**不得补全**，也**不得**写成「默认无限制」。见第四节。
- **「本束未采集」**：指站点侧栏存在某 `/docs/` slug，但本束**未采集其正文**；处理方式为「**本次未采集，仅登记入口**」，**只证明该 slug 存在于站点侧栏**，**不得据名称推断能力**，也**不得写成「不存在」**。见第三节。
- 二者**均不可断言为「官方未发布该能力」**——「官方是否发布」超出本束单源可断言范围；本束仅登记**文档所述**与**采集状态**，不替官方宣布。

## 八、读者可据此做的判断

- **可判断**：五类口径的分层结论、端与形态归属（PC 端本机 / 云侧）、七类 Open API 的路径/权限/参数框架、版本门槛为「客户端 ≥5.8.0（同组公告口径）」这一并列事实。
- **不可断言**：任何「已上线 / 已 GA / 已完成审核 / 功能已验证可用」表述——本束**未实跑**、**单源自述**，为「文档声称」而非第三方验证（[核验报告](../references/verification.md) 第六节）。
- **不可测算**：收益测算与现金流规划——**无分成比例、无结算周期**（第四节第 1、2 项）。
- **不可推定**：`access_token` 有效期、签名填充方案等**两处口径冲突**的任一单值；未采集 7 篇与官方未给 10 项的具体内容。
- **复核纪律**：全部字节数、标题与侧栏集合绑定核验时点 **2026-10-16**；`stale_after` = **2027-04-16**，到期须回源复核（[核验报告](../references/verification.md) 第八节降级条件）。
