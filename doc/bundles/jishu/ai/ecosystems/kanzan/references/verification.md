## 口径与安全边界

| 对象 | 裁定 | 处理位置 |
|---|---|---|
| MCP 自动沙箱与脱敏 | 协议不自动实现这些部署控制；固定版本安全文档把隔离与权限交给实现方 | `02-agent-and-event-contracts.md` |
| MCP 无缝互通与任意换模型 | 接口标准化不能替代能力、权限、版本和行为评测 | 同上；不承诺零成本迁移 |
| Prompts 等于执行工作流 | Prompts 是交互模板，不自动授权或完成执行 | 同上 |
| EventType 工具名就是发布 API | 博文为设计讨论，未读源码或实际调用 | 将权限矩阵标为本包教学设计 |
| 私有部署自动合规 | 部署位置不足以证明数据处理、授权、留存和责任合规 | 产品与工业章节采用风险评估，不给合规认证 |
| 未成年人或养老场景“非敏感” | 不采用作者这类笼统判断；视频、身份、健康相关内容按具体场景审查 | 产品章节限制自动处分与外部分享 |
| 表单/法律页已完善 | 联系页表示仍在完善；法律页为占位文本 | 概览与采购边界保留缺口 |
| `/api/health` 通过即全部上线成功 | 作者健康响应不足以证明数据库、队列和业务链路正常 | 部署章节补分层验收建议 |
| 通知允许失败等于门禁允许失败 | 非核心通知与构建/迁移/业务验收分开 | 部署章节明确失败分类 |

## 引文纪律

教程以原创解释为主，没有大段转载文章。公司、研究、产品和作者观点采用带来源的间接引述。原文标题保留在台账中用于定位，不替读者下判断。公开照片的内部存储地址、带用户标识的资源路径未复制为教程素材。

MCP 官方架构页与安全参考不是同一版本集合：前者为采集时动态文档，后者固定 2025-11-25。这里仅对照共同稳定的概念与安全责任，不把它们拼成一套可运行的协议实现。
