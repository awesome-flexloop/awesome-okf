# 免费访问、隐私与人工确认的边界

> **先看边界：**“每月 13 亿 token”和“全程不花钱”都不能当作长期可兑现的产品保证。额度由多个 provider 的免费层拼接而来，限制会变化。[F-005][F-013][F-028]

## 免费不只是一张价格表

至少要拆成四项：

| 层次 | 需要核对的问题 |
|---|---|
| 软件 | 项目许可证、安装脚本和维护状态是什么？[F-024][F-025] |
| 模型 | 实际执行任务的是哪一个 provider 和模型？是否满足工具调用与长上下文要求？ |
| 额度 | 免费层按用户、时间、速率还是活动政策计算？是否可随时调整？[F-013] |
| 运维 | 本地部署、API key、网络、故障切换和人工复核由谁负责？ |

## 隐私不是“完全不上网”

career-ops 将简历、投递记录和生成文件保存在本地，但它仍会调用用户选择的 AI CLI/模型服务。[F-022] 因此“本地运行”只说明本地文件管理，不等于内容从不离开设备。使用前应确认职位描述、简历和生成结果会发送到哪些服务。

## 人类在环是安全边界

career-ops 不自动提交申请，最终提交由用户确认。[F-021] 这能降低误投、错误回答和不当承诺的风险，但不会自动保证评分正确、职位真实或材料符合当地法律和招聘平台规则。

## 如何使用这篇文章

把文章当作工具发现和架构启发，而不是价格承诺或求职成功率证明。尤其是 90% token 节省和作者 740+ 职位案例，应视为项目/作者自述，不应直接外推到自己的工作量。[F-009][F-023]
