# 02 核心命令使用

> 对应事实：F-011~F-023、F-089~F-094
> 知识层级：操作层

本文档展示 Zhihu CLI 常用命令的基本使用方法和输出示例。

> **说明**：以下命令示例基于社区文章描述整理 [S1][S2][S5]，具体命令格式可能因版本不同略有差异。Zhihu CLI 当前版本为 v0.5.0 [F-009]，产品处于快速迭代期。

## 一、搜索命令实战

### 知乎站内搜索

搜索知乎站内内容 [F-015]：

```bash
zhihu search zhihu "AI Agent 最佳实践"
```

**适用场景**：
- 查找专业问题的高质量回答
- 搜索知乎专栏文章
- 寻找特定领域的深度分析

### 全网搜索

搜索全网内容 [F-015]：

```bash
zhihu search global "最新 AI 技术趋势"
```

全网搜索技术特性 [厂商自述] [F-012]：
- 百亿级索引规模
- 分钟级实时更新
- 平均响应延迟约 600ms
- 全网+知乎双源融合

> ⚠️ 以上数据为厂商自述，无独立第三方实测验证。

### 输出格式

搜索结果以 JSON 格式输出到 stdout [F-022]，大致结构如下：

```json
{
  "query": "搜索关键词",
  "results": [
    {
      "title": "结果标题",
      "url": "结果链接",
      "snippet": "摘要片段",
      "source": "来源"
    }
  ]
}
```

> 实际字段以 CLI 真实输出为准，以上为示例结构。

## 二、热榜命令实战

### 获取热榜

获取知乎热榜 [F-016]：

```bash
zhihu hot
```

或者 [F-013]：

```bash
zhihu trending
```

### 结果字段说明

热榜数据以 JSON 格式输出 [F-022]，通常包含以下信息：

- 热榜排名
- 问题标题
- 热度值
- 问题链接

### 典型用途

1. **快速了解热点**：早上一条命令知道今天大家在讨论什么
2. **选题灵感**：结合自己的创作领域找选题 [F-076]
3. **定时监控**：配合 cron/计划任务，监控特定话题热度变化

## 三、直答命令实战

### 基础提问

使用知乎直答 [F-017]：

```bash
zhihu ask "如何学习 AI Agent 开发？"
```

或者 [F-014]：

```bash
zhihu answer "如何学习 AI Agent 开发？"
```

### 流式输出体验

answer 命令支持流式输出 [F-023] [F-059]，答案会逐字/逐段输出，类似 ChatGPT 的交互体验。

**流式输出的优势**：
- 不需要等待完整答案生成
- 可以边看边思考
- 对于长答案体验更好

### 知识库问答

支持接入知乎直答知识库 [F-020]，可以基于私有知识库进行问答。具体使用方式请参考官方文档。

## 四、个人数据命令实战

### 拉取我的创作

获取自己的创作内容列表 [F-089]：

```bash
zhihu me contents
```

支持分页拉取，可以获取全部历史创作数据。

**可用于**：
- 创作数据统计分析 [F-071]
- 内容备份
- 风格蒸馏的语料来源 [F-074]

### 查看我的关注

获取关注列表 [F-093]：

```bash
zhihu me followees
```

### 查看我的收藏

获取收藏内容 [F-094]：

```bash
zhihu me favorites
```

## 五、额度查询

### 查询额度使用情况

使用 `quota` 命令查询当前额度使用情况 [F-019]：

```bash
zhihu quota
```

支持查询体验额度 [F-021]。

⏰ 截至 2026 年 9 月，邀测阶段免费额度为 5000 次/天 [F-006]。额度可能随时间调整——2026 年 5 月为 1000 次/天，后扩容至 5000 次/天 [E-002]。

## 六、输出约定说明

Zhihu CLI 遵循严格的输出约定 [F-022]：

| 通道 | 内容 | 格式 |
|------|------|------|
| **stdout** | 正常数据 | JSON |
| **stderr** | 诊断/日志 | 文本 |
| **错误** | 错误信息 | JSON 错误码 |

**调试技巧**：
- 遇到问题时，查看 stderr 输出的诊断信息
- 错误时会返回稳定的 JSON 错误码，便于程序化处理
- 重定向 stdout 到文件可以保存结构化数据
