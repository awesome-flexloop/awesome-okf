# 00 平台与产品介绍

> 对应事实：F-001~F-010、F-024~F-030
> 知识层级：事实层

## 一、平台定位

### Zhihu CLI 是什么

Zhihu CLI 是知乎数据开放平台给 AI Agent 提供的官方命令行工具 [F-001]。它将知乎海量优质专业内容与个人数据能力整合到命令行接口中，让 AI Agent 可以程序化地调用知乎数据。

### 核心价值

社区观点认为，Zhihu CLI 最大价值在于：**公共内容 + 个人数据同时交到 AI 手中** [F-004]。

这意味着 Agent 不仅能搜索知乎公开内容（热榜、搜索、直答），还能访问授权用户的个人数据（创作、关注、收藏），实现"公共知识 + 个人积累"的融合使用 [F-084]。

### 产品阶段

截至 2026 年 9 月，知乎数据开放平台处于**邀测阶段** [F-005]。

⏰ **时效性提示**：邀测阶段免费试用额度为 5000 次/天 [厂商自述] [F-006]。额度随时间调整——2026 年 5 月为 1000 次/天，后于 2026 年 Q3 扩容至 5000 次/天 [E-002]。

Zhihu CLI 技能版本已更新到 v0.5.0 [F-009]，产品处于快速迭代期。

## 二、产品矩阵

知乎数据开放平台提供全链路数据产品矩阵，包含知乎海量优质专业内容 [F-002]。

### 六大核心产品

平台核心产品包括六大类 [厂商自述] [F-003]：

| 产品类别 | 说明 |
|----------|------|
| 全网搜索 | 百亿索引规模的全网搜索引擎 |
| 知乎搜索 | 知乎站内内容搜索 |
| 直答 Agent | 基于知乎内容的问答能力 |
| 工具 | 工具类产品（具体边界待官方文档细化） |
| 社区数据 | 社区数据类产品（具体边界待官方文档细化） |
| 知识库 | 知识库类产品（具体边界待官方文档细化） |

> ⚠️ **核验说明**：官方页面列出六大类产品，但"工具""社区数据""知识库"的具体边界和内容尚不清晰，需后续文档细化 [P0-014]。

### 官方 Skills 与 Zhihu CLI 的关系

官方提供 4 套独立 Skills：热榜、站内搜索、全网搜索、直答 [E-003]。

Zhihu CLI 是另一个**统一入口**的 CLI 工具 + Skill，将上述能力整合到一个命令行工具中 [F-011]。开发者可以选择使用单一 Skill，也可以使用 Zhihu CLI 统一调用所有能力。

## 三、内容质量保障

### L1-L5 内容分级体系

知乎数据开放平台提供 L1-L5 内容分级体系以保障内容质量 [厂商自述] [F-007]。该分级体系已通过多源交叉验证 [P0-005]。

**深度分级机制** [产品介绍页]：
- 知乎搜索采用 **L1-L5 深度内容分级**，优先提取 L3 及以上高价值"硬核"内容，确保 AI 获取的语料处于行业领先水平 [F-210]
  - ⚠️ "L3+ 硬核内容占比"为厂商自述，可通过 API 返回内容抽样做定性验证 [P0-049]
- 内容运营 L1-L5 体系确保优质内容经过人工审核 [F-203]

### 专业创作者生态

知乎平台汇聚了大量专业创作者 [厂商自述] [F-008]，这是知乎内容质量的基础保障。

**创作者构成** [产品介绍页]：
- 汇聚 75% 以上的国内头部科研人员、工程师及行业资深从业者 [F-211]
  - ⚠️ 此数据为官方宣传口径，暂无第三方独立验证 [P0-049]；可通过检索行业研究报告交叉验证
- 覆盖科技、科学、知识等多个垂直领域 [F-203]
- 基于"问题-回答"天然的逻辑结构，通过社区互动筛选出结构化、高逻辑性的内容体系 [F-214]

### 专业背书与可信度机制

除内容分级外，知乎搜索的高可信度还来自三重机制 [F-212] [产品介绍页]：

| 机制 | 说明 |
|------|------|
| 多维专业验证 | 基于赞同/反对机制及专业认证体系，多方观点交叉验证，保障客观性与严谨性 |
| 理性讨论传统 | 坚持"谢邀，利益相关"的理性讨论传统，注重事实引用与逻辑拆解 |
| 全链路内容溯源 | 每条结果均可追溯至真实、专业的创作者身份，确保信息透明度与版权合规性 |

### 全网搜索技术规格

全网搜索能力的技术参数如下 [厂商自述] [F-012]：

| 参数 | 数值 | 核验状态 |
|------|------|----------|
| 索引规模 | 百亿级 | ⚠️ 厂商自述，无法独立核验 |
| 架构 | 全网+知乎双源融合 | ⚠️ 厂商自述，多源转述一致 |
| 更新频率 | 分钟级实时索引 | ⚠️ 厂商自述，无独立实测 |
| 平均响应延迟 | 600ms | ⚠️ 技术媒体报道，非第三方实测 |

## 四、Zhihu CLI 核心能力概览

Zhihu CLI 整合了以下核心能力 [F-011]：

1. **搜索能力**：知乎站内搜索、全网搜索
2. **热榜能力**：知乎热榜实时数据
3. **直答能力**：知乎直答问答，支持流式输出，三档模型 + 三档产品模式
4. **知识库 RAG**：知识库管理、文件上传、语义检索
5. **文档工具**：PDF 解析、PPT 生成（异步任务模式）
6. **个人数据**：我的创作、我的关注、我的收藏

详细能力说明见 [03-core-capabilities.md](03-core-capabilities.md)。
