# 概念拆解索引

本 bundle 将《有用户，有收入，AI 应用却不是好生意》拆为 6 个核心概念，按"总纲 → 三股挤压拆解 → 陷阱 → 出路"组织：

| # | 概念 | 核心命题 | 对应事实 |
|---|------|----------|----------|
| 00 | [三难困境](00-triple-squeeze.md) | 独立 AI 应用同时被模型吞噬、负毛利、上游入口三重挤压 | F-002~F-008 |
| 01 | [卖 token 的经济学](01-token-economics.md) | ARR 幻觉 + 毛利倒挂，增长指标必须切换到单位经济 | F-009~F-023 |
| 02 | [模型吞噬周期](02-model-engulfment.md) | 能力增速翻倍背景下窗口坍缩，转向触发器必须前置 | F-024~F-037 |
| 03 | [模型即应用](03-model-as-app.md) | 上游下场是商业模式必然，入口层不宜独立创业 | F-038~F-049 |
| 04 | [躲避陷阱](04-avoidance-trap.md) | 为差异而差异会筛掉用户；0→1 先问"谁在用、为什么用" | F-050~F-058 |
| 05 | [两条逃生路线](05-two-escape-routes.md) | 下游卖结果（交付/重交付/收购改造）或上游做模型（场景-模型互强化） | F-059~F-080 |

阅读顺序建议：00 建立全景 → 01/02/03 理解三股挤压的机制与数据 → 04 规避最常见的反应错误 → 05 落到路线选择与决策树。
