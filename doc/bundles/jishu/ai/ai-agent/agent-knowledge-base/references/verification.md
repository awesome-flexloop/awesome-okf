1. 全文结论来自作者个人工程经验，非经大样本实证；三个"乘法公式"是认知支架而非定量模型。

3. 文章为方法论综述，**不含可照做的操作流程**：无工具、代码、配置，读者无法据本文直接动手搭建知识库（故无 examples/）。
