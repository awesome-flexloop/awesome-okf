## 四、适合谁读（博文线索 + 官方学习建议）

博文的缘起故事指向典型读者："收藏了几十篇教程、把 LangChain 文档看了两遍，还是不知道怎么从头搭一个 Agent"（F-001 正文）。结合官方 LEARNING.md 与章节设计：

- **会调大模型、想从"调 API"升级到"搭 Agent 系统"的开发者**——第 1~5 章（公式/上下文/记忆/工具/Coding Agent）；
- **做 Agent 技术选型与评估的工程/产品角色**——第 7 章评估方法论（指标、统计显著性、评估驱动选型）；
- **关心训练侧的研究者**——第 8 章 SFT vs RL 取舍、工具调用内化（第三方评测称"论文级内容"，F-037）；
- **关注前沿交互的读者**——第 6 章（2.0）语音三范式、Computer Use、机器人。

阅读门槛提示（第三方实测，F-037）：信息密度高（v1.2 中文 PDF 约 428 页），需要一定工程基础；部分实验依赖 API Key/GPU/外部基准，"跑通全套"成本不低——建议先用 ✅ 类可运行实验上手（见 [03 章节地图](03-chapter-map-and-experiments.md)）。
