# Hypit 是什么

## 从“生成一条视频”到“复用一个视频结构”

传统 AI 视频生产通常以一次提示词生成一次结果为中心。Hypit 的核心变化是：把已经跑通的视频看成一个可编辑的结构，把素材、字幕、B-roll、特效、声音和它们之间的关系保留下来，再替换真正变化的内容（F-004、F-005）。

因此，“复刻”不是逐帧复制，而是保留一种形式：开头如何吸引注意、字幕何时出现、画面何时切换、排行榜如何跟随解说、产品何时被递出。

## 三个入口

1. **参考视频**：让 Agent 先分析视频的画面、帧、语音时间和结构，再生成工作流（F-020）。
2. **模板**：从已有的可复用视频结构开始。
3. **自然语言**：直接描述想做的视频，让 Agent 从零写工作流（F-006）。

## 能力边界

- Hypit 本身是编排和制作系统，不等于某个图像或视频生成模型。
- 生成模型是可选的；字幕、动效和代码渲染视觉可以不调用生成模型完成（F-007）。
- 使用 Seedance、GPT Image、WhisperX 等服务时，费用和配额由对应服务决定（F-014、F-016）。
- 官方成本数字只说明具体示例，不构成普遍价格承诺（F-016）。

## 可迁移洞察

当一类内容的“形式”稳定而“内容”经常变化时，应优先把形式建模成工作流，再把人物、产品、语言和观点作为可替换输入。这个判断同样适用于广告、课程片段、播客切片和产品演示。
