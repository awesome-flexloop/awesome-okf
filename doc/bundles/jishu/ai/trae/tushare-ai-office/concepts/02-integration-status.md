# 02 集成状态与核验

> 博文声称的三平台上架与实际核验状态逐条对照。**这是本知识包最核心的概念文档。**

## ⚠️ 核验结论摘要

博文核心声明（F-006）"Tushare 数据同步上架三大平台，成为官方预置连接器"经 P0 核验判定为 **❌ 未获证实**。

关键发现：
1. 2026-08-25 同日的"多平台上架"新闻主体是**启信慧眼**（企业数据查询），非 Tushare
2. Tushare 官方 MCP 文档仍指导用户**手动配置**
3. 千问办公和 TraeWork 的官方连接器列表中**未发现 Tushare**
4. WorkBuddy 上存在的是**社区 Skill**，非官方预置

## 逐条对照

### WorkBuddy

| 博文声称（F-006, F-009） | 核验实际 | 判定 |
|--------------------------|----------|------|
| Tushare 上线 WorkBuddy 官方预置连接器 | WorkBuddy 技能市场有社区 Skill `tushare-finance`（作者 stanleychanh，非 Tushare 官方） | ⚠️ |
| 无需通过"自定义连接器"手动添加 Tushare MCP | Tushare 官方文档仍列出 WorkBuddy 为支持平台，但需手动配置 MCP key | ⚠️ |
| 点击"+"→输入 Token→保存并连接 | 社区 Skill 安装后确实需配置 Token，但这不是官方预置连接器 | ⚠️ |

**可能的解释**：WorkBuddy 上确实有 Tushare 相关能力可用（通过社区 Skill 或手动 MCP 配置），但"官方预置连接器"的表述不准确——它需要用户主动搜索、安装和配置。

### 千问办公

| 博文声称（F-012~F-014） | 核验实际 | 判定 |
|--------------------------|----------|------|
| Tushare 上架千问办公官方预置连接器，开箱即用 | 千问办公官方连接器列表（qwenwork.cn/docs/features/connectors）中**无 Tushare** | ❌ |
| 点击 Tushare 金融数据→安装→连接→授权 | 无法在官方连接器列表中找到 Tushare 入口 | ❌ |
| 微信扫码登录 Tushare 完成授权 | Tushare 确实支持微信登录，但前提（预置连接器）不成立 | ❌ |

**可能的解释**：千问办公支持自定义 MCP 连接器，高级用户可能通过手动配置 MCP Server URL 接入 Tushare，但这不是"官方预置、开箱即用"。

### TraeWork

| 博文声称（F-018~F-019） | 核验实际 | 判定 |
|--------------------------|----------|------|
| Tushare 是 TraeWork 官方预置连接器 | Tushare 官方 MCP 文档列出的是 **"Trae"**（编程 IDE），非 **"TraeWork"**（办公工作台） | ❌ |
| 点"安装"→输入 Token→保存并连接 | Trae（IDE）中可手动配置 Tushare MCP，但 TraeWork 的连接器状态未获证实 | ❌ |
| 在 TraeWork 对话框直接使用 | 无法确认 | ❌ |

**关键区分**：
- **Trae**（trae.ai）：AI 编程 IDE，类似 Cursor，支持 MCP 手动配置
- **TraeWork**（work.trae.ai）：AI 原生工作台，含 Work/Code/Design 三模式

博文可能将 Trae（IDE）的 MCP 支持混淆为 TraeWork（工作台）的预置连接器。

## 对博文的整体评价

1. **平台描述基本准确**：WorkBuddy/千问办公/TraeWork 的产品定位、功能、形态描述经核验大体正确
2. **核心声明存疑**："官方预置连接器"与官方文档矛盾，可能是营销性表述或预告
3. **配置流程合理但无法验证**：博文描述的 Token 输入、授权流程在技术上可行，但前提（预置连接器存在）未获证实
4. **用例真实**：金融数据查询示例（板块涨幅/龙虎榜/两融等）确实是 Tushare 可提供的数据类型
5. **开发主体有误**：千问办公由钉钉业务线开发而非"千问团队"
