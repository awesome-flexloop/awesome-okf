# 示例：三个可直接照做的练习

- [最小可行路径](qq-bot-minimal-path.md)：只走官方插件，把「能聊十句」跑通，含六级验收与四级排错；耗时主要在客户端下载与额度准备。
- [人设骨架](persona-prompt-skeleton.md)：五段填空模板，附一段不同角色的原创填充与六项自检。
- [直播迭代](live-broadcast-iteration.md)：彩排—请示—正式三轮动作、四类问题归因与记分卡。

三个练习的难度递增：第一个验证环境，第二个验证人格，第三个验证「有外部副作用」的动作链。没做过第一个之前，不要跳到第三个。
