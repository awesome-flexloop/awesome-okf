## 3. 勘误与口径说明

### E-1（⚠️ 次级表述偏差）技能文件内的“规避计数”

源文称每个 SKILL.md 包含“触发描述、应用模式、关键工具序列、前置技能、状态和规避计数”。论文附录 C.1 明确：SKILL.md 的 front matter 只有 description、app_mode、tool_sequence、prerequisites、status + version；**每技能统计存放在文件外的独立 store**，以保持技能文件干净、可发布。

影响：不影响机制理解，但会误导读者以为统计字段应写进技能文件。本包正文按论文口径呈现，并在术语页标注差异。

### E-2（⚠️ 措辞偏差）“计划中的小规模用户研究尚未完成”

源文称论文“计划中的小规模用户研究尚未完成”。论文 §6 只说内部 judge 不能替代真实用户研究；附录 K 明确“No users have been recruited”。全文未出现“计划中（planned）”的用户研究表述。

影响：结论方向一致（无人类偏好研究），但“计划中”属源文补充，不能作为论文事实引用。本包表述为“论文未招募用户、未做人类偏好研究”。

### E-3（⚠️ 口径边界，不计入源文勘误）“内部 prompt 和轨迹没有公开”

论文未在 abs 页或 HTML 全文提供 data/code availability 声明，也未给出数据集或代码链接；附录 J 只展示 held-out 图库。可核验事实是“未提供公开数据集/代码链接”；“因此复现受限”是合理推断，但与“作者明确声明不公开”不同。本包按推断标注。

### E-4（口径混用风险）+11.99 与 +7.70 不是同一个数

arXiv 摘要写 “+11.99 points in generation quality”。论文表 1 显示：GenEval2 质量 34.26→46.25，差 **+11.99**；Sonnet 四个通用基准的平均质量 51.63→59.33，差 **+7.70**。源文分别引用了 72.7→99.3（GenEval2 成功率）与 51.63→59.33（平均值），但未点明 +11.99 的归属。

本包在结果页并列标注两个口径，禁止把 +11.99 当作“平均质量提升”。

### E-5（源文省略，非错误）

源文未提：每 50 条新评分记录触发一轮演化、tie band δ、工具面收窄默认关闭、延迟开销 3.4%–6.2%、token 成本对照、R1 具体过门数。这些不构成错误，本包按论文补全。
