## 3. 口径差异登记（并存，不合并抹平）

### D-1（范围合并）泛化降幅的四种写法

| 信源 | 写法 | 覆盖范围 |
|---|---|---|
| 论文表 2(b) | Web-Bench −21.2/−16.0/−18.7；CredData −19.6/−16.5/−18.3；ReposVul −7.5/−6.4/−9.3 | 逐基准、逐 agent |
| 论文摘要 | 6.4–21.2% | Web-Bench + 两个安全基准合并 |
| 博客 | Web-Bench 16.0–21.2%；安全审计 6.4–19.6% | 按任务结构分两组 |
| 仓库 README | Web-Bench 16–21%；安全审计 6–20% | 取整简写 |

**本束口径**：正文一律采用论文表 2(b) 的逐基准数值；引用摘要 / 博客区间时显式标注「合并区间」。教程不把 6.4–21.2% 说成「安全审计降幅」。

### D-2（符号复用）参数字母同名不同义

论文与项目页用 `k / p / c / r / b / κ / β / γ / λ / ρ` 描述**实验控制器**；仓库 README 用 `k / p / m / s / q / e / c / r / b` 描述**插件默认设置**。其中 `k` 在论文式 (2) 附近指工具连续未调用任务数（3），在 README 指 `microskills_propose_every`（3）；`p` 在论文指 90 分位，在 README 指 `toolprune_evidence`（10）。数值相同不代表语义相同。逐项对照见 [参数分账台账](parameter-ledger.md)。

### D-3（行为差异）默认配置 ≠ 实验全栈

| 维度 | 论文实验控制器 | 开源插件默认值 |
|---|---|---|
| micro-skills | 三条元策略全开 | 默认 **off** |
| 循环干预终止 | redirect 1 次后 stop / abort | 只提示开发者，**从不自行停止** |
| 任务单元 | 277 个独立 SWE-Bench 会话 | 开发者真实仓库会话 |
| 支持 harness | 论文测 3 种（§6 明确未覆盖 Pi） | 稳定 4 种（含 Pi）+ 实验性 6 种 |

**影响**：直接安装插件并沿用默认值，不构成对论文 18.4–30.9% 结果的复现。此条已作为「先读这一条」写入 [速览](../concepts/00-overview.md) 与 [安装示例](../examples/01-install-and-verify.md)。
