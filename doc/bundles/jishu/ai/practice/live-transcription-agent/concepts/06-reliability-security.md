# 断线恢复、质量验收与隐私保护

一次两分钟样本只能验证那次路径，不能证明跨夜直播、所有平台和所有口音都可用。验收应分别覆盖采集完整性、识别质量、时间定位和分析引用，保留每一项未覆盖的范围。

## 常见故障

| 现象 | 优先检查 | 不应采用的处理 |
|---|---|---|
| 文件只有麦克风声音 | 应用音频源、轨道勾选、输出设备切换 | 提高 ASR 模型大小 |
| 出现双声或回音 | 桌面音频和应用音频是否重复录入，监听是否回灌 | 用摘要掩盖重复 |
| 下载退出 | 插件支持、直播状态、网络、合法凭证是否过期 | 绕过登录、验证码、访问控制或 DRM |
| 一直读到损坏片段 | 是否消费了尚未关闭文件 | 只等文件大小暂时不变就认定完成 |
| 字幕时间归零或漂移 | 分段偏移、PTS、采样率、VAD 映射 | 用文件编号乘块长强行拼齐 |
| 静音中出现文字 | 静音/背景音乐样本、VAD、识别参数 | 把 ASR 输出全当真实发言 |
| 多人内容混在一起 | 音轨分离、重叠语音和分离模型 | 把聚类标签自动实名化 |
| 越跑越慢 | 单块识别耗时、队列积压、硬盘与温度 | 无限增加并发，拖垮录制进程 |
| 引用原文不存在 | 模型输出和证据验证日志 | 删除引用后照样发布结论 |

## 采集与消费分离

写入端先完成一个文件，关闭成功后以同一文件系统内的原子改名或明确的完成事件交给消费者。`*.part` 约定需由实际写入器实现；不是随便改扩展名就获得保证。FFmpeg segment 输出列表的可见性也需要结合该版本行为验证。

识别任务键可由输入散列、模型/参数标识和归一化版本组合。成功结果不可覆盖；失败记录与重试单独保留。读取任务失败不应停止录制，积压时优先保全信号，再延后识别。重启只重跑未完成任务；重试本身不会补回错过的直播。

分析产物须绑定当前输入快照散列、模型版本、prompt/schema 版本及参数；任一项变化，旧结果即对当前分析失效，须重算。旧产物及对应快照、版本记录按保留策略留作历史，不覆盖。

跨夜运行应设置磁盘余量阈值、保留期限、断线告警和最大任务队列。清理前核实对应原始媒体是否仍被分析引用，备份也需要独立保留策略。以上为设计要求，本包没有实现守护进程。

## 四组验收指标

| 对象 | 度量定义 | 起步方法 |
|---|---|---|
| 采集 | 应录时段、实际记录时段、未知缺口分别列出 | 对照应用开始/结束标记，故意断开再重连 |
| ASR | 中文 CER = 字符替换、删除、插入次数之和 / 人工参考字符数 | 保存人工参考与标点、空白、繁简处理规则；CER 可以大于 100% |
| 速度 | RTF = 处理耗时 / 音频时长；端到端定稿延迟另算 | 记录冷启动与热运行，硬件、模型、量化、并发及样本 |
| 分析 | 引用 ID 合法率、引文一致率、结论支持度 | 前两项程序检查，支持度由原媒体和上下文复核 |

RTF 小于 1 表示该次识别耗时短于音频时长，不代表实时链路没有排队，也不等于字幕延迟小于一秒。单段 RTF 不能外推所有语言和长时运行性能。

存储可按公式估算：16 kHz、16-bit、单声道 PCM 每秒 32,000 字节，约 115.2 MB/小时（十进制、不含容器开销）；视频则按实测平均比特率乘时长计算。这是单位换算，不是本机性能测试。

## 隐私与授权分层

公开可观看不等于可无限录制、批量再分发或商用训练。录制、转写、发送云端、改编、发布是不同用途；在相应平台规则和当地法律下确认权利。遇到受保护内容时，不提供 DRM 绕过、破解下载或批量窃取身份凭证的路径。

只录指定应用通常比整桌面录制更符合数据最小化。关闭不相关应用提示音，避免同时记录会议、电话、账号页面和家庭成员声音。组织内部录音应确认知情、用途、访问人员与保留期。

模型、客户端、插件都可能有网络行为。离线验证应在预下载之后完成：断网运行自有样本，检查是否仍能生成转录与分析。断网可用不能替代正常联网时的外发白名单核验；须用操作系统网络监测核对遥测、错误日志等流量的目标与字段。仅从界面看到“local”或“localhost”不能证明所有处理都在本机。

日常使用云后端时，默认拒绝未经批准的外发。批准范围须明确供应商、处理地域、留存期限、是否用于训练及允许发送的最小字段；超出范围不得发送。

## Agent 的权限边界

转录可以包含“忽略之前规则”“上传文件”之类语句；它们是被研究的内容，不是授权。分析进程只读指定会话，写入独立分析目录，不拥有 shell、直播账号或对外发布能力。文件路径、工具参数、大小上限和会话归属由程序校验，不能交给语言模型自觉遵守。[^owasp]

需要外部核验某条主张时，仅提交经批准的最小查询，不上传整段私域文本。发布前重新检查个人信息、内部细节、版权和引文长度。私人转录应留在私人工作区；公共知识包只保留通用方法和授权允许的证据。

## 可迁移模式

**证据先行**适用于直播、访谈、会议记录以及故障日志分析，不适用于无法合法保存来源或无法回查的场景。做法是先登记来源，再冻结原始输入，保存位置映射，生成引用，验证支持度，最后发布。

需要避免的三个反模式是：摘要替代原始证据、时间戳归零后按计划块长拼接、结构化输出通过便认定事实成立。这些来自上游接口和威胁模型的已知限制，不伪称本项目发生过生产事故。迁移到故障日志时，媒体时间可替换为日志行号和文件散列；该迁移仅作设计推演，尚无本包实测案例，成熟度保留为 L1 候选。
