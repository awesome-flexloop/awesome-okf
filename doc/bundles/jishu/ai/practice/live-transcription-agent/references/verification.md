## 纯程序验证

[引用检查](../examples/agent-evidence-check.md)的 15 条函数断言已在 Python 3.14 中执行通过，包括同 ID 多版本、旧版 final 与新版 provisional 并存、过时修订引用和空证据等情况。另将文档中的函数与命令入口组合到系统临时目录，使用真实 JSONL、JSON 文件和子进程完成 14 组测试。

| 文件入口用例 | 期望退出码 | 实测 |
|---|---|---|
| 合法引用、空 claims、引文正确但结论反义 | 0 | 3 组符合；空 claims 不代表分析完成，反义结论揭示语义检查缺口 |
| 错误引文、多修订并存、旧引用、旧 final 与新 provisional 并存、混会话、空转录、无效时间区间 | 1 | 7 组符合，每组恰好 1 个错误 |
| schema 缺字段、非法 JSON、非 UTF-8、布尔型 revision | 2 | 4 组符合 |

对非 2 退出同时核对了输入快照 SHA-256、错误数和检查条数。快照散列只标识校验器读取的文件，不证明模型读过它，也不证明操作者提供的是最新快照。引文存在而结论相反仍会通过，因此还需要人工判断支持度。

全包 4 个 Python 代码块通过 AST 解析，15 个 frontmatter 通过 YAML 解析；文本为 UTF-8 无 BOM，包内无 Python 缓存。AST 解析不等于 ASR 代码已执行，WAV 前置检查也未单独做运行夹具测试。
