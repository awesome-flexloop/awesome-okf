# 内容与Agent工作流中的小判断

> **五例仍是微信单源转述。** 像素与航班原帖访问失败，写作、广告和上下文原帖未尝试。场景拆解是教学推导，不是原项目实现细节或复现实验。

## 6 逐像素配色

微信描述让模型为像素选择颜色及概率，再由程序汇总成画面。[F-017](../references/article-source.md) 一种可理解的教学建模是：程序提供像素位置与文字场景信息，把允许颜色作为候选，模型返回选择或概率，画布程序写入颜色。

这与“向模型上传图片”是不同的接口方向。模型文档当前只支持文本，画布、像素循环、坐标组织和图像编码都在外围。[F-035](../references/article-source.md) 也不能确认原演示逐像素单独请求，还是将多个独立像素问题批在同请求中；原文没有足够的实现证据。

原语层面可以使用Choice表达有限调色板，实际候选上限须核对当前版本，发布文给出的Choice上限为255。[F-026、F-039](../references/article-source.md) 独立像素选择本身不能保证空间连贯，图像一致性取决于输入表达与外围生成组织。需要检验的是画质、连贯性、耗时与完整调用量，而不只是能否显示一幅图。

## 7 航班检索

原文说Jev负责决定浏览器下一动作，小LLM处理文本输入，称7秒完成、费用0.0039美元。[F-018](../references/article-source.md) 因此不能把整个演示归因于Jev单独完成。

| 环节 | 教学拆解 |
| --- | --- |
| 状态 | 用户检索目标与当前页面可读状态 |
| 判断 | 从页面允许的动作中选择下一步 |
| 输出 | 动作候选及概率，必要时转入下一轮 |
| 外围依赖 | 浏览器驱动、页面提取、文本输入模型、结果解析与完成判定 |
| 回退 | 页面变化或动作无法确认时停下；购买、登录或提交敏感信息须另行授权 |

网页内容会随时间变化，动作是否仍合法应在执行前复查。模型输出“点击某选项”后，只有浏览器反馈才能说明点击是否完成。费用比较还需要知道页面解析、辅助模型、重试与网络等待是否计入；原文没有给出这些分项。

## 8 写作反馈

Riley Brown的案例被描述为边编辑帖子边评价传播潜力，没有真实传播预测效果数据。[F-019](../references/article-source.md) 可把草稿作为state，将表达清晰度、具体性或受众匹配拆成独立问题，再由界面展示Score反馈。这些评价维度是教学设计，不是原演示的已知字段。

外围需要文本编辑器、输入更新管理与结果呈现。若用户继续修改，过期草稿的评分应丢弃或注明版本；低置信度应提示评价依据不足，而非要求用户按分数盲改。模型评分是否能帮助写作，应通过编辑质量或真实受众评价检验，不能把“传播潜力”标签直接当曝光量预测。

原文此节还混入角色卡与编号片段；事实登记将它作为编辑结构观察，没有把它扩展为另一项技术能力。[F-022](../references/article-source.md)

## 9 竞品广告分析

原文称评价37个品牌的724条广告，用时40秒、成本9美分，维度涉及钩子、素材、优惠、转化目标和落地页匹配。[F-020](../references/article-source.md) 没有原帖及样本集，不能确认数据规模、统计单位或端到端成本。

教学上可将广告文本与落地页信息提供给模型，按统一量表分别评价各维度，输出表格特征，再由分析程序汇总排序。当前模型不能直接看广告视频或图片；如果实际材料包含这些模态，需要由其他组件先提取信息。[F-035](../references/article-source.md)

外围工作包括合法获取素材、去重、文本化、对齐广告与落地页以及记录来源。应允许缺失材料进入“无法判断”，不能把空字段评分当成低质量广告。即使评分稳定，也不等同转化提升；评价量表与真实业务结果之间的联系需要另行检验。

## 10 上下文筛选

微信描述模型判断历史网页、文件和工具结果对当前任务是否相关，然后筛掉低相关内容；没有压缩率、误删率或任务质量对照。[F-021](../references/article-source.md)

| 环节 | 教学拆解 |
| --- | --- |
| 状态 | 当前任务与带稳定标识的候选片段 |
| 判断 | 每个片段是否相关，或相关程度如何 |
| 输出 | Noul或Score信号，策略决定保留哪些引用 |
| 外围依赖 | 分块、索引、原文存储、检索与上下文拼接 |
| 回退 | 不确定片段暂留；原始内容可恢复，关键约束不交给相关性阈值删除 |

短片段可能缺少解释它重要性的前提；“暂时不相关”也不等于以后没有用。安全约束、用户授权范围和原始证据应保留可追溯通道。对比筛选前后同一任务的答案与证据保留情况，才有资格讨论收益。

## 两种依赖不要混淆

广告的多维评价、同一草稿的几个质量问题，通常可对相同state并行提问。航班检索的下一页尚未打开时，模型无法判断它还未见到的内容；真正的新状态需要后续请求。[F-029](../references/article-source.md)

这个区分可迁移到许多Agent任务：同材料的独立判断可以批处理；需要上一动作产生的新信息就等待真实反馈。类型化输出简化的是决策接口，感知、事实更新与执行仍有各自职责。
