# 机理：压缩内核家族与相位专门化

## 为什么需要从头预训练

DeepSeek-V4 除分块 KV 压缩外，与标准 Transformer 还有其他差异，且无法重新无压缩训练它来观察周期性是否消失。为验证**分块压缩是否为相位敏感性的成因**，团队以 **Qwen3-0.6B 架构**为骨干、**分块压缩作为唯一实质架构改动**，从头预训练了一族模型，并训练同样的**全注意力基线**作对照 [F-028]。

## 压缩内核家族

每个内核把一个窗口压缩成每 KV 头一个 key、一个 value [F-031][F-047]。关键组件：

- **payload map**：决定窗口内每个 token 贡献什么
- **compression gate**：决定该 token 以多强进入摘要
- 支持标量门控（scalar gates）与向量门控（vector gates）

参考模型在每层用单个 KV 头、非重叠 8-token 窗口、标量门控（W8/S8）[F-047]。通过分离**窗口大小 W** 与**步长 S**，可判断周期跟谁走；通过重叠窗口（S<W，token 以多个 offset 出现而相位固定）可检验能否消除该效应 [F-047]。该家族还包含 DeepSeek-V4 的 CSA kernel，以在 Qwen 骨干上复现第 2 节研究的 kernel [F-020]。

## 关键发现

### ① 周期跟随压缩步长，而非窗口

为测量，团队把 NIAH 任务适配到 64 个随机键值对，采用两种填充协议（Prefix Padding / In-sequence Padding）以排除干扰项相位随动的假象 [F-031]。

结果是：**所有受测分块压缩模型都出现与压缩步长对应的周期性变化**；**全注意力基线没有同等周期性** [F-029][F-030]。分别调整窗口与步长，**周期主要跟着压缩步长走**——步长 4→周期 4、步长 6→周期 6、步长 8→周期 8 [F-031]。

更进一步：**不使用 RoPE 位置编码、或把可学习压缩权重换成简单平均（uniform averaging）**，相位敏感性依旧存在 [F-032]。这排除了"某位置编码或某特殊模块单独造成"的解释——**分块压缩这一设计本身就可能引入周期性检索弱点** [F-033][F-034]。

### ② 因果干预揭示相位专门化

对注意力头做**因果干预**（移除不同组件），观察各相位检索能力变化 [F-035]。结果：

- 不同注意力头对**不同相位**的贡献并不一样 [F-036]
- 某些头更擅长处理某些位置，另一些头在别处作用更大
- 团队称之为 **Phase Specialization（相位专门化）** [F-037]

这种"分工"在无分块压缩模型中不可见。在可学习门控的预训练模型里，**部分头在预训练中发展出跨输入复现的稳定位置偏好**，其干预效应在其偏好的相位附近最强——即检索工作在这些被考察的头之间发生了分工 [F-038]。这种分工帮助完成信息检索，却也可能使某些位置成为相对薄弱环节 [F-038]。

### ③ 梯度流驱动压缩门控形成偏好

在理想化的**归纳任务 + 压缩注意力**中，压缩窗口内信息混合会削弱压缩 key 与后续 query 的匹配 [F-039]。理论分析表明：

- **最优压缩器会偏好特定相位** [F-040]
- **梯度流推动门控趋向持久的位置偏好** [F-040]

这解释了两点：为何这种周期性不是简单随机噪声，以及它为何可能是模型在学习压缩信息时**自然而然形成的结果** [F-040]。

## 一句话机理链

分块压缩 → 引入相位结构 → 压缩门控因梯度流形成稳定位置偏好 → 不同注意力头对相位专门化 → 检索能力随相位周期性起伏 → 平均分掩盖周期性弱点。
