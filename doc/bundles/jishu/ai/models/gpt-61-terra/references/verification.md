## 检索边界

搜索 `"Terra" "6.1 Sol"` 找到官方发布文与转述报道；搜索帖子编号返回无关结果，未采纳。转述发布文的报道不计为独立实验。发布文经浏览器读取；系统卡先提取失败，再浏览器访问失败（ERR_CONNECTION_CLOSED），停止补写系统卡细项。

模型参考的 Endpoints 依赖图标表达支持状态，Defuddle 扁平文本丢失该区别。浏览器复核显示 Chat Completions、Responses、Batch 支持，Live、Realtime、Realtime translation、Realtime transcription 不支持；工具调用另有 Responses API 必需约束。图像生成工具支持不代表图像生成端点支持。

## V 审查关注点

| 视角 | 攻击点 | 预防写法 |
|---|---|---|
| 挑战结论 | 两个官方页面会不会被当成独立证据 | 台账注明同厂商证据家族 |
| 挑战结论 | 相同 benchmark 分数会不会被当成全面能力相等 | 仅说该评测 medium 分数相同 |
| 新人 | API 名称是否遗漏，端点名单是否被当支持名单 | 明确 gpt-6.1-terra；单列浏览器矩阵复核 |
| 新人 | “编辑视频”是否被当成原生视频输入 | 明确图像输入、文本输出，电脑操作与原生模态分离 |
| 业务 | 2X 是否能直接换算生产容量与节省人力 | 按成功任务总成本设计试验，不承诺倍数 |
| 业务 | Computer use 是否天然允许转账和发送消息 | 建议最小权限、人工确认；注明本束建议非厂商合同 |
| 未来 | 价格、限速、套餐名单是否会持续不变 | 2026-11-27 前复核；采集日快照 |
| 未来 | 未读取系统卡是否还能标成“已验证安全” | 保持 draft，安全只保留官方归因 |

以上是审查问题与写作约束，不冒充独立审查通过记录。实际独立审查及机械门禁结果在 [变更日志](../log.md) 留痕。

## 独立审查修订

四个独立审查任务分别检查证据、新人理解、业务成本和未来时效。没有 P0；证据视角提出 Cost 台账不充分的 P1，以及任务例、未登记宣传引文和 effort 缺口。新人视角提出执行器定义、验收样例、端点记录和术语释义；业务视角提出费用分母与人工成本统一口径；未来视角未发现问题。

修订已将官网任务例、cost per task 及其统计缺口、Claude effort 观测补入原 F 条目，保持 45 条连续；删除未登记的宣传措辞。能力章补执行器先决条件与术语解释，评估章补非实测验收设计和端点 / 环境版本，费用章补统一币种及统计周期。修补没有新增未经来源取得的性能数值，也没有将设计示例升级为实际案例。
