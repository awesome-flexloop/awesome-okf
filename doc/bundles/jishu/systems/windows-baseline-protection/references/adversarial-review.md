## 🔴 视角一 · 魔鬼代言人（刻意挑刺）

**A1｜「8 项」是不是微软自己都说法不一？有没有可能整篇都在传一个错数字？**
- 攻击点：若支持页写 7 类、博客写 8 项，读者有理由怀疑媒体在凑数。
- **采纳**：不裁决、不抹平。核验报告 E2 与概念页 [02 · 检查项](../concepts/02-baseline-criteria.md) 并列呈现 **8 项（IT Pro Blog 拆分）/ 7 类（支持页合并测试签名保护）**，并说明差别的来源是两条驱动规则是否拆开。
- 回归：两卷事实台账 F-026 与 F-029 分别登记两种口径，未合并成单一数字。

**A2｜「平台不裁决」会不会只是官方话术？预览期有没有可能已有默认拦截？**
- 攻击点：官方博客是市场传播面，不能排除存在未公开的默认策略。
- **采纳**：登记为缺口 **G1**（预览期是否存在默认拦截策略无公开证据）；所有概念页一律写「平台**提供**四档、伙伴**未承诺**任何一档」，不写「Windows 会拦软件」或「Windows 不会拦软件」。
- 回归：F-036 与 F-042 分栏，能力陈述与策略陈述不混用。

## 🟢 视角二 · 新人视角（第一次见这些词）

**A3｜TPM、VBS、HVCI、证明令牌第一次见，直接看 8 项清单等于没看。**
- 攻击点：清单是名词堆砌，缺白话作用与前置知识。
- **采纳**：新建[信源与术语表](sources-and-glossary.md)给出中英对照与一句白话；[02 · 检查项](../concepts/02-baseline-criteria.md) 每一项配「挡住什么」一条，不要求读者先懂内核安全。
- 回归：术语表覆盖 8 项检查 + 3 种读出 + 2 个易混名词。

**A4｜看完只知道「软件可能打不开」，第一步到底该做什么？**
- 攻击点：纯机制拆解没有可执行入口，教程名不副实。
- **采纳**：**创建 `examples/` 两页**——[01 · 设备自查](../examples/01-check-your-device.md)（设置页逐步走查 + 重启/UEFI/IT 管理员三条修复路径）与 [02 · 判断某应用策略](../examples/02-read-an-app-policy.md)（五问核对表）。这是本包区别于「纯商业分析包」的关键：**存在读者可照做的操作，就不能跳过 examples**。
- 回归：`examples/index.md` 挂载两页，bundle 根 toctree 含 `examples/index`。

## 🟠 视角三 · 老板视角（投入产出与合规）

**A5｜2027 才 GA，现在做 19 个文件是不是过早、很快过期？**
- 攻击点：预览期功能的细则会变，投入可能白费。
- **采纳**：全包设 `status: flagged` + `stale_after: 2027-03-31`；[bundle 根](../index.md) 设时效表与**复核触发条件**（GA 发布 / 基线版本增项 / 伙伴公布策略 / 官方版本化规则博客）；把易变部分集中在核验报告与缺口表，机制层与证据层分开写。
- 回归：所有 19 个文件的 frontmatter 一致携带 `status` 与 `stale_after`。

**A6｜源文只是一篇单源公众号，凭什么撑起一个教程？会不会是洗稿？**
- 攻击点：单源媒体评论不足以承载结构化教程，且有版权与事实风险。
- **采纳**：以 **7 个微软官方一手源**为机制骨架（M1~M7），源文降为「切入案例与观点来源」；全包标 `route: chaptered-summary`（深度摘要 + 原创改写，**非逐字转录**）；事实台账分 `page_fact` / `official_fact` / `author_claim` 三层，F-001~F-048 每条标 `src` 与 `locator`。
- 回归：正文无整段原文搬运；作者观点 7 条（F-011、F-038、F-042、F-044、F-046~F-048）全部显式标注，其中 F-046/F-048 登记为不采信。

## 🔵 视角四 · 未来视角（一年后回看）

**A7｜基线是版本化的，今天通过的设备明天可能不通过——教程会不会写成一次性快照？**
- 攻击点：若不写清「地板不是天花板」，读者会把首版 8 项当成永久定义。
- **采纳**：F-031 登记官方原句；[03 · 可验证安全状态](../concepts/03-verifiable-security-state.md) 单列「版本化」一节；时效表把「基线版本增项 / 官方版本化规则博客」列为复核触发；缺口 G2 登记规则尚未发布。
- 回归：任何概念页提到「8 项」均带「首版」限定词。

**A8｜AI 恶意软件那段是科幻推演，会不会被读者当成趋势预测引用？**
- 攻击点：把 speculative 段落与事实混排，是最容易被二次引用放大的部分。
- **采纳**：F-048 标 `author_claim` 并附作者自述「有点科幻」；核验报告 C16 判「不采信、不作为事实或预测引用」；[05 · 信任边界](../concepts/05-trust-boundary-shift.md) 只在「作者观点与其边界」一节引用，明确标注为推测。
- 回归：F-046 的 Defender 黑历史同样列为不采信（C15）。
