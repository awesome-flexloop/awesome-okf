# 🚗 智能驾驶与无人驾驶

本组存放无人驾驶（自动驾驶）技术栈与生态的知识包，以 2020 年前后简书连载《☠️无人驾驶(停止维护)》（作者"水之心"）为事实来源，覆盖从通信底座到整车栈、再到外围生态的完整链路。

> **⚠️ 时效提示**：本组四个知识包均为**历史教程类**，内容时点为 2020 年前后，涉及的版本、命令与资源链接可能过时，请以各项目官方当前文档为准。
