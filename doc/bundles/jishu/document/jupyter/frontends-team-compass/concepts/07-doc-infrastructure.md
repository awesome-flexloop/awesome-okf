# 文档基础设施与构建系统

frontends-team-compass 的文档使用 Python 生态中成熟的 Sphinx 工具链构建，支持 Markdown（通过 MyST）和 reStructuredText 双格式，托管在 ReadTheDocs 上实现自动化构建和部署。

## 技术栈概览

```
┌─────────────────────────────────────────────────────┐
│              ReadTheDocs（CI/CD 托管）               │
│         Ubuntu 22.04 + Python 3.11 自动构建          │
└──────────────────────┬──────────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────────┐
│              Sphinx ≥ 3.0（构建引擎）                │
│  ┌────────────────┐ ┌─────────────────────────────┐ │
│  │ sphinx_book_   │ │ myst_parser（Markdown支持） │ │
│  │ theme（主题）   │ │  → 支持 .md 文件            │ │
│  └────────────────┘ └─────────────────────────────┘ │
│  ┌────────────────┐ ┌─────────────────────────────┐ │
│  │ sphinx_copy-   │ │ sphinx.ext.mathjax（公式）  │ │
│  │ button（代码）  │ │                             │ │
│  └────────────────┘ └─────────────────────────────┘ │
└──────────────────────┬──────────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────────┐
│              源文件                                  │
│  ┌──────────┐ ┌──────────┐ ┌─────────────────────┐ │
│  │ .rst 文件 │ │ .md 文件  │ │ _static/（图片/CSS）│ │
│  │ (index)  │ │ (MyST)   │ │ logo/favicon/custom  │ │
│  └──────────┘ └──────────┘ └─────────────────────┘ │
└──────────────────────┬──────────────────────────────┘
                       │ 构建时执行
┌──────────────────────▼──────────────────────────────┐
│         gen_contributors.py（自动化脚本）            │
│  contributors.yaml → active.txt（HTML表格）         │
└─────────────────────────────────────────────────────┘
```

## Sphinx 配置详解

### 核心配置（conf.py）

| 配置项 | 值 | 说明 |
|--------|-----|------|
| `extensions` | `sphinx.ext.mathjax`, `myst_parser` | 启用数学公式和 Markdown 支持 |
| `source_suffix` | `['.rst', '.md']` | 同时支持 reStructuredText 和 Markdown |
| `master_doc` | `'index'` | 主文档为 index.rst |
| `html_theme` | `'sphinx_book_theme'` | 使用 Jupyter Book 风格的现代化主题 |
| `html_logo` | `'_static/logo.png'` | 侧边栏 Logo |
| `html_favicon` | `'_static/favicon.png'` | 浏览器标签页图标 |
| `html_theme_options` | `{"logo_only": True}` | 仅显示 Logo，隐藏项目标题文字 |
| `pygments_style` | `'sphinx'` | 代码高亮样式 |
| `language` | `"en"` | 文档语言为英语 |

### 自定义 CSS

通过 `setup(app)` 函数注入自定义样式：

```python
def setup(app):
    app.add_css_file("custom.css")
```

这允许在 `_static/custom.css` 中覆盖默认主题样式。

### 构建时自动化

conf.py 的最后两行执行贡献者表格生成：

```python
import subprocess
subprocess.run(['python', 'scripts/gen_contributors.py'], check=True)
```

**注意**：每次 Sphinx 构建都会重新运行此脚本，确保成员表格始终是最新的。

## 构建依赖

文档构建需要以下 Python 包：

| 包 | 用途 |
|----|------|
| `sphinx>=3` | 文档构建引擎 |
| `sphinx_copybutton` | 代码块一键复制按钮 |
| `sphinx_book_theme` | 文档主题 |
| `myst_parser` | Markdown 解析支持 |
| `pandas` | 数据处理（gen_contributors.py 使用） |
| `ruamel.yaml` | YAML 解析（gen_contributors.py 使用） |

## ReadTheDocs 配置

`.readthedocs.yml` 配置自动化 CI/CD 构建：

```yaml
version: 2
build:
  os: ubuntu-22.04
  tools:
    python: "3.11"
sphinx:
  configuration: docs/conf.py
python:
  install:
    - requirements: docs/requirements.txt
```

- 每次推送到 main 分支或提 PR 时自动构建
- 构建环境：Ubuntu 22.04 + Python 3.11
- 自动安装 requirements.txt 中的依赖
- 构建预览在 PR 中可查看

## 贡献者表格自动化

`gen_contributors.py` 实现了成员数据到 HTML 展示表格的自动转换：

### 数据流

```
jupyterlab/council 仓库的 GitHub Actions
       │
       │ 自动更新
       ▼
docs/team/contributors.yaml（YAML数据）
       │
       │ Sphinx构建时
       ▼
gen_contributors.py 读取
       │
       ▼
docs/team/active.txt（raw HTML表格）
       │
       │ Sphinx .. raw:: html 指令
       ▼
最终HTML页面中的贡献者表格
```

### 脚本工作原理

1. **读取 YAML**：使用 `ruamel.yaml` 解析 contributors.yaml
2. **构建 DataFrame**：pandas DataFrame 结构化处理成员数据
3. **生成 HTML**：每行4人（`N_PER_ROW = 4`），每人包含：
   - GitHub 头像（`https://github.com/{handle}.png?size=200`）
   - 链接到 GitHub 个人主页
   - 姓名（加粗）和所属机构
4. **输出文件**：生成 reStructuredText raw HTML 指令包裹的表格，写入 `active.txt`

### 为什么不手动编辑？

contributors.yaml 开头有明确注释：

> This file is automatically generated from workflow https://github.com/jupyterlab/council/.github/workflow/update-members.yml
> **Do not edit manually**

成员数据由 council 仓库的自动化 workflow 统一管理——半年活跃确认 bot 运行后自动更新。这避免了多源数据不一致的问题。

## 本地构建

要在本地构建文档预览：

```bash
# 安装依赖
pip install -r docs/requirements.txt

# 构建 HTML
cd docs/
make html

# 查看输出（_build/html/index.html）
```

Windows 用户使用 `make.bat` 替代 `make`。
