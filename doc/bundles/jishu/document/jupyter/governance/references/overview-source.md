# 治理总览文档信源

**原始文件路径**：`docs/overview.md`

**内容摘要**：

Jupyter 治理模型以三个互补的主体为支柱：

1. **Executive Council (EC)**：对项目所有维度（软件、法律、财务、社区、运营、DEI等）负最终责任
2. **Software Steering Council (SSC)**：管辖跨项目的软件相关决策，协调各子项目
3. **Jupyter Foundation**：Linux Foundation 501(c)(6) 下的定向基金，提供资源和战略咨询

此外，EC 还接收社区顾问小组（Community Advisory Panel）的意见。

其他主要治理组件：
- Software Subprojects（软件子项目）：官方重点领域，每个子项目维护 Subproject Council
- Standing Committees and Working Groups（常设委员会和工作组）：承担非软件工作
- Union of Councils（理事会联盟）：各 Council/委员会/工作组成员的联合
- Distinguished Contributors（杰出贡献者）：荣誉性认可

所有治理机构使用统一的投票程序（见 decision_making.md）。
