# 帮助支持页面 help-support.rst 关键内容

`help-support.rst` 是 Conda 社区资源导航页面。

## 社区支持渠道

| 渠道 | 链接 | 用途 |
|------|------|------|
| Conda Discourse 论坛 | https://conda.discourse.group/ | 异步讨论、新闻、长文问题 |
| Conda Zulip 聊天 | https://conda.zulipchat.com | 实时聊天、快速问答 |
| Anaconda 社区论坛 | https://community.anaconda.cloud/ | Anaconda 产品问答 |

## 付费支持

conda 组织本身不提供付费支持/培训/咨询。商业支持通过 Anaconda 获取（参见其 Help and Support 页面）。

## Feedstock 贡献

conda 社区采用 feedstock 模式：每个包配方对应独立 GitHub 仓库，通过 CI 自动构建。

| 渠道 | 地址 | 说明 |
|------|------|------|
| AnacondaRecipes | github.com/AnacondaRecipes | 可克隆/fork，不接受新 feedstock |
| conda-forge | github.com/conda-forge/staged-recipes | 社区主渠道，提交 PR |
| bioconda | github.com/bioconda/bioconda-recipes | 生物信息学包 |

接受 GPL、BSD、MIT、Apache 等任何许可证的包。

## Conda Announce 邮件列表

- 地址：announce@lists.conda.org
- 订阅：https://lists.conda.org/wws/subscribe/announce
- 特点：低流量（每周≤1封）、官方公告、无营销、无垃圾邮件、隐私保护

## 文档 Issue

conda-docs 文档问题提交到：https://github.com/conda/conda-docs/issues

> 注意：conda-docs 只包含共通文档和着陆页，子项目问题提交到对应仓库。
