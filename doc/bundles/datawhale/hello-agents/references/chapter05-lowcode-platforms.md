# 第五章 基于低代码平台的智能体搭建

## 章节概要

本章介绍Coze、Dify、FastGPT、n8n四个低代码智能体平台，体验图形化、模块化的快速构建方式。教程明确区分"流程驱动的软件工程派"和"AI Native Agent"两条路线。

## 核心知识点

### 低代码平台价值
1. **降低技术门槛**：非技术人员通过拖拽参与构建
2. **提升开发效率**：数分钟完成原型，专注业务逻辑
3. **可视化与可观测性**：端到端运行轨迹可视化
4. **标准化与最佳实践**：内置ReAct模板、RAG引擎、工具规范

### Coze（扣子）
- **出品方**：字节跳动
- **定位**：零代码/低代码Agent构建
- **特点**：
  - 极其友好的可视化界面
  - 丰富插件库
  - 一键发布到抖音、飞书、微信等平台
  - 工作流、对话流、知识库、数据库、卡片等完整能力
- **游戏化比喻**：工作流=通关路线图，插件=技能卡，知识库=百科全书，数据库=云存档
- **适用**：入门用户、产品经理、运营、个人创作者

### Dify
- **定位**：开源LLM应用开发与运营平台
- **特点**：
  - Agent工作流 + RAG Pipeline + 数据标注与微调
  - 后端服务+模型运营理念
  - 企业级可扩展
- **适用**：有技术背景的开发者、企业团队

### FastGPT
- **定位**：开源知识库问答平台与Agent构建工具
- **特点**：
  - RAG场景极致优化
  - 数据导入→自动分块→向量化→智能检索完整链路
  - 可视化工作流编排（Flow模块）
  - 模型中立设计
- **适用**：私有知识库问答、智能客服、文档问答机器人

### n8n
- **定位**：开源工作流自动化工具（非纯LLM平台）
- **特点**：
  - 数百预置节点连接SaaS服务、数据库、API
  - AI能力作为自动化链路一环
  - 通用自动化能力独一无二
  - 学习曲线相对陡峭
- **适用**：AI深度整合业务流程、高度定制自动化

### 平台对比

| 平台 | 核心优势 | 最适合场景 |
|------|---------|-----------|
| Coze | 生态丰富、一键多平台发布 | 快速产品化、C端应用 |
| Dify | 功能全面、企业级 | 企业AI应用、RAG+Agent |
| FastGPT | RAG极致优化 | 知识库问答 |
| n8n | 通用自动化连接 | 业务流程AI集成 |
