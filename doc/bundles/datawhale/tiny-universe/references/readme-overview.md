# 参考：README 项目总览与意义

本页登记 tiny-universe README 中"项目介绍""项目意义""项目受众""项目亮点"章节的核心内容。

## 项目介绍

- 项目是一个从原理出发、以"白盒"为导向、围绕大模型全链路的"手搓"大模型指南。
- 目标读者：有传统深度学习基础的读者。
- 范围：大模型本身、RAG 框架、Agent 系统、大模型评估体系。
- 手段：深入剖析每一个技术点并附完整代码实现，以细致讲解和代码注释帮助读者独立复现核心部分。
- 愿景：为学习者搭建清晰、可用、可复现的大模型世界，帮助每个人手工搭建自己的 **Tiny LLM Universe**。

## 项目意义

- 百模大战背景下，开源/闭源大模型不断刷新能力上限，二次微调与应用开发门槛持续降低。
- 但生态愈成熟，深入理解框架内部细节、实现独立于框架的开发能力愈关键。
- 现有教程多基于高度封装的 API 与开源框架，使学习者"知其然而不知其所以然"，只能机械使用工具包。
- 本项目从底层（PyTorch 层）出发，"纯手搓"大模型系统，完成 RAG、Agent、Eval 任务，帮助学习者掌握原理、自由魔改。

## 项目受众

- 掌握了大模型基本应用，想学习原理但不知从何开始
- 好奇心旺盛、求知欲强、有学习热情
- 对 RAG、Agent、Eval 感兴趣，想从原理层面了解
- 喜欢动手实践，想从零手写 RAG、Agent、Eval
- 想了解底层原理、提升技术水平

## 项目亮点

1. **全流程从零手搓**
2. **LLM 全栈教程**：从 Model 到 RAG、Agent、Eval
3. **简洁清晰、更"白盒子"**：区别于大型算法包，对初级开发者友好
4. **持续迭代**：TinyLlama3、垂直领域数据集等
5. **开放贡献**：欢迎社区参与
