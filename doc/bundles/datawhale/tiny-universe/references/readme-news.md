# 参考：README 发布时间线（News）

本页登记 README"News"章节记录的项目发布与更新事件，按时间倒序排列。

## 时间线

| 日期 | 事件 | 涉及模块 |
|------|------|----------|
| 2025.8.12 | 发布 TinyGraphRAG，从零上手 GraphRAG | TinyGraphRAG |
| 2024.12.25 | 发布 TinyDiffusion，从零上手 Diffusion；两小时完成图像生成预训练 | TinyDiffusion |
| 2024.10.28 | 发布 TinyLlama3，从零上手 Llama 预训练到加载模型推理；2G 显存即可完成 | TinyLlama3 / TinyLLM |
| 2024.6.26 | 增加选修内容——高考数学评测，使 TinyEval 接入高考题目评测 | TinyEval |
| 2024.5.20 | 增加选修内容——Tiny Transformer，纯手工搭建 Transformer 模型 | TinyTransformer |
| 2024.5.1 | 发布 Tiny-Universe V1 版本（劳动节帕鲁献礼） | 项目整体 |

## 观察

- 项目从基础组件（TinyTransformer、V1）起步，逐步扩展到模型训练（TinyLlama3）、生成模型（TinyDiffusion）和图检索增强（TinyGraphRAG）。
- TinyEval 在 V1 之后持续扩充垂直领域评测能力（高考数学）。
- TinyGraphRAG 是最新加入的模块（2025.8.12），标志着项目从基础 RAG 向进阶检索技术延伸。
- 探索部分的 CDDRS (ADVEI25) 未在 News 中标注具体发布日期，属于较新的学术复现内容。
