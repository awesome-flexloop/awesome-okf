1. **前置准备**：确保已安装 pandas 和 numpy：`pip install pandas numpy`
2. **运行环境**：推荐在 Jupyter Notebook/Lab 中交互式运行示例代码
3. **学习路径**：先阅读 [concepts/](../concepts/00-introduction.md) 理解核心概念，再运行示例巩固
