# pyplot 状态机

`matplotlib.pyplot`（通常导入为 `plt`）是 Matplotlib 提供的 MATLAB 风格过程式接口。它通过一个全局状态机隐式追踪「当前 Figure」和「当前 Axes」，让用户无需显式管理对象引用即可快速绑图。pyplot 的所有绘图函数本质上都是 Axes 对象方法的薄包装（thin wrapper）。

## 一、状态机的核心概念

pyplot 的核心思想是维护两个全局状态：

1. **当前 Figure**：最近创建或激活的 Figure 对象
2. **当前 Axes**：当前 Figure 中最近创建或激活的 Axes 对象

用户调用 `plt.plot()` 时，pyplot 会自动找到当前 Axes 并调用其 `plot()` 方法，用户不需要持有 Axes 引用。这与 MATLAB 的工作方式高度相似。

### 全局 Figure 管理器：Gcf

状态机的核心是 `_pylab_helpers.Gcf`（Global Current Figure）单例，它维护一个 Figure 对象的有序字典，并追踪活动 Figure：

```python
# _pylab_helpers.py 中的 Gcf 类
class Gcf:
    """Singleton to maintain a mapping of figure numbers to Figure instances."""
    _figures = {}          # fig_num -> FigureManager 映射
    _currentFigure = None  # 当前活动 Figure 编号

    @classmethod
    def get_active_manager(cls):
        """返回当前活动 FigureManager，无则返回 None"""
    @classmethod
    def destroy(cls, num):
        """销毁指定编号的 Figure"""
    @classmethod
    def destroy_all(cls):
        """销毁所有 Figure"""
```

## 二、关键函数解析

### gcf()：获取当前 Figure（Get Current Figure）

定义在 `pyplot.py` 第 1150 行：

```python
def gcf() -> Figure:
    """Get the current figure.

    If there is currently no figure on the pyplot figure stack,
    a new one is created.
    """
    manager = _pylab_helpers.Gcf.get_active()
    if manager is not None:
        return manager.canvas.figure
    else:
        return figure()
```

行为：
- 如果已有活动 Figure，返回该 Figure
- 如果没有活动 Figure，**自动创建一个新的**并返回
- 这就是为什么直接调用 `plt.plot()` 不需要先创建 Figure

### gca()：获取当前 Axes（Get Current Axes）

定义在 `pyplot.py` 第 2933 行：

```python
def gca() -> Axes:
    """Get the current Axes.

    If there is currently no Axes on the current figure,
    a new one is created.
    """
    return gcf().gca()
```

它调用当前 Figure 的 `gca()` 方法。Figure 通过 `_AxesStack`（`figure.py` 第71行）追踪当前 Axes，`_AxesStack.current()` 返回最近添加/激活的 Axes。

### figure()：创建/激活 Figure

定义在 `pyplot.py` 第 904 行：

```python
def figure(num=None, figsize=None, dpi=None, facecolor=None,
           edgecolor=None, frameon=True, FigureClass=Figure,
           clear=False, **kwargs) -> Figure:
```

- 如果 `num` 对应的 Figure 已存在，激活它并返回
- 如果不存在，创建新 Figure，编号为 `num`（或自动递增）
- 新创建的 Figure 自动成为当前 Figure

### subplots()：创建 Figure 和子图网格

定义在 `pyplot.py` 第 1679 行：

```python
def subplots(nrows=1, ncols=1, *, sharex=False, sharey=False,
             squeeze=True, width_ratios=None, height_ratios=None,
             subplot_kw=None, gridspec_kw=None, **fig_kw):
```

这是最推荐的 Figure/Axes 创建方式，一次性返回 `(fig, axs)`：

```python
fig, ax = plt.subplots()           # 单个 Axes
fig, (ax1, ax2) = plt.subplots(1, 2)  # 1行2列
fig, axs = plt.subplots(2, 2)      # 2行2列，axs 是二维数组
```

### plot()：绘制折线

定义在 `pyplot.py` 第 4041 行（boilerplate 生成部分）：

```python
def plot(*args, scalex=True, scaley=True, data=None, **kwargs):
    return gca().plot(
        *args, scalex=scalex, scaley=scaley,
        **({"data": data} if data is not None else {}), **kwargs)
```

可以看到，`plt.plot()` 就是 `gca().plot()` 的一行包装！几乎所有 pyplot 绘图函数都遵循这个模式。

### show()：显示图形

定义在 `pyplot.py` 第 602 行，启动后端 GUI 事件循环，显示所有 Figure 窗口并阻塞直到窗口关闭。

### savefig()：保存图形

定义在 `pyplot.py` 第 1343 行：

```python
def savefig(fname, *, transparent=None, **kwargs):
    return gcf().savefig(fname, **({"transparent": transparent} if transparent is not None else {}), **kwargs)
```

保存**当前 Figure**到文件。

### switch_backend()：切换后端

定义在 `pyplot.py` 第 395 行，关闭所有已有 Figure 并切换到新后端。

## 三、pyplot 函数 = Axes 方法的薄包装

pyplot 文件的大部分（第3行注释中说明从 `### REMAINING CONTENT GENERATED BY boilerplate.py ###` 开始）由 `boilerplate.py` 脚本自动生成，为每个 Axes 绘图方法生成对应的 pyplot 包装函数。

模式如下：

```python
# boilerplate.py 自动生成的模式
def <pyplot_func>(*args, **kwargs):
    return gca().<axes_method>(*args, **kwargs)
```

常见对应关系：

| pyplot 函数 | 等价的 Axes 方法 | 说明 |
|------------|-----------------|------|
| `plt.plot(x, y)` | `ax.plot(x, y)` | 折线图 |
| `plt.scatter(x, y)` | `ax.scatter(x, y)` | 散点图 |
| `plt.bar(x, h)` | `ax.bar(x, h)` | 柱状图 |
| `plt.hist(x)` | `ax.hist(x)` | 直方图 |
| `plt.imshow(img)` | `ax.imshow(img)` | 显示图像 |
| `plt.contour(x,y,z)` | `ax.contour(x,y,z)` | 等高线 |
| `plt.pie(x)` | `ax.pie(x)` | 饼图 |
| `plt.fill_between(x,y1,y2)` | `ax.fill_between(x,y1,y2)` | 填充区域 |
| `plt.errorbar(x,y,yerr)` | `ax.errorbar(x,y,yerr)` | 误差棒 |

## 四、Figure 的 Axes 栈：_AxesStack

Figure 内部使用 `_AxesStack`（`figure.py` 第71行）管理其 Axes：

```python
class _AxesStack:
    def __init__(self):
        self._axes = {}     # Axes -> 顺序编号
        self._counter = itertools.count()

    def add(self, a): ...       # 添加 Axes
    def remove(self, a): ...    # 移除 Axes
    def bubble(self, a): ...    # 将 Axes 提到栈顶（激活）
    def current(self): ...      # 返回栈顶（当前）Axes
```

- 当通过 `add_subplot()` 或 `add_axes()` 添加新 Axes 时，它被 `add()` 到栈中
- 当用户点击某个子图或调用 `sca(ax)`（Set Current Axes）时，该 Axes 被 `bubble()` 到栈顶
- `fig.gca()` 返回 `_axstack.current()`

## 五、OO 接口 vs pyplot 接口

### 对比

| 维度 | 面向对象接口（OO） | pyplot 状态机接口 |
|------|-------------------|------------------|
| **风格** | 显式持有 fig/ax 引用 | 隐式 gcf()/gca() |
| **适合场景** | 脚本、函数、应用、复杂绑图 | Jupyter/IPython 交互探索、快速原型 |
| **控制力** | 完全控制每个对象 | 受限于当前 Figure/Axes |
| **多图管理** | 自然（每个 fig 独立引用） | 需要切换当前图（`plt.figure(n)`） |
| **可维护性** | 高（明确的对象依赖） | 低（全局状态，难调试） |
| **函数封装** | 可传入 ax 参数 | 依赖全局状态，难封装 |
| **线程安全** | 相对安全（无全局共享） | 不安全（全局状态） |

### OO 接口推荐写法

```python
import matplotlib.pyplot as plt
import numpy as np

def make_plot(ax, x, y, title):
    """接受 Axes 参数的绑图函数，可复用"""
    ax.plot(x, y, 'b-', linewidth=2)
    ax.fill_between(x, y*0.8, y*1.2, alpha=0.2, color='blue')
    ax.set_xlabel('X')
    ax.set_ylabel('Y')
    ax.set_title(title)
    ax.grid(True, alpha=0.3)
    return ax.lines[-1]  # 返回创建的 Artist

# 创建 Figure 和 Axes 网格
fig, axs = plt.subplots(2, 2, figsize=(10, 8))
x = np.linspace(0, 2*np.pi, 100)

# 在每个子图上绑图
make_plot(axs[0,0], x, np.sin(x), 'sin(x)')
make_plot(axs[0,1], x, np.cos(x), 'cos(x)')
make_plot(axs[1,0], x, np.tan(x), 'tan(x)'); axs[1,0].set_ylim(-5, 5)
make_plot(axs[1,1], x, np.exp(-x), 'exp(-x)')

fig.suptitle('三角函数与指数函数', fontsize=14)
fig.tight_layout()
plt.show()
```

### pyplot 交互写法（适合 Jupyter）

```python
import matplotlib.pyplot as plt
import numpy as np

# 快速探索数据
plt.figure(figsize=(8, 4))
x = np.linspace(0, 10, 100)
plt.plot(x, np.sin(x), 'r-', label='sin')
plt.plot(x, np.cos(x), 'b--', label='cos')
plt.fill_between(x, np.sin(x), np.cos(x), alpha=0.1)
plt.xlabel('x')
plt.ylabel('y')
plt.title('三角函数')
plt.legend()
plt.grid(alpha=0.3)
plt.show()
```

## 六、在两者之间切换

即使使用 pyplot 创建 Figure，也可以随时获取对象引用切换到 OO 风格：

```python
plt.figure()
plt.plot([1,2,3], [1,4,9])  # pyplot 风格

# 切换到 OO 风格
ax = plt.gca()       # 获取当前 Axes
fig = plt.gcf()      # 获取当前 Figure
ax.set_ylabel('平方值')  # OO 风格操作
ax.annotate('最大值', xy=(3,9), xytext=(2,8),
            arrowprops=dict(arrowstyle='->'))
```

反之，持有 OO 引用时也可以使用 pyplot 函数，但建议保持一致：

```python
fig, ax = plt.subplots()
ax.plot(x, y)
# 不推荐混合：虽然能工作但风格混乱
plt.xlabel('X')     # 操作的是 gca()，即刚才的 ax
```

## 七、状态机陷阱

pyplot 状态机虽然方便，但有一些常见陷阱：

### 陷阱1：忘记当前 Axes 已经切换

```python
plt.figure()
ax1 = plt.subplot(2,1,1)
plt.plot(x1, y1)
ax2 = plt.subplot(2,1,2)
plt.plot(x2, y2)

# 此时 gca() 是 ax2！下面操作会影响 ax2 而非 ax1
plt.xlabel('标签')  # 标签加到了 ax2！

# 解决方案：使用 OO 接口
ax1.set_xlabel('标签')
```

### 陷阱2：多 Figure 混淆

```python
plt.figure(1)
plt.plot(x1, y1)

plt.figure(2)
plt.plot(x2, y2)

# gcf() 现在是 figure 2
plt.title('图1标题')  # 标题加到了图2！

# 解决方案：显式激活或使用引用
plt.figure(1)
plt.title('图1标题')
# 或
fig1, ax1 = plt.subplots()
fig2, ax2 = plt.subplots()
ax1.set_title('图1标题')
```

### 陷阱3：在函数/类中使用 pyplot

```python
# ❌ 不好的封装：依赖全局状态
def plot_data(x, y):
    plt.plot(x, y)
    plt.xlabel('X')  # 影响调用者的当前 Axes

# ✅ 好的封装：接受/创建 Axes
def plot_data(ax=None, x=None, y=None):
    if ax is None:
        ax = plt.gca()
    ax.plot(x, y)
    return ax
```

### 陷阱4：多次 show()

在非交互模式下，`plt.show()` 会阻塞并在窗口关闭后清空所有 Figure。第二次调用 `show()` 不会重新显示——需要在 `show()` 之前完成所有绑图。

```python
plt.plot([1,2,3])
plt.show()         # 显示窗口，阻塞
# ... 用户关闭窗口后 ...
plt.plot([4,5,6])
plt.show()         # 在某些后端/环境中可能不显示新窗口
```

## 八、交互模式

pyplot 支持交互模式（interactive mode），通过 `plt.ion()` 开启，`plt.ioff()` 关闭：

- **交互模式（ion）**：每次绑图命令后自动更新显示，`show()` 不阻塞
- **非交互模式（ioff，默认）**：绑图命令不立即显示，`show()` 阻塞直到窗口关闭

```python
plt.ion()   # 开启交互模式
plt.plot([1,2,3])  # 立即显示
plt.pause(0.5)     # 暂停让GUI事件循环处理
plt.plot([4,5,6])  # 自动更新
```

在 IPython/Jupyter 中，`%matplotlib` 魔法命令会自动开启交互模式。

## 九、pyplot 自动生成机制

`pyplot.py` 文件分为两部分：
1. **手写部分**（文件开头到 `### REMAINING CONTENT GENERATED BY boilerplate.py ###`）：包含核心函数（gcf、gca、figure、subplots、show、savefig、switch_backend 等）和导入
2. **生成部分**：由 `boilerplate.py` 脚本根据 Axes 方法自动生成包装函数

这种自动生成保证了 pyplot 函数与 Axes 方法签名/文档保持同步。每个生成的包装函数都使用 `_copy_docstring_and_deprecators` 装饰器从对应 Axes 方法复制文档字符串和弃用警告。
