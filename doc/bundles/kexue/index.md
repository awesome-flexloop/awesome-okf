# 🔬 科学

本域存放自然科学经典著作的系统阅读知识包，以"经典原文选读 + 现代解读"方式组织：

- **化学经典**：中西双线索——西方近代化学奠基四元典（波义耳→拉瓦锡→道尔顿→门捷列夫）与中国古代炼丹/工艺化学三典籍（《周易参同契》《抱朴子·内篇》《天工开物》）。
- **物理学经典**：四条线索——原著阅读指南（12 部核心元典 + 9 部扩充核心级著作，伽利略至温伯格）、公有领域著作原文逐段精读、量子力学/相对论/热统三个分领域专题精读束，以及中国古代物理典籍原文解读。
- **数学经典**：国外数学经典阅读（欧几里得到布尔巴基，五时段经典谱系）与中西数学对读（六大对读主题——几何度量/数论代数/极限无穷小/符号化抽象/公理化算法化/接触互鉴，含双源精读示范）。

**收录边界**：中国传统算学归 [国学](../guoxue/index.md) 域；本域收录西方科学元典与国外数学经典。
