# 🔬 科学

本域存放自然科学经典著作的系统阅读知识包，以"经典原文选读 + 现代解读"方式组织：

- **化学经典**：中西双线索——西方近代化学奠基四元典（波义耳→拉瓦锡→道尔顿→门捷列夫）与中国古代炼丹/工艺化学三典籍（《周易参同契》《抱朴子·内篇》《天工开物》）。
- **物理学经典**：中西双线索——西方物理学里程碑元典（伽利略《两门新科学》至朗道-栗弗席兹《理论物理学教程》）与中国古代物理典籍原文解读。
- **数学经典**：国外数学经典阅读——欧美数学原著原文与解读教程（欧几里得到布尔巴基，五时段经典谱系）。

**收录边界**：中国传统算学归 [国学](../guoxue/index.md) 域；本域收录西方科学元典与国外数学经典。
