## 三、使用提示

1. **检索式建议**：平台内检索用"作者拉丁名/英文名 + 书名拉丁名 + 年份"（如 `Euler Introductio 1748`、`Cauchy Cours d'analyse 1821`），命中率高于中文检索。
2. **扫描本优先选大学馆藏**：Internet Archive 条目注意看上传来源（Cornell、UC Berkeley、Osmania 等大学扫描质量稳定）。
3. **PDF 大小与 OCR**：早期扫描 PDF 常无文字层，无法复制；Gutenberg 纯文本适合做选段，扫描 PDF 适合核对原版版式。
4. **版权红线**：1929 年后出版的译本（Clarke 1966、Neumann 2011、Cohen-Whitman 1999 等）即使全文出现在网络上，也仅限个人学习访问，不得复制再发布；引用时按合理使用原则做短摘并标注出处。
