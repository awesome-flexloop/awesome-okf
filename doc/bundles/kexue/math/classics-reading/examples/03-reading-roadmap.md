# 十二个月通读路线图

本计划把 [概念谱系](../concepts/index.md) 中的 14 篇文档组织成一条约 12 个月、每周 4–6 小时的阅读路径。原则：**每个阶段 2–3 部核心文本精读，其余选读**；不追求读完，追求读懂关键命题并建立时间轴。

前置条件：高中数学；微积分与线性代数在阶段三开始前补齐到本科一年级水平即可（可并行）。

## 总览

```
 └─ 《原本》卷一精读               └─ 概念 08 笛卡尔/牛顿/莱布尼茨
        │                                  │
阶段三（月7–9）分析的世纪          阶段四（月10–12）严格化与现代
 ├─ 概念 09 欧拉三部曲             ├─ 概念 11 非欧/黎曼/伽罗瓦

```

## 阶段一（月 1–3）：方法与希腊

**目标**：建立三遍读法习惯；体验公理化文体。

| 周 | 内容 | 动作 |
|----|------|------|
| 1 | [第一天示例](02-first-originals-starter.md) | 60 分钟三段式体验 |
| 2–3 | 概念 00–04 | 通读五篇方法论，建好个人笔记模板 |
| 4–6 | 《原本》卷一 | 照 [精读示范](01-euclid-close-reading.md) 精读 I.1、I.47；再选读 I.4、I.5、I.32、I.48 |
| 7–8 | 《原本》卷五（比例论）选读 | 读定义 5（Eudoxus 比例定义）与几个命题，体会"无理量如何被严格处理" |
| 9–10 | 阿基米德选读 | 《圆的度量》命题 1（面积穷竭法）或《方法》选段（Heath 译本，见 [原文信源](../references/original-sources.md)） |
| 11–12 | 阿波罗尼奥斯选读 + 复盘 | 读 Heath 译本导言与卷一关于抛物线/双曲线基本性质的 2–3 个命题；写阶段笔记 |

**阶段产出**：一份《原本》I.47 精读笔记；一张"希腊几何三大家"对照表。

## 阶段二（月 4–6）：传承与革命

**目标**：看到代数-几何关系的两次重构（阿拉伯、笛卡尔）与微积分诞生。

| 周 | 内容 |
|----|------|
| 13–14 | 概念 06：丢番图选读（Heath 译本卷一若干问题）、帕普斯选读（Rorres 站点卷五等周问题片段） |
| 15–17 | 概念 07：花剌子米 Rosen 译本前 40 页（六类方程 + x²+10x=39 几何证明）；海亚姆 Kasir 译本导言 + 一类三次方程求解 |
| 18–20 | 概念 08a：笛卡尔 Smith-Latham 译本第一卷前 20 页（单位线段构造），配导读 |
| 21–22 | 概念 08b：莱布尼茨三篇论文（Struik 或 Smith 资料汇编英译，合计约 20 页），对照现代求导/积分法则表 |
| 23–24 | 概念 08c：牛顿《原理》选读——Cohen-Whitman Guide 对应章 + 原书命题 1、命题 11；写阶段笔记 |

**阶段产出**：一张"从海亚姆到笛卡尔：三次方程求解方法对比"表；一篇莱布尼茨 1684 论文的法则对照表。

## 阶段三（月 7–9）：分析的世纪

**目标**：理解"函数"成为中心；体验 18 世纪形式化风格。

| 周 | 内容 |
|----|------|
| 25–28 | 概念 09a：欧拉 E101 前 8 章（Bruce 英译免费），每周 2 章；配 Sandifer HEDI 专栏每周 1 篇 |
| 29–31 | 概念 09b：《微分学原理》前 5 章选读；用 SymPy 验证 3 个级数展开（见库内 [SymPy 包](../../../../jishu/data/pydata/sympy/index.md)） |
| 32–34 | 概念 09c：《积分学原理》卷一/卷二选读：部分分式与一阶微分方程分类 |
| 35–36 | 概念 10：高斯《算术研究》Clarke 译本前两节（同余体系）+ 第七节条目 365–366（正十七边形结论）；写阶段笔记 |

**阶段产出**：一份"欧拉式形式操作"清单（哪些大胆、后来如何被严格化）；二次互反律陈述卡。

## 阶段四（月 10–12）：严格化与现代

**目标**：亲历 19 世纪三大革命与 20 世纪公理化。

| 周 | 内容 |
|----|------|
| 37–39 | 概念 11a：罗巴切夫斯基 1840 小书（Halsted 译，61 页）通读；Bonola 史书相关章 |
| 40–41 | 概念 11b：黎曼 1854 演讲（Clifford 英译）慢读两遍 |
| 42–43 | 概念 11c：伽罗瓦——先读现代群论教材基础章，再读 Edwards《Galois Theory》中 Premier Memoire 英译与讲解；绝笔信短读 |
| 44–46 | 概念 12a：戴德金 1872 整本（Gutenberg #21016，约 40 页）；康托尔 1874 论文（Ewald 汇编或网络译文） |
| 47–48 | 概念 12b：柯西《分析教程》Bradley-Sandifer 译注前 20 页（图书馆）；希尔伯特《几何基础》Townsend 译本前两章（IA 免费） |
| 49–50 | 概念 13（选读）：SEP 的 Principia Mathematica 条目 + PM 二版导言选段（Gutenberg #78050）；布尔巴基《数学史原理》选读 2 章 |
| 51–52 | 总复盘：更新个人时间轴；写一篇"我的经典阅读年"总结 |

**阶段产出**：一张"19 世纪三场革命"对照表（对象/旧假设/新对象/后果）；个人数学经典时间轴（公元前 300 → 1939）。

## 弹性规则

1. **跳读合法**：阿波罗尼奥斯、帕普斯、牛顿《原理》、PM 都可以只选读——路线图标注"选读"的部分跳过不影响后续；
2. **顺序可调**：对分析兴趣大者可把阶段三提前到阶段二之后、阶段四之前（计划已如此安排）；对几何兴趣大者可在阶段一加读《原本》卷六；
3. **译本获取**：公共领域文本用 [原文信源](../references/original-sources.md) 的免费链接；版权译本（Cohen-Whitman、Clarke、Bradley-Sandifer、Neumann 等）走图书馆，不要复制传播；
4. **时间不足的压缩版**（每周 3 小时）：保留《原本》I.47、花剌子米前 40 页、莱布尼茨三篇、E101 前 4 章、罗氏 1840、戴德金 1872，其余全部选读，路线延长到约 18 个月；
5. 每阶段结束写复盘笔记，格式可参考概念 03 的"三遍读法"归档要求。
