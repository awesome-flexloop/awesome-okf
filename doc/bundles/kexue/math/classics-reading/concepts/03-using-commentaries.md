# 如何使用评注与二手研究

读经典不是"原文 vs 二手"的二选一，而是**原文、译注、解读三者的配合**。关键纪律只有一条：先自己读，再让评注介入——否则评注会替你思考，你得到的是评注者的结论而非自己的理解。

## 一、三类评注资源

### 第一类：逐命题/逐节评注（贴身导读）

- **Joyce《几何原本》网络版**：每个命题一页，译文下方评注解释命题意图、与现代几何的关系、欧几里得隐含的假设（如对图形连续性的默认）。这是零外语读者读希腊几何的最佳贴身导读。
- **Heath 译注脚注**：保存历代阐释分歧，标注哪些步骤是后人补入。适合二读时逐条看。
- **Rorres 阿基米德站、Fitzpatrick 对照本脚注**：解决具体术语与文本异文。

### 第二类：解读专栏/专书（方法示范）

- **Sandifer《How Euler Did It》**（MAA 月刊专栏归档）：每篇用几页重走一个欧拉论证，展示"欧拉为什么这样算"。这是学习"像欧拉一样思考"的最佳范本，语言浅白。
- **Edwards《Galois Theory》**（Springer 1984）：含 Premier Memoire 英译与逐节讲解，伽罗瓦理论入门的经典桥梁。
- **Cohen-Whitman《原理》Guide**：370 页独立导读，解决 17 世纪力学与几何语言障碍。
- **Bradley-Sandifer 译注柯西**：2009 年首个英译本，译者注解释 19 世纪分析术语。

### 第三类：通史与传记（语境坐标）

- **MacTutor 传记**：读任何一位作者前先花 20 分钟读其传记页，建立生卒年、著作年表、学术关系网。
- **Katz / Boyer-Merzbach 通史**：读完一个时段后用通史核对概念定位。
- **Ewald《From Kant to Hilbert》**：19 世纪基础论战的一手论文汇编，本身带长篇导论。
- **SEP**：数学哲学问题（逻辑主义、形式主义、直觉主义）的权威综述。

资源清单见 [现代解读信源](../references/modern-expositions.md)。

## 二、配合方法：三遍读法

```
第一遍（裸读）：只读译文，不看任何注。
  → 目标：标记"卡住的地方"（术语、跳步、奇怪的论证）。
  → 卡住是收获而非失败：标记点正是评注要解决的问题。

第二遍（对注）：逐命题对照 Joyce/Heath/Sandifer。
  → 重点看：作者隐含了什么假设？这一步在现代数学里对应什么？
  → 对注时在笔记里区分两层：【原文说的】与【注者解释的】。

第三遍（回语境）：读 MacTutor 传记 + 通史对应章节。
  → 回答：这部书写于作者生涯哪个阶段？回应的是什么问题？
  → 同时代人（如牛顿与莱布尼茨、罗巴切夫斯基与鲍耶）互相参照。
```

## 三、两个纪律

1. **区分"原文说的"与"注者认为的"**。Heath 会用 19 世纪末的数学眼光解释古人；Edwards 的伽罗瓦讲解用了现代群论语言重构。笔记中把两层分开，才能看到思想的原貌与后世的重构之间的距离。
2. **评注也会过时**。Heath 的个别判断（如对阿波罗尼奥斯卷五至七的评价）已被 Toomer 1990 年阿拉伯文译本修正；把 MacTutor、SEP 等当代资源作为交叉核对层。

## 反模式

- **以注代经**：只读通史和导读，从不打开原文——二手叙述会把争议抹平、把失败剪掉，你永远看不到数学生产现场的粗糙感。
- **注海战术**：同时摊开五本注本逐条比对——新手负担不起也不需要，一文一注足矣。
- **跳过传记直接读**：不知道作者在回应谁（如希尔伯特回应非欧几何后的公理危机），很多论证意图无从理解。

## 初学者建议

从一篇 Sandifer 专栏开始：它有原文（Euler Archive 链接）、有重走、有评论，长度合适，是"三遍读法"的最小演练场。
