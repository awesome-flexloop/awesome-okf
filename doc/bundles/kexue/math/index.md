# 数学经典阅读知识包

本分组收录数学经典的系统阅读知识包，包含两条互补线索：

- **国外数学经典**：古希腊—阿拉伯—欧洲传统经典谱系（欧几里得《几何原本》约公元前 300 年到布尔巴基《数学原本》1939 年起），回答原文获取、译本注本选用、思想解读三个问题。
- **中西数学对读**：比较视角的整合层——中国算学传统与西方数学传统的平行发展、路径分歧、优先权辨析与接触互鉴（1607/1857《几何原本》汉译），与国学域算学束对读联动。
