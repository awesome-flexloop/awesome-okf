# 架构洞察（Architecture Insights）

> 基于事实清单（facts.md，F-001~F-020）与四篇精读得出，每条洞察遵循四元组结构（陈述/证据/反常识/行动）

---

## 洞察1：四篇论文代表四种正当性策略

| 四元组 | 内容 |
|--------|------|
| **陈述** | 玻尔 1913（现象覆盖）、海森堡 1925（可观察性纲领）、薛定谔 1926（形式替换）、狄拉克 1928（现象缺口+代数强制）——四篇论文各用一种不同的策略为新形式辩护。 |
| **证据** | examples/01（"硬性规定"）、examples/02（纲领句）、examples/03（替换宣言）、examples/04（ad hoc 批评） |
| **反常识** | 教材把 1925-1928 写成"理论进步的直线"，实际每一步的辩护方式不同——矩阵派与波动派的"哲学对立"（离散 vs 连续）在形式等价后依然存在。 |
| **行动** | 精读方法论第一步固定为"纲领句定位"，并分类其策略类型。 |

## 洞察2：符号系统的代际差是精读的最大陷阱

| 四元组 | 内容 |
|--------|------|
| **陈述** | 海森堡 1925 无矩阵一词、薛定谔 1926 无概率诠释、狄拉克 1928 无 bra-ket——把现代符号脑补进原文会系统性误读论证。 |
| **证据** | facts F-007/F-015/F-020（三个"缺席"事实）；各示范的符号还原表 |
| **反常识** | 读原文比读教材容易犯错的地方不是"看不懂"，而是"看懂了不存在的东西"。 |
| **行动** | 每篇示范固定附符号还原表；方法论规定不把现代符号带入原文推导。 |

## 洞察3：奠基论文的"未完成处"标示了下一步工作

| 四元组 | 内容 |
|--------|------|
| **陈述** | 四篇论文各自公开承认的缺口，精确指向后续工作：玻尔的"与电磁理论不协调"→量子力学；海森堡的能量守恒困难→Born-Jordan 与三人论文；薛定谔的诠释缺位→玻恩 1926；狄拉克的负能量搁置→1931 正电子。 |
| **证据** | facts F-004/F-009/F-015/F-019 与各示范历史定位节 |
| **反常识** | 读经典的一个高效策略是直接读论文结尾的"困难与展望"段——作者自己标注的未完成处是科学史的路标。 |
| **行动** | 精读示范的"历史定位"节固定回答"作者在回避/搁置什么"。 |
