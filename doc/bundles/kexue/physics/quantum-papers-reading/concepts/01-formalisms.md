# 矩阵与波动力学形式对照

海森堡 1925（数组）与薛定谔 1926（波动方程）在 1926 年被证明等价。精读两篇论文需要一张"形式互译表"。

## 概念互译表

| 矩阵力学（1925-26） | 波动力学（1926） | 现代语言 |
|--------------------|----------------|---------|
| 力学量 x(n,m) 双下标数组 | 作用在 Ψ 上的算符 | 厄米算符 $\hat{x}$ |
| 数组乘法 Σ_k x(n,k)y(k,m) | 算符复合 | 矩阵元 ⟨n|x̂y|m⟩ |
| 量子化条件 pq − qp = (h/2πi)·1 | 本征值问题 | 对易关系 [x̂,p̂] = iℏ |
| 能量对角元 W(n,n) | 本征值 | 定态能量 E_n |
| 运动方程 dx/dt 数组版 | Ψ(t) 演化 | 海森堡/薛定谔绘景 |
| 频率组合原理 ν(n,m) = ν(n,k)+ν(k,m) | 本征值差的谱线解释 | 里茨组合原则的量子起源 |

## 两条路线的出发点差异

| | 海森堡 1925 | 薛定谔 1926 |
|--|-----------|------------|
| 起点 | 对经典频率 ν(n,m) = (E_n−E_m)/h 的傅里叶重构 | 德布罗意物质波（λ=h/p） |
| 核心对象 | 可观察量的数组 | 波函数 Ψ |
| 量子化来源 | 数组乘法不可交换性（Born-Jordan） | 边界条件导致分立本征值 |
| 正当性策略 | 只用可观察量（纲领句） | 量子化规则→本征值问题（纲领句） |

**读这里要停一下**：薛定谔在 1926 年证明两形式数学等价时，双方对"什么是实在"的分歧并未消失（矩阵派的离散性 vs 波动派的连续性）——等价性证明是形式层面的，不是哲学层面的。精读两篇论文时应保持各自的内部视角，不急于合并。

## 精读中的应用

- 读海森堡 1925 时把"频率组合原理"当路标：所有数组都由 ν(n,m) 索引。
- 读薛定谔 1926 第一篇时盯住"从变分问题到本征值问题"的转换段。
- 对照表在两篇示范的还原节反复使用。
