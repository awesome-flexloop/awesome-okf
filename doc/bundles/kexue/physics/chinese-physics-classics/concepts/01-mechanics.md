# 01 · 力学：力的定义、杠杆力矩与斜面运动

中国古代力学知识有三条脉络：《墨经》的概念定义与静力学论证、《考工记》的车辆与器具制造规范、《天工开物》为代表的工艺操作经验。三者互不通约——墨家的逻辑传统秦汉以后中绝，工艺规范则世代延续。

## 一、力与运动的概念定义（《墨经》）

- **力的定义**："力，刑（形）之所以奋也。"（经上 21）"奋"指状态改变（由静而动、由慢而快），说："力：重之谓，下与重，奋也。"——把重力视为力的一种、下落与重都属"奋"。这与亚里士多德"力是运动的原因"思路相近而更接近"力是运动状态改变的原因"的表述方向（方孝博、钱临照解读，M-2、M-3）。
- **运动与静止**："动，或（域）徙也"（经上 50）——运动是位置迁移；"止，以久也"（经上 51）——静止是时间中的持续停留。"久，弥异时也；宇，弥异所也"（经上 40、41）给出时间、空间的定义，经下 114"宇：或徙，说在长宇久"讨论空间迁徙与时间延续的关联。
- **四种力的区分**：经下 130 以"方石去地尺"的悬丝实验区分"柱"（支撑）、"挈"（上提）、"引"（下坠，丝绝则引）、"收"（木材形变后力名改变）——同一条中分析了支持力、拉力、重力与材料变形。
- **斜面**：经下 128"两轮高，两轮为輲，车梯也"分析车梯（斜面搬运器）；经下 129"倚者不可正，说在剃"指出倾斜面上的力不能按正立情形处理。

## 二、杠杆与平衡（《墨经》）

经下 126"负而不挠，说在胜"与说"衡加重于其一旁必捶，权重相若也。相衡则本短标长，两加焉重相若，则标必下，标得权也"——这是中国古代对力矩原理最完整的定性表述：

- "本"（重臂）短、"标"（力臂）长；等重加于两端，标端必下沉，因为标端获得了更大的"权"（力矩效果）；
- 经下 127 接着分析桔槔："挈，长重者下，短轻者上……绳直权重相若，则正矣"——吊绳竖直、权与重匹配时杠杆平衡。

这些条目距阿基米德杠杆定律（前 3 世纪）时代相近，结论方向一致，但《墨经》未给出重量与臂长的定量反比关系。

## 三、工艺规范中的力学（《考工记》《天工开物》）

| 知识 | 原文要点 | 现代力学对应 |
|------|----------|--------------|
| 车轮设计 | "毂也者，以为利转也；辐也者，以为直指也；牙也者，以为固抱也"（轮人） | 轮毂减摩（滑动→近滚动）、辐条受力、轮辋紧固 |
| 惯性 | "劝登马力，马力既竭，辀犹能一取焉"（辀人） | 马拉车停止用力后车仍前行一段——惯性现象的明确观察（早于伽利略近两千年的观察记录，但无理论展开） |
| 箭杆平衡 | "水之，以辨其阴阳……前弱则俯，后弱则翔；中弱则纡，中强则扬；羽丰则迟，羽杀则躁"（矢人） | 浮水法检验箭杆质量分布；重心/压心关系决定飞行姿态；尾羽过多阻力大、过少不稳 |
| 长兵器检验 | "置而摇之，以视其蜎也；灸诸墙，以视其桡之均也；横而摇之，以视其劲也"（庐人） | 三种加载方式检验杆件的挠曲、弹性均匀度与刚度 |
| 船舵 | "舵板一转，一泓从之……船身太长而风力横劲，舵力不甚应手，则急下一偏披水板，以抵其势"（《天工开物·舟车》） | 舵利用水流侧向力产生转船力矩；披水板（腰舵）下移以减横漂、增加侧向阻力，与龙骨作用相通 |
| 风帆 | "风篷之力，其末一叶敌本三叶"（同上） | 帆高处风速梯度大，顶端效率高——对风场垂直分布的经验把握 |
| 提花机 | "结花本者，心计最精巧……提起衢脚，梭过之后居然花现"（《天工开物·乃服》，衢脚约 1800 根） | 花本是织物纹样的程序存储，衢脚升降执行——可视为程序控制的机械雏形（非自动，但信息与执行分离） |
| 弓弩 | "扁担弩力最雄……三撑、五撑、七撑而止"（《天工开物·佳兵》） | 竹木叠层复合弹性体储存弹性势能；叠片数与蓄能关系的经验分级 |

## 四、局限与方法论提示

- **无定量定律**：从"本短标长"到 F₁L₁=F₂L₂，差的是重量与臂长的数值化测量与比例表述；墨家逻辑传统中绝后，这类论证未被继续推进。
- **工艺知识的强项**：矢人"水之辨阴阳"（浮水测重心）、庐人三种加载检验、敲釜探伤（见 [03-acoustics.md](03-acoustics.md)）表明，中国工匠拥有一整套**材料力学性能的经验测试方法**，这是文献中更常见的成就形态。
