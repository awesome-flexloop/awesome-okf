# 06 · 仪器与度量：测影定向、弩机瞄准与实验装置

仪器是物理知识定量化的载体。中国古代在**天文测量仪器**、**军用瞄准具**与**工艺度量**上成就突出，而物理实验装置的自觉设计以赵友钦、郑复光为代表。

## 一、测影定向：《考工记》匠人建国

"匠人建国，水地以县。置槷以县，视以景。为规，识日出之景，与日入之景。昼参诸日中之景，夜考之极星，以正朝夕。"

- "水地以县"：悬绳（垂线）校准平地（水准与垂直基准）；
- "置槷以县"：立表（槷=表杆）并以悬绳校正其垂直；
- "为规，识日出之景与日入之景"：以表为圆心画圆，标记日出、日没时表影与圆周的交点，两点连线即正东—西方向；
- 白天再以正午表影、夜晚以北极星校验。

这是一套完整的**大地测量定向规程**，几何原理为对称日影连线定东西；"水地以县"则是水准仪与铅垂线的结合。同篇"匠人营国，方九里，旁三门，国中九经九纬，经涂九轨"显示该规程服务于都城规划。

## 二、弩机望山：弹道瞄准的勾股法

《梦溪笔谈》卷十九："以目注镞端，以望山之度拟之，準其高下，正用算家勾股法也。"——汉弩机上的"望山"（带刻度的表尺）配合箭镞端点瞄准，按刻度调整仰角补偿弹道下垂，沈括明确指出其数学本质是勾股（直角三角形）测算。这是中国古代表尺式射击瞄准具的代表记录（"世界上最早"一类的断代评价见相关研究文献，此处不作硬性断言），与现代步枪表尺原理相通。

## 三、天文仪器

苏颂《新仪象法要》（1096，E-8）记录水运仪象台：浑仪（观测）、浑象（演示）、报时机构三位一体，以水斗枢轮驱动，含类似擒纵器的卡子机构——机械计时与天文观测仪器的高峰。沈括本人曾主持浑仪改制（《梦溪笔谈》卷七象数），提出简化环组、校正极轴等改进。

## 四、赵友钦的实验装置：双阱千烛

《革象新书·小罅光景》的装置设计本身即是仪器思想的体现（详见 [02-optics.md](02-optics.md) 与 [examples/06](../examples/06-gexiang-xinshu.md)）：

- 两阱深四尺/八尺 → 改变像距（屏可在阱口楼板或阱底）；
- 圆板可升降 → 改变物距（烛—孔距离）；
- 板心方窍寸许/寸半许 → 改变孔径；
- 千余蜡烛可任减任灭 → 改变光源形状与强度。

四个变量均有对应装置部件，且实验结果以楼板上影像的形状、大小、浓淡记录——虽未引入数值仪表，但**装置参数化**的意识已与近代实验方法相通。

## 五、郑复光的"测限"：透镜参数的仪器化测量

《镜镜詅痴》的核心方法是"测限"：对每片透镜实测顺收限（焦距）、顺展限、顺均限，并给出比率换算（平凸"率用六"、双凸"七五折"）。这使透镜第一次在中国成为有**可测参数**的标准元件，望远镜组装变成"按限配比"（足距、距显限）的工程计算。虽然部分换算有误（凹深限虚取，F-056），但"仪器参数→组合设计"的方法链已完整建立。其《作照景镜》引《考工记》金锡齐与栗氏火候，把青铜镜铸造也纳入"按规范制镜"的同一思路。

## 六、工艺度量

- 《营造法式》（1103，E-9）"材分制"：以斗栱截面"材"为模数（八等材），全部构件按模数比例下料——建筑构件的标准化度量体系；
- 《天工开物·乃服》花机"结花本……算计分寸秒忽而结成之"，衢脚约 1800 根——纹样信息以尺寸编码存储（程序控制雏形，见 [01-mechanics.md](01-mechanics.md)）。

## 小结

中国古代仪器传统的强项在**测量定向**（表、规、水准、望山）与**天文机械**（浑仪、水运仪象台）；物理实验装置在赵友钦、郑复光两处达到高峰，但未形成公共仪器传统（装置未被后人重复与改进——赵友钦的阱要等到阮元《畴人传》才被重新提起）。理解这一点，有助于理解为什么"有实验高峰却无理论连续"。
