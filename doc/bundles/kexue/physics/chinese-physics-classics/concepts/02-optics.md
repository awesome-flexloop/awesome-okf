# 02 · 光学：影论、面镜、小孔成像与透镜体系

光学是中国古代物理知识中记录链条较连续、实验与定量化程度较高的分支之一（对"最早/最高"一类评价，参见下文的学术归属说明）。从《墨经》光学八条到郑复光《镜镜詅痴》，构成本包最完整的一条知识链。

## 一、《墨经》光学八条（前 4—前 3 世纪）

《墨经》经下连续排列 118—125 共八条光学条目，钱临照 1943 年称之为"世界上最早的几何光学知识系统记录之一"（M-2）：

| 条号 | 命题 | 现代光学对应 |
|------|------|--------------|
| 118 | "景不徙，说在改为"；说"光至景亡，若在尽可息" | 影不移动：光源/物体/屏相对位置改变时旧影消失、新影生成；视觉暂留式的观察 |
| 119 | "景二，说在重"；"二光夹一光，一光者景也" | 本影与半影：两个光源（重光）形成两个半影区与共同本影区 |
| 120 | "景到（倒），在午有端与景长，说在端"；"光之人煦若射。下者之人也高，高者之人也下。足敝下光，故成景于上；首敝上光，故成景于下" | **小孔成像**：光线交叉（午）于小孔（端）形成倒像；"光之人煦若射"是光直线传播的明确表述，并给出上下颠倒的光路解释 |
| 121 | "景迎日，说在慱"；"日之光反烛人，则景在日与人之间" | 光的反射：日光经镜面（或水面）反射照人，影子成现在日与人间——反射成像与影的位置 |
| 122 | "景之小大，说在地（杝）正远近"；"木杝，景短大。木正，景长小。火小于木，则景大于木。非独小也，远近" | 影的大小取决于斜正、远近：斜放影短大、正放影长小；光源小于物则影大于物，并与距离相关 |
| 123 | "临鉴而立，景到。多而若少，说在寡区" | 平面镜成像（景到=左右/上下倒置的像）；"多而若少"论两镜组合多次反射 |
| 124 | "鉴位（洼），景一小而易，一大而正，说在中之外内" | **凹面镜**：物体在"中"（焦点/球心区）外成缩小倒立像、在内成放大正立像——与现代凹面镜成像规律一致（"中"对应焦点至球心区域，墨家未细分焦点与球心） |
| 125 | "鉴团，景一天（一大？），而必正，说在得" | **凸面镜**：凸面镜所成像恒为正立缩小像 |

## 二、取火于日：阳燧、冰透镜与焦点意识

- 阳燧（凹面青铜镜）取火：《淮南子·览冥训》"夫燧之取火于日，慈石之引铁"、《天文训》"阳燧见日，则燃而为火；方诸见月，则津而为水"；《论衡·乱龙》"铸阳燧取飞火于日"、《率性》"消炼五石，铸以为器，磨砺生光，仰以向日，则火来至"——汉代已明确阳燧是铸造并经抛光的凹面镜。
- 沈括《梦溪笔谈》卷三给出焦点描述："阳燧面洼，向日照之，光皆聚向内。离镜一二寸，光聚为一点，大如麻菽，著物则火发，此则腰鼓最细处也"——以"腰鼓最细处"比喻光束会聚的焦点；并以"格术"解释凹镜倒影："阳燧照物皆倒，中间有碍故也。算家谓之格术。"
- 冰透镜："削冰令圆，举以向日，以艾承其影，则火生。"一级出处为《艺文类聚》卷九引《博物志》，归《淮南万毕术》为后世物理学史著述（戴念祖、白寿彝）之说，两说并列（F-047）；郑复光《镜镜詅痴》载"予曾亲试而验"。

## 三、赵友钦千烛实验（14 世纪初）：基本的受控实验案例

《革象新书》卷五"小罅光景"以双阱（径四尺余、深四尺/八尺）、千余蜡烛的活动圆板、可拆装楼板屏、寸许/寸半许两个方窍构成实验装置，系统验证：

1. **小孔成像随光形（光源形状）**："罅景所射，未有不圆；及至日食，则罅景亦如所食分数"——日偏食时屏上光斑也缺相应比例；
2. **孔径分界**："小景随光之形，大景随空之象"——小孔成光源之像（圆/缺随日月），大孔成孔之形（方尖随窍）；
3. **像距效应**："景近则狭而浓，远则广而淡"——像距越大像越大越淡（照度与距离关系的定性表述）；
4. **物距与光源强度**：减烛模拟月相/日食（减东五百烛则西缺半），"宽者浓而窄者淡"；
5. **变量自觉**："烛也，光也，窍也，景也，四者消长胜负，皆所当论者也"——明确列出光源、孔、屏、像四个待控制变量。

注意：该实验"古代世界最大规模光学实验"一类评价出自王锦光、李鹏举等中国学者及科普文章，**李约瑟 SCC 并未提及赵友钦**（F-044，王哲然考证）。

## 四、透镜时代：郑复光《镜镜詅痴》（1846）

望远镜（《远镜说》1626 传入）之后，郑复光以独立测量建立本土透镜光学：

- **三限**："第一限因收光成象，名顺收限"（≈凸透镜焦距 f）；"第二限因展光成象，名顺展限"；"第三限因光象相等……名顺均限"（≈2f）。学界公认顺收限≈焦距（F-057）。
- **凸镜成像**："目切凸，视近在顺收限内，则物必大；视远出限，即昏不可视"——物在焦点内成放大虚像、出焦点则不可视；"单凸之力亦必减半……故率用六也"给出平凸透镜与双凸透镜的折光力比率（双凸按七五折换算）。
- **望远镜四条件**：①"一凹一凸为远镜之所本"（伽利略式）；②"变显限……以凹侧收限一、凸顺收限十二为定率，谓之足距"（伽利略式镜距，李磊译注指出此值与现代 f₁−f₂ 不合）；③"距显限……两凸同深者，则倍顺收限；内深外浅者，以两顺收限并之"（开普勒式镜距＝两焦距之和，与现代 D=f₁+f₂ 一致）；④远镜三种：观象（一凸一凹）、窥筒（两凸）、四凸以上游览镜。
- **错误方法**：凹透镜"凹深限"借凸率×4/×6 虚取，被李磊译注证明为错误方法（F-056）。
- 另载眼镜（"老花镜，凸镜也""短视宜缩，老花宜伸"=焦距选择）、柱镜预畸变画（"画不照常作为人物，则柱镜中象不成形者亦可成形"）、透光镜机理（刮磨说）。

## 五、两个长期争论

- **透光镜**：西汉铜镜以日光反射可把背面花纹映到壁上。沈括主冷却收缩说（"铸时薄处先冷……铜缩多"）；郑复光主刮磨说（"刮力在手，随镜凸凹而生轻重"）；现代研究（毛增滇 1992）认为镜面曲率差异（铸造残余应力 + 刮磨）使反射光强分布重现背纹——两说机理互补（F-041）。
- **凸面镜的工程应用**：沈括记"古人铸鉴，鉴大则平，鉴小则凸……小鉴不能全视人面，故令微凸，收人面令小"——以凸面增大视场，是明确的工程光学设计。
