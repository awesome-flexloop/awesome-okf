# 07 · 解读方法论：原文、解读与辉格叙事的界限

本篇是全 bundle 的"使用说明书"。读古代物理典籍最大的风险不是读不懂，而是**读得太懂**——用现代物理框架强行对号入座，制造"古已有之"的辉格史叙事。

## 一、信源四层级

引用任何一条"中国古代物理成就"前，先判断它处在哪一层：

| 层级 | 内容 | 可信度与用法 |
|------|------|--------------|
| L1 一级原文 | 典籍原文（整理本/善本） | 唯一可直接引用的"古人说了什么"；必须能给出篇卷 |
| L2 类书/辑佚 | 《艺文类聚》《古今图书集成》引某书、清代辑本 | 须写成"某书引某书"；被引之书已佚则不得当作该书成文 |
| L3 现代研究 | 戴念祖、方孝博、李磊等学者论著 | "现代如何解读"的依据；注意不同学派异说 |
| L4 科普转引 | 博物馆说明、公众号文章、百科词条 | 仅作线索，不可作为事实出处；名人评语尤须回查 |

本包已执行的层级纠偏案例：

- "削冰取火"：L2（《艺文类聚》引《博物志》）常被误标为 L1《淮南万毕术》（F-047）；
- 潜望镜"取大镜高悬"：只有 L4/L3 转引，清代辑本未在线核对（F-048），本包不作为确证使用；
- "李约瑟盛赞赵友钦实验"：L4 转引讹传，李约瑟 SCC 三、四卷未提赵友钦；真正的评价者是王锦光、李鹏举等中国学者（F-044）。

## 二、辉格史检查清单（五问）

1. **术语对号了吗？** 古文术语与现代概念多为多对多映射："景"=影+像；"鉴/燧"=镜/凹面镜；"端"≈点（几何点说与原子说并存，F-051）；"限"≈焦距（顺收限≈f，但顺展限并不严格对应任何单一现代量）。映射前先查训诂与现代校释。
2. **是定量还是定性？** "本短标长"是力矩的定性洞察，不等于杠杆定律 F₁L₁=F₂L₂；"微偏东"是磁偏角的定性发现，不等于有偏角数值。定性记录 → 定量定律之间隔着测量与数学化，这一步要明确说"古人没走"。
3. **是实物还是复原？** "汉代司南磁勺"是王振铎 1948 年推测复原（其本人自承"姑以古勺之形体充之"，F-055），不是出土文物；表述应为"复原方案"。
4. **是观测还是传说？** 异说要并列：司南四说（磁勺/指南车/北斗/水浮瓢针，F-040）、"顿牟"琥珀/玳瑁两训（F-054）、扁钟条刻误之疑（F-053）。
5. **评价者是谁？** "世界上最早""古代最高峰"一类判断必须标注评价者与年代（如"王锦光等中国学者评价"），不嫁接到李约瑟等名人名下。

## 三、术语对照表（供初读建立感觉，不代替训诂）

| 古文 | 大致对应 | 注意事项 |
|------|----------|----------|
| 景 | 影、像 | 小孔条的"景到"是像，影论条的"景"是影 |
| 鉴 | 青铜镜 | 鉴洼=凹面镜，鉴团=凸面镜 |
| 燧/阳燧 | 凹面取火镜 | 方诸是取露器（一般认为是大蚌壳/铜镜） |
| 端 | 点/起始 | 《墨经》几何点说主流，原子说为一家之言 |
| 久/宇 | 时间/空间 | "久弥异时、宇弥所"是操作性定义 |
| 奋 | 状态改变 | "力，形之所以奋"中的关键动词 |
| 本/标 | 重臂/力臂 | 杠杆支点两侧 |
| 格术 | 小孔/凹镜光路几何 | 沈括引算家术语，邹伯奇《格术补》借名 |
| 顺收限 | 凸透镜焦距 f | 学界公认；顺均限≈2f（F-057） |
| 足距/距显限 | 伽利略式/开普勒式镜筒长 | 距显限=f₁+f₂ 一致；足距与 f₁−f₂ 不合（F-056） |
| 质测/通几 | 实证考察/哲学原理 | 方以智："质测即藏通几" |

## 四、推荐阅读流程

1. 先读 L1 原文（本包 `>` 引用块 + 整理本），自己试作今译；
2. 再看"字词注释"解决训诂，读"现代物理解读"对照；
3. 凡见"争议/异说"框，两说并录、不强作裁决；
4. 写作引用时回到 [references](../references/index.md) 的 L1/L3 信源核对，并在文中写明层级（"《艺文类聚》引《博物志》"而非"《淮南万毕术》"）；
5. 在线核实用 [online-sources.md](../references/online-sources.md)；维基文库已经人工复核（关键条目逐字一致，见 W-14/F-049），但其收录不全，宋以后典籍与《论衡》部分篇仍以 ctext/中华文库/典藏网等完整信源为底本。

## 五、一条总原则

**区分"古人记录了什么现象"与"我们知道这是什么现象"。** 前者是文明史事实，后者是现代科学的回溯性解释；把两者混为一谈，既拔高了古人，也取消了科学革命的真实难度。本包所有 examples 都以体例强制这一区分：原文引用块与现代解读段落绝不相混。
