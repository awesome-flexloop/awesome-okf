# 中国古代物理典籍阅读教程

中国古代没有以"物理学"命名的著作，但物理知识分散在名辩条目（《墨经》）、工艺规范（《考工记》《天工开物》）、子书论证（《淮南子》《论衡》）、笔记考辨（《梦溪笔谈》《物理小识》）、历算实验（《革象新书》）与西学消化型专著（《镜镜詅痴》）之中。本知识包精选先秦至清代九部核心典籍，按"原文引录（标注篇卷）→ 字词注释 → 现代物理解读 → 局限与争议"四步体例逐段解读，并按力学、光学、声学、磁学、热学、仪器六个主题横向组织，帮助读者直接读懂原典，同时了解现代物理学史界的共识与争论。

> 姊妹篇：[物理学经典原著阅读指南](../physics-classics-reading/index.md) 收录伽利略至朗道的西方物理元典；本束为中国典籍线索，两束构成物理分组的中西双线索。化学视角的《天工开物》另见 [化学经典·天工开物](../../chemistry/tiangong-kaiwu/index.md)。

## 🚀 快速开始

**零基础读者**（约 8 小时）：

1. 读 [00-why-read](concepts/00-why-read.md) 与 [07-interpretation-method](concepts/07-interpretation-method.md)，建立阅读框架与"防过度解读"意识；
2. 选最感兴趣的两个主题读 concepts（推荐 [02 光学](concepts/02-optics.md) 与 [04 磁学](concepts/04-magnetism.md)，史料最集中）；
3. 配合对应的 examples 读原文片段：光学 → [02 墨经光学](examples/02-mojing-optics.md) + [06 革象新书](examples/06-gexiang-xinshu.md)；磁学 → [04 淮南论衡](examples/04-huainanzi-lunheng.md) + [05 梦溪笔谈](examples/05-mengxi-bitan.md)；
4. 到 [在线信源](references/online-sources.md) 登记的网站打开原典上下文浏览。

**有物理基础的读者**（约 12 小时）：

1. 直接按编年顺序通读九篇 examples，每篇先自己尝试用现代物理翻译原文，再对照文中"现代物理解读"；
2. 重点研读争议标注（司南形制、冰透镜归属、郑复光三限换算之误、赵友钦评价出处）；
3. 走 [insights.md](insights.md) 的"中西对照线"，与 [西方物理元典束](../physics-classics-reading/index.md) 互参。

**科技史/写作研究者**：

1. 以 [references/modern-studies.md](references/modern-studies.md) 为入口回到戴念祖、钱临照、方孝博、李磊等整理本；
2. 引用任何原文前核对 [references/online-sources.md](references/online-sources.md) 的信源层级与可达性记录；
3. 用 [concepts/07](concepts/07-interpretation-method.md) 的检查清单自查文稿中的辉格史表述。

## 🎯 九部典籍编年定位

| 典籍 | 时代/作者 | 性质 | 物理内容焦点 |
|------|-----------|------|-------------|
| 《考工记》 | 春秋战国之际 | 手工业技术规范 | 合金配比、钟磬声学、矢杆平衡、测影定向 |
| 《墨经》 | 战国后期·墨家后学 | 名辩逻辑条目 | 力定义、杠杆力矩、斜面、光学八条、时空与"端" |
| 《淮南子》 | 西汉·刘安门客 | 子书（黄老） | 阳燧方诸、慈石引铁、冰透镜（辑佚）、燥湿验气 |
| 《论衡》 | 东汉·王充 | 子书（疾虚妄） | 司南、顿牟掇芥、阳燧铸造、雷为火、波衰减 |
| 《梦溪笔谈》 | 北宋·沈括 | 笔记考辨 | 磁针四法与磁偏角、格术与凹镜焦点、透光镜、纸人共振、扁钟 |
| 《革象新书》 | 元·赵友钦 | 历算著作 | 双阱千烛小孔成像受控实验、孔径与像的浓淡 |
| 《天工开物》 | 明·宋应星（1637） | 工艺百科 | 失蜡法、敲击探伤、淬火、舵与披水板、花机、龙窑 |
| 《物理小识》 | 明清之际·方以智 | 笔记（质测通几） | 气论、折射（气映差）、瓮墙隔声、磁偏角中西差异 |
| 《镜镜詅痴》 | 清·郑复光（1846） | 光学专著 | 透镜三限、伽利略/开普勒式望远镜、眼镜、透光镜机理 |
