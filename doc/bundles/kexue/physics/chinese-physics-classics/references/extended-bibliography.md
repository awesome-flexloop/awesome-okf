# 扩展书目（E-1 ～ E-20）

> 九部核心典籍之外，本包事实与解读涉及二十部外围文献：先秦两汉子书与类书、宋代仪器与军事技术文献、晚明西学译著、清代光学与力学著作。编号与 [../facts.md](../facts.md) 引用一致（E-3《淮南万毕术》、E-4《博物志》、E-14《海国图志》、E-15《畴人传》被 facts 直接引用）。

## 三、晚明至晚清：西学东渐与本土回应

| 编号 | 文献 | 时代/作者 | 物理相关内容 |
|------|------|-----------|-------------|
| E-11 | 《远镜说》 | 汤若望授、焦勖撰（1626 刊） | 中文世界第一部望远镜专著，介绍伽利略式望远镜构造、用法与光学知识；《镜镜詅痴》自言"因本《远镜说》，推广其理"（F-033） |
| E-12 | 《远西奇器图说录最》 | 邓玉函口授、王徵绘图译述（1627 刊）；王徵另著《新制诸器图说》 | 中文第一部西方力学与机械工程编译著作：重心、杠杆、滑轮、起重引重诸器 |
| E-13 | 《费隐与知录》 | 清·郑复光（1842 刊） | 郑复光早年物理知识札记，涉及天文、气象、光学疑问考辨，为《镜镜詅痴》先声 |
| E-14 | 《海国图志》 | 清·魏源（1842 五十卷本，1852 百卷本） | 卷九十五《作远镜法说略》转述郑复光光学（顺收限、距显限，F-034）；《镜镜詅痴》卷五"作远镜"全文未在线取得时的替代核对依据（F-060） |
| E-15 | 《畴人传》 | 清·阮元主编（1799 刊），续编有罗士琳等 | 卷二十七收赵友钦传，是其"小罅光景"实验在清代被纳入天算家谱系的证据（F-012）；识典古籍编号 CADAL08001211 |
| E-16 | 《演炮图说辑要》（附《火轮船图说》） | 清·丁拱辰（1843 刊） | 火炮铸造、弹道瞄准与蒸汽轮船原理的中文图说，工艺力学与热机知识的晚清样本 |
| E-17 | 《一斑录》 | 清·郑光祖（1839 成书，1843 刊） | 杂记自然现象与物理小识考辨（光学、气象、器具），与《物理小识》笔记体传统相续 |
| E-18 | 《光论》 | 艾约瑟口译、张福僖笔述（1853） | 第一部较系统传入西方几何光学的中文译本，与《镜镜詅痴》本土体系形成对照 |
| E-19 | 《格术补》 | 清·邹伯奇（1874 刊） | 借沈括"格术"之名系统阐述透镜成像、望远镜与照相机原理，郑氏之后清代光学又一高峰；邹氏亦自制照相机 |
| E-20 | 《乐律全书》 | 明·朱载堉（1584—1606 间成书刊行） | "新法密率"即十二平均律的数学推导（用算盘开平方/立方），与《考工记》钟磬、沈括琴徽声学互参 |
