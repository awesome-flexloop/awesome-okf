# 🔭 物理学经典

本分组以"经典原文选读 + 现代解读"方式整理物理学史上的奠基性著作，按三条线索组织：

- **原著阅读指南线索**：1638—1981 年，从伽利略《两门新科学》、牛顿《自然哲学的数学原理》到费曼讲义与朗道教程，解决"原文在哪里、读哪个版本、怎么读"的原著阅读问题。
- **原文逐段精读线索**：对公有领域著作的关键段落做原文（拉丁/法/德/英）与中译对照的逐段精读，配现代物理解读与符号还原，超越"指南"进入文本内部。
- **分领域专题精读线索**：量子力学论文、相对论原著、热统经典三个专题束，各自聚焦一个分支的核心论文与著作。

## 阅读建议

- 首次接触物理学元典：从 [原著阅读指南](physics-classics-reading/index.md) 入门，了解版本与路径。
- 已有版本、想读进去：进入 [原文精读](physics-original-text-reading/index.md)，逐段对照。
- 想走量子线索：[量子力学论文精读](quantum-papers-reading/index.md) 从玻尔 1913 读到狄拉克 1928。
- 想走相对论线索：[相对论原著精读](relativity-originals-reading/index.md) 三步递进。
