# 架构洞察（Architecture Insights）

> 基于事实清单（facts.md，F-001~F-028）与精读示范得出，每条洞察遵循四元组结构（陈述/证据/反常识/行动）

---

## 洞察1：逐段精读的门槛不在语言而在"定义的选择性"

| 四元组 | 内容 |
|--------|------|
| **陈述** | 六篇精读示范的共同发现：关键段落的理解障碍几乎都不是外文词汇，而是读者把"定义的选择"误当"自明真理"——伽利略选 v∝t 而非 v∝s、爱因斯坦"定义"异地同时性、普朗克"选择"能量复分，都是可替换的决定。 |
| **证据** | examples/01（惠更斯命题先比切线）、examples/03（卡诺"transfer of the caloric"）、examples/04（"最要紧的一点"）、examples/05（§1 定义操作） |
| **反常识** | 读者以为"读原文是为了看懂公式"，实际公式的现代等价物一查即得；原文不可替代处恰在"为什么这样定义、而不是那样定义"的论证现场。 |
| **行动** | 本束精读模板固定包含"读这里要停一下"注记，指向定义选择或论证转折。 |

## 洞察2：PD 资源覆盖六种文体，精读束可以全 PD 运行

| 四元组 | 内容 |
|--------|------|
| **陈述** | 本束选取的 6 部著作（1673-1902）全部有美国 PD 的精读底本，覆盖拉丁几何专著、英文实验报告、法文工程论著、德文理论论文（两篇）、英文公理化专著六种文体——精读束不需要引用任何在版权译本即可运行。 |
| **证据** | facts.md F-002/F-008/F-013/F-018/F-022/F-026（六个 PD 底本）；references/02 引用分级表 |
| **反常识** | "找权威英译本"常把读者带进在版权陷阱（Princeton 惠更斯选译 1977-1995、现代中译本）；直接用 PD 原文 + 原创中译示范反而授权更干净。 |
| **行动** | references/02 固定"在版权译本零引用"规则，PD 英译（Thurston、Perrett-Jeffery）作为德文/法文的替代阅读层。 |

## 洞察3：原文与教材的叙事删除点就是精读的收获点

| 四元组 | 内容 |
|--------|------|
| **陈述** | 三处被教材删除/重排的原文结构在精读中显影：法拉第的负结果实验（para. 7 稳态电流无感应）、卡诺的热质说承诺（门面宣称不依赖热假说）、爱因斯坦的"同时性=定义"顺序。 |
| **证据** | examples/02（para. 7 分析）、examples/03（历史定位节）、examples/05（§1 论证顺序） |
| **反常识** | 教材删除负结果与定义选择是为了效率；但这两个删除点恰是概念发生的关键——负结果排除错误图景，定义选择展示概念自由度。 |
| **行动** | 每篇精读的历史定位节固定回答"现代教科书如何重写了这一段"。 |
