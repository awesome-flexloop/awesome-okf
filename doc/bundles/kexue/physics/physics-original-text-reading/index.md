## 🎯 Bundle 定位

| 维度 | 说明 |
|------|------|
| 读者对象 | 已有基本物理训练、想直接面对原文的读者 |
| 覆盖范围 | 公有领域（PD）著作：惠更斯《摆钟论》、法拉第《电学实验研究》、卡诺《火的动力思考》、普朗克 1901 论文、爱因斯坦 1905 论文、吉布斯《统计力学基本原理》 |
| 产出形态 | 逐段精读：原文（拉丁/法/德/英）+ 中译对照 + 现代解读 + 符号还原 |
| 版权原则 | 全部精读文本来自美国公有领域出版物（1929 年前），可全文引用；现代解读为原创 |

## 🚀 快速开始

1. **先读** [精读方法论总纲](concepts/00-method-overview.md)，了解本束的三步精读法。
