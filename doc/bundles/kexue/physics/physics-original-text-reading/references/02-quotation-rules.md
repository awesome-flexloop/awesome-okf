# 引用许可与中译示范规则

本束全部精读对象为美国公有领域（PD）著作，但引用与翻译仍需规则约束，以保证可核查性与一致性。

## 一、引用分级

| 层级 | 适用对象 | 规则 |
|------|---------|------|
| PD 原文 | 本束 6 部著作的原文 | 可整段引用，但单段建议 ≤100 词（保持精读粒度），每篇示范累计引用 ≤600 词 |
| PD 英译 | Thurston 译卡诺、Perrett-Jeffery 译爱因斯坦、Saha/Bose 译相对论论文集 | 同 PD 原文；引用时注明译者与出版年 |
| 在版权译本 | Princeton 惠更斯选译（1977-1995）、UBC 普朗克英译（译者年份不明）、全部现代中译本 | **不引用**；用 PD 原文或 PD 英译替代 |
| 现代研究文献 | Darrigol、Kuhn 等 | 只做思想归纳，不做文字引用 |

## 二、中译示范规范

本束所有"中译示范"为**原创翻译**，不转述任何在版权中译本。规范：

1. 中译示范紧随原文引用块，以加粗标出。
2. 命题、定义、公设类句子**先保结构**：比例关系、条件从句、量词辖域必须在译文中显式保留。
3. 历史术语首次出现给"原文—中译"对照（如 chute de calorique—热质下落），之后可用简写。
4. 不确定的处理（多义词、字体残损）用中译后括注说明，不静默猜测。

## 三、Fraktur 与特殊字符处理

- 德文 Fraktur 字体（普朗克/爱因斯坦原版扫描件）中 f/s、u/v 等字母易误读；E-text（如 Gutenberg）已转写为拉丁字母，优先用 E-text 核对拼写。
- 长音符号（ā ē ī ō ū）与变音（ä ö ü ß）保留原文写法。
- 数学公式按原文版式转录，编号公式用原文编号（如普朗克 #7）。

## 四、自检清单

- [ ] 每个引用块标注语言与底本（或链接到 [信源表](01-sources.md) 对应行）
- [ ] 在版权译本零引用（Princeton 惠更斯选译、UBC 普朗克英译、现代中译本）
- [ ] 中译示范均为原创且结构忠实
- [ ] 单篇累计 PD 引用 ≤600 词
- [ ] 公式编号沿用原文体系
