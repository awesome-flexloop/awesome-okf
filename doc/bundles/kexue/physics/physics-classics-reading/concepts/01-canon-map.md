## 按分支阅读

**经典力学线索**（1→13→2→12）：伽利略建立运动学 → 惠更斯几何力学（摆线与离心力）→ 牛顿建立动力学与引力体系 → 朗道《力学》以分析力学重构。中间可选拉格朗日《分析力学》（1788）与拉普拉斯《天体力学》（见 [扩展书单](../references/05-extended-canon.md)）。

**热与统计线索**（15→4→5→12）：卡诺的热机极限 → 玻尔兹曼的分子运动论与概率 → 吉布斯的系综公理化 → 朗道 V5/V9 的现代统计物理。前置可选克劳修斯（1850s）、普朗克（1906）。逐段精读见 [热统经典精读束](../../thermo-statistical-classics/index.md)。

**电磁与光线索**（16→3→11）：法拉第的实验研究（电磁感应与力线）→ 麦克斯韦建立场论 → 费曼第 2 卷以现代视角重述电磁学。注意麦克斯韦用分量方程，现代矢量形式见费曼。

**相对论线索**（6→12）：1905 狭义相对论论文 → 1915/1916 广义相对论 → 朗道 V2《场论》。原文精读递进见 [相对论原著精读束](../../relativity-originals-reading/index.md)。

**量子线索**（17→7→8→9→10→11/12）：普朗克 1900-1901 量子假设 → 玻尔旧量子论 → 海森堡矩阵力学与薛定谔波动力学（同年两种等价形式）→ 狄拉克公理化 → 费曼第 3 卷与朗道 V3。德布罗意（19）与玻色（20）为两条辅线：物质波先于波动力学，光子计数先于玻色-爱因斯坦统计。逐篇论文精读见 [量子力学论文精读束](../../quantum-papers-reading/index.md)。

**现代前沿线索**（18→21）：居里夫人的放射性研究开创原子物理实验传统 → 温伯格电弱统一理论构建标准模型核心。此线索的原文获取多依赖诺奖演讲（NobelPrize.org）与期刊付费墙，精读以官方演讲文本为主。
