# 核心元典地图

本 bundle 选定 12 部里程碑著作作为核心元典。遴选标准：① 开创或终结一个研究传统；② 原文有可靠获取渠道（公有领域全文或官方免费在线）；③ 中文世界有可检索的译本或导读。

## 按分支阅读

**经典力学线索**（1→2→12）：伽利略建立运动学 → 牛顿建立动力学与引力体系 → 朗道《力学》以分析力学重构。中间可选拉格朗日《分析力学》（1788）与拉普拉斯《天体力学》（见 [扩展书单](../references/05-extended-canon.md)）。

**热与统计线索**（4→5→12）：玻尔兹曼的分子运动论与概率 → 吉布斯的系综公理化 → 朗道 V5/V9 的现代统计物理。前置可选卡诺（1824）、克劳修斯（1850s）、普朗克（1906）。

**电磁与光线索**（3→11）：麦克斯韦建立场论 → 费曼第 2 卷以现代视角重述电磁学。注意麦克斯韦用分量方程，现代矢量形式见费曼。

**相对论线索**（6→12）：1905 狭义相对论论文 → 1915/1916 广义相对论 → 朗道 V2《场论》是最薄的现代入门。

**量子线索**（7→8→9→10→11/12）：玻尔旧量子论 → 海森堡矩阵力学与薛定谔波动力学（同年两种等价形式）→ 狄拉克公理化 → 费曼第 3 卷与朗道 V3 的现代教学表述。这是原文阅读回报最高的线索，因为量子概念无法从日常经验类比，原文展示的概念斗争过程最有价值。
