# 教材与原典配合

12 部元典中有 2 部本身就是教材——费曼《费曼物理学讲义》与朗道-栗弗席兹《理论物理学教程》。它们既是经典，也是进入其他原著的最佳阶梯。

## 一、两部教材的不同用法

### 费曼讲义：直觉与物理图像的入口

- 基于 1961-1963 年 Caltech 课堂，三卷覆盖经典物理（V1）、电磁学（V2）、量子力学（V3）。
- 特点：不追求体系完备，追求物理图像与论证动机。第 2 卷第 18 章（麦克斯韦方程组）、第 3 卷开篇（双缝实验与概率幅）是进入麦克斯韦与量子原著的最佳准备。
- 获取：Caltech 官网免费全文（feynmanlectures.caltech.edu，浏览器访问）；在版权，引用短引并指向官网。
- 读法：按章节通读，做章末习题可选；配合中译本（上海科技社新千年版）核对术语。
- 示范见 [费曼讲义章节读法](../examples/04-feynman-chapter-reading.md)。

### 朗道十卷：体系与形式语言的训练

- 十卷覆盖全部理论物理，篇幅薄、密度高，假设读者已具备相应数学基础。
- 入门顺序建议：V1《力学》（变分法与拉格朗日/哈密顿形式）→ V2《场论》（狭义与广义相对论最薄的现代入门）→ V3《量子力学》→ V5《统计物理》。
- 中译本高教社十卷齐全（2020 年出齐），V1 有鞠国兴《解读》配套。
- 读法：先读教材正文掌握形式，再回原典看同一主题的历史表达——例如读朗道 V1 的拉格朗日形式后，再回看牛顿《原理》的综合几何，能看清两种语言处理同一问题的差别。

## 二、往返读法（ping-pong reading）

```
现代教材建立框架（费曼/朗道/标准教材）
  → 回到原典读对应章节（看概念怎么第一次被构造）
    → 发现原文与教材的差异处（符号/顺序/被简化的论证）
      → 回教材核对现代处理（理解为什么这样简化）
        → 带问题再回原典
```

典型搭配：

| 原典章节 | 现代对照 |
|---------|---------|
| 伽利略第三日（匀加速） | 费曼 V1 第 5-8 章 |
| 牛顿《原理》第三卷 | 朗道 V1 + 任意天体物理教材引力章 |
| 麦克斯韦《电磁通论》第 XX 章 | 费曼 V2 第 18、21 章 |
| 玻尔 1913 | 任意现代量子力学教材第 1-3 章（旧量子论回顾） |
| 海森堡/薛定谔 1925-26 | 狄拉克《原理》前 5 章或朗道 V3 前 3 章 |
| 爱因斯坦 1905 | 朗道 V2 前 4 节 |

## 三、导读专著的位置

导读是"第三方"，不替代原文也不替代教材：

- Cohen《A Guide to Newton's Principia》：《原理》的版本与结构地图，选读命题时按图索骥。
- Chandrasekhar《Newton's Principia for the Common Reader》：逐命题现代重解，几何证明卡住时对照。
- Norton 课程材料（爱因斯坦）、Weinberger 评注（玻尔）：论文级逐节导读。
- 鞠国兴《朗道〈力学〉解读》：中文读者做朗道习题与补数学细节用。

完整清单见 [权威解读资源](../references/02-interpretations.md)。

## 四、避免两种极端

1. **只读教材不读原典**：得到知识但错过方法——教材展示"物理学是什么"，原典展示"物理学怎么做"。
2. **硬啃原典不用教材**：几何证明与历史符号会消耗全部精力，反而错过论证主线。卡住 30 分钟即切换。
