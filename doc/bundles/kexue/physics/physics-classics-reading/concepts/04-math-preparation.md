# 数学准备清单

读物理原文的主要门槛是数学形式，而不是物理直觉。本清单按分支给出**最小**准备原则：不为读原著而系统重修数学，而是在读到具体段落时定向补齐。

## 一、各分支所需数学

| 分支 | 代表原著 | 所需数学 | 最小准备到什么程度 |
|------|---------|---------|-------------------|
| 运动学/经典力学 | 伽利略、牛顿 | 欧几里得几何、比例论、圆锥曲线（阿波罗尼奥斯）、三角 | 能读懂比例式 a:b = c:d 的论证；知道椭圆焦点性质 |
| 分析力学 | 朗道 V1（对照） | 单变量微积分、常微分方程、变分法初步（泛函极值） | 理解 δS=0 的推导思路即可，不必手算复杂变分 |
| 电磁学 | 麦克斯韦 | 多变量微积分、偏微分方程、矢量场论（散度/旋度） | 现代读者先用费曼第 2 卷掌握矢量形式，再回看麦克斯韦分量式 |
| 热统 | 玻尔兹曼、吉布斯 | 概率初步、相空间（6N 维）、积分、勒让德变换 | 理解系综平均、配分函数的构造；偏导关系能跟上 |
| 狭义相对论 | 爱因斯坦 1905 | 代数、洛伦兹变换的推导（原文用初等方法） | 1905 论文本身数学简单，难在运动学概念分析 |
| 广义相对论 | 爱因斯坦 1915/16、朗道 V2 | 张量分析、黎曼几何初步、测地线 | 建议先用朗道 V2 或温伯格教材建立张量语言 |
| 非相对论量子力学 | 海森堡、薛定谔、狄拉克 | 线性代数（特征值问题）、傅里叶分析、希尔伯特空间初步、偏微分方程 | 学过一学期量子力学或线性代数即可读薛定谔；狄拉克需 bra-ket 形式 |

## 二、三次数学语言切换

1. **综合几何 → 分析**：伽利略与牛顿用比例论几何表述全部物理；拉格朗日（1788）之后力学转为分析语言。现代读者读《原理》的困难主要在这里——不是物理难，是几何推理陌生。
2. **分量式 → 矢量/张量**：麦克斯韦用 20 个分量方程；Heaviside-Gibbs 的矢量分析（1880s）将其压缩为四个矢量方程；广义相对论进一步用张量。读原文时手边放一张"分量式 ↔ 矢量式"对照表（费曼第 2 卷第 18、21 章可作对照）。
3. **数表/方程 → 算符与希尔伯特空间**：海森堡从数表乘法出发，玻恩认出是矩阵；薛定谔用本征值问题；狄拉克在第 3 版（1947）用 bra-ket 统一表述。线性代数的特征值/特征向量理论是这一切的现代钥匙。

## 三、"读到哪补到哪"操作法

```
遇到第一个读不懂的数学步骤
  → 标记页码与步骤（不要立刻跳去补课）
  → 继续读完当前小节，判断这个步骤是否重复出现
  → 若重复出现且阻塞理解：
      几何步骤 → 补欧几里得《几何原本》卷 I-VI 的相关命题
      微积分步骤 → 用现代教材（如 Thomas 微积分）对应章节
      矢量/张量 → 费曼第 2 卷或朗道 V2 对应章节
      量子算符 → 任意现代量子力学教材前 2 章
  → 补完后回到原文重读该段，用自己的话复述推导
```

## 四、不需要提前补的数学

- 读伽利略、1905 爱因斯坦、玻尔三部曲：高中代数+几何足够，数学不是门槛。
- 读费曼讲义：费曼自己在书中逐步引入所需数学，按顺序读即可。
- 读朗道：朗道假设读者具备相应数学基础，但《力学》卷只用变分法与 ODE，配套鞠国兴《朗道〈力学〉解读》可补细节。
