# 架构洞察（Architecture Insights）

> 基于事实清单（facts.md，F-001~F-017）与三篇精读得出，每条洞察遵循四元组结构（陈述/证据/反常识/行动）

---

## 洞察1：相对论的"公理化外观"是回溯重构

| 四元组 | 内容 |
|--------|------|
| **陈述** | 教材以"两公设→洛伦兹变换→几何化→场方程"的公理链呈现相对论，但 1905 原文是函数方程推导（含未声明的各向同性假设），1908 才几何化，1916 场方程靠守恒律"猜测+验证"确立——公理化是闵可夫斯基以后的组织方式。 |
| **证据** | facts F-003（各向同性未声明）、F-008（世界线首次引入）、F-013（场方程分量形式） |
| **反常识** | "从公理出发"的现代呈现反而掩盖了推导的实验约束来源；读原文能重建"被推导的公理"。 |
| **行动** | 本束方法论按"定义→公设→变换"的原文顺序读 1905，不做公理化重排。 |

## 洞察2：语言台阶决定读法台阶

| 四元组 | 内容 |
|--------|------|
| **陈述** | 三部文献使用三种互不相同的语言（坐标操作语言→四维几何语言→张量语言），每一种都改变"什么是不动点"：1905 不变量是光速，1908 是间隔，1916 是协变形式。 |
| **证据** | concepts/00 语言台阶表；examples/02（构造对照表） |
| **反常识** | 直接读 1916 并不比读 1905 难——难的是未经 1908 的几何化台阶就从操作语言跳到张量语言。 |
| **行动** | 精读顺序固定为 1905→1908→1916；每篇示范开头有"语言台阶"提示。 |

## 洞察3：免费英译通道足以支撑全精读

| 四元组 | 内容 |
|--------|------|
| **陈述** | 三部文献各有至少一条免费 PD 英译通道（Gutenberg #66944、Perrett-Jeffery PDF、Einstein Papers vol6-trans），精读不需要任何在版权译本。 |
| **证据** | facts F-005/F-010/F-016 与 references/01 信源表 |
| **反常识** | 常见的"爱因斯坦论文只有付费版"印象来自把全集纸本与 Portal 订阅库当成唯一渠道；旧卷次免费 URL 一直在线。 |
| **行动** | references/02 固化旧卷次 URL 的定位流程并提示 Portal 上线后的迁移检查。 |
