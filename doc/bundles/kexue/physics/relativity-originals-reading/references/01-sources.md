# 相对论原文信源表

三部文献的德文原文均为美国 PD（1929 年前出版/发表）。

## 信源明细

| 文献 | 原文出处 | PD 英译 | 精读示范 |
|------|---------|--------|---------|
| 爱因斯坦 1905 狭义相对论 | *Ann. Phys.* 322:891-921 | Perrett-Jeffery（1923，Methuen）；Saha/Bose（1920，Gutenberg #66944） | [01](../examples/01-einstein-1905.md) |
| 闵可夫斯基 1908 演讲 | *Phys. Z.* 10, 104-111（1909） | Saha/Bose 文集收录 "Space and Time" | [02](../examples/02-minkowski-1908.md) |
| 爱因斯坦 1916 广义相对论 | *Ann. Phys.* 49, 769-822 | Einstein Papers vol.6 Doc 30（免费在线德英对照） | [03](../examples/03-einstein-1916.md) |

## 说明

- Perrett-Jeffery 与 Saha/Bose 两个译本均为美国 PD，可整段引用。
- Einstein Papers 数字版为出版社授权免费阅读（见 [Einstein Papers 门户用法](02-einstein-papers.md)）。
- 1916 综述另有单行本重印历史（Vieweg 1917 起），引用页码建议以 *Ann. Phys.* 原刊为准。
