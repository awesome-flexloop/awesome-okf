## 一、卡诺 1824

| 编号 | 事实内容 |
|------|---------|

## 二、玻尔兹曼 1872 H 定理

| 编号 | 事实内容 |
|------|---------|
| F-005 | "Weitere Studien über das Wärmegleichgewicht unter Gasmolekülen" 载 *Sitzungsber. Wien* IIa 66, 275-370（1872），PD。 |
| F-006 | 论文证明二元碰撞下分布趋向 Maxwell 分布；单调量原文以积分表达式呈现（H 记号为后起）。 |
| F-007 | 证明依赖碰撞前无关联假设（Stosszahlansatz / molecular chaos），未标注为独立假设。 |
| F-008 | Loschmidt 可逆性佯谬（1876）与 Zermelo 复现佯谬（1896）分别针对该论文的时间箭头与不可逆结论。 |
| F-009 | S = k log W 的标准形式由普朗克整理；玻尔兹曼本人未写下该式（该式刻于维也纳墓碑）。 |
| F-010 | 《气体理论讲义》德文原版 1896/1898 PD；Brush 英译 1964 在版权。 |
| F-011 | 玻尔兹曼 1877 论文以离散配容计数（Complexionen）建立 S ∝ log W 关系；2015 年 Entropy 期刊刊出开放获取英译。 |

## 三、吉布斯 1902

| 编号 | 事实内容 |
|------|---------|
| F-012 | *Elementary Principles in Statistical Mechanics* 1902 纽约 Scribner's 出版，239 页，PD。 |
| F-013 | "statistical mechanics" 与 "ensemble" 术语为吉布斯首创/引入。 |
| F-014 | Chap. IV 建立正则分布；modulus（模量）对应现代 kT。 |
| F-015 | 熵的相空间定义（−∫ρ ln ρ 型）在 Chap. XIV 区域给出。 |
| F-016 | 全书以平衡态为对象，不讨论趋向平衡的演化方程。 |
| F-017 | archive.org 收录全文扫描（elementaryprinc00gibbgoog，NOT_IN_COPYRIGHT，LCCN 61000387）。 |
