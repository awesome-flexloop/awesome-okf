# 架构洞察（Architecture Insights）

> 基于事实清单（facts.md，F-001~F-017）与三篇精读得出，每条洞察遵循四元组结构（陈述/证据/反常识/行动）

---

## 洞察1：熵有两条独立的来路，合流点在"概率"

| 四元组 | 内容 |
|--------|------|
| **陈述** | 宏观线（卡诺 1824 → 克劳修斯 1865 熵）从热机效率出发；微观线（玻尔兹曼 1872/1877 → 吉布斯 1902）从碰撞与配容计数出发——两条线在"概率"概念处合流为现代统计力学。 |
| **证据** | examples/01（循环方法）、examples/02（配容计数）、examples/03（系综熵）、facts F-009/F-015 |
| **反常识** | "熵"不是被一次发明的：卡诺的文本里根本没有熵；克劳修斯熵与吉布斯熵的定义路径完全不同，精读必须分开走线再合流。 |
| **行动** | 本束按"宏观线→微观线→合流"编排三篇精读，每篇"承前"节标明路线位置。 |

## 洞察2：时间箭头藏在假设层，不在方程层

| 四元组 | 内容 |
|--------|------|
| **陈述** | 微观动力学时间反演对称，H 定理的不可逆性来自碰撞数假设（Stosszahlansatz）——时间箭头由"碰撞前无关联"这一概率性假设注入，而非方程本身。 |
| **证据** | facts F-007；examples/02 的"读这里要停一下"节 |
| **反常识** | 教材把 H 定理写成"力学定理"，原文却是一个依赖统计假设的推导——Loschmidt 佯谬攻击的正是这个隐藏假设。 |
| **行动** | 精读示范显式标注分子混沌假设在推导中的位置。 |

## 洞察3：吉布斯的选择是"悬置不可逆"

| 四元组 | 内容 |
|--------|------|
| **陈述** | 吉布斯 1902 把统计对象从真实分子改为虚构副本（系综），全书只处理平衡态，把"趋向平衡"问题整个悬置——这是方法论选择而非能力不足。 |
| **证据** | facts F-016；examples/03 的对照表 |
| **反常识** | 现代统计力学教材的"平衡态框架"正是吉布斯悬置的直接遗产；非平衡统计力学至今仍无统一体系。 |
| **行动** | 精读时区分"平衡态统计力学"与"不可逆过程理论"的问题域，不要求 1902 回答 H 定理式问题。 |
