# 卡诺 1824 循环论证精读

## 一、文本定位

- 底本：*Réflexions sur la Puissance Motrice du Feu*（1824 巴黎 Bachelier，118 页），PD；Thurston 英译 PD（Gutenberg #78610）。
- 本示范聚焦**循环方法与可逆性**（原文第 III 部分区域）；核心命题的逐句精读见 [原文精读束](../../physics-original-text-reading/examples/03-carnot-motive-power.md)。

## 二、精读：循环方法的发明

卡诺之前的蒸汽机分析都追踪"连续流动"（锅炉进-汽缸出）。卡诺的转向：让同一份工质经历**闭合循环**，回到初始状态——这样工质内部的任何净变化都为零，动力产出完全归因于"热从高温到低温的转移"。

原文操作序列（汽缸+活塞+等温/绝热接触）在现代 p-V 图上为：等温膨胀 → 绝热膨胀 → 等温压缩 → 绝热压缩。原文无图，读者应自行画出（Clapeyron 1834 首画）。

## 三、精读：可逆性论证

> （大意，Thurston 英译）"Wherever there is a difference of temperature, wherever it has been possible for the cause of motion to act, motive power can be produced."

紧随其后的**反证**：若存在效率高于卡诺循环的任何过程，则让其逆过程与正向过程耦合，可在"热量回到原位"的同时产出净动力——无限动力源，与经验矛盾。

**读这里要停一下**：卡诺的"矛盾"不是能量守恒（第一定律当时未确立），而是**热质守恒下的运动守恒直觉**。他的反证结构在热质说框架内自洽；Clausius 1850 年改造时把"热量不减少"换成"热量从热到冷（不等量）"，才得到现代形式。

## 五、历史定位

- 卡诺 1824 使用热质说；1832 年去世前的未刊手稿显示其转向热运动说（Thurston 译本附录 A 收录摘录）。
- 开尔文 1848 绝对温标与 Clausius 1850 论文都以卡诺定理为起点（Kelvin 评述附于 Thurston 译本）。
- 现代热力学教材的"卡诺定理"证明用开尔文-普朗克表述反证——结构同源但守恒基底不同。
