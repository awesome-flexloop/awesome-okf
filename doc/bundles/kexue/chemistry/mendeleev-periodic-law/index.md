# 门捷列夫元素周期律阅读教程

1869 年，门捷列夫把当时已知的 63 种元素按原子量排列，发现性质呈周期性重复；他没有把表格填满，而是留下若干空位，为尚未发现的元素预先写出原子量与理化性质。六年后，类铝（镓）、十六年后类硼（钪）、十七年后类硅（锗）相继被发现，预言值与实测值高度吻合。本束以公版原典（1869 年论文、1889 年法拉第讲座、三位发现者的原始论文）为骨干，带领读者完成一次"科学预言如何被验证"的原典精读。
