# 《周易参同契》阅读教程

> 东汉魏伯阳《周易参同契》原文选读与现代解读——炼丹术从方技记录走向成体系理论的标志文本：以《周易》卦象、月相纳甲编码火候，以铅汞龙虎隐语组织药物，三代注本（彭晓、朱熹、内丹派）层层诠释。
>
> ⚠️ **安全警示**：书中涉及铅、汞、硫黄及含砷矿物等剧毒物质，本束为历史文献阅读教程，**严禁仿制、服食任何丹方**。

《周易参同契》（以下简称《参同契》）传统题署东汉魏伯阳（公元 2 世纪），传世本分上中下三篇，五代彭晓分为 35 章，被后世道教尊为"万古丹经王"。它第一次把《周易》卦象框架、黄老养生思想与炉火炼丹操作焊接为一个整体（"羅列三條……皆由一門"），既保存了汞遇火则飞、胡粉还铅等可核验的物质观察，也大量使用易学类比来编码火候规程。本束采用"三层分读"法：事实层（物质、设备、操作）、框架层（符号系统）、信念层（服食求仙）分开评价，不吹捧也不贬斥。

## 🚀 快速开始

**零基础读者**（第一次接触炼丹典籍）：

1. 读 [为什么读](concepts/00-why-read.md) 与 [文本与作者](concepts/01-text-and-author.md)，建立背景；
2. 读 [核心段落选读](concepts/04-key-passages.md) 三段选文，感受原文与隐语；
3. 跟 [炉火段逐句精读](examples/01-furnace-passage-reading.md) 走一遍六步法；
4. 以 [现代化学视角](concepts/05-modern-chemistry-lens.md) 收束。

**有中国哲学或化学史背景的读者**：

- 哲学/道教方向：直读 [易理框架](concepts/02-theoretical-framework.md)，注意易—老—丹三家的接榫方式，思想背景参 [帛书《老子》阅读教程](../../../guoxue/laozi/boshu-reading/index.md)；
- 化学史方向：直读 [炼丹内容](concepts/03-alchemy-content.md) 与 [现代化学视角](concepts/05-modern-chemistry-lens.md)，再对照 [波义耳《怀疑的化学家》阅读教程](../boyle-sceptical-chymist/index.md)；
- 文献方向：按 [阅读路线](examples/02-reading-route.md) 选朱熹《考异》进阶，注意外丹/内丹两套注本的诠释差异。
