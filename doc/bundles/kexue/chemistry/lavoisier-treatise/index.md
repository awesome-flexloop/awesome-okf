# 拉瓦锡《化学基础论》阅读教程

1789 年，巴黎书商 Cuchet 印行了一本厚达两卷的化学教科书。书的全名很长——《按一种新秩序编排、并依据现代发现写成的化学基础论》。作者安托万-洛朗·拉瓦锡在序言里宣称：他只打算写一本"入门书"，把化学还原为"事实的数目很少、几乎全是初级"的内容。五年后，作者在断头台上身首异处；而这本书成为化学史上被称作"化学革命"的那场范式转换的标准文本——氧化学说取代燃素说、天平成为化学的核心仪器、元素获得可操作的定义、化合物第一次有了系统名称。

本知识包面向希望直接阅读这本经典的中文读者：提供公版原文选段（1789 法文原版与 1790 年克尔英译本，均逐字核校）、自撰今译、逐句精读示例、关键概念的现代解读，以及一份分档阅读路线。
