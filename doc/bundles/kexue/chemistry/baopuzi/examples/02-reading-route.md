## 二、底本与版本常识

- 《四部丛刊初编》本《抱朴子内外篇》：民国商务印书馆影印明刊本，ctext 主用底本，通行可靠。
- 《平津馆丛书》本：清孙星衍校刻本，清代校勘成果，ctext 另页提供。
- 文渊阁《四库全书》本：中华文库可在线全览，可与丛刊本对校。
- 纸质整理本：王明《抱朴子内篇校释》（中华书局"新编诸子集成"）是现代学术标准校释本，征引校勘详尽；一般读者可选带白话译文的注译本入门（注：译文版本请自行在正规出版物中选择，本束不照抄任何版权注本译文，所有今译为自撰）。

## 三、内篇各卷读法建议

| 篇名 | 阅读优先级 | 读法 |
|------|-----------|------|
| 金丹（卷四） | ★★★ 必读 | 丹法总集，配 [02-jindan-chapter.md](../concepts/02-jindan-chapter.md) 读 |
| 黄白（卷十六） | ★★★ 必读 | 药金药银，配 [03-huangbai-chapter.md](../concepts/03-huangbai-chapter.md) 读 |
| 仙药（卷十一） | ★★★ 必读 | 仙药品第与雄黄六法，砷化学关键 |
| 论仙（卷二） | ★★ 选读 | 神仙实有论证，"黄丹胡粉化铅"段 |
| 对俗（卷三） | ★★ 选读 | "上药延命"论 |
| 杂应（卷十五） | ★★ 选读 | "为道者兼修医术"，理解医道关系 |
| 畅玄（卷一） | ★ 背景 | 本体论总纲，哲学兴趣者读 |
| 明本（卷十）、道意（卷九） | ★ 背景 | 道本儒末之辨 |
| 遐览（卷十九） | ★ 工具 | 早期道经目录，文献学价值 |
| 登涉（卷十七）、地真（卷十八）等 | ☆ 备查 | 入山禁忌、守一存真，初读可略 |

外篇五十卷论时政人事，与化学史主题关系较远，本束不展开；对儒道关系感兴趣的读者可择读《嘉遁》《尚博》等篇。

## 四、三阶段阅读计划

### 第一阶段：建立地图（约 2 小时）

1. 读 [00-why-read.md](../concepts/00-why-read.md) 与 [01-gehong-context.md](../concepts/01-gehong-context.md)；
2. 在 ctext 打开《抱朴子》目录页，浏览内篇 20 篇篇名；
3. 读 [04-key-passages.md](../concepts/04-key-passages.md) 三段选文。

### 第二阶段：精读核心三篇（约 6–8 小时）

1. 按 [01-cinnabar-passage-reading.md](01-cinnabar-passage-reading.md) 的六步法精读《金丹》丹砂循环段；
2. 通读《金丹》篇（劝学网简体本通览 + ctext 核对关键句），配合 [02-jindan-chapter.md](../concepts/02-jindan-chapter.md)；
3. 通读《黄白》篇，重点"外变内不化"段与紫磨金法，配合 [03-huangbai-chapter.md](../concepts/03-huangbai-chapter.md)；
4. 读《仙药》药序与雄黄六法。

### 第三阶段：现代视角与对照（约 4 小时）

1. 读 [05-modern-chemistry-lens.md](../concepts/05-modern-chemistry-lens.md)，对照每个物质体系；
2. 延伸阅读：
   - 上承：[《周易参同契》阅读教程](../../cantongqi/index.md)；
   - 下启：[《天工开物》阅读教程](../../tiangong-kaiwu/index.md)；
   - 西学对照：[道尔顿《化学哲学新体系》阅读教程](../../dalton-new-system/index.md)；
   - 思想背景：[帛书《老子》阅读教程](../../../../guoxue/laozi/boshu-reading/index.md)；
3. 研究型读者按 [references/modern-scholarship.md](../references/modern-scholarship.md) 追溯王奎克（1982）、赵匡华（1984）原始论文与李约瑟《中国科学技术史》第五卷。

## 五、阅读中的注意事项

1. **安全第一**：所有丹方含汞、铅、砷等毒物，仅作文献阅读，严禁仿制、服食、实验。
2. **数字保留态度**：篇中"火之三十六日""十斤锡得金二十两"等数字带有方术化与传抄成分，不宜当作精确实验参数。
3. **区分观察与解释**：每读一段，先问"他看到了什么"（现象），再问"他认为这意味着什么"（信仰），详见 [insights.md](../insights.md)。
4. **版本异文**：关键引文以 ctext 四部丛刊本为准；发现异文可比对平津馆本与四库本。
5. **简体镜像局限**：简体标点网页可能有录文错误，引用重要字句时务必回 ctext 繁体本核对。
