## 一、作者生平与文本成书

| 编号 | 事实内容 |
|------|---------|
| F-001 | 《抱朴子》作者葛洪，字稚川，自号抱朴子，丹阳句容（今江苏句容）人；中国哲学书电子化计划标注其为晋代人，生卒年作 300—343 年。 |
| F-002 | 白寿彝主编《中国通史》第五卷记述葛洪生卒年为 283—343 年；学界另有卒于 363 年之说。 |
| F-003 | 葛洪祖父葛系仕三国吴，历任吏部尚书等职；父葛悌入晋后官至邵陵太守；葛洪十三岁丧父，家道中落，自述以砍柴所得换取纸笔抄读。 |
| F-004 | 葛洪从祖葛玄（字孝先，世称葛仙公）受业于方士左慈（左元放）；葛玄传炼丹术于弟子郑隐（郑思远）；葛洪约十八九岁入马迹山师事郑隐。 |
| F-005 | 葛洪后拜南海太守鲍靓（鲍太玄）为师，娶鲍靓之女鲍姑（名潜光）；鲍姑是中国历史上最早见于记载的女针灸医家。 |
| F-006 | 《中国通史》第五卷记述：约在建武元年（317）葛洪三十五岁时，《抱朴子内篇》二十卷、《外篇》五十卷完成。 |
| F-007 | 葛洪名下著作另有《神仙传》十卷、《玉函方》一百卷、《肘后备急方》三卷等；咸和年间（326—334）葛洪上书求为勾漏（今广西北流）令，其后退居罗浮山炼丹著述。 |

## 三、《金丹》篇与丹法体系

| 编号 | 事实内容 |
|------|---------|
| F-012 | 《内篇·金丹》开篇称："余考览养性之书，鸠集久视之方……莫不皆以还丹金液为大要者焉。然则此二事，盖仙道之极也。" |
| F-013 | 《金丹》篇记述丹经传承：左元放在天柱山中得神人授金丹仙经，汉末避乱渡江，传葛玄，葛玄传郑君（郑隐），郑隐在马迹山立坛盟授葛洪；葛洪称受《太清丹经》三卷、《九鼎丹经》一卷、《金液丹经》一卷。 |
| F-014 | 《金丹》篇载"九鼎神丹"（九丹）名目：一丹华、二神符（篇中作"神丹，亦曰神符"）、三神丹、四还丹、五饵丹、六炼丹、七柔丹、八伏丹、九寒丹。 |
| F-015 | 《金丹》篇载第一丹丹华方：用雄黄水、矾石水、戎盐、卤盐、礜石、牡蛎、赤石脂、滑石、胡粉各数十斤作"六一泥"封固，"火之三十六日成"；又称"以二百四十铢合水银百斤火之，亦成黄金"。 |
| F-016 | 《金丹》篇载："凡草木烧之即烬，而丹砂烧之成水银，积变又还成丹砂，其去凡草木亦远矣。" |
| F-017 | 《金丹》篇载："复有太清神丹，其法出于元君。元君者，老子之师也。" |
| F-018 | 《金丹》篇阐述服食理论："夫金丹之为物，烧之愈久，变化愈妙。黄金入火，百炼不消，埋之，毕天不朽……此盖假求于外物以自坚固。" |

## 四、《黄白》篇与人造"金银"

| 编号 | 事实内容 |
|------|---------|
| F-019 | 《内篇·黄白》载："铅性白也，而赤之以为丹。丹性赤也，而白之而为铅。" |
| F-020 | 《黄白》篇载："诈者谓以曾青涂铁，铁赤色如铜；以鸡子白化银，银黄如金，而皆外变而内不化也。" |
| F-021 | 《黄白》篇引《龟甲文》："我命在我不在天，还丹成金亿万年。" |
| F-022 | 《黄白》篇载"金楼先生所从青林子受作黄金法"：先锻锡为方六寸、厚一寸二分的片，以赤盐和灰汁如泥涂锡上，置赤土釜中封固，以马通火温之三十日，"锡中悉如灰状，中有累累如豆者，即黄金也"，并称"率十斤锡，得金二十两"。 |
| F-023 | 《黄白》篇载"紫磨金"法：以矾水石置铁器中加炭火令沸，投入汞搅动，"注地上成白银"；再取丹砂水、曾青水各一分、雄黄水二分合炼，投入所成"白银"，"注地上凝，则成上色紫磨金也"。 |

## 五、《仙药》《论仙》诸篇的物质记载

| 编号 | 事实内容 |
|------|---------|
| F-024 | 《内篇·仙药》载仙药次第："仙药之上者丹砂，次则黄金，次则白银，次则诸芝，次则五玉，次则云母，次则明珠，次则雄黄……次则石硫黄……次则曾青。" |
| F-025 | 《仙药》篇引《神农四经》："上药令人身安命延……中药养性，下药除病。" |
| F-026 | 《仙药》篇载雄黄饵服六法："或以蒸煮之；或以酒饵；或先以硝石化为水，乃凝之；或以玄胴肠裹蒸之于赤土下；或以松脂和之；或以三物炼之，引之如布，白如冰。"（按：玄胴肠即猪大肠/猪脂一类含碳物，"三物"指硝石、玄胴肠、松脂。） |
| F-027 | 《内篇·论仙》载："愚人乃不信黄丹及胡粉，是化铅所作"；同篇又载"外国作水精碗，实是合五种灰以作之，今交广多有得其法而铸作之者"。 |
| F-028 | 《内篇·杂应》载："故古之初为道者，莫不兼修医术，以救近祸焉。" |
| F-029 | 《内篇·地真》载"生可惜也，死可畏也"；《内篇·对俗》载"知上药之延命，故服其药以求仙"。 |

## 六、医学实践与后世影响

| 编号 | 事实内容 |
|------|---------|
| F-030 | 葛洪《肘后备急方》载治疟方："青蒿一握，以水二升渍，绞取汁，尽服之。" |
| F-031 | 屠呦呦在 2015 年 12 月 7 日卡罗林斯卡医学院诺奖演讲中称，《肘后备急方》"青蒿一握，以水二升渍，绞取汁，尽服之"的截疟记载，令其联想到提取过程可能需要避免高温；其团队改用乙醚低温提取，1971 年第 191 号青蒿乙醚中性提取物样品对鼠疟原虫抑制率达 100%，1972 年分离得到青蒿素（分子式 C₁₅H₂₂O₅，含过氧基的倍半萜内酯）。 |

## 七、现代化学与模拟实验研究

| 编号 | 事实内容 |
|------|---------|
| F-032 | 现代化学中，丹砂（朱砂）主要成分为硫化汞 HgS；焙烧反应为 HgS + O₂ → Hg + SO₂；汞与硫化合为 Hg + S → HgS（初成黑色硫化汞，密闭升华后转为红色结晶）。 |
| F-033 | 铅在空气中加热先生成一氧化铅 PbO（黄丹、密陀僧类），继续焙烧生成四氧化三铅 Pb₃O₄（铅丹、红丹）：6PbO + O₂ → 2Pb₃O₄；胡粉（铅白）为碱式碳酸铅 2PbCO₃·Pb(OH)₂。 |
| F-034 | 曾青为含硫酸铜的矿物/溶液，"曾青涂铁"对应铁置换铜反应：Fe + CuSO₄ → FeSO₄ + Cu。 |
| F-035 | 雄黄主要成分为 As₄S₄（经验式亦作 As₂S₂），雌黄为 As₂S₃，礜石（毒砂）为 FeAsS，砒霜（砒石主要成分）为三氧化二砷 As₂O₃。 |
| F-036 | 王奎克、朱晟、郑同、袁书玉《砷的历史在中国》（《自然科学史研究》1982 年第 2 期）提出：《仙药》篇饵雄黄方以硝石、玄胴肠（猪脂）、松脂与雄黄合炼，可能产生单质砷。 |
| F-037 | 赵匡华、骆萌《关于我国古代取得单质砷的进一步确证和实验研究》（《自然科学史研究》1984 年第 2 期）的模拟实验显示：硝石用量少时析出单质砷结晶，硝石用量多时生成氧化砷（As₂O₃）并可能发生爆燃；该混合体系成分接近早期火药配方。 |
| F-038 | 白寿彝主编《中国通史》第五卷称：葛洪《黄白》篇关于铜砷合金（砷黄铜）炼制的记述，是中国古代文献中关于砷黄铜炼制法的最早记载；现代研究归纳药金、药银实物包括铜砷合金、铜锌合金、汞齐、铅锡合金等类别。 |
| F-039 | Glidewell《中国古代和中世纪的原始化学》（《世界科学》1994 年第 5 期中译）述及：公元 300 年前后葛洪《抱朴子》记载人工炼制的药金胜于天然金；后世模拟实验支持书中部分无机变化观察的可靠性。 |

## 八、服食中毒与理论局限

| 编号 | 事实内容 |
|------|---------|
| F-040 | 据《西安晚报》综述（中国新闻网 2008 年 12 月 22 日转载），唐代 21 位皇帝中至少 5 位服用丹药中毒身亡：太宗、宪宗、穆宗、武宗、宣宗；唐太宗服中天竺方士那罗迩娑婆寐所炼"延年之药"后暴疾，事见《旧唐书》郝处俊谏言。 |
| F-041 | 《抱朴子内篇》的核心目标为神仙长生信仰，其服食成仙主张未被现代科学证实；金丹所涉汞、铅、砷化合物对人体具有明确毒性。 |
| F-042 | 李约瑟（Joseph Needham）主编《中国科学技术史》（Science and Civilisation in China）第五卷第二分册（1974 年剑桥大学出版社）以"金丹与不朽"（Magisteries of Gold and Immortality）为主题，集中讨论中国炼丹术。 |
