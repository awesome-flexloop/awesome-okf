# 《抱朴子·内篇》阅读教程

> 东晋葛洪《抱朴子·内篇》原文选读与现代解读——炼丹实践的集大成文本，汞/铅/砷化学经验的珍贵记录，以及服食求仙理论的冷静辨析。
>
> ⚠️ **安全警示**：书中丹方涉及汞、铅、砷等剧毒物质，本束为历史文献阅读教程，**严禁仿制、服食任何丹方**。

《抱朴子·内篇》二十卷是东晋葛洪（283—343，一说 300—343）论神仙方药的著作，其中《金丹》《黄白》《仙药》三篇集中保存了 4 世纪中国炼丹术的丹方与物质变化观察：丹砂烧之成水银、积变又还成丹砂的汞—硫循环，铅与铅丹的氧化还原往复，以硝石、猪脂、松脂合炼雄黄的砷制剂升炼，以及"药金""药银"的合金点化。这些观察与"假求外物以自坚固"的服食信仰交织于同一文本——本束采用"双镜头"读法：现象层还原化学反应，信仰层标注历史局限。

## 核心内容速览

- **汞化学**："丹砂烧之成水银，积变又还成丹砂"——HgS⇌Hg 循环的明确记录；
- **铅化学**："铅性白也，而赤之以为丹；丹性赤也，而白之而为铅"——氧化—还原往复；
- **砷化学**：《仙药》雄黄饵服六法，硝石—猪脂—松脂合炼体系，现代模拟实验可析出单质砷或砒霜；
- **合金化学**：《黄白》紫磨金法为中国文献中砷黄铜炼制法的最早记载；"曾青涂铁"即铁置换铜；
- **思想命题**："我命在我不在天，还丹成金亿万年"；
- **历史教训**：唐代至少五位皇帝服丹身亡；同一作者《肘后备急方》"青蒿绞汁"启示青蒿素发现。
