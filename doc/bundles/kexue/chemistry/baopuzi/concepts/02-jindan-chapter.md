## 《金丹》篇的地位

《金丹》是《抱朴子·内篇》卷四，为全书炼丹理论与丹方的总集。葛洪在篇首即判定：

> 余考览养性之书，鸠集久视之方，曾所披涉篇卷，以千计矣，莫不皆以还丹金液为大要者焉。然则此二事，盖仙道之极也。

"还丹"与"金液"被他列为仙道的最高级——还丹指丹砂—水银—丹砂循环变炼的丹药，金液指可饮用的"金液"体系。读《金丹》篇，等于拿到 4 世纪金丹术的体系说明书：它既有师承来历、丹法分类，又有具体丹方、火候时日，还有整套服食理论。[^ctext]

## 丹经传承谱系

葛洪自述丹法来源（原文见 [01-gehong-context.md](01-gehong-context.md) 引文）：

```
左慈（元放）天柱山得神人授金丹仙经
   → 葛玄（从祖，葛仙公）
      → 郑隐（郑君）
         → 葛洪（马迹山立坛盟受）
```

受经为《太清丹经》三卷、《九鼎丹经》一卷、《金液丹经》一卷。这一谱系有三点值得注意：

1. **秘传性**："立坛盟受""口诀之不书者"，关键环节不形诸文字；
2. **地域性**："江东先无此书"，丹经随汉末乱局南渡，是江南炼丹传统的起点之一；
3. **稀缺性**：葛洪自陈"受之已二十余年，资无担石，无以为之，但有长叹"——有方无财，炼丹在当时是资本密集的活动。

## 丹法分类：九鼎神丹

《九鼎丹经》所载"九丹"（九鼎神丹）是层层递进的丹法序列，篇中列出名目：

| 序次 | 丹名 | 篇中要点 |
|------|------|---------|
| 一 | 丹华 | 先作"玄黄"，以雄黄水、矾石水、戎盐、卤盐、礜石、牡蛎、赤石脂、滑石、胡粉各数十斤作"六一泥"封固，火之三十六日成；"以二百四十铢合水银百斤火之，亦成黄金" |
| 二 | 神丹（亦曰神符） | 服之百日仙；"以此丹涂足下，步行水上" |
| 三 | 神丹 | （九丹序列之一） |
| 四 | 还丹 | 即"还丹"名义所系，取丹砂往复变化之义 |
| 五 | 饵丹 | 服之三十日仙 |
| 六 | 炼丹 | "又以汞合火之，亦成黄金" |
| 七 | 柔丹 | 服一刀圭，百日仙；"与金公合火之，即成黄金"（金公即铅） |
| 八 | 伏丹 | 持之辟百鬼、盗贼虎狼 |
| 九 | 寒丹 | 服一刀圭，百日仙 |

读这张表有两个看点：

- **操作要素**：封固用的"六一泥"是一种复合涂层（含戎盐、矾石、胡粉等），作用是密封丹釜、控制气氛；"火之三十六日"是固定火数；丹成后还要"以玄膏丸此丹，置猛火上，须臾成黄金"——即把丹药与汞、铅合炼检验是否"成金"。
- **现代化学注脚**：方中雄黄、礜石含砷，胡粉即碱式碳酸铅（铅白），汞、铅、砷三大有毒金属体系在第一丹中已全部登场；"丹成金"的检验实为合金/硫化物外观判断，详见 [03-huangbai-chapter.md](03-huangbai-chapter.md) 与 [05-modern-chemistry-lens.md](05-modern-chemistry-lens.md)。

## 丹法分类：太清神丹与金液

### 太清神丹

篇中又载："复有太清神丹，其法出于元君。元君者，老子之师也。"《太清观天经》分九篇，上三篇不可教授、中三篇沉于三泉之下、下三篇即丹经上中下三卷。这一叙述把丹法挂接到老神"元君"名下，是金丹道神化其经的常见做法。

### 金液

"金液"在篇中与还丹并称"仙道之极"。葛洪比较各种"化为水服"的方子（银、蚌珠、云母等）后强调"皆不及金液也"，并说"合此金液九丹，既当用钱，又宜入名山，绝人事，故能为之者少"。金液的理想是把最不朽的黄金转化为可服食的液态——"金可作，世可度"观念的技术化表达。

与金液水法相关的《三十六水法》（约 6 世纪成书的另一丹经）记载以硝石、醋等在密封竹筒中长时间处理使金属"成水"，现代模拟实验表明这类溶解依赖原料杂质带入的亚硝酸根、碘离子等，部分配方经实验复核确有可行性（Glidewell，1994）。[^scholarship]

## 核心理论："假求于外物以自坚固"

《金丹》篇最著名的理论段落：

> 夫金丹之为物，烧之愈久，变化愈妙。黄金入火，百炼不消，埋之，毕天不朽。服此二物，炼人身体，故能令人不老不死。此盖假求于外物以自坚固，有如脂之养火而不可灭，铜青涂脚，入水不腐，此是借铜之劲以扞其肉也。

其论证结构是一个类比：

1. 观察事实：黄金、丹砂在火炼与埋藏中表现出稳定性（"百炼不消""毕天不朽"）；
2. 类比外推：服食这类"不朽"物质，可以把其坚固性转移给人体；
3. 辅助例证：铜青（铜锈，碱式碳酸铜）涂脚入水不腐，被解释为"借铜之劲以扞其肉"。

**双镜头读法**：

- 现象层：金的化学惰性、丹砂的可循环转化、铜盐的防腐抑菌作用，都有可验证的事实内核；
- 信仰层："物性可随服食转移给人"是类比巫术式的推理，不成立；汞、铅、砷化合物进入人体后表现为强烈毒性而非"坚固"。唐代五位皇帝的死亡是这一理论的历史反证（见 [05-modern-chemistry-lens.md](05-modern-chemistry-lens.md)）。

## 丹砂循环：全篇的实验观察核心

《金丹》篇在比较草木药与丹药时写下：

> 凡草木烧之即烬，而丹砂烧之成水银，积变又还成丹砂，其去凡草木亦远矣。故能令人长生。

葛洪还记录了时人的怀疑与他的反驳："或不知水银出于丹砂，告之终不肯信，云丹砂本赤物，从何得成此白物。又云丹砂是石耳，今烧诸石皆成灰，而丹砂何独得尔。"

这段文字是本束精读的核心，逐句讲读见 [examples/01-cinnabar-passage-reading.md](../examples/01-cinnabar-passage-reading.md)，段落选注见 [04-key-passages.md](04-key-passages.md)。现代化学解读：

- 焙烧：HgS + O₂ → Hg + SO₂↑（汞蒸气逸出，冷凝得水银）
- 再化合：Hg + S → HgS（初成黑色，密闭升华后转为红色结晶）

他从"烧之成灰"的草木中区分出"烧之成水银、又还成丹砂"的矿物，观察本身准确而领先；但"故能令人长生"是信仰跳跃。
