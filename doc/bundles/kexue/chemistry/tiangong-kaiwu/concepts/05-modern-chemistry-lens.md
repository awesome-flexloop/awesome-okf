# 现代化学视角——成就与局限

本篇把《天工开物》化学工艺相关卷篇（五金、丹青、作咸、燔石等）的记载放回现代化学框架中评估：先列五项经得起核验的工艺成就，再指出三重理论局限，最后与同时代及稍后的西方化学对照。评估遵循本束的平衡立场：成就不吹捧为"科学"，局限不贬斥为"落后"，二者是同一种知识形态的两面——前现代工艺知识以"物性观察＋操作规程"存在，尚未形成成分与反应的理论语言（见 [../insights.md](../insights.md) 洞察 1）。

## 一、工艺成就

### 1. 锌冶炼：世界上最早的系统文字记载之一

《五金·附倭铅》完整记录了从炉甘石（菱锌矿，ZnCO₃）到金属锌的冶炼：泥罐密封、煤炭饼垫盛、发火煅红、冷定毁罐取锌，连"每十耗去其二"的损耗率都有交代[^1]。现代化学将其还原为碳热还原两步：

```
分解：ZnCO₃ ──高温──▶ ZnO + CO₂↑
还原：ZnO + C  ──高温──▶ Zn（蒸气）+ CO↑
```

工艺难点在于温度窗口：氧化锌的碳还原温度约 900℃ 以上，而锌沸点约 907℃，两者几乎重合，还原所得立即是锌蒸气，必须设置冷凝回收装置[^2]。原文"无铜收伏，入火即成烟飞去"正是对这一物理约束的经验表述[^3]。2013 年重庆忠县临江二队明代炼锌遗址出土冶锌炉、反应罐、冷凝盖与锌锭，"密封蒸馏—冷凝收锌"的考古工艺与文字记载相互印证[^4]；学界普遍视本书为世界上最早系统记载金属锌冶炼工艺的文献之一，欧洲大规模蒸馏炼锌以 18 世纪布里斯托尔为标志（Champion 1738 年专利）[^5]。

### 2. 黄铜与铸钱：定量配比意识

《五金》记黄铜"每红铜六斤，入倭铅四斤"，即约 60:40 的铜锌比，落在现代工业黄铜常见配比区间；《冶铸·钱》记铸钱料"红铜居六七，倭铅居三四"并载"倭铅每见烈火必耗四分之一"[^6]。两条记载的共同点是把合金成分写成明确的斤两数字——从"炉甘石点化"的不可控共熔改为金属锌配料，成分可称量、可重复，是定量思维的工艺体现。

### 3. 煤炭按用途分类

《燔石·煤炭》把煤分为明煤、碎煤、末煤三种，碎煤又按火焰高低分为供炊烹的"饭炭"与供冶锻的"铁炭"[^7]。这已是在按**燃烧性能与用途**给燃料分类，与现代按煤质特性（挥发分、火焰性质）选煤的思路相通，属世界较早的煤按用途分类记载之一。

### 4. 石灰焙烧与建筑应用

《燔石·石灰》记"经火焚炼为用，成质之后，入水永劫不坏"，以煤饼与石灰石层叠燔烧，产物用于固舟缝、砌墙、垩壁、筑三和土[^8]。现代对位即碳酸钙高温分解：

```
CaCO₃ ──高温──▶ CaO + CO₂↑
```

从原料（石灰石 CaCO₃）、产物（生石灰 CaO）到应用场景，这是一条完整的无机化工流程记录。

### 5. 还原焙烧的经验体系

升炼水银（HgS 加热分解出汞蒸气并经曲溜管入水冷凝）、回升银朱（Hg＋S 化合且"出数藉硫质而生"记录增重）、烧矾、取硫、烧砒——分散各卷的记载合起来，覆盖了分解、还原、化合、结晶、蒸馏冷凝等基本化工操作类型[^9]。这些操作虽无理论命名，但装置设计（密封泥罐、曲溜管冷凝、层叠焙烧）显示出对"挥发性物质要收集、反应要隔绝空气"等要点的稳定把握。

## 二、理论局限

### 1. 没有元素与原子理论

全书对物质的解释停留在性状类比与命名附会层面：锌名"倭铅"，释名曰"以其似铅而性猛"[^3]——以外观相似与性情比喻代替成分分析；诸"矾"以颜色区分（白矾、皂矾、胆矾），其现代身份（硫酸铝钾、硫酸亚铁、硫酸铜的结晶水合物）要等现代化学才得以厘清[^10]。没有"元素—化合物"的分层概念，物质变化只能被描述，不能被解释。

### 2. 定量停留在经验配比

书中确有定量意识（六斤四斤的配比、十耗其二与耗四分之一的损耗率、银朱"出数藉硫质而生"的增重归因[^11]），但这些数字是操作规程与记账口径，不是受控测量：没有纯度概念、没有天平级的质量守恒检验、没有把配比上升为组成定律的尝试。经验数字准确，理论通道缺席。

### 3. 传闻性内容与考辨需求

作为部帙庞大的工艺总集，书中还混有依传闻而录、难以核验的条目；本束仅择与化学工艺相关且经考古或多方互证的记载精读（如倭铅条），其余不作展开。这也提示读者：引用此书宜以现代校注整理本（见 [../references/modern-scholarship.md](../references/modern-scholarship.md) 第三节书目）为底本对照，避免孤证直引。

## 三、与同时代西方的对照

| 时间 | 中国 | 西方 |
|------|------|------|
| 1637 | 《天工开物》初刊：锌冶炼、黄铜配比、煤分类、石灰焙烧的工艺实录[^12] | 炼金术传统仍在；波义耳《怀疑的化学家》尚未问世 |
| 1661 | （书已在清代渐趋湮没[^13]） | 波义耳《怀疑的化学家》出版，批判四元素说、提出近代元素概念——**仅晚本书 24 年**，见 [波义耳《怀疑的化学家》阅读教程](../../boyle-sceptical-chymist/index.md) |
| 1789 | （国内传本稀少，靠日本和刻本存续[^13]） | 拉瓦锡《化学基础论》确立定量方法与氧化理论，见 [拉瓦锡《化学基础论》阅读教程](../../lavoisier-treatise/index.md) |

对照的含义：1637 年的中国在**操作层**不落后——炼锌工艺甚至领先欧洲百年以上[^5]；但 24 年后波义耳换了一条赛道，把化学从"做什么"转向"是什么"，元素概念与实验方法论由此分野。工艺成就与理论创新的断裂，正是本束双镜头读法要呈现的核心张力。

- **西学对照**：向前对照 [波义耳《怀疑的化学家》阅读教程](../../boyle-sceptical-chymist/index.md)（元素概念）与 [拉瓦锡《化学基础论》阅读教程](../../lavoisier-treatise/index.md)（定量化学），看经验工艺如何在理论化之后变成近代化学；
