# 《天工开物》阅读教程

> 明崇祯十年（1637）初刊的《天工开物》，是宋应星（1587—？，字长庚，江西奉新人）在分宜教谕任上写成的十八卷生产工艺百科：全书以农食之卷《乃粒》开篇、以珍宝之卷《珠玉》殿后，体现"贵五谷而贱金玉"的编排取向。本束聚焦其中化学工艺关系最密的四卷——《五金》（金属冶炼，含世界最早系统记载锌冶炼的"附倭铅"条）、《丹青》（朱砂—水银—银朱与制墨）、《作咸》（四类食盐）、《燔石》（煤炭、石灰、矾类、硫磺、砒石），采用"双镜头"读法：现象层用现代化学方程式还原工艺，名理层标注经验记录的理论局限，成就与局限并陈。
>
> ⚠️ **安全警示**：书中工艺涉及汞、砷、铅等剧毒物质与高温冶炼、焙烧操作，本束为历史文献阅读教程，**严禁模仿任何冶炼、升炼、烧制操作**。

## 🚀 快速开始

**零基础读者**（第一次接触古代工艺典籍）：

1. 读 [为什么读《天工开物》](concepts/00-why-read.md)，了解这部书的价值与读法承诺；
2. 读 [宋应星与晚明](concepts/01-song-yingxing-context.md)，建立成书语境；
3. 打开 [阅读路线](examples/02-reading-route.md)，备好在线原文、选定优先卷次；
4. 顺着 [《丹青》《作咸》《燔石》](concepts/03-chemical-crafts.md) 通览工艺总貌，再精读 [核心段落选读](concepts/04-key-passages.md)，跟 [《五金》段落逐句精读](examples/01-wujin-passage-reading.md) 走一遍六步法；
5. 以 [现代化学视角](concepts/05-modern-chemistry-lens.md) 收束。

**有科技史或化学背景的读者**：

1. 直读 [《五金》卷](concepts/02-wujin-metallurgy.md)，重点看倭铅（锌）冶炼的碳热还原与考古互证；
2. 读 [现代化学视角](concepts/05-modern-chemistry-lens.md)，对照成就与局限；
3. 用 [核心段落选读](concepts/04-key-passages.md) 与 [《五金》段落逐句精读](examples/01-wujin-passage-reading.md) 校验原文细节；
4. 延伸对照：[波义耳《怀疑的化学家》阅读教程](../boyle-sceptical-chymist/index.md)（1661 年元素概念，仅晚本书 24 年）与 [拉瓦锡《化学基础论》阅读教程](../lavoisier-treatise/index.md)（1789 年定量化学）。
