# 阅读路线——在线十八卷、参照读物与姊妹束配合

本篇回答一个问题：**决定读《天工开物》之后，从哪里开始、按什么顺序、读到什么程度**。核心原则是[不必通读](../concepts/00-why-read.md)——全书十八卷约五万余字[^1]，化学工艺相关者不过数卷，按兴趣选卷即可。

## 一、在线十八卷读法

### 入口与用法

古诗文网收录《天工开物》序一篇与十八卷全文，简体字、现代标点，每卷独立成页[^2]。用法：

1. 先打开全书目录页（O-01），总览十八卷标题；
2. 点入优先卷次的页面直读正文；桌面版打印引用更方便；
3. 遇到名物疑难，回本束 [facts.md](../facts.md) 查对应条目，或查 [concepts/03-chemical-crafts.md](../concepts/03-chemical-crafts.md) 的现代对位。

### 优先卷次表

| 优先级 | 卷 | 在线原文 | 为什么先读 |
|--------|----|----------|-----------|
| ★★★ | 《五金》 | O-07 | 倭铅（锌）冶炼为世界最早系统记载之一，黄铜配比、生熟铁与钢，本束精读核心[^3] |
| ★★★ | 《燔石》 | O-06 | 煤炭按用途分类、石灰焙烧、矾类硫磺砒石，非金属化工最密集的一卷[^4] |
| ★★☆ | 《丹青》 | O-08 | 朱砂—水银—银朱转化与银朱增重的定量观察，制墨工艺[^5] |
| ★★☆ | 《作咸》 | O-03 | 海盐池盐井盐崖盐四类制盐法，井火（天然气）煮盐[^6] |
| ★☆☆ | 《冶铸》《锤锻》 | O-04、O-05 | 铸钱配比、钢铁加工与淬法，与《五金》互为表里[^7] |
| ★☆☆ | 其余十二卷 | 见 O-01 目录 | 乃粒、乃服、陶埏、舟车等，按个人兴趣选读 |

### 三种时间预算的路线

**15 分钟路线**（只看一眼）：

```
本束 index.md 快速开始 → concepts/04-key-passages.md 三段选文 → 收工
```

**2 小时路线**（摸清门道）：

```
concepts/00 → concepts/02（五金）→ examples/02（本篇，备好在线原文）
→ 打开 O-07 通读《五金》卷 → examples/01 跟练倭铅段 → concepts/05 收束
```

**一周路线**（系统阅读）：

```
第 1 天：concepts/00、01（背景）＋ O-02《序》
第 2 天：concepts/02 ＋ O-07《五金》通读
第 3 天：concepts/03 ＋ O-06《燔石》通读
第 4 天：O-08《丹青》＋ O-03《作咸》
第 5 天：O-04《冶铸》＋ O-05《锤锻》选读
第 6 天：examples/01 六步法自选一段精读 ＋ concepts/05
第 7 天：M-01—M-03 考古报道 ＋ 回看 facts.md 全表
```

## 二、与科技史参照读物配合

原书文言直读有门槛，参照读物按需取用（本束仅登记书目线索，不引用其译文）[^8]：

| 读物 | 用途 | 适用阶段 |
|------|------|---------|
| 钟广言《天工开物译注》（广东人民出版社） | 白话对照通读，初学者入门 | 第一遍读原著时对照 |
| 潘吉星《天工开物校注及研究》（巴蜀书社） | 校勘与专题研究 | 需要考订字句、深究专题时 |
| 李约瑟《中国科学技术史》（Science and Civilisation in China） | 国际科技史视野，多处引用本书[^9] | 中西对照阶段 |
| 忠县临江二队炼锌遗址考古报道（M-01—M-03） | 工艺记载的实物互证[^10] | 读《五金》卷时配合 |

配合方式建议"**先原文、后译注**"：先自己用六步法啃一段（见 [01-wujin-passage-reading.md](01-wujin-passage-reading.md)），带着问题再看译注，避免被现成理解取代自己的阅读。

## 三、与姊妹束配合阅读

本束处在化学典籍阅读教程序列中，配合读法按目标选择：

**目标一：看懂中国古代物质知识全貌（中国线索）**

```
《周易参同契》阅读教程（../../cantongqi/index.md）   → 理论框架：易学符号统合炼丹
《抱朴子·内篇》阅读教程（../../baopuzi/index.md）    → 实践记录：丹方、操作与观察
《天工开物》阅读教程（本束）                      → 生产工艺：冶炼与化工入百科
```

三束对照点：同样面对炉火与矿物，葛洪问"如何点化成金"，宋应星问"如何多出锌、少损耗"——价值取向从求仙转向民用，正是理解"贵五谷而贱金玉"的背景。

**目标二：看经验工艺如何走向近代化学（西学对照线）**

```
本束（1637，工艺实录）→ 波义耳《怀疑的化学家》（../../boyle-sceptical-chymist/index.md，1661，元素概念，仅晚 24 年）→ 拉瓦锡《化学基础论》（../../lavoisier-treatise/index.md，1789，定量化学）
```

重点对照：本束"配比与损耗"的记账式定量，与拉瓦锡天平级的质量守恒，差在测量制度与理论框架，不在观察是否细心。

**目标三：理解知识背后的自然观（思想背景）**

宋应星的书名取自《尚书》"天工人其代之"与《周易》"开物成务"[^11]，其"天工—开物"的人天关系可想见道家自然观的底色，参读 [帛书《老子》阅读教程](../../../../guoxue/laozi/boshu-reading/index.md)。

## 四、阅读记录建议

- 用 [facts.md](../facts.md) 作"对账本"：每读到一处工艺记载，查对应 F 编号，核对现代化学对应是否如本束所述；
- 自选一段（建议《燔石》石灰条或《丹青》朱条）走完六步法，写成自己的精读笔记；
- 记下本束未覆盖的疑问（如其他各卷的工艺细节），它们是扩展阅读的入口。
