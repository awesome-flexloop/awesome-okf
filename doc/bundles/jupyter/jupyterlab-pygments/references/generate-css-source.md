# CSS生成脚本源码（generate_css.py）

本信源登记 `generate_css.py`（共33行）的完整内容与执行逻辑。该脚本是双桥架构的核心转换器——将 Python 端定义的 `JupyterStyle` 类（使用 CSS 变量）转换为静态 CSS 文件，供前端 JupyterLab 扩展加载。

## 完整源码

```python
"""Generates pygments style sheet from jupyterlab-pygments.
Source: https://github.com/jupyterlab/jupyterlab_pygments
"""
from pathlib import Path

from jupyterlab_pygments import JupyterStyle

from pygments.formatters import HtmlFormatter


prefix = """
/*-----------------------------------------------------------------------------
| Copyright (c) Jupyter Development Team.
| Distributed under the terms of the Modified BSD License.
|----------------------------------------------------------------------------*/
/* This file was auto-generated by generate_css.py in jupyterlab_pygments */
"""


def main():
    formatter = HtmlFormatter(style=JupyterStyle)
    css = formatter.get_style_defs('.highlight')
    highlight_css = '\n'.join(filter(
        lambda line: line.startswith('.highlight'), css.splitlines()
    ))

    here = Path(__file__).parent
    style_file = here / "style" / "base.css"
    style_file.write_text("\n".join((prefix, highlight_css)))


if __name__ == "__main__":
    main()
```

## 逐段解析

### 导入部分（第4-8行）

```python
from pathlib import Path
from jupyterlab_pygments import JupyterStyle
from pygments.formatters import HtmlFormatter
```

- `pathlib.Path`: 用于跨平台路径操作
- `JupyterStyle`: 导入同包中定义的 Pygments 样式类
- `HtmlFormatter`: Pygments 的 HTML 格式化器，能够根据 Style 类生成对应的 CSS 样式表

### 版权前缀（第11-17行）

```python
prefix = """
/*-----------------------------------------------------------------------------
| Copyright (c) Jupyter Development Team.
| Distributed under the terms of the Modified BSD License.
|----------------------------------------------------------------------------*/
/* This file was auto-generated by generate_css.py in jupyterlab_pygments */
"""
```

- 定义生成 CSS 文件的版权注释头部
- 明确标注该文件是自动生成的，不应手动编辑
- 使用 Jupyter 标准的 Modified BSD License 版权声明格式

### main() 函数（第20-29行）

**步骤1：创建格式化器**
```python
formatter = HtmlFormatter(style=JupyterStyle)
```
- 创建 `HtmlFormatter` 实例，传入 `JupyterStyle` 作为样式类
- `HtmlFormatter` 是 Pygments 内置的格式化器，负责将 token 流转换为 HTML，并根据 Style 类生成对应的 CSS

**步骤2：生成CSS定义**
```python
css = formatter.get_style_defs('.highlight')
```
- 调用 `get_style_defs('.highlight')` 方法
- 参数 `'.highlight'` 指定 CSS 选择器前缀——所有生成的 CSS 规则都将以 `.highlight` 开头
- 返回值是包含完整 CSS 规则的字符串

**步骤3：过滤CSS行**
```python
highlight_css = '\n'.join(filter(
    lambda line: line.startswith('.highlight'), css.splitlines()
))
```
- 将 CSS 按行分割
- 过滤出以 `.highlight` 开头的行（排除空行、注释行等）
- 重新连接为字符串
- 这个过滤确保只保留 `.highlight` 选择器下的样式规则，去除 Pygments 可能生成的其他内容（如 `pre` 样式等）

**步骤4：写入文件**
```python
here = Path(__file__).parent
style_file = here / "style" / "base.css"
style_file.write_text("\n".join((prefix, highlight_css)))
```
- 获取脚本所在目录路径
- 定位到 `style/base.css`（相对于脚本位置）
- 将版权前缀和过滤后的 CSS 规则拼接写入文件
- 这个 `base.css` 随后被 `style/index.css`（`@import url('base.css')`）和 `style/index.js`（`import './base.css'`）引入

### 入口点（第32-33行）

```python
if __name__ == "__main__":
    main()
```

- 当脚本直接运行时执行 `main()` 函数
- 在 `package.json` 的 `build:css` 脚本中通过 `python generate_css.py` 调用

## 执行时机

该脚本在构建流程中由 npm/yarn 脚本触发：

```json
"build:css": "python generate_css.py"
```

在完整构建链 `build: css → lib → labextension` 中，CSS 生成是第一步——前端资源编译依赖于 `style/base.css` 的存在。

## 输出文件

脚本生成的 `style/base.css` 包含如下格式的规则（示例）：

```css
.highlight .c { color: var(--jp-mirror-editor-comment-color); font-style: italic }
.highlight .k { color: var(--jp-mirror-editor-keyword-color); font-weight: bold }
.highlight .o { color: var(--jp-mirror-editor-operator-color); font-weight: bold }
.highlight .m { color: var(--jp-mirror-editor-number-color) }
.highlight .s { color: var(--jp-mirror-editor-string-color) }
.highlight .p { color: var(--jp-mirror-editor-punctuation-color) }
.highlight .err { color: var(--jp-mirror-editor-error-color) }
```

每条规则对应 Pygments token 的 CSS class，值为 JupyterLab 的 CSS 变量引用。
