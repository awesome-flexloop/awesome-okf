## 二、底本与校勘

- 维基文库底本附**校勘记 19 条**，对校引据之书包括《难经本义》《难经疏证》《古本难经阐注》《脉经》《灵枢》；
- 与《灵枢》互证五条：三十七难九窍/七窍、二十四难三阴/五阴与肉满/人中满、六十六难大陵/太陵（据《灵枢·九针十二原》改）、二十七难不虞（据《脉经》改）。

## 三、历代版本与影印系统

- **早期版本**：明经厂刻医要集览本、日本武村市兵卫刻宋·王九思《黄帝八十一难》集注本等；
- **《难经集注》系统**：南宋李元立汇集南宋以前 9 家校注编《难经十家补注》，后人据此重刻改订为《王翰林集注八十一难经》（简称《难经集注》，后世通行本）；传世通行本传入日本保存至今，国内上海涵芬楼影印本（1924）、中华书局《四部备要》排印本、人民卫生出版社影印本（1956）均据日人林衡氏辑《佚存丛书》本；
- **北宋官校**：王九思、王鼎象、王惟一先后校勘；王惟一校勘本在吕广注本和杨玄操注本基础上完成，曾刊印颁行。

## 四、异文登记摘要（维基文库本 vs 国学导航本，古诗文网为第三参证）

本束事实登记共 18 组异文（NJ-064~NJ-081），要点如下：

| 类型 | 代表条目 |
|------|---------|
| **义理级两读** | 三十六难末句：**维基文库本作"故知肾有二也"，国学导航本与古诗文网作"故知肾有一也"**——直接关系"肾有几个"的理论表述，两读必须并列登记 |
| 义理相关 | 三十八难"谓二焦也/谓三焦也"；四难"脾受谷味也/谷气也/脾也"三读 |
| 句读两读 | 一难末句"手太阴寸口者/手太阴。寸口者"；八十一难"肝虚微少气"句读 |
| 形误 | 十四难"四乎一至命绝"（乎为呼之形写）；五十六难"在胃皖"（皖为脘之形误） |
| 字有有无 | 七十难句首"经言"二字有无；六十八难"其"字有无；三十九难"亦"字有无 |
| 用字通例 | 维基文库本作"五藏六府""荣卫""𫏋""齐（脐）"等古字，国学导航本与古诗文网作"五脏六腑""营卫""跷""脐"等通行字 |
| 异体字 | 六十六难肾之原"太谿/太溪"，心之原"大陵/太陵"，脾之原"太白/大白" |

## 五、引用规范

1. 引用原文必须标注底本与信源（本束以维基文库本为工作底本）；
2. 异文显式标注"维基文库本作某/国学导航本作某"（古诗文网参证位次之）；
3. 义理级两读（如"故知肾有一也/二也"）并列登记，不作裁决；
4. 诸难无独立题名，引用作"《难经》第 N 难"，不用"秦越人说"。
