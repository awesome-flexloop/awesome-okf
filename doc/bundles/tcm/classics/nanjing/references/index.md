## 信源使用说明

- 概念文档（concepts/）与精读文档（examples/）通过 frontmatter `sources` 字段引用信源，格式为 `id / resource / title`。
- **原文工作底本**：维基文库《难经》（附校勘记 19 条，连排照录）；**主对校本**：国学导航《黄帝八十一难经》（六部分类）；**第三参证**：古诗文网。ctext.org 因访问受限未采用。
- **异文标注惯例**：凡两本文字有实质差异，正文显式标注"维基文库本作某/国学导航本作某"；义理级两读（如三十六难"故知肾有一也/二也"）并列登记不裁决。
- **用字通例**：维基文库本作"五藏六府""荣卫""𫏋"等古字，国学导航本与古诗文网作"五脏六腑""营卫""跷"等通行字，不逐条出校。
- **版权边界**：原典与古注为公共领域；1949 年后现代整理本仅书目登记与结论性引用，不转录其题解译文注文。
