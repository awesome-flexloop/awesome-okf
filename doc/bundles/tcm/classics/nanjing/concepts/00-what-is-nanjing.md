# 什么是《难经》

《难经》原名《黄帝八十一难经》，又称《八十一难》，是中医现存较早的经典著作之一。"难"字有"问难"或"疑难"二义——全书以设问作"曰"、答以"然"的问答体裁，对脉诊、脏腑、阴阳、五行、病能、营卫、俞穴、针灸，以及三焦、命门、奇经八脉等理论疑难问题逐一释疑解难，故以"八十一难"为名。

## 书目著录的"缺位信号"

一部书的著录链往往透露其文本身世。《难经》的著录链有一个显著特征：**所托名的成书年代（战国）与书目著录的出现（东汉以后）之间存在数百年的缺位**。

| 时段 | 著录情况 | 信号 |
|------|---------|------|
| 西汉 | 《汉书·艺文志》**未著录**《难经》，仅著录《扁鹊内经》《扁鹊外经》（均佚） | 缺位信号 |
| 东汉 | 张仲景《伤寒杂病论·序》首见《八十一难》之名："撰用《素问》《九卷》《八十一难》《阴阳大论》《胎胪药录》，并《平脉辨证》，为《伤寒杂病论》合十六卷" | 书名首见 |
| 隋 | 《隋书·经籍志》载《黄帝八十一难经》二卷，**未载作者**——此为最早正史书目著录 | 作者不明 |
| 唐 | 《旧唐书·经籍志》著录《黄帝八十一难》一卷，题秦越人撰；《新唐书·艺文志》载秦越人《黄帝八十一难经》二卷 | 托名题署定型 |
| 唐 | 杨玄操《难经注·序》首次明确记载："黄帝八十一难者，斯乃勃海秦越人之所作也"，并称秦越人"家于卢国，因命之曰卢医" | 托名叙事展开 |

**反证**：《史记·扁鹊仓公列传》未记载秦越人著《难经》一事——距秦越人时代最近的传记对此书只字未提。宋赵希弁《读书后志》著录"黄帝八十一难经一卷，秦越人撰，吴吕广注，唐杨玄操演"，说明"秦越人撰"的题署在唐宋书目中已成定式，但这是文化归属而非文本事实。

## 托名性质与文本流动

今本题"秦越人撰"属于古籍常见的文化托名。《难经》的托名之外，其文本在汉唐间还表现出明显的流动性：

- 张仲景撰《伤寒杂病论》时所引《八十一难》文字与今本《难经》**互有出入**；
- 晋王叔和《脉经》收录的《难经》原文均**不见于今本**《难经》，说明另有传本；
- 唐张守节《史记正义》于《扁鹊仓公列传》全引《难经》文以释其义，并全载第四十二难与第一难、三十七难全文——可见唐初已有较稳定的传本。

因此，"《难经》为秦越人所作"只能作为著录层的文化归属陈述登记；本知识包一律不用"秦越人说"表述，涉及原文论断时采用"《难经》第 N 难作某"的引述格式。

## 成书年代五说并列（不裁决）

关于《难经》成书年代，现代信源至少可归纳为五说，本束并列登记如下：

| 说 | 内容 | 出处 |
|---|------|------|
| 战国说 | "《难经》是战国时期成书，作者是扁鹊……传说为战国时期秦越人（扁鹊）所作" | 古诗文网词条 |
| 西汉末至东汉之间说 | "大约成书于西汉末期至东汉之间" | 国学导航词条 |
| 不晚于东汉说 | "一般认为其成书不晚于东汉，内容可能与秦越人（扁鹊）有一定关系" | 中医宝典词条（国家中医药管理局名词术语规范推广项目审核认证） |
| 东汉伪托说 | "《难经》当为东汉时期的作品。作者也非秦越人，当为后人伪托"；文中并录异说"或疑为两汉前书，或疑为元人所作，或疑为六朝人所作，众说不一" | 《难经的成书年代及作者考辨》 |
| 东汉以后说 | 丹波元胤《中国医籍考》按语：其文"较之于《素问》《灵枢》，其语气稍弱，似出于东都（东汉定都洛阳）以后之人" | 《八十一难经吕杨注》辑校与研究引 |

**断代旁证**（《难经的成书年代及作者考辨》一文的方法）：以马王堆汉墓帛书十一脉与《难经》十二经概念相比证，并以六十三难"行喘息"语首见于西汉末王褒《洞箫赋》为据，推断《难经》成书上限在《汉书·艺文志》之后、下限在《伤寒论》之前。

## 本束的处理立场

1. **托名与年代诸说并列登记，不作裁决**——五说各有信源与论证路径，本束不设"标准答案"；
2. **引用规范**：涉及学理表述一律用"《难经》第 N 难作某"，不用"秦越人认为/扁鹊说"；
3. 书名使用上，《难经》《黄帝八十一难经》《八十一难》三名并通行，本束正文统一用《难经》，著录语境保留全名。
