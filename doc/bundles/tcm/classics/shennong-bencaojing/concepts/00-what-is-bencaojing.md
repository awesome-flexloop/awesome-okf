# 什么是《神农本草经》：托名、早佚与辑复

一部"作者不明、原本已亡、今本皆辑"的书，必须先把这三层事实分清楚再读。

## 一句话定位

《神农本草经》又名《神农本草》，简称《本草经》《本经》，是我国现存最早的药学专著。它的三个基本事实必须放在最前面：**撰人不详，"神农"为托名；原书早佚；今传全书皆为后世从历代本草书中集辑的辑复本**。

## 三层分离

| 层次 | 对象 | 事实状态 |
|------|------|---------|
| **托名层** | 题名"神农"所指向的上古圣人作者 | 文化归属符号，非历史事实——撰人不详，历代以"神农"托名处理 |
| **著录层** | 历代官修书目著录：最早见《隋书·经籍志》"神农本草，四卷，雷公集注" | 书目记录连续但卷帙波动（四卷/三卷/八卷），是传本变动的轨迹 |
| **文本层** | 今传各辑复本：明卢复辑（1616）、清孙星衍孙冯翼辑（1799）、清顾观光辑（1844）、日本森立之辑（1854）等 | 可读的真实文本，各成系统，详见 [概念 01：辑本系统](01-reconstruction-systems.md) |

## "神农"为什么是托名

第一，原书没有留下任何作者信息，现代解题直言其"撰人不详，'神农'为托名"。

第二，清代邵晋涵为孙星衍辑本所作序有一段经典考辨："《汉书》引本草方术而《艺文志》缺载，贾公彦引《中经簿》，有《子仪本草经》一卷，不言出于神农。至隋《经籍志》，始载《神农本草经》三卷，与今分上、中、下三品者相合，当属汉以来旧本。"——汉志不载，隋志始见，唐人所见另有题名不同的《子仪本草经》，托名之迹显然。

第三，梁陶弘景早有清醒判断（孙星衍自序引其语）："轩辕已前，文字未传，药性所主，当以识识相因。至於桐、雷，乃着在於编简。"——轩辕以前文字未传，药物知识靠口耳相授，上古圣人不可能留下亲笔药书。

## 成书年代：诸说并列

其成书年代自古即有不同考论：**或谓成于秦汉时期，或谓成于战国时期**。两说并列，本知识包不作裁决——结论取决于如何权衡隋志著录、郡县地名、药物知识水准等间接证据，不同证据组合导向不同判断。

## 历代著录的卷帙波动

| 书目 | 著录 |
|---|---|
| 《隋书·经籍志》 | 神农本草，四卷，雷公集注 |
| 《旧唐书·经籍志》《唐书·艺文志》 | 神农本草，三卷 |
| 宋《通志·艺文略》 | 神农本草，八卷，陶隐居集注 |
| 明《国史经籍志》 | 神农本草经，三卷 |
| 《清史稿·艺文志》 | 神农本草经，三卷 |

著录卷帙从四卷、三卷到八卷再到三卷的波动，本身就是"此书无稳定原典、只有变动传本"的书目学证据；而各辑本最终多以三卷（上、中、下三品各一卷）行世，与邵序"与今分上、中、下三品者相合"的分品结构相合。

## 与读者的三条约定

1. 本知识包中"《本经》"一词指这一文献共同体（托名神农的本草经文本系统），不指某一具体印本。
2. 引用《本经》文字一律标注所据辑本（"维基文库本""孙星衍辑本"等）——**不存在"神农原文"**，这是全束的引用纪律。
3. 读到任何《神农本草经》出版物，第一个动作是查版权页与凡例，确认它据哪个辑本排印（选用建议见[现代研究与辑本选用建议](../references/modern-research.md)）。
