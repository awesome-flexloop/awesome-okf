## 四、异文登记摘要（8 处）

精读条文中版本差异 8 处（义理级并列不裁决）：

| 条文 | 异文 |
|---|---|
| 第 16 条 | 康平本"随证治之"作"随证治"，成注本同宋本 |
| 第 31 条 | "几几"成注本或作"沉沉"，为异体字之别 |
| 第 96 条 | "嘿嘿"一本作"默默"，为通假异写 |
| 第 182 条 | 宋本作"不恶热反恶热"，J 本作"不恶寒反恶热"；宋本原文系传抄之误，诸家校注多从"不恶寒反恶热"，今通行整理本作"不恶寒，反恶热" |
| 第 219 条 | 成无己本"口不仁"下有"而"字，《脉经》"口"字下有"中"字，《千金翼方》"面垢"作"语言向经"；康平本"三阳合病"作嵌注，层次与宋本不同 |
| 第 236 条 | 《玉函经》"汗出"上有"而"字，《千金翼方》《外台秘要》"身无"作"身无有"，《玉函经》《千金翼方》"剂颈"之"剂"作"齐"，成无己本方名无"蒿"字 |
| 第 263 条 | 成注本此条作"少阳病"，无"为"字 |
| 第 302 条 | "无证"康平本作"无里证"，宋本作"无证"，诸家有校议 |

## 五、出处辨正

**"正气存内，邪不可干"**：该句出自《素问·刺法论》（遗篇），原文为"正气存内，邪不可干，避其毒气"。《伤寒论》全书中无此句。《伤寒论》中与正气相关的表述见于第 97 条"血弱气尽，腠理开，邪气因入，与正气相搏，结于胁下"。（信源：https://ctext.org/huangdi-neijing/su-wen/72b/zhs ；https://ctext.org/shang-han-lun/zhs ）
