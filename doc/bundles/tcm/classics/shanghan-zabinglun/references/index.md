## 信源使用说明

- 概念文档（concepts/）与精读文档（examples/）通过 frontmatter 的 `sources` 字段引用信源，格式为 `id / resource / title` 三字段；引用路径使用 bundle 相对路径或外部 URL。
- **原文工作底本**：《伤寒论》以维基文库宋本赵开美刻本转录本（W）与中国哲学书电子化计划（C）双源核对，中医宝典（J）对校；《金匮要略》第一篇以中医宝典排印本（JY）为底本、篇名及条文编次以北宋校正医书局编次为据（WS）。
- **版本立场提示**：任何单一网络文本都是某一版本系统的投影（INS-002）；本束条文引用一律标注信源缩写，异文显式登记"某本作某"，义理级异文并列不裁决（完整登记见 [sources-editions.md](sources-editions.md)）。
- **版权边界**：原典原文为公共领域文献，可照录；现代整理本（刘渡舟《伤寒论校注》等）的题解、译文、注解受版权保护，本知识包仅做书目登记与结论性引用（如底本选择等 facts 记载事项），不转录其注文译文。
- **编号体系声明**：本束所引"第 N 条"为现代校注本所加（SH-019），宋本、成注本原书无条文编号——引用时知此为研读工具而非古籍原貌。
