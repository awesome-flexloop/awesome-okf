# 什么是伤寒杂病论——张仲景与原书十六卷

> ⚠️ 本知识包内容为古籍文献学习资料，非医疗建议；任何健康问题请咨询执业医师。文中方药剂量仅为文献记录，不构成用药指导。

## 一部书，三个名字

"伤寒杂病论"这个名字之下，实际上叠着三个不同层次的对象：

1. **原书**：东汉末年张仲景撰《伤寒杂病论》十六卷——此书已佚，今人无法读到原貌（SH-003、SH-008）。
2. **今本《伤寒论》**：十卷，西晋王叔和取原书伤寒部分整理编纂，北宋校正医书局校订刊行（SH-008、SH-009）。
3. **今本《金匮要略》**：三卷二十五篇，北宋林亿等自馆阁残卷《金匮玉函要略方》中卷编成（SH-011）。

换言之，今天书架上任何一部《伤寒论》或《金匮要略》，都是原书十六卷散佚后，经整理者、校订者之手重新拼合定型的产物。把"张仲景著《伤寒论》398 条"当作直接的文本事实，是把文化归属误认成了文本事实（INS-001）。

## 张仲景其人：信源几何

关于张仲景生平，可考的早期材料相当有限：

- **自序署名**：原书自序署"南阳张机"。张仲景名机，字仲景，东汉南阳郡人（SH-001）。
- **正史无传**：张仲景在《后汉书》《三国志》两种正史中均无传记，此为通行记载（SH-005）。这意味着他的生平没有正史级的权威记录，主要依靠自序与后人追记。
- **早期旁证**：西晋皇甫谧《甲乙经》序记载"仲景论广伊尹汤液为数十卷，用之多验"，并记载仲景判断王仲宣（王粲）四十岁后"眉落"之事，是仲景活动的早期旁证文献（SH-004）。这条材料同时提示了原书方剂与《汤液经法》的渊源问题（详见[概念 06](06-commentators.md)）。
- **长沙太守说**："张仲景曾任长沙太守"之说，现存最早文字依据为唐代甘伯宗《名医录》（原书已佚，经宋代校正医书局《伤寒论》卷首序文转引），此说在学界存有争议（SH-006）。

**正史无传的信号**：一位被后世尊为"医圣"的人物，在记传体正史中无一席之地，这提示两点——其一，仲景生前主要活动于民间医家层面，未进入史官视野；其二，其形象与地位是后世（尤其宋代以后）经方传统逐渐建构的结果。读其书与知其人，须分层处理。

## 成书缘起：自序的原始自述

《伤寒杂病论》自序记述宗族遭遇："余宗族素多，向余二百，建安纪年以来，犹未十稔，其死亡者，三分有二，伤寒十居其七"（SH-002）。这是成书缘起的原始自述——建安纪年以来不足十年，宗族二百余口死亡三分之二，其中伤寒（外感热病一类）占十分之七。惨烈的疫病流行，是这部书出现的直接历史背景。

自序又记其撰著内容："撰用《素问》《九卷》《八十一难》《阴阳大论》《胎胪药录》，并平脉辨证，为《伤寒杂病论》合十六卷"（SH-003）。这份书单表明原书的学术渊源上承医经家著作（《素问》《九卷》《八十一难》即《灵枢》《难经》一类）与古医方书（《胎胪药录》一类），"平脉辨证"则是其方法纲领。

成书年代，学界通行系年约为东汉末年建安年间，即公元 200—210 年（SH-007）。

## "伤寒"是什么

书名之"伤寒"，据第 3 条"太阳病，或已发热，或未发热，必恶寒，体痛，呕逆，脉阴阳俱紧者，名为伤寒"（C、W、J），在书中首先是一个具体证型名——与"名为中风"（第 2 条）相对；同时"伤寒"又作为外感热病的总名使用（各篇通称）。一词两用，读条文时须依上下文分辨。

## 阅读姿势

- 引用今本文字时，表述为"《伤寒论》第 N 条作某"，不表述为"张仲景说某"——因为今本文字经王叔和整理、宋臣校订而定型（SH-008、SH-009，INS-001）。
- 涉及仲景生平，区分自序自述（一手）与后人追记（如《甲乙经》序、《名医录》转引），后者标注转引链。
- 原书与今本的关系，续读[概念 01：成书流变](01-textual-history.md)；今日应选哪个本子读，见[概念 02：版本系统考](02-version-systems.md)。
