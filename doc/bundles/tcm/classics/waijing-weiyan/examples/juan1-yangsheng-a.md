# 卷一精读（上）——阴阳颠倒等五篇

> ⚠️ 本文为古籍文献学习资料，非医疗建议；养生方药内容仅作历史文献研究，健康问题请咨询执业医师。

本文件以维基文库《外經微言/一卷》简体转录本为底本逐段照录，校以古书网所收清代抄本（繁体）；底本中近人批注（含篇末按语处与混入正文、未署名的现代口语夹批）已全部剔除，正文与篇末陈士铎曰、陈远公曰微言按语则为原文，完整照录。

## 第一篇　陰陽顛倒篇

### 原文

黄帝闻广成子窈窈冥冥之旨，叹广成子之谓天矣。退而夜思，尚有未获。遣鬼臾区问于岐伯。

天师曰：帝问至道于广成子，广成子曰：至道之精，窈窈冥冥；至道之极，昏昏默默。无视无听，抱神以静，形将自正。必静必清，无劳汝形，无摇汝精，无思虑营营，乃可以长生。目无所见，耳无所闻，心无所知，汝神将守汝形，形乃长生。慎汝内，闭汝外，多知为败。我为汝遂于大明之上矣，至彼至阳之原也。为汝入于窈冥之门矣，至彼至阴之原也。天地有官，阴阳有藏，慎守汝身，物将自壮。我守其一，以处其和，故身可以不老也。天师必知厥义，幸明晰之。

岐伯稽首奏曰：大哉言乎，非吾圣帝安克闻至道哉。帝明知故问，岂欲传旨于万祀乎，何心之仁也！臣愚，何足知之。然仁圣明问，敢备述以闻。窈冥者，阴阳之谓也。昏默者，内外之词也。视听者，耳目之语也。至道无形而有形，有形而实无形。无形藏于有形之中，有形化于无形之内，始能形与神全，精与神合乎。

鬼臾区曰：诺，虽然，师言微矣，未及其妙也。

岐伯曰：乾坤之道，不外男女。男女之道，不外阴阳。阴阳之道，不外顺逆。顺则生，逆则死也。阴阳之原，即颠倒之术也。世人皆顺生，不知顺之有死；皆逆死，不知逆之有生，故未老先衰矣。广成子之教示帝行颠倒之术也。

鬼臾区赞曰：何言之神乎。虽然，请示其原。

岐伯曰：颠倒之术，即探阴阳之原乎。窈冥之中有神也，昏默之中有神也，视听之中有神也。探其原而守神，精不摇矣。探其原而保精，神不驰矣。精固神全，形安能敝乎。

鬼臾区覆奏帝前。

帝曰：俞哉，载之《外经》，传示臣工，使共闻至道，同游于无极之野也。

陈士铎曰：此篇帝问而天师答之，乃首篇之论也。问不止黄帝，而答止天师者，帝引天师之论也。帝非不知阴阳颠倒之术，明知故问，亦欲尽人皆知广成子之教也。

### 异文校记

- "颠倒之术，即探阴阳之原乎"句：底本（维基文库）作『乎』，古书网清抄本作『子』（"即探陰陽之原子"），按：古书网疑讹，"乎"为句末语气词，上承"请示其原"之问，作"子"则文不成义。
- "鬼臾区覆奏帝前"句：底本作『覆』，古书网清抄本作『復』（"鬼臾區復奏"），按：二字古通，"覆奏"谓回奏、复奏于帝前，两义皆可通，存异备考。
- 篇末陈士铎曰"明知故问，亦欲尽人皆知"句：底本作『明知故问』，古书网清抄本作『明知故』（脱"问"字，作"明知故亦欲盡人皆知"），按：古书网脱误，"明知故问"为成语，且与正文"帝明知故问"相呼应。

### 白话大意与解读

黄帝从广成子处闻"窈窈冥冥"之至道，退而思之犹有未明，遣鬼臾区问于岐伯。岐伯借广成子之言点出：至道不离阴阳，阴阳之机在顺逆——世人皆知顺阴阳而生，却不知顺中伏死；皆畏逆而死，却不知逆中有生。故"阴阳之原"即"颠倒之术"：能于窈冥、昏默、视听之中探得其原而守神保精，则精固神全、形可不敝。全篇以"顺则生、逆则死"立纲，以"探原守神"为功夫，为全卷养生诸论之总纲。

**微言按语**：陈士铎指出，此篇为《外经》开卷首论——问者虽有黄帝、鬼臾区，而答辞独归天师（岐伯），乃黄帝援引天师之论；黄帝并非不知阴阳颠倒之术，其"明知故问"，是欲使天下后世人人尽知广成子之教，仁及万世。

## 第二篇　順逆探原篇

### 原文

伯高太师问于岐伯曰：天师言颠倒之术，即探阴阳之原也，其旨奈何？

岐伯不答，再问曰，唯唯三问。

岐伯叹曰：吾不敢隐矣。夫阴阳之原者，即生克之道也。颠倒之术者，即顺逆之理也。知颠倒之术，即可知阴阳之原矣。

伯高曰：阴阳不同也。天之阴阳，地之阴阳，人身之阴阳，男女之阴阳，何以探之哉？

岐伯曰：知其原亦何异哉！

伯高曰：请显言其原。

岐伯曰：五行顺生不生，逆死不死。生而不生者，金生水而克水，水生木而克木；木生火而克火，火生土而克土，土生金而克金，此害生于恩也。死而不死者，金克木而生木，木克土而生土，土克水而生水，水克火而生火，火克金而生金，此仁生于义也。夫五行之顺相生而相克，五行之逆不克而不生。逆之至者，顺之至也。

伯高曰：美哉言乎。然何以逆而顺之也？

岐伯曰：五行之顺，得土而化。五行之逆，得土而神。土以合之，土以成之也。

伯高曰：余知之矣。阴中有阳，杀之内以求生乎。阳中有阴，生之内以出死乎。余与帝同游干无极之野也。

岐伯曰：逆而顺之，必先顺而逆之。绝欲而毋为邪所侵也，守神而毋为境所移也，练气而毋为物所诱也，保精而毋为妖所耗也。服药饵以生其津，慎吐纳以添其液，慎劳逸以安其髓，节饮食以益其气，其庶几乎。

伯高曰：天师教我以原者全矣。

岐伯曰：未也，心死则身生，死心之道，即逆之之功也。心过死则身亦不生，生心之道又顺之之功也。顺而不顺，始成逆而不逆乎。

伯高曰：志之矣，敢志秘诲哉。

陈士铎曰；伯高之问，亦有为之问也。顺中求逆，逆处求顺，亦死克之门也。今奈何求生于顺乎。于顺处求生，不若于逆处求生之为得也。

### 异文校记

- "木生火而克火"句：底本（维基文库）作『木生火而克火』，古书网清抄本作『水生火而剋火』，按：古书网误，五行相生之序为木生火，且上承"水生木而克木"、下接"火生土而克土"，唯"木"字合于五行序。
- "余与帝同游干无极之野"句：底本作『干』，古书网清抄本作『於』（游于无极），按："干"为"于"之形讹，古书网"於（于）"字义长，且与第一篇帝曰"同游于无极之野"语脉相承。
- 篇末"陈士铎曰；"：底本「曰」下作「；」（他本同），义当作「：」，标点之异不碍文义，照录不出校。
- "敢志秘诲哉"句：底本作『敢志秘诲哉』，古书网清抄本作『敢忘秘誨哉』（上句"志之矣"古书网作"誌之矣"），按：义当作"忘"，此句谓"岂敢忘记天师秘传之教诲"，"敢志"不辞；上句"志（誌）之矣"训"记"则两源同义，不为异。

### 字词注解

| 词语 | 注解 |
|---|---|
| 伯高太师 | 传说黄帝之臣，《内经》常见问对人物。 |
| 五行顺生不生，逆死不死 | 顺次相生之中反伏克害之机，逆行相克之中反藏生生之理。 |
| 害生于恩 | 相生之恩过当反成其害，如金生水而水盛反受其困之类。 |
| 仁生于义 | 相克之义中反成生养之仁，如金克木而木因之剪裁得生之类。 |
| 得土而化 / 得土而神 | 土为五行中枢，顺行者得土而化成，逆用者得土而神妙。 |
| 杀之内以求生 | 于阴肃杀之中蕴求生意，即逆修之法；与"生之内以出死"对文。 |
| 心死则身生 | 道家语，寂灭妄心、不逐外缘，则身命得全。 |
| 心过死则身亦不生 | 戒其偏弊：若强制枯心、槁木死灰，则生机亦绝，故"生心"又为顺之之功。 |
| 吐纳 | 道家炼气法，吐故纳新，呼浊吸清。 |
| 药饵 | 服食调养之药物。 |
| 秘诲 | 秘藏不轻传之教诲。 |
| 死克之门 | 于克伐死绝处寻出生门，即"逆处求生"之喻。 |

### 白话大意与解读

伯高追问"颠倒之术"的本原，岐伯揭示：阴阳之原就是五行生克之道，颠倒之术就是顺逆之理。五行顺次相生，恩中有害（金生水而克水之类）；逆行相克，义中藏仁（金克木而生木之类）——所以"逆之至者，顺之至也"。修持之法，先须"顺而逆之"：绝欲、守神、练气、保精，辅以药饵、吐纳、劳逸、饮食之节；功夫之要在心——"心死则身生"是逆修之功，但"心过死则身亦不生"，又须防枯寂之偏。

**微言按语**：陈士铎谓伯高之问乃"有为之问"，全篇眼目在"顺中求逆，逆处求顺"；世人只知于顺处求生，不知于逆处求生方为得之，这正是"死克之门"的深意。

## 第三篇　回天生育篇

### 原文

雷公问曰：人生子嗣，天命也。岂尽非人事乎？

岐伯曰：天命居半，人事居半也。

雷公曰：天可回乎？

岐伯曰：天不可回，人事则可尽也。

雷公曰：请言人事。

岐伯曰：男子不能生子者，病有九；女子不能生子者，病有十也。

雷公曰：请晰言之。

岐伯曰：男子九病者：精寒也，精薄也，气馁也，痰盛也，精涩也，相火过旺也，精不能射也，气郁也，天厌也。女子十病者：胞胎寒也，脾胃冷也，带脉急也，肝气郁也，痰气盛也，相火旺也，肾水衰也，任督病也，膀胱气化不行也，气血虚而不能摄也。

雷公曰：然则治之奈何？

岐伯曰：精寒者，温其火乎。精薄者，益其髓乎。气馁者，壮其气乎。痰盛者，消其涎乎。精涩者，顺其水乎。火旺者，补其精乎。精不能射者，助其气乎。气郁者，舒其气乎。天厌者，增其势乎，则男子无子而可以有子矣。不可徒益其相火也。胞胎冷者，温其胞胎乎。脾胃冷者，暖其脾胃乎。带脉急者，缓其带脉乎。肝气郁者，开其肝气乎。痰气盛者，消其痰气乎，相火旺者，平其相火乎。肾水衰者，滋其肾水乎。任督病者，理其任督乎。膀胱气化不行者，助其肾气以益膀胱乎。气血不能摄胎者，益其气血以摄胎乎，则女子无子而可以有子矣。不可徒治其胞胎也。

雷公曰：天师之言，真回天之法也。然用天师法男女仍不生子奈何？

岐伯曰：必夫妇德行交亏也。修德以宜男，岂虚语哉。

陈士铎曰；男无子有九，女无子有十，似乎女多于男也。谁知男女皆一乎，知不一而一者，大约健其脾胃为主，脾胃健而肾亦健矣，何必分男女哉。

### 异文校记

- "不可徒益其相火也"句：底本（维基文库）作『其』，古书网清抄本作『真』（"徒益真相火"），按：古书网疑讹，"其"指代上文男子诸病，且与下句"不可徒治其胞胎也"句式相偶，作"真"则句法不伦。
- 篇名"回天生育"之"回"，古书网清抄本作"迴"，按：回、迴为异体字，繁简异体之异不计。
- 篇末"陈士铎曰；"：底本「曰」下作「；」（他本同），义当作「：」，标点之异不碍文义，照录不出校。

### 字词注解

| 词语 | 注解 |
|---|---|
| 雷公 | 传说黄帝之臣，《内经》主要问对人物之一。 |
| 天命居半，人事居半 | 子嗣有无，先天命数与后天调摄各占其半。 |
| 精寒 / 精薄 | 精液清稀冷薄，古人归因命门火衰、精髓不足。 |
| 气馁 | 元气虚衰，交合无力。 |
| 相火 | 对"君火"（心火）而言，寄于肝肾命门之火；相火过旺则精易泄。 |
| 精涩 / 精不能射 | 精道滞涩、射精不能，多属气滞或气虚。 |
| 天厌 | 男子九病之一，旧注或谓先天形器缺陷、阳事不举之类。 |
| 胞胎寒 | 子宫寒冷，难以摄精成孕。 |
| 带脉急 | 带脉拘急；带脉环腰一周，总束诸经，与胞胎相关。 |
| 任督病 | 任脉、督脉为病；任主胞胎，督统阳气，皆奇经八脉。 |

| 修德以宜男 | 修德行善以招男嗣，乃古人"德福相招"之观念。 |

### 白话大意与解读

雷公问：人生子嗣莫非尽由天命、全无人事可为？岐伯答"天命居半，人事居半"——天不可回，人事则可尽。于是条列男子九种无子之病（精寒、精薄、气馁、痰盛、精涩、相火过旺、精不能射、气郁、天厌）与女子十种无子之病（胞胎寒、脾胃冷、带脉急、肝气郁、痰气盛、相火旺、肾水衰、任督病、膀胱气化不行、气血虚不能摄胎），各出治法大要，并两申戒辞：男子"不可徒益其相火"，女子"不可徒治其胞胎"。若依法调治仍不生子，则多因夫妇德行交亏，当修德以回天。

**微言按语**：陈士铎点明：男九病、女十病看似女多于男，实则病机归一——调治大约总以健旺脾胃为主，脾胃健则肾亦自健，临证不必强分男女。

## 第四篇　天人壽夭篇

### 原文

伯高太师问岐伯曰：余闻形有缓急，气有盛衰，骨有大小，肉有坚脆，皮有厚薄，可分寿天然乎？

岐伯曰：人有形则有气，有气则有骨，有骨则有肉，有肉则有皮。形必与气相合也，皮必与肉相称也，气血经络必与形相配也，形充而皮肤缓者寿。形充而皮肤急者天。形充而脉坚大者，气血之顺也，顺则寿。形充而脉小弱者，气血之衰也，衰则危。形充而颧不起者，肉胜于骨也，骨大则寿，骨小则天。形充而大，肉（月囷）坚有分理者，皮胜于肉也，肉疏则天，肉坚则寿。形充而大肉无分理者，皮仅包乎肉也，肉厚寿，肉脆夭。此天生，人不可强也，故见则定人寿夭，即可测人生死矣。

少师问曰：诚若师言，人之寿天天定之矣，无豫于人乎？

岐伯曰：寿夭定于天，挽回天命者人也。寿夭听于天；戕贼其形骸，泻泄其精髓，耗散其气血，不必至天数而先天者，天不任咎也。

少师曰：天可回乎？

岐伯曰：天不可回，而天可节也。节天之有余，补人之不足，不亦善全其天命乎。

伯高太师闻之曰：岐天师真善言天也。世人贼夭之不足，乌能留人之有余哉。

少师曰：伯高非知在人之天者乎。在天之夭，难回也。在人之夭，易延也。吾亦修吾之天，以全天命乎。

陈远公曰：天之天难延，人之天易延。亦训世延人之夭也。伯高之论，因天师之教而推广之，不可轻天师而重伯高也。

### 异文校记

- 本篇"夭"字底本（维基文库）多讹作"天"，凡八处："可分寿天然乎"（当作"寿夭"）、"形充而皮肤急者天"（当作"夭"）、"骨小则天"（古书网清抄本作"骨小則夭"）、"肉疏则天"（古书网作"肉疏則夭"）、"人之寿天天定之矣"（古书网作"人之壽夭，天定之矣"）、"不必至天数而先天者"（古书网作"先夭者"）、篇末陈远公曰"天之天难延，人之天易延"（古书网作"天之夭難延，人之夭易延"二处），按：八处皆以古书网"夭"字为是，"寿夭""夭折"正本篇主题，底本"天"皆"夭"之形讹，阅读底本时须随文改读。
- "世人贼夭之不足"句：底本作『夭』，古书网清抄本作『天』（"世人賊天之不足"），按：此条异文方向与上条相反，存异待考；寻绎文义，"贼天"与下句"人之有余"为天、人对文，且上承"节天之有余，补人之不足"，古书网"天"字似长，然孤证存疑。
- "肉（月囷）坚有分理者"句：底本以『（月囷）』拼注『䐃』字，即"肉䐃坚"（䐃音jùn，肌肉聚结丰厚之处），古书网清抄本作"肉堅有分理"，脱"䐃"字，按：底本存字为长，《灵枢·寿夭刚柔》论形气寿夭有"大肉䐃坚"之文，可证此字当存。

### 白话大意与解读

伯高问：形之缓急、气之盛衰、骨之大小、肉之坚脆、皮之厚薄，能否据以判定寿夭？岐伯论之：形必与气相合、皮与肉相称、气血经络与形相配——形充而皮肤和缓、脉坚大、骨大、肉䐃坚而腠理分明天寿兆；皮急、脉小弱、颧不起、骨小、肉疏脆者夭折之征。少师进而问寿夭是否全由天定，岐伯谓"寿夭定于天，挽回天命者人"：若戕贼形骸、泻泄精髓、耗散气血，未尽天年而先折，天不任其咎；天固不可回，而天可节——节天之有余、补人之不足，即可善全天命。

**微言按语**：陈远公申论："天之夭难延，人之夭易延"，此论亦是训世人延养人自致之夭；伯高"在人之夭易延"之说乃由天师之教推广而来，读者不可因文辞归重伯高而轻视天师本论。

## 第五篇　命根養生篇

### 原文

伯高太师复问岐伯曰：养生之道，可得闻乎？

岐伯曰：愚何足以知之。

伯高再问，岐伯曰，人生天地之中，不能与天地并久者，不体天地之道也。天锡人以长生之命，地锡人以长生之根。天地锡人以命根者，父母子之也。合父母之精，以生人之身，则精即人之命根也。魂魄藏于精之中，魂属阳，魄属阴，魂趋生，魄趋死。夫魂魄皆神也。凡人皆有神，内存则生，外游则死。魂最善游，由于心之不寂也。

广成子谓：抱神以静者，正抱心而同寂也。

伯高曰：夫精者，非肾中之水乎？水性主动，心之不寂者，不由于肾之不静乎？

岐伯曰：肾水之中，有真火在焉。水欲下而火欲升，此精之所以不静也。精一动而心摇摇矣。然而制精之不动，仍在心之寂也。

伯高曰：吾心寂矣，肾之精欲动奈何？

岐伯曰：水火原相须也，无火则水不安，无水则火亦不安。制心而精动者，由于肾水之涸也。补先天之水以济心，则精不动而心易寂矣。

陈远公曰：精出于水，亦出于水中之火也。精动由于火动，火不动则精安能摇乎？！可见精动由于心动也，心动之极则水火俱动矣。

故安心为利精之法也。

### 异文校记

- "天地锡人以命根者，父母子之也"句：底本（维基文库）作『子』，古书网清抄本作『予』（"父母予之也"），按：存异，"予"训"给予"，与上句"天锡""地锡"之"锡（赐）"同义相承，古书网"予"于义似长；底本"子"或"予"之声近而讹，两存待考。

| 词语 | 注解 |

| 天锡 / 地锡 | "锡"通"赐"，谓天地赐予人长生之命与根。 |
| 父母子之 / 予之 | 父母给予（命根）；二源异文，详校记。 |
| 命根 | 生命之根本；本篇直指为"精"——合父母之精以生人之身。 |
| 魂魄 | 魂属阳而趋生、善游，魄属阴而趋死、主形；魂魄皆神之所藏。 |
| 内存则生，外游则死 | 神守于身则生，神驰于外则死，即"得神者昌，失神者亡"。 |
| 抱神以静 | 广成子之教（见第一篇），持守神气、同归于虚静。 |
| 真火 | 肾中真阳，寓于肾水之中，即命门之火。 |
| 水欲下而火欲升 | 肾水性润下、真火性炎上，二气相交则安，相激则精摇。 |

| 肾水之涸 | 肾阴干涸，则不能上济心火、制精不动。 |
| 补先天之水以济心 | 滋补肾中真阴（先天之水）以上济心火，则精自固、心自寂。 |
| 利精 | 安固、调摄精气。 |

### 白话大意与解读

伯高再问养生之道，岐伯谓人不能与天地并久，只因不能体法天地之道：天地以长生之命根锡人，命根实由父母之精而成——故"精即人之命根"。精中藏魂魄，魂魄皆神，神内存则生、外游则死；而魂最善游，其根在心之不寂。伯高疑精动由于肾水不静，岐伯辨之：肾水中有真火，水欲下、火欲升，精故不静；然制精之权仍在心寂。若心已寂而精犹欲动，则是肾水涸竭、水火失济，当补先天之水以济心，则精不动而心易寂。

**微言按语**：陈远公申论：精出于肾水，亦出于水中真火；精动根于火动，火不动则精摇无所自来——推极而言，精动实根于心动，心动之极则水火俱动。故"安心"为利精之根本法，治精治肾，终归治心。
