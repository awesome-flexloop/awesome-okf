# 结构导览：九卷八十一篇怎么读

## 总体结构：九卷九篇，九九八十一

今本《外经微言》九卷，每卷九篇，合计八十一篇（WJ-BIB-03）。全书仿《素问》《灵枢》体例，以黄帝君臣问答展开（WJ-BIB-16），每篇篇末附"陈士铎曰"或"陈远公曰"微言按语（WJ-BIB-17）。

主题分布的整体走向（WJ-RES-01）：**卷一立养生总纲 → 卷二卷三打经脉脏腑基础 → 卷四卷五推出命门水火核心理论 → 卷六卷七展开运气诊疗 → 卷八卷九落实到伤寒与辨证治则，终篇回到养生**。首尾呼应，是一部"从养生出发、以养生收束"的书。

## 问答人物谱

问答体是本书的基本论述形式。问难人物除岐伯（主要答者）外，还有二十余位（WJ-BIB-16）：

- **《内经》旧臣**：雷公（出现最多，问经脉、诊法、伤寒）、伯高、少师（问脏腑诸篇）、鬼臾区（问三才、五运六气）、少俞、少师
- **道家/上古人物**：广成子（卷一养生诸篇，与《庄子·在宥》互见，WJ-RES-11）、容成（容成公，问天癸生育）、天老、力牧、风后（问伤寒八风）
- **传说人物**：大挠（问天人一气、地气合人）、巫咸（问三关升降）、胡孔甲（问胆腑、冬夏火热）、奢龙（问奇恒、解阳解阴）、雍父（问六气独胜）、祝融（问暑火二气）、常伯（问阴阳上下）、鸟师（问亡阳亡阴）、云师（问瞳子散大）、大封司马（问水不克火）、奚仲（问表微）、盘盂（问阴寒格阳）、应龙、司马等

读法提示：问者的身份往往与问题领域相配——雷公问医经正事，广成子、容成问养生方术，鬼臾区、大挠问运气天人，风后、少俞问外感伤寒。这是作者借人物分工组织题材。

## 篇末"微言"按语怎么读

每篇篇末的"陈士铎曰"或"陈远公曰"是本书固定体例，**属原文组成部分**（WJ-BIB-17），不是后人批注。它的功能有三：

1. **点题**：用一两句话把通篇问答的主旨拎出，如善养篇末"善养一篇，俱非泛然之论，不可轻用攻补也"（WJ-RES-07）。
2. **转授语气**：常以"此天师/岐伯之微言，余何敢自秘"一类措辞收束，呼应"微言"书名——作者把自己定位为天师微言的转述者。
3. **读法警示**：如顺逆探原篇末提示"明知故问，亦欲尽人皆知"（WJ-TEX-06），红铅损益篇末的按语则体现对方术内容的分寸。

> ⚠️ 注意：维基文库电子本中夹带的"凌波按"等近人批注共 7 处（WJ-TEX-03），与"陈士铎曰"按语体例完全不同，**不是原文**，本知识包录文时已全部剔除。
