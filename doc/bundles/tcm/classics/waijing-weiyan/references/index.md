## 信源使用说明

- 概念文档（concepts/）与精读文档（examples/）通过 frontmatter 的 `sources` 字段引用信源，格式为 `id / resource / title` 三字段。
- 引用路径使用 bundle-relative 绝对路径（`/references/xxx.md`）。
- **原文工作底本**：维基文库《外經微言》各卷子页（简体转录本）；**对校信源**：古书网（繁体，清代抄本）、古诗文网、cloudtcm 等。双源实义异文在精读文档"异文校记"中逐条标注"某本作某"。
- **同源风险提示**：维基文库与古诗文网命门三章文本同源度极高，双源一致不能排除共同传抄之误；8 条电子本共同疑误已在精读文档中标注"存疑，待纸本裁定"。
- **版权边界**：原典原文为公共领域文献，可照录；1949 年后现代整理本的题解、白话译文、注解受版权保护，本知识包仅做书目登记与结论性引用，不转录其注文译文。
- **文献学分层**：《汉书·艺文志》著录之《黄帝外经》三十七卷已佚（著录层）；今本题"岐伯天师传"为托名叙事层；现存文本为清代陈士铎述《外经微言》九卷八十一篇（文本层）。三层关系详见 [概念 00：名实之辨](../concepts/00-what-is-huangdi-waijing.md)。
