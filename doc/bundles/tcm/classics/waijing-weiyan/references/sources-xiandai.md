## 四、工具书与背景文献（不直接引用，供延伸）

- 《汉书·艺文志·方技略》：医经七家著录"《黄帝内经》十八卷、《外经》三十七卷"等——著录层事实的原始出处。
- 《四库全书总目提要》：陈士铎《辨证录》等著作入存目，提要对"天师授受"叙事持疑——文献学考辨背景。
- 赵献可《医贯》、张景岳《景岳全书·传忠录》：明代命门水火学说代表，与《外经微言》命门三章对读。
- 《难经·三十六难/三十九难》："命门者，诸神精之所舍，原气之所系"——命门概念的经典源头。
- 《素问·灵兰秘典论》："主不明则十二官危"——命门经主篇直接化用的经文。

## 五、版权与引用边界

1. **可照录**：清代及以前文献原文（《外经微言》正文、篇末按语、《汉书·艺文志》等古文献）。
2. **仅登记与结论性引用**：表内现代书籍的注解、白话译文、章节结构——引用时标注"据某书"，不逐句转录。
3. **网络文章**（头条号、百科、科普帖）仅作线索，不作为学术结论依据；凡采用其数据（如"全书 94 处提及命门"），均标注"据当代网络研究文章统计，待纸本复核"。
4. 本知识包所有白话大意、字词注解均为撰写者依据公版原文自撰，不复制任何现代注本译文。
